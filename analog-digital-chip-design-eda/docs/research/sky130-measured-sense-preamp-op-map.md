# Sky130 Measured Sense Preamp OP Map

This page maps DC operating points for the measured-source differential preamp.

The question is narrow: before transient startup, can any preamp bias point settle with usable tail and output voltages while preserving the tiny input sign?

This is not converter acceptance. It is a DC bias map before transient startup, extracted-frontend loading, latch, SAR, energy, DRC/LVS, and strict evidence.
