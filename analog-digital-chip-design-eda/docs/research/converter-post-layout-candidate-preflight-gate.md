# Converter Post-Layout Candidate Preflight Gate

This page checks the actual preflight command. The current candidate scaffold should fail preflight. A complete temporary package should pass preflight. Neither path should submit evidence.

## First Principle

Preflight is not a claim that a converter is good. It is the door before judgment. It asks whether the packet is complete enough to inspect.

If names still point to placeholders, or referenced files do not exist, the packet cannot be judged yet.
