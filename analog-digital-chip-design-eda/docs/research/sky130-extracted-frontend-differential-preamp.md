# Sky130 Extracted Frontend Differential Preamp

This page tests the next active readout idea after passive gate coupling and a bare source follower failed.

The question is narrow: can a simple biased Sky130 differential pair read the extracted frontend sense nodes and create enough output difference for both signs?

This is still not a complete converter. It is a pre-latch handoff probe before latch, SAR, energy, area, DRC/LVS, and strict accepted evidence.
