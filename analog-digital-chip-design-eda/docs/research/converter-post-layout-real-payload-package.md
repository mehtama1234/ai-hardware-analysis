# Converter Post-Layout Real Payload Package

This page defines what must arrive from layout extraction, post-layout simulation, or measured silicon before the converter claim can change.

The package is deliberately stricter than a normal result table. A table can say that one ADC conversion costs some energy. The project needs to know what object produced that number, which files can be inspected, what boundary was simulated, and whether the same sharing rule was used when break-even was rerun.
