# Sky130 Preamp-Alone Latch Debug

This page is generated from the first isolated-latch debug-ladder step.

The regenerative latch is removed. The runner tests whether the preamp alone can settle from the target-edge input before latch reconnection. This separates preamp transient setup from latch resolution and latch kickback.

It is a debug result, not a latch proof, not SAR evidence, not layout evidence, and not accepted post-layout converter evidence.
