# Converter Post-Layout Handoff Manifest

This page is the handoff sheet for real converter evidence. It names the files, values, fixed boundary, and commands needed before the candidate package can move from scaffold to strict submission.

## First Principle

The next handoff should not depend on memory. It should say exactly what object to provide, what number to measure or simulate, and what command proves the packet is ready.

This manifest is not evidence. It is the checklist for producing evidence.
