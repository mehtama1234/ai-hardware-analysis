# Converter Post-Layout Candidate Submission Gate

This page checks the strict submission command. The current candidate scaffold should be rejected. A complete temporary package should write accepted-output files only inside a temporary directory.

## First Principle

Submission is different from preflight. Preflight asks whether a packet can be inspected. Submission writes the rerun artifact and report that later evidence pages may read.

For that reason, this gate proves the command path without writing canonical accepted evidence.
