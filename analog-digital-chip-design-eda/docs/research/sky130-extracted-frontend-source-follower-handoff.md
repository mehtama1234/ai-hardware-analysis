# Sky130 Extracted Frontend Source-Follower Handoff

This page tests the first active-isolation move after the passive gate-coupling sweep failed.

The question is narrow: can the extracted frontend drive a Sky130 source-follower buffer, and can that buffered signal then drive the real transistor readout pair with the right sign and enough output margin?

This is still not a complete converter. It is a handoff probe before latch, SAR, energy, area, DRC/LVS, and strict accepted evidence.
