# Sky130 Extracted Frontend Two-Stage Preamp

The first-stage transistor preamp had enough raw gain in some settings but carried a deterministic offset that consumed the target-edge margin. This test adds a second all-transistor differential gain stage after the first stage and subtracts the measured zero-input output as an explicit calibration diagnostic.

## Result

- extracted frontend: `sky130_ultra_sense_capacitive_frontend`
- stages: two Sky130 NMOS differential pairs with resistive loads;
- target-edge cases: `2/2` measured;
- zero-input output offset: about `-37.30 mV` under the tested transient setup;
- offset-corrected output: approximately `+2.05 mV` and `+2.11 mV` for the two target signs;
- offset-corrected polarity: `2/2`;
- offset-corrected margin: `2/2` above the `0.5 mV` target.

The evidence is [sky130-extracted-frontend-two-stage-preamp.json](../../evidence/aimc-simulator-adapters/sky130-extracted-frontend-two-stage-preamp.json), generated by `scripts/run_sky130_extracted_frontend_two_stage_preamp.py`.

## Interpretation

This is a meaningful circuit candidate: the first stage presents the extracted sense nodes to a transistor input pair, while the second stage supplies enough gain after that isolation. The established converter polarity contract is `positive model value = out_p - out_n`; the runner now evaluates the two-stage output using that convention.

The calibration number is large, so this is not yet a production-ready analog block. The next test must measure offset over mismatch and process/temperature corners, measure noise and decision time, and connect the calibrated preamp to the latch while measuring sampled-node kickback.

## Current-Mirror Load Experiment

The generator also supports a matched PMOS current-mirror load through
`AIMC_TWO_STAGE_LOAD_MODE=pmos_mirror`. This is a separate candidate mode and
does not replace the default resistor-loaded evidence. With an `8 um` mirror
device, the extracted two-stage preamp produced corrected target-edge outputs
of approximately `-0.523 mV/+1.593 mV` and preserved both signs. The connected
latch handoff artifact
`evidence/aimc-simulator-adapters/sky130-two-stage-pmos-mirror8-latch-handoff.json`
still resolved only `1/2` polarities because latch input-referred offset
remained dominant. The mirror load is therefore the leading preamp direction,
but it is not yet an accepted latch or converter solution.

Adding the existing transistor source-follower buffer after the `8 um`
current-mirror candidate reduced the measured latch-handoff zero-input offset
from roughly `154 mV` to `27 mV`, but the nominal target-edge handoff remained
`1/2` polarity decisions. Reducing the latch input width to `0.5 um` reduced
the offset further to about `25 mV` without restoring the missing polarity.
These results rule out latch loading alone as the complete repair.

The corrected-precharge capacitive latch was also tested with the `8 um`
current-mirror preamp. It resolved the negative target edge but not the
positive edge (`1/2`), and the latch-gate differential changed by roughly
`0.4 V` during evaluation. That is excessive for the intended low-kickback
interface, so this coupling arrangement is rejected as the offset-cancellation
solution. The evidence is
`evidence/aimc-simulator-adapters/sky130-two-stage-pmos-mirror8-capacitive-latch-correct-precharge.json`.

A balanced diode-connected PMOS load was also tested at `8 um`. It preserved
both signs but produced only approximately `-45 uV/+45 uV` corrected output,
below the `0.5 mV` isolated margin target. This rejects simple symmetric diode
loads as the gain solution; the next active-load design must retain differential
symmetry while increasing output resistance, for example with cascoding and a
defined common-mode bias.

A lower cascode bias was then evaluated. At `load bias = 1.2 V` and `cascode
bias = 0.4 V`, the symmetric cascode preamp passed both isolated target signs
with corrected outputs of approximately `-1.191 mV/+0.897 mV`. Its connected
latch handoff still resolved only `1/2` signs, with the positive case captured
by the wrong regenerative rail; the source-follower buffer did not repair that
result. This is the best cascode operating point found so far, but it still
requires a dedicated offset-cancelled differential latch interface.

A reset-controlled output equalizer was also added as an optional transistor
(`AIMC_LATCH_OUTPUT_EQUALIZER=1`) and tested with the best `0.4 V` cascode
point. It did not change the `1/2` nominal polarity result, ruling out output
node initialization alone as the dominant offset source. Offset cancellation
must act at the latch input/common-mode path.

An input-side sample-and-isolate network was then added using two Sky130 NMOS
switches and `20 fF` hold capacitors (`AIMC_LATCH_INPUT_SAMPLE_ISOLATION=1`).
With the `0.4 V` cascode preamp, the measured zero-input handoff offset fell
to approximately `2.04 mV`, but the target-edge latch still resolved only
`1/2` polarities. The network reduces DC loading and offset, but the stored
differential is still not large enough to dominate regeneration. Its evidence
is `evidence/aimc-simulator-adapters/sky130-two-stage-pmos-cascode4-bias04-input-sample-latch-handoff.json`.

Increasing the input hold capacitor to `100 fF` and the sampling switch to
`4 um` reduced the measured zero-input offset to approximately `0.493 mV`,
but the latch still resolved only `1/2` target signs. The larger sampler is
therefore an offset-reduction improvement, not yet a valid decision interface;
the missing signed separation must be generated before or within the latch
input pair.

A symmetric two-device PMOS cascode load was then implemented with explicit
load and cascode bias rails. The tested `1.0 V` and `0.8 V` cascode-bias points
collapsed the first-stage differential and failed the `0.5 mV` corrected-output
target. This rejects fixed-bias cascodes at those operating points and makes
the next requirement explicit: the cascode must be biased from a real
common-mode feedback or replica-bias circuit, not a guessed constant rail.

The best `0.4 V` cascode point was then separated from the coupled handoff by
driving the latch with ideal voltage sources equal to the measured preamp
outputs. This direct test resolved `1/2` target-edge polarities: the positive
edge produced the expected latch sign, while the negative edge was consumed by
the latch's input-referred offset at only about `0.153 mV` of preamp
differential. The named evidence is
`evidence/aimc-simulator-adapters/sky130-latch-alone-cascode4-bias04.json`.
This establishes that the preamp has a usable isolated sign, but the interface
still needs substantially more differential separation or explicit latch-input
offset cancellation. It also corrects the polarity interpretation: the latch
observable is `out_n - out_p`, the inverse of the converter's `out_p - out_n`
model contract.

When the measured zero-input offset is removed before the latch, the same
cascode outputs become `-1.191 mV` and `+0.897 mV`, and the ideal-source latch
resolves both target signs (`2/2`) with approximately `1.37 V` output
separation. This is an intermediate calibration proof, not a physical claim:
the offset subtraction is currently an ideal source transformation. Its
reproducible evidence is
`evidence/aimc-simulator-adapters/sky130-latch-alone-cascode4-offset-corrected.json`.
The next implementation must replace that ideal subtraction with a clocked
sample/hold or replica-based offset-cancellation circuit.

The best cascode front end was also run through the coupled handoff with
same-run output trim. The trim removed the measured `-312.3 mV` common
zero-input output difference, but the delivered signed separation at the
latch was only about `+45/-43 uV`; both target cases regenerated to the same
output sign (`0/2`). The named artifact is
`evidence/aimc-simulator-adapters/sky130-two-stage-pmos-cascode4-bias04-trimmed-latch-handoff.json`.
This rejects voltage trim as a complete solution: calibration must preserve
differential signal transfer while cancelling input-referred latch offset.
An additional ideal-source sweep tested a differential input trim as a proxy
for a calibration DAC. A `-0.5 mV` trim still left the negative edge wrong,
while `-10 mV` and larger trims flipped both cases together; no fixed trim
window resolved both signs. The sweep controls are implemented in
`scripts/run_sky130_latch_alone_from_preamp_voltage_debug.py` and the named
traces are retained under
`evidence/aimc-simulator-adapters/sky130-latch-alone-cascode4-input-trim-*.json`.
The next circuit revision therefore needs a dynamic offset-cancellation phase
or materially higher preamp differential gain, followed by the coupled
sample-and-kickback test.

The first dynamic charge-transfer implementation is now available in
`scripts/run_sky130_dynamic_offset_cancelled_latch.py`. It holds the measured
zero-input output during calibration, then steps to each measured target
output and transfers only the change through crossed `10 fF` capacitors into
an isolated Sky130 latch. The crossed polarity produces gate differentials of
approximately `+0.646/-0.498 mV` and resolves both target signs (`2/2`) with
about `+/-1.764 V` latch separation. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-offset-cancelled-latch-cascode4-crossed10f.json`.
This is the strongest interface milestone so far, but the source is still
measured-output PWL data; the next test must replace those sources with the
live extracted transistor preamp and then measure kickback and variation.

That live test is now implemented through the same runner with
`AIMC_DYNAMIC_LIVE_PREAMP=1`. It delays the input step, samples the extracted
frontend, and then evaluates the isolated latch. The `0.2`, `1`, `5`, and
`10 fF` coupling points all transferred signed gate movement but converged to
one latch state (`1/2` target signs); the `10 fF` point produced approximately
`+/-0.34 V` gate movement and is clearly too disturbing. The best live-path
artifact is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-0.2f.json`.
The next circuit revision must control the latch common-mode and clock
sequencing during charge transfer before it can be considered a coupled
offset-cancelled interface.

The live-path version with a calibration clamp and delayed input/sample clocks
also now records the preamp outputs at the latch handoff. At the tested `10
fF` point, both target cases reached approximately `0.86837 V` on both output
nodes (`-0.1 uV` differential) before regeneration, while the latch gate
differential was approximately `-0.312 V` in both cases. This localizes the
current live failure one stage earlier: the delayed extracted frontend is not
preserving target differential by the handoff time. The next clock revision
must establish a valid two-phase sequence for frontend sampling and output
settling before evaluating the latch. The artifact is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-clamped10f.json`.

A phase-corrected run at `1.2 V` gate bias preserved approximately `+/-0.35 V`
gate movement but left one input near `0.59 V`; both latch cases still chose
the same state. Raising the gate bias to `1.5 V` moved both inputs above
threshold, but reduced the transferred differential to approximately `10--110
uV` and produced no valid decision. These results reject bias-only common-mode
correction. The interface needs a dedicated common-mode level-shift/buffer
stage that preserves the calibrated differential before regeneration.

The dynamic runner now also supports clocked source isolation: matched Sky130
NMOS switches disconnect the preamp or buffer from the coupling capacitors at
the latch edge. In the live buffered test this removed the continuous
kickback path and preserved opposite gate-drive signs of approximately
`+10.1/-10.6 mV`, but the latch still resolved only `1/2` cases. The isolated
interface artifact is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated.json`.
This is a real improvement in interface containment, while input-referred
regenerative offset remains unresolved.

Matched gate common-mode restoration was tested with `1 GOhm` resistors to
the bias rail. It pulled the live latch-gate common-mode down to approximately
`0.31 V` while preserving `+/-0.38 V` differential, and the latch remained
`1/2`. This rejects a simple passive restoration resistor at that strength;
the interface needs an actively biased, high-impedance level-shift stage.
Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated-bias1g.json`.

The buffered interface was then tested with a fixed `1.5 V` receiving bias.
It raised the latch-gate common-mode to approximately `0.88 V`, but reduced
the transferred differential to below `0.3 uV`; the latch remained `1/2`.
This rejects a fixed-bias level shift and requires an active differential
charge-preserving common-mode stage. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated-bias15.json`.

Increasing the isolated latch input pair to `50 um` was also tested as a
current-drive remedy. It loaded the capacitive interface and reduced the
transferred differential from approximately `+/-10 mV` to only `+/-8 uV`,
while the latch remained at `1/2`. This rejects brute-force latch sizing and
supports the requirement for a high-impedance, calibrated input stage. The
trace is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated-input50.json`.

As a final isolation check, the latch gates were driven with fixed `0.8 V`
common-mode sources and `+/-18 mV` differential, matching the buffered live
interface measurement while removing all capacitor and preamp dynamics. The
latch resolved both target signs (`2/2`) with approximately `+/-1.664 V`
output separation. This proves the latch core can make the decision at the
available signal level; the remaining defect is specifically the live
charge-transfer network's gate waveform, not the regenerative core. Evidence:
`evidence/aimc-simulator-adapters/sky130-latch-gate-override-18mV.json`.

An explicit latch-input track-and-hold was then added with matched Sky130
tracking switches, `10 fF` hold capacitors, and `100 MOhm` common-mode returns.
The corrected probes show the actual held latch inputs at approximately
`0.458 V` common-mode, but with approximately `-0.214 V` differential for both
target signs; the latch consequently remains `1/2`. This rejects the current
hold-switch polarity/charge-transfer topology and establishes the next design
task: preserve opposite signed charge at the held nodes before regeneration.
Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated-inputhold-bias100m.json`.

The hold timing was then separated from regeneration by releasing the tracking
switch `0.5 ns` before latch evaluation. This produced a valid regenerated
decision for one polarity, but the held differential remained approximately
`-0.214 V` for both target signs, so the result was still only `1/2`.
The timing separation is therefore useful instrumentation, but it does not
close the signed-data handoff. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-isolated-inputhold-releaseearly.json`.

An active matched PMOS receiver with resistive loads was added as a transistor
level-shift and gain stage. Its outputs were sampled directly by the latch
track-and-hold, bypassing the second capacitive interface. The receiver was
measured explicitly: it produced approximately `-69.4 mV` and `-73.3 mV` for
the two opposite target signs, so the sign is already lost before latch
regeneration. This identifies receiver startup/offset cancellation as the
next circuit problem; it is not evidence of a closed converter. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-active-receiver-directhold-probed.json`.

Matched NMOS branch-current trim was added as a calibrated auto-zero actuator.
A small trim setting moved the receiver offset only slightly, while a larger
setting crossed the offset and moved the measured differential from about
`-66 mV` to `+245 mV`. This proves the actuator has control authority, but the
intermediate capacitive handoff at the tested point did not converge, and no
trimmed setting has yet produced both signed decisions. The runner now records
such ngspice timeouts as failed evidence cases instead of dropping the report.

A matched PMOS source-follower level-shift stage was also inserted after the
receiver to raise its low DC common-mode before latch sampling. After fixing
the device source/drain orientation, the live run still failed the two-polarity
gate condition (`0/2` in the tested run; one case also timed out). This rejects
the level shift as a sufficient fix by itself and leaves calibrated differential
hold loading and receiver operating point as open design requirements.

The receiver operating-point sweep found a better direct candidate at
`W=0.5 um` and `R_D=500 kOhm`: both live cases converged, the output common-mode
was approximately `1.70 V` before sampling, and the receiver differential offset
was approximately `-4.6 mV`. A `0.10 V` transistor trim moved that differential
to approximately `+28.8 mV`, proving the calibration range. Intermediate
`1 um/300 kOhm` sizing did not converge in either polarity, so it is rejected.
The remaining task is to combine the stable `0.5 um/500 kOhm` operating point
with a finer auto-zero trim and a high-gain, non-loading second stage.

A first transistor-level attempt at that second stage used a matched NMOS pair,
independent resistive loads, and a `4 uA` tail current driven directly from
the receiver outputs. The two live polarity cases both hit the ngspice timeout
and produced no valid decision. This rejects a naïve direct-coupled gain stage:
the next amplifier must include an explicitly designed input common-mode range,
tail bias, and output swing rather than simply adding another differential pair.

The gain-stage input was then biased through matched `1 Mohm/1 Mohm` dividers,
reducing the receiver common-mode from approximately `1.7 V` to the nominal
NMOS input range. This allowed one polarity to converge, but the opposite
polarity still timed out; the resulting run is not accepted. A robust next
stage therefore needs a startup/reset path and controlled output common-mode,
not only resistor attenuation.

Adding matched reset switches to precharge the gain outputs before evaluation
restored two-case convergence. With the stable `0.5 um/500 kOhm` receiver and
fine trim `0.0102 V`, the receiver residual itself straddled zero at
approximately `+17 uV` and `-145 uV` for the two target signs. The final latch
still saw a same-sign gain-stage offset, so this is not an accepted converter
result; it establishes that the next calibration actuator belongs at the gain
stage output, after reset, rather than at the original preamp input.

After correcting the control flag in the runner, the resettable gain stage was
rerun as an actually enabled circuit. With `R_D=300 kOhm`, `I_tail=2 uA`, and
gain-output trim `0.00040 V`, both cases converged and the measured latch-gate
calibration residuals straddled zero at approximately `-29.9 uV` and
`+21.7 uV`. The final latch still made the same decision for both cases because
this residual is below its practical input margin, but the signed signal is now
stable through the active receiver and resettable gain stage. The next step is
additional gain or a lower-offset regenerative input, followed by PVT and
mismatch validation.

A matched transistor common-source buffer was then added between the live
extracted preamp and the capacitive interface. It moved the latch inputs to a
healthier approximately `0.8 V` common-mode and preserved about `+/-18 mV`
differential, but both polarity cases still regenerated to the same latch state
(`1/2`). The buffer inversion was tested with both crossed and uncrossed
capacitor wiring; neither orientation closed the decision. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1.json`
and
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-buffer1-uncrossed.json`.
The remaining interface requirement is therefore an explicitly reset,
offset-cancelled regenerative stage, not another passive coupling or gain
change.

An explicit reset/equalizer NMOS was then added across the regenerative output
nodes and released at the latch clock edge. It changed the live gate
differential to approximately `+/-45 mV` at the tested phase point but did not
change the final decision (`1/2`). This rejects output-node initialization as
the dominant cause and leaves input-referred offset/common-mode capture as the
next circuit target. The trace is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-cascode4-phase-latch6-eq.json`.

## Boundary

The latch tail was also changed to a dedicated biased Sky130 NMOS current
device enabled by a timed bias pulse, rather than using the clock directly as
the tail gate. With input sampling enabled, this reduced the measured
zero-input offset to approximately `1.74 mV`, but the latch still resolved only
`1/2` target signs. Tail-current control alone is therefore not sufficient;
the input pair still needs a balanced offset-cancellation mechanism.

This is extracted frontend plus schematic two-stage transistor-preamp evidence. It does not prove a drawn preamp layout, statistical offset yield, noise, latch resolution, latch kickback, DRC/LVS, SAR bit cycling, or accepted post-layout converter economics.

Increasing the resettable gain-pair width to `4 um` did not improve signed
margin. A separate low-tail-current trial (`0.2 uA`) converged in both cases,
but also produced a same-sign latch response. These results reject width-only
and tail-current-only tuning. The next physical revision must use a folded or
regenerative gain architecture with an explicitly controlled output common
mode; the current resistor-loaded stage is retained as a diagnostic baseline.

The existing PMOS-input dynamic latch candidate was also rerun against the
extracted frontend. It converged for both target cases, but produced the same
output polarity (`1/2`). This shows that changing the regenerative direction
and precharge level alone does not remove the upstream signed-offset problem;
the calibrated differential signal must be amplified and held before either
latch architecture can be accepted.

For comparison, the existing three-stage resistor-loaded preamp/latch was
rerun with same-run trim. It converged in both cases and produced sizable
third-stage drive differentials (`-324 mV` and `-356 mV`), but the final latch
still returned only `1/2` correct polarities. This rejects adding an uncalibrated
third resistor-loaded stage as the closure path; the next revision must carry
the differential calibration state into the regenerative decision itself.

An optional resettable regenerative intermediate stage was then inserted after
the active receiver. It converged for both cases and amplified the input to
approximately `1.19 V` differential at the next latch interface, proving that
the positive-feedback stage is electrically active. It nevertheless made the
same decision for both polarities, so its own input-referred offset dominates
the calibrated residual. This candidate is rejected until calibration is
applied before the regenerative release or included in the regeneration loop.

A differential trim pair was added directly to the regenerative-stage outputs.
At a coarse `-0.05 V` trim it moved the regenerated differential to roughly
`-1.20 V` in both cases without recovering polarity. This confirms output trim
authority but rejects coarse post-regeneration correction; calibration must be
resolved at a much finer current/voltage step before positive feedback is
released.

An optional reset-phase equalizer was then placed directly between the two
regenerative-stage output nodes. It is enabled only while the existing reset
devices precharge the nodes and is released before positive feedback. With the
same stable receiver/gain settings, both transient cases converged, but the
regenerative gate differential remained approximately `-1.535 V` for both
input polarities and the latch result remained `1/2`. This rejects unequal
regenerative-node startup as the dominant failure mechanism. The evidence is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-regen-equalizer-diagnostic.json`.
The next calibration revision must capture and subtract the receiver/gain
input-referred offset before regeneration rather than equalizing only the
regenerative output nodes.

The next diagnostic added reset switches from both regenerative input nodes to
the calibrated common-mode node. This holds the input pair at a known common
mode during reset and releases it with the regenerated stage. The two live
cases still converged, but both produced the same positive latch state (`1/2`)
and approximately `+1.541 V` regenerative gate differential. Input-node reset
alone therefore does not remove the receiver/gain input-referred error. The
evidence is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-regen-input-reset-diagnostic.json`.
The required next step is a true auto-zero storage element or differential
subtraction path that measures the zero-input receiver output and subtracts it
from the target transition before the regenerative pair is enabled.

An optional AC-coupled regenerative-input path was implemented to carry only
the receiver/gain transition while matched `1 Mohm` resistors restored both
inputs to the calibrated common mode. The initial `20 fF` coupling run was
`1/2`; increasing the coupling to `100 fF` and releasing regeneration later
still produced `1/2`, with approximately `-1.542 V` regenerative differential
for both polarities. The stronger-charge experiment therefore rejects weak
AC transfer as the primary cause. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-regen-ac-input-100f-diagnostic.json`.
The remaining design requirement is a differential auto-zero that changes the
receiver/gain operating point itself, or a calibrated current subtraction at
that stage, before its output drives any regenerative pair.

To separate that missing analog calibration from downstream latch behavior, an
explicit idealized offset-cancelled source was added to the dynamic runner. It
replaced each raw preamp target with the measured target-minus-zero transition,
using the documented offset-corrected differential values. With the default
crossed capacitor orientation the two outputs were reversed (`0/2` against the
contract), while the physically corresponding uncrossed orientation resolved
both target polarities (`2/2`). This proves that the corrected signed signal
survives the receiver, gain, and regenerative stages; it does not claim that
the ideal source is a physical auto-zero implementation. The evidence is
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-ideal-autozero-source-uncrossed-diagnostic.json`.
The remaining implementation is therefore to realize this target-minus-zero
operation with a clocked capacitor/current-subtraction network at the
preamp-to-receiver boundary and retain the uncrossed polarity mapping.

That physical boundary was then implemented as an optional matched capacitive
interface from the extracted preamp outputs to the PMOS receiver gates, with
`1 Mohm` common-mode restoration. The first run with the old crossed mapping
was reversed (`0/2`); switching to the corresponding uncrossed mapping produced
opposite signed receiver differentials of approximately `-0.213 mV` and
`+0.323 mV`, regenerative gate differentials of approximately `-1.541 V` and
`+1.541 V`, and final latch decisions of `+1.8 V` and `-1.8 V` (`2/2`). This is
the first nominal transistor-level auto-zero interface result that preserves
both target signs. It remains a diagnostic: the coupling capacitors and
restoration network still require PVT, mismatch, noise, kickback, layout, and
SAR-cycle validation before the physical converter gate can open. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-uncrossed-diagnostic.json`.

A `1 Mohm` receiver-load variant was also rerun with the same auto-zero
interface. It retained the `2/2` polarity result, with receiver differentials
of approximately `-0.225 mV` and `+0.341 mV`, but its output common mode did not
move materially from the low-rail region. The larger load is therefore not
promoted as a common-mode fix; the `0.5 um / 500 kohm` receiver remains the
stable nominal baseline. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-rd1m-diagnostic.json`.

The successful `0.5 um / 500 kohm` auto-zero interface was then rerun with the
Sky130 `ss` and `ff` model sections at `27 C`; both corners converged and
resolved both target polarities (`2/2`). This is process-corner evidence for
the nominal-supply auto-zero path, not a complete PVT or yield claim. Supply,
temperature, mismatch, noise, kickback, layout extraction, and continuous SAR
integration remain open gates. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-ss27-diagnostic.json`
and
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-ff27-diagnostic.json`.

The waveform and frontend supply levels were then made supply-relative and the
path was exercised at a slow, low-voltage, hot corner (`ss`, `1.62 V`, `85 C`).
Both target polarities still resolved correctly (`2/2`). This closes one
representative supply/temperature corner for the auto-zero interface, but it
is not a full PVT or statistical-yield result. Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-ss162-85-diagnostic.json`.

The opposite fast/high-voltage/cold corner (`ff`, `1.98 V`, `-20 C`) also
converged and resolved both polarities (`2/2`). Together with the `ss` and `ff`
nominal-supply runs, this gives four representative process/supply/temperature
points for the auto-zero interface. It is still not a statistical mismatch or
noise-yield proof, and it does not replace full continuous-SAR validation.
Evidence:
`evidence/aimc-simulator-adapters/sky130-dynamic-live-offset-cancelled-latch-receiver-ac-autozero-ff198-cold-diagnostic.json`.
