# Converter Post-Layout Candidate Readiness Run

This page shows the one-command readiness path for the candidate post-layout package. It refreshes the audit, checklist, progress report, and preflight result, then stops before strict submission.

## First Principle

The package should not jump straight from a filled JSON file to an accepted claim. It should pass through ordered checks: workspace completeness, checklist closure, progress state, and preflight readiness.

Only then is strict submission allowed to start.
