# Converter Post-Layout Candidate Progress Gate

This page checks the progress report itself. The real candidate folder should stay closed while it is still a scaffold. A complete temporary folder should make the same reporter say ready for preflight.

## First Principle

A readiness gate has to reject the wrong object and accept the right-shaped object. Otherwise it is not a gate. It is just text.

This proof does not submit evidence. It only checks whether the status logic changes for the correct reason.
