Sky130 Balanced Extracted Frontend To Latch Handoff

This is the first connected transient between the Magic-extracted balanced frontend and the Sky130 transistor latch.

The test is important because the previous reports tested these objects separately:

  • the extracted balanced frontend preserved both input signs at its sense nodes (4/4 cases);
  • the ideal-input transistor latch resolved the target sign;
  • the combined object had not yet been tested.

The connected run measures both input polarities and the sampled-node differential against the 12-bit half-LSB limit.

Result

  • measured cases: 2/2
  • correct complete output decisions: 0/2
  • sampled-node kickback: 0 V in this setup, because the source-side sample nodes remained fixed;
  • sense differential before latch evaluation: about +16.7 mV for both input signs;
  • output behavior: both cases resolve to the same polarity.

The evidence is sky130-balanced-extracted-latch-kickback.json, generated by scripts/run_sky130_balanced_extracted_latch_kickback.py.

Interpretation

This is not a failure of latch regeneration time. Extending the measurement from 2.6 ns to 4.6 ns produced full rail separation, but the negative and positive input cases still produced the same output sign. The failure occurs earlier: the latch input devices load the extracted sense nodes and create a much larger one-sided bias than the roughly 15–16 uV differential produced by the balanced frontend alone.

The next circuit move is therefore an isolation or buffering stage with a defined input capacitance and common-mode behavior. Simply increasing latch time or changing the digital polarity convention cannot repair this handoff.

Refused Claim

This does not prove offset, noise, mismatch, DRC/LVS, SAR bit cycling, full converter behavior, or accepted post-layout economics. The sample sources are still ideal voltage sources, so the measured zero sampled-node kickback is not a complete source-impedance result.
