# Fine-grained Automated Failure Management for Extreme-Scale GPU Accelerated Systems

**Venue:** SC  
**Theme:** Fault Tolerance and System Reliability  
**Confidence:** low

## Problem Statement
As HPC systems scale, hardware failure rates increase; mean time to repair (MTTR) becomes critical bottleneck, with MTBF decreasing for GPU-accelerated systems

## Motivation
Future exascale systems will experience more frequent hardware failures; automated recovery strategies minimizing MTTR are essential for system availability and cost efficiency

## Methodology
Centralized meta-database tracking event history with correlated event analysis; fine-grained multi-strike repair policies; automated recovery framework deployed on Aurora supercomputer

## Key Novelty
First fine-grained automated failure management system for exascale GPUs; uses correlated event analysis and multi-strike policies for intelligent recovery

## Contributions
- Centralized meta-database for event history and correlation analysis
- Fine-grained multi-strike repair policies
- Automated recovery framework with real-time decision making
- 84X reduction in MTTR compared to manual servicing on Aurora

## Hardware Targets
Aurora supercomputer, Intel Ponte Vecchio GPUs, Exascale systems

## Technique Categories
Fault management, Failure prediction, Recovery algorithms

## Workloads
HPC applications, GPU workloads

## Performance Metrics
- **mttr_reduction:** up to 84X vs manual servicing
- **system_downtime:** reduced

## Baselines Compared
- Manual failure servicing

## Limitations & Future Work
Limited to Aurora deployment; generalizability to other systems not discussed; MTBF projection methodology not detailed
