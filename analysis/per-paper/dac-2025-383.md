# GSAcc: Accelerate 3D Gaussian Splatting via Depth Speculation and Gaussian-centric Rasterization

**Venue:** DAC
**ID:** dac-2025-383

## Problem
GPU-based 3D Gaussian Splatting rendering suffers from insufficient parallelism in sequential pipeline stages and large memory overhead for intermediate results.

## Motivation
Real-time photorealistic rendering on edge devices requires specialized hardware; dataflow optimization can eliminate serialization bottlenecks.

## Method
GSAcc introduces Gaussian depth speculation to parallelize preprocessing and sorting. A Gaussian-centric dataflow interleaves preprocessing and rasterization, executing all steps concurrently without storing intermediates. Dedicated hardware accelerates sorting and rasterization.

## Key Novelty
Gaussian-centric dataflow interleaving preprocessing and rasterization to eliminate intermediate storage and enable full parallelism.

## Contributions
1. Gaussian depth speculation enabling parallel preprocessing and sorting
2. Gaussian-centric dataflow interleaving all rendering stages without intermediate storage
3. Dedicated hardware acceleration for sorting and rasterization bottlenecks
4. 16,600x PPA improvement vs desktop GPUs, 48.7x energy savings, 2.3x PPA improvement over GSCore
