# GSAcc: Accelerate 3D Gaussian Splatting via Depth Speculation and Gaussian-centric Rasterization

**Venue:** DAC
**ID:** dac-2025-383

## Problem
GPU-based 3D Gaussian Splatting rendering suffers from insufficient parallelism in sequential pipeline stages and large memory overhead for intermediate results.

## Motivation
Real-time photorealistic rendering on edge devices requires specialized hardware; dataflow optimization can eliminate serialization bottlenecks.

## Method
GSAcc uses a technique called Gaussian depth speculation—predicting the depth ordering of Gaussian elements (a way of representing 3D objects as blobs) early on to parallelize the initial steps. Instead of processing Gaussian elements through sequential stages one-by-one, it reorganizes the pipeline around Gaussian elements themselves (Gaussian-centric dataflow), allowing preprocessing and rasterization (converting the Gaussian elements into pixels) to happen at the same time rather than one after the other. This avoids storing temporary results between stages, freeing up memory. Dedicated hardware accelerators handle the sorting and rasterization operations faster than the GPU alone.

## Key Novelty
The key innovation is reorganizing the rendering pipeline around Gaussian elements so preprocessing and rasterization can happen simultaneously, eliminating the need to store intermediate results and allowing all stages to run in parallel.

## Contributions
1. Gaussian depth speculation enabling parallel preprocessing and sorting
2. Gaussian-centric dataflow interleaving all rendering stages without intermediate storage
3. Dedicated hardware acceleration for sorting and rasterization bottlenecks
4. 16,600x PPA improvement vs desktop GPUs, 48.7x energy savings, 2.3x PPA improvement over GSCore
