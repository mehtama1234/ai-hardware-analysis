# hpca-2025-099 — HSMU-SpGEMM: Achieving High Shared Memory Utilization for Parallel Sparse General Matrix-Matrix Multiplication on Modern GPUs

**Venue:** HPCA  
**Authors:** Min Wu, Huizhang Luo, Fenfang Li, Yiran Zhang, Zhuo Tang, Kenli Li, Jeff Zhang, Chubo Liu  
**Confidence:** low (abstract only)

## Problem
Hash-based SpGEMM algorithms on GPUs fail to simultaneously minimize hash collisions and efficiently utilize fast shared memory, causing significant performance degradation.

## Motivation
SpGEMM is a core primitive for scientific computing, and the memory bandwidth and shared memory of modern GPUs are underutilized by existing hash-based approaches.

## Method
HSMU-SpGEMM introduces a novel accumulator design that maximizes shared memory utilization on modern GPUs by rethinking hash-based accumulation to reduce collision overhead while packing more active data into shared memory. The symbolic stages (row count, product computation) are also optimized to complement the new accumulator. Evaluation covers three GPU generations: Ampere, Ada Lovelace, and Turing.

## Key Novelty
A new GPU accumulator design that achieves high shared memory utilization for SpGEMM by decoupling collision reduction from memory packing efficiency.

## Contributions
- Novel accumulator design achieving high shared memory utilization for GPU SpGEMM
- Optimization of symbolic SpGEMM stages
- Significant improvements over Nsparse, spECK, OpSparse, cuSPARSE across three GPU generations
