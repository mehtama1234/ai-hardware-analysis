# hpca-2025-099 — HSMU-SpGEMM: Achieving High Shared Memory Utilization for Parallel Sparse General Matrix-Matrix Multiplication on Modern GPUs

**Venue:** HPCA  
**Authors:** Min Wu, Huizhang Luo, Fenfang Li, Yiran Zhang, Zhuo Tang, Kenli Li, Jeff Zhang, Chubo Liu  
**Confidence:** low (abstract only)

## Problem
Hash-based SpGEMM algorithms on GPUs fail to simultaneously minimize hash collisions and efficiently utilize fast shared memory, causing significant performance degradation.

## Motivation
SpGEMM is a core primitive for scientific computing, and the memory bandwidth and shared memory of modern GPUs are underutilized by existing hash-based approaches.

## Method
HSMU-SpGEMM redesigns how GPUs accumulate (collect and combine) partial results in sparse matrix multiplication by separating two competing demands that usually force a compromise: reducing hash collisions (when multiple values map to the same memory address) and efficiently packing data into fast shared memory. Rather than solving both together, the new accumulator tackles each independently, allowing more useful data to fit in shared memory while keeping collisions low. The design also optimizes earlier calculation stages (row counting and product computation) to work better with the new accumulator, with testing on three GPU types (Ampere, Ada Lovelace, Turing) showing the improvement.

## Key Novelty
By decoupling collision reduction from memory packing efficiency, the new accumulator design allows both to be optimized independently rather than forcing a tradeoff between them.

## Contributions
- Novel accumulator design achieving high shared memory utilization for GPU SpGEMM
- Optimization of symbolic SpGEMM stages
- Significant improvements over Nsparse, spECK, OpSparse, cuSPARSE across three GPU generations
