# An Input-Aware Sparse Tensor Compiler Empowered by Vectorized Acceleration

**Venue:** DAC 2025  
**Confidence:** low (abstract-only)

## Problem
Existing tensor compilers struggle with sparse tensor operations, especially sparse matrix-matrix multiplication (SpMM). Rigid sparse formats and lack of input-aware optimization force choice between manual tuning (expensive) and generic code (slow).

## Key Insight
Analyzing non-zero distribution at compile time enables generation of vectorized kernels optimized for specific sparsity patterns, eliminating the need for manual per-matrix tuning.

## Approach
- **SpMMTC compiler:** Input-aware analysis of sparse matrix structure
- Vectorized kernel generation tailored to sparsity pattern
- Hardware-aware optimization (SIMD width, cache hierarchy)
- Pattern-specific unrolling and parallelization strategies

## Results
- **1.21–2.97× speedup** vs. TACO, TVM, ASpT on multi-core CPUs
- **1.52× speedup** for sparse MobileNetV1 inference on edge devices
- No manual kernel rewriting required; purely compiler-driven optimization

## Workloads Addressed

- Graph analytics (sparse adjacency matrices)
- HPC sparse linear algebra
