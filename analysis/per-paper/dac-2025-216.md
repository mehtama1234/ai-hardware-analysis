# Late Breaking Results: An Efficient and Scalable Track Assignment with GPU Parallelism

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Track assignment (between global/detail routing) is compute-intensive bottleneck limiting design iteration speed.

## Key Insight
Track assignment tasks are divisible and independent; fine-grained asynchronous GPU parallelism exploits this structure.

## Method
GPU-accelerated algorithm with asynchronous fine-grained task partitioning of routing resources and assignment; simultaneous global/local net consideration improves routability.

## Contributions
- GPU-accelerated parallel track assignment
- Asynchronous fine-grained parallelism
- Improved routability estimation
- Significant speedup vs. sequential

## Hardware Target
GPU

## Workloads
HPC (EDA)

## Theme
GPU parallelization of track assignment for physical design acceleration.
