# Late Breaking Results: An Efficient and Scalable Track Assignment with GPU Parallelism

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Track assignment (between global/detail routing) is compute-intensive bottleneck limiting design iteration speed.

## Key Insight
Track assignment tasks are divisible and independent; fine-grained asynchronous GPU parallelism exploits this structure.

## Method
Uses graphics processors (GPUs) to speed up track assignment by breaking the work into small, independent tasks that run in parallel. It separates routing resource computation from track assignment, allowing them to execute asynchronously (without waiting for each other in sequence). By considering both global network paths and local connections simultaneously, it produces better estimates of whether the routing will fit.

## Contributions
- GPU-accelerated parallel track assignment
- Asynchronous fine-grained parallelism
- Improved routability estimation
- Significant speedup vs. sequential
