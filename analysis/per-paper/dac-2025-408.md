# SDM-PEB: Spatial-Depthwise Mamba for Enhanced Post-Exposure Bake Simulation

**Problem:** PEB simulation needs precise 3D modeling of photoacid diffusion and inhibitor reactions to maintain resist profile accuracy in lithography.

**Method:** SDM-PEB begins by extracting features at multiple scales using overlapping image patches that are hierarchically merged together—this lets the system recognize both broad patterns and fine details in the 3D resist structure. The core is a Mamba-based attention unit (a neural network layer that learns which parts of the 3D space matter most), which uses customized selective scanning (efficiently focusing computation on relevant data instead of processing everything equally) and structured state space models (a mathematical framework for tracking how chemical concentrations change over time). This combination captures how photoacids and inhibitors spread vertically between layers and how they vary spatially within each layer.

**Key Result:** Outperforms previous methods in accuracy and efficiency (validated against commercial rigorous models).

**Hardware Target:** GPU, ASIC  
**Workloads:** HPC, database  
**Confidence:** low (abstract-only)
