# isscc-2025-094: Adaptive Wireless Power Receiver for IMDs

## Summary
Programming-free resonant current-mode wireless power receiver with real-time link-adaptivity and compact 3D coil (0.904cm³) for implantable medical devices.

## Key Contributions
- Programming-free real-time link-adaptivity
- Compact 3D receiver coil integration
- Low-power wireless reception
- Tissue-safe operation

## Hardware Target
ASIC
