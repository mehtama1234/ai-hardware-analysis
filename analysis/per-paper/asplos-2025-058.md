# asplos-2025-058 — Wave: Offloading Resource Management to SmartNIC Cores

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Userspace system software tasks (kernel thread scheduling, memory management, RPC stacks) consume scarce host CPU cores in cloud servers, reducing the compute available to paying tenants. Existing SmartNIC offload frameworks require custom APIs and cannot handle microsecond-scale system software latencies without host CPU involvement.

## Motivation
Datacenter operators are under pressure to maximize the fraction of server CPU cycles available to tenants; SmartNICs with ARM cores are now widely deployed but underutilized for host system software offload due to latency and API mismatch.

## Method
Wave is a framework that runs existing Linux userspace system software (unchanged or minimally modified) as processes/agents on mid-tier SmartNIC ARM cores. It introduces a new host-SmartNIC communication API designed to support microsecond-scale decision latencies, enabling offload of preemption-sensitive tasks such as the kernel thread scheduler. The framework uses Linux userspace system interfaces to align host OS functionality with SmartNIC capabilities, avoiding custom kernel modifications on the host side.

## Key Novelty
A general framework and microsecond-latency host-SmartNIC communication API that enables offloading of latency-sensitive userspace system software (scheduling, memory management, RPCs) to SmartNIC ARM cores with minimal code changes.

## Contributions
- Wave framework architecture enabling execution of preexisting userspace system software on SmartNIC ARM cores.
- New host-SmartNIC communication API supporting us-scale system software offload.
- Offload case studies: kernel thread scheduling (saving 16 host cores for memory management), RPCs (saving 8 host cores), and VM management (11.2% performance improvement).
- Empirical measurement of performance overhead (1.1%-7.4%) vs. on-host implementations.
