# GMI-DRL: Empowering Multi-GPU DRL with Adaptive-Grained Parallelism

**Problem:** Deep reinforcement learning workloads exhibit irregular computation patterns that are inefficiently parallelized across multiple GPUs with fixed granularity strategies. The key challenge is determining optimal parallelism granularity that adapts to dynamic workload characteristics.

**Method:** GMI-DRL monitors the workload and switches its parallelization strategy in real time between two approaches: for bursty, irregular computation, it uses fine-grained task parallelism (breaking work into many small parallel tasks so every GPU stays active), and for more uniform workloads, it uses coarse-grained pipeline parallelism (feeding work sequentially through GPU stages to reduce communication overhead).

**Novelty:** The key innovation is automatically switching between fine-grained task parallelism and coarse-grained pipeline parallelism based on real-time GPU workload patterns.
