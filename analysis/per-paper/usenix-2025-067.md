# GMI-DRL: Empowering Multi-GPU DRL with Adaptive-Grained Parallelism

**Problem:** Deep reinforcement learning workloads exhibit irregular computation patterns that are inefficiently parallelized across multiple GPUs with fixed granularity strategies. The key challenge is determining optimal parallelism granularity that adapts to dynamic workload characteristics.

**Method:** GMI-DRL dynamically adjusts the granularity of parallel tasks across multiple GPUs by monitoring workload characteristics and GPU utilization patterns. It adapts between fine-grained task parallelism and coarse-grained pipeline parallelism based on real-time feedback.

**Novelty:** Adaptive-grained parallelism framework that dynamically adjusts granularity in real-time for multi-GPU DRL execution to maximize efficiency.
