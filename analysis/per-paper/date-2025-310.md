# Handling Latch Loops in Timing Analysis with Improved Complexity and Divergent Loop Detection

**Venue**: DATE  
**Primary Theme**: Scalable latch loop handling in static timing analysis  

## Problem
Latch loops introduce feedback cycles in timing graphs disrupting static timing analysis; existing timers require global iterations with worst-case O(n²) complexity where n is number of pins.

## Method
The algorithm breaks the timing graph into cycles (called strongly connected components) and arranges them into layers. It calculates how signals propagate in parallel across different layers, but works through each cycle step-by-step. It also detects divergent loops—cycles where the calculation won't converge—so it can skip those unnecessary iterations.

## Key Novelty
By breaking timing feedback loops into independent groups (strongly connected components) and looking ahead for cycles that won't converge, the method cuts computation from quadratic in all pins to quadratic in each group's size.

## Contributions
- Complexity reduction from O(n²) to O(Σk_i²)
- 10.31× speedup over PrimeTime on average
- 8.77× speedup over OpenSTA on average
- Divergent loop detection avoiding over-iteration
