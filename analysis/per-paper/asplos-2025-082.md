# COMET: Towards Practical W4A4KV4 LLMs Serving

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Standard activation quantization to 4-bit causes unacceptable accuracy loss, making W4A4 impractical despite INT4 tensor core availability on modern GPUs, and leaving KV cache memory bandwidth largely unaddressed by existing W8A8 or W4-only methods.

## Motivation
LLM inference is bottlenecked by GPU memory bandwidth and capacity; W4A4KV4 would halve memory traffic vs W8A8, but requires solving the activation outlier accuracy problem to be deployable.

## Method
COMET introduces FMPQ (fine-grained mixed-precision quantization), which compresses most activations to INT4 while retaining outliers at INT8 in a mixed-precision format. A highly optimized W4Ax GPU kernel implements both W4A4 and W4A8 GEMM using a novel mixed-precision data layout that co-locates 4-bit and 8-bit elements for fast dequantization. GPU software pipelining overlaps loading and conversion with compute, and fine-grained SM scheduling balances load across streaming multiprocessors. COMET integrates this into a full inference framework with KV4 cache management supporting LLaMA-3-70B on a single A100-80G.

## Key Novelty
FMPQ enabling practical W4A4 by selectively retaining outlier activations at INT8, combined with a W4Ax kernel with mixed-precision data layout and SM-level load-balanced scheduling to fully exploit INT4 tensor cores.

## Contributions
- FMPQ: fine-grained mixed-precision algorithm compressing most activations to INT4 with negligible accuracy loss
- Optimized W4Ax kernel with mixed-precision layout, software pipelining, and fast dequantization
- Fine-grained SM scheduling for load balance across streaming multiprocessors
- COMET framework: first practical W4A4KV4 LLM serving; 2.88x kernel speedup vs cuBLAS, 2.02x throughput vs TensorRT-LLM
