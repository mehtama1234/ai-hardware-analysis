# hpca-2025-035: EXION: Exploiting Inter- and Intra-Iteration Output Sparsity for Diffusion Models

**Venue:** HPCA  
**Confidence:** high (full text)  
**Authors:** Jaehoon Heo, Adiwena Putra, Jieon Yoon, Sungwoong Yune, Hangyeol Lee, Ji-Hoon Kim, Joo-Young Kim (KAIST)

## Problem
Diffusion model inference requires up to 1000 denoising iterations through transformer blocks (38-100% of operations per model), causing 23.6x higher energy and 9.8x higher latency than GANs on identical GPUs. Prior transformer accelerators target only QKV and attention within a single iteration, ignoring inter-iteration redundancy and the dominant FFN layer overhead (up to 67% of per-iteration ops in transformer blocks).

## Motivation
Diffusion models are increasingly deployed for text-to-image, -video, -audio, and -motion generation, but their energy and latency are prohibitive; the iterative denoising structure creates a unique and unexploited source of temporal data redundancy in FFN outputs across iterations.

## Method
EXION is a SW-HW co-designed ASIC accelerator exploiting two output sparsity types:

**Inter-iteration (FFN-Reuse):** Runs one dense iteration, then N sparse iterations reusing the GELU output for low-magnitude FFN elements (below a threshold). Only elements above threshold are recomputed in sparse iterations. Achieves 70-97% first-FFN-layer output sparsity, reducing FFN operations by 52-85%. Threshold values are determined empirically without retraining.

**Intra-iteration (improved Eager Prediction):** Uses two-step leading-one detection (TS-LOD) — a more accurate log-domain approximation than standard single-LOD — to predict attention scores and skip negligible attention computation within each iteration. Achieves 20-95% intra-iteration sparsity, skipping avg. 26% of Q projection and 22% of KV projection.

**ConMerge data compaction:** Converts unstructured output sparsity to compact dense forms via: (1) Condensing — removes all-zero columns from output matrices; (2) Merging — partitions output into tiled blocks, merges sparse+dense block pairs using conflict-vector (CV) tracking to resolve row index conflicts, achieving 77.4%->8.4% remaining columns for Stable Diffusion.

**Hardware (14nm, 800MHz, 0.8V):** Diffusion-Sparsity Aware Core (DSC) contains:
- Sparse-Dense Unified Engine (SDUE): 16x16 DPU array with per-DPU conflict-vector switches (cv_sw), input switches (i_sw), weight switches (w_sw), triple-buffered WMEMs supporting ConMerge merged blocks.
- ConMerge Assistant Unit (CAU): Sparsity-level classifier, SortBuffer for coarse sparsity sorting, ConMerge Vector Generator (CVG) resolving merge conflicts with degree-of-freedom minimization. CAU is 0.94% of DSC area.
- Eager Prediction Engine (EPRE): TS-LOD-enhanced log-domain DPU array with one-hot adder trees (OR gates only) to reduce TS-LOD addition overhead.
- Configurable SIMD Engine (CFSE): 32-bit or 2x16-bit ALUs for LayerNorm, Softmax, GELU, residual addition.
- Global Scratchpad (512KB) connected via NoC; DMA to external DRAM (LPDDR5 or GDDR6 depending on configuration).

Quantization: 12-bit INT for SDUE/EPRE, 16/32-bit INT for CFSE (post-training, no retraining).

## Key Novelty
FFN-Reuse: the first algorithm exploiting temporal data redundancy in FFN GELU outputs across diffusion iteration steps, creating inter-iteration output sparsity that is orthogonal to and independent of weight/input sparsity. Combined with ConMerge hardware that converts this unstructured output sparsity into compact matrices for high-utilization execution.

## Contributions
1. FFN-Reuse algorithm achieving 70-97% inter-iteration FFN output sparsity and 52-85% FFN op reduction across 7 diffusion model types without retraining.
2. Improved eager prediction with TS-LOD enabling accurate intra-iteration attention sparsity (20-95%) without accuracy degradation in iterative diffusion context.
3. ConMerge mechanism (condensing + conflict-vector-guided merging) converting unstructured output sparsity to compact form; Stable Diffusion: 77.4%->8.4% remaining columns.
4. EXION ASIC achieving 3.2-379.3x speedup and 45.1-3067.6x energy efficiency over RTX 6000 Ada server GPU; 42.6-1090.9x speedup and 196.9-4668.2x energy efficiency over Jetson Orin Nano edge GPU; 5.2x vs. Cambricon-D on DiT (transformer-only model).

## Hardware Target
ASIC (14nm synthesis, commercial PDK)

## Techniques
sparsity, dataflow, approximation, kernel-fusion

## Workloads
Evaluated on 7 diffusion models: MLD, MDM (text-to-motion), EDGE (music-to-motion), Stable Diffusion (text-to-image), DiT (class-to-image), Make-an-Audio (text-to-audio), VideoCrafter2 (text-to-video)

## Baselines
- NVIDIA RTX 6000 Ada (server GPU, 91.1 TFLOPS, 960 GB/s, 300W)
- NVIDIA Jetson Orin Nano (edge GPU, 40 TOPS, 68 GB/s, 15W)
- NVIDIA A100 GPU (for Cambricon-D comparison)
- Cambricon-D (ISCA 2024 diffusion accelerator)

## Limitations
ResBlock-containing models (Make-an-Audio, Stable Diffusion) show reduced efficiency gains because sparsity optimizations are applied only to transformer blocks; ResBlocks are not addressed. Accuracy exceptions exist for MDM and EDGE on one of two metrics under out-of-dataset inputs.
