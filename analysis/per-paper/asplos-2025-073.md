# Aqua: Network-Accelerated Memory Offloading for LLMs in Scale-Up GPU Domains

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
LLM inference under bursty requests exhausts GPU memory; admission-control-based engines become unresponsive, while preemptive time-slicing incurs high KV-cache paging overhead that collapses throughput.

## Motivation
Cloud LLM serving must be simultaneously responsive under bursts and high-throughput, but current GPU memory management cannot satisfy both requirements.

## Method
Aqua pages LLM request state using the high-bandwidth cables that connect GPUs (NVLink/NVSwitch fabric), storing data on remote GPU memory instead of the system's slow main memory or disk. When the system needs to pause a request to handle a higher-priority one, it moves that request's key-value cache—the data structure tracking what the model computed so far—across these fast GPU cables to another GPU's memory. When the paused request resumes, retrieving this data from a nearby GPU is much faster than reading from slow storage, so the system can efficiently time-slice many requests on a single GPU without performance loss.

## Key Novelty
Using the fast cables that connect GPUs (NVLink/NVSwitch) to page LLM key-value caches instead of slow storage, enabling quick pause-resume of requests without throughput loss.

## Contributions
- Insight that scale-up network bandwidth can serve as fast GPU memory offloading
- Aqua framework enabling preemptive time-sliced LLM inference on 8x H100 servers
- 20x responsiveness improvement; 4x throughput improvement over state-of-the-art
