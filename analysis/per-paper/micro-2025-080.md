# micro-2025-080: Empowering Vector Architectures for ML: The CAMP Architecture for Matrix Multiplication

**Venue:** MICRO 2025  
**Authors:** Mohammadreza Esmali Nojehdeh, Hossein Mokhtarnia, Julian Pavon, Narcis Rodas, Roger Figueras Bague, Enrico Reggiani, Miquel Moreto, Osman S. Unsal  
**Confidence:** low (abstract only)

## Problem
Existing vector architectures (VAs) and SIMD units—including ARM SVE and RISC-V SIMD—cannot efficiently execute quantized neural network matrix multiplication at 4-bit and 8-bit integer precisions because their datapaths target wider, fixed-width computations.

## Motivation
Quantized models (4-bit, 8-bit) are the dominant deployment format for LLMs and CNNs at edge and server platforms, yet the gap between quantized arithmetic efficiency and what vector ISAs provide forces inefficient emulation wasting throughput and energy.

## Method
CAMP (Cartesian Accumulative Matrix Pipeline) introduces a hybrid multiplier that hierarchically decomposes quantized integer multiplication into a two-level Cartesian product structure, natively handling INT4 and INT8 within the same datapath. Integrated into ARM A64FX (ARMv8 SVE, TSMC 7nm, Synopsys ICC2) and a RISC-V edge SoC (GF 22nm, Cadence Innovus), adding 1% and 4% area overhead respectively.

## Key Novelty
A hierarchical hybrid multiplier (Cartesian Accumulative Matrix Pipeline) enabling vector architectures to natively support multi-precision quantized integer matrix multiplication with minimal (1-4%) area overhead.

## Contributions
1. CAMP architecture: hybrid multiplier extending VA/SIMD datapaths to natively support INT4 and INT8 GEMM
2. Up to 17x performance improvement over ARM A64FX baseline
3. Up to 23x performance improvement over a RISC-V edge SoC baseline
4. 1% area overhead at TSMC 7nm; 4% at GF22nm, verified through place-and-route
