# SHAKTI: Securing Hardware IPs by Cascade Gated Multiplexer-Based Logic Obfuscation

**Venue:** VLSID

## Problem
Logic locking vulnerable to SAT/structural learning attacks; MUX-based locking susceptible despite effectiveness

## Motivation
Distributed chip design chain faces IP piracy/overproduction; logic locking essential; need attack-resilient locking

## Method
SHAKTI protects hardware by inserting cascaded gated multiplexers (logic gates that route signals differently based on a secret key) connected in a daisy-chain, where each gate's output feeds the next. The entire chain is controlled by a 64-128 bit secret key. Because each gate depends on the previous gate's output, cracking one gate doesn't reveal the complete key—an attacker would need to understand how all the gates work together.

## Key Novelty
Linking gated multiplexers in a daisy-chain—where each logic gate routes signals based on a secret key and feeds the next—creates a hardware lock resistant to SAT solver and structural learning attacks, with only 19.32-19.45% additional chip area.
