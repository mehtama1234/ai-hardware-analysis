# isscc-2025-023: GaN-Based Gate Driver with Integrated Current Sensing

**An Accurate Secondary-Side Controller with GaN-Based CGS Isolated Driver Achieving Sub-1% Error On-Chip Sensing**

## Summary
Secondary-side controller with GaN-based common-gate-source (CGS) isolated driver enabling sub-1% error integrated current sensing for synchronous-rectifier control in LLC converters.

## Technical Approach
- **CGS driver**: Novel isolated driver topology with strong driving capability and zero delay
- **Current sensing**: Gate-charge (CGS) monitoring technique integrated on-chip
- **Accuracy**: Sub-1% error eliminating external sensing components
- **Application**: GaN SR timing control in LLC resonant converter secondary

## Key Innovation
CGS-based isolated driver enabling integrated sub-1% current sensing for GaN SR control, eliminating external sensors and improving dead-time loss control.

## Contributions
- Strong-drive CGS isolated driver topology
- Integrated on-chip current sensing via gate-charge monitoring
- Sub-1% sensing accuracy achievement
- Monolithic integration for cost and space savings
