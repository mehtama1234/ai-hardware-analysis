# ZION: A Practical Confidential Virtual Machine Architecture on Commodity RISC-V Processors

**Venue:** DAC  
**ID:** dac-2025-346

## Problem
Existing RISC-V TEE architectures rely on process-level abstractions or custom hardware extensions, limiting compatibility and scalability for confidential virtual machine deployment on commodity RISC-V processors.

## Motivation
Cloud platforms increasingly require Confidential VMs to protect sensitive workloads, driving demand for VM-level TEE solutions on open ISAs like RISC-V.

## Key Innovation
VM-level confidential execution on unmodified commodity RISC-V processors without custom hardware extensions, using hierarchical memory isolation and split-page-table semantics.

## Method
ZION protects a virtual machine's memory by combining Physical Memory Protection (a built-in hardware feature controlling which code accesses which memory regions) with paging (dividing memory into chunks) for scalable isolation. It speeds up context switching between virtual CPUs with a faster code path that avoids redundant security checks. It also enables virtio devices to access memory securely using split page tables—where the same page appears at different privilege levels—without modifying the RISC-V processor.

## Contributions
- Confidential VM architecture for commodity RISC-V without custom extensions
- Secure vCPU mechanism optimizing context-switching performance
- Hierarchical memory management combining PMP and paging
- Split-page-table design for secure virtio device memory sharing

## Results
<5% overhead on real-world applications.
