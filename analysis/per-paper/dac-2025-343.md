# ZenLeak: Practical Last-Level Cache Side-Channel Attacks on AMD Zen Processors
**Venue:** DAC

## Problem
AMD's non-inclusive caches have been assumed resistant to LLC side-channel attacks due to reverse-engineering challenges; practical attack feasibility on Zen processors remains undemonstrated.

## Motivation
Understanding cache vulnerabilities in mainstream processors (AMD Zen) is critical for security; existing attack methods designed for inclusive caches do not translate to non-inclusive caches.

## Method
ZenLeak reverse-engineers AMD's cache addressing for L2 set index, L3 slice, and L3 set index; constructs eviction sets for non-inclusive caches by solving eviction patterns; demonstrates first LLC side-channel attack on AMD Zen CPUs via OpenSSL AES T-table.

## Key Novelty
First practical LLC side-channel attack on AMD's non-inclusive Zen caches via reverse-engineered addressing and novel eviction set construction.

## Contributions
1. Reverse-engineering of AMD Zen cache addressing functions
2. First eviction set construction for AMD non-inclusive caches
3. Practical LLC side-channel attack on Zen CPUs
