# CRIS-b: A High-Speed Unified Modulo Reduction Algorithm and Hardware Architecture for CRYSTALS-Kyber

**ID**: vlsid-2025-050 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
Modulo reduction is a performance bottleneck in post-quantum cryptography (PQC) implementations, particularly for CRYSTALS-Kyber. The widely-used Barrett algorithm suffers from intermediate value expansion, limiting achievable clock frequencies in hardware implementations.

## Motivation
Practical deployment of PQC standards requires efficient hardware accelerators. Modulo reduction performance directly impacts overall cryptographic throughput and must be optimized without sacrificing reliability or architectural compatibility.

## Method
- **Algorithm**: CRIS-b (Conditional R-index Switching for b-value Minimization)
- **Innovation**: Eliminates size expansion bottleneck in Barrett reduction
- **Capabilities**: 
  - Unified handling of positive and negative numbers
  - Complete NTT butterfly operation support
  - Conditional index switching for value minimization
- **Platform**: Artix-7 FPGA implementation

## Key Results
**Performance (Artix-7)**:
- **Clock Frequency**: 351.62 MHz (35.24% faster than state-of-the-art)
- **Latency**: 5 clock cycles
- **Architecture**: Unified positive/negative reduction path

## Novelty & Contributions
1. **CRIS-b algorithm** overcoming size expansion limitations of conventional Barrett
2. **Unified reduction architecture** for complete NTT spectrum without path splitting
3. **Substantial frequency improvement** (35% over prior art)
4. **Practical PQC acceleration** framework applicable to Kyber and related algorithms

## Limitations
- **FPGA-only results**: ASIC synthesis, power consumption, and area metrics absent
