# Run-time Energy-Efficiency Optimization for AI and HPC Workloads

**Venue:** SC
**ID:** sc-2025-133
**Confidence:** low

## Problem
Power management at exascale is critical for environmental/cost impact, but most methods require deep application knowledge.

## Motivation
GPU-dominated datacenters for AI/HPC need application-agnostic power optimization with minimal overhead.

## Method
The system watches code as it runs and uses spectral analysis (a technique that identifies repeating computational patterns) to detect which patterns recur during execution. For each pattern, it measures the GPU's energy consumption, then uses gradient-descent optimization (systematically testing frequency adjustments to find the best setting) to determine the ideal GPU frequency for that pattern. This saves energy because different computation patterns achieve different power-efficiency tradeoffs at different GPU speeds.

## Key Novelty
The innovation is optimizing GPU power consumption at runtime for any application—without needing to know its internal details—by detecting repeating patterns and tuning the GPU frequency separately for each one.

## Contributions
1. 15% energy reduction for equivalent compute
2. No overhead
3. Minimal execution time impact
4. Validated on diverse AI applications
