# MTJ-Based Unified LIF Spiking Neuron and PUF

**Venue:** DAC | **ID:** dac-2025-262

## Problem
SNNs offer superior energy efficiency but lack integrated security; existing approaches require separate circuits for neuromorphic computation and cryptographic key generation.

## Key Innovation
First unified MTJ-based circuit simultaneously functioning as both Leaky Integrate-and-Fire (LIF) spiking neuron and physically unclonable function (PUF) through integrated architecture.

## Method
The design uses magnetic tunnel junctions (devices exploiting magnetic properties to process information) in a unified circuit serving two functions simultaneously. The circuit acts as a leaky integrate-and-fire neuron—it accumulates electrical signals, gradually leaks them away, and fires when reaching a threshold, mimicking how biological neurons work. The same circuit simultaneously functions as a physically unclonable function, generating a unique security key based on unavoidable random physical variations in the device. This unified approach combines energy-efficient, brain-inspired computing with hardware-based security in a single integrated component.

## Security Metrics (Monte Carlo Simulation)
- **Uniqueness:** 50.07% (ideal: 50%)
- **Uniformity:** 49.66% (ideal: 50%)
- **Shannon entropy (128-bit):** 0.9974 (ideal: 1.0)

## Applications
