# MTJ-Based Unified LIF Spiking Neuron and PUF

**Venue:** DAC | **ID:** dac-2025-262

## Problem
SNNs offer superior energy efficiency but lack integrated security; existing approaches require separate circuits for neuromorphic computation and cryptographic key generation.

## Key Innovation
First unified MTJ-based circuit simultaneously functioning as both Leaky Integrate-and-Fire (LIF) spiking neuron and physically unclonable function (PUF) through integrated architecture.

## Method
MTJ device leveraging magnetic properties for dual-mode operation:
- **Neuron mode:** LIF spike generation with threshold and integration
- **PUF mode:** Device-unique response for authentication/cryptography

## Security Metrics (Monte Carlo Simulation)
- **Uniqueness:** 50.07% (ideal: 50%)
- **Uniformity:** 49.66% (ideal: 50%)
- **Shannon entropy (128-bit):** 0.9974 (ideal: 1.0)

## Applications
- Device authentication
- Embedded licensing
- Cryptographic key generation
- Anti-counterfeiting

## Hardware Target
ASIC (memristive devices)

## Techniques
Circuit design, neuromorphic computing, PUF design

## Limitations
Monte Carlo simulation only; silicon implementation and reliability under noise/temperature variation not evaluated.
