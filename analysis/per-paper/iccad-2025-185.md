# Gotta Hash 'Em All! Accelerating Hash Functions for Zero-Knowledge Proof Applications

**Venue:** ICCAD  
**ID:** iccad-2025-185

## Problem
Zero-knowledge proof generation is computationally expensive; hash functions (Griffin, Rescue-Prime, Concrete) are bottlenecks in ZK circuits, requiring efficient hardware acceleration.

## Motivation
ZK-friendly hash acceleration on FPGA reduces proof generation latency and enables privacy-preserving applications at scale (privacy coins, confidential transactions, DeFi).

## Method
Design FPGA accelerators targeting ZK-friendly hash functions (Griffin, Rescue-Prime, Concrete) using specialized datapaths for GF(p) arithmetic and optimized pipelining. Implement parallel hashing with memory hierarchy optimization for proof generation workloads.

## Key Novelty
FPGA accelerators for ZK-friendly hash functions with optimized GF(p) arithmetic and pipelined execution.

## Contributions
1. FPGA accelerator architectures for Griffin, Rescue-Prime, Concrete hash functions
2. Optimized GF(p) arithmetic datapaths for ZK primitives
3. Parallel hashing pipeline with resource-efficiency trade-offs
4. Performance improvements for ZK proof generation
