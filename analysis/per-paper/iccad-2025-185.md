# Gotta Hash 'Em All! Accelerating Hash Functions for Zero-Knowledge Proof Applications

**Venue:** ICCAD  
**ID:** iccad-2025-185

## Problem
Zero-knowledge proof generation is computationally expensive; hash functions (Griffin, Rescue-Prime, Concrete) are bottlenecks in ZK circuits, requiring efficient hardware acceleration.

## Motivation
ZK-friendly hash acceleration on FPGA reduces proof generation latency and enables privacy-preserving applications at scale (privacy coins, confidential transactions, DeFi).

## Method
Build custom circuits on reconfigurable hardware (FPGAs) that accelerate three hash functions designed for zero-knowledge proofs: Griffin, Rescue-Prime, and Concrete. The circuits use specialized calculation paths for modular arithmetic (operations within a finite mathematical field) and pipeline stages so multiple operations overlap in time. Process multiple hashes in parallel while optimizing how the hardware fetches and stores data to reduce delays during proof generation.

## Key Novelty
Accelerate zero-knowledge proof generation by building customized FPGA circuits that speed up its bottleneck hash functions (Griffin, Rescue-Prime, Concrete) through optimized modular arithmetic and pipelined calculation stages.

## Contributions
1. FPGA accelerator architectures for Griffin, Rescue-Prime, Concrete hash functions
2. Optimized GF(p) arithmetic datapaths for ZK primitives
3. Parallel hashing pipeline with resource-efficiency trade-offs
4. Performance improvements for ZK proof generation
