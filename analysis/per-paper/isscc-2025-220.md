# isscc-2025-220: Ultra-Low-Power Event-Driven Neural Interface IC

## Quick Summary
An event-based neural interface IC achieving 10nW/input power with spatially-selective zooming and input-adaptive quantization, targeting million-electrode brain recording for cognitive research.

## Problem
Next-generation brain interfaces need million+ electrodes:
- Current neural ADCs: >50× higher power than 10nW/input target
- 1M electrodes at 8b/25kHz = 200Gb/s output (exceeds wireless link capacity ~2Gb/s)
- Static electrode selection loses information
- Implantable power budget: 10mW tissue-safe limit

## Method
1. Event-driven architecture exploiting neural spiking sparsity
2. Spatially-selective zooming that dynamically chooses informative electrodes (vs. static selection)
3. 10nW/input reconfigurable-inverter ADC fabric
4. Input-adaptive quantization: reduce bit-width for low-variance channels, preserve high-variance regions

## Key Novelty
Input-adaptive quantization with spatially-selective zooming to minimize power while preserving neural information.

## Contributions
- 10nW/input ultra-low-power ADC
- Reconfigurable inverter fabric
- Event-driven spatial zooming
- Adaptive quantization per channel
- Information-preserving data reduction

## Hardware Target
ASIC, SoC
