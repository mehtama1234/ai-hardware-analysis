# isscc-2025-220: Ultra-Low-Power Event-Driven Neural Interface IC

## Quick Summary
An event-based neural interface IC achieving 10nW/input power with spatially-selective zooming and input-adaptive quantization, targeting million-electrode brain recording for cognitive research.

## Problem
Next-generation brain interfaces need million+ electrodes:
- Current neural ADCs: >50× higher power than 10nW/input target
- 1M electrodes at 8b/25kHz = 200Gb/s output (exceeds wireless link capacity ~2Gb/s)
- Static electrode selection loses information
- Implantable power budget: 10mW tissue-safe limit

## Method
The system exploits sparse, intermittent neural firing to hit the 10nW-per-input power target. It uses event-driven activation (reading only during spikes) and spatially-selective zooming (focusing on active electrode clusters), paired with an ultra-low-power analog-to-digital converter (ADC) using a reconfigurable-inverter fabric. Each electrode also adaptively compresses its signal (input-adaptive quantization), using fewer bits for less-informative channels, which reduces data rates and power while preserving critical neural information.

## Key Novelty
The innovation combines input-adaptive quantization (varying precision per electrode) with spatially-selective event-based recording (capturing only from active regions during spikes) to achieve 10nW-per-input power consumption while preserving neural information.

## Contributions
- 10nW/input ultra-low-power ADC
- Reconfigurable inverter fabric
- Event-driven spatial zooming
- Adaptive quantization per channel
- Information-preserving data reduction
