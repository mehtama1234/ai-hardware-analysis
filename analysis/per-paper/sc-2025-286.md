# Caracal: A GPU-Resident Sparse LU Solver with Lightweight Fine-Grained Scheduling

**Venue:** SC 2025  
**Authors:** Jie Ren, Tingxuan Zhong, Yuxi Hong, Guofeng Feng, Xincheng Wang, Weile Jia, Hatem Ltaief, David Elliot Keyes

## Problem Statement
GPU-resident sparse LU factorization suffers from inefficient task scheduling, poor memory management, and limited scalability on multi-GPU systems. Existing approaches either use dynamic scheduling with high overhead or fail to leverage modern GPU capabilities like multi-stream execution and NVLink.

## Technical Approach
**Two-Level Hierarchical Scheduling:**
- Coarse-grained blocks with sequential scheduling to reduce synchronization overhead
- Fine-grained blocks within each coarse block managed by lightweight static scheduler
- Multi-stream parallelism to hide latency and improve throughput

**Memory Optimization:**
- Intelligent caching mechanism retains frequently accessed matrix blocks in GPU memory
- Reduces redundant data movements between GPU and host

**Communication Optimization:**
- 1D block-cyclic matrix distribution for better load balancing
- Optimized NVLink utilization for inter-GPU communication

## Key Results
- **Throughput:** 6.46 TFLOPS on 4× A100 GPUs (21% of peak)
- **Speedup vs. SuperLU_DIST (3D comm):** 7×
- **Speedup vs. PanguLU:** 94×
- **Speedup vs. PasTiX:** 16×

## Hardware Target
NVIDIA A100 GPUs with NVLink interconnect

## Limitations & Future Work
- Evaluation limited to 4 GPUs; larger-scale behavior unclear
- Static scheduling may limit adaptability to irregular matrices
- Comparison with recent GPU-native solvers (cuSPARSE) not detailed
