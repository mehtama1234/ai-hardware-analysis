# Constraints-aware Adaptive Routing with Hybrid Waveguides for Photonic Integrated Circuits

**Paper ID:** iccad-2025-228  
**Venue:** ICCAD

## Problem

Automatic optical routing for photonic integrated circuits (PICs) typically assumes uniform waveguide types, neglecting real-world requirements for multiple waveguide types to enhance performance and integration density. Prior work lacks support for hybrid waveguide routing with stringent constraints.

## Motivation

PICs offer superior bandwidth and energy efficiency for next-generation computing and interconnects, but effective design automation supporting diverse waveguide types and matching constraints is needed.

## Method

Proposes an adaptive waveguide routing framework with two components: (1) fast initial routing algorithm optimizing waveguide paths considering target net lengths, length matching constraints, bend minimization, and hybrid waveguide compatibility, and (2) MILP-based automatic transition insertion technique strategically deploying different waveguide types to reduce transmission loss while satisfying matching constraints.

## Key Novelty

First framework for automatic optical routing supporting hybrid waveguide classes with both length-matching and loss-minimization constraints using MILP optimization.

## Contributions

- Adaptive initial routing algorithm handling multiple waveguide types and diverse constraints
- MILP-based transition insertion for waveguide type selection and loss minimization
- Up to 37% reduction in total insertion loss on target-length routing and 5-14% improvement in multi-net cases
