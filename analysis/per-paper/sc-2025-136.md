# StraGCN: GPU-Accelerated Strassen's Sparse-Dense Matrix Multiplication for Graph Convolutional Network Training

**Venue:** SC 2025  
**Authors:** Weidong He, Haikun Liu, Zhuohui Duan, Xiaofei Liao, Shuhao Zhang, Fubing Mao, Hai Jin

## Problem
Graph Convolutional Networks face critical training bottleneck from high computational cost of Sparse-Dense Matrix Multiplication (SpMM), limiting training efficiency and scalability.

## Motivation
GCNs are fundamental deep learning approach for graph-structured data. Existing GPU implementations using multi-stream CUDA model suffer from poor on-chip shared memory locality. Strassen's algorithm offers asymptotic improvement over standard matrix multiplication, but its practical GPU implementation for GCN SpMM remains unexplored despite potential benefits.

## Method
The method runs sparse-dense matrix multiplications on GPUs using Strassen's algorithm, which reduces the number of required multiplications through mathematical rearrangement. It applies three improvements: (1) fusing related GPU operations so the fast on-chip memory holds more data at once, (2) reusing intermediate calculation results because the adjacency matrix doesn't change between iterations, and (3) splitting the computation across two stages to distribute the irregular workload from sparse matrices evenly across processing cores.

## Key Novelty
It combines Strassen's algorithm (which reduces multiplications) with GPU-specific optimizations tailored to the sparse-dense matrix multiplications that GCN training requires.

## Contributions
1. Horizontal kernel fusion model providing better shared memory locality than traditional multi-stream approach
2. Intermediate result reuse strategy leveraging static adjacency matrices in GCNs
3. Load-balanced partitioning scheme addressing irregular sparsity patterns
4. Comprehensive evaluation: 2.1x (GNNA), 2.6x (PyG), 3.3x (DGL) speedup on 15 datasets
