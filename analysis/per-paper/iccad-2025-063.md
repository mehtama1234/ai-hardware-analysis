# SAGE: Saliency-Aware Grouping for Efficient Mapping of LLMs on Analog Compute-in-Memory

**Venue:** ICCAD

## Problem
LLM inference on ACIM systems suffers from long-tailed data distributions with salient values that degrade signal quality under quantization and system noise.

## Motivation
ACIM architectures offer high bandwidth and low power by co-locating storage and computation, but hardware non-idealities challenge accurate LLM execution.

## Method
Training-free strategy reordering weight and input channels based on kurtosis and saliency metrics to reduce output kurtosis and enhance signal-to-noise ratio, with reconfigurable tile design for mixed-precision execution.

## Key Novelty
Saliency-aware mapping based on statistical properties to improve noise resilience in analog systems without requiring model retraining.

## Contributions
- Reduced output kurtosis enhancing signal-to-noise ratio
- Improved inference accuracy on ACIM systems
- Mixed-precision execution with reconfigurable tile design
- Training-free optimization method
