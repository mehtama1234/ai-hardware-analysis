# dac-2025-250: Easz: An Agile Transformer-based Image Compression Framework for Resource-constrained IoTs

## Summary
Edge-computation-free image compression framework offloading encoder to server and using lightweight transformer-based reconstruction on edge. Supports adaptive compression levels without model switching.

## Key Idea
Server-side encoding + lightweight edge decoding via patch-erase + conditional sampler for adaptive IoT compression.

## Contributions
- Server-side encoder offload
- Adaptive compression without model switching
- Lightweight transformer reconstruction
- Real testbed validation

## Limitations
End-to-end latency including server-edge communication not detailed.
