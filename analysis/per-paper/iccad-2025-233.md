# Promise: Property Mining for Sequential Synthesis

**Paper ID:** iccad-2025-233  
**Venue:** ICCAD

## Problem

Sequential synthesis for removing redundant circuit logic depends critically on accurate invariant generation, but existing techniques are problem-specific or rely on localized reasoning, limiting their applicability to diverse circuit designs with modular composition.

## Motivation

Modular hardware design creates opportunities for redundancy removal through state unreachability, but existing invariant generation is too limited to be generally useful across different circuits.

## Method

Promise figures out what's always true in a circuit by analyzing simulation traces—recordings of how the circuit behaves when you run it. From these traces, it identifies invariants: relationships between signals and registers that are always true across every possible circuit state, like 'if signal A is high, register B always stores value X'. Using fast algorithms (polynomial-time, meaning they stay efficient on large circuits), it removes parts that these invariants prove unnecessary, and integrates with high-level synthesis tools to optimize the final design.

## Key Novelty

Promise finds circuit-wide invariants (patterns that are always true) from simulation traces using polynomial-time algorithms, making it practical to remove redundancy from circuits created by high-level synthesis.

## Contributions

- Trace-based global invariant mining from simulation data
- Polynomial-time algorithms for efficient invariant inference
- Effective optimization of HLS-generated circuits
- Open-source implementation at github.com/ETHZ-DYNAMO/promise
