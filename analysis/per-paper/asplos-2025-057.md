# asplos-2025-057 — Simplifying and Accelerating NOR Flash I/O Stack for RAM-Restricted Microcontrollers

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
NOR flash file systems for RAM-restricted microcontrollers migrate block-level data organization and wear leveling logic from RAM into flash, introducing fine-grained block-level management that causes frequent index updates and full-device scans. This results in severe I/O amplification that worsens when the management layers are decoupled across the I/O stack.

## Motivation
IoT microcontrollers have extreme RAM budgets (tens of KB) but must use NOR flash for persistent storage; the current approach of emulating a block-layer abstraction in flash creates unsustainable write amplification and latency that degrades device lifetime and responsiveness.

## Method
Rather than using separate software layers that each independently manage small data chunks (a decoupled approach), the paper combines them into one integrated system working with larger chunks. These larger chunks align with the natural erase boundaries the hardware uses when erasing memory, which significantly reduces index updates—the frequent catalog rewrites needed to track data locations. Wear leveling (the mechanism for distributing writes evenly to prevent memory wear) is restructured to operate at these same larger granularities, eliminating the scanning overhead from managing tiny chunks. The simplified system reduces both the interdependencies between software components and the total I/O operations required.

## Key Novelty
The core innovation is consolidating separate block-management layers into one unified system aligned with hardware erase boundaries, which jointly eliminates index-update overhead and wear-leveling scan overhead.

## Contributions
- Analysis of I/O amplification sources in existing NOR flash file systems for RAM-restricted microcontrollers.
- Redesigned I/O stack that integrates data organization and wear leveling at coarse granularity.
- Reduction of NOR flash index update frequency and device scanning overhead.
- Evaluation demonstrating improved I/O performance and reduced write amplification on microcontroller workloads.
