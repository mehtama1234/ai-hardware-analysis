# micro-2025-077: Boosting Task Scheduling Data Locality with Low-latency, HW-accelerated Label Propagation

**Venue:** MICRO 2025  
**Authors:** Lucas Morais, Juan Miguel de Haro Ruiz, Alfredo Goldman, Guido Araujo, Giacomo Pedretti, Jim Ignowski, Michael Frank, Xavier Martorell, Daniel Jimenez-Gonzalez, Carlos Alvarez  
**Confidence:** high (full text)

## Problem
Hardware-accelerated task schedulers dispatch ready tasks to the first available core without locality awareness, causing cache misses when dependent tasks execute on different cores. Existing locality-aware policies require static programmer hints or incur high scheduling overhead incompatible with fine-grained tasks.

## Motivation
Fine-grained task-parallel workloads on many-core systems suffer from data cache misses that negate parallelism gains because conventional task schedulers ignore data dependency graphs when making placement decisions.

## Method
Task-LP is a hardware label propagation (LP) accelerator that clusters up to 128 in-flight tasks using the dynamic task dependency graph built by the Picos HW module. It uses a bitmask adjacency matrix, color-iteration parallelism (First-Fit online graph coloring), and bitwise popcount to compute label popularity, converging in under 300 cycles for typical inputs. A Task Placement Engine (TPE) combines LP cluster labels with core-idleness signals via a tunable relaxation cycle-length parameter (R_len=256 default) to balance locality vs. core utilization. Prototyped on a 24-core RISC-V (Rocket Chip) on Alveo U55C FPGA with custom RoCC instructions and the Phentos API.

## Key Novelty
A hardware label-propagation accelerator that clusters dynamic task dependency graphs in under 300 cycles (up to 581x faster than software), enabling runtime data-locality-aware task placement with negligible scheduling overhead.

## Contributions
1. Task-LP: parametrized HW label-propagation clustering 128-node task graphs in under 600 cycles; 0.313 mm2 at GF 12 nm
2. Task Placement Engine combining LP labels and core-idleness via single tunable relaxation parameter
3. Up to 1.50x execution-time improvement and 1.81x task-size reduction on 24-core RISC-V FPGA
4. Clustering quality statistically indistinguishable from software LP while 581x faster

## Hardware Target
RISC-V, FPGA, ASIC

## Techniques
scheduling, cache, parallelism

## Workloads
graph-analytics, HPC (matrix decomposition, sparse matrix operations, graph coloring, MIS)

## Key Metrics
- Speedup: up to 1.50x execution time on 24 cores vs. random task stealing
- Area: 0.313 mm2 at GF 12 nm (128-node configuration)
- LP accelerator: 581x faster than software LP; convergence under 300 cycles
- Task size reduction: up to 1.81x

## Baselines
Random Task Stealing (GNU OpenMP/Nanos), Immediate Successor (IS) policy, software label propagation, Fast Greedy clustering

## Limitations
The 128-node context window limits visibility of long-range task dependencies; larger windows grow area super-linearly (~N^1.58), and gains diminish for compute-bound workloads where random placement already achieves high core utilization.
