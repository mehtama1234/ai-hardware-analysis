# asplos-2025-144: FlexSP: Accelerating Large Language Model Training via Flexible Sequence Parallelism

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing sequence parallelism methods for long-context LLM training assume homogeneous (equal-length) input sequences and apply a single static scattering strategy, causing severe load imbalance when real training corpora have heterogeneous, long-tail sequence length distributions.

## Motivation
Long-context LLM training requires sequence parallelism to handle sequences exceeding single-device memory, but static homogeneous scattering wastes device utilization when sequence lengths vary substantially.

## Method
FlexSP adapts the scattering strategy per-sequence to match each sequence's actual length, dynamically selecting the degree of sequence parallelism and the scattering pattern per batch based on the current length distribution. Communication and attention computation are co-optimized under the flexible strategy.

## Key Novelty
Per-sequence adaptive scattering that dynamically matches parallelism degree to each input sequence's length, resolving the load imbalance caused by heterogeneous-length training corpora.
