# asplos-2025-144: FlexSP: Accelerating Large Language Model Training via Flexible Sequence Parallelism

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing sequence parallelism methods for long-context LLM training assume homogeneous (equal-length) input sequences and apply a single static scattering strategy, causing severe load imbalance when real training corpora have heterogeneous, long-tail sequence length distributions.

## Motivation
Long-context LLM training requires sequence parallelism to handle sequences exceeding single-device memory, but static homogeneous scattering wastes device utilization when sequence lengths vary substantially.

## Method
FlexSP improves sequence parallelism—splitting long sequences across multiple devices—by adjusting how many devices each sequence is split across based on its actual length. The system dynamically determines this for each batch: short sequences are split across fewer devices, long sequences across more. This keeps the workload balanced so no device sits idle. The system also optimizes how devices communicate with each other and how attention works to match this flexible strategy.

## Key Novelty
The core innovation is adjusting how many devices split each sequence based on that sequence's length, rather than using the same split for all sequences.
