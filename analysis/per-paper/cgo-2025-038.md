# Synthesis of Quantum Simulators by Compilation

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Existing quantum circuit simulators lack maintainability and extensibility; dense tensor operations waste resources on inherent sparsity in quantum gate representations.

## Core Innovation
Using compilation and sparsity-aware code synthesis to automatically generate efficient quantum simulators that outperform hand-written implementations and dense tensor frameworks.

## Method
LFQS automatically synthesizes efficient quantum simulator code in C and CUDA from an intermediate language specification (a formal notation between human-readable code and machine instructions). It recognizes that quantum gate matrices—the mathematical representations of quantum operations—naturally contain many zeros and structured patterns that general dense matrix libraries can't exploit. Rather than treating all values equally, it generates code that only computes where needed, skipping the zeros. The result is simulators significantly faster than those using standard dense tensor frameworks.

## Key Contributions
- Compilation-based framework (LFQS) synthesizing quantum simulators in C and CUDA from IR
- Sparsity-exploitation techniques targeting quantum gate matrix structure
- Empirical superiority over Qiskit, Catalyst, QuEST, and NumPy on micro and macro benchmarks

## Results
Outperforms Qiskit, Catalyst, QuEST, and NumPy on benchmark circuits.

Specific speedup magnitudes and scalability to large qubit counts not detailed.
