# LowGradQ: Adaptive Gradient Quantization for Low-Bit CNN Training via Kernel Density Estimation-Guided Thresholding and Hardware-Efficient Stochastic Rounding Unit

**Venue**: DATE  
**Primary Theme**: Hardware-efficient low-bit gradient quantization  

## Problem
On-device CNN training requires low-bit precision but stochastic rounding in INT8 training imposes high computational and memory overhead; generating quality random numbers for rounding is a bottleneck.

## Method
Proposes dual-scale adaptive gradient quantization (DAGQ) capturing both small and large-magnitude gradients with kernel density estimation-guided thresholding; introduces LFSR-based reusable stochastic rounding unit (RLSRU) that generates and reuses random numbers efficiently, reducing hardware complexity.

## Key Novelty
LFSR-based reusable stochastic rounding unit eliminating redundant random number generation in low-bit training.

## Contributions
- Dual-scale adaptive gradient quantization capturing gradient magnitude range
- Kernel density estimation-guided thresholding for optimal quantization boundaries
- LFSR-based reusable stochastic rounding unit reducing random number generation overhead
- Stable INT8 training across diverse networks with minimal accuracy loss
