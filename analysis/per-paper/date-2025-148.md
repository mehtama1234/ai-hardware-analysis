# LowGradQ: Adaptive Gradient Quantization for Low-Bit CNN Training via Kernel Density Estimation-Guided Thresholding and Hardware-Efficient Stochastic Rounding Unit

**Venue**: DATE  
**Primary Theme**: Hardware-efficient low-bit gradient quantization  

## Problem
On-device CNN training requires low-bit precision but stochastic rounding in INT8 training imposes high computational and memory overhead; generating quality random numbers for rounding is a bottleneck.

## Method
The method uses adaptive gradient quantization that handles both small and large-magnitude gradients by finding optimal thresholds through kernel density estimation (examining how densely gradient values cluster). Rather than generating expensive new random numbers for each rounding operation, it introduces an LFSR-based reusable stochastic rounding unit—a simple shift register that produces repeating pseudo-random patterns—allowing the same random numbers to be reused across many rounding steps and significantly reducing hardware complexity.

## Key Novelty
An LFSR-based stochastic rounding unit that reuses the same pseudo-random number patterns instead of generating new ones, eliminating the computational cost of random number generation in low-bit training.

## Contributions
- Dual-scale adaptive gradient quantization capturing gradient magnitude range
- Kernel density estimation-guided thresholding for optimal quantization boundaries
- LFSR-based reusable stochastic rounding unit reducing random number generation overhead
- Stable INT8 training across diverse networks with minimal accuracy loss
