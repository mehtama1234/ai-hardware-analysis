# Atrial Flutter Detection System by AdEx Encoded Lead-II ECG

**Paper ID:** vlsid-2025-066
**Venue:** VLSID
**Confidence:** low

## Problem
Detecting and quantifying atrial electrical activity during irregular heart rhythms (atrial fibrillation/flutter) is challenging due to signal complexity.

## Motivation
Need for efficient, deployable systems to detect cardiac arrhythmias, particularly atrial flutter, from ECG signals.

## Method
FPGA implementation of spiking neuron model using biologically-plausible AdEx (Adaptive Exponential) neuron for ECG encoding. Extracts parameters IFW (Individual Flutter Width) and ACL (Atrial Cycle Length) from encoded spikes for AFL classification.

## Key Novelty
Application of AdEx spiking neuron model for ECG feature extraction and arrhythmia detection; biologically plausible neural encoding on FPGA.

## Contributions
- Novel AdEx-based ECG encoding for arrhythmia detection
- FPGA implementation of spiking neural model
- AFL detection with 92% sensitivity (MIT-BIH record 202)
- AF detection with 88% sensitivity (MIT-BIH record 04043)
