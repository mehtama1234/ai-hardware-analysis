# Atrial Flutter Detection System by AdEx Encoded Lead-II ECG

**Paper ID:** vlsid-2025-066
**Venue:** VLSID
**Confidence:** low

## Problem
Detecting and quantifying atrial electrical activity during irregular heart rhythms (atrial fibrillation/flutter) is challenging due to signal complexity.

## Motivation
Need for efficient, deployable systems to detect cardiac arrhythmias, particularly atrial flutter, from ECG signals.

## Method
The system converts ECG heart signals into spike patterns using an Adaptive Exponential (AdEx) neuron model—an artificial neuron that mimics how brain cells work by firing discrete electrical pulses (spikes) and adjusting its firing threshold. This conversion runs on an FPGA (reprogrammable hardware) for real-time processing. From the spike patterns, the system extracts two measurements—Individual Flutter Width (duration of each irregular heartbeat) and Atrial Cycle Length (time between beats)—to detect and classify atrial flutter.

## Key Novelty
It applies the AdEx spiking neuron model to detect atrial flutter from ECG signals.

## Contributions
- Novel AdEx-based ECG encoding for arrhythmia detection
- FPGA implementation of spiking neural model
- AFL detection with 92% sensitivity (MIT-BIH record 202)
- AF detection with 88% sensitivity (MIT-BIH record 04043)
