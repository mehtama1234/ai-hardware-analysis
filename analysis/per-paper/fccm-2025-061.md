# Ph.D. Project AIM: Accelerating Arbitrary-Precision Integer Multiplication on Heterogeneous Reconfigurable Computing Platform Versal ACAP

**Problem:** Arbitrary-precision integer multiplication requires decomposing large integers and performing parallel byte-level low-bit multiplications, followed by shifting and adding results through long bit-level propagation chains. Current hardware accelerators are not optimally designed for both computation phases simultaneously.

**Method:** Arbitrary-precision multiplication splits into two computational phases: parallel byte-level multiplications and sequential bit-level additions with shifting. The approach uses AMD's Versal ACAP platform—a single chip integrating 400 AI Engine processors (each capable of doing many multiplications at once), an FPGA (reconfigurable logic with DSPs and LUTs—specialized components for arithmetic), and an ARM CPU. It assigns the parallel byte-level phase to the 400 AIEs because they're built for processing many operations simultaneously, and assigns the sequential bit-level phase to the FPGA because its DSPs and LUTs excel at step-by-step arithmetic.

**Novelty:** The approach partitions arbitrary-precision multiplication across two hardware types—AI Engines handle parallel byte-level multiplications and FPGAs handle sequential bit-level operations—assigning each phase to the processor optimized for it.
