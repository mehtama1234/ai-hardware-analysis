# Ph.D. Project AIM: Accelerating Arbitrary-Precision Integer Multiplication on Heterogeneous Reconfigurable Computing Platform Versal ACAP

**Problem:** Arbitrary-precision integer multiplication requires decomposing large integers and performing parallel byte-level low-bit multiplications, followed by shifting and adding results through long bit-level propagation chains. Current hardware accelerators are not optimally designed for both computation phases simultaneously.

**Method:** AIM leverages the heterogeneous AMD Versal ACAP platform containing 400 AI Engine (AIE) processors, an FPGA, and an ARM CPU. The framework assigns the parallel byte-level multiplication phase to 400 AIEs which have efficient vector units, and assigns the sequential bit-level addition/shifting phase to the FPGA which has optimized DSPs and LUTs.

**Novelty:** Strategic partitioning of arbitrary-precision multiplication computation across heterogeneous resources optimized for different algorithmic patterns: AIEs for parallel byte-level operations and FPGA for sequential bit-level processing.
