# SC-2025-188: RISC-V Vectorization Coverage for HPC

**Venue:** SC 2025  
**Authors:** Hung-Ming Lai, Pei-Hung Lin, Maya B. Gokhale, Ivy Peng, Hiren D. Patel, Jenq-Kuen Lee  
**Confidence:** low (abstract only)

## Summary

Comprehensive analysis of RISC-V Vector Extension compiler auto-vectorization coverage using TSVC benchmark suite across GNU and LLVM implementations.

## Hardware Target

- RISC-V architecture
- RISC-V Vector Extension (RVV 1.0)

## Problem & Motivation

RISC-V Vector Extension introduces scalable, vector-length agnostic operations with HPC potential. However, compiler auto-vectorization support remains unclear, and instruction coverage for HPC workloads is unknown.

## Approach

1. TSVC (Test Suite for Vectorizing Compilers) compilation with:
   - GNU compiler
   - LLVM compiler
   - Vector-Length Agnostic (VLA) mode
   - Vector-Length Specific (VLS) mode

2. Instruction coverage analysis against RVV 1.0 specification

3. Vectorization failure classification:
   - Compiler backend limitations
   - Missing TSVC use cases
   - Nontrivial/unsupported patterns

## Key Contributions

1. First comprehensive RVV compiler coverage analysis
2. Quantified instruction usage across key groups
3. Identification of missed instructions
4. Root cause analysis of vectorization failures
5. Benchmark suite improvement recommendations
6. Compiler development guidance

## Limitations & Findings

TSVC limitations identified:
- Ambiguous kernel vectorizability
- Missing modern HPC-relevant patterns
- Analysis limited to TSVC benchmark suite
