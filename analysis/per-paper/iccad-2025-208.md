# Capacitance Extraction via Machine Learning with Application to Interconnect Geometry Exploration

**Venue:** ICCAD  
**ID:** iccad-2025-208

## Problem
Commercial parasitic extraction tools require 25+ minutes per process parameter change, bottlenecking design technology co-optimization (DTCO) workflows.

## Motivation


## Method
The approach trains a machine learning model on standard cell layouts—the repeating building blocks of chip designs—to predict capacitance, which measures how much electrical charge connections store. Once trained, this model predicts capacitance in milliseconds for new layouts, replacing commercial tools that require 25+ minutes per change. The predictions are as accurate as traditional 2.5D extraction methods (models that treat geometry as 2.5-dimensional), enabling designers to quickly test many design variations.

## Key Novelty
Machine learning predicts parasitic capacitance in milliseconds, enabling designers to rapidly test chip design parameter variations during optimization (tasks that previously required 25+ minutes each).

## Contributions
- ML-based parasitic capacitance extraction from layout patterns
- Millisecond prediction of coupling capacitance under unseen layer thickness
- 25-minute reduction to seconds for process parameter changes
- Competitive error distribution vs state-of-the-art 2.5D extraction
