# Capacitance Extraction via Machine Learning with Application to Interconnect Geometry Exploration

**Venue:** ICCAD  
**ID:** iccad-2025-208

## Problem
Commercial parasitic extraction tools require 25+ minutes per process parameter change, bottlenecking design technology co-optimization (DTCO) workflows.

## Motivation


## Method
Machine learning-based capacitance extraction trained on standard cell layouts achieving millisecond-scale prediction while maintaining error parity with 2.5D extraction methods.

## Key Novelty
First ML-based parasitic extraction achieving millisecond-scale prediction for DTCO parameter sensitivity analysis.

## Contributions
- ML-based parasitic capacitance extraction from layout patterns
- Millisecond prediction of coupling capacitance under unseen layer thickness
- 25-minute reduction to seconds for process parameter changes
- Competitive error distribution vs state-of-the-art 2.5D extraction
