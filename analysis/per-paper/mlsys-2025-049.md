# ScaleFusion: Scalable Inference of Spatial-Temporal Diffusion Transformers for High-Resolution Long Video Generation

**ID:** mlsys-2025-049 | **Venue:** MLSYS 2025

## Problem
Existing sequence parallelism techniques for distributed ST-DiT inference incur 34-44% communication overhead crossing machine boundaries due to back-to-back serial dependencies between all-to-all collectives and spatial/temporal attention layers, preventing efficient multi-machine scaling.

## Method
ScaleFusion exploits spatial-temporal independence: spatial attention is independent along the temporal dimension (and vice versa). This allows slicing each layer into NT temporal slices (spatial layers) or NS spatial slices (temporal layers).

- **Intra-layer scheduling**: execute all-to-all for slice i+1 asynchronously while computing slice i in one CUDA stream each (overlap computation and communication within a layer).
- **Inter-layer scheduling**: further decompose the first slice's all-to-all into LT/LS sub-partitions, lift most of them to overlap with the last-slice computation of the previous layer, eliminating the pipeline head and tail gaps.

Default hyperparameters: NT=NS=4, LT=1, LS=3.

## Key Novelty
First system hiding cross-machine all-to-all communication in ST-DiT inference through intra- and inter-layer pipelined scheduling enabled by spatial-temporal independence.

## Results
- **3.60x** strong scaling on 4 machines (32 A100 GPUs) vs 1 machine (8 A100 GPUs)
- **1.36x** average (up to **1.58x**) speedup over DSP (state-of-the-art)
- **97-103%** weak scaling efficiency
- **1.28x** peak memory reduction vs OpenSora; avoids OOM at 4K resolution
- Baselines: OpenSora (DeepSpeed-Ulysses), DSP (Zhao et al. 2024)

## Hardware Target
NVIDIA A100 40GB GPUs; Amazon EC2 p4d.24xlarge; AWS EFA 400 Gbps cross-machine network
