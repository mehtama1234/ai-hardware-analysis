# ScaleFusion: Scalable Inference of Spatial-Temporal Diffusion Transformers for High-Resolution Long Video Generation

**ID:** mlsys-2025-049 | **Venue:** MLSYS 2025

## Problem
Existing sequence parallelism techniques for distributed ST-DiT inference incur 34-44% communication overhead crossing machine boundaries due to back-to-back serial dependencies between all-to-all collectives and spatial/temporal attention layers, preventing efficient multi-machine scaling.

## Method
ScaleFusion exploits spatial-temporal independence: spatial attention (comparing pixels across the image) is independent from different time frames, and temporal attention is independent from different spatial regions. This enables splitting each layer into 4 temporal or 4 spatial slices without breaking dependencies. Within a layer, it overlaps computation and communication: while computing slice i, it prepares the all-to-all data exchange for slice i+1. Between layers, it eliminates additional idle time by overlapping 2/3 of the next layer's data exchange with the previous layer's final slice, using two parallel execution streams with default parameters: 4 temporal slices, 4 spatial slices, 1 temporal sub-partition, and 3 spatial sub-partitions.

## Key Novelty
ScaleFusion eliminates cross-machine all-to-all communication overhead in spatial-temporal video transformers by overlapping these data exchanges with computation both within layers and between consecutive layers, exploiting the independence of spatial and temporal attention.

## Results
- **3.60x** strong scaling on 4 machines (32 A100 GPUs) vs 1 machine (8 A100 GPUs)
- **1.36x** average (up to **1.58x**) speedup over DSP (state-of-the-art)
- **97-103%** weak scaling efficiency
- **1.28x** peak memory reduction vs OpenSora; avoids OOM at 4K resolution
- Baselines: OpenSora (DeepSpeed-Ulysses), DSP (Zhao et al. 2024)

## Hardware Target
NVIDIA A100 40GB GPUs; Amazon EC2 p4d.24xlarge; AWS EFA 400 Gbps cross-machine network
