# LogCrisp: Fast Aggregated Analysis on Large-scale Compressed Logs by Enabling Two-Phase Pattern Extraction and Vectorized Queries

**Problem:** Large-scale log analysis is bottlenecked by decompression overhead and query latency on voluminous datasets. Existing systems require full decompression before pattern extraction and aggregation, creating performance and memory pressure.

**Method:** LogCrisp performs pattern extraction directly on compressed logs in two phases: the first phase extracts raw patterns from compressed data without decompression, and the second phase refines patterns for accuracy. Vectorized queries execute over extracted patterns using SIMD operations to achieve high-throughput aggregated analysis.

**Novelty:** Combining two-phase pattern extraction on compressed logs with vectorized query execution to eliminate decompression overhead while maintaining query accuracy.
