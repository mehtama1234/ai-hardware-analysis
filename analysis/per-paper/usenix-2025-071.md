# LogCrisp: Fast Aggregated Analysis on Large-scale Compressed Logs by Enabling Two-Phase Pattern Extraction and Vectorized Queries

**Problem:** Large-scale log analysis is bottlenecked by decompression overhead and query latency on voluminous datasets. Existing systems require full decompression before pattern extraction and aggregation, creating performance and memory pressure.

**Method:** LogCrisp extracts patterns directly from compressed logs without decompressing them first. It works in two stages: the first stage pulls raw patterns from the compressed data, and the second stage refines them for accuracy. Then it runs queries on those patterns using SIMD operations—a technique where one instruction processes multiple pieces of data at once—enabling rapid analysis of large datasets.

**Novelty:** Instead of decompressing logs first, it extracts patterns directly from compressed data in two stages and queries those patterns using SIMD (fast parallel processing) to eliminate the decompression bottleneck.
