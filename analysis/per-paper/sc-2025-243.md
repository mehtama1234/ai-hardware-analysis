# SC-2025-243: Hetis - LLM Serving on Heterogeneous GPU Clusters

**Fine-grained Dynamic Parallelism for Cost-Efficient LLM Inference**

## Summary
Hetis is a distributed LLM serving system designed for heterogeneous GPU clusters combining high-end and low-end GPUs. It employs fine-grained, dynamic parallelism strategies that adapt to the characteristics of different model components rather than using static coarse-grained approaches.

## Problem
Production clusters use heterogeneous hardware (mix of high-end and low-end GPUs) for cost efficiency. However:
1. **Memory Mismatch**: Different GPU types have varying memory capacity-to-compute ratios causing inefficiencies
2. **Static Parallelism**: Existing coarse-grained approaches don't adapt to performance characteristics of different model components
3. **Performance Gaps**: Compute-intensive operations (MLPs) and memory-intensive operations (Attention) have different optimization strategies, yet static partitioning treats them uniformly

## Approach
Hetis introduces a multi-layered optimization strategy:

### 1. Fine-grained Parallelism
- Selective parallelization targeting compute-intensive operations (e.g., feedforward networks) to reduce latency
- Preserves single-GPU execution for latency-critical components when beneficial

### 2. Dynamic Attention Distribution
- Distributes Transformer Attention computations to low-end GPUs at **head granularity**
- Exploits head-wise independence in multi-head attention (key insight: heads can be computed independently)
- Leverages low-end GPU's bandwidth efficiency for attention-specific patterns

### 3. Online Load Dispatching
- Runtime policy balancing three objectives:
  - Network latency (data transfer costs)
  - Computational load (GPU utilization fairness)
  - Memory intensity (bandwidth constraints)
- Dynamically adapts batch composition and distribution

## Key Contributions
1. **Heterogeneous-aware Parallelism Framework**: First system to tailor parallelism strategies per-operation type
2. **Head-level Attention Distribution**: Novel insight exploiting multi-head attention's parallelizable nature
3. **Dynamic Online Scheduling**: Real-time load balancing optimizing for heterogeneous cluster constraints
4. **Significant Performance Gains**:
   - 2.25x throughput improvement
   - 1.49x latency reduction vs existing systems

## Architectural Innovation
The system recognizes that different model components have fundamentally different computational characteristics:
- **Attention**: Memory-bound, latency-sensitive, embarrassingly parallel (head-wise)
- **Feed-Forward**: Compute-bound, can tolerate communication overhead

Rather than uniform tensor parallelism, Hetis partitions these components and distributes them to GPUs optimized for their characteristics.

## Significance for AI Hardware
This work addresses a practical reality: production deployments will be increasingly heterogeneous as older and newer GPU generations coexist. Hetis provides a principled approach to extracting value from mixed-generation clusters rather than treating them as burden.
