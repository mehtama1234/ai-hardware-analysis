# Quorum: Zero-Training Unsupervised Anomaly Detection using Quantum Autoencoders

**Venue:** DAC
**ID:** dac-2025-239

## Problem
Unsupervised anomaly detection requires training-free methods due to lack of labeled anomalies. Quantum machine learning models are hard to train (gradient computation), but unsupervised autoencoders might bypass this.

## Motivation
Mission-critical anomaly detection (finance, healthcare, energy) needs practical solutions; quantum approaches might enable training-free learning.

## Method
Quorum is a quantum autoencoder that detects anomalies without training. It works by compressing normal data patterns into a compact quantum state, then reconstructing them—if anomalies fail to reconstruct well, they score higher as anomalies. This avoids the usual quantum learning problem of computing gradients, instead letting quantum properties handle the compression naturally.

## Key Novelty
Quorum detects anomalies by using quantum autoencoders (quantum circuits that compress and reconstruct data) without any training.

## Contributions

- Quorum quantum anomaly detection framework
- Training-free unsupervised learning approach
- Quantum autoencoder-based anomaly scoring
