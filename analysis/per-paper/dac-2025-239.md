# Quorum: Zero-Training Unsupervised Anomaly Detection using Quantum Autoencoders

**Venue:** DAC
**ID:** dac-2025-239

## Problem
Unsupervised anomaly detection requires training-free methods due to lack of labeled anomalies. Quantum machine learning models are hard to train (gradient computation), but unsupervised autoencoders might bypass this.

## Motivation
Mission-critical anomaly detection (finance, healthcare, energy) needs practical solutions; quantum approaches might enable training-free learning.

## Method
Quantum autoencoder framework (Quorum) designed for unsupervised anomaly detection without classical training. Abstract suggests leveraging quantum properties for dimensionality reduction and anomaly scoring without gradient-based optimization.

## Key Novelty
First quantum anomaly detection framework operating training-free via quantum autoencoder properties.

## Contributions

- Quorum quantum anomaly detection framework
- Training-free unsupervised learning approach
- Quantum autoencoder-based anomaly scoring
