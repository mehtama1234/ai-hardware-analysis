# asplos-2025-010: OS2G: A High-Performance DPU Offloading Architecture for GPU-based Deep Learning with Object Storage

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Object storage for deep learning workloads imposes intensive CPU processing overhead and causes redundant data movements (DPU->host->GPU), consuming host resources and creating a data ingestion bottleneck that limits GPU utilization during training.

## Motivation
Object storage is increasingly attractive for DL due to cost-effectiveness and scalability, but naive DPU offloading of the object storage client still burdens host CPUs with data relay tasks, preventing full benefit from DPU acceleration in GPU-based DL clusters.

## Method
OS2G establishes a direct DPU-to-GPU data path that bypasses the host CPU entirely for object storage data delivery. It redesigns the object storage client to run on the DPU and exploits GPU-Direct/RDMA mechanisms to transfer data directly from the DPU's network interface into GPU memory. A DPU-side processing pipeline (decompression, format conversion) prepares DL-ready tensors before they enter GPU memory.

## Key Novelty
End-to-end DPU-to-GPU direct data path for object storage in DL clusters that eliminates host CPU involvement and redundant data copies from the storage ingestion pipeline.

## Contributions
- Characterization of CPU overhead and redundant data movement costs in naive DPU offloading for object storage in DL clusters.
- OS2G architecture establishing a direct DPU-to-GPU data path that bypasses host CPU for storage I/O.
- DPU-side DL-oriented data processing pipeline delivering GPU-ready tensors.
