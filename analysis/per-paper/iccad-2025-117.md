# Efficient Analytical Placement Algorithm with Hybrid Fence Region Constraints Using Non-Newtonian Fluid Model

**Venue:** ICCAD  
**Confidence:** low

## Problem
Analytical placement with multiple fence region types struggles to handle mixed-type constraints where instances from different fence types are allowed in the same region; instances initially displaced by wirelength forces require extra repositioning effort to return to designated regions.

## Motivation
Modern chip designs require multiple power domains and complex placement constraints; efficient handling of hybrid fence constraints improves convergence speed and solution quality.

## Method
The algorithm uses multiple electrostatic systems—treating component placement like a physics problem where components repel each other like electric charges—to prevent overlaps while keeping movement minimal. It applies resistive forces based on non-Newtonian fluid physics (fluids whose thickness changes under stress), which gradually pull components back to their designated boundaries (called fence regions) when they drift out. This gradual restoration improves convergence and handles cases where components are permitted in multiple boundary types.

## Key Novelty
Resistive forces based on non-Newtonian fluid physics (fluids whose thickness changes under stress) that gradually restore components to fence regions, combined with multi-electrostatic systems to prevent overlaps.

## Contributions
- Multi-electrostatic system for hybrid fence region types
- Non-Newtonian fluid model for resistive forces
- 11-14% iteration reduction vs. MORPH and DREAMPlace 3.0
- 7.8× runtime reduction vs. Innovus on industrial benchmarks
