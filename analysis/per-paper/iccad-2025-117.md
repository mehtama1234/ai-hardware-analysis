# Efficient Analytical Placement Algorithm with Hybrid Fence Region Constraints Using Non-Newtonian Fluid Model

**Venue:** ICCAD  
**Confidence:** low

## Problem
Analytical placement with multiple fence region types struggles to handle mixed-type constraints where instances from different fence types are allowed in the same region; instances initially displaced by wirelength forces require extra repositioning effort to return to designated regions.

## Motivation
Modern chip designs require multiple power domains and complex placement constraints; efficient handling of hybrid fence constraints improves convergence speed and solution quality.

## Method
Hybrid-Region-Aware Multi-Electrostatic System generates General electrostatic systems eliminating overlaps across isolated systems while minimizing placement disruptions. Resistive force formulation based on non-Newtonian fluid model enhances convergence stability by gently pushing displaced instances back to fence regions.

## Key Novelty
Non-Newtonian fluid model-based resistive forces for soft fence constraint enforcement with multi-electrostatic system generation.

## Contributions
- Multi-electrostatic system for hybrid fence region types
- Non-Newtonian fluid model for resistive forces
- 11-14% iteration reduction vs. MORPH and DREAMPlace 3.0
- 7.8× runtime reduction vs. Innovus on industrial benchmarks
