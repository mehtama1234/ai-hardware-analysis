# hpca-2025-102 — UniNDP: A Unified Compilation and Simulation Tool for Near DRAM Processing Architectures

**Venue:** HPCA  
**Authors:** Tongxin Xie, Zhenhua Zhu, Bing Li, Yukai He, Cong Li, Guangyu Sun, Huazhong Yang, Yuan Xie  
**Confidence:** low (abstract only)

## Problem
Existing NDP simulators and compilers are designed for specific DRAM technologies and NDP configurations, preventing cross-architecture evaluation and optimal data placement/scheduling for ML workloads across different NDP designs.

## Motivation
NDP architectures are a promising path to commercializing in-memory computing and addressing the memory wall for memory-intensive ML, but lack of unified tooling blocks systematic exploration.

## Method
It creates a unified tree-based representation of Near-DRAM Processing hardware that works across different DRAM types. A simulator counts every clock cycle to precisely track what the memory and processing units are doing moment-by-moment. A compiler then optimizes where data gets stored and how work gets scheduled across the DRAM layers, using a strategy that quickly eliminates bad options by checking the hardware's current behavior. It uses a performance predictor tuned to the specific DRAM's timing characteristics to speed up compilation.

## Key Novelty
A tree-based (hierarchical) representation of hardware with matching instructions lets a single compiler and simulator handle Near-DRAM Processing architectures across all DRAM technologies.

## Contributions
- Unified tree-based NDP hardware abstraction and instruction set covering multiple DRAM technologies
- Cycle-accurate instruction-driven NDP simulator
- NDP compiler with data partition/mapping/scheduling optimization and DRAM timing-based performance predictor
- 1.05-3.43x speedup vs. existing mapping and compilation methods
