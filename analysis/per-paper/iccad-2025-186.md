# ToMamba: Towards Token-Efficient Mamba Architecture on FPGA

**Venue:** ICCAD  
**ID:** iccad-2025-186

## Problem
State Space Models (Mamba) show promise for sequence modeling but token-level processing creates memory access inefficiencies on FPGAs, limiting throughput and energy efficiency.

## Motivation
Efficient Mamba FPGA implementations enable low-latency inference for sequence tasks; token merging reduces memory bandwidth and computation without sacrificing accuracy.

## Method
The team implemented Mamba—a sequence-processing model—on an FPGA, which is reprogrammable hardware that accelerates computation. To overcome memory bottlenecks from processing tokens (smallest input units) one at a time, they merged multiple tokens together, reducing the effective sequence length. They also optimized the hardware circuit to process only selected tokens and built an efficient memory system to store the state vector (the model's running context). These changes eliminate the memory access delays that normally limit FPGA throughput.

## Key Novelty
Token merging—combining multiple input tokens—eliminates the memory delays that bottleneck Mamba on FPGAs, improving throughput and energy efficiency.

## Contributions
1. Token merging methodology for State Space Models
2. FPGA datapath design for Mamba inference
3. Memory hierarchy optimization for state vector storage
4. Throughput/latency/energy improvements vs. baseline Mamba
