# ToMamba: Towards Token-Efficient Mamba Architecture on FPGA

**Venue:** ICCAD  
**ID:** iccad-2025-186

## Problem
State Space Models (Mamba) show promise for sequence modeling but token-level processing creates memory access inefficiencies on FPGAs, limiting throughput and energy efficiency.

## Motivation
Efficient Mamba FPGA implementations enable low-latency inference for sequence tasks; token merging reduces memory bandwidth and computation without sacrificing accuracy.

## Method
Implement Mamba state space model on FPGA with token merging to reduce effective sequence length. Optimize datapath for selective token processing and state update computation; implement efficient memory hierarchy for state vector management.

## Key Novelty
FPGA-optimized Mamba architecture with token merging strategy for efficient sequence processing.

## Contributions
1. Token merging methodology for State Space Models
2. FPGA datapath design for Mamba inference
3. Memory hierarchy optimization for state vector storage
4. Throughput/latency/energy improvements vs. baseline Mamba
