# SC25 Paper Analysis: sc-2025-092

## Trillion Ligands per Day: Performance-Portable Virtual Screening via Compound Database Optimization and Multi-Target Docking

### Summary
SWDOCKP2 demonstrates extreme-scale structure-based drug discovery by screening 1.9 trillion ligand-receptor pairs daily on the Sunway OceanLight supercomputer. The work combines database optimization, multi-target parallel docking, and SIMD acceleration to achieve 10x speedup and generate unprecedented protein-ligand interaction datasets.

### Key Problem
- **Scale Challenge**: Virtual screening requires evaluating trillions of ligand-protein combinations
- **Multi-Target Bottleneck**: Screening against multiple protein targets multiplies computational cost
- **Portability Gap**: HPC-optimized code often lacks portability across architectures

### Technical Approach
1. **Ligand Database Optimizer**: Conformational sorting and merging to improve cache locality
2. **Multi-Receptor Grid Alignment**: Enables parallel screening of multiple targets
3. **SIMD-Accelerated Trilinear Interpolation**: Key computational kernel optimization
4. **Sunway Architecture Emulator**: Cross-platform design and optimization

### Contributions
1. Database optimization strategy for ligand conformations
2. Multi-target parallel docking framework
3. SIMD kernel optimization for interpolation
4. Architecture emulator for design space exploration
5. 1.9 trillion ligand-receptor pairs screened daily
6. 10x speedup over prior methods
7. Dataset generation for ML-driven drug discovery

### Hardware & Workloads
- **Target Hardware**: Sunway OceanLight supercomputer (39 million cores)
- **Workloads**: Virtual screening, protein-ligand docking, drug discovery

### Performance Results
- **Throughput**: 1.9 trillion ligand-receptor pairs per day
- **Speedup**: 10x vs prior state-of-the-art
- **Dataset**: Unprecedented protein-ligand interaction predictions

### Applications
- Accelerated drug discovery pipelines
- ML-driven generative chemistry
- Computational structural biology

Extreme-Scale Molecular Simulation and Computational Drug Discovery
