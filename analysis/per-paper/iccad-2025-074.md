# JitFilt: Mitigate Jitter-based Side Channel Analysis Attacks

**Venue:** ICCAD

## Problem
Signal jitter emanating from cryptographic circuits can be exploited via jitter-based side-channel analysis (JitSCA) attacks using time-to-digital converters to conduct remote attacks.

## Motivation
Cryptographic circuits face critical vulnerability from jitter-based attacks; effective countermeasures are needed.

## Method
The solution uses FPGA components—mixed-mode clock managers (MMCMs), phase-locked loops (PLLs), and IDELAY blocks—to filter out timing noise (jitter) from cryptographic circuits. These components smooth out signal timing variations that an attacker could otherwise detect using a time-to-digital converter (hardware that measures precise signal timing). By removing the jitter, the defense eliminates the information needed for a jitter-based side-channel analysis attack.

## Key Novelty
This is the first defense built specifically to stop jitter-based side-channel analysis attacks on cryptographic hardware.

## Contributions
- 166x protection improvement (5 million traces vs 30k for unprotected AES)
- Full secret key protection up to 5 million traces
- PLL-based filter shows highest JitSCA protection
- Practical FPGA implementation
