# A Full-system, Programmable, and Extensible In-Memory Computing Simulation Framework for Deep Learning

**ID**: dac-2025-441  
**Venue**: DAC  
**Confidence**: low

## Problem
Designing scalable, programmable IMC platforms for modern generative AI (LLMs, DiTs) lacks simulation infrastructure that accurately models device-level physics while supporting full-stack software integration.

## Motivation
IMC offers superior energy efficiency for AI, but design space exploration requires accurate simulation combining circuit-level detail with software workload modeling.

## Method
IMCsim simulates complete AI systems by adding tensor operations (specialized instructions for neural network math) to a processor, mapping them onto different memory architectures—embedded flash, SRAM, or in-memory compute circuits—and validating results against actual silicon prototypes built at 22nm and 28nm scales. Researchers can then explore how to trade off performance, power consumption, and chip area for different AI tasks.

## Key Novelty
The first simulator connecting in-memory computing device physics to running AI workloads, verified against actual silicon.

## Contributions
- ISA extensions for tensor operators on IMC
- Support for three IMC technology variants (eNVM, SRAM, digital)
- Silicon validation using MRAM and SRAM prototypes
- Design space exploration for LLM, ResNet-18, DiT
