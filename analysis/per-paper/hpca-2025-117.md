# hpca-2025-117: MeHyper: Accelerating Hypergraph Neural Networks by Exploring Implicit Dataflows

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Hypergraph Neural Networks (HGNNs) based on hyperedge-centric dataflow independently process vertex and hyperedge aggregation tasks, causing significant computational redundancy from recalculating shared information (intermediate feature values) across these tasks.

## Motivation
HGNNs are increasingly used for complex relational data analysis, but their computational redundancy and large volumes of intermediate features create memory bandwidth bottlenecks that make existing CPU/GPU systems highly inefficient.

## Method
MeHyper addresses computational redundancy in hypergraph neural networks: when processing vertices and hyperedges separately, systems recalculate the same intermediate feature values. The system introduces microedges—small units that capture shared information—and processes each microedge once using a Read-Process-Activate-Generate cycle, distributing results to all dependent aggregation tasks. The hardware accelerator uses a decoupled pipeline (processing stages that work independently in parallel) and hierarchical feature management (organizing on-chip memory by data granularity) to reduce expensive off-chip DRAM accesses for the large intermediate feature vectors created during microedge aggregation.

## Key Novelty
MeHyper identifies and exploits implicit dataflow dependencies—hidden patterns in how data flows through computations—in hypergraph neural networks via the microedge abstraction, eliminating redundant calculations across vertex and hyperedge aggregation.

## Contributions
- Discovery and formalization of implicit dataflows in HGNNs via the microedge concept
- Microedge-centric dataflow model with Read-Process-Activate-Generate execution for parallel processing
- Decoupled pipeline architecture for maximizing computational parallelism in HGNN acceleration
- Hierarchical on-chip feature management reducing off-chip accesses; 1032x/10.51x speedup over PyG-CPU/HyperGef

## Limitations
Evaluation is limited to HGNN workloads; applicability to standard GNNs or heterogeneous graph models is not assessed.
