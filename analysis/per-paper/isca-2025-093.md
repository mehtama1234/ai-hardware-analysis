# FRED: A Wafer-scale Fabric for 3D Parallel DNN Training

**Venue:** ISCA  
**ID:** isca-2025-093  
**Confidence:** low (abstract-only)

## Problem
Current wafer-scale interconnect topologies (e.g., 2D mesh) lack the flexibility to simultaneously support tensor, pipeline, and data parallelism in DNN training, causing collective communications to contend for shared links and inflating training time.

## Motivation
Wafer-scale systems offer extremely high on-wafer bandwidth but existing static topologies cannot reconfigure to form the non-overlapping communication groups required by hybrid 3D parallelism.

## Method
FRED introduces a distributed on-wafer topology built from tiny microswitches interconnecting accelerator chiplets on the wafer. The microswitches form a reconfigurable, nonblocking network that can route collective communications (all-reduce, all-to-all) between arbitrary subsets of chiplets without interference. In-switch collective support allows reduction operations to be partially executed at intermediate network nodes, reducing traffic volume. This topology is tailored so that different parallelism dimensions (data, tensor, pipeline) map to non-overlapping logical groups with dedicated bandwidth.

## Key Novelty
Distributing microswitches across the wafer to create a reconfigurable, nonblocking on-wafer fabric that supports in-switch collective operations for arbitrary accelerator subgroup communications.

## Contributions
1. FRED wafer-scale fabric with microswitches providing nonblocking connectivity for arbitrary collective communication groups.
2. In-switch collective execution that partially aggregates reduction results at network nodes.
3. Evaluation showing 1.34-1.87x training speedup over 2D Mesh for ResNet-152, Transformer-17B, GPT-3, Transformer-1T.
4. Analysis of topology suitability for diverse 3D parallelism configurations.

## Metrics
- **Speedup:** 1.34-1.87x end-to-end training time over 2D Mesh wafer-scale baseline

## Baselines
- 2D Mesh wafer-scale system

## Limitations
Cost and manufacturing complexity of integrating microswitches across a full wafer, and scalability of microswitch routing logic, are not discussed.
