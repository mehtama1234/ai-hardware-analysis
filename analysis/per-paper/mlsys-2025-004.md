# Marconi: Prefix Caching for the Era of Hybrid LLMs

**Problem:** Hybrid Attention+SSM LLMs (Mamba, Jamba) cannot use standard prefix caching because SSM in-place state updates preclude partial-sequence reuse; only exact-match hits are valid, causing a cache explosion with low reuse.

**Method:** Unified radix tree managing both KV-cache blocks and SSM state checkpoints. Admission restricts entries to two reuse classes: purely-input shared prefixes and input+output conversation prefixes; speculative pre-prefill insertion identifies SSM checkpointing branch points without model execution. FLOP-aware eviction scores entries as S(n) = recency(n) + alpha * (FLOPs_saved / cache_bytes), with alpha tuned via grid search on bootstrap period. Only leaf and single-child intermediate nodes are eviction-eligible to prevent cascade invalidation.

**Key novelty:** First hybrid Attention+SSM prefix cache; FLOP-efficiency eviction metric (FLOPs saved per cache byte) combining recency and compute-return value.

**Metrics:**
- Up to 34.4x higher token hit rates vs vLLM+ prefix caching
- 71.1% lower P95 TTFT vs vLLM+
- 617 ms lower P95 TTFT vs vLLM+
