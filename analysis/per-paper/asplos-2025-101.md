# asplos-2025-101: Data Cache for Intermittent Computing Systems with Non-Volatile Main Memory

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
Energy-harvesting embedded systems with non-volatile main memory (NVM) must checkpoint frequently to cover Write After Read (WAR) data hazards, incurring both high runtime overhead and excessive NVM writes; existing data cache solutions do not integrate WAR detection and require additional hardware or software memory trackers.

## Motivation
Intermittent computing on energy-harvesting platforms is gaining importance for batteryless IoT sensors and edge devices, but NVM's slow access and high write energy make naive caching approaches inefficient without WAR-aware management.

## Method
NACHO embeds detection of Write After Read hazards (when modified data is read before being permanently saved) directly into the data cache (fast temporary memory between processor and permanent storage). When the cache detects this hazard, it handles it immediately without a separate tracking system. This lets the system save its state less often by catching hazards early, and keeps modified data in the cache longer before writing to permanent storage, reducing both runtime slowdown and storage wear.

## Key Novelty
Putting Write After Read (data modified but not yet saved) hazard detection inside the data cache, instead of using a separate tracking system.

## Contributions
- NACHO: a data cache architecture with integrated WAR detection for intermittent NVM-based platforms.
- 54% average runtime overhead reduction vs. state-of-the-art cache-based systems.
- 82% reduction in NVM writes vs. cache-less system; 18% average reduction vs. prior cache-based systems.
