# GeoFA - 2D Layout Pattern Matching using Deterministic Finite Automaton

GeoFA applies deterministic finite automaton theory to 2D layout pattern matching for chip design verification, achieving 201.7× speedup over commercial tools like Calibre. By encoding geometric patterns as DFA states and transitions, the system converts expensive geometric search into linear-time automaton traversal. This work demonstrates that classical automaton theory can be effectively applied to modern EDA challenges, enabling rapid verification of manufacturing rules and complex design constraints at scale.
