# ElasticMiter: Formally Verified Dataflow Circuit Rewrites

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-043  
**Confidence:** low (abstract only)

## Problem
Dataflow circuits from HLS compilers cannot be optimized via standard sequential equivalence verification because their latency-insensitive handshake semantics are incompatible with traditional equivalence notions, leaving no sound basis for automated simplification.

## Motivation
HLS-generated dataflow circuits are increasingly important for both async and sync designs, but without formally verified transformation passes, circuits cannot be safely simplified post-synthesis, wasting area and timing slack.

## Method
ElasticMiter constructs a miter circuit for latency-insensitive dataflow circuits that detects functional divergence under all possible token arrival patterns. A graph rewriting system applies verified simplification rules, with each rule proven sound by the miter framework before use. Handles elastic buffers, fork/join nodes, and control tokens absent in traditional sequential circuits.

## Key Novelty
First formally verified dataflow circuit transformation system using a latency-insensitive miter to prove graph rewrite rules sound for HLS-generated circuits.

## Contributions
- Generic equivalence verification framework for latency-insensitive dataflow circuits via miter construction.
- Graph rewriting system for systematic dataflow circuit datapath simplification.
- Formal proofs that each rewrite pattern preserves latency-insensitive equivalence.
- Foundation for formally verified dataflow HLS compilers.
