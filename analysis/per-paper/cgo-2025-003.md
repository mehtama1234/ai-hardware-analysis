# PreFix: Optimizing the Performance of Heap-Intensive Applications

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Heap-intensive applications suffer poor spatial locality despite concentration of accesses in few objects. Prior techniques (HDS, HALO) achieve imperfect separation and cannot reorder objects.

## Technical Approach
Context-based mechanism precisely identifies hot objects at runtime. Preallocates fixed-size memory regions for hot objects at predetermined locations, enabling reordering and colocation of hot data streams. Object recycling reuses space when lifetimes don't overlap.

## Key Novelty
Context mechanism for near-perfect hot object separation with flexibility for object reordering.

## Key Results
- 21.7% average execution time reduction (vs 7.3% HDS, 14% HALO)
- Range of 2.77%-74% per benchmark
- 13 heap-intensive applications tested

- **Target:** CPU
- **Techniques:** Memory system optimization, cache locality, profiling
