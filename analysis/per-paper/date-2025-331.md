# Maximum Fanout-Free Window Enumeration: Towards Multi-Output Sub-Structure Synthesis

**Venue**: DATE  
**Primary Theme**: multi-output sub-structure enumeration for logic synthesis  

## Problem
AIG optimization peephole algorithms need efficient enumeration of multi-output sub-structures (Maximum Fanout-Free Windows) beyond single-output cuts.

## Method
The approach identifies optimization opportunities using two enumeration strategies. A dynamic strategy adapts in real-time as the circuit (represented as an And-Inverter Graph, or AIG—a compact way to store circuit logic) changes during optimization, while a static strategy prioritizes speed for stable circuits. Both search for Maximum Fanout-Free Windows—sub-structures where outputs don't branch—to rewrite and improve circuits and prepare them for specific hardware.

## Key Novelty
This is the first systematic exploration of fanout-free windows as multi-output optimization targets, introducing dynamic and static enumeration algorithms for circuit optimization.

## Contributions
- MFFW sub-structure definition and characterization for AIGs
- Dynamic enumeration method adapting to AIG changes
- Static enumeration method for stable AIG structures
- Application to circuit rewriting and technology mapping with performance gains
