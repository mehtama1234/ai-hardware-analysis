# iSEW: in-Sensor Embedded Watermarking for Secure Imaging

**Problem:** Digital images lack hardware-native tamper resistance and are vulnerable to post-capture modifications. Current watermarking approaches operate post-acquisition, adding computational overhead and remaining susceptible to removal attacks.

**Method:** Analog-domain watermarking is embedded during the readout stage before ADC conversion in CMOS sensors. The column amplifier architecture is modified to inject the watermark, controlled by a secure pattern generator. The watermark is embedded at the pixel readout level, creating a hardware-native, low-overhead tamper-resistant mechanism.

**Novelty:** Implementing watermark embedding at the analog readout stage before ADC, directly integrated into CMOS sensor circuitry, provides a hardware-native security primitive.
