# Efficient Approximate Nearest Neighbor Search via Data-Adaptive Parameter Adjustment in Hierarchical Navigable Small Graphs

**Venue**: DATE  
**Primary Theme**: Adaptive HNSW parameter tuning  

## Problem
Hierarchical Navigable Small World graph algorithms use static parameters (connection count M and search depth ef) that do not adapt to variations in data density and dimensionality, causing suboptimal performance across diverse datasets.

## Method
Proposes Dynamic HNSW with data-adaptive parameter adjustment algorithms; automatically tunes M (connections per node) and ef (search depth) based on local data density and dataset dimensionality to optimize graph construction and search efficiency.

## Key Novelty
Adaptive parameter tuning algorithm for HNSW based on local data density and global dimensionality.

## Contributions
- Analysis of HNSW parameter sensitivity to data density and dimensionality
- Adaptive M and ef adjustment algorithm
- Graph build time reduction up to 33.11%
- Memory usage reduction up to 32.44% with comparable recall
