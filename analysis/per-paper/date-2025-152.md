# Efficient Approximate Nearest Neighbor Search via Data-Adaptive Parameter Adjustment in Hierarchical Navigable Small Graphs

**Venue**: DATE  
**Primary Theme**: Adaptive HNSW parameter tuning  

## Problem
Hierarchical Navigable Small World graph algorithms use static parameters (connection count M and search depth ef) that do not adapt to variations in data density and dimensionality, causing suboptimal performance across diverse datasets.

## Method
This approach builds Hierarchical Navigable Small World graphs (network structures that find similar data points by navigating through connections) with parameters that automatically adapt to your data. Instead of using fixed settings for the number of connections per node and the search depth, it measures how tightly data points cluster together locally and how many dimensions your data has, then adjusts these two settings accordingly. The result is a graph structure optimized for your specific data characteristics, making both construction and searching more efficient.

## Key Novelty
Instead of using fixed settings, automatically adjust a Hierarchical Navigable Small World graph's connection count and search depth based on how clustered and high-dimensional your data is.

## Contributions
- Analysis of HNSW parameter sensitivity to data density and dimensionality
- Adaptive M and ef adjustment algorithm
- Graph build time reduction up to 33.11%
- Memory usage reduction up to 32.44% with comparable recall
