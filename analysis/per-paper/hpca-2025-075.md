# Machine Learning-Guided Memory Optimization for DLRM Inference on Tiered Memory

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Deep learning recommendation models (DLRMs) have embedding tables at terabyte scale that cannot fit in DRAM alone; tiered memory (DRAM + cheaper capacity tiers) is cost-effective but embedding access patterns have long and irregular reuse distances that defeat classical caching and prefetching heuristics.

## Motivation
As DLRM embedding tables grow to terabyte scale in production systems, tiered memory becomes necessary for cost, but suboptimal placement of embedding vectors causes frequent slow-tier fetches that dominate end-to-end inference latency.

## Method
RecMG uses two machine learning models that optimize where embedding vectors (chunks of lookup data for recommendation systems) are stored across tiered memory: a caching model predicts which vectors have long reuse distances or few future reuses and keeps them in fast memory, while a prefetching model predicts upcoming accesses and loads vectors into fast memory ahead of time using a differentiable loss function (a mathematically optimized guide) that narrows which candidates to consider and directly reduces unnecessary memory fetches. Both models train on real access patterns from recommendation systems where data is accessed sparsely and at irregular intervals. At inference time, the models continuously make placement decisions based on these predictions.

## Key Novelty
The core innovation is a differentiable loss function—a mathematically optimized formula—for the prefetching model that directly reduces on-demand memory fetches from slow tiers by focusing on the highest-value embedding vectors to prefetch into fast memory.

## Contributions
1. RecMG: an ML-guided system combining separate caching and prefetching models for DLRM embedding-vector placement on tiered memory
2. Novel differentiable loss function for embedding prefetching that reduces search space and on-demand fetches
3. Tailored data labeling addressing unique challenges of sparse DLRM access patterns for ML training
4. 2.2x, 2.8x, and 1.5x reduction in on-demand fetches over temporal, spatial, and ML-based prefetchers; up to 43% end-to-end inference time reduction
