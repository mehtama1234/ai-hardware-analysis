# Training Ultra Long Context Language Model with Fully Pipelined Distributed Transformer

**Venue:** MLSYS 2025

## One-line Problem
Training LLMs on sequences beyond GPU memory capacity is bottlenecked by PCIe transfer latency when offloading to CPU; naive implementations serialize compute and transfer.

## Method
Fully Pipelined Distributed Transformer (FPDT) trains large language models by splitting the work across multiple GPUs, storing pieces of the input in the computer's main memory when GPU memory fills up. It breaks the long sequence into 64,000-token chunks and uses a double-buffer strategy—keeping one chunk ready to copy while the GPU processes the current chunk—which hides the delay of transferring data from main memory to GPU. The system redistributes intermediate results across GPUs in a coordinated pattern and synchronizes the final output layer (vocabulary computation) with this chunking process.

## Novelty
Double-buffer design that hides PCIe latency behind GPU compute, enabling 16x longer sequences than SOTA on the same hardware. First system to train 8B LLM at 2M sequence length on only 4 GPUs.

## Key Metrics
- Max sequence length: **2M tokens** on 4 GPUs for 8B LLM
- MFU: **>55%** on 2M-token sequences
- **16x** sequence length increase vs prior SOTA on same hardware
