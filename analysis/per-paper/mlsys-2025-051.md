# Training Ultra Long Context Language Model with Fully Pipelined Distributed Transformer

**Venue:** MLSYS 2025

## One-line Problem
Training LLMs on sequences beyond GPU memory capacity is bottlenecked by PCIe transfer latency when offloading to CPU; naive implementations serialize compute and transfer.

## Method
Fully Pipelined Distributed Transformer (FPDT) extends DeepSpeed Ulysses with CPU offloading via a **double-buffer design**: the sequence is sliced into 64K-token chunks, and a pipeline overlaps PCIe host-to-device prefetch of the next chunk with GPU computation of the current chunk. A rank-ordinal scatter redistributes activations across GPUs. Vocabulary computation is also pipelined within the chunk pipeline.

## Novelty
Double-buffer design that hides PCIe latency behind GPU compute, enabling 16x longer sequences than SOTA on the same hardware. First system to train 8B LLM at 2M sequence length on only 4 GPUs.

## Key Metrics
- Max sequence length: **2M tokens** on 4 GPUs for 8B LLM
- MFU: **>55%** on 2M-token sequences
- **16x** sequence length increase vs prior SOTA on same hardware
