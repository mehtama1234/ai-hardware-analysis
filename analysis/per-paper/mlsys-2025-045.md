# Scaling Deep Learning Training with MPMD Pipeline Parallelism

**ID:** mlsys-2025-045 | **Venue:** MLSYS 2025

## Problem
GSPMD/SPMD-based pipeline parallelism in JAX can only encode GPipe-style schedules; it cannot express more efficient 1F1B or Interleaved 1F1B schedules, leaving ~20% throughput and significant activation memory savings unrealized.

## Method
JaxPP extends JAX with a MPMD pipeline runtime. Users mark stage boundaries with `pipeline_yield` annotations; JaxPP infers stages from data dependencies. The `accumulate_grads` API implements gradient accumulation with any user-specified schedule (1F1B, Interleaved 1F1B). A single-controller driver traces computation to a task graph, assigns tasks to SPMD actors, infers send/receive pairs topologically, and fuses all dispatches into one RPC per actor. Async P2P communication is overlapped with compute.

## Key Novelty
First JAX-native MPMD pipeline parallelism system supporting arbitrary user-defined pipeline schedules via lightweight annotations, without model rewrites, compiled by XLA.

## Results
- **51.2%** faster than SPMD PP (GPipe) on GPT-3 175B (128 H100 GPUs)
- **1.16x** improvement over JAX FSDP
- **95.6%** of NeMo's hand-optimized throughput
- **98.33%** weak scaling efficiency from 64 to 1024 H100 GPUs
- Baselines: JAX SPMD PP, JAX FSDP, NeMo

## Hardware Target
NVIDIA H100 GPUs (DGX nodes), InfiniBand NDR400; multi-node clusters
