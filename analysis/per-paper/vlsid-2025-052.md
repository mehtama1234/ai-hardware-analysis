# Novel Hardware Architectures for PRESENT Block Cipher and its FPGA Realizations

**ID**: vlsid-2025-052 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
IoT devices require lightweight cryptographic ciphers balancing security, power efficiency, and hardware footprint. PRESENT cipher is ideal for IoT but existing implementations have not comprehensively optimized power consumption without sacrificing throughput.

## Motivation
As IoT deployments proliferate, battery-powered devices demand extremely power-efficient cryptography. PRESENT, a 64-bit lightweight block cipher, is well-suited for IoT but requires careful hardware design to minimize power while maintaining practical performance.

## Method
- **Focus**: Optimizing Substitution Permutation Network (SPN) core module
- **Techniques**:
  1. Datapath modifications for reduced switching activity
  2. Optimized input selection/feeding via multiplexer architecture
  3. Additional hardware units targeting power-critical paths
- **Platform**: NEXYS4 DDR FPGA at 13.56 MHz (RFID standard frequency)
- **Scope**: Complete PRESENT cipher architecture including optimized SPN

## Key Results
**Performance Improvements**:
- **28.57% dynamic power reduction** vs. state-of-the-art
- **32.81% area reduction** on FPGA
- **Improved throughput** (exact value not specified)
- **Maintained energy efficiency** across optimizations

**Target Application**: RFID and IoT at 13.56 MHz operating frequency

## Novelty & Contributions
1. **Comprehensive power-optimized SPN module** through datapath and multiplexer innovations
2. **Dual optimization** achieving both power reduction and area savings
3. **FPGA resource efficiency guidelines** for cipher designers
4. **Practical IoT-class implementation** validated on real FPGA platform
