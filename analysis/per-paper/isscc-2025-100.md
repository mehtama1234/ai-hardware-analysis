# isscc-2025-100: Monolithic MRAM-Based In-Memory Computing

## Summary
Monolithic in-memory computing microprocessor with 1.1Mb MRAM-embedded weight storage in 28nm CMOS for end-to-end DNN inference on always-on AI sensors.

## Key Contributions
- MRAM-embedded IMC microprocessor
- 1.1Mb monolithic weight storage
- End-to-end DNN inference
- Low power (idle + compute)

ASIC
