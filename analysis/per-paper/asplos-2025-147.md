# asplos-2025-147: D-VSync: Decoupled Rendering and Displaying for Smartphone Graphics

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
VSync-based rendering tightly couples the rendering pipeline to the display refresh cycle, causing frame drops when complex visual effects exceed the VSync interval on high-frame-rate smartphone displays.

## Motivation
Modern smartphones adopt 90-144 Hz displays with increasingly complex animations, overstressing the rigid synchronized rendering-display architecture.

## Method
D-VSync decouples rendering from VSync via asynchronous rendering completion with a buffering/synchronization layer and predictive scheduling that aligns rendered frames to the nearest display window.

## Key Novelty
Asynchronous rendering decoupled from VSync with predictive display-cycle-aware frame scheduling to eliminate hard-coupling frame drops.

## Contributions
- D-VSync architecture decoupling rendering scheduler from display VSync cycle
- Asynchronous rendering with buffering layer for frame alignment
- Reduced frame drops and latency on high-frame-rate displays
- Implementation on Android/OpenHarmony rendering stacks
