# CrossPipe: Towards Optimal Pipeline Schedules for Cross-Datacenter Training

**Problem:** Training large language models requires optimizing model parallelism and communication across geographically distributed datacenters where network latency and limited bandwidth create significant performance bottlenecks.

**Method:** CrossPipe explicitly models network latency and bandwidth constraints, then performs unified optimization over pipeline parallelism (PP) and overlapping data parallelism (DP) communication. It generates optimal schedules using either solver-based algorithms or fast greedy approximations, built on a flexible execution engine that decouples scheduling decisions from communication implementation details.

**Novelty:** Integrated optimization of pipeline parallelism with overlapping data parallelism communication specifically for cross-datacenter training with explicit network modeling.
