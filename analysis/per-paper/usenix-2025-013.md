# CrossPipe: Towards Optimal Pipeline Schedules for Cross-Datacenter Training

**Problem:** Training large language models requires optimizing model parallelism and communication across geographically distributed datacenters where network latency and limited bandwidth create significant performance bottlenecks.

**Method:** CrossPipe models real-world network delays and bandwidth limits that slow distributed training. It then finds optimal schedules by jointly optimizing two training strategies: running the model across a sequence of machines (pipeline parallelism) and overlapping gradient synchronization between model copies with other computation (data parallelism). The system can use mathematical solvers to find perfect schedules or faster approximations for practical use. Its flexible execution engine keeps scheduling decisions separate from how communication is actually implemented.

**Novelty:** CrossPipe jointly optimizes pipeline parallelism (running model stages across machines), overlapping data parallelism updates (sharing gradients during other computations), and explicit accounting for network latency and bandwidth limits to find optimal training schedules across distant datacenters.
