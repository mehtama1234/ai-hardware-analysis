# MEMHD: Memory-Efficient Multi-Centroid Hyperdimensional Computing for Fully-Utilized In-Memory Computing Architectures

**Venue**: DATE  
**Primary Theme**: Memory-efficient multi-centroid HDC for IMC  

## Problem
Hyperdimensional Computing vectors are too large for typical In-Memory Computing array dimensions, causing mismatch: high-dimensional HDC cannot efficiently map to fixed-size IMC arrays, resulting in poor utilization and extended computation cycles.

## Method
MEMHD breaks high-dimensional vectors into multiple smaller pieces, grouped by similarity (clustering). These pieces are shrunk to fit the fixed-size in-memory computing array, and the system learns to compensate for this shrinkage over repeated cycles. This approach enables one-shot and few-shot retrieval while fully utilizing the array.

## Key Novelty
Decomposing hyperdimensional vectors into multiple clustered representations enables full utilization of fixed-size in-memory computing arrays.

## Contributions
- Clustering-based initialization method for multi-centroid associative memory
- Quantization-aware iterative learning for efficient memory training
- Architecture enabling full IMC array utilization and one-shot associative search
- 13.69% accuracy improvement over binary HDC, 13.25x memory efficiency gain, 80x computation cycle reduction
