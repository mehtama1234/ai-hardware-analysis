# Enhancing HPX with FleCSI: Automatic Detection of Implicit Task Dependencies

**Venue:** SC
**Paper ID:** sc-2025-004
**Confidence:** low

## Problem Statement
Mapping Legion-like task graph programming model to HPX's different programming semantics is challenging; balancing parallelism opportunities vs overhead

## Motivation
FleCSI enables performance-portable code; HPX backend provides middle ground between MPI's low overhead and Legion's parallelism; efficient mapping enables better performance

## Method
They built an HPX backend for FleCSI to make it work with HPX's parallel execution model. Task dependencies—where one task must wait for another to finish—are represented as HPX futures, which are promises of results. The key optimization reduces the overhead of creating communicators, which are the data channels between tasks, by streamlining expensive setup work. They validated the approach on two physics simulation applications.

## Key Novelty
The key idea is reducing the overhead of creating communicators, the data channels between tasks, when translating Legion-like task graphs to HPX's execution model.
