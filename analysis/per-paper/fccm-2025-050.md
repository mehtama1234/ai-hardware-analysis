# Soaring with TRILLI: An HW/SW Heterogeneous Accelerator for Multi-Modal Image Registration

**Problem:** 3D rigid image registration requires compute-intensive geometric transformation with interpolation and similarity metric computation, but existing hardware accelerators cannot address both components effectively since GPUs excel at image transformation while FPGAs dominate in similarity metric computation.

**Method:** TRILLI uses a Versal chip that combines a GPU and FPGA to split image registration work. The GPU handles the computationally heavy geometric transformation and interpolation (moving and resizing images to align them), while the FPGA computes similarity metrics (measurements of how well images match). By using each hardware type where it excels, TRILLI creates an end-to-end system that performs better than making one hardware type handle all the work.

**Novelty:** TRILLI's core idea is using the GPU for image transformation and the FPGA for similarity metric computation, rather than forcing one hardware type to handle both tasks.
