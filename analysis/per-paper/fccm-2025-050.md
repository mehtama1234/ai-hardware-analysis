# Soaring with TRILLI: An HW/SW Heterogeneous Accelerator for Multi-Modal Image Registration

**Problem:** 3D rigid image registration requires compute-intensive geometric transformation with interpolation and similarity metric computation, but existing hardware accelerators cannot address both components effectively since GPUs excel at image transformation while FPGAs dominate in similarity metric computation.

**Method:** TRILLI uses a Versal-based SoC to implement heterogeneous acceleration by mapping image transformation and interpolation to appropriate hardware components, integrating with FPGA-based similarity metric computation to create an optimized end-to-end rigid registration pipeline that leverages each component's computational strengths.

**Novelty:** Optimal heterogeneous hardware mapping that distributes image transformation and similarity metric computation across GPU and FPGA components rather than forcing one hardware type to handle both workloads.
