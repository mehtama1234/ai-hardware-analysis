# Mascot: Predicting Memory Dependencies and Opportunities for Speculative Memory Bypassing

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Memory dependence prediction (MDP) and speculative memory bypassing (SMB) require conflicting predictor properties: MDP tolerates false positives but not false negatives, while SMB tolerates false negatives but not false positives. Prior TAGE-based predictors for either mechanism fail to learn patterns of non-dependence, causing inaccuracy.

## Motivation
Improving instruction-level parallelism (ILP) in out-of-order processors by enabling more aggressive load scheduling requires a unified predictor that can simultaneously satisfy the divergent accuracy requirements of MDP and SMB.

## Method
Mascot builds on TAGE (a prediction technique that uses instruction history patterns) but extends it to track both when memory accesses depend on each other and when they don't. This dual tracking lets it serve two purposes: preventing loads from starting before their dependencies complete, and speculatively sending values directly from stores to loads without waiting for address resolution. A single shared prediction table handles both, eliminating the need for separate hardware.

## Key Novelty
A single prediction table that learns when memory accesses are independent (as well as dependent), letting it handle both dependency prediction and speculative value forwarding.

## Contributions
- Mascot unified predictor that learns dependence and non-dependence contexts for both MDP and SMB
- 0.4% IPC gain over prior state-of-the-art MDP predictor at same size
- 1.9% average IPC gain (up to 26% peak) when enabling both MDP and SMB
- Mascot-opt: compact 10.1 KiB variant achieving similar gains within 0.1%
