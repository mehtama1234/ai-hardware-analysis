# ISSCC-2025-137: Self-Calibrating RC Oscillator with Clock-Glitch Detection

**Problem:**  
On-chip oscillators for SoC security must both provide stable clocks (for boot-up, eliminating external crystal dependency) and detect clock-glitch attacks, but existing designs handle only one function.

**Solution:**  
Self-calibrating RC oscillator in 3nm FinFET with integrated clock-glitch detection, enabling a single validated security IP for both boot independence and real-time attack monitoring.

**Key Results:**  
- 100MHz stable oscillation
- Integrated glitch detection for fault injection attacks
- Single unified security IP

**Key Innovation:**  
First oscillator design combining stable operation with integrated glitch detection in one security IP module.
