# Complex Parsing for In-Network Acceleration of High-Energy Physics Experiments

**Venue:** SC 2025  
**Authors:** Bjoern Sagstad, Nishanth Shyamkumar, Sophia Chen, Wesley Robert Ketchum, Roland Sipos, James B. Kowalkowski, Michael Wang, Nik Sultana

## Problem Statement
The DUNE (Deep Underground Neutrino Experiment) at Fermilab generates massive volumes of network traffic containing digitized detector sensor readings in a custom packet format. Current data processing approaches handle all parsing and filtering at compute nodes, creating network and CPU bottlenecks.

## Technical Approach
**In-Network Packet Parsing:**
- Implements custom packet parser for DUNE data format on Tofino programmable network switch
- Parses Jumbo Ethernet frames containing sensor digitizations
- Early-stage packet processing reduces data reaching compute nodes
- Deployed on FABRIC testbed using ICEBERG DUNE prototype traffic

**DUNE Protocol Characteristics:**
- Custom packet format not compatible with standard Ethernet/IP parsing
- Requires domain-specific parsing logic
- High packet rate from detector arrays

## Evaluation Setup
- **Hardware:** Tofino programmable switch
- **Testbed:** FABRIC (national-scale research testbed)
- **Traffic Source:** ICEBERG DUNE prototype detector simulation

## Findings
- Identified key technical challenges in implementing HEP-specific packet parsing on switches
- Performance bottlenecks due to:
  - Complex custom packet format
  - Limited switch memory and processing pipelines
  - High packet throughput requirements

## Key Contribution
First demonstration that programmable switches can perform useful domain-specific parsing for HEP experiments, opening research directions for in-network acceleration of scientific infrastructure.

## Limitations & Future Work
- **Early Investigation:** No quantitative performance metrics (throughput, latency reduction)
- **Limited Scope:** Evaluation on ICEBERG prototype only; full DUNE detector not tested
- **Resource Constraints:** Challenges with switch memory and pipeline depth not fully resolved
- **Generalization:** Unknown how techniques transfer to other HEP experiments
- **Production Deployment:** Feasibility for real DUNE operations not addressed
