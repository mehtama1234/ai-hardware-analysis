# ReaL: Efficient RLHF Training of Large Language Models with Parameter Reallocation

**ID:** mlsys-2025-030 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
RLHF training involves multiple model functions (actor, critic, reference, reward) with radically different compute/memory profiles, but existing systems use static parallelization that leaves GPU resources underutilized.

## Method
In RLHF training, the model serves four different roles (actor, critic, reference model, and reward model) with different GPU and memory needs. Instead of using one fixed GPU arrangement for all, this system moves the model's parameters between GPUs between stages—each role can use the GPU layout optimized for it. The system uses MCMC (a statistical method that efficiently explores configuration options) to automatically find the best way to arrange GPUs for each stage and the order to run them.

## Key Novelty
Instead of keeping model parameters in one fixed GPU arrangement throughout the training pipeline, this redistributes them between RLHF stages to match each stage's needs, using MCMC to find the optimal redistribution and execution order.

## Metrics
- **Speedup:** 3.58x over DeepSpeed-Chat/OpenRLHF/NeMo-Aligner/veRL; 81% over Megatron-LM heuristic (8192 ctx, H100 128-GPU)
- **Accuracy:** No degradation in reward model quality

## Baselines
DeepSpeed-Chat, OpenRLHF, NeMo-Aligner, veRL, Megatron-LM
