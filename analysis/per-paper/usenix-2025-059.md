# Bluetooth Low Energy Security Testing with Combinatorial Methods

**Problem:** Bluetooth Low Energy testing is difficult due to HCI abstraction layers, and fuzzing approaches are inherently probabilistic, potentially leaving vulnerabilities undiscovered. BLE implementations across multiple devices and firmware versions contain numerous exploitable security flaws.

**Method:** The work enhances a Bluetooth Low Energy fuzzing framework with Combinatorial Security Testing, a method that systematically explores all combinations of protocol inputs and device states instead of random sampling. Because it tests all meaningful cases, this approach is more reliable at finding security bugs than traditional fuzzing. The researchers evaluate it on 10 real Bluetooth devices across multiple firmware versions and measure how many bugs it finds and execution time compared to traditional fuzzing.

**Novelty:** Combinatorial Security Testing with guaranteed input space coverage—systematically testing all input combinations—overcomes the probabilistic limitations of traditional fuzzing for finding Bluetooth Low Energy security bugs.
