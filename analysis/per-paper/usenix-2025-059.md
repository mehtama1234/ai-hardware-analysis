# Bluetooth Low Energy Security Testing with Combinatorial Methods

**Problem:** Bluetooth Low Energy testing is difficult due to HCI abstraction layers, and fuzzing approaches are inherently probabilistic, potentially leaving vulnerabilities undiscovered. BLE implementations across multiple devices and firmware versions contain numerous exploitable security flaws.

**Method:** The approach enhances a custom BLE fuzzing framework with Combinatorial Security Testing (CST) that systematically explores combinations of protocol inputs and states to guarantee input space coverage. Evaluation targets 10 real BLE devices across multiple firmware versions, comparing CST against fuzzing on both execution time and fault discovery rates.

**Novelty:** Applying Combinatorial Security Testing with guaranteed input space coverage to overcome the probabilistic limitations of fuzzing in BLE protocol testing.
