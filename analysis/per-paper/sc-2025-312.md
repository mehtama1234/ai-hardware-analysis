# SC-2025-312: ATLAHS: An Application-centric Network Simulator Toolchain for AI, HPC, and Distributed Storage

## Summary
This work presents ATLAHS, an open-source network simulation toolchain designed to accurately model real-world applications in AI systems, HPC, and distributed storage. Using the GOAL (Group Operation Assembly Language) trace format, ATLAHS enables flexible simulation across multiple network backends while maintaining high accuracy (<5% error) and significantly outperforming existing simulators like AstraSim.

## Key Contributions
1. **ATLAHS simulation toolchain** for application-centric network modeling
2. **GOAL trace format** for portable, reusable workload representation
3. **Multi-scenario support** including multi-job and multi-tenant execution
4. **High-fidelity simulation**: <5% error on realistic workloads
5. **Performance improvement** over AstraSim in simulation runtime and trace efficiency

## Technical Approach
- Application trace collection and GOAL format conversion
- Flexible simulation backend architecture supporting multiple network simulators
- Multi-job and multi-tenant scenario orchestration
- Congestion control, job placement, and scheduling simulation
- Comprehensive validation on real distributed systems

## Hardware & Systems
- Simulated HPC interconnects (Dragonfly, fat-tree, etc.)
- AI system networks (data center topologies)
- Distributed storage system networks
- Multi-tier network architectures

## Workloads & Evaluation
- **Domains**: AI training/inference, HPC applications, distributed storage
- **Case studies**: 
  - Congestion control impact on distributed storage performance
  - Job placement strategies effect on application runtime
- **Accuracy**: <5% error on real-world workloads
- **Scalability**: Handling multi-job and multi-tenant scenarios
