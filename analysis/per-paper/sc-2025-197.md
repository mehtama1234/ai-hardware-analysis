# A GPU FFT Wrapper to Co-optimize Floating-Point Precision and Library Selection via Predictive Error Modeling

**Venue:** SC  
**Theme:** Precision and Library Optimization  
**Confidence:** low

## Problem Statement
FFT libraries exhibit different performance-accuracy tradeoffs at different scales and precisions; selecting optimal library+precision combination requires manual exploration or expensive profiling

## Motivation
FFT is ubiquitous in scientific computing; enabling automatic precision/library selection could unlock substantial performance gains (>40% speedup) with guaranteed error bounds

## Methodology
ML-based wrapper library that samples input features, predicts per-kernel error via lightweight model, selects library+precision minimizing runtime/energy while meeting error threshold

## Key Novelty
First framework combining multiple GPU FFT libraries with ML-based precision/library co-optimization; addresses performance-accuracy tradeoff systematically

## Contributions
- Characterization of precision-performance-accuracy tradeoffs across FFT libraries
- Lightweight ML predictor achieving 98% selection accuracy
- Wrapper library seamlessly integrating into existing workflows
- Mean speedups exceeding 40% vs double-precision baseline

## Limitations & Future Work
