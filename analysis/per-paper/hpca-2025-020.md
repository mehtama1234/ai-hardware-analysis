# hpca-2025-020 — Grad: Intelligent Microservice Scaling by Harnessing Resource Fungibility

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing auto-scaling solutions for microservices focus only on critical bottleneck services and ignore non-critical microservices, missing resource efficiency opportunities through inter-service resource fungibility under co-location contention.

## Motivation
Cloud operators need to maximize resource utilization while maintaining SLA compliance; resource fungibility between critical and non-critical microservices can simultaneously reduce waste and prevent latency violations.

## Method
Grad learns how each microservice's response time changes with different CPU and memory allocations, accounting for interference from other services. Using calculus-based optimization to find where performance improves most per additional resource (gradient-based extraction), it automatically selects which microservices—both bottleneck and supporting ones—should get more resources. A real-time simulator predicts overall performance and detects when response-time targets are missed (SLA violations). The approach was tested on real microservice benchmarks and production workloads.

## Key Novelty
Grad jointly scales both critical and non-critical microservices by measuring how each responds to resources and how they interfere with each other—recognizing that one service's resources can help another service perform better (resource substitutability)—to minimize overall latency.

## Contributions
- Identification that non-critical microservice scaling via resource fungibility improves efficiency.
- Modular latency profiling with gradient extraction for microservice resource modeling.
- Scalable gradient-based optimization for dynamic joint microservice scaling.
- 49.1% resource reduction; 3.7x fewer SLA violations vs. state-of-the-art.
