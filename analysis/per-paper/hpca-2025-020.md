# hpca-2025-020 — Grad: Intelligent Microservice Scaling by Harnessing Resource Fungibility

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing auto-scaling solutions for microservices focus only on critical bottleneck services and ignore non-critical microservices, missing resource efficiency opportunities through inter-service resource fungibility under co-location contention.

## Motivation
Cloud operators need to maximize resource utilization while maintaining SLA compliance; resource fungibility between critical and non-critical microservices can simultaneously reduce waste and prevent latency violations.

## Method
Three components: (1) modular learning profiles individual microservice latency vs. resource/environment; (2) gradient extraction enables a scalable optimization module for dynamic joint microservice selection for scaling; (3) end-to-end latency predictor as real-time simulator for rapid SLA feedback. Evaluated on real microservice benchmarks and production traces.

## Key Novelty
Gradient-based resource fungibility framework jointly optimizing scaling of both critical and non-critical microservices by modeling their latency-resource trade-offs and inter-service resource substitutability.

## Contributions
- Identification that non-critical microservice scaling via resource fungibility improves efficiency.
- Modular latency profiling with gradient extraction for microservice resource modeling.
- Scalable gradient-based optimization for dynamic joint microservice scaling.
- 49.1% resource reduction; 3.7x fewer SLA violations vs. state-of-the-art.
