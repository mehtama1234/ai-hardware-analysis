# H2EAL: Hybrid-Bonding Architecture with Hybrid Sparse Attention for Efficient Long-Context LLM Inference

**Venue:** ICCAD | **ID:** iccad-2025-048

## Problem
High energy and latency overhead from KV cache limits edge deployment of long-context LLMs. Traditional near-memory processing trades bandwidth efficiency for power. Attention heads exhibit different sparsity patterns mismatched to hardware.

## Motivation
Enable efficient long-context LLM inference on edge devices through hardware-algorithm co-design.

## Method
The system uses hybrid sparse attention, which recognizes that different attention heads benefit from different patterns of skipping computations—some heads skip the same token pairs consistently (static sparsity), while others skip adaptively based on what's important in each input (dynamic sparsity). The hardware exploits this by placing compute and memory directly adjacent to each other using hybrid bonding (stacking silicon dies closely to share data locally), eliminating long data transfers that consume power. A load-balancing scheduler breaks the attention computation into tiles and orchestrates parallel execution, ensuring all compute units stay busy and work distributes evenly across the hardware.

## Key Novelty
The system combines hybrid sparse attention—which adapts each attention head to use static or dynamic sparsity—with hybrid bonding hardware that co-locates compute and memory to efficiently match the varying sparsity patterns across heads.

## Contributions
- Hybrid sparse attention scheme combining static and dynamic sparsity for different heads
- Memory-compute co-placement architecture leveraging distributed memory
- Load-balancing scheduler with parallel tiled attention for workload optimization
