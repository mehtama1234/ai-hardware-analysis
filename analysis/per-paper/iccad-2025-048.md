# H2EAL: Hybrid-Bonding Architecture with Hybrid Sparse Attention for Efficient Long-Context LLM Inference

**Venue:** ICCAD | **ID:** iccad-2025-048

## Problem
High energy and latency overhead from KV cache limits edge deployment of long-context LLMs. Traditional near-memory processing trades bandwidth efficiency for power. Attention heads exhibit different sparsity patterns mismatched to hardware.

## Motivation
Enable efficient long-context LLM inference on edge devices through hardware-algorithm co-design.

## Method
HB-based accelerator with hybrid sparse attention co-design: algorithm level proposes hybrid sparse attention with static and dynamic sparsity per head; hardware level implements memory-compute co-placement to leverage distributed memory. Load-balancing scheduler with parallel tiled attention addresses workload imbalance and optimizes mapping.

## Key Novelty
Hybrid sparse attention algorithm-hardware co-design exploiting both static and dynamic sparsity patterns within hybrid bonding architecture.

## Contributions
- Hybrid sparse attention scheme combining static and dynamic sparsity for different heads
- Memory-compute co-placement architecture leveraging distributed memory
- Load-balancing scheduler with parallel tiled attention for workload optimization
