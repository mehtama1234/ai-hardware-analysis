# Ariadne: A Hotness-Aware and Size-Adaptive Compressed Swap Technique for Fast Application Relaunch and Reduced CPU Usage on Mobile Devices
**Venue:** HPCA 2025 | **ID:** hpca-2025-005 | **Confidence:** low (abstract only)

## Problem
Mobile devices under memory pressure use ZRAM (RAM-based compressed swap) but ZRAM prolongs relaunch latency because it applies uniform compression settings regardless of data hotness, does not differentiate compression chunk size, and lacks prefetching of soon-to-be-needed decompressed data.

## Motivation
Application relaunch latency and CPU compression/decompression cost directly impact mobile user experience, and growing app memory footprints exacerbate memory pressure on fixed mobile DRAM.

## Method
Ariadne tracks which memory pages get used frequently when an app relaunches (labeled 'hot'), sometimes ('warm'), or rarely ('cold'), and remembers these labels for future relaunches. It compresses hot and warm memory using small chunks that decompress quickly on the critical launch path, while using large chunks for cold data to save more storage space. It also predicts which pages will be needed next during startup and decompresses them in advance, so this decompression happens in parallel with the app launching.

## Key Novelty
The core idea is to compress relaunch-critical data into small fast-decompressing chunks while compressing rarely-used data into larger high-compression chunks, and to predict which data is needed next so decompression can happen in the background.

## Contributions
1. Observation that anonymous data hotness is stable across consecutive relaunches with spatial locality
2. Low-overhead hotness classification for ZRAM pages
3. Size-adaptive compression per hotness tier (speed vs ratio trade-off)
4. 50% relaunch latency reduction and 15% CPU usage reduction vs ZRAM on Google Pixel 7 (Android 14)

## Metrics
- **Speedup:** 50% relaunch latency reduction vs ZRAM
- **CPU:** 15% reduction in compression/decompression CPU usage

## Baselines
ZRAM (state-of-the-art mobile compressed swap)

SoC (Google Pixel 7)

Evaluated on a single device (Google Pixel 7); generalization to different SoC configurations and Android versions not discussed.
