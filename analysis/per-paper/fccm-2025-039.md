# Efficient Adaptable Streaming Aggregation Engine

**Problem:** Aggregation queries on grouped and time-series data suffer from high hardware utilization and random memory access patterns when implemented with hash-based approaches or multi-tasking mechanisms.

**Method:** The paper presents a reconfigurable pipeline architecture for streaming aggregation that adapts to different aggregation task types. The design minimizes hardware overhead while achieving high throughput through optimized dataflow and reduced random memory access patterns.

**Novelty:** A reconfigurable streaming aggregation pipeline that achieves high throughput with minimal hardware overhead by eliminating hash-based memory access bottlenecks.
