# SNAcc: An Open-Source Framework for Streaming-based Network-to-Storage Accelerators

**Venue:** SC
**ID:** sc-2025-377
**Confidence:** low

## Problem

General purpose CPUs struggle to keep up with current Ethernet line speeds in network-to-storage pipelines, wasting compute resources and bandwidth for storage management.

## Motivation

FPGAs have wide data paths suitable for network applications; need framework for seamless integration of FPGA-based accelerators with network and storage without CPU bottleneck.

## Method

The framework uses an FPGA (a programmable hardware chip) to connect incoming network data directly to storage drives (NVMe SSDs) without going through the CPU. The FPGA acts as a bridge that moves data and performs processing tasks—like classifying images from the stream—without the main processor getting involved. This works because FPGAs can handle the sustained high-speed data flow that would slow down a general-purpose CPU.

## Key Novelty

It connects 100G Ethernet directly to SSD storage via FPGA, allowing both the network and storage to hit their maximum speed limits simultaneously without the CPU getting in the way.

## Contributions

1. Open-source framework for FPGA network-to-storage accelerators
2. Direct PCIe NVMe access without CPU intervention
3. Bandwidth saturation demonstration for network and storage
