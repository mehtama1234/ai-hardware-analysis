# asplos-2025-006: TempGraph: An Efficient Chain-driven Temporal Graph Computing Framework on the GPU

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Temporal graph path problems require vertices to be processed sequentially along time-dependent chains, creating inherently poor parallelism and slow convergence that prevents existing GPU solutions from exploiting massive thread-level parallelism and high memory bandwidth.

## Motivation
Time-sensitive applications depend on efficient temporal path computation, but the sequential temporal dependency between vertices in temporal graphs fundamentally conflicts with the GPU's SIMT execution model, leaving GPU resources severely underutilized.

## Method
TempGraph breaks a temporal graph (a network of events happening in time order) into separate chains, then runs them in parallel on a GPU using the Generate-Activate-Compute model. Generate creates shortcut references (pointers between chains), Activate identifies which steps across all chains are ready to execute right now, and Compute runs all those steps simultaneously with thousands of GPU threads. The shortcuts let chains proceed without waiting for each other, enabling the full computation to finish quickly while using all of the GPU's parallel capacity.

## Key Novelty
The Generate-Activate-Compute model with inter-chain shortcut references breaks the sequential constraint of temporal dependencies, allowing GPU threads to process time-dependent chains concurrently.

## Contributions
- Chain-driven temporal graph transformation that exposes temporal dependencies as disjoint processable units.
- Generate-Activate-Compute execution model with shortcut references for cross-chain dependency decoupling.
- 3.0-16.2x speedup over state-of-the-art GPU-based temporal graph solutions on an A100 GPU.
- 33.9-368.9x speedup over CPU-based TeGraph on a 128-core CPU machine.
