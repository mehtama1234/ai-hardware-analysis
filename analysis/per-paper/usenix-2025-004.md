# Towards High-Performance Transactional Stateful Serverless Workflows with Affinity-Aware Leasing

**Problem:** Serverless platforms struggle to efficiently maintain transactional state consistency across distributed function invocations while achieving high performance, as state coordination typically introduces significant latency overhead and coordination bottlenecks.

**Method:** The system uses temporary ownership agreements (called leases) to ensure only one function can modify a piece of data at a time, keeping it consistent. To avoid slowdowns from moving data across the network, it places functions close to the data they need (called affinity-aware placement). By combining these two strategies—leasing for consistency and colocated placement for speed—the system handles many concurrent tasks without corruption or major performance loss.

**Novelty:** Use temporary-access leases combined with placing functions near their data to achieve both consistency and speed in serverless systems.
