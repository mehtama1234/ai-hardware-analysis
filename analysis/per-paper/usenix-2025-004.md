# Towards High-Performance Transactional Stateful Serverless Workflows with Affinity-Aware Leasing

**Problem:** Serverless platforms struggle to efficiently maintain transactional state consistency across distributed function invocations while achieving high performance, as state coordination typically introduces significant latency overhead and coordination bottlenecks.

**Method:** The system implements an affinity-aware leasing protocol that manages state ownership across function instances while keeping related computations colocated with their state. Transactional semantics are enforced through lease-based concurrency control that coordinates state access with minimal overhead. The scheduler uses affinity information to optimize function placement and colocation with state, reducing data movement and network latency.

**Novelty:** Combining affinity-aware task scheduling with lease-based distributed state management to achieve both transactional consistency and high throughput in serverless workflows.
