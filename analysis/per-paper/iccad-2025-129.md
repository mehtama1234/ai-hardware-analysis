# LUT-HD: Accelerating Hyperdimensional Computing Inference via Efficient Table Lookup

**Venue:** ICCAD  
**ID:** iccad-2025-129

## Problem
Hyperdimensional computing encoding and associative search phases are computationally expensive and resource-intensive, limiting deployment on edge devices.

## Motivation
Enable efficient HDC inference on resource-constrained platforms for robust cognitive computing applications.

## Method
The approach replaces expensive matrix-vector multiplications in hyperdimensional computing's encoding and search phases with fast lookup operations. This is enabled by binary code quantization, which converts data into a discretized form that maps directly to lookup tables. These table lookups run on a custom FPGA (a programmable chip designed for specific applications) with an optimized pipeline.

## Key Novelty
Replacing matrix-vector multiplications with lookup table operations to speed up hyperdimensional computing while keeping accuracy high.

## Contributions
- Binary code quantization (BCQ) algorithm with lookup table acceleration
- Custom FPGA accelerator tailored for LUT-based HDC
- Performance-optimized pipeline for encoding and associative search
