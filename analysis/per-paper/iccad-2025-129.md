# LUT-HD: Accelerating Hyperdimensional Computing Inference via Efficient Table Lookup

**Venue:** ICCAD  
**ID:** iccad-2025-129

## Problem
Hyperdimensional computing encoding and associative search phases are computationally expensive and resource-intensive, limiting deployment on edge devices.

## Motivation
Enable efficient HDC inference on resource-constrained platforms for robust cognitive computing applications.

## Method
Software-hardware co-design with binary code quantization (BCQ) algorithm using lookup tables to transform matrix-vector multiplications into table lookups; custom FPGA-based accelerator with optimized pipeline for encoding and associative search.

## Key Novelty
Table lookup-based acceleration of HDC matrix-vector multiplications with minimal accuracy loss.

## Contributions
- Binary code quantization (BCQ) algorithm with lookup table acceleration
- Custom FPGA accelerator tailored for LUT-based HDC
- Performance-optimized pipeline for encoding and associative search
