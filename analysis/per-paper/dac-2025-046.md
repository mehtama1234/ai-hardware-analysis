# Scalable Community Detection Using Quantum Hamiltonian Descent and QUBO Formulation

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Classical community detection suffers from computational expense and scalability limits on large-scale graphs.

## Key Idea
Reformulate community detection as QUBO and apply Quantum Hamiltonian Descent (QHD) with multi-level iterative refinement.

## Method
The algorithm reformulates community detection—finding groups of densely connected nodes in a network—as an optimization problem where each node is either in a group or not (a binary choice written as a QUBO, or Quadratic Unconstrained Binary Optimization). It then applies Quantum Hamiltonian Descent, a quantum-inspired optimization technique that finds good solutions by simulating how quantum systems settle into low-energy states. To scale to large networks, the approach uses a multi-level strategy: solving simplified versions of the problem first, then using those results to iteratively refine community assignments across progressively larger sections of the full network.

## Contributions
1. QUBO formulation enabling quantum-inspired optimization
2. Multi-level QHD-based refinement algorithm
3. 5.49% modularity improvement with reduced runtime vs. classical methods
