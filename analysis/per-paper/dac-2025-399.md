# dac-2025-399: SplitSync: Bank Group-Level Split-Synchronization for High-Performance DRAM PIM

**Problem:** Synchronous DRAM PIM requires all bank activation before computation, incurring overhead exceeding computation time. Asynchronous approaches require large shared accumulators per bank.

**Method:** The approach divides DRAM memory into bank groups and lets each group operate independently—loading data from its rows and processing it without waiting for other groups to finish. This independence hides the time overhead of row activation (the delay in accessing stored memory data) that would otherwise slow computation. Within each bank group, however, all banks stay synchronized, which eliminates the need for large accumulator circuits (temporary storage units needed for intermediate results). This hybrid two-level synchronization balances the speed gains from independent group operation with the area efficiency from coordination within groups.

**Key Novelty:** Hybrid split synchronization at bank group level balancing activation hiding and area efficiency.

**Contributions:**
- Bank group-level split synchronization
- Asynchronous inter-BG operation
- Synchronous intra-BG eliminates accumulators
- 1.70x vs conventional PIM, 1.06x vs asynchronous

**Confidence:** low (abstract-only)
