# Addressing Reproducibility Challenges in HPC with Continuous Integration

**Venue:** SC
**ID:** sc-2025-134
**Confidence:** low

## Problem
HPC research reproducibility is limited by unique infrastructure access, software complexity, and lack of CI/CD tooling tailored to HPC.

## Motivation
SC badges incentivize reproducibility but infrastructure uniqueness makes it hard to reproduce; CI can substitute when access is unavailable.

## Method
They built a GitHub Action—a tool that automatically runs when code changes—that securely connects to and runs tests on remote HPC machines. This solves the problem that HPC researchers can't easily test their code on the specialized hardware they need without manual work. The tool includes security controls so only trusted code can access expensive HPC systems. They also surveyed existing reproducibility efforts and identified the main barriers preventing HPC research from being more reproducible.

## Key Novelty
They enabled GitHub Actions to automatically run tests on remote HPC machines with security protections, allowing HPC research to be reproduced without manual intervention on specialized hardware.
