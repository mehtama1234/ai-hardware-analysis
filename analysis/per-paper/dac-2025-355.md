# Generative Model Based Standard Cell Timing Library Characterization

**Venue:** DAC  
**ID:** dac-2025-355

## Problem
Accurate cell timing characterization across PVT corners is essential, but conventional SPICE simulation becomes prohibitively expensive as corner count explodes.

## Motivation
Post-Moore design complexity and corner explosion make SPICE-based characterization inefficient; scalable methods needed.

## Key Innovation
Generative model approach (GAN + autoencoder hybrid) to timing library characterization, enabling high-accuracy, scalable prediction across corners.

## Method
The approach uses machine learning to predict circuit timing instead of running expensive electrical simulations. It trains neural networks to recognize timing patterns by learning from existing data: one type (generative adversarial network) generates timing predictions, while another type (autoencoder) learns a compact representation of timing characteristics. These models learn how circuit delays vary across operating conditions like temperature, voltage, and manufacturing variations—what chip designers call 'corners.' Once trained, the networks can rapidly predict timing at new corners without expensive simulations.

## Contributions
- Generative modeling perspective on characterization
- Hybrid GAN/autoencoder architecture
- High-accuracy timing prediction across corners
- Significant runtime reduction vs SPICE
