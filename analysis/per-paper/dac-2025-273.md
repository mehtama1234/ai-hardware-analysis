# dac-2025-273: Precon—Precision-Convertible Architecture for Quantized Models

**Problem:** LLMs are quantization-sensitive; existing accelerators are tailored to specific precision schemes (weight-only, mixed), creating inefficiencies across different models.

**Motivation:** Cloud inference serves diverse quantized workloads (LLMs, CNNs); flexible hardware supporting multiple precisions reduces the need for model-specific accelerators.

**Method:** Precon uses a single processing unit that can switch between 16-bit floating-point (FP16, a decimal number format) and integer arithmetic. By reusing core logic and controlling how data moves through the chip and the sequence of operations, the same hardware can execute three different low-precision combinations: INT4-FP16, INT4-INT4, and INT4-INT8.

**Key Novelty:** Single hardware design supporting efficient inference across diverse quantized workloads via precision-convertible logic.

**Contributions:**
- Unified processing unit (INT4-FP16, INT4-INT4, INT4-INT8)
- 4.1x speedup across domains
- 81.4% energy reduction

**Confidence:** low (abstract-only)

**Tags:** quantization, llm-inference, precision-conversion, mixed-precision
