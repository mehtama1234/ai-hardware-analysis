# FIGLUT: An Energy-Efficient Accelerator Design for FP-INT GEMM Using Look-Up Tables

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Weight-only quantization for LLM deployment produces FP-INT mixed-precision GEMM operations where one operand is floating-point (activations) and the other is low-bit integer (weights); this FP-INT compute is difficult to implement efficiently on conventional GPU multiply-accumulate hardware.

## Motivation
Weight-only quantization is a leading approach to reduce LLM memory footprint and bandwidth, but hardware that efficiently executes the resulting FP-INT GEMM is lacking, limiting achievable TOPS/W.

## Method
Rather than computing floating-point and integer multiplication directly, FIGLUT precomputes all possible products of floating-point activation values (intermediate computations flowing through the neural network) with every possible low-bit integer weight pattern, storing these results in lookup tables. During inference, the hardware looks up the answer in these tables using the weight bits as an index. To reduce memory overhead, the design uses a half-size lookup table variant with a dedicated decoding and multiplexing unit (hardware that selects between precomputed results). This single hardware configuration supports multiple bit precisions and quantization methods (different levels of weight compression).

## Key Novelty
The design uses a half-size lookup table with dedicated decoding to replace floating-point and integer multiplication with table lookups, enabling efficient multi-precision weight-only quantized operations and delivering 59% higher energy efficiency (TOPS/W—computation per watt) than prior lookup-table accelerators.

## Contributions
- FIGLUT LUT-based GEMM architecture replacing FP-INT multipliers with precomputed lookup tables
- Half-size LUT design with dedicated decoding and multiplexing unit reducing storage area
- Single fixed hardware configuration supporting multiple bit precisions and quantization methods
- 59% higher TOPS/W and 20% lower perplexity than state-of-the-art at 3-bit; 98% higher TOPS/W at matched perplexity using 2.4-bit operations
