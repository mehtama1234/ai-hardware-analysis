# An Efficient Compute-in-Memory based Accelerator for Point-based Point Cloud Neural Networks

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Point cloud networks are computationally intensive with irregular access patterns; edge deployment requires memory-efficient acceleration.

## Method
**Reconfigurable CIM unit** exploits zero-bit-skipping sparsity via feature decomposition. **Voxel-Morton-sorted Partitioning (VMP)** and **Channel-wise Minimum** improve decomposition sparsity. **Bit-level Truncation Quantization (BTQ)** compresses bit-width without hardware overhead. **Pre-decomposition** reduces data movement.

## Key Novelty
CIM architecture with adaptive feature decomposition and bit-sparsity exploitation for efficient point cloud inference.

## Results
- **1.69-9.63× speedup**
- **3.11-17.32× energy efficiency improvement** vs state-of-the-art
