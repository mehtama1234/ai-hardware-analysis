# An Efficient Compute-in-Memory based Accelerator for Point-based Point Cloud Neural Networks

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Point cloud networks are computationally intensive with irregular access patterns; edge deployment requires memory-efficient acceleration.

## Method
Point-CIM accelerates point cloud processing with a reconfigurable compute-in-memory unit (a special chip that performs calculations where data is stored and can be configured for different tasks). It uses three techniques to reduce unnecessary work: skipping multiplications by zero, reorganizing 3D point data in a spatial order (Voxel-Morton-sorted Partitioning) with minimum reference points per feature channel for better compression, and storing numbers in fewer bits (Bit-level Truncation Quantization) without needing extra hardware. An optimized data arrangement loads everything to the compute array in one sequence, avoiding repeated transfers between buffer and array.

## Key Novelty
Point-CIM's core idea is a reconfigurable compute-in-memory architecture that accelerates point cloud neural networks by exploiting bit-level sparsity (using fewer bits per number) through feature decomposition and compression-aware optimization.

## Results
- **1.69-9.63× speedup**
- **3.11-17.32× energy efficiency improvement** vs state-of-the-art
