# Guaranteed Yet Hard to Find: Uncovering FPGA Routing Convergence Paradox

**Problem:** PathFinder, the ubiquitous FPGA routing algorithm, fails to find guaranteed legal routing solutions in constrained problems where solutions are provably available. When circuits fail to route, it is unclear whether the root cause is the routing algorithm or the architecture.

**Method:** The authors built specially designed routing puzzles where solutions are mathematically guaranteed to exist but resources are limited. This setup let them pinpoint exactly where PathFinder fails. They discovered that PathFinder's approach of routing each connection in isolation and making greedy choices (picking the immediately easiest path without considering the overall picture) creates tangled paths with excess nodes. They designed a better algorithm that avoids this trap by making more coordinated routing decisions.

**Novelty:** PathFinder fails because routing each connection greedily in isolation builds paths with unnecessary nodes, even when more efficient solutions are possible.
