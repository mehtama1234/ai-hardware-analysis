# DECA: A Near-Core LLM Decompression Accelerator Grounded on a 3D Roofline Model

**Venue:** MICRO 2025  
**Confidence:** High (analyzed from full text)

## Problem
LLM inference on CPU servers (Intel Sapphire Rapids with AMX TMUL and HBM) is bottlenecked not by memory bandwidth or matrix compute throughput, but by AVX vector decompression overhead: decompressing quantized (BF8, MXFP4) and sparsified weight tiles in software consumes over 95% of dynamic instructions per core, and even a 4x increase in AVX vector throughput is insufficient to eliminate this bottleneck for highly compressed models.

## Motivation
CPU servers are an increasingly attractive LLM inference platform due to AMX matrix engines and HBM, but the inability of the traditional 2D roofline model to expose the vector-decompression bottleneck makes it unclear how to improve the system; a principled, model-driven hardware solution is needed.

## Method
DECA is a near-core ML model decompression accelerator placed alongside each CPU core, sharing the L2 TLB and connected via memory-mapped interface. Its three-stage pipeline:
1. **Dequantization** — LUT array (L parallel 256-entry LUTs) converts 1–8 bit quantized values to BF16.
2. **Expansion (de-sparsification)** — crossbar (XBAR) controlled by Parallel Prefix Sum-generated expansion indices inserts zeros at bitmask-specified positions.
3. **Scaling** — applies per-group scale factors for group quantization (e.g., MXFP4's 32-element groups).

Two duplicated Loader+TOut register pairs enable hardware double buffering. The **TEPL ISA extension** (Tile External Preprocess and Load) eliminates per-iteration memory fences: TEPL instructions are issued speculatively out-of-order like loads, safe because DECA never writes memory. The design is grounded in the **3D Roof-Surface model** that extends the 2D roofline with a vector-throughput axis (AIXV), correctly attributing the bottleneck to VEC operations rather than MEM for HBM systems.

## Key Novelty
A 3D Roof-Surface analytical model that adds a vector-throughput dimension to the traditional roofline, directly motivating and correctly sizing DECA, combined with the TEPL out-of-order ISA extension that speculatively invokes the near-core accelerator without serializing fences.

## Contributions
- **Roof-Surface model** (3D visual + 2D BORD projection) correctly predicts VEC-bound bottleneck for compressed HBM GeMMs where roofline is off by up to 4.94x.
- **DECA near-core accelerator** with LUT/XBAR/scaling pipeline: supports 1–8 bit quantization, arbitrary unstructured sparsity, group quantization; up to 4x over libxsmm.
- **TEPL ISA extension** for out-of-order, speculative DECA invocation with squash safety, eliminating per-iteration memory fences.
- Llama2-70B/OPT-66B next-token time: 1.6x–2.6x vs software-only; 2.5x–5.0x vs uncompressed baseline on simulated 56-core SPR with HBM.

## Hardware Target
CPU (Intel Sapphire Rapids with AMX+HBM), ASIC-style near-core accelerator

## Technique Categories
quantization, sparsity, near-data-processing, memory-system, compiler

## Workloads
LLM-inference (Llama2-70B, OPT-66B generation phase)

## Metrics
- **Speedup:** Up to 4x over Intel libxsmm on compressed GeMMs
- **Inference latency:** 1.6x–2.6x reduction in next-token time vs software-only; 2.5x–5.0x vs uncompressed baseline
- **Model accuracy:** Roof-Surface within ~10% of real measurements; libxsmm BF8_5%/HBM achieves only 20% of roofline-optimal

## Baselines
Intel libxsmm software kernels (AVX+AMX cooperative), uncompressed BF16 baseline on SPR DDR5/HBM

## Limitations
Evaluation is simulation-only (56-core SPR model); no silicon measurements. Analysis focuses on generation-phase (small batch) inference where weight bandwidth dominates; not evaluated for prompt phase or large-batch workloads.
