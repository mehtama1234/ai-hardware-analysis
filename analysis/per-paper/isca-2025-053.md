# Neo: Towards Efficient Fully Homomorphic Encryption Acceleration using Tensor Core
**ID:** isca-2025-053 | **Venue:** ISCA | **Confidence:** low (abstract-only)

## Problem
Fully Homomorphic Encryption (FHE) imposes massive computational overhead—orders of magnitude over plaintext computation—that prevents practical deployment, while existing ASIC accelerators lack generality as FHE algorithms rapidly evolve. GPU-based solutions exist but fail to exploit tensor core (TCU) hardware for the dominant FHE primitives.

## Motivation
FHE enables privacy-preserving computation on encrypted data, but its performance gap vs. plaintext is too large for real-world use; exploiting the high throughput of Tensor Cores on modern GPUs is a promising path to close this gap without sacrificing generality.

## Method
Neo maps the CKKS FHE scheme's core operations—Number Theoretic Transform (NTT) and polynomial multiplication—onto GPU Tensor Cores (TCUs) by reformulating them as matrix operations compatible with the TCU's INT8/FP16 matrix-multiply-accumulate pipeline. The design includes careful decomposition of NTT butterfly stages and residue number system (RNS) arithmetic to fit TCU matrix dimensions, with custom CUDA kernels orchestrating data layout, twiddle factor injection, and modular reduction to avoid overflow in low-precision arithmetic.

## Key Novelty
Reformulating FHE polynomial arithmetic (NTT and RNS multiplication for CKKS) as tensor-core matrix operations, enabling use of specialized high-throughput TCU hardware for cryptographic workloads rather than general CUDA cores.

## Contributions
- TCU-based acceleration of NTT and polynomial multiplication for the CKKS FHE scheme
- Custom kernel design mapping FHE polynomial arithmetic to INT8/FP16 matrix operations within GPU tensor cores
- Analysis of precision requirements and modular arithmetic constraints to preserve correctness under low-precision TCU computation
- Performance evaluation demonstrating GPGPU FHE acceleration with Tensor Core utilization
