# NVR: Vector Runahead on NPUs for Sparse Memory Access

**Venue:** DAC  
**ID:** dac-2025-351

## Problem
Sparse DNNs suffer from irregular memory access patterns causing high cache miss rates and stalls, negating computational benefits of sparsity.

## Motivation
Model pruning and sparsity reduce parameters but create cache-miss bottlenecks offsetting gains.

## Key Innovation
Runahead prefetching mechanism specialized for NPU architecture, providing general micro-architectural solution for sparse DNN cache misses without compiler/algorithmic modification.

## Method
Adapts runahead execution to NPU as decoupled, speculative, lightweight sub-thread running ahead to prefetch data; operates with <5% hardware overhead without compiler support.

## Contributions
- Runahead prefetching adapted to NPU architecture
- Lightweight decoupled sub-thread design with <5% overhead
- General solution requiring no compiler/algorithmic changes
- 90% cache miss reduction; 4x average speedup on sparse workloads

## Results
90% cache miss reduction vs SOTA prefetching; 4x average speedup on sparse workloads; 5x benefit from 16KB cache vs L2 expansion.
