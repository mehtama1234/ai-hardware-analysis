# HATT: Hamiltonian Adaptive Ternary Tree for Optimizing Fermion-to-Qubit Mapping

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Mapping Fermionic quantum systems to qubit systems produces Hamiltonians with high Pauli weight, inflating quantum circuit gate count and depth. Existing Fermion-to-qubit mappings are not tailored to specific Hamiltonian structures, leading to unnecessary overhead.

## Motivation
Reducing Pauli weight and circuit depth is critical for near-term quantum devices where gate error accumulates with circuit length, making Hamiltonian-aware mappings essential for practical quantum chemistry simulation.

## Method
HATT converts fermionic quantum systems (particles that behave like fermions) into qubits (quantum bits) using a customized bottom-up tree construction tailored to the specific system's properties. Rather than using generic methods like Jordan-Wigner or Bravyi-Kitaev, the algorithm analyzes the target quantum system and builds a ternary tree (a branching structure where each node has up to three children) that minimizes Pauli weight (the complexity measure of quantum operations needed). This reduces the algorithmic complexity from O(N^4) to O(N^3) while preserving the vacuum state properties (the zero-particle quantum state needed for correct simulation).

## Key Novelty
The core idea is a bottom-up ternary tree construction that is Hamiltonian-aware—meaning it adapts itself to fit the specific quantum system being studied—thereby reducing computational complexity from O(N^4) to O(N^3).

## Contributions
- HATT framework for Hamiltonian-adaptive Fermion-to-qubit mapping using ternary trees
- Bottom-up construction procedure reducing algorithm complexity from O(N^4) to O(N^3)
- Preservation of vacuum state property in optimized mappings
- Experimental validation on IonQ quantum devices showing noise-resilience benefits
