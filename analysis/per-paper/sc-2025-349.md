# Fantastic Hardware Counters and How to Find Them: Automating the Detection of Noise-Resilient Performance Counters in HPC

**Paper ID:** sc-2025-349
**Venue:** SC
**Confidence:** low

## Problem Statement
Hardware performance counters are noisy and unreliable for performance modeling on HPC systems

## Motivation
Accurate performance models require noise-resilient counters, but manual selection is tedious and system-dependent

## Method
The tool automatically sets up and runs the same performance test repeatedly, measuring results from hardware performance counters—numeric readings that track what's happening in the CPU/GPU during execution. It analyzes how much each counter's results vary from run to run, identifying which ones stay stable despite system noise (interference from background processes and unpredictable system behavior). Finally, it ranks all available counters by their resilience, showing which ones reliably give consistent measurements even when other things are happening on the system.

## Key Novelty
It automatically identifies which hardware performance counters remain stable by running experiments repeatedly and selecting the ones that produce consistent results every time.
