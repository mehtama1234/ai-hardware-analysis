# Fantastic Hardware Counters and How to Find Them: Automating the Detection of Noise-Resilient Performance Counters in HPC

**Paper ID:** sc-2025-349
**Venue:** SC
**Confidence:** low

## Problem Statement
Hardware performance counters are noisy and unreliable for performance modeling on HPC systems

## Motivation
Accurate performance models require noise-resilient counters, but manual selection is tedious and system-dependent

## Method
Automated tool that: builds experimental setup, runs repeated experiments, analyzes counter noise patterns, ranks counters by resilience

## Key Novelty
Automated detection and ranking of noise-resilient hardware counters with systematic noise analysis methodology

## Contributions
- Automated counter selection framework
- Noise resilience metrics and ranking system
- Tool with graphical and console interfaces
