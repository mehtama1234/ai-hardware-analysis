# Engine-Agnostic Model Hot-Swapping for Cost-Effective LLM Inference

**Venue:** SC
**ID:** sc-2025-329
**Confidence:** low

## Problem Statement
LLM inference services face cost/efficiency challenges: GPUs must handle bursty requests, leading to underutilization and high costs; models must be swapped between GPU and host memory.

## Motivation
Large-scale inference is expensive; dynamic model loading/unloading via hot-swapping can reduce costs if engine-agnostic; recent GPU drivers enable transparent checkpointing.

## Method
SwapServeLLM saves model checkpoints to GPU, enabling hot-swapping (moving models in and out without stopping service) between fast GPU memory and slower host memory as requests arrive. It analyzes incoming request patterns to decide which models should stay on GPU, and directs requests to minimize response delays. The same checkpointing approach works across different serving engines like vLLM and Ollama without needing engine-specific code, letting providers pause underutilized models and reactivate them when demand increases.

## Key Novelty
The core innovation is using a single checkpointing technique to swap models between GPU and host memory identically across any serving engine, eliminating engine-specific engineering.
