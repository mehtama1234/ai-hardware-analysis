# Engine-Agnostic Model Hot-Swapping for Cost-Effective LLM Inference

**Venue:** SC
**ID:** sc-2025-329
**Confidence:** low

## Problem Statement
LLM inference services face cost/efficiency challenges: GPUs must handle bursty requests, leading to underutilization and high costs; models must be swapped between GPU and host memory.

## Motivation
Large-scale inference is expensive; dynamic model loading/unloading via hot-swapping can reduce costs if engine-agnostic; recent GPU drivers enable transparent checkpointing.

## Method
SwapServeLLM: engine-agnostic hot-swapping using GPU checkpointing. Mechanisms: (1) demand-aware preemption via concurrent request info, (2) memory-aware routing with minimized latency.

## Key Novelty
Engine-agnostic hot-swapping for LLM inference using transparent GPU checkpointing; unified approach across vLLM, Ollama, etc.

## Contributions
1. SwapServeLLM hot-swapping method
2. 31x faster model loading (vs vLLM)
3. 29% faster loading (vs Ollama)
4. Cost-effective inference at scale
