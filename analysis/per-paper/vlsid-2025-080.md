# An SRAM-Based Multi-Operand Architecture Implementing Multi-Bit Boolean Functions Using in-Memory Periphery Computing

**VLSID 2025** | vlsid-2025-080

## Abstract
Conventional SRAM uses shared bitlines for read/write, limiting in-memory compute. This work presents a modified 9T SRAM with dedicated read lines enabling periphery-based multi-operand multi-bit Boolean operations (AND/NAND/NOR/OR, arbitrary sum-of-products, parallel XOR). Demonstration: 64-bit operations at TSMC 65nm, 24.5 fJ/bit @ 0.7V, 660 MHz (XOR), 384 MHz (logic).

## Problem
- Conventional SRAM bitline sharing restricts in-memory compute capabilities
- Boolean operations require data movement to processor, increasing energy/latency
- Multi-operand and arbitrary function support difficult with traditional SRAM

## Key Insight
Separating read and write bitlines in SRAM enables dedicated peripheral compute blocks for complex Boolean operations directly in memory array.

## Approach
1. Modified 9T SRAM cell with dedicated read lines
2. Dedicated compute blocks in periphery (N blocks for N-bit operations)
3. Equality checkers select original/complemented inputs
4. Product lines combine outputs (DeMorgan's theorem)
5. Supports arbitrary sum-of-products functions

## Implementation
- **Technology**: TSMC 65nm
- **Voltage**: 0.7V (low-power demonstration)
- **Demonstrated**: 64-bit operations
- **Workloads**:
  - AND/NAND/OR/NOR (N-bit, M-operand)
  - Arbitrary sum-of-products (e.g., F=AB'CD+ABC'D')
  - 64 parallel 2-bit XOR
