# Parallel Dynamic Partitioning for Datapath Combinational Equivalence Checking

**ID**: dac-2025-450  
**Venue**: DAC  
**Confidence**: low

## Problem
Datapath CEC (combinational equivalence checking) is slow and fails on complex arithmetic circuits; state-of-the-art tools cannot efficiently split and solve large datapath verification problems.

## Motivation
Datapath circuits are ubiquitous in high-precision arithmetic accelerators; verification delays block design iteration.

## Method
The approach splits a circuit's verification problem into smaller, independent pieces by identifying key cutting points (critical nodes), which can then be checked in parallel rather than as one large problem. A dynamic task scheduler distributes these verification tasks across processors, keeping the workload balanced so that difficult pieces don't become a bottleneck for the entire process.

## Key Novelty
Critical-node circuit partitioning combined with dynamic task scheduling enables parallel datapath equivalence checking.

## Contributions
- Critical node selection for CEC partitioning
- Dynamic task scheduling with load balancing
- 5.11x-125.27x speedup vs ABC and HybridCEC
- Solves 3x more datapath CEC problems
