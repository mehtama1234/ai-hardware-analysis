# Parallel Dynamic Partitioning for Datapath Combinational Equivalence Checking

**ID**: dac-2025-450  
**Venue**: DAC  
**Confidence**: low

## Problem
Datapath CEC (combinational equivalence checking) is slow and fails on complex arithmetic circuits; state-of-the-art tools cannot efficiently split and solve large datapath verification problems.

## Motivation
Datapath circuits are ubiquitous in high-precision arithmetic accelerators; verification delays block design iteration.

## Method
PDP-CEC partitions the CEC problem at critical nodes to generate independent subproblems; dynamic task scheduling ensures load balancing and prevents hard instances from blocking the overall verification.

## Key Novelty
Critical-node-based circuit partitioning with dynamic task scheduling for parallel datapath CEC.

## Contributions
- Critical node selection for CEC partitioning
- Dynamic task scheduling with load balancing
- 5.11x-125.27x speedup vs ABC and HybridCEC
- Solves 3x more datapath CEC problems
