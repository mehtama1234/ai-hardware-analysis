# Reproducibility Report for SC25 Paper Ab-initio Quantum Transport with the GW Approximation, 42,240 Atoms, and Sustained Exascale Performance

**Venue:** SC 2025 Reproducibility Initiative  
**Evaluator:** Sayef Azad Sakin (SC25 Reproducibility Committee)

## Scope
Independent evaluation of artifact accompanying SC25 paper on ab-initio quantum transport simulations using GW approximation with 42,240 atoms achieving sustained exascale performance.

## Evaluation Purpose
- Verify simulation correctness and physics
- Reproduce exascale performance claims
- Assess code quality and documentation
- Confirm scalability across exascale systems

## Evaluation Methodology
Following SC25 AE guidelines:
- Independent compilation and execution on exascale systems
- Reproduction of performance benchmarks
- Verification of correctness metrics
- Assessment of code availability and reproducibility

## Key Parameters
- **System Size:** 42,240 atoms
- **Method:** GW approximation for quantum transport
- **Target:** Sustained exascale performance (>1 exaflop)

## Note
This report is a secondary artifact. For complete technical details, refer to the main quantum transport paper in the SC25 proceedings.
