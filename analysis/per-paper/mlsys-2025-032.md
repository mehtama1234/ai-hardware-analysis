# SwiftVI: Faster Value Iteration via Heap-Based Action Elimination

**ID:** mlsys-2025-032 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Standard value iteration for large MDPs updates all state-action pairs every iteration, even when most actions can be provably pruned, wasting significant computation.

## Method
For each state, it maintains a sorted ranking (max-heap) of upper-bound reward estimates for each possible action, and discards actions whose upper bounds fall below the current best lower bound after each update. It provides four variants combining different optimizations: VIH (heap only), VIAE (updating states one at a time rather than all together), VIAEH (combining both approaches), and VIAEHL (with a look-ahead step). All exploit the monotone nature of value estimates—they improve or stay constant across iterations—which ensures the action pruning is always correct.

## Key Novelty
It eliminates dominated actions using a sorted list of upper bounds during value iteration, relying on value estimates that only improve (never decrease) over iterations to avoid pre-analyzing the action space.

## Metrics
- **Speedup:** VIH consistently best vs VI/IVI/BAO/AncVI on random and real-world MDPs (exact ratio is MDP-dependent)
- **Accuracy:** Exact value iteration (no approximation)

## Baselines
VI, IVI, BAO, AncVI
