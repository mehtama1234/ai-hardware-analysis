# SwiftVI: Faster Value Iteration via Heap-Based Action Elimination

**ID:** mlsys-2025-032 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Standard value iteration for large MDPs updates all state-action pairs every iteration, even when most actions can be provably pruned, wasting significant computation.

## Method
Maintains a max-heap of action upper bounds per state. After each value update, eliminates actions whose upper bounds fall below the current best lower bound, exploiting monotone value function structure. Four variants: VIH, VIAE, VIAEH, VIAEHL (with increasing pruning aggressiveness).

## Key Novelty
Heap-based action elimination that leverages value function monotonicity to prune dominated actions incrementally without requiring offline precomputation of action space structure.

## Metrics
- **Speedup:** VIH consistently best vs VI/IVI/BAO/AncVI on random and real-world MDPs (exact ratio is MDP-dependent)
- **Accuracy:** Exact value iteration (no approximation)

## Baselines
VI, IVI, BAO, AncVI
