# Accelerating Genome Alignment Pipeline with In-NAND Search Technology and Group Testing Techniques

**Venue:** ICCAD  
**ID:** iccad-2025-209

## Problem
Genome alignment pipelines bottleneck on computational complexity of aligning short reads to reference genomes; existing exact-match filters require expensive NAND page-by-page loading.

## Motivation


## Method
The approach performs computations directly inside NAND flash memory (where the data lives) rather than moving it to a separate processor. It uses group testing—a technique for testing multiple patterns together—to compare many genome sequences against hundreds of memory pages simultaneously in one read cycle. This allows multiple genomic searches to run in parallel, speeding up the filtering stage.

## Key Novelty
The core idea is using group testing (simultaneous multi-pattern matching) inside NAND flash memory to compare hundreds of genome sequences in a single read cycle.

## Contributions
- Computing-in-NAND-flash design for match detection
- Group testing methods for concurrent multi-query searches
- 48-96% reduction in data movement vs GenStore
- 1.60x-4.99x speedup and 30% energy efficiency improvement
