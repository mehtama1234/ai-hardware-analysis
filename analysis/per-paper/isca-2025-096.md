# ATiM: Autotuning Tensor Programs for Processing-in-DRAM

**Venue:** ISCA 2025
**Confidence:** low (abstract-only)

## Problem
DRAM-PIM (UPMEM) software stacks rely on hand-tuned libraries with no high-level abstractions and no systematic optimization framework, forcing manual effort to approach peak hardware utilization for tensor workloads.

## Motivation
DRAM-PIM reduces memory bandwidth pressure for LLM inference, but poor programmability leaves substantial performance untapped.

## Method
ATiM automatically optimizes tensor programs (matrix calculations) for UPMEM systems, which perform computation inside memory chips rather than in the main processor. It searches different ways of organizing code that runs on the main processor and the code that runs inside the memory chips, using techniques designed for UPMEM's structure where memory is organized into separate banks. The system explores different choices like how many parallel workers to use, how to break up loops, and where to place data in memory, then generates optimized code without requiring manual library engineering.

## Key Novelty
ATiM is the first compiler that automatically searches for and generates optimized tensor program code for UPMEM systems, handling their banked-memory structure without requiring engineers to manually write libraries.

## Contributions
1. Automated joint search over host and kernel tensor program space for UPMEM
2. PIM-aware optimizations for boundary conditions in banked DRAM layouts
3. Improved search algorithms for UPMEM's expanded design space
4. Up to 6.18x speedup on UPMEM benchmarks; 8.21x on GPT-J layers
