# ATiM: Autotuning Tensor Programs for Processing-in-DRAM

**Venue:** ISCA 2025
**Confidence:** low (abstract-only)

## Problem
DRAM-PIM (UPMEM) software stacks rely on hand-tuned libraries with no high-level abstractions and no systematic optimization framework, forcing manual effort to approach peak hardware utilization for tensor workloads.

## Motivation
DRAM-PIM reduces memory bandwidth pressure for LLM inference, but poor programmability leaves substantial performance untapped.

## Method
ATiM is a search-based optimizing tensor compiler for UPMEM. It jointly searches the host-side and kernel-side tensor program spaces, applies PIM-aware optimizations for boundary conditions in banked DRAM layouts, and extends standard autotuning algorithms to cover UPMEM-specific parameters (tasklet counts, loop tiling, data placement across DPU banks). The compiler generates fused, hardware-specific code without manual library authoring.

## Key Novelty
First tensor compiler with fully automated autotuning-integrated code generation for a DRAM-PIM system, bridging high-level tensor abstractions to UPMEM's banked-DRAM programming model.

## Contributions
1. Automated joint search over host and kernel tensor program space for UPMEM
2. PIM-aware optimizations for boundary conditions in banked DRAM layouts
3. Improved search algorithms for UPMEM's expanded design space
4. Up to 6.18x speedup on UPMEM benchmarks; 8.21x on GPT-J layers
