# Efficient Performance-Aware GPU Sharing with Compatibility and Isolation through Kernel Space Interception

**Problem:** GPUs are expensive resources that are often underutilized when used by single applications. Multiple workloads need to share GPU resources while maintaining performance isolation and compatibility, but existing GPU sharing solutions require significant modifications or introduce high virtualization overhead.

**Method:** When multiple applications request GPU resources, the system intercepts these requests at the kernel level—the lowest software layer where the OS directly controls hardware. Based on each workload's priority, it schedules GPU compute and memory access across the applications while enforcing isolation boundaries so one app's GPU use doesn't affect another. This kernel-level approach means existing applications don't need to be modified and you don't need to create virtual GPUs.

**Novelty:** Intercepting GPU requests at the kernel level enables transparent, priority-aware GPU sharing and isolation without modifying applications or requiring virtual GPUs.
