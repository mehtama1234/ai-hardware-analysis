# Multi-Object Detection Through Meta-Training in Resource-Constrained UAV-Based Surveillance Applications

**Venue:** VLSID 2025  
**Authors:** Abhishek Yadav, Vyom Kumar Gupta, Kethireddy Harshith Reddy, Masahiro Fujita, Binod Kumar

## Problem Statement
Unmanned aerial vehicles (UAVs) for surveillance require real-time object detection on resource-constrained edge processors. Environmental variation (nighttime, crowds, varied lighting, small objects) causes domain shift and degrades detection accuracy. Training separate models for each domain is impractical; a general model is needed.

## Key Contributions
1. **Meta-Training Framework**: Transfer learning approach for domain generalization across YOLO model variants
2. **Multi-Domain Generalization**: Improved accuracy across diverse conditions (nighttime, crowds, weather, small objects) without single-domain specialization
3. **Average Precision Improvements**: Demonstrated on both public and custom drone imagery datasets
4. **Hardware Deployment**: Validated on three commercially available resource-constrained devices
5. **Open-Source Release**: Code available on GitHub for reproducibility and adoption

## Technical Approach
- **Base Model**: YOLO object detector (multiple configurations tested)
- **Optimization Method**: Gradient descent-based meta-learning for iterative domain adaptation
- **Training Strategy**: Successive training on diverse domains to learn domain-invariant features
  - Domain 1: Nighttime/low-light detection
  - Domain 2: Crowd/high-density object detection
  - Domain 3: Weather/atmospheric effects
  - Domain 4: Small object detection
- **Transfer Learning**: Each domain adaptation step learns to generalize to next domain
- **Deployment**: Tested on three commercial edge devices
