# SSDTrain: An Activation Offloading Framework to SSDs for Faster Large Language Model Training

**Venue:** DAC  
**ID:** dac-2025-359

## Problem
GPU memory capacity growth lags LLM size growth; activations dominate GPU memory during training, limiting micro-batch size and increasing overhead.

## Motivation
Training large LLMs requires offloading activations to reduce GPU memory pressure while maintaining throughput.

## Key Innovation
Adaptive activation offloading to NVMe SSDs with perfect I/O-computation overlap, enabling larger micro-batches and reduced training overhead.

## Method
Adaptively offloads activations to high-capacity NVMe SSDs while fully overlapping data transfers with computation; employs tensor deduplication and forwarding optimizations; integrates with PyTorch, Megatron, DeepSpeed.

## Contributions
- Adaptive activation offloading framework to NVMe SSDs
- I/O-computation overlap eliminating offloading overhead
- Tensor deduplication and forwarding optimizations
- Framework integration with major deep learning frameworks
- 47% reduction in activation peak memory

## Results
47% reduction in activation peak memory with negligible throughput loss; perfect I/O-computation overlap.
