# Bridging Performance Portability and Scalability for Plasma Simulations on Heterogeneous Systems

**ID:** sc-2025-344  
**Venue:** SC 2025  
**Authors:** Nigel Phillip Tan, Scott V. Luedtke, Michela Taufer, Brian J. Albright

## Problem & Motivation

Performance portability abstractions (like **Kokkos**) enable code to run on diverse hardware, but they often come with **performance overhead** that can undermine efficiency on specialized platforms.

**VPIC** (Vector Particle-In-Cell) plasma physics code historically required:
- Manual, hand-tuned CPU optimizations
- Separate GPU implementations
- Significant engineering effort per platform

## Solution: VPIC 2.0 with Kokkos + Optimizations

**VPIC 2.0** adopts Kokkos for portability, then recovers performance via:

### Optimization Strategies
1. **Platform-targeted particle sorting**
   - Data layout optimized for CPU cache hierarchies
   - Coalesced memory access for GPU efficiency
   
2. **Enhanced vectorization**
   - SIMD optimization for CPU cores
   - Kokkos vector semantics for GPU threads
   
3. **Memory access pattern optimization**
   - Prefetching-aware patterns for CPUs
   - Coalescing-aware patterns for GPUs

## Results

| Target | Performance |
|--------|-------------|
| CPU | Matches VPIC 1.2 (legacy hand-tuned) |
| GPU | Superlinear scaling |

## Key Insight

By carefully targeting platform-specific optimizations **within** the Kokkos abstraction layer, you can achieve both **portability AND performance**—eliminating the traditional tradeoff.

## Implications

Enables sustained development of production physics codes across multiple architectures without maintenance burden of separate implementations.
