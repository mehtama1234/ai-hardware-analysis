# PCBFormer: Understanding 3D Structure of RealWorld PCB Traces for S-Parameter Prediction

**Venue:** ICCAD
**ID:** iccad-2025-148
**Confidence:** low

## Problem
S-parameter extraction for PCB traces via electromagnetic simulation is computationally expensive and becomes a bottleneck with iterative design changes in component placement.

## Motivation
Efficient S-parameter prediction enables faster signal integrity analysis and PCB design iteration.

## Method
PCBFormer is a deep learning framework capturing electromagnetic interactions across multiple layers in 3D PCB structures. The model accounts for each layer's properties and multiple traces' coupling effects to predict S-parameters across frequency ranges from DC to 1 GHz.

## Key Novelty
Deep learning framework capturing multi-layer 3D PCB trace interactions for rapid S-parameter prediction.

## Contributions
- Multi-layer 3D PCB structure modeling in deep learning
- Capture of electromagnetic coupling across traces and layers
- 0.86 R² score across 210 S-parameters for realistic PCBs
- High accuracy replacement for electromagnetic simulation
