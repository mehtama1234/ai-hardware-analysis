# Enhancing ChatPORT with CUDA-to-SYCL Kernel Translation Capability

**Venue:** SC

## Problem
Code translation for parallel programming models (CUDA to SYCL) remains largely unexplored despite LLMs' general code translation capabilities

## Motivation
Enable portable code translation across heterogeneous computing platforms with high fidelity

## Method
Parameter-efficient fine-tuning of 19 open-source code models (0.5-34B params) on CUDA-to-SYCL kernel pairs from heterogeneous computing benchmarks

## Key Novelty
ChatPORT: fine-tuned LLMs for parallel kernel translation; demonstrates that modest fine-tuning significantly improves correctness from baseline ~0% to 19.9-81.7%

## Contributions
- Dataset preparation from heterogeneous computing benchmarks for CUDA-SYCL translation
- Parameter-efficient fine-tuning methodology for code models across size spectrum
- Comprehensive evaluation showing effectiveness of fine-tuning for parallel kernel translation

## Hardware Targets
- GPUs (CUDA)
- Heterogeneous processors (SYCL)

## Technique Categories
- Code generation

- Parallel programming

## Workloads
- CUDA kernel translation
- SYCL kernel generation

## Metrics
- correctness_rate: 19.9-81.7% (model-size dependent)
- test_set_size: 62 CUDA kernels

## Baselines
- Unadjusted code LLMs (0% correctness)

## Limitations
Correctness highly model-size dependent; limited test set; potential domain-specificity of training data
