# Enhancing ChatPORT with CUDA-to-SYCL Kernel Translation Capability

**Venue:** SC

## Problem
Code translation for parallel programming models (CUDA to SYCL) remains largely unexplored despite LLMs' general code translation capabilities

## Motivation
Enable portable code translation across heterogeneous computing platforms with high fidelity

## Method
They trained 19 open-source language models (ranging from 500 million to 34 billion parameters—the weights that define what each model knows) on pairs of CUDA and SYCL kernel code, two languages for programming graphics processors and specialized hardware. The training examples came from heterogeneous computing benchmarks—standard test suites for code that runs across mixed CPU and GPU systems. They used parameter-efficient fine-tuning, which adjusts only a small subset of weights rather than retraining everything, making the process faster and cheaper.

## Key Novelty
ChatPORT uses language models fine-tuned on paired CUDA-to-SYCL code examples to translate parallel computation kernels (the core functions that run on graphics processors), achieving 19.9-81.7% correctness compared to the near-0% baseline of unfine-tuned models.

## Contributions
- Dataset preparation from heterogeneous computing benchmarks for CUDA-SYCL translation
- Parameter-efficient fine-tuning methodology for code models across size spectrum
- Comprehensive evaluation showing effectiveness of fine-tuning for parallel kernel translation
