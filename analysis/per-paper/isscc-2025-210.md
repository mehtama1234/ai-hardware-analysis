# isscc-2025-210: Miniature Biomedical Implant Secured by Two-Factor Authentication with Emergency Access

## Quick Summary
Addresses the critical challenge of securing implantable medical devices (IMDs) that handle life-critical therapies and sensitive data while enabling emergency responders to access devices without server-stored credentials.

## Problem
IMDs require Internet connectivity for remote patient and doctor access, but two major challenges emerge:
1. In emergencies, responders lack server-stored pre-shared keys (PSKs), preventing device programming
2. If a doctor's account is compromised (e.g., phishing), attackers can hijack the implant

## Method
Two-factor authentication architecture with emergency override mechanism that allows responders to bypass standard authentication during emergencies without requiring access to the centralized PSK server.

## Key Novelty
Built-in emergency access pathway that does not compromise overall security or require centralized server access in crisis situations.

## Contributions
- Two-factor authentication for IMDs
- Emergency override without credential requirements
- Protection against compromised doctor accounts
- Emergency accessibility without server dependency
