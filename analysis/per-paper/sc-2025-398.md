# Boosting Scientific Error-Bounded Lossy Compression through Optimized Synergistic Lossy-Lossless Orchestration

**Venue:** SC
**ID:** sc-2025-398
**Confidence:** low

## Problem
Scientific workflows on GPUs produce high-throughput data requiring fast error-bounded compression; existing solutions sacrifice ratio or throughput.

## Motivation
High-ratio, low-latency compression is critical for data-intensive scientific computing on exascale systems; GPU-native solutions are needed.

## Method
cuSZ-Hi compresses scientific data on GPUs while keeping errors within a user-set bound. It uses interpolation-based prediction (estimating each value from nearby values) to find the error between the estimate and the actual data, then applies lossless compression to shrink those errors further. Running fully on GPU hardware, this approach compresses large data streams quickly while guaranteeing the data stays within the specified error limit.

## Key Novelty
cuSZ-Hi achieves a 249% compression ratio improvement over existing methods at the same error bound using fully GPU-optimized adaptive prediction.

## Contributions
1. Optimized GPU interpolation-based prediction with adaptive data characteristic handling
2. Systematic lossless encoding pipeline selection for maximum compression ratio
3. 249% compression ratio improvement vs. SOTA with comparable throughput
4. 215% improvement under same PSNR metric
