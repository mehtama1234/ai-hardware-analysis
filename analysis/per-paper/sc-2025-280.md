# Reproducibility Report for SC25 Paper KAMI: Communication-Avoiding General Matrix Multiplication within a Single GPU

**Venue:** SC 2025  
**Author:** Amir Raoofy (SC25 Reproducibility Committee)

## Overview

This reproducibility report documents the artifact evaluation for the SC25 paper "KAMI: Communication-Avoiding General Matrix Multiplication within a Single GPU" by Xiaowen Tian et al., conducted as part of the SC25 Reproducibility Initiative.

## Evaluation Scope

Independent artifact assessment against SC25 Artifact Description and Evaluation appendix criteria, validating the reproducibility of published research on communication-avoiding GPU GEMM.

## Focus Areas

- Artifact functionality and correctness
- Result reproducibility and verification
- Code quality, documentation, and usability
- Ease of artifact setup and execution

## Classification

**Primary Theme:** Research Reproducibility & Artifact Evaluation  
**Confidence:** Low (reproducibility report; limited algorithmic depth)
