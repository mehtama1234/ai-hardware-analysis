# Hardware-Software Co-design for Distributed Quantum Computing

**Venue:** DAC
**ID:** dac-2025-232

## Problem
Distributed quantum computing requires remote entanglement generation, which is probabilistic and has long latency. Naive scheduling wastes opportunity to parallelize gate execution with entanglement generation.

## Motivation
Scaling quantum computers beyond single-chip limits requires distributed architectures; entanglement generation is the critical resource bottleneck, not local gates.

## Method
The system caches successfully-created entangled pairs (connected quantum bits that affect each other) so they're ready immediately when needed. While quantum operations (individual computational steps) run, it continuously generates new pairs asynchronously in the background—meaning generation happens in parallel without pausing other work. A scheduler then adapts which operations execute next based on which pairs are currently available, eliminating idle waiting time.

## Key Novelty
The key idea is to adaptively schedule quantum operations as pairs become available while generating new pairs asynchronously in the background, preventing idle time from unpredictable entanglement latency.

## Contributions

- Entanglement buffering mechanism for DQC
- Asynchronous entanglement generation architecture
- Adaptive gate scheduling based on entanglement patterns
- Improved runtime and output fidelity for realistic DQC systems
