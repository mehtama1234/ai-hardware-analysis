# LLMs Meet Post-Silicon Test Engineering: A New Era (Invited)

## Problem
Post-silicon test engineering requires domain expertise; LLMs lack grounding in test infrastructure for autonomous execution.

## Solution
Two-stage LLM-based AI agent: (1) reasoning stage interprets user queries, (2) grounding stage executes tasks via existing test infrastructure. Case study: Intelligent Engineering Assistant (IEA).

## Impact
Framework for domain-specific LLM automation in test engineering; enables context-aware autonomous task execution.
