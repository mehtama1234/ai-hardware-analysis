# BLOOM: Bit-Slice Framework for DNN Acceleration with Mixed-Precision

**Venue:** DAC
**ID:** dac-2025-230

## Problem
INT4 quantization limited by outliers (high-magnitude values); existing outlier-aware compression adds complex serialization/deserialization logic that dominates execution time, reducing speedup.

## Motivation
Sub-INT8 quantization is necessary for model compression on edge hardware; but outlier handling complexity negates speedup gains.

## Method
Bit-slicing framework exploiting outlier-precision separation: outliers retain higher precision (INT8), normal values use INT4; interleaved bit-level storage exposes sparsity in high-precision components, enabling adaptive dataflow with minimal serialization overhead.

## Key Novelty
Bit-slicing mixed-precision architecture that decouples outlier/normal pathways to eliminate serialization bottleneck.

## Contributions

- Bit-slice framework for mixed-precision DNN acceleration
- Structured sparsity exploitation in interleaved INT4/INT8 values
- Adaptive dataflow for outlier-aware computation
- 1.2-4.0x speedup and 24.6%-71.3% energy reduction vs outlier-aware methods
