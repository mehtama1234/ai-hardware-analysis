# BLOOM: Bit-Slice Framework for DNN Acceleration with Mixed-Precision

**Venue:** DAC
**ID:** dac-2025-230

## Problem
INT4 quantization limited by outliers (high-magnitude values); existing outlier-aware compression adds complex serialization/deserialization logic that dominates execution time, reducing speedup.

## Motivation
Sub-INT8 quantization is necessary for model compression on edge hardware; but outlier handling complexity negates speedup gains.

## Method
The framework uses bit-slicing (storing each number as separate groups of individual bits) to handle outliers and normal values with different precision levels. Outliers—the rare, high-magnitude values—keep 8-bit precision, while regular values compress into 4-bit integers. By arranging these bits in an interleaved pattern, the system finds empty spaces (sparsity) in the high-precision sections, enabling the processor to optimize how data flows without expensive packing and unpacking. This avoids the serialization bottleneck that made previous outlier-aware compression methods impractical.

## Key Novelty
The core idea is using bit-slicing to separate outliers and normal values into different precision levels, eliminating the serialization work that slowed previous methods.

## Contributions

- Bit-slice framework for mixed-precision DNN acceleration
- Structured sparsity exploitation in interleaved INT4/INT8 values
- Adaptive dataflow for outlier-aware computation
- 1.2-4.0x speedup and 24.6%-71.3% energy reduction vs outlier-aware methods
