# An Adaptive Sparse Matrix Compression CIM Accelerator based on 256Kb SOT-MRAM for Downlink Massive MIMO Communications

**Venue:** ICCAD  
**Confidence:** low

## Problem
Downlink precoding in massive MIMO systems involves high-dimensional sparse matrix calculations that existing architectures handle inefficiently; sparse computing for wireless communication remains underexplored in CIM designs.

## Motivation
5G massive MIMO systems require efficient sparse matrix processing for precoding; CIM offers parallel processing advantages but sparse matrix handling is underexplored for wireless applications.

## Method
The accelerator uses compute-in-memory (CIM) technology, which processes data directly where it's stored in memory rather than moving it back and forth to a separate processor. It stores data in 256 kilobytes of SOT-MRAM (a fast magnetic memory) and uses adaptive compression that automatically adjusts data packing based on patterns in the sparse matrix. For MIMO precoding (the signal processing needed to send wireless data to multiple users simultaneously), this minimizes storage while keeping parallel calculations fast through CIM's design.

## Key Novelty
The core innovation is combining compute-in-memory technology with adaptive data compression to efficiently handle the sparse matrix calculations that massive MIMO systems need for wireless precoding.

## Contributions
- First CIM-based sparse matrix accelerator for MIMO precoding
- 8.35× storage overhead reduction for 90% sparsity
- 39.4× power saving
- 9.85× speedup for 32×256×8 MIMO downlink task
