# Breaking the System Noise Barrier at Exascale

**Venue:** SC  
**Theme:** System Software and Noise Management  
**Confidence:** low

## Problem Statement
On exascale systems like El Capitan (1M+ CPU cores, 10K+ GPUs), OS and system services cause application interference, degrading performance and scalability

## Motivation
System noise at extreme scale directly impacts application performance; enabling scientific applications to leverage exascale hardware requires isolation strategies

## Methodology
Two-pronged strategy: (1) isolate system services from applications via cgroup/systemd tuning, (2) apply OS-level tuning to minimize application interference; distribution-independent guide provided

## Key Novelty
First comprehensive system noise characterization and mitigation for exascale systems; provides distribution-agnostic tuning strategies applicable to any Linux system

## Contributions
- Characterization of system noise at exascale (El Capitan)
- System service isolation techniques reducing interference
- OS-level tuning guide for general Linux systems
- Strategies for multi-service co-location management
