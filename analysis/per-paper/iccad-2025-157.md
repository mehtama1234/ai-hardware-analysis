# MASIM - Multi-array Scheduler for SIMD Logic-in-memory

MASIM provides intelligent scheduling for SIMD logic-in-memory systems with multiple processing arrays, minimizing data copy operations through optimized task assignment and data placement. By orchestrating computation across multiple arrays with awareness of data dependencies and array capabilities, the system achieves 28% energy reduction. This work demonstrates that thoughtful scheduling can significantly reduce data movement overhead in memory-compute integrated systems, a critical bottleneck in modern hardware accelerators.
