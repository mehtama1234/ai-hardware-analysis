# Seeing Through Designs: Attention-Based Knowledge Transfer for Preference-Guided Microarchitecture Search

**Venue:** ICCAD  
**Paper ID:** iccad-2025-269

## Problem Statement
Microarchitecture design search faces large search spaces and lengthy validation flows; design knowledge reuse across architectures is limited by PPA metric discrepancies.

## Motivation
Cross-architecture knowledge transfer can accelerate design discovery while meeting user-specified PPA targets.

## Method
The approach uses cross-attention networks—neural mechanisms that learn which design elements affect each other—to understand how a processor's internal structure (microarchitecture) and design tool settings interact. This captures design interdependencies, allowing insights from one processor design to transfer to others despite their different performance characteristics. It then uses uncertainty estimates (confidence in predicted design quality) to guide the search toward solutions matching the designer's preferences for speed, power consumption, and area tradeoffs.

## Key Novelty
Using attention mechanisms to transfer processor design knowledge across different architectures, guided by uncertainty toward the designer's preferred speed-power-area tradeoffs.
