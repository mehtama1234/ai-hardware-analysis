# Deploying Lightweight Input-Aware Selective Instruction Duplication in HPC Applications

**Venue:** SC
**Paper ID:** sc-2025-002
**Confidence:** low

## Problem Statement
Silent data corruptions (SDCs) from transient hardware faults in HPC; input-dependent SDC propagation not captured by existing SID methods that use only default inputs

## Motivation
Modern HPC applications vulnerable to transient faults; existing selective instruction duplication (SID) approaches have poor SDC coverage on non-default inputs

## Method
Protego framework: vulnerability-guided input exploration to identify distinct input groups with different SID patterns; lightweight runtime feature extraction for input classification; adaptive SID deployment

## Key Novelty
Input-aware SID that adapts protection strategy based on runtime input characteristics without full re-profiling

## Contributions
- Vulnerability-guided input exploration methodology
- Lightweight input classification for runtime SID selection
- Adaptive protection framework (Protego)
- Evaluation across 10 HPC applications demonstrating coverage preservation
