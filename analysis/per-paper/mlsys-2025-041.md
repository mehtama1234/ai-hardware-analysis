# FedProphet: Memory-Efficient Federated Adversarial Training via Robust and Consistent Cascade Learning

**ID:** mlsys-2025-041 | **Venue:** MLSYS 2025

## Problem
Federated Adversarial Training (FAT) requires large models for accuracy and robustness, but memory-constrained edge devices cannot fit full-model training; existing memory-efficient FL methods sacrifice accuracy or robustness.

## Method
FedProphet uses adversarial cascade learning: the model is partitioned into sequential modules, each trained on a subset of devices. Strong convexity regularization ensures local module objectives stay consistent with the global adversarial loss. A server-side coordinator provides Adaptive Perturbation Adjustment (APA) for utility-robustness balance and Differentiated Module Assignment (DMA) for heterogeneous device handling.

## Key Novelty
Cascade learning with strong convexity regularization proven to simultaneously achieve memory efficiency, adversarial robustness, and low objective inconsistency in federated settings.

## Results
- **80%** memory reduction vs end-to-end FAT
- Up to **10.8x** training speedup vs jFAT
- Models: VGG16, ResNet34 on CIFAR-10, Caltech-256
- Baselines: jFAT, FedDF-AT, FedET-AT, HeteroFL-AT, FedRolex-AT

## Hardware Target
Memory-constrained edge devices; server-side FL coordinator
