# FedProphet: Memory-Efficient Federated Adversarial Training via Robust and Consistent Cascade Learning

**ID:** mlsys-2025-041 | **Venue:** MLSYS 2025

## Problem
Federated Adversarial Training (FAT) requires large models for accuracy and robustness, but memory-constrained edge devices cannot fit full-model training; existing memory-efficient FL methods sacrifice accuracy or robustness.

## Method
FedProphet breaks the full neural network into small sequential modules (cascade learning), with each module trained on devices of a particular capability level. To ensure all modules pull toward the same training goals despite working separately, the system applies a mathematical constraint called strong convexity regularization to each module. A central server then orchestrates using two mechanisms: Adaptive Perturbation Adjustment (APA), which dynamically adjusts the strength of adversarial attacks to balance accuracy and robustness trade-offs, and Differentiated Module Assignment (DMA), which assigns each module to device types based on their memory and compute capabilities.

## Key Novelty
The core insight is that cascade learning combined with strong convexity regularization (mathematical constraints ensuring consistent training goals) allows neural networks to be both memory-efficient and adversarially robust in federated settings.

## Results
- **80%** memory reduction vs end-to-end FAT
- Up to **10.8x** training speedup vs jFAT
- Models: VGG16, ResNet34 on CIFAR-10, Caltech-256
- Baselines: jFAT, FedDF-AT, FedET-AT, HeteroFL-AT, FedRolex-AT

## Hardware Target
Memory-constrained edge devices; server-side FL coordinator
