# RePM: Reconfigurable Elastic Computing for Polynomial Multiplier with Hybrid NTT Algorithm

**Venue:** ICCAD  
**Confidence:** low

## Problem
Lattice-based cryptography requires efficient polynomial multiplication via Number Theoretic Transform (NTT), but current ASIC/FPGA designs suffer from high resource consumption, low efficiency, and inflexible designs under strict power constraints.

## Motivation
Post-quantum cryptography (PQC) standards like ML-KEM require practical hardware implementations; efficient, flexible NTT accelerators enable deployment in power-constrained environments.

## Method
RePM uses conflict-free near-memory mapping to reduce data relocation overhead, elastic butterfly unit architecture eliminating pre-computing, and mixed radix-2/4 NTT algorithm removing pre/post-processing stages. Architecture applies to multiple PQC algorithms under strict power constraints.

## Key Novelty
Elastic computing array architecture for NTT butterfly units with hybrid radix-2/4 algorithms and conflict-free memory mapping.

## Contributions
- 2.1× acceleration in ML-KEM execution speed
- 75% power reduction vs. SOTA
- 65.8% area efficiency improvement
- 17× higher throughput under strict power constraints
