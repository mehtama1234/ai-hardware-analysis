# RePM: Reconfigurable Elastic Computing for Polynomial Multiplier with Hybrid NTT Algorithm

**Venue:** ICCAD  
**Confidence:** low

## Problem
Lattice-based cryptography requires efficient polynomial multiplication via Number Theoretic Transform (NTT), but current ASIC/FPGA designs suffer from high resource consumption, low efficiency, and inflexible designs under strict power constraints.

## Motivation
Post-quantum cryptography (PQC) standards like ML-KEM require practical hardware implementations; efficient, flexible NTT accelerators enable deployment in power-constrained environments.

## Method
RePM uses adaptable computation units (butterfly units) that eliminate the need for pre-computing values, combined with a memory layout that reduces data shuffling (conflict-free near-memory mapping). It applies two alternating computation strategies (radix-2 and radix-4) that together remove the setup and cleanup steps normally required for polynomial multiplication. This flexible design works with multiple post-quantum cryptography algorithms while meeting strict power budgets.

## Key Novelty
Adaptive butterfly units with hybrid radix-2/4 computation and conflict-free memory mapping eliminate preprocessing steps in polynomial multiplication for cryptography.

## Contributions
- 2.1× acceleration in ML-KEM execution speed
- 75% power reduction vs. SOTA
- 65.8% area efficiency improvement
- 17× higher throughput under strict power constraints
