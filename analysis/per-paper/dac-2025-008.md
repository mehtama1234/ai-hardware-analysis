# EdgeMM: Multi-Core CPU with Heterogeneous AI-Extension and Activation-aware Weight Pruning for Multimodal LLMs at Edge

**Problem:** Multimodal LLMs mix compute-intensive encoders and memory-bound decoders, presenting conflicting performance bottlenecks.

**Method:** EdgeMM pairs a multi-core CPU with two specialized hardware types: systolic arrays (processing units designed for rapid parallel calculations) handle the compute-intensive encoding stage, while compute-in-memory chips (processors built directly into memory to minimize data movement) handle the memory-bound decoding stage. Dynamic activation-aware weight pruning (removing less important learned parameters based on which parts of the network are actually active) further improves efficiency. The system is built using 22-nanometer manufacturing technology.

**Key Contribution:** Specialized coprocessor design matched to distinct workload bottlenecks in multimodal pipelines.

**Results:** 2.84x speedup vs RTX 3060 GPU; implemented in 22nm.
