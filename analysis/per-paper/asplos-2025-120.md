# Target-Aware Implementation of Real Expressions

**Venue:** ASPLOS  
**Authors:** Brett Saiki, Jackson Brough, Jonas Regehr, Jesus Ponce, Varun Pradeep, Aditya Akhileshwaran, Zachary Tatlock, Pavel Panchekha  
**Confidence:** low (abstract only)

## Problem
Numerical code running on low-precision accelerators and vector ISAs must simultaneously maximize accuracy and performance, but traditional compiler backends optimize for specific targets without accuracy reasoning, while numerical compilers trade accuracy vs. performance without considering the target hardware environment.

## Motivation
New low-precision accelerators and vector instruction sets make it increasingly challenging to balance accuracy and performance of floating-point numerical code, a gap neither traditional nor numerical compilers alone can bridge.

## Method
Chassis takes a mathematical expression and generates multiple implementations for a specific target—like a GPU, a vector ISA (the instructions for processing multiple numbers at once), or optimized library functions—each offering different trade-offs between accuracy and speed. It measures how accurate and how fast each implementation will be on that hardware. Then it picks and generates the code for whichever implementation works best for that target by optimizing both accuracy and speed together, based on what the hardware can actually do.

## Key Novelty
A compiler that improves both numerical accuracy and speed at the same time, designed for specific hardware and instruction sets, doing what traditional compiler backends and numerical compilers used to do separately.

## Contributions
- Chassis: a target-aware numerical compiler bridging traditional and numerical compilation
- Joint accuracy-performance optimization conditioned on target-environment capabilities
- Support for low-precision accelerators, vector instruction sets, and library functions
- Demonstrated ability to improve both accuracy and performance simultaneously
