# A Modular, Responsive, and Accessible HPC Dashboard Built upon Open OnDemand

**ID:** sc-2025-343  
**Venue:** SC 2025  
**Authors:** Richie Tan, Guangzhen Jin

## Problem & Motivation

Traditional HPC systems present **high barriers to entry** for non-expert users:
- Heavy reliance on command-line tools (SSH, job schedulers, monitoring)
- Complex syntax and steep learning curve
- Limited accessibility for researchers without HPC background

As HPC expands to broader scientific communities, **intuitive web interfaces become essential**.

## Solution: Modern HPC Dashboard

A **modular, responsive web dashboard** built on **Open OnDemand**:

### Features
- **Announcements:** System news and alerts
- **System status:** Cluster health and availability
- **Job information:** Running and completed jobs, logs
- **Resource usage:** Allocation tracking, usage analytics
- **Modern design:** Clean, contemporary UI
- **Responsive layout:** Works on desktop and mobile
- **Accessibility:** WCAG compliance for diverse users

### Benefits
1. **Reduced CLI dependency** — visual job management
2. **Faster onboarding** — intuitive interfaces
3. **Better visibility** — real-time system status
4. **Efficient resource tracking** — quota and allocation info

## Architecture

- Built on **Open OnDemand** framework
- Modular page design for extensibility
- Modern web standards (responsive CSS, progressive enhancement)

## Impact

Dramatically **lowers the barrier to HPC** for new users while maintaining power-user capabilities via CLI access.
