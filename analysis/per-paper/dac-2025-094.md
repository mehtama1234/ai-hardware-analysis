# BBAL: Bidirectional Block Floating Point Quantization Accelerator for LLMs

## Problem
BFP quantization for LLM edge deployment suffers accuracy degradation because all values align to the maximum exponent, losing small and moderate magnitude values.

## Method
BBAL introduces Bidirectional Block Floating Point (BBFP) format that reduces reliance on maximum exponent by allowing bidirectional selection, lowering quantization error. Full-stack includes BBFP processing element array and cost-effective nonlinear computation unit.

## Key Innovation
Bidirectional exponent selection in BFP format minimizes outlier-driven quantization error.

## Contributions
- BBFP data format reducing quantization error
- BBAL full-stack accelerator with BBFP PE array
- Cost-effective nonlinear computation unit
- 22% accuracy improvement vs outlier-aware; 40% efficiency gain vs standard BFP

## Motivation
Edge LLM deployment requires aggressive quantization without severe accuracy loss.
