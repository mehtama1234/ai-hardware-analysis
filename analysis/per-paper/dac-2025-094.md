# BBAL: Bidirectional Block Floating Point Quantization Accelerator for LLMs

## Problem
BFP quantization for LLM edge deployment suffers accuracy degradation because all values align to the maximum exponent, losing small and moderate magnitude values.

## Method
BBAL improves Block Floating Point quantization—a technique that compresses numbers by fitting them all to one shared scale—by making the scale selection smarter. Instead of simply using the maximum value's scale (which causes small numbers to lose precision), the bidirectional approach selects the scale by considering both extremes, resulting in better overall accuracy. The system uses a processing element array (a bank of specialized circuits) optimized for this bidirectional quantization, along with an efficient circuit for the nonlinear math operations that language models need. This enables accurate low-bit inference (very few bits per number) on edge accelerators—small, power-efficient devices.

## Key Innovation
Bidirectional exponent selection in BFP format minimizes outlier-driven quantization error.

## Contributions
- BBFP data format reducing quantization error
- BBAL full-stack accelerator with BBFP PE array
- Cost-effective nonlinear computation unit
- 22% accuracy improvement vs outlier-aware; 40% efficiency gain vs standard BFP

## Motivation
Edge LLM deployment requires aggressive quantization without severe accuracy loss.
