# BiKA: Binarized KAN-inspired Neural Network for Efficient Hardware Accelerator Designs

**Problem:** Kolmogorov-Arnold Networks replace standard multiplication and activation functions with learnable nonlinear functions, which are complex to implement in hardware. Prior work lacks thorough exploration of lightweight KAN hardware accelerators suitable for edge devices.

**Method:** BiKA applies binarization to KAN architecture to reduce hardware complexity of learnable nonlinear functions. The approach uses binary weights and activations to simplify the nonlinear function computations while maintaining the KAN paradigm, enabling efficient hardware implementation for edge inference.

**Novelty:** Combining binarization with KAN architecture to reduce hardware implementation complexity of learnable nonlinear functions while preserving KAN's potential benefits.
