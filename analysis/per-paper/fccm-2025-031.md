# BiKA: Binarized KAN-inspired Neural Network for Efficient Hardware Accelerator Designs

**Problem:** Kolmogorov-Arnold Networks replace standard multiplication and activation functions with learnable nonlinear functions, which are complex to implement in hardware. Prior work lacks thorough exploration of lightweight KAN hardware accelerators suitable for edge devices.

**Method:** BiKA makes KANs practical for edge hardware by using binarization—converting weights and activations (the numerical parameters a network learns) to just two values instead of decimals. This cuts the hardware complexity of computing the learned nonlinear functions (functions that adapt to the data), since binary arithmetic is far simpler to build into circuits than continuous-number math. The technique preserves what makes KANs work while shrinking the physical chip size and power needed.

**Novelty:** The core idea is applying binarization (reducing learned parameters to just two values) to KAN's learnable nonlinear functions to reduce hardware implementation complexity while preserving KAN's benefits.
