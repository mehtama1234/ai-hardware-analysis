# Cooperative Warp Execution in Tensor Core for RISC-V GPGPU

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Tensor cores integrated into RISC-V GPGPU architectures (e.g., Vortex) are severely under-utilized in many configurations, and simply increasing compute capacity does not yield proportional performance gains due to memory bandwidth limitations and warp divergence.

## Motivation
Open-source RISC-V GPGPU platforms lack efficient tensor core designs with principled analysis of the relationship between GPU system parameters and tensor core configuration, limiting research and customization beyond NVIDIA's closed ecosystem.

## Method
The paper integrates a tensor core into the open-source Vortex RISC-V GPGPU with a suite of GEMM intrinsics. Analysis of utilization identifies that memory bandwidth and warp-level resource contention bottleneck performance. The proposed cooperative warp execution mechanism allows multiple warps to share a single tensor core invocation, reducing per-warp memory requirements for GEMM operands and enabling better pipelining of data movement and computation. Hardware warp cooperation support is added to the tensor core datapath to manage the cooperative scheduling.

## Key Novelty
Cooperative warp execution in tensor core that allows multiple warps to collaboratively share a tensor core operation, reducing memory pressure and improving utilization by up to 3x over the baseline tensor core.

## Contributions
- First open-source tensor core integration into RISC-V Vortex GPGPU with GEMM intrinsics
- Systematic analysis linking GPU architectural parameters to tensor core utilization
- Cooperative warp execution mechanism enabling hardware-supported warp cooperation in tensor core
- Up to 3x performance improvement over baseline tensor core implementation
