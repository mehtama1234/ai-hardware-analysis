# Generating Frequently Asked Questions from Technical Support Tickets using Large Language Models

**Venue:** SC

## Problem
Exponential growth in HPC user base and system complexity creates overwhelming volume and variability in technical support tickets; manual FAQ curation is unsustainable

## Motivation
Automate extraction of clear, accurate FAQs from raw support tickets to improve HPC support scalability and responsiveness

## Method
Multi-stage pipeline: frequency/recency filtering → LLM summarization → semantic clustering → LLM-based FAQ generation; expert evaluation

## Key Novelty
End-to-end LLM-driven FAQ extraction pipeline combining semantic clustering, domain-specific summarization, and multi-stage generation

## Contributions
- Scalable automated FAQ extraction from raw support tickets
- Semantic clustering for issue categorization and subclustering
- Multi-stage LLM generation producing understandable and factually sound FAQs
