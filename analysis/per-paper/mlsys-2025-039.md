# AdaParse: An Adaptive Parallel PDF Parsing and Resource Scaling Engine

**ID:** mlsys-2025-039 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Building trillion-token scientific text datasets requires parsing millions of PDFs, but state-of-the-art ML parsers (Nougat) achieve only 1-2 PDFs/sec on 4-A100 nodes, while cheap parsers produce poor quality on complex documents.

## Method
AdaParse routes PDFs through a three-stage classifier to pick the right parser: first, a rule-based check of PyMuPDF-extracted text features to reject broken files; second, a prediction of whether expensive high-quality parsers are worth running on a particular document; third, a SciBERT-based ML model trained on preferences from 23 domain experts to select the best parser. The model is fine-tuned using Direct Preference Optimization (DPO), which teaches it to predict what experts prefer. To handle massive scale, Parsl orchestrates execution on the Polaris supercomputer, batching PDFs together, warming up parser models, and distributing tasks across nodes.

## Key Novelty
The core idea is using Direct Preference Optimization to align an ML router to expert preferences, enabling it to skip expensive parsers when faster ones will work—achieving 17x throughput improvement over Nougat with 0.2% better BLEU accuracy.

## Metrics
- **Throughput:** 17x vs Nougat alone; ~78 PDFs/sec on 128 Polaris nodes (vs ~8 for Nougat)
- **Accuracy:** BLEU 52.1 vs Nougat 48.1; 76.9% accepted tokens vs 69.8%

## Baselines
Nougat, Marker, PyMuPDF, pypdf, GROBID, Tesseract
