# AdaParse: An Adaptive Parallel PDF Parsing and Resource Scaling Engine

**ID:** mlsys-2025-039 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Building trillion-token scientific text datasets requires parsing millions of PDFs, but state-of-the-art ML parsers (Nougat) achieve only 1-2 PDFs/sec on 4-A100 nodes, while cheap parsers produce poor quality on complex documents.

## Method
Hierarchical three-stage classifier pipeline: CLS I (rule-based validity from extracted text stats), CLS II (metadata-driven regression predicting if improvement is likely), CLS III (SciBERT LLM-based multi-class parser selection). Human preferences from 23 domain experts are incorporated via DPO fine-tuning. Parsl orchestrates parallel HPC execution with warm-start model persistence.

## Key Novelty
DPO-aligned adaptive parser routing combining a fast extraction first-pass with hierarchical ML classifiers trained on expert human preferences, achieving 17x throughput vs Nougat with 0.2% better BLEU.

## Metrics
- **Throughput:** 17x vs Nougat alone; ~78 PDFs/sec on 128 Polaris nodes (vs ~8 for Nougat)
- **Accuracy:** BLEU 52.1 vs Nougat 48.1; 76.9% accepted tokens vs 69.8%

## Baselines
Nougat, Marker, PyMuPDF, pypdf, GROBID, Tesseract
