# SC-2025-160: PerfDojo - LLM-Driven Kernel Optimization

## Summary
Automated ML library generation for heterogeneous architectures using LLMs and Reinforcement Learning within PerfDojo, an RL environment with human-readable, semantically-valid code representation.

## Problem
- ML optimization requires different kernels per architecture (x86/Arm/RISC-V/GPU)
- Manual tuning expensive and time-consuming
- Existing automated tools rely on opaque heuristics
- Performance portability challenging

## Solution: PerfLLM + PerfDojo
**PerfDojo**: RL environment with:
- **Human-readable representation**: Mathematically-inspired code format
- **Semantic validity**: Transformations guarantee correctness
- **LLM guidance**: Large language models drive optimization
- **RL training**: Reinforcement learning optimizes kernel parameters

## Key Innovation
Avoid complex hardware-specific heuristics by using:
1. Interpretable code representation
2. LLM-guided exploration (semantic understanding)
3. RL for systematic optimization
4. Enables human understanding + agent training

## Hardware Support
| Category | Examples |
|----------|----------|
| **CPUs** | x86, ARM, RISC-V |
| **GPUs** | NVIDIA, AMD |
| **Accelerators** | Custom DL hardware |

## Features
- Optimization without prior hardware knowledge
- Support for sparsity, quantization, mixed-precision
- Architecture-specific kernel generation
- Performance portability

## Implications
- Reduces manual optimization burden
- Enables non-experts to optimize kernels
- Applicable across emerging hardware
