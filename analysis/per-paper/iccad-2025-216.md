# Towards Multi-Objective Routing: A Novel Coreset-based Transfer Learning Framework

**Venue:** ICCAD  
**ID:** iccad-2025-216  
**Confidence:** low

## Problem Statement
Routing optimization with multiple conflicting objectives (timing, power, wirelength) traditionally trades quality for optimization time.

## Motivation
Efficient multi-objective routing enables better design tradeoff exploration without excessive computation time.

## Method
Coreset-based transfer learning framework for multi-objective routing. Reduces training data requirements while preserving routing quality. Enables knowledge transfer across routing problems.

## Key Novelty
First coreset-based transfer learning approach for multi-objective circuit routing.

## Contributions

1. Coreset-based transfer learning for routing
2. 5-8x training time reduction
3. Preserves routing quality across objectives
