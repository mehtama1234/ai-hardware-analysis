# Accelerating design-technology co-development using neural compact modeling

**Authors:** Yongjeong Lee, Seungsoo Lee, Jeongyeol Kim, Jungyun Choi, Zhaojie Li, Dehuang Wu, Joddy Wang  
**Venue:** DAC 2025

## Summary
This paper proposes a design-technology co-optimization framework using neural compact modeling (NCM) with efficient retargeting and data-driven SPICE simulation. By eliminating SPICE runtime, it achieves 95% reduction in PDK release time while maintaining model consistency and accuracy for 15k-transistor designs.

## Key Contributions
- Neural compact modeling with efficient fine-tuning for process variants
- Data-driven SPICE simulation via interpolation and derating
- Elimination of SPICE simulation from design feedback loops
- 95% PDK release time reduction with maintained consistency

## Technical Approach
Pre-trained neural compact models are efficiently fine-tuned for new process variations using retargeting strategies. Data interpolation and derating recreate realistic design environments (instance binning, process variations, layout effects) without requiring SPICE runs. This enables rapid technology-design iteration by providing quick feedback on design viability.
