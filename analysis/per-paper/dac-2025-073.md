# NetTAG: A Multimodal RTL-and-Layout-Aligned Netlist Foundation Model via Text-Attributed Graph

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Circuit representation learning methods rely on complex functional supervision (truth-table simulation) and handle only simple-and-inverter graphs, failing to encode diverse gate functionalities and lacking structural awareness needed for full netlist understanding.

## Motivation
Advancing Electronic Design Automation requires circuit representations that capture both gate-level semantics and global structure, bridging the gap between LLM functional understanding and graph-based structural learning.

## Method
NetTAG represents circuits as diagrams of interconnected logic gates, where each gate is annotated with text describing its logical function and physical properties. The system combines two neural network approaches: a language model that interprets the gate descriptions to understand what each gate does, and a graph neural network (a technique for learning from connected structures) that learns how gates interact through their connections. It learns these patterns automatically from unlabeled data and is then aligned with both the high-level circuit specifications (RTL) and the physical chip layout.

## Key Novelty
The innovation is combining a language model's understanding of gate semantics with graph-network learning of circuit structure in a single text-attributed graph representation that supports both functional and physical design tasks.

## Contributions
- NetTAG netlist foundation model combining text and graph modalities for gate and structure understanding
- Text-attributed graph formulation with symbolic logic expressions for gate semantics
- Multimodal architecture with LLM text encoder and graph transformer backbone
- Outperforms task-specific methods on four diverse functional and physical tasks
