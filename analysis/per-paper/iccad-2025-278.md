# High-Resolution Full-Chip Thermal Resistance Extraction of BEOL Interconnects in 3-D ICs Considering Detailed Via Connectivity

**Venue:** ICCAD  
**ID:** iccad-2025-278

## Problem
Back-end-of-line (BEOL) interconnects play an important role in thermal dissipation in 3D ICs, but existing analytical models are inaccurate because they cannot consider detailed via connectivity.

## Motivation
To achieve accurate thermal resistance extraction for BEOL interconnects by explicitly modeling via connectivity for reliable hotspot prediction in 3D ICs.

## Method
The method treats thermal resistance—the opposition to heat flow—like electrical resistance in a circuit, using a resistor network model that naturally captures how heat distributes through interconnects. Unlike previous approaches, it explicitly incorporates the detailed physical layout of vias, the tiny vertical connections between metal layers, using the Woodbury formula to calculate thermal resistance. This inclusion of actual connection geometry, rather than simplified approximations, produces more accurate thermal predictions for 3D chips where via layout significantly affects heat dissipation.

## Key Novelty
The core contribution is using a resistor network model that accounts for detailed via connectivity—the actual layout of vertical connections between layers—when calculating thermal resistance in 3D integrated circuits.

## Contributions
- Analytical model using resistor network theory and Woodbury formula
- Explicit modeling of detailed via connectivity in thermal calculations
- 3.4× improvement in accuracy compared with previous work
- 1.8% absolute percentage error in max temperature vs 5.2% previously
