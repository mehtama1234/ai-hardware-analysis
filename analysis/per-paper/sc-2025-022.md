# A Model for Teaching Machine Learning, Deep Learning, and Research Computing to Domain Scientists on HPC Resources

## Overview
Adaptable one-week workshop model for teaching biologists HPC basics, machine learning, and deep learning on supercomputing systems using accessible technologies.

## Problem & Motivation
- **Challenge**: Domain scientists lack HPC, ML, DL skills; traditional HPC training assumes CS background
- **Opportunity**: Hands-on workshop with accessible technologies (notebooks, graphical interfaces, containers) can enable domain scientist adoption
- **Goal**: Enable biological discovery via HPC-accelerated ML/DL

## Architecture & Method
**Curriculum**
- **HPC Basics**: Command-line file systems, SLURM job submission, system navigation
- **ML/DL Techniques**: Applied to real-world biological datasets
- **Hands-on Practice**: Real supercomputing systems (not simulators)

**Accessibility Technology**
- **Jupyter Notebooks**: Interactive code execution, exploratory learning
- **DCV (Graphical Desktops)**: GUI-based HPC access for command-line averse users
- **Software Containers**: Pre-configured environments reducing setup friction
- **Minimal User Setup**: Deployment on HPC with out-of-box usability

## Key Contributions
1. **Adaptable workshop framework** for domain scientist training
2. **Accessibility-focused delivery** (notebooks, GUI, containers)
3. **Real HPC system integration** (not virtualized environments)
4. **Survey-validated effectiveness** demonstrating skill improvement
5. **Extensible model** for other scientific domains

## Education Insights
- Accessibility critical for domain scientists unfamiliar with Unix/CLI
- Jupyter and graphical interfaces lower adoption barriers
- Containers eliminate environment configuration overhead
- Survey validation supports effectiveness claims

## Limitations
- Survey results details sparse (quantitative improvement metrics missing)
- Long-term retention and skill transfer unclear
- No comparison with alternative educational approaches
- Biological dataset details (diversity, complexity) missing
- Scalability to larger cohorts not discussed
- Abstract-only prevents detailed assessment

## Relevance to Hardware/AI Systems
**Low relevance**: Focuses on education and training rather than hardware optimization or systems research.
