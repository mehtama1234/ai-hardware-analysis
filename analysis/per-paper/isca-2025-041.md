# isca-2025-041: Cassandra: Efficient Enforcement of Sequential Execution for Cryptographic Programs

**Venue:** ISCA  
**Confidence:** low (abstract only)  
**Primary Theme:** secure sequential execution enforcement for constant-time cryptographic code

## Problem
Modern out-of-order processors violate constant-time programming assumptions by transiently executing unintended control-flow paths, enabling Spectre-class transient execution attacks against cryptographic code. Existing mitigations that address control-flow misspeculations impose high performance overhead by broadly restricting speculative execution.

## Motivation
Constant-time programming is the dominant practical defense for cryptographic side-channel attacks, but hardware speculation repeatedly undermines it, and no efficient hardware mechanism has closed this gap without major performance loss.

## Method
Cassandra adds a hardware Branch Trace Unit (BTU) to the processor that replays predetermined control-flow paths (branching sequences) for cryptographic code instead of using normal branch prediction, which makes speculative guesses that can lead to unintended code paths. The system records and compresses the branching patterns of these code regions—which tend to be repetitive with loop-heavy structures—and stores the compressed traces in the BTU. During execution, the BTU supplies the correct branch decisions directly to the processor, eliminating the speculative paths that enable Spectre-class attacks.

## Key Novelty
Cassandra replaces branch prediction with a hardware record-and-replay system using compressed control-flow traces for cryptographic code, achieving security against Spectre-class attacks without speculation overhead and gaining a net speedup.

## Contributions
1. Identification that constant-time program control flow is mostly static and highly compressible across different runs
2. Cassandra hardware/software mechanism: Branch Trace Unit (BTU) that stores compressed sequential control-flow traces and drives fetch redirections without speculative prediction
3. Upfront branch analysis pass that compresses loop-intensive cryptographic control-flow patterns for efficient trace storage
4. Demonstration of average 1.85% speedup over unsafe baseline processor while enforcing strong sequential execution security guarantees
