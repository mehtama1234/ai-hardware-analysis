# ACRS: Adjacent Computation Resource Sharing among Partitioned GPU Sub-Cores

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

ACRS proposes dynamic sharing of functional units among adjacent GPU sub-cores to improve efficiency in partitioned architectures. Through instruction offloading and result routing, it achieves 14.1% average performance improvement with 8.3% energy reduction.

## Key Contributions

- **Dynamic Offloading**: Monitors operand collector/FU status and offloads stalled instructions to adjacent unoccupied FUs
- **Result Routing**: SF_WriteBack mechanism for efficient result return to original sub-core
- **Wiring Efficiency**: Fixed target core assignment minimizes routing overhead
- **Performance Gains**: 46.4% max speedup, 14.1% average, 12.3% vs. SOTA methods

## Technical Focus

Exploits observation that FU blockages in one sub-core often coincide with available FUs in adjacent sub-cores. Sequential matching policies balance wiring complexity against utilization gains.
