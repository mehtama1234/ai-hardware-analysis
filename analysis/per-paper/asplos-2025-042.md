# Orion: A Fully Homomorphic Encryption Framework for Deep Learning

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-042  
**Confidence:** low (abstract only)

## Problem
Mapping arbitrary deep neural networks to FHE primitives is intractable with existing tools due to vector-packing complexity, noise budget management, and the limited FHE instruction set—limiting FHE neural inference to shallow or small networks.

## Motivation
Neural inference in the cloud exposes user data to service providers; FHE enables inference on encrypted inputs but no automated, scalable compiler has existed for large models.

## Method
Orion compiles PyTorch DNNs to FHE programs using a single-shot multiplexed packing strategy for arbitrary convolutions and an automated bootstrap placement algorithm that tracks noise accumulation and inserts bootstrapping at minimum-cost positions. Together these enable end-to-end compilation of ResNet-50, YOLO-v1 (139M params) without manual FHE engineering.

## Key Novelty
Single-shot multiplexed packing for arbitrary convolutions combined with automated bootstrap placement and scale management, enabling fully automated FHE compilation of large CNNs.

## Contributions
- Single-shot multiplexed packing for FHE-mapping of arbitrary convolutions.
- Automated bootstrap placement and noise/scale management for deep networks.
- Orion open-source framework (PyTorch input → FHE output).
- 2.38x speedup over state-of-the-art on ResNet-20; first FHE YOLO-v1 and ResNet-50 on ImageNet.
