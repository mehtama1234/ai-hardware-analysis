# sc-2025-216: Sparsified Preconditioned Conjugate Gradient Solver on GPUs

## Overview
Novel sparsification technique for preconditioners in iterative linear solvers to increase GPU parallelism while preserving convergence.

## Key Problem
Preconditioned iterative solvers suffer from iteration dependences that limit GPU parallelization. Dense preconditioner application serializes computation despite many available parallel cores.

## Approach
Introduce sparsification to preconditioner: strategically reduce preconditioner density to decrease iteration dependences. Apply to both ILU(0) and ILU(K) preconditioners on SPD matrices.

## Contributions
- Preconditioner sparsification technique for GPU solvers
- Maintains convergence properties despite reduced preconditioner density
- Evaluation on diverse SPD matrix problems
- Significant improvements on NVIDIA A100 GPUs

## Performance Results
**NVIDIA A100 GPU:**
- **Iterative phase (ILU(0))**: 1.23x speedup
- **Iterative phase (ILU(K))**: 1.65x speedup
- **End-to-end (ILU(0))**: 1.68x speedup
- **End-to-end (ILU(K))**: 3.73x speedup
