# H3D-LLM: Heterogeneous 3D Chiplet Design for LLM Inference with Dynamic Task Scheduling and Memory-Aware Orchestration

**Venue:** ICCAD  
**ID:** iccad-2025-096

## Problem
3D chiplet integration for LLM inference faces three critical challenges: asymmetric compression constraints from sparsity-precision tradeoffs, tier-level load imbalance from static resource allocation, and coupling-induced signal degradation in high-density TSV networks.

## Motivation
Enable energy-efficient, low-latency LLM inference through 3D heterogeneous chiplet integration with scalable memory bandwidth and dynamic orchestration.

## Method
The system uses three coordinated techniques to handle a 3D-stacked chip. It shrinks the model layer-by-layer by removing unnecessary weights (sparsity) and using different numerical precision levels (4-bit to 8-bit integers) tuned to each layer's hardware constraints. It dynamically splits inference work into adaptive batches and adjusts temporary memory usage (the KV-cache) during execution. It also schedules data transfers across the silicon interconnects (Through-Silicon Vias or TSVs) in phases to avoid signal degradation in the densely-packed layers.

## Key Novelty
The core idea is stacking different processor types (analog and digital compute-in-memory units plus a neural processing unit) in 3D and using dynamic scheduling to balance work across layers instead of using a fixed allocation.
