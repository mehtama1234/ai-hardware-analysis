# isscc-2025-077: Multi-Domain Isolated DC-DC Converter

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
Multi-output isolated DC-DC converters require separate Tx-Rx control across barriers and custom interconnects; conventional designs need digital isolators and complex communication.

## Motivation
Industrial systems (motor drives, battery management, gate drivers) demand multiple isolated outputs with simplified control infrastructure.

## Method
The converter uses a single shared magnetic core (a passive transformer) that connects to all power domains, instead of requiring separate connections for each domain. Power distribution is controlled by sensing what the receiving circuits actually demand, and using that information to adjust the converter's switching. Since all adjustments happen on the receiver side and information only flows one way through the isolation barrier (the electrical separation between input and output), the system doesn't need digital isolators—chips that would normally relay control signals across isolated sections.

## Key Novelty
A single shared magnetic core, combined with receiver-side power modulation based on sensing actual power demands, eliminates the need for control signals to cross the isolation barrier.

## Contributions
- Single micro-transformer multi-domain support
- Passive flux sharing reduces area/cost
- Rx-side sensing enables Tx control
- Flexible domain isolation

## Metrics
- Multi-domain outputs via single link
- No digital isolators required
