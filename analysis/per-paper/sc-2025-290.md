# AI Agents for Enabling Autonomous Experiments at ORNL's HPC and Manufacturing User Facilities

**Venue:** SC 2025  
**Authors:** Daniel Rosendo, Stephen DeWitt, Renan Souza, Phillipe Austria, Tirthankar Ghosal, Marshall T. McDonnell, Ross Miller, Tyler J. Skluzacek

## Problem Statement
Operating multiple scientific user facilities (HPC, manufacturing) with heterogeneous interfaces creates coordination bottlenecks. Manual interaction between experimental design and computational simulation slows discovery and prevents adaptive, closed-loop optimization.

## Technical Approach
**Modular AI-Agent Architecture:**
1. **Natural Language Interface:** LLM-powered interaction for researchers
2. **Multi-Agent Framework:** Autonomous decision-making and coordination
3. **Programmable Facility APIs:** Unified access to heterogeneous systems
4. **Provenance Infrastructure:** Tracks experiments for reproducibility and adaptivity

**Workflow Integration:**
- Real-time bidirectional communication between manufacturing and HPC resources
- Autonomous adaptation based on experimental outcomes
- Explainable decision logs for scientific validation

## Use Case: Additive Manufacturing
- Manufacturing facility runs experiments (3D printing)
- HPC simulates material properties and predicts outcomes
- Agent loop: Experiment → HPC simulation → Analysis → Next experiment design

## Key Benefits
- Reduced coordination overhead between systems
- Accelerated discovery cycles via autonomous adaptation
- Reproducible, provenance-tracked workflows
- Generalization to other cross-facility workflows

## Limitations & Future Work
- Evaluation on simulated (not real) manufacturing facility
- Applicability to other scientific domains not demonstrated
- LLM hallucination, error recovery, and fallback strategies not discussed
- Scalability to concurrent multi-agent experiments unclear
- Safety and validation of autonomous decisions not addressed
