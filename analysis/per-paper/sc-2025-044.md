# sc-2025-044: AskHPC: A ChatBot for High Performance Computing User Support

## Summary
AskHPC is an LLM-based question-answering system for HPC user support. Uses retrieval-augmented generation (RAG) with curated knowledge base and novel dual-context strategy to provide accurate, accessible answers from scattered HPC documentation.

## Problem
- Exascale HPC systems are complex and heterogeneous
- Documentation scattered across multiple sources (guides, manuals, code examples, papers)
- Multimodal (text, code, diagrams, tables)
- Users spend excessive time searching for information
- Fragmentation makes expert knowledge difficult to access

## Method
The system is an AI chatbot that helps answer HPC questions by combining a curated knowledge base with retrieval-augmented generation—a technique where relevant documents are retrieved and paired with AI-generated explanations, keeping answers grounded in actual sources. It can read and understand different types of HPC documents (code, text, diagrams, etc.) and their structure, since HPC information is scattered across multiple formats. When answering, the system shows both the retrieved source material and the AI-generated explanation, providing users with factual references and clear, understandable answers.

## Key Innovations
1. **Modality-aware parsing**: Preserves structure of technical documentation
2. **Dual-context RAG**: Combines retrieval fidelity with semantic generation
3. **Curated knowledge base**: Built specifically for HPC domain
4. **User study validation**: Real HPC users in evaluation

## Hardware Targets
- Any HPC system (generic infrastructure documentation)
- Exascale systems specifically
