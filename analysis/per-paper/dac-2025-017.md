# dac-2025-017: CaMDN - Multi-tenant Cache Optimization for NPUs

**Title:** CaMDN: Enhancing Cache Efficiency for Multi-tenant DNNs on Integrated NPUs

**Venue:** DAC 2025

**Core Issue:** Shared cache contention in multi-tenant DNN execution on NPU SoCs degrades individual model performance.

**Key Contribution:** Architecture + scheduling co-design with model-exclusive cache regions (hardware) and dynamic allocation (software); 1.88x average speedup.

**Hardware Target:** NPU, SoC

**Workload:** CNN inference, multi-tenant DNN

**Metrics:**
- Memory access reduction: 33.4% avg
- Speedup: 2.56x max / 1.88x avg

**Confidence:** Low (abstract-only)
