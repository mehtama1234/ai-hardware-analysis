# sc-2025-220: Energy-Aware OpenMP Dynamic Variants

## Overview
Runtime system for energy-aware dynamic variant selection in OpenMP, balancing performance portability with power and thermal constraints.

## Key Problem
Performance portability across diverse HPC and embedded platforms is constrained by power caps and thermal limits. Existing variants only optimize performance, ignoring energy/thermal aspects.

## Approach
Extend OpenMP variants with energy-aware runtime:
- **Profiling**: Per-variant energy and thermal behavior measurement
- **Instrumentation**: Low-overhead power and temperature monitoring
- **Selection**: Multi-criteria policy balancing power caps, thermal headroom, performance

Implementation in LLVM, publicly available.

## Contributions
- Energy-aware dynamic variant selection
- Low-overhead power/thermal instrumentation
- Multi-criteria optimization policy
- Public LLVM-based implementation
- Cross-platform validation

## Performance Results
- **Workstation**: 98% power cap compliance (vs 67% unconstrained)
- **Edge devices**: 39% speedup vs hardware throttling (proactive CPU/GPU migration)
- **Battery-limited**: Extended battery lifetime in simulated missions

## Hardware Target
HPC systems, embedded systems, edge devices, heterogeneous CPU/GPU platforms

## Confidence
High (specific performance metrics provided across multiple platforms)
