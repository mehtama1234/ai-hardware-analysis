# UltraFormer: An Efficient Transformer for FPGAs

**Problem:** Existing FPGA-based transformer accelerators attempt to implement algorithms poorly suited to FPGA constraints, resulting in avoidable inefficiencies. Designing transformer architectures that account for FPGA-specific limitations while maintaining model quality is challenging.

**Method:** UltraFormer reduces the memory and computation needed for transformers on FPGAs by combining hybrid linear attention—a simplified attention mechanism that works better on FPGAs than standard approaches—with BitNet b1.58, which uses ultra-low-precision arithmetic (roughly 1.58 bits per number instead of standard 32-bit floats) for the linear projection layers. This achieves ~10x compression in model weights and 13.2x compression in the key-value cache (the temporary data needed during inference). High-Level Synthesis tools compile the architecture to hardware, and it runs on Xilinx FPGAs with optimizations tailored to FPGA constraints.

**Novelty:** UltraFormer combines hybrid linear attention with BitNet b1.58 ultra-low-precision projections as a transformer design specifically optimized for FPGAs.
