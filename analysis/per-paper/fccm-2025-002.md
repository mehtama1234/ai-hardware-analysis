# UltraFormer: An Efficient Transformer for FPGAs

**Problem:** Existing FPGA-based transformer accelerators attempt to implement algorithms poorly suited to FPGA constraints, resulting in avoidable inefficiencies. Designing transformer architectures that account for FPGA-specific limitations while maintaining model quality is challenging.

**Method:** UltraFormer combines hybrid linear attention with BitNet b1.58 ultra-low-precision linear projections, achieving ~10x weight compression and 13.2x KV cache compression. The architecture is synthesized via HLS flows and deployed on enterprise Xilinx FPGAs with optimizations for FPGA-specific constraints.

**Novelty:** First combination of hybrid linear attention with BitNet b1.58 extremely low-precision projections specifically architected for FPGA transformer acceleration.
