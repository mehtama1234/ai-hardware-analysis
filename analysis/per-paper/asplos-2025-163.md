# KernelGPT: Enhanced Kernel Fuzzing via Large Language Models

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Kernel fuzzing effectiveness depends on syscall specifications defining syscall syntax and semantics, but generating these specifications is largely manual work, leaving many important syscalls uncovered and limiting automated kernel vulnerability discovery.

## Motivation
OS kernel bugs affect billions of devices globally, and the primary bottleneck for automated kernel fuzzing (e.g., via Syzkaller) is incomplete syscall specification coverage.

## Method
KernelGPT prompts an LLM with kernel source code and documentation to synthesize syscall specifications in Syzkaller's format, then uses an iterative refinement loop where fuzzing feedback is fed back to the LLM to repair invalid or incomplete specifications. This covers previously uncovered syscalls and improves the semantic validity of generated syscall sequences.

## Key Novelty
Using LLMs to automatically synthesize and iteratively repair syscall specifications from kernel source code, dramatically expanding coverage available to a kernel fuzzer.

## Contributions
- KernelGPT: LLM-based automatic generation of syscall specifications for kernel fuzzing
- Iterative specification repair loop using fuzzing execution feedback as an LLM oracle
- Expanded syscall coverage vs. existing manually written Syzkaller specifications
- Discovery of new kernel bugs enabled by increased specification coverage

## Limitations
LLM-generated specifications may contain semantic errors not caught by syntactic validation; quality depends on LLM training coverage of kernel internals.
