# PacTrain: Pruning and Adaptive Sparse Gradient Compression for Efficient Collective Communication in Distributed Deep Learning
**Venue:** DAC

## Problem
Distributed DNN training is bottlenecked by gradient aggregation overhead; existing gradient compression schemes fail to accelerate training while preserving accuracy.

## Motivation
Large-scale DNN training on bandwidth-constrained clusters requires reducing gradient communication volume; combining sparsity from pruning with compression enables near-optimal compression without accuracy loss.

## Method
PacTrain removes unnecessary weights from neural networks through pruning, which makes most gradient values zero (sparse). It then applies adaptive compression—adjusting compression levels based on patterns of which weights matter. Since it works with allreduce, the standard mechanism distributed training systems use to combine gradients across machines, it integrates directly into existing frameworks without modification.

## Key Novelty
PacTrain combines weight pruning with adaptive gradient compression to achieve near-optimal compression while remaining compatible with allreduce, the distributed training operation that combines gradients across machines.

## Contributions
1. 1.25-8.72x training throughput improvement under bandwidth constraints
2. Near-optimal compression strategy compatible with allreduce
3. Accuracy preservation via sparsity-aware compression
