# PacTrain: Pruning and Adaptive Sparse Gradient Compression for Efficient Collective Communication in Distributed Deep Learning
**Venue:** DAC

## Problem
Distributed DNN training is bottlenecked by gradient aggregation overhead; existing gradient compression schemes fail to accelerate training while preserving accuracy.

## Motivation
Large-scale DNN training on bandwidth-constrained clusters requires reducing gradient communication volume; combining sparsity from pruning with compression enables near-optimal compression without accuracy loss.

## Method
PacTrain actively prunes DNN weights (sparsifying gradients); performs lightweight adaptive compression using known global sparsity patterns; integrates with allreduce primitive for compatibility with distributed training frameworks.

## Key Novelty
Combines pruning and adaptive gradient compression to achieve near-optimal compression while remaining allreduce-compatible.

## Contributions
1. 1.25-8.72x training throughput improvement under bandwidth constraints
2. Near-optimal compression strategy compatible with allreduce
3. Accuracy preservation via sparsity-aware compression
