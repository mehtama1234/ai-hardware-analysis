# Batch Tiling on Attention: Efficient Mixture of Experts Training on Wafer-Scale Processors

**Venue:** SC
**ID:** sc-2025-317
**Confidence:** low

## Problem Statement
Mixture of Experts models on wafer-scale processors face conflicting batch size requirements: attention layers need small batches for memory efficiency, while MLP experts require large batches for compute density.

## Motivation
Wafer-scale processors like Cerebras offer massive parallelism but require careful optimization of batch sizes across heterogeneous computation stages. Existing solutions (FlashAttention, expert parallelism) target GPUs, not wafer-scale architectures.

## Method
Batch Tiling on Attention (BTA): decouples batch processing by applying dynamic tiling to attention mechanisms. Attention processes at reduced batch size B via tiled computation, outputs concatenated to larger batch size B_tilde=G*B for MLP operations.

## Key Novelty
Dynamic batch tiling specifically for wafer-scale processor characteristics, addressing the architectural mismatch between attention and MLP layer batch requirements.

## Contributions
1. BTA algorithm for decoupled batch processing in MoE models on wafer-scale processors
2. Demonstration of 5× performance improvements at higher sparsity on Cerebras WSE
3. Architectural insights into batch size conflicts in MoE training
