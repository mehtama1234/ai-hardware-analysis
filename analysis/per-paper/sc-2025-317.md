# Batch Tiling on Attention: Efficient Mixture of Experts Training on Wafer-Scale Processors

**Venue:** SC
**ID:** sc-2025-317
**Confidence:** low

## Problem Statement
Mixture of Experts models on wafer-scale processors face conflicting batch size requirements: attention layers need small batches for memory efficiency, while MLP experts require large batches for compute density.

## Motivation
Wafer-scale processors like Cerebras offer massive parallelism but require careful optimization of batch sizes across heterogeneous computation stages. Existing solutions (FlashAttention, expert parallelism) target GPUs, not wafer-scale architectures.

## Method
Attention breaks its batch into smaller independent blocks (called tiling) and processes B examples at a time, which reduces memory usage. The attention outputs are then concatenated back into a larger batch of size B_tilde=G*B. This larger batch feeds into the MLP experts (computational units that handle calculations beyond attention). By decoupling batch size between these layer types, attention can operate at the small batch size B it needs for memory efficiency, while MLPs receive the large batch they need for compute efficiency on wafer-scale processors.

## Key Novelty
Dynamic batch tiling applied to attention layers addresses the architectural mismatch between attention's need for small batches and MLPs' need for large batches on wafer-scale processors.
