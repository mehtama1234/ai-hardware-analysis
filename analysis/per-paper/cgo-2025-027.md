# Teapot: Efficiently Uncovering Spectre Gadgets in COTS Binaries

**Venue:** CGO
**Confidence:** low

## Problem
Spectre vulnerabilities persist in deployed binaries; existing gadget detection either requires source code or suffers runtime overhead and limited detection. Binary-only analysis has been impractical.

## Motivation
Most deployed software exists as binaries; practical Spectre gadget detection in COTS binaries enables vulnerability assessment without source access.

## Method
Teapot rewrites compiled binaries without source code to run two parallel execution paths: one normal, one simulating speculative execution (the CPU's process of guessing what code to run ahead of time). This technique, Speculation Shadows, tracks whether timing differences in speculative paths could leak secrets. Runtime integrity checks flag exploitable patterns, and automated testing (fuzzing) confirms which vulnerabilities actually work.

## Key Novelty
Speculation Shadows: a technique that instruments compiled binaries to run normal and speculative execution paths in parallel, enabling detection of exploitable Spectre gadgets.

## Contributions
- First Spectre gadget scanner for COTS binaries with performance comparable to compiler-based tools
- Speculation Shadows binary rewriting technique
- 20x+ performance improvement over prior binary-based approaches
