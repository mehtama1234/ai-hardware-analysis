# ASTERINAS: A Linux ABI-Compatible, Rust-Based Framekernel OS with a Small and Sound TCB

**Problem:** Existing Rust-based OSes improperly use unsafe Rust in kernel development, preventing them from achieving a minimal and sound Trusted Computing Base (TCB) for memory safety. Building a feature-rich, general-purpose OS with minimal and verifiable memory-safety guarantees requires addressing improper unsafe code practices.

**Method:** Asterinas uses a framekernel architecture—an OS design where the kernel has different privilege levels, similar to building zones with restricted access—to isolate risky code. All unsafe operations (code that bypasses memory-safety checks) are confined to a single, carefully audited section, while the rest of the kernel uses safe Rust that the compiler automatically verifies. OSTD provides a framework and tools for this safe OS development. The system implements kernel functionality through safe Rust abstractions (clean, memory-safe-by-design interfaces), supports 210+ Linux syscalls, and keeps the unsafe code portion minimal and auditable.

**Novelty:** The framekernel architecture confines all memory-unsafe code to a small, audited section while the rest uses safe Rust, reducing the memory-safety code that must be manually verified.
