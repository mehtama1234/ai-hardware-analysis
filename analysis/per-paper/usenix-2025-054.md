# ASTERINAS: A Linux ABI-Compatible, Rust-Based Framekernel OS with a Small and Sound TCB

**Problem:** Existing Rust-based OSes improperly use unsafe Rust in kernel development, preventing them from achieving a minimal and sound Trusted Computing Base (TCB) for memory safety. Building a feature-rich, general-purpose OS with minimal and verifiable memory-safety guarantees requires addressing improper unsafe code practices.

**Method:** The framekernel architecture enables intra-kernel privilege separation, confining unsafe operations to a small portion verified by Rust's type system. OSTD provides a streamlined framework for safe Rust OS development. Asterinas implements this using safe Rust abstractions for kernel functionality, supporting 210+ Linux syscalls with a small unsafe TCB.

**Novelty:** The framekernel architecture that achieves intra-kernel privilege separation using safe Rust to minimize the memory-safety TCB.
