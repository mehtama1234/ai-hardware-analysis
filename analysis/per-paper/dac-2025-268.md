# Data Oblivious CPU: Microarchitectural Side-Channel Resilience

**Venue:** DAC | **ID:** dac-2025-268

## Problem
Microarchitectural side-channel attacks (cache, speculation) remain broadly applicable; existing defenses are narrowly tailored to specific vulnerabilities, leaving systems exposed.

## Key Innovation
Generic data-aware dynamic decoding mechanism that selectively uses secure instruction variants for sensitive data with zero overhead for non-sensitive operations.

## Method
The processor dynamically selects between two instruction variants based on the sensitivity of its data: fast optimized versions for public data, and secure variants that prevent side-channel attacks for sensitive data. This selection happens at the decode stage during runtime. The implementation was built on RISC-V BOOM, an out-of-order processor.

## Implementation
- RISC-V BOOM out-of-order processor
- FPGA prototype

## Results
- **FPGA overhead:** 2% vs. baseline
- **Unprotected workload overhead:** 0%
- **Protected workload overhead:** Up to 25%
- **Scalable:** Covers full spectrum of side-channels

## Hardware Target
CPU (RISC-V architecture)

## Techniques
Security, circuit design, dynamic decoding

## Advantages
- Generic defense (not specific to cache/speculation)
- Zero overhead for non-sensitive operations
- Scalable implementation

## Limitations
Evaluation on RISC-V BOOM only; applicability to other ISAs not explored.
