# LaZagna: An Open-Source Framework for Flexible 3D FPGA Architectural Exploration

**ID:** iccad-2025-249

## Problem
3D FPGA design exploration requires extensive manual effort and specialized tools. Limited flexibility in vertical interconnect configurations and no open-source infrastructure.

## Motivation
Open-source 3D FPGA frameworks enable research and rapid prototyping of advanced packaging technologies, accelerating innovation in heterogeneous computing.

## Method
The framework automates 3D FPGA design by letting you specify how the vertically stacked layers should connect to each other. It generates the complete hardware description (synthesizable RTL, which is code that hardware tools convert into circuits) and the configuration file (bitstream) needed to program the chip. This lets researchers quickly test many different vertical interconnect designs to find the best trade-offs for their application.

## Key Novelty
An open-source tool that automates 3D FPGA design with flexible vertical interconnects, eliminating manual effort in the design-to-configuration pipeline.
