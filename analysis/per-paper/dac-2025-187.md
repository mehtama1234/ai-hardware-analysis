# InfScaler: Asymmetric Auto-Scaling for Multi-Accelerator Edge ML Inference

**Venue:** DAC | **ID:** dac-2025-187

## Summary
InfScaler optimizes ML inference serving on heterogeneous edge SoCs via bottleneck-aware asymmetric auto-scaling that allocates resources unequally across CPU/GPU/NPU/TPU accelerators. Leverages unified memory for efficient data sharing between scaled partitions.

## Key Results
- **Throughput:** 126.59% improvement vs. state-of-the-art
- **Resource Efficiency:** 27.32% resource reduction
- **Approach:** Bottleneck detection + asymmetric scaling + unified memory optimization

## Technique
Discovers model bottlenecks through profiling; asymmetrically allocates resources to different stages; leverages SoC unified memory to minimize data movement between partitions.
