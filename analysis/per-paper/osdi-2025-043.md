# Mirage: A Multi-Level Superoptimizer for Tensor Programs

**Problem:** Existing tensor program optimizers operate at single levels of the GPU compute hierarchy. There is a need for multi-level optimization that jointly applies algebraic transformations, schedule transformations, and custom kernel generation across kernel, thread block, and thread levels.

**Method:** The system creates a unified blueprint (μGraphs) representing tensor programs at three levels of GPU organization: kernels (whole programs), thread blocks (groups of threads), and threads (individual execution units). This lets it explore improvements across all levels simultaneously rather than one level at a time, using smart shortcuts (abstraction-based pruning) that discard unpromising options early while guaranteeing the final answer is optimal. The system finds improvements in three forms: rearranging the math operations, changing how computation is scheduled across hardware, and writing new optimized code. Finally, it uses a probabilistic equivalence verification procedure—a mathematically-proven method to check that the optimized program produces identical results—to ensure correctness.

**Novelty:** μGraphs provide a unified representation of tensor programs across GPU hierarchy levels (kernels, thread blocks, and threads), enabling optimizations across all levels simultaneously with guaranteed optimality.
