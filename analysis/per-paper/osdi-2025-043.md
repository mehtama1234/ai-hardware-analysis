# Mirage: A Multi-Level Superoptimizer for Tensor Programs

**Problem:** Existing tensor program optimizers operate at single levels of the GPU compute hierarchy. There is a need for multi-level optimization that jointly applies algebraic transformations, schedule transformations, and custom kernel generation across kernel, thread block, and thread levels.

**Method:** Mirage introduces μGraphs, a uniform representation of tensor programs at kernel, thread block, and thread levels enabling multi-level exploration. It applies abstraction-based pruning to reduce the search space while providing optimality guarantees. The system discovers optimizations combining algebraic transformations, schedule transformations, and generation of new custom kernels. A probabilistic equivalence verification procedure with theoretical guarantees ensures the optimized program is functionally equivalent to the input.

**Novelty:** μGraphs provide a unified multi-level representation that enables discovering novel optimizations across the GPU hierarchy with abstraction-based pruning providing optimality guarantees.
