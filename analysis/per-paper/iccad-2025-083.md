# CTDM: Resource-Efficient FPGA-Accelerated Simulation of Large-Scale NPU Designs

**Venue:** ICCAD  
**ID:** iccad-2025-083

## Problem
Large-scale NPU simulations on FPGA face significant resource utilization challenges, limiting the ability to simulate large processor variants and enabling multi-FPGA deployments for comprehensive hardware verification.

## Motivation
Efficient FPGA-accelerated simulation is critical for NPU design verification and validation, enabling faster iteration cycles during hardware development without resorting to expensive full-system simulations.

## Method
CTDM introduces Chain-based Time-Division Multiplexing that replaces repeated logic patterns with single logic and register chains exploiting built-in shift register primitives. An automated CTDM compiler supports Verilog, VHDL, HLS, and Chisel across various FPGA devices. For multi-FPGA systems, block interleaving hides inter-FPGA link latency and fully utilizes high-speed serial I/O pipelines.

## Key Novelty
Chain-based Time-Division Multiplexing with automated compiler supporting multiple HDLs and enabling multi-FPGA deployments for large-scale NPU simulation with dramatically reduced resource overhead.

## Contributions
- Chain-based TDM approach reducing FPGA resource overhead more effectively than multiplexer-based TDM
- Automated CTDM compiler supporting Verilog, VHDL, HLS, and Chisel HDLs with wide FPGA device support
- Block interleaving technique for multi-FPGA systems enabling high-speed I/O utilization
- 66% LUT and 82% FF reduction enabling largest NVDLA variant deployment on single FPGA; 3,653× simulation acceleration vs CPU
