# ReGate: Enabling Power Gating in Neural Processing Units

**Venue:** MICRO  
**Confidence:** high (full-text analysis)

## Problem
Modern NPU chips (e.g., Google TPU generations) waste 30-72% of their active energy on static (leakage) power because they lack fine-grained power management support; conventional CPU/GPU power-gating techniques do not transfer directly because NPUs use large systolic arrays with deterministic dataflows, software-managed SRAM scratchpads, in-order VLIW pipelines, and no dynamic instruction scheduling.

## Motivation
As CMOS feature sizes shrink to 7nm and below, leakage power becomes a larger fraction of total chip power, and the massive scale-up of NPU fleets in data centers amplifies even single-chip static power waste into significant carbon emissions.

## Method
ReGate cuts energy waste in NPU chips (neural processing units) by powering off unused components using hardware and software controls adapted to each type. In the systolic array (a grid of processors performing neural-network multiplications), it detects which rows and columns have zero weights (multiply-by-zero operations) and powers them off; the power-on signal propagates diagonally, matching how data naturally flows through the array, so processors wake up at exactly the right moment with only single-processor latency. For memory controllers—ICI (inter-chip interconnect) and HBM (high-bandwidth memory)—a hardware detector recognizes idle periods between collective operations like AllReduce and AllGather and gates them off. For vector units and SRAM scratchpad (on-chip memory), the compiler uses a new ISA extension with setpm instructions in three modes (on/auto/off) to insert power-management commands at statically-known idle points determined from instruction scheduling and memory analysis.

## Key Novelty
The key innovation is exploiting the natural diagonal data flow of weight-stationary neural-network computation—where weights stay fixed in the array while data flows diagonally—to synchronize individual processor power-on signals in the systolic array, achieving processor-level power-gating with only single-processor wake-up latency.

## Contributions
- First quantification of power-gating opportunities across all major NPU components (SA, VU, SRAM, ICI, HBM) using multi-generation TPU-derived simulators
- Diagonal-dataflow-aware PE-level power gating for systolic arrays using row/column non-zero weight detection and PE_on signal propagation
- NPU ISA extension (setpm instruction) enabling software-managed power gating for vector units and SRAM with on/auto/off modes
- 15.5% average (up to 32.8%) energy reduction across LLM training/inference, DLRM, and stable diffusion workloads with <0.5% performance overhead and <3.3% area overhead at 7nm

## Metrics
- Energy reduction: 8.5%-32.8% (15.5% average) vs. no power gating
- Performance overhead: <0.5%
- Area overhead: <3.3%
- Fleet-scale carbon emission reduction: 31.1%-62.9%

## Baselines
- NPU without power gating (NPU-A/B/C/D derived from TPUv2/3/4/5p)

## Limitations
The power-gating analysis excludes peripheral components (PCIe, chip management, control logic) that account for ~40% of static energy; evaluation is on a simulator validated against real TPU data rather than fabricated silicon.
