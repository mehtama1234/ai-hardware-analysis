# SC-2025-159: Dynamic Thread Coarsening

## Summary
Compiler-based thread coarsening for CPU and GPU OpenMP code that handles divergent control flow through dynamic convergence—runtime selection between coarsened and non-coarsened paths.

## Problem
- Thread coarsening improves ILP and memory patterns but underutilized
- Divergent branches (unprovable uniformity) block compile-time coarsening
- Both CPUs and GPUs affected but approach differs
- Real-world programs have data-dependent branching

## Innovation: Dynamic Convergence
Instead of failing on divergence, generate **both** code paths:
1. **Coarsened path**: Optimized for uniform branches
2. **Non-coarsened path**: Standard execution
3. **Runtime decision**: Check thread uniformity at execute time

## Performance Gains
| Platform | Static TC | Dynamic TC | Improvement |
|----------|-----------|-----------|------------|
| **GPU** | 4.6% | 7.5% | +3% | 
| **CPU** | 2.9% | 4.3% | +1.4% |

## Implementation
- Generic LLVM IR transformation (portable)
- Multi-level coarsening support
- Integrated into OpenMP compilation

## Benchmarks
- **GPU**: HecBench kernels
- **CPU**: LULESH (multiphysics)

## Overhead Analysis
Not explicitly discussed in abstract; dynamic path selection cost presumably minimal.

## Implications
- Divergence less problematic with dynamic approach
- Modest but consistent improvements on real workloads
- Applicable to portable OpenMP code
