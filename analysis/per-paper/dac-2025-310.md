# BPUFuzzer: Fuzz Testing for Transient Execution Vulnerabilities in RISC-V CPUs

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

BPUFuzzer is a fuzz testing framework for detecting branching transient execution vulnerabilities (Spectre variants) in CPU RTL. Uses CFG-based testcase generation with anomaly detection and fitness-guided selection to discover vulnerabilities, finding multiple Spectre types including a novel Spectre-LOOP variant.

## Key Contributions

- **CFG-Based Generation**: Control flow graph-driven testcase generation for complex branch exploration
- **Anomaly Detection**: Systematic extraction of vulnerability symptoms from vast RTL state spaces
- **Fitness Metrics**: Coverage-guided selection for effective testcase prioritization
- **Novel Discovery**: Uncovered previously unknown Spectre-LOOP variant on Boom v3, outperforming SOTA methods

## Technical Focus

Addresses the challenge of generating testcases covering complex control flows and extracting meaningful signals from hardware states. Combines multiple guidance strategies to systematically explore branch prediction behavior.

## Relevance

**Keywords:** fuzz-testing, spectre, transient-execution, risc-v, security
