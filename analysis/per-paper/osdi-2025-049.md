# BlitzScale: Fast and Live Large Model Autoscaling with O(1) Host Caching

**Problem:** Model autoscaling faces a fundamental trade-off between scaling speed and storage/memory usage for parameter caching. The data plane is slow and blocking—scaled instances halt while parameters load—preventing frequent multi-host scaling.

**Method:** BlitzScale loads parameters through the inter-GPU compute network with O(1) host caching, which is fast and underutilized. It shifts scaling from coarse-grained instance-level to fine-grained layer-level, enabling computation offload to scaled instances before parameters fully load. Network-optimized multicast handles multi-instance scaling without excessive caching.

**Novelty:** Leveraging the inter-GPU compute network for fast parameter loading with O(1) host caching, combined with layer-level scaling to enable live autoscaling without instance blocking.
