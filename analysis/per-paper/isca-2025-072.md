# isca-2025-072 — HeterRAG: Heterogeneous Processing-in-Memory Acceleration for Retrieval-augmented Generation

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
RAG systems face two distinct memory bottlenecks: retrieval suffers from random/irregular access patterns causing low bandwidth utilization, and generation is bandwidth-limited by frequent GEMV over large LLM weights. HBM-based PIM alone is both too expensive and capacity-insufficient to hold large-scale knowledge bases.

## Motivation
Enterprise RAG adoption is accelerating, but each stage has fundamentally different memory requirements; no single PIM technology adequately addresses both capacity (retrieval) and bandwidth (generation) demands.

## Method
HeterRAG pairs DIMM-based PIM (low cost, high capacity) for the retrieval stage's irregular accesses and large knowledge base storage with HBM-based PIM for bandwidth-intensive GEMV during LLM generation. The system maps each RAG stage to the PIM type best matched to its access pattern and coordinates inter-domain data movement.

## Key Novelty
First heterogeneous PIM system that jointly handles the capacity bottleneck of RAG retrieval (DIMM-PIM) and the bandwidth bottleneck of LLM generation (HBM-PIM).

## Contributions
1. Characterization of distinct memory bottlenecks in RAG retrieval vs. generation stages
2. Heterogeneous PIM architecture combining DIMM-based and HBM-based PIM
3. Stage-to-PIM-domain mapping strategy for end-to-end RAG acceleration
4. System demonstrating capacity + bandwidth coverage beyond HBM-only PIM
