# Chasoñ: Supporting Cross HBM Channel Data Migration to Enable Efficient Sparse Algebraic Acceleration

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
HBM-based sparse accelerators suffer from high resource underutilization due to static non-zero scheduling that cannot redistribute work across HBM channels when data access patterns are irregular. Existing designs like Serpens fix data-to-channel mapping, leaving processing elements idle when a channel has no work.

## Motivation
Sparse matrix-vector multiplication (SpMV) is memory-bound and irregular; HBM's multiple independent channels are underutilized with static scheduling, capping throughput well below hardware limits.

## Method
Chaso is an FPGA-based streaming HBM accelerator for SpMV that introduces Cross-HBM Channel out-of-Order Scheduling (CrHCS), which dynamically migrates non-zero data across HBM channels at runtime to balance load. When one channel's processing elements are starved, CrHCS identifies data in other channels and migrates it, enabling out-of-order execution across channel boundaries. The design is implemented on AMD Alveo U55C running at 301 MHz, targeting the SuiteSparse and SNAP matrix collections.

## Key Novelty
CrHCS is the first non-zero scheduling scheme that permits out-of-order cross-channel data migration in HBM-based sparse accelerators, directly addressing per-channel load imbalance.

## Contributions
- Cross-HBM Channel out-of-Order Scheduling (CrHCS) for dynamic non-zero load balancing across HBM channels
- Chaso HBM streaming accelerator design implemented on AMD Alveo U55C at 301 MHz
- Up to 8x throughput improvement and 2.03x energy efficiency gain over Serpens baseline
- Open-source implementation demonstrating generality across SuiteSparse and SNAP benchmarks

## Metrics
- Speedup: up to 8x over Serpens, 20.33x over RTX 4090, 11.65x over RTX 6000 Ada, 2.67x over Core i9-11980HK
- Energy efficiency: 2.03x–34.72x better than baselines
- Frequency: 301 MHz on AMD Alveo U55C

## Baselines
Serpens, Nvidia RTX 4090, Nvidia RTX 6000 Ada, Intel Core i9-11980HK

## Limitations
Evaluation is limited to SpMV; generalization of CrHCS to other sparse kernels (e.g., SpGEMM) is not demonstrated.
