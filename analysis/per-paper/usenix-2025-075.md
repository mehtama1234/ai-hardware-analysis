# Unveiling Compiler Faults via Attribute-Guided Compilation Space Exploration

**Problem:** Compilers contain latent bugs that silently produce incorrect executable code, and existing random testing approaches lack systematic coverage of the vast space of compilation configurations and program attributes needed to trigger these faults.

**Method:** The approach systematically explores the compiler configuration space using attribute-guided search, where program attributes (semantic properties, syntax patterns, input characteristics) guide test generation to maximize fault-triggering likelihood. Likely employs differential testing or output verification to detect generated incorrect code.

**Novelty:** Attribute-guided exploration of compiler configuration space to systematically uncover compiler faults rather than relying on random or coverage-based testing.
