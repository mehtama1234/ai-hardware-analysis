# Unveiling Compiler Faults via Attribute-Guided Compilation Space Exploration

**Problem:** Compilers contain latent bugs that silently produce incorrect executable code, and existing random testing approaches lack systematic coverage of the vast space of compilation configurations and program attributes needed to trigger these faults.

**Method:** The approach tests a compiler by systematically trying different compilation settings. It uses attributes of the program being compiled (structure, patterns, characteristics) to guide which settings to try first, prioritizing combinations likely to trigger bugs. It then checks whether the compiled code is correct, catching mistakes the compiler made.

**Novelty:** It uses program attributes to systematically search for compiler bugs instead of randomly testing.
