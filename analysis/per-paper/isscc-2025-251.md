# Fully Dynamic Noise-Shaping SAR ADC

**Venue:** ISSCC  
**ID:** isscc-2025-251

## Problem
High-resolution ADCs (>100dB SNDR) with µW power and kHz bandwidth face trade-offs: DSMs are power-hungry; zoom ADCs handle DC only; multi-step SAR needs calibration; prior NS-SAR limited to ~90-105dB SNDR with high static power.

## Solution
Fully dynamic noise-shaping SAR ADC eliminates static power via transient comparators and dynamic reference generation. Integrates noise-shaping into SAR without residue amplification, gain calibration, or bulky loop filters. Power scales with sampling speed.

## Key Innovation
Fully dynamic NS-SAR achieving 120dB SNDR without static power or external amplification.

## Results
- **SNDR:** 120 dB
- **FoMs:** 189 dB (Figure of Merit for Speed)
- **Bandwidth:** 1 kHz
- **Power:** No static power (fully dynamic)

## Hardware Target
ASIC

## Techniques
Circuit design, signal processing, power efficiency
