# Mixed-Signal Photonic Tensor Core with Photonic SRAM

## Problem
Traditional electrical von Neumann architectures suffer from memory-compute data movement bottlenecks and rising bitline/wordline capacitance at advanced nodes, limiting throughput and efficiency for AI/ML workloads.

## Method
The system stores and processes data using light instead of electricity, combining a photonic memory cell (pSRAM) with a matrix-multiplication processor built from integrated photonic components on a single chip. After the processor multiplies numbers using light signals, a specialized light-to-digital converter (called an eoADC, using 1-hot encoding where one signal is active at a time) quickly translates the results back into electrical data. This approach eliminates the slow step where data normally travels between memory and the processor, since everything stays in the photonic domain.

## Key Results
- 4.10 TOPS computation speed
- 3.02 TOPS/W energy efficiency
- Fabrication-friendly integrated photonic components on GlobalFoundries 45SPCLO
