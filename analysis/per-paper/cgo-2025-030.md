# IntelliGen: Instruction-Level Auto-tuning for Tensor Program with Monotonic Memory Optimization

**Venue:** CGO
**Confidence:** low

## Problem
Tensor compilers must optimize memory performance (throughput, latency) for DNN code generation, but existing auto-tuning either uses coarse-grained descriptions (missing opportunities) or explores vast search spaces (impractical). Fine-grained auto-tuning has been infeasible.

## Motivation
Memory performance is the bottleneck in tensor compilation; enabling fine-grained auto-tuning without exploding search space is critical for next-generation compilers.

## Method
IntelliGen optimizes deep neural network code by making instruction-level choices about memory access patterns on NVIDIA, AMD, and Cambricon hardware. It relies on a key insight: memory optimizations are "monotonic," meaning if two optimizations each improve performance independently, combining them still improves performance without conflicts. This property lets it efficiently explore thousands of parameter combinations instead of billions.

## Key Novelty
Instruction-level auto-tuning is made practical through monotonic memory optimization: a principle where each improvement adds on top of others without creating conflicts, which lets the system explore efficiently instead of checking exponentially many possibilities.

## Contributions
- Instruction-level graph IR for tensor programs
- Monotonic optimization method for memory performance
- Up to 3.13x, 3.55x, 16.9x speedups on NVIDIA, AMD, Cambricon respectively
