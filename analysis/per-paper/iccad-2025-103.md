# DynVec: An End-to-End Framework for Efficient Vector-Dataflow Execution

**Venue:** ICCAD  
**ID:** iccad-2025-103

## Problem
HLS tools struggle with vectorization and dynamic scheduling for irregular workloads due to unknown memory access patterns and control flow divergence at compile time.

## Motivation
Enable efficient hardware acceleration of irregular kernels by combining compile-time and runtime parallelism optimization through vectorization and dynamic dataflow scheduling.

## Method
DynVec uses MLIR, an intermediate representation for code, to automatically convert scalar operations into vector operations (where a single operation processes multiple data items simultaneously). It generates execution graphs showing how data flows through these vector operations, using flexible computational units that adapt to different vector sizes. Rather than making all scheduling decisions at compile time when memory access patterns are unknown, DynVec makes both vectorization and scheduling decisions at runtime, based on actual data patterns. This allows it to exploit parallelism opportunities in irregular workloads that traditional tools cannot vectorize.

## Key Novelty
DynVec couples vectorization and dynamic scheduling in a single framework, allowing both to adapt based on runtime memory access patterns in irregular workloads.

## Contributions
- Significant speedup over state-of-the-art HLS implementations
- Superior performance vs hybrid accelerators with separate vectorization/dynamic support
- Context-aware vectorizer identifying vectorizable operations in irregular code
- Bottom-up type-safe composition of vector and scalar operations
- MLIR-based framework preserving kernel structural hierarchy
