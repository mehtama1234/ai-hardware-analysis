# IntraFuzz: Coverage-Guided Intra-Enclave Fuzzing for Intel SGX Applications

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
SGX applications have intra-enclave vulnerabilities; simulated fuzzing misses actual hardware-based bugs in enclaves.

## Key Idea
First coverage-guided fuzzing system for SGX applications running in actual hardware enclaves on Intel Xeon processors.

## Method
- Coverage-guided fuzzing inside actual SGX hardware enclaves
- Enclave code instrumentation for coverage feedback
- Integration with SGX runtime
- Tested on Intel Xeon with up to 256GB EPC

## Contributions
1. First hardware-based intra-enclave fuzzing system
2. Coverage-guided approach on actual SGX enclaves
3. All known + 6 new vulnerabilities detected vs. EnclaveFuzz

CPU (Intel SGX)
