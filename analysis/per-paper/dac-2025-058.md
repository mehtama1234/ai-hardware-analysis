# IntraFuzz: Coverage-Guided Intra-Enclave Fuzzing for Intel SGX Applications

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
SGX applications have intra-enclave vulnerabilities; simulated fuzzing misses actual hardware-based bugs in enclaves.

## Key Idea
First coverage-guided fuzzing system for SGX applications running in actual hardware enclaves on Intel Xeon processors.

## Method
IntraFuzz finds bugs in SGX applications (programs running in Intel's hardware-protected memory called enclaves) using coverage-guided fuzzing—a method that repeatedly sends random test data to the program while tracking which code paths execute, then uses that feedback to generate new tests targeting unexplored code. The system runs directly on actual Intel hardware, not in simulation, integrating with the SGX runtime to monitor enclave code during testing. By observing real hardware execution rather than simulated behavior, IntraFuzz can uncover vulnerabilities that appear only under actual hardware-protected conditions.

## Contributions
1. First hardware-based intra-enclave fuzzing system
2. Coverage-guided approach on actual SGX enclaves
3. All known + 6 new vulnerabilities detected vs. EnclaveFuzz
