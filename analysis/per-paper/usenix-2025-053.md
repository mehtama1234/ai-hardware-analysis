# XRT: An Accelerator-Aware Runtime for Accelerated Chip Multiprocessors

**Problem:** Heterogeneous chip multiprocessors with multiple accelerators lack unified runtime support for coordinating workload execution across diverse hardware units with different capabilities and constraints.

**Method:** XRT provides a runtime system that maintains awareness of different accelerator types and their capabilities, implementing scheduling algorithms to map workloads to appropriate accelerators and manage resource contention and synchronization across the system.

**Novelty:** A unified accelerator-aware runtime abstraction that coordinates execution and resource management across heterogeneous accelerators in chip multiprocessors.
