# XRT: An Accelerator-Aware Runtime for Accelerated Chip Multiprocessors

**Problem:** Heterogeneous chip multiprocessors with multiple accelerators lack unified runtime support for coordinating workload execution across diverse hardware units with different capabilities and constraints.

**Method:** XRT is software that runs alongside your programs and keeps track of what different hardware accelerators (specialized chip units optimized for specific tasks like graphics, AI, or encryption) can and can't do. When your program has work to do, XRT decides which accelerator to send each piece to, managing the coordination—preventing multiple tasks from using the same accelerator at once and ensuring all pieces finish in the right order. It does this by continuously monitoring what the hardware is doing and intelligently scheduling incoming work to the accelerator that can handle it best.

**Novelty:** Instead of requiring separate, incompatible software for each accelerator type, XRT provides one unified layer that understands all accelerators and coordinates work across them.
