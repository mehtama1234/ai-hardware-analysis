# HoBBy: Hardening Unbalanced Branches against Control Flow Attacks on Intel SGX and AMD SEV

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Control flow attacks exploit instruction-level timing differences in secret-dependent branches that source-level balancing misses, compromising SGX/SEV security.

## Key Insight
Instruction-level transformations (shadowing, cogging, spiraling) can obfuscate control flow timing to defeat timing-based side-channel attacks.

## Method
A compiler automatically identifies branches in secret-dependent code where different execution paths would take different amounts of time, then balances them using three instruction-level techniques: shadowing (duplicating operations), cogging (interleaving operations), and spiraling (rearranging operations). By making all paths take equal time, the technique prevents attackers from using timing measurements to deduce secrets. It works on code compiled for Intel SGX and AMD SEV, which are trusted execution environments—hardware-protected regions where sensitive computations run isolated.

## Contributions
- Single-step unbalanced instruction identification
- Three instruction-level hardening techniques
- Validation against 3 SOTA attacks (SGX/SEV)
- 2.8% runtime, 0.6% binary size overhead
