# HoBBy: Hardening Unbalanced Branches against Control Flow Attacks on Intel SGX and AMD SEV

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Control flow attacks exploit instruction-level timing differences in secret-dependent branches that source-level balancing misses, compromising SGX/SEV security.

## Key Insight
Instruction-level transformations (shadowing, cogging, spiraling) can obfuscate control flow timing to defeat timing-based side-channel attacks.

## Method
Compiler-based identification of unbalanced instructions in branches via single-step analysis; applies instruction-level transformations to make parallel flows indistinguishable.

## Contributions
- Single-step unbalanced instruction identification
- Three instruction-level hardening techniques
- Validation against 3 SOTA attacks (SGX/SEV)
- 2.8% runtime, 0.6% binary size overhead

## Hardware Target
CPU (Intel SGX, AMD SEV)

## Workloads
Cryptography

## Theme
Instruction-level control flow obfuscation for TEE security.
