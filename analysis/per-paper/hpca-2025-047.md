# Ditto: Accelerating Diffusion Model via Temporal Value Similarity

**Venue:** HPCA 2025  
**Authors:** Sungbin Kim, Hyunwuk Lee, Wonho Cho, Mincheol Park, Won Woo Ro

## Problem
Diffusion models require many iterative denoising steps, each a full forward pass, causing prohibitive compute and memory overhead; adjacent time steps produce outputs with high value similarity and narrow differences that existing accelerators do not exploit.

## Motivation
Diffusion models achieve top image generation quality but their iterative structure multiplies compute cost by the number of denoising steps, making them impractical for low-power or real-time deployment without algorithmic-hardware co-design.

## Method
Ditto exploits a simple fact: when a diffusion model removes noise step-by-step, the output from one step to the next barely changes. Instead of recalculating everything each time, the algorithm computes the full result on the first step, then only figures out the tiny differences in each subsequent step (representing them with fewer bits, often as zero). Neural network math lets you do this: you can compute just the difference and add it back instead of recalculating the whole thing. The hardware is specially designed to recognize when there's no difference at all and skip that step, while organizing memory to efficiently handle storing and retrieving these differences.

## Key Novelty
The core innovation is to exploit nearly identical outputs between diffusion model steps by representing their tiny differences with fewer bits (often zero) and designing hardware that skips these zero-difference operations without sacrificing accuracy.

## Contributions
- Analysis demonstrating adjacent diffusion timestep differences are representable at reduced bit-widths or zero
- Ditto algorithm for temporal difference processing using distributive property to skip redundant computation
- Ditto execution flow optimization reducing memory overhead of temporal difference management
- Ditto hardware accelerator: up to 1.5x speedup and 17.74% energy saving

## Results
- **Speedup:** Up to 1.5x vs other diffusion accelerators
- **Energy:** 17.74% saving vs other accelerators

## Hardware Target
ASIC

## Limitations
Speedup is modest (1.5x) and specific baseline accelerators compared against are not named in the abstract.
