# ISSCC 2025-208: Ultra-Efficient Incremental Noise-Shaping ADC

## Core Contribution
Incremental noise-shaping pipeline ADC achieving record 184.8dB FoM at 1.6MS/s via single-amplification kT/C noise cancellation with gated amplifier and concurrent coarse/fine quantization.

## Technical Approach
- **Architecture**: Hybrid zoom combining low-power SAR quantizer with high-resolution ΔΣ modulator
- **kT/C Cancellation**: Single amplifier activated only during cancellation phase (not throughout conversion)—key power reduction vs. static or repeated-trigger approaches
- **Quantization**: Concurrent coarse and fine stages (unlike sequential zoom requiring repeated sampling)
- **Noise-Shaping**: ΔΣ modulation for high SNR despite reduced OSR
- **Speed**: 1.6MS/s conversion rate (5x faster than conventional incremental ADCs, competitive with NS-SAR)

## Performance Metrics
- **Energy Efficiency**: 184.8dB FoM (highest reported for incremental ADC architecture)
- **Conversion Rate**: 1.6MS/s
- **Estimated Resolution**: ~15–16 bits (extrapolated from FoM, not stated in abstract)
- **Power**: Optimized via gated amplification (specific value not provided)

## Baselines
- Conventional incremental zoom (sequential coarse/fine, slow)
- NS-SAR zoom ADC (300kS/s, requires extensive conversion cycles)
- Prior kT/C cancellation (continuous amplifier, high power overhead)

## Hardware Impact
Addresses key gap in sensor interfaces: high-resolution (16–18b) + moderate speed (1–10MS/s) + ultra-low power. Suitable for precision IoT sensors (environmental, medical, industrial) with battery/harvested-power constraints.
