# DRAFT: Decoupling Backpropagation from Pre-trained Backbone for Efficient Transformer Fine-Tuning on Edge

**Venue:** DAC | **ID:** dac-2025-122

## Core Problem
Efficient fine-tuning of pre-trained Transformers on edge devices; backpropagation through massive backbone weights incurs high cost and memory overhead.

## Method
DRAFT solves the problem of expensive gradient calculations during fine-tuning on edge devices by splitting backpropagation (the process of calculating weight updates) into two separate pathways via Feedback Decoupling Approximation (FDA): a trainable adapter and a sparse ternary Bypass Network (a network using mostly-zero weights to efficiently approximate gradients). Custom hardware—a reconfigurable DRAFT accelerator—runs these pathways by exploiting sparsity (the many zeros) and data parallelism (splitting work across processors) through sparse gather networks and dynamic workflows.

## Key Novelty
The key innovation is algorithm-hardware co-design (designing a special algorithm and custom hardware together) where Feedback Decoupling Approximation splits backpropagation (gradient calculation) into two lightweight pathways rather than computing through the entire pre-trained model, reducing computational cost while preserving training accuracy.

## Contributions
- FDA algorithm with adapter and sparse BPN pathways
- DRAFT accelerator with reconfigurable sparse gather networks
- 4.9x speedup, 4.2x energy efficiency improvement
- Negligible accuracy loss
