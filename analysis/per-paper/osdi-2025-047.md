# KRR: Efficient and Scalable Kernel Record Replay

**Problem:** Kernel record-replay systems incur significant recording overhead and struggle to scale deterministically across multi-core systems. Efficiently capturing kernel events while enabling fast, correct replay across many processors remains a fundamental challenge.

**Method:** KRR records only the critical kernel events that determine a program's behavior, not every single operation, to avoid the massive slowdown that recording typically causes. It compresses this recorded information so it takes little space. To replay the program later, KRR runs the execution across multiple processor cores simultaneously, but carefully coordinates when each event happens so the result is always the same.

**Novelty:** KRR is the first system to record kernel events with minimal performance slowdown while also replaying them efficiently across many processors simultaneously.
