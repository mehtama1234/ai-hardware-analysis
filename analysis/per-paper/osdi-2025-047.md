# KRR: Efficient and Scalable Kernel Record Replay

**Problem:** Kernel record-replay systems incur significant recording overhead and struggle to scale deterministically across multi-core systems. Efficiently capturing kernel events while enabling fast, correct replay across many processors remains a fundamental challenge.

**Method:** KRR uses selective event logging to minimize recording overhead, optimized storage and compression of trace data, and parallel deterministic replay mechanisms. The system likely leverages kernel instrumentation hooks and efficient data structures to scale recording and replay across many cores while preserving execution determinism.

**Novelty:** First system to achieve both low recording overhead and efficient scaling to many-core systems simultaneously in kernel record-replay.
