# SMART: High-Performance SAR ATR Through Model-Architecture Co-Design on FPGA

**Problem:** SAR ATR systems suffer from high latency, large memory footprint, and high power consumption, particularly in resource-constrained environments like small satellites.

**Method:** The team designed a small neural network for detecting objects in SAR radar images that uses attention mechanisms (ways to focus computation on important regions). To run fast on constrained hardware, they replaced expensive softmax-based attention with a simpler version and reduced numerical precision (quantization). They then built custom hardware on an FPGA (Xilinx Alveo U280, a reprogrammable chip) using HLS to program processing kernels that implement a streaming dataflow architecture—data flows continuously through these units like an assembly line, avoiding repeated memory accesses.

**Novelty:** The approach combines softmax-free attention mechanisms (simplified focus calculations) with streaming dataflow FPGA architecture through joint design of the neural network and hardware for SAR radar image recognition.
