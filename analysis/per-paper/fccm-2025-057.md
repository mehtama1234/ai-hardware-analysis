# SMART: High-Performance SAR ATR Through Model-Architecture Co-Design on FPGA

**Problem:** SAR ATR systems suffer from high latency, large memory footprint, and high power consumption, particularly in resource-constrained environments like small satellites.

**Method:** Develops a compact CNN with integrated spatial, channel, and cross attention mechanisms using softmax-free attention and quantization. Implements a customized FPGA accelerator with streaming dataflow architecture using HLS on Xilinx Alveo U280, featuring parameterized hardware kernels for key operations to optimize dataflow.

**Novelty:** Model-architecture co-design combining softmax-free attention mechanisms with FPGA streaming dataflow architecture for SAR ATR systems.
