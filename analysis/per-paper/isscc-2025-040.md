# isscc-2025-040: Mobile Super-Resolution Processor

**Title:** A 0.52mJ/Frame 107fps Super-Resolution Processor Exploiting Pseudo-FP6 Sparsity for Mobile Applications

**Venue:** ISSCC

## Core Contribution
Mobile super-resolution processor achieving 0.52mJ/frame at 107fps via pseudo-FP6 quantization and memory-optimized layer-fusion.

## Key Metrics
- **Energy:** 0.52mJ/frame
- **Throughput:** 107fps (real-time)
- **Precision:** Pseudo-FP6

## Problem
SRCNN on mobile faces memory bottlenecks (overlapping regions), image-quality degradation with traditional quantization, and redundant deconvolution computations.

## Method
The processor uses a number format called pseudo-FP6 that stores values in fewer bits while maintaining the full numerical range needed for image quality, saving power. It combines multiple neural-network layers in a memory-efficient way, minimizing temporary storage of overlapping pixel regions to further reduce energy use. It also optimizes the deconvolution step (which enlarges images using learned patterns) to avoid redundant calculations. These techniques achieve image enlargement at 107 frames per second while consuming only 0.52 millijoules per frame.
