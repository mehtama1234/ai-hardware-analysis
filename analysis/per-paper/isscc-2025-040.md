# isscc-2025-040: Mobile Super-Resolution Processor

**Title:** A 0.52mJ/Frame 107fps Super-Resolution Processor Exploiting Pseudo-FP6 Sparsity for Mobile Applications

**Venue:** ISSCC

## Core Contribution
Mobile super-resolution processor achieving 0.52mJ/frame at 107fps via pseudo-FP6 quantization and memory-optimized layer-fusion.

## Key Metrics
- **Energy:** 0.52mJ/frame
- **Throughput:** 107fps (real-time)
- **Precision:** Pseudo-FP6

## Problem
SRCNN on mobile faces memory bottlenecks (overlapping regions), image-quality degradation with traditional quantization, and redundant deconvolution computations.

## Method
Pseudo-FP6 high-dynamic-range quantization, memory-optimized layer-fusion minimizing overlapping regions, efficient deconvolution mapping.

## Confidence
Low (abstract-only analysis).
