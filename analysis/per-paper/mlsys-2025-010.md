# PipeFill: Using GPUs During Bubbles in Pipeline-Parallel LLM Training

**Venue:** MLSys 2025 | **ID:** mlsys-2025-010 | **Confidence:** high

## Problem
Pipeline-parallel LLM training leaves substantial GPU idle time (pipeline bubbles) that represents wasted compute capacity at scale.

## Method
In pipeline-parallel training, GPUs process data in stages that sometimes pause, leaving compute time wasted—these idle gaps are called bubbles. PipeFill uses this wasted time to run secondary work: batch inference or small model training that can complete during the pause. It introduces three components to make this work: a Pipeline Bubble Instruction (PBI, a description of what fill work is allowed), a Fill Job Executor (which assigns fill work to idle GPU moments), and a Fill Job Scheduler (which tracks when bubbles occur and sends work to them). The implementation uses DeepSpeed with GPipe and 1F1B schedule strategies.

## Novelty
First system to systematically exploit pipeline bubble structure for productive secondary workloads via the PBI abstraction.

## Metrics
- 63% GPU utilization increase at 8K GPUs
- <2% slowdown on primary LLM training job
