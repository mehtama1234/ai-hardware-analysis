# SDISC: A Spike-Driven Human-Machine Interface with In-Situ Computing for Real-Time Low-Power Interaction

**ID**: dac-2025-451  
**Venue**: DAC  
**Confidence**: low

## Problem
Bio-signal processing for HMI (EMG, EEG) incurs high latency and power using conventional hardware; frame-based methods cannot achieve real-time energy-efficient edge inference.

## Motivation
Neuromorphic systems promise ultra-low-power inference; direct integration of spike-driven encoding and in-memory computing enables real-time HMI.

## Method
SDISC combines: (1) spike-driven feature extraction (>10x sparsity vs frame-based), (2) RRAM-based in-situ SNN computation (4.09 TOPS/W), (3) Spike-Activity-Distillation and Aid-Loser-Only recovery schemes to handle RRAM non-ideality and long-term drift.

## Key Novelty
Spike-driven bioprocessing with RRAM in-situ computing and device-aware algorithm design for long-horizon HMI.

## Contributions
- Spike-driven bio-signal feature extraction
- RRAM in-memory computing for SNNs
- Spike-Activity-Distillation algorithm
- Aid-Loser-Only recovery scheme
- 98% accuracy over 15+ days, 34 µs latency, 39.72 µW/sample
