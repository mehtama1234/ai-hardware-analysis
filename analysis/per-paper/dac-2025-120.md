# MIA-aware FinFlex Cell Legalization with Power-Driven Cell Version Substitution

**Venue:** DAC | **ID:** dac-2025-120

## Core Problem
Standard cell legalization for TSMC FinFlex technology in sub-3nm nodes, with multiple cell versions (varying heights/Vth) and MIA constraints.

## Method
The algorithm uses three stages. First, it scans for violations within each row, considering both timing (speed) and power consumption. Second, it creates an initial arrangement using a directed acyclic graph (a dependency diagram showing how cells relate to each other) and selects which version of each cell to use—choosing between power-efficient and faster variants. Third, it removes violations between rows using dynamic programming (an optimization technique that builds solutions step-by-step), while ensuring manufacturing minimum implant area requirements are satisfied.

## Key Novelty
It's the first systematic approach to FinFlex cell legalization that combines power-driven cell version selection with minimum implant area constraint handling, using both directed acyclic graphs (dependency diagrams) and dynamic programming (an optimization technique).

## Contributions
- First FinFlex legalization work addressing version substitution and MIA
- Multi-stage DAG + DP approach for violation removal
- Power-efficient cell version selection
