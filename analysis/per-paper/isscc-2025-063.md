# isscc-2025-063

**Title:** 23.5 MAE: A 3nm 0.168mm2 576MAC Mini AutoEncoder with Line-Based Depth-First Scheduling for Generative AI in Vision on Edge Devices

**Venue:** ISSCC

**Problem:** Diffusion-based generative models on edge devices face DRAM bandwidth bottlenecks (40–80% energy cost) and temporal under-utilization of limited MACs.

**Key Contribution:** Line-based depth-first fusion + H-reuse caching reduces DRAM access; global scheduling achieves 84.5% utilization in 0.168 mm².

**Method:** MAE is a tiny specialized processor built in 3nm technology, integrating 576 MAC units (the multiply-accumulate operations that form the basis of neural networks) into just 0.168 mm². Instead of processing each layer completely before moving to the next, it uses a line-based depth-first approach: processing thin horizontal slices of data all the way through the computation pipeline, which keeps related data in fast on-chip memory much longer and avoids repetitive trips to slow external DRAM. The design includes local caching to hold frequently reused data, and an optimization system that jointly minimizes memory access while keeping the computation units busy—addressing the problem where tiny chips normally sit idle waiting for data from memory.

**Hardware:** NPU, ASIC

**Metrics:** 576 MACs, 12.38 TOPS/W, 84.5% utilization, 0.168 mm²

**Workloads:** Diffusion, vision (autoencoders)

**Techniques:** Dataflow, memory-system, kernel-fusion, scheduling

**Primary Theme:** Domain-specific NPU for edge generative vision
