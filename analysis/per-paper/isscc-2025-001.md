# isscc-2025-001: Nebula – 3D PNN Accelerator

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
Point-cloud neural networks suffer from quadratic latency in farthest-point sampling (FPS), redundant operations on points in grouping/convolution/aggregation phases, and irregular external memory accesses.

## Approach
**Nebula** (28nm ASIC) combines three techniques:
1. **Adaptive block-wise partitioning:** Replaces serial FPS with load-balanced geometric segmentation
2. **Multi-skipping dataflow:** Skips redundant operations for discarded points; reduces grouping/convolution/aggregation overhead
3. **Block-wise aggregation:** Reduces memory access irregularity via structured neighbor lookups

## Key Contribution
Eliminates PNN dataflow inefficiencies—both compute (redundant ops) and memory (irregular accesses)—yielding 109.8 TOPS/W.

## Performance
- Energy: 109.8 TOPS/W (28nm)
- Applications: autonomous driving, robotics, VR
