# Ultra Energy-Efficient Butterfly Counting in Bipartite Networks via Algorithm-Architecture Co-Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-125

## Problem
Butterfly counting in large bipartite graphs requires repetitive vertex traversal with limited data reusability, causing substantial latency and energy consumption on CPU/GPU platforms.

## Motivation
Graph analytics on large networks is increasingly important; energy-efficient solutions enable deployment on resource-constrained systems.

## Method
The approach designs the algorithm and hardware together from the start, allowing them to optimize for each other rather than working independently. It reduces computational overhead by using lightweight math operations (simple calculations), data compression (making data smaller to move around faster), and pruning strategies (skipping branches that won't find results) that especially help with sparse graphs (networks where most possible connections don't exist). The resulting custom FPGA design (programmable circuit built for this specific job) runs on Zynq UltraScale+ hardware with only 4 GB of working memory (DRAM), consuming minimal energy.

## Key Novelty
The core idea is designing the algorithm and hardware together as one system from the start, rather than separately, to enable efficient graph pattern counting while keeping memory use minimal.

## Contributions
- Optimized butterfly counting algorithm with lightweight operations and high parallelization
- Data compression and pruning strategies for sparse graph processing
- Custom FPGA hardware architecture achieving 50× energy efficiency improvement
