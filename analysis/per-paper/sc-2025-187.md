# SC-2025-187: Mouse Whole Cortex Simulation on Fugaku

**Venue:** SC 2025  
**Authors:** Rin Kuriyama, Kaaya Akira, Laura Green, Beatriz Herrera, Kael Dai, Mari Iura, Gilles Gouaillardet, Asako Terasawa  
**Confidence:** low (abstract only)

## Summary

First demonstrated simulation of whole mouse cerebral cortex (9M neurons, 26B synapses) using biophysical neuron models on Fugaku supercomputer, validating extreme-scale HPC capabilities for computational neuroscience.

## Hardware Target

- Fugaku Supercomputer
- Exascale systems (145,728-152,064 nodes)

## Problem & Motivation

Understanding brain structure and function requires high-fidelity biophysical simulations. Whole-mammalian-cortex simulation at cellular resolution demands extreme computational power. Validating HPC readiness for this scale of scientific computing.

## Approach

1. Lightweight biophysical neuron simulator design
2. Fugaku-specific optimization for memory, communication
3. Strong scaling studies up to 152,064 nodes
4. Full cortex simulation on 145,728 nodes

## Key Contributions

1. Optimized lightweight neuron simulator for exascale
2. Strong scaling to 7.13 petaflops
3. First whole-cortex biophysical simulation at scale
4. Demonstrated HPC readiness for extreme-scale neuroscience
5. Model includes:
   - 9 million biophysical neurons
   - 26 billion synapses
   - Diverse biophysical properties

## Scientific Impact

Demonstrates capability to build accurate digital replicas of mammalian brains using standardized public databases and extreme-scale computing.

## Limitations

Time-to-solution, I/O requirements, communication analysis not in abstract; simulation accuracy metrics limited.
