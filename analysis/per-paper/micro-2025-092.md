# micro-2025-092: FALA: Locality-Aware PIM-Host Cooperation for Graph Processing with Fine-Grained Column Access

**Venue:** MICRO 2025  
**Authors:** Changmin Shin, Jaeyong Song, Seongmin Na, Jun Sung, Hongsun Jang, Jinho Lee  
**Confidence:** low (abstract only)

## Problem
Graph processing has irregular memory access patterns causing memory bandwidth waste: cache-based graph tiling suffers from overfetching (DRAM burst size >> useful data per access), while PIM-only approaches fail to exploit cache locality for reused vertex data.

## Motivation
Graph processing underlies social networks, recommendation systems, and analytics; neither pure cache-based nor pure PIM approaches solve the dual challenge of sparse access overfetching and cache underutilization for reused data.

## Method
FALA combines two processing approaches: a CPU with its cache, and processing-in-memory (PIM—computing hardware built into DRAM banks). It uses fine-grained column access to let the system fetch only the specific columns (graph vertices) it actually needs, rather than full DRAM rows, which eliminates bandwidth waste from pulling data you don't actually use. A locality-aware policy routes frequently-used vertex data through the CPU cache, while irregular accesses get processed directly near-memory via PIM. This combined strategy cuts unnecessary memory traffic while fully utilizing both DRAM bandwidth and CPU cache.

## Key Novelty
The core innovation is a fine-grained column access mechanism within DRAM banks (allowing selective access to individual vertices instead of full rows) combined with a locality-aware policy that routes frequently-accessed vertex data through the host CPU cache and irregular accesses through processing-in-memory.

## Contributions
1. Fine-grained column access mechanism within DRAM banks for sparse graph vertex access
2. Locality-aware PIM-host cooperation policy for reuse-based routing
3. 1.56x geometric mean speedup and 35.3% energy reduction vs. prior art
4. Hybrid architecture overcoming limitations of both pure cache-based and pure PIM graph accelerators
