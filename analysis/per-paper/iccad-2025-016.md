# Performance-Driven Pre-Assignment Routing for High-Speed Package Designs

**Venue:** ICCAD  
**ID:** iccad-2025-016

## Problem
High-speed package routing lacks performance-driven optimization that minimizes critical path while preventing wire crossings within single metal layers.

## Motivation
Package routing optimization is essential for high-speed circuit performance without excessive overhead in wire length.

## Method
Dynamic programming—an optimization technique that builds solutions from smaller pieces—creates a baseline routing solution. A search algorithm then explores different orderings for routing individual signals through the package. It keeps only the promising options, finding an ordering that shortens the longest signal path (called the critical path) without allowing wires to cross on the same metal layer.

## Key Novelty
It combines dynamic programming baseline routing with search-based signal reordering to minimize the critical path while preventing wire crossings.

## Contributions
- Novel dynamic programming method for baseline routing generation
- Search-based optimization with effective pruning techniques
- 32.9% critical path reduction with minimal total path increase
- 5000x speedup over exhaustive branch-and-bound methods
