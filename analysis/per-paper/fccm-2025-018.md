# InTAR: Inter-Task Auto-Reconfigurable Accelerator Design for High Data Volume Variation in DNNs

**Problem:** Modern DNNs exhibit high data volume variation (HDV) across tasks, causing FPGA accelerators with fixed execution patterns (dataflow or sequential) to suffer from pipeline stalls or frequent off-chip memory accesses.

**Method:** InTAR combines the computational efficiency of sequential execution with the reduced off-chip memory overhead of dataflow execution by automatically switching between patterns based on a static schedule determined before circuit design. The reconfiguration schedule is computed once based on resource constraints and problem sizes, then encoded into the hardware design to enable model-specific optimizations without runtime overhead. The design supports HLS for rapid code generation and achieves low reconfiguration latency through pre-computed switching logic.

**Novelty:** Static pre-computed reconfiguration schedules encoded at circuit design time enable model-specific resource allocation and optimizations, eliminating the need for runtime schedule computation unlike previous reconfigurable accelerators.
