# InTAR: Inter-Task Auto-Reconfigurable Accelerator Design for High Data Volume Variation in DNNs

**Problem:** Modern DNNs exhibit high data volume variation (HDV) across tasks, causing FPGA accelerators with fixed execution patterns (dataflow or sequential) to suffer from pipeline stalls or frequent off-chip memory accesses.

**Method:** InTAR automatically switches between two execution patterns based on what each task needs: sequential (doing operations one after another, which efficiently uses the chip's computation resources) and dataflow (where data stays on the chip and moves directly from one processing stage to the next, reducing trips to external memory). Rather than committing the hardware to one pattern, InTAR computes the best pattern sequence ahead of time based on available resources and the sizes of the problems being solved, then encodes this sequence directly into the circuit design, tailoring each neural network model to run optimally. Since the pattern sequence is pre-computed and encoded into the design, the hardware can optimize each model without any runtime delays, using HLS (a code-generation tool) to make implementation practical.

**Novelty:** InTAR's main innovation is determining the execution pattern schedule once before building the hardware and encoding it directly into the design, enabling model-specific resource allocation without the runtime computation that traditional reconfigurable accelerators require.
