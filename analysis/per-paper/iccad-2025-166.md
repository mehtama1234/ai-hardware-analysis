# Automatic Microarchitecture-Aware Custom Instruction Design for RISC-V Processors

**Authors:** Evgenii Rezunov, Niko Zurstraßen, Lennart M. Reimann, Rainer Leupers

**Venue:** ICCAD

## Summary
CIDRE automates custom instruction discovery for RISC-V ASIPs by analyzing application hot spots and generating instruction suggestions with EDA cost-benefit assessment.

## Key Contributions
- Automated analysis of RISC-V application hot spots
- Automatic custom instruction suggestion with nML descriptions
- Up to 2.47× acceleration of embedded benchmarks with <24% area increase
- Fully automated end-to-end ASIP design without manual intervention
