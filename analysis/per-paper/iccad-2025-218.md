# NUA-Timer: Pre-Synthesis Timing Prediction Under Non-Uniform Input Arrival Times

**Venue:** ICCAD  
**ID:** iccad-2025-218  
**Confidence:** low

## Problem Statement
Pre-synthesis timing prediction for hierarchical designs must handle non-uniform input arrival times, a common real-world scenario.

## Motivation
Accurate timing prediction before synthesis enables better design decisions and reduces iteration cycles.

## Method
The tool uses a neural network (an AI trained on examples) to predict circuit timing by analyzing signal paths in both forward and backward directions through the circuit. What makes it different is handling non-uniform input arrival times—accounting for the fact that different signals reach a circuit block at different moments, a common real-world scenario that traditional prediction methods usually ignore. These predictions happen before the circuit design is physically built (pre-synthesis stage), working on hierarchical designs (complex circuits built from smaller building blocks), which is much faster than actually simulating or testing the hardware.

## Key Novelty
This is the first neural network-based timing predictor that directly accounts for non-uniform input arrival times at the pre-synthesis stage.

## Contributions

1. Bidirectional propagation neural network for timing
2. Pre-synthesis timing prediction
3. Handles non-uniform input arrival times
