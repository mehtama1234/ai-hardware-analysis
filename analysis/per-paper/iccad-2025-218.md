# NUA-Timer: Pre-Synthesis Timing Prediction Under Non-Uniform Input Arrival Times

**Venue:** ICCAD  
**ID:** iccad-2025-218  
**Confidence:** low

## Problem Statement
Pre-synthesis timing prediction for hierarchical designs must handle non-uniform input arrival times, a common real-world scenario.

## Motivation
Accurate timing prediction before synthesis enables better design decisions and reduces iteration cycles.

## Method
Bidirectional propagation neural network for timing analysis. Handles non-uniform input arrival times (NUAT) explicitly. Pre-synthesis analysis on hierarchical design blocks.

## Key Novelty
First neural network-based timing predictor addressing non-uniform input arrival times at pre-synthesis stage.

## Contributions

1. Bidirectional propagation neural network for timing
2. Pre-synthesis timing prediction
3. Handles non-uniform input arrival times
