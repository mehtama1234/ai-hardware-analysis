# TETRIS: On-Device Trainable Energy-Efficient FPGA Accelerator for Trustworthy and Real-Time Instance Segmentation

**Venue:** ICCAD  
**ID:** iccad-2025-101

## Problem
On-device training for instance segmentation on resource-constrained edge devices remains largely unexplored despite the intensive computation and complex dataflows required.

## Motivation
Enable privacy-preserving, adaptive learning for computer vision tasks directly on edge devices with real-time training capability.

## Method
TETRIS: FPGA accelerator with:
- Channel-aware smoothing quantization
- Distribution-aware tie quantization
- Reconfigurable convolution processing unit (RC-PU) supporting variable kernel sizes
- Fully pipelined auxiliary processing unit for specialized operations

## Key Novelty
First FPGA accelerator specifically designed for on-device instance segmentation training.

## Contributions
- Peak performance of 805.9 GOPS
- Energy efficiency of 69.5 GOPS/W
- Real-time training capability on edge devices
- Structural and quantization-aware optimizations
- Heterogeneous hardware architecture for specialized operations
