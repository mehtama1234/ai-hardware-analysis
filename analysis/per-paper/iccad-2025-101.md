# TETRIS: On-Device Trainable Energy-Efficient FPGA Accelerator for Trustworthy and Real-Time Instance Segmentation

**Venue:** ICCAD  
**ID:** iccad-2025-101

## Problem
On-device training for instance segmentation on resource-constrained edge devices remains largely unexplored despite the intensive computation and complex dataflows required.

## Motivation
Enable privacy-preserving, adaptive learning for computer vision tasks directly on edge devices with real-time training capability.

## Method
TETRIS is an FPGA accelerator (programmable hardware that speeds up calculations) that trains instance segmentation models on edge devices while reducing computational and memory demands through quantization (converting high-precision numbers to lower-precision). It uses two quantization techniques: channel-aware smoothing quantization, which reduces precision while respecting patterns in the data, and distribution-aware tie quantization, which handles repeated values intelligently. The hardware uses different types of processors: a reconfigurable convolution processing unit (a specialized calculator for neural networks) that adjusts to variable kernel sizes and a fully pipelined auxiliary processing unit that processes operations in parallel stages.

## Key Novelty
TETRIS is the first FPGA accelerator specifically built to train instance segmentation models on resource-constrained edge devices.
