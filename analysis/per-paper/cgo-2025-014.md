# Scalar Interpolation: A Better Balance between Vector and Scalar Execution

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Compilers vectorize all loop iterations, but processors with distinct scalar and vector pipelines remain underutilized. Vectorization forces scalar operations to use vector registers, incurring data movement overhead.

## Technical Approach
Inserts scalar operations for entire sequential loop iterations into vectorized loops. Processes complete iterations in scalar form to avoid vector-scalar register moves. Uses static cost model or auto-tuning to determine interpolation factor.

## Key Novelty
First approach to balance vector and scalar pipeline utilization through strategic scalar operation interpolation.

## Key Results
- 30% speedup on Intel Xeon (x86) with static model
- 43% speedup on Kunpeng-920 (AArch64) with auto-tuning

## Hardware & Techniques
- **Target:** CPU (superscalar)
- **Techniques:** Vectorization, pipeline scheduling, auto-tuning
