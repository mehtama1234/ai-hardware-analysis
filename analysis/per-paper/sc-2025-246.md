# SC-2025-246: Open Composer - Web-Based HPC Job Management

**Democratizing HPC Access Through User-Friendly Interfaces**

## Summary
Open Composer is a web-based application that simplifies batch job submission and management on HPC clusters by eliminating the need for command-line expertise. Built on the Open OnDemand framework, it provides form-driven script generation with real-time preview and editing capabilities.

## Problem
HPC resources remain significantly underutilized due to:
1. **High Learning Curve**: Users must master Linux commands and job scheduler syntax (SLURM, PBS, etc.)
2. **Error Prone**: Manual script writing leads to syntax errors and misconfigurations
3. **Training Burden**: Support staff spend substantial time teaching basic submission procedures
4. **Access Barriers**: Non-computational users hesitate to use HPC due to technical complexity
5. **Inconsistent Practices**: Users develop idiosyncratic submission patterns without guidance

## Approach
### Architecture
- Built on Open OnDemand (widely adopted HPC web portal framework)
- Web-based UI for job composition and monitoring
- Backend integration with standard HPC schedulers (SLURM, PBS, etc.)
- Flexible parameter handling

### Key Features
1. **Form-Driven Script Generation**:
   - Application-specific web forms defining typical job parameters
   - Automatic shell script synthesis from form inputs
   - Customizable per-institution or per-application

2. **Real-Time Preview**:
   - Shows generated shell script as user fills form
   - Enables immediate detection of syntax issues
   - Builds user confidence in submission process

3. **Direct Script Editing**:
   - Users can hand-edit generated scripts
   - Maintains power-user flexibility
   - Bridges gap between GUI simplicity and CLI power

4. **Job Management**:
   - Unified submission interface
   - Real-time job status monitoring
   - Job history and resubmission

5. **Parameter Reuse**:
   - Save and reuse common job configurations
   - Templates for domain-specific workflows
   - Dynamic form widgets for complex scenarios

6. **Preprocessing Support**:
   - Setup steps before actual computation
   - Module loading, environment preparation
   - Data staging

## Key Contributions
1. **Accessibility Enhancement**: Reduces HPC barrier-to-entry for non-specialist users
2. **Error Reduction**: Form-driven generation eliminates common submission errors
3. **Unified Interface**: Combines job submission, monitoring, and management
4. **Backward Compatibility**: Built on standard Open OnDemand, works across diverse HPC centers
5. **Flexibility Preservation**: Manual editing ensures power users aren't constrained

## User Experience Innovation
### Bridging Novice-Expert Divide
Traditional HPC tools force users to choose:
- **Web portals** (e.g., Globus): Very user-friendly, but constrain power users
- **Command line** (SLURM): Maximum flexibility, steep learning curve

Open Composer bridges this by:
1. Guiding novices through form filling (no CLI knowledge needed)
2. Showing actual commands being generated (education component)
3. Allowing manual editing for power users (escape hatch)
4. Preserving familiar CLi interface (users learn by doing)

### Form-Driven Approach Benefits
- **Contextual Guidance**: Forms can include tooltips explaining parameters
- **Validation**: Form constraints prevent invalid combinations
- **Presets**: Application-specific forms encode best practices
- **Evolution**: Easy to update forms as requirements change
