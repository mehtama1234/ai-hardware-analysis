# Hypertron: Efficiently Scaling Large Models by Exploring High-Dimensional Parallelization Space

**Venue:** SC
**Paper ID:** sc-2025-010
**Confidence:** low

## Problem Statement
Large model training on parallel machines is inefficient due to limited parallelization strategy space; dense and sparse models with long context require diverse strategies

## Motivation
Model scale growing rapidly; existing strategies (data/tensor/pipeline parallelism) are sub-optimal; high-dimensional strategy exploration could unlock better scaling

## Method
Hypertron explores seven different ways to distribute model training work across multiple Ascend NPU accelerators, including approaches like splitting the model across devices, splitting training data across devices, and their combinations. It intelligently combines these seven dimensions and uses a performance model to predict which combination runs fastest while using the least memory and communication bandwidth. This approach supports both dense and sparse models with different context lengths.

## Key Novelty
By exploring all seven parallelization dimensions together, Hypertron finds optimal training strategies that existing frameworks cannot support, significantly reducing memory usage and communication overhead.
