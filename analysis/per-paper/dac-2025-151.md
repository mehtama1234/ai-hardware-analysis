# Late Breaking Results: A Diffusion-Based Framework for Configurable and Realistic Multi-Storage Trace Generation

**Authors:** Seohyun Kim, Junyoung Lee, Jongho Park, Jinhyung Koo, Sungjin Lee, Yeseong Kim  
**Venue:** DAC 2025

## Summary
DiTTO is a novel framework using diffusion models to generate realistic, configurable storage traces for multi-device systems. The approach captures temporal dynamics and inter-device dependencies while allowing users to specify trace characteristics, achieving generation with only 8% configuration errors.

## Key Contributions
- Diffusion-based framework for multi-storage trace synthesis
- Support for user-guided configuration in synthetic trace generation
- Capture of temporal dynamics and inter-device dependencies
- 8% configuration error rate

## Technical Approach
The framework leverages advanced diffusion generative models to synthesize high-fidelity continuous storage traces. It enables precise control over trace characteristics through user-defined configurations while maintaining alignment with real-world patterns.
