# Slicing Is All You Need: Towards A Universal One-Sided Algorithm for Distributed Matrix Multiplication

**ID:** sc-2025-051  
**Venue:** SC  
**Confidence:** high

## Problem
Existing distributed matmul algorithms limited to specific partitioning subsets; requires operator redistribution with communication costs

## Motivation
AI and scientific computing require flexible partitioning strategies; current algorithms fragment support across 1D/2D/1.5D/2.5D variants

## Method
The algorithm divides matrices into tiles and uses index arithmetic—calculations based on position—to identify which overlapping sections from different tiles must be combined. It runs on graphics processors using a PGAS C++ framework that creates a shared virtual memory space, allowing GPUs on the same machine to send data directly to each other. Because the algorithm calculates overlaps using position-based arithmetic rather than assuming a fixed partitioning pattern, it works with any way of dividing matrices without requiring data to be shuffled around.

## Key Novelty
Unlike existing algorithms that work only with specific partitioning patterns and require data redistribution, this algorithm uses index arithmetic to support any matrix partitioning scheme directly.

## Contributions
1. Develops universal partitioning-agnostic distributed matmul
2. Implements high-level PGAS framework
3. Competitive with PyTorch DTensor optimization
