## Method
DRAM-PIM (processing-in-memory) integrates small processors into DRAM itself, eliminating the usual bottleneck of moving data between memory and a separate CPU or GPU. DRIM-ANN optimizes approximate nearest-neighbor search (finding items similar to a query, not necessarily the closest match) for UPMEM's commercial DRAM-PIM hardware through tuning approximation levels to balance speed and accuracy, replacing expensive squaring math with pre-computed lookup tables, distributing work evenly across embedded processors (load-balancing), and minimizing data transfers (I/O optimization). This keeps computation and data together, avoiding the memory bottlenecks that slow CPUs and the capacity limits that constrain GPUs.

## Key Novelty
DRIM-ANN is the first approximate nearest-neighbor search system built for commercial DRAM-PIM hardware, with optimizations targeting the low-power embedded processors inside DRAM banks.
