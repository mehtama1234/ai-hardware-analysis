# EQSIM Agent: A Conversational AI for Interactive Exploration of Large-scale Earthquake Simulation Data

**ID:** sc-2025-345  
**Venue:** SC 2025  
**Authors:** Houjun Tang, David McCallen

## Problem & Motivation

Large-scale earthquake simulations produce **massive, high-fidelity datasets** essential for seismic risk analysis, but:
1. **Volume:** Terabyte-scale outputs
2. **Complexity:** Multidimensional spatial-temporal data
3. **Expertise gap:** Requires specialized knowledge to extract insights

Researchers from diverse backgrounds struggle to explore and analyze earthquake data without advanced programming skills.

## Solution: EQSIM Agent

An **LLM-based conversational AI** for interactive data exploration with three novel capabilities:

### 1. Natural Language Querying
- Users query data in natural language
- Results returned as text, images, videos, and maps
- No SQL or programming required

### 2. Vision-Based Waveform Similarity Search
- Visual pattern matching on seismic waveforms
- Find similar earthquake responses across simulations
- Novel feature for scientific discovery

### 3. Retrieval-Augmented Generation (RAG)
- Answers grounded in published literature
- Links results to relevant papers
- Provides scientific context

## Evaluation & Insights

Paper provides **practical analysis** of LLM performance for scientific contexts:
- Multiple LLM comparison (performance, cost, reliability)
- Tool-calling reliability assessment
- Challenges specific to scientific AI agents

## Results

EQSIM Agent enables **non-expert researchers** to explore earthquake simulations interactively, dramatically lowering barriers to seismic analysis.

## Implications

Demonstrates viability of conversational AI for scientific data exploration; provides blueprint for deploying LLMs in other scientific domains.
