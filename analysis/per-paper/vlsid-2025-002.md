# Fast Bit-Sliced VLSI Architectures on FPGA for Montgomery Domain Modular Inversion

**Venue:** VLSID
**Authors:** Soham Adhikary, Ayan Palchaudhuri

## Problem Statement
Modular inversion computation forms a crucial component in Elliptic Curve Cryptosystems

## Key Innovation
Novel propose approach

## Method
The approach uses a hardware circuit design (VLSI) implemented on an FPGA—a reconfigurable chip—to speed up Kaliski's Montgomery domain modular inversion algorithm. Bit-slicing is the key technique: each bit of the data is processed through parallel hardware paths, allowing many computations to run simultaneously. Montgomery domain is a number representation that trades one-time conversion work for much faster repeated multiplications during the algorithm's execution. This hardware-software combination significantly accelerates modular inversion, a crucial operation in elliptic curve cryptography.
