# A Geometry-Material Aware Point Cloud Transformer for Large-scale Unstructured Thermal Analysis in 2.5D ICs

**Venue:** ICCAD  
**Paper ID:** iccad-2025-259

## Problem Statement
Thermal management in large-scale unstructured 2.5D ICs requires modeling complex geometries and heterogeneous materials while maintaining memory efficiency.

## Motivation
Dense 2.5D integration creates multiscale thermal challenges; existing DL methods need efficient unstructured representation and material-aware adaptation.

## Method
Therm-PCT represents the 2.5D IC as a point cloud (scattered 3D points rather than a grid) and processes it with a transformer, a neural network designed to learn patterns in data. It combines three techniques: adaptive multipath-coupled diffusion (AMD) which simulates how heat flows through multiple pathways, wavelet-based fine-grained recovery (WFR) which captures fine-scale temperature variations, and thermal-aware Mixture-of-Material-Experts (TA-MoME) that routes predictions through specialized submodels trained for each material type.

## Key Novelty
A point-cloud transformer that routes predictions through material-specific expert submodels to predict thermal behavior in geometrically complex 2.5D integrated circuits.

## Contributions

1. 78–84% accuracy improvements over FSA-Heat
2. 147× speedup vs COMSOL
3. Zero-shot generalization to 5.7× larger point clouds
