# HIPPO: A Hierarchy-Preserving and Noise-Tolerant Pre-HLS Power Modeling Framework for FPGA

**Venue:** ICCAD  
**Confidence:** low

## Problem
Power estimation for custom FPGA accelerators from C/C++ requires invoking full EDA tool chains after high-level synthesis, creating large timing overheads that hinder early design optimization and limit iterative design space exploration.

## Motivation
Early power estimation enables faster design space exploration and optimization; pre-HLS analysis avoids expensive EDA tool invocation, enabling rapid prototyping of accelerator designs.

## Method
HIPPO estimates how much power an FPGA accelerator will consume by analyzing C/C++ source code directly, without waiting for the full synthesis process. It respects the code's natural structure—nested loops and operations at different levels—and builds power estimates that mirror this structure. The system converts the code into a hardware representation (a control/dataflow graph, tracking how data and operations connect), combines mathematical formulas with machine-learning models trained on real data, and filters out measurement noise through intelligent operation grouping. This multi-level approach lets designers estimate power during early design stages instead of waiting for expensive full synthesis runs.

## Key Novelty
HIPPO estimates FPGA power consumption from C/C++ code before synthesis using multi-level power models that preserve the code's hierarchical structure.

## Contributions
- Pre-HLS power modeling avoiding full EDA tool chain
- Hierarchy-preserving multi-level power estimation
- Code transformation to hardware-oriented dataflow
- 8.89% dynamic power error, 6.31% total power error for nested loops
