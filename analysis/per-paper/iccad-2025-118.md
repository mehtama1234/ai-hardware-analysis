# HIPPO: A Hierarchy-Preserving and Noise-Tolerant Pre-HLS Power Modeling Framework for FPGA

**Venue:** ICCAD  
**Confidence:** low

## Problem
Power estimation for custom FPGA accelerators from C/C++ requires invoking full EDA tool chains after high-level synthesis, creating large timing overheads that hinder early design optimization and limit iterative design space exploration.

## Motivation
Early power estimation enables faster design space exploration and optimization; pre-HLS analysis avoids expensive EDA tool invocation, enabling rapid prototyping of accelerator designs.

## Method
HIPPO operates directly on C/C++ programs with HLS pragmas, exploiting intrinsic code hierarchies (nested loops, operations). Multi-level power estimation aligns with different code hierarchies via: (1) code transformation to hardware-oriented control/dataflow graph, (2) hierarchy-preserving power modeling combining analytical and data-driven learning, (3) adaptive dataflow coarsening suppressing measurement noise.

## Key Novelty
Hierarchy-preserving power modeling framework operating pre-HLS on C/C++ code with multi-level estimation accuracy.

## Contributions
- Pre-HLS power modeling avoiding full EDA tool chain
- Hierarchy-preserving multi-level power estimation
- Code transformation to hardware-oriented dataflow
- 8.89% dynamic power error, 6.31% total power error for nested loops

## Limitations
