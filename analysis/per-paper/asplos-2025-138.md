# asplos-2025-138: pulse: Accelerating Distributed Pointer-Traversals on Disaggregated Memory

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
CPU-side caches in disaggregated memory architectures cannot amortize network latency for pointer-chasing workloads over linked data structures, because each traversal step depends on the preceding result, making prefetching and caching ineffective.

## Motivation
Disaggregated memory is increasingly deployed for rack-scale resource pooling, but pointer-intensive operations suffer from serial network round-trips that caching cannot hide.

## Method
pulse offloads pointer-chasing computations to processing elements co-located with disaggregated memory, supporting diverse linked data structures through a programmable traversal interface. Distributed execution across multiple memory nodes enables rack-scale workloads.

## Key Novelty
A near-data, distributed execution framework specifically designed to accelerate diverse pointer traversals over rack-scale disaggregated memory.

## Hardware Target
PIM (processing-in-memory)
