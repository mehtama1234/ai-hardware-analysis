# EFFACT: A Highly Efficient Full-Stack FHE Acceleration Platform

**Venue:** HPCA 2025  
**Authors:** Yi Huang, Xinsheng Gong, Xiangyu Kong, Dibei Chen, Jianfeng Zhu, Wenping Zhu, Liangwei Li, Mingyu Gao

## Problem
FHE suffers from massive ciphertext expansion (thousands of times over plaintext) and enormous off-chip memory bandwidth demands during bootstrapping and privacy-preserving ML inference, making it impractically slow on existing hardware.

## Motivation
FHE enables secure computation on encrypted data but its ciphertext blowup and compute intensity make practical deployment infeasible without specialized hardware that balances programmability, efficiency, and low area overhead.

## Method
EFFACT combines a compiler with vector-friendly hardware for both FPGA and ASIC. Streaming memory access overlaps data movement with NTT computation using limited on-chip SRAM. A circuit-level function unit reuse scheme reduces hardware resources. Novel NTT and automorphism units are designed for cost-sensitive area budgets. An ISA and compiler backend support CKKS, BGV, and BFV schemes.

## Key Novelty
Streaming memory access optimization enabling high NTT throughput with limited on-chip SRAM, combined with circuit-level function unit reuse that substantially reduces computing resources without performance degradation.

## Contributions
- Streaming memory access scheme for high throughput with small SRAM
- Circuit-level function unit reuse reducing area without performance loss
- Novel NTT and automorphism units for area-cost-sensitive implementations
- Full-stack design with ISA and compiler supporting CKKS, BGV, BFV on FPGA and ASIC

## Results
- **Throughput:** FPGA version 1.22x geomean over SOTA FPGA FHE accelerators
- **PPA:** ASIC improved performance/area and performance/Watt vs SOTA ASIC works

## Hardware Target
FPGA, ASIC
