# EFFACT: A Highly Efficient Full-Stack FHE Acceleration Platform

**Venue:** HPCA 2025  
**Authors:** Yi Huang, Xinsheng Gong, Xiangyu Kong, Dibei Chen, Jianfeng Zhu, Wenping Zhu, Liangwei Li, Mingyu Gao

## Problem
FHE suffers from massive ciphertext expansion (thousands of times over plaintext) and enormous off-chip memory bandwidth demands during bootstrapping and privacy-preserving ML inference, making it impractically slow on existing hardware.

## Motivation
FHE enables secure computation on encrypted data but its ciphertext blowup and compute intensity make practical deployment infeasible without specialized hardware that balances programmability, efficiency, and low area overhead.

## Method
EFFACT pairs a specialized compiler with custom hardware design (targeting both FPGA and ASIC) to accelerate Fully Homomorphic Encryption. The key optimizations are: (1) a streaming memory access scheme that continuously feeds data into calculations, achieving high throughput even with limited on-chip memory; (2) function unit reuse at the circuit level, letting the same hardware components handle multiple tasks without performance loss; and (3) custom hardware for Number Theoretic Transform operations (the mathematical calculations central to FHE) and automorphisms (operations that rearrange encrypted data). The compiler supports multiple FHE schemes—CKKS, BGV, BFV—and automatically determines optimal on-chip memory allocation.

## Key Novelty
EFFACT achieves high Number Theoretic Transform throughput with limited on-chip memory by streaming data sequentially (matching how encryption kernels naturally access information), combined with circuit-level function unit reuse that maintains performance while reducing hardware.

## Contributions
- Streaming memory access scheme for high throughput with small SRAM
- Circuit-level function unit reuse reducing area without performance loss
- Novel NTT and automorphism units for area-cost-sensitive implementations
- Full-stack design with ISA and compiler supporting CKKS, BGV, BFV on FPGA and ASIC

## Results
- **Throughput:** FPGA version 1.22x geomean over SOTA FPGA FHE accelerators
- **PPA:** ASIC improved performance/area and performance/Watt vs SOTA ASIC works

FPGA, ASIC
