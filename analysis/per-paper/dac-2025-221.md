# ClusterKV: Manipulating LLM KV Cache in Semantic Space for Recallable Compression

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Long-context LLM inference (32K+ tokens) incurs massive KV cache memory and latency; existing compression loses recall capability or uses coarse positional granularity.

## Key Insight
Semantic clustering enables fine-grained selective recall of KV tokens, maintaining accuracy while achieving high compression.

## Method
ClusterKV compresses the KV cache by grouping tokens that mean similar things (semantic clustering) and deciding which clusters to keep—rather than permanently erasing tokens or simply grouping by position in the text. When processing long contexts, it selectively recalls only the most relevant semantic clusters, shrinking the cache to a 1K–2K token budget even for 32K-token inputs. The system uses efficient algorithms for clustering tokens, selecting which ones matter, indexing them, and caching the results.

## Contributions
- Semantic-cluster-based recallable KV compression
- Efficient clustering/selection/indexing algorithms
- Negligible accuracy loss (1K–2K cache for 32K context)
- 2× latency speedup, 2.5× throughput improvement
- Higher quality vs. SOTA
