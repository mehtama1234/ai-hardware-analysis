# Fast Iterative Clock Skew Scheduling with Dynamic Graph Extraction

**Problem:** Sequential graph extraction dominates clock skew scheduling (CSS) runtime; full graph construction is unnecessary for timing optimization.

**Key Idea:** Use timing propagation to dynamically extract only necessary sequential graph edges during iterative CSS, reducing edge extraction by 90%.

**Approach:** Iterative algorithm with comprehensive skew calculation handling multiple clock latency constraints; slack optimization achieves target latencies discovered by skew analysis.

**Results:** 49.11× speedup vs. prior CSS, 27.01× speedup vs. state-of-the-art with superior slack improvement.

**Theme:** Fast clock skew scheduling through dynamic on-demand graph extraction.
