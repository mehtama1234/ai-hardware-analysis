# Automated Decoder Generation for Irregular Instruction Sets

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

Proposes information-theoretic decision tree algorithm for automated generation of instruction decoders, handling irregular ISA features including non-uniform opcodes and nested specializations. Successfully generates correct decoders for SPARC, MIPS32, and ARMv7.

## Key Contributions

- **Information-Theoretic Foundation**: Decision tree algorithm grounded in information theory concepts
- **Irregular ISA Support**: Handles non-uniform opcodes, complex logic propositions, nested specializations
- **Cost-Aware Optimization**: Generates decoders optimized for both correctness and performance/area
- **Proven Functionality**: Fully automated decoders for major ISAs (SPARC, MIPS32, ARMv7)

## Technical Focus

Applies machine learning-based decision tree generation to hardware decoder synthesis, moving beyond ad hoc tools to principled information-theoretic approach. Scales to complex ISAs with irregular structure.

## Relevance

**Keywords:** instruction-decoding, isa-design, decision-trees, automation, irregular-instructions
