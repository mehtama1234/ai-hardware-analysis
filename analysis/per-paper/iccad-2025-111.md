# Secure Token Pruning Mechanism and Accelerator for Vision Transformer

**Venue:** ICCAD  
**Confidence:** low

## Problem
Vision Transformers are vulnerable to adversarial patch attacks; existing defense strategies improve robustness but incur significant computational overhead, limiting practical deployment in security-critical applications.

## Motivation
Secure ViT deployment in critical applications requires efficient adversarial robustness; combining defense with efficiency enables edge deployment without sacrificing security.

## Method
STEM defense integrates Block-wise Selective Fusion (BSF) to fuse redundant and flag suspicious tokens, and Identify-Prune (IP) to remove adversarial tokens based on multi-head attention statistics. STEMA accelerator features dedicated Security Core with token fusion, top-k selection, and metadata engines (5% chip area).

## Key Novelty
Parallelizable token pruning defense combining selective fusion and statistical pruning with dedicated hardware accelerator occupying minimal chip area.

## Contributions
- 4.7× robustness improvement vs. token pruning methods
- 46.8-105.8× runtime speedup vs. defense baselines
- Up to 71× speedup via STEMA
- 397× energy efficiency improvement via accelerator
