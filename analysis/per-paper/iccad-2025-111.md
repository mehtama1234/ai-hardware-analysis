# Secure Token Pruning Mechanism and Accelerator for Vision Transformer

**Venue:** ICCAD  
**Confidence:** low

## Problem
Vision Transformers are vulnerable to adversarial patch attacks; existing defense strategies improve robustness but incur significant computational overhead, limiting practical deployment in security-critical applications.

## Motivation
Secure ViT deployment in critical applications requires efficient adversarial robustness; combining defense with efficiency enables edge deployment without sacrificing security.

## Method
STEM defends Vision Transformers against adversarial attacks by identifying and removing malicious image tokens (the discrete pieces the model processes). It combines Block-wise Selective Fusion, which groups tokens into blocks and merges redundant ones while flagging suspicious ones, with Identify-Prune, which removes flagged tokens based on the model's attention patterns (the internal calculations showing which tokens matter most). The defense runs on STEMA, a specialized hardware accelerator with a dedicated Security Core that performs token fusion, selects the top-k highest-priority tokens, and manages token metadata—using just 5% of the chip.

## Key Novelty
The core innovation is a parallelizable token-removal defense combining selective fusion with statistical adversarial detection, implemented with minimal dedicated hardware.

## Contributions
- 4.7× robustness improvement vs. token pruning methods
- 46.8-105.8× runtime speedup vs. defense baselines
- Up to 71× speedup via STEMA
- 397× energy efficiency improvement via accelerator
