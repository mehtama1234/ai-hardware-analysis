# Coflex: Enhancing HW-NAS with Sparse Gaussian Processes for Efficient and Scalable DNN Accelerator Design

**Venue:** ICCAD
**ID:** iccad-2025-138
**Confidence:** low

## Problem
Hardware-Aware Neural Architecture Search (HW-NAS) suffers from extensive search spaces and high computational costs, limiting practical adoption for DNN accelerator design.

## Motivation
Efficient HW-NAS enables automated co-optimization of neural networks and hardware for edge accelerator development.

## Method
Coflex combines a Sparse Gaussian Process (a model that learns from past accelerator designs to predict which new designs will work well) with multi-objective Bayesian optimization (a search algorithm that balances competing design goals). It simplifies the mathematical calculations from cubic to near-linear complexity, making the model much faster while keeping predictions accurate. This enables efficient exploration of large design spaces that would otherwise require prohibitive computational cost.

## Key Novelty
Sparse Gaussian Process combined with multi-objective Bayesian optimization reduces accelerator design search complexity from cubic to near-linear, making large-scale exploration practical.

## Contributions
- SGP-based HW-NAS framework with near-linear kernel complexity
- Multi-objective Bayesian optimization for hardware-aware architecture search
- 1.9x to 9.5x computational speed-up over state-of-the-art methods
- High network accuracy with improved Energy-Delay-Product
