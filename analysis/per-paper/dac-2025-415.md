# An Efficient Bit-level Sparse MAC-accelerated Architecture on FPGA

**Problem:** FPGA implementations lack effective bit-level sparsity support for MAC units compared to ASIC designs.

**Method:** The solution combines software and hardware design: the software creates an encoding (a way of representing numbers and data) tailored to work with FPGA lookup tables—the small memory blocks FPGAs use to implement logic—with adjustable sensitivity to detect zero bits. The hardware handles multiply-accumulate operations that take variable time depending on sparsity. This allows FPGAs to efficiently skip computing with zero bits while keeping results accurate.

**Key Result:** 2.2x smaller PEs vs bit-parallel; 1.04-1.74x speedup vs bit-parallel, 1.40-2.79x vs Booth designs.

**Hardware Target:** FPGA  
**Workloads:** CNN, vision, LLM-inference  
**Confidence:** low (abstract-only)
