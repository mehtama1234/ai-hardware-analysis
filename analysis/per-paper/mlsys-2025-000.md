# FlashInfer: Efficient and Customizable Attention Engine for LLM Inference Serving

**Problem:** LLM inference attention kernels cannot simultaneously handle heterogeneous KV-cache layouts, diverse attention variants, and CUDAGraph-compatible dynamic batching without significant performance loss.

**Method:** FlashInfer unifies different KV-cache layouts—ragged, paged, and tree-structured—through a single Block-Sparse Row (BSR) format, allowing all layouts to use the same computation path. It decomposes attention calculations into shared-prefix and unique-suffix portions, combining partial softmax results to reuse work across requests. For each attention variant (GQA, MLA, sliding-window), a JIT compiler generates optimized CUDA code templates once on first request, then reuses the compiled binaries for all subsequent requests. Finally, a load-balanced scheduler distributes computation work to GPU thread blocks using a priority queue, wrapped in a static layer to remain compatible with CUDAGraph (static CUDA execution graphs).

**Key novelty:** BSR as a single unifying KV-cache abstraction; CUDAGraph-compatible dynamic load balancing via priority-queue indirection.

**Metrics:**
- 29-69% inter-token latency reduction vs Triton compiler backends
- 28-30% latency reduction for long-context inference
- 13-17% speedup for parallel generation
