# FlashInfer: Efficient and Customizable Attention Engine for LLM Inference Serving

**Problem:** LLM inference attention kernels cannot simultaneously handle heterogeneous KV-cache layouts, diverse attention variants, and CUDAGraph-compatible dynamic batching without significant performance loss.

**Method:** Block-Sparse Row (BSR) format unifies paged/ragged/tree KV-cache layouts into one kernel path. Composable formats split shared-prefix from unique-suffix attention and merge partial softmax states. A JIT compiler instantiates CUDA templates per attention variant at first use. A load-balanced scheduler uses a priority-queue tile assignment that remains CUDAGraph-compatible via a static-size wrapper.

**Key novelty:** BSR as a single unifying KV-cache abstraction; CUDAGraph-compatible dynamic load balancing via priority-queue indirection.

**Metrics:**
- 29-69% inter-token latency reduction vs Triton compiler backends
- 28-30% latency reduction for long-context inference
- 13-17% speedup for parallel generation
