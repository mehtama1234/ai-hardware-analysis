# SAFELOC: Overcoming Data Poisoning Attacks in Heterogeneous Federated Machine Learning for Indoor Localization

**Venue**: DATE  
**Primary Theme**: federated learning for robust heterogeneous mobile localization  

## Problem
Indoor localization systems suffer from device heterogeneity (hardware/software variations across mobile devices) and ML data poisoning attacks, compromising both accuracy and model efficiency for deployment.

## Method
SAFELOC combines poisoning detection (identifying data deliberately corrupted to sabotage training) with indoor localization in a single neural network deployed across mobile devices using federated learning, so sensitive data never leaves the device. As training happens, it monitors for poisoning attacks, and when one is detected, it uses saliency maps—a technique that shows which parts of the model matter most—to adjust how much it trusts each device's updates. The stronger the detected attack, the more aggressively it filters out suspicious contributions.

## Key Novelty
SAFELOC's innovation is using saliency maps to intelligently combine federated learning updates from multiple devices, scaling its poisoning defenses proportional to detected attack severity while maintaining a model compact enough for mobile devices.

## Contributions
- Fused neural network architecture combining poisoning detection and localization in single model
- 5.9× improvement in mean localization error over SOTA
- 7.8× improvement in worst-case localization error
- 2.1× reduction in inference latency with compact model footprint
