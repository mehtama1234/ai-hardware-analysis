# SAFELOC: Overcoming Data Poisoning Attacks in Heterogeneous Federated Machine Learning for Indoor Localization

**Venue**: DATE  
**Primary Theme**: federated learning for robust heterogeneous mobile localization  

## Problem
Indoor localization systems suffer from device heterogeneity (hardware/software variations across mobile devices) and ML data poisoning attacks, compromising both accuracy and model efficiency for deployment.

## Method
SAFELOC combines a fused neural network performing concurrent poisoning detection and localization with federated learning, employing a dynamic saliency map-based aggregation strategy that adapts based on detected poisoning severity.

## Key Novelty
Dynamic saliency-map-driven federated aggregation that adapts poisoning defense to attack severity while maintaining model compactness.

## Contributions
- Fused neural network architecture combining poisoning detection and localization in single model
- 5.9× improvement in mean localization error over SOTA
- 7.8× improvement in worst-case localization error
- 2.1× reduction in inference latency with compact model footprint
