# Sphinx: A High-Performance Hybrid Index for Disaggregated Memory With Succinct Filter Cache

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Range indexes for disaggregated memory suffer from excessive network round trips during tree traversal and inefficient node caching.

## Method
Sphinx uses an **Inner Node Hash Table** to replace sequential tree traversal with parallel hash reads, and adds a **Succinct Filter Cache** to minimize network overhead while maintaining a small coherent cache.

## Key Novelty
Parallel hash-based traversal eliminates sequential network bottlenecks in distributed memory lookups.

## Results
- **7.3× speedup** on YCSB benchmark
