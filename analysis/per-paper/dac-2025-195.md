# Sphinx: A High-Performance Hybrid Index for Disaggregated Memory With Succinct Filter Cache

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Range indexes for disaggregated memory suffer from excessive network round trips during tree traversal and inefficient node caching.

## Method
Sphinx speeds up lookups by replacing sequential tree navigation—where you ask about one branch at a time and wait for each answer—with parallel hash reads. It uses an Inner Node Hash Table to check multiple branches at once, cutting down network round trips. A Succinct Filter Cache on the computing side further reduces network traffic by keeping track of which remote data locations are likely to contain your target, staying small and coherent.

## Key Novelty
An Inner Node Hash Table replaces sequential tree traversal (checking one branch at a time) with parallel hash lookups, eliminating network bottlenecks.

## Results
- **7.3× speedup** on YCSB benchmark
