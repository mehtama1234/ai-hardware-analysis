# QFactory: Accelerating Quantized Large Language Model Serving with Qtile Graphs

**Problem:** Quantized LLM inference suffers from suboptimal dataflow scheduling and kernel execution patterns that fail to fully exploit the performance benefits of quantization. Existing serving systems lack specialized compilation strategies for the unique compute and memory characteristics of quantized operations.

**Method:** QFactory creates a specialized diagram called Qtile Graphs that maps how quantized operations (reduced-precision math that runs faster) flow through the hardware. The compiler then uses this diagram to apply three key optimizations: combining related operations into single instructions (kernel fusion) to cut overhead, choosing the best order to run operations while moving the least data possible between memory and processors (memory-aware scheduling), and grouping operations into blocks sized for the hardware (operation tiling). These optimizations work together to use more of the hardware's computing power and reduce the time spent moving data during inference.

**Novelty:** Qtile Graphs are a specialized diagram format for quantized operations that automatically exposes where the compiler can combine operations, minimize data movement, and organize work into hardware-efficient blocks.
