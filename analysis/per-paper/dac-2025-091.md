# GEM: GPU-Accelerated Emulator-Inspired RTL Simulation

## Problem
CPU-based RTL simulators have poor scalability; FPGA emulators are expensive; prior GPU attempts failed because circuit heterogeneity conflicts with GPU's SIMT (Single Instruction, Multiple Thread) execution model.

## Method
GEM creates a virtual Very Long Instruction Word architecture (VLIW — a compact way to represent operations, inspired by FPGA emulator design) that runs on NVIDIA GPUs via CUDA. It maps circuit logic into this VLIW form using a CAD process (computer-aided design) based on FPGA place-and-route — the step that assigns circuit logic to physical locations and routes their connections. This solves two problems that prevented earlier GPU simulators from working: irregular memory access patterns (when threads access memory unpredictably) and thread divergence (when different threads take different execution paths), both of which severely reduce GPU efficiency.

## Key Innovation
First GPU RTL simulator using virtual VLIW architecture to reconcile heterogeneous circuits with SIMT execution.

## Contributions
- Virtual VLIW architecture for GPU-based RTL simulation
- Circuit-to-VLIW mapping flow (FPGA CAD-inspired)
- Mitigation of thread divergence and irregular memory access
- 64x speedup over best CPU simulators

## Motivation
Democratizing high-speed circuit verification with affordable GPU hardware accelerates design cycles.
