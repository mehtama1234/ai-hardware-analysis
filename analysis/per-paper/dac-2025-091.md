# GEM: GPU-Accelerated Emulator-Inspired RTL Simulation

## Problem
CPU-based RTL simulators have poor scalability; FPGA emulators are expensive; prior GPU attempts failed because circuit heterogeneity conflicts with GPU's SIMT (Single Instruction, Multiple Thread) execution model.

## Method
GEM introduces a virtual Very Long Instruction Word (VLIW) architecture inspired by FPGA emulator design, mapped from circuit logic using a CAD flow analogous to FPGA place-and-route. This bridges circuit heterogeneity with GPU parallelism, reducing thread divergence and irregular memory access.

## Key Innovation
First GPU RTL simulator using virtual VLIW architecture to reconcile heterogeneous circuits with SIMT execution.

## Contributions
- Virtual VLIW architecture for GPU-based RTL simulation
- Circuit-to-VLIW mapping flow (FPGA CAD-inspired)
- Mitigation of thread divergence and irregular memory access
- 64x speedup over best CPU simulators

## Motivation
Democratizing high-speed circuit verification with affordable GPU hardware accelerates design cycles.
