# A Complete Modeling Methodology for Full-chip Parasitic Extraction

**Paper ID:** iccad-2025-239  
**Venue:** ICCAD

## Problem

As process nodes shrink, on-chip parasitics become increasingly critical, but comprehensive methodology for full-chip parasitic extraction considering shielding effects and process variations is lacking. Existing extractors (OpenRCX, PEX) are incomplete on multiple metrics.

## Motivation

Modern advanced-node designs require accurate parasitic extraction across full chips to ensure timing, power, and signal integrity; incomplete extraction methods limit design accuracy.

## Method

The system extracts parasitic effects—unwanted electrical interference that slows down circuits—across an entire chip using four complementary techniques. These include geometric shielding patterns in three designs to isolate wires, a fast data structure to efficiently identify candidate interfering signals, timing simulation to find which interference actually affects circuit behavior (versus just being theoretically possible), and a model of how manufacturing variations alter wire resistance.

## Key Novelty

The core innovation is being the first methodology to comprehensively extract parasitic effects across an entire chip while realistically accounting for wire shielding, manufacturing variations, and which interference actually occurs.

## Contributions

- Ring structure geometric distribution with multiple pattern types for shielding modeling
- STR tree and event-based sweeping for efficient aggressor identification
- Process-aware resistivity modeling using fixed metal density approach
- Systematic benchmark framework for parasitic extraction evaluation
