# A Two-level SLC Cache Hierarchy for Hybrid SSDs

**Venue**: DATE  
**Primary Theme**: hierarchical SLC cache for hybrid SSD performance  

## Problem
Triple-level-cell (TLC) NAND flash memory suffers lower write performance and endurance compared to single-level-cell (SLC); hybrid SLC-TLC SSDs use SLC as write cache but existing cache management schemes do not effectively optimize granularity and cold/hot data separation.

## Method
The paper proposes a two-level cache system using SLC (single-level-cell, faster but more expensive memory) in front of TLC (triple-level-cell, slower but cheaper memory). The two levels operate at different chunk sizes: L2 (the lower level) works with large chunks of data, while L1 (the upper level) works with small chunks, allowing each level to process data efficiently at its own scale. The system monitors how applications write data and automatically adjusts how much cache space goes to each level based on the typical chunk size each application uses, rather than using a fixed allocation. The design is then compared against existing SLC cache management schemes.

## Key Novelty
A two-level SLC cache where each level handles different chunk sizes and the division of cache space automatically adjusts based on how each application actually writes data.

## Contributions
- Two-level SLC cache hierarchy design with fine and coarse granularity tiers
- Dynamic cache segmentation strategy based on workload write patterns
- 12.6%-25.1% I/O performance improvement over existing hybrid SSD cache schemes
