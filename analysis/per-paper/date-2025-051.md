# A Two-level SLC Cache Hierarchy for Hybrid SSDs

**Venue**: DATE  
**Primary Theme**: hierarchical SLC cache for hybrid SSD performance  

## Problem
Triple-level-cell (TLC) NAND flash memory suffers lower write performance and endurance compared to single-level-cell (SLC); hybrid SLC-TLC SSDs use SLC as write cache but existing cache management schemes do not effectively optimize granularity and cold/hot data separation.

## Method
Proposes two-level SLC cache hierarchy (L1 and L2) with varying data granularity (coarse L2, fine L1). Implements dynamic segmentation of L1 and L2 cache capacity based on write size characteristics of running applications. Evaluates against existing SLC cache schemes.

## Key Novelty
Hierarchical two-level SLC cache with dynamic granularity management and application-aware cache partitioning for SLC-TLC hybrid SSDs.

## Contributions
- Two-level SLC cache hierarchy design with fine and coarse granularity tiers
- Dynamic cache segmentation strategy based on workload write patterns
- 12.6%-25.1% I/O performance improvement over existing hybrid SSD cache schemes
