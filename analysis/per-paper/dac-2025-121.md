# Construction of DAG Models for Autonomous Systems

**Venue:** DAC | **ID:** dac-2025-121

## Core Problem
Constructing optimal DAG task models for autonomous systems (vehicles, drones) to minimize end-to-end response time in time-triggered task chains.

## Method
Representation semantics for time-triggered tasks + topology optimization method achieving 4.8x response time reduction (O(n²) complexity).

## Key Novelty
First systematic study of DAG model construction (vs. scheduling) with optimized topology for autonomous systems.

## Contributions
- First DAG construction work (not scheduling) for autonomous systems
- Representation semantics for time-triggered blended task chains
- 4.8x response time speedup over Floyd algorithm
- O(n²) complexity for dynamic tasks
