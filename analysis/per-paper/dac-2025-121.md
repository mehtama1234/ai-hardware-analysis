# Construction of DAG Models for Autonomous Systems

**Venue:** DAC | **ID:** dac-2025-121

## Core Problem
Constructing optimal DAG task models for autonomous systems (vehicles, drones) to minimize end-to-end response time in time-triggered task chains.

## Method
The method defines how to represent and organize task chains in autonomous systems (vehicles, drones) where tasks must run at specific times and pass data between each other. It applies topology optimization—a technique that reorganizes task connections to minimize end-to-end latency (the total time from the first task starting to all dependent tasks completing)—achieving 4.8x faster results than the simpler Floyd algorithm. The approach has O(n²) complexity (computation grows quadratically with task count) and adapts to systems where tasks change dynamically.

## Key Novelty
This is the first systematic study of how to construct optimal task graphs (rather than just schedule them) for autonomous systems with time-triggered tasks, using topology optimization.

## Contributions
- First DAG construction work (not scheduling) for autonomous systems
- Representation semantics for time-triggered blended task chains
- 4.8x response time speedup over Floyd algorithm
- O(n²) complexity for dynamic tasks
