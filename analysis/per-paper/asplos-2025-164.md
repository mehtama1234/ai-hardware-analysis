# QECC-Synth: A Layout Synthesizer for Quantum Error Correction Codes on Sparse Architectures

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
QEC codes require dense qubit connectivity not matched by sparse hardware coupling graphs, and existing QEC compilation approaches either underutilize QEC circuit structure or rely on manual, architecture-specific designs that do not generalize.

## Motivation
Fault-tolerant quantum computing requires efficient QEC code implementation on real sparse hardware, but the connectivity mismatch is a fundamental barrier to scalable FTQC.

## Method
QECC-Synth automatically arranges quantum error correction circuits on quantum computers with limited qubit connections. It works by inserting extra helper qubits (called ancillas) that relay information between distant qubits, then uses mathematical optimization (MaxSAT—a technique for finding the best solution among many possibilities) to determine the best placement and routing for these helpers. The system systematically explores all the different ways to set up these helpers and selects the combination that works best for a given error-correction pattern and hardware architecture. This approach works for different types of quantum hardware and different error-correction codes (like surface code or color code) without requiring manual customization.

## Key Novelty
The core idea is treating quantum circuit arrangement on limited-connection hardware as a mathematical optimization problem (MaxSAT) solved over all possible helper-qubit placements, enabling automated solutions that work across hardware types and error-correction patterns.

## Contributions
- Systematic classification of ancilla bridge design space flexibilities for QEC circuits
- MaxSAT-based QEC layout synthesis enabling global optimization over ancilla placement
- QECC-Synth compiler demonstrating generality across diverse QEC codes and architectures
- Significant outperformance of existing QEC compilation methods
