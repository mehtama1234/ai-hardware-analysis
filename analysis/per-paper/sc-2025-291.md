# A Data-Size Adaptive Approach to I/O of Poorly Load Balanced In Situ Data Extracts

**Venue:** SC 2025  
**Authors:** Caitlin Ross, Scott Wittenburg, Greg Eisenhauer, Corey Wetterer-Nelson

## Problem Statement
In situ visualization pipelines in scientific simulations often encounter load imbalance where different processes generate vastly different output data volumes. Traditional aggregation strategies group writers by compute node, creating bottlenecks when some nodes have much larger subfiles than others.

## Technical Approach
**Data-Size Based Aggregation:**
- Abandons assumption that ADIOS2 writers are grouped by compute node
- Dynamically partitions writers based on per-process data volume
- Aims to balance resulting subfile sizes across aggregators
- Integrates with ADIOS2 BP5 engine

**Implementation Strategy:**
- Analyzes each process's output size
- Regroups writers to equalize subfile sizes
- Minimal changes to existing ADIOS2 infrastructure

## Evaluation
**Test Scenarios:**
- Low load imbalance
- Severe load imbalance (synthetic workloads)

**Results:**
- Matches or outperforms existing node-based aggregation strategies
- Demonstrates robustness across imbalance levels

## Benefits
- Improved I/O throughput under load imbalance
- Better resource utilization across aggregators
- Applies to any in situ pipeline using ADIOS2 BP5

## Limitations & Future Work
- Evaluation on synthetic workloads only; real production simulation needed
- Scalability beyond tested system size unclear
- Dynamic partitioning overhead not quantified
- Interaction with other ADIOS2 features (compression, filters) not explored
- Memory overhead for partitioning algorithm not discussed
