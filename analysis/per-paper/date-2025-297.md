# BIMAX: A Bitwise In-Memory Accelerator Using 6T-SRAM Structure

**Venue**: DATE  
**Primary Theme**: Noise-robust in-memory bitwise accelerator  

## Problem
SRAM-based in-memory computing has limited operations and unreliable accuracy due to environmental noise and process variations.

## Method
BIMAX performs bitwise logic operations (AND, OR, NOT, XOR, NAND, NXOR) and row-copy directly within 6T-SRAM cells using a specially modified sense amplifier—the circuit normally used to read bits from memory. By designing this sense amplifier with intentional asymmetry (making one input path stronger than the other), it can compute logic results when comparing multiple cell values in parallel, instead of just reading them. The computed results are then written back to memory, enabling logic gates and data copying to happen inside the SRAM array itself.

## Key Novelty
The core innovation is designing the sense amplifier asymmetrically (with one input path intentionally stronger) so it can reliably compute bitwise logic operations in standard 6T-SRAM cells despite electrical noise.

## Contributions
- 52.7% lower energy dissipation vs state-of-the-art IMC
- 5.7% higher average performance rate
- 5.4× improved noise robustness against environmental variations
