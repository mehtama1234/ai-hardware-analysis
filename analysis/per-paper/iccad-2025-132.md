# MF-MOR: Multi-Fidelity Model Order Reduction for Many-Port Linear Systems in Chip Power Modeling

**Venue:** ICCAD  
**ID:** iccad-2025-132

## Problem
Reducing systems with millions of nodes and tens of thousands of I/O ports is extremely difficult; existing projection-based MOR techniques offer only partial solutions for many-port systems.

## Motivation
Efficient model order reduction for 3DIC power modeling is critical for advanced package design and validation.

## Method
Multi-fidelity ML strategy combining aggressive port reduction followed by conventional MOR (PRIMA) for low-fidelity ROM, high-fidelity time-domain simulation for limited samples, compensation network trained to bridge gap, tensorized mapping technique capturing port correlations for efficient learning.

## Key Novelty
Multi-fidelity approach combining reduced-order model with learned compensation network for many-port systems.

## Contributions
- Multi-fidelity MOR strategy for many-port linear systems
- Tensorized mapping technique capturing port and transient correlations
- Scalable approach for large-scale chip power modeling
