# Routability-aware Packing for High-density Nonvolatile FPGAs

**ID**: dac-2025-438  
**Venue**: DAC  
**Confidence**: low

## Problem
NVFPGAs with MLC NVMs achieve high logic density but suffer from severely degraded CLB intra-routability, causing long packing times in CAD flow.

## Motivation
High-density FPGAs require fast CAD turnaround; packing bottlenecks block design iteration.

## Method
During the packing stage (where logic pieces are grouped into blocks), the approach reassigns which lookup tables (LUTs—small memory blocks that implement logic) are paired together within each block to reduce routing congestion (overuse of routing wires). Because lookup tables in MLC-based FPGAs (nonvolatile FPGAs using multi-level-cell memory for higher density) can be functionally equivalent—the same logic can work from different positions—the method can quickly explore different pairings. By re-pairing LUT assignments instead of doing full block re-placement, it keeps wire usage down without completely redesigning block positions.

## Key Novelty
The approach reduces congestion by re-pairing lookup table assignments to match MLC routing topology, avoiding the cost of full block re-placement.

## Contributions
- Routability-aware LUT re-pairing algorithm
- MLC LUT structural equivalence exploitation
- Reduction in packing time by 41.48% average
- Maintains output quality while improving CAD flow speed
