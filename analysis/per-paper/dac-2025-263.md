# ESM: Surrogate Models for Hardware-Aware Neural Architecture Search

**Venue:** DAC | **ID:** dac-2025-263

## Problem
Hardware-aware NAS depends on accurate surrogate models to predict DNN performance (latency, energy) on target devices, but building reliable predictors requires systematic understanding of design factors.

## Key Innovation
Holistic ESM framework analyzing critical factors across the entire surrogate model pipeline (data generation, model selection, training) for GPU-powered hardware-aware NAS.

## Method
The team tested different types of prediction models (called surrogate models) to see which ones most accurately estimate how fast neural networks run on GPUs. They examined every step of the process—how training data is collected, which model type to choose, and how to train it—to understand what actually matters for accurate predictions. They built the ESM framework as a systematic toolkit that helps you generate reliable training data and automatically pick or build the best prediction model while keeping computational costs in mind.

## Scope
- **Focus:** GPU-powered latency prediction
- **Models:** Various surrogate model architectures
- **Pipeline stages:** Dataset generation, model selection, training

## Contributions
- Comprehensive analysis of hardware-aware latency prediction
- Identification of critical design factors
- Practical ESM framework for NAS
- Cost-aware optimization guidelines

## Hardware Target
GPU

## Techniques
Compiler design, dataflow optimization

## Workloads
CNNs, transformers

## Limitations
Evaluation primarily on GPUs; applicability to TPU, NPU, ASIC not addressed.
