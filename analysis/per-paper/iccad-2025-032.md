# Enabling Decoder-only Language Model Inference on a CNN Accelerator

**ID:** iccad-2025-032  
**Venue:** ICCAD

## Problem
CNN accelerators cannot efficiently run decoder-only language models due to non-computational operations in attention (head merging/splitting, transpositions), lack of floating-point support for Softmax and RMSNorm, and memory-bound operations during generation that degrade throughput.

## Motivation
Reusing existing CNN accelerators for NLP avoids high cost of dedicated NLP hardware while leveraging already-deployed commercial infrastructure.

## Method
The paper adds three small modifications to existing CNN accelerators (chips optimized for visual processing) to enable them to run transformer language models. First, it modifies how the accelerator handles multi-head attention (where the same computation runs on different slices of data) to avoid requiring dedicated hardware for data rearrangement. Second, it adds a lightweight processor that performs non-linear operations like Softmax and RMSNorm (functions that squeeze and normalize values during transformer computations). Third, it optimizes power efficiency during the generation phase, when the system is waiting for data from memory rather than performing intensive calculations.

## Key Novelty
By adding three targeted hardware modifications to handle attention data-rearrangement, non-linear math, and memory efficiency, standard CNN accelerators can efficiently run modern transformer language models.

## Contributions
1. Efficient multi-head attention execution without dedicated reshaping hardware
2. Lightweight SIMD coprocessor design for nonlinear operations
3. Power-efficiency techniques for memory-bound generation stage
4. Demonstration that low-power CNN accelerators achieve GPU-comparable NLP inference throughput
