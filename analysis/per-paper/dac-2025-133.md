# Unlocking a New Rust Programming Experience: Fast and Slow Thinking with LLMs to Conquer Undefined Behaviors

**Venue:** DAC | **ID:** dac-2025-133

## Core Problem
Eliminating Undefined Behaviors in Rust's 'unsafe' code; manual UB detection requires deep expertise and is laborious.

## Method
RustBrain leverages LLMs with dual-process thinking: Fast thinking extracts features and generates solutions; Slow thinking verifies and generalizes; feedback mechanism enables dynamic adjustment.

## Key Novelty
LLM-based dual-process thinking for flexible, adaptive Rust UB minimization.

## Contributions
- RustBrain LLM framework for automated UB minimization
- Fast-Slow thinking with verification and generalization
- Feedback mechanism for dynamic adjustment
- 94.3% pass rate; 80.4% execution on Miri dataset
