# Unlocking a New Rust Programming Experience: Fast and Slow Thinking with LLMs to Conquer Undefined Behaviors

**Venue:** DAC | **ID:** dac-2025-133

## Core Problem
Eliminating Undefined Behaviors in Rust's 'unsafe' code; manual UB detection requires deep expertise and is laborious.

## Method
RustBrain uses a large language model (LLM—a machine learning system trained on vast text) to find and fix undefined behaviors in Rust 'unsafe' code. It employs two complementary thinking modes inspired by cognitive science: a 'fast thinking' phase that quickly identifies code patterns and proposes fixes, and a 'slow thinking' phase that carefully breaks down those proposals, verifies whether they work, and generalizes them (adapts them to similar patterns). A feedback loop connects verification and generalization results back to generation, so each cycle improves the system's future proposals.

## Key Novelty
It applies dual-process thinking (a cognitive science framework where the mind uses both quick intuition and careful deliberation) through a large language model to identify and fix undefined behaviors in Rust code.

## Contributions
- RustBrain LLM framework for automated UB minimization
- Fast-Slow thinking with verification and generalization
- Feedback mechanism for dynamic adjustment
- 94.3% pass rate; 80.4% execution on Miri dataset
