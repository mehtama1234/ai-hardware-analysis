# BrokenSleep: Remote Power Timing Attack Exploiting Processor Idle States

**Venue:** HPCA 2025  
**Authors:** Hyosang Kim, Ki-Dong Kang, Gyeongseo Park, Seungkyu Lee, Daehoon Kim

## Problem
Modern processors support multiple C-state idle levels with different wake-up latencies; an attacker can remotely detect which C-state a victim core is in by measuring network response timing, enabling covert and side-channel communication across nodes without co-location on the same machine.

## Motivation
Prior power-based side-channel attacks require attacker and victim to share the same physical machine, but C-state wake-up latency differences are observable through network-level timing measurements, dramatically expanding the attack surface to distributed systems.

## Method
BrokenSleep exploits deterministic wake-up latency differences between processor C-states (C0 active, C1/C1E/C6 sleep) to encode information in network response timing. The attacker sends requests and measures response latency to deduce the victim's current C-state. Both covert channel (data exfiltration without direct network access) and side-channel (keystroke timing inference) variants are demonstrated. The attack works on standard ACPI power management without requiring any microarchitectural vulnerability.

## Key Novelty
The first remote timing attack based purely on CPU C-state wake-up latency differences, eliminating the co-location requirement of all prior power-based side-channel attacks.

## Contributions
- BrokenSleep: first remote covert and side-channel attack exploiting C-state wake-up latency
- Covert channel for data exfiltration to remote machines without direct network access
- Keystroke timing inference via remote C-state observation
- Cross-architecture validation on both Intel and ARM processors

## Results
- Demonstrated remote covert channel and keystroke timing inference on Intel and ARM CPUs across an external network

## Hardware Target
CPU (Intel and ARM)

## Baselines
Prior local power side-channel attacks requiring co-location

## Limitations
Covert channel bandwidth and error rate are not quantified in the abstract; mitigation strategies are not discussed.
