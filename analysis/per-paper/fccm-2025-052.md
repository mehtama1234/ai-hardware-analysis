# Moyogi: A Memory-Centric Accelerator for Low-Latency Random Forest Inference on Embedded Devices

**Problem:** Random Forest inference on resource-constrained embedded devices must maintain low latency as model size grows; state-of-the-art memory-centric approaches suffer from latency degradation with increasing RF complexity.

**Method:** Proposes a hardware-software codesign framework that optimizes memory-centric Random Forest inference by exploring Decision Trees of multiple depths and various architectural configurations. Employs a resource estimation model based on architectural features to guide Design Space Exploration for identifying optimal configurations for a given RF model.

**Novelty:** Hardware-software codesign framework that optimizes memory-centric RF inference through systematic exploration of DT depths and architectural variations guided by a resource estimation model.
