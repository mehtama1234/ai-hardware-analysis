# Moyogi: A Memory-Centric Accelerator for Low-Latency Random Forest Inference on Embedded Devices

**Problem:** Random Forest inference on resource-constrained embedded devices must maintain low latency as model size grows; state-of-the-art memory-centric approaches suffer from latency degradation with increasing RF complexity.

**Method:** Designs the hardware accelerator and software together to run Random Forest inference (making predictions using decision-tree ensembles) efficiently on embedded devices by organizing computation around memory access patterns. Tests different configurations: varying the depth of individual decision trees and trying different hardware designs, using a resource estimation model to predict how much computing hardware each option needs. Systematically explores these combinations to find which one delivers the fastest prediction time for a given Random Forest model.

**Novelty:** Co-optimizing decision tree structure and hardware architecture using resource estimates to achieve low-latency Random Forest inference on embedded devices.
