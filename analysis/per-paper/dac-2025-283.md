# dac-2025-283: MHDiff—Focal Pixel Quantization for Efficient Diffusion

**Problem:** Diffusion accelerators with mixed-precision differential quantization require high memory access to load raw inputs; memory bottleneck and poor hardware utilization.

**Motivation:** Diffusion models dominate generative tasks; reducing memory bandwidth and improving PE utilization is critical.

**Method:** Identify focal pixels at first layer, finetune across all layers. High-precision for focal, low-precision for others. Packing merges low-precision into full high-precision matrices for efficient PE processing.

**Key Novelty:** Focal pixel aware quantization with packing to full matrices, reducing memory burden and improving hardware utilization.

**Contributions:**
- Focal pixel identification reducing memory overhead
- Packing for efficient PE array processing
- Negligible quality loss
