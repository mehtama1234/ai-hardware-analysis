# UPVSS: Jointly Managing Vector Similarity Search with Near-Memory Processing Systems

**Venue:** DAC
**ID:** dac-2025-226

## Problem
Vector similarity search is bandwidth-bound in CPU-based systems; DRAM bandwidth becomes the critical bottleneck as data scales, limiting throughput in recommendation systems and LLM deployments.

## Motivation
Modern applications (LLMs, recommendations) demand efficient similarity search; conventional von Neumann architectures cannot saturate compute due to memory bandwidth limitations.

## Method
Offloads similarity search to UPMEM near-memory processing units, distributing computation close to data to reduce core-to-memory data movement and maximize UPMEM's parallelism through architecture-aware workload distribution.

## Key Novelty
Architecture-aware integration of vector search with UPMEM's distributed PIM capabilities to overcome bandwidth bottlenecks.

## Contributions

- UPMEM-aware vector similarity search system (UPVSS)
- Intelligent operation prioritization for PIM vs CPU
- Bandwidth-efficient data movement reduction
- System-level performance improvements for real-world search workloads
