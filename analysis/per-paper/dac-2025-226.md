# UPVSS: Jointly Managing Vector Similarity Search with Near-Memory Processing Systems

**Venue:** DAC
**ID:** dac-2025-226

## Problem
Vector similarity search is bandwidth-bound in CPU-based systems; DRAM bandwidth becomes the critical bottleneck as data scales, limiting throughput in recommendation systems and LLM deployments.

## Motivation
Modern applications (LLMs, recommendations) demand efficient similarity search; conventional von Neumann architectures cannot saturate compute due to memory bandwidth limitations.

## Method
The system moves similarity search computation to UPMEM units—processors built into or adjacent to memory chips—instead of doing it on the CPU. This avoids the data-movement bottleneck: since the search runs where the data already lives, far less data has to travel between memory and the processor. The system divvies up search tasks across multiple UPMEM processors based on their architecture and capabilities, keeping all of them busy to maximize total computing power.

## Key Novelty
Optimizing vector similarity search for UPMEM's in-memory processor architecture—rather than trying to run it on the CPU—eliminates the data-movement bottleneck.

## Contributions

- UPMEM-aware vector similarity search system (UPVSS)
- Intelligent operation prioritization for PIM vs CPU
- Bandwidth-efficient data movement reduction
- System-level performance improvements for real-world search workloads
