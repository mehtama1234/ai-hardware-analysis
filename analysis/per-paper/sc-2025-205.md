# SlimPipe: Memory-Thrifty and Efficient Pipeline Parallelism for Long-Context LLM Training

**Venue:** SC  
**Theme:** LLM Training Optimization  
**Confidence:** low

## Problem Statement
Pipeline parallelism for long-context LLMs faces severe activation memory pressure from multi-microbatch accumulation and pipeline bubbles limiting MFU efficiency

## Motivation
Long-context LLM training requires extreme parallelism; reducing memory overhead while minimizing bubbles is critical for efficient training on limited GPU memory

## Methodology
Uniform sequence slicing partitioning context into smaller chunks; 1F1B schedule with workload redistribution balancing computation imbalance from causal attention

## Key Novelty
First to enable pipeline parallelism for extreme long contexts (2M tokens); combines sequence slicing with intelligent workload redistribution

## Contributions
- Uniform sequence slicing constraining activation memory to single microbatch
- Workload redistribution balancing causal attention imbalance
- Near-zero memory overhead for activation management
- 1.57x MFU improvement vs SOTA at 512K context; 45% MFU sustained on 256 GPUs for 2M context
