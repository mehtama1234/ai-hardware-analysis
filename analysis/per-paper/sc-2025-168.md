# Bridging Speed and Optimality in Job Scheduling: A Hybrid Ant Colony Optimization Approach for Distributed Systems

**Venue:** SC

## Problem
Job scheduling in distributed systems suffers from exponential complexity; trade-off between speed (heuristics) and optimality (solvers) is fundamental

## Motivation
Bridge the speed-optimality gap for scalable job scheduling in distributed systems

## Method
The approach uses ant colony optimization (an algorithm inspired by how ants find efficient paths by marking promising routes) initialized with a good starting solution from the queue. It represents job scheduling constraints as disjunctive graphs (networks showing which jobs can run simultaneously and which must wait). It then refines the solution through parallel local search on subgraphs (testing small schedule variations across different parts of the network at the same time) while OR-Tools (an optimization library) handles the complex mathematical optimization.

## Key Novelty
The core idea is combining fast heuristic scheduling with rigorous optimization techniques, achieving 5-10x speedup while solutions remain only 3-5% worse than the theoretical optimal.

## Contributions
- HACO algorithm design with strategic pheromone initialization and local search
- Disjunctive graph formulation for precedence and resource constraints
- Evaluation on JSSP, FJSP, and synthetic large-scale problems showing scalability
