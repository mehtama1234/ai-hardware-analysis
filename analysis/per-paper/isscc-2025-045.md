# isscc-2025-045: Shape-Aware 3D GS Processor

**Title:** 1.78mJ/Frame 373fps 3D GS Processor Based on Shape-Aware Hybrid Architecture Using Earlier Computation Skipping and Gaussian Cache Scheduler

**Venue:** ISSCC

**Core Problem:**
3D Gaussian Splatting rendering on edge devices is bottlenecked by variable Gaussian shapes requiring complex mixed dataflow, input-dependent redundant computations, and irregular memory access for spherical-harmonic storage.

**Method:**
Shape-aware hybrid processor that detects input properties, skips/early-terminates redundant work, and uses intelligent caching for Gaussian parameters to minimize off-chip traffic.

**Key Innovation:**
Input-dependent computation skipping + cache-aware scheduling for Gaussian coefficients.

**Metrics:**
- **Throughput:** 373 fps (58x over Xavier NX @ 6.4fps)
- **Energy:** 1.78 mJ/frame
- **Target:** Edge AI (VR, embodied AI)

**Architecture:** Shape-aware hybrid ASIC with computation skipping & Gaussian cache scheduler

**Techniques:** Dataflow optimization, sparsity exploitation, memory-system design, approximation

**Confidence:** Low (abstract-only analysis)
