# FlexStep: Enabling Flexible Error Detection in Multi/Many-core Real-time Systems
**Venue:** DAC

## Problem
Traditional error detection (e.g., LockStep) requires pre-configured checker cores and static regions, causing over-provisioning and reducing real-time performance in systems with mixed reliability requirements.

## Motivation
Safety-critical real-time systems need flexible resource allocation between reliability and performance; rigid error detection reduces schedulability.

## Method
FlexStep integrates hardware microarchitecture supporting dynamic core reconfiguration with OS scheduling layer; enables asynchronous, preemptive error detection via lightweight hardware support and OS-level task scheduling policies.

## Key Novelty
First systematic hardware-software co-design enabling flexible, dynamic error detection adapted to per-task reliability needs.

## Contributions
1. Dynamic core configuration and asynchronous error detection
2. Flexible task scheduling with heterogeneous reliability requirements
3. Improved resource efficiency and real-time schedulability
