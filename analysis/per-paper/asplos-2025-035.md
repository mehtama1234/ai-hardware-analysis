# Energy-aware Scheduling and Input Buffer Overflow Prevention for Energy-harvesting Systems

**ID:** asplos-2025-035  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Energy-aware scheduling with IBO prevention for energy-harvesting IoT devices

## Problem
Energy-harvesting IoT devices capture data at a fixed rate but process it at a dynamically varying rate determined by available ambient power; when capture rate exceeds processing rate the fixed-size input buffer overflows and events are permanently lost, and no existing dynamic solution prevents this across varying energy and workload conditions.

## Motivation
Missed events in energy-harvesting sensor systems (e.g., wildlife monitors, structural sensors) are unrecoverable, making input buffer overflow (IBO) prevention a hard correctness constraint that static scheduling and prior runtime systems cannot satisfy under dynamic environmental variability.

## Method
Quetzal combines a simple hardware power-measurement circuit with scheduling software. The scheduler decides which job to run by calculating the total time needed—including how long for the battery to recharge—not just the job's execution time. Before running a job, software uses queueing theory (mathematical models for how fast items pile up in queues) to predict whether incoming data will arrive faster than the job can process it; if overflow is about to happen, the system intentionally makes the job simpler or shorter to speed up processing and prevent data loss.

## Key Novelty
The system prevents data loss on devices powered by ambient energy by combining three coordinated techniques—predicting buffer overflow using queue models, choosing jobs based on available power, and automatically simplifying jobs when overflow threatens—all made possible by a simple hardware power meter.

## Contributions
- Energy-aware scheduler that minimizes end-to-end latency by accounting for energy recharging time in job selection.
- Runtime IBO prediction using queueing theory to proactively detect impending buffer overflows.
- Job degradation mechanism that reduces processing load when overflow is imminent.
- Reduction of missed events due to IBO by up to 4.2x versus baseline schedulers.
