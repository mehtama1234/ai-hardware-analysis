# dac-2025-240: From Flatland to Forest: Exploring Pareto-optimal Design through RTL Hierarchy Trees

## Summary
Proposes RTL hierarchy-aware design space exploration by introducing a hierarchy-preserving kernel that directly compares RTL architectures. Uses module importance from synthesis reports and clustering to identify distinct patterns for efficient parallel evaluation.

## Key Idea
Replace flat parameter-vector DSE with hierarchy-aware kernels that exploit structural patterns inherent in RTL designs.

## Contributions
- RTL hierarchy-aware kernel preserving structural characteristics
- Weighted kernel extension using synthesis-derived module importance
- Clustering for architectural pattern identification
- Evaluation on Gemmini RISC-V SoC

## Limitations
Scalability to large/complex designs not demonstrated.
