# SC-2025-195: RISC-V Accelerator for Cross-Section Lookup

**Venue:** SC 2025  
**Authors:** Andrew Ledbetter, Kazutomo Yoshii, John R. Tramm  
**Confidence:** low (abstract only)

## Summary

Custom RISC-V accelerator integrated in Chipyard for neutron cross-section lookups in Monte Carlo transport simulations, achieving 10x wall-clock speedup through specialized hardware for Doppler broadening.

## Hardware Target

- RISC-V architecture
- Custom accelerator (integrated with RocketCore)
- Chipyard simulation environment

## Problem & Motivation

Monte Carlo neutron transport for high-fidelity nuclear reactor simulations bottlenecked on neutron cross-section lookups. Doppler broadening requires expensive Faddeeva function computation. Explore RISC-V accelerator potential for HPC through custom extension design.

## Approach

1. **Custom Accelerator Design:** Pipelined RISC-V accelerator for cross-section lookups
2. **Faddeeva Computation:** Humlídek 8th-order rational approximation
3. **Integration:** RocketCore in Chipyard simulation framework
4. **Validation:** RSBench benchmark performance comparison
5. **Baselines:** Software RISC-V and Intel Core i5 Tiger Lake-U

## Key Contributions

1. Custom RISC-V accelerator design for neutron transport
2. Faddeeva function speedup: 17x cycle reduction
3. Inner loop speedup: 34.2x
4. Overall: 10x wall-clock time improvement
5. Competitive with Intel Core i5 Tiger Lake-U
6. Demonstrates Chipyard utility for HPC accelerator research
7. Validates RISC-V for specialized HPC workloads

## Limitations

Focus on single kernel; operating frequency optimization incomplete; scalability to additional kernels not addressed; energy/power analysis missing.
