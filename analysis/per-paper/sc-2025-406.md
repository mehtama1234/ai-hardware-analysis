# Applying Surrogate Modeling to Decouple Data Collection and Analysis from Simulation for Accelerated In-Situ Analysis

**Venue:** SC
**ID:** sc-2025-406
**Confidence:** low

## Problem
Traditional in-situ analysis is tightly coupled to simulation timesteps, degrading performance and limiting adaptive control of analysis quality.

## Motivation
Decoupled analysis enables asynchronous processing and early termination decisions; surrogate models can reduce simulation overhead while maintaining accuracy.

## Method
Online surrogate modeling trained on early-stage simulation data; trained models replace simulation for targeted in-situ analysis enabling asynchronous operation.

## Key Novelty
First decoupled in-situ analysis via online surrogate modeling; 1.20-3.51x speedup with 83.33-99.60% accuracy retention.

## Contributions
1. Online surrogate model training during early simulation stages
2. Asynchronous in-situ analysis decoupled from simulation
3. Early termination decisions without pretraining or manual tuning
4. 1.20-3.51x speedup with high accuracy retention
