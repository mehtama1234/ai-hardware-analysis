# Applying Surrogate Modeling to Decouple Data Collection and Analysis from Simulation for Accelerated In-Situ Analysis

**Venue:** SC
**ID:** sc-2025-406
**Confidence:** low

## Problem
Traditional in-situ analysis is tightly coupled to simulation timesteps, degrading performance and limiting adaptive control of analysis quality.

## Motivation
Decoupled analysis enables asynchronous processing and early termination decisions; surrogate models can reduce simulation overhead while maintaining accuracy.

## Method
The approach trains a predictive model on data collected during the early stages of a simulation run. This model learns to approximate what the full simulation would compute, so analysis tasks can run independently rather than waiting for each simulation timestep. By decoupling analysis from simulation, the system avoids the performance slowdown that comes from tightly synchronizing these two operations.

## Key Novelty
A predictive model trained from early simulation data decouples in-situ analysis from simulation steps, achieving 1.20-3.51x speedup while maintaining 83.33-99.60% accuracy.

## Contributions
1. Online surrogate model training during early simulation stages
2. Asynchronous in-situ analysis decoupled from simulation
3. Early termination decisions without pretraining or manual tuning
4. 1.20-3.51x speedup with high accuracy retention
