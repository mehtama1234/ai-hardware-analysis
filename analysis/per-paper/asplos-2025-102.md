# asplos-2025-102: Affinity-based Optimizations for TFHE on Processing-in-DRAM

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
Fully Homomorphic Encryption over the Torus (TFHE) is compute- and bandwidth-intensive; when mapped to Processing-in-Memory (PIM/HBM) architectures, existing accelerators over-exploit parallelism at the expense of data affinity, causing excessive remote data accesses (RDAs) that degrade performance due to PIM's limited inter-bank communication bandwidth.

## Motivation
PIM architectures offer high internal bandwidth that can dramatically accelerate TFHE, but the workload's affinity patterns must be respected to avoid the remote-access bottleneck that nullifies bandwidth advantages.

## Method
TFHE consists of three core operations—bootstrapping, key-switching, and FFT operations—that the paper restructures so data accessed together is stored in the same processing-in-memory vault or bank. An offline scheduler analyzes which data operands are used together and how frequently, then determines the optimal operation order to minimize remote data accesses (fetches across memory banks) while maintaining sufficient parallelism. The approach was tested on a modified existing processing-in-memory device with minimal hardware changes and validated on an FPGA-based processing-in-memory system emulator.

## Key Novelty
The core idea is applying affinity-aware offline scheduling to TFHE so that operations sharing data run on the same processing-in-memory unit, minimizing remote data accesses.

## Contributions
- Analysis of data affinity patterns in TFHE sub-tasks on PIM architectures.
- An offline affinity-aware scheduler that minimizes RDAs while maintaining parallelism.
- Algorithmic restructuring of TFHE to expose better data locality on PIM.
- 4.24x to 209x speedup over prior TFHE accelerators on real-world benchmarks.
