# A Multimodal AI Acceleration with Dynamic Pruning and Run-Time Configuration

**Problem:** Multimodal AI workloads spanning vision transformers, GNNs, CNNs, and transformer-based NLP have diverse computational requirements, making it challenging for embedded acceleration platforms to efficiently handle all of them. Fixed hardware designs cannot be optimal across this heterogeneity.

**Method:** The system proposes an FPGA-based framework with compile-time and run-time configurability. It introduces a reconfigurable processing unit (RPU) capable of executing dense and sparse matrix operations (DDMM, SpMM, SDDMM), a scalable top-k pruning engine for Vision Transformers, and a domain-specific compiler for hardware-software co-design. The architecture enables real-time configuration without reloading bitstreams, allowing unified deployment across different AI tasks.

**Novelty:** Runtime reconfigurability of FPGA hardware without bitstream reloading enables unified support for heterogeneous multimodal AI workloads.
