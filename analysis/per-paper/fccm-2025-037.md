# A Multimodal AI Acceleration with Dynamic Pruning and Run-Time Configuration

**Problem:** Multimodal AI workloads spanning vision transformers, GNNs, CNNs, and transformer-based NLP have diverse computational requirements, making it challenging for embedded acceleration platforms to efficiently handle all of them. Fixed hardware designs cannot be optimal across this heterogeneity.

**Method:** The system builds an FPGA (a programmable chip) with a reconfigurable processing unit that can perform both dense and sparse matrix operations, plus a pruning unit to trim calculations in Vision Transformers. A compiler translates each AI task into hardware configuration, and the FPGA can reconfigure at runtime without reloading. This allows one chip to efficiently run diverse AI models—vision, graphs, language—without being completely reprogrammed between tasks.

**Novelty:** An FPGA that reconfigures itself at runtime without reloading can efficiently support diverse AI workloads on a single chip.
