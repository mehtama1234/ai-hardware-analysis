# GSIM: Accelerating RTL Simulation for Large-Scale Designs

**Problem:** Software RTL simulation exhibits high computational overhead across multiple abstraction levels, slowing design exploration and verification of complex processors.

**Key Idea:** Optimize RTL simulation across three levels simultaneously: supernode-level for high-level logic, node-level for gates, and bit-level for bitwise operations.

**Approach:** Multi-level optimization with efficient data structures and scheduling; demonstrated on XiangShan RISC-V processor.

**Results:** 7.34× speedup for Linux boot, 19.94× for CoreMark on Rocket vs. Verilator.

**Theme:** Hierarchical RTL simulation acceleration for rapid processor design iteration.
