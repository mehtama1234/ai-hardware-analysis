# hpca-2025-013 — ChameleonEC: Exploiting Tunability of Erasure Coding for Low-Interference Repair

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Erasure coding repair traffic contends with foreground I/O over shared network bandwidth, slowing repair and degrading service quality. Existing mechanisms lack dynamic adaptability to changing foreground traffic and stragglers.

## Motivation
At scale, erasure code repair bandwidth increasingly threatens both availability and application latency, requiring adaptive co-scheduling with foreground traffic.

## Method
ChameleonEC breaks the repair process into small tasks and assigns them to unused network bandwidth, avoiding interference with regular traffic. It dynamically adjusts how data flows across these tasks in real time. When it detects slow nodes (stragglers), it rearranges which repair tasks go where and adapts transmission speeds to bypass them. The system was implemented and evaluated on Amazon EC2.

## Key Novelty
The key idea is that repair can adapt in real time to network conditions and slow nodes by flexibly rerouting and rescheduling repair tasks, without modifying the erasure code (the redundancy algorithm).

## Contributions
- Identification of repair/foreground traffic entanglement as the key bottleneck.
- Repair task assignment saturating idle bandwidth without foreground contention.
- Elastic multi-path repair routing across tasks.
- Straggler-aware re-scheduling; 4.9-498.2% repair acceleration on Amazon EC2.
