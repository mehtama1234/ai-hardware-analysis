# Accelerating Intra-Node GPU Communication: A Performance Model for Multi-Path Transfers

**Venue:** SC
**ID:** sc-2025-321
**Confidence:** low

## Problem Statement
GPU-to-GPU intra-node communication bottleneck in MPI applications; unclear how to optimally distribute P2P transfers across multiple communication paths.

## Motivation
Multi-path GPU communication (via NVLink, PCIe, etc.) can improve throughput if routed optimally; MPI+UCX currently lacks guidance for path selection.

## Method
Performance model for intra-node multi-path GPU communication: considers link bandwidth, pipeline overhead, stream synchronization to identify optimal path distribution for P2P transfers.

## Key Novelty
Analytical performance model for multi-path GPU communication that accurately predicts optimal configurations with <6% error.
