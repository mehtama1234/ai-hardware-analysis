# Accelerating Intra-Node GPU Communication: A Performance Model for Multi-Path Transfers

**Venue:** SC
**ID:** sc-2025-321
**Confidence:** low

## Problem Statement
GPU-to-GPU intra-node communication bottleneck in MPI applications; unclear how to optimally distribute P2P transfers across multiple communication paths.

## Motivation
Multi-path GPU communication (via NVLink, PCIe, etc.) can improve throughput if routed optimally; MPI+UCX currently lacks guidance for path selection.

## Method
When GPUs in the same computer send data to each other, they can use multiple communication paths simultaneously. This model predicts how fast data will actually move by accounting for the speed of each communication link (link bandwidth), the delay cost of managing multiple data flows (pipeline overhead), and the need to coordinate different data streams so they don't interfere with each other (stream synchronization). By understanding these factors, it determines the best way to split up the data transfer across available paths to minimize total transfer time.

## Key Novelty
The key insight is a mathematical model that accurately predicts the fastest way to split GPU data transfers across multiple paths—within 6% accuracy.

3. Increased throughput via intelligent path distribution
