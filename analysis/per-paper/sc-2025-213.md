# sc-2025-213: Assessing Page Reclamation Mechanisms for Linux

## Overview
Comprehensive analysis of Linux page reclamation policies (2QLRU vs MGLRU) using lightweight profiling to measure decision overhead and effectiveness.

## Key Problem
Understanding page reclamation decision-making and effectiveness remains challenging. Need to quantify trade-offs between MGLRU and 2QLRU under various memory constraints.

## Approach
Develop lightweight profiler to instrument decision overhead and reclamation effectiveness. Test on seven diverse applications under various memory constraint scenarios.

## Key Findings
- MGLRU makes better reclamation decisions despite higher decision overhead
- Performance benefits of MGLRU diminish under severe memory constraints
- Trade-offs between decision cost and reclamation quality

## Contributions
- Lightweight profiling methodology for page reclamation analysis
- Quantitative comparison of MGLRU vs 2QLRU
- Practical guidance for memory management optimization

## Hardware Target
Linux systems (servers, HPC nodes)
