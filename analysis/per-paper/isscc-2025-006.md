# isscc-2025-006: D-Band Active Reflective Relay with Fast AoA Detection

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
Sub-THz relays for 6G NLOS links currently operate open-loop; existing AoA detection methods require lossy down-/up-mixers, tunable phase shifters with stability issues, or narrow AoA range—limiting adaptive beam steering.

## Approach
**4×4 active reflective relay** (D-band) with:
- Orthogonally polarized on-chip TX/RX dual-polarization antennas
- **In-front-end common-centroid AoA detection** for fast azimuth + elevation tracking
- Scalable 2D relay array architecture
- Adaptive beam steering without digital backend overhead

## Key Contribution
In-front-end AoA detection enables on-the-fly angle tracking, eliminating open-loop limitations and lossy mixer overhead in sub-THz relays.

## Performance
- Frequency: D-band (110-170 GHz)
- Array: 4×4 elements, 2D-scalable
- Detection: Azimuth + elevation AoA
- Integration: On-chip TX/RX antennas
