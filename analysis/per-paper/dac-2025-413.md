# STREAMINGGS: Voxel-Based Streaming 3D Gaussian Splatting

**Problem:** 3D Gaussian Splatting on mobile devices achieves only 2-9 FPS vs required 90 FPS; DRAM bandwidth is the primary bottleneck, not compute.

**Method:** STREAMINGGS replaces tile-centric rendering (loading all Gaussian blob data first, then selecting which tiles need them) with memory-centric rendering (streaming Gaussian groups and loading only the tiles each group affects). The algorithm and hardware work together using fine-grained pipelining—overlapping different tasks so the GPU stays busy while waiting for memory. This dramatically reduces wasted DRAM transfers and lets the mobile GPU's memory system predict and fetch data more efficiently.

**Key Result:** 45.7x speedup, 62.9x energy savings vs Ampere GPU.

**Hardware Target:** GPU  
**Workloads:** vision, diffusion  
**Confidence:** low (abstract-only)
