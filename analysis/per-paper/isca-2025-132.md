# Resource Analysis of Low-Overhead Transversal Architectures for Reconfigurable Atom Arrays

**Venue:** ISCA  
**Confidence:** high (full text)

## Problem
Fault-tolerant quantum computation on neutral atom arrays using standard lattice-surgery gate schemes requires O(d) syndrome extraction (SE) rounds per logical gate, where d is the code distance, leading to run times of years for large-scale algorithms such as 2048-bit RSA factoring. Existing resource estimates do not account for transversal gates that reduce SE overhead to O(1) rounds per gate, nor do they provide detailed architectural layouts and logical error models for such schemes.

## Motivation
Neutral atom arrays uniquely support dynamically-reconfigurable connectivity and block-level optical control (transversal gates), enabling O(d) logical clock speedup over lattice-surgery baselines, but no complete large-scale architecture with resource estimates had been demonstrated.

## Method
The approach breaks down the quantum algorithm (2048-bit factoring as the test case) into specialized building blocks—magic state factories that prepare T-state magic states for 8T-to-CCZ distillation, ripple-carry adders using Cuccaro gadgets with CCZ teleportation, and quantum lookup tables via GHZ-state-assisted CNOT fan-out—each built using surface-code transversal gates (gates where syndrome extraction doesn't require additional rounds beyond the operation itself). Atoms are moved using optical tweezers with pipelined ancilla measurement to keep movement distances bounded (at most √2·d·l per step, where d is code distance). The team calibrated a logical error model against MLE decoder simulations, finding that transversal CNOTs introduce noise requiring a decoding correction factor of roughly 1/6. Finally, space-time trade-offs using bridge qubits and time-optimal scheduling minimize total computation work while keeping syndrome extraction constant per operation.

## Key Novelty
Using transversal gates (gates where syndrome extraction stays constant with code distance) on neutral atom arrays, this work provides the first complete architectural design with detailed subroutine layouts and a calibrated logical error model that achieves 50x speedup for 2048-bit RSA factoring through correlated decoding.

## Contributions
- Space-time-efficient transversal implementations of magic state factories, quantum adders, and quantum look-up tables with explicit 2D physical layouts minimizing atom move distances and decoding volume.
- Heuristic logical error model for transversal gate circuits, capturing elevated noise via decoding factor α, validated against MLE decoder numerical data.
- Full resource estimation framework for 2048-bit Shor's factoring: 19 million qubits, 5.6 days at 1 ms QEC cycle time — 50x run-time speedup over lattice-surgery baselines with no space increase.
- Sensitivity analysis over physical error rates, decoder performance (α), atom acceleration, reaction time, and qubit count constraints, plus a hybrid qLDPC code storage extension.
