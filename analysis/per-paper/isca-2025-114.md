# isca-2025-114 — DS-TPU: Dynamical System for on-Device Lifelong Graph Learning with Nonlinear Node Interaction

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Electronic Dynamical System (DS) hardware achieves orders-of-magnitude speed and energy improvements over GNNs for graph inference via natural annealing, but it (1) lacks native on-device training support—forcing reliance on slower conventional hardware for model updates—and (2) restricts node interactions to linear functions, limiting expressiveness and training accuracy.

## Motivation
Graph learning on dynamical systems promises radical efficiency gains, but the inability to train natively and the restriction to linear node dynamics prevent DS hardware from replacing conventional GNN accelerators in continually-updating, real-world deployments.

## Method
DS-TPU introduces two algorithmic-architectural co-design innovations. First, an on-device lifelong learning mechanism uses feedback electric current as a native loss signal in response to observed training data, enabling electron-speed model parameter refinement directly on the DS chip without off-chip software. Second, nonlinear DS node interactions are constructed from Chebyshev polynomial expansions, making the DS hardware compatible with the richer relational structure in graph data while remaining implementable in analog hardware. The DS-TPU architecture is evaluated at a 5-Watt power envelope on six real-world graph learning benchmarks.

## Key Novelty
On-device lifelong learning via feedback electric current as a loss function, combined with Chebyshev polynomial nonlinear node interactions, enabling native training on an electronic Dynamical System chip.

## Contributions
- On-device lifelong learning mechanism using feedback electric current as loss for native DS hardware training.
- Nonlinear DS node interaction model based on Chebyshev polynomial expansions to improve compatibility with graph data structure.
- DS-TPU architecture achieving 810x training speedup over offline DS training on NVIDIA A100 GPU and 640x over GNN training on A100.
- 10.8% MAE reduction over five state-of-the-art GNNs across six real-world graph learning applications.

## Metrics
- **Speedup:** 810x over offline DS training on A100 GPU; 640x over GNN training on A100 GPU
- **Power:** 5-Watt power envelope
- **Accuracy:** 10.8% MAE reduction over best of five GNNs on six graph learning tasks
