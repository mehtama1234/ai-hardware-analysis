# sc-2025-041: Design and Implementation of a Custom Hardware Accelerator for SZx Compression in Chipyard

## Summary
Designs and implements a custom hardware accelerator for SZx (streaming scientific data compression) using Chipyard HDL framework. Achieves 1.45x speedup over software with 31% fewer cycles and 45% faster throughput.

## Problem
- Data movement is dominant bottleneck in modern systems
- Scientific data generation rates exploding:
  - X-ray detectors: terabytes/second
  - High-energy physics: petabytes/second
- Streaming compression promising but hardware-level exploration lacking

## Method
1. **Design**: SZx compression in Chisel HDL (Chipyard)
2. **Architecture**:
   - Multi-stage state machine
   - Parallel element processing
   - Optimized data transfer paths
3. **Evaluation**: Chipyard simulation
4. **Comparison**: Software baseline measurement

## Key Innovations
1. **Hardware accelerator**: First for SZx compression
2. **System integration**: Complete end-to-end acceleration (CPU + accelerator)
3. **Design methodology**: Modern HDL approach enabling rapid prototyping
4. **Streaming focus**: Optimized for continuous high-throughput compression

## Hardware Targets
- CPU-based platforms with custom accelerator interface
- Chipyard FPGA simulation
- Potential future ASIC implementation

## Performance
- **Speedup vs. software**: 1.45x
- **Cycles per element**: 31% reduction
- **Compression throughput**: 45% faster
- **Compression quality**: Comparable to software
