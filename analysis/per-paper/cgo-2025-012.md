# xDSL: Sidekick Compilation for SSA-Based Compilers

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Compiler researchers choose between cumbersome prototyping in production compilers vs. building new prototypes requiring significant engineering to transition. Bridging this gap enables faster research cycles.

## Technical Approach
Introduces sidekick compiler frameworks: multiple interoperable frameworks using textual interchange formats and declarative IR descriptions. Each specializes for specific use cases. xDSL demonstrates this as MLIR sidekick using shared textual IR and IRDL dialect.

## Key Novelty
First sidekick compiler framework paradigm enabling seamless interoperability between specialized compilers via textual IR.

## Key Results
- Demonstrated on three use cases: teaching, DSL compilation, rewrite systems
- Simplified prototype-to-production transition
- Shared abstractions across frameworks

- **Target:** General (compiler infrastructure)
- **Techniques:** Compiler design, DSL, framework interoperability
