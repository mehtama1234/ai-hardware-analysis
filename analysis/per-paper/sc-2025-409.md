# SC-2025-409: LCI - Lightweight Communication Interface for Async Multithreaded Communication

## Summary
LCI is a communication library designed for efficient asynchronous multithreaded communication in HPC environments, providing a threading-efficient runtime that outperforms traditional multi-process execution models.

## Problem
Modern HPC architectures and programming models increasingly require asynchronous, multithreaded communication patterns, but existing communication libraries (primarily MPI) are optimized for multi-process execution rather than multithreaded scenarios.

## Method
- **Threading-efficient runtime**: Built on atomic data structures and fine-grained non-blocking locks
- **Low-level network insights**: Leverages direct understanding of network behavior
- **Diverse completion mechanisms**: Supports polling, callbacks, and event-driven patterns
- **Flexible resource controls**: Enables incremental tuning of communication resources

## Key Results
- Significantly outperforms existing communication libraries in multithreaded scenarios
- Performance exceeds traditional multi-process execution mode
- Evaluated on both Infiniband and Slingshot-11 clusters
- Microbenchmarks and application-level evaluations provided

## Hardware Target
- HPC clusters with Infiniband interconnects
- Systems with Slingshot-11 networks
- Multi-core processors with shared memory
- NUMA-aware systems

## Application Domain
