# asplos-2025-174: DeepContext: A Context-aware, Cross-platform, and Cross-framework Tool for Performance Profiling and Analysis of Deep Learning Workloads

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing DL profiling tools fail to bridge the semantic gap between high-level Python/framework operations and low-level GPU execution, making it difficult to identify root-cause performance bottlenecks across the full software stack. No existing tool provides correlated context-aware profiling spanning Python, DL frameworks, C/C++ libraries, and GPU kernels simultaneously.

## Motivation
Performance optimization of DL models requires holistic visibility across heterogeneous software and hardware layers, but current profilers provide only siloed views that leave critical cross-stack bottlenecks hidden.

## Method
DeepContext uses an interceptor—a monitoring layer that watches operations without modifying them—placed between the deep learning framework and C/C++ libraries to record each operation and match it with GPU performance data and the Python code that triggered it. Without changing the framework code itself, this approach traces high-level operations directly to the GPU instructions that executed them. An automated analyzer then examines these linked traces to identify which layers are causing slowdowns and recommend optimizations.

## Key Novelty
A framework-agnostic interceptor that automatically links Python operations down through the framework and libraries to GPU execution, exposing exactly where performance bottlenecks occur in the entire software stack.

## Contributions
- Framework-agnostic shim layer enabling cross-stack correlation of DL program context with hardware performance metrics
- Automated performance analyzer providing actionable optimization guidance from holistic stack-wide profiling data
- Cross-platform and cross-framework support with low overhead on mainstream DL frameworks and CPU+GPU architectures
- Discovery and fixing of previously hidden bottlenecks achieving 1.06x to 1.66x speedups on real-world DL applications
