# IDEA-GP: Instruction-Driven Architecture with Efficient Online Workload Allocation for Geometric Perception

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Robotic geometric perception tasks (SLAM, Structure from Motion) involve diverse and dynamically varying computational operators — including point cloud registration, pose graph optimization, bundle adjustment, and feature matching — whose workload fluctuates with environment and task, preventing static mapping to specialized accelerators and causing poor resource utilization.

## Motivation
Robotic autonomy requires real-time localization and 3D mapping on constrained edge platforms, but the diversity of spatial-positioning operators and runtime variability of geometric workloads make conventional fixed-function accelerators or CPU/GPU solutions either inflexible or too power-hungry.

## Method
IDEA-GP is an FPGA (a reconfigurable hardware chip that can be reprogrammed after manufacturing) containing an array of general-purpose processing units designed for the 3D math needed in robotics—rotation matrices, quaternions, and coordinate transformations. A compiler watches what computations are happening at runtime and dynamically sends instructions to assign each processing unit sub-problems, like solving linear equations or optimizing pose graphs. Because the assignment happens through instructions rather than being fixed at hardware design time, the same processor array can efficiently handle both SLAM's varied operations (incremental position tracking and loop-closure detection) and Structure from Motion's operations (camera position optimization and point triangulation) without rebuilding the hardware. The system is deployed on a Xilinx ZCU102 evaluation board.

## Key Novelty
A compiler that dynamically assigns different geometric-perception operators to the same processor array at runtime using instructions, rather than requiring hardware reconfiguration for each task type—achieving high resource efficiency despite changing workloads.

## Contributions
- IDEA-GP accelerator architecture: a unified PE array designed for spatial-positioning representations supporting diverse robot pose-related computations.
- Online compiler that performs runtime workload analysis and emits instructions to dynamically allocate PE resources across heterogeneous geometric operators.
- Demonstrated 7.5x speedup over Intel CPU and 19.7x over ARM CPU on SLAM tasks, and 16.4x over Intel CPU and 41.6x over ARM CPU on SfM tasks on ZCU102.
