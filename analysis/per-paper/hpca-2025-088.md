# hpca-2025-088 — Interleaved Logical Qubits in Atom Arrays

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Neutral atom quantum computers require physical qubit movement to perform two-qubit gates, which introduces an unavoidable latency bottleneck and may eliminate quantum advantage in fault-tolerant computations. Existing surface code architectures in atom arrays are movement-dependent and do not scale efficiently.

## Motivation
As neutral atom platforms move toward fault-tolerant regimes, qubit movement latency becomes a fundamental speed constraint, making movement-free quantum error correction (QEC) architectures critical for achieving practical quantum speedup.

## Method
The paper proposes a movement-free QEC architecture based on interleaved surface code groups using dual-species neutral atom arrays. Within a group, transversal CNOTs are executed at high fidelity by leveraging asymmetric interaction strengths: interspecies interactions decay as 1/r^3 (long-range) while intraspecies decay as 1/r^6 (short-range). Between groups, interleaved lattice surgery creates high-capacity routing channels for logical qubit communication. The architecture is validated through numerical circuit simulations and benchmarked via compilation of key quantum algorithms.

## Key Novelty
A movement-free fault-tolerant quantum architecture for neutral atom arrays that exploits dual-species asymmetric interaction scaling to enable transversal CNOTs within interleaved surface code groups.

## Contributions
- Identification that qubit movement in neutral atom arrays sets an unavoidable speed bottleneck for quantum computation
- Movement-free interleaved surface code architecture achieving approximately 3x compute time reduction in high-parallelism regimes
- Interleaved lattice surgery for high-capacity inter-group logical qubit routing
- Tolerance analysis showing the architecture admits 1x-3x error rate increases while maintaining fault-tolerance benefits
