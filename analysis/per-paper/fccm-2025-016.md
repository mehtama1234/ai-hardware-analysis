# Ph.D. Project: An Efficient NTT Accelerator Supporting Various Lengths for HHE

**Problem:** Hybrid Homomorphic Encryption (HHE) performance is bottlenecked by the efficiency of Number Theoretic Transform (NTT) operations. Supporting variable-length NTT efficiently across different HHE schemes on FPGA requires architectural innovations to avoid per-length redesign.

**Method:** The paper designs a specialized computing chip (FPGA) that speeds up the Number Theoretic Transform (NTT)—a mathematical operation central to homomorphic encryption, which enables computation on encrypted data. Rather than building different hardware for each NTT size, the design reuses the same computational units flexibly across different sizes and different types of homomorphic encryption. This approach is more efficient than traditional designs because it avoids duplicating expensive hardware components.

**Novelty:** A single NTT accelerator hardware design that works across different transform sizes and different types of homomorphic encryption, without needing separate hardware for each size.
