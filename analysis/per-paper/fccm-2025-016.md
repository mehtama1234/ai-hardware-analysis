# Ph.D. Project: An Efficient NTT Accelerator Supporting Various Lengths for HHE

**Problem:** Hybrid Homomorphic Encryption (HHE) performance is bottlenecked by the efficiency of Number Theoretic Transform (NTT) operations. Supporting variable-length NTT efficiently across different HHE schemes on FPGA requires architectural innovations to avoid per-length redesign.

**Method:** The paper proposes an FPGA-based NTT accelerator with a cross-scheme-friendly architecture that reuses NTT computational units to support variable-length transforms. The architecture eliminates redundant hardware through intelligent unit sharing, enabling efficient execution across multiple NTT lengths while maintaining HHE scheme compatibility.

**Novelty:** Cross-scheme-friendly reusable NTT unit architecture that dynamically supports variable-length transformations without per-length hardware duplication.
