# Distributed Sparse Tensor Computations in MLIR

**ID**: sc-2025-365
**Venue**: SC
**Confidence**: low

## Problem
Lack of compiler support for distributed sparse tensor computations

## Motivation
MLIR enables compiler optimization for tensor computations

## Method
They created a new MLIR dialect—a custom language within the MLIR compiler framework—specifically for distributed sparse tensor computations. Sparse tensors are arrays containing mostly zeros, and this dialect lets the compiler handle operations on these tensors efficiently across multiple machines. This fills a gap where compiler support for distributed sparse tensor operations was previously missing.

## Key Novelty
An MLIR dialect that enables compiler support for distributed sparse tensor computations.
