# RemapCom: Optimizing Compaction Performance of LSM Trees via Data Block Remapping in SSDs

**Venue**: DATE  
**Primary Theme**: Storage-aware LSM compaction  

## Problem
LSM-tree compaction in DRAM-SSD systems generates significant write amplification because unchanged data blocks are repeatedly read and written back to storage, degrading write performance and shortening SSD lifetime.

## Method
Identifies Unchanged Data Blocks (UDBs) that traverse compaction unmodified and retains them via remapping instead of rewriting. Implements a lightweight state machine to track KV item status within blocks and designs a UDB retention strategy preventing block splits from adjacent modified blocks.

## Key Novelty
Recognition and selective remapping of unchanged data blocks during compaction to eliminate redundant writes.

## Contributions
- Characterization of the UDB phenomenon in LSM compaction
- Lightweight state machine for tracking data block modification status
- UDB retention strategy preventing unnecessary block fragmentation
- Prototype achieving 53% write amplification reduction over state-of-the-art
