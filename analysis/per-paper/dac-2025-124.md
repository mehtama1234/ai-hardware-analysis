# Expanding Logical Space Freely: A Memory-efficient Mapping Table Design for Compressional SSDs

**Venue:** DAC | **ID:** dac-2025-124

## Core Problem
Reducing memory footprint of L2P mapping tables in compressional SSDs; mapping table bloat degrades in-SSD memory and I/O performance.

## Method
Instead of one mapping entry per logical page (data as seen by the user), the system groups multiple compressed logical pages that fit into one physical page (actual storage location) into a single entry, eliminating redundant records. As compression patterns change, entries dynamically migrate to physical pages with different capacities—promoted to consolidate more aggressively when compression is strong, demoted to spread out when compression weakens. The garbage collection algorithm accounts for this grouping, minimizing data copying during cleanup of invalid entries.

## Key Novelty
An N-to-1 mapping design (consolidating multiple compressed logical pages into single entries instead of separate ones) that dynamically adjusts to changing compression patterns, reducing memory overhead.

## Contributions
- N-to-1 mapping consolidation eliminating duplication
- Promotion/demotion for compression ratio adaptation
- Compression-aware garbage collection
- Improved cache hit ratio and I/O latency
