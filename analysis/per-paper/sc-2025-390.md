# Rapid Quantum Network Simulation Design with a Path to Scalable Execution

**Venue:** SC
**ID:** sc-2025-390
**Confidence:** low

## Problem

Quantum network simulation frameworks difficult to work with and performance-limited due to serial nature; SeQUeNCe scalability not proven.

## Motivation

Need user-friendly framework for rapid quantum network experiment design with path to scalable execution.

## Method

BISQIT uses a block-diagram framework (visual representations of how components connect and exchange data) to make quantum network design more intuitive and manageable. The framework creates a documented migration path that allows designs to transition from BISQIT into SeQUeNCe, a production quantum network simulator. Scalability is validated through testing on Frontier, a supercomputer, demonstrating the approach can handle realistic simulation scales.

## Key Novelty

The key novelty is a block-diagram design framework for quantum networks that provides a practical migration path to production simulators, demonstrated through integration with SeQUeNCe.

## Contributions

1. BISQIT block-diagram framework for quantum experiment design
2. Modular reusable component library
3. Rapid iteration capability
4. Path for SeQUeNCe migration
5. Scalability insights on Frontier
