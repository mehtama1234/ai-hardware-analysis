# TrackScorer: Skyrmion Logic-in-Memory Accelerator for Tree-Based Ranking Models

**Venue**: DATE  
**Primary Theme**: in-memory ranking acceleration  

## Problem
Efficiently implementing Quickscorer (tree-based document ranking) on racetrack memories where shift overhead to access ports limits efficiency. SK-RTM density/leakage advantages are hindered by data movement cost.

## Method
Logic-in-Memory accelerator designed specifically for SK-RTMs exploiting Quickscorer's bitvector representation and interleaved tree traversal via bitwise logical operations. Multiple mapping strategies including quadratic assignment problem (QAP) optimization for data placement.

## Key Novelty
Mapping tree-based ranking algorithms to logic-in-memory primitives within racetrack memory to minimize read/write/shift operations.

## Contributions
- Efficient Quickscorer mapping to SK-RTM using bitwise logical operations
- QAP-based data placement optimization
- Significant reduction in read/write operations and shift time during inference
