# TrackScorer: Skyrmion Logic-in-Memory Accelerator for Tree-Based Ranking Models

**Venue**: DATE  
**Primary Theme**: in-memory ranking acceleration  

## Problem
Efficiently implementing Quickscorer (tree-based document ranking) on racetrack memories where shift overhead to access ports limits efficiency. SK-RTM density/leakage advantages are hindered by data movement cost.

## Method
The accelerator implements Quickscorer (a tree-based algorithm for ranking documents) by representing its decisions as bit sequences (bitvectors) and performing logical operations—like AND and OR—directly within racetrack memory rather than moving data elsewhere. To reduce expensive shifting operations needed to access data in racetrack memory, it schedules related decision steps together (interleaving). An optimization algorithm (quadratic assignment problem) determines the best placement of data in memory to minimize total read, write, and shift costs.

## Key Novelty
The core innovation is adapting tree-based ranking algorithms to run directly inside racetrack memory using logical operations on bits, avoiding the expensive data movement of traditional ranking systems.

## Contributions
- Efficient Quickscorer mapping to SK-RTM using bitwise logical operations
- QAP-based data placement optimization
- Significant reduction in read/write operations and shift time during inference
