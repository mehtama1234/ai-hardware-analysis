# HD-MoE: Hybrid and Dynamic Parallelism for Mixture-of-Expert LLMs with 3D Near-Memory Processing

**Venue:** ICCAD

## Problem
MoE LLMs on distributed Near-Memory Processing accelerators face communication bottlenecks and unbalanced computation utilization with existing parallel strategies.

## Motivation
NMP accelerators with high bandwidth via hybrid bonding promise efficiency for MoE models but dynamic routing creates mapping challenges.

## Method
The system automatically selects between two strategies: Tensor Parallelism (dividing mathematical computations among devices) or Expert Parallelism (assigning specialized model components to different devices). As the model runs, it monitors device usage and communication traffic, then dynamically switches between strategies to keep devices equally busy while reducing the time data spends moving between devices.

## Key Novelty
During execution, the system dynamically switches between Tensor and Expert Parallelism (two ways to distribute a language model across devices) and continuously rebalances work to minimize communication delays in mixture-of-expert models running on distributed near-memory processing accelerators.

## Contributions
- 1.1-1.8x speedup over Tensor Parallelism
- 1.1-1.5x speedup over Expert Parallelism
- 1.0-1.4x speedup over baseline hybrid TP-EP
- Reduced communication costs
- Maximized computation utilization across layers
