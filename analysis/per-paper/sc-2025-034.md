# sc-2025-034: Bridging Simulation and Silicon: A Study of RISC-V Hardware and FireSim Simulation

## Summary
Systematic validation of the FireSim FPGA-based architecture simulator against real RISC-V hardware (MILK-V Pioneer). Evaluates simulation fidelity and identifies sources of divergence between simulated and measured performance.

## Problem
- RISC-V emergence for HPC offers opportunities but architectural exploration tools need validation
- FireSim is powerful for simulation but lacks empirical validation for RISC-V targets
- MILK-V Pioneer enables real hardware evaluation but simulation-hardware gap is unknown
- Manufacturer specs often incomplete, hindering accurate simulation configuration

## Method
1. **Hardware target**: MILK-V Pioneer (commercial RISC-V single-board computer)
2. **Simulation setup**: Model Pioneer in FireSim FPGA simulator
3. **Evaluation**:
   - Benchmark performance measurement on real hardware
   - Compare with FireSim simulated results
   - Test single-core and four-core configurations
   - Evaluate with LAMMPS molecular dynamics code

## Key Innovations
1. **First RISC-V FireSim validation**: First systematic comparison of FireSim predictions to real RISC-V hardware
2. **Fidelity assessment**: Quantifies simulation accuracy gaps
3. **Scalability evaluation**: Four-core scaling analysis
4. **HPC workload testing**: LAMMPS provides realistic application context

## Hardware Targets
- MILK-V Pioneer (RISC-V SBC)
- Desktop-grade RISC-V CPUs
- FireSim FPGA simulator

## Results (from abstract)
- FireSim provides insights into architectural trends but has prediction inaccuracies
- Discrepancies stem from:
  - Incomplete CPU specification details from manufacturers
  - Inherent simulation environment limitations
- Trade-off between simulation flexibility and accuracy

## Technique Category
- Computer architecture simulation
- RISC-V ISA evaluation
- Performance prediction methodology
- Benchmark design and execution
- FPGA-based simulation

## Limitations
- Limited CPU specification details restrict accurate configuration
- Discrepancies remain partially unexplained
- Evaluation limited to 4 cores (scalability to larger systems unclear)
- Single RISC-V platform tested (generalizability uncertain)
- No comparison with other simulators (gem5, etc.)

## Related to AI-Hardware
Relevant to HPC architecture design and evaluation. RISC-V as open ISA for HPC is gaining interest; accurate simulation tools are essential for design space exploration before expensive silicon spins.
