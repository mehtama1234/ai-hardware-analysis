# Performance Modeling and Comparisons of an FPGA-based Direct Simulation Monte Carlo Solver

**Problem:** DSMC simulations encounter race conditions when parallelizing collision evaluation in conventional implementations, limiting speedup on multi-core and many-core platforms.

**Method:** The solver runs on specialized hardware (an FPGA) using a spatially-parallel collision algorithm: it divides space into regions and processes collisions region-by-region instead of letting all processors randomly evaluate collisions. This spatial organization eliminates race conditions—conflicts that occur when multiple processors simultaneously update the same data—that normally limit parallel speedup. The FPGA hardware includes custom memory layouts tailored to different particle densities, which is especially valuable for low-particle microscale simulations.

**Novelty:** Organizing collision calculations spatially (dividing space into regions) prevents race conditions that normally block parallel speedup.
