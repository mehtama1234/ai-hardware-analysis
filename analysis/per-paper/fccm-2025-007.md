# Performance Modeling and Comparisons of an FPGA-based Direct Simulation Monte Carlo Solver

**Problem:** DSMC simulations encounter race conditions when parallelizing collision evaluation in conventional implementations, limiting speedup on multi-core and many-core platforms.

**Method:** The solver employs a spatially-parallel collision evaluation algorithm implemented on FPGA, which organizes collision processing by spatial domain to eliminate synchronization race conditions inherent in conventional parallel DSMC. The FPGA leverages custom hardware parallelism and memory hierarchies tailored for different particle count regimes, particularly low-particle scenarios typical in microscale flows.

**Novelty:** Spatially-parallel collision evaluation algorithm that eliminates race conditions in DSMC parallelization.
