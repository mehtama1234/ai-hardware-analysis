# Monomorphism-Based CGRA Mapping Via Space and Time Decoupling

**Venue**: DATE  
**Primary Theme**: scalable CGRA compilation via time-space decoupling  

## Problem
CGRA compilation faces scalability challenges when mapping code onto large arrays due to combined space-time search complexity.

## Method
Decouples spatial and temporal mapping dimensions via SMT formulation: SMT traverses time dimension first identifying feasible schedules, then monomorphism-based graph matching finds valid spatial assignments.

## Key Novelty
Time-space decoupling with monomorphism-based spatial search achieves dramatic compilation speedup for large CGRAs.

## Contributions
- Time-space decoupled CGRA mapping formulation
- SMT-based temporal scheduling phase
- Monomorphism-based spatial mapping phase
- 105× average compilation speedup for 20×20 CGRA with comparable mapping quality
