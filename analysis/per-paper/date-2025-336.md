# Monomorphism-Based CGRA Mapping Via Space and Time Decoupling

**Venue**: DATE  
**Primary Theme**: scalable CGRA compilation via time-space decoupling  

## Problem
CGRA compilation faces scalability challenges when mapping code onto large arrays due to combined space-time search complexity.

## Method
The approach splits the mapping problem into two sequential searches instead of solving them together. First, it uses SMT (a logical solver that checks whether constraints can be satisfied) to find the timing schedule—determining when each operation should execute. Then, it uses monomorphism-based graph matching (a structural pattern-matching technique that preserves how operations connect to each other) to assign each operation to a physical location on the array. By solving timing first, it eliminates many impossible spatial arrangements, making the spatial search much faster.

## Key Novelty
Solving the timing schedule before choosing spatial locations eliminates impossible option combinations and dramatically speeds up compilation for large arrays.

## Contributions
- Time-space decoupled CGRA mapping formulation
- SMT-based temporal scheduling phase
- Monomorphism-based spatial mapping phase
- 105× average compilation speedup for 20×20 CGRA with comparable mapping quality
