# DecDEC: A Systems Approach to Advancing Low-Bit LLM Quantization

**Problem:** Aggressive low-bit quantization (3-bit, 4-bit) of LLMs severely degrades model quality due to precision loss. Maintaining acceptable inference accuracy while preserving quantization's memory and latency benefits remains challenging for on-device deployment.

**Method:** DecDEC stores residual matrices (full-precision minus quantized weights) in CPU and dynamically identifies salient channels marked by activation outliers at each decoding step. Residuals are selectively fetched from CPU for these salient channels to correct quantization errors, enabling adaptation to dynamic activation distributions during inference.

**Novelty:** Dynamic identification of salient channels via activation outlier analysis enables selective residual correction that adapts to changing activation distributions at inference time.
