# DecDEC: A Systems Approach to Advancing Low-Bit LLM Quantization

**Problem:** Aggressive low-bit quantization (3-bit, 4-bit) of LLMs severely degrades model quality due to precision loss. Maintaining acceptable inference accuracy while preserving quantization's memory and latency benefits remains challenging for on-device deployment.

**Method:** DecDEC stores the lost precision as residuals—the differences between original full-precision weights and their quantized low-precision versions—on the CPU. As the model runs inference, it monitors for activation outliers (unusual spikes in intermediate values flowing through the network) to identify which channels (processing pathways) are most sensitive to precision loss at that moment. For these sensitive channels, it fetches the stored residuals from the CPU and adds them back to recover some precision. This lets the model adapt its precision correction to what's actually happening during inference instead of using a fixed strategy.

**Novelty:** The key idea is detecting activation outliers as the model runs to identify which channels need precision correction in real-time, rather than deciding this upfront.
