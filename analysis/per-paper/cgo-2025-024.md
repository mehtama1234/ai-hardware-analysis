# Stack Filtering: Elevating Precision and Efficiency in Rust Pointer Analysis

**Venue:** CGO
**Confidence:** low

## Problem
Context-sensitive pointer analysis generates excessive spurious points-to relations involving variables pointing to stack objects beyond their lifetimes, harming both efficiency and precision in Rust program analysis.

## Motivation
Rust's automatic memory management and stack-first allocation strategy create opportunities to prune invalid points-to relations; improving analysis precision is critical for Rust verification.

## Method
Stack filtering uses Rust's stack object lifetime information in two phases: (1) assess stack object liveness via function reachability and efficient call graph (RTA), (2) filter out points-to relations involving inactive stack objects during context-sensitive analysis. Integrated into Ruypē pointer analysis framework.

## Key Novelty
Leveraging Rust's explicit stack object lifetimes to prune spurious context-sensitive points-to relations without full flow-sensitivity.

## Contributions
- Stack filtering technique using stack object liveness
- Integration into Rust context-sensitive pointer analysis
- Reduced analysis time and memory consumption while improving precision
