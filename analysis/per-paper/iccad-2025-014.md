# MIRAGE: Microarchitectural Footprints for Detecting Adversarial Attacks in One-Shot Inference

**Venue:** ICCAD  
**ID:** iccad-2025-014

## Problem
Detecting adversarial attacks on DNNs in resource-constrained systems requires expensive defenses; existing HPC-based detection requires state cleaning between inferences, degrading system performance.

## Motivation
Lightweight, one-shot adversarial detection enables practical deployment on edge systems without state management overhead.

## Method
MIRAGE uses hardware performance counters without requiring cache/branch predictor state cleaning. CNN classifier trained on HPC signals detects adversarial samples in single inference.

## Key Novelty
One-shot adversarial detection using HPCs without state cleaning, enabling practical online deployment with full hardware optimization.

## Contributions
1. Lightweight HPC-based adversarial detection without state cleaning requirement
2. Single-shot detection enabling online operation without repeated inferences
3. Full hardware optimization compatibility (cache, branch predictor)
4. 96%+ accuracy on CIFAR-10/MNIST with 60ms timing overhead
