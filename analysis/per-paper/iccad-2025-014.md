# MIRAGE: Microarchitectural Footprints for Detecting Adversarial Attacks in One-Shot Inference

**Venue:** ICCAD  
**ID:** iccad-2025-014

## Problem
Detecting adversarial attacks on DNNs in resource-constrained systems requires expensive defenses; existing HPC-based detection requires state cleaning between inferences, degrading system performance.

## Motivation
Lightweight, one-shot adversarial detection enables practical deployment on edge systems without state management overhead.

## Method
MIRAGE detects adversarial attacks by monitoring hardware performance counters—measurements that track CPU cache and branch predictor activity—without requiring their reset between inference runs. It trains a CNN classifier to recognize attack patterns in these counter signals. Unlike existing defenses that need to clean the hardware's state between runs (slowing the system down), MIRAGE completes detection in one pass at full performance.

## Key Novelty
MIRAGE detects adversarial attacks in a single inference using hardware performance counters without resetting cache or branch predictor state, enabling practical deployment on performance-critical systems.

## Contributions
1. Lightweight HPC-based adversarial detection without state cleaning requirement
2. Single-shot detection enabling online operation without repeated inferences
3. Full hardware optimization compatibility (cache, branch predictor)
4. 96%+ accuracy on CIFAR-10/MNIST with 60ms timing overhead
