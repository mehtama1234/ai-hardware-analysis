# Concorde: Fast and Accurate CPU Performance Modeling with Compositional Analytical-ML Fusion
**Venue:** ISCA | **Confidence:** low (title-only — abstract not available in batch)

## Problem
Accurate CPU performance simulation (cycle-accurate or analytical) is extremely slow, while pure ML-based performance models are fast but lack accuracy and generalizability across microarchitectures and workloads. Neither approach alone satisfies the speed-accuracy requirements of design-space exploration for modern out-of-order processors.

## Motivation
Rapid CPU microarchitecture design-space exploration during early design phases requires performance models that are simultaneously fast enough for large sweeps and accurate enough to guide architectural decisions, a gap that existing tools (gem5, Sniper, ChampSim, or standalone ML models) fail to close.

## Method
Concorde combines analytical models (mathematical formulas based on how CPUs work) with machine learning to predict CPU performance quickly and accurately. The analytical part separately models major CPU components—pipeline stages (instruction execution steps), cache hierarchy (layered memory), branch prediction (guessing execution paths), and memory access—using structured equations. Machine learning then corrects the remaining errors from complex interactions between components that the math alone can't capture. Each analytical sub-model is tuned independently and combined at prediction time, making it fast to evaluate new CPU designs.

## Key Novelty
The key innovation is composing separate analytical models for each CPU stage that are tuned independently, then combining them with machine learning to fix errors from complex component interactions.

## Contributions
- Concorde: a compositional analytical-ML hybrid framework for CPU performance modeling
- Fast and accurate design-space exploration methodology for modern CPU microarchitectures
- Demonstration of speed-accuracy trade-off improvement over pure analytical and pure ML baselines
