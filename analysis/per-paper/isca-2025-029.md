# isca-2025-029 — FAST: An FHE Accelerator for Scalable-parallelism with Tunable-bit

**Venue:** ISCA 2025  
**Confidence:** low (abstract only)

## Problem
FHE imposes enormous computational overhead over plaintext and existing accelerators do not exploit hoisting technology or the gadget decomposition KLSS key-switching method. Ciphertext level consumption varies significantly during application execution (affecting precision and method requirements), causing workload imbalance that fixed-precision accelerators cannot address.

## Motivation
FHE is a key enabler for secure cloud computation, but its performance gap vs. plaintext makes real-world adoption infeasible without hardware that co-optimizes recent cryptographic improvements and handles variable-precision workloads.

## Method
FAST integrates hoisting technology (reducing redundant NTT operations in key-switching) and KLSS gadget decomposition key-switching into a hardware accelerator. A versatile framework dynamically selects between hybrid and KLSS key-switching within a single application run based on the current ciphertext level. Tunable-bit arithmetic datapaths adapt precision to the requirements of each method at each level. A scalable parallel PE array is provisioned to match current workload level and method demands.

## Key Novelty
Single FHE accelerator framework supporting hoisting + both hybrid and KLSS key-switching with tunable-bit arithmetic, dynamically adapting to ciphertext level within one application execution.

## Contributions
1. Hardware integration of hoisting technology and KLSS key-switching method.
2. Versatile dual-method framework with dynamic selection by ciphertext level.
3. Tunable-bit arithmetic datapath adapting precision per method/level.
4. Scalable parallel architecture with improved FHE application throughput over prior accelerators.
