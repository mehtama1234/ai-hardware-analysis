# Quantifying AWS S3 I/O Performance Boundaries Using the Roofline Model

**Paper ID:** sc-2025-347
**Venue:** SC
**Confidence:** low

## Problem Statement
Understanding performance characteristics of AWS S3 integration with HPC systems using different access methods and patterns

## Motivation
Hybrid HPC-cloud environments need clear guidance on S3 integration strategies to avoid suboptimal data transfer approaches

## Method
They apply the roofline model—a performance technique that reveals whether a system is limited by computation speed or data-transfer bandwidth—to analyze three ways of accessing AWS S3 cloud storage from high-performance computers: NFS-mounted Storage Gateway, data migration through Storage Gateway, or direct S3 API calls. By measuring how much computational work happens per byte of data (operational intensity) for each method and comparing it against available bandwidth, they identify which approach performs best and whether its bottleneck is compute, network bandwidth, or latency.

## Key Novelty
The work extends roofline modeling to cloud storage systems by measuring operational intensity and bandwidth ceilings across different S3 access methods to identify performance limits.

## Contributions
- Extended I/O roofline methodology for cloud storage
- Comparative analysis of three S3 integration approaches
- Identification of 6.4x performance differences between methods
