# Late Breaking Results: The Hidden Risks of Activation Duration in PLPUFs

**Problem:** PLPUF security critically depends on activation duration selection; improper choices lead to 96% response predictability.

**Method:** The researchers tested how predictable responses were from different PLPUF chips by varying how long they let circuits run before recording outputs (activation duration). They discovered that certain activation durations create mathematical relationships between chips' responses — if you know one chip's output, you can calculate another's with 96% accuracy. This reveals that activation duration is a critical security parameter: wrong choices destroy the unpredictability that protects these chips.

**Key Contribution:** Demonstrates that unsuitable activation duration choices can reduce PLPUF security to 4% (96% predictability).

**Results:** Reveals critical design parameter sensitivity in PLPUF-based IoT authentication.
