# ModuLair: Streamlining Python Virtual Environment Management for HPC

**ID:** sc-2025-335  
**Venue:** SC 2025  
**Authors:** Surada Suwansathit, Ananya Adiki, Gabriel Floreslovo, Marinus Pennings, Honggao Liu

## Problem & Motivation

Python environment management on HPC systems is notoriously complex:
- Complex toolchains and module systems
- File system constraints (parallel file systems, quotas)
- Diverse user needs (from novices to power users)
- Reproducibility challenges
- Lack of integrated tools

**Result:** High barrier to entry for non-expert users.

## Solution: ModuLair

A **modular, metadata-driven Python virtual environment framework** supporting:

### Features
- **Automatic module system detection** (EasyBuild or non-EasyBuild)
- **CLI interface** for power users
- **GUI interfaces:**
  - HPRC Dashboard (web-based)
  - Drona Composer (visual composition)
  - JupyterLab plugin
- **Metadata-driven design** ensuring reproducibility

## Validation

Deployed across **3 HPC clusters** over 5 months with:
- Sustained adoption by active Python users
- Integration into ongoing research workflows
- Both CLI and GUI usage patterns

## Impact

- Reduces setup complexity
- Lowers barrier to entry for non-expert users
- Promotes best practices in environment configuration
- Seamless integration with popular tools (Jupyter)
