# FIRST: Federated Inference Resource Scheduling Toolkit for Scientific AI Model Access

**Paper ID:** sc-2025-348
**Venue:** SC
**Confidence:** low

## Problem Statement
Lack of scalable, on-premises AI inference infrastructure for scientific workloads with privacy constraints

## Motivation
Scientific communities need private, secure, scalable inference without relying on commercial cloud infrastructure

## Method
Federated inference framework using Globus Auth/Compute, multiple inference backends (vLLM), auto-scaling with hot-node management

## Key Novelty
Cloud-like Inference-as-a-Service on federated HPC clusters with OpenAI-compliant API and cross-cluster distribution

## Contributions
- FIRST framework for federated AI inference
- Cluster-agnostic API for distributed inference
- Support for billions of tokens daily on-premises
- Multiple inference backend support
