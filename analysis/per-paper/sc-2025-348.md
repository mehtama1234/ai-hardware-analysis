# FIRST: Federated Inference Resource Scheduling Toolkit for Scientific AI Model Access

**Paper ID:** sc-2025-348
**Venue:** SC
**Confidence:** low

## Problem Statement
Lack of scalable, on-premises AI inference infrastructure for scientific workloads with privacy constraints

## Motivation
Scientific communities need private, secure, scalable inference without relying on commercial cloud infrastructure

## Method
The system connects multiple university supercomputing centers together as one federated network, letting researchers share access to AI model-serving capacity. When scientists submit requests, the system uses Globus—a secure authentication service—to verify who they are and what they can access, then automatically distributes work across available computers. If demand grows, the system wakes up standby machines while keeping some warmed up for instant response. It supports multiple AI model serving backends like vLLM, so each institution can choose their preferred software.

## Key Novelty
It brings cloud-like AI inference services to federated research computing centers by using OpenAI's standard API and automatically distributing requests across multiple institutions' supercomputers.
