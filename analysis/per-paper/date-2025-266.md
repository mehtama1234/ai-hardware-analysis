# Multi-Partner Project: Key Enabling Technologies for Cognitive Computing Continuum - MYRTUS Project Perspective

**Venue**: DATE  
**Primary Theme**: Cognitive orchestration for edge-fog-cloud continuum  

## Problem
Building distributed, heterogeneous computing systems across edge-fog-cloud continuum requires abstractions, orchestration mechanisms, and design environments that are currently lacking.

## Method
The project creates tools to manage computing resources spread across edge devices (at network boundaries), fog nodes (in between), and cloud servers (centralized). It uses cognitive orchestration—intelligent algorithms that automatically place tasks where they'll run most efficiently based on current conditions. It provides one unified environment where developers design and manage these distributed systems without separately handling each layer's unique technical requirements.

## Key Novelty
Unified design and intelligent orchestration across the entire edge-fog-cloud computing continuum.

## Contributions
- Abstractions for heterogeneous computing resources across continuum
- Cognitive orchestration mechanisms for automated resource management
- Unified design environment for continuum applications
