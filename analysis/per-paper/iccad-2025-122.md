# IncreGPUSTA: GPU-Accelerated Incremental Static Timing Analysis for Iterative Design Flows

**Venue:** ICCAD  
**ID:** iccad-2025-122

## Problem
Combining GPU acceleration with incremental STA is challenging; existing solutions offer only partial incrementality, either reverting to CPU for small modifications or ignoring structural updates.

## Motivation
Static timing analysis is essential for VLSI optimization but can be computationally expensive; efficient incremental analysis with GPU acceleration would speed design iterations.

## Method
It speeds up timing analysis—predicting signal propagation through circuits—by running on a GPU (graphics processor) instead of a CPU. When designers modify the circuit, instead of recalculating everything from scratch, it updates only the affected paths using dual-CSR data structures (optimized storage formats) and incrementally recalculates dependency levels (how elements depend on each other). This approach efficiently handles both small timing adjustments and major structural changes like rearranging circuit components.

## Key Novelty
First GPU-accelerated circuit timing analyzer that can efficiently handle both small modifications and major structural changes using dual-CSR data structures.

## Contributions
- Dual-CSR data structures for efficient GPU incremental processing
- Incremental levelization algorithm supporting structural modifications
- GPU acceleration maintaining full incrementality
