# lsCOMP: Efficient Light Source Compression

**Venue:** SC 2025  
**Authors:** Yafan Huang, Sheng Di, Robert Underwood, Peco Myint, Miaoqi Chu, Guanpeng Li, Nicholas Schwarz, Franck Cappello

## Problem
Light source facilities (synchrotrons, free-electron lasers) generate X-ray data at extreme rates currently reaching 250 GB/s and projected to exceed 1 TB/s by end of this decade. Intense data streams create critical I/O and bandwidth bottlenecks when offloading to HPC systems for analysis. Local processing capacity insufficient for online data analysis.

## Motivation
Light source facilities produce world-leading scientific data but face fundamental data management challenge. High data rates exceed typical storage and network bandwidth capacity, creating I/O wall. Compression at data source reduces bandwidth requirements for transfer to HPC systems and reduces storage footprint. Existing compression tools cannot sustain required throughput while maintaining data quality.

## Method
lsCOMP runs a single processing kernel on a GPU to compress X-ray data from light sources, supporting both lossless compression (keeping all original data) and lossy compression with adjustable precision (trading quality for smaller file size). It achieves 380-509 gigabytes per second throughput in lossless mode and can randomly access compressed data at terabyte-per-second speeds, making it practical for near-real-time data handling. The system works with multiple types of light source data formats.

## Key Novelty
A GPU compressor built for light source data that can sustain 250+ gigabytes per second processing rates today and 1+ terabytes per second in the future while maintaining data quality.

## Contributions
1. Single-kernel GPU compression architecture for efficiency
2. Lossless mode achieving 380.89-509.21 GB/s (20x industry leaders)
3. Configurable lossy compression with high compression ratios
4. Superior compression ratio-throughput tradeoff
5. TB/s-level random access throughput for selective data access
6. Support for diverse integer dataset types
