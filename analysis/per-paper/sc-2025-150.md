# lsCOMP: Efficient Light Source Compression

**Venue:** SC 2025  
**Authors:** Yafan Huang, Sheng Di, Robert Underwood, Peco Myint, Miaoqi Chu, Guanpeng Li, Nicholas Schwarz, Franck Cappello

## Problem
Light source facilities (synchrotrons, free-electron lasers) generate X-ray data at extreme rates currently reaching 250 GB/s and projected to exceed 1 TB/s by end of this decade. Intense data streams create critical I/O and bandwidth bottlenecks when offloading to HPC systems for analysis. Local processing capacity insufficient for online data analysis.

## Motivation
Light source facilities produce world-leading scientific data but face fundamental data management challenge. High data rates exceed typical storage and network bandwidth capacity, creating I/O wall. Compression at data source reduces bandwidth requirements for transfer to HPC systems and reduces storage footprint. Existing compression tools cannot sustain required throughput while maintaining data quality.

## Method
lsCOMP single-kernel GPU compressor designed for light source data:

1. **Single-Kernel Design:** Streamlined implementation for efficiency and low latency

2. **Lossless Compression:** 
   - Throughput: 380.89-509.21 GB/s on single A100 GPU
   - 20x higher performance than industry-leading GPU compressors
   - High compression ratios

3. **Configurable Lossy Compression:**
   - Further improve throughput and compression ratios
   - User-controlled precision for quality-compression tradeoff
   - Tailored for scientific data quality requirements

4. **Diverse Data Support:** Integer datasets of various types and distributions

5. **Random Access:** TB/s-level random access throughput enabling selective data reading

## Key Novelty
First GPU compressor specifically designed for light source data, meeting current 250 GB/s and future 1+ TB/s data rate requirements with high compression efficiency.
