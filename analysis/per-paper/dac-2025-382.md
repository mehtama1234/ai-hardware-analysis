# Hybrid Embedding Framework for Memory-Efficient Recommendation Systems

**Venue:** DAC
**ID:** dac-2025-382

## Problem
Deep learning recommendation models (DLRM) suffer from memory bottleneck of large embedding tables that grow with data scale.

## Motivation
Embedding table size dominates memory usage in recommendation systems; selective compression of infrequently accessed embeddings can significantly reduce footprint.

## Method
The framework distinguishes hot (frequent) and cold (infrequent) embeddings. Hot embeddings are stored in compact lookup tables; cold embeddings are computed via deep hash embedding (DHE) networks. Hybrid approach minimizes training time while maintaining accuracy.

## Key Novelty
Hybrid hot-cold embedding representation combining direct lookup for frequent embeddings with neural hash functions for sparse embeddings.

## Contributions
1. Hybrid representation distinguishing hot and cold embeddings
2. Deep hash embedding (DHE) network for cold embedding computation
3. Reduced memory usage while maintaining training speed and accuracy
4. Outperforms other embedding reduction techniques in memory, accuracy, and training speed
