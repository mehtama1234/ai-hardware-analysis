# Hybrid Embedding Framework for Memory-Efficient Recommendation Systems

**Venue:** DAC
**ID:** dac-2025-382

## Problem
Deep learning recommendation models (DLRM) suffer from memory bottleneck of large embedding tables that grow with data scale.

## Motivation
Embedding table size dominates memory usage in recommendation systems; selective compression of infrequently accessed embeddings can significantly reduce footprint.

## Method
Recommendation systems store numerical representations called embeddings for every item, wasting memory on items users rarely interact with. This framework splits embeddings by frequency: frequently-used embeddings go into compact lookup tables; infrequently-used embeddings are computed on-the-fly using deep hash embedding networks (neural networks trained to approximate embeddings via mathematical hash functions). This reduces memory demands significantly while keeping training time and accuracy essentially unchanged.

## Key Novelty
The key innovation is this hybrid approach: direct storage via lookup tables for frequently-accessed embeddings and on-the-fly computation via deep hash embedding networks (neural networks using hash functions) for rare ones.

## Contributions
1. Hybrid representation distinguishing hot and cold embeddings
2. Deep hash embedding (DHE) network for cold embedding computation
3. Reduced memory usage while maintaining training speed and accuracy
4. Outperforms other embedding reduction techniques in memory, accuracy, and training speed
