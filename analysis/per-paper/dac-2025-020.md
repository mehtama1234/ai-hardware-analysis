# dac-2025-020: GPU-Accelerated SSTA with STG Scheduling

**Title:** Late Breaking Results: Statistical Timing Graph Scheduling Algorithm for GPU Computation

**Venue:** DAC 2025

**Core Issue:** SSTA is computationally expensive and memory-intensive; CPU-based analysis prohibitive for large designs.

**Key Contribution:** STG scheduling algorithm for GPU with memory management; 4.9x speedup on 18.2 GB STG.

**Hardware Target:** GPU

**Workload:** EDA (static timing analysis)

**Metrics:**
- Speedup: 4.9x vs 20-thread CPU
- STG size handled: 18.2 GB

**Confidence:** Low (abstract-only)
