# isscc-2025-010: 200GHz 2D Near-Field Biomedical Imager

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
Near-field mmWave/THz imagers suffer from: (1) single-source-per-pixel limits resolution scalability, (2) no isolated resonator selection, (3) poor resonator Q near lossy biological samples → low sensitivity.

## Approach
200GHz 200-pixel 2D imager via:
1. **Q-boosted active split-ring resonators (ASRR):** dense integration, minimal capacitive loading for isolation
2. **Shared source/detector** with selective pixel activation (not per-pixel)
3. **Phase detection:** robust to free-running VCO phase noise (vs. power/frequency detection)
4. **Correlated-doubling sampling:** suppresses low-frequency noise

## Key Contribution
Q-boosted ASRR + phase detection enables true 2D scalable near-field imaging with high sensitivity despite lossy biological samples.

## Performance
- Frequency: 200 GHz
- Pixels: 200 (2D array)
- Resolution: Sub-wavelength (cellular scale)
- Applications: Intraoperative imaging, cell proliferation monitoring
