# isscc-2025-257: Photocurrent-Driven Current-to-Phase ADC for Infrared Arrays

**Title:** A 320×256 6.9mW 2.2mK-NETD 120.4dB-DR LW-IRFPA with Pixel-Paralleled Light-Driven 20b Current-to-Phase ADC

**Venue:** ISSCC 2025

**Problem:** Long-wavelength cryogenic infrared focal plane arrays need high-DR readout circuits for SNR, but conventional analog modulation (current-voltage, current-frequency) wastes power, introduces crosstalk, and relies on global analog circuits vulnerable to interference.

**Key Innovation:** Light-current-driven (photocurrent-powered) modulator for pixel-parallel current-to-phase ADC—no external power supply needed.

**Approach:**
1. Light-current-controlled oscillator (LCO) modulator powered by sensor photocurrent
2. Phase-reconstruction with sub-phase extraction for low-light improvement
3. Pixel-level 20-bit asynchronous gray-code counter
4. Low-swing bus for crosstalk/power reduction
5. 0.18μm CMOS QWIP 320×256 array

**Results:**
- **Power:** 6.9mW full array
- **Dynamic Range:** 120.4dB
- **Noise:** 2.2mK NETD (noise-equivalent temperature difference)
- **Resolution:** 20-bit per pixel

**Confidence:** Low (abstract-only; frame rate, integration time not specified)
