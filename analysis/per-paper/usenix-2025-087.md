# AssyLLM: Efficient Federated Fine-tuning of LLMs via Assembling Pre-trained Blocks

**Problem:** Federated fine-tuning of large language models incurs high communication and computational overhead as model updates must be synchronized across distributed nodes. This work addresses reducing the communication volume and computation cost in federated LLM fine-tuning scenarios.

**Method:** AssyLLM assembles pre-trained LLM blocks (modular components) that are selectively fine-tuned in a federated manner, rather than updating entire model weights. The approach leverages parameter-efficient optimization by identifying critical pre-trained components and reducing communication through block-level aggregation instead of full-model parameter synchronization.

**Novelty:** Using pre-trained block assembly to enable communication-efficient federated LLM fine-tuning by selectively optimizing modular components rather than complete model weights.
