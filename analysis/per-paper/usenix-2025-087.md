# AssyLLM: Efficient Federated Fine-tuning of LLMs via Assembling Pre-trained Blocks

**Problem:** Federated fine-tuning of large language models incurs high communication and computational overhead as model updates must be synchronized across distributed nodes. This work addresses reducing the communication volume and computation cost in federated LLM fine-tuning scenarios.

**Method:** AssyLLM breaks a language model into pre-trained blocks (self-contained components trained beforehand) and selectively fine-tunes only the critical ones across multiple distributed computers. Instead of synchronizing the entire model's weights between computers, it sends only block-level updates, which cuts communication and computation costs. This parameter-efficient approach works because not all model components need retraining—focusing on the essential blocks is enough.

**Novelty:** The core contribution is selective fine-tuning of pre-trained blocks in a federated setting, which reduces communication by synchronizing only block updates instead of full model weights.
