# STORM: a Multipath QUIC Scheduler for Quick Streaming Media Transport under Unstable Mobile Networks

**Problem:** Existing QUIC schedulers do not effectively utilize multiple paths simultaneously on mobile networks where link quality varies dynamically with packet loss and latency fluctuations. Streaming applications need intelligent packet distribution across available paths to maintain quality under network instability.

**Method:** STORM monitors per-path metrics (latency, loss rates) and adaptively schedules packet transmission across available paths based on real-time network conditions. The scheduler learns path characteristics from acknowledgment feedback and adjusts assignments to optimize throughput while minimizing buffering delays.

**Novelty:** An adaptive scheduling algorithm that dynamically responds to mobile network instability to optimize packet distribution across multiple QUIC paths.
