# STORM: a Multipath QUIC Scheduler for Quick Streaming Media Transport under Unstable Mobile Networks

**Problem:** Existing QUIC schedulers do not effectively utilize multiple paths simultaneously on mobile networks where link quality varies dynamically with packet loss and latency fluctuations. Streaming applications need intelligent packet distribution across available paths to maintain quality under network instability.

**Method:** STORM monitors how each network path performs—tracking latency (how long packets take to arrive) and loss rates (how many packets disappear)—then sends each packet on whichever path is performing best at that moment. Using acknowledgments (delivery confirmations) as feedback, the scheduler continuously updates its understanding of each path's quality and shifts packet assignments between paths to maximize throughput (total data arriving per second) while keeping buffering delays minimal.

**Novelty:** The core insight is continuously measuring performance on each available network path and dynamically routing each packet to whichever path will deliver it most reliably, adapting instantly as mobile network conditions change.
