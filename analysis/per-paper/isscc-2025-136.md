# ISSCC-2025-136: Distributed Contactless Battery Monitoring and Balancing

**Problem:**  
EV and grid-storage BMSs require per-cell monitoring and charge balancing across large packs (up to 216 cells) with robust communication and network formation, but wired architectures scale poorly.

**Solution:**  
Distributed on-cell monitor (CM) architecture with contactless serial communication to a system hub (SH); each CM performs local processing, storage, and charge balancing with dynamic network formation.

**Key Results:**  
- Supports up to 216 cell monitors per system hub
- Distributed per-cell processing and storage
- Contactless communication eliminates wiring complexity

**Key Innovation:**  
Per-cell distributed processing with contactless serial communication enables scalable, reusable CM chips across different pack topologies.
