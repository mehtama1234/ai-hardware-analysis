# Toppings: CPU-Assisted, Rank-Aware Adapter Serving for LLM Inference

**Problem:** Serving multiple LLM adapters (parameter-efficient fine-tuned models) concurrently during inference incurs significant memory and scheduling overhead, creating contention on GPU resources and degrading throughput when handling diverse adapter requests simultaneously.

**Method:** Toppings delegates scheduling and memory management to the CPU while GPUs focus purely on inference computation. The CPU uses rank-aware prioritization—scoring adapters by request characteristics or importance—to decide which adapter to use, batch requests efficiently, and move data between CPU and GPU memory. This keeps GPUs busy with compute work instead of wasting cycles on scheduling and overhead, enabling them to handle more adapters concurrently.

**Novelty:** Using CPU-based rank-aware prioritization (dynamically scoring adapters by request characteristics or importance) to handle adapter scheduling and memory overhead, freeing GPUs to focus entirely on inference for multiple adapters.
