# Toppings: CPU-Assisted, Rank-Aware Adapter Serving for LLM Inference

**Problem:** Serving multiple LLM adapters (parameter-efficient fine-tuned models) concurrently during inference incurs significant memory and scheduling overhead, creating contention on GPU resources and degrading throughput when handling diverse adapter requests simultaneously.

**Method:** Toppings employs a CPU-assisted serving architecture where the CPU handles adapter scheduling, routing decisions, and memory management based on rank-aware prioritization, while GPUs focus on compute-heavy inference operations. The rank-aware component dynamically prioritizes adapters based on request characteristics or adapter importance metrics. CPU handles adapter lookup, batching decisions, and memory movement overhead between CPU/GPU memory, reducing GPU idle cycles and enabling higher adapter concurrency.

**Novelty:** Rank-aware adapter scheduling that offloads memory and routing overhead to CPU, allowing GPUs to maximize inference throughput for multi-adapter workloads.
