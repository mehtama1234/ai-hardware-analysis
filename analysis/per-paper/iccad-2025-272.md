# Diffusion-Model-Enhanced Layout Pattern Generation for Sub-3nm DFM

**Venue:** ICCAD  
**ID:** iccad-2025-272

## Problem
Modern VLSI layout pattern generation for design for manufacturability (DFM) at sub-3nm nodes faces rapid evolution of intricate design rules and scarcity of high-quality, rule-compliant layout data during new process technology development.

## Motivation
To generate diverse, legally compliant layout patterns at sub-3nm with minimal training data by leveraging pre-trained diffusion models.

## Method
The approach uses diffusion models—AI systems that build images by gradually refining noise—to create chip layouts as a series of template-guided image-filling tasks (inpainting). Each task fills in parts of a chip design while respecting the intricate 2D metal interconnect design rules that govern how metal layers can be arranged. It applies a denoising step with templates to clean up residual artifacts. The system then uses minimal labeled examples (few-shot fine-tuning) to quickly adapt to new semiconductor process nodes.

## Key Novelty
It uses diffusion models—AI systems trained to generate images by refining noise—as a pre-trained foundation for efficiently generating chip layouts at sub-3nm nodes with minimal new training data.

## Contributions
- Diffusion-based framework reframing layout synthesis as template-guided inpainting
- Template-based denoising scheme for eliminating residual noise in generated patterns
- Few-shot fine-tuning approach requiring minimal rule-compliant data
- Production-ready solution generating legal layouts conforming to full sign-off rule deck at sub-3nm
