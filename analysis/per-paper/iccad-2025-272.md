# Diffusion-Model-Enhanced Layout Pattern Generation for Sub-3nm DFM

**Venue:** ICCAD  
**ID:** iccad-2025-272

## Problem
Modern VLSI layout pattern generation for design for manufacturability (DFM) at sub-3nm nodes faces rapid evolution of intricate design rules and scarcity of high-quality, rule-compliant layout data during new process technology development.

## Motivation
To generate diverse, legally compliant layout patterns at sub-3nm with minimal training data by leveraging pre-trained diffusion models.

## Method
Diffusion-based framework reframes complex layout synthesis as a sequence of template-guided inpainting tasks, significantly reducing training sample requirements. Leverages knowledge of a pre-trained image foundation model to generate layout variations satisfying complex 2D metal interconnect design rule constraints. Introduces novel template-based denoising scheme to eliminate residual noisy pixels. Uses few-shot fine-tuning to adapt to new technology nodes.

## Key Novelty
Uses diffusion models as image foundation models for data-efficient layout pattern generation at sub-3nm nodes.

## Contributions
- Diffusion-based framework reframing layout synthesis as template-guided inpainting
- Template-based denoising scheme for eliminating residual noise in generated patterns
- Few-shot fine-tuning approach requiring minimal rule-compliant data
- Production-ready solution generating legal layouts conforming to full sign-off rule deck at sub-3nm
