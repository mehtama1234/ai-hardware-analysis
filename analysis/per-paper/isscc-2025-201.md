# ISSCC 2025-201: Fully-Analog 256×256 Cross-Correlator via Margin-Propagation

## Core Contribution
Analog cross-correlation engine achieving 1000+ TOPS/W efficiency with single-shot 256-lag readout, enabling power-efficient radar range/velocity detection and communication synchronization.

## Technical Approach
- **Compute Cell**: Margin-propagation (MP) based 4-transistor analog compute unit
- **Delay Generation**: Sampling-based approach creates wideband analog delays (>10ns with 4GHz BW) on-chip
- **Readout**: Single-shot propagation across all 256 lags (vs. sequential N readouts)
- **Accuracy**: 8.2–8.5 bit compute accuracy (51–53dB hardware dynamic range)
- **Input**: 1–4GS/s wideband signal

## Performance Metrics
- **Efficiency**: 996–1060 TOPS/W (6.6x better than prior analog correlators, orders-of-magnitude vs. digital)
- **Compute Density**: 1.3 TOPS/mm^2 (7x better than prior art)
- **Correlation Length**: 256 lags single-shot
- **Accuracy**: 7–8.5 bit (competitive with digital MACs despite analog substrate)
- **Radar Demo**: 15cm range resolution, 256 range bins, up to 1024 chirp averages, 115Hz refresh rate

## Baselines
- Digital ADC + MAC approach (5–20 TOPS/W, significant power overhead)
- Prior single-lag analog correlators (poor area efficiency when replicated N times)
- Wideband delays via discrete elements (off-chip integration)

## Hardware Impact
Enables ultra-low-power always-on radar/communication signal processing for edge IoT, autonomous vehicles, and portable spectrum sensing. Analog compute paradigm shows path to orders-of-magnitude efficiency gains for signal processing beyond ML/neural nets.
