# VLSID 2025-036: E-DOSA - Efficient SNN Accelerator Dataflow

## Summary
Novel dataflow for Spiking Neural Network acceleration splitting inputs across time-batches and distributing kernels across processing elements. Achieves 1.2x average and 6.6x peak speedup.

## Problem
SNNs add temporal dimension to neural computation, requiring fundamentally different dataflow from ANNs. Sparse spike events and time-series processing create challenges for memory access patterns and data reuse.

## Method
- Time-batch splitting of inputs
- Kernel distribution across 2D PE array
- 2D systolic array architecture
- Optimized for memory access and data reuse

## Key Results
- **1.2x average speedup** over existing designs
- **6.6x peak speedup** in best cases
- Reduced memory access overhead
- Improved data reuse efficiency

## Applications
- Neuromorphic processors
- SNN inference accelerators
- Edge inference devices
- Brain-inspired computing systems
