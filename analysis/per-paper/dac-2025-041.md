# April: Accuracy-Improved Floating-Point Approximation for NN Accelerators

**Problem:** Floating-point approximation (e.g., Mitchell's logarithm) suffers precision loss and lacks practical integration into NN accelerators despite offering low-cost multiplication.

**Key Idea:** Combine down-sampling-based compensation for precision recovery with distribution-aware bias mechanisms; auto-generate configurable systolic arrays balancing accuracy and area.

**Approach:** Co-design framework with compensation circuit for FP error mitigation, flexible bias for data distributions, and parameterized systolic templates.

**Results:** 96% RMSE reduction, 34-52% area vs. INT8, maintaining or improving model accuracy.

**Theme:** Practical floating-point approximation for area-efficient neural network hardware.
