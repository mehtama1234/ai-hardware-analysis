# isscc-2025-127: 10b 3GS/s Time-Domain ADC with Metastability Correction

**Problem:** Time-domain (TD) ADCs suffer from unpredictable metastable trajectories in comparators that cause non-Gaussian error behaviors incompatible with low-bit-error-rate applications; prior metastability detection approaches constrain error probability gains by limiting available decision time on the critical path.

**Motivation:** TD ADCs demonstrate superior speed scaling over voltage-domain and SAR architectures; however, metastability artifacts at stringent time deadlines must be addressed without sacrificing speed or adding latency.

**Method:** This 10-bit, 3-billion-sample-per-second ADC detects and corrects for ambiguous comparator outputs (metastability — when a comparator gets a marginal input and oscillates between 0 and 1) by pipelining extra decision stages. Instead of trying to resolve the ambiguity within the main conversion path, it separates detection into additional latches that work in parallel, giving more time for diagnosis. Mutually exclusive correction logic (only one error path can fire at a time) then fixes the error, keeping the overall conversion speed intact.

**Key Novelty:** Pipelined unresolved-decision detection with mutually exclusive metastability correction maintaining multistep ADC latency while improving error probability.

**Contributions:**
- 10-bit 3GS/s time-domain ADC with metastability correction
- Mutually exclusive metastability correction logic
- Pipelined unresolved-decision detection achieving superior Pmet
- Wide common-mode input range support
