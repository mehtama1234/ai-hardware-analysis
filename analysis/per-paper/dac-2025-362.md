# Cayman: Custom Accelerator Generation with Control Flow and Data Access Optimization

## Summary
Automated end-to-end framework for synthesizing custom accelerators with kernel extraction, control flow support, and data access optimization.

## Key Results
- **8.0x speedup** vs SOTA HLS framework A
- **14.4x speedup** vs SOTA HLS framework B

## Core Innovation
Hierarchical program representation automatically selects and extracts kernels with complex control flows, eliminating manual kernel identification.

## Technique
Uses hierarchical IR for kernel candidate identification, specializes processor-accelerator interfaces for data access, and merges accelerators for reusability.
