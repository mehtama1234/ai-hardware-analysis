# A Compute Graph Simulation and Implementation Framework Targeting AMD Versal AI Engines

**Venue:** SC
**ID:** sc-2025-330
**Confidence:** low

## Problem Statement
Developing AI Engine (AIE) applications for AMD Versal requires separate host/accelerator codebases using AMD Vitis; this complicates development and integration with existing C++ code.

## Motivation
Unified C++ development would improve productivity; need to bridge C++ ecosystem with AIE dataflow graph compilation without Vitis's manual separation.

## Method
The framework provides a C++ library for simulating the compute graph (the sequence of operations performed on hardware) and an automatic code translator that converts your C++ code into AMD's AIE format. You write your application in standard C++, and the translator automatically generates the host and accelerator code, eliminating the need to manually maintain separate codebases.

## Key Novelty
The framework automatically translates a single C++ program into separate host and accelerator components using compile-time code execution, eliminating manual code separation.

## Contributions
1. C++ compute graph simulation library for AIE
2. Clang-based source-to-source translator
3. Performance comparable to hand-optimized Vitis code
4. Simplified AIE development workflow
