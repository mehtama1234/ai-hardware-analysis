# A Compute Graph Simulation and Implementation Framework Targeting AMD Versal AI Engines

**Venue:** SC
**ID:** sc-2025-330
**Confidence:** low

## Problem Statement
Developing AI Engine (AIE) applications for AMD Versal requires separate host/accelerator codebases using AMD Vitis; this complicates development and integration with existing C++ code.

## Motivation
Unified C++ development would improve productivity; need to bridge C++ ecosystem with AIE dataflow graph compilation without Vitis's manual separation.

## Method
Framework with two components: (1) compute graph simulation library in C++, (2) Clang-based source-to-source translator. Enables embedding AIE prototypes in C++, auto-transforms to AIE projects.

## Key Novelty
Unified C++ framework for AIE development; source-to-source translation eliminates manual host/accelerator separation; leverages C++ compile-time code execution.

## Contributions
1. C++ compute graph simulation library for AIE
2. Clang-based source-to-source translator
3. Performance comparable to hand-optimized Vitis code
4. Simplified AIE development workflow
