# Mitigating Resource Contention for Responsive On-device Machine Learning Inferences

**Venue:** ICCAD  
**ID:** iccad-2025-090

## Problem
On-device ML inference frameworks suffer from performance degradation under resource contention due to static and coarse-grained resource allocation in dynamic embedded system environments.

## Motivation
Responsive ML inference on edge devices requires adaptation to unpredictable resource availability and load fluctuations.

## Method
FlexOn framework combines fine-grained model segmentation with dynamic resource selection to rapidly adapt to runtime conditions. The framework selects execution segments based on available resources, utilizing both local and external compute as needed.

## Key Novelty
First work addressing resource contention in open embedded systems for better ML inference responsiveness.

## Contributions
- Fine-grained model segmentation enabling flexible execution strategies
- Dynamic resource selection mechanism adapting to runtime availability
- 54% average latency and 58% tail latency improvement across embedded platforms
