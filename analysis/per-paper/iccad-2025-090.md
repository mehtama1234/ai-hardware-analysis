# Mitigating Resource Contention for Responsive On-device Machine Learning Inferences

**Venue:** ICCAD  
**ID:** iccad-2025-090

## Problem
On-device ML inference frameworks suffer from performance degradation under resource contention due to static and coarse-grained resource allocation in dynamic embedded system environments.

## Motivation
Responsive ML inference on edge devices requires adaptation to unpredictable resource availability and load fluctuations.

## Method
FlexOn breaks a machine learning model into small, fine-grained segments and then dynamically selects where each segment runs based on available computing resources at that moment. As the device's workload and resource availability change during operation, the framework can run segments locally on the device or offload them to external processors and servers—whichever provides the best performance. This dynamic, fine-grained approach lets the framework adapt rapidly even when multiple programs are competing for the same computing resources.

## Key Novelty
This is the first work to address resource contention (programs competing for computing resources) in embedded systems, enabling faster and more responsive machine learning predictions.

## Contributions
- Fine-grained model segmentation enabling flexible execution strategies
- Dynamic resource selection mechanism adapting to runtime availability
- 54% average latency and 58% tail latency improvement across embedded platforms
