# hpca-2025-034: GSArch: Breaking Memory Barriers in 3D Gaussian Splatting Training via Architectural Support

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
3DGS training is bottlenecked by three memory inefficiencies during backward propagation: redundant off-chip DRAM loads for large hot Gaussians, expensive atomic gradient write operations, and severe bank conflicts during on-chip buffer reads.

## Motivation
Online 3DGS training for autonomous driving and embodied AI requires much higher training throughput; existing 3DGS accelerators address only rendering, not the backward pass.

## Method
GSArch fixes the three main slowdowns in 3D Gaussian Splatting training with three targeted hardware techniques. First, it identifies which Gaussian data objects are accessed repeatedly (called 'hot' Gaussians) and stores them in fast on-chip memory rather than fetching them from slower main memory each time—this eliminates the dominant source of redundant memory traffic. Second, it recognizes that many gradients (values used to update the model during training) contribute very little to the final result, so it skips the expensive atomic write operations for these low-value gradients. Third, it reorganizes memory read requests to avoid 'bank conflicts'—a problem where multiple reads hitting the same memory location simultaneously force them to queue up—by bundling conflicting requests into non-conflicting groups. These three changes together speed up the backward pass of 3DGS training.

## Key Novelty
The core insight is automatically identifying which Gaussians are used repeatedly and caching them in fast on-chip memory instead of constantly fetching them from slower main memory, which eliminates the single biggest bottleneck in 3DGS training.

## Contributions
- Characterization of three 3DGS training backward-pass bottlenecks.
- Hybrid memory management with hot/cold Gaussian classification and on-chip buffering.
- Gradient informativeness filtering to skip low-contribution atomic writes.
- Rearrangement unit eliminating bank conflicts; up to 6.49x speedup over A100, 15.42x over Jetson AGX Xavier with negligible quality loss.
