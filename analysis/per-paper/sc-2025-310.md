# SC-2025-310: DiOMP-Offloading: Toward Portable Distributed Heterogeneous OpenMP

## Summary
This work presents DiOMP-Offloading, a unified programming framework that extends OpenMP target offloading with Partitioned Global Address Space (PGAS) semantics to support distributed GPU memory and portable device-side collective communication. Built on LLVM-OpenMP and GASNet-EX, it simplifies heterogeneous HPC programming while maintaining vendor portability.

## Key Contributions
1. **Unified OpenMP+PGAS programming model** for distributed heterogeneous systems
2. **OMPCCL (OpenMP GPU Collective Communication Layer)** for vendor-neutral device collectives
3. **Support for symmetric/asymmetric GPU allocations** with remote put/get operations
4. **Superior performance** on NVIDIA A100, Grace Hopper, and AMD MI250X platforms

## Technical Approach
- OpenMP target offloading extended with PGAS global address space
- Centralized memory management for distributed GPU systems
- OMPCCL abstraction layer providing portable collective operations
- GASNet-EX backend for efficient inter-node communication
- Unified memory allocation and lifecycle management

## Hardware & Systems
- NVIDIA GPUs: A100, Grace Hopper
- AMD MI250X accelerators
- Multi-GPU systems with NVLink/Infinity Fabric
- Distributed heterogeneous supercomputers

## Workloads & Evaluation
- **Scope**: Large-scale NVIDIA A100, Grace Hopper, AMD MI250X systems
- **Comparison**: Against traditional MPI+OpenMP+device-library approaches
- **Metrics**: Application performance, scalability, programmability improvements
