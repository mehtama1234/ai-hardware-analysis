# Meta-Heuristic Optimization of Custom Heterogeneous Blocks Defined eFPGA Design

**Venue:** VLSID
**Authors:** D. V. Bhargav, G. Pradyumna, Madhav Rao

## Problem Statement
Modern Field-Programmable Gate Arrays (FPGAs) are highly versatile, with reconfigurable logic functionality that allows designers to create custom designs

## Key Innovation
Novel propose approach

## Method
The approach uses NSGA-II, a genetic algorithm that explores many potential designs and identifies the best combinations across competing objectives. It automatically tunes the number of basic logic blocks (CLBs), signal-processing units (DSPs), and memory blocks (BRAMs) in an FPGA design. By evaluating multiple configurations, it finds architectures that minimize both critical path delay—the time electrical signals take to traverse the circuit—and power consumption, tailored to the specific workload.
