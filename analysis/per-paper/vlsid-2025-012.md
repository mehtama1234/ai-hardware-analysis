# Meta-Heuristic Optimization of Custom Heterogeneous Blocks Defined eFPGA Design

**Venue:** VLSID
**Authors:** D. V. Bhargav, G. Pradyumna, Madhav Rao

## Problem Statement
Modern Field-Programmable Gate Arrays (FPGAs) are highly versatile, with reconfigurable logic functionality that allows designers to create custom designs

## Key Innovation
Novel propose approach

## Method
proposed work employs Non-dominated Sorting Genetic Algorithm-II (NSGA-II) to evolve efficient and high-performing eFPGA architectures with reduced critical path delay and power defined by a sufficient number of Configurable Logic Blocks (CLBs), custom Digital Signal Processors (DSPs) and Block RAM (BRAMs) for targetting workload under consideration
