# GTA: GPU-Accelerated Track Assignment with Lightweight Lookup Table for Conflict Detection

**Venue:** ICCAD  
**Paper ID:** iccad-2025-268

## Problem Statement
Track assignment in VLSI routing is computationally intensive and typically CPU-only; existing approaches lack design-rule awareness for accurate congestion analysis.

## Motivation
Track assignment bridges global and detailed routing; design-rule-aware and GPU-accelerated approaches can accelerate the full routing pipeline.

## Method
GTA accelerates track assignment—the process of placing wires along predefined paths on a chip—by running it on a GPU (graphics processor) instead of a CPU, and uses lightweight lookup tables to quickly detect when placements conflict. Unlike prior GPU approaches, it accounts for design rules (the physical and electrical constraints layouts must satisfy), enabling accurate congestion analysis and high-quality starting solutions for detailed routing.

## Key Novelty
GTA is the first track assignment system that combines GPU acceleration with design-rule awareness to improve routing quality.

## Contributions

1. 20× runtime speedup
2. 25% CPU peak memory reduction
3. Competitive detailed routing quality
