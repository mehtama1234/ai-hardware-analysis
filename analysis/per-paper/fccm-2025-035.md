# C2OPU: Hybrid Compute-in-Memory and Coarse-Grained Reconfigurable Architecture for Overlay Processing of Transformers

**Problem:** Von Neumann architecture-based accelerators are memory-bound when processing Transformers, and computing-in-memory (CIM) processors suffer from computing pattern mismatches and low precision that limit transformer acceleration effectiveness.

**Method:** C2OPU is a hybrid dual-core processor combining CIM arrays for weight-stationary vector-matrix multiplications with a coarse-grained reconfigurable architecture (CGRA) to handle computing pattern mismatches and precision limitations. An accuracy-bound workload allocation strategy balances throughput and accuracy by considering non-ideal analog computing characteristics. A compiler automatically determines optimal system configurations when transformer models change.

**Novelty:** Hybrid architecture coupling CIM for efficient matrix operations with CGRA for flexible high-precision computation, enabled by accuracy-bound workload allocation and automated compilation.
