# C2OPU: Hybrid Compute-in-Memory and Coarse-Grained Reconfigurable Architecture for Overlay Processing of Transformers

**Problem:** Von Neumann architecture-based accelerators are memory-bound when processing Transformers, and computing-in-memory (CIM) processors suffer from computing pattern mismatches and low precision that limit transformer acceleration effectiveness.

**Method:** C2OPU combines two hardware units: computing-in-memory arrays (which perform calculations directly where data is stored) optimized for weight-stationary vector-matrix multiplications (where weights stay fixed during matrix operations), and a coarse-grained reconfigurable architecture or CGRA (a flexible unit that can be rewired to handle different computation patterns and higher precision). An accuracy-bound workload allocation strategy assigns tasks between these units by predicting how analog computing errors will affect results, balancing speed with accuracy. A compiler automatically determines the optimal configuration as different transformer models are processed.

**Novelty:** An accuracy-bound workload allocation strategy, implemented through automated compilation, automatically distributes transformer operations between computing-in-memory arrays (which efficiently execute matrix math but with limited precision) and a coarse-grained reconfigurable architecture (which provides flexible, high-precision computation).
