# isscc-2025-130: 28nm Reconfigurable Multi-Scheme FHE Processor

**Problem:** Fully homomorphic encryption (FHE) enables privacy-preserving machine learning but incurs prohibitive power consumption and fabrication costs for bootstrapping operations; supporting multiple FHE schemes (BGV, BFV, CKKS) and diverse client/server primitives while managing intensive memory bottlenecks remains challenging.

**Motivation:** Privacy-preserving ML for collaborative computation demands practical FHE hardware; leveled FHE with designated multiplication depth is more practical than full FHE but requires hardware support for multiple schemes and efficient data movement.

**Method:** The processor is built on 28-nanometer technology and can be reconfigured to run three encryption schemes (BGV, BFV, CKKS) that allow computation directly on encrypted data—a property called homomorphic encryption. It optimizes circuits for both the client side (requesting encrypted computation) and server side (performing computation on encrypted data). The design reduces overhead from expensive operations like NTT transforms (mathematical operations essential to these encryption schemes) and polynomial automorphisms (rearrangements of encrypted values), and optimizes how data moves within the chip to reduce memory bottlenecks.

**Key Novelty:** First silicon-proven reconfigurable multi-scheme FHE processor supporting both client-side and server-side encrypted computation patterns with integrated memory optimization.

**Contributions:**
- 28nm reconfigurable multi-scheme FHE processor (BGV, BFV, CKKS)
- 4.05µJ/encryption energy efficiency
- 8.72 kHMul/s throughput for polynomial multiplication
- First silicon-proven solution for both client and server computing patterns
