# HLSTester: Efficient Testing of Behavioral Discrepancies with LLMs for High-Level Synthesis

**Paper ID:** iccad-2025-235  
**Venue:** ICCAD

## Problem

High-level synthesis generates hardware from C/C++ programs with synthesis directives, but hardware-specific and platform-dependent characteristics can introduce behavioral discrepancies between original software and synthesized circuits. Existing testing methods require significant human effort and are immature.

## Motivation

HLS tools are increasingly adopted for rapid prototyping, but verifying equivalence between behavioral C/C++ and synthesized hardware is critical and currently manual.

## Method

Proposes HLSTester, an LLM-aided testing framework combining: (1) LLM-guided testbench generation from existing C/C++ tests, adapting syntax to HLS compatibility, (2) backward slicing to identify key variables in both C/C++ and HLS programs for runtime spectrum analysis, (3) dynamic mutation with LLM-based progressive reasoning for test input generation, and (4) redundancy-aware filtering to skip repetitive hardware testing.

## Key Novelty

First LLM-aided testing framework for HLS behavioral verification that significantly accelerates testing while achieving higher pass rates than traditional methods.

## Contributions

- LLM-guided HLS-compatible testbench generation reducing hallucinations
- Backward slicing for key variable identification in discrepancy analysis
- Dynamic mutation with LLM reasoning chains for test generation
- Redundancy-aware filtering reducing repetitive hardware testing
- Higher testbench pass rates than traditional methods and direct LLM use
