# asplos-2025-137: RTL Verification for Secure Speculation Using Contract Shadow Logic

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Out-of-order processors face speculative execution attacks, and proposed hardware mitigations lack formal, RTL-level security proofs, leaving unknown vulnerabilities as new attacks continue to emerge.

## Motivation
Formal and rigorous evaluation of processor hardware designs against speculative execution attacks is urgently needed to break the cycle of ad-hoc mitigations and newly discovered exploits.

## Method
Contract Shadow Logic augments processor RTL with shadow logic encoding speculative execution contracts that define what information the processor's speculative state may leak. Information flow through speculative pipelines is tracked at RTL level, and model checking verifies that no execution trace violates the contract.

## Key Novelty
Contract-encoding shadow logic attached directly to processor RTL enables automated formal verification of speculative execution security properties at the implementation level.
