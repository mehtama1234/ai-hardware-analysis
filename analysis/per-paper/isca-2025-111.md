# isca-2025-111 — Assassyn: A Unified Abstraction for Architectural Simulation and Implementation

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Architecture developers maintain two separate codebases—a simulation model for design-space exploration and an RTL implementation—creating coordination overhead, alignment errors, and duplicated effort that slow hardware development. Programming directly in RTL is error-prone and low-productivity, forcing teams to decouple modeling from implementation.

## Motivation
As transistor counts grow with technology scaling, the cost of misalignment between simulation and RTL implementation rises, making a unified high-level programming abstraction that generates both accurate simulators and competitive RTL essential for productive architecture research.

## Method
Assassyn provides a high-level, general-purpose programming framework built on asynchronous event handling—a behavioral model common to both hardware design and software engineering. Developers write a single Assassyn program; the framework compiles it to both a cycle-accurate simulator and synthesizable RTL, enforcing structural alignment by construction. The asynchronous event abstraction covers a broad class of architectures from pipeline components to out-of-order CPUs and application-specific accelerators.

## Key Novelty
A single programming abstraction based on asynchronous event handling that simultaneously generates aligned cycle-accurate simulators and synthesizable RTL, eliminating the dual-codebase problem by construction.

## Contributions
- Assassyn: a unified high-level framework for architectural simulation and RTL implementation using asynchronous event semantics.
- Demonstrated expressiveness across a wide architecture range: pipeline components, application-specific accelerators, and out-of-order CPUs.
- 2.2-8.1x simulation speedup with perfect behavioral alignment to generated RTL, using 70% fewer lines of code than conventional approaches.
- Generated RTL achieves comparable perf/area to hand-crafted RTL and 6x better perf/area than HLS-generated RTL with only 1.26x code overhead.

## Metrics
- **Speedup:** 2.2-8.1x simulation speedup over baseline simulators
- **Area:** comparable perf/area to hand-crafted RTL; 6x perf/area vs. HLS-generated RTL
- **Other:** 70% reduction in lines of code; 1.26x code overhead vs. hand-crafted RTL
