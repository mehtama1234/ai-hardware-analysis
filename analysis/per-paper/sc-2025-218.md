# sc-2025-218: mLR - Scalable Laminography Reconstruction via Memoization

## Overview
Memoization-based optimization for ADMM-FFT laminography reconstruction, reducing computation time and memory consumption through FFT operation caching and variable offloading.

## Key Problem
ADMM-FFT provides accurate laminography reconstruction but suffers from:
- Excessive computation time due to repeated FFT operations
- Large memory consumption
- Limited to small problem sizes

## Approach
1. **Memoization**: Identify and cache similar FFT operations across ADMM iterations
2. **Variable offloading**: Move intermediate variables to main memory to reduce GPU memory pressure
3. **Multi-GPU scaling**: Distribute across nodes and multiple GPUs per node

## Contributions
- Memoization technique for redundant FFT elimination
- Variable offloading strategy for memory efficiency
- Multi-GPU and multi-node scaling methodology
- First ADMM-FFT solution for 2K×2K×2K problems

## Performance Results
- **Average improvement**: 52.8%
- **Peak improvement**: 65.4%
- **Largest problem**: 2K×2K×2K (previously infeasible)

## Hardware Target
Multi-GPU systems and GPU clusters with CPU-GPU memory hierarchy
