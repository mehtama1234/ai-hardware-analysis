# LVM-MO: A Large Vision Model Pioneer on Full-Chip Mask Optimization

**Venue:** DAC  
**ID:** dac-2025-356

## Problem
Full-chip mask optimization requires handling entire layouts with optical proximity and process bias effects; existing clip-level approaches show limited correction, poor generalization, and inefficiency at full-chip scale.

## Motivation
Post-Moore semiconductor manufacturing requires pivotal full-chip MO balancing correction fidelity with computational efficiency.

## Key Innovation
Foundation large vision model for full-chip mask optimization with lithography-aware layout feature extraction, enabling high-fidelity full-chip processing.

## Method
The approach trains a large vision model—a machine-learning system trained on massive amounts of image data—to optimize chip masks at full-chip scale. It frames mask optimization as a vision task rather than a traditional engineering problem, which lets the model learn from many different mask patterns and understand how different shapes influence each other. The model incorporates knowledge of optical physics (how light behaves through manufacturing) and lithography chemistry (how chemicals etch patterns), so it can work at full-chip scale more accurately than previous approaches that only handled small isolated regions.

## Contributions
- Data-driven large vision model for mask optimization
- Lithography-aware layout feature extractor
- Foundation model trained on massive lithography dataset
- Improved fidelity, correction speed, and full-chip scalability
