# An Efficient Parallel Fault Simulator for Functional Patterns on Multi-Core Systems

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Accelerate functional pattern fault simulation on multi-core CPUs via three complementary techniques: fault filtering (remove non-critical), grouping (batch similar), and parallelization (distribute across cores).

## Problem
Functional pattern fault simulation is essential for safety verification but computationally expensive; software lacks efficient parallelization.

## Method
The approach uses three techniques running on a multi-core CPU (a processor with multiple processing units working together) to speed up the simulation of functional pattern faults. First, it removes faults that can be mathematically proven to not matter, so the simulator doesn't waste time on them. Second, it groups similar faults together so they can share calculations instead of being simulated separately. Third, it distributes the remaining work across the CPU's cores so multiple faults are tested at the same time.
