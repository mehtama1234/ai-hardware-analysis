# An Efficient Parallel Fault Simulator for Functional Patterns on Multi-Core Systems

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Accelerate functional pattern fault simulation on multi-core CPUs via three complementary techniques: fault filtering (remove non-critical), grouping (batch similar), and parallelization (distribute across cores).

## Problem
Functional pattern fault simulation is essential for safety verification but computationally expensive; software lacks efficient parallelization.

## Method
- **Fault filtering:** Prunes provably non-critical faults early
- **Fault grouping:** Batches similar faults to share computation
- **CPU parallelism:** Distributes faults across available cores
- All techniques tailored to functional pattern characteristics

## Key Results
- **79x average speedup** on 48-core system vs commercial tool
