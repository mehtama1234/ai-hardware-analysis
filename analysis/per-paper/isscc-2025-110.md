# isscc-2025-110: p-Circuits—Probabilistic Computing Paradigm

**Problem:** Traditional analog-digital trade-offs limit efficiency; circuits requiring probabilistic computation need ADC/DAC overhead.

**Method:** p-circuits avoid the power and area costs of converting between analog and digital by using a hybrid approach: inputs and outputs look digital, but the actual computation happens through probability. Each output is a random 0 or 1, where how often it outputs 1 (versus 0) is controlled by an analog function that smoothly responds to the inputs. By manipulating these probabilities, the circuit performs calculations without ever converting signals between analog and digital domains.

**Key Novelty:** Probabilistic circuit paradigm enabling stochastic computation without conversion overhead.

**Main Results:** New computational model bridging analog-digital gap; framework for hybrid processing.
