# isscc-2025-110: p-Circuits—Probabilistic Computing Paradigm

**Problem:** Traditional analog-digital trade-offs limit efficiency; circuits requiring probabilistic computation need ADC/DAC overhead.

**Method:** p-circuits use digital-like interfaces (no ADC/DAC) with outputs as random binary variables; probability P(B=1) governed by analog function A(inputs) continuously varying [0,1].

**Key Novelty:** Probabilistic circuit paradigm enabling stochastic computation without conversion overhead.

**Main Results:** New computational model bridging analog-digital gap; framework for hybrid processing.
