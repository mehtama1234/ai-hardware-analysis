# GoPTX: Fine-grained GPU Kernel Fusion by PTX-level Instruction Flow Weaving

**Venue:** DAC  
**ID:** dac-2025-358

## Problem
Concurrent kernel execution misses opportunities to improve instruction-level parallelism through inter-kernel resource sharing due to sequential default execution.

## Motivation
GPU kernel fusion can boost efficiency, but existing approaches overlook ILP improvements from deliberate instruction-level coordination.

## Key Innovation
PTX-level instruction flow weaving enabling fine-grained interleaving across kernel boundaries to improve ILP while minimizing stalls.

## Method
Performs fine-grained fusion at PTX instruction level using merged CFG, interleaving instructions from multiple kernels to minimize data hazard stalls; proposes latency-aware algorithm and adaptive code slicing.

## Contributions
- PTX-level kernel fusion with merged CFG
- Instruction interleaving minimizing data hazard stalls
- Latency-aware weaving algorithm
- Adaptive code slicing for larger scheduling space
- 11.2% average speedup, 23% max vs concurrent execution

## Results
Average 11.2% speedup, maximum 23% improvement over baseline concurrent execution; enhanced resource utilization.
