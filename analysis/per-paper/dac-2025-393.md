# dac-2025-393: DataMaestro: A Versatile and Efficient Data Streaming Engine Bringing Decoupled Memory Access To Dataflow Accelerators

**Problem:** DNN inference on dataflow accelerators suffers from data movement bottlenecks and bank conflicts.

**Method:** DataMaestro is a specialized data-fetching unit that speeds up deep learning inference on dataflow accelerators. It fetches data before the processor needs it (called prefetch) and dynamically switches how it accesses memory to avoid conflicts when multiple accesses try to hit the same memory location simultaneously (bank conflicts). It can also reshape data as it fetches it to use less memory. The system integrates with matrix-multiply (GeMM) and quantization accelerators on a RISC-V processor, with an FPGA prototype and silicon synthesis (VLSI) validation.

**Key Novelty:** Decoupled access/execute architecture with programmable prefetch and dynamic bank-conflict resolution for dataflow accelerators.

**Contributions:**
- Programmable flexible access patterns
- Dynamic addressing mode switching
- On-the-fly data manipulation
- Near-100% GeMM utilization (1.05-21.39x SOTA)

**Confidence:** low (abstract-only)
