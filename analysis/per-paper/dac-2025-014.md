# Dynamic Local Usage: An Accurate Model for Usage of Tile-Internal Wiring in Global Routing

**Problem:** Static pre-estimated local wiring models fail to account for exact wire geometry and pin-shape interactions, causing detailed routing failures.

**Method:** Dynamic Local Usage (DLU) model evaluates wiring based on exact wire shapes and pin geometries; tip-to-tip penalties model packing density; routing algorithms optimize per DLU congestion.

**Key Contribution:** Exact-geometry-based model replaces static estimates, improving pre-detailed-routing predictions.

**Results:** Fewer vias, design-rule violations, and timing issues after detailed routing on 3nm/5nm nodes vs industrial router.
