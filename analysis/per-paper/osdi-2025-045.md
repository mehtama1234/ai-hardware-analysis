# Decouple and Decompose: Scaling Resource Allocation with DeDe

**Problem:** Resource allocation optimization in cloud systems has grown beyond the capacity of commercial solvers as problem scale increases. Existing approaches either specialize in narrow domains or impose workload-specific assumptions that limit generalizability.

**Method:** DeDe starts by recognizing that resource allocation problems (the challenge of distributing resources to meet competing demands) have a natural separation: the constraints governing resources are independent from the constraints governing demands. It breaks the optimization into alternating subproblems for each resource and each demand, which can be solved both efficiently and in parallel. The framework is provided as a Python package with an intuitive modeling interface.

**Novelty:** The key insight is that resource and demand constraints in allocation problems are naturally separable, making it possible to decompose them into parallelizable subproblems.
