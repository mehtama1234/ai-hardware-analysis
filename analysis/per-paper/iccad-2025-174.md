# Uncertainty-Guided Live Measurement Sequencing for Fast SAR ADC Linearity Testing

**Authors:** Thorben Schey, Khaled Karoonlatifi, Michael Weyrich, Andrey Morozov 0001

**Venue:** ICCAD

## Summary
Proposes adaptive closed-loop testing for SAR ADCs using Extended Kalman Filter and uncertainty-guided measurement sequencing to reduce test time and computational overhead.

## Key Contributions
- Real-time behavioral model refinement using Extended Kalman Filter
- Uncertainty-guided measurement point selection for information maximization
- Direct estimation of INL-determining capacitor mismatch parameters
- Substantial reductions in test time and computational overhead
