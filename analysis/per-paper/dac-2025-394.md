# dac-2025-394: PacQ: A SIMT Microarchitecture for Efficient Dataflow in Hyper-asymmetric GEMMs

**Problem:** Weight-only quantized LLMs must unpack INT weights to FP before GEMM on SIMT architectures, negating compute efficiency.

**Method:** PacQ optimizes three things together at the tile level: how low-precision integer weights are packed in memory, how data flows through the processor, and the design of a multiplier that works directly on packed weights. Normally, weights must be unpacked and converted back to full-precision floating-point numbers before multiplication—a slow process that wastes the efficiency gains of using low-precision weights. Because PacQ's packing, dataflow, and multiplier are designed for each other, no unpacking is needed. This co-optimized design processes multiple weights in parallel and fits into SIMT processors (which run the same instruction across many parallel threads).

**Key Novelty:** Custom FP-INT multiplier co-designed with packing/dataflow to directly process packed weights without unpacking.

**Contributions:**
- Tile-level packing strategy for INT weights
- Co-optimized dataflow strategy
- Custom FP-INT multiplier for parallel processing
- 1.99x speedup, 81.4% EDP reduction

**Confidence:** low (abstract-only)
