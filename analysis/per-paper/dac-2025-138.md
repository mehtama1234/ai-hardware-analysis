# Generalizable Lithographic Hotspot Detection via Few-Shot Meta-Learning

## Problem
CNN-based lithographic hotspot detectors overfit and fail to generalize to unseen circuit layouts despite being trained on existing designs, limiting applicability across diverse design styles at the same technology node.

## Method
Few-shot meta-learning framework using asynchronous multi-task learning with a multi-gate mixture-of-experts (MMoE) model that separately updates CNN feature extraction and classification components. Layout topology-based sampling strategy enhances few-shot adaptation, enabling rapid generalization to new designs with only one training layout clip.

## Key Results
- Superior generalization capabilities to unseen designs vs prior art
- Enables adaptation with only one training layout sample
- Tested on ICCAD 2012 and 2019 datasets
