# Generalizable Lithographic Hotspot Detection via Few-Shot Meta-Learning

## Problem
CNN-based lithographic hotspot detectors overfit and fail to generalize to unseen circuit layouts despite being trained on existing designs, limiting applicability across diverse design styles at the same technology node.

## Method
The method combines meta-learning (training a system to learn how to adapt quickly to new problems) with a multi-gate mixture-of-experts model (multiple specialized sub-networks with several decision gates routing inputs to the right expert) and asynchronous multi-task learning (where different components are trained independently rather than all at once). The CNN's feature detection (identifying hotspot indicators) and classification (deciding if it's a hotspot) components are updated separately, which allows them to specialize independently. A topology-based sampling strategy (selecting training examples based on circuit structure) guides the adaptation process, enabling the system to generalize to new designs using only one training layout clip.

## Key Results
- Superior generalization capabilities to unseen designs vs prior art
- Enables adaptation with only one training layout sample
- Tested on ICCAD 2012 and 2019 datasets
