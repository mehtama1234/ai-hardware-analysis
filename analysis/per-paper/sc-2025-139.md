# Extending the C++ Execution Control Library to Support Dynamic Parallel Runtime Systems

**Venue:** SC 2025  
**Authors:** Ian Henriksen, Jan Ciesko, Stephen L. Olivier

## Problem
C++26 execution control library (senders and receivers) provides standardized asynchronous work coordination interface, but interoperability with dynamic runtime systems remains unexplored. Dynamic runtimes like Qthreads discover and create work at runtime with concurrency vastly exceeding hardware resources.

## Motivation
C++26 execution control idioms enable structured parallelism and composable heterogeneous programming. However, applicability to dynamic runtime systems is untested. Demonstrating that the standard interface extends to dynamic work discovery is critical for validating the standard's expressiveness and enabling broader adoption across diverse parallel runtime ecosystems.

## Method
Implement a sender-based interface for the Qthreads user-level threading library by:
- Mapping C++26 sender/receiver concepts to Qthreads runtime abstractions
- Supporting dynamic work discovery and creation during execution
- Handling massive oversubscription (concurrency >> hardware threads)
- Measuring overhead of the interoperability layer

## Key Novelty
Demonstrates that C++26 execution control patterns are applicable to dynamic runtime systems with runtime work discovery, extending beyond traditional static parallel frameworks.

## Contributions
1. Sender-based interface implementation for Qthreads user-level threading library
2. Validation of C++26 execution control patterns for dynamic parallelism
3. Low-overhead interoperability layer enabling standard interface usage
4. Identification of additional optimization opportunities through standardized interface
