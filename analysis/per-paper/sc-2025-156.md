# SC-2025-156: Arithmetic Formats for Eigenvalue Computation

## Summary
Comprehensive evaluation of Implicitly Restarted Arnoldi method across emerging floating-point formats (OFP8, bfloat16, posit, takum) using real-world matrices.

## Problem
- Emerging arithmetic formats lack evaluation on standard eigenvalue solvers
- ARPACK (IRLM) not systematically studied in alternative formats
- Numerical stability and performance unclear for real applications

## Evaluation
**Formats tested**:
- OFP8 (E4M3, E5M2): 8-bit formats from NVIDIA
- **bfloat16**: Brain float (16-bit reduced precision)
- **Posit**: Tapered-precision format
- **Takum**: Alternative tapered-precision format

**Datasets**:
1. SuiteSparse Matrix Collection: varying sizes, condition numbers
2. Network Repository: graph-based matrices

## Key Findings
| Format | Suitability | Notes |
|--------|-------------|-------|
| **Posit** | Good | Improved performance vs IEEE 754 |
| **Takum** | **Best** | Avoids posit weaknesses |
| **bfloat16** | Good | Better than float16 |
| **OFP8** | Poor | Unsuitable for general-purpose |

## Implications
- Takum shows promise for scientific computing at reduced precision
- Posit limitations identified for eigenvalue problems
- OFP8 primarily for specialized AI workloads (not general HPC)

## Applications
- Large-scale PCA, spectral clustering
- Network analysis
- Scientific simulations
