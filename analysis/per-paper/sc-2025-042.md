# sc-2025-042: Lowering and Runtime Support for Fortran's Multi-Image Parallel Features using LLVM Flang, PRIF, and Caffeine

## Summary
Provides complete implementation of Fortran 2023 multi-image parallel features (SPMD execution model and coarray distributed memory) through LLVM Flang compiler, PRIF intermediate interface, and Caffeine runtime library.

## Problem
- Fortran 2023 includes modern parallel features (coarrays, multi-image)
- Existing implementations incomplete or fragmented
- Open-source MLIR/LLVM ecosystem lacked Fortran support for new features
- Need for complete, validated stack

## Method
The work extends the LLVM Flang compiler to translate Fortran 2023 code containing multi-image parallelism (running the same program across multiple processors simultaneously) into PRIF, a standard intermediate form called the Parallel Runtime Interface for Fortran. The Caffeine parallel runtime is built to execute PRIF instructions. Finally, an MLIR dialect—a standardized notation used in compilers to represent code—is designed specifically for Fortran's multi-image features so different compiler tools can reuse the same representation.

## Key Innovations
1. **Complete open-source stack**: Compiler + intermediate + runtime
2. **MLIR dialect**: First MLIR dialect for Fortran parallelism
3. **PRIF abstraction**: Clean interface between compiler and runtime
4. **Competitive performance**: Matches established GCC/OpenCoarrays

## Hardware Targets

## Technical Components
1. **Fortran features**: Multi-image SPMD model, coarray distributed arrays
2. **PRIF**: Abstraction layer for parallelism
3. **MLIR dialect**: First-class representation of Fortran parallel constructs
4. **Caffeine**: Lightweight parallel runtime
