# UniCAIM: Unified CAM/CIM Architecture with Static-Dynamic KV Cache Pruning for Efficient Long-Context LLM Inference

## Summary
FeFET-based unified CAM/CIM architecture supporting flexible static and dynamic KV cache pruning for long-context Transformer inference.

## Key Results
- **8.2x to 831x AEDP reduction** vs SOTA CIM accelerators
- **High accuracy** comparable with dense attention
- **Three computation modes** for flexible pruning strategies

## Core Innovation
First unified CAM/CIM leveraging FeFET multi-level storage for simultaneous support of static pattern pruning and dynamic O(1) similarity-based pruning.

## Technique
FeFET-based cell design for signed multibit KV storage; CAM mode for O(1) dynamic pruning, charge-domain CIM for flexible static pruning, current-domain for exact computation.
