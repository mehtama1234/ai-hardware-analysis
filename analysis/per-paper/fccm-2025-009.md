# An Energy-Efficient FPGA-Based Vision Transformer Accelerator via Software-Hardware Co-Design

**Problem:** Vision Transformer models contain a large number of parameters and intensive matrix computations, making deployment on resource-constrained FPGAs fundamentally challenging due to memory and compute capacity limitations.

**Method:** The approach combines end-to-end quantization of ViT models with a multi-kernel hardware architecture and time-multiplexed scheduling strategy. Customized hardware is implemented for key ViT operations (likely attention and linear layers), enabling efficient resource utilization and memory optimization while maintaining model accuracy.

**Novelty:** Integration of multi-kernel architecture with time-multiplexed scheduling for quantized ViT acceleration on resource-constrained FPGAs.
