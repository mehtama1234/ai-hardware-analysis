# An Energy-Efficient FPGA-Based Vision Transformer Accelerator via Software-Hardware Co-Design

**Problem:** Vision Transformer models contain a large number of parameters and intensive matrix computations, making deployment on resource-constrained FPGAs fundamentally challenging due to memory and compute capacity limitations.

**Method:** The approach shrinks Vision Transformer models through quantization—converting numbers from 32-bit floating point to lower precision to reduce memory and computation needs. It then implements a multi-kernel hardware design on an FPGA (a reconfigurable hardware chip) where processing units share resources by taking turns executing different operations (time-multiplexed scheduling). Custom hardware accelerators are built specifically for the most expensive ViT computations: attention mechanisms (finding important patterns in images) and linear layers (applying learned transformations). This combination lets the complete model fit and run efficiently on memory-limited FPGAs while preserving its accuracy.

**Novelty:** The innovation combines quantization, multi-kernel hardware, and time-multiplexed scheduling (where processing units take turns using shared resources) into a unified design that lets Vision Transformer models run efficiently on memory-limited FPGAs.
