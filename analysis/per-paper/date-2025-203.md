# PEARL: FPGA-Based Reinforcement Learning Acceleration with Pipelined Parallel Environments

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Accelerate RL training by instantiating multiple parallel environments on FPGA with pipelined execution that overlaps data transfer with computation.

## Problem
CPU-based RL frameworks bottleneck on multi-environment updates; data transfer latency limits scaling of parallel environments.

## Method
- **Pipelined parallel environment architecture** on FPGA
- Data transfer overlapped with computation time to hide I/O latency
- Flexible environment framework for custom RL tasks
- Scales to 43,008+ simultaneous environments

## Key Results
- **4.36-972.6x speedup** vs fastest software framework
- Scales to 43k environments with **only 3% power increase**
- **7-15% training time reduction** when integrated with existing RL algorithms
- Open-source repository available

## Hardware Targets
FPGA

## Technique Category
parallelism, dataflow

## Workloads
RL (Reinforcement Learning)

## Limitations
FPGA-specific; cloud-scale distributed RL and memory bandwidth constraints for very large environments not addressed.
