# SERA-Float: A Soft Error Resilient Approximate Floating-Point Computing Format

**Venue:** ICCAD
**ID:** iccad-2025-143
**Confidence:** low

## Problem
Approximate floating-point computing lacks resilience to soft errors, and interaction between approximation-induced errors and soft errors can cause exceptions or unexpected failures in DNN inference.

## Motivation
Soft error resilient approximation formats enable energy-efficient neural network inference without sacrificing reliability.

## Method
SERA-Float protects the most important bits (sign and exponent, which control a number's sign and magnitude) using error-correcting codes—redundant bits that can automatically fix errors. Rather than discarding the least important precision bits, it keeps 8 valid mantissa bits (the digits representing the number) and intelligently tracks which bits are critical to prevent overflow (when numbers get too large), underflow (when numbers get too small), and NaN exceptions (invalid results). Smaller arithmetic circuits can exploit this format, reducing energy use while maintaining protection against random hardware errors.

## Key Novelty
SERA-Float combines error-correcting codes with critical bit tracking to protect approximate floating-point computation against both hardware errors and the exceptions they trigger.

## Contributions
- ECC-protected sign and exponent bits for soft error resilience
- Critical bit tracking to prevent floating-point exceptions
- 8-bit valid mantissa approach replacing truncation
- Up to 80.3% energy savings per multiplication with 0.9% accuracy loss
