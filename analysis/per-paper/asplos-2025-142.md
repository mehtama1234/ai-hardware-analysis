# asplos-2025-142: UniZK: Accelerating Zero-Knowledge Proof with Unified Hardware and Flexible Kernel Mapping

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Emerging hash-based ZKP protocols introduce diverse computation kernels (NTT, hash functions, polynomial arithmetic) that existing ZKP accelerators cannot efficiently handle, since prior designs are built for elliptic-curve protocols with dedicated per-kernel units that waste area for multi-kernel workloads.

## Motivation
Hash-based ZKP protocols greatly reduce algorithmic complexity vs. elliptic-curve protocols for privacy-preserving blockchains and ZK-ML, but their diverse kernel mix creates an accelerator design challenge.

## Method
UniZK builds a systolic array—a grid of specialized processors that work together on repetitive computations—and enhances it with extra direct connections between nearby processors and a new vector processing mode. This makes the single array flexible enough to execute all three types of zero-knowledge proof computations: number-theoretic transforms (NTT, a fast polynomial transform), cryptographic hash functions, and general polynomial operations. Intelligent mapping strategies route each computation across the shared hardware optimally, keeping all processors utilized instead of having separate dedicated units for each computation type.

## Key Novelty
The innovation is a systolic array with added local connections and vector processing that works as a unified, efficient hardware substrate for all zero-knowledge proof computations by mapping kernels flexibly, instead of having separate hardware for each computation type.

## Metrics
- 97x speedup over CPU, 46x over GPU (same protocols)
- 840x speedup over previous ZKP ASICs (different protocols)

## Hardware Target
ASIC

## Baselines
CPU ZKP implementations, GPU ZKP implementations, prior ZKP FPGA/ASIC accelerators
