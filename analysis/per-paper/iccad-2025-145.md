# HyDra: SOT-CAM Based Vector Symbolic Macro for Hyperdimensional Computing

**Venue:** ICCAD
**ID:** iccad-2025-145
**Confidence:** low

## Problem
HDC accelerators suffer from high latency and energy costs in encoding, binding, permutation, and similarity search operations, limiting their practical deployment.

## Motivation
Energy-efficient HDC accelerators can enable scalable brain-inspired computing for edge and IoT applications.

## Method
HyDra accelerates hyperdimensional computing (a computation method using massive high-dimensional vectors) by performing critical operations directly in memory using SOT-MRAM, a fast and energy-efficient magnetic memory technology configured as a CAM—searchable memory that finds matching content rather than retrieving by fixed address. This architecture supports three key operations in-memory: binding (combining vectors through bitwise operations), permutation (rearranging bit order), and similarity search (measuring how closely vectors match). A bit-drop permutation method—which skips certain bit positions during rearrangement—reduces latency by 6x. Additional optimizations for addition operations and four-stage voltage scaling (which reduces power loss in interconnects) further decrease energy consumption and chip area.

## Key Novelty
HyDra pairs SOT-MRAM based CAM (searchable memory using magnetic storage) with a bit-drop permutation technique that rearranges bits more efficiently, achieving 6x speedup in hyperdimensional computing.

## Contributions
- SOT-CAM integration for in-memory binding, permutation, and search
- Bit-drop permutation method with 6x latency improvement
- HDC-specific adder reducing energy and area by 1.51x and 1.43x
- 21.5x-552.74x energy reduction vs. CMOS implementations, 2.27x lower energy vs. state-of-the-art
