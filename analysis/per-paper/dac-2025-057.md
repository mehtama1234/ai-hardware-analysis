# PreDAC: An Efficient Framework of Pre-Refining Enhanced Design Space Exploration for Approximate Computing

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
DSE algorithms for approximate computing struggle with large complex design spaces; optimization is slow.

## Key Idea
Pre-refinement step customizes design space for each application, reducing size before DSE. Novel cost-performance-based algorithm exploits refined space.

## Method
- Application-customized design space refinement
- Cost-performance formula generation
- Pre-refined space for fast DSE convergence
- Cost-performance-based exploration algorithm

## Contributions
1. Pre-refining framework with application-specific customization
2. Cost-performance DSE algorithm
3. 87x DSE speedup with 23% overhead improvement; additional 7.7x and 8.8% gains

## Hardware Target
ASIC (approximate computing)

## Techniques
Approximation, compiler/design automation
