# A Sample-Free Compilation Framework for Efficient Dynamic Tensor Computation

**Venue:** SC
**Paper ID:** sc-2025-007
**Confidence:** low

## Problem Statement
Dynamic-shape tensor computation requires shape-specific compilation; existing compilers rely on shape sampling, causing high tuning cost and poor performance on unseen shapes

## Motivation
ML workloads increasingly have dynamic shapes; shape sampling is expensive and inefficient; sample-free compilation could enable better generalization

## Method
Helix compiles tensor code (numerical arrays) without requiring specific shape information beforehand by decomposing the compilation task across the computer's architectural layers—from high-level programming abstractions down to low-level machine operations. It uses a bidirectional strategy: applying optimization rules top-down while building concrete machine kernels (instruction sequences) bottom-up. At lower architectural levels it measures performance directly, and at higher levels it estimates performance to avoid expensive measurement.

## Key Novelty
Helix eliminates the expensive shape-sampling step in dynamic tensor compilation by organizing the compiler around the computer's architectural hierarchy instead.
