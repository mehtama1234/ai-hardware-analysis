# A Sample-Free Compilation Framework for Efficient Dynamic Tensor Computation

**Venue:** SC
**Paper ID:** sc-2025-007
**Confidence:** low

## Problem Statement
Dynamic-shape tensor computation requires shape-specific compilation; existing compilers rely on shape sampling, causing high tuning cost and poor performance on unseen shapes

## Motivation
ML workloads increasingly have dynamic shapes; shape sampling is expensive and inefficient; sample-free compilation could enable better generalization

## Method
Helix framework: shape-agnostic compilation via hierarchical decomposition across architectural layers; bidirectional strategy (top-down abstraction + bottom-up kernel construction); hybrid analyzer (profiling at lower levels, modeling at higher levels)

## Key Novelty
Sample-free dynamic tensor compilation via architecture-aligned hierarchical decomposition; shape-adaptive execution without tuning

## Contributions
- Shape-agnostic compilation framework (Helix)
- Bidirectional architecture-aware compilation strategy
- Hybrid profiling+modeling analyzer
- 174x compilation time reduction; 2.26x-3.29x speedup vs existing compilers
