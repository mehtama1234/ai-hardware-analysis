# Parallel Programming Performance under System Noise

## Problem
System noise causes unpredictable variability in parallel workloads. No systematic methodology exists to characterize and compare resilience across programming models.

## Approach
Noise injection framework that:
1. Captures real system traces
2. Replays noise as controlled perturbations
3. Evaluates OpenMP and SYCL under same conditions
4. Tests mitigations: thread pinning, core isolation, SMT toggling

## Workloads
- N-body simulation
- Babelstream
- MiniFE mini-app
- Two processor platforms

## Key Findings
- **OpenMP**: higher raw performance, more susceptible to noise
- **SYCL**: lower peak performance, greater resilience to noise
- **Mitigation effectiveness**: workload and noise-intensity dependent
- **Housekeeping isolation**: clearest benefits in high-noise scenarios

## Significance
Demonstrates that programming model choice impacts not just performance but also robustness. SYCL's resilience suggests its value for latency-sensitive HPC applications.

## Themes
- Reproducibility
- Performance variability
- Parallel programming models
