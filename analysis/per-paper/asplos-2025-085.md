# asplos-2025-085 — ASDR: Exploiting Adaptive Sampling and Data Reuse for CIM-based Instant Neural Rendering

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** CIM-accelerated neural radiance field inference with adaptive sampling

## Problem
Neural Radiance Field (NeRF) inference exhibits irregular memory access patterns and high computational overhead, making it unsuitable for low-latency, power-efficient deployment on edge devices. Standard compute architectures cannot bridge the gap between NeRF's memory-bound irregular accesses and the immediacy/power requirements of practical neural rendering.

## Motivation
NeRF-based neural rendering demands instant, power-efficient inference for practical AR/VR and mobile applications, but the combination of irregular access patterns and large MLP computations overwhelms conventional memory hierarchies.

## Method
ASDR maps NeRF inference onto computing-in-memory (CIM) arrays to address the memory access bottleneck by performing computation near data storage, eliminating costly DRAM transfers. Adaptive sampling reduces the number of points sampled per ray dynamically based on scene complexity, cutting redundant computation. Data reuse strategies exploit spatial and temporal coherence across adjacent rays and frames to avoid redundant CIM macro activations. Together, these techniques reduce both the number of operations and the energy per operation on the CIM substrate.

## Key Novelty
Co-designing adaptive ray sampling and cross-ray data reuse specifically for CIM array execution to simultaneously reduce irregular access overhead and compute volume in NeRF inference.

## Contributions
- CIM-based accelerator mapping for NeRF inference targeting irregular memory access patterns
- Adaptive sampling scheme that dynamically reduces per-ray sample counts
- Data reuse strategy exploiting spatial/temporal coherence across rays and frames
- Instant neural rendering with improved power efficiency over conventional compute platforms
