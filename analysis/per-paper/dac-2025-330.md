# VEDA: Efficient LLM Generation Through Voting-based KV Cache Eviction and Dataflow-flexible Accelerator

## Problem
LLM edge inference faces memory bottleneck (KV cache) and computational challenge (variable sequence dimensions), limiting deployment.

## Solution
Tri-optimization: (1) voting-based KV cache eviction identifies and removes unimportant vectors, (2) flexible-product dataflow with runtime-reconfigurable PE handles variable matrix dimensions, (3) element-serial scheduling for softmax/layernorm. Hardware complexity reduced O(N)→O(1). Custom VEDA accelerator.

## Impact
Substantial latency reduction and hardware complexity reduction; enables real-time LLM inference on edge with privacy and customization.
