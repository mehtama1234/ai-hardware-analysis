# Making the Best Switch: Encoding Strategy Management for Efficient TFHE Circuit Evaluation

**ID:** iccad-2025-251

## Problem
Fully Homomorphic Encryption (TFHE) circuit evaluation is computationally expensive. Different operations benefit from different plaintext encoding strategies, but selecting optimal strategies requires manual effort.

## Motivation
Automated encoding strategy selection accelerates TFHE circuit evaluation, enabling practical encrypted computing for sensitive applications.

## Method
The system works with fully homomorphic encrypted circuits (TFHE), which let you perform computations directly on encrypted data. When evaluating these circuits, different operations run faster with different ways of representing plaintext numbers—called encoding strategies. Rather than manually choosing a single strategy for the entire circuit, this system automatically picks the best strategy for each operation, achieving a 53.46% reduction in evaluation time.

## Key Novelty
Automatically choosing the optimal plaintext encoding strategy for each operation during fully homomorphic encrypted circuit evaluation.
