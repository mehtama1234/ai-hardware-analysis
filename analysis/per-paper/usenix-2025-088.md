# WIC: Hiding Producer-Consumer Synchronization Delays with Warp-Level Interrupt-based GPU Communications

**Problem:** GPU kernels suffer high synchronization overhead when producers must wait for consumers through traditional barriers and polling-based synchronization. Producer-consumer communication patterns incur latency stalls that reduce GPU utilization and throughput.

**Method:** WIC introduces warp-level interrupt-based communication that allows producers to asynchronously signal consumers through event-driven notifications rather than explicit barriers. Interrupt handlers at the warp level enable non-blocking handshakes and decouple producer-consumer execution, hiding synchronization delays through event-driven coordination.

**Novelty:** Warp-level interrupt-based communication protocol that decouples producer-consumer synchronization through asynchronous event notification instead of explicit barrier synchronization.
