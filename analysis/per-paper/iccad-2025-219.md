# HLSDebugger: Identification and Correction of Logic Bugs in HLS Code with LLM Solutions

**Venue:** ICCAD  
**ID:** iccad-2025-219  
**Confidence:** low

## Problem Statement
Logic bugs in High-Level Synthesis code are difficult to identify and correct, slowing hardware design cycles.

## Motivation
Automated HLS debugging with LLM assistance accelerates hardware design and improves code quality.

## Method
The system trains a language model (an encoder-decoder architecture that converts buggy code into a mathematical representation and back out as fixed code) on 300,000 examples of buggy hardware synthesis code, learning to identify where bugs are located, what type they are, and how to correct them.

## Key Novelty
A language model specialized for hardware synthesis code debugging achieves 3x better bug correction than GPT-4.

## Contributions

1. LLM-based bug identification and correction for HLS
2. 300k HLS dataset with bugs
3. Encoder-decoder for bug location/type/fix
4. 3x better bug correction than GPT-4
