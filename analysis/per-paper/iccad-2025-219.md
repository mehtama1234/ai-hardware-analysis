# HLSDebugger: Identification and Correction of Logic Bugs in HLS Code with LLM Solutions

**Venue:** ICCAD  
**ID:** iccad-2025-219  
**Confidence:** low

## Problem Statement
Logic bugs in High-Level Synthesis code are difficult to identify and correct, slowing hardware design cycles.

## Motivation
Automated HLS debugging with LLM assistance accelerates hardware design and improves code quality.

## Method
LLM-based encoder-decoder architecture for bug identification, categorization, and correction. Trained on 300k HLS code samples with bugs. Distinguishes bug location, type, and generates fixes.

## Key Novelty
First specialized LLM-based HLS debugger achieving 3x better bug correction than GPT-4.

## Contributions

1. LLM-based bug identification and correction for HLS
2. 300k HLS dataset with bugs
3. Encoder-decoder for bug location/type/fix
4. 3x better bug correction than GPT-4
