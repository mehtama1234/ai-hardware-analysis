# SC-2025-413: Classification of 3D Electron Diffraction Data with LLM

## Summary
This work applies fine-tuned LLMs to automatically classify molecular structures from 3D electron diffraction data, reducing manual inspection burden by 95.8% while maintaining 100% recall on seven real datasets.

## Problem
3D electron diffraction generates hundreds to thousands of molecular structures per sample, but many contain errors due to noise and angular measurement constraints. Manual validation is labor-intensive and time-consuming.

## Method
- **Topology representation**: Converts atomic coordinates to topology-only language representation
- **Rule-based filtering**: Eliminates clearly impossible candidates
- **Fine-tuned LLM classification**: Trains on correct vs. artificially-corrupted molecules
- **Topology grouping**: Merges identical structures across outputs

## Key Results
- 95.8% reduction in structures requiring manual inspection
- 100% recall (preserves all valid structures)
- Evaluated on seven real 3D ED datasets
- Efficient automation of quality control bottleneck
