# Vectron: A Dynamic Programming Auto-vectorization Framework

**Venue:** CGO
**Confidence:** low

## Problem
Dynamic programming algorithms (especially sequence alignment) are computation bottlenecks in genomics and other fields; hand-vectorization is tedious and error-prone. Auto-vectorization of array-based DP code is needed.

## Motivation
DP algorithms are widely used but computationally expensive; SIMD and GPU acceleration via auto-vectorization can deliver massive speedups without algorithm changes.

## Method
Vectron takes Python code that implements dynamic programming algorithms (like sequence alignment problems that build up solutions by filling arrays) and automatically converts it to faster C++ code. The C++ version uses SIMD (a CPU feature that applies the same operation to many data values in parallel) and GPU acceleration to speed up computation. It processes multiple problem instances together simultaneously rather than one at a time, letting the parallel hardware handle them efficiently without requiring you to modify your original algorithm.

## Key Novelty
It automatically converts Python code for dynamic programming into SIMD and GPU-accelerated C++, eliminating the need for manual algorithm redesign.

## Contributions

- SIMD and GPU parallelization without code rewriting
- 10-20x speedups over conventional C++ and manual implementations
