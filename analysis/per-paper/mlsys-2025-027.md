# mlsys-2025-027 — LAVA: Lifetime-Aware VM Allocation with Learned Distributions and Adaptation to Mispredictions

**Venue:** MLSYS 2025

**One-line problem:** Improve cloud VM bin-packing by repredicting VM remaining lifetimes using observed uptime and adapting scheduling decisions on mispredictions.

## Method
LAVA uses a machine learning model (gradient boosted decision tree) trained on VM features (zone, family, shape, SSD, project metadata) to continuously estimate remaining VM lifetime based on how long it's already run—updating its guess as time passes instead of guessing once at startup. The model compiles into the Borg scheduler to run in <10 microseconds (780x faster than previous systems). Three algorithms use these predictions: NILAS picks hosts where running VMs are predicted to exit soonest; LAVA marks each host as open or recycling and switches modes when predictions are wrong; and LARS defragments by migrating longest-lived VMs first, letting shorter ones exit naturally.

## Key Novelty
LAVA is the first production system to continuously update VM lifetime predictions as they run and adapt scheduling decisions when predictions are wrong, showing that this approach works better than guessing once at startup.

## Metrics
- 2.3–9.2 pp increase in empty hosts (production pilots)
- ~3% reduction in stranded compute, ~2% in stranded memory
- 4.5% reduction in VM live migrations (LARS)
- Model: 99% precision at 70% recall for 7-day lifetime threshold
