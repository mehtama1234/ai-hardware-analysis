# mlsys-2025-027 — LAVA: Lifetime-Aware VM Allocation with Learned Distributions and Adaptation to Mispredictions

**Venue:** MLSYS 2025

**One-line problem:** Improve cloud VM bin-packing by repredicting VM remaining lifetimes using observed uptime and adapting scheduling decisions on mispredictions.

## Method
LAVA uses a GBDT model predicting conditional expected remaining lifetime E(Tr|Tu) given VM uptime, compiled directly into the Borg scheduler binary (<10us latency). Three algorithms: NILAS (non-invasive reprediction tie-breaker using max repredicted exit time), LAVA (lifetime-class host state machine placing shorter-lived VMs in longer-lived host gaps, with class upgrade/downgrade on mispredictions), and LARS (migration ordering by longest-lived-first to let short VMs exit during migration). Theoretically proven that reprediction reduces host requirements by Omega(m) over one-shot prediction.

## Key Novelty
First production scheduler using distribution-based lifetime reprediction (conditional E(Tr|Tu)) with on-the-fly misprediction detection and correction, deployed fleet-wide at Google Borg.

## Metrics
- 2.3–9.2 pp increase in empty hosts (production pilots)
- ~3% reduction in stranded compute, ~2% in stranded memory
- 4.5% reduction in VM live migrations (LARS)
- Model: 99% precision at 70% recall for 7-day lifetime threshold
