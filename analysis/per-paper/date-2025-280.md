# HAAN: A Holistic Approach for Accelerating Normalization Operations in Large Language Models

**Venue**: DATE  
**Primary Theme**: Co-designed normalization accelerator for LLMs  

## Problem
Normalization operations (LayerNorm) in LLMs substantially elevate processing latency and energy consumption, becoming a performance bottleneck.

## Method
HAAN tackles the normalization bottleneck—the step where models stabilize values flowing through the network—by jointly redesigning the computation and the hardware that runs it. Rather than keeping the algorithm fixed and hoping hardware will improve, the approach tweaks the computation itself and designs specialized hardware tailored to run that exact algorithm. This co-design (joint optimization of algorithm and hardware) reduces both latency and energy consumption. Because normalization happens frequently in LLM inference, even small per-operation gains compound into significant overall speedups.

## Key Novelty
The core idea is applying co-design (joint algorithm-and-hardware optimization) to normalization in LLM inference.

## Contributions
- HAAN normalization acceleration framework
- Significantly better hardware performance than state-of-the-art solutions
