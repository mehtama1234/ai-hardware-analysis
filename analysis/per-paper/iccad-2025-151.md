# Tensor Program Optimization for RISC-V Vector Extension using MetaSchedule

This work applies the MetaSchedule probabilistic framework to automatically optimize tensor programs for RISC-V vector extensions through intelligent loop scheduling, tiling, and vectorization strategies. The system discovers near-optimal execution schedules without manual tuning, achieving 46% speedup over GCC autovectorization. By automating the traditionally manual optimization process, this approach enables efficient tensor computation on RISC-V architectures and reduces the burden on compiler engineers.
