# WISEDRAM: A Reliable Bitwise In-DRAM Accelerator

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

WISEDRAM proposes a processing-in-memory architecture using special X-cells for in-DRAM bulk-bitwise operations while preserving standard DRAM cell access procedures, achieving 22% latency reduction and 71% XOR speedup with only 1.6% area overhead.

## Key Contributions

- **X-Cell Innovation**: Dedicated row of cells enabling reliable in-DRAM bitwise computation
- **Reliability Preservation**: Maintains standard DRAM access reliability for reads and writes
- **Performance Gains**: 22% latency reduction in bitwise ops, 71% speedup in XOR operations
- **Minimal Overhead**: Only 1.6% area increase, practical for deployment

## Technical Focus

Addresses reliability gap in prior PIM approaches by retaining conventional DRAM cell access while introducing specialized cells for bitwise operations. Enables practical in-DRAM compute for database and analytics workloads.

**Keywords:** pim, dram, bitwise-operations, reliability, processing-in-memory
