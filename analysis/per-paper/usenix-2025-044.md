# Accelerating Distributed Graph Learning by Using Collaborative In-Network Multicast and Aggregation

**Problem:** Distributed graph learning systems face communication bottlenecks when aggregating results across multiple nodes during training.

**Method:** When multiple computers train together on graph data (distributed graph learning), they need to combine results from all computers—a process called aggregation that normally happens at the endpoint computers, creating a bottleneck. This method offloads that work to programmable network hardware (specialized adapter cards called SmartNICs or programmable switches). The network hardware collects results from all computers and combines them in the network as data flows through, eliminating both the computational load on endpoints and the need to send all raw data to one location.

**Novelty:** This approach performs result aggregation (combining data from multiple sources) directly in programmable network hardware (SmartNICs or switches) instead of at endpoint computers.
