# Accelerating Distributed Graph Learning by Using Collaborative In-Network Multicast and Aggregation

**Problem:** Distributed graph learning systems face communication bottlenecks when aggregating results across multiple nodes during training.

**Method:** Uses programmable in-network hardware (SmartNICs or network switches) to perform collaborative multicast and aggregation of results during distributed graph learning, offloading aggregation computation from endpoints to the network fabric.

**Novelty:** Collaborative in-network aggregation that moves result combination from endpoints to programmable network hardware.
