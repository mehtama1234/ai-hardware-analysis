# MXBLAS: Accelerating 8-bit Deep Learning with a Unified Micro-Scaled GEMM Library

**Venue:** SC
**ID:** sc-2025-385
**Confidence:** low

## Problem

Current MX-GEMM implementations are model-oriented with rigid problem-kernel coupling, inefficient promotion operations, and overlooked quantization overhead.

## Motivation

8-bit micro-scaled computing requires general MX-GEMM library supporting diverse format variations without model-specific customization.

## Method

MXBLAS: template-based MX-GEMM library; adaptive runtime kernel generation; compute-store co-optimization fusing quantization into epilogue.

## Key Novelty

Unified MX-format support across all variations; first to realize full 8-bit computing benefits generalized across formats.

## Contributions

1. Unified MX-GEMM library for all MX-format variations
2. Template-based kernel design framework
3. Adaptive runtime kernel generation
4. Compute-store co-optimization strategy
5. 33% improvement over existing MX-GEMM libraries
