# MXBLAS: Accelerating 8-bit Deep Learning with a Unified Micro-Scaled GEMM Library

**Venue:** SC
**ID:** sc-2025-385
**Confidence:** low

## Problem

Current MX-GEMM implementations are model-oriented with rigid problem-kernel coupling, inefficient promotion operations, and overlooked quantization overhead.

## Motivation

8-bit micro-scaled computing requires general MX-GEMM library supporting diverse format variations without model-specific customization.

## Method

MXBLAS speeds up matrix multiplication (the core computation in deep learning) using templates that generate optimized code at runtime for each specific problem, rather than relying on one fixed approach. It coordinates computation and memory access together and embeds the quantization step (reducing numbers to 8-bit precision) directly into the final calculation stage instead of handling it separately.

## Key Novelty

It's the first system to handle all MX format variations (different representations of 8-bit numbers) with a unified library while actually delivering the full speed benefits of 8-bit computing.

## Contributions

1. Unified MX-GEMM library for all MX-format variations
2. Template-based kernel design framework
3. Adaptive runtime kernel generation
4. Compute-store co-optimization strategy
5. 33% improvement over existing MX-GEMM libraries
