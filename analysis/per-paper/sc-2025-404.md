# Kilometer-Scale AI-Powered and Performance-Portable Earth System Model (AP3ESM) to Achieve Year-Scale Simulation Speed on Heterogeneous Supercomputers

**Venue:** SC
**ID:** sc-2025-404
**Confidence:** low

## Problem
Ultra-high-resolution Earth system models (ESMs) at kilometer scale require exascale resources; achieving performance portability across heterogeneous architectures is challenging.

## Motivation
Climate and weather simulation at breakthrough resolution enables realistic forecasting; AI-enhanced parameterizations and mixed-precision boost efficiency.

## Method
AP3ESM uses Kokkos, a software framework that lets the same code run efficiently on different supercomputers like Sunway and GPU systems, solving the challenge of writing code that works portably across different hardware. It improves weather prediction by replacing traditional approximations (called parameterizations) with AI-learned versions that better capture small-scale weather patterns. The model accelerates computation through adaptive algorithms that adjust the level of detail based on local conditions, and mixed-precision arithmetic that uses lower-precision calculations in less sensitive parts while keeping high precision where it matters.

## Key Novelty
This is the first kilometer-scale Earth system model to run year-scale simulations (0.85-0.54 years simulated per computation day), achieving accurate predictions of extreme events like Super Typhoon Doksuri's rainfall.

## Contributions
1. Breakthrough kilometer resolution Earth system model
2. Year-scale simulation speed on 37.2M Sunway cores (0.54 SYPD holistic)
3. AI-enhanced physical parameterizations
4. Successful extreme weather event prediction (Super Typhoon Doksuri)
