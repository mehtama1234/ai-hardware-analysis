# Self-Error Detection and Correction Techniques for Reliable and Efficient Selector-Only Memory

**Venue:** ICCAD  
**ID:** iccad-2025-102

## Problem
Selector-Only Memory (SOM) devices face threshold voltage (Vth) drift and device variation, reducing read window margin and increasing error rate, particularly challenging for advanced manufacturing processes.

## Motivation
Enable reliable SOM operation without external ECC overhead through inherent error detection and correction mechanisms.

## Method
Securer: self-detection via dual-polarity read operation leveraging SOM's unique features; self-correction using analytical Vth drift estimation model to track drifted threshold voltage with adaptive error-aware read operations.

## Key Novelty
First self-detection and self-correction technique for SOM without relying on external error correction codes.

## Contributions
- Error rate below 10^-13 without external ECC
- Single-error correction capability
- Negligible overhead for error management
- Effective across diverse application workloads
- Compatible with ECC for additional protection
