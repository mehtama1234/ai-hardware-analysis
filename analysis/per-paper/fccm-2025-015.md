# HighWave: Large-Scale High-Bandwidth Wave Simulations on FPGAs

**Problem:** Wave simulations represented as PDEs face memory bandwidth bottlenecks on FPGAs, especially when using discontinuous Galerkin schemes with low arithmetic intensity and complex irregular data access patterns. Achieving high HBM utilization while managing irregular accesses requires careful co-design of compute and memory systems.

**Method:** HighWave employs a spatial FPGA architecture with configurable processing cores that integrate High-Bandwidth Memory through coordinated memory optimizations. The design maximizes data reuse, minimizes access irregularities through careful scheduling, and ensures load balancing across memory channels. It targets discontinuous Galerkin wave solvers with Gauss-Lobatto-Legendre quadrature and supports elastic and acoustic wave equations.

**Novelty:** First FPGA wave simulator with HBM integration and co-designed memory optimizations (data reuse, irregular access mitigation, load balancing) achieving high bandwidth utilization for intrinsically low-arithmetic-intensity discontinuous Galerkin schemes.
