# HighWave: Large-Scale High-Bandwidth Wave Simulations on FPGAs

**Problem:** Wave simulations represented as PDEs face memory bandwidth bottlenecks on FPGAs, especially when using discontinuous Galerkin schemes with low arithmetic intensity and complex irregular data access patterns. Achieving high HBM utilization while managing irregular accesses requires careful co-design of compute and memory systems.

**Method:** HighWave simulates waves on an FPGA (a computer chip reconfigurable for specific tasks) by coordinating processing cores with High-Bandwidth Memory (memory optimized for rapid data transfer). The design keeps frequently-used data close to processors to reuse it, schedules memory accesses in predictable patterns rather than random jumps, and distributes work evenly across memory channels to prevent bottlenecks. It uses the discontinuous Galerkin method with Gauss-Lobatto-Legendre quadrature (mathematical techniques for solving wave equations) to handle elastic and acoustic waves.

**Novelty:** HighWave is the first FPGA wave simulator combining High-Bandwidth Memory with coordinated optimizations—data reuse, predictable access scheduling, and balanced load distribution—to achieve full memory bandwidth utilization for discontinuous Galerkin solvers, which inherently require processing large data volumes despite minimal computation.
