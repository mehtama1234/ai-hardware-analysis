# dac-2025-276: BS-PDN-Last—Multifunctional Backside Power Delivery

**Problem:** Traditional PDN-first flows reserve backside for power, leaving suboptimal signal routing and performance trade-offs.

**Motivation:** Maximizing PPA gains requires rethinking design order to exploit multifunctional backside layers.

**Method:** The traditional approach reserves backside metal layers for power delivery from the start, limiting how signal routing (the data paths between circuits) can optimize and hurting performance. BS-PDN-Last reverses this order: it lets signal routing optimize for speed and performance first by using as much backside space as needed, then fits the power delivery network into the space that remains. This reordering works because signal routing is harder to reroute than power distribution. The method uses vector-based IR-drop analysis—a calculation that predicts voltage drop (power wasted as heat in the wires)—to ensure the final power network still delivers power reliably.

**Key Novelty:** Post-signal-routing PDN design to unlock multifunctional backside utilization.

**Contributions:**
- 90% Total Negative Slack reduction
- 12% performance gain with BS-CDN
- First comprehensive FS-PDN/BS-PDN/multifunctional comparison
