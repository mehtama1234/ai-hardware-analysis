# SC-2025-307: Performance-Portable Symbolic Factorization through Common Graph Operations

## Summary
This work demonstrates the viability of using the GraphBLAS standard (linear algebra on graphs) for performing symbolic factorization in sparse LU decomposition. By expressing edge-based and path-based symbolic factorization using common GraphBLAS operations, the authors achieve portable performance across multi-core CPUs and many-core accelerators without architecture-specific implementations.

## Key Contributions
1. **GraphBLAS-based symbolic factorization** using standard graph and linear algebra operations
2. **Performance optimization** via masks and elimination tree utilization
3. **Portable execution** on multi-core CPUs, GPUs, and other many-core systems
4. **Proof-of-concept** demonstrating GraphBLAS viability for sparse computational kernels

## Technical Approach
- Expression of symbolic factorization (edge-based and path-based algorithms) using GraphBLAS primitives
- Optimization through mask operations and elimination tree structures
- Evaluation across diverse sparse matrix types and sparsity patterns
- Comparison of implementation efficiency across hardware targets

## Hardware & Systems
- Multi-core CPUs with GraphBLAS implementations
- Many-core accelerators (GPUs with GraphBLAS support)
- Heterogeneous systems with multiple backends

## Workloads & Evaluation
- **Primary kernel**: Sparse LU factorization
- **Matrix types**: Various non-symmetric sparse matrices
- **Evaluation dimensions**: Performance, portability, scaling behavior

## Limitations & Future Work
- Comparison with heavily optimized sparse libraries (SuperLU, PARDISO, MUMPS) not thoroughly explored
- Scalability to very large distributed-memory systems not addressed
- Memory overhead of GraphBLAS abstraction layer not quantified
- Performance on symmetric matrices not detailed
- Numerical stability considerations not discussed
