# Multi-Agent Yield Analysis For Circuit Design

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Yield estimation via Monte Carlo is computationally expensive; existing ML/importance-sampling methods lack consistency across topologies. Critical for manufacturing cost control.

## Core Method
Three-layer LLM-powered multi-agent architecture analyzing circuit characteristics to dynamically select estimation strategies; Retrieval-Augmented Generation for domain knowledge + Tree-structured Parzen Estimators for hyperparameter tuning.

## Key Contribution
LLM-powered multi-agent framework dynamically balancing estimation methods with adaptive hyperparameter tuning.

## Results
- 2.9× computational overhead reduction
- Maintains/exceeds SOTA accuracy across 12nm–40nm nodes
- Topology-adaptive estimation
