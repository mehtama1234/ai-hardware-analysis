# SNAPPIX: Efficient-Coding-Inspired In-Sensor Compression for Edge Vision

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Edge vision sensors face severe energy bottleneck transmitting high-volume pixel data; conventional compression is task-agnostic and inefficient.

## Method
SNAPPIX compresses pixel data directly at the camera using coded exposure (where different pixels capture light for different durations), which automatically removes redundancy based on efficient coding theory—a mathematical framework that minimizes data waste. The system learns which pixels to sample without needing to know the specific vision task ahead of time. The downstream AI models are redesigned to handle the uneven pixel brightness that results from this variable exposure. Lightweight hardware additions to the sensor enable this compression without significant power overhead.

## Key Novelty
SNAPPIX's key innovation is to use efficient-coding-inspired coded exposure—where pixels capture light for different durations—at the camera sensor for task-agnostic compression, with AI models and hardware specifically co-designed to support this approach.

## Results
- **15.4× energy reduction** vs state-of-the-art video methods
- Improved action recognition and video reconstruction
