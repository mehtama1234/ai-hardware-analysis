# SC-2025-412: LowDiff - Efficient Frequent Checkpointing via Differential Compression

## Summary
LowDiff enables frequent per-iteration checkpointing in distributed training with <3.1% overhead by reusing gradient compression as differential checkpoints, extending differential checkpointing beyond recommendation systems.

## Problem
Distributed training requires frequent checkpointing for fast failure recovery, but checkpoint storage costs grow with frequency. Differential checkpointing reduces costs but prior work was limited to recommendation systems.

## Method
- **Gradient reuse**: Leverages compressed gradients (already computed in distributed training) as differential checkpoints
- **Batched gradient write**: Optimizes persistence of differential checkpoints to storage
- **Dynamic tuning**: Automatically adjusts checkpoint frequency and batch size based on system state

## Key Results
- Per-iteration checkpointing frequency achievable
- <3.1% training time overhead
- General applicability across various training workloads
- Storage cost reduction through differential approach
