# Poby: SmartNIC-accelerated Image Provisioning for Coldstart in Clouds

**Problem:** Cloud VM coldstart latency is dominated by image provisioning—transferring and decompressing large VM images from storage to compute nodes consumes CPU cycles and network bandwidth, delaying instance availability.

**Method:** Poby uses SmartNICs—specialized hardware cards positioned in the network between storage and compute nodes—to handle image decompression and transfer. The SmartNIC's hardware acceleration decompresses the VM image and moves it from storage to the compute node, work that would otherwise use the compute node's CPU. By offloading this work, Poby frees the CPU for other tasks, reducing contention and speeding up image provisioning.

**Novelty:** The innovation is using a SmartNIC (a specialized network acceleration card) to handle VM image decompression and transfer instead of relying on the compute node's CPU.
