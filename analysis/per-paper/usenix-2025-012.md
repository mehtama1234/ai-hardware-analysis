# Poby: SmartNIC-accelerated Image Provisioning for Coldstart in Clouds

**Problem:** Cloud VM coldstart latency is dominated by image provisioning—transferring and decompressing large VM images from storage to compute nodes consumes CPU cycles and network bandwidth, delaying instance availability.

**Method:** Poby offloads image provisioning operations to SmartNICs positioned in the network datapath, leveraging their hardware acceleration for decompression and image transfer between storage and compute nodes. SmartNICs process image data without consuming CPU resources on compute nodes, reducing contention and latency in the provisioning pipeline.

**Novelty:** Offloading VM image provisioning to SmartNICs as dedicated accelerators instead of relying on CPU-based decompression and standard network I/O.
