# BUFFALO: PPA-Configurable, LLM-based Buffer Tree Generation via Group Relative Policy Optimization

**Venue:** ICCAD

## Problem
Buffer insertion optimization requires balancing trade-offs between Power, Performance, and Area but local heuristics don't scale to achieve globally optimal solutions.

## Motivation
Traditional buffering methods are suboptimal; prior ML approaches are prohibitively slow due to incremental nature.

## Method
The approach uses a large language model to generate an optimized buffer tree—the arrangement of signal buffers throughout a circuit—in one pass for all connections that violate timing constraints. The model is then trained with Group Relative Policy Optimization, a reinforcement learning technique that updates the model based on how well each solution balances power consumption, circuit speed, and chip area. This allows designers to prioritize whichever trade-off matters most for their specific design.

## Key Novelty
This is the first formulation of buffer tree generation as a sequence-to-sequence task—translating circuit connection constraints into optimized buffer placement—that large language models can solve directly.

## Contributions
- 71% improvement in Total Negative Slack (TNS)
- 67.69% improvement in Worst Negative Slack (WNS)
- 83x faster runtime than commercial tool
- No additional power consumption increase
