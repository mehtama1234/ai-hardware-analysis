# REACT3D: Real-time Edge Accelerator for Incremental Training in 3D Gaussian Splatting based SLAM Systems

**Venue:** MICRO  
**Confidence:** low (abstract-only analysis)

## Problem
3D Gaussian Splatting (3DGS) SLAM requires incremental training and rendering at over 30 FPS on edge devices, but existing GPU-based solutions and prior accelerators fall short due to redundant training computation, unnecessary loss computation, and irregular memory access patterns. The combination of continuous camera streaming, per-Gaussian gradient accumulation, and sparse activated Gaussian sets creates severe compute and memory irregularity.

## Motivation
Real-time 3DGS-SLAM on edge platforms is a critical capability for autonomous robots and AR/VR systems, and no prior hardware design achieves the 30 FPS real-time threshold required for accurate tracking and mapping.

## Method
REACT3D accelerates 3D Gaussian Splatting through two algorithmic optimizations and a hardware buffer design. First, it identifies fully-trained 3D point clouds (Gaussians) by checking their spatial spread and training convergence, skipping redundant rendering passes, and merges loss calculation (the measure of prediction error) into the rendering pipeline through a pixel block-wise dataflow instead of storing it separately. The hardware uses content-addressable memory (special silicon that retrieves data by matching its contents rather than using addresses) with two parallel index tables to resolve memory conflicts when combining training updates across scattered point-to-pixel mappings.

## Key Novelty
The dual-index Gaussian Buffer, built with content-addressable memory hardware that retrieves data by content rather than address, that resolves irregular memory access and gradient-merging conflicts when training 3D point clouds from streaming camera feeds.

## Contributions
- Spatial consistency and convergence-aware sparsification algorithm that eliminates redundant Gaussian forward/backward passes
- Pixel block-wise fine-grained dataflow that fuses loss computation and eliminates explicit loss memory traffic
- CAM-based Dual-index Gaussian Buffer microarchitecture for irregular memory disambiguation during gradient merging
- First hardware design demonstrated to meet real-time (>30 FPS) requirements for 3DGS SLAM on an edge device, achieving 12.10x speedup and 33.69x energy efficiency over NVIDIA Jetson AGX Orin
