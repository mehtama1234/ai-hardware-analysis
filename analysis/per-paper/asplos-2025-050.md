# Snowplow: Effective Kernel Fuzzing with a Learned White-box Test Mutator

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-050  
**Confidence:** low (abstract only)

## Problem
Kernel fuzzers rely on program mutation to generate test programs exploring new code paths, but existing heuristics cannot navigate complex kernel control/data flow to trigger target code locations or increase coverage effectively.

## Motivation
OS kernel bugs are critical security vulnerabilities; manual mutation heuristics cannot keep pace with modern kernel complexity, leaving large code regions unexplored.

## Method
Snowplow trains a machine learning model to make smarter choices about how to mutate (modify) test programs. Instead of guessing randomly or following hand-written rules, the model learns from analyzing the actual kernel source code—specifically how instructions are ordered (control flow graphs) and how data moves between them (data flow). During testing, it predicts which mutations—like adding system calls, changing argument values, or restructuring the test—would most likely guide execution into untested kernel code regions. The model improves by learning from real coverage feedback showing which code actually ran.

## Key Novelty
Snowplow replaces hand-written mutation rules with a machine learning model that learns from kernel code which test changes will reach untested code.

## Contributions
- Snowplow: kernel fuzzer with learned white-box mutation model replacing hand-crafted heuristics.
- Higher kernel code coverage and improved bug-finding vs state-of-the-art fuzzers.
- Training methodology using kernel control/data flow as white-box features.
