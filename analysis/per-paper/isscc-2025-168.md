# isscc-2025-168: CMOS E-Nose with MOF Sensors and Thermodynamic Modulation

**Title:** 20.4 MEMS-Free 4096-Pixel CMOS E-Nose Gas-Sensor Array with Molecular-Selective Metal-Organic-Framework Sensing and In-Pixel Thermodynamic Modulation for Fast Sensor Regeneration

**Problem:** E-noses lack selectivity, suffer sensor memory effects, and have limited array size with no in-pixel processing.

**Approach:** Monolithic CMOS integration of 4096 MOF sensors with in-pixel temperature regulation for thermodynamic control of gas adsorption/desorption, plus local readout circuits.

**Key Result:** Rapid sensor regeneration, high selectivity (ammonia-specific NiNi-Pyz MOFs), eliminated sensing memory.

**Hardware:** ASIC (CMOS gas sensor array).

**Tags:** gas-sensor, e-nose, metal-organic-framework, mof, in-pixel-processing, chemical-sensing
