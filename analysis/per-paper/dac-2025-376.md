# YOCO: A Hybrid In-Memory Computing Architecture with 8-bit Sub-PetaOps/W In-Situ Multiply Arithmetic for Large-Scale AI

**Venue:** DAC
**ID:** dac-2025-376

## Problem
Analog in-memory computing (AiMC) requires efficient 8-bit multiply operations for AI accelerators with high energy efficiency and throughput.

## Motivation
AI inference demands extreme efficiency; analog computing avoids costly analog-to-digital conversions in the computational path.

## Method
YOCO performs 8-bit multiplication directly inside the memory (rather than moving data out to a separate processor), using electrical charge to encode numbers and accumulating results over time—both techniques are efficient in analog circuits. It combines two types of memory: ReRAM, which packs data densely, and SRAM, which is fast and reliable, to achieve both efficiency and high capacity. For transformer AI models, which rely on an expensive attention mechanism, YOCO includes a specialized pipeline optimized for this calculation, reducing data movement overhead.

## Key Novelty
YOCO performs 8-bit multiplication inside memory cells using electrical charge and accumulation over time, achieving 123.8 TOPS/W (operations per watt).

## Contributions
1. Novel 8-bit in-situ multiply arithmetic with 123.8 TOPS/W energy efficiency and 34.9 TOPS throughput
2. Hybrid ReRAM-SRAM memory architecture balancing computational efficiency and storage density
3. IMC-friendly attention computing flow with optimized pipeline for transformer acceleration
4. 3.9-19.9x energy efficiency improvement and 6.8-33.6x throughput improvement over SOTA baselines across CNN/transformer models
