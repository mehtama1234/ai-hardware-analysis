# Extending RAJA Parallel Programming Abstractions with Just-In-Time Optimization

**ID:** sc-2025-046  
**Venue:** SC  
**Confidence:** high

## Problem
AOT parallel programming models cannot perform context-specific optimizations due to lack of runtime information

## Motivation
Heterogeneous computing dominance requires performance portability without sacrificing per-hardware optimizations

## Method
Integration of Proteus JIT framework (LLVM-based) with RAJA portability layer; introduces dimension specialization optimization

## Key Novelty
JIT compilation for portable parallel loop bodies; dimension specialization replaces runtime queries with constants

## Contributions
1. Extends RAJA to support JIT-deferred compilation
2. Introduces dimension specialization optimization
3. Demonstrates speedups on both AMD and NVIDIA GPUs

## Hardware Targets
AMD MI250X, NVIDIA V100

## Technique Categories
Compiler Optimization, JIT Compilation, Performance Portability

## Workloads
Parallel loops, RAJAPerf benchmarks

## Metrics
- speedup_amd: 1.2x-23x
- speedup_nvidia: 1.1x-15x

## Baselines
- RAJA AOT
- Traditional compilers

## Limitations
Evaluation limited to RAJAPerf benchmarks; impact on real applications unclear
