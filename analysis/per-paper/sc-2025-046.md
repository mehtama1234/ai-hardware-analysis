# Extending RAJA Parallel Programming Abstractions with Just-In-Time Optimization

**ID:** sc-2025-046  
**Venue:** SC  
**Confidence:** high

## Problem
AOT parallel programming models cannot perform context-specific optimizations due to lack of runtime information

## Motivation
Heterogeneous computing dominance requires performance portability without sacrificing per-hardware optimizations

## Method
They integrated Proteus (a runtime compiler based on LLVM) with RAJA, a layer that lets parallel code run across different hardware platforms. At runtime, Proteus applies dimension specialization: it replaces generic variables for loop sizes with the specific numbers determined when code starts executing, enabling highly optimized code tailored to those exact dimensions.

## Key Novelty
Using a runtime compiler to optimize portable parallel code by specializing loops for the actual dimensions available when code executes.

## Contributions
1. Extends RAJA to support JIT-deferred compilation
2. Introduces dimension specialization optimization
3. Demonstrates speedups on both AMD and NVIDIA GPUs
