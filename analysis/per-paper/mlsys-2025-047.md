# LServe: Efficient Long-sequence LLM Serving with Unified Sparse Attention

**ID:** mlsys-2025-047 | **Venue:** MLSYS 2025

## Problem
Serving LLMs on 64k-512k token sequences is bottlenecked by attention in both prefill (quadratic compute) and decode (linear KV memory) stages; no existing system addresses both simultaneously in a unified framework.

## Method
LServe unifies block-sparse attention patterns:
- **Static sparsity**: half of attention heads designated as streaming heads offline (Λ-mask: sink + local only); fused CUDA kernels handle both head types in one pass.
- **Dynamic sparsity (decode)**: hierarchical paging separates logical pages (NL tokens, used for importance scoring via per-page kmax/kmin stats) from physical pages (NP=g*NL tokens, for quantized storage). Page importance is max-pooled from logical scores. Reusable page selection shares selection results across consecutive decode steps (4x overhead reduction).
- All patterns integrated with W4A8KV4 quantization in unified kernels.

## Key Novelty
Unified block-sparse attention with hierarchical paging and reusable page selection, compounding static and dynamic sparsity savings multiplicatively with KV quantization.

## Results
- **2.9x** prefill speedup over vLLM (up to 2.9x)
- **1.3-2.1x** decode speedup over vLLM
- Maintains LongBench, NIAH, RULER accuracy; compatible with DeepSeek-R1-Distill-Llama-8B
- Models: Llama-3-8B, Llama-2-7B, Minitron-4B; context up to 512k tokens

## Hardware Target
NVIDIA A100 80GB, L40S 48GB GPUs
