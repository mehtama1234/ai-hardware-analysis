# LServe: Efficient Long-sequence LLM Serving with Unified Sparse Attention

**ID:** mlsys-2025-047 | **Venue:** MLSYS 2025

## Problem
Serving LLMs on 64k-512k token sequences is bottlenecked by attention in both prefill (quadratic compute) and decode (linear KV memory) stages; no existing system addresses both simultaneously in a unified framework.

## Method
LServe accelerates attention on long sequences by strategically reducing required computations. During prefill, half the attention heads are predetermined to only look at sink tokens (the very beginning) plus recent tokens in a sliding window, while other heads compute normally—both run together in one optimized GPU kernel. During decode, LServe uses a two-level page system: fine-grained logical pages score which key-value memories matter most using query dot products with statistics, while larger physical pages store the actual compressed data; it reuses these scores across consecutive decode steps instead of recalculating them. All key-value data is quantized to 4 bits (W4A8KV4) to minimize memory usage.

## Key Novelty
LServe's core contribution is unifying static sparse attention heads (predetermined during prefill) with dynamic hierarchical page pruning (during decode) into one fused GPU kernel using quantized key-value storage, speeding up both stages of long-sequence LLM serving.

## Results
- **2.9x** prefill speedup over vLLM (up to 2.9x)
- **1.3-2.1x** decode speedup over vLLM
- Maintains LongBench, NIAH, RULER accuracy; compatible with DeepSeek-R1-Distill-Llama-8B
- Models: Llama-3-8B, Llama-2-7B, Minitron-4B; context up to 512k tokens

## Hardware Target
NVIDIA A100 80GB, L40S 48GB GPUs
