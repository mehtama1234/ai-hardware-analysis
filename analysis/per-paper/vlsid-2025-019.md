# Efficient Mitigation of DRAM Row Buffer Conflict Using Request Clustering in Manycore Systems

**Venue:** VLSID

## Problem
Memory wall: DRAM row buffer conflicts cause inefficient bandwidth utilization in manycore systems

## Motivation
Memory consumes 40% system energy; row buffer conflicts degrade performance; need efficient request scheduling

## Method
The approach clusters (groups) incoming memory requests based on which memory rows they need to access. Modern DRAM uses a row buffer—a temporary holding area that keeps one row of data readily available. When requests keep asking for different rows, the buffer must constantly close the current row and load a new one; these switches are slow and waste memory bandwidth. By bundling requests that target the same row together, the system can process many requests from that row before switching—reducing the number of expensive row switches and making better use of available bandwidth.

## Key Novelty
Clustering memory requests by their target rows reduces DRAM row buffer switching overhead in manycore systems.
