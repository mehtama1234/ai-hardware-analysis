# Late Breaking Results: Versatile 4:1 Multiplexer Using 1T1R RRAM Crossbar for High Speed In-Memory Computing

**Authors:** B. Vinodh Kumar, Binsu J. Kailath  
**Venue:** DAC 2025

## Summary
This work proposes a NAND-based 4:1 multiplexer for 1T1R RRAM crossbars that executes in 3 steps instead of the conventional 10, reducing computational latency for in-memory logic. Full adders, subtractors, and comparators show 75% clock-cycle reduction versus state-of-the-art.

## Key Contributions
- NAND-based 4:1 multiplexer reducing execution from 10 to 3 steps
- Full adder with 75% cycle reduction
- Full subtractor with 75% cycle reduction
- 1-bit comparator with 75% cycle reduction

## Technical Approach
The design leverages NAND logic operations within the RRAM crossbar structure, enabling the multiplexer to complete in 3 steps rather than 10. This optimization extends to higher-level logic functions (adder, subtractor, comparator), all showing consistent 75% cycle reduction. The trade-off is increased memristor count.

## Hardware Target
Compute-in-memory (CIM) systems using RRAM crossbars

## Technique Categories
Near-data processing, circuit design

## Metrics
- MUX execution: 3 steps (vs. 10)
- Arithmetic logic cycle reduction: 75%

## Limitations
Increased memristor overhead, though justified by significant computational delay reduction.
