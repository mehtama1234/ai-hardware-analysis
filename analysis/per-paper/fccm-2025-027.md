# RealProbe: An Automated and Lightweight Performance Profiler for In-FPGA Execution of High-Level Synthesis Designs

**Problem:** High-level synthesis designs exhibit significant discrepancies between cycle-accurate C/RTL co-simulation results and actual FPGA performance, hindering accurate bottleneck identification. Existing profiling tools like the Integrated Logic Analyzer require tedious manual inspection of HLS-generated RTL and manual signal monitoring, reducing design productivity.

**Method:** RealProbe uses a single pragma directive (#pragma HLS RealProbe) to automatically generate profiling instrumentation code across the full function hierarchy including submodules and loops. It implements profiling logic as independent non-intrusive hardware to minimize impact on kernel functionality and timing. The tool extracts and records cycle counts with high precision, and supports automated design space exploration by leveraging incremental synthesis to explore resource allocation independently of the HLS kernel.

**Novelty:** The first fully automated, non-intrusive in-FPGA profiler for HLS designs requiring only a single pragma directive, achieving 100% accuracy in cycle counting with minimal hardware overhead.
