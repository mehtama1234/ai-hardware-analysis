# RealProbe: An Automated and Lightweight Performance Profiler for In-FPGA Execution of High-Level Synthesis Designs

**Problem:** High-level synthesis designs exhibit significant discrepancies between cycle-accurate C/RTL co-simulation results and actual FPGA performance, hindering accurate bottleneck identification. Existing profiling tools like the Integrated Logic Analyzer require tedious manual inspection of HLS-generated RTL and manual signal monitoring, reducing design productivity.

**Method:** You add one special instruction (#pragma HLS RealProbe) to your code, and RealProbe automatically creates measurement code that tracks everything—the main function, helper functions, and loops. Instead of interfering with your actual computation, it uses separate dedicated measurement hardware alongside your design. This measurement hardware counts clock cycles with high precision to tell you where time is being spent. You can also use it to quickly try different hardware configurations by only rebuilding the parts you changed, rather than rebuilding everything.

**Novelty:** It is the first fully automated profiler that measures performance inside running FPGA hardware using only a single pragma instruction, achieving 100% accuracy in counting clock cycles with minimal extra hardware and no interference with the design.
