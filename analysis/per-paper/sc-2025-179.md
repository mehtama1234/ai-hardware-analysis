# Scaling All-to-All Operations Across Emerging Many-Core Supercomputers

**Venue:** SC

## Problem
Existing all-to-all MPI algorithms don't fully exploit many-core supercomputer architectures; performance varies with message size and process count

## Motivation
Develop all-to-all algorithms optimized for emerging many-core systems to accelerate FFT, transposition, and ML applications

## Method
These algorithms optimize all-to-all communication, where every parallel process sends data to all the others simultaneously—a common bottleneck on modern supercomputers with many cores per processor. Instead of using a fixed strategy, the algorithms adapt based on the message size and number of processes involved, since different communication patterns work better at different scales. By aligning the algorithm choice with many-core processor characteristics, they avoid performance losses that generic implementations suffer from.

## Key Novelty
Tailoring all-to-all algorithms to many-core processor characteristics instead of using generic implementations yields 3x speedup on Sapphire Rapids at 32 nodes.
