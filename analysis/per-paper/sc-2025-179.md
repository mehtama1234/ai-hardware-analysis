# Scaling All-to-All Operations Across Emerging Many-Core Supercomputers

**Venue:** SC

## Problem
Existing all-to-all MPI algorithms don't fully exploit many-core supercomputer architectures; performance varies with message size and process count

## Motivation
Develop all-to-all algorithms optimized for emerging many-core systems to accelerate FFT, transposition, and ML applications

## Method
Novel all-to-all algorithms designed for many-core supercomputers with optimization for message size and process count variations

## Key Novelty
3x speedup over system MPI on Sapphire Rapids at 32 nodes; algorithms tailored to many-core architecture characteristics
