# Chameleon-SAT: An Adaptive Boolean Satisfiability Accelerator Using Mixed-Signal In-Memory Computing for Versatile SAT Problems

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
SAT problems span diverse scales and complexities; single solvers cannot efficiently handle all variants.

## Key Idea
ASIC accelerator with mixed-signal in-memory computing supporting three algorithm classes (local search, DPLL, CDCL) via adaptive reconfiguration.

## Method
- Mixed-signal in-memory computing substrate
- Reconfigurable algorithm support: local search, DPLL, CDCL
- Problem-specific algorithm selection
- Handles small/high-complexity, medium/structured, large/high-complexity cases

## Contributions
1. First multi-algorithm ASIC SAT accelerator
2. Mixed-signal in-memory computing implementation
3. Orders-of-magnitude speedups: 90x (small), 19x (medium), 7x (large)

## Hardware Target
ASIC

## Techniques
Near-data-processing, circuit-design
