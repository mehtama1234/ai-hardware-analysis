# Chameleon-SAT: An Adaptive Boolean Satisfiability Accelerator Using Mixed-Signal In-Memory Computing for Versatile SAT Problems

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
SAT problems span diverse scales and complexities; single solvers cannot efficiently handle all variants.

## Key Idea
ASIC accelerator with mixed-signal in-memory computing supporting three algorithm classes (local search, DPLL, CDCL) via adaptive reconfiguration.

## Method
Chameleon-SAT is a specialized computer chip (an ASIC) that solves Boolean satisfiability problems—puzzles where you find true/false values satisfying a set of logical rules. It uses mixed-signal in-memory computing (calculations done directly in memory using both digital and analog signals) to run three different solving strategies: local search (making small changes to find solutions), DPLL (systematic exploration with backtracking), and CDCL (learning from conflicts to avoid repeating failed attempts). By reconfiguring to use the best strategy for each problem's type and size, it efficiently handles the full range from small high-complexity cases to large high-complexity problems.

## Contributions
1. First multi-algorithm ASIC SAT accelerator
2. Mixed-signal in-memory computing implementation
3. Orders-of-magnitude speedups: 90x (small), 19x (medium), 7x (large)
