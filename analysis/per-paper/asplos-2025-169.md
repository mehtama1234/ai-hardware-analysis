# Pirate: No Compromise Low-Bandwidth VR Streaming for Edge Devices

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
High-quality VR streaming for edge devices must simultaneously satisfy low bandwidth constraints and real-time 90 FPS operation, but previous approaches sacrifice one for the other.

## Motivation
Edge platforms cannot render VR locally, making streaming necessary, but existing ML-based stereo synthesis models are too computationally expensive for resource-constrained edge devices.

## Method
Pirate sends only one eye's video at a time (alternating left and right), since the two views in VR are almost identical. Each transmission includes lightweight geometric information—disparity maps showing object distance and optical flow showing pixel motion—that let the device recreate the missing eye's view without large AI models, at bitrates as low as 0.1 bits per pixel. By alternating transmission, the system can also reuse frames recreated earlier, further saving bandwidth.

## Key Novelty
Reconstructing VR's missing eye view step-by-step using only distance and motion information (disparity and optical flow)—not large AI models—to enable 90 FPS streaming at 0.1 bits per pixel on edge devices.

## Contributions
- Pirate framework exploiting stereo similarity via single-eye alternating transmission
- Lightweight iterative stereo view synthesis using disparity and optical flow without ML inference
- 90 FPS real-time operation at 0.1 bpp bandwidth on edge hardware
- 20%–40% bandwidth reduction with similar quality vs. prior approaches
