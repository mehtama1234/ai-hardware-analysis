# PIMnet: A Domain-Specific Network for Efficient Collective Communication in Scalable PIM

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
PIM compute units can only access their local memory; inter-bank communication in PIM systems must route through the host CPU, which becomes a bottleneck for collective communication operations (e.g., all-reduce, broadcast) that are common in many workloads, limiting PIM's scalability.

## Motivation
As PIM systems scale to many banks and chips, the overhead of routing inter-PIM communication through the host CPU dominates application performance, making direct PIM-to-PIM interconnects essential for realizing the full potential of processing-in-memory at scale.

## Method
PIMnet is a network that lets PIM compute units communicate directly across memory banks, eliminating the need to route messages through the host CPU—a traditional bottleneck for collective operations like all-reduce and broadcast. It uses a multi-tier architecture mirroring DRAM's physical structure: communication within a single chip and across chips happen simultaneously, multiplying available bandwidth. Since PIM logic itself manages this network rather than the host processor, it's optimized for the collective communication patterns that appear in actual PIM workloads.

## Key Novelty
PIMnet enables direct communication between PIM compute units across memory banks and chips without routing through the host CPU, using a network structure that matches DRAM's physical organization.

## Contributions
1. PIMnet: domain-specific PIM interconnection network enabling direct connectivity between PIM compute units
2. Bandwidth parallelism exploitation enabling concurrent inter-bank/inter-chip transfers
3. Multi-tier network architecture matched to DRAM packaging hierarchy
4. Up to 85x speedup on collective communications and 11.8x improvement on real applications over baseline PIM (UPMEM)
