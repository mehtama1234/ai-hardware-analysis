# Towards Secure Data Management using Multi-Cryptographic Solutions

**Problem:** Secure data outsourcing systems lack principled approaches to reason about security properties and acceptable information leakage.

**Method:** The Secure Normal Form (SNF) framework lets data owners explicitly specify which data aspects are non-sensitive and how much information those aspects can safely leak—like rough frequency patterns. The system then processes queries on encrypted data in a way that reveals only those pre-approved patterns while protecting the sensitive data completely, so queries can run efficiently without accidentally leaking secret information.

**Key Result:** Principled formalization of leakage definitions; discussed application to advanced computational environments and modern data architectures.

**Hardware Target:** CPU  
**Workloads:** database
