# isscc-2025-030: High-Density 3D NAND Flash

**Title:** A 321-Layer 2Tb 4b/cell 3D-NAND-Flash Memory with a 75MB/s Program Throughput

**Venue:** ISSCC

## Core Contribution
Ultra-high-layer 3D NAND achieving 2Tb capacity with 4-bit/cell density and 75MB/s program throughput for enterprise SSDs and AI systems.

## Key Metrics
- **Capacity:** 2Tb
- **Cell Density:** 4 bits/cell
- **Program Throughput:** 75MB/s

## Problem
Enterprise SSDs and AI systems demand memory with both high density and fast sequential/random-access performance while maintaining reliability in QLC (4-bit/cell) flash.

## Method
321-layer 3D-NAND-Flash stack design with optimized multi-layer cell programming and encoding schemes.

Low (abstract-only analysis).
