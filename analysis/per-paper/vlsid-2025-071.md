# BMC Engine Sequencing with Graph Neural Network Embeddings of Hardware Circuits

**Paper ID:** vlsid-2025-071
**Venue:** VLSID
**Confidence:** low

## Problem
Formal verification via Bounded Model Checking (BMC) requires engine selection and sequencing; traditional approaches lack intelligent switching between engines at different verification depths.

## Motivation
Different BMC engines perform better at different verification depths; intelligent selection can improve overall verification performance.

## Method
The approach uses a neural network (GNN) trained to understand hardware circuit structure—creating mathematical embeddings via the DeepGate2 tool—to predict which formal verification engine will perform best at each depth of checking. Rather than using a single engine for the entire verification process, it learns to switch between different engines as it digs deeper into the circuit, based on what the neural network discovers about the circuit's structural properties.

## Key Novelty
Using neural circuit embeddings to automatically select which formal verification engine to use and when, replacing fixed strategies with machine-learned decisions.

## Contributions
- GNN-based circuit representation learning for BMC
- Intelligent BMC engine switching strategy
- Integration with DeepGate2 for circuit embeddings
