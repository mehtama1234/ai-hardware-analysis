# Analog In-Memory Computing Enhanced FPGA for High-Throughput and Energy-Efficient Acceleration

**Problem:** FPGA routing fabric incurs high data movement overhead because large amounts of data must be shuttled between compute and memory blocks, limiting energy efficiency for AI workloads.

**Method:** They add small computing circuits called Dot Product Engines—built from RRAM (a type of memory that retains data without power) and placed directly in the FPGA fabric so computation happens where data lives. Dot products (which multiply matching pairs and add the results) are a common operation in AI workloads. They design this for 40 nm chips using the Verilog to Routing framework and test it with a custom event-driven simulator that measures how operations perform over time.

**Novelty:** Building analog Dot Product Engines from RRAM and embedding them directly in FPGA fabric means computing happens in memory instead of shuttling data between separate compute and storage blocks.
