# Advancing Functional Safety: Improving Failure Mode Analysis and Fault Injection Using Automation and GNN Algorithms

**Paper ID:** vlsid-2025-064
**Venue:** VLSID
**Confidence:** low

## Problem
Complex electronic systems require Failure Mode Analysis and Fault Injection for functional safety, but traditional methods suffer from high simulation time, manual effort, and scalability challenges.

## Motivation
High-reliability systems need efficient FMA and FI processes. Growing design complexity makes manual analysis impractical and error-prone. Need for automation and accelerated fault criticality detection.

## Method
Two-part solution: (1) FMA automation system ensuring consistency and reducing manual effort, (2) GNN-based acceleration of FI process using GCNII model to detect critical nodes and predict fault criticality.

## Key Novelty
Application of GCNII Graph Neural Networks to functional safety verification; overcomes limitations of traditional GCN in handling complex designs with higher logic depth.

## Contributions
- FMA automation system for consistency and effort reduction
- GNN-based (GCNII) fault criticality detection and prediction
- Acceleration of fault injection process for complex designs
- Improved accuracy in forecasting fault impact
