# Advancing Functional Safety: Improving Failure Mode Analysis and Fault Injection Using Automation and GNN Algorithms

**Paper ID:** vlsid-2025-064
**Venue:** VLSID
**Confidence:** low

## Problem
Complex electronic systems require Failure Mode Analysis and Fault Injection for functional safety, but traditional methods suffer from high simulation time, manual effort, and scalability challenges.

## Motivation
High-reliability systems need efficient FMA and FI processes. Growing design complexity makes manual analysis impractical and error-prone. Need for automation and accelerated fault criticality detection.

## Method
The solution works in two stages: First, an automated Failure Mode Analysis system that systematically identifies all the ways an electronic system could fail, ensuring consistency and reducing manual effort. Second, the system uses GCNII (a machine learning model that learns from how circuit components connect together) to automatically identify which parts are most critical to safety and predict how damaging faults in each would be, accelerating the fault injection testing process.

## Key Novelty
The key innovation is applying GCNII (a graph neural network that, unlike earlier models, can handle the depth and complexity of modern electronic designs) to automatically identify safety-critical components and predict their vulnerability to faults.
