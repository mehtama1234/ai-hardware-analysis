# EF-IMR: Embedded Flash with Interlaced Magnetic Recording Technology

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Optimize Interlaced Magnetic Recording storage by reducing RMW latency and head movement overhead through coordinated scheduling and redundant-operation elimination.

## Problem
IMR increases storage density via track overlap but introduces severe performance penalties from Read-Modify-Write operations and head repositioning.

## Method
When data is written to overlapping magnetic disk tracks, it can disturb neighbors, requiring expensive read-modify-write fix-ups to keep data correct. EF-IMR minimizes these fix-ups through smart scheduling (reducing disk head movement), write merging (combining multiple writes), and skip detection (avoiding unnecessary operations).

## Key Results
- **20.11% RMW latency reduction**
- **89.37% head movement latency reduction**
- Maintains IMR density benefits

## Limitations
