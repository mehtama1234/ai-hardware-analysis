# dac-2025-452: HLS Performance Prediction with Directives

## Summary
Proposes a post-implementation performance prediction method for High-Level Synthesis circuits that explicitly models HLS optimization directives and resource reuse patterns using TransformerConv-based Graph Neural Networks.

## Key Results
- Critical path delay prediction: 3.87–8.08% error
- Power prediction: 3.87–8.08% error  
- Resource utilization prediction: 3.87–8.08% error
- Good generalization to unseen kernels

## Technical Approach
- **Graph Representation**: Integrates directive optimization and resource reuse info into CDFG-derived graphs
- **GNN Architecture**: TransformerConv with aggregation pooling to extract performance-critical features
- **Target**: FPGA/HLS design flows

## Contribution
Addresses the gap where existing HLS tools fail to predict performance impact of optimization directives before costly re-synthesis, enabling better design trade-offs.
