# ScanNow: A Scan Window-Based Sparse Matrix Multiplication Accelerator Design

**Venue:** ICCAD
**ID:** iccad-2025-135
**Confidence:** low

## Problem
Sparse matrix-matrix multiplication (SpMM) exhibits irregular memory access patterns across diverse sparse structures, creating performance bottlenecks on traditional computing platforms.

## Motivation
Dedicated hardware accelerators for SpMM must handle diverse sparse patterns flexibly to achieve significant speedups.

## Method
ScanNow breaks sparse matrices into 'scan windows'—regions it processes in sequence—and automatically adjusts each window's size based on the actual data patterns it encounters, keeping frequently-used data in fast local storage to reduce unpredictable memory access. The architecture dynamically balances how much input versus output data to keep in this local storage based on what's happening in real time, rather than using a fixed ratio. This design lets multiple operations run in parallel, maximizing how busy the hardware stays.

## Key Novelty
The innovation is a 'scan window' task dispatch method that automatically adjusts window sizes and input/output data buffering based on real sparsity patterns, processing the matrix row by row.

## Contributions
- Scan window-based task dispatch scheme for flexible SpMM acceleration
- Hardware architecture with multiple memory components and custom schedulers
- 1.67x average speedup across diverse SpMM workloads
