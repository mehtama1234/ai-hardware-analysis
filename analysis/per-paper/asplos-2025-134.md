# asplos-2025-134: Formalising CXL Cache Coherence

**Venue:** ASPLOS  
**Confidence:** high (full text)

## Problem
The CXL.cache inter-device cache coherence protocol specification contains ambiguities, redundancies, inaccuracies, and potential coherence violations (e.g., if Snoop-pushes-GO is relaxed, two devices can simultaneously hold M-state on the same cacheline) that could cause vendor interoperability failures or silent data corruption.

## Motivation
CXL is the first broadly supported industry standard for inter-device cache coherence; formal verification before wide deployment is the most effective time to identify and fix specification defects.

## Method
The authors built a formal model of the CXL.cache protocol using Isabelle (a tool for proving systems mathematically correct), encoding 20 system components like caches and message buffers, plus 68 transition rules covering all legal message flows. They tested the model against real protocol scenarios (called litmus tests) and verified that removing safety restrictions like Snoop-pushes-GO would break cache coherence. To prove the model guarantees only one device can write shared data at a time (the Single-Writer-Multiple-Reader property), they created a mathematical invariant with 796 parts that stays true through all 68 rules, automatically generating and checking 53,332 proof steps using a custom tool called super_sketch.

## Key Novelty
The first formally verified proof that the CXL.cache protocol correctly implements the Single-Writer-Multiple-Reader property (only one device can write at a time), built with a 796-part mathematical invariant and 53,332 verification steps, which led directly to five accepted fixes in the CXL standard.

## Metrics
- 53,332 Isabelle lemmas proven; 796-conjunct invariant; ~211k lines of proof
- 3-5 hours build time on Intel Core i9-14900HX; 12 person-months total
- 4 of 5 proposed fixes accepted by the CXL consortium

## Hardware Target
CPU, GPU, ASIC, SoC (protocol applies to all CXL-attached devices)

## Baselines
CXL.cache prose English specification (CXL standard)

## Limitations
Formal model is restricted to two devices; coherence violations requiring three or more device interactions are not covered.
