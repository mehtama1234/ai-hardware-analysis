# IceSpy: Reconfigurable Edge Accelerator for Scalable and Private Structural Health Monitoring

**Problem:** Structural Health Monitoring deployment is hindered by high costs from power-hungry wireless transmission and privacy concerns from data exposure. The challenge is implementing privacy-preserving data filtering at the edge while minimizing power consumption and deployment costs.

**Method:** IceSpy uses reconfigurable circuit chips called FPGAs (field-programmable gate arrays) arranged in a parallel-processing pattern called a systolic array to filter sensor data and add privacy protection directly at the monitoring site, before transmitting anything. The system removes unnecessary information from sensor readings, dramatically cutting how much data needs to be sent wirelessly. It also scrambles sensitive readings using local differential privacy (mathematically adding disguising noise to preserve individual privacy while keeping overall patterns intact), so measurements are already hidden before reaching untrusted servers. This parallel arrangement processes large streams of sensor data efficiently.

**Novelty:** IceSpy combines on-device data filtering with privacy protection through local differential privacy using reconfigurable chips (FPGAs) arranged for parallel processing, achieving 3× power reduction while preserving privacy in structural health monitoring.
