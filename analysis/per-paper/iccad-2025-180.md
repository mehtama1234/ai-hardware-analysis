# Design of Machine Learning Accelerators as RISC-V Extensions using an Open Source Tool Flow

**Venue:** ICCAD  
**ID:** iccad-2025-180

## Problem
Designing custom ML accelerators that integrate with RISC-V ISA is complex due to lack of open-source tooling for ISA extension specification and hardware-software co-design.

## Motivation
Open-source ML accelerator design flows are needed to democratize hardware customization for RISC-V platforms, enabling efficient quantized neural networks on edge and embedded systems.

## Method
The approach uses open-source tools to add custom instructions (new operations) to RISC-V processors (an open-source chip design standard) that handle machine-learning operations. Specifically, it defines instructions for quantized LSTM inference (a compressed type of neural network) and table-based function approximation (using lookup tables instead of calculating functions). These new instructions integrate into the standard RISC-V software toolchain by encoding them as instruction types and creating memory-mapped control registers (special memory addresses that control the accelerator).

## Key Novelty
An open-source software toolflow that lets designers add custom machine-learning accelerator instructions to RISC-V processors, demonstrated with quantized LSTM inference and table-based function approximation.

## Contributions
1. Open-source RISC-V ML extension specification and design methodology
2. Quantized LSTM inference accelerator using table-based approximation
3. Integration pathway between accelerator RTL and RISC-V ISA/toolchain
4. Demonstrations on standard RISC-V platforms with hardware-software co-design
