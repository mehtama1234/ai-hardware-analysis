# Design of Machine Learning Accelerators as RISC-V Extensions using an Open Source Tool Flow

**Venue:** ICCAD  
**ID:** iccad-2025-180

## Problem
Designing custom ML accelerators that integrate with RISC-V ISA is complex due to lack of open-source tooling for ISA extension specification and hardware-software co-design.

## Motivation
Open-source ML accelerator design flows are needed to democratize hardware customization for RISC-V platforms, enabling efficient quantized neural networks on edge and embedded systems.

## Method
Leverage open-source RISC-V extension framework (XLEN, custom instructions) to define ML operations (quantized LSTM inference, table-based function approximation). Integrate accelerator design with standard RISC-V toolchain via custom instruction encoding and memory-mapped control registers.

## Key Novelty
Complete open-source toolflow for integrating ML accelerators as RISC-V ISA extensions, demonstrating quantized LSTM and function approximation on extensible architecture.

## Contributions
1. Open-source RISC-V ML extension specification and design methodology
2. Quantized LSTM inference accelerator using table-based approximation
3. Integration pathway between accelerator RTL and RISC-V ISA/toolchain
4. Demonstrations on standard RISC-V platforms with hardware-software co-design
