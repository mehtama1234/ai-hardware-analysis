# isscc-2025-019: High-Density SRAM in 2nm Nanosheet Technology

**A 38.1Mb/mm2 SRAM in a 2nm-CMOS-Nanosheet Technology for High-Density and Energy-Efficient Compute**

## Summary
38.1 Mb/mm² SRAM leveraging 2nm nanosheet CMOS to enable 2x bitline loading increase, optimized via design-technology co-optimization spanning cell, periphery, and floor-planning.

## Technical Approach
- **Nanosheet advantage**: Improved on/off current ratio enables 2x BL loading
- **DTCO**: Optimized cell voltage, peripheral logic, and macro architecture
- **Floor-planning**: Minimized periphery area per bit array

## Key Innovation
Exploitation of nanosheet FET current-ratio advantages for denser BL loading, coupled with area-optimized peripheral logic using advanced design rules.

## Contributions
- 2x BL loading increase vs. previous node
- Area-optimized peripheral logic implementation
- Comprehensive DTCO methodology for advanced nodes
- High density (38.1 Mb/mm²) achievement

## Target Workloads
On-chip cache, compute buffers, embedded memory for SoCs
