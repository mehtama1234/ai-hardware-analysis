# LLM-IMC: Automating Analog In-Memory Computing Architecture Generation with Large Language Models

**Problem:** The knowledge-intensive hardware design process and lack of high-quality circuit netlists constrain design space exploration and optimization of analog In-Memory Computing systems, limiting designs to behavioral system-level tools.

**Method:** LLM-IMC is a fine-tune-free LLM framework that automates SPICE netlist generation for analog IMC through a Python-based tool. It systematically generates diverse IMC simulation scripts, performs LLM-driven performance analysis for design space exploration, and provides an integration roadmap for neuromorphic crossbar design flows.

**Novelty:** Using a fine-tune-free LLM to automate SPICE netlist generation and performance analysis for analog in-memory computing architecture design.
