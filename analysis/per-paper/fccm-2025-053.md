# LLM-IMC: Automating Analog In-Memory Computing Architecture Generation with Large Language Models

**Problem:** The knowledge-intensive hardware design process and lack of high-quality circuit netlists constrain design space exploration and optimization of analog In-Memory Computing systems, limiting designs to behavioral system-level tools.

**Method:** LLM-IMC uses a large language model (without requiring special training) to automatically write SPICE netlists—the detailed circuit descriptions needed for simulation—for analog in-memory computing systems (where processing happens inside memory using continuous electrical signals). The Python-based framework systematically generates diverse simulation scripts and uses the LLM to analyze their performance, helping engineers explore different design options. It also provides a roadmap for integrating these designs into neuromorphic crossbar architectures, which are grid-like circuits modeled after how biological brains process information.

**Novelty:** Using a large language model without special training to automate SPICE netlist generation and performance analysis for analog in-memory computing system design.
