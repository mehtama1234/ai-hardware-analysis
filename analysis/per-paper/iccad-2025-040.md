# Differentiable Physical Optimization

**ID:** iccad-2025-040  
**Venue:** ICCAD

## Problem
Gate sizing and buffer insertion are interdependent VLSI physical optimization tasks typically solved in decoupled manner, yielding suboptimal results; existing simultaneous methods use oversimplified timing models or heuristics, lacking mathematical rigor.

## Motivation
High-performance circuit design requires unified optimization of interdependent physical design tasks for better timing closure.

## Method
Presents a differentiable physical optimization framework with GPU acceleration integrating gate sizing and buffer insertion: timing-aware buffer tree skeleton construction, physics-aware modeling, and discrete-aware optimization algorithms.

## Key Novelty
First differentiable framework mathematically unifying gate sizing and buffer insertion with rigorous physical modeling.

## Contributions
1. Differentiable physical optimization framework for gate sizing and buffer insertion
2. Timing-aware buffer tree skeleton construction
3. Physics-aware modeling of design interdependencies
4. Discrete-aware optimization algorithms
5. 23% TNS improvement, 12% WNS improvement with 30× speedup versus CPU flow
