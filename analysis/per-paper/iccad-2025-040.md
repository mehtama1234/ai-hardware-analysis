# Differentiable Physical Optimization

**ID:** iccad-2025-040  
**Venue:** ICCAD

## Problem
Gate sizing and buffer insertion are interdependent VLSI physical optimization tasks typically solved in decoupled manner, yielding suboptimal results; existing simultaneous methods use oversimplified timing models or heuristics, lacking mathematical rigor.

## Motivation
High-performance circuit design requires unified optimization of interdependent physical design tasks for better timing closure.

## Method
The framework solves gate sizing (resizing logic gates) and buffer insertion (adding intermediate signal copies) together as a unified mathematical problem, rather than separately. It builds a mathematical model where changes in circuit design directly compute their timing effects, using GPU acceleration to speed up the calculations. It strategically places buffers based on timing requirements and simultaneously optimizes both gate sizes and buffer placement using algorithms that respect the fact that circuit components only come in certain fixed sizes. Throughout the optimization, it accurately models the actual physics of the circuit instead of relying on simplified approximations.

## Key Novelty
It unifies gate sizing and buffer insertion into a single mathematical problem (differentiable—solvable with calculus) with rigorous circuit physics, rather than solving them separately with simplified models.

2. Timing-aware buffer tree skeleton construction
