# GradMap: A Gradient-Descent Approach to Simultaneous Technology Mapping, Buffer Insertion, and Gate Sizing

**Venue:** ICCAD  
**ID:** iccad-2025-210  
**Confidence:** low

## Problem Statement
Technology mapping, buffer insertion, and gate sizing are traditionally sequential or use greedy approaches. This work addresses the need for simultaneous optimization of these interdependent tasks.

## Motivation
Simultaneous optimization of circuit design tasks can achieve better quality-of-results than sequential approaches.

## Method
Treats circuit design as a differentiable optimization problem—one where you can compute gradients like neural network training—then applies gradient descent to simultaneously optimize three interconnected choices: logic gate selection (technology mapping), repeater placement (buffer insertion), and transistor sizing (gate sizing). Since these choices affect each other—transistor sizes determine circuit speed, which determines where repeaters are needed, which constrains gate selection—optimizing them jointly finds better solutions than sequential tuning. The GPU-accelerated method efficiently explores the design space.

## Key Novelty
First to simultaneously optimize technology mapping, buffer insertion, and gate sizing using gradient descent on differentiable circuit timing analysis.

## Contributions

1. Differentiable STA formulation enabling gradient-based optimization
2. GPU-parallelizable simultaneous optimization framework
3. 7-33% QoR improvements over state-of-the-art ABC tool
