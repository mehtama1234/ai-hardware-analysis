# GradMap: A Gradient-Descent Approach to Simultaneous Technology Mapping, Buffer Insertion, and Gate Sizing

**Venue:** ICCAD  
**ID:** iccad-2025-210  
**Confidence:** low

## Problem Statement
Technology mapping, buffer insertion, and gate sizing are traditionally sequential or use greedy approaches. This work addresses the need for simultaneous optimization of these interdependent tasks.

## Motivation
Simultaneous optimization of circuit design tasks can achieve better quality-of-results than sequential approaches.

## Method
Uses differentiable Static Timing Analysis (STA) enabling gradient descent optimization. GPU-parallelizable optimization framework allows efficient exploration of the design space. Integrates technology mapping, buffer insertion, and gate sizing in a unified gradient-based framework.

## Key Novelty
First to apply differentiable STA for simultaneous optimization of technology mapping, buffer insertion, and gate sizing using gradient descent.

## Contributions

1. Differentiable STA formulation enabling gradient-based optimization
2. GPU-parallelizable simultaneous optimization framework
3. 7-33% QoR improvements over state-of-the-art ABC tool
