# A Cross-model Fusion-aware Framework for Optimizing (gather-matmul-scatter)s Workload

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Sparse neural networks (RGCN, SpConv, MoE) use gather-matmul-scatter primitives, but optimizations are model-specific, require expensive search, and fail on dynamic inputs.

## Method
Efficient-GMS analyzes dataflow (how data flows through computation) to identify shared patterns in gather-matmul-scatter operations across different neural network types like RGCN, SpConv, and MoE. It creates four optimized dataflow variants by fusing (combining) operations either vertically or horizontally—different structural ways to merge computation steps. A performance model predicts execution speed for each configuration, and a lightweight heuristic selects the best dataflow variant based on input characteristics and hardware, avoiding expensive search across all possibilities.

## Key Novelty
Shared dataflow patterns in gather-matmul-scatter operations enable the same optimizations to work across different neural networks (RGCN, SpConv, MoE) without per-model tuning.

## Results
- **1.46× speedup** (RGCN)
- **1.32× speedup** (SpConv-based)
- **1.15× speedup** (MoE)
