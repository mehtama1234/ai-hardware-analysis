# SC-2025-190: Load Imbalance Modelling in Shared Memory Systems

**Venue:** SC 2025  
**Authors:** Johannes Langguth, James D. Trotter, Xing Cai  
**Confidence:** low (abstract only)

## Summary

New performance model for shared memory multicores accounting for inhomogeneous per-core memory traffic patterns, improving accuracy over mainstream bandwidth-division strategies.

## Hardware Target

- Multicore processors
- Shared memory systems

## Problem & Motivation

Memory bandwidth is the primary limiting factor in many modern HPC applications. Aggregate memory bandwidth saturates as core count exceeds a threshold. Mainstream performance models divide total traffic volume by maximum bandwidth, assuming homogeneous per-core traffic. This leads to inaccurate estimates when actual per-core traffic is uneven.

## Approach

New performance model:
1. Targets inhomogeneous per-core memory traffic patterns
2. Requires only three hardware parameters
3. Accounts for bandwidth saturation effects
4. Improves time estimation accuracy

## Key Contributions

1. Performance model handling inhomogeneous traffic
2. Minimal parameter requirements (3 hardware parameters)
3. Demonstrates mainstream strategy inaccuracy
4. Case studies of uneven per-core memory traffic
5. Improved prediction for memory-bound workloads

## Limitations

Specific model accuracy metrics not in abstract; experimental validation details limited; conditions triggering inhomogeneity not fully specified.
