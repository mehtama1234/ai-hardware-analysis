# CaRDS: Compiler-aided Remote Data Structures

**Paper ID:** sc-2025-350
**Venue:** SC
**Confidence:** low

## Problem Statement
Conservative compile-time policies for far memory placement harm performance when memory is constrained

## Motivation
Applications need dynamic far memory policies that adapt to runtime conditions without expensive profiling

## Method
The compiler analyzes code to identify data structures (organized chunks of data) that are candidates for movement to slower, far memory. At runtime, the system monitors actual memory conditions and dynamically decides for each data structure whether to move it ('remoting'), load it ahead of time ('prefetch' to hide delays), or clear it out ('evacuation' to free space), rather than following a fixed compile-time decision. By operating at the data structure level instead of byte-by-byte, the system makes decisions efficiently.

## Key Novelty
The key innovation is adapting far-memory placement decisions at runtime at the data structure level, guided by compile-time analysis, instead of locking in decisions at compile time.
