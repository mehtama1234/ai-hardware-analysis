# CaRDS: Compiler-aided Remote Data Structures

**Paper ID:** sc-2025-350
**Venue:** SC
**Confidence:** low

## Problem Statement
Conservative compile-time policies for far memory placement harm performance when memory is constrained

## Motivation
Applications need dynamic far memory policies that adapt to runtime conditions without expensive profiling

## Method
Compiler-runtime hybrid: static analysis identifies candidate objects, runtime determines remoting/prefetch/evacuation policies at data structure granularity

## Key Novelty
Dynamic far memory policies at data structure granularity combining compile-time static analysis with runtime adaptation

## Contributions
- CaRDS system for dynamic far memory management
- 2x improvement over prior automatic approaches
- 25% of profile-guided performance without profiling overhead
