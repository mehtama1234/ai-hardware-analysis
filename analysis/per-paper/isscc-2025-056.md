# isscc-2025-056: 64Gb STT-MRAM Cross-Point with Discharge-Read

**Title:** 30.6 A 64Gb DDR4 STT-MRAM Using a Time-Controlled Discharge-Reading Scheme for a .001681µm 1T-1MTJ Cross-Point Cell

**Venue:** ISSCC

**Core Problem:**
High-density 1S1M MRAM cross-point arrays require reliable reads balancing signal amplitude and disturbance; conventional schemes fail at tight 0.001681µm² cell areas.

**Method:**
Time-controlled discharge-read scheme with local-capacitance mode optimizes discharge timing for reliable read signal and minimal disturbance across entire 64Gb array.

**Key Innovation:**
Discharge-read timing control + local-capacitance mode for dense 1S1M cross-point reliability.

**Metrics:**
- **Capacity:** 64 Gb
- **Cell Area:** 0.001681 µm² (1S1M)
- **Technology:** 20.5 nm HP

**Architecture:** 1S1M cross-point STT-MRAM array with timing-controlled discharge read

**Techniques:** Memory-system design, circuit design

**Confidence:** Low (abstract-only)
