# PluS: Highly Efficient and Expandable ML Compiler with Pluggable Graph Schedules

**Problem:** ML compilers must balance optimization efficiency with extensibility across heterogeneous hardware platforms. Existing compilers either specialize for specific targets or lack flexible scheduling strategies that can be easily adapted.

**Method:** PluS is an ML compiler with pluggable scheduling strategies—the rules for arranging computations efficiently can be swapped or combined for different hardware. The system separates scheduling logic from the core compiler framework, enabling different optimization strategies to be applied independently. This lets the same compiler efficiently work with different hardware platforms (like GPUs or CPUs) by plugging in the right schedule.

**Novelty:** The core idea is pluggable scheduling: you can swap optimization rules for different hardware targets without modifying the compiler itself.
