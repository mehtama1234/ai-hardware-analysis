# PluS: Highly Efficient and Expandable ML Compiler with Pluggable Graph Schedules

**Problem:** ML compilers must balance optimization efficiency with extensibility across heterogeneous hardware platforms. Existing compilers either specialize for specific targets or lack flexible scheduling strategies that can be easily adapted.

**Method:** PluS implements a modular ML compiler architecture where graph scheduling strategies are pluggable components that can be swapped and composed. The system separates scheduling logic from the core compiler framework, enabling different optimization strategies to be applied to computation graphs. This allows the same compiler to efficiently target multiple hardware platforms through interchangeable schedule implementations.

**Novelty:** Pluggable graph schedules that decouple optimization strategies from compiler infrastructure, enabling modular and extensible scheduling within a unified ML compilation framework.
