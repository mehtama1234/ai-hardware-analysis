# Apollo: Automated Routing-Informed Placement for Large-Scale Photonic Integrated Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-275

## Problem
Photonic integrated circuits (PICs) at scale are manually laid out due to analog custom layout nature, curvy waveguide structures, and single-layer routing resources with stringent physical constraints. Manual process takes weeks and is error-prone, fundamentally unscalable for large-scale PIC systems.

## Motivation
To automate PIC layout design at scale by coupling placement with physical-aware routing and leveraging GPU acceleration.

## Method
GPU-accelerated framework featuring asymmetric bending-aware wirelength function with explicit modeling of waveguide routing congestion and crossings; conditional projection gradually enforcing user-defined constraints (alignment, spacing); custom blockwise adaptive Nesterov-accelerated optimizer for stable, high-quality convergence. Tightly couples placement with physical-aware routing.

## Key Novelty
First GPU-accelerated, routing-informed placement framework tailored for large-scale PICs coupling placement with physical-aware routing.

## Contributions
- Asymmetric bending-aware wirelength model with explicit congestion/crossing modeling
- Conditional projection constraint handling for alignment and spacing
- Custom blockwise adaptive optimizer for efficient convergence
- 94.79% average routing success rate for large-scale PICs
- Large-scale PIC benchmarks derived from real-world photonic tensor cores
