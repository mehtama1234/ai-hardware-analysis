# SC25 Paper Analysis: sc-2025-094

## Compute4Biology: Taking Stock of High Performance Computing Needs for Foundation Models in Biological Sciences

### Summary
This systematic study characterizes HPC requirements for foundation models across biological domains (genomics, proteomics, chemistry, biomedical NLP). It identifies domain-specific computational bottlenecks and proposes unified HPC co-design principles for next-generation systems supporting AI-driven biological discovery.

### Key Problem
- **Domain Diversity**: Biological sciences have heterogeneous computational needs
- **Infrastructure Gap**: General-purpose HPC systems are not optimized for biological AI workloads
- **Co-Design Unknown**: Lack of systematic guidance for building biology-specific HPC systems

### Technical Approach
1. **Cross-Domain Analysis**: Genomics, transcriptomics, proteomics, chemistry, biomedical literature
2. **Bottleneck Characterization**: I/O, memory, compute kernels specific to each domain
3. **Pattern Identification**: Common hardware utilization and design trade-offs
4. **Principle Extraction**: Best practices for HPC system design

### Key Findings by Domain
- **Genomics**: Massive I/O throughput demands from sequence data
- **Protein Structure Prediction**: Intense memory bandwidth and capacity pressure
- **Molecular Modeling**: Specialized compute kernels and linear algebra operations
- **Biomedical NLP**: Transformer-based foundation models with specific memory/compute balance

### Contributions
1. First comprehensive cross-domain HPC characterization for biological AI
2. Domain-specific bottleneck analysis
3. Hardware utilization trade-offs and patterns
4. Software stack design guidance
5. Co-design principles for future systems
6. Unified best practices framework

### Hardware & Workloads
- **Target Hardware**: HPC systems with specialized accelerators
- **Workloads**: Foundation models in genomics, proteomics, chemistry, biomedical NLP

### Applications
- AI-driven drug discovery
- Protein structure prediction
- Genomic analysis at scale
- Computational structural biology

### Theme
AI Infrastructure and System Co-Design for Scientific Computing

### Confidence
Low (appears to be a survey/position paper based on abstract)
