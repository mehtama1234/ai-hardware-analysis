# RTPU: Unifying Non-Private and Private Inference with Reconfigurable Architecture

**Venue:** ICCAD  
**Confidence:** low

## Problem
Data centers must simultaneously handle plaintext-based non-private inference and ciphertext-based private inference (via fully homomorphic encryption), but current solutions require costly dedicated accelerators or inflexible general-purpose hardware with poor performance.

## Motivation
Privacy-preserving inference is increasingly important; unified hardware supporting both plaintext and encrypted computation improves efficiency and reduces deployment costs in heterogeneous data center workloads.

## Method
RTPU reconfigurable architecture exploits inherent similarities between plaintext tensor and polynomial ring ciphertext computations through fine-grained reconfiguration. Kernel group-based scheduling optimizes hardware utilization and QoS across multi-tenant workloads with varying privacy requirements.

## Key Novelty
Reconfigurable multi-core architecture that seamlessly switches between tensor-based plaintext and polynomial ring-based ciphertext computations with substantial silicon reuse.

## Contributions
- Unified architecture supporting both non-private and private inference
- Near-ASIC performance with beyond-ASIC flexibility
- Substantial silicon reuse between NPI and PI modes
- High resource utilization for multi-tenant workloads with kernel group scheduling
