# RTPU: Unifying Non-Private and Private Inference with Reconfigurable Architecture

**Venue:** ICCAD  
**Confidence:** low

## Problem
Data centers must simultaneously handle plaintext-based non-private inference and ciphertext-based private inference (via fully homomorphic encryption), but current solutions require costly dedicated accelerators or inflexible general-purpose hardware with poor performance.

## Motivation
Privacy-preserving inference is increasingly important; unified hardware supporting both plaintext and encrypted computation improves efficiency and reduces deployment costs in heterogeneous data center workloads.

## Method
RTPU is a reconfigurable multi-core hardware design that performs similar underlying operations for both regular unencrypted tensor math (plaintext) and encrypted homomorphic-encryption math (polynomial ring ciphertext), enabling the same hardware to handle both through fine-grained reconfiguration. It uses kernel group-based scheduling to organize and coordinate computations strategically, optimizing how much of the hardware gets used while maintaining consistent performance (quality of service) for multiple simultaneous jobs with different privacy requirements.

## Key Novelty
A reconfigurable multi-core architecture that seamlessly switches between regular unencrypted tensor math (plaintext) and encrypted polynomial-ring computations, achieving substantial silicon reuse instead of requiring separate specialized accelerators.

## Contributions
- Unified architecture supporting both non-private and private inference
- Near-ASIC performance with beyond-ASIC flexibility
- Substantial silicon reuse between NPI and PI modes
- High resource utilization for multi-tenant workloads with kernel group scheduling
