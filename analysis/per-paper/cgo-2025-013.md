# Proteus: Portable Runtime Optimization of GPU Kernel Execution with Just-in-Time Compilation

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
AOT compilation misses runtime specialization opportunities for GPU kernels. Language-specific JIT solutions like CUDA Jitify have high overhead. HPC applications benefit from specialization to input arguments and launch parameters.

## Technical Approach
Lightweight JIT compilation extracts language-agnostic LLVM IR and recompiles at runtime. Annotation-based interface specifies specialization points. Portable across AMD and NVIDIA using standard LLVM infrastructure.

## Key Novelty
First portable JIT approach for GPU kernels using language-agnostic LLVM IR with reduced overhead vs. language-specific solutions.

## Key Results
- 2.8× speedup (AMD), 1.78× (NVIDIA) over AOT
- 1.23× faster than CUDA Jitify
- Portable across vendors

- **Techniques:** JIT compilation, LLVM IR, runtime optimization
