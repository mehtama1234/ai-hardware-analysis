# HybridTier: an Adaptive and Lightweight CXL-Memory Tiering System

**Venue:** ASPLOS  
**Authors:** Kevin Song, Jiacheng Yang, Zixuan Wang, Jishen Zhao, Sihang Liu, Gennady Pekhimenko  
**Confidence:** low (abstract only)

## Problem
CXL-based memory tiering systems must efficiently migrate pages between fast DRAM and slow CXL memory, but existing systems fail to adapt to dynamically shifting hotness distributions and incur excessive memory and cache overhead from tracking metadata.

## Motivation
CXL memory expands capacity at lower cost but at 2-3x higher access latency, so effective page migration is critical for performance, yet dynamic skewed access patterns defeat static tracking policies.

## Method
HybridTier simultaneously tracks both long-term data access frequency and short-term access momentum to capture shifting hotness distributions. To reduce memory overhead, it employs probabilistic access tracking with compact data structures that trade minimal inaccuracy for 2-7.8x lower metadata footprint. Cache overhead is minimized by organizing tracking metadata in data-locality-optimized structures that reduce hotness-lookup cache misses. Migration decisions combine both temporal signals for higher accuracy than either alone.

## Key Novelty
Simultaneous dual-signal tracking (long-term frequency plus short-term momentum) combined with probabilistic metadata to achieve high hotness accuracy at minimal memory and cache overhead in CXL tiering.

## Contributions
- HybridTier: adaptive CXL tiering combining long-term frequency and short-term momentum tracking
- Probabilistic access tracking reducing metadata memory overhead by 2.0-7.8x
- Locality-optimized data structures reducing cache misses by 1.7-3.5x
- Up to 91% (19% geomean) performance improvement over prior tiering systems
