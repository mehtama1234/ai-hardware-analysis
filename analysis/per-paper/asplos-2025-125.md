# HybridTier: an Adaptive and Lightweight CXL-Memory Tiering System

**Venue:** ASPLOS  
**Authors:** Kevin Song, Jiacheng Yang, Zixuan Wang, Jishen Zhao, Sihang Liu, Gennady Pekhimenko  
**Confidence:** low (abstract only)

## Problem
CXL-based memory tiering systems must efficiently migrate pages between fast DRAM and slow CXL memory, but existing systems fail to adapt to dynamically shifting hotness distributions and incur excessive memory and cache overhead from tracking metadata.

## Motivation
CXL memory expands capacity at lower cost but at 2-3x higher access latency, so effective page migration is critical for performance, yet dynamic skewed access patterns defeat static tracking policies.

## Method
HybridTier tracks two different signals simultaneously to decide which pages should stay in fast DRAM: long-term frequency (which pages are accessed often overall) and short-term momentum (which pages are being used right now). To reduce memory overhead, it uses probabilistic tracking—sampling access patterns and inferring behavior rather than recording every access—which is slightly less precise but uses far less memory. It minimizes cache overhead by organizing tracking metadata in compact structures that keep related data close together, reducing cache misses during lookups. Migration decisions combine both signals together, achieving better accuracy than either signal alone.

## Key Novelty
HybridTier combines long-term access frequency and short-term momentum—two complementary signals that capture both steady usage patterns and immediate workload shifts—using probabilistic tracking to accurately decide which pages stay in fast memory while minimizing memory and cache overhead.

## Contributions
- HybridTier: adaptive CXL tiering combining long-term frequency and short-term momentum tracking
- Probabilistic access tracking reducing metadata memory overhead by 2.0-7.8x
- Locality-optimized data structures reducing cache misses by 1.7-3.5x
- Up to 91% (19% geomean) performance improvement over prior tiering systems
