# NetKeeper: Enhancing Network Resilience with Autonomous Network Configuration Update on Traffic Patterns and Anomalies

**Problem:** Networks lack autonomous mechanisms to respond to traffic anomalies and pattern changes by dynamically reconfiguring settings, resulting in prolonged degradation or failures when unexpected traffic conditions occur.

**Method:** NetKeeper continuously watches network traffic and automatically detects anomalies—unexpected shifts in how data flows. When an anomaly is spotted, it reconfigures the network on its own (adjusting routing rules, queue management, and resource allocation) to handle the new conditions without manual intervention.

**Novelty:** The system automatically adjusts network settings when traffic patterns change unexpectedly, without human intervention.
