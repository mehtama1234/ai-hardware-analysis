# NetKeeper: Enhancing Network Resilience with Autonomous Network Configuration Update on Traffic Patterns and Anomalies

**Problem:** Networks lack autonomous mechanisms to respond to traffic anomalies and pattern changes by dynamically reconfiguring settings, resulting in prolonged degradation or failures when unexpected traffic conditions occur.

**Method:** NetKeeper monitors network traffic patterns and detects anomalies in real-time. When anomalies are detected, the system autonomously updates network configurations (e.g., routing policies, queue management, resource allocation) to adapt to the new conditions without manual intervention.

**Novelty:** Closed-loop autonomous network configuration management that dynamically responds to traffic anomalies and pattern changes.
