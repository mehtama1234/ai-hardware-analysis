# Continuous On-Chip Learning in Neural Networks using SOT-MRAM based CIM Architectures

**Authors:** Anubha Sehgal, Sandeep Soni, Sumit Diware, Alok Kumar Shukla, Sourajeet Roy, Rajendra Bishnoi

**Venue:** ICCAD

## Summary
Proposes SOT-MRAM-based CIM architecture with concurrent read-write capability for continuous on-chip learning without interrupting inference.

## Key Contributions
- SOT-MRAM bit-cell design with 2R1W configuration for concurrent operations
- Dedicated inference and learning paths enabling non-blocking weight updates
- 2.4× energy-efficiency improvement over state-of-the-art solutions
- 5.4× throughput improvement with minimal overhead
