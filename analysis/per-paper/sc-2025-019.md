# Accelerating Advanced Light Source Science Through Multi-Facility HPC Workflows

## Overview
Infrastructure connecting Advanced Light Source synchrotron to ALCF and NERSC for transparent HPC-accelerated microtomography reconstruction, supporting both real-time streaming and batch processing.

## Problem & Motivation
- **Challenge**: Synchrotron beamlines produce high-volume complex data; scientists lack transparent access to HPC resources for reconstruction and analysis
- **Opportunity**: Remote HPC integration enables rapid feedback and high-quality reconstructions without beamline scientists managing backend systems
- **Use Case**: Microtomography 3D reconstruction requiring CPU and GPU algorithms

## Architecture & Method
**Dual Pipeline Architecture**

1. **Real-time Streaming**
   - Microtomography data streams directly to NERSC compute nodes
   - On-the-fly reconstruction algorithm execution
   - User feedback <10 seconds

2. **Batch File-Based**
   - Automated transfer to NERSC and ALCF file systems
   - Intensive 3D reconstruction algorithms
   - 20-30 minute turnaround for high-quality results

**Infrastructure**
- ESnet high-bandwidth network connecting ALS to HPC centers
- Transparent resource access (users don't manage backend systems)
- CPU and GPU algorithm deployment

## Key Contributions
1. **Real-time feedback** (<10 seconds) enabling quick data quality assessment
2. **Batch processing** (20-30 min) producing analysis-ready reconstructions
3. **Transparent HPC integration** for beamline scientists
4. **Dual-pipeline architecture** balancing speed vs quality
5. **Extensible framework** for additional beamlines

## Performance & Results
| Workflow | Latency | Use Case |
|----------|---------|----------|
| Real-time Streaming | <10 seconds | Rapid feedback, data quality check |
| Batch Processing | 20-30 minutes | High-quality reconstruction for analysis |

## System Design Insights

- ESnet bandwidth enables seamless remote HPC integration
- GPU and CPU algorithms both relevant for synchrotron data
