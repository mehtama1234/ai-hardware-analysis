# dac-2025-422: Learning-Based Architecture for Dynamic Graph Processing

**Problem:** Dynamic graph processors suffer inefficient memory access and index management, limiting throughput.

**Motivation:** Learned indexes improve access but interconnected graph data needs specialized adaptive structures.

**Method:** The system trains a machine learning model to learn where different parts of the graph (vertices and edges) are located in memory, using information about the graph's structure. It then watches how the graph is actually accessed and reorganizes memory by moving frequently used data closer together, so these pieces can be retrieved faster.

**Key Novelty:** Learned-index–driven adaptive memory reorganization for dynamic graphs.

**Contributions:**
- Topology-aware learned index for vertex/edge prediction
- Adaptive tree memory manager with runtime pattern-based reorganization
- 3.4x higher throughput; 1.7x–11x processing time reduction

**Workloads:** Graph analytics

**Confidence:** low (abstract-only)
