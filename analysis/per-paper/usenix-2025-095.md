# FlexPipe: Maximizing Training Efficiency for Transformer-based Models with Variable-Length Inputs

**Problem:** Training transformers with variable-length inputs causes padding waste and pipeline stage imbalances. GPU hardware cannot efficiently handle heterogeneous sequence lengths within a single batch.

**Method:** FlexPipe introduces a flexible pipelining strategy that adapts pipeline bubble boundaries and batch composition to variable-length inputs. The system dynamically groups sequences by length and adjusts pipeline stages to minimize padding overhead while maintaining stage utilization.

**Novelty:** Adaptive pipelining mechanism that eliminates padding inefficiency by matching pipeline boundaries to variable-length input distributions rather than enforcing fixed-length batching.
