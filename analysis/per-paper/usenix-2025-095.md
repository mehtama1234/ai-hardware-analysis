# FlexPipe: Maximizing Training Efficiency for Transformer-based Models with Variable-Length Inputs

**Problem:** Training transformers with variable-length inputs causes padding waste and pipeline stage imbalances. GPU hardware cannot efficiently handle heterogeneous sequence lengths within a single batch.

**Method:** FlexPipe groups sequences by actual length instead of padding them to uniform length. It then dynamically reconfigures the pipeline—the parallel stages that process data on the GPU—to match these groups. This eliminates wasted computation from padding while keeping all pipeline stages active and busy.

**Novelty:** Dynamically adjust the pipeline to match how input lengths are actually distributed, rather than enforcing fixed-length batching and padding.
