# mlsys-2025-022 — Enabling Unstructured Sparse Acceleration on Structured Sparse Accelerators (TASD/TASDER)

**Venue:** MLSYS 2025

**One-line problem:** Enable unstructured sparse DNNs to run on structured sparse hardware (e.g., 2:4 Tensor Cores) without hardware-specific fine-tuning.

## Method
TASD (Tensor Approximation via Structured Decomposition) breaks any randomly-scattered sparse weights down into a series of structured patterns (where exactly N out of M values are non-zero) that can run efficiently on GPU accelerators. For weights, an offline greedy search (trying combinations and keeping the best) finds the decomposition minimizing dropped values while maintaining 99% model accuracy. For activations (data flowing through during inference), the system picks the right pattern dynamically based on how sparse the data is. Custom hardware (TTC) extends existing accelerators to support multiple N:M patterns simultaneously, while optimizations keep data blocks stationary to spread the decomposition cost across many operations.

## Key Novelty
This is the first method that enables unstructured sparse neural networks to run on structured sparse hardware without retraining, by decomposing weights into a series of structured patterns using the distributive property of matrix algebra.

## Metrics
- 39% speedup on NVIDIA RTX 3080 (2:4 sparse Tensor Cores)
- EDP improvement: up to 83% (dense DNNs), 74% (sparse DNNs)
- Computation reduction up to 40%
