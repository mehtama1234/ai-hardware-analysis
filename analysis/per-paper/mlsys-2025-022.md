# mlsys-2025-022 — Enabling Unstructured Sparse Acceleration on Structured Sparse Accelerators (TASD/TASDER)

**Venue:** MLSYS 2025

**One-line problem:** Enable unstructured sparse DNNs to run on structured sparse hardware (e.g., 2:4 Tensor Cores) without hardware-specific fine-tuning.

## Method
TASD decomposes any sparse tensor into a series of N:M structured sparse tensors using the distributive property of tensor algebra. TASD-W performs offline weight decomposition with a greedy layer-wise search maintaining 99% quality. TASD-A handles runtime activation decomposition with sparsity-degree-based pattern selection. TTC hardware supports multiple N:M patterns; decomposition-aware dataflow keeps B/C tiles stationary to amortize overhead.

## Key Novelty
First approach enabling unstructured sparse models to run on structured sparse accelerators without retraining, via tensor series decomposition.

## Metrics
- 39% speedup on NVIDIA RTX 3080 (2:4 sparse Tensor Cores)
- EDP improvement: up to 83% (dense DNNs), 74% (sparse DNNs)
- Computation reduction up to 40%
