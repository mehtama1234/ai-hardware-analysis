# asplos-2025-145: Spindle: Efficient Distributed Training of Multi-Task Large Models via Wavefront Scheduling

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Training multi-task, multi-modal (MT MM) foundation models is inefficient because their heterogeneous model components and diverse workloads across tasks and modalities create complex dependency patterns that existing parallelism strategies cannot jointly optimize.

## Motivation
Foundation models increasingly unify multiple tasks and modalities under a shared base with specialized components, causing severe resource under-utilization in standard training systems.

## Method
Spindle breaks model execution into 'waves'—groups of different computational tasks—and uses two strategies to run them efficiently. First, it sends each wave to devices based on how much computation it needs, accounting for the fact that different data types (images, text, etc.) have different computational costs. Second, it schedules waves based on which waves need output from other waves, allowing new waves to start before old ones finish, so devices never sit idle waiting. This overlapping execution fills the gaps that normally occur when some devices finish their work before others.

## Key Novelty
The innovation is 'wavefront scheduling'—jointly optimizing how to assign different types of tasks to devices and when they should run based on data dependencies, all in one unified system instead of separately.

## Contributions
- Wavefront scheduling formulation for heterogeneous MT MM wave decomposition
- Heterogeneity-aware workload parallelization strategy
- Dependency-driven execution scheduling overlapping waves across tasks
- Up to 71% speedup over state-of-the-art training systems
