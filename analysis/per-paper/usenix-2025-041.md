# PPipe: Efficient Video Analytics Serving on Heterogeneous GPU Clusters via Pool-Based Pipeline Parallelism

**Problem:** Efficient serving of latency-bound model inference on heterogeneous GPU clusters where GPUs have vastly different computational capabilities. Current systems underutilize lower-tier GPUs despite many CNN layers executing with comparable latency across different GPU classes.

**Method:** PPipe uses pool-based pipeline parallelism to assign model layers to GPU classes based on per-layer latency profiles. An MILP-based control plane optimizes task assignments while the data plane implements resource reservation-based adaptive batching to maintain pipeline throughput and latency bounds.

**Novelty:** Applying pipeline parallelism (traditionally for training throughput) to latency-bound inference serving by exploiting comparable per-layer execution times across heterogeneous GPU classes.
