# PPipe: Efficient Video Analytics Serving on Heterogeneous GPU Clusters via Pool-Based Pipeline Parallelism

**Problem:** Efficient serving of latency-bound model inference on heterogeneous GPU clusters where GPUs have vastly different computational capabilities. Current systems underutilize lower-tier GPUs despite many CNN layers executing with comparable latency across different GPU classes.

**Method:** PPipe measures how fast each layer of the model runs on different GPU types. It uses pool-based pipeline parallelism to assign layers to GPU classes based on these per-layer latency measurements. An optimization algorithm (MILP) in the control plane decides the assignments, while the data plane implements adaptive batching with resource reservations to maintain consistent throughput and meet response-time deadlines.

**Novelty:** Pipeline parallelism—traditionally used for training throughput—is applied to time-critical inference serving by exploiting how many layers run at comparable speeds across different GPU types.
