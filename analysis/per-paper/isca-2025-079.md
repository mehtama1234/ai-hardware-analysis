# isca-2025-079 — LUT Tensor Core: A Software-Hardware Co-Design for LUT-Based Low-Bit LLM Inference

**Venue:** ISCA 2025  
**Authors:** Zhiwen Mo, Lei Wang, Jianyu Wei, Zhichen Zeng, Shijie Cao, Lingxiao Ma, Naifeng Jing, Ting Cao, et al. (Microsoft Research + collaborators)  
**Confidence:** high (full text)

## Problem
Low-bit LLM inference (INT4/2/1 weights x FP16/INT8 activations) requires mixed-precision GEMM (mpGEMM), not natively supported by GPU Tensor Cores. Conventional LUT approaches to mpGEMM are bottlenecked by table precomputation and storage overhead that negates area/power gains over dequantization-based methods.

## Motivation
Weight quantization to 1–4 bits is the primary approach to reducing LLM memory footprint, but the lack of hardware mpGEMM support forces costly dequantization, especially at large batch sizes.

## Method
LUT Tensor Core combines software and hardware optimization to speed up AI inference with low-precision numbers. On the software side, lookup-table precomputation is merged with the preceding operation to eliminate redundant work; weights are rewritten symmetrically (from {0,1} to {-1,+1}), which halves table storage. On the hardware side, a specialized Tensor Core processes bits one at a time and uses an elongated tiling pattern (M=2, N=64, K=4) to reuse the lookup table across calculations; a new instruction (LMMA) integrates with compilers (TVM/Roller/Welder) to automatically generate optimized code.

## Key Novelty
The innovation combines table-lookup software optimization (symmetric weight rewriting and operation merging) with a bit-serial elongated-tiling Tensor Core, achieving 4–6x lower power and area than MAC-based Tensor Cores and 1.44x better efficiency than prior lookup-table designs.

## Contributions
1. Root-cause analysis showing conventional LUT hardware fails due to precomputation/storage overhead.
2. DFG-based precompute fusion + weight reinterpretation (halves table size and MUX overhead).
3. LUT Tensor Core (TSMC 28nm): 16% area of FP16 Tensor Core; 4–6x PPA gains for 1-bit weights.
4. LMMA ISA + compilation stack achieving 2.06–5.51x end-to-end LLM inference speedup with comparable accuracy.

## Metrics
- GEMV speedup: 1.42x over LUT-GEMM software
- GEMM speedup: 72.2x over LUT-GEMM software
- Compute density: 1.44x over UNPU (SOTA LUT accelerator)
- End-to-end LLM speedup: 2.06–5.51x vs. FP16 baseline
- TC area: 16% of conventional FP16 Tensor Core

## Baselines
- A100 GPU with cuBLAS (FP16)
- CUTLASS dequantization-based INT4 kernel
- LUT-GEMM (software LUT on GPU)
- UNPU (LUT-based ASIC accelerator)

## Limitations
Full hardware validation requires tape-out; results rely on Accel-Sim simulation and analytical tile-based simulator (~5.21% mean error); register file capacity constrains large tiling on real GPUs.
