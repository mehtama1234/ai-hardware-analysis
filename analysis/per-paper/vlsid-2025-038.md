# VLSID 2025-038: 407μW Real-Time Speech Denoiser Chip

## Summary
Ultra-low-power on-device audio denoiser chip achieving real-time speech processing at 407μW (28nm CMOS, 0.75mm²). Quantized cascaded encoder-decoder with specialized memory routing yields 75% memory reduction and 5-9x memory access reduction.

## Problem
Wearable IoT devices require on-device audio denoising for privacy, consistency, and low latency. Traditional ML models are too power-hungry for battery-powered hearing aids, earbuds, and smartwatches.

## Method
- Quantized convolutional encoder-decoder network
- Cascaded redundant architecture
- Specialized PE activation routing scheme
- 28nm CMOS implementation
- Optimized for memory access patterns

## Key Results
- **407μW power consumption** (at 0.65V, 18.5MHz)
- **3.24μJ per frame**
- **0.75mm² die area**
- **8ms frame latency** (real-time capable for 125 Hz)
- **75% memory reduction** via quantization
- **5-9x memory access reduction** via routing
- **Highest PESQ audio quality** vs prior works

## Applications
- Hearing aids and HAs
- Wireless earbuds/earpieces
- Smartwatch audio processing
- Military/communication headsets
- Privacy-preserving audio systems

## Limitations
- Single frequency point (18.5MHz) evaluated
- Single voltage point (0.65V) evaluated
- Audio quality comparison against specific baselines not detailed
- Generalization to other audio tasks unclear
- Limited dataset evaluation

## Hardware Targets
- Wearable audio devices
- Ultra-low-power IoT
- Battery-powered systems
