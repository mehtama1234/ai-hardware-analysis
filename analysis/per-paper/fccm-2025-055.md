# HP-FFT: A General High-Performance FFT Generator Using High-Level Synthesis

**Problem:** Existing FFT HLS IP libraries suffer from low throughput and poor usability due to inadequate parallelism exploitation, while high-throughput RTL FFT designs lack portability and flexibility.

**Method:** The approach analyzes FFT loop structures to find places where calculations at different levels can run in parallel—called hierarchical parallelism, which means different stages of the algorithm progress simultaneously rather than sequentially. HP-FFT automatically generates hardware designs from this analysis with adjustable parallelism settings. This tuning dial lets designers choose between using less silicon and power or achieving faster data throughput.

**Novelty:** The core idea is using automatic hardware generation to systematically find and exploit multiple levels of parallelism within FFT algorithms, balancing high throughput with hardware portability.
