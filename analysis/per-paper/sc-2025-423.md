# BOER: Enhancing Resource Utilization for Deep Learning Inference with Hybrid Spatial GPU Sharing

**Paper ID:** sc-2025-423
**Venue:** SC
**Authors:** Bowen Zhang, Yuhang Wang 0012, Zhuozhao Li

## Problem

Spatial multiplexing via MPS and MIG introduces interference and partitioning rigidity, limiting multi-model inference throughput and GPU utilization in production systems.

## Motivation

Single-GPU multi-model inference requires higher utilization to amortize model deployment costs; MPS-only solutions suffer performance interference; MIG-only solutions waste compute due to rigid partition sizes.

## Method

The system runs multiple AI models on a single GPU by splitting it into logical sections using MIG (Multi-Instance GPU partitioning), then further sharing each section using MPS (Multi-Process Service), which lets multiple model processes run simultaneously on the same partition. It automatically decides which models to run together, how to split the GPU into partitions, how to distribute the workload across processes, and where to map the GPU's computing threads (thread blocks) to each process. Rather than trying to predict exactly how models will interfere with each other when sharing resources—which often leads to inaccurate guesses—it uses Bayesian optimization (a method that learns from past experiments to intelligently suggest new configurations to try) to explore different MPS settings and find what actually works best in practice.

## Key Novelty

This system combines MPS (letting multiple processes share sections of the GPU) with MIG (dividing the GPU into partitions), then uses Bayesian optimization to automatically find the best MPS settings by trying different configurations and measuring performance, avoiding the inaccuracy of trying to predict interference mathematically.

## Contributions

- Identification of MPS+MIG integration challenges (interference amplification, partition mismatch)
- Hierarchical scheduling framework for joint resource allocation decisions
- Bayesian optimization with acceleration strategies for MPS configuration search
- 46–77% throughput improvement over state-of-the-art spatial multiplexing
