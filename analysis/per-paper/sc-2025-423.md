# BOER: Enhancing Resource Utilization for Deep Learning Inference with Hybrid Spatial GPU Sharing

**Paper ID:** sc-2025-423
**Venue:** SC
**Authors:** Bowen Zhang, Yuhang Wang 0012, Zhuozhao Li

## Problem

Spatial multiplexing via MPS and MIG introduces interference and partitioning rigidity, limiting multi-model inference throughput and GPU utilization in production systems.

## Motivation

Single-GPU multi-model inference requires higher utilization to amortize model deployment costs; MPS-only solutions suffer performance interference; MIG-only solutions waste compute due to rigid partition sizes.

## Method

Hierarchical scheduling framework combining MPS on top of MIG partitions. Jointly optimizes model colocation, workload distribution, MIG partition selection, and MPS thread-block mapping. Bayesian optimization explores MPS configuration space without building explicit performance models.

## Key Novelty

First system to effectively combine MPS with MIG to mitigate interference; Bayesian-driven MPS tuning avoids inaccurate interference prediction models.

## Contributions

- Identification of MPS+MIG integration challenges (interference amplification, partition mismatch)
- Hierarchical scheduling framework for joint resource allocation decisions
- Bayesian optimization with acceleration strategies for MPS configuration search
- 46–77% throughput improvement over state-of-the-art spatial multiplexing
