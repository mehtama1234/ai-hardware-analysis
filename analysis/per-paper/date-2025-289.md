# CorrectBench: Automatic Testbench Generation with Functional Self-Correction using LLMs for HDL Design

**Venue**: DATE  
**Primary Theme**: LLM-based HDL testbench generation with self-correction  

## Problem
LLM-based hardware testbench generation produces functional errors without automatic correction mechanisms; performance is especially poor for sequential circuit testing.

## Method
CorrectBench framework uses LLM to generate testbenches from RTL specification, performs automatic functional validation, and applies self-correction using bug information from validation failures; iteratively improves until passing.

## Key Novelty
Automatic functional self-correction mechanism that uses bug information to fix generated testbenches without human intervention.

## Contributions
- Self-validation achieving 88.85% validation success rate
- Self-correction improving overall pass rate to 70.13% vs 52.18% prior work
- 62.18% improvement for sequential circuits over previous method
- Open-sourced implementation and benchmarks
