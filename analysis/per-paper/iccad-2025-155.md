# MM-GRADE - Multi-modal RAG System for EDA Tool Documentation QA

MM-GRADE presents a multi-modal retrieval-augmented generation system for answering questions about EDA tool documentation by combining text and vision-based understanding. Through vision LLM finetuning, the system can interpret diagrams, screenshots, and textual content to retrieve relevant information and synthesize comprehensive answers. This approach addresses the challenge of scattered and heterogeneous documentation in EDA tools by enabling semantic search across mixed content types and improving user query resolution efficiency.
