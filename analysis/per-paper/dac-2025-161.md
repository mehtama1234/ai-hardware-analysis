# BEVSA: A Real-Time Bird's-Eye-View Semantic Segmentation Accelerator

**Authors:** Sangho Lee, Jueun Jung, Wuyoung Jang, Jihyeon Hwang, Kyuho Lee  
**Venue:** DAC 2025

## Summary
BEVSA is a specialized 28nm hardware accelerator for real-time BEV semantic segmentation in multi-camera systems. It achieves 43.2x speedup for BEV pooling via hierarchical decomposition and 1.61x convolution improvement via coarse-to-fine sparsity handling, delivering 23.1 fps with 167.4x energy advantage over edge platforms.

## Key Contributions
- Block-decomposed hierarchical BEV pooling cluster (43.2x speedup)
- Coarse-to-fine-grained zero-skipping convolution (1.61x improvement)
- Real-time BEV segmentation at 23.1 fps
- 167.4x energy-per-frame improvement over edge baseline

## Technical Approach
BEVSA addresses two bottlenecks: (1) BEV transformation latency by hierarchically decomposing the search space into MCS-compatible blocks, enabling parallel pooling, and (2) high sparsity (69.1%) by implementing coarse-grained channel-level zero skipping for all-zero channels plus tile-wise fine-grained skipping, significantly reducing unnecessary computations.
