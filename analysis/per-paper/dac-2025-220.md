# CIM-BLAS: Computing-in-Memory Accelerator for BLAS

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
BLAS operations are memory-bandwidth-bound in CPUs and GPUs; memory wall is the primary bottleneck.

## Key Insight
Computing-in-memory can alleviate memory bandwidth bottleneck for data-intensive linear algebra workloads.

## Method
CIM-based BLAS accelerator with high-precision unified floating-point pipeline; configurable dataflows support BLAS levels 1/2/3.

## Contributions
- First CIM BLAS accelerator with high-precision FP pipeline
- Configurable dataflows for BLAS hierarchy
- Orders of magnitude gains for level-1/2 BLAS
- 2.6–24.1× energy efficiency for level-3; excellent scalability

## Hardware Target
CIM

## Workloads
HPC (Scientific/Engineering Computing)

## Theme
CIM-based BLAS acceleration for memory-bandwidth-intensive linear algebra.
