# isca-2025-034 — WindServe: Efficient Phase-Disaggregated LLM Serving with Stream-based Dynamic Scheduling

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Phase-disaggregated LLM serving still suffers from coarse-grained static scheduling that leaves prefill compute overloaded while decoding resources sit idle. KV cache transfers between disaggregated phases introduce additional scheduling overhead degrading latency SLOs.

## Motivation
LLM inference serving must meet tight TTFT and TPOT SLOs under high load, but existing disaggregated systems use static assignment that cannot adapt to dynamic request arrival patterns.

## Method
WindServe uses a central scheduler that constantly watches how much compute and memory each part of the system is using, then dynamically reassigns jobs between the compute-heavy prefill phase (which prepares input) and the memory-heavy decoding phase (which generates output) to avoid queuing and reduce overhead from moving KV caches (data that stores the model's context) between phases. Its stall-free rescheduling strategy keeps memory constantly busy during these data transfers without creating scheduling pauses. A stream-based pipeline separates prefill and decoding tasks into different execution channels and handles their dependencies asynchronously, preventing interference when both run at the same time.

## Key Novelty
WindServe's key breakthrough is a rescheduling method that keeps memory constantly busy while moving KV caches between phases without scheduling delays, enabling dynamic load balancing that static schedules cannot match.

## Contributions
1. Fine-grained dynamic scheduler monitoring compute/memory utilization for real-time cross-phase job assignment.
2. Stall-free rescheduling strategy saturating memory resources during KV cache transfers.
3. Stream-based pipeline mitigating prefill-decoding interference.
4. 4.28x TTFT median improvement and 1.5x TPOT P99 reduction vs SOTA phase-disaggregated systems.
