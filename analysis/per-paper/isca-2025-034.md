# isca-2025-034 — WindServe: Efficient Phase-Disaggregated LLM Serving with Stream-based Dynamic Scheduling

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Phase-disaggregated LLM serving still suffers from coarse-grained static scheduling that leaves prefill compute overloaded while decoding resources sit idle. KV cache transfers between disaggregated phases introduce additional scheduling overhead degrading latency SLOs.

## Motivation
LLM inference serving must meet tight TTFT and TPOT SLOs under high load, but existing disaggregated systems use static assignment that cannot adapt to dynamic request arrival patterns.

## Method
WindServe implements a global scheduler continuously monitoring compute and memory resource usage across prefill and decoding pools, dynamically orchestrating cross-phase job assignments to reduce queuing delay and KV-cache swapping overhead. A stall-free rescheduling strategy saturates memory resources while minimizing KV cache transfer overhead. A stream-based pipeline separates prefill and decoding execution streams and manages dependencies asynchronously to mitigate interference.

## Key Novelty
Stall-free rescheduling strategy that enables continuous memory resource saturation during KV cache migration between disaggregated phases, enabling fine-grained dynamic load balancing impossible with static schedules.

## Contributions
1. Fine-grained dynamic scheduler monitoring compute/memory utilization for real-time cross-phase job assignment.
2. Stall-free rescheduling strategy saturating memory resources during KV cache transfers.
3. Stream-based pipeline mitigating prefill-decoding interference.
4. 4.28x TTFT median improvement and 1.5x TPOT P99 reduction vs SOTA phase-disaggregated systems.
