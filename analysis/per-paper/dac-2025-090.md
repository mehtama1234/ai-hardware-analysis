# IRGNN: Graph-based Framework for Static IR Drop Prediction

## Problem
IR drop analysis in modern integrated circuits' on-chip power grids requires high accuracy but is computationally expensive. Traditional numerical methods are slow; CNN-based ML approaches lose fine-grained topology information.

## Method
The method uses a two-part approach: it first runs a numerical solver called AMG-PCG (which finds approximate solutions without fully solving the system) to create initial rough estimates of where power is lost in the chip's power grid, then uses graph-based machine learning to refine them. It represents the power grid nodes as a point cloud—a set of interconnected points—and feeds this into a graph transformer, a type of neural network that learns how nodes relate to each other based on their connections. The key innovation is a technique called Neighbor Distance Attention (NDA) that weights nearby nodes based on physical distance, allowing the model to capture both local fine-grained details and large-scale patterns in how power distributes across the grid.

## Key Innovation
First framework enabling per-node IR drop prediction (unlike CNNs which produce coarse maps) while grounding learning in numerical solutions for interpretability.

## Contributions
- Graph-based framework (IRGNN + IRGraph) for node-wise IR drop
- NDA layer for topology-aware aggregation
- Numerical solution integration as interpretability foundation
- Higher accuracy than CNN and traditional solvers with reduced runtime

## Motivation
IR drop verification bottlenecks design closure at advanced nodes; ML acceleration must preserve power grid structure.
