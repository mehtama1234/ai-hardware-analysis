# RAGO: Systematic Performance Optimization for Retrieval-Augmented Generation Serving
**ID:** isca-2025-052 | **Venue:** ISCA | **Confidence:** low (abstract-only)

## Problem
Retrieval-Augmented Generation (RAG) serving is emerging as a critical LLM deployment pattern, but diverse RAG algorithm variants exhibit wildly different workload characteristics (retrieval latency, reranking compute, generation length), making a single optimization strategy inadequate. There is no systematic framework for characterizing and optimizing across the space of RAG pipelines.

## Motivation
RAG is now a standard technique for grounding LLM outputs, but its serving efficiency lags standalone LLM inference because the retrieval, reranking, and generation stages interact in workload-specific ways that existing LLM serving systems are not designed to handle.

## Method
RAGO introduces RAGSchema, a structured abstraction encoding the components and dataflow of any RAG algorithm, used to characterize and compare workload behaviors. The paper analyzes representative RAG variants with distinct schemas, exposing performance bottlenecks. RAGO then applies algorithm-specific system optimizations—scheduling policies, resource partitioning, and batching strategies—tuned to each RAGSchema's profile, rather than treating all RAG variants uniformly as extended LLM inference workloads.

## Key Novelty
RAGSchema is the first structured abstraction that captures the full diversity of RAG algorithm variants, enabling principled, schema-driven performance optimization rather than ad-hoc per-system tuning.

## Contributions
- RAGSchema: a structured abstraction covering the wide space of RAG algorithm designs
- Systematic characterization of performance variability across representative RAG workloads with distinct schemas
- RAGO optimization framework targeting up to 2x QPS per chip improvement
- Up to 55% reduction in time-to-first-token latency vs. RAG systems built on LLM-serving extensions
