# Improving Software Reliability with Rust: Implementation for Enhanced Control Flow Checking Methods

**Venue**: DATE  
**Primary Theme**: Rust-based hardened embedded systems with control flow checking  

## Problem
C language memory management vulnerabilities threaten safety-critical embedded systems; control flow checking (CFC) methods need platform-agnostic implementation for fault detection.

## Method
The method implements two control flow checking algorithms—YACCA and RACFED—using Rust, which has built-in protections against memory errors that are common in C. Because Rust prevents these memory mistakes automatically, the same code can run on any hardware without modification (this is called 'platform-agnostic'). The checks work at the application level, meaning they're built into the program itself rather than requiring special OS or hardware support, and they detect when a program's execution path deviates from its intended course to catch faults in safety-critical systems—those where failures could cause real harm.

## Key Novelty
These control flow checking algorithms are the first to be implemented in Rust at the application level, making it possible to detect faults in safety-critical systems using the same code across any hardware platform.

## Contributions
- Rust-based implementation of YACCA achieving 46.5% diagnostic coverage
- Rust-based implementation of RACFED achieving 50.1% diagnostic coverage
- Platform-agnostic application-level CFC approach
- Alignment with functional safety standards (ISO 26262 class systems)
