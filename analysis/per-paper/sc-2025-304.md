# SC-2025-304: C.A.T.S.: Memory and Control Flow Tracing for Whole-Program Performance Analysis

## Summary
This work introduces C.A.T.S. (a memory and control flow tracing framework) designed for whole-program performance analysis. Rather than traditional call-stack based profiling, C.A.T.S. uses control flow stacks and memory events to identify performance anti-patterns, enable code fusion, optimize data layouts, and improve communication-computation overlap.

## Key Contributions
1. **C.A.T.S. tracing format** capturing control flow stacks and memory events at scale
2. **Compiler analysis passes** for static trace extraction in seconds on consumer hardware
3. **Interactive visualizations** (timeline, dataflow, access patterns) for exploring optimization opportunities
4. **Case study results**: 3x memory footprint reduction, improved communication-computation overlap, data layout optimizations

## Technical Approach
- Control flow stack and memory event tracing (vs. traditional call stacks)
- Compiler-based static analysis for rapid trace generation
- Multiple visualization modalities for different analytical perspectives
- Pattern recognition for common performance anti-patterns

## Hardware & Systems
- Multi-core CPUs
- Distributed HPC systems
- Systems with complex memory hierarchies

## Workloads & Evaluation
- **Applications**: Sparse computations, hydrodynamics, climate modeling
- **Key metrics**: Memory footprint reduction (3x), optimization opportunities identified
- **Performance gain mechanisms**: Code fusion, data layout optimization, communication-computation overlap

## Limitations & Future Work
- Limited to specific application domains (sparse, simulation-heavy)
- Scalability to million-line codebases not thoroughly explored
- Static extraction accuracy for complex control flow not fully characterized
- GPU memory optimization not addressed
- Generalization to streaming and dynamic workloads unclear
