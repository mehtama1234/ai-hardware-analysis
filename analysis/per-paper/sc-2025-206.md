# MISA-AKMC : Achieve Kinetic Monte Carlo Simulation of 20 Quadrillion Atoms on GPU Clusters

**Venue:** SC  
**Theme:** Materials Science Simulation  
**Confidence:** low

## Problem Statement
Atomic Kinetic Monte Carlo requires massive memory for large-scale simulations; porting to GPUs faces memory pressure and communication overhead scaling limitations

## Motivation
AKMC enables materials science discovery at atomistic scale; enabling micrometer-scale simulations (quadrillion atoms) could unlock new materials insights

## Methodology
GPU cluster implementation with Lattice Data Compression and Vacancy Decompression algorithms; multi-level pipeline with on-demand communication merging reduces data transfer

## Key Novelty
This is the first Kinetic Monte Carlo simulation to reach micrometer scale—simulating 20 quadrillion atoms—on GPU clusters, made possible by data compression strategies that work within GPUs' memory constraints.

## Contributions
- GPU cluster AKMC implementation
- Lattice data compression and vacancy decompression algorithms
- Multi-level pipeline with communication optimization
- 10.41x throughput improvement vs state-of-the-art KMC
- 52.07x simulation scale expansion enabling quadrillion-atom simulations
- 96.03% weak scaling, 85.29% strong scaling on 16K GPUs
