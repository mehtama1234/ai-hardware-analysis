# An Efficient Polynomial Multiplication Derived Implementation of Convolution in Neural Networks

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Convolution is the most time-consuming kernel in CNNs/GNNs; im2col+MM introduces redundancy while FFT requires multiple passes, so no approach optimizes all parameter configurations.

## Core Innovation
Reformulating convolution as polynomial multiplication to achieve efficiency gains not available through standard im2col or FFT approaches.

## Method
Reinterprets neural network convolution as polynomial multiplication by carefully constructing conceptual polynomials that map convolution to computing polynomial product coefficients. This transformation avoids data redundancy and multiple passes by leveraging fast polynomial multiplication algorithms.

## Key Contributions
- Novel polynomial multiplication-based convolution formulation eliminating im2col redundancy and FFT overhead
- Implementation for multiple NVIDIA GPUs with PyTorch integration
- Speedups: 43.1% (V100), 34.6% (3090Ti), 33.6% (A10G) vs cuDNN

## Results
- V100: 43.1% speedup
- 3090Ti: 34.6% speedup
- A10G: 33.6% speedup

## Limitations
Scalability to large convolutions, memory bandwidth utilization, and depthwise/grouped convolutions not discussed.
