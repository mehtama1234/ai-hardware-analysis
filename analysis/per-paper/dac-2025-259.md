# LIO-DPC: Accurate and Fast LiDAR-Inertial Odometry with Dynamic Pose Chain

**Venue:** DAC | **ID:** dac-2025-259

## Problem
LiDAR-inertial odometry must balance speed and accuracy: filter-based methods are fast but accumulate errors; graph-based methods are accurate but computationally expensive for real-time systems.

## Key Innovation
Dynamic pose chain optimization that applies efficient local graph optimization to fast filter-generated poses while using loop sparsification to reduce computational complexity.

## Method
The system starts with a fast filter that quickly estimates poses at each moment, then selectively refines them using local graph optimization—checking whether nearby poses fit together correctly. To keep computation manageable, it uses loop sparsification: it identifies representative loops (when the device returns to a location it's seen before) but only checks the ones closest together in time and space, skipping redundant constraints. This selective checking captures the accuracy benefits of graph-based optimization without the computational cost of handling every constraint.

## Results
- Real-time performance
- Outperforms state-of-the-art methods in accuracy
- Combines benefits of filter-based speed and graph-based accuracy
