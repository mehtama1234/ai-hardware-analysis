# LIO-DPC: Accurate and Fast LiDAR-Inertial Odometry with Dynamic Pose Chain

**Venue:** DAC | **ID:** dac-2025-259

## Problem
LiDAR-inertial odometry must balance speed and accuracy: filter-based methods are fast but accumulate errors; graph-based methods are accurate but computationally expensive for real-time systems.

## Key Innovation
Dynamic pose chain optimization that applies efficient local graph optimization to fast filter-generated poses while using loop sparsification to reduce computational complexity.

## Method
1. Fast filter generates initial pose chain
2. Computationally efficient local graph optimization refines relative poses on pose chains
3. Loop sparsification selects representative loops (temporally/spatially proximate)
4. Minimal loop errors while maintaining real-time performance

## Results
- Real-time performance
- Outperforms state-of-the-art methods in accuracy
- Combines benefits of filter-based speed and graph-based accuracy

## Applications
Robotics navigation, autonomous driving, drone operation

## Techniques
