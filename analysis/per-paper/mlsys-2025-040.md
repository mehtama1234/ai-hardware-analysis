# Seesaw: High-throughput LLM Inference via Model Re-sharding

**ID:** mlsys-2025-040 | **Venue:** MLSYS 2025

## Problem
A single static parallelization strategy cannot optimally serve both prefill (compute-bound, benefits from tensor parallelism) and decode (memory-bandwidth-bound, benefits from pipeline parallelism) stages of LLM inference.

## Method
Seesaw switches the model's parallelization strategy during inference based on the current phase: using tensor parallelism (splitting layers across GPUs) for prefill (processing prompts) and pipeline parallelism (distributing layers sequentially across GPUs) for decode (generating tokens). To manage memory efficiently, the key-value cache—intermediate results needed for fast computation—is stored in fast GPU VRAM for active batches and slower CPU DRAM as overflow storage, with asynchronous background transfers between them. A scheduler batches requests together to reduce how often resharding occurs, spreading the switching cost across multiple requests.

## Key Novelty
The core idea is dynamically resharding the model between different parallelization strategies mid-inference, combined with tiered KV cache management and request batching to minimize resharding overhead.

## Results
- **1.78x** peak throughput improvement over vLLM (1.36x average)
- Evaluated on NVIDIA A10, L4, A100 GPUs
- Baseline: vLLM 0.5.4

## Hardware Target
NVIDIA A10, L4, A100 GPUs; multi-GPU server nodes
