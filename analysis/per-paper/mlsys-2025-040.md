# Seesaw: High-throughput LLM Inference via Model Re-sharding

**ID:** mlsys-2025-040 | **Venue:** MLSYS 2025

## Problem
A single static parallelization strategy cannot optimally serve both prefill (compute-bound, benefits from tensor parallelism) and decode (memory-bandwidth-bound, benefits from pipeline parallelism) stages of LLM inference.

## Method
Seesaw dynamically re-shards the model between TP for prefill and PP for decode at every stage boundary. KV cache is tiered across GPU VRAM and CPU DRAM with async swap pipelines. A transition-minimizing scheduler batches requests to reduce re-sharding frequency.

## Key Novelty
Dynamic mid-inference model re-sharding combined with CPU-backed tiered KV cache buffering and a transition-minimizing request scheduler.

## Results
- **1.78x** peak throughput improvement over vLLM (1.36x average)
- Evaluated on NVIDIA A10, L4, A100 GPUs
- Baseline: vLLM 0.5.4

## Hardware Target
NVIDIA A10, L4, A100 GPUs; multi-GPU server nodes
