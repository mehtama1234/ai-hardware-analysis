# sc-2025-225: Porting Gysela Plasma Simulation to AMD GPUs

## Overview
Practical two-phase porting of petascale Fortran plasma simulation (Gysela) to exascale using OpenMP and Kokkos on AMD GPUs.

## Application
Gysela: Turbulence simulation for tokamak plasmas

## Approach
**Phase 1: OpenMP Offloading**
- Broad code coverage with minimal changes
- Speedups: 1x to 12.5x
- Identified collision operator as bottleneck

**Phase 2: Kokkos Rewrite**
- Rewrote collision operator in C++ using Kokkos
- Developed KoLiOp (Kokkos-based collision operator)
- Among largest speedups relative to CPU baseline

## Contributions
- Practical hybrid OpenMP + Kokkos porting strategy
- Detailed framework comparison and best practices
- Guidance for legacy Fortran code modernization
- Comprehensive benchmarking across CPU/GPU/APU

## Benchmarked Hardware
- **CPU**: AMD Genoa (baseline)
- **GPU**: AMD MI250X (Adastra)
- **APU**: AMD MI300A (Adastra)

## Key Insights
- OpenMP suitable for regular code patterns
- Kokkos better for performance-critical components
- Combination provides flexibility for diverse code
