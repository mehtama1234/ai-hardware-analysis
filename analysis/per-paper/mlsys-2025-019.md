# Efficient On-Device Machine Learning with a Biologically-Plausible Forward-Only Algorithm

**Venue:** MLSys 2025 | **ID:** mlsys-2025-019 | **Confidence:** high

## Problem
Backpropagation-based DNN training is infeasible on IoT/wearable edge devices due to excessive memory requirements and biological implausibility (weight transport, non-locality, update locking, frozen activities).

## Method
Bio-FO trains networks layer-by-layer using only forward passes, without any backward error propagation. At each hidden layer, an auxiliary classifier (a small neural network attached to that layer) uses the layer's output and a fixed random matrix to estimate how well that layer is performing, computing a local error and updating weights based only on adjacent layer activations. This prevents needing error signals from deeper layers and simultaneously eliminates four biological implausibilities: it doesn't require symmetric feedback weights (weight transport), error signals stay local (non-locality), layers update immediately as data arrives (update locking), and activations don't pile up in memory (frozen activities). The method supports locally-connected and convolutional networks through sparsity masking.

## Novelty
First forward-only algorithm simultaneously resolving all four BP biological implausibility issues while outperforming FF, PEPITA, and DRTP in accuracy with 3x memory and up to 19.8x energy reduction.

## Metrics
- 3x memory reduction vs BP (32MB vs 96MB)
- Up to 19.8x energy reduction vs FF (CIFAR-100: 37.9 Wh vs 753.5 Wh)
- CIFAR-100 error: 74.57% (vs 85.76% FF, 76.16% PEPITA)
- mini-ImageNet error: 67.39% (vs 74.58% CaFo, 91.23% PEPITA)
