# Efficient On-Device Machine Learning with a Biologically-Plausible Forward-Only Algorithm

**Venue:** MLSys 2025 | **ID:** mlsys-2025-019 | **Confidence:** high

## Problem
Backpropagation-based DNN training is infeasible on IoT/wearable edge devices due to excessive memory requirements and biological implausibility (weight transport, non-locality, update locking, frozen activities).

## Method
Bio-FO trains each layer independently using only forward passes. An auxiliary classifier with fixed random matrix Bl projects layer activations to class predictions, computing local cross-entropy loss and gradient. Weights updated using only adjacent-layer activations, eliminating all inter-layer dependencies. Sparsity mask Sl enables LC and CNN extensions. Evaluated on Jetson Nano (5W) on MNIST, CIFAR-10/100, CHB-MIT (EEG), MIT-BIH (ECG), and mini-ImageNet.

## Novelty
First forward-only algorithm simultaneously resolving all four BP biological implausibility issues while outperforming FF, PEPITA, and DRTP in accuracy with 3x memory and up to 19.8x energy reduction.

## Metrics
- 3x memory reduction vs BP (32MB vs 96MB)
- Up to 19.8x energy reduction vs FF (CIFAR-100: 37.9 Wh vs 753.5 Wh)
- CIFAR-100 error: 74.57% (vs 85.76% FF, 76.16% PEPITA)
- mini-ImageNet error: 67.39% (vs 74.58% CaFo, 91.23% PEPITA)
