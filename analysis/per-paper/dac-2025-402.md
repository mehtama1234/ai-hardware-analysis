# dac-2025-402: Late Breaking Results: FPGen-3D: Automated Framework for 3D-FPGA Architecture Generation and Exploration

**Problem:** 3D FPGA architecture design requires manual exploration; lack of automated tools prevents efficient design space navigation.

**Method:** FPGen-3D automatically creates 3D FPGA designs (reconfigurable chips with logic blocks stacked vertically and connected by programmable wires) based on parameters you specify. It produces the hardware description code and the programming instructions for each design. The framework explores different strategies for connecting components across vertical layers by testing different designs of 3D switch blocks (devices that route signals between layers) and 3D logic blocks (computational units arranged in 3D).

**Key Novelty:** Automated 3D FPGA generation enabling systematic exploration of vertical connections.

**Contributions:**
- Automated 3D FPGA generation framework
- Synthesizable RTL from parameters
- Routing results and bitstream generation
- 18.5% wire length reduction vs 2D

**Confidence:** low (abstract-only)
