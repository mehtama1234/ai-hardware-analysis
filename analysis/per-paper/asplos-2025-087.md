# asplos-2025-087 — Systematic CXL Memory Characterization and Performance Analysis at Scale

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** Systematic CXL memory performance characterization

## Problem
CXL-attached memory introduces sub-microsecond latency overheads (140-410 ns) relative to local DRAM, but the performance impact across diverse devices, CPU platforms, and workloads is poorly understood, including tail latencies, prefetcher behavior, and bottleneck localization.

## Motivation
CXL is rapidly emerging as the standard interconnect for memory expansion in data centers, but systems architects lack systematic empirical data to reason about performance tradeoffs across the CXL device and CPU ecosystem.

## Method
Melody is a characterization framework that runs 265 workloads across 4 real CXL devices, 5 CPU platforms, and 7 injected latency levels to comprehensively profile CXL memory performance. It introduces SPA (Sub-operation Performance Analysis), a novel methodology that decomposes memory access latency into sub-operations to pinpoint CXL-specific bottlenecks. Melody also measures and discloses CXL tail latency distributions for the first time, and characterizes CPU hardware prefetcher effectiveness (and failures) under CXL latency conditions.

## Key Novelty
SPA is the first technique to pinpoint CXL memory bottlenecks at sub-operation granularity, and Melody provides the first systematic, multi-device, multi-CPU, multi-latency CXL characterization including tail latency disclosure.

## Contributions
- Melody: a CXL characterization framework spanning 265 workloads, 4 devices, 7 latency levels, 5 CPU platforms
- First disclosure of CXL tail latency distributions
- SPA: novel sub-operation analysis methodology for pinpointing CXL bottlenecks
- Characterization of CPU prefetcher inefficiencies specifically under CXL latency conditions
