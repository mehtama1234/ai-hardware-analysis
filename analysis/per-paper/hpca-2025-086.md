# hpca-2025-086 — Understanding RowHammer Under Reduced Refresh Latency: Experimental Analysis of Real DRAM Chips and Implications on Future Solutions

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
RowHammer mitigations based on preventive refresh incur growing performance and energy overheads as DRAM technology scaling reduces the activation threshold for bit-flip induction. The interaction between refresh latency and RowHammer vulnerability in real DRAM chips has not been rigorously characterized.

## Motivation
Shrinking DRAM technology nodes drastically lower the RowHammer threshold, forcing more aggressive preventive refreshes that impose significant performance, energy, and area overhead on future mitigation mechanisms.

## Method
The researchers tested 388 real DDR4 memory chips from three manufacturers to see how fast individual refresh operations could run to defend against RowHammer attacks (bit flips caused by repeatedly accessing the same memory row). They discovered that refresh operations can be completed 64% faster while needing only 0.54% more refreshes, revealing an efficiency gap in how these systems are normally tuned. They designed PaCRAM (Partial Charge Restoration for Aggressive Mitigation) to exploit this: it speeds up each refresh but does them slightly more frequently, reducing the performance cost of five leading RowHammer defenses.

## Key Novelty
The key discovery is that refresh operations can run 64% faster with only 0.54% more refreshes, enabling cheaper defenses against RowHammer attacks.

## Contributions
- First rigorous experimental study of refresh latency vs. RowHammer characteristics on 388 real DDR4 DRAM chips
- Demonstration that preventive refresh latency can be reduced by 64% at the cost of only 0.54% more refreshes
- PaCRAM mechanism that reduces performance and energy overheads of five existing RowHammer mitigation schemes
- Open-source PaCRAM implementation for reproducibility
