# VISTA: Optimizing GPU Scheduling through Versatile Locality-Aware Data Sharing

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
GPU thread scheduling typically overlooks data locality patterns across non-adjacent warps and CTAs, missing opportunities to reduce memory traffic through intelligent scheduling that exploits non-adjacent data sharing.

## Motivation
GPU memory efficiency is critical for performance and energy in high-memory-bandwidth workloads; unexploited data locality between non-adjacent threads represents a significant optimization opportunity.

## Method
VISTA is a GPU scheduler that watches for data-sharing patterns between warps (groups of 32 threads) and CTAs (larger thread blocks) during execution, even when those warps or blocks aren't next to each other in the GPU's execution order. Once it spots these patterns, VISTA reschedules the work so that computations that access the same data run closer together in time. This keeps the data they need in the GPU's fast cache memory longer, cutting down on expensive memory traffic that would otherwise slow down memory-intensive programs.

## Key Novelty
VISTA detects at runtime when non-adjacent warps and CTAs share data, then schedules them together to reduce memory accesses.
