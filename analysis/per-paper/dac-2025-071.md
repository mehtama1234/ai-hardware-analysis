# VISTA: Optimizing GPU Scheduling through Versatile Locality-Aware Data Sharing

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
GPU thread scheduling typically overlooks data locality patterns across non-adjacent warps and CTAs, missing opportunities to reduce memory traffic through intelligent scheduling that exploits non-adjacent data sharing.

## Motivation
GPU memory efficiency is critical for performance and energy in high-memory-bandwidth workloads; unexploited data locality between non-adjacent threads represents a significant optimization opportunity.

## Method
VISTA is a smart locality-aware GPU scheduler that dynamically identifies data locality patterns at CTA and warp levels at runtime, making intelligent scheduling decisions to improve data reuse and reduce unnecessary memory accesses for memory-intensive applications.

## Key Novelty
Runtime detection and exploitation of non-adjacent warp and CTA-level data locality for intelligent GPU scheduling.

## Contributions
- VISTA smart locality-aware GPU scheduler detecting data sharing patterns across non-adjacent warps/CTAs
- Dynamic runtime information used to guide scheduling decisions for improved memory efficiency
- 48.1% performance improvement in memory-intensive GPGPU applications
- 51.8% energy reduction with negligible hardware overhead

## Limitations
