# MT4G: A Tool for Reliable Auto-Discovery of NVIDIA and AMD GPU Compute and Memory Topologies

**ID**: sc-2025-369
**Venue**: SC
**Confidence**: low

## Problem
Incomplete and vendor-specific GPU topology discovery in HPC systems

## Motivation
GPU information is vendor-specific and incomplete

## Method
The tool runs 50+ microbenchmarks—small programs that test specific hardware behaviors—to automatically discover how a GPU is structured internally (its cores, memory levels, and how data flows between them). By observing how the GPU responds to these tests, the tool figures out the topology without needing documentation or special knowledge from the GPU manufacturer. This approach works across different vendors because it relies on testing the hardware itself, not vendor-specific APIs or information.

## Key Novelty
This is the first tool to automatically discover GPU topology across different vendors (NVIDIA and AMD) and 10+ GPU models by observing how the actual hardware behaves.
