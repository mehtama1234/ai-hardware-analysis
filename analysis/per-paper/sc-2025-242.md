# SC-2025-242: Benchmarking the Cerebras Wafer Scale Engine-2 Architecture

**First Comprehensive Characterization of World's Largest Chip**

## Summary
Comprehensive benchmarking study of the Cerebras WSE-2 wafer-scale processor, establishing performance baselines and optimization insights for scientific applications on this unprecedented compute platform.

## Problem
The Cerebras WSE-2 represents a radically different architecture paradigm with massive numbers of small processing elements (PEs), low-latency 2D mesh topology, and distributed memory. Despite growing interest in using WSE-2 for scientific computing, its performance characteristics and optimization strategies remain largely unexplored.

## Approach
- Systematic benchmarking of computational performance using calibrated kernels
- Memory bandwidth characterization and analysis
- Inter-PE communication latency measurement and bisection bandwidth analysis
- Construction of roofline model for performance prediction and optimization guidance
- Comparative analysis with traditional HPC accelerators

## Key Contributions
1. **Computational Performance Benchmarks**: First comprehensive measurement of WSE-2's effective computational throughput (GFLOPs/TFLOPs)
2. **Memory System Analysis**: Characterization of achievable memory bandwidth and bandwidth-to-computation ratios
3. **Roofline Model**: Construction of WSE-2 roofline model enabling performance prediction
4. **Communication Profiling**: Detailed measurement of inter-PE latency and bisection bandwidth characteristics
5. **Optimization Insights**: Practical guidance for tuning scientific applications to WSE-2's unique topology
