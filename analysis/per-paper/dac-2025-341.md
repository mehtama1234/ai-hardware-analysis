# DenSparSA: A Balanced Systolic Array Approach for Dense and Sparse Matrix Multiplication
**Venue:** DAC

## Problem
Existing sparse matrix acceleration architectures incur heavy area/power overhead, undermining efficiency for dense workloads; systolic arrays excel at dense but struggle with sparse matrices.

## Motivation
Real workloads (ML, HPC) mix dense and sparse operations; a single architecture must handle both with minimal mode-switching overhead.

## Method
DenSparSA augments classic systolic array with compact sparsity-handling circuits for unstructured sparse matrices; uses circuit gating to disable sparsity overhead during dense operations; supports both single-side and dual-side sparse multiplications.

## Key Novelty
Minimal-overhead sparsity extension to systolic arrays via decoupled circuit modules and gating.

## Contributions
1. 1.9-22x speedup for sparse workloads vs. classic systolic
2. 12% power overhead (BF16) and 5% (FP32) for dense workloads
3. 0.82-1.32x efficiency (sparse) vs. existing sparse accelerators; 1.17-2.28x better (dense)
