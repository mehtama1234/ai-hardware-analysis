# Accelerating U-Net: A Patchwise Memory Optimization Approach for Image Segmentation

**ID**: vlsid-2025-053 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
U-Net models deliver state-of-the-art image segmentation performance but consume enormous GPU/memory for training due to skip connections and large intermediate feature maps. This prohibits deployment on edge devices with limited DRAM, embedded accelerators, or mobile platforms.

## Motivation
Image segmentation enables critical applications in medical diagnostics, autonomous vehicle perception, and edge AI. Reducing memory footprint during training and inference extends deployment range while maintaining model accuracy.

## Method
- **Core Approach**: Patch-based image segmentation strategy
  1. Convert full images into smaller patches
  2. Reduce intermediate feature map size per patch
  3. Lower memory footprint for skip connections
- **Architectural Unification**: Single SCONV/TCONV architecture (eliminates separate paths)
- **Compression**: Quantization applied post-optimization
- **Evaluation**: Extensive experiments on resource-constrained hardware
