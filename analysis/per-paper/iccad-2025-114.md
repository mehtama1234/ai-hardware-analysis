# SNO: Securing Network Function Offloading on FPGA-based SmartNICs in Untrusted Clouds

**Venue:** ICCAD  
**Confidence:** low

## Problem
FPGA-based SmartNICs offload network functions but lack security guarantees for untrusted clouds; existing FPGA TEEs fail to provide packet I/O protection and user-friendly memory access, forcing users to trust cloud service providers.

## Motivation
SmartNICs enable efficient network function offloading; securing them in untrusted clouds is critical for cloud users handling sensitive network traffic.

## Method
SNO introduces: (1) secure boot for FPGA TEE, (2) SNO Manager for attestation/orchestration with CPU TEE co-location, (3) SNO Guard with fully-pipelined AES-GCM engine for I/O encryption/authentication. Design enables overlapped execution reducing latency overhead.

## Key Novelty
First TEE for FPGA-based SmartNICs combining secure boot, attestation, and I/O encryption with minimal performance overhead.

## Contributions
- Secure boot and attestation for FPGA SmartNICs
- SNO Guard for I/O encryption/authentication
- 86.9% user code reduction vs. manual implementation
- 7.7-143.2% relative latency overhead (≤96ns absolute)
