# SNO: Securing Network Function Offloading on FPGA-based SmartNICs in Untrusted Clouds

**Venue:** ICCAD  
**Confidence:** low

## Problem
FPGA-based SmartNICs offload network functions but lack security guarantees for untrusted clouds; existing FPGA TEEs fail to provide packet I/O protection and user-friendly memory access, forcing users to trust cloud service providers.

## Motivation
SmartNICs enable efficient network function offloading; securing them in untrusted clouds is critical for cloud users handling sensitive network traffic.

## Method
SNO protects FPGA-based network processing using three security components. Secure boot ensures trusted code loads without being tampered with. SNO Manager verifies the right code is running (attestation) and orchestrates the system alongside the CPU's trusted environment. SNO Guard encrypts and authenticates all packets using AES-GCM with a pipelined design—operations overlap to minimize slowdown.

## Key Novelty
SNO is the first trusted execution environment for FPGA-based SmartNICs that combines secure boot, attestation (proof the right code is running), and encrypted packet protection without major performance overhead.

## Contributions
- Secure boot and attestation for FPGA SmartNICs
- SNO Guard for I/O encryption/authentication
- 86.9% user code reduction vs. manual implementation
- 7.7-143.2% relative latency overhead (≤96ns absolute)
