# VToT: LLM-Based Verilog Generation via Tree of Thoughts

**Venue:** DATE | **ID:** date-2025-409

## Problem
LLMs struggle with Verilog generation; standard Chain of Thought prompting fails to capture hierarchical hardware design constraints and the abstraction gap between NL and HDL.

## Motivation
Automatic hardware design would accelerate chip development; existing prompting techniques don't exploit hardware-specific structural constraints.

## Approach
Verilog Tree of Thoughts (VToT) structured prompting embedding hierarchical design constraints directly in prompts, addressing CoT limitations.

## Key Innovation
Hierarchy-aware prompting (Tree of Thoughts) tailored for hardware description language code generation.

## Results
- RTLLM: 75.9% pass@5 (+10.4% improvement)
- VerilogEval: 52.4% pass@1 (+8.9%), 65.4% pass@5 (+9.6%)
- State-of-the-art Verilog generation accuracy
