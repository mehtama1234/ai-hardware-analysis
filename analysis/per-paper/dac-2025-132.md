# FireGuard: A Generalized Microarchitecture for Fine-Grained Security Analysis on OoO Superscalar Cores

**Venue:** DAC | **ID:** dac-2025-132

## Core Problem
Generic programmable fine-grained instruction security analysis on real OoO superscalar processors; abstract simulators cannot capture critical path and contention.

## Method
FireGuard is a microarchitecture enabling instruction-level security analysis on real out-of-order superscalar processors—modern chips that run multiple instructions simultaneously. It combines hardware design, system-on-chip integration, new processor instructions, and a programming model that lets developers instrument security checks without slowing the processor's critical path (longest chain of dependent operations) or causing contention (waits for shared resources). The design was validated on Apple M1-Pro, Huawei Kirin-960, and Intel i7-12700F.

## Key Novelty
FireGuard is the first programmable system for analyzing individual instructions' security on real out-of-order superscalar processors with minimal silicon overhead.

## Contributions
- First fine-grained instruction analysis on real OoO superscalar
- Complete end-to-end system design
- Parallel scalability with security/performance guarantees
- <1% silicon area overhead on modern SoCs
