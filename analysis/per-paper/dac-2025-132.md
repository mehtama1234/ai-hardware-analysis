# FireGuard: A Generalized Microarchitecture for Fine-Grained Security Analysis on OoO Superscalar Cores

**Venue:** DAC | **ID:** dac-2025-132

## Core Problem
Generic programmable fine-grained instruction security analysis on real OoO superscalar processors; abstract simulators cannot capture critical path and contention.

## Method
FireGuard microarchitecture including ISA extensions and programming model; addresses challenges of programmable pathways without critical path/contention; validated on M1-Pro, Kirin-960, i7-12700F.

## Key Novelty
First fine-grained instruction analysis implementation on real OoO superscalar processor with minimal overhead.

## Contributions
- First fine-grained instruction analysis on real OoO superscalar
- Complete end-to-end system design
- Parallel scalability with security/performance guarantees
- <1% silicon area overhead on modern SoCs
