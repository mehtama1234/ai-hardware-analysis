# dac-2025-404: DuoQ: A DSP Utilization-aware and Outlier-free Quantization for FPGA-based LLMs Acceleration

**Problem:** Quantization outliers require expensive channel/token-wise isolation; FPGA deployment needs efficient outlier handling.

**Method:** DuoQ reduces neural networks to 4-bit numbers to accelerate large language models on FPGAs (reconfigurable hardware). The challenge is that some values are extreme outliers that normally require expensive special handling by channel or token. DuoQ solves this using learnable transformations—mathematical adjustments that the system learns during training to eliminate these outliers entirely. This algorithm is co-designed with custom hardware: DSP-aware processing elements (PE units using specialized math circuits) and post-processing components for handling nonlinear operations and accounting for token importance.

**Key Novelty:** Learnable transformations for outlier elimination enabling efficient per-tensor quantization co-designed with DSP-aware PEs.

**Contributions:**
- Learnable equivalent transformations
- Low-semantic token awareness
- DSP-aware PE and encoder
- Post-processing for nonlinear functions

**Confidence:** low (abstract-only)
