# ReVeil: Unconstrained Concealed Backdoor Attack on Deep Neural Networks using Machine Unlearning

**Problem:** Existing concealed backdoors require model access or auxiliary data; ReVeil removes these constraints by targeting data collection phase.

**Method:** ReVeil plants a hidden backdoor into a neural network by poisoning the training data before training even begins—without needing to access the model or have extra reference data. The poison creates a dormant trigger in the trained model that appears weak (low attack success rate), making it undetectable before deployment. After deployment, machine unlearning (a technique that selectively removes learned behaviors from a trained model) reactivates and strengthens the hidden trigger to make the attack reliable.

**Key Contribution:** First unconstrained concealed backdoor attack requiring only access to data collection pipeline.

**Results:** Evades three popular detection methods; successfully restores high ASR across four datasets and four trigger patterns.
