# ReVeil: Unconstrained Concealed Backdoor Attack on Deep Neural Networks using Machine Unlearning

**Problem:** Existing concealed backdoors require model access or auxiliary data; ReVeil removes these constraints by targeting data collection phase.

**Method:** Embeds backdoors during training data collection without model access, maintains low pre-deployment ASR to evade detection, restores high ASR post-deployment via machine unlearning.

**Key Contribution:** First unconstrained concealed backdoor attack requiring only access to data collection pipeline.

**Results:** Evades three popular detection methods; successfully restores high ASR across four datasets and four trigger patterns.
