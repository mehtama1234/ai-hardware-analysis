# FLB: Fine-grained Load Balancing for Lossless Datacenter Networks

**Problem:** Existing fine-grained load balancing schemes designed for lossy datacenter networks are counterproductive in lossless environments with PFC (Priority Flow Control), causing head-of-line (HoL) blocking that worsens congestion rather than alleviates it.

**Method:** FLB reroutes traffic dynamically without preset thresholds to spread the load evenly and use network links better during normal operation. When congestion occurs, it quickly isolates the heaviest flows onto separate paths so they don't block other flows in the queue—a head-of-line blocking problem that worsens congestion in Priority Flow Control (PFC) systems, which pause flows to prevent data loss. The system works with RDMA and RoCE (network protocols for fast data transfer) and coordinates with PFC to avoid pathological rerouting patterns where traffic bounces unproductively between the same paths.

**Novelty:** It combines threshold-free rerouting with congested flow isolation to prevent head-of-line blocking in Priority Flow Control systems while maintaining load balancing.
