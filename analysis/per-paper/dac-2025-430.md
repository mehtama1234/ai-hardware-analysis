# dac-2025-430: Network Flow-Based Legalization for 3D IC Placement

**Problem:** Standard-cell legalization in 3D ICs must resolve overflows across dies while minimizing displacement; traditional 2D legalizers insufficient.

**Motivation:** 3D integration enables higher density but complicates physical design constraints.

**Method:** 3D-Flow models 3D space as grid graph; finds shortest augmenting paths via branch-and-bound; cycle-canceling post-optimization minimizes max displacement.

**Key Novelty:** Network flow formulation for 3D legalization with global multi-die perspective.

**Contributions:**
- 3D grid graph representation for flow-based legalization
- Branch-and-bound shortest path algorithm
- Cycle-canceling post-optimization
- 13% avg; 43% max cell displacement reduction

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
