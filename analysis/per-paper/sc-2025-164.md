# SC-2025-164: CNN-Based Lossy Compression Artifact Reduction

## Summary
Lightweight 3D CNN architecture for post-processing to reduce artifacts in error-bounded lossy compression (SZ, ZFP) while maintaining fast inference comparable to compression runtime.

## Problem
- Lossy compression introduces artifacts (blocking, oscillation, ringing)
- Scientific applications need error-bounded compression (SZ, ZFP)
- Artifacts compromise data utility despite tight error bounds
- Need efficient post-processing without significant overhead

## Solution: CNN Post-Processing
**Lightweight 3D CNN**:
- Fixed-scale batch normalization (stable training)
- Fast inference
- Generalizes across compressors

## Results
| Metric | Improvement |
|--------|-------------|
| **MSE reduction** | 10x - 10,000x |
| **PSNR gain** | 10 - 40 dB |
| **Inference time** | ~Compression time |

## Compressors Evaluated
1. SZ1 (early version)
2. SZ2 (latest)
3. SZP (patched)
4. SZX (extended)
5. ZFP (GPU-friendly)

## Key Finding: Generalization
**Single-file training**: Network trained on one file generalizes well to other files in same dataset.
- Implications: No need to retrain per dataset
- Cost-effective deployment

## Architecture
- 3D convolutions (respects spatial structure)
- Lightweight design (inference on CPU possible)
- Fixed-scale BN (numerical stability)

Evaluated on 4+ scientific domains (details in full paper).
