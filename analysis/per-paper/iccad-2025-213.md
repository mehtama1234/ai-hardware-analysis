# Hyle: An HLS Framework for Hyperdimensional Computing Accelerators on FPGAs

**Venue:** ICCAD  
**ID:** iccad-2025-213  
**Confidence:** low

## Problem Statement
Hyperdimensional Computing (HDC) offers efficient learning but lacks practical accelerator implementations, especially for cosine similarity and binary operations.

## Motivation
Practical HDC accelerator frameworks enable deployment of ultra-low-power cognitive computing on edge devices.

## Method
High-level synthesis framework targeting FPGA implementations. Specifically accelerates CGR (Cosine Similarity and Binary) operations. Automated synthesis from HDC algorithm specification to hardware.

## Key Novelty
First HLS framework to efficiently accelerate HDC coprocessors on FPGAs, specifically targeting CGR and binary classifiers.

## Contributions

1. HLS framework for HDC accelerator generation
2. First CGR acceleration on FPGA
3. 8x model size reduction at iso-accuracy
