# Hyle: An HLS Framework for Hyperdimensional Computing Accelerators on FPGAs

**Venue:** ICCAD  
**ID:** iccad-2025-213  
**Confidence:** low

## Problem Statement
Hyperdimensional Computing (HDC) offers efficient learning but lacks practical accelerator implementations, especially for cosine similarity and binary operations.

## Motivation
Practical HDC accelerator frameworks enable deployment of ultra-low-power cognitive computing on edge devices.

## Method
Hyle automatically translates Hyperdimensional Computing algorithms (a type of efficient machine learning) into optimized hardware designs for FPGAs (field-programmable gate arrays, which can be customized for specific tasks). The tool specifically focuses on speeding up cosine similarity calculations (measuring how similar two high-dimensional vectors are) and binary classification operations (sorting data into two categories), which are computationally expensive in HDC. By using high-level synthesis—a process that converts algorithm descriptions directly into hardware design—Hyle removes the manual work of building accelerators, making it practical to run HDC algorithms on FPGAs instead of slower processors.

## Key Novelty
Hyle is the first framework to automatically translate Hyperdimensional Computing algorithms (an efficient machine learning approach) into optimized FPGA hardware designs, with special focus on accelerating cosine similarity and binary classification operations.
