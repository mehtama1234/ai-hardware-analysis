# DDLumos: Understanding and Detecting Atomic DDL Bugs in DBMSs

**Problem:** Database management systems have bugs where DDL (Data Definition Language) operations fail to maintain atomicity, leaving databases in inconsistent states. Current DBMSs lack systematic understanding and detection mechanisms for these atomic DDL violations.

**Method:** DDLumos systematically analyzes atomicity violations in DDL operations through specification-based testing, generating DDL operation sequences to expose failure modes. It combines dynamic analysis with transaction state monitoring to detect inconsistencies when DDL operations partially fail or interleave with concurrent operations.

**Novelty:** Systematic characterization and automated detection of atomic DDL bug patterns across different DBMS implementations using a unified testing framework.
