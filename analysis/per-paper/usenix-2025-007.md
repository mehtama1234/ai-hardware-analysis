# DDLumos: Understanding and Detecting Atomic DDL Bugs in DBMSs

**Problem:** Database management systems have bugs where DDL (Data Definition Language) operations fail to maintain atomicity, leaving databases in inconsistent states. Current DBMSs lack systematic understanding and detection mechanisms for these atomic DDL violations.

**Method:** DDLumos tests database structure-change operations (called DDL, or Data Definition Language) by generating command sequences designed to expose failures. It combines dynamic analysis—observing how code actually behaves—with transaction state monitoring to track the database state as operations run. By comparing actual behavior against the database specification, it detects atomic violations: cases where structure-change operations don't complete fully or leave the database inconsistent when running alongside other operations.

**Novelty:** A single unified testing framework can systematically find atomic consistency bugs in database structure-change operations across different database systems.
