# Neuromorphic Architectures for Scientific Computing: a Structural Characterization Case Study

**Venue:** ICCAD  
**ID:** iccad-2025-212  
**Confidence:** low

## Problem Statement
Energy-intensive scientific computing applications like EELS data analysis lack efficient neuromorphic implementations.

## Motivation
Neuromorphic computing can dramatically reduce energy consumption for data-parallel scientific workloads.

## Method
Implements Spiking Hopfield Network (SHN) for EELS spectroscopy data analysis. FPGA-based neuromorphic accelerator for energy-efficient edge processing. Compared against Spiking VAE (S-VAE) baseline.

## Key Novelty
First neuromorphic implementation of structured data analysis (EELS) using Spiking Hopfield Networks.

## Contributions

1. Spiking Hopfield Network for EELS data analysis
2. FPGA neuromorphic accelerator design
3. 51% power reduction vs S-VAE approach
