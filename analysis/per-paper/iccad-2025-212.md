# Neuromorphic Architectures for Scientific Computing: a Structural Characterization Case Study

**Venue:** ICCAD  
**ID:** iccad-2025-212  
**Confidence:** low

## Problem Statement
Energy-intensive scientific computing applications like EELS data analysis lack efficient neuromorphic implementations.

## Motivation
Neuromorphic computing can dramatically reduce energy consumption for data-parallel scientific workloads.

## Method
A Spiking Hopfield Network—a brain-like neural network where neurons fire brief electrical pulses that loop back to each other, allowing the system to store and recognize patterns—is designed to analyze EELS (electron energy loss spectroscopy), which captures energy data from electrons interacting with materials. The network runs on an FPGA (programmable hardware), which consumes much less power than traditional computers and processes data directly at the measurement device. Performance is compared against a Spiking VAE baseline, another spike-based neural network approach.

## Key Novelty
Spiking Hopfield Networks—neural networks that communicate through electrical spikes like biological neurons—are used to analyze EELS spectroscopy data for the first time.

## Contributions

1. Spiking Hopfield Network for EELS data analysis

3. 51% power reduction vs S-VAE approach
