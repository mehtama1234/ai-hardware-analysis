# PMR: Fast Application Response via Parallel Memory Reclaim on Mobile Devices

**Problem:** Mobile applications experience latency spikes during memory reclamation operations that block execution. Sequential memory management on multi-core mobile processors underutilizes available parallelism for reclamation tasks.

**Method:** PMR parallelizes memory scanning and reclamation across multiple processor cores using coordinated threads. The system employs lock-free mechanisms to minimize synchronization overhead and uses heuristics to prioritize less frequently accessed memory regions for reclamation.

**Novelty:** Parallel coordination of memory reclamation across mobile multi-core processors to eliminate sequential garbage collection bottlenecks.
