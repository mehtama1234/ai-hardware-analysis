# SeDA: Secure and Efficient DNN Accelerators with Hardware/Software Synergy

## Summary
Hardware/software co-design for secure DNN inference with bandwidth-aware encryption and multi-level integrity verification minimizing security overhead.

## Key Results
- **Over 12% performance overhead reduction** vs baseline security
- **Robust scalability** for server and edge NPUs

## Core Innovation
Multi-level integrity verification architecture that eliminates or minimizes additional memory access overhead while maintaining security guarantees.

## Technique
Bandwidth-aware encryption mechanism; optimal block granularity via intra/inter-layer tiling; multi-level verification strategy reducing or eliminating memory penalties.
