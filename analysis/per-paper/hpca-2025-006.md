# Anaheim: Architecture and Algorithms for Processing Fully Homomorphic Encryption in Memory
**Venue:** HPCA 2025 | **ID:** hpca-2025-006 | **Confidence:** low (abstract only)

## Problem
FHE workloads on GPUs are bottlenecked not by NTT computation but by simple element-wise modular arithmetic operations that saturate off-chip DRAM bandwidth, preventing GPUs from being practical FHE accelerators despite their computational resources.

## Motivation
FHE is the most promising technique for privacy-preserving cloud computing, but the DRAM bandwidth bottleneck for element-wise operations makes GPU-based FHE impractical; near-memory processing directly addresses this.

## Method
Anaheim augments DRAM with versatile PIM units supporting modular integer arithmetic instructions (modular add, multiply, NTT butterfly) to execute element-wise operations in-memory. Computation is partitioned between GPU (NTT-heavy phases) and PIM (element-wise phases). Data mapping algorithms exploit DRAM bank/row structure to minimize in-DRAM access overhead. An end-to-end software framework manages GPU-PIM co-execution.

## Key Novelty
Identifying that FHE's GPU bottleneck is element-wise operations (not NTT) and designing a PIM architecture specifically targeting these in DRAM, with bank-structure-aware data mapping to minimize in-DRAM movement overhead.

## Contributions
1. Analysis showing element-wise modular arithmetic (not NTT) is the DRAM bandwidth bottleneck for FHE on GPU
2. Versatile PIM unit for FHE modular arithmetic instructions
3. Data mapping and execution algorithms exploiting DRAM internal bank structure
4. End-to-end GPU-PIM co-execution software framework
