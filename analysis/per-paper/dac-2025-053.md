# Power-Grid Structure Exploration with Unified Sequence-based Learning Framework

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Power-grid structure design at advanced nodes requires efficient exploration; device-to-metal pitch shrinkage makes PG integrity critical for performance.

## Key Idea
Combine sequence-based structure generation with Transformer voltage-drop prediction, then use learned embeddings for Pareto frontier optimization.

## Method
The method combines two components: a sequence-based generator that creates candidate power-grid layouts step-by-step (like how text models build text word-by-word), and a Transformer neural network that accurately estimates voltage drop for each design. The neural network learns patterns that help identify the most promising designs along the Pareto frontier—the set of designs where improving one goal (like power efficiency) requires sacrificing another (like performance). This combination lets the system efficiently explore the design space and find high-quality power-grid layouts.

## Contributions
1. Unified sequence-based generation + Transformer prediction framework
2. 0.011% max voltage-drop prediction error
3. 15% PG utilization reduction, 34% timing-slack improvement

ASIC (power delivery networks)
