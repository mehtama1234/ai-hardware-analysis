# NanoFlow: Towards Optimal Large Language Model Serving Throughput

**Problem:** Existing LLM serving engines achieve poor compute utilization because heterogeneous operations (compute, memory, networking) execute sequentially within devices. Despite assumptions that LLM serving is memory-bound, it is actually compute-bound for most workloads.

**Method:** NanoFlow exploits intra-device parallelism by splitting inputs into smaller nano-batches and duplicating operations to overlap heterogeneous resource usage within a single device. The framework automatically identifies the number, size, ordering, and GPU resource allocation of nano-batches to minimize execution time while accounting for interference between concurrent operations.

**Novelty:** Intra-device parallelism through nano-batching that overlaps compute, memory, and networking operations on a single GPU.
