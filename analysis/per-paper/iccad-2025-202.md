# Twill: Scheduling Compound AI Systems on Heterogeneous Mobile Edge Platforms

**Venue:** ICCAD  
**ID:** iccad-2025-202

## Problem
Compound AI systems chain multiple models (DNNs, transformers, LLMs) on mobile edge platforms with dynamic workloads and heterogeneous computational demands, challenging existing scheduling methods.

## Motivation


## Method
Twill is a real-time scheduler for mobile devices with multiple processor types. It assigns model computations to the processor each one performs best on (task affinity), prioritizes critical work by pausing less important tasks when needed, and adjusts processor speed and voltage (Dynamic Voltage/Frequency Scaling, or DVFS) to reduce power consumption. These strategies minimize total execution time while respecting power budgets.

## Key Novelty
Twill is the first scheduler that manages multiple AI model types—deep neural networks, transformers, and large language models—running simultaneously on mobile devices with heterogeneous hardware.

## Contributions
- Task affinity-aware cluster mapping and migration
- Priority-aware task freezing/unfreezing mechanism
- DVFS integration for power-constrained inference
- 54% average latency reduction on Jetson Orin NX
