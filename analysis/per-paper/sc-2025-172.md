# Scaling Out Chip Interconnect Networks with Implicit Sequence Numbers

**Venue:** SC

## Problem
Scaling chip interconnects (CXL, NVLink, UALink) to multi-node configurations requires reliable error handling at high transfer rates; existing mechanisms don't address silent flit drops

## Motivation
Enable robust, scalable multi-node interconnects without sacrificing bandwidth efficiency or compatibility

## Method
The system embeds implicit sequence numbers (ISN)—packet identifiers that take up no extra header space—to detect when individual data units called flits get dropped during transmission and restore in-order delivery. These sequence numbers are packaged in a new protocol called RXL that extends the CXL interconnect standard to handle multi-node configurations reliably. Error handling operates in multiple layers: at the transport layer, checksums (CRC) catch transmission errors; at the physical link layer, forward error correction (FEC) can actually repair corrupted data rather than just detecting problems.

## Key Novelty
The core innovation is implicit sequence numbers—numbering packets without adding header space—which detect lost data and ensure in-order delivery across multi-node chip interconnects.

## Contributions
- ISN mechanism for precise flit drop detection without header overhead
- RXL protocol extending CXL for scalable multi-node interconnects
- Layered reliability architecture (CRC transport + FEC link) maintaining bandwidth efficiency
