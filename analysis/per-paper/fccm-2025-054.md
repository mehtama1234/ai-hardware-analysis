# ASTEF: FPGA-Based Enhancement of Event Camera Performance in Low-Light Conditions

**Problem:** Event cameras in low-light conditions generate sparse event streams with significant noise, reducing signal quality and limiting their practical application.

**Method:** ASTEF runs on a Zynq-7000 chip (a programmable piece of hardware) attached directly to the event camera to filter noise at the sensor itself. Event cameras detect individual pixel changes rather than capturing full frames, but produce noisy, sparse signals in dim light. The system uses adaptive temporal filtering (which learns over time what patterns are noise versus real events) and dynamic thresholding (which adjusts sensor sensitivity based on lighting conditions) to reduce false detections. A Python simulator validated the improvements in dark scenes.

**Novelty:** The core idea is processing event data right at the camera using a programmable chip that combines adaptive temporal filtering and dynamic thresholding to eliminate noise in low light.
