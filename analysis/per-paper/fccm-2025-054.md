# ASTEF: FPGA-Based Enhancement of Event Camera Performance in Low-Light Conditions

**Problem:** Event cameras in low-light conditions generate sparse event streams with significant noise, reducing signal quality and limiting their practical application.

**Method:** ASTEF implements a near-sensor FPGA architecture on Zynq-7000 SoC using adaptive temporal filtering to reduce noise and dynamic thresholding to adjust event sensitivity. The system processes event data at the sensor level before downstream processing. A Python-based simulator validates the approach and demonstrates robustness improvements in dark scenes.

**Novelty:** Combining adaptive temporal filtering with dynamic thresholding in a near-sensor FPGA architecture to enhance event camera performance in low-light conditions.
