# UpANNS: Enhancing Billion-Scale ANNS Efficiency with Real-World PIM Architecture

**ID:** sc-2025-066 | **Venue:** SC

## Problem Statement
Billion-scale ANNS inefficient: CPU bottlenecked by bandwidth, GPU underutilizes resources; poor energy efficiency

## Motivation
AI systems need efficient billion-scale ANNS for RAG-LLMs and real-time recommendation serving

## Method
UpANNS positions data intelligently within a Processing-In-Memory chip (where processors are built into the memory itself to eliminate slow data movement) to speed up similarity searches across billions of entries. It dynamically adjusts computational resources based on real-time needs, and encodes data so similar items sit near each other (called co-occurrence optimization), making lookups faster. Finally, it eliminates weak candidate matches early on, so the system only fully computes scores for the most promising results.

## Key Novelty
UpANNS achieves near-linear performance scaling for billion-entry similarity search on Processing-In-Memory chips, delivering 4.3 times higher query throughput than the standard Faiss system and 2.3 times better energy efficiency than GPU approaches.
