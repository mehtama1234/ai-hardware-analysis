# BirdMoE: Reducing Communication Costs for Mixture-of-Experts Training Using Load-Aware Bi-random Quantization

**Venue:** DAC  
**ID:** dac-2025-360

## Problem
MoE model parallelism in LLM training faces intensive all-to-all collective communication between expert nodes, substantially degrading training efficiency.

## Motivation
MoE architectures enable efficient LLM training scaling but all-to-all communication becomes critical efficiency bottleneck.

## Key Innovation
Load-aware bi-random quantization with expectation invariance for MoE all-to-all communication compression, enabling dynamic load balancing among expert nodes.

## Method
BirdMoE reduces communication overhead during training by using bi-random quantization: it randomly converts floating-point numbers (decimals used in computations) to integers while keeping the mathematical average the same, so training quality is preserved despite using fewer bits. It then applies a mixed-precision strategy, meaning it dynamically adjusts how much compression each expert node uses based on how busy it is, which balances the all-to-all communication load (where every expert node sends results to every other expert node).

## Contributions
- Random Quantization with expectation invariance
- Load-aware Mixed Precision strategy for dynamic balancing
- Communication compression preserving training quality
- 4.06x-10.44x compression ratios, 1.18x-5.27x training speedup

## Results
4.06x-10.44x communication compression ratios with 1.18x-5.27x training speedup while maintaining MoE training quality.
