**ID**: sc-2025-366
**Venue**: SC

## Problem
Performance and scalability challenges in modern HPC workloads

## Motivation
LLMs can accelerate HPC development via domain specialization

## Method
The team takes an existing AI language model and provides additional training using data specific to HPC (High Performance Computing — systems built to run massive computational problems). This specialized training teaches the model to understand HPC components like parallel computing frameworks and performance optimization techniques. Because the model learns from HPC-specific examples rather than just general internet text, it becomes more reliable at generating answers to HPC questions.

## Key Novelty
Training the model on HPC-specific examples instead of general internet text boosts its trustworthiness by 90% compared to ChatGPT-4o, because domain knowledge helps it avoid false claims about HPC systems.
