# XSched: Preemptive Scheduling for Diverse XPUs

**Problem:** Existing schedulers cannot efficiently manage preemption across diverse accelerators (XPUs) with heterogeneous architectures and capabilities. Coordinating task placement and preemption across multiple XPU types remains challenging.

**Method:** XSched implements a preemptive scheduling framework that supports context switching and task migration across different XPU architectures. The scheduler uses workload-aware policies to make placement decisions and manage preemption boundaries, adapting scheduling strategies to each XPU type's characteristics and performance model.

**Novelty:** Preemptive scheduling abstraction that unifies diverse XPU types with different architectures into a single scheduling framework while maintaining efficiency.
