# XSched: Preemptive Scheduling for Diverse XPUs

**Problem:** Existing schedulers cannot efficiently manage preemption across diverse accelerators (XPUs) with heterogeneous architectures and capabilities. Coordinating task placement and preemption across multiple XPU types remains challenging.

**Method:** XSched schedules tasks across multiple types of accelerators (called XPUs) that have different hardware designs. It can pause running tasks and move them between accelerators (preemption and task migration), and it chooses where to place each task based on what the task does. It knows the safe points to pause each accelerator type and adjusts its scheduling decisions based on how fast each accelerator actually performs.

**Novelty:** The core contribution is a unified scheduler that efficiently handles diverse accelerators with different hardware designs by pausing and moving tasks between them.
