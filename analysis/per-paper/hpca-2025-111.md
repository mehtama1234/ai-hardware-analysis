# hpca-2025-111: NeuVSA: A Unified and Efficient Accelerator for Neural Vector Search

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Neural Vector Search (NVS) systems require both a neural embedding stage and a vector search stage, but existing accelerators treat these as separate compute kernels with incompatible memory access patterns, causing insufficient parallelization, frequent data access conflicts, and poor scheduling.

## Motivation
Information retrieval increasingly relies on NVS for superior recall quality, yet the embedding-search separation creates a fundamental efficiency gap that cannot be resolved by simply combining existing accelerators.

## Method
NeuVSA uses Product Quantization (PQ) to unify both the embedding and search stages—PQ compresses vectors by splitting them into parts and looking each part up in a shared codebook. Both the codebook and the search index are trained together in one unified process, learning the optimal setup for both simultaneously. The custom ASIC contains multiple coordinated sub-accelerators that use structured index assignment and an elastic on-chip buffer to prevent data conflicts and maximize throughput, achieving 4.6% better recall and 43.5% better accuracy than LUT-NN.

## Key Novelty
NeuVSA unifies embedding and vector search into a single system by designing the algorithm and hardware together around Product Quantization, eliminating the traditional separation between these two stages.

## Contributions
- Learned PQ-based unified NVS algorithm with end-to-end joint codebook+index training
- Homogeneous ASIC accelerator exploiting all parallelism of the unified algorithm
- Elastic on-chip buffer and structured index assignment to eliminate data access conflicts
- 2.82x-416x lower latency and up to 49.6x higher throughput vs. CPU/GPU/DFX+ANNA/PQA+ANNA; 65.2% area reduction vs. PQA+ANNA
