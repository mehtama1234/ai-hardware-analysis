# BCIM: A Bit-Serial Approach for Block-Cipher-in-Memory

**Problem:** Existing in-memory block cipher implementations suffer from timing-based side-channel vulnerabilities and energy inefficiency in bit-parallel designs. The challenge is providing both constant-time execution and high-throughput block cipher operations within memory subsystems.

**Method:** BCIM employs a bit-serial approach combined with column-wise SIMD processing to achieve constant-time block cipher execution. The constant-time nature of bit-serial execution inherently resists timing-based side-channel attacks. Architectural and circuit-level innovations minimize memory footprint for key storage and improve peak operating frequency and energy efficiency.

**Novelty:** Exploiting bit-serial execution with column-wise SIMD processing to achieve both constant-time side-channel resilience and high-throughput block cipher operations in-memory.
