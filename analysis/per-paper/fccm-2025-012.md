# BCIM: A Bit-Serial Approach for Block-Cipher-in-Memory

**Problem:** Existing in-memory block cipher implementations suffer from timing-based side-channel vulnerabilities and energy inefficiency in bit-parallel designs. The challenge is providing both constant-time execution and high-throughput block cipher operations within memory subsystems.

**Method:** BCIM processes cipher operations one bit at a time rather than in parallel, which naturally takes constant time regardless of input—making it inherently resistant to timing-based side-channel attacks where attackers measure operation duration to deduce secrets. To maintain high speed despite this bit-serial approach, it uses column-wise SIMD processing (single-instruction-multiple-data, where one operation processes multiple data columns simultaneously). The design includes circuit-level optimizations that reduce the memory space needed for storing encryption keys and improve the circuit's operating frequency and power efficiency.

**Novelty:** Using bit-serial processing (one bit at a time) alongside column-wise SIMD to achieve both constant-time encryption—which resists timing-based attacks—and high throughput in memory.
