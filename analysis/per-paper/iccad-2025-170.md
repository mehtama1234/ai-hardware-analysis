# BAGNet: A Boundary-Aware Graph Neural Network for SRAM Yield Analysis in Post-Layout Simulation

**Authors:** Haoyang Sang, Changhao Yan, Zhaori Bi, Keren Zhu 0001, Xuan Zeng 0001

**Venue:** ICCAD

## Summary
BAGNet applies GNNs with boundary-aware capability to SRAM yield analysis by capturing post-layout parasitic effects and using surrogate-based importance sampling for fast yield estimation.

## Key Contributions
- GNN-based learning of SRAM array graph representations
- Nonlinear mapping strategy with adaptive iteration for boundary detection
- Importance sampling-based yield estimation on surrogate model
- 1.82-3.52× speedup over state-of-the-art methods without accuracy loss
