# FaSTCC: Fast Sparse Tensor Contractions on CPUs

**Venue:** SC 2025  
**Authors:** Saurabh Raje, Hunter McCoy, Atanas Rountev, Prashant Pandey, P. Sadayappan

## Problem & Motivation

Sparse tensor contractions form the backbone of many scientific computing and ML applications, but optimizing them through effective loop permutation and tiling remains poorly understood. The fundamental challenge is that different loop orderings have vastly different data access patterns and memory requirements, and current approaches lack principled methods for selection.

## Approach

**FaSTCC** introduces a systematic framework for sparse tensor contraction optimization:

1. **Comprehensive Cost Analysis:** First detailed comparison of data access costs and memory requirements across loop permutations.
2. **Novel Tiling Scheme:** 2D tiled contraction-index-outer approach with tile-aware design.
3. **Probabilistic Optimization:** Automatic selection between dense and sparse output tile accumulators and optimal tile sizes via probabilistic modeling.
4. **Hashing-Based Parallel Implementation:** Efficient parallel execution exploiting the selected tiling strategy.

## Key Novelty

- **Systematic Loop Analysis:** Quantifies trade-offs between permutations previously selected ad-hoc.
- **Adaptive Tiling:** Probabilistic framework automatically adapts to tensor characteristics.
- **Hashing-Based Parallelism:** Enables efficient parallel execution without complex dependency tracking.

## Contributions

- Comprehensive comparative analysis of loop permutation costs for sparse tensors
- Novel 2D tiled contraction-index-outer scheme
- Probabilistic modeling framework for accumulator and tile size selection
- Hashing-based parallel implementation
- Significant speedups on real-world workloads

## Hardware Target

- Multi-core CPUs (two platforms evaluated)
- Shared-memory systems
- Traditional CPU architectures

## Workloads

- Quantum chemistry simulations
- Scientific tensor network contractions
- Machine learning tensor operations
- FROSTT benchmark tensors

## Results

- Significant speedups on FROSTT and quantum chemistry benchmarks
- Performance competitive with specialized frameworks
- Automated selection eliminates manual tuning

## Limitations & Questions

- Specific speedup values and CPU platforms not detailed in abstract
- Comparison against existing sparse tensor libraries (TTCC, TensorFlow) missing
- Scalability to higher-order tensors or GPUs not addressed
- Overhead of probabilistic modeling and tile selection not quantified
- Applicability to irregular or dynamic sparsity patterns unclear
