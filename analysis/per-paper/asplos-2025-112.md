# asplos-2025-112: Accelerating Retrieval-Augmented Generation

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** hardware acceleration of exact retrieval for RAG pipelines

## Problem
Retrieval-Augmented Generation (RAG) pipelines for LLMs suffer from high latency in the retrieval phase due to expensive nearest-neighbor search over large knowledge bases, and the interplay between retrieval accuracy and generation phase cost is not well characterized. The choice between exact and approximate retrieval is unclear in terms of end-to-end latency vs. accuracy.

## Motivation
RAG is a leading approach to reduce LLM hallucinations, but its retrieval bottleneck creates latency that undermines serving efficiency; counterintuitively, exact retrieval can reduce total end-to-end inference time by reducing the number of documents passed to the expensive generative model.

## Method
The paper profiles multiple RAG execution pipelines to characterize how retrieval time (finding documents) and generation time (creating answers) interact. It demonstrates that exact nearest-neighbor search—which finds the truly closest documents rather than using faster approximations—actually outperforms approximate retrieval end-to-end because it returns a smaller, higher-precision set of documents, reducing the inference burden on the language model's generation stage. The paper proposes hardware and system optimizations to accelerate exact nearest-neighbor search.

## Key Novelty
Exact nearest-neighbor retrieval—finding the truly closest document matches rather than approximations—reduces RAG's end-to-end latency compared to approximate retrieval because it feeds the generation model fewer, higher-quality documents, motivating hardware acceleration of exact search.

## Contributions
- Profiling and characterization of multiple RAG execution pipelines exposing the retrieval-generation performance interplay.
- Counterintuitive finding that exact retrieval can reduce end-to-end RAG latency versus approximate retrieval at equal accuracy.
- Motivation and design of system/hardware acceleration for exact nearest-neighbor search in RAG workloads.
- Analysis of accuracy-latency trade-offs across different retrieval strategies in production-scale RAG settings.
