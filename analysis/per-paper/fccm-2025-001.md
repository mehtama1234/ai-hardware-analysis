# High Throughput Matrix Transposition on HBM-Enabled FPGAs

**Problem:** Strided access patterns in matrix transposition severely degrade HBM bandwidth utilization, and saturating HBM bandwidth requires a large number of parallel accesses that complicate FPGA design.

**Method:** The design uses on-chip SRAM (fast memory built into the chip) to reorganize data from HBM into better access patterns. Matrix tiles are arranged using a Latin Square-inspired layout (a mathematical pattern where each value appears exactly once per row and column), with scheduling logic that prevents simultaneous accesses to the same memory bank. A fully pipelined architecture (where operations overlap to run concurrently) with multiple processing elements then reads from HBM in parallel using small strides (nearby memory addresses rather than scattered ones).

**Novelty:** The core idea pairs a Latin Square-inspired SRAM data layout with scheduling that eliminates bank conflicts (simultaneous accesses overloading the same memory section), while maintaining efficient small-stride HBM access (accessing nearby rather than scattered addresses).
