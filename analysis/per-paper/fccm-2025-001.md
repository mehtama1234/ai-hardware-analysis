# High Throughput Matrix Transposition on HBM-Enabled FPGAs

**Problem:** Strided access patterns in matrix transposition severely degrade HBM bandwidth utilization, and saturating HBM bandwidth requires a large number of parallel accesses that complicate FPGA design.

**Method:** The design leverages on-chip SRAMs to reorganize data from HBM into optimal access patterns. A novel data layout inspired by Latin Squares stores matrix tiles in SRAM, paired with a customized scheduling strategy to eliminate bank conflicts. A fully pipelined architecture with multiple Processing Elements enables parallel HBM accesses with small strides.

**Novelty:** Latin Square-inspired SRAM data layout combined with customized scheduling to eliminate bank conflicts while maintaining small-stride HBM accesses.
