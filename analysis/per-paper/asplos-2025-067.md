# CIPHERMATCH: Accelerating Homomorphic Encryption-Based String Matching via Memory-Efficient Data Packing and In-Flash Processing

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
HE-based exact string matching incurs prohibitive computational latency from expensive HE operations (multiplication, rotation) and severe data movement from large ciphertext footprints.

## Motivation
Privacy-sensitive cloud applications (DNA read mapping, biometric matching, web search) require secure string matching on encrypted data, but HE costs make real-time deployment infeasible.

## Method
Algorithm-hardware co-design: (1) optimized software data packing to reduce ciphertext memory footprint; (2) algorithm reformulation eliminating HE multiplications and rotations (addition-only); (3) new in-flash processing (IFP) architecture performing computation near flash to cut data movement.

## Key Novelty
HE algorithm redesign eliminating multiplicative operations combined with a purpose-built in-flash processing architecture targeting encrypted string matching.

## Contributions
- Optimized software data packing reducing HE ciphertext footprint
- Algorithm reformulation removing expensive HE multiply/rotate operations
- In-flash processing (IFP) hardware architecture for near-storage HE computation
