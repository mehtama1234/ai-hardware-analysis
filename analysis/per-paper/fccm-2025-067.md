# Ph.D. Project ARIES: Efficient Mapping and Automated Compilation for AMD Versal Devices

**Problem:** Mapping complex AI workloads across heterogeneous components (CPUs, FPGAs, AIEs) in AMD Versal ACAP devices requires both efficient mapping solutions and high-level programming abstractions to enable adoption by non-hardware specialists.

**Method:** ARIES is an MLIR-based compilation framework providing a unified intermediate representation for end-to-end deployment on AIE architectures. The work systematically maps transformer layers to different system components (CPUs, FPGAs, AIEs) and analyzes latency-throughput trade-offs to optimize heterogeneous execution.

**Novelty:** First MLIR-based multi-level intermediate representation framework providing unified IR abstraction for automated end-to-end compilation on AMD Versal heterogeneous devices.
