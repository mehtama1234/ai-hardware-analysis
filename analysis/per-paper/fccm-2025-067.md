# Ph.D. Project ARIES: Efficient Mapping and Automated Compilation for AMD Versal Devices

**Problem:** Mapping complex AI workloads across heterogeneous components (CPUs, FPGAs, AIEs) in AMD Versal ACAP devices requires both efficient mapping solutions and high-level programming abstractions to enable adoption by non-hardware specialists.

**Method:** The approach tests different ways to split transformer workloads (deep learning models) across AMD Versal's three processor types: CPUs for logic, FPGAs (reconfigurable custom circuits), and AIEs (specialized AI processors). For each split, they measure speed and data throughput to find the best trade-off. They built ARIES, an automated compilation tool using MLIR (a standard compiler intermediate format), which creates a unified translation that takes application code all the way down to running on the AIEs without manual hardware configuration.

**Novelty:** ARIES is the first unified MLIR-based compiler intermediate representation that enables automatic end-to-end deployment of applications on AMD Versal's AIE processors, eliminating manual hardware mapping.
