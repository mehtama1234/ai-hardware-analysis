# FactorHD: A Hyperdimensional Computing Model for Multi-Object Multi-Class Representation and Factorization

**ID**: dac-2025-442  
**Venue**: DAC  
**Confidence**: low

## Problem
Existing HDC models struggle to represent and factorize complex multi-object class-subclass relations; they suffer from superposition catastrophe and information loss when handling multiple objects simultaneously.

## Motivation
Neuro-symbolic AI requires efficient factorization for reasoning; HDC offers brain-inspired efficiency but needs expressiveness for hierarchical concepts.

## Method
FactorHD encodes each object with a symbolic memorization clause to preserve multi-object information, avoiding superposition catastrophe. Factorization algorithm selectively eliminates redundant classes by identifying the memorization clause of the target class.

## Key Novelty
Memorization-clause-based encoding enabling lossless factorization of multi-object class-subclass hierarchies in HDC.

## Contributions
- Symbolic encoding method with memorization clause
- Efficient factorization algorithm
- 5667x speedup at representation size 10^9
- 92.48% accuracy on CIFAR-10 with ResNet-18
