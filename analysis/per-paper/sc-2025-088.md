# eIM: GPU-Accelerated Efficient Influence Maximization in Large-Scale Social Networks

**Venue:** SC 2025  
**Authors:** Doney, Huang, Lee

## Problem
**Influence Maximization (IM):** Given social network and diffusion model, find k vertices whose activation maximizes expected influence spread. Application: viral marketing, information campaigns, disease prevention.

**Complexity:** NP-hard; no polynomial-time optimal algorithm.

**Current GPU Solution:** IMM (Influence Maximization via Martingales) algorithm
- Pros: Efficient approximation with theoretical guarantees
- Cons: **Memory intensive** – stores millions of RRR (Random Reverse Reachable) sets for large networks

**Problem:** Memory footprint limits applicability to largest social networks (billions of nodes/edges).

## Algorithm Background: IMM

### IMM Overview
1. **Generate RRR sets** – Reverse reachable sample sets via random walks backward from random vertices
2. **Greedy selection** – Select k vertices maximizing RRR set coverage
3. **Probabilistic guarantees** – Approximation ratio (1 - 1/e) achieved with sufficient RRR samples

### Memory Requirement
- RRR set storage is bottleneck:
  - Billions of RRR sets for large networks
  - Each set contains variable-length vertex lists
  - Total storage: several TB for largest networks

## Technical Challenges

### Memory Management
1. **RRR set compression** – Reduce per-set storage without losing correctness
2. **Memory coalescing** – Minimize fragmentation in GPU memory allocations
3. **Streaming generation** – Generate RRR sets on-demand rather than storing all upfront

### Algorithmic
1. **Parallel greedy selection** – Greedy inherently sequential; GPU acceleration non-trivial
2. **Load balancing** – GPU work distribution across varied RRR set sizes
3. **Approximation preservation** – Ensure compressed representation maintains guarantees
