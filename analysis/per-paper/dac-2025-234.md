# Adora Compiler: End-to-End Optimization for High-Efficiency Dataflow Acceleration and Task Pipelining on CGRAs

**Venue:** DAC
**ID:** dac-2025-234

## Problem
CGRAs are energy-efficient for nested-loop workloads but lack a user-friendly compiler; existing tools cannot automatically map loop algorithms to dataflow + task-pipelining, limiting CGRA adoption.

## Motivation
CGRAs offer 10-100x better energy efficiency than GPUs for certain workloads; a good compiler unlocks this potential for edge applications.

## Method
The compiler restructures nested loops using CGRA-specific transformations to expose parallelism and enable dataflow (direct data flow between operations without memory). It optimizes task pipelining across loops (overlapping iterations and stages so multiple loop passes execute in parallel). A scheduling algorithm coordinates the timing across the entire computation, creating efficient mappings that keep CGRA hardware heavily utilized with minimal user input.

## Key Novelty
The compiler jointly optimizes loop restructuring and task pipelining (overlapping iterations), rather than handling them separately, to efficiently map computation onto CGRA hardware.

## Contributions

- Adora compiler for CGRA SoC targeting
- CGRA-specific loop transformations for dataflow
- Task pipelining optimization across loop boundaries
- Scalable edge computing acceleration for nested-loop kernels
