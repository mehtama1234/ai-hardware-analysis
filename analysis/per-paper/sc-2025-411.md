# SC-2025-411: AGILE - Lightweight Asynchronous GPU-SSD Integration

## Summary
AGILE enables efficient asynchronous GPU-centric I/O for workloads exceeding GPU memory, achieving 1.88x average speedup through overlapped computation and I/O with integrated HBM caching.

## Problem
Emerging workloads (recommender systems, graph analytics) exceed GPU memory capacity. Current GPU-centric I/O uses synchronous semantics, forcing threads to stall during I/O, wasting compute resources.

## Method
- **Asynchronous I/O library**: GPU threads issue I/O without blocking
- **Deadlock-free design**: Eliminates deadlock risks in asynchronous scenarios
- **HBM-based software cache**: Flexible caching layer integrated into GPU memory hierarchy
- **Lock-free synchronization**: Reduces synchronization overhead

## Key Results
- 1.88x average speedup across diverse compute-to-communication ratios
- 1.75x speedup over BaM on DLRM
- 3.12x cache overhead reduction (graphs)
- 2.85x NVMe I/O overhead reduction (graphs)
- 1.32x register usage reduction

## Hardware Target
- GPU systems with NVMe storage
- Systems with HBM memory (NVIDIA, AMD GPUs)
- Recommender system accelerators
- Graph processing platforms
