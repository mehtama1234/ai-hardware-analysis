# Computing the Full Earth System at 1km Resolution

**Venue:** SC

## Problem
Global Earth system simulation at high resolution requires handling massive degrees of freedom across heterogeneous processors

## Motivation
Enable full Earth system simulation at unprecedented 1km resolution to study complete atmosphere-ocean-land interactions

## Method
The researchers used NVIDIA's GH200 superchip, which combines Grace CPUs (general-purpose processors) and Hopper GPUs (graphics processors optimized for heavy computation). They split the Earth system simulation work between these two processor types, letting each handle what it does best rather than forcing one type to do everything. They also optimized the ICON codebase (the Earth system simulation software) to run efficiently on this mixed setup.

## Key Novelty
For the first time, they simulated the entire global Earth system (atmosphere, oceans, and land simultaneously) at 1.25km resolution, achieving 145.7 simulated days per real day—faster than previous atmosphere-only simulations.

## Contributions
- Full Earth system model (atmosphere, ocean, land) at 1km resolution
- Heterogeneous CPU-GPU optimization on GH200 superchips
- Separation of concerns reducing code complexity 50% while improving performance
