# isscc-2025-111: Wideband Bioimpedance Spectroscopy via Time-to-Digital Demodulation

**Problem:** Existing bioimpedance ICs limited to 10MHz with analog I-Q suffering phase errors >4°; 30MHz wideband needed for tissue characterization.

**Method:** Time-to-digital (T-D) demodulation with co-prime delay-locked (CDL) sampling: 21.6GHz equivalent rate from 240MHz clock; compact phase comparator DLL; optimized wideband front-end.

**Key Novelty:** T-D demodulation with CDL sampling eliminating analog multiplication distortion for unprecedented phase accuracy to 30MHz.

**Main Results:** 30MHz bandwidth, 92.7dB SNR, 99.6% accuracy, 0.57° phase error at 30MHz, 3.18mW power.

**Confidence:** Low (abstract-only analysis)
