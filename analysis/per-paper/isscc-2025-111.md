# isscc-2025-111: Wideband Bioimpedance Spectroscopy via Time-to-Digital Demodulation

**Problem:** Existing bioimpedance ICs limited to 10MHz with analog I-Q suffering phase errors >4°; 30MHz wideband needed for tissue characterization.

**Method:** Instead of conventional I-Q mixing (multiplying the signal by two reference signals), this IC uses time-to-digital demodulation, which converts signal timing into digital information for measurement. It achieves high phase accuracy through co-prime delay-locked sampling (a technique where precisely timed delays stack to simulate a much faster sampling rate), reaching 21.6GHz effective sampling from a 240MHz clock. A phase comparator-based delay-locked loop generates these accurate delays, while an optimized wideband current generator and front-end design handle frequencies up to 30MHz. This design eliminates the distortion caused by analog multiplication in conventional systems.

**Key Novelty:** T-D demodulation with CDL sampling eliminating analog multiplication distortion for unprecedented phase accuracy to 30MHz.

**Main Results:** 30MHz bandwidth, 92.7dB SNR, 99.6% accuracy, 0.57° phase error at 30MHz, 3.18mW power.

**Confidence:** Low (abstract-only analysis)
