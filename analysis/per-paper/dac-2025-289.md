# ADVeRL-ELF: ADVersarial ELF Malware Generation using Reinforcement Learning

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Deep learning malware detectors lack robustness testing; Linux ELF adversarial generation is under-investigated despite critical security implications.

## Core Method
RL framework generating adversarial ELF malware by injecting semantic NOPs (no-operation instructions) within executable regions while preserving malicious functionality; RL agent learns optimal NOP placement patterns for detector evasion.

## Key Contribution
RL-driven generation of semantically-preserving adversarial Linux malware via NOP injection.

## Results
- 59.5% attack success rate
- Foundation for hardening Linux malware detection
