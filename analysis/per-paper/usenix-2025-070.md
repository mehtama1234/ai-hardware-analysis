# Colocating ML Inference and Training with Fast GPU Memory Handover

**Problem:** GPU memory becomes a bottleneck when running inference and training workloads simultaneously; inefficient memory transfers between these workloads cause performance degradation and resource underutilization.

**Method:** When a GPU runs both inference (applying a trained model to new data) and training (improving a model) at the same time, they both compete for GPU memory. Instead of copying data between them, this approach lets them hand off and reuse memory blocks directly. Optimized scheduling coordinates which workload accesses which memory regions and when, preventing conflicts, minimizing handoff delays, and reducing fragmentation.

**Novelty:** The key idea is a fast way to hand off memory blocks between inference and training workloads on the same GPU, enabling them to reuse the same memory with minimal delay.
