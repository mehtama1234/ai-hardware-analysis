# SPARTA: Spike-Aware Token Skipping Co-Optimization with Heterogeneous ReRAM-CIM Architecture for Spiking Transformer Acceleration

**Venue:** ICCAD  
**ID:** iccad-2025-081

## Problem
Spiking transformers combine energy-efficiency advantages of SNNs with transformer accuracy but suffer from unstructured sparsity in spike activations that creates substantial hardware overhead in accelerators, limiting practical deployment efficiency.

## Motivation
Spiking transformers offer promising energy efficiency while maintaining model accuracy for resource-constrained applications, but realizing this potential requires hardware design that exploits their inherent sparsity patterns.

## Method
SPARTA combines algorithm and hardware design to address the scattered, unpredictable spikes that waste power in spiking transformers. On the algorithm side, it uses reinforcement learning (a machine-learning approach that learns through trial-and-error) to intelligently decide which transformer tokens (input chunks) are informative and which can be skipped; it also predicts and eliminates tokens that will be inactive, converting unstructured spikes into organized token-level sparsity. The hardware implements a specialized ReRAM-based architecture (ReRAM is resistive memory that performs calculations in-place) with ReRAM-CIM (computing-in-memory) for linear layers and a dedicated token-spike fusion engine that efficiently routes tokens and computes spike attention operations.

## Key Novelty
The core innovation is combining reinforcement-learning-based token skipping (a learned algorithm for selecting which tokens matter) with custom ReRAM-CIM hardware, both specifically designed to handle the sparsity patterns that naturally emerge in spiking transformers.

## Contributions
- Spike-aware dynamic token skipping algorithm using RL for structured sparsity across spatial and temporal domains
- Spike-aware token prediction algorithm reducing inactive token overhead
- Heterogeneous ReRAM-CIM architecture with specialized engines for linear layers and token routing
- Up to 543.1× speedup and 308.0× energy efficiency vs GPU; 10.2× speedup and 5.2× efficiency vs state-of-the-art
