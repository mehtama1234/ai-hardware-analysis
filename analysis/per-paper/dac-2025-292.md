# LA-MTL: Latency-Aware Automated Multi-Task Learning

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Real-time multi-task embedded inference requires simultaneous optimization of accuracy, parameter efficiency, AND latency; existing MTL methods lack explicit latency constraints, forcing post-hoc tuning.

## Core Method
Layer-level automated MTL policy search incorporating Analytical Latency Factor (ALF) capturing local/global inference latencies; derives Pareto-optimal solutions balancing all three objectives via architecture search.

## Key Contribution
Analytical Latency Factor enabling latency-aware MTL search without post-hoc optimization.

## Results
- 50% latency reduction on Jetson AGX Orin
- ±2 p.p. accuracy maintenance
- 20+ p.p. parameter efficiency gain
