# Hardware Implementation of Blind Decoding of Downlink Control Information for 5G

**Venue:** VLSID 2025  
**Authors:** Y. Anu Rajarajeswari, Nitin Chandrachoodan, Anji Babu Vadapalli, J. Klutto Milleth

## Problem Statement
5G user equipment (UE) must decode Downlink Control Information (DCI) to obtain time-frequency resource allocations, modulation schemes, and coding rates for data reception. The UE does not know DCI location a priori and must blindly search multiple candidate locations (PDCCH search space). This exhaustive search must complete within 0.25 milliseconds (3GPP latency budget), creating significant computational pressure on UE baseband processors.

## Key Contributions
1. **Hardware-Accelerated DCI Decoding**: Flexible hardware implementation meeting the 0.25 ms blind decoding latency budget
2. **Efficient Resource Utilization**: Achieves 65% utilization of available time budget (150 µs actual vs. 250 µs budget)
3. **Testbed Integration**: Successfully integrated into existing in-house 5G testbed UE receive chain
4. **FPGA Platform**: Implemented on Xilinx Zynq Ultrascale+ RFSoC (ZCU111) board
5. **Functional Validation**: Validated for correctness and performance on real 5G testbed environment

## Technical Approach
- **Hardware Platform**: Xilinx Zynq Ultrascale+ RFSoC ZCU111 (ARM + FPGA co-design)
- **Algorithm**: Blind search across DCI candidates with parallel decoding paths
- **Optimization**: Resource-efficient architecture achieving 65% time utilization
- **Integration**: Seamless integration with existing 5G UE baseband receive chain
- **Validation**: Real-time operation on in-house 5G testbed
