# isscc-2025-186: IRIS Spatial Computing SoC for 3D Gaussian Splatting

**Problem**: Mixed-reality requires real-time surface-aware modeling and interactive photorealistic rendering with 15ms latency and 3D object deformation; NeRF accelerators cannot support deformation, and 3DGS on edge GPUs requires >400ms/frame due to massive external memory access (81.3% of energy), sequential IPR stages, and expensive backpropagation.

**Solution**: IRIS SoC with SEMM-based 3DGS compression (50MB→smaller), co-optimized SAM/IPR/backprop pipelines, and memory hierarchy minimizing EMA. Specialized datapath and hardware reuse reduce backprop from 55.8% to <45% of compute.

**Key Results**:
- 8.55mJ/frame energy efficiency
- 15ms latency interactive rendering (real-time MR)
- EMA reduced from 81.3% to 52.8% of energy via compression
- IPR stages fused, backprop reuse optimized

**Hardware**: Edge SoC / ASIC  
**Workload**: 3D neural rendering / mixed-reality  
**Confidence**: high (rich abstract detail)
