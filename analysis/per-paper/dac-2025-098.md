# Near-Memory LLM Inference Processor based on 3D DRAM-to-logic Hybrid Bonding

## Problem
LLM inference requires high memory bandwidth and compute; separation of memory and compute creates bandwidth bottlenecks and energy inefficiency.

## Method
The architecture stacks memory (DRAM) directly on top of the compute chip using 3D hybrid bonding, drastically shortening how far data must travel. Instead of scattered control units across the chip, a single centralized controller manages everything, saving significant chip area. This controller reconfigures between two types of matrix operations—vector-matrix multiplication (GEMV) and matrix-matrix multiplication (GEMM)—depending on the phase of LLM inference. Dual-IO pathways (two separate data routes) prevent data traffic jams.

## Key Innovation
Centralized controller with dual-IO on hybrid-bonded DRAM eliminates distributed controller overhead while enabling efficient reconfigurability.

## Contributions
- Centralized controller reducing area overhead
- Dual-IO scheme for reconfigurable GEMV/GEMM
- 3D hybrid-bonded DRAM-to-logic integration
- 2.9x-3.5x speedup over NPU and DRAM-PIM

## Motivation
Near-memory computing via 3D hybrid bonding enables massive bandwidth/parallelism; prior designs suffered from distributed controller overhead.
