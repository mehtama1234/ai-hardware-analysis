# SparCIM: A Heterogeneous CIM-Based Accelerator for Large Language Models with Contextual and Unstructured Bit Sparsity

**Paper ID:** iccad-2025-237  
**Venue:** ICCAD

## Problem

Transformer-based LLMs have high computation and memory demands on edge devices. Sparsification through contextual sparsity reduces demands but existing CIM accelerators suffer from low utilization from unstructured bit sparsity, imbalanced workloads between prefilling and decoding stages, and sparsity prediction overhead.

## Motivation

Edge deployment of LLMs requires energy-efficient inference; combining contextual sparsity with hardware-efficient CIM implementation is needed to reduce memory and computation demands.

## Method

Proposes SparCIM, a heterogeneous CIM accelerator with: (1) Heterogeneous CIM Architecture (HCA) utilizing Analog CIM for sparse attention/FFN prediction and Digital CIM for contextual sparse computations, (2) Dynamic Workload Allocator (DWA) configuring DCIM memory/compute modes to reduce external memory access and token latency, and (3) Bit-level Butterfly Sparsity Alignment Unit (BSAU) exploiting unstructured bit sparsity to improve CIM utilization and throughput. Implemented in 28nm technology.

## Key Novelty

First heterogeneous analog-digital CIM accelerator supporting LLM inference with contextual and bit-level sparsity, achieving 1.27-5.98× energy efficiency improvements.

## Contributions

- Heterogeneous CIM architecture combining Analog and Digital CIM for different computation phases
- Dynamic workload allocator for balanced prefilling/decoding execution
- Bit-level butterfly sparsity alignment improving CIM utilization
- 1.27-5.98× energy efficiency vs. state-of-the-art transformer accelerators with minimal accuracy loss
