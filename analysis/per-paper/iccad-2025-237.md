# SparCIM: A Heterogeneous CIM-Based Accelerator for Large Language Models with Contextual and Unstructured Bit Sparsity

**Paper ID:** iccad-2025-237  
**Venue:** ICCAD

## Problem

Transformer-based LLMs have high computation and memory demands on edge devices. Sparsification through contextual sparsity reduces demands but existing CIM accelerators suffer from low utilization from unstructured bit sparsity, imbalanced workloads between prefilling and decoding stages, and sparsity prediction overhead.

## Motivation

Edge deployment of LLMs requires energy-efficient inference; combining contextual sparsity with hardware-efficient CIM implementation is needed to reduce memory and computation demands.

## Method

SparCIM combines two types of computing-in-memory chips (where calculations happen in memory rather than being shuttled to a separate processor): analog chips that quickly approximate patterns with many zeros in attention and feedforward calculations, and digital chips for precise calculations that depend on the input context. A dynamic workload allocator switches the digital chips between storage and compute modes, reducing trips to external memory and the time per generated token. A bit-level alignment unit exploits the fact that individual bits within numbers can often be ignored (bit-level sparsity), packing more useful computation into each memory cell. Built in 28nm process technology.

## Key Novelty

SparCIM is the first heterogeneous analog-digital computing-in-memory accelerator for large language models that exploits both context-dependent sparsity and bit-level sparsity, achieving 1.27–5.98 times better energy efficiency.

## Contributions

- Heterogeneous CIM architecture combining Analog and Digital CIM for different computation phases
- Dynamic workload allocator for balanced prefilling/decoding execution
- Bit-level butterfly sparsity alignment improving CIM utilization
- 1.27-5.98× energy efficiency vs. state-of-the-art transformer accelerators with minimal accuracy loss
