# TianheEngine: Hierarchy-aware Adaptive Partitioning System for Trillion-scale Graph Processing

**Venue:** SC | **ID:** sc-2025-111

## Summary
TianheEngine: hierarchy-aware graph partitioning system exploiting communication topology and graph sparsity for efficient trillion-scale graph processing on ultra-large HPC systems (79K+ nodes).

## Problem & Motivation
Trillion-scale graphs in modern HPC pose challenges for traditional partitioning approaches. Standard methods ignore hierarchical communication costs (e.g., intra-node, node-pair, rack-level, cross-rack), leading to excessive cross-layer overhead and suboptimal scalability.

## Key Findings
- **Scale:** Tested on 79,024 computing nodes with 1.2M+ processor cores
- **Performance:** Outperforms state-of-the-art graph partitioning and parallel systems
- **Ranking:** Achieves top-ranked performance in Graph500 benchmarks
- **Methodology:** Adaptive partitioning based on hierarchical communication awareness

## Hardware & Systems
- **Scale:** 79,024+ computing nodes
- **Cores:** 1.2+ million processor cores
- **Architecture:** Multi-tier hierarchical communication topology
- **Platform:** Supercomputer infrastructure (Tianhe-implied)

## Techniques
- **Hierarchy-aware partitioning:** Exploit communication tiers (intra-node, node-pair, rack, cross-rack)
- **Adaptive strategies:** Dynamic partitioning based on graph structure
- **Sparsity exploitation:** Optimize for real-world sparse graphs
- **Communication optimization:** Minimize cross-layer communication costs
