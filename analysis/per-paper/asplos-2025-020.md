# Einsum Trees: An Abstraction for Optimizing the Execution of Tensor Expressions

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** global tensor data-layout optimization via Einsum Tree IR

## Problem
Optimizing multi-operand einsum tensor expressions requires co-optimizing both the contraction path and the data layout of intermediate tensors, but these two problems have been studied in isolation, leading to suboptimal global execution performance.

## Motivation
Tensor contraction workloads in ML and scientific computing are highly sensitive to memory layout and contraction ordering; separate optimization of each leaves significant performance on the table.

## Method
Einsum Tree IR captures a full contraction path as a tree structure, enabling global optimization of tensor data layouts across all intermediate binary contractions simultaneously. Given a contraction path, it applies global data-layout optimization to minimize data movement and improve cache utilization, with kernels executed using existing BLAS/tensor libraries on Arm and x86 CPUs.

## Key Novelty
Einsum Tree IR: a global intermediate representation for jointly optimizing tensor data layouts across an entire multi-contraction path, rather than optimizing each binary contraction independently.

## Contributions
- Einsum Tree IR: intermediate representation for globally optimizing data layout for a given contraction path
- Global data-layout optimization algorithm operating on the full contraction tree
- Evaluation on Arm and x86 server and desktop processors showing improvement over local optimization
