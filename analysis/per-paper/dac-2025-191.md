# RE3: Automated Refinement Relation Discovery via Sequential Equivalence Checking

**Venue:** DAC | **ID:** dac-2025-191

## Summary
RE3 automates discovery of concise, human-comprehensible refinement relations between sequential circuits via rigorous equivalence checking. Reduces manual effort in regression verification, assertion synthesis, and helps catch errors in LLM-generated RTL.

## Key Results
- **Automation:** Automatic refinement relation discovery from design pairs
- **Readability:** Human-comprehensible relation extraction
- **Application:** Error detection/correction for LLM-generated RTL designs

## Technique
Rigorous sequential equivalence checking for non-cycle-accurate designs using relational mapping abstraction to automatically extract refinement relations.
