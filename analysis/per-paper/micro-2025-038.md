# Quartz: A Reconfigurable, Distributed-Memory Accelerator for Sparse Applications

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Sparse tensor and graph workloads exhibit irregular memory access patterns and variable computation densities that defeat fixed-dataflow ASIC accelerators designed for dense workloads. No single dataflow or memory organization handles the full diversity of sparse application kernels efficiently.

## Motivation
Sparse workloads (graph analytics, sparse linear algebra, sparse ML) are increasingly important and their irregular structure causes severe underutilization on both GPUs and existing domain-specific accelerators.

## Method
Quartz is a specialized computer chip (ASIC) that can reconfigure itself while it's running—meaning its dataflow (how data moves through it) can be reprogrammed to match the access patterns of a sparse application. Instead of one large central memory, it uses multiple small memory banks spread across the chip close to the processing units, allowing data to travel short distances instead of getting stuck in traffic. A flexible routing system inside the chip directs data between the memory banks and processing elements based on the reconfigured dataflow.

## Key Novelty
Combining runtime-reconfigurable dataflow—the ability to adjust how data moves through the chip while running—with distributed memory banks allows one chip to efficiently adapt to the different access patterns of various sparse applications.

## Contributions
- Quartz ASIC architecture with runtime-reconfigurable dataflow for sparse workloads
- Distributed-memory organization providing high aggregate on-chip bandwidth
- Evaluation across multiple sparse application domains demonstrating efficiency gains
