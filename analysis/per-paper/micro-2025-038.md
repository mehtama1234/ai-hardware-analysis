# Quartz: A Reconfigurable, Distributed-Memory Accelerator for Sparse Applications

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Sparse tensor and graph workloads exhibit irregular memory access patterns and variable computation densities that defeat fixed-dataflow ASIC accelerators designed for dense workloads. No single dataflow or memory organization handles the full diversity of sparse application kernels efficiently.

## Motivation
Sparse workloads (graph analytics, sparse linear algebra, sparse ML) are increasingly important and their irregular structure causes severe underutilization on both GPUs and existing domain-specific accelerators.

## Method
Quartz is a reconfigurable ASIC accelerator with distributed on-chip SRAM banks. The architecture exposes a programmable dataflow substrate that can be configured at runtime to match the access pattern of a given sparse kernel. Distributed memory banks reduce the bandwidth bottleneck by providing high aggregate internal bandwidth close to the compute units. A reconfigurable interconnect routes data between memory banks and processing elements according to the configured dataflow.

## Key Novelty
Runtime-reconfigurable dataflow combined with distributed SRAM memory enables a single chip to efficiently serve the diverse access patterns of multiple sparse application classes.

## Contributions
- Quartz ASIC architecture with runtime-reconfigurable dataflow for sparse workloads
- Distributed-memory organization providing high aggregate on-chip bandwidth
- Evaluation across multiple sparse application domains demonstrating efficiency gains
