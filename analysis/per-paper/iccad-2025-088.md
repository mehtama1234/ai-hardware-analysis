# LLM-on-the-Palm: Mobile LLM Inference with PIM-Enhanced NAND Flash Memory

**Venue:** ICCAD  
**ID:** iccad-2025-088

## Problem
LLM inference on mobile devices is severely limited by the inability to fit billion-parameter models in DRAM, forcing reliance on slow NAND flash memory, resulting in poor user experience and high latency.

## Motivation
Enabling on-device LLM inference is crucial for privacy, security, and user experience, but requires solving the memory access bottleneck when parameters must be stored in slower flash memory.

## Method
LLM-on-the-Palm puts tiny math processors (called multiply-accumulate or MAC units—the basic calculations that neural networks use) directly into NAND flash storage. A 256 GB storage drive gets one of these processors per storage layer, giving 256 total. Instead of hauling data back and forth between storage and the main processor—the speed bottleneck that kills mobile LLM performance—the math happens right in storage where the data already is. This way, mobile phones can run billion-parameter language models fast without slowing down the storage itself.

## Key Novelty
Running neural-network computations directly in NAND flash storage with one processor per storage layer enables mobile LLM inference with minimal hardware modifications.

## Contributions
- PIM-enhanced NAND flash architecture with one MAC unit per plane maintaining cell density
- Innovative data movement reduction through compute-in-storage design
- Demonstrates approximately 100 ms per token generation on 6.7B model with iPhone-15-class specifications
- Hardware modification minimal and pragmatic for smartphone deployment
