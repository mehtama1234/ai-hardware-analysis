# Cocktail: Chunk-Adaptive Mixed-Precision Quantization for Long-Context LLM Inference

**Venue**: DATE  
**Primary Theme**: chunk-adaptive KV cache quantization for long-context LLMs  

## Problem
Long-context LLM inference suffers from intolerable latency and GPU memory consumption; token-level KV cache quantization is time-consuming in search and hardware-inefficient during computation.

## Method
Cocktail reduces GPU memory by lowering the precision of the KV cache—the data cached from previous tokens that enables fast attention computation. Instead of deciding precision individually for each token (which takes too long to search), it groups tokens into chunks and uses the similarity between the current query and previous context to choose how much precision each chunk needs. It then reorders the chunks by precision level, so the GPU processes all chunks of one precision level together before switching to the next, which lets the hardware run efficiently without constantly switching between different precision formats.

## Key Novelty
Cocktail groups tokens into chunks for mixed-precision decisions and explicitly reorders them by precision level so the GPU can process chunks of the same precision together, avoiding the efficiency penalty of constantly switching precisions.

## Contributions
- Chunk-level quantization search avoiding expensive token-level search
- KV cache chunk reordering for hardware efficiency
- Maintains model accuracy across various LLM scales
- Outperforms SOTA KV cache quantization methods
