# Programmer productivity and performance on AMD's AI Engines: Offloading Fortran intrinsics via MLIR a case-study

**Venue:** SC
**Paper ID:** sc-2025-014
**Confidence:** low

## Problem Statement
Specialized architectures (FPGAs, AI Engines) offer energy efficiency but require substantial expertise to program; programmers prefer familiar languages like Fortran

## Motivation
Energy efficiency critical; specialized hardware promising but hard to use; automatic offloading of familiar language constructs could bridge productivity gap

## Method
The system uses MLIR (an intermediate language compilers use to translate between human-readable source code and hardware instructions) to automatically identify Fortran intrinsics—built-in mathematical functions in Fortran—and redirect them to AMD AIEs, which are specialized hardware accelerators built into Ryzen AI processors. The compiler translates these high-level operations into low-level instructions specifically optimized for the accelerators. Programmers don't need to modify their existing code at all; the compiler handles the entire offloading automatically.

## Key Novelty
The compiler automatically routes Fortran's mathematical functions to specialized hardware accelerators without requiring code changes.
