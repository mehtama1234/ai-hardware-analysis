# SC25 Paper Analysis: sc-2025-098

## AMRaCut: Scalable Partitioning for Adaptive Mesh Refinement

### Summary
AMRaCut is a distributed-parallel mesh partitioner combining parallel label propagation and graph diffusion. It achieves 5-10x speedups over traditional partitioners (ParMETIS, PT-Scotch) while maintaining comparable partition quality, and efficiently handles dynamic AMR mesh evolution.

### Key Problem
- **Scalability-Quality Trade-off**: Multi-level graph partitioning offers quality but doesn't scale; space-filling curves scale but compromise quality
- **AMR Dynamics**: Mesh evolution requires efficient repartitioning with mostly local changes
- **Communication Bottleneck**: Global communication in partitioning limits scalability

### Technical Approach
1. **Parallel Label Propagation**: Local partitioning decisions with minimal global communication
2. **Graph Diffusion**: Smoothing partition boundaries while maintaining locality
3. **Locality Exploitation**: Operates on initial partitions, limiting inter-process communication to neighbors
4. **AMR-Aware Design**: Leverages property of mostly local mesh changes

### Contributions
1. AMRaCut partitioner combining label propagation and graph diffusion
2. 5-10x speedups vs ParMETIS/PT-Scotch
3. Partition quality comparable to traditional methods
4. Minimized partition boundaries
5. Efficiency approaching space-filling curve methods
6. Validation on realistic FEM SpMV workloads
7. Load balance within 2x of optimal

### Hardware & Workloads
- **Target Hardware**: Distributed memory supercomputers
- **Workloads**: Finite Element Method simulations, PDE solvers with AMR

### Performance Results
- **Speedup**: 5-10x vs multi-level partitioners
- **Partition Quality**: Comparable to ParMETIS/PT-Scotch
- **Load Imbalance**: Maximum 2x of optimal
- **Downstream Performance**: Comparable SpMV times despite load imbalance

### Applications
- PDE solvers for science and engineering
- Adaptive mesh refinement simulations
- Finite element analysis
