# throttLL'eM: Predictive GPU Throttling for Energy Efficient LLM Inference Serving

**Venue:** HPCA 2025  
**Authors:** Andreas Kosmas Kakolyris, Dimosthenis Masouros, Petros Vavaroutsos, Sotirios Xydis, Dimitrios Soudris

## Problem
LLM inference serving on GPUs consumes excessive energy while providers must satisfy SLOs; static GPU frequency settings over-provision compute resources when request load or KV cache pressure is low.

## Motivation
Inference dominates LLM workloads and GPU power demand is a growing environmental and monetary concern, requiring dynamic power management that maintains user-facing SLO compliance.

## Method
The system watches upcoming requests and predicts how much temporary storage space for computation will be needed, then uses a machine learning model to estimate how long each computational step will take. Based on these predictions, it adjusts the GPU's speed—running it fast when there's work to do and slow when it can coast—and updates these decisions after every single step. The predictions are highly accurate (R² score exceeding 0.97) with an average error of less than 1 step per second. By tuning both the GPU speed and the number of model instances running in parallel, the system cuts energy use while guaranteeing response times stay within promised limits.

## Key Novelty
The system predicts upcoming memory and request needs to adjust GPU speed after every computational step, cutting energy proactively instead of waiting and capping power after the system gets overloaded.

## Contributions
- Predictive ML model projecting KV cache usage and batch size for LLM inference
- Iteration-level GPU frequency and instance scaling framework respecting SLOs
- Up to 43.8% energy reduction vs NVIDIA Triton server under SLO constraints
- Open-source release: https://github.com/WilliamBlaskowicz/throttLL-eM

## Results
- **Energy:** Up to 43.8% lower consumption vs NVIDIA Triton server
- **Efficiency:** At least 1.71x energy efficiency improvement under SLOs

## Hardware Target
GPU

## Limitations
The ML prediction model is trained on specific LLM inference traces and may require retraining to generalize to different model families or serving configurations.
