# Revealing Floating-Point Accumulation Orders in Software/Hardware Implementations

**Problem:** Accumulation orders in software and hardware implementations are undocumented, making it difficult for developers to ensure consistent results across systems and verify implementation equivalence.

**Method:** FPRev reveals the accumulation order (the order in which a system adds floating-point numbers—decimal numbers represented in computers) without modifying code or hardware. It tests the system with carefully chosen numerical inputs and observes the output differences, since different addition orders produce different results. By analyzing these output patterns, FPRev determines which order was used, and the efficient test design makes this faster than checking all possible sequences.

**Novelty:** It reveals the accumulation order (the sequence of additions) by analyzing how outputs vary with carefully chosen numerical tests, rather than requiring inspection of the implementation code or hardware.
