# Revealing Floating-Point Accumulation Orders in Software/Hardware Implementations

**Problem:** Accumulation orders in software and hardware implementations are undocumented, making it difficult for developers to ensure consistent results across systems and verify implementation equivalence.

**Method:** FPRev is a non-intrusive diagnostic tool that reveals accumulation orders by analyzing implementation outputs for specially designed numerical test inputs. It determines accumulation sequences without modifying source code or hardware, achieving lower time complexity than basic approaches through efficient test design.

**Novelty:** A non-intrusive, numerical-testing-based diagnostic approach that reveals implicit accumulation orders in implementations by analyzing output patterns rather than inspecting code or hardware.
