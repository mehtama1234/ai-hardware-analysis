# BioR5: A Three-Layer Architecture for Biological Reasoning in Scientific AI

**Venue:** SC 2025  
**Authors:** Ding, Brettin, Stevens

## Problem
Biological research encompasses diverse reasoning paradigms:
- **Phylogenetic analysis** – Tree-based evolutionary relationships
- **Mechanistic reasoning** – Pathway understanding, protein interactions
- **Literature synthesis** – Information extraction from publications
- **Predictive modeling** – Property prediction (toxicity, binding, etc.)

Current AI systems (including LLMs) employ single methodologies, insufficient for complex biological domains requiring multiple reasoning strategies.

## Approach
**BioR5: Three-Layer Architecture**

### Layer A: Parametric Memory
- Large Language Models (LLMs)
- Stores general biological knowledge
- Provides semantic understanding

### Layer B: Specialized Foundation Models
- Multimodal foundation models for:
  - Molecular representations (SMILES, 3D structures)
  - Sequence data (proteins, DNA)
  - Image analysis (microscopy, pathology)
- Domain-specific embeddings and predictions

### Layer C: External Tools & Databases
- Computational tools:
  - Structure prediction (AlphaFold, ESMFold)
  - Docking simulations
  - Property calculations
- Databases:
  - PubChem (chemical structures)
  - ToxCast (toxicity data)
  - ChEMBL (bioactive compounds)
  - UniProt (protein sequences)

## Reasoning Mode Selection

### Intelligent Triage
**Hybrid approach:**
1. **Keyword matching** – Detect problem type from query
   - "phylogenetic" → phylogenetic mode
   - "toxicity prediction" → toxicology mode
2. **LLM analysis** – Semantic understanding of context
   - Disambiguate multi-interpretable queries
   - Suggest alternative modes

## Case Study: Toxicology Specialization

### Components
- **TX-Gemma** – Toxicology-specific foundation model
- **Data integration**:
  - PubChem structures
  - ToxCast bioassay results
  - ChEMBL bioactivity data
- **Inference pipeline**: Query → TX-Gemma prediction → validation against databases

### Workflow
```
Query: "Is compound XYZ toxic?"
  → Layer A: LLM contextualizes
  → Layer B: TX-Gemma produces embedding
  → Layer C: Lookup PubChem/ToxCast/ChEMBL
  → Integrate predictions with evidence
```

## System Characteristics

### Extensibility
- **Dynamic mode registration** – Add new reasoning modes without recompilation
- **Tool integration framework** – Plug in new tools (databases, models)
- **Community-driven** – Open-source enables collaborative development

### Generality
- Applied to toxicology (proof-of-concept)
- Architecture extends to other biology subdomains
- Same three-layer pattern for all modes

## Technical Innovation

### Reasoning Mode as First-Class Abstraction
Traditional approach: single monolithic model
BioR5 approach: collection of specialized sub-systems coordinated by mode selection

Enables:
- Rapid specialization (swap Layer B models)
- Tool composability (plug new tools in Layer C)
- Graceful degradation (Layer A fallback if specialized tools unavailable)
