# Energy-Efficient Accelerator for Scalable Point Transformer Networks with Reduced Data Access

**ID:** iccad-2025-248

## Problem
Point cloud transformer networks have high data access requirements for attention computation, making them energy-inefficient. Current accelerators struggle with scalability for large point clouds.

## Motivation
Point cloud processing is critical for 3D vision and autonomous systems; energy-efficient hardware enables deployment on power-constrained devices.

## Method
The accelerator organizes 3D point cloud data into spatial regions (called panels) and assigns computation to these regions, so points that interact are stored near each other in memory. For the attention layers—where the network learns which points are related—it uses locality-based compression, shrinking the data representation based on how close points are to each other in 3D space, since distant points barely interact. This spatial organization and compression reduce memory bandwidth (the amount of data moving between storage and computation units), which is where most energy is consumed in current accelerators.

## Key Novelty
Using spatial locality to both organize computation into regions and compress attention data, so the hardware only moves data for point interactions that actually matter.
