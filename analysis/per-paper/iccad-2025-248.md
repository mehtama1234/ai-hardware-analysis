# Energy-Efficient Accelerator for Scalable Point Transformer Networks with Reduced Data Access

**ID:** iccad-2025-248

## Problem
Point cloud transformer networks have high data access requirements for attention computation, making them energy-inefficient. Current accelerators struggle with scalability for large point clouds.

## Motivation
Point cloud processing is critical for 3D vision and autonomous systems; energy-efficient hardware enables deployment on power-constrained devices.

## Method
Hardware accelerator for 3D point cloud transformers using panel-level kernel mapping to reduce data access patterns. Locality-based compression for attention layers. Optimized data flow to minimize memory bandwidth.

## Key Novelty
Panel-level kernel mapping with locality-based compression for energy-efficient point transformer acceleration.
