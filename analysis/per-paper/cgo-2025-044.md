# Parallaft: Runtime-Based CPU Fault Tolerance via Heterogeneous Parallelism

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Increasing silicon faults create silent data corruption risks; software-based detection has high overhead while hardware approaches are too complex for production.

## Core Innovation
Adapting hardware heterogeneous fault-tolerance concepts to software-based implementation using OS primitives and little-core offloading on commodity heterogeneous processors.

## Method
Parallaft repurposes insights from hardware heterogeneous-parallelism fault tolerance in pure software using copy-on-write checkpointing, dirty-page tracking, and performance-counter synchronization. Error checking is offloaded to little cores of heterogeneous processors (e.g., Apple M2).

## Key Contributions
- Software-based error detection leveraging heterogeneous parallelism without hardware modifications
- Using copy-on-write, dirty-page tracking, and performance-counter synchronization
- Achieves 50% energy cost reduction vs RAFT while maintaining comparable performance

## Results
- Energy: 50% vs RAFT homogeneous duplication
- Performance: comparable to RAFT

## Limitations
Evaluation limited to Apple M2; applicability to other heterogeneous processors not discussed.
