# Late Breaking Results: Scalable GPU-Friendly Parallelization for Sweep-Based Maze Routing

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
GPU-accelerated maze routing fails on large-scale designs due to GPU memory limits and excessive kernel launching overhead.

## Key Idea
Sweep-sharing enables simultaneous routing of multiple nets in a single sweep pass, with edge-level selective rerouting of overflowed segments.

## Method
The technique bundles multiple electrical connections (nets) into a single routing pass (sweep) instead of routing them separately, which reduces GPU memory usage and the cost of repeatedly launching GPU operations. When a path gets blocked, the algorithm selectively recalculates only the problematic segment (edge-level rip-up-and-reroute) rather than starting over, preserving successful routes and speeding up the solution.

## Contributions
1. Sweep-sharing mechanism for simultaneous multi-net routing
2. Edge-level selective rerouting strategy
3. Improved efficiency on ISPD-24 benchmarks
