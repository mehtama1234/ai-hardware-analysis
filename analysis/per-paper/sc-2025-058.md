# Scaling LLM Training Using RDMA over Converged Ethernet

**ID:** sc-2025-058  
**Venue:** SC  
**Confidence:** high

## Problem
InfiniBand traditional for HPC but expensive; RoCE offers cost-effective alternative but scaling performance unclear

## Motivation
Large-scale LLM training demands high-bandwidth networking; commodity Ethernet + RDMA provides cost savings

## Method
The researchers tested whether RoCE (RDMA over Converged Ethernet—a technique for efficiently moving data using regular network cables) could match the performance of the more expensive InfiniBand networking standard when training large language models at scale. They systematically benchmarked different training configurations: splitting the workload across multiple computers (data sharding), representing numbers with fewer bits (quantization), recalculating values instead of storing them (recomputation), and adjusting how many examples are processed together (batch sizing). By measuring how well these approaches worked on both RoCE and InfiniBand, they identified the settings where RoCE achieves similar scaling efficiency.

## Key Novelty
RoCE (RDMA over Converged Ethernet, a cheaper networking approach using regular cables) achieves near-linear scaling—where speed improves proportionally as you add more computers—matching the performance of InfiniBand when properly configured.

## Contributions
1. Benchmarks RoCE scaling for LLM training
2. Provides guidance on data sharding strategies
3. Documents quantization and recomputation tradeoffs
4. Shows cost-effective infrastructure design
