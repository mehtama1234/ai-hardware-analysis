# Transfer Learning on the Edge for a Wireless Application Using an SoC Platform

**Problem:** Deploying neural network training on resource-constrained edge devices remains a significant challenge, particularly for wireless systems that need to adapt models to dynamic environments with limited memory and computational resources.

**Method:** The TinyTL framework runs on an AMD RFSoC platform, which combines an ARM processor with an FPGA (field-programmable gate array—a reconfigurable chip that can be optimized for specific tasks). The FPGA handles the computationally intensive training of neural networks, while the ARM processor manages the overall coordination, allowing models to be adapted directly on wireless devices. This approach is applied to Digital PreDistortion (DPD)—a technique for adjusting power amplifier models in real-time as wireless conditions change.

**Novelty:** The core idea is combining an ARM processor and an FPGA accelerator on a single chip to enable transfer learning training (adapting pre-trained models to new tasks) efficiently on resource-limited wireless devices.
