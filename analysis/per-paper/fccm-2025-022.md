# Transfer Learning on the Edge for a Wireless Application Using an SoC Platform

**Problem:** Deploying neural network training on resource-constrained edge devices remains a significant challenge, particularly for wireless systems that need to adapt models to dynamic environments with limited memory and computational resources.

**Method:** The Tiny Transfer Learning (TinyTL) framework is implemented on an AMD RFSoC platform that combines ARM processors with FPGA fabric for heterogeneous acceleration. The FPGA accelerates the training computations while the ARM processor manages coordination, enabling efficient on-device adaptation. The system is applied to Digital PreDistortion (DPD) for adapting power amplifier models in wireless systems.

**Novelty:** First application of a heterogeneous SoC platform (ARM + FPGA) to accelerate transfer learning-based training on resource-constrained edge devices.
