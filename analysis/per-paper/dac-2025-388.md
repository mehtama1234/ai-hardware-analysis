# Location is Key: Leveraging LLM for Functional Bug Localization in Verilog Design

**Venue:** DAC
**ID:** dac-2025-388

## Problem
Automatic Verilog bug localization methods only suggest buggy line sets rather than precise identification, and depend on expert-written verification tools.

## Motivation
Reducing design verification time requires precise bug localization without expert-written testbenches and reference models.

## Method
LiK teaches an existing language model (Deepseek-Coder) to specialize in Verilog hardware design through three training stages. First, continuous pre-training exposes it to more Verilog code to build domain expertise. Second, supervised fine-tuning trains it on examples of actual bugs paired with their exact locations. Finally, reinforcement learning refines its accuracy by rewarding correct predictions and penalizing errors.

## Key Novelty
The core novelty is using three specialized training techniques together—continuous exposure to Verilog code, supervised learning on bug-location pairs, and reinforcement learning on accuracy—to train an LLM that pinpoints exact bugs in hardware designs.

## Contributions
1. Open-source specialized Verilog bug localization LLM (LiK)
2. Three-step training approach: continuous pre-training, SFT, and reinforcement learning
3. Superior accuracy over SOTA traditional method (Strider) and closed-source LLMs
4. Improves LLM-based Verilog debugging tool success rate from 76.47% to 90.54%
