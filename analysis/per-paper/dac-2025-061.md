# Mixed-Precision Quantization for Deep Vision Models with Integer Quadratic Programming

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Uniform bit-width quantization causes significant accuracy degradation at low precision and inefficiency at high precision; existing mixed-precision methods assume independence of layer quantization errors, leading to suboptimal assignments.

## Motivation
Mixed-precision quantization is essential to balance accuracy and efficiency tradeoffs across layers, but cross-layer error dependencies have been ignored, leaving performance on the table.

## Method
CLADO learns how reducing a layer's precision (using fewer bits to represent numbers) doesn't just affect that layer—it also affects other layers. It builds mathematical equations to predict these cross-layer interactions from a small sample of data, then uses Integer Quadratic Programming (a method for optimizing combinations of choices) to assign each layer an optimal number of bits. By accounting for how layers actually depend on each other, rather than treating each as an independent problem, it finds better tradeoffs between accuracy and efficiency.

## Key Novelty
Rather than treating each layer's quantization error (accuracy loss from reduced precision) as independent, this method optimizes for cross-layer dependencies—how one layer's precision choice affects other layers' accuracy.

## Contributions
- Novel sensitivity-based MPQ formulation capturing pairwise cross-layer quantization error dependencies
- Integer Quadratic Program solver for practical mixed-precision bit-width assignment
- State-of-the-art results on ImageNet for CNN and vision transformer quantization

## Metrics
- Accuracy: State-of-the-art mixed-precision quantization on ImageNet

## Baselines

## Limitations
