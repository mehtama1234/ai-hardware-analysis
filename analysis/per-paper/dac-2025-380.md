# High Energy-efficiency and Low latency In-Memory Computing using Analog Accumulator and In-Memory ADC with shared References

**Venue:** DAC
**ID:** dac-2025-380

## Problem
In-memory computing array ADCs require high area overhead for data conversion; traditional approaches sacrifice linearity and energy efficiency.

## Motivation
In-memory analog-to-digital conversion consumes large area; efficient shared-reference designs can drastically reduce overhead while maintaining signal integrity.

## Method
The system builds a 256-by-128 array of dual-8T SRAM bitcells (memory cells containing 8 transistors each, grouped in pairs) that store three-level weights rather than binary, keeping read and write operations separate for better efficiency. To handle multi-bit inputs, it splits them into single bits (a process called bit-slicing) and combines them using a charge-sharing binary weighted accumulator—a circuit where electrical charge flows between weighted components to add values more efficiently than traditional circuits. A reading technique called Read WWL Under Drive lowers the electrical current during reading, which reduces current variation and noise.

## Key Novelty
The key innovation is sharing reference signals across a reconfigurable in-memory converter (ADC), which reduces area overhead by 9 times while achieving 1146 trillion operations per watt.

## Contributions
1. Reconfigurable in-memory ADC with shared references reducing area overhead by 9x (3% vs traditional)
2. Charge-sharing binary weighted accumulator (CHA) for low-latency multi-bit handling
3. Bit-slicing approach improving throughput by 1.9x and linearity by 23x vs pulse-width modulation
4. 1146 TOPS/W and 27 TOPS/mm^2 energy and area efficiency with <1% accuracy loss on vision/graph tasks
