# FastTree: Optimizing Attention Computation for Tree-Structured LLM Inference

**ID:** mlsys-2025-034 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM serving with radix-tree KV cache sharing runs separate GEMV attention per query even when many queries share a large common prefix, failing to exploit tree structure for hardware-efficient GEMM.

## Method
The algorithm uses a greedy approach to partition the KV-cache radix tree (a tree structure representing shared prefixes in the cache) into two groups: shared context and query-specific parts. A specialized attention kernel based on FlashAttention processes the shared context once and reuses it across all queries in a group by processing them together. This transforms slow individual matrix-vector operations (GEMV) into a single fast batched matrix-matrix operation (GEMM) that hardware can efficiently execute.

## Key Novelty
The algorithm greedily assigns edges in the KV-cache tree to identify query groups that can share computation, converting slow per-query matrix-vector operations into fast batched matrix-matrix operations.

## Metrics
- **Speedup:** 2.2x system throughput over SGLang+FlashInfer; kernel: 5.1x over FlashAttention, 4.2x over FlashInfer, 10.6x over DeFT (H100)

## Baselines
FlashAttention, FlashInfer, DeFT, CascadeAttn, SGLang
