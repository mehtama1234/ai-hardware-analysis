# SC-2025-184: MPI Communication Performance on AMD MI300A

**Venue:** SC 2025  
**Authors:** Goutham Kalikrishna Reddy Kuncham, Siyuan Zhang, Shoaib Mohammad, Chen-Chun Chen, Dhabaleswar K. Panda  
**Confidence:** low (abstract only)

## Summary

Comprehensive characterization of MPI library performance on AMD MI300A APUs, analyzing point-to-point communication, collectives, and application-level performance across multiple MPI implementations.

## Hardware Target

- AMD MI300A APU
- CPU and GPU chiplets with shared HBM3
- Integrated memory hierarchy

## Problem & Motivation

AMD MI300A removes traditional host-device boundary by integrating CPU and GPU chiplets around shared HBM3. This novel architecture invalidates existing assumptions about GPU-aware MPI. Early deployments lack performance guidance for MPI optimization.

## Approach

1. Comparative study: MVAPICH-Plus, Open MPI, MPICH, Cray MPICH
2. Microbenchmark analysis:
   - Point-to-point performance on CPU and GPU buffers
   - Intra-node and internode latency/bandwidth
   - Various message sizes
3. Collective operations evaluation:
   - Reduction-based operations
   - Data-movement operations
   - Scaling behavior
4. Application validation:
   - OpenFOAM (CFD)
   - LLM distributed training with PyTorch

## Key Contributions

1. First comprehensive MPI characterization on MI300A
2. Performance guidance for MI300A-aware optimizations
3. Identification of MPI bottlenecks on APU architecture
4. Practical recommendations for library implementations
5. Application-level validation

## Limitations

Specific performance metrics not provided in abstract; detailed bottleneck analysis limited.
