# SC-2025-194: Fast Linear Solvers via AI-Tuned MCMC

**Venue:** SC 2025  
**Authors:** Anton Lebedev, Won Kyung Lee, Soumyadip Ghosh, Olha Ivanyshyn Yaman, Vassilis Kalantzis, Yingdong Lu, Tomasz Nowicki, Shashanka Ubaru  
**Confidence:** low (abstract only)

## Summary

AI-driven framework using graph neural surrogate models and Bayesian optimization to automatically tune MCMC-based preconditioners for fast convergence of ill-conditioned linear systems.

## Hardware Target

- GPUs
- Multi-GPU systems

## Problem & Motivation

Large sparse linear systems pervasive in science/engineering. Krylov subspace solvers are standard but converge slowly for ill-conditioned matrices. MCMC-based preconditioners can accelerate convergence, but parameter optimization requires costly manual tuning or grid search.

## Approach

AI-driven parameter optimization framework:

1. **Graph Neural Surrogate:** Predicts preconditioning speed from matrix A and MCMC parameters
2. **Bayesian Acquisition Function:** Selects parameter sets most likely to minimize iterations
3. **Parameter Tuning:** Intelligently explores parameter space instead of grid search
4. **Integration:** Seamless integration with Krylov solvers

## Key Contributions

1. Graph neural network surrogate for MCMC performance prediction
2. Bayesian optimization framework for parameter selection
3. 50% reduction in search budget vs. conventional methods
4. 10% reduction in convergence iterations
5. Practical framework integrating AI with numerical solvers
6. Route for MCMC adoption in large-scale systems

## Limitations

Specific Krylov method not specified; scalability to extremely ill-conditioned systems unclear; comparison with other surrogate models limited.
