# micro-2025-091: A Probabilistic Perspective on Tiling Sparse Tensor Algebra

**Venue:** MICRO 2025

**Confidence:** low (title/abstract only — abstract body was unavailable)

## Problem
Tiling sparse tensor algebra for cache efficiency is difficult because effective tile size and cache behavior depend on sparse data distribution, which varies across inputs and is unknown at compile time.

## Motivation
Sparse tensor operations underlie graph analytics, scientific computing, and ML workloads; poor tiling decisions cause cache thrashing and memory bandwidth bottlenecks.

## Method
When doing math with sparse tensors (large arrays where most values are zero), you organize the computation into smaller blocks called 'tiles' that fit in the computer's fast memory (cache). The best tile size depends on where the non-zero values are scattered, which varies for each input and isn't known when the code is written. This paper uses probability and statistics—building a model of typical sparsity patterns—to predict how the cache will perform with different tile sizes, then automatically selects the best one.

## Key Novelty
Using statistical models of sparsity patterns to predict cache behavior and automatically select the best tile size.

## Contributions
1. Probabilistic model for cache behavior of sparse tensor algebra under varying sparsity patterns
2. Tiling strategy guided by sparsity probability models rather than static heuristics
