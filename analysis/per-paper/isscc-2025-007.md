# isscc-2025-007: kNOTs – Network-on-Textiles for Wearables

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
E-textile wearables need miniaturized, flexible SoCs with seamless fabric integration, heterogeneous sensing/compute, and distributed memory—prior work requires bulk form factors, high cost, or 1D networks.

## Approach
**kNOT** (network-on-textiles) integrates two chiplets directly into braided composite yarns:
1. **SoC (0.6×2.15mm²):** reconfigurable pads, fault-tolerant bootup, clock sync, dynamic network config
2. **bySPI chiplet:** 3-wire multi-receiver connectivity enhancement of bypass-SPI

Direct die-to-yarn solder interconnection via laser ablation; distributed memory replaces bulky monolithic blocks.

## Key Contribution
Direct die-to-yarn attachment + bySPI-enhanced networking enables board/interposer-free textile integration of multi-chip distributed systems.

## Performance
- SoC: 0.6×2.15 mm² (ultra-miniaturized)
- Interconnect: 3-wire bySPI
- Packaging: Direct solder integration with laser-selective ablation
