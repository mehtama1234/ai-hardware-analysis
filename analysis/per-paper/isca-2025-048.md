# TRACI: Network Acceleration of Input-Dynamic Communication for Large-Scale Deep Learning Recommendation Model

**ID:** isca-2025-048
**Venue:** ISCA
**Confidence:** low

## Problem
Multi-GPU DLRM training is bottlenecked by embedding layer communication: the Aggregation collective (sparse, input-dependent gather/reduce across GPUs) cannot be accelerated by existing in-network compute solutions designed for All-Reduce because its data transfer patterns are dynamic and depend on input batch content, not topology.

## Motivation
DLRM embedding tables are terabyte-scale and require high memory bandwidth; multi-GPU scaling is necessary but Aggregation communication becomes the binding bottleneck as All-Reduce solutions do not apply to input-dynamic sparse patterns.

## Method
TRACI introduces an in-network acceleration architecture with a novel network transaction design that augments messages with input reuse and output reuse identifications, allowing the network switch hardware to proactively identify and exploit message connections on-the-fly. New switch hardware dynamically discovers reuse relationships between embedding lookup requests arriving from different GPUs and performs in-network aggregation or deduplication rather than routing all data to a host.

## Key Novelty
Network transactions with embedded input-reuse and output-reuse identifiers that enable smart switch hardware to perform on-the-fly aggregation of input-dynamic, sparse DLRM embedding communication.

## Contributions
1. Analysis of Aggregation as a distinct communication bottleneck in multi-GPU DLRM that existing in-network solutions cannot address.
2. Novel network transaction type augmenting messages with reuse identifiers to expose embedding lookup sharing to the network.
3. Custom switch hardware design that discovers and exploits message connections dynamically for in-network Aggregation.
4. Demonstrated network communication reduction for multi-GPU DLRM training.
