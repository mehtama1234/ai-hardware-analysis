# Buffer Prospector: Discovering and Exploiting Untapped Buffer Resources in Many-Core DNN Accelerators

**Venue:** DAC  
**ID:** dac-2025-353

## Problem
Layer-pipeline mapping on many-core DNN accelerators exhibits significant buffer underutilization across cores due to timing mismatches, wasting performance potential.

## Motivation
Many-core DNN accelerators with LP mapping are mainstream, but buffer underutilization represents universal optimization opportunity overlooked by existing frameworks.

## Key Innovation
Universal buffer allocation strategy exploiting unused on-chip buffer space through dynamic redistribution and timing-aware allocation.

## Method
BufferProspector first calculates how much memory each core needs at each stage of the pipeline. Then it redistributes the unused memory sitting idle in some cores to the cores that need it more, timing everything so the memory is available when each stage runs. This solves the fundamental problem of buffer space going to waste because pipeline stages don't all need their memory at the same time.

## Contributions
- Identification of widespread buffer underutilization in LP mapping
- Buffer Requirement Calculator for per-core analysis
- Timing-aware Buffer Allocator for dynamic redistribution
- 1.44x energy efficiency, 2.26x performance improvement vs Tangram

## Results
1.44x energy efficiency improvement, 2.26x performance improvement vs SOTA.
