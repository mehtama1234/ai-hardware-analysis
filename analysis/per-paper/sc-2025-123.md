# RESILIO : A Scalable and Composable Architecture for Tomographic Reconstruction Workflows

**Venue:** SC
**ID:** sc-2025-123
**Confidence:** low

## Problem
Tomographic reconstruction pipelines struggle with high-volume data, low latency requirements, fault tolerance, and scalability in scientific facilities.

## Motivation
Advanced synchrotrons (e.g., upgraded APS) enable unprecedented data rates, but traditional batch workflows cannot keep up.

## Method
RESILIO: composable, high-performance framework built on Mochi ecosystem using Mofka for persistent streaming and resilience.

## Key Novelty
High-performance composable architecture for tomographic reconstruction with streaming resilience

## Contributions
1. Composable TR pipeline architecture
2. Persistent streaming via Mofka
3. 3490x reduction in per-event overhead vs ZeroMQ
4. 3268x throughput improvement
