# RESILIO : A Scalable and Composable Architecture for Tomographic Reconstruction Workflows

**Venue:** SC
**ID:** sc-2025-123
**Confidence:** low

## Problem
Tomographic reconstruction pipelines struggle with high-volume data, low latency requirements, fault tolerance, and scalability in scientific facilities.

## Motivation
Advanced synchrotrons (e.g., upgraded APS) enable unprecedented data rates, but traditional batch workflows cannot keep up.

## Method
RESILIO builds tomographic reconstruction (assembling a 3D image from many 2D slices taken at different angles) as a pipeline of independent, pluggable components using Mofka (a persistent data streaming system from the Mochi middleware). Because data flows through the pipeline continuously as it arrives rather than waiting to batch, latency stays low. The persistent streaming (data recorded at each step) lets the system recover from failures by restarting at the last checkpoint rather than from the beginning.

## Key Novelty
RESILIO treats tomographic reconstruction as a composable pipeline of components that continuously stream and persist data, enabling automatic failure recovery without reprocessing.
