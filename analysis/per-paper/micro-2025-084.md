# micro-2025-084: Symbiotic Task Scheduling and Data Prefetching

**Venue:** MICRO 2025  
**Authors:** Gilead Posluns, Mark C. Jeffrey  
**Confidence:** low (abstract only)

## Problem
Hardware task-parallel systems with fine-grained tasks (~100-cycle execution) cannot benefit from conventional hardware prefetchers because tasks complete before prefetches finish, leaving DRAM latency fully exposed and limiting performance on memory-intensive irregular workloads.

## Motivation
Many-core hardware task-parallel systems (100s of cores) already provide 3-60x speedup over software, but DRAM latency exposure due to ultra-short tasks is the remaining bottleneck; no existing prefetcher is aware of task-function memory patterns or the upcoming dispatch schedule.

## Method
The Task-Seeded Prefetcher (TSP) learns the data-access pattern of each task function type and issues prefetches as soon as a task descriptor is queued by the hardware scheduler, using the descriptor as a seed to identify future memory accesses. The Memory Response Task Scheduler (MRS) augments task-to-core dispatch by monitoring TSP prefetch completion status and preferentially dispatching tasks whose data has already been prefetched. Together, TSP seeds prefetching from scheduling events, and MRS uses prefetch readiness to refine scheduling decisions.

## Key Novelty
A symbiotic co-design of a function-aware task-seeded prefetcher (TSP) and a prefetch-status-aware task scheduler (MRS) that exploit the task descriptor queue as an early prefetch trigger in hardware task-parallel systems.

## Contributions
1. TSP: learns and prefetches per-task-function data patterns seeded from task descriptors before dispatch
2. MRS: uses TSP prefetch status to optimize core dispatch decisions
3. Up to 3.1x speedup (geometric mean up to 1.4x) across 13 benchmarks on 256-core task-parallel systems
4. Additive benefit on systems already 3-60x faster than parallel software
