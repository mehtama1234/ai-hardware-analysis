# Adapting Scientific Streaming Inference Workflows for a Deterministic Tensor Processing Unit

**Venue:** SC | **ID:** sc-2025-106

## Summary
Hybrid edge computing architecture for real-time X-ray ptychography inference, streaming high-speed detector data to Groq deterministic TPU for microsecond-latency image processing.

## Problem & Motivation
X-ray detector facilities face tight latency requirements for experimental-in-the-loop computing. Traditional approaches limited by: (1) long ASIC development cycles, (2) insufficient computational capacity of near-detector FPGAs. Need for deterministic, low-latency inference at the edge to enable real-time scientific decision-making.

## Key Findings
- **Latency:** 156.06 μs for 128×128 image inference (including data transfer)
- **Throughput:** 6.4 kHz processing capability
- **Performance:** 3.6× speedup vs. previous systems (edgePtychoNN model)
- Deterministic execution enables predictable real-time behavior

## Hardware & Systems
- **Accelerator:** Groq AI deterministic tensor processing unit
- **Target:** X-ray ptychography beamlines (photon science)
- **Deployment:** Edge computing at detector assembly
- **Data flow:** Detector → TPU → experimental control loop

## Techniques
- Streaming data architecture for low-latency inference
- Deterministic TPU execution ensuring timing predictability
- Integration with photon science data acquisition pipeline

## Metrics
| Metric | Value |
|--------|-------|
| Single inference latency | 156.06 μs |

## Contributions
1. First TPU-based streaming inference system for X-ray imaging
2. Demonstrated microsecond-latency inference for scientific experimentation
3. Enabled experimental-in-the-loop control in photon science
4. Showed viability of deterministic accelerators for edge science workflows

## Limitations
- Evaluation limited to single detector modality (X-ray ptychography)
- Groq accelerator availability/accessibility concerns
- Scalability to larger image sizes not demonstrated
- Model specificity (edgePtychoNN) limits generalizability
