# HyCache: Hybrid Caching for Accelerating DNN Input Preprocessing Pipelines

**Problem:** DNN input preprocessing incurs significant memory latency due to poor cache utilization and inefficient data access patterns across the memory hierarchy. Cache misses during data loading and transformation stages bottleneck overall pipeline throughput.

**Method:** HyCache speeds up DNN input preprocessing (the data-loading stage in AI models) by coordinating fast-memory caches on both the CPU and GPU. The system tracks which data is used repeatedly and keeps it in the fastest available storage, avoiding slow main-memory delays. It also predicts which data will be needed next and loads it ahead of time (prefetching), continuously adjusting its storage strategy based on the actual data access patterns it observes.

**Novelty:** Coordinating CPU and GPU fast-memory caches as one integrated system for the data-preparation stage of AI models, rather than treating them separately.
