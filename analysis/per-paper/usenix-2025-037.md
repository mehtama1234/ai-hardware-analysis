# HyCache: Hybrid Caching for Accelerating DNN Input Preprocessing Pipelines

**Problem:** DNN input preprocessing incurs significant memory latency due to poor cache utilization and inefficient data access patterns across the memory hierarchy. Cache misses during data loading and transformation stages bottleneck overall pipeline throughput.

**Method:** HyCache proposes a hybrid caching strategy that coordinates CPU and GPU memory hierarchies to optimize data reuse during preprocessing. The system employs intelligent prefetching and adaptive cache scheduling to reduce memory access latency and improve data locality. Cache management is tuned specifically for preprocessing access patterns.

**Novelty:** A hybrid caching architecture that jointly optimizes multiple cache levels across CPU-GPU systems for DNN preprocessing workloads.
