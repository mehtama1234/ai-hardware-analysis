# Comprehensive Placement and Routing Framework with Guaranteed In-Cell Routability for Synthesizing Complementary-FET Cells

**ID**: dac-2025-437  
**Venue**: DAC  
**Confidence**: low

## Problem
CFET cell layout synthesis faces extreme routing resource scarcity due to vertical transistor stacking; existing generators struggle with in-cell routability and produce suboptimal or infeasible layouts.

## Motivation
CFET is a critical technology scaling path beyond 5nm; enabling efficient cell generation accelerates technology adoption.

## Method
The approach works in three stages: first, it breaks transistors into smaller groups while keeping solution quality high, making the problem easier to solve; second, it places transistors using an SMT solver (a constraint-solving tool) that simultaneously checks whether connections can actually be routed, catching routing conflicts before they become expensive to fix; third, it routes the metal connections layer by layer—the bottom layer follows manual routing practices, while upper layers use integer linear programming (mathematical optimization) to handle the vertical stacking's unidirectional routing constraints.

## Key Novelty
The key advance is doing routability checks (verifying whether metal connections can fit) while placing transistors using a constraint solver, rather than after placement, which prevents layouts from becoming unroutable.

## Contributions
- Partitioning strategy for large-scale CFET cells
- SMT-based placement with embedded routability constraints
- Progressive multi-layer routing with ILP optimization
- Achieves smallest cell width and reduced metal usage vs SOTA generators
