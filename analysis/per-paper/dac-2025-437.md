# Comprehensive Placement and Routing Framework with Guaranteed In-Cell Routability for Synthesizing Complementary-FET Cells

**ID**: dac-2025-437  
**Venue**: DAC  
**Confidence**: low

## Problem
CFET cell layout synthesis faces extreme routing resource scarcity due to vertical transistor stacking; existing generators struggle with in-cell routability and produce suboptimal or infeasible layouts.

## Motivation
CFET is a critical technology scaling path beyond 5nm; enabling efficient cell generation accelerates technology adoption.

## Method
Three-stage approach: (1) partitioning + quality maintenance for scalability, (2) SMT-based placement with partial routing integration to determine pin positions and ensure routability, (3) progressive metal routing using manual-inspired M0 + ILP-based M1/M2 layers to handle unidirectional constraints.

## Key Novelty
SMT solver integration with partial routing during placement to guarantee in-cell routability, eliminating post-placement routing failures.

## Contributions
- Partitioning strategy for large-scale CFET cells
- SMT-based placement with embedded routability constraints
- Progressive multi-layer routing with ILP optimization
- Achieves smallest cell width and reduced metal usage vs SOTA generators
