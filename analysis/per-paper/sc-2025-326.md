# GPU Programming for AI Workflow Development on AWS SageMaker: An Instructional Approach

**Venue:** SC
**ID:** sc-2025-326
**Confidence:** low

## Problem Statement
GPU programming education and practical experience with cloud platforms is limited; students need hands-on exposure to GPU architecture and AI agent development on realistic infrastructure.

## Motivation
AI and GPU computing are increasingly central to STEM; experiential cloud-based GPU education strengthens problem-solving skills and industry readiness.

## Method
Specialized course (Fall 2024-Spring 2025): GPU architecture fundamentals → GPU programming → RAG and AI agent development on AWS SageMaker. Evaluated via assessments, course surveys, TensorBoard/HPC profilers.

## Key Novelty
Comprehensive GPU+cloud pedagogical model integrating hardware concepts, parallel programming, and practical AI agent deployment.

## Contributions
1. GPU+cloud curriculum for undergraduate/graduate students
2. Evidence that AWS SageMaker is economical platform for education
3. Experiential learning improves technical proficiency and critical thinking
