# 77GHz Hybrid TDMA-MIMO Phased-Array Radar

**Venue:** ISSCC  
**ID:** isscc-2025-241

## Problem
Current MIMO and phased-array radars cannot simultaneously achieve optimal performance across long-range (LRR), medium-range (MRR), and short-range (SRR) modes with unified hardware.

## Solution
Fully integrated 77GHz 8TX/2×4RX hybrid TDMA-MIMO phased-array FMCW radar using different chirp profiles to dynamically support all three detection modes from a single design.

## Key Innovation
Hybrid TDMA-MIMO enabling LRR/MRR/SRR modes from unified architecture via adaptive chirp profiling.

## Results
- **Detection range:** 186m
- **Range resolution:** 3cm
- **Supported modes:** LRR, MRR, SRR simultaneously

## Hardware Target
ASIC, SoC

## Techniques
Circuit design, signal processing
