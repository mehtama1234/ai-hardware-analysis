# Enabling Unstructured Sparse Fine-Tuning and Inference for Foundation Models on Wafer-Scale Engine

**Paper ID:** sc-2025-430
**Venue:** SC
**Authors:** Haoyu Zheng, Yifan Zeng, Linghao Song, Murali Emani, Wenqian Dong

## Problem

Foundation models fine-tuned on dense weights don't benefit from sparse pre-training; dense fine-tuning negates sparsity savings, requiring full-precision inference despite underlying sparse structure.

## Motivation

Downstream task adaptation (fine-tuning) on sparse pre-trained models should preserve sparsity to reduce inference cost; Cerebras wafer-scale engine efficiently handles unstructured sparsity.

## Method

Phoenix works by keeping the original sparse pre-trained weights (with many zeros placed strategically) and adding small task-specific layers called low-rank adapters on top during fine-tuning. Instead of retraining all the original weights and filling in the zeros, only these small adapters are updated, which preserves the sparsity pattern throughout. The approach takes advantage of Cerebras CS-2 hardware, which efficiently handles unstructured sparsity—weights that can be zero in any irregular pattern, not just regular grids—to make inference fast without computing through the zero values.

## Key Novelty

This is the first method to maintain weight sparsity during fine-tuning by combining sparse pre-trained weights with low-rank adapters, enabling 50–60% sparsity on Cerebras without accuracy loss.

## Contributions

- Sparse weight + low-rank adapter merging for sparsity-preserving fine-tuning
- Demonstrated unstructured sparse inference on Cerebras CS-2
- Near 2× FLOP reduction at 50–60% sparsity with maintained accuracy
- 1.7× inference throughput improvement vs A100 GPU
