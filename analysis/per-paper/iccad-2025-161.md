# 3D-MoE - 3D Stacked Near-DRAM Architecture for MoE LLM with Hybrid Parallelism

3D-MoE presents a 3D-stacked memory architecture that places Mixture of Experts computation adjacent to DRAM, enabling efficient MoE LLM inference through hybrid data-model parallelism. By eliminating the bandwidth bottleneck between memory and computation inherent in flat architectures, the system achieves 143.10× speedup over conventional GPU implementations. The architecture distributes experts and data strategically across the 3D stack to maximize throughput and minimize latency, demonstrating the potential of integrated memory-compute designs for transformer-scale workloads.
