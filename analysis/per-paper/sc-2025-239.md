# CAMEO: A Co-design Architecture for Multi-objective Energy System Optimization

**ID:** sc-2025-239

## Motivation

Complex interdependent optimization problems need flexible, scalable workflow framework

## Approach

CAMEO: DAG-based modular workflow framework; JSON specs; containerized components; Nextflow orchestration

## Key Novelty
