# The MALL is Open: Exploring Shared Caches and Latency in AMD CDNA 3 GPUs

**Paper ID:** sc-2025-352
**Venue:** SC
**Confidence:** low

## Problem Statement
Memory hierarchy characteristics of AMD CDNA 3 GPUs are not fully understood, hindering optimization

## Motivation
GPU applications need detailed latency profiles across cache hierarchy to optimize memory access patterns

## Method
Fine-grained pointer-chasing microbenchmarks characterizing sL1, L2, MALL (Infinity Cache), and HBM latencies across configurations

## Key Novelty
Detailed latency characterization of AMD MALL (Memory Attached Last Level cache) and NUMA effects on CDNA 3 GPUs

## Contributions
- Memory latency profiles for MI300A, MI300X, MI250X
- MALL contention and TLB behavior analysis
- 1.42x latency improvement via NPS4 NUMA partitioning

## Hardware Targets
- AMD Instinct MI300A
- AMD Instinct MI300X
- AMD Instinct MI250X

## Technique Categories
