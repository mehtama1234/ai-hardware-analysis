# The MALL is Open: Exploring Shared Caches and Latency in AMD CDNA 3 GPUs

**Paper ID:** sc-2025-352
**Venue:** SC
**Confidence:** low

## Problem Statement
Memory hierarchy characteristics of AMD CDNA 3 GPUs are not fully understood, hindering optimization

## Motivation
GPU applications need detailed latency profiles across cache hierarchy to optimize memory access patterns

## Method
They used pointer-chasing microbenchmarks—small focused tests where each memory access points to the next location, forcing the system to wait rather than parallelize requests—to measure data-retrieval speed from each GPU memory layer: sL1, L2, MALL (Infinity Cache), and HBM. They tested different configurations to understand how memory performance varies.

## Key Novelty
It characterizes memory access latency in AMD CDNA 3 GPUs, focusing on the MALL (Memory Attached Last Level cache) and revealing how NUMA effects—the variation in access speed based on data location—influence performance.

## Contributions
- Memory latency profiles for MI300A, MI300X, MI250X
- MALL contention and TLB behavior analysis
- 1.42x latency improvement via NPS4 NUMA partitioning
