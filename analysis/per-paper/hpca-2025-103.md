# hpca-2025-103 — I-DGNN: A Graph Dissimilarity-based Framework for Designing Scalable and Efficient DGNN Accelerators

**Venue:** HPCA  
**Authors:** Jiaqi Yang, Hao Zheng, Ahmed Louri  
**Confidence:** low (abstract only)

## Problem
DGNN execution routes each graph snapshot through the entire pipeline, generating excessive intermediate data and off-chip memory access even when consecutive snapshots differ minimally.

## Motivation
DGNNs are increasingly applied to time-evolving graph data, but existing accelerators fail to exploit inter-snapshot similarity, causing redundant computation and data movement that limits throughput and energy efficiency.

## Method
I-DGNN formulates inter-snapshot computation as a standalone chained matrix multiplication kernel derived from rigorous mathematical reformulation, decoupled from the full DGNN pipeline. A unified dynamically reconfigurable accelerator supports this computing model with improved data and pipeline parallelism. A tailored dataflow and mapping improves inter-kernel data locality across the DGNN pipeline.

## Key Novelty
Reformulating inter-snapshot DGNN computation as a standalone chained matrix multiplication kernel eliminates routing evolving graph data through the entire DGNN pipeline, cutting both compute redundancy and off-chip data movement.

## Contributions
- Theoretical one-pass DGNN computing model expressing inter-snapshot updates as chained matrix multiplication
- Unified dynamically reconfigurable accelerator with improved data and pipeline parallelism
- New dataflow and mapping for inter-kernel data locality
- 65.9-71.1% execution time reduction and 85.9-88.4% energy efficiency improvement vs. state-of-the-art DGNN accelerators

## Metrics
- **Speedup:** 65.9%, 71.1%, 58.8% execution time reduction vs. three SOTA DGNN accelerators
- **Energy:** 88.4%, 87.0%, 85.9% energy efficiency improvement
