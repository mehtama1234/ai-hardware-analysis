# hpca-2025-103 — I-DGNN: A Graph Dissimilarity-based Framework for Designing Scalable and Efficient DGNN Accelerators

**Venue:** HPCA  
**Authors:** Jiaqi Yang, Hao Zheng, Ahmed Louri  
**Confidence:** low (abstract only)

## Problem
DGNN execution routes each graph snapshot through the entire pipeline, generating excessive intermediate data and off-chip memory access even when consecutive snapshots differ minimally.

## Motivation
DGNNs are increasingly applied to time-evolving graph data, but existing accelerators fail to exploit inter-snapshot similarity, causing redundant computation and data movement that limits throughput and energy efficiency.

## Method
I-DGNN avoids reprocessing unchanged parts of the graph by recognizing that the differences between consecutive snapshots can be expressed as chained matrix multiplications (repeated sequences of matrix operations), which can be computed independently rather than routing the entire updated graph through the full neural network pipeline. The system uses a unified accelerator architecture that flexibly reconfigures itself to handle both this independent computation and the main pipeline stages. The dataflow is optimized so data stays locally available rather than moving repeatedly to off-chip memory. Together, these changes reduce the redundant computation and data movement that normally accumulate when processing sequences of similar graphs.

## Key Novelty
The core insight is that differences between consecutive graph snapshots can be expressed as independent chained matrix multiplications (repeated matrix operations), eliminating the need to route data through the entire neural network pipeline and thus cutting both computational redundancy and expensive memory transfers.

## Contributions
- Theoretical one-pass DGNN computing model expressing inter-snapshot updates as chained matrix multiplication
- Unified dynamically reconfigurable accelerator with improved data and pipeline parallelism
- New dataflow and mapping for inter-kernel data locality
- 65.9-71.1% execution time reduction and 85.9-88.4% energy efficiency improvement vs. state-of-the-art DGNN accelerators

## Metrics
- **Speedup:** 65.9%, 71.1%, 58.8% execution time reduction vs. three SOTA DGNN accelerators
- **Energy:** 88.4%, 87.0%, 85.9% energy efficiency improvement
