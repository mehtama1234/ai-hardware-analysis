# Fast Distributed Transactions for RDMA-based Disaggregated Memory

**Problem:** Distributed transaction protocols must maintain consistency and coordinate across disaggregated memory nodes accessed via RDMA, facing challenges from network latency and coordination overhead. Traditional transaction designs incur significant latency when operating on remotely accessed memory.

**Method:** The system uses RDMA (Remote Direct Memory Access), which lets computers directly read and write each other's memory without CPU involvement, to minimize transaction coordination overhead. Instead of locking data to prevent conflicts, it relies on optimistic concurrency control (checking whether data changed after reading rather than preventing changes upfront) paired with RDMA atomic operations—actions that either fully complete or have no effect. By using RDMA's one-sided operations, where the remote computer doesn't need to respond or participate, most transaction work completes in a single message round-trip instead of requiring back-and-forth coordination steps.

**Novelty:** The core idea is replacing traditional request-response coordination with RDMA's one-sided operations, so distributed transactions can commit across multiple computers in fewer network round-trips.
