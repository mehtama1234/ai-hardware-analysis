# Fast Distributed Transactions for RDMA-based Disaggregated Memory

**Problem:** Distributed transaction protocols must maintain consistency and coordinate across disaggregated memory nodes accessed via RDMA, facing challenges from network latency and coordination overhead. Traditional transaction designs incur significant latency when operating on remotely accessed memory.

**Method:** Optimizes transaction protocols to exploit RDMA hardware primitives, likely using one-sided RDMA operations to reduce coordination round-trips. Employs techniques such as lock-free or optimistic concurrency control tailored to RDMA semantics to minimize communication overhead. Leverages RDMA atomic operations and immediate data features for efficient distributed coordination.

**Novelty:** Designing distributed transaction protocols that exploit RDMA hardware capabilities to achieve low-latency coordination in disaggregated memory systems.
