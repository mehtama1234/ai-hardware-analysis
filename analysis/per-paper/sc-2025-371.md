# StreamHub: High-performance Managed SciStream as a Service

**ID**: sc-2025-371
**Venue**: SC
**Confidence**: low

## Problem
Real-time transfer and analysis of high-throughput scientific data to remote facilities

## Motivation
Scientific discovery requires real-time data transfer for adaptive experiments

## Method
StreamHub transfers scientific data securely by verifying each packet (zero-trust security—checking that nothing is tampered with or sent from an untrusted source) instead of trusting the network. It integrates Globus Compute, which runs analysis code on remote facilities, so data flows directly into computational pipelines at the destination. Encryption and cryptographic checks protect every packet during transit.

## Key Novelty
StreamHub is the first zero-trust streaming system—one that verifies every packet for security—with less than 2% performance overhead.
