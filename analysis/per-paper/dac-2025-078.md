# dac-2025-078: PairGraph: Search-space-aware Graph Accelerator

**Problem:** Concurrent pairwise graph queries suffer from irregular memory access and poor data sharing due to low locality.

**Method:** PairGraph recognizes that when you run multiple queries on a graph simultaneously, they often explore the same regions of the graph structure. It detects these overlapping search spaces (the parts of the graph that multiple queries traverse) and reuses the data across queries instead of fetching it separately each time. By sharing this common graph data, it reduces how much information needs to travel to and from off-chip memory, which is the primary bottleneck in these workloads.

**Key Novelty:** Leveraging strong similarity of concurrent query search spaces to maximize data reuse and minimize bandwidth.

**Hardware Target:** ASIC, GPU  
**Technique Category:** memory-system, cache, dataflow  
**Workloads:** graph-analytics  

**Metrics:**
- CPU speedup: 5.59-14.25x vs Gemini
- GPU speedup: 3.76-7.58x vs Gunrock
- Accelerator speedup: 1.67-4.28x vs LCCG/ScalaGraph/ReGraph

**Baselines:** Gemini, Gunrock, LCCG, ScalaGraph, ReGraph

**Confidence:** low (abstract only)
