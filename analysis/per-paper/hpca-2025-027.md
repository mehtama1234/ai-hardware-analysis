# hpca-2025-027: WarpDrive: GPU-Based Fully Homomorphic Encryption Acceleration Leveraging Tensor and CUDA Cores

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
GPU-based FHE acceleration is bottlenecked by pipeline stalls from memory-latency-bound NTT operations and suboptimal GPU hardware utilization, leaving both CUDA Cores and Tensor Cores underused.

## Motivation
FHE is increasingly important for privacy-preserving computation, but its multi-orders-of-magnitude overhead over plaintext computation demands practical GPU acceleration; existing solutions fail to fully exploit modern NVIDIA GPU parallelism.

## Method
WarpDrive applies: (1) computation decomposition of NTT reducing instruction count by 73%; (2) fine-grained memory access design eliminating 86% of pipeline stalls; (3) concurrent CUDA Core + Tensor Core execution within a single NTT kernel — the first such combined use. Intra-ciphertext parallelism is maximally extracted without ciphertext batching.

## Key Novelty
First framework to concurrently utilize CUDA Cores and Tensor Cores within the same NTT kernel for FHE, exceeding the throughput of either unit type alone.

## Contributions
- Computation decomposition reducing FHE NTT instruction count by 73%.
- Fine-grained memory access design cutting pipeline stalls by 86%.
- Concurrent CUDA Core + Tensor Core NTT kernel surpassing single-unit throughput.
- 13.4x NTT and 3.5x homomorphic multiplication speedup over TensorFHE on A100; 2.12x intra-ciphertext parallelism without batching.

## Metrics
- speedup: 13.4x NTT, 3.5x homomorphic multiplication, 2.8x FHE workload vs TensorFHE on A100
- other: 1218 KOPS NTT, 305 KOPS homomorphic multiplication; 73% instruction reduction; 86% stall reduction
