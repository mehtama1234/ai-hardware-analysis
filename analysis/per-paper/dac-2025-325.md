# Enabling Data-Deduplication-Assisted Data Relocation for Interlaced Magnetic Recording

## Problem
IMR hard drives suffer performance degradation from track rewrites when updating overlapped tracks.

## Solution
Uses deduplication reference counts to guide data relocation: deduplicated (static) data can be placed on overlapped tracks without triggering rewrites. Replaces frequency-based hot/cold separation.

## Impact
37.57% reduction in average accumulated read/write latency vs state-of-the-art IMR schemes.
