# isscc-2025-156: On-Device Generative AI NPU (Exynos 2400)

**Problem:** Generative AI workloads (LLMs, vision models) exhibit distinct compute characteristics: LLMs memory-intensive (GB weight streaming/token), vision models compute-intensive (softmax/layernorm = 40% vs. convolution = 90-99% in CNNs). Homogeneous tensor engines fail both.

**Motivation:** On-device AI is shifting CNN→transformer-based; single compute fabric cannot efficiently support both memory-bound and compute-bound patterns.

**Method:** The chip includes two specialized tensor engines: one optimized for language models that need to continuously read large weights from memory, another for vision models that require intensive matrix calculations. A multi-level memory system with on-chip storage and DRAM tiling efficiently caches weights to reduce repeated memory fetches. Fan-out wafer-level packaging improves heat dissipation for sustained high performance. Built at 4nm in Samsung's Exynos 2400, it supports traditional image processing (CNNs), language models (LLMs), and image generation models.

**Key Novelty:** Dual heterogeneous tensor engines optimized for LLM-memory and vision-compute workloads.

**Contributions:**
- First mobile NPU supporting on-device LLM inference
- Heterogeneous vector+dual-tensor design
- CNN/LLM/LVM support in single NPU
- FOWLP thermal management

**Hardware Target:** NPU, SoC

**Technique Categories:** dataflow, memory-system, packaging, parallelism

**Workloads:** LLM-inference, transformer, vision, CNN, diffusion

**Metrics:** 4nm process, heterogeneous architecture, FOWLP package

**Baselines:** CNN-optimized NPUs, cloud LLM inference, homogeneous tensors

**Confidence:** low (abstract-only)
