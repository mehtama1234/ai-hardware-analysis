# dac-2025-088: PracMHBench: Federated Learning on Edge Devices

**Problem:** Model-heterogeneous FL is practical but algorithms lack evaluation under realistic edge device constraints.

**Method:** PracMHBench platform evaluates model-heterogeneous FL algorithms under practical edge constraints, classifying algorithms and testing on multiple data tasks and resource scenarios.

**Key Novelty:** First comprehensive evaluation platform for model-heterogeneous FL under realistic edge device constraints.

**Hardware Target:** CPU, NPU  
**Technique Category:** virtualization, scheduling  
**Workloads:** LLM-training, ML-at-edge  

**Metrics:** Algorithm applicability patterns under edge constraints

**Confidence:** low (abstract only)
