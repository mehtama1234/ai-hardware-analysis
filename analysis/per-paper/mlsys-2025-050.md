# Context Parallelism for Scalable Million-Token Inference

**Venue:** MLSYS 2025

## One-line Problem
Long-context LLM prefill at 1M+ tokens exceeds single-GPU capacity; distributed ring-attention with load balancing is needed for near-linear scaling.

## Method
The system splits a massive input sequence across multiple GPUs instead of fitting it all on one. It uses two complementary ring strategies: pass-KV circulates Key/Value tensors (cached representations) across GPUs while each GPU keeps its own query block; pass-Q does the opposite, circulating queries while GPUs hold fixed Key/Value data. To keep all GPUs equally busy, each sequence is split into 2N chunks across N GPUs. The system automatically switches between pass-KV and pass-Q based on how often cached data must be fetched, optimizing for all three inference phases: prefill (encoding the input), persistent KV prefill (caching intermediate results), and decode (generating one token at a time).

## Novelty
Two complementary ring-attention algorithms with load-balanced sharding and adaptive mode selection, demonstrated on both RDMA and TCP interconnects with near-linear scaling to 128 GPUs.

## Key Metrics
- 1M-token prefill (Llama3 405B): **77 seconds** on 128 H100 GPUs
- 128K-token prefill: **3.8 seconds**
- Parallelization efficiency: **93%**; FLOPS utilization: **63%**
- Near-linear scaling from 1 to 128 GPUs on both RDMA and TCP
