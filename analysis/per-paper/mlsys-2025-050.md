# Context Parallelism for Scalable Million-Token Inference

**Venue:** MLSYS 2025

## One-line Problem
Long-context LLM prefill at 1M+ tokens exceeds single-GPU capacity; distributed ring-attention with load balancing is needed for near-linear scaling.

## Method
Context Parallelism (CP) partitions input tokens across GPUs along the sequence dimension. Two ring-attention variants: **pass-KV** (circulates K/V tensors, each GPU holds fixed Q) and **pass-Q** (circulates Q, each GPU holds fixed KV). A **2N-chunk load-balanced sharding** eliminates causal-mask work imbalance. Adaptive selection switches between modes based on KV-cache miss rate to cover full prefill, persistent KV prefill, and decode.

## Novelty
Two complementary ring-attention algorithms with load-balanced sharding and adaptive mode selection, demonstrated on both RDMA and TCP interconnects with near-linear scaling to 128 GPUs.

## Key Metrics
- 1M-token prefill (Llama3 405B): **77 seconds** on 128 H100 GPUs
- 128K-token prefill: **3.8 seconds**
- Parallelization efficiency: **93%**; FLOPS utilization: **63%**
- Near-linear scaling from 1 to 128 GPUs on both RDMA and TCP
