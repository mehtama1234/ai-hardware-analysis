# Dissecting and Modeling the Architecture of Modern GPU Cores

**Venue:** MICRO  
**Confidence:** high (full text)

## Problem
Academic GPU microarchitecture simulators such as Accel-sim rely on pipeline models derived from NVIDIA Tesla (2006), missing 15+ years of GPU core evolution including compiler-guided dependency management, the L0 instruction cache, register file cache, and updated issue logic in Ampere-class SMs. This causes simulation inaccuracy that misleads research conclusions.

## Motivation
GPU microarchitecture research requires accurate simulators; existing models diverge significantly from modern NVIDIA designs, producing flawed performance predictions for HPC and ML workloads.

## Method
The authors reverse-engineered NVIDIA Ampere GPU cores (RTX A6000) using hand-written test programs that measure exactly how many clock cycles each instruction takes. They discovered that dependency management—coordinating when instructions can safely run—is handled by the compiler inserting special control bits (Stall and Dependence counters) into instructions rather than using hardware scoreboards. They also found a compiler-guided warp scheduling policy, a two-bank register file without collector units, a 6-entry register file cache, an L0 instruction cache with a 16-entry prefetcher, and specific queue sizes and latencies in the memory pipeline. They rebuilt the Accel-sim simulator with all these findings and validated it against real hardware.

## Key Novelty
Reverse-engineering revealed that NVIDIA Ampere GPUs handle all instruction dependency management through compiler-inserted control bits (Stall and Dependence counters), eliminating traditional hardware scoreboards and collector units.

## Contributions
1. Full characterization of the CGGTY warp issue scheduler policy with readiness conditions and yield/stall control bits
2. Discovery that modern NVIDIA GPUs use software-managed Dependence counters instead of hardware scoreboards, saving area and energy
3. Characterization of the two-bank register file cache (RFC) organization and compiler-controlled allocation/reuse policy
4. Updated Accel-sim simulator achieving 13.98% MAPE on A6000 (18.24% improvement over prior state-of-the-art), with portability to Turing

## Limitations
Experiments cover only same-CTA warp interactions; cross-CTA scheduling behavior and multi-SM interactions are not characterized.
