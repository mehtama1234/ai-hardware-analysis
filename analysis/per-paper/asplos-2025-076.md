# Forecasting GPU Performance for Deep Learning Training and Inference

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Prior ML-based GPU performance predictors attempt direct end-to-end kernel latency prediction and suffer >100% error for unseen model-GPU pairs, making cross-GPU performance forecasting unreliable.

## Motivation
Limited access to new GPU hardware makes accurate performance prediction for new model-GPU combinations essential for architecture decisions, resource planning, and procurement.

## Method
NeuSight breaks down the task of predicting how long a deep-learning kernel (a single GPU operation) will take into smaller pieces called "tiles" that match the GPU's streaming multiprocessors—the parallel processing units it actually uses to execute work. A machine-learning model predicts the execution time for each tile, and these predictions are added together to estimate the total time. The predictions stay realistic by constraining them with fundamental performance limits (the roofline model, which describes the maximum speed possible given the hardware design) and by incorporating actual GPU specifications plus optimization tricks from libraries like cuDNN and cuBLAS. This approach works on new, unseen GPU models by learning their core hardware properties rather than encoding specific GPU identities, so it can predict performance without running code on the target hardware.

## Key Novelty
The core idea is decomposing deep-learning kernel predictions into tiles matching the GPU's execution units and constraining them with performance laws, which enables those predictions to generalize to new GPU models without requiring code execution.

## Contributions
- NeuSight: GPU performance forecasting for unseen model-GPU combinations
- Tile-level prediction decomposition bounded by roofline laws
- Hardware parameter + software library integration for cross-GPU generalization
- GPT-3 on H100 error: 121.4%/30.8% (SOTA) reduced to 2.3%
