# Forecasting GPU Performance for Deep Learning Training and Inference

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Prior ML-based GPU performance predictors attempt direct end-to-end kernel latency prediction and suffer >100% error for unseen model-GPU pairs, making cross-GPU performance forecasting unreliable.

## Motivation
Limited access to new GPU hardware makes accurate performance prediction for new model-GPU combinations essential for architecture decisions, resource planning, and procurement.

## Method
NeuSight decomposes each DL kernel into SM-level execution tiles; an ML model predicts tile-level latency, then aggregates across tiles to estimate end-to-end latency. Predictions are bounded by roofline performance laws. GPU hardware parameters and software library (cuDNN/cuBLAS) optimizations are incorporated to parameterize hardware, enabling generalization to unseen GPUs without running code on target hardware.

## Key Novelty
Tile-level decomposition of kernel latency prediction bounded by fundamental performance laws, enabling accurate cross-GPU generalization.

## Contributions
- NeuSight: GPU performance forecasting for unseen model-GPU combinations
- Tile-level prediction decomposition bounded by roofline laws
- Hardware parameter + software library integration for cross-GPU generalization
- GPT-3 on H100 error: 121.4%/30.8% (SOTA) reduced to 2.3%
