# Replay4NCL: Efficient Neuromorphic Continual Learning for Embedded AI

**Venue:** DAC | **ID:** dac-2025-255

## Problem
Neuromorphic continual learning with SNNs requires memory replay to prevent catastrophic forgetting, but current approaches suffer from high latency and energy overhead due to long timesteps and compression-decompression cycles—incompatible with embedded systems like mobile robots.

## Key Innovation
Replaying compressed latent data with reduced timesteps while dynamically adjusting neuron thresholds and learning rates to compensate for spike loss, achieving massive speedup and energy savings without sacrificing accuracy.

## Results
- **Accuracy:** 90.43% top-1 (vs. 86.22% baseline)
- **Speedup:** 4.88x latency reduction
- **Energy:** 36.43% savings
- **Memory:** 20% latent memory reduction

## Hardware Target
Neuromorphic / Edge AI systems

## Techniques
Near-data processing, quantization, circuit design

## Limitations
Evaluation only on SHD dataset; scalability to larger datasets unclear.
