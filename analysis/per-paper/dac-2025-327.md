# A Novel Covert Timing Channel for Cloud FPGAs

## Problem
Shared cloud FPGA infrastructure enables covert data exfiltration via side-channel attacks with minimal detection risk.

## Solution
Exploits AXI protocol handshake signals and Internet interpacket delay to establish covert timing channel from cloud FPGA to external attacker. Encodes data via timing modulation of AXI backpressure/valid-ready signals.

## Impact
Bit error rate of 0.01988%; enables practical remote power analysis attacks on AWS EC2.
