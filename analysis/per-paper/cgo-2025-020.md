# Accelerating LLMs using an Efficient GEMM Library and Target-Aware Optimizations on Real-World PIM Devices

**Venue:** CGO
**Confidence:** low

## Problem
LLM serving is memory-bottlenecked; GEMM operations dominate execution but are memory-intensive. Real PIM systems incur high host-to-PIM data transfer overhead that negates bandwidth benefits without careful optimization.

## Motivation
PIM offers high internal bandwidth but incomplete replacement of traditional memory; minimizing host-PIM transfer is critical for practical LLM acceleration.

## Method
The PIM-LLM framework optimizes matrix multiplication (the core LLM operation) on Processing-In-Memory hardware by dividing problems into smaller tiles (PGEMMlib) and using an analytical model (Tile-Selector) to automatically pick optimal tile sizes. Integrated into TVM (a compiler for hardware-specific code), it employs several techniques: pre-compilation data reorganization, combining PIM resources for efficiency, coordinating CPU-PIM work, and fusing attention steps (Q, K, V generation) to reduce host-PIM data transfer overhead.

## Key Novelty
The approach combines a matrix-multiplication tiling method optimized for PIM hardware (PGEMMlib) with an analytical model that automatically selects tile sizes (Tile-Selector), minimizing data transfers between host and PIM.

## Contributions
- PGEMMlib library with PIM-aware tiled GEMM and parallelism optimization
- Tile-Selector analytical model for parameter tuning across GEMM shapes
- TVM compiler integration with CPU/PIM cooperation and fusion optimizations
- Up to 45.75x speedup over TVM baseline on real PIM hardware
