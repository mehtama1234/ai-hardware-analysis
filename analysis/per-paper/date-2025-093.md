# Enabling a Portable Brain Computer Interface for Rehabilitation of Spinal Cord Injuries

**Venue**: DATE  
**Primary Theme**: power-efficient BCI systems  

## Problem
Deploying brain signal decoding algorithm for spinal stimulation to low-power portable battery-operated system. Current implementations too power-hungry for home use.

## Method
The researchers ported a brain-signal decoding algorithm (software that interprets electrical brain patterns for control commands) from high-power laboratory computers to a small battery-powered embedded device. They optimized the algorithm through techniques like streamlining calculations, using more efficient operations, and restructuring the code for lower-power hardware, achieving a 25-fold reduction in power consumption. Crucially, these optimizations preserved the algorithm's ability to process signals instantly in real time and maintain accuracy for spinal stimulation control.

## Key Novelty
The core innovation is that brain signal-decoding algorithms can be ported to battery-powered portable devices achieving 25-fold power reduction while preserving real-time responsiveness and accuracy.

## Contributions
- 25x power reduction vs previous implementation
- Maintained real-time decoding performance
- Preserved decoding accuracy
- Enabled portable battery-operated home deployment
