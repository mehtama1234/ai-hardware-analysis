# Enabling a Portable Brain Computer Interface for Rehabilitation of Spinal Cord Injuries

**Venue**: DATE  
**Primary Theme**: power-efficient BCI systems  

## Problem
Deploying brain signal decoding algorithm for spinal stimulation to low-power portable battery-operated system. Current implementations too power-hungry for home use.

## Method
Porting brain signal decoding algorithm from high-power implementation to low-power embedded platform while respecting real-time and accuracy constraints.

## Key Novelty
Efficient algorithm porting achieving 25x power reduction while maintaining real-time performance and decoding accuracy.

## Contributions
- 25x power reduction vs previous implementation
- Maintained real-time decoding performance
- Preserved decoding accuracy
- Enabled portable battery-operated home deployment
