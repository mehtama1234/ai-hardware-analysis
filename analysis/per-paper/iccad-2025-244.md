# Optimizing Neural Networks with Learnable Non-Linear Activation Functions via Lookup-Based FPGA Acceleration

**ID:** iccad-2025-244

## Problem
Kolmogorov-Arnold Networks (KANs) with learnable activation functions are computationally expensive on conventional hardware. Standard implementations lack energy efficiency for edge deployment.

## Motivation
Edge AI requires energy-efficient neural network acceleration; KANs offer potential accuracy improvements but need specialized hardware support.

## Method
The approach uses an FPGA (a programmable hardware chip) to accelerate KANs by replacing expensive mathematical calculations with fast lookup tables—pre-computed tables that instantly provide answers. To make lookup tables handle KANs' learnable non-linear activation functions (the mathematical transformations neurons apply, which change as the network learns), the design uses two techniques: quantization (representing numbers with fewer bits to save space and power) and adaptive lookup tables that adjust to match what each network learns. This achieves roughly 10,000 times better energy efficiency than running KANs on standard edge CPUs (processors in phones and IoT devices).

## Key Novelty
The innovation is replacing KANs' learnable non-linear activation functions with adaptive lookup tables implemented on FPGA hardware.
