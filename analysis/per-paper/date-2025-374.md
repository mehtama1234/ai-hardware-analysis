# Enabling Memory-Efficient On-Device Learning via Dataset Condensation

**Venue:** DATE | **ID:** date-2025-374

## Problem
Edge devices must learn from streaming, unlabeled, non-i.i.d. data without catastrophic forgetting, but buffer constraints force discarding most data, causing significant information loss.

## Motivation
On-device continual learning is limited by strict memory constraints; data selection strategies wastefully discard most incoming information.

## Approach
Pseudo-labeling + dataset condensation tailored for on-device scenarios + feature discrimination objective for label purity.

## Key Innovation
Pseudo-labeling and fast dataset condensation specifically for unlabeled streaming data without clean labels.

## Results
- 56.7% relative accuracy improvement on CORe50 with 1 sample/class buffer
- Condensation faster than prior methods

## Target Hardware
CPU (embedded/edge devices)

## Techniques
Approximation, sparsity (buffer reduction)

## Workload
CNN (image classification on CORe50)

**Low** (abstract-only analysis)
