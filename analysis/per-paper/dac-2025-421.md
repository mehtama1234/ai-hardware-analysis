# dac-2025-421: Cache Hierarchy Optimization for Multi-Chiplet Systems

**Problem:** Multi-chiplet systems have complex cache hierarchies spanning multiple dies; existing design space exploration methods fail to optimize cache subsystem performance.

**Motivation:** Post-Moore manufacturing requires chiplet-based integration, but optimizing cache hierarchies across dies with inter-chiplet interconnects remains a key bottleneck.

**Method:** Bilevel optimization jointly optimizes cache hierarchy and inter-chiplet interconnects by (1) modeling cache miss rates and network latency, then (2) iteratively solving cache and interconnect subproblems to minimize concurrent average memory access time (C-AMAT).

**Key Novelty:** First bilevel optimization for joint cache and multi-die interconnect co-design.

**Contributions:**
- C-AMAT formulation as functions of hierarchy and interconnect parameters
- Bilevel algorithm for scalable cache–interconnect co-optimization
- 39.7% speedup vs Zen 4; 39.2% vs Sapphire Rapids; 25.91% vs IntLP

**Baselines:** AMD Zen 4, Intel Sapphire Rapids, IntLP, NN-Baton

**Confidence:** low (abstract-only)
