# Synthesis of CFET Cell Library Leveraging Backside Metal Routing

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
CFET stacking reduces routing tracks and increases complexity; current cell synthesis cannot efficiently use backside metal resources or handle transistor folding.

## Method
The approach leverages metal routing on both the backside and frontside of the chip to pack transistors more efficiently. Euler path analysis, a graph-based optimization method, determines the minimum spacing between transistor gates (contacted poly pitch); dynamic programming then calculates the number of routing channels required on the frontside. A mathematical constraint solver finalizes exact transistor placement and routing.

## Key Novelty
This is the first cell-synthesis approach to combine backside metal routing with efficient transistor folding (arranging transistors in space-saving patterns), using Euler path analysis and dynamic programming.

## Results
- **1% CPP reduction**
- **45% M2 track reduction**
- **19% runtime reduction**
