# TB-STC: Transposable Block-wise N:M Structured Sparse Tensor Core

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing N:M structured sparsity for DNN accelerators causes significant accuracy degradation (e.g., >6% on OPT-6.7B and Llama2-7B at 50% sparsity) because one-dimensional structured sparsity patterns diverge far from the unstructured optimal. Hardware support for sparsity must simultaneously deliver high bandwidth utilization and computational efficiency.

## Motivation
Growing computational and memory demands of LLMs and CNNs require aggressive sparsity-based compression, but the accuracy-efficiency tradeoff of existing structured sparsity approaches is unacceptable for production deployment.

## Method
The paper introduces Transposable Block-wise Structured (TBS) sparsity, which exploits the transpose relationship between forward and backward pass weight matrices during training to find a 2D block sparsity pattern that more closely approximates unstructured sparsity. At the micro-architecture level, TB-STC implements a Transposable Block-wise N:M Sparse Tensor Core with an adaptive codec for on-the-fly storage format conversion supporting both row-wise and column-wise sparse access, and an I/O-aware configurable scheduler for sparsity-aware compute scheduling. This enables 1.47x bandwidth utilization and 1.57x computational utilization improvements.

## Key Novelty
Exploiting the transpose symmetry of forward/backward weight matrices to derive a 2D block-wise sparsity pattern that simultaneously maintains structured hardware efficiency and near-unstructured accuracy.

## Contributions
- Transposable Block-wise Structured (TBS) sparsity pattern achieving up to 2.58% accuracy improvement over prior structured sparsity at equal sparsity degree
- TB-STC tensor core with adaptive codec for on-the-fly storage format conversion (1.47x bandwidth utilization)
- I/O-aware configurable sparsity-aware scheduler improving computational utilization by 1.57x
- 3.82x average EDP improvement and improved accuracy-EDP Pareto frontier over existing structured sparse accelerators
