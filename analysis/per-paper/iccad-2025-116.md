# Refinement Strategies for Any-Angle Package Routing with I/O Alignment Consideration

**Venue:** ICCAD  
**Confidence:** low

## Problem
Traditional packaging routers support only 90- and 135-degree angles; advanced packaging with increased I/O demands requires any-angle routing to explore larger solution space and reduce wirelength, but I/O alignment constraints complicate routing.

## Motivation
Advanced packaging technologies demand higher I/O density; any-angle routing enables superior solutions, but existing methods lack optimization for I/O alignment constraints in die-to-substrate connections.

## Method
Framework introduces accurate routing resource utilization estimation in global routing stage, concurrent access point adjustment to reduce total wirelength across all nets simultaneously, and dynamic programming-based method minimizing wire segments per net.

## Key Novelty
Any-angle routing framework with two-stage wire-length optimization strategies considering I/O alignment constraints.

## Contributions
- Any-angle routing for die-to-substrate connections
- Routing resource utilization estimation
- Concurrent access point adjustment strategy
- Dynamic programming-based single-net optimization
