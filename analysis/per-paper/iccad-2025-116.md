# Refinement Strategies for Any-Angle Package Routing with I/O Alignment Consideration

**Venue:** ICCAD  
**Confidence:** low

## Problem
Traditional packaging routers support only 90- and 135-degree angles; advanced packaging with increased I/O demands requires any-angle routing to explore larger solution space and reduce wirelength, but I/O alignment constraints complicate routing.

## Motivation
Advanced packaging technologies demand higher I/O density; any-angle routing enables superior solutions, but existing methods lack optimization for I/O alignment constraints in die-to-substrate connections.

## Method
The framework predicts available routing space during the initial global routing phase to enable better early decisions. It then adjusts all connection points (where wires attach to circuit elements) simultaneously across every wire rather than optimizing one at a time, which reduces total wire length. Finally, for each individual wire, it uses dynamic programming (an algorithm that efficiently explores path options) to find the route with the fewest wire segments while respecting I/O alignment constraints.

## Key Novelty
It enables any-angle routing (wires can route in any direction, not just 90 or 135 degrees) through two-stage optimization of connection points across all wires, while satisfying I/O alignment constraints.
