# TCAD Based Study of String Current Variability in 3D NAND Flash Memory

**ID**: vlsid-2025-045 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
3D NAND flash memory experiences significant variability in string current due to process variations during etching, deposition, and lithography. As cell sizes shrink and densities increase, this variability threatens device performance and reliability.

## Motivation
Advanced 3D NAND technology promises superior scalability and cost-efficiency, but only with precise fabrication control. Uncontrolled process variation causes electrical parameter drift that can degrade memory functionality and reliability.

## Method
- **Approach**: TCAD simulations to model 3D NAND cell operation under various process conditions
- **Varied Parameters**: Cell spacing, tunneling oxide thickness, blocking oxide thickness, channel thickness, plug depth
- **Metrics Analyzed**: Ion (on-current), Vth (threshold voltage), Gm (transconductance), SS (subthreshold slope)

## Key Findings
Under worst-case 20% process variation across all dimensions:
- **Ion**: ~78% deviation (most sensitive)
- **Vth**: ~21% deviation
- **Gm**: ~38% deviation  
- **SS**: ~14% deviation (most robust)

Cell spacing emerged as the critical parameter, while plug depth showed negligible effect.

## Novelty & Contributions
1. Systematic TCAD-based quantification of process variation sensitivity in 3D NAND strings
2. Hierarchical identification of which parameters matter most (cell spacing >> others)
3. Empirical evidence supporting need for variability-aware design methodologies

## Limitations
- **Simulation-only**: No experimental validation on actual fabricated devices
- **Architecture-specific**: Results apply only to 3D NAND; transferability to other memory types unclear
- **No mitigation**: Paper identifies problems but proposes no design-level solutions
- **Limited scope**: Does not explore dynamic variation or cross-temperature effects

## Primary Theme
Memory Reliability and Process Variation Characterization

## Related Work Context
Complements ongoing 3D NAND research by providing quantitative variation sensitivity baseline. Relevant to design-for-manufacturability (DFM) and memory architecture planning.
