# CAFault: Enhance Fault Injection Technique in Practical Distributed Systems via Abundant Fault-Dependent Configurations

**Problem:** Existing fault injection techniques for distributed systems do not adequately explore configuration space to reveal faults across diverse system settings. Current approaches either use static configurations or fail to systematically vary configurations based on fault types.

**Method:** CAFault creates system configurations (settings that determine how a system behaves) specifically tailored to each fault type being tested. Rather than using the same configuration for all tests, it adapts the settings based on what fault is being injected—for example, changing timing parameters or network constraints based on whether you're testing crash faults, delay faults, or resource exhaustion. By systematically trying these targeted configurations, it discovers which combinations of settings and faults cause distributed systems to actually fail.

**Novelty:** CAFault generates many system configurations customized to each fault type rather than using fixed or random configurations for all tests.
