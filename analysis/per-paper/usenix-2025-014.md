# CAFault: Enhance Fault Injection Technique in Practical Distributed Systems via Abundant Fault-Dependent Configurations

**Problem:** Existing fault injection techniques for distributed systems do not adequately explore configuration space to reveal faults across diverse system settings. Current approaches either use static configurations or fail to systematically vary configurations based on fault types.

**Method:** CAFault generates abundant configurations dynamically dependent on fault types being injected, enabling systematic exploration of how configuration choices affect fault handling. The framework adapts configurations to each fault scenario rather than using fixed injection parameters. It empirically evaluates which configurations are most effective at revealing faults in distributed systems.

**Novelty:** Using abundant fault-dependent configurations that adapt to fault characteristics rather than static or random configurations, enabling more targeted and comprehensive fault discovery.
