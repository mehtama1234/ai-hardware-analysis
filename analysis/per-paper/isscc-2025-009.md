# isscc-2025-009: Ultra-Low-Power Multi-Channel Spike-Sorting Chip

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
High-density MEAs for BCIs generate massive raw spike data; on-chip sorting is essential for wireless operation. Prior designs require large buffers, use temporal features that don't scale, or access full clustering memory per spike.

## Approach
1024-channel spike-sorting via:
- **Event-driven spike detection:** processes only spike events, not raw samples → avoids large buffers
- **Spatial spike-sorting:** uses waveform shape features, not temporal → scales to multi-channel
- **Self-organizing map (SOM):** efficient clustering memory access

## Key Contribution
Event-driven + spatial SOM approach eliminates buffer/temporal scaling bottlenecks, achieving 74nW/ch and 0.00029mm²/ch over 1024 channels.

## Performance
- Power: 74 nW/channel
- Area: 0.00029 mm²/channel
- Channels: 1024
- Latency: <50 μs
- Improvement: >10× power/area vs. prior, 3× more channels
