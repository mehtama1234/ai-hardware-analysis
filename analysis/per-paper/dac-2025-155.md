# GPS: GNN-Based Two-Stage Pre-Scheduling Loop Mapping Method on CGRAs

**Authors:** Mingyang Kou, Weiqing Ji, Shouyi Yin, Hailong Yao  
**Venue:** DAC 2025

## Summary
GPS accelerates CGRA loop mapping by combining Graph Neural Networks (GNNs) for search-space reduction with Integer Linear Programming (ILP) for final optimization. The approach achieves 29.4-406.7% performance improvements and 1106.8x compilation speedup versus existing CGRA compilers.

## Key Contributions
- GNN-based pre-scheduling to intelligently reduce ILP search space
- Two-stage mapping combining learning and optimization
- 29.4-406.7% performance improvement range
- 1106.8x compilation time speedup with excellent scalability

## Technical Approach
The method uses a GNN to learn which loop mappings are likely to be high-quality, pruning the search space before ILP optimization. The two-stage approach balances the speed of neural heuristics with the optimality of ILP, enabling fast compilation without sacrificing mapping quality.
