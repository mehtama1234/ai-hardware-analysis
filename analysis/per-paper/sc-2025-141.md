# RAPTOR: Practical Numerical Profiling of Scientific Applications

**Venue:** SC 2025  
**Authors:** Faveo Hoerold, Ivan R. Ivanov, Akash Dhruv, William S. Moses, Anshu Dubey, Mohamed Wahib, Jens Domke

## Problem
Modern HPC hardware increasingly provides low-precision units (FP16, FP32 tensor cores, custom formats) while reducing or eliminating FP64 capabilities. Scientists must systematically evaluate precision requirements in their codes, but simple find-and-replace from FP64 to FP16 fails. Principled precision lowering requires understanding numerical stability and identifying tolerant code regions.

## Motivation
Hardware trends driven by AI accelerators reduce FP64 support while introducing specialized low-precision formats. Scientists lack systematic tools to profile which code regions tolerate reduced precision and which require FP64 accuracy. Manual precision analysis is tedious and error-prone; automated profiling is necessary for informed precision tuning decisions.

## Method
LLVM-based numerical profiling framework (RAPTOR):

1. **Transparent Precision Replacement:** Intercept floating-point operations via LLVM instrumentation

2. **Precision Emulation:** Support user-defined precision formats beyond standard IEEE formats

3. **Profiling:** Collect statistics on where precision changes propagate errors

4. **Stability Analysis:** Identify regions tolerant of precision lowering and detect instabilities

5. **Ease of Use:** Focus on practical, accessible workflow for domain scientists

## Key Novelty
First LLVM-based systematic numerical profiling tool enabling guided precision lowering for mixed-precision HPC codes. Shifts from manual trial-and-error to automated precision evaluation.

## Contributions
1. LLVM-based transparent precision replacement and custom format emulation
2. Numerical stability profiling to identify instability sources
3. Practical methodology for evaluating precision requirements
4. Application to four real-world Flash-X multi-physics simulation codes
