# RAP-Track: Efficient Control Flow Attestation via Parallel Tracking

**Venue:** DAC | **ID:** dac-2025-264

## Problem
Control flow attestation (CFA) for safety-critical embedded systems requires high overhead from code instrumentation and frequent context switches, limiting practical deployment.

## Key Innovation
First use of commodity hardware trace buffers (MTB/DWT) for parallel control flow tracking, eliminating instrumentation overhead and context-switch costs.

## Method
Uses specialized hardware features (Micro Trace Buffer and Data Watchpoint and Trace Unit) built into microcontrollers to automatically log program execution paths while code runs, without adding monitoring code or pausing execution. Because logging happens in hardware separate from the running program, it eliminates the performance overhead that made previous approaches too slow. The authors validated the technique on open-source systems.

## Results
- Substantial performance gains vs. state-of-the-art CFA
- Enhanced security with reduced overhead
- Practical for embedded system deployment

## Hardware Requirements
- MTB (Micro Trace Buffer)
- DWT (Data Watchpoint and Trace Unit)

## Hardware Target
CPU (MCU/embedded processors)

## Techniques
Security, hardware-assisted tracing, circuit design

## Applications
- Safety-critical embedded systems
- Industrial control
- Medical devices
- Remote attestation

## Limitations
Limited to MCUs with MTB/DWT; applicability to other embedded platforms unclear.
