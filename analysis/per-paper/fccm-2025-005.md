# Ph.D. Project Hardware-Aware Neural Networks

**Problem:** Deploying overparameterized neural networks on resource-constrained hardware like FPGAs requires new approaches that transcend traditional precision and overparameterization paradigms to reduce inference costs.

**Method:** The approach builds neural networks by programming FPGA lookup tables (LUTs)—the basic programmable logic elements that FPGAs are made of—to compute network operations. Rather than using uniform precision, it strategically mixes low-precision lookups (to save hardware space) with high-precision lookups (to maintain accuracy and allow the network to represent complex patterns). Three specific designs—PolyLUT, NeuraLUT, and NeuraLUT-Assemble—each combine these mixed-precision lookups differently to reduce the network's size and speed up inference.

**Novelty:** The key innovation is constructing neural networks directly from FPGA lookup tables with multiple precision levels integrated, rather than building networks first and then adapting them to hardware.
