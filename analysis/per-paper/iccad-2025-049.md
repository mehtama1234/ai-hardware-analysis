# Building Reasoning LLMs for Hardware Design Generation via Function-Aligned Differentiated Revision

**Venue:** ICCAD | **ID:** iccad-2025-049

## Problem
LLM-based hardware generation produces functional errors and structural flaws. Current approaches focus on direct generation, yielding 27-44% pass rates. Lack reasoning capability for complex structural constraints.

## Motivation
Improve correctness and structural integrity of LLM-generated hardware designs to enable practical synthesis.

## Method
The approach trains the model in four stages. It filters training data to only include compilable code (100% pass rate), then compares code pairs across five hardware design dimensions (RTL: register-transfer level, meaning how hardware state changes), marking which version is better in each dimension—teaching the model to evaluate code across multiple criteria. Finally, it fine-tunes with reasoning examples and uses Verilator simulation (a hardware validation tool) with reinforcement learning to reward code that passes functional validation.

## Key Novelty
The innovation is comparing hardware code versions across five design dimensions based on functional correctness, combined with training that emphasizes step-by-step reasoning.

## Contributions
- Compilation filtering achieving 100% pass rate on curated hardware generation dataset
- Function-aligned differentiated revision for multi-dimensional RTL annotation
- Reasoning-enhanced training with Verilator-guided RL improving pass@1 by up to 20%
