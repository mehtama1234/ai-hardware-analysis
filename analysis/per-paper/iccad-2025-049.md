# Building Reasoning LLMs for Hardware Design Generation via Function-Aligned Differentiated Revision

**Venue:** ICCAD | **ID:** iccad-2025-049

## Problem
LLM-based hardware generation produces functional errors and structural flaws. Current approaches focus on direct generation, yielding 27-44% pass rates. Lack reasoning capability for complex structural constraints.

## Motivation
Improve correctness and structural integrity of LLM-generated hardware designs to enable practical synthesis.

## Method
Multi-stage reasoning-enhanced training framework: (1) compilation filtering dataset curation achieving 100% pass rate, (2) function-aligned differentiated revision for comparative annotation across five RTL-relevant dimensions, (3) supervised fine-tuning using reasoning prompts, (4) reinforcement learning guided by Verilator parser for functional validation.

## Key Novelty
Function-aligned differentiated revision methodology annotating RTL code across five dimensions, combined with reasoning-enhanced training.

## Contributions
- Compilation filtering achieving 100% pass rate on curated hardware generation dataset
- Function-aligned differentiated revision for multi-dimensional RTL annotation
- Reasoning-enhanced training with Verilator-guided RL improving pass@1 by up to 20%
