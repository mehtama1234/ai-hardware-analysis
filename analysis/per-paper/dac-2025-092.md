# DM-Tune: Quantizing Diffusion Models with Mixture-of-Gaussian Guided Noise Tuning

## Problem
Diffusion models demand high compute and memory; naive mixed-precision quantization adds runtime overhead from format casting and management complexity.

## Method
DM-Tune uses a simpler approach to compress models: instead of using different precision levels for different parts (which requires costly switching between formats), it converts everything to a single low-precision format. To maintain image quality despite the lower precision, it adds a tuning step that learns to compensate for what was lost, using a mathematical function based on Gaussian distributions (smooth probability curves) and linear adjustments. The system identifies which layers lose quality most easily, measures the quantization errors throughout the model, and runs this compensation efficiently on GPUs with custom code.

## Key Innovation
Unified low-precision format with Gaussian-guided noise reconstruction achieves mixed-precision quality at single-format efficiency without format-casting overhead.

## Contributions
- Unified low-precision quantization with noise-tuning mechanism
- Sensitivity-aware layer identification
- Custom low-precision GPU kernels with efficient noise-tuning
- Mixed-precision-quality results in single FP8 format

## Motivation
Efficient diffusion model deployment requires aggressive quantization while maintaining image quality, diversity, and text-to-image alignment.
