# dac-2025-425: Constraint-Reduced Zero-Knowledge Proofs for Verifiable Computing

**Problem:** Zero-knowledge proofs (zkSNARKs) require extensive constraints for basic operations like matrix multiplication, creating high computational overhead.

**Motivation:** Cloud verification requires privacy without leaking server IP, but zkSNARKs are too slow for practical deployment.

**Method:** Optimizes ZKP computation with Constraint-reduced Polynomial Circuit (CRPC) and Prefix-Sum Query (PSQ) modules; reduces constraint overhead for matrix multiplication.

**Key Novelty:** Constraint-reduced polynomial circuits minimizing ZKP overhead.

**Contributions:**
- CRPC reducing matrix multiplication proof constraints
- PSQ for efficient aggregation in ZKP
- 12x faster proof generation

**Workloads:** Cryptography

**Confidence:** low (abstract-only)
