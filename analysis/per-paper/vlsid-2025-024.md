# PrOFraC: Property Ordering and Frame Clause Reuse for Multi-Property Verification

**Venue:** VLSID

## Problem
Multi-property formal verification scales poorly; sequential property proving inefficient; design complexity rising

## Motivation
Hardware verification critical for safety/security; multi-property verification bottleneck; need efficient property ordering

## Method
The approach expands the hardware design's behavior step-by-step and reorganizes what needs to be proven. Rather than proving each property from scratch, it reuses proof artifacts (frames—stored proof results) from earlier properties to speed up later ones. It uses statistics to choose the order in which to prove properties—solving simpler ones first to build up proof fragments that help with harder ones.
