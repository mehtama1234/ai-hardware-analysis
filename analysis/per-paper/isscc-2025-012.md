# isscc-2025-012: Dynamic Voltage-Regulator Reconfiguration

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
Conventional SoC voltage-regulator architectures use static domain grouping and fixed buck topologies. However, runtime power-state transitions create dynamic voltage/current changes—static groupings cannot reconfigure to maximize efficiency.

## Approach
Reconfigurable **digital-integrated VR fabric** enables runtime optimization:
1. **Dynamic domain regrouping:** reflect changing power states
2. **Multi-phase buck disaggregation:** disable unused phases for improved efficiency
3. **LDO reassignment:** minimize dropout losses per state

## Key Contribution
Runtime reconfigurable buck/LDO fabric exploits dynamic power states to maximize voltage-scaling efficiency and DVFS effectiveness.

## Performance
- Application: Multi-domain SoCs
- Technique: DVFS with dynamic VR reconfiguration
- Benefit: Runtime efficiency optimization vs. static designs
