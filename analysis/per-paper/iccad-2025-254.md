# Non-Negative AdderNet: Algorithm-Hardware Co-design for Lightweight Defense of Adversarial Bit-Flip Attacks

**ID:** iccad-2025-254

## Problem
Neural networks are vulnerable to bit-flip attacks that corrupt computation. Traditional defense mechanisms add significant overhead, limiting deployment on resource-constrained devices.

## Motivation
Lightweight hardware defense against bit-flip attacks enables secure neural network deployment on edge devices without sacrificing performance.

## Method
The approach replaces neural network multiplications with addition operations, which are simpler for hardware to implement efficiently. Network weights are encoded in a non-positive format (zero or negative values), and a decoder is built directly into the hardware to detect when bit-flips corrupt data during computation. By designing the algorithm and hardware together for this specific approach, the overhead of the defense mechanism stays minimal.

## Key Novelty
The innovation is efficiently defending against bit-flip attacks in non-negative addition-based neural networks by encoding weights as non-positive values through hardware-algorithm co-design.
