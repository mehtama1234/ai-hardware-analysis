# asplos-2025-001: Voyager: Input-Adaptive Algebraic Transformations for High-Performance Graph Neural Networks

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
GNN execution is bottlenecked by irregular memory access patterns and low compute utilization; algebraic transformations (operator reordering, fusion) that work for dense DNNs fail to generalize across dynamically varying graph structures. Static transformation strategies cannot adapt to per-input graph topology variations.

## Motivation
GNNs are increasingly used in diverse applications and growing in complexity, making high-performance execution critical; however, the highly irregular and input-dependent nature of graph data makes static algebraic optimization strategies ineffective.

## Method
Voyager examines each incoming graph's structure—how many connections each node has (degree distribution), how densely packed the nodes are (density), and how sparse the connections are—to decide which transformations to apply on the fly. Rather than using one fixed optimization strategy for all graphs, it measures the graph's properties and generates a custom execution plan that reorders and combines operations (a process called algebraic transformation) specifically matched to that graph's shape. This means a graph with many high-degree nodes gets optimized differently than a sparse one, because the performance bottlenecks are fundamentally different.

## Key Novelty
Voyager chooses how to transform and reorder operations for each graph at runtime based on the graph's actual topology, instead of using a single fixed transformation strategy for all graphs.

## Contributions
- Input-adaptive framework that selects algebraic transformations at runtime based on graph structural properties.
- Analysis of how graph topology variations affect the efficacy of operator reordering and fusion for GNNs.
- Demonstration of performance improvements across diverse GNN models and graph datasets.
