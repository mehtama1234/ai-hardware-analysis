# hpca-2025-031: PROCA: Programmable Probabilistic Processing Unit Architecture with Accept/Reject Prediction & Multicore Pipelining for Causal Inference

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
MCMC algorithms for probabilistic programming and causal inference are inherently sequential and compute-intensive, preventing effective parallelization; existing MCMC accelerators are not programmable across arbitrary posterior distribution forms.

## Motivation
Causal inference and Bayesian probabilistic programming are growing in importance, but MCMC's sequential accept/reject structure and arbitrary posterior computation create a performance wall that neither general-purpose nor prior domain-specific hardware has solved with both flexibility and efficiency.

## Method
PROCA is a programmable MCMC processing unit using PIM function units for sample generation. A novel accept/reject prediction method predicts sampling outcomes before full posterior evaluation, breaking the sequential dependency and enabling multi-core pipelined execution. The architecture is programmable to support arbitrary posterior forms from software probabilistic programming frameworks (e.g., PyMC). Validated on 9 benchmarks with commercial PDK implementation.

## Key Novelty
Accept/reject prediction breaking the sequential MCMC chain dependency, enabling multi-core pipelining of arbitrary posterior distributions with PIM-based sample generation.

## Contributions
- PROCA programmable MCMC PIM processing unit supporting arbitrary posterior distributions.
- Novel accept/reject prediction enabling multi-core pipelining of sequential MCMC.
- 172-4871x speedup over Intel Xeon Gold CPU; 42-1058x over NVIDIA A100 GPU.
- 1.765x speedup and 9.47x energy efficiency over SOTA MCMC domain-specific accelerators.

## Metrics
