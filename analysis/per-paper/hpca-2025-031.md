# hpca-2025-031: PROCA: Programmable Probabilistic Processing Unit Architecture with Accept/Reject Prediction & Multicore Pipelining for Causal Inference

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
MCMC algorithms for probabilistic programming and causal inference are inherently sequential and compute-intensive, preventing effective parallelization; existing MCMC accelerators are not programmable across arbitrary posterior distribution forms.

## Motivation
Causal inference and Bayesian probabilistic programming are growing in importance, but MCMC's sequential accept/reject structure and arbitrary posterior computation create a performance wall that neither general-purpose nor prior domain-specific hardware has solved with both flexibility and efficiency.

## Method
PROCA is a specialized hardware processor for MCMC algorithms (Markov Chain Monte Carlo - a statistical method where each sample depends on the previous one). The processor uses processing-in-memory function units to generate samples, and it's programmable to handle any posterior distribution form from software probabilistic programming frameworks. The speed-up comes from a prediction step: PROCA predicts whether a proposed sample will be accepted before the full evaluation completes, starting computation on the next sample while still finalizing the current accept/reject decision. This prediction breaks MCMC's inherent sequential dependency, enabling multiple processor cores to work in parallel on different samples.

## Key Novelty
PROCA breaks MCMC's sequential dependency by predicting accept/reject decisions before they're fully computed, enabling multiple cores to process samples in parallel using processing-in-memory function units.

## Contributions
- PROCA programmable MCMC PIM processing unit supporting arbitrary posterior distributions.
- Novel accept/reject prediction enabling multi-core pipelining of sequential MCMC.
- 172-4871x speedup over Intel Xeon Gold CPU; 42-1058x over NVIDIA A100 GPU.
- 1.765x speedup and 9.47x energy efficiency over SOTA MCMC domain-specific accelerators.

## Metrics
- speedup: 172-4871x vs. Intel Xeon Gold CPU; 42-1058x vs. NVIDIA A100; 1.765x vs. SOTA MCMC accelerator
