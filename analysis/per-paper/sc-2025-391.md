# Towards a user-centric HPC-QC environment

**Venue:** SC
**ID:** sc-2025-391
**Confidence:** low

## Problem

Hybrid HPC-QPU systems lack robust execution environment for hybrid quantum-classical programs; integration challenges in scheduling, portability, and reproducibility.

## Motivation

Portable runtime environment needed for hybrid quantum-classical program development in HPC with QPU integration.

## Method

HPC-QC middleware with second-layer scheduling post-HPC manager for QPU utilization; vendor-neutral QRMI support; monitoring and observability stack.

## Key Novelty

Vendor-neutral QRMI-based middleware for hybrid HPC-QPU systems; second-tier scheduling for QPU optimization.

## Contributions

1. Portable runtime for hybrid quantum-classical HPC programs
2. Second-layer QPU scheduling mechanism
3. Multi-SDK management via QRMI
4. Monitoring and observability infrastructure
5. Hybrid system architecture
