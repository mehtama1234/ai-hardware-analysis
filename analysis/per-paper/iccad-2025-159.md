# Tiny-Align - Cross-modal Alignment Framework for ASR-LLM on Edge

Tiny-Align enables efficient cross-modal alignment between automatic speech recognition and language models on edge devices like Raspberry Pi through knowledge distillation, quantization, and lightweight fusion mechanisms. The framework achieves 50× training speedup by optimizing for resource-constrained platforms, demonstrating that multi-modal AI systems can be practically deployed on commodity edge hardware. This work opens new possibilities for privacy-preserving, always-on voice-based AI assistants running entirely on user devices.
