# SpecMamba: Accelerating Mamba Inference on FPGA with Speculative Decoding

**Venue:** ICCAD  
**ID:** iccad-2025-271

## Problem
State Space Models (SSMs) like Mamba for long-sequence modeling on edge devices have autoregressive generation that remains memory-bound, and directly applying speculative decoding faces hidden state backtracking difficulties, tree-based parallel verification incompatibility, and hardware workload mismatch.

## Motivation
To accelerate Mamba inference on edge FPGAs through speculative decoding by addressing system, algorithm, and hardware co-design challenges.

## Method
System-level memory-aware hybrid backtracking strategy coordinates draft and target models; algorithm-level FIFO-based tree verification with tiling minimizes memory access; hardware-level custom dataflow computes linear layers in parallel and SSM layers in series for maximal overlapping. Implemented on AMD FPGA platforms (VHK158 and VCK190).

## Key Novelty
First FPGA-based accelerator for Mamba with speculative decoding combining system-algorithm-hardware co-design.

## Contributions
- Memory-aware hybrid backtracking strategy for coordinating draft and target model execution
- FIFO-based tree verification with tiling algorithm for efficient parallel verification
- Specialized dataflow architecture enabling parallel linear and series SSM computation
- 2.27× speedup over GPU baselines and 2.85× improvement over prior FPGA solutions
