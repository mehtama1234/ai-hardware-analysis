# SpecMamba: Accelerating Mamba Inference on FPGA with Speculative Decoding

**Venue:** ICCAD  
**ID:** iccad-2025-271

## Problem
State Space Models (SSMs) like Mamba for long-sequence modeling on edge devices have autoregressive generation that remains memory-bound, and directly applying speculative decoding faces hidden state backtracking difficulties, tree-based parallel verification incompatibility, and hardware workload mismatch.

## Motivation
To accelerate Mamba inference on edge FPGAs through speculative decoding by addressing system, algorithm, and hardware co-design challenges.

## Method
The system uses a fast draft model to generate multiple candidate next words in parallel, then verifies them using a slower but accurate target model—when candidates are wrong, it backtracks to a previous point without storing all intermediate values (hidden states). At the algorithm level, it processes candidates in order rather than exploring all possible branches, and breaks computations into small chunks (tiles) that fit in fast memory to reduce slow memory accesses. The FPGA hardware (AMD VHK158 and VCK190) runs matrix multiplications in parallel while state-space model layers—which depend on prior results—run sequentially, keeping the hardware continuously computing.

## Key Novelty
It's the first FPGA accelerator that enables speculative decoding for Mamba by coordinating memory backtracking at the system level, candidate verification at the algorithm level, and computation scheduling at the hardware level.

## Contributions
- Memory-aware hybrid backtracking strategy for coordinating draft and target model execution
- FIFO-based tree verification with tiling algorithm for efficient parallel verification
- Specialized dataflow architecture enabling parallel linear and series SSM computation
- 2.27× speedup over GPU baselines and 2.85× improvement over prior FPGA solutions
