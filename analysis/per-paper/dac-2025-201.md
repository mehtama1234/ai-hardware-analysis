# AutoRE: Bayesian-Optimization-based Automatic Reliability Enhancement Tool for Flow-based Microfluidic Biochips

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Manufacturing defects in microfluidic biochips cause malfunctions and low yield; no automated layout optimization methods exist for reliability enhancement.

## Method
AutoRE tests many different physical layouts of a microfluidic chip—adjusting component sizes and positions—while keeping the connections between parts the same. It uses Bayesian optimization (a search method that learns from each test to find good solutions efficiently) to explore these variations and identify the layout that works most reliably when manufactured.

## Key Novelty
It's the first automatic tool to make microfluidic biochips more reliable by exploring different physical layouts using Bayesian optimization (a search method that learns as it tests).

## Results
- **40% average reliability improvement** across testcases
