# Adapting Classic Scheduling Heuristics for Online Execution under Uncertainty

**ID:** sc-2025-060 | **Venue:** SC

## Problem Statement
Task scheduling on heterogeneous distributed systems with incomplete future knowledge

## Motivation
Real-world systems require online scheduling decisions without full task graph knowledge; classical offline schedulers (HEFT, CPoP) assume complete information unavailable at runtime

## Method
The system assigns computational tasks to machines in a distributed system without knowing what tasks will arrive next. Instead of planning everything in advance, it adapts proven scheduling strategies from the past (HEFT and CPoP heuristics, which identify which machine each task should run on) to make decisions in real-time. As new information arrives—like how busy each machine currently is—the scheduler adjusts its choices dynamically to keep things running efficiently.

## Key Novelty
Classic offline scheduling strategies (HEFT and CPoP) can be adapted to work online with incomplete future knowledge, achieving 3–5% performance overhead compared to perfect scheduling versus 10% for naive approaches.

- Dynamic scheduling variants for different estimation methods and CCR settings
