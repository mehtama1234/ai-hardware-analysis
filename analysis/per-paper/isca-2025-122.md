# Cramming a Data Center into One Cabinet: Co-Exploration of Computing and Hardware Architecture of Waferscale Chip

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Current wafer-scale data center architectures waste integration density due to uncoordinated resource allocation between compute and memory dies, and lack co-optimization of system area across chiplet configurations, preventing optimal performance within physical and cost constraints.

## Motivation
Wafer-scale chips integrate thousands of compute units on a single wafer and can extend Moore's Law at system level for LLM workloads, but their design space is too large for manual optimization without automated cross-layer co-exploration.

## Method
The work creates a model for a data center that fits in a single cabinet using a single wafer (the silicon base) with chips stacked vertically. The framework, called Titan, automatically explores different hardware designs by tracking dependencies between decisions—how large to make processing tiles, how much fast memory (SRAM) to include, how to connect separate chiplets, and whether to stack them—and verifies each design is physically feasible, won't overheat or fail, and fits within space constraints. By rejecting infeasible designs early, Titan accelerates the search for an optimal configuration.

## Key Novelty
Titan simultaneously optimizes how computation is organized (parallelism and task assignment) and how hardware is built (chiplet layout and vertical memory stacking) for single-wafer data centers, subject to physical space and reliability limits.

## Contributions
1. Optimized wafer-scale single-cabinet data center model with configurable memory dies and vertical stacking
2. Titan automated framework for intra-chip and inter-chip co-design and optimization
3. Vertical area constraint formulation with physical limit pre-checks to reduce design cycle time
4. Integration of reliability prediction models into the wafer-scale design exploration loop
