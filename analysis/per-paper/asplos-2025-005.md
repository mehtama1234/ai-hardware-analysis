# asplos-2025-005: EXIST: Enabling Extremely Efficient Intra-Service Tracing Observability in Datacenters

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Intra-service application-level tracing imposes 5-10% average runtime overhead (up to 18% worst case) on traced applications, making it impractical for continuous deployment in shared, stressed datacenters where sub-percent-level overhead is required.

## Motivation
Modern cloud applications require both inter-service and intra-service traces to precisely reason about event causality and diagnose performance anomalies; reducing intra-service overhead to the per-mille level is essential for practical datacenter observability.

## Method
EXIST redesigns the intra-service tracing pipeline through extremely lightweight instrumentation hooks that avoid expensive context-switching or synchronization, asynchronous off-path trace collection and encoding that decouples tracing cost from the critical path, and selective event compression that preserves causality chains while discarding redundant intermediate events.

## Key Novelty
A holistic intra-service tracing system redesigned from instrumentation to collection to achieve per-mille-level overhead (~10-50x lower than existing schemes) while maintaining full causal observability.

## Contributions
- Characterization showing that 5-10% average (18% worst-case) overhead is dominated by synchronization and data copy costs.
- EXIST's lightweight instrumentation and asynchronous off-path collection architecture reducing overhead to per-mille level.
- Evaluation in production-like datacenter environments demonstrating practical observability with negligible overhead.
