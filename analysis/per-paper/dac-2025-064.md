# Graph in the Vault: Protecting Edge GNN Inference with Trusted Execution Environment

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
GNN model intellectual property and private graph data are vulnerable during edge deployment; existing defenses do not adequately protect both model parameters and graph topology against extraction and privacy attacks.

## Motivation
Edge deployment of GNNs requires protecting both model IP and sensitive graph structure from state-of-the-art link stealing attacks while maintaining practical inference performance.

## Method
GNNVault partitions GNNs into a public backbone model and a private GNN rectifier component, both protected within Intel SGX trusted execution environment compartments, securing both model parameters and graph data during inference without requiring full model deployment in TEE.

## Key Novelty
Partition-before-training design with private GNN rectifier enabling TEE-protected GNN inference with manageable TEE memory footprint.

## Contributions
- First secure GNN deployment strategy leveraging Trusted Execution Environments
- Partition-before-training methodology enabling efficient TEE utilization
- Protection against state-of-the-art link stealing attacks with <2% accuracy degradation
- Practical implementation with Intel SGX demonstrating feasibility

## Metrics
- Accuracy: <2% accuracy degradation

## Baselines
- Link stealing attacks, Standard edge GNN deployment

## Limitations
Evaluation limited to Intel SGX without exploring other TEE platforms.
