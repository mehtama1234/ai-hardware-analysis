# Ph.D. Project: Holistic Partitioning and Optimization of CPU-FPGA Applications Through Source-to-Source Compilation

**Problem:** Hardware/software partitioning and High-level Synthesis (HLS) optimization are typically applied independently without leveraging their potential interplay. This leads to suboptimal offloading decisions that don't account for how partitioning choices affect optimization opportunities and vice versa.

**Method:** The approach automatically converts C/C++ code into an Extended Task Graph (ETG), breaking the program into individual tasks. It then groups these tasks into clusters for an FPGA (a reconfigurable chip optimized for specific workloads), while simultaneously balancing three objectives: applying the hardware's available optimizations within each cluster, reducing data traffic between the CPU and FPGA, and keeping tasks that access the same data together.

**Novelty:** Instead of separately deciding how to split work between CPU and FPGA and then optimizing each piece, this approach handles both simultaneously through source-to-source compilation, allowing partitioning choices to directly influence available optimizations.
