# LAMMPS-KOKKOS: Performance Portable Molecular Dynamics Across Exascale Architectures

**Venue:** SC

## Problem
LAMMPS molecular dynamics code must adapt to modern heterogeneous computing with multi-vendor GPUs while maintaining performance portability

## Motivation
Enable LAMMPS to leverage exascale heterogeneous architectures efficiently across different force field models

## Method
They integrated Kokkos—a library that lets code run efficiently on different hardware—into LAMMPS, a molecular dynamics simulator. They then optimized this combination to handle three types of atomic force calculations: pairwise interactions between atoms, many-body reactive forces in complex chemical reactions, and machine learning-based models that predict atomic behavior.

## Key Novelty
They proved Kokkos integration works reliably in production LAMMPS, maintaining efficient performance across three exascale supercomputers and the Alps system with different force field types.

## Contributions
- Kokkos integration for performance portability across heterogeneous architectures
- Implementation and optimization of multiple interatomic potential types
- Strong scaling demonstration on OLCF Frontier, ALCF Aurora, NNSA El Capitan, and CSCS Alps
