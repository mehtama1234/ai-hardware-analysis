# RTL-Breaker: Assessing the Security of LLMs Against Backdoor Attacks on HDL Code Generation

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Investigate backdoor attack vulnerability in LLM-based HDL code generation, exploring trigger mechanisms, effectiveness, and detectability through poisoned training data.

## Problem
LLMs trained on public code repositories are vulnerable to data poisoning; malicious HDL injected into training can propagate into generated hardware, creating undetectable backdoors.

## Method
The RTL-Breaker framework tests how to poison LLMs that generate hardware designs (HDL/RTL code specifies how chips operate). It hides malicious patterns in training data to make the LLM produce harmful code in hardware designs, then measures which patterns are most effective and whether the poisoned code still works. It also examines whether attacks stay effective over time. The framework and datasets were released publicly.

## Key Results
- Novel attack framework (RTL-Breaker) for LLM HDL generation
- Comprehensive trigger effectiveness analysis
- Open-source framework and datasets released
