# FRoZN: Fault-Tolerant Routing Technique Using Reinforcement Learning for ZMesh NoC

**Venue:** VLSID

## Problem
Fault-tolerant NoC routing faces dynamic network conditions and inefficient fault recovery

## Motivation
AI accelerators/automotive SoCs require robust NoC solutions; traditional algorithms struggle with dynamic faults

## Method
The system uses Q-learning (a machine learning technique where a routing agent learns which paths work best through repeated trials and feedback) to manage data routing on a ZMesh NoC—a network topology that combines a regular mesh grid with zigzag routing patterns. When faults occur and damage parts of the network, the routing algorithm dynamically adapts its decisions based on what it has learned about which paths remain functional. This allows messages to automatically find alternate routes around broken connections without manual reconfiguration.

## Key Novelty
The core innovation is using Q-learning (machine learning that learns by trial and reward) to automatically adapt routing around network faults in a ZMesh NoC's mesh-zigzag topology.
