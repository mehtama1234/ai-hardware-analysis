# LEMOE: LLM-Enhanced Bayesian Optimization for Microarchitecture Exploration

**Venue:** DAC | **ID:** dac-2025-193

## Summary
LEMOE enhances multi-objective Bayesian optimization for CPU microarchitecture DSE via LLM-powered domain knowledge. Features program-aware warm-up using LLM+LLVM for initial designs and leverages LLM contextual learning to improve surrogate models under sparse data.

## Key Results
- **Energy Efficiency:** 22.8% improvement with same iteration count
- **Runtime:** 2.9× speedup for same target
- **Approach:** LLM-enhanced Bayesian model + program-aware warm-up + contextual learning

## Technique
LLM and LLVM generate program-aware initial design set; LLM contextual learning improves implicit Bayesian surrogate modeling; multi-objective optimization balances competing metrics.
