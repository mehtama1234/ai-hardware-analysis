# hpca-2025-107 — LegoZK: A Dynamically Reconfigurable Accelerator for Zero-Knowledge Proof

**Venue:** HPCA  
**Authors:** Zhengbang Yang, Lutan Zhao, Peinan Li, Han Liu, Kai Li, Boyan Zhao, Dan Meng, Rui Hou  
**Confidence:** low (abstract only)

## Problem
Existing ZKP accelerators are designed at core-operator granularity, yielding low hardware resource utilization and limited adaptability across the different computation stages of proof generation (NTT, MSM, polynomial operations).

## Motivation
ZKP proof generation overhead impedes privacy-preserving application adoption; current accelerators cannot efficiently reconfigure across all ZKP stages without per-operator specialization.

## Method
LegoZK uses reusable building blocks called finite field arithmetic units, or FAUs (circuits that perform specialized math for zero-knowledge proofs), connected through a hierarchical on-chip network. Because the FAUs and network can be reconfigured at runtime, the same hardware can handle all stages of proof generation without needing different chips for each stage. For Multi-Scalar Multiplication (MSM)—the slowest stage—it uses a pipelined bucket reduction algorithm based on lookup tables, which speeds up calculations by processing many values in parallel. The network connections and FAU assignments automatically switch between proof stages.

## Key Novelty
By treating simple arithmetic circuits (FAUs) as universal, reconfigurable building blocks and connecting them with a hierarchical network, one chip design can efficiently handle all stages of zero-knowledge proof generation instead of needing separate specialized chips for each computation type.

## Contributions
- Dynamically reconfigurable ASIC using FAUs + hierarchical NoC for all ZKP computation stages
- Fast fully pipelined lookup-table-based bucket reduction for MSM
- 31.96x speedup over PipeZK (ASIC); 11.30x over GZKP (GPU)
- 50.1% area reduction and 37.7% power reduction vs. PipeZK
