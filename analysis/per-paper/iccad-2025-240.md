# ZeroSim: Zero-Shot Analog Circuit Evaluation with Unified Transformer Embeddings

**ID:** iccad-2025-240

## Problem
Analog circuit performance evaluation requires expensive SPICE simulations. Existing neural surrogate models lack generalization to unseen topologies and design variants.

## Motivation
Accelerating analog circuit design requires fast, generalizable performance prediction without retraining for new topologies.

## Method
The system uses a transformer (a neural network) to learn how circuit components interact with each other and creates unified numerical representations (embeddings) for all components. Since it learned the fundamental rules of how components work together, it can predict performance for new circuit layouts it has never seen before—without retraining—a capability called zero-shot inference. This approach evaluates circuits 13 times faster than running expensive SPICE simulations.

## Key Novelty
It learns circuit component interactions using transformer embeddings and applies that knowledge to predict performance on new circuit designs without retraining.

## Contributions
- Unified transformer embedding scheme for circuit components
- Zero-shot generalization to new topologies
- 13× speedup over SPICE simulation
- Topology-agnostic neural surrogate model
