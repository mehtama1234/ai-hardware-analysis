# ZeroSim: Zero-Shot Analog Circuit Evaluation with Unified Transformer Embeddings

**ID:** iccad-2025-240

## Problem
Analog circuit performance evaluation requires expensive SPICE simulations. Existing neural surrogate models lack generalization to unseen topologies and design variants.

## Motivation
Accelerating analog circuit design requires fast, generalizable performance prediction without retraining for new topologies.

## Method
Transformer-based encoder with unified embeddings for circuit components and topology-agnostic architecture. Zero-shot inference on unseen topologies by leveraging learned component interactions. Achieves 13× speedup compared to SPICE simulation.

## Key Novelty
Zero-shot generalization to unseen circuit topologies using transformer embeddings without retraining.

## Contributions
- Unified transformer embedding scheme for circuit components
- Zero-shot generalization to new topologies
- 13× speedup over SPICE simulation
- Topology-agnostic neural surrogate model
