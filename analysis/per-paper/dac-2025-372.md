# Efficient Recycling Subspace Truncation Method for Periodic Small-Signal Analysis

## Summary
Floquet-based subspace truncation strategy for Krylov recycling methods reducing memory overhead while maintaining efficiency in RF simulation.

## Key Results
- **Up to 2.5x speedup** compared to existing methods
- **Same memory cost** without restart

## Core Innovation
Floquet-based truncation strategy balances memory efficiency with recycling benefits, avoiding performance loss from memory-driven restarts.

## Technique
Efficient initial guess selection for truncated subspaces; Floquet-based truncation reduces memory while preserving Krylov recycling convergence acceleration.
