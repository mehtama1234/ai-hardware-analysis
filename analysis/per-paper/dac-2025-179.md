# FT-MUX: A Fault-Tolerant Microfluidic Multiplexer Design

**Problem:** Microfluidic MUX defects scale with integration; single control-channel fault affects many flow channels.

**Solution:** Formal analysis and BWCC-based optimization to design multiplexers tolerating n defective control channels.

**Results:** Up to 100x resource efficiency improvement; tolerates ≥1 defect with ≥10 control channels.

**Theme:** Fault-tolerant microfluidic routing via coding theory.
