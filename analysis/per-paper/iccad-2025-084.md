# Building an Open CGRA Ecosystem for Agile Innovation

**Venue:** ICCAD  
**ID:** iccad-2025-084

## Problem
Closed, vertically-integrated CGRA development limits architectural exploration and innovation. Lack of open, modular CGRA ecosystems hinders community-driven research and real-world deployment of reconfigurable accelerators.

## Motivation
Modern AI and edge computing workloads require agile hardware-software co-design, which benefits from open ecosystems replacing closed vertically-integrated approaches with modular, community-driven architectures.

## Method
The work presents an open CGRA ecosystem (a modular set of tools for building flexible reconfigurable hardware). It has three components: HyCUBE, a chip with reconfigurable data-routing wiring that completes all data transfers in a single cycle even when routing through multiple intermediate steps; PACE, which embeds HyCUBE in a complete RISC-V processor system for edge computing devices; and Morpher, an open-source framework that automatically adapts to different hardware designs and provides tools for design exploration, code compilation, simulation, and testing. The entire ecosystem is deliberately open at every layer—from hardware design to software tooling—to remove barriers to innovation.

## Key Novelty
The key novelty is an open ecosystem for building reconfigurable accelerators, with a design framework that adapts to different hardware architectures, enabling customization and optimization across the entire hardware-software stack without being locked to any specific software implementation.

## Contributions
- HyCUBE CGRA with reconfigurable single-cycle multi-hop interconnect for flexible data movement
- PACE architecture integrating HyCUBE within RISC-V SoC for power-efficient edge computing
- Morpher open-source design framework supporting full design space exploration and compilation pipeline
- Demonstration of modular, community-driven CGRA development enabling reproducible research
