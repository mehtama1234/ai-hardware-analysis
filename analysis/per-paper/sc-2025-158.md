# SC-2025-158: SpGEMM Acceleration via Hierarchical Clustering

## Summary
Accelerates sparse matrix-sparse matrix multiplication (SpGEMM) through hierarchical clustering combining row reordering and cluster-wise computation to improve cache locality.

## Problem
- SpGEMM limited by irregular memory patterns (especially in 2nd matrix B)
- Prior reordering work (SpMV-focused) doesn't directly apply to SpGEMM
- Cache misses destroy performance despite high compute intensity
- No systematic approach for decoupled reordering + clustering

## Innovation: Hierarchical Clustering
**Key insight**: Reorder A matrix rows for sequential access; cluster both matrices for improved B reuse.

**Novel format**: Row-clustered matrix format enabling cluster-wise computation

## Performance
- **Speedup**: 1.39x average
- **Preprocessing**: <20x SpGEMM cost for ~90% of matrices
- **Evaluation**: 110 matrices (SuiteSparse collection)

## Comparison of Strategies
| Approach | Speedup | Preprocessing | Notes |
|----------|---------|----------------|-------|
| Graph partitioning | Highest | Very high | Impractical for repeated use |
| Hierarchical clustering | 1.39x | Low | Practical for production |

## Reordering Schemes Studied
- 10 algorithms tested (including graph partitioning, bandwidth reduction, etc.)
- 3 clustering methods compared
- Comprehensive 110-matrix evaluation

## Implications
- Clustering more cost-effective than pure reordering for SpGEMM
- Independent optimization enables flexible application
- Practical for scientific computing and graph algorithms
