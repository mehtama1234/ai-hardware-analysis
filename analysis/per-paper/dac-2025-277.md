# dac-2025-277: Quantum-Tunneling BNN Engine for Robotic Perception

**Problem:** Bayesian NNs provide uncertainty quantification but have prohibitive hardware overhead; real-time robotic perception requires efficient deployment.

**Motivation:** Safety-critical autonomous robots need both accuracy and uncertainty estimates; hardware efficiency enables real-time inference.

**Method:** The hardware generates random numbers using quantum tunneling in specially designed transistors, rather than computing them in software. Quantum tunneling is a quantum-mechanical effect where electrons pass through energy barriers they shouldn't classically be able to cross—this inherently random process produces numbers with the bell-curve distribution (Gaussian) that Bayesian neural networks need. This approach is extremely efficient at 200 femtojoules per sample with 0.997 correlation to true randomness, and multiple generators run in parallel for fast inference.

**Key Novelty:** FDSOI quantum tunneling for efficient on-chip random variable generation in BNN hardware.

**Contributions:**
- 10^3-10^4x latency reduction vs. software BNNs
- 200 fJ/sample Gaussian RNG via quantum tunneling
- 4.5x resampling efficiency in uncertainty-aware localization
