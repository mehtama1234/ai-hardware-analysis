# LLMTailor: A Layer-wise Tailoring Tool for Efficient Checkpointing of Large Language Models

**ID:** sc-2025-333  
**Venue:** SC 2025  
**Authors:** Minqiu Sun, Xin Huang, Luanzheng Guo, Nathan R. Tallent, Kento Sato, Dong Dai

## Problem & Motivation

LLM training requires frequent checkpointing for fault tolerance, but existing methods periodically store **entire model and optimizer states** regardless of how much each layer actually changes. This incurs:
- Massive storage overhead
- Resource contention on I/O subsystems

**Key insight:** Layer updates are highly non-uniform—some layers undergo significant changes while others remain stable. This asymmetry can be exploited.

## Solution: LLMTailor

A checkpoint-merging framework that:
1. **Filters layers** based on update significance
2. **Assembles composite checkpoints** from heterogeneous layer snapshots
3. Provides **fine-grained control** over weights and optimizer states

## Key Contributions

- First tool supporting **layer-wise selective checkpointing** via merging
- Significant reduction in storage footprint and I/O time
- Compatible with different selective strategies
- No impact on final model quality

## Implications

Enables practical deployment of selective checkpointing for large-scale LLM training on resource-constrained systems, reducing both storage and I/O bottlenecks.
