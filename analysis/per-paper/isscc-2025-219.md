# isscc-2025-219: Adaptive Dual-Impedance Class-E WPT Transmitter

## Quick Summary
A 6.78MHz, 94.2%-peak-efficiency Class-E wireless power transmitter with adaptive real and imaginary impedance compensation, delivering 33W across wide load-impedance ranges.

## Problem
WPT systems achieve high efficiency only at specific load impedances. In practice:
- Charging state (battery SOC) changes load resistance
- Temperature and coil coupling affect impedance
- Both real and imaginary parts vary, detuning the circuit

## Method
A 6.78MHz Class-E power amplifier (a highly efficient power circuit) solves wireless charging efficiency by separately controlling how the circuit adapts to changing loads. It adjusts the real part of load impedance (the resistive load) using a dynamic matching network, and adjusts the imaginary part (the phase shift) using adaptive capacitance, specifically using tunable elements instead of nonlinear MOS capacitors. This dual control keeps the circuit operating efficiently across changing charge states, achieving 94.2% peak efficiency.

## Key Novelty
Separately controlling the real and imaginary parts of load impedance with adaptive tuning elements instead of using nonlinear MOS capacitors.

## Contributions
- 94.2% peak efficiency
- 6.78MHz Class-E
- 33W power transfer
- Real-part adaptive matching
- Imaginary-part phase compensation
- Wide operating impedance range
