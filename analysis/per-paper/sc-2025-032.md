# sc-2025-032: SmartIO: A Lightweight End-to-End Workflow for Runtime I/O Optimization of HPC Systems

## Summary
SmartIO is an automated I/O optimization system that improves HPC system performance at runtime without requiring offline training, profiling, or exhaustive parameter searches. It uses context-free grammar-based prediction and rules-based optimization.

## Problem
- I/O bottlenecks are critical in HPC systems
- Traditional optimization approaches are expensive:
  - Offline tuning requires deep expertise
  - Exhaustive search is computationally costly
  - ML model training requires infrastructure and time
- Need for lightweight runtime solution

## Method
1. **Prediction**: Context-free grammar (CFG) predicts future I/O calls during runtime
2. **Learning**: Extracts key I/O characteristics from predicted calls
3. **Optimization**: Rules-based mapping engine applies optimizations proactively
4. **Rules engine**: Constructed from literature review and empirical evaluation

## Key Innovations
1. **CFG-based prediction**: Novel use of context-free grammars for pattern prediction without ML
2. **Rule-based engine**: Interpretable optimization without opaque neural networks
3. **Runtime deployment**: Minimal overhead, no need for offline analysis phase
4. **Lightweight architecture**: Practical for production HPC systems

## Hardware Targets
- Generic HPC parallel storage systems
- Flash-based storage
- Network-based I/O

## Results
- **IOR read bandwidth**: ~13x improvement
- **IOR write bandwidth**: ~12x improvement
- **Flash-X I/O bandwidth**: ~4x speedup
- **Overhead**: Negligible
- **Comparison**: Comparable or better performance than state-of-the-art tools with drastically reduced tuning cost
