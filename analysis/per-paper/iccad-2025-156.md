# BIGX - GPU-accelerated Dynamic Programming for Buffer Insertion

BIGX accelerates the buffer insertion problem for timing violation recovery by implementing Van Ginneken's dynamic programming algorithm on GPUs. The system parallelizes buffer placement optimization across GPU threads, enabling simultaneous computation across multiple signal nets. Achieving 11.68× speedup over CPU implementations, BIGX significantly reduces timing closure optimization runtime and demonstrates the effectiveness of GPU acceleration for dynamic programming workloads in EDA tools.
