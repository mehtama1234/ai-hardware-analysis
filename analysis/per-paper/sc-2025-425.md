# KDRSolvers: Scalable, Flexible, Task-Oriented Krylov Solvers

**Paper ID:** sc-2025-425
**Venue:** SC
**Authors:** David Kai Zhang, Rohan Yadav, Alex Aiken, Fredrik Kjolstad, Sean Treichler

## Problem

Sparse linear solver frameworks (PETSc, Trilinos) are inflexible in data partitioning; changes to partitioning strategies require extensive code refactoring and don't automatically propagate.

## Motivation

Krylov methods require flexible partitioning for optimal load balancing on heterogeneous systems; manual tuning for each new partition strategy wastes developer time and introduces bugs.

## Method

Abstract sparse matrix representation using dependent partitioning that maps between domain, range, and nonzero entries. Universal co-partitioning operators for matrices and vectors. Multi-operator systems enable non-contiguous data processing. Targets Legion task-based runtime system.

## Key Novelty

First abstraction to decouple sparse matrix storage format from Krylov algorithm implementation; automatic partitioning strategy propagation; multi-operator data ingestion.

## Contributions

- Dependent partitioning abstraction for sparse matrix representation
- Universal co-partitioning operators independent of storage format
- Multi-operator systems for non-contiguous data processing
- Competitive performance vs PETSc/Trilinos (9.6% time reduction on 1,024 GPUs)
