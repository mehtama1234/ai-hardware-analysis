# dac-2025-279: ARCANE—Cache-Integrated Near-Memory Computing

**Problem:** Von Neumann architecture limits energy and throughput on data-driven apps; existing near-memory compute solutions require explicit data placement.

**Motivation:** CNNs and analytics are memory-bound; automatic near-memory compute with software transparency enables adoption.

**Method:** ARCANE puts a computing unit directly inside the cache memory—the fast storage between your CPU and main memory. A RISC-V controller (a processor using a standard instruction set) takes custom instructions from the main CPU and runs vector operations (calculations on multiple data items at once) on data already stored in cache. Because computation happens where data sits, instead of moving data back and forth to a distant processor, most data stays fast. The architecture automatically handles data placement and synchronization, so programmers never need to manually move data around.

**Key Novelty:** Cache-integrated near-memory computing via RISC-V ISA with transparent data placement.

**Contributions:**
- 30-84x performance for 8-bit data vs. traditional cache
- Automatic data mapping abstraction
- 41.3% area overhead

**Confidence:** low (abstract-only)
