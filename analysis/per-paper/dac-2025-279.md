# dac-2025-279: ARCANE—Cache-Integrated Near-Memory Computing

**Problem:** Von Neumann architecture limits energy and throughput on data-driven apps; existing near-memory compute solutions require explicit data placement.

**Motivation:** CNNs and analytics are memory-bound; automatic near-memory compute with software transparency enables adoption.

**Method:** RISC-V cache controller executes custom instructions dispatched to vector processors embedded in cache. Automatic data placement and synchronization via architecture, not software.

**Key Novelty:** Cache-integrated near-memory computing via RISC-V ISA with transparent data placement.

**Contributions:**
- 30-84x performance for 8-bit data vs. traditional cache
- Automatic data mapping abstraction
- 41.3% area overhead

**Confidence:** low (abstract-only)

**Tags:** near-memory-compute, cache-architecture, risc-v, cnn
