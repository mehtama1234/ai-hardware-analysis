# InstAttention: In-Storage Attention Offloading for Cost-Effective Long-Context LLM Inference

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Long-context LLM inference at large batch sizes generates KV caches that exceed GPU VRAM capacity; offloading KV caches to SSDs via PCIe creates a critical bandwidth bottleneck that severely limits throughput.

## Motivation
Growing context lengths and batch sizes in offline LLM inference for resource-constrained scenarios (e.g., edge) demand cost-effective storage solutions that do not sacrifice throughput to PCIe bandwidth limitations.

## Method
InstAttention offloads both the attention computation and KV cache storage to Computational Storage Drives (CSDs), which have high internal NAND bandwidth not limited by PCIe. A flash-aware in-storage attention engine executes the attention decode phase directly inside the CSD, with KV cache management mechanisms tailored to flash access patterns (e.g., large sequential reads). Optimized P2P transmission between GPU and CSDs eliminates unnecessary data migration back across PCIe. The system targets offline inference of a 13B model on an NVIDIA A6000 GPU.

## Key Novelty
Offloading attention computation itself (not just storage) to in-storage CSD compute units, leveraging internal flash bandwidth to bypass the PCIe bottleneck for long-sequence KV cache access.

## Contributions
- InstAttention system architecture offloading attention decode computation and KV cache to CSDs
- Flash-aware in-storage attention engine with KV cache management for CSD flash access patterns
- P2P GPU-to-CSD transmission mechanism reducing data migration overhead
- Up to 11.1x throughput improvement over FlexGen for long-sequence 13B inference on A6000
