# InstAttention: In-Storage Attention Offloading for Cost-Effective Long-Context LLM Inference

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Long-context LLM inference at large batch sizes generates KV caches that exceed GPU VRAM capacity; offloading KV caches to SSDs via PCIe creates a critical bandwidth bottleneck that severely limits throughput.

## Motivation
Growing context lengths and batch sizes in offline LLM inference for resource-constrained scenarios (e.g., edge) demand cost-effective storage solutions that do not sacrifice throughput to PCIe bandwidth limitations.

## Method
InstAttention offloads both the KV cache (the data storing information about previous tokens) and the attention computation to special storage drives with built-in processors (Computational Storage Drives, or CSDs). Because the computation runs inside the drive, it can access the stored data through fast internal flash memory instead of the slow PCIe connection between the GPU and drive. The system is optimized for how flash memory actually works—reading large sequential blocks efficiently—and runs the attention decode phase (where the model calculates which previous tokens matter when generating each new token) directly in the CSD, sending only the final results back to the GPU. The approach targets offline inference of 13B-parameter models on NVIDIA A6000 GPUs.

## Key Novelty
The key idea is performing attention computation directly inside the storage drive, where it can access the KV cache through fast internal flash pathways instead of sending data back and forth through the slow PCIe cable.

## Contributions
- InstAttention system architecture offloading attention decode computation and KV cache to CSDs
- Flash-aware in-storage attention engine with KV cache management for CSD flash access patterns
- P2P GPU-to-CSD transmission mechanism reducing data migration overhead
- Up to 11.1x throughput improvement over FlexGen for long-sequence 13B inference on A6000
