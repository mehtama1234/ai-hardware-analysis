# CMFuzz: Parallel Fuzzing of IoT Protocols by Configuration Model Identification and Scheduling

## Summary
Configuration-aware parallel fuzzing framework for IoT protocols that models configuration interactions and schedules them across fuzzing instances.

## Key Results
- **34.4% more branch coverage** vs Peach baseline in 24h
- **28.5% more branches** vs SPFuzz
- **14 new bugs** detected in real-world IoT protocols

## Core Innovation
First framework to systematically model protocol configurations and their relations, using relation-aware scheduling for parallel fuzzing.

## Technique
Extracts generalized configuration model from implementations, identifies configuration item relations, allocates configurations to fuzzing instances based on relations.
