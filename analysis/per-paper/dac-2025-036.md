# Rimast: Retrieval-in-Memory Architecture for Language Models

**Problem:** Retrieval-augmented language models suffer from massive data movement and irregular memory access patterns, severely limiting performance on conventional processors.

**Key Idea:** Use 3D-stacked PIM with hierarchical retrieval-specific dataflow to perform retrieval operations near memory, combined with skew-free data mapping to handle irregular access.

**Approach:** Hardware-software co-design: hierarchical PIM dataflow minimizes data transfer, skew-free mapping distributes data uniformly, adaptive offloading strategies handle dynamic workloads.

**Results:** 273× speedup over CPUs, 55× over GPUs, 2.41× over prior accelerators.

**Theme:** Processing-in-memory optimization for efficient retrieval-augmented language model inference.
