# Torpor: GPU-Enabled Serverless Computing for Low-Latency, Resource-Efficient Inference

**Problem:** Existing serverless platforms lack efficient GPU support, preventing them from delivering high-performance inference. Sharing a node's limited GPUs among hundreds of inference functions requires minimizing latency overhead from model swapping.

**Method:** Torpor stores inference models in regular memory, then loads them onto the GPU only when needed (late binding), minimizing the slowdown from moving models around. It speeds up this loading through four techniques: asynchronously handling incoming requests while models load in the background, sharing GPU runtime across multiple functions, executing predictions in a pipelined sequence, and managing GPU memory efficiently. It then schedules requests intelligently, using high-speed GPU interconnects to avoid conflicts and meet each function's performance targets.

**Novelty:** Late binding (loading models only when needed) with dynamic model swapping allows hundreds of concurrent inference functions to share GPUs while maintaining performance as good as if each function had its own GPU.
