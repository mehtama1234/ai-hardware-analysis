# Torpor: GPU-Enabled Serverless Computing for Low-Latency, Resource-Efficient Inference

**Problem:** Existing serverless platforms lack efficient GPU support, preventing them from delivering high-performance inference. Sharing a node's limited GPUs among hundreds of inference functions requires minimizing latency overhead from model swapping.

**Method:** Torpor maintains inference models in main memory and dynamically swaps them onto GPUs upon request arrivals via late binding. It minimizes swapping overhead through asynchronous API redirection, GPU runtime sharing, pipelined model execution, and efficient GPU memory management. An interference-aware request scheduling algorithm leverages high-speed GPU interconnects to meet per-function latency SLOs.

**Novelty:** Late binding with dynamic model swapping enables hundreds of concurrent inference functions to share GPUs while achieving latency performance comparable to native execution.
