# Modeling and Analysis Technique for the Formal Verification of System-on-Chip Address Maps: Extended Abstract

**Venue**: DATE  
**Primary Theme**: Graph-based SoC address map verification  

## Problem
Complex SoC designs require verification that specification and implementation address maps are equivalent, and identifying root causes of discrepancies is challenging.

## Method
The technique represents both the specification and implementation of how memory addresses are assigned in a chip using graphs—diagrams where components appear as nodes and their memory connections appear as edges. It then systematically compares these two graphs to detect any discrepancies and pinpoint exactly where they differ. This graph-based approach ensures complete and systematic verification compared to manual inspection.

## Key Novelty
A single graph-based representation for both specification and implementation address maps enables systematic verification that they're identical.

## Contributions
- Unified graph model for representing both specification and implementation address maps
- Equivalence analysis technique for identifying address map discrepancies
- Demonstration on mid-size industrial SoC design with root cause identification
