# Fringe-SGC: Counting Subgraphs with Fringe Vertices

**ID:** sc-2025-047  
**Venue:** SC  
**Confidence:** high

## Problem
Subgraph counting algorithms cannot handle large patterns due to exponential computational complexity

## Motivation
Subgraph counting is essential for cybersecurity, drug discovery, social networks, and NLP applications

## Method
Novel algorithm separates core subgraph search from fringe-based occurrence computation using set methods

## Key Novelty
Fringe-based decomposition enables exact counting of larger subgraphs; GPU acceleration for fringe-heavy patterns

## Contributions
1. Introduces Fringe-SGC technique for subgraph counting
2. Enables counting of previously infeasible large patterns
3. Achieves significant GPU speedups over SOTA

## Limitations
Performance gains most significant on patterns with many fringes; limited to exact counting
