# FineMem: Breaking the Allocation Overhead vs. Memory Waste Dilemma in Fine-Grained Disaggregated Memory Management

**Problem:** Fine-grained memory allocation in disaggregated memory systems incurs high allocation overhead, while coarse-grained allocation wastes memory through internal fragmentation. Existing approaches force systems to choose between computational overhead and memory inefficiency.

**Method:** FineMem adapts memory chunk size based on how the program actually allocates and uses memory—choosing smaller chunks when allocations are frequent (to waste less space) and larger chunks when they're sparse (to reduce bookkeeping overhead). It uses historical patterns to predict needs, stores allocation metadata (bookkeeping information) in a layered structure to minimize tracking costs, and automatically combines free chunks back together to prevent fragmentation.

**Novelty:** FineMem adapts memory chunk size in real-time based on allocation patterns, eliminating the choice between allocation speed and memory waste in disaggregated memory systems.
