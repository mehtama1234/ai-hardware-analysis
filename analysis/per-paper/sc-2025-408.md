# SC-2025-408: Phoenix - Refactored I/O Stack for GPU Direct Storage

## Summary
Phoenix eliminates phony buffers from GPU Direct Storage (GDS) by leveraging ZONE_DEVICE memory mapping, achieving 70.3% overhead reduction and 4.11x speedup on checkpoint loading for AI/ML workloads.

## Problem
Current GDS implementations require phony buffers in host memory as intermediaries for GPU-storage communication, adding latency, memory overhead, and deployment complexity.

## Method
- **ZONE_DEVICE mapping**: Maps GPU memory directly into the system page table at startup
- **Kernel module optimization**: Allocates user-space virtual memory and establishes direct GPU memory mappings
- **Elimination of host buffers**: Removes the intermediary buffering layer entirely

## Key Results
- 70.3% reduction in I/O path software overhead
- 2.29x faster small-size I/O (KV-cache operations)
- 4.11x faster large file loading (model checkpoints)
- Implementation verified on recent GPU and NPU models

## Hardware Target
- NVIDIA GPUs (recently-released models)
- AMD NPUs
- GPU systems with NVMe storage
- AI/ML training and inference infrastructure

## Technique Categories

- Page table management
- GPU-storage integration

## Workload Impact
