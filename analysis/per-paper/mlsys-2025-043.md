# HyC-LoRA: Memory Efficient LoRA Fine-tuning with Hybrid Activation Compression

**ID:** mlsys-2025-043 | **Venue:** MLSYS 2025

## Problem
LoRA fine-tuning reduces trainable weight count but buffered activations for backpropagation still dominate memory—69.7% of total in Llama-2-7B—and non-linear operator activations (RMSNorm, RoPE) resist standard quantization due to channel-wise outliers.

## Method
HyC-LoRA uses a two-tier hybrid compression:
1. **Intra-operator**: For RMSNorm, detect outlier channels via calibration and store at FP16, quantize rest to INT2. For attention Q/K, apply pre-RoPE quantization where values are smoother.
2. **Inter-operator**: LoRA Reorder Computing retains XA (activation times LoRA A) while quantizing main branch separately, enabling YAB recomputation during backward instead of storage. Triton kernel fusion integrates quantization with adjacent ops.

## Key Novelty
Hybrid two-tier compression combining per-channel outlier extraction for non-linear activations with LoRA-aware quantization reordering to enable selective recomputation—achieving near-2-bit across all operators.

## Results
- **3.97x** end-to-end memory reduction vs baseline LoRA
- **8x** activation memory reduction
- Negligible accuracy degradation on Llama-2-7B, Llama-3-8B
- Baselines: QLoRA, SparseBP, BackRazor, LoRA-FA, QST

## Hardware Target
NVIDIA GPUs with Triton support; targets on-device fine-tuning
