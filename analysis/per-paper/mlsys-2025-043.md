# HyC-LoRA: Memory Efficient LoRA Fine-tuning with Hybrid Activation Compression

**ID:** mlsys-2025-043 | **Venue:** MLSYS 2025

## Problem
LoRA fine-tuning reduces trainable weight count but buffered activations for backpropagation still dominate memory—69.7% of total in Llama-2-7B—and non-linear operator activations (RMSNorm, RoPE) resist standard quantization due to channel-wise outliers.

## Method
HyC-LoRA compresses activations using two coordinated strategies. Within individual operations, it identifies data channels with extreme outliers and keeps those in full precision (FP16) while compressing the rest to 2-bit (INT2); for attention queries/keys, it compresses before the rotation step (RoPE) where values are smoother. Across operations, it reorders quantization and LoRA adapter application so the activation-times-adapter product (XA) stays in memory while the main branch is compressed separately, enabling backward passes to regenerate results instead of storing them; it also fuses quantization with adjacent operations using Triton kernels to reduce processing overhead.

## Key Novelty
It combines outlier preservation within operations (keeping extreme values at full precision, compressing others to 2-bit) with LoRA-aware compression reordering that enables backward passes to regenerate data instead of storing it.

## Results
- **3.97x** end-to-end memory reduction vs baseline LoRA
- **8x** activation memory reduction
- Negligible accuracy degradation on Llama-2-7B, Llama-3-8B
- Baselines: QLoRA, SparseBP, BackRazor, LoRA-FA, QST

## Hardware Target
NVIDIA GPUs with Triton support; targets on-device fine-tuning
