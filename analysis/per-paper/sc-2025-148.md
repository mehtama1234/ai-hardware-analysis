# LiquidGEMM: Hardware-Efficient W4A8 GEMM Kernel for High-Performance LLM Serving

**Venue:** SC 2025  
**Authors:** Huanqi Hu, Bowen Xiao, Shixuan Sun, Jianian Yin, Zhexi Zhang, Xiang Luo, Chengquan Jiang, Weiqi Xu

## Problem
Quantization accelerates LLM inference by reducing memory footprint and computational cost. W4A8 quantization (4-bit weights, 8-bit activations) offers strong accuracy-performance balance, but existing GEMM kernel implementations suffer from inefficient dequantization on CUDA Cores, unable to match Tensor Core computational throughput, creating critical bottleneck.

## Motivation
LLM inference is dominant modern AI workload requiring low latency and high throughput. Quantization is essential for efficient production serving. However, kernel-level optimization for W4A8 remains challenging - dequantization overhead undermines Tensor Core performance gains, limiting practical speedup achievable in end-to-end systems.

## Method
LiquidGEMM accelerates 4-bit weight, 8-bit activation matrix operations using two techniques. LiquidQuant converts compressed 4-bit weights back into usable form using just 2 operations per 4 elements while preventing overflow. The kernel then overlaps three tasks—loading weights, converting them, and performing matrix multiplication—across parallel thread groups without pausing any threads or repeating data from memory.

## Key Novelty
LiquidQuant converts 4-bit weights in just 2 operations per 4 elements, fast enough that W4A8 matrix operations run all computation stages in parallel on Tensor Cores without needing thread synchronization.

## Contributions
1. LiquidQuant quantization format with 2-instruction fast dequantization
2. Implicit pipeline design overlapping all computational phases
3. 2.90x speedup over prior W4A8 kernels
4. 4.94x end-to-end system-level speedup
5. 1.12-1.63x performance gain vs. NVIDIA TensorRT-LLM quantized kernels
