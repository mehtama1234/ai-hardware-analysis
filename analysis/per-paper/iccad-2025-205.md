# GROOT: Graph Edge Re-growth and Partitioning for the Verification of Large Designs in Logic Synthesis

**Venue:** ICCAD  
**ID:** iccad-2025-205

## Problem
GNN-based verification for large circuits lacks joint framework considering chip domain knowledge, graph theory, and GPU optimization, leading to memory bottlenecks.

## Motivation


## Method
Algorithm-system co-design with polarized node feature extraction, graph partitioning algorithm with edge re-growth, and specialized GPU kernels (HD-kernel, LD-kernel) for high/low-degree node handling.

## Key Novelty
First algorithm-system co-design framework for GNN-based logic synthesis verification with domain-specific GPU optimization.

## Contributions
- Polarized AIG node feature extraction for domain knowledge
- Graph partitioning with edge re-growth for accuracy recovery
- Dual GPU kernel design for heterogeneous node distributions
- 59.38% memory reduction with 99.96% accuracy on 1B-node circuits
