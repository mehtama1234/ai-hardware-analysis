# GROOT: Graph Edge Re-growth and Partitioning for the Verification of Large Designs in Logic Synthesis

**Venue:** ICCAD  
**ID:** iccad-2025-205

## Problem
GNN-based verification for large circuits lacks joint framework considering chip domain knowledge, graph theory, and GPU optimization, leading to memory bottlenecks.

## Motivation


## Method
GROOT co-designs the algorithm and GPU implementation together, rather than separately. It extracts node features using a polarized approach that distinguishes high-degree nodes (with many connections) from low-degree nodes (with few). It partitions the graph into smaller sections and re-grows edges between them to reduce memory usage. Two specialized GPU kernels (HD-kernel for high-degree nodes, LD-kernel for low-degree nodes) optimize how each type is processed.

## Key Novelty
GROOT is the first algorithm-system co-design for circuit verification using graph neural networks, optimizing both the algorithm and GPU implementation for circuit structure.

## Contributions
- Polarized AIG node feature extraction for domain knowledge
- Graph partitioning with edge re-growth for accuracy recovery
- Dual GPU kernel design for heterogeneous node distributions
- 59.38% memory reduction with 99.96% accuracy on 1B-node circuits
