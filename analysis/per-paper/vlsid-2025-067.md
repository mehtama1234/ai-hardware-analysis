# FPUGen: A FrameWork to Generate Custom Floating Point FMA Accelerators on FPGAs

**Paper ID:** vlsid-2025-067
**Venue:** VLSID
**Confidence:** low

## Problem
ML model training and inference require flexible floating-point arithmetic with variable precision to balance accuracy, power consumption, and performance.

## Motivation
Variable bit-width floating-point can reduce computational complexity while maintaining accuracy. Need for configurable FMA accelerators adaptable to different workloads and precisions.

## Method
Framework (FPUGen) to auto-generate custom FP-FMA accelerators on FPGA with: (a) Reconfigurable units for any mantissa/exponent size, (b) DFMA support for multiple parallel operations at different precisions (1×SP32, 2×TF32, 2×HP16, or 3×BF16), (c) Dynamic precision rounding, (d) Pipelined/non-pipelined architecture options.

## Key Novelty
Automated framework for generating custom variable-precision FMA accelerators; dynamic precision support enabling multiple operations per cycle.

## Contributions
- FPUGen auto-generation framework for custom FP-FMA
- Reconfigurable mantissa/exponent sizes
- Dynamic Precision FMA (DFMA) support for 1-3 parallel ops
- Pipelined architecture achieving 56.10 GFLOP/s on ZCU104
- BF16 savings: 5.73x energy vs DP64, 2.56x vs SP32
- DFMA-V2 improvements: 1.49x resource efficiency, 3.85x better throughput, 1.71x better energy vs DFMA-V1
- 5.8x higher throughput than baseline
