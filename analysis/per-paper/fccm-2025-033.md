# EVO-QNN: Efficient Mixed-Precision Quantization Inference on RISC-V-Based Edge Device

**Problem:** Mixed-precision quantized neural networks enable resource-efficient inference but existing solutions lack high-energy-efficiency hardware acceleration on edge devices. Balancing inference precision, performance, and energy efficiency while minimizing area and power overhead remains challenging.

**Method:** EVO-QNN implements a software/hardware co-design framework that manages operator bit-widths and extends SIMD instructions on a customized RISC-V core. The framework supports 2-8 bit mixed-precision quantization for convolution operators with specialized instruction set extensions optimized for different precision levels.

**Novelty:** Mixed-precision quantization inference acceleration through RISC-V instruction set extensions with automated operator-specific bit-width management.
