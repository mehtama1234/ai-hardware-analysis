# EVO-QNN: Efficient Mixed-Precision Quantization Inference on RISC-V-Based Edge Device

**Problem:** Mixed-precision quantized neural networks enable resource-efficient inference but existing solutions lack high-energy-efficiency hardware acceleration on edge devices. Balancing inference precision, performance, and energy efficiency while minimizing area and power overhead remains challenging.

**Method:** EVO-QNN pairs software and hardware to run neural networks efficiently on edge devices. The software identifies which parts of the neural network (like convolution operators) can use lower precision representations (2-8 bit quantization, which stores numbers with fewer bits), while the hardware provides custom instructions and SIMD extensions (which process multiple data points in parallel) on a RISC-V processor so these different precision levels execute fast.

**Novelty:** Using specialized RISC-V instructions to automatically select the best precision level (2-8 bits) for each neural network operator.
