# An Energy-Efficient High-Utilization Hardware Architecture for Attention Mechanism in Transformer using Balanced Systolic Array and Multi-Row Interleaved Operation Ordering

**ID**: dac-2025-443  
**Venue**: DAC  
**Confidence**: low

## Problem
Existing attention accelerators use conventional systolic arrays that cannot balance data reuse, register savings, and utilization; layer-by-layer scheduling causes high SRAM energy for intermediate results.

## Motivation
Attention dominates Transformer latency and energy; hardware optimization requires rethinking dataflow architecture and operation scheduling.

## Method
The architecture combines two strategies. First, a Balanced Systolic Array (a processing grid where data flows through connected processors in coordinated waves) redesigns tiling—how computation is divided into memory-sized chunks—so that it can achieve both efficient data reuse AND keep all processors busy, reaching 99.5% utilization compared to conventional systolic arrays. Second, Multi-Row Interleaved operation ordering batches multiple rows of computation together, which keeps more intermediate results in fast cache instead of writing them all to slower memory (SRAM), reducing those writes by 31.7%.

## Key Novelty
Balanced systolic array that achieves high processor utilization and efficient data reuse together, combined with multi-row interleaved operation ordering to reduce SRAM energy.

## Contributions
- Balanced Systolic Array achieving 99.5% utilization
- 40% energy improvement vs conventional SAs
- Multi-Row Interleaved scheduling
- 31.7% SRAM energy reduction, 39% overall energy efficiency gain
