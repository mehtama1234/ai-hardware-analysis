# The Unwritten Contract of Cloud-based Elastic Solid-State Drives

**Venue:** DAC  
**ID:** dac-2025-348

## Problem
Performance characteristics and suitability of Elastic SSDs (ESSDs) as local SSD replacements remain uncharacterized, leaving cloud users uncertain about deployment decisions.

## Motivation
As workloads migrate to cloud, users need empirical understanding of ESSD performance contracts and trade-offs vs. local SSDs.

## Key Innovation
First comprehensive characterization of ESSD performance contracts revealing counter-intuitive behavior patterns diverging from local SSD expectations.

## Method
The researchers tested two production Elastic SSDs (cloud storage drives from AWS and Alibaba Cloud that automatically adjust capacity) by running various workloads and measuring performance. They discovered surprising patterns—these cloud drives behaved differently than expected compared to regular local SSDs. From these findings, they identified how cloud software developers can optimize code to take advantage of ESSDs' actual performance characteristics.

## Contributions
- Empirical characterization of AWS and Alibaba Cloud ESSD performance
- Four key observations about ESSD behavior contradicting conventional assumptions
- Five design implications for cloud software to exploit ESSD characteristics
- Framework for understanding storage-compute disaggregation trade-offs
