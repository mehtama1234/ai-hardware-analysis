# Towards Efficient LLM Inference via Collective and Adaptive Speculative Decoding

**Venue:** SC
**ID:** sc-2025-386
**Confidence:** low

## Problem

LLM inference bottlenecked by autoregressive one-token-at-a-time decoding; speculative decoding limited by low SSM acceptance rate and high LLM verification cost.

## Motivation

Multi-SSM collaboration and pipelined verification can improve speculative decoding efficiency by increasing acceptance rate and hiding verification latency.

## Method

Smurfs runs multiple smaller, faster models (called SSMs, or State Space Models) that each try to predict what tokens the full LLM would generate next. Instead of relying on any single prediction, it collects all their guesses and uses majority voting—only accepting tokens that most SSMs predict. These voted tokens are then verified by the full LLM in a pipelined fashion, where each new batch of predictions starts before the previous batch finishes verification, eliminating idle waiting time.

## Key Novelty

Using multiple smaller models that vote on predicted tokens instead of trusting a single model increases accuracy and reduces verification overhead in LLM inference.

## Contributions

1. Collective speculative decoding with multiple SSMs
2. Majority-voted mechanism for multi-task scenarios
3. Pipelined speculation-verification architecture
4. Adaptive speculation length determination
5. Superior throughput and latency vs state-of-the-art
