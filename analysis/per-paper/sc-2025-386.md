# Towards Efficient LLM Inference via Collective and Adaptive Speculative Decoding

**Venue:** SC
**ID:** sc-2025-386
**Confidence:** low

## Problem

LLM inference bottlenecked by autoregressive one-token-at-a-time decoding; speculative decoding limited by low SSM acceptance rate and high LLM verification cost.

## Motivation

Multi-SSM collaboration and pipelined verification can improve speculative decoding efficiency by increasing acceptance rate and hiding verification latency.

## Method

Smurfs: collective speculative decoding using majority-voted multiple SSMs; decouples SSM speculation from LLM verification with pipelined execution.

## Key Novelty

Multi-SSM majority voting for higher acceptance; dynamic speculation length tuning; pipelined decoupling of speculation and verification.

## Contributions

1. Collective speculative decoding with multiple SSMs
2. Majority-voted mechanism for multi-task scenarios
3. Pipelined speculation-verification architecture
4. Adaptive speculation length determination
5. Superior throughput and latency vs state-of-the-art
