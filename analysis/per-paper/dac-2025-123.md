# Segmented Angular Pre-Processing for Accurate and Efficient In-Memory Vector Similarity Search

**Venue:** DAC | **ID:** dac-2025-123

## Core Problem
Energy-efficient vector similarity search using cosine similarity in high dimensions for few-shot learning and approximate nearest neighbor search.

## Method
Seg-Cos leverages EX-TCAM and Best-TCAM via segmented angular encoding (circular ranges by angle/magnitude), Locality-aware Compute Mapping to minimize row activations, and LUT Aggregation for multi-precision.

## Key Novelty
First TCAM-based framework directly approximating cosine similarity (angular metric), compatible with both EX-TCAM and Best-TCAM.

## Contributions
- First angular VSS in TCAM (Seg-Cos framework)
- Segmented circular-range vector encoding
- Locality-aware Compute Mapping
- LUT Aggregation for multi-precision
- 1.41x-2x energy efficiency; 2.2%-52% accuracy improvements
