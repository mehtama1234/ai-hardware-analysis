# Segmented Angular Pre-Processing for Accurate and Efficient In-Memory Vector Similarity Search

**Venue:** DAC | **ID:** dac-2025-123

## Core Problem
Energy-efficient vector similarity search using cosine similarity in high dimensions for few-shot learning and approximate nearest neighbor search.

## Method
The Seg-Cos framework divides vectors into segments and encodes them as ranges on a circle based on angles and magnitudes (direction and length). This encoding works directly on TCAM hardware (EX-TCAM and Best-TCAM), which can search all ranges in parallel. Locality-aware Compute Mapping minimizes memory row activations, and LUT Aggregation combines multiple small look-up table results to handle different precision levels.

## Key Novelty
This framework is the first to directly approximate cosine similarity (an angular metric for measuring vector alignment) within TCAM hardware, compatible with both EX-TCAM and Best-TCAM.

## Contributions
- First angular VSS in TCAM (Seg-Cos framework)
- Segmented circular-range vector encoding
- Locality-aware Compute Mapping
- LUT Aggregation for multi-precision
- 1.41x-2x energy efficiency; 2.2%-52% accuracy improvements
