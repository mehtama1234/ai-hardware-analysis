# Flexible Thermal Conductance Model (TCM) for Efficient Thermal Simulation of 3-D ICs and Packages

**Venue**: DATE  
**Primary Theme**: Efficient 3D IC thermal simulation  

## Problem
Thermal simulation of 3D ICs and packages is computationally expensive, requiring large solution domains and extensive simulations despite the fact that only specific regions (ROI) contain key thermal design components.

## Method
Instead of simulating the entire 3D structure, the method splits it into a Region of Interest (ROI—where the important thermal components are) and a Region of Fixity (ROF—the rest). It then simulates only the ROI, using a flexible thermal conductance model (TCM) to represent how the ROF region thermally affects the ROI. The TCM uses rational expressions (fractions of polynomials)—which encode the steady-state thermal impact as a function of varying boundary conditions like cooling rates—so the model adapts to different scenarios without re-running the full simulation.

## Key Novelty
A thermal conductance model using rational expressions (polynomial fractions) predicts how outer regions thermally affect the inner region without full re-simulation, and adapts to changing boundary conditions.

## Contributions
- 138x speedup compared to commercial software
- Flexible boundary condition handling for varying thermal scenarios
- Significant reduction in computational domain and memory requirements
