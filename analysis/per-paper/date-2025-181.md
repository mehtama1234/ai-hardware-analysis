# Flexible Thermal Conductance Model (TCM) for Efficient Thermal Simulation of 3-D ICs and Packages

**Venue**: DATE  
**Primary Theme**: Efficient 3D IC thermal simulation  

## Problem
Thermal simulation of 3D ICs and packages is computationally expensive, requiring large solution domains and extensive simulations despite the fact that only specific regions (ROI) contain key thermal design components.

## Method
The method partitions the structure into Region of Interest (ROI) and Region of Fixity (ROF), constraining the solution domain to the ROI. A flexible thermal conductance model (TCM) with rational expressions represents the thermal impact of ROF as boundary conditions, enabling efficient handling of varying boundary conditions.

## Key Novelty
Flexible TCM with elegant rational expressions for heat convection coefficients that adapts to varying boundary conditions while constraining computation to ROI.

## Contributions
- 138x speedup compared to commercial software
- Flexible boundary condition handling for varying thermal scenarios
- Significant reduction in computational domain and memory requirements
