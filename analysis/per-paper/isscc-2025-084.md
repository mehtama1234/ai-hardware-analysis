# isscc-2025-084: High-Speed Distributed Voltage Droop Detector

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
Voltage droop detection needs PVT tolerance + remote distribution; TDC-based detectors lack robustness; analog detectors have large area/routing constraints.

## Motivation
Per-core voltage scaling critical for power efficiency in modern SoCs; requires accurate, fast droop detection.

## Method
2nm GAAFET architecture: compact distributed remote droop detectors (RDD) sampling at 4GHz, synchronized by PVT-tolerant centralized droop detection controller (DDC).

## Key Novelty
Distributed remote detectors with centralized PVT-tolerant control enabling high-frequency sampling without routing overhead.

## Contributions
- 0.69% detection accuracy
- <2-cycle latency at 4GHz
- Distributed remote sensing
- PVT-tolerant centralized control

## Metrics
- Accuracy: 0.69%
- Latency: <2 cycles
- Frequency: 4 GHz
- Technology: 2nm GAAFET
