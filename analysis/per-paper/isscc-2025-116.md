# isscc-2025-116: Sub-1V Core-MOS Voltage Reference

**Problem:** Sub-1V PVT-independent references face headroom limits; DNW approaches non-standard; switched-cap requires large ripple filters.

**Method:** This design creates a stable voltage reference that works at just 0.8V power supply—a challenge because traditional approaches using BJTs (bipolar transistors) need significant voltage overhead to function, and existing solutions required either special non-standard transistor structures or large filtering circuits. Instead, it uses charge-pump and switched-capacitor circuits (transistor-based switching techniques that manage voltage with minimal overhead rather than pushing steady current through components). The result is exceptional: the voltage drifts only 31 parts per million per degree Celsius as temperature changes, and it rejects power-supply noise across DC-to-GHz frequencies by -40dB (meaning interference is reduced to roughly 1/10,000th of its original strength), all within just 294µm² using only standard core transistors.

**Key Novelty:** Standard-Vth MOS-only achieving 0.8V operation with high PSRR and minimal 294µm² area.

**Main Results:** 31ppm/°C temperature coefficient, -40dB DC-to-GHz PSRR, 294µm² area.

**Confidence:** Low (abstract-only analysis)
