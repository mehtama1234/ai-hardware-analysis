# Comparing Graph Algorithm Styles on NVIDIA and AMD GPUs

**ID**: sc-2025-367
**Venue**: SC
**Confidence**: low

## Problem
Portability of GPU graph algorithms across vendor platforms (NVIDIA vs AMD)

## Motivation
Emerging hardware and scale challenge existing approaches

## Method
They converted graph algorithm implementations from CUDA (NVIDIA's GPU programming language) to HIP, a compatibility layer that allows code to run on both NVIDIA and AMD GPUs. The conversion involves translating the GPU kernels—the specialized computational code that executes directly on the GPU—to use HIP's standardized interface instead of CUDA-specific features. After porting, they ran performance benchmarks on both NVIDIA and AMD hardware to measure how efficiently the algorithms execute on each platform.

## Key Novelty
Using HIP, they enabled the same graph algorithms to run on both NVIDIA and AMD GPUs and measured the performance difference between the two platforms.
