# Energy-Efficient Multi-Operand XOR Logic-Based CIM Accelerator using RRAM technology

**Venue:** ICCAD  
**ID:** iccad-2025-188

## Problem
Compute-in-memory (CIM) accelerators with standard RRAM suffer from energy overhead in multi-operand operations; XOR-based logic-in-memory can reduce switching activity but requires efficient circuit design.

## Motivation
RRAM-based CIM with XOR logic reduces energy per operation for sparse neural networks and graph algorithms; logic in RRAM memory eliminates data movement overhead.

## Method
The design embeds XOR logic gates (basic logical operators) directly into an RRAM crossbar array—a grid of resistive memory elements that can perform computations. To handle multi-input operations, it uses a voltage-to-time converter: a circuit that translates voltage signals into time delays (encoding the answer as how quickly a signal crosses a threshold), which are then read out. Careful tuning of timing and voltage settings minimizes the energy wasted on unnecessary switching while maintaining accuracy.

## Key Novelty
Voltage-to-time conversion (translating voltage signals into time delays) allows XOR-logic RRAM arrays to compute multiple-input operations directly in memory with minimal energy waste.

## Contributions
1. RRAM crossbar design with embedded XOR logic operators
2. Voltage-to-time converter for multi-operand operations
3. Energy-efficiency analysis for sparse neural networks
4. Demonstrated improvements over standard RRAM CIM
