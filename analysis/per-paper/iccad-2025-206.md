# COPA: A Congestion-Oriented Pin Assignment Framework for Intra-Block Physical Design Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-206

## Problem
Hierarchical IC pin assignment focuses on wirelength minimization but overlooks impact on internal routing congestion and feedthrough pin placement.

## Motivation


## Method
Congestion-oriented gradient-based optimization framework iteratively adjusting feedthrough pin positions based on routing-demand-driven congestion metrics.

## Key Novelty
First framework explicitly targeting feedthrough pin assignment to minimize routing congestion within hierarchical designs.

## Contributions
- Formulation of feedthrough pin assignment as nonlinear optimization
- Gradient-based algorithm with congestion-severity quantification
- 7.6% average routing overflow reduction without wirelength increase
- Industrial validation on multiple testcases
