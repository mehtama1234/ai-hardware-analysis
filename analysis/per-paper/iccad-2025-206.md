# COPA: A Congestion-Oriented Pin Assignment Framework for Intra-Block Physical Design Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-206

## Problem
Hierarchical IC pin assignment focuses on wirelength minimization but overlooks impact on internal routing congestion and feedthrough pin placement.

## Motivation


## Method
The framework repeatedly repositions feedthrough pins—internal connection points that pass through the chip's hierarchy levels—using a gradient-based optimization approach (making small adjustments to find the best solution). After each move, it measures how crowded the routing paths become (congestion) based on signal flow patterns, then uses this measurement to guide the next adjustment. This process repeats until congestion stops improving.

## Key Novelty
The first to reduce routing congestion in hierarchical designs by optimizing feedthrough pin placement (where internal connections pass between hierarchy levels) rather than just minimizing wire length.

## Contributions
- Formulation of feedthrough pin assignment as nonlinear optimization
- Gradient-based algorithm with congestion-severity quantification
- 7.6% average routing overflow reduction without wirelength increase
- Industrial validation on multiple testcases
