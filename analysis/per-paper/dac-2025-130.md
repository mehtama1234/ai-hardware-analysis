# HH-PIM: Dynamic Optimization of Power and Performance with Heterogeneous-Hybrid PIM for Edge AI Devices

**Venue:** DAC | **ID:** dac-2025-130

## Core Problem
Energy-efficient PIM for edge AI; hybrid PIM with MRAM/ReRAM reduces power but has mismatch between fixed resources and dynamic workloads.

## Method
The system puts two types of processing cores directly into memory chips—one built for speed, one built for low power—each with both nonvolatile memory (MRAM, which retains data without power) and fast memory (SRAM). An algorithm watches what computation each piece of data needs and automatically moves data to the core type that will handle it most efficiently, shifting workload between cores as demands change. By keeping simple tasks on low-power cores and complex ones on fast cores, the system avoids wasting energy on unnecessary high-performance processing.

## Key Novelty
The key innovation is using two different types of processing cores and automatically choosing which one processes each piece of data, adapting in real-time to minimize energy use.

## Contributions
- HH-PIM with heterogeneous compute modules
- Dynamic data placement optimization
- 60.43% energy savings vs. conventional PIMs
- FPGA prototyping and validation
