# A High-Precision and Low-Cost Approximate Transform Accelerator for Video Coding

**Venue:** DAC 2025  
**Confidence:** low (abstract-only)

## Problem
Multiple transform types in Versatile Video Coding (VVC) require separate hardware implementations, causing substantial area overhead. Unifying transform circuits while maintaining precision is challenging.

## Key Insight
Diagonal aggregation properties in DCT2–DST7 transfer matrices enable sparse least-squares approximation, allowing a single shift-adder unit to handle multiple transform types and sizes.

## Approach
- Exploit mathematical structure (diagonal aggregation) in DCT2–DST7 matrices
- Apply least-squares optimization to sparsify transfer matrices
- Design lightweight matrix decomposition for efficient product generation
- Unified architecture supporting 4–32 point transforms for three VVC types

## Results
- **44% area reduction** with only 0.53% BD-BR quality loss
- Sustains 8K video at 57 fps
- Eliminates redundant transform circuits through approximate conversion

## Hardware Target
- ASIC (video codec accelerator)

- Kernel fusion
