# SubtreeLU: High-Performance Parallel Sparse LU Factorization for Circuit Simulation

**ID:** iccad-2025-030  
**Venue:** ICCAD

## Problem
Parallel sparse LU factorization for circuit simulation faces synchronization overheads, conservative dependency estimation, and under-utilization of supernodal structures in existing SPICE solvers.

## Motivation
Solving sparse linear systems via LU factorization is a critical performance bottleneck in SPICE-based circuit simulation.

## Method
SubtreeLU reshapes the separator tree—the structure that nested dissection creates from circuit equations—by combining or splitting pieces to form a private-pipeline where processors work independently without synchronizing. It supports both pivoting (reordering values for numerical stability) and non-pivoting modes. Supernodal methods batch related operations together to speed up the numerical calculations.

## Key Novelty
Reorganizing the separator tree into a private-pipeline structure that decouples synchronization constraints, allowing processors to work independently in parallel sparse LU factorization.

## Contributions
1. Novel scheduling framework for organizing computation into private-pipeline structures that eliminate synchronization bottlenecks
2. Support for both pivoting and non-pivoting modes in a unified framework
3. Supernodal method integration for improved numerical update acceleration
4. Consistent improvements in accuracy, runtime, and scalability on 46 circuit matrices versus NICSLU and CKTSO
