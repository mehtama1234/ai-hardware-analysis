# SDR-RDMA: Software-Defined Reliability Architecture for Planetary Scale RDMA Communication

**Venue:** SC

## Problem
RDMA reliability layer design is complicated by millisecond-scale long-haul latencies; Selective Repeat inefficient for some link conditions

## Motivation
Enable flexible, efficient reliability schemes for inter-datacenter RDMA communication adapted to link characteristics

## Method
RDMA (Remote Direct Memory Access) needs error recovery when data travels long distances, but traditional Selective Repeat doesn't work well at millisecond-scale latencies. SDR-RDMA solves this with a software-defined approach that lets you customize the error-recovery strategy. It tracks received packets using a receive buffer bitmap and offloads the high-speed work to a Data Path Accelerator (DPA), specialized hardware that maintains line-rate (full network speed) performance without slowing anything down.

## Key Novelty
SDR-RDMA enables software-defined error recovery for remote memory transfers, letting you choose strategies beyond Selective Repeat while maintaining line-rate performance and zero-copy semantics.

## Contributions
- SDR-RDMA architecture with receive buffer bitmap for partial completion
- Extensible reliability scheme support (Selective Repeat, Erasure Coding variants)
- DPA offload implementation for line-rate performance
