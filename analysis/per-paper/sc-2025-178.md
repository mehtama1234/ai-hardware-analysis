# SDR-RDMA: Software-Defined Reliability Architecture for Planetary Scale RDMA Communication

**Venue:** SC

## Problem
RDMA reliability layer design is complicated by millisecond-scale long-haul latencies; Selective Repeat inefficient for some link conditions

## Motivation
Enable flexible, efficient reliability schemes for inter-datacenter RDMA communication adapted to link characteristics

## Method
SDR-RDMA software-defined reliability stack with receive buffer bitmap; DPA offload for line-rate performance; extensible reliability schemes

## Key Novelty
Software-defined RDMA reliability enabling custom schemes beyond Selective Repeat; DPA offload achieving line-rate; preserves zero-copy semantics

## Contributions
- SDR-RDMA architecture with receive buffer bitmap for partial completion
- Extensible reliability scheme support (Selective Repeat, Erasure Coding variants)
- DPA offload implementation for line-rate performance
