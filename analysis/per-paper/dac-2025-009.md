# Pipirima: Predicting Patterns in Sparsity to Accelerate Matrix Algebra

**Problem:** Load imbalance from unpredictable non-zero distributions in sparse matrices limits accelerator performance.

**Method:** Pipirima predicts where non-zero values will appear in sparse matrices using simple counters inspired by CPU branch predictors. When streaming through a compressed matrix (CSR, a compact way to store sparse matrices), these predictions let the accelerator prepare its processing units in advance, preventing load imbalance where some units sit idle while others are overloaded. The system is tested on sparse matrix-vector multiplication (SpMV) and sparse matrix-matrix multiplication (SpMM).

**Key Contribution:** Pattern prediction mitigates load imbalance in sparse accelerators with minimal resource overhead.

**Results:** 6x speedup over Tensaurus (SpMM), 40x over ExTensor; 45nm: 5.621 mm^2, 544.93 mW.
