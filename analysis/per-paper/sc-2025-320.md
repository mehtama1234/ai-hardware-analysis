# MPPI - Type safe C++ Datatypes for MPI

**Venue:** SC
**ID:** sc-2025-320
**Confidence:** low

## Problem Statement
MPI's C-API requires users to manually describe buffer memory layouts for communication, which is error-prone and lacks type safety in modern object-oriented C++ code.

## Motivation
Object-oriented C++ applications are standard but MPI datatype construction is verbose and manual; modern C++ features (concepts, ranges, reflection) can automate this at compile-time.

## Method
MPPI uses C++20 language features—concepts (rules defining what operations a type supports), ranges (sequences of elements), and reflection (inspecting a type's internal structure)—to automatically examine your C++ data types at compile-time (when the code is being prepared to run). It generates the correct MPI datatypes describing how your data should be communicated, eliminating the error-prone manual work of describing memory layouts.

## Key Novelty
The tool automatically extracts MPI datatype information from C++ types at compile-time using C++20 features, removing the need for manual specification.
