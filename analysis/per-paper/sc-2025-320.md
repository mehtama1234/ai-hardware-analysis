# MPPI - Type safe C++ Datatypes for MPI

**Venue:** SC
**ID:** sc-2025-320
**Confidence:** low

## Problem Statement
MPI's C-API requires users to manually describe buffer memory layouts for communication, which is error-prone and lacks type safety in modern object-oriented C++ code.

## Motivation
Object-oriented C++ applications are standard but MPI datatype construction is verbose and manual; modern C++ features (concepts, ranges, reflection) can automate this at compile-time.

## Method
MPPI: C++-API and datatype engine leveraging C++20 concepts, ranges, and upcoming reflection to extract datatype information at compile-time; automatic MPI datatype construction.

## Key Novelty
Compile-time MPI datatype extraction from C++ types using modern language features (concepts/reflection), eliminating manual datatype specification.

## Contributions
1. Type-safe C++ MPI API with compile-time datatype extraction
2. Zero-overhead abstraction with no performance penalty
3. Simplification of distributed C++ code development
