# NNQS-SCI: Tackling Trillion-Dimensional Hilbert Space with Adaptive Neural Network Quantum States

**Venue:** SC

## Problem
Scaling NNQS to large chemical systems requires managing trillion-dimensional Hilbert spaces while preserving accuracy

## Motivation
Enable high-accuracy quantum many-body simulations on HPC platforms with trillion-dimensional state spaces

## Method
The approach combines neural networks—which learn patterns in quantum system behavior—with a filtering technique called Selected Configuration Interaction (SCI, which selects only the most important quantum states to simulate). Instead of calculating all possible states for large systems (which is infeasible), the system automatically chooses which ones to include based on their importance. It runs the Slater-Condon rules (the mathematical calculations for quantum interactions) in parallel across multiple processors and uses memory compression to efficiently handle the vast space of quantum states.

## Key Novelty
NNQS-SCI scales to 152 spin orbitals (representing over 10^14 possible quantum states) through adaptive configuration selection, which maintains accuracy without arbitrary limits.

## Contributions
- NNQS-SCI architecture combining neural networks with exact SCI for accuracy
- Parallelized Slater-Condon rules for efficient local energy computation
- Adaptive SCI engine managing billions of configurations without space explosion
