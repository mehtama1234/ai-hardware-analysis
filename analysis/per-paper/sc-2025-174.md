# NNQS-SCI: Tackling Trillion-Dimensional Hilbert Space with Adaptive Neural Network Quantum States

**Venue:** SC

## Problem
Scaling NNQS to large chemical systems requires managing trillion-dimensional Hilbert spaces while preserving accuracy

## Motivation
Enable high-accuracy quantum many-body simulations on HPC platforms with trillion-dimensional state spaces

## Method
NNQS combined with Selected Configuration Interaction (SCI); parallelized Slater-Condon rules; adaptive SCI engine with multi-level parallelism and memory compression

## Key Novelty
NNQS-SCI handling up to 152 spin orbitals (>10^14 Hilbert dimensions); adaptive configuration management avoiding accuracy loss and arbitrary cutoffs

## Contributions
- NNQS-SCI architecture combining neural networks with exact SCI for accuracy
- Parallelized Slater-Condon rules for efficient local energy computation
- Adaptive SCI engine managing billions of configurations without space explosion
