# EGIS: Entropy Guided Image Synthesis for Dataset-Agnostic Testing of RRAM-Based DNNs

**Venue**: DATE  
**Primary Theme**: Privacy-preserving RRAM DNN manufacturing test  

## Problem
RRAM-based DNNs are vulnerable to manufacturing process variations; post-manufacture testing requires dataset access which may be unavailable due to privacy constraints.

## Method
The method creates artificial test images and uses entropy—a measure of information diversity—to guide which images reveal the most about how a chip behaves under manufacturing variations. It then selects a compact set of just 10-20 images from these synthetic options that capture all the important testing scenarios. Finally, it uses a machine learning model to detect outlier patterns in how the chip responds to these images, classifying each test result as pass or fail.

## Key Novelty
The core idea is using entropy-guided synthetic images to test manufacturing variations without needing the original training data.

## Contributions
- Entropy-guided synthetic image dataset generation
- Compact test image subset (10-20 images) for rapid testing
- ML-based outlier detection for RRAM crossbar quality assessment
- Test accuracy comparable to contemporary methods
