# Sensor-Less Laser Voltage-Probing Attack Detection

**Venue:** ISSCC  
**ID:** isscc-2025-240

## Problem
Laser voltage probing (LVP) attacks achieve near-100% success at probing on-chip voltages through backside laser illumination. Current detection approaches lack effective sensor-less mechanisms.

## Solution
Run-time leakage-shift monitoring detects laser-induced anomalies by observing device leakage current changes from photocurrent injection, enabling low-overhead attack detection without dedicated sensors.

## Key Innovation
Sensor-less LVP detection via leakage-shift signatures without photodiode infrastructure.

## Results
- **Area overhead:** 4.35%
- **Detection coverage:** Near 100% attack success prevention

ASIC
