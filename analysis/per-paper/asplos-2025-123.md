# RESCQ: Realtime Scheduling for Continuous Angle Quantum Error Correction Architectures

**Venue:** ASPLOS  
**Authors:** Sayam Sethi, Jonathan Mark Baker  
**Confidence:** low (abstract only)

## Problem
Continuous angle quantum error correction architectures require non-deterministic resource state production, meaning statically generated schedules waste cycles when states fail and must be re-attempted. Without a realtime scheduler, execution time is unnecessarily long and classical control overhead can dominate.

## Motivation
Large-scale quantum error correction is bottlenecked by expensive resource state preparation; continuous angle rotation alternatives are non-deterministic and require dynamic resource management that static scheduling cannot provide.

## Method
RESCQ is a real-time scheduler for quantum computers using continuous-angle error correction—a technique where quantum states are constantly rotated in small angles to fix errors as they happen. RESCQ predicts how reliably each quantum state can be created using expected production rates, and uses those predictions to dynamically allocate resources to the most urgent tasks. When state creation actually fails (which is unpredictable), RESCQ quickly reassigns resources from less urgent to more urgent operations to keep total runtime short. To prevent excessive overhead from constant rescheduling, RESCQ also adjusts how often it recalculates its schedule based on system stability.

## Key Novelty
RESCQ's key innovation is dynamically redistributing quantum resources on-demand in continuous-angle error correction systems, adaptively adjusting rescheduling frequency to balance speed against scheduling overhead.

## Contributions
- RESCQ: a realtime scheduler for continuous angle rotation QEC architectures
- On-demand resource redistribution based on expected production rates
- Adaptive recomputation frequency to limit classical control overhead
- Average 2x cycle count improvement over baseline static proposals
