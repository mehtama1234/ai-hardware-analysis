# RESCQ: Realtime Scheduling for Continuous Angle Quantum Error Correction Architectures

**Venue:** ASPLOS  
**Authors:** Sayam Sethi, Jonathan Mark Baker  
**Confidence:** low (abstract only)

## Problem
Continuous angle quantum error correction architectures require non-deterministic resource state production, meaning statically generated schedules waste cycles when states fail and must be re-attempted. Without a realtime scheduler, execution time is unnecessarily long and classical control overhead can dominate.

## Motivation
Large-scale quantum error correction is bottlenecked by expensive resource state preparation; continuous angle rotation alternatives are non-deterministic and require dynamic resource management that static scheduling cannot provide.

## Method
RESCQ is a realtime scheduler for continuous angle QEC architectures that actively redistributes resources on-demand based on expected production rates of rotation states. It monitors resource state generation success and dynamically reassigns resources to minimize total cycle count. To control classical control overhead, RESCQ adaptively selects the recomputation frequency based on system state.

## Key Novelty
Dynamic, on-demand redistribution of quantum resources in continuous angle QEC systems with adaptive recomputation frequency to balance cycle-count minimization against classical control overhead.

## Contributions
- RESCQ: a realtime scheduler for continuous angle rotation QEC architectures
- On-demand resource redistribution based on expected production rates
- Adaptive recomputation frequency to limit classical control overhead
- Average 2x cycle count improvement over baseline static proposals
