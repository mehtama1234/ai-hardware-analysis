# isscc-2025-038: Hybrid CNN-Transformer Accelerator

**Title:** A 28nm 0.22μJ/Token Memory-Compute-Intensity-Aware CNN-Transformer Accelerator with Hybrid-Attention-Based Layer-Fusion and Cascaded Pruning for Semantic-Segmentation

**Venue:** ISSCC

## Core Contribution
28nm hybrid CNN-Transformer accelerator achieving 0.22μJ/token for semantic segmentation via hybrid-attention layer-fusion and cascaded pruning.

## Key Metrics
- **Energy:** 0.22μJ/token
- **Technology:** 28nm
- **Token Length:** >16K TL

## Problem
ConvFormers suffer from (1) on-chip buffering limits at high sparsity, (2) infeasible K/V/weight simultaneous buffering in layer-fusion, (3) low sparsity in segmentation head.

## Method
The 28nm chip uses three techniques to process hybrid CNN-Transformer models efficiently. It schedules computation to balance memory access and computing demands (memory-compute-intensity-aware dataflow) and merges attention layers with a hybrid approach (hybrid-attention-based layer-fusion) that avoids redundant reloads of Key/Value cache and model weights from external memory. It also removes unimportant weights across the backbone and segmentation head (cascaded pruning), even where sparsity is naturally low. These techniques achieve 0.22μJ per token.
