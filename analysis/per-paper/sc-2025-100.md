# SC25 Paper Analysis: sc-2025-100

## MPI Collectives with Programmable Smart Switches

### Summary
mpitofino demonstrates how to offload MPI collective operations (particularly reductions) onto programmable Ethernet switches (Intel Tofino). Using P4 programming and RoCEv2, it achieves near-line-rate throughput while reducing latency for data-intensive HPC and ML workloads.

### Key Problem
- **Collective Overhead**: MPI collective operations create communication bottlenecks
- **Switch Underutilization**: Programmable switches are deployed in clouds but not exploited in HPC
- **Latency Challenge**: Host-based collective execution adds significant latency

### Technical Approach
1. **Programmable Switch Target**: Intel Tofino ASIC with P4 programming
2. **RoCEv2 Protocol**: Leverages existing RDMA support on NICs
3. **On-Chip Processing**: Low-latency collective execution on switch fabric
4. **Open MPI Integration**: Transparent collective provider in MPI stack

### Key Components
- **P4 Programs**: Custom reduction operations on switch data path
- **RoCEv2 Integration**: Compatibility with standard RDMA hardware
- **RDMA Hardware**: NIC-level RDMA support for efficiency
- **Ethernet Fabric**: Standard data center networking

### Contributions
1. mpitofino prototype for collective offloading
2. P4 implementation of MPI reduction operations
3. RoCEv2 integration with RDMA hardware support
4. Open MPI collective provider implementation
5. Demonstration of near-line-rate throughput (100GBit/s)
6. Scalable collective communication architecture
7. Blueprint for network-level MPI optimization

### Hardware & Workloads
- **Target Hardware**: Intel Tofino programmable switches, RDMA-capable NICs
- **Workloads**: Data-intensive HPC applications, ML training, collective communication patterns

### Performance Results
- **Throughput**: Near 100GBit/s line rate
- **Communication**: Low-latency network-level execution

### Applications
- HPC interconnect optimization
- ML training communication optimization
- Data center collective operations

Network-Level Communication Optimization
