# asplos-2025-143: Enabling Efficient Mobile Tracing with BTrace

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing mobile tracing tools use distributed per-core or per-thread buffers that prioritize performance but miss crucial trace events with high probability in smartphone scenarios, limiting their usefulness for diagnosing stability issues.

## Motivation
Smartphones require detailed, complete system traces for diagnosing stability and optimizing user experience, but server-oriented distributed buffer designs are poorly suited to mobile's dense, latency-sensitive event workloads.

## Method
Existing mobile tracing tools use per-core or per-thread distributed buffers that prioritize speed but lose events when buffers overflow. BTrace replaces this with a centralized or coordinated buffering approach—all events flow through a single collection point rather than independent buffers on each core—which preserves event completeness and ordering. This design maintains acceptable performance overhead while ensuring trace reliability, essential for diagnosing smartphone stability issues.

## Key Novelty
BTrace trades processing throughput for trace completeness by using centralized or coordinated buffering instead of per-core/per-thread distributed buffers, preventing the event loss endemic to existing mobile tracing.
