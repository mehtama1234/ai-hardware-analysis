# asplos-2025-143: Enabling Efficient Mobile Tracing with BTrace

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing mobile tracing tools use distributed per-core or per-thread buffers that prioritize performance but miss crucial trace events with high probability in smartphone scenarios, limiting their usefulness for diagnosing stability issues.

## Motivation
Smartphones require detailed, complete system traces for diagnosing stability and optimizing user experience, but server-oriented distributed buffer designs are poorly suited to mobile's dense, latency-sensitive event workloads.

## Method
BTrace redesigns the tracing buffer management and synchronization strategy specifically for smartphones, using a coordinated buffering approach that preserves event completeness while maintaining acceptable performance overhead, tailored to the mobile system software stack.

## Key Novelty
A tracing buffer architecture for smartphones that trades some throughput for substantially improved trace completeness, avoiding the event loss endemic to per-core distributed tracing on mobile.

SoC (smartphone)
