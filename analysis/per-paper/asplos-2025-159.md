# DejaVuzz: Disclosing Transient Execution Bugs with Dynamic Swappable Memory and Differential Information Flow Tracking Assisted Processor Fuzzing

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing hardware fuzzers for detecting transient execution vulnerabilities (e.g., Spectre, Meltdown variants) suffer from poor microarchitectural controllability and observability: they cannot reliably set up the precise microarchitectural state needed to trigger transient execution paths, nor detect covert information leakage resulting from such paths.

## Motivation
Transient execution attacks remain a critical threat to modern CPUs, and manual or undirected fuzzing approaches miss subtle variants due to inability to observe information flow at the microarchitectural level.

## Method
DejaVuzz combines two complementary techniques: Dynamic Swappable Memory (DSM) swaps physical memory pages at runtime to precisely control the processor's microarchitectural state—its TLBs (address-translation caches), caches, and branch predictors—which enables triggering transient execution bugs. Differential Information Flow Tracking (DIFT) instruments the processor simulator to detect whether secret data leaks through these bugs by monitoring if information flows from a secret source to an observable side channel like cache timing. The fuzzer generates test programs using DSM to reset the microarchitectural state between tests, then uses DIFT differential analysis to identify which tests actually cause information leakage, achieving both comprehensive coverage and precise detection.

## Key Novelty
Combining dynamic swappable memory to control processor state with information flow tracking to detect secret data leaks enables both reliable triggering and detection of transient execution bugs.

## Contributions
- Dynamic Swappable Memory (DSM) mechanism enabling fine-grained microarchitectural state control
- Differential Information Flow Tracking (DIFT) for detecting covert leakage through transient execution side channels
- End-to-end fuzzing framework for large-scale out-of-order processor designs
- Empirical discovery of new transient execution vulnerabilities
