# INSTA: An Ultra-Fast, Differentiable, Statistical Static Timing Analysis Engine for Industrial Physical Design Applications

**Venue:** DAC
**ID:** dac-2025-235

## Problem
GPU-accelerated STA (static timing analysis) fails to gain adoption because it cannot emulate proprietary delay models of commercial tools; high-accuracy incremental timing for iterative design loops is slow.

## Motivation
Physical design optimization (gate sizing, placement) requires millions of timing queries; gradient-based optimization demands differentiable timing models.

## Method
The approach uses a graphics processor (GPU) to speed up static timing analysis—the process of checking whether signals in a chip design propagate fast enough to meet timing targets. It starts from delay predictions of a commercial reference tool (one-time initialization), then fine-tunes itself on the GPU to match that tool's delay model. Because the engine's math is differentiable (you can compute how small changes propagate through the calculations), it can calculate gradients—directions for tweaking gate sizes and placements to improve timing—making incremental design updates 25 times faster than traditional methods.

## Key Novelty
A GPU-accelerated timing analyzer that is calibrated to match commercial tools (achieving 0.999 correlation) and differentiable, enabling gradient-based optimization across chip designs.

## Contributions

- First differentiable statistical GPU-STA engine
- Calibration from commercial tool for high accuracy
- 25x faster incremental timing updates
- INSTA-Size achieves 15% better TNS with 68% fewer gates
- INSTA-Place improves HPWL 16% and TNS 59.4% on ICCAD benchmarks
