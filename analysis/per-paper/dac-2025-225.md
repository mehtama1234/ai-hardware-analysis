# SynCircuit: Automated Generation of New Synthetic RTL Circuits Can Enable Big Data in Circuits

**Venue:** DAC
**ID:** dac-2025-225

## Problem
Scarcity of circuit design data limits AI-assisted IC design. Existing generative models cannot reliably generate valid HDL circuits with correct digital logic.

## Motivation
Circuit dataset availability is the primary bottleneck preventing ML model scaling in automated design.

## Method
The method uses a diffusion-based generative model (an AI trained to reverse the process of corrupting data) to create circuit designs represented as directed acyclic graphs—connection diagrams with no loops. Constraint refinement then validates that the generated circuits follow valid digital logic rules. Finally, Monte Carlo tree search (a strategic exploration technique) removes redundant components to optimize each circuit.

## Key Novelty
The core idea is using a diffusion-based generative model to automatically generate circuit designs represented as directed acyclic graphs, with constraint-guided refinement to ensure the generated circuits follow valid digital logic.

## Contributions

- Customized diffusion model for directed acyclic graph generation in HDL
- Constraint-based refinement to ensure circuit validity
- MCTS-based optimization for logic redundancy reduction
- Demonstration of improved downstream ML model performance
