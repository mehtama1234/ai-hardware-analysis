# asplos-2025-098: FLEXPROF: Flexible, Side-Channel-Free Memory Access

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
Secure memory controllers that prevent microarchitectural side-channels by allocating fixed 'turns' to co-scheduled VMs impose a ~2x performance slowdown because the schedule must conservatively handle worst-case mixed read/write patterns, leaving memory bus utilization inefficient.

## Motivation
Eliminating timing-based memory side-channels in shared cloud systems is essential for VM isolation, but the current overhead of 2x slowdown makes secure scheduling impractical for production workloads.

## Method
FlexProf uses two types of memory scheduling slots (called turns), each sized and structured for its dominant operation: read-optimized turns and write-optimized turns. It determines which type each application needs through coarse-grain profiling (measuring patterns) that observes read/write ratios without revealing sensitive timing information. When a read-optimized turn finishes reading, it can opportunistically handle writes if the read slots are idle, and vice versa, keeping the memory bus busier. This flexible approach preserves the fixed-turn structure that blocks timing attacks—where one program measures memory speed to deduce secrets—between co-scheduled VMs.

## Key Novelty
Splitting memory scheduling into read-optimized and write-optimized types—chosen by secure, coarse profiling (measuring safely without leaking timing information)—recovers speed wasted by overly cautious worst-case scheduling.

## Contributions
- Read-optimized and write-optimized turn types matched to application access patterns via coarse profiling.
- Opportunistic cross-turn operation issuance that preserves isolation guarantees while improving utilization.
- Up to 33% performance improvement (geometric mean 8%) over state-of-the-art on mixed workloads.
