# dyGRASS: Dynamic Spectral Graph Sparsification via Localized Random Walks on GPUs

**ID:** iccad-2025-252

## Problem
Graph sparsification for both edge insertions and deletions is computationally expensive. Existing algorithms like inGRASS lack efficiency for dynamic graphs.

## Motivation
Dynamic graph sparsification enables efficient processing of evolving datasets in optimization, network analysis, and CAD tools.

## Method
GPU-accelerated dynamic graph sparsification using localized random walks. Handles both edge insertions and deletions efficiently. Achieves 10× speedup over inGRASS algorithm.

## Key Novelty
GPU-accelerated dynamic graph sparsification with localized random walks supporting both insertions and deletions.

## Contributions
- GPU-based dynamic graph sparsification
- Localized random walk algorithm
- Insertion and deletion support
- 10× speedup over inGRASS
- Efficient dynamic graph processing
