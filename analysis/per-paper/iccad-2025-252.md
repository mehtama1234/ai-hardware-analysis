# dyGRASS: Dynamic Spectral Graph Sparsification via Localized Random Walks on GPUs

**ID:** iccad-2025-252

## Problem
Graph sparsification for both edge insertions and deletions is computationally expensive. Existing algorithms like inGRASS lack efficiency for dynamic graphs.

## Motivation
Dynamic graph sparsification enables efficient processing of evolving datasets in optimization, network analysis, and CAD tools.

## Method
The approach runs graph sparsification on a GPU (a specialized processor designed for parallel computation), using localized random walks—a technique that samples paths through the graph while staying in nearby regions to identify which edges are critical and can be safely removed. By processing only the affected parts of the graph when edges are added or deleted, rather than recomputing everything, it efficiently handles both operations. This achieves a 10× speedup over the inGRASS algorithm.

## Key Novelty
Running graph sparsification on a GPU using localized random walks—sampling nearby paths to identify important edges—to efficiently handle both edge additions and removals.
