# Basilisk: Using Provenance Invariants to Automate Proofs of Undecidable Protocols

**Problem:** Verifying correctness of distributed protocols is challenging, especially for undecidable protocols where no complete algorithmic proof procedure exists. Manual proof construction is labor-intensive and error-prone.

**Method:** Basilisk tracks where data originates and how it flows through a distributed protocol—this data-origin tracking (provenance invariants) serves as a foundation for automated proof generation. The system translates the protocol's rules and tracking properties into a constraint-satisfaction problem: a set of logical requirements that must all be satisfied simultaneously. Automated solvers then search for solutions that satisfy every constraint, which effectively constructs a valid proof, even for protocols that no traditional proof algorithm could handle.

**Novelty:** Using provenance tracking (data-origin tracking) to automatically prove the correctness of theoretically undecidable protocols.
