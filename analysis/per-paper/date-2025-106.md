# Segment-Wise Accumulation: Low-Error Logarithmic Domain Computing for Efficient Large Language Model Inference

**Venue**: DATE  
**Primary Theme**: Segment-wise accumulation for low-precision LDC  

## Problem
Logarithmic domain computing reduces quantization error and computational complexity for LLMs but faces a precision-versus-hardware-overhead trade-off in multiply-accumulate operations requiring expensive high-precision logarithmic adders.

## Method
Logarithmic domain computing (representing numbers as logarithms) reduces quantization error and complexity in large language models, but normally requires expensive, high-precision hardware to handle the multiplication and accumulation operations that neural networks depend on. The paper proposes segment-wise accumulation (SWA): dividing the computation into segments that are processed separately and then combined, which reduces errors that build up during computation. A custom processing element allows SWA to integrate into systolic array architectures (the grid-like hardware accelerators used in AI chips) with significantly lower hardware overhead than floating-point precision enhancements.

## Key Novelty
Segment-wise accumulation decomposes computation into segments, enabling efficient logarithmic domain computing without requiring expensive, high-precision hardware.

## Contributions
- Error analysis identifying accumulation as the critical LDC error source in LLMs
- SWA technique providing error mitigation with minimal architectural changes
- PE design for seamless systolic array integration
- 13.9% average accuracy improvement on LLAMA-2-7B with 24.6% area and 42.3% power reduction versus integer computing
