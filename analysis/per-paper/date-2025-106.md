# Segment-Wise Accumulation: Low-Error Logarithmic Domain Computing for Efficient Large Language Model Inference

**Venue**: DATE  
**Primary Theme**: Segment-wise accumulation for low-precision LDC  

## Problem
Logarithmic domain computing reduces quantization error and computational complexity for LLMs but faces a precision-versus-hardware-overhead trade-off in multiply-accumulate operations requiring expensive high-precision logarithmic adders.

## Method
Proposes segment-wise accumulation (SWA) decomposing results into segments to mitigate LDC errors; introduces a processing element enabling SWA integration into systolic array architectures with lower overhead than floating-point enhancements.

## Key Novelty
Segment-wise accumulation strategy enabling low-precision logarithmic computing without equivalent hardware overhead.

## Contributions
- Error analysis identifying accumulation as the critical LDC error source in LLMs
- SWA technique providing error mitigation with minimal architectural changes
- PE design for seamless systolic array integration
- 13.9% average accuracy improvement on LLAMA-2-7B with 24.6% area and 42.3% power reduction versus integer computing
