# Transferable Parasitic Estimation via Graph Contrastive Learning and Label Rebalancing in AMS Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-183

## Problem
Parasitic element estimation in AMS circuits is critical for accurate simulation but suffers from high variance and circuit-specific variation, limiting generalization across designs.

## Motivation
Transferable parasitic models reduce design iteration cycles and enable fast simulation-in-the-loop optimization; cross-circuit generalization is essential for large design spaces.

## Method
The approach represents a circuit as a network of electrical components and their connections (called a graph), then trains a machine learning model using pairs of similar and different circuits so it learns which connections affect parasitics—the unwanted electrical properties that slow down circuits. Because training data tends to have many examples of common parasitic types but few rare ones, the method rebalances these categories so the model learns to handle all types equally well. With this combination of graph-based learning and balanced data, models trained on one set of circuits can make good predictions on entirely new circuit designs without retraining.

## Key Novelty
Combining graph-based contrastive learning with label rebalancing enables parasitic element predictions to transfer across different AMS circuit designs.

## Contributions
1. GNN-based parasitic extraction model with structural circuit representation
2. Contrastive learning objective for improved feature learning
3. Label rebalancing technique for skewed parasitic distributions
4. Demonstrated transfer across different circuit topologies and technologies
