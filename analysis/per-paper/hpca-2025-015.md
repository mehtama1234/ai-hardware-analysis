# hpca-2025-015 — Chronus: Understanding and Securing the Cutting-Edge Industry Solutions to DRAM Read Disturbance

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
DDR5 PRAC RowHammer mitigation places counter increment on the critical DRAM access path and is vulnerable to the "wave attack," forcing overly conservative refresh thresholds and prohibitive performance overhead for future DRAM generations.

## Motivation
DRAM cell shrinkage increases RowHammer vulnerability each generation; PRAC is the first in-DRAM standard mitigation but had no rigorous security/performance analysis and its overheads grow with future node scaling.

## Method
Chronus mitigates RowHammer attacks (where repeatedly accessing one memory row corrupts adjacent rows) by moving the activation counters (devices that track how many times each row is accessed) to a separate location on the DRAM chip. This separation lets the system update these counters simultaneously with reading or writing data, instead of doing them sequentially, which eliminates the performance delay. To stop 'wave attacks' (where attackers use specific patterns to force the system to exhaust its refresh budget), Chronus dynamically adjusts how many preventive memory refreshes are triggered each time, rather than using one fixed conservative number that degrades performance. The solution requires only in-DRAM modifications and is open-sourced.

## Key Novelty
Chronus mitigates RowHammer (memory corruption from repeated row access) by decoupling activation counters from data storage, enabling concurrent updates without performance penalty, and by dynamically controlling preventive refresh counts to defeat wave attacks.

## Contributions
- First rigorous security, performance, energy, and cost analysis of DDR5 PRAC.
- Identification of PRAC's two weaknesses: critical-path counter latency and wave-attack vulnerability.
- Chronus concurrent counter mechanism eliminating PRAC latency overhead.
- Dynamic preventive refresh count control defeating wave attacks; near-zero overhead for modern DRAM.
