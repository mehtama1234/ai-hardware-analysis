# Dancer: Dynamic Compression and Quantization Architecture for Deep Graph Convolutional Network

**Venue**: DATE  
**Primary Theme**: efficient deep GCN processing  

## Problem
High computational and data movement burden in deep GCNs significantly more severe than shallow GCNs due to numerous layers. Prior processing-in-memory GCN accelerators show limited performance on deep architectures.

## Method
Processing-in-memory GCN accelerator with compressed graph storage reducing memory footprint. Dynamic quantization applied per layer based on weight characteristics. Sparsity propagation strategy analyzes weight dynamics to minimize computational and data transfer burden between layers.

## Key Novelty
Dynamic quantization and sparsity propagation leveraging per-layer weight dynamics to minimize data movement in deep GCNs.

## Contributions
- Compressed graph storage architecture for PIM
- Dynamic per-layer quantization technique
- Sparsity propagation strategy based on weight dynamics
- 3.7x speedup, 7.6x energy efficiency, 9.6x DRAM access reduction
