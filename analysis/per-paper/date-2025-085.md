# Dancer: Dynamic Compression and Quantization Architecture for Deep Graph Convolutional Network

**Venue**: DATE  
**Primary Theme**: efficient deep GCN processing  

## Problem
High computational and data movement burden in deep GCNs significantly more severe than shallow GCNs due to numerous layers. Prior processing-in-memory GCN accelerators show limited performance on deep architectures.

## Method
The system uses a specialized processor embedded in memory that computes directly on stored data, avoiding the cost of moving data to and from external memory. It compresses the graph structure to reduce space and applies dynamic quantization—adjusting the precision of numbers per layer based on how weights are distributed in that layer. It also tracks weight patterns to identify which connections contribute little and propagates this sparsity (pattern of sparse values) through layers to skip unnecessary computations.

## Key Novelty
The system minimizes data movement by using dynamic quantization and sparsity propagation (reducing number precision and skipping unnecessary computations) that adapt to each layer's actual weights.

## Contributions
- Compressed graph storage architecture for PIM
- Dynamic per-layer quantization technique
- Sparsity propagation strategy based on weight dynamics
- 3.7x speedup, 7.6x energy efficiency, 9.6x DRAM access reduction
