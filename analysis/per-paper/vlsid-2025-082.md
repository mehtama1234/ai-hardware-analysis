# OwlsEye: Real-Time Low-Light Video Instance Segmentation on Edge and Exploration of Fixed-Posit Quantization

**VLSID 2025** | vlsid-2025-082

## Abstract
OwlsEye is the first real-time low-light Video Instance Segmentation (VIS) system on edge hardware (Intel Nezha), improving throughput from 0.6 to 28 FPS via model quantization, brightness verification, and FIFO pipelining. Introduces EQyTorch: Fixed-Posit quantization framework for YOLOv8 achieving 2.35-9.02x latency and 3.6-87.91x power improvement vs. INT8/FP32.

## Problem
- VIS in low-light challenging for real-time deployment on edge devices
- Autonomous vehicles, surveillance, robotics require robust low-light perception
- Resource constraints demand aggressive optimization

## Key Insight
Fixed-Posit arithmetic combined with quantization-aware training outperforms INT8 and FP32 for edge VIS workloads, enabling 28 FPS real-time performance.

## Approach
1. YOLOv8 model as base architecture
2. Model weight quantization (INT8, FP32, Fixed-Posit)
3. Brightness verification preprocessing for low-light robustness
4. Asynchronous FIFO pipelining for throughput acceleration
5. EQyTorch framework for Fixed-Posit training/inference

## Implementation
- **Platform**: Intel Nezha embedded board
- **Model**: YOLOv8
- **Input**: RGB camera feed
- **Target**: Real-time low-light VIS
