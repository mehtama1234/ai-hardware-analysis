# MEEK: Heterogeneous Parallel Error Detection for OoO Superscalar Processors

## Problem
Heterogeneous parallel error detection requires gathering data cross-chip from many core components to re-execute software. Integrating this into commodity out-of-order superscalar cores creates design complexity and risks heavy modifications to mature microarchitectures.

## Method
MEEK detects hardware errors using two types of processors working in parallel: a fast main processor executes instructions speculatively (running ahead while assuming everything is safe), while slower, power-efficient backup processors re-run the same code to verify correctness. Software and minimal operating-system changes compare the results between main and backup paths and report any mismatches within microseconds. The approach avoids major rewiring of existing processors by dividing the error-detection work across three layers: the instruction set (the software-hardware interface), the processor's internal design, and the operating system.

## Key Results
- First full-RTL implementation of heterogeneous parallel error detection in an open-source SoC
- Achieves microsecond-scale fault detection with minimal architectural disruption
- Light changes to mature out-of-order cores; simple coordinating software layers
