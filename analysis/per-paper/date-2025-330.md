# Amphi: Practical and Intelligent Data Prefetching for the First-Level Cache

**Venue**: DATE  
**Primary Theme**: binarized ML-based L1 cache prefetcher  

## Problem
First-level cache prefetchers must balance comprehensive pattern coverage through ML with strict resource constraints, while existing ML prefetchers are deployed only at last-level cache.

## Method
Amphi predicts which memory addresses the processor will need next from the L1 cache (the processor's smallest, fastest built-in memory) using a binarized temporal convolutional network—a type of neural network that learns patterns from sequences of past memory requests. By binarizing the network (converting its internal values to just 1s and 0s), Amphi shrinks the model from ~27 KB (the size used by previous ML prefetcher Pythia) to 3.4 KB, small enough to fit on a chip, while maintaining the same performance.

## Key Novelty
This is the first machine-learning prefetcher designed for the first-level cache, made practical by using binarized neural networks to compress the model small enough to fit on a chip.

## Contributions
- Binarized TCN architecture for L1 prefetch prediction
- Storage reduction to 3.4 KB (8× more efficient than Pythia)
- Performance comparable to SOTA intelligent prefetchers
- Practical deployment model for L1 cache integration
