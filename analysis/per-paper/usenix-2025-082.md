# Cosmic: Cost-Effective Support for Cloud-Assisted 3D Printing

**Problem:** 3D printing operations require computational coordination and resource management when leveraging cloud infrastructure, with communication overhead and resource allocation creating significant cost penalties in distributed deployments.

**Method:** The system automatically decides where each 3D printing job should run—whether on a local printer or processed in the cloud—and coordinates the work to minimize data transfer and computing resources used. It predicts what each job will need and uses coordination protocols that reduce communication overhead (the repetitive back-and-forth messages between the cloud and printer) while respecting both the printer's capabilities and the job's constraints.

**Novelty:** The key innovation is a scheduling system that considers cloud computing costs and 3D printing job placement together as a single optimization problem, rather than optimizing them separately, to achieve near-optimal total cost of operation.
