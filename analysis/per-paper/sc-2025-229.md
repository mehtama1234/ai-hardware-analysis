# Frameworks for Large Language Model Serving in HPC Environments

**ID:** sc-2025-229
**Venue:** SC
**Confidence:** low

## Problem

LLM serving in HPC lacks unified frameworks for batch/interactive workloads; complexity of resource management

## Motivation

Growing need for LLM inference in HPC; diverse workloads require specialized scheduling and resource allocation

## Approach

Three complementary frameworks: AI-Flux (batch), Ray Serve (dynamic), Illinois Chat (always-on)

## Key Novelty

Integrated LLM serving frameworks for HPC; OpenAI-compatible APIs; hierarchical resource management

## Contributions

- AI-Flux framework for high-throughput batch LLM inference
- Ray Serve integration for dynamic interactive serving
- Illinois Chat production platform for real-time LLM access
- Simplified resource abstraction for HPC users
