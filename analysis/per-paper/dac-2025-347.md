# MILLION: MasterIng Long-Context LLM Inference Via Outlier-Immunized KV Product QuaNtization

**Venue:** DAC  
**ID:** dac-2025-347

## Problem
Long-context LLM inference faces two bottlenecks: (1) quadratic attention complexity, and (2) KV cache size scaling linearly with context; traditional quantization fails due to outliers and on-the-fly de-quantization overhead.

## Motivation
LLMs supporting 128K-1M token contexts require efficient memory and compute to reduce footprint and inference latency.

## Key Innovation
Non-uniform product quantization tailored to KV cache distribution with asynchronous execution pipeline to eliminate on-the-fly quantization bottleneck.

## Method
MILLION compresses the KV cache (data needed for attention computation) using product quantization with adaptive precision: each chunk gets different compression levels based on its actual values, with special handling for outliers. A custom GPU kernel runs attention computation and compression in parallel, preventing compression from becoming a bottleneck. Sparse computation further reduces overhead by skipping unnecessary decompression.

## Contributions
- Analysis of KV cache distribution and uniform quantization limits
- Non-uniform product quantization for outlier-resistant compression
- High-performance GPU inference framework with asynchronous pipeline
- 4-bit KV quantization achieving 2.09x speedup at 32K context

## Results
2.09x end-to-end speedup at 32K context with trivial accuracy loss; 4-bit quantization.
