# Medusa: Accelerating Serverless LLM Inference with Materialization

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Serverless LLM inference suffers from excessive cold-start latency from three stages: model weight loading, KV cache initialization (profiling memory reservations), and CUDA graph capturing for different batch sizes—all repeated on every cold start.

## Motivation
Serverless promises scalable and cost-efficient model inference, but LLMs introduce unique cold-start overheads (KV cache profiling and CUDA graph construction) not addressed by prior serverless optimization work.

## Method
Instead of repeating expensive setup work on every cold start, Medusa pre-computes and saves that work as materialized snapshots on disk. Specifically, it saves two things: the KV cache initialization state (memory pre-allocated and configured for inference) and CUDA graphs (pre-compiled GPU execution instructions for each batch size). When a cold start occurs, the system loads these saved snapshots directly into the GPU, skipping the expensive initialization and compilation steps that normally repeat every time. This pre-computation happens offline or on the first warm start, with minimal overhead to restore the saved state.

## Key Novelty
Medusa's core idea is materializing the KV cache initialization state and CUDA graphs—storing pre-built copies on disk—so cold starts can reload them directly into the GPU instead of rebuilding them each time.

## Contributions
- Characterization of KV cache initialization and CUDA graph capturing as dominant LLM cold-start overheads in serverless settings
- Medusa materialization framework pre-computing and persisting these states as reusable snapshots
- Snapshot management system for catalog, versioning, and fast GPU memory restore
- Significant reduction in LLM cold-start latency enabling practical serverless LLM serving
