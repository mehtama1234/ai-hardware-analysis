# sc-2025-211: COSMOS - Performance Portable Graph Pattern Matching

## Overview
COSMOS presents a domain-specific software distributed shared memory (DSM) model to enable performance-portable graph pattern matching (GPM) across diverse supercomputer architectures.

## Key Problem
Graph pattern matching is NP-complete and irregular, making distributed scaling challenging. Existing solutions require architecture-specific manual optimization, leading to vendor lock-in and complicating code evolution with hardware changes.

## Approach
Use a domain-specific DSM layer to abstract supercomputer architectural diversity, enabling the same code to scale across different systems while maintaining performance.

## Contributions
- Domain-specific DSM model for graph pattern matching
- Performance-portable implementation across heterogeneous supercomputers
- Demonstration of scaling to thousands of nodes without code modification

## Application Domains
- Circuit logic synthesis
- Anomaly detection
- Social network analysis
- Cheminformatics
- Recommendation systems
- Classification systems

## Hardware Target
Multi-node supercomputers and distributed HPC clusters
