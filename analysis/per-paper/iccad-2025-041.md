# Automated Design Space Exploration in High-Level Physical Synthesis

**ID:** iccad-2025-041  
**Venue:** ICCAD

## Problem
High-Level Physical Synthesis (HLPS) for multi-die FPGAs suffers from unstable and inconsistent quality-of-results due to vast number of parameters requiring ad-hoc user selection, necessitating substantial manual effort and low-level expertise.

## Motivation
FPGA accelerators on large-scale multi-die devices require reliable timing closure at high frequencies; current HLPS tools lack automated parameter tuning.

## Method
The framework automatically adjusts the many configuration settings (parameters) used in high-level physical synthesis—the process of placing hardware components on multi-die FPGAs. It uses smart decision rules (heuristics) that respond to measurements from the actual physical design, like how well signals arrive on time (timing closure). By repeatedly measuring the design's performance and adjusting settings accordingly, it achieves consistent results without requiring engineers to manually tweak settings.

## Key Novelty
Using measurements from actual physical design performance to automatically optimize configuration settings, creating a feedback loop that eliminates manual tuning.

## Contributions
1. Robust and practical DSE framework automating HLPS parameter iteration
2. Metrics-informed heuristics for parameter refinement based on physical implementation outcomes
3. Consistent timing closure automation eliminating manual effort
4. 311.06 MHz average frequency: 2.42× AMD Vitis/Vivado, 1.67× leading academic solutions
