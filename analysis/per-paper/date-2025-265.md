# Runtime Security Analysis of Monolithic 3D Embedded DRAM with Oxide-Channel Transistor

**Venue**: DATE  
**Primary Theme**: Security of 3D embedded DRAM with oxide transistors  

## Problem
Monolithic 3D eDRAM with oxide-channel transistors is vulnerable to Rowhammer/Rowpress attacks and M3D-specific electrical disturbances that degrade data integrity and security.

## Method
The researchers tested whether Rowhammer and Rowpress attacks—which exploit repeated memory access to flip bits in nearby rows—could compromise monolithic 3D embedded DRAM with oxide-channel transistors. They examined vulnerabilities across traditional 2D layouts and new 3D stacking arrangements (including memory on logic and memory-on-memory configurations), investigating whether the physical stacking itself introduces new electrical disturbances. They evaluated whether changes to chip design and memory architecture could defend against these attacks.

## Key Novelty
This provides the first comprehensive security analysis of monolithic 3D embedded DRAM with oxide-channel transistors, identifying vulnerabilities specific to vertical memory stacking.

## Contributions
- First security analysis of IWO eDRAM in monolithic 3D integration
- Identifies 300nm minimum vertical interlayer distance to mitigate disturbances in memory-on-memory stacking
- Characterizes read bitline crosstalk sensitivity to high-speed logic switching
- Demonstrates 30× resilience improvement over SOTA memory access transistors against Rowhammer
