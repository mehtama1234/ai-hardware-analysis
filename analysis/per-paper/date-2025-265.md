# Runtime Security Analysis of Monolithic 3D Embedded DRAM with Oxide-Channel Transistor

**Venue**: DATE  
**Primary Theme**: Security of 3D embedded DRAM with oxide transistors  

## Problem
Monolithic 3D eDRAM with oxide-channel transistors is vulnerable to Rowhammer/Rowpress attacks and M3D-specific electrical disturbances that degrade data integrity and security.

## Method
Characterizes Rowhammer/Rowpress vulnerabilities in IWO eDRAM across 2D and M3D configurations; examines electrical disturbances from memory-on-logic and memory-on-memory stacking; evaluates physical design and architecture mitigation strategies.

## Key Novelty
First comprehensive security and disturbance analysis of M3D eDRAM with oxide-channel transistors identifying M3D-specific vulnerability vectors.

## Contributions
- First security analysis of IWO eDRAM in monolithic 3D integration
- Identifies 300nm minimum vertical interlayer distance to mitigate disturbances in memory-on-memory stacking
- Characterizes read bitline crosstalk sensitivity to high-speed logic switching
- Demonstrates 30× resilience improvement over SOTA memory access transistors against Rowhammer
