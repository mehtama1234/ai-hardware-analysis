# DAOP: Data-Aware Offloading for Efficient MoE Inference

**Venue:** DATE | **ID:** date-2025-394

## Problem
MoE models on memory-constrained systems cannot fit all experts on GPU; frequent CPU-GPU transfers negate GPU speed advantages and degrade inference latency.

## Motivation
MoE effectiveness is limited by heterogeneous memory hierarchy; intelligent scheduling exploiting activation patterns can reduce transfer overhead.

## Approach
Dynamic expert allocation between CPU/GPU based on per-sequence activation patterns + selective pre-calculation of predicted experts on CPU to minimize transfer latency + graceful degradation across cache ratios.

## Key Innovation
Data-aware predictive offloading leveraging per-sequence activation patterns for efficient expert placement.

## Results
- 8.20x speedup vs. expert caching/prefetching
- 1.35x speedup vs. pure offloading
- Maintains accuracy across varying cache configurations

## Target Hardware
GPU, CPU (heterogeneous systems)

## Techniques
Scheduling, prefetching, memory-system optimization

## Workload
MoE, LLM inference
