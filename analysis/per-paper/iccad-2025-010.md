# Semidefinite Programming-Based Decoupling Capacitor Placement for Power Distribution Network Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-010

## Problem
Decoupling capacitor placement for power distribution networks is formulated as nonlinear optimization, causing traditional heuristics to converge to local minima or search unnecessarily.

## Motivation
Optimal decap placement minimizing count improves circuit reliability and board cost, critical for high-speed PCB design.

## Method
Decoupling capacitors smooth voltage delivery by storing energy in power distribution networks. Traditional optimization methods get stuck in local optima. This approach models the problem as integer semidefinite programming (SDP—a mathematical optimization framework), then relaxes integer constraints to enable efficient solving and reduces connection points (ports) to improve scalability. An adaptive optimization scheme further refines the result.

## Key Novelty
The core insight is reformulating the nonlinear decap placement problem as integer semidefinite programming, which enables deterministic global optimization instead of heuristic local search.

## Contributions
1. Nonlinear-to-integer-SDP problem reformulation for decap placement
2. Integer relaxation and port reduction techniques for scalability
3. Adaptive optimization scheme improving solution quality
4. Outperforms state-of-the-art heuristics and commercial tools in both quality and runtime
