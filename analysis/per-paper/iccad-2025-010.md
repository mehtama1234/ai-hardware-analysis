# Semidefinite Programming-Based Decoupling Capacitor Placement for Power Distribution Network Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-010

## Problem
Decoupling capacitor placement for power distribution networks is formulated as nonlinear optimization, causing traditional heuristics to converge to local minima or search unnecessarily.

## Motivation
Optimal decap placement minimizing count improves circuit reliability and board cost, critical for high-speed PCB design.

## Method
Reformulates decap placement as integer semidefinite programming (SDP) model. Applies relaxation and port reduction for scalability. Adaptive scheme further optimizes solution.

## Key Novelty
Analytical integer SDP formulation of nonlinear decap placement problem enabling deterministic optimization.

## Contributions
1. Nonlinear-to-integer-SDP problem reformulation for decap placement
2. Integer relaxation and port reduction techniques for scalability
3. Adaptive optimization scheme improving solution quality
4. Outperforms state-of-the-art heuristics and commercial tools in both quality and runtime
