# Automatic Design for Modular Microfluidic Routing Blocks

**ID:** iccad-2025-042  
**Venue:** ICCAD

## Problem
Designing microfluidic routing blocks that interconnect pumps, cell cultures, and other modules is a cumbersome, repetitive, manual task, hindering rapid development of organs-on-chip devices.

## Motivation
Recent ISO standardization of modular microfluidic building blocks enables reusable components, but manual routing design remains a bottleneck for implementing organ-on-chip systems.

## Method
Proposes an automated design and routing method that fully automates interconnection of microfluidic chip components. Provides user-friendly interactive online tool as part of Munich Microfluidic Toolkit (MMFT).

## Key Novelty
Automated routing method for modular microfluidic systems following ISO standardization.

## Contributions
1. Automated design method for microfluidic routing blocks
2. Automated interconnection of pumps, cell cultures, and module components
3. User-friendly interactive online tool in MMFT
4. Feasibility demonstrated on physically fabricated routing blocks
