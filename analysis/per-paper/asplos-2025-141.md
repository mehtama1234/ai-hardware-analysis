# asplos-2025-141: Neuralink: Fast on-Device LLM Inference with Neuron Co-Activation Linking

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Sparsity-based on-device LLM inference (loading only active neurons from flash) suffers from excessive random I/O operations due to scattered neuron placement, and smartphones face severe IOPS constraints that make random flash reads the critical bottleneck.

## Motivation
Full-accuracy LLMs must reside in flash on mobile devices; current storage placement ignores co-activation patterns, causing random reads that exhaust flash IOPS.

## Method
Neuralink tackles an on-device inference bottleneck: sparse neural network inference (activating only necessary neurons) requires loading scattered neurons from flash storage, creating random memory access patterns, but smartphones face severe IOPS constraints on random flash operations. The system uses a two-stage approach: offline, it analyzes co-activation patterns (which neurons activate together) and reorganizes flash storage to place frequently co-activated neurons contiguously; online, it applies caching and sequential read strategies tuned to both the new layout and the target phone's hardware. By converting random access into sequential reads—which mobile flash handles orders of magnitude more efficiently—it substantially reduces the I/O operations required for sparse LLM inference.

## Key Novelty
Offline co-activation analysis (finding which neurons activate together) reorders flash storage to place frequently co-activated neurons next to each other, converting random I/O patterns into sequential reads that mobile flash handles orders of magnitude more efficiently.
