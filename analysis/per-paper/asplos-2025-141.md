# asplos-2025-141: Neuralink: Fast on-Device LLM Inference with Neuron Co-Activation Linking

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Sparsity-based on-device LLM inference (loading only active neurons from flash) suffers from excessive random I/O operations due to scattered neuron placement, and smartphones face severe IOPS constraints that make random flash reads the critical bottleneck.

## Motivation
Full-accuracy LLMs must reside in flash on mobile devices; current storage placement ignores co-activation patterns, causing random reads that exhaust flash IOPS.

## Method
Neuralink reorganizes neuron placement offline by profiling co-activation patterns and linking frequently co-activated neurons contiguously in flash, converting random I/O into sequential reads. An online stage uses cache-aligned sequential access strategies tuned to target device flash characteristics.

## Key Novelty
Offline neuron co-activation analysis reorders flash storage placement so frequently co-activated neurons are contiguous, converting random I/O into sequential reads on mobile flash.

## Metrics
- Average 1.49x end-to-end latency improvement over state-of-the-art
