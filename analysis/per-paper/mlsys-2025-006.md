# ProtoRAIL: A Risk-cognizant Imitation Agent for Adaptive vCPU Oversubscription In the Cloud

**Problem:** Cloud vCPU oversubscription policies must jointly minimize hot node overloading and maximize stranded resource recovery, but dynamic demand patterns across VM types make static heuristics fail on both objectives.

**Method:** Three-component framework: (1) Prototypical IL learns K prototype usage pattern embeddings (LSTM/Transformer encoder) representing equivalence classes of VM demand trajectories; policy is linear over prototype similarities; four-term loss (representativeness, diversity, interpretability, IL loss). (2) Active KITL queries domain experts with minimum budget using uncertainty (prototype cluster entropy) and risk (predicted rate < actual usage) triggers; expert feedback is up/down votes on prototypes/actions and merge/split operations on clusters; applied via advice potential gates (exponential loss scaling). (3) Deployed on Microsoft internal cloud (300 clusters, 2-week A/B test).

**Key novelty:** Prototypical IL with interpretable usage-pattern equivalence classes; active expert-in-the-loop de-risking with prototype-level merge/split/vote feedback using minimal query budget.

**Metrics:**
- 0% hot node rate (best baseline: 0.89% Coop-MARL)
- 8161 remain cores (benefit) vs 7938 for Dagger
- 9.4% vCPU utilization improvement on 300 production clusters
- Benefit-risk ratio 31.34 vs 18.95 heuristic, 7.79 manual
- <=10 KITL queries to reach stable policy
