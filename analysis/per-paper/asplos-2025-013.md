# PartIR: Composing SPMD Partitioning Strategies for Machine Learning

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** composable SPMD partitioning for distributed ML training

## Problem
Training large neural networks requires combining multiple parallelization strategies (data, model, and optimizer sharding), but existing systems make it difficult to compose, verify, and reason about these strategies in a predictable way. The tight coupling of partitioning strategies with ML implementation code makes it hard to experiment with or automatically derive optimal sharding plans.

## Motivation
As model scale grows, no single parallelism strategy suffices and their interactions become complex, creating a need for a composable, hardware-agnostic partitioning abstraction that can be verified before execution.

## Method
PartIR provides a schedule-like API that incrementally rewrites a neural network's intermediate representation (IR) after each applied partitioning strategy. Each strategy (data parallelism, tensor/model parallelism, optimizer sharding) is expressed as a composable, declarative transformation on the IR. The system is hardware-and-runtime agnostic and follows well-defined general rewriting rules so each step is independently verifiable.

## Key Novelty
Decoupling partitioning strategies from ML implementation via an incremental IR-rewriting schedule API that allows predictable, verifiable composition of arbitrary SPMD sharding strategies.

## Contributions
- A hardware-and-runtime agnostic IR for expressing and composing multiple SPMD partitioning strategies
- An incremental schedule-like API that allows step-by-step verification of sharding decisions
- Demonstration of expressiveness across diverse model architectures and large-scale training runs
- Support for both user-defined and automatically derived sharding strategies within the same framework
