# SEAL: A Single-Event Architecture for In-Sensor Visual Localization

**ID:** isca-2025-046 | **Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Traditional binary-encoded image sensors generate large data volumes causing energy and latency bottlenecks during transfer and processing for visual localization. Moving keypoint detection and tracking off-sensor to a host processor adds significant latency and energy cost.

## Motivation
In-sensor processing eliminates redundant data movement, but conventional digital pixel sensor designs lack the compute fabric and coding efficiency to run computer vision primitives locally.

## Method
SEAL replaces binary encoding with analog-to-time converters (ATCs) at the pixel array, representing pixel values as pulse delays (race logic: single-wire-per-variable, single-event-per-wire). A temporal processor co-designed with ATCs implements keypoint detection and tracking within the sensor, followed by a heavily quantized frontend processor before the sensor-processor interface.

## Key Novelty
End-to-end in-sensor localization pipeline built on delay-based (race logic) encoding instead of binary encoding, enabling keypoint detection and tracking within the pixel sensor itself using fully digital CMOS circuits.

## Contributions
1. SEAL architecture: in-sensor temporal processor for keypoint detection and tracking using race logic delay coding.
2. Co-design of analog-to-time converters with digital temporal processing using standard CMOS/EDA tools.
3. 16-61x latency reduction vs. software baselines on host processor.
4. 7x energy reduction vs. standard digital pixel sensor; preserves VIO tracking accuracy (<=1 cm RMSE ATE change on EuRoC).

## Hardware Target
ASIC, analog

## Techniques

## Metrics
- **Speedup:** 16-61x latency reduction for keypoint detection and tracking vs. software baseline
- **Energy:** 7x reduction vs. standard digital pixel sensor
- **Accuracy:** ATE RMSE changes: -1.0 cm (HybVIO), +0.3 cm (VINS-Mono) on EuRoC

## Baselines
Software baseline on host processor; standard digital pixel sensor without in-sensor processing

## Limitations
Evaluation combines analog/digital simulation and FPGA prototyping but lacks fabricated silicon results; race logic encoding restricts the class of computable operations.
