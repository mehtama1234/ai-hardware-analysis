# ChatLS: Multimodal Retrieval-Augmented Generation and Chain-of-Thought for Logic Synthesis Script Customization

**ID**: dac-2025-436  
**Venue**: DAC  
**Confidence**: low

## Problem
Logic synthesis script customization is manually intensive and design-specific; no automated method exists to adapt synthesis parameters to individual design characteristics.

## Motivation
Automating EDA workflows reduces design cycle time and enables more efficient design exploration.

## Method
ChatLS works in two stages. First, it searches a database of past chip designs to find similar examples and the synthesis strategies that succeeded for them (retrieval-augmented generation). Second, it feeds the current design's features and constraints into a language model, asking it to work through the reasoning step-by-step (chain-of-thought prompting) before generating the final TCL script, which is the configuration file that controls chip optimization.

## Key Novelty
This is the first application of step-by-step language-model reasoning combined with database example retrieval for automatically generating logic synthesis scripts, by treating the optimization as a reasoning problem over the design's metadata—its key characteristics.

## Contributions
- Multimodal RAG framework for synthesis script synthesis
- Chain-of-thought prompting strategy for design feature analysis
- Integration with commercial synthesis tools (Synopsys)
- Demonstrates superior customization performance vs baseline
