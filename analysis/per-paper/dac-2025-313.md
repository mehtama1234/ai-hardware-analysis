# ResISC: RNS-Based Integrated Sensing and Computing for Edge AI

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

ResISC is an integrated sensing-computing architecture for edge AI using residue number system (RNS) representation. Features in-sensor RNS encoding, SOT-MRAM-based CNN processing, and mixed-radix activations, achieving 3.4x power efficiency gain, 71x execution time reduction, and up to 94.63% CIFAR-10 accuracy.

## Key Contributions

- **In-Sensor Encoding**: Analog residue number conversion directly at image sensor, eliminating data movement
- **RNS-Based Processing**: CNN accelerator leveraging SOT-MRAM for efficient RNS arithmetic
- **Channel Deactivation**: Selective activation reducing computation overhead by up to 89%
- **Efficiency Metrics**: 3.4x power improvement, 71x speedup vs. processing-in-MRAM, minimal accuracy loss

## Technical Focus

Exploits RNS number system properties enabling efficient hardware implementation and reduced data movement. Processes images in residue domain from sensor through CNN inference.
