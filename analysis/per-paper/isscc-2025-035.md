# isscc-2025-035: Oscillator-Based SAT Solver

**Title:** A Physics-Inspired Oscillator-Based Mixed-Signal Optimization Engine for Solving 50-Variable 218-Clause 3-SAT Problems with 100% Solvability and 31.7μs Solution Time

**Venue:** ISSCC

## Core Contribution
Mixed-signal oscillator-based engine solving NP-complete 3-SAT instances (50 variables, 218 clauses) at 31.7μs with 100% solvability via physics-inspired coupled-spin dynamics.

## Key Metrics
- **Problem Size:** 50 variables, 218 clauses
- **Solvability:** 100%
- **Solution Time:** 31.7μs

## Problem
Prior SAT solvers limited to small sizes (<20 variables), long ms-scale times, or expensive embedding preprocessing.

## Method
The engine uses coupled oscillators—electronic devices that swing back and forth and naturally synchronize with each other—to solve Boolean satisfiability problems (finding values for multiple true-or-false variables that satisfy a set of logical rules). Each variable and rule maps to an oscillator; the oscillators all interact at once in a continuous physical system, and their synchronized state naturally encodes which variable values satisfy all rules. This all-at-once approach, driven by physics rather than step-by-step logic, is much faster than traditional search. The hardware achieves 100% success on 50-variable, 218-clause problems in 31.7 microseconds.
