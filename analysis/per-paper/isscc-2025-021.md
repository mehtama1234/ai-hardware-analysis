# isscc-2025-021: Bit-Rotated Hybrid CIM with Cooperative Quantization

**A 28nm 64kb Bit-Rotated Hybrid-CIM Macro with Embedded Sign-Bit-Processing Array and Multi-Bit-Fusion Cooperative Quantizer**

## Summary
64 kb hybrid-domain CIM using bit-rotated feature-in scheme with integrated sign-bit-processing array and dual-granularity cooperative quantization, balancing digital precision with analog efficiency.

## Technical Approach
- **Bit-rotated scheme**: Consider sign-bits in first product-wise adder, avoiding error pollution
- **Sign-bit processing**: Embedded digital array handling signed-unsigned compression
- **Cooperative quantization**: Dynamic precision allocation between analog and digital based on bit significance

## Key Innovation
Bit-rotated HCIM addressing digital-analog boundary challenge with integrated sign-bit array and dual-granularity cooperative quantization minimizing wasted energy from low-accuracy analog bits.

## Contributions
- Bit-rotated scheme eliminating error-pollution problem
- Embedded sign-bit-processing reducing digital overhead
- Multi-bit-fusion cooperative quantizer with dynamic precision
- Balanced accuracy-area-power tradeoff for inference

## Target Workloads
Neural network inference, CNN acceleration, DNN inference
