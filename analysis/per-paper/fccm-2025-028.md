# AutoNTT: Automatic Architecture Design and Exploration for Number Theoretic Transform Acceleration on FPGAs

**Problem:** NTT is a major computational bottleneck in FHE systems, but there lacks a systematic design automation tool to explore various NTT accelerator architectures that support diverse FHE parameters such as different polynomial sizes, modulo sizes, and reduction methods.

**Method:** AutoNTT is a tool that automatically designs hardware accelerators for NTT (a computational building block in cryptography) by converting high-level code into hardware designs (high-level synthesis). It explores three circuit arrangements—sequential processing (iterative), parallel pipeline processing (dataflow), and mixed approaches (hybrid)—across different polynomial sizes (2^10 to 2^17 elements) and number ranges (28-64 bits). The designs are optimized by reducing memory for temporary values and precomputed factors (twiddle factors), and by simplifying how the circuit's computation modules (butterfly units) connect.

**Novelty:** The key innovation is automating the generation and exploration of multiple NTT accelerator architecture patterns to support diverse fully homomorphic encryption parameter ranges.
