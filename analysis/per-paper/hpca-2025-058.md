# TidalMesh: Topology-Driven AllReduce Collective Communication for Mesh Topology

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing AllReduce algorithms are topology-aware adaptations of generic algorithms (ring, tree) to physical 2D mesh networks, resulting in a mismatch between logical and physical communication patterns that wastes bandwidth and increases latency.

## Motivation
AllReduce is a critical collective operation for both DNN training and inference at scale, and 2D mesh interconnects are widely deployed in scale-out ML systems, yet no algorithm is specifically designed from the ground up to exploit 2D mesh topology characteristics.

## Method
TidalMesh is an AllReduce algorithm (a distributed operation where all computing nodes combine their data and share results) built specifically for 2D mesh networks—grid-shaped topologies where each node connects to neighbors. Instead of adapting generic algorithms to the mesh, it sends data in wave-like patterns that follow the grid lines, using both directions on every link and preventing traffic bottlenecks. A "Sparse" variant cuts bandwidth overhead. To reduce communication delays, it overlaps different operation phases (reduction, scattering, then gathering) so that compute and communication can happen in parallel instead of sequentially.

## Key Novelty
It builds an AllReduce algorithm natively for 2D mesh networks using wave-like flows aligned to the grid, achieving near-optimal bandwidth usage instead of adapting generic ring or tree algorithms.

## Contributions
1. TidalMesh AllReduce algorithm natively designed for 2D mesh topology achieving near-optimal bandwidth utilization
2. Sparse TidalMesh variant that reduces bandwidth overhead while maintaining performance
3. Collective communication unrolling technique enabling software pipelining of AllReduce phases
4. Up to 24% AllReduce performance improvement on 64-node 8x8 2D mesh
