# Towards Efficient Compiler Auto-tuning: Leveraging Synergistic Search Spaces

**Venue:** CGO
**Confidence:** low

## Problem
Determining optimal compiler optimization pass sequences is hard due to exponential search space. Traditional auto-tuning (iterative compilation, ML) incurs high cost and poor generalization. No efficient pruning strategy exists.

## Motivation
Compiler pass selection directly impacts code quality; efficient auto-tuning enabling fast convergence to near-optimal sequences is critical for practical deployment.

## Method
Identifies synergistic pass pairs (chained pairs jointly optimizing targets) using K-means clustering on benchmark patterns to form coresets. Trains supervised model on coresets to predict beneficial coreset for new programs. Integrates various search strategies for fast convergence.

## Key Novelty
Coreset-based approach using chained synergy pass pairs to reduce compiler auto-tuning search space and enable learning across programs.

## Contributions
- Synergistic pass pair identification via K-means clustering
- Coreset-based prediction for new programs
- 7.5% average IR instruction reduction vs Oz, 13.9% code size reduction with 5-second search
- Applicable to iterative search studies
