# Towards Efficient Compiler Auto-tuning: Leveraging Synergistic Search Spaces

**Venue:** CGO
**Confidence:** low

## Problem
Determining optimal compiler optimization pass sequences is hard due to exponential search space. Traditional auto-tuning (iterative compilation, ML) incurs high cost and poor generalization. No efficient pruning strategy exists.

## Motivation
Compiler pass selection directly impacts code quality; efficient auto-tuning enabling fast convergence to near-optimal sequences is critical for practical deployment.

## Method
The approach tests pairs of compiler optimization passes on benchmark programs and uses clustering (a technique to group similar patterns) to identify which pairs work best when applied in sequence. These successful combinations are collected into a small representative set called a coreset. A machine learning model is then trained on these coresets to predict which combinations will work for new programs without testing each possibility individually. Various search strategies are applied to quickly converge to good solutions.

## Key Novelty
Identifying synergistic optimization-pass pairs (combinations that work well together) and collecting them into small representative sets (coresets) makes the search space manageable and enables machine learning to predict good strategies for new programs.

## Contributions
- Synergistic pass pair identification via K-means clustering
- Coreset-based prediction for new programs
- 7.5% average IR instruction reduction vs Oz, 13.9% code size reduction with 5-second search
- Applicable to iterative search studies
