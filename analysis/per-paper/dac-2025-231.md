# Gem5-AcceSys: Enabling System-Level Exploration of Standard Interconnects for Novel Accelerators

**Venue:** DAC
**ID:** dac-2025-231

## Problem
Interconnect design for novel accelerators (GPUs, DSAs) is critical but under-explored at system level; PCIe bandwidth limits transformer accelerator performance with different memory hierarchies.

## Motivation
Modern accelerators rely on interconnect efficiency; system architects need rapid evaluation of memory+interconnect combinations to balance cost and performance.

## Method
The researchers use Gem5, a computer system simulator, to test how well PCIe (the standard connection between a computer's main processor and accelerator cards) works with different memory configurations—DDR4, DDR5, GDDR6, and HBM2. They simulate a transformer accelerator that performs matrix multiplication as a realistic test case, measuring how performance varies across different memory setups. Their results show that the best configurations achieve 80% of the performance you'd get if the memory lived directly on the accelerator chip itself.

## Key Novelty
The core innovation is a system-level simulation framework for exploring how standard interconnects like PCIe perform with different accelerator designs.

## Contributions

- Gem5-AcceSys framework for interconnect+memory co-design
- Evaluation of PCIe across diverse memory types and hierarchies
- Quantifies achievable performance (80%) with standard vs premium interconnects
- Design insights for cost-efficient accelerator systems
