# Gem5-AcceSys: Enabling System-Level Exploration of Standard Interconnects for Novel Accelerators

**Venue:** DAC
**ID:** dac-2025-231

## Problem
Interconnect design for novel accelerators (GPUs, DSAs) is critical but under-explored at system level; PCIe bandwidth limits transformer accelerator performance with different memory hierarchies.

## Motivation
Modern accelerators rely on interconnect efficiency; system architects need rapid evaluation of memory+interconnect combinations to balance cost and performance.

## Method
System simulation framework (Gem5-based) for evaluating standard interconnects (PCIe) with configurable memory hierarchies (DDR4, DDR5, GDDR6, HBM2); matrix-multiply transformer accelerator as case study reveals optimal configurations achieve 80% of device-memory performance.

## Key Novelty
Gem5 framework with accelerator modeling for standard interconnect exploration.

## Contributions

- Gem5-AcceSys framework for interconnect+memory co-design
- Evaluation of PCIe across diverse memory types and hierarchies
- Quantifies achievable performance (80%) with standard vs premium interconnects
- Design insights for cost-efficient accelerator systems
