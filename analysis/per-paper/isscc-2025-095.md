# isscc-2025-095: Slim-Llama Binary-Quantized LLM Processor

## Summary
4.69mW ASIC processor for billion-parameter Llama inference using binary/ternary weight quantization and hardware optimizations, achieving 9pJ/param (26-25x improvement over prior work).

## Key Contributions
- Binary/ternary weight quantization
- Hardware-software codesign for EMA reduction
- 9pJ/param energy efficiency
- Sub-5mW power for billion-param LLM

## Hardware Target
ASIC

## Technique Category
Quantization, Memory-system, Dataflow

## Workloads
LLM-inference

## Baselines
