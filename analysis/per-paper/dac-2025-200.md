# ZK-Hammer: Leaking Secrets from Zero-Knowledge Proofs via Rowhammer

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Zero-knowledge SNARK schemes are assumed cryptographically secure, but vulnerability to hardware fault injection attacks has not been studied.

## Method
ZK-Hammer uses a hardware vulnerability called Rowhammer (repeatedly accessing memory to flip bits in nearby locations) to corrupt the variables used in the mathematical calculations of zk-SNARK proofs—a type of cryptographic proof scheme designed to hide secrets. It targets the exponentiation step in the proof's mathematical representation (called a Quadratic Arithmetic Program). By analyzing these deliberately corrupted proofs using bilinear pairings (a cryptographic technique that works with pairs of values in a special mathematical structure), the attack recovers the secret parameters that should have remained hidden.

## Key Novelty
ZK-SNARK cryptographic proofs, which were thought to be secure, can be broken by Rowhammer attacks (hardware faults that flip bits in memory during calculations), allowing recovery of the secret parameters.
