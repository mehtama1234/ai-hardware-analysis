# ZK-Hammer: Leaking Secrets from Zero-Knowledge Proofs via Rowhammer

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Zero-knowledge SNARK schemes are assumed cryptographically secure, but vulnerability to hardware fault injection attacks has not been studied.

## Method
ZK-Hammer uses **Rowhammer** to induce faults in QAP exponentiate variables, then recovers secrets via **bilinear pairing analysis** of the faulty proof.

## Key Novelty
First demonstration that zk-SNARK implementations are vulnerable to Rowhammer-based fault injection attacks.

## Results
- Successful secret recovery from libsnark
- **3 CVEs identified**
