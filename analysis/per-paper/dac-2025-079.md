# dac-2025-079: Hybrid Logic Optimization with Predictive Self-Supervision

**Problem:** Different circuit regions benefit from different optimization techniques but identifying optimal method per region is computationally expensive.

**Method:** They extract vertex features—metrics describing each circuit region's local structure and compatibility with different optimization methods—by analyzing subgraph neighborhoods and testing how various optimization approaches perform. They use these features to partition the circuit into clusters, applying each cluster's optimal optimization method. To avoid expensive testing, they use self-supervised learning to predict these vertex features for any circuit region, enabling rapid hybrid optimization without simulation.

**Key Novelty:** Self-supervised vertex feature prediction enabling efficient identification of optimization-method compatibility per circuit region.
