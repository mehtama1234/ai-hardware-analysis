# dac-2025-435: Cardinal Spline-Based Curvilinear OPC with MRC Compliance

**Problem:** Optical proximity correction must handle complex curvilinear patterns while maintaining mask rule checking compliance.

**Motivation:** Advanced lithography requires precise OPC; curvilinear patterns enable better fidelity but complicate correction.

**Method:** The approach represents curved mask patterns using cardinal splines—mathematical curves defined through a few control points that can be adjusted. It iteratively refines these control points by simulating lithography (the optical printing process used in chip manufacturing) to predict how light will actually render each curve. While optimizing, it continuously verifies that designs meet all mask manufacturing rules for line width, spacing, area, and curve properties, and it reconciles results with inverse lithography techniques (methods that reverse-engineer ideal mask designs from manufacturing constraints) to fix any violations.

**Key Novelty:** Cardinal spline-based curvilinear mask representation with integrated MRC compliance.

**Contributions:**
- Cardinal spline representation enabling smooth curvature handling
- Comprehensive MRC checking (width, space, area, curvature)
- Algorithms fitting ILT results and resolving violations
- Viable OPC/ILT alternative

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
