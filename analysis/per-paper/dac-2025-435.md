# dac-2025-435: Cardinal Spline-Based Curvilinear OPC with MRC Compliance

**Problem:** Optical proximity correction must handle complex curvilinear patterns while maintaining mask rule checking compliance.

**Motivation:** Advanced lithography requires precise OPC; curvilinear patterns enable better fidelity but complicate correction.

**Method:** Uses cardinal splines to represent mask patterns via control points; iteratively adjusts guided by lithography simulation; develops MRC checking for width/space/area/curvature; fits ILT results and resolves violations.

**Key Novelty:** Cardinal spline-based curvilinear mask representation with integrated MRC compliance.

**Contributions:**
- Cardinal spline representation enabling smooth curvature handling
- Comprehensive MRC checking (width, space, area, curvature)
- Algorithms fitting ILT results and resolving violations
- Viable OPC/ILT alternative

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
