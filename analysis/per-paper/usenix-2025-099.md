# Accelerating Nested Virtualization with HyperTurtle

**Problem:** Nested virtualization (running virtual machines within virtual machines) incurs significant performance overhead due to repeated VM exits and trap handling. This overhead limits practical adoption in cloud and container environments.

**Method:** HyperTurtle uses hardware acceleration to speed up nested virtual machines (VMs running inside other VMs). Nested VMs are slow because they repeatedly trigger 'exits'—expensive pauses when the inner VM needs to request something from the outer VM. By optimizing how these exits are handled at the hardware level, HyperTurtle cuts the overhead and makes nested VMs practical.

**Novelty:** Specialized hardware that accelerates nested virtual machines specifically, rather than just making regular VMs faster.
