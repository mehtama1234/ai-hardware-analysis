# dac-2025-080: CND-IDS: Continual Novelty Detection for Intrusion Detection

**Problem:** ML-IDS degrades on changing traffic and lacks labels for zero-day attacks.

**Method:** CND-IDS continuously learns which patterns matter in network traffic, updating its understanding as new data arrives. To detect anomalies, it uses PCA (a technique that identifies the main patterns in normal data and flags anything significantly different from them). Because it spots deviations from normal behavior rather than matching known attacks, it doesn't need labeled examples of attacks to learn from.

**Key Novelty:** Continual feature learning with unsupervised PCA-based novelty detection enabling zero-label attack detection.
