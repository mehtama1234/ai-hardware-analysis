# sc-2025-224: HPC Digital Twins for Scheduler Evaluation

## Overview
First framework integrating HPC scheduling simulation with digital twins to evaluate scheduler policies' impact on physical infrastructure (power, cooling, sustainability).

## Key Problem
Scheduler evaluation limited to post-deployment analysis or simulators that ignore infrastructure. Need pre-deployment what-if analysis of scheduler impact on power, cooling, and sustainability.

## Approach
Digital twin framework with integrated scheduling:
1. Integration of public datasets from top-tier HPC systems
2. Scheduling simulator integration (extensible)
3. Incentive structure modeling
4. ML-based scheduling evaluation
5. What-if scenario analysis

## Contributions
- First digital twin framework with scheduling capabilities
- Multi-system dataset integration (publicly available)
- Extensible simulator integration interface
- Incentive structure evaluation framework
- ML-based scheduling evaluation methodology
- Sustainability-focused what-if analysis

## Use Cases
- Evaluate scheduling policies before deployment
- Assess incentive structures on power/cooling
- Prototype ML-based scheduling algorithms
- Study impact on physical infrastructure

## Hardware Target
HPC centers and data centers

Low (framework-focused, limited specific results or metrics in abstract)
