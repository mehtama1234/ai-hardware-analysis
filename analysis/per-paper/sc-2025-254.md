## Scientific Significance

### Persistent Memory Context
Intel Optane persistent memory (and similar technologies) represent new tier in memory hierarchy:
- **Capacity**: Orders of magnitude larger than DRAM
- **Persistence**: Survives power failures
- **Latency**: Slower than DRAM but faster than disk
- **Cost**: Between DRAM and storage

MetoHash optimizes for this new tier, potentially enabling:
- Larger in-memory data structures
- Persistent indexes (survive crashes)
- Novel database designs
- Low-latency large-scale analytics
