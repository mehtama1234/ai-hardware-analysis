# A Multi-level Compiler Backend for Accelerated Micro-kernels Targeting RISC-V ISA Extensions

**Venue:** CGO
**Confidence:** low

## Problem
Micro-kernels for DNNs must exploit specialized hardware (custom ISA, hardware loops, streaming registers) to achieve peak performance, but classical compiler backends use CPU-focused abstractions and general-purpose heuristics, missing domain-specific optimization opportunities.

## Motivation
Modern accelerators have specialized hardware (loops, streaming) requiring tailored code generation; general-purpose LLVM/GCC backends cannot fully exploit these features.

## Method
Custom RISC-V backend with progressive lowering through multiple structured abstraction levels matching hardware capabilities. Uses incremental register allocation over structured IRs without classical spilling, enabling direct hardware loop and streaming register exploitation.

## Key Novelty
Breaking classical backend hourglass by progressive lowering across domain-specific abstraction levels, directly exposing hardware features like loops and streaming.

## Contributions
- Multi-level compiler backend for RISC-V accelerators with hardware loops
- Structured IR design matching accelerator capabilities
- Incremental register allocation without classical spilling
- Up to 90% FPU utilization on key DNN kernels
