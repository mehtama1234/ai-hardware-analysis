# FabThink: A Wafer Analysis Multimodal LLM via Chain-of-Thought-Driven Retrieval Augmentation

**Venue:** ICCAD  
**ID:** iccad-2025-078

## Problem
Standard RAG methods in LLMs lack domain-specific adaptation for semiconductor manufacturing, leading to poor retrieval accuracy and excessive hallucinations when addressing complex wafer defect analysis and root cause identification tasks.

## Motivation
Accurate defect root cause analysis in wafer manufacturing is critical for yield optimization and process improvement, but requires domain-tailored knowledge retrieval that generic LLMs cannot provide.

## Method
FabThink combines a language model with document retrieval and step-by-step reasoning to solve complex wafer defect problems in semiconductor manufacturing. It breaks questions into logical steps and retrieves relevant documents at each step, combining information from both text and images. It ranks documents by their relevance to each reasoning step and uses a specialized generator to produce answers based on the most relevant documents.

## Key Novelty
It uses step-by-step reasoning to improve document retrieval—processing both text and images—for semiconductor manufacturing problems involving wafer defects.

## Contributions
- Wafer-domain-tailored multimodal LLM architecture with CoT-driven RAG optimization
- Logical decomposition and cross-modal integration strategy for complex defect analysis queries
- Adaptive weighted ranking mechanism for prioritizing critical manufacturing documents
- Experimental validation on fab data showing excellence in detection, retrieval, and generation tasks
