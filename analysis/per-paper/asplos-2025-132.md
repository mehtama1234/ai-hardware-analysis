# asplos-2025-132: Optimizing Datalog for the GPU

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Modern Datalog engines designed for CPUs cannot efficiently exploit GPU parallelism due to relational algebra over sparse, recursively updated fact sets. Existing GPU join implementations carry high memory overhead for recursive workloads like points-to analysis.

## Motivation
High-throughput applications in static analysis, network monitoring, and social-media mining rely on Datalog engines, and GPU compute density offers large potential speedups that existing engines fail to capture.

## Method
GPUlog implements Datalog on data center GPUs by using a data structure called Hash-Indexed Sorted Array (HISA). HISA packs data into arrays that GPUs can efficiently parallelize while supporting fast range-based lookups. The system implements database operations like joins, unions, and set differences using HISA, and optimizes recursive queries by only recomputing new results at each iteration, using less memory than earlier GPU approaches.

## Key Novelty
HISA (Hash-Indexed Sorted Array) combines array storage optimized for GPU parallelism with fast range-based lookups that allow recursive Datalog queries to recompute only new results at each step.
