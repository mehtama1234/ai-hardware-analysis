# asplos-2025-132: Optimizing Datalog for the GPU

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Modern Datalog engines designed for CPUs cannot efficiently exploit GPU parallelism due to relational algebra over sparse, recursively updated fact sets. Existing GPU join implementations carry high memory overhead for recursive workloads like points-to analysis.

## Motivation
High-throughput applications in static analysis, network monitoring, and social-media mining rely on Datalog engines, and GPU compute density offers large potential speedups that existing engines fail to capture.

## Method
GPUlog implements a Datalog engine backend on data center GPUs using the Hash-Indexed Sorted Array (HISA), a novel range-indexed data structure combining incremental range indexing (for semi-naive evaluation) with dense array operations amenable to GPU throughput. Iterated relational algebra kernels (join, union, difference) run over HISA.

## Key Novelty
HISA combines incremental range-indexed relation semantics with dense-array GPU throughput, enabling efficient recursive Datalog evaluation on GPUs.
