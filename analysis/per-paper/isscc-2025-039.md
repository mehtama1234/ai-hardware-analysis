# isscc-2025-039: Low-BER Arbiter PUF

**Title:** An Eye-Opening Arbiter PUF for Fingerprint Generation Using Auto-Error Detection for PVT-Robust Masking and Bit Stabilization Achieving a BER of 2e-8 in 28nm CMOS

**Venue:** ISSCC

## Core Contribution
Arbiter PUF with auto-error-detection achieving ultra-low BER (2e-8) via on-chip PVT-robust masking, without large error-correction overhead.

## Key Metrics
- **Bit Error Rate:** 2e-8 (extremely low)
- **Technology:** 28nm CMOS
- **Type:** Arbiter-based PUF

## Problem
Prior PUFs require area-expensive error correction or off-chip/shared hardware for stability across PVT variations, creating security risks.

## Method
Auto-error-detection enabling on-chip masking and bit stabilization without dedicated large error-correction hardware.

## Confidence
Low (abstract-only analysis).
