# isscc-2025-039: Low-BER Arbiter PUF

**Title:** An Eye-Opening Arbiter PUF for Fingerprint Generation Using Auto-Error Detection for PVT-Robust Masking and Bit Stabilization Achieving a BER of 2e-8 in 28nm CMOS

**Venue:** ISSCC

## Core Contribution
Arbiter PUF with auto-error-detection achieving ultra-low BER (2e-8) via on-chip PVT-robust masking, without large error-correction overhead.

## Key Metrics
- **Bit Error Rate:** 2e-8 (extremely low)
- **Technology:** 28nm CMOS
- **Type:** Arbiter-based PUF

## Problem
Prior PUFs require area-expensive error correction or off-chip/shared hardware for stability across PVT variations, creating security risks.

## Method
The circuit uses a race between two electrical signals—an arbiter—to detect tiny manufacturing variations in the silicon, creating a unique fingerprint for each chip. It includes built-in error detection that identifies unstable bit readings when voltage, temperature, or the chip ages over time (variations known as PVT changes), and automatically corrects those bits to keep the fingerprint steady. This on-chip correction achieves an extremely low error rate of just 2 in 100 million readings using 28nm-size transistors, without requiring large external error-correction hardware.
