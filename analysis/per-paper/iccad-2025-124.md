# DiffCkt: A Diffusion Model-Based Hybrid Neural Network Framework for Automatic Transistor-Level Generation of Analog Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-124

## Problem
Analog circuit pre-layout design heavily depends on manual design by experienced engineers, limiting automation and scalability across diverse application scenarios.

## Motivation
Automating analog circuit design can reduce development time and enable rapid exploration of design variants for specific performance requirements.

## Method
The system uses a diffusion model (an AI technique that gradually clears noise to produce structured data) paired with neural networks to automatically create analog circuits at the transistor level. Rather than having engineers manually design each circuit, the system generates both the transistor arrangement and the settings for each device to meet specific performance targets. It measures success using the Circuit Generation Efficiency Index (CGEI), which combines how well the circuit performs (figure of merit) with how quickly it generates the design.

## Key Novelty
This work uses diffusion models (AI that gradually refines random data into organized structures) to automate the complete generation of transistor-level analog circuits, from overall layout to individual component settings.

## Contributions
- Diffusion model-based framework for circuit structure and parameter generation
- Circuit Generation Efficiency Index (CGEI) metric for generation quality assessment
- Automated pre-layout design flow achieving state-of-the-art efficiency
