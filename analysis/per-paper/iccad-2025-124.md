# DiffCkt: A Diffusion Model-Based Hybrid Neural Network Framework for Automatic Transistor-Level Generation of Analog Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-124

## Problem
Analog circuit pre-layout design heavily depends on manual design by experienced engineers, limiting automation and scalability across diverse application scenarios.

## Motivation
Automating analog circuit design can reduce development time and enable rapid exploration of design variants for specific performance requirements.

## Method
Diffusion model-based hybrid neural network framework that directly generates transistor-level circuit structures and device parameters tailored to performance requirements; introduces Circuit Generation Efficiency Index (CGEI) metric combining figure of merit and generation time.

## Key Novelty
Using diffusion models for end-to-end automated transistor-level analog circuit topology and parameter generation.

## Contributions
- Diffusion model-based framework for circuit structure and parameter generation
- Circuit Generation Efficiency Index (CGEI) metric for generation quality assessment
- Automated pre-layout design flow achieving state-of-the-art efficiency
