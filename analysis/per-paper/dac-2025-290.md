# In-Memory Arithmetic: Enabling Division with Stochastic Logic

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Binary division circuits require multiple cycles and complex control logic; in-memory computing adds noise and process variation challenges, making traditional division intractable.

## Core Method
Stochastic computing (SC) for division—numbers represented as bitstreams, arithmetic via simple logic operations—leverages MTJ-based memory crossbars for logic-in-memory substrate. SC's inherent fault tolerance handles noise and process variation.

## Key Contribution
Stochastic in-memory division using MTJ crossbars for fault-tolerant analog computation.

## Results
- Robustness demonstrated across process variation conditions
- Real-world application: Retinex Algorithm for image enhancement
