# From Concept to Practice: an Automated LLM-aided UVM Machine for RTL Verification

**ID:** iccad-2025-243

## Problem
UVM testbench development is time-consuming and requires deep hardware verification expertise. Manual testbench creation is error-prone and labor-intensive.

## Motivation
Automated testbench generation with LLMs can significantly reduce verification time and improve coverage, enabling faster RTL design cycles.

## Method
LLM-based framework (UVM2) that generates UVM testbenches from RTL specifications with coverage feedback loop. Uses LLM to synthesize test sequences and constraints. Achieves 38.82× reduction in testbench setup time and 87.44% code coverage.

## Key Novelty
LLM-driven automated UVM testbench generation with integrated coverage feedback for improved test quality.

## Contributions
