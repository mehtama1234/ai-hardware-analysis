# From Concept to Practice: an Automated LLM-aided UVM Machine for RTL Verification

**ID:** iccad-2025-243

## Problem
UVM testbench development is time-consuming and requires deep hardware verification expertise. Manual testbench creation is error-prone and labor-intensive.

## Motivation
Automated testbench generation with LLMs can significantly reduce verification time and improve coverage, enabling faster RTL design cycles.

## Method
An AI system called UVM2 automatically generates testbenches—code that verifies whether a hardware design works correctly—by reading circuit specifications, replacing the manual process where experts hand-write verification code. It then measures test coverage (which parts of the design were actually tested) and uses this information in a feedback loop to improve the tests iteratively. This addresses the core problems of verification being time-consuming and error-prone. The method achieves a 38.82× reduction in setup time and 87.44% code coverage.

## Key Novelty
The key idea is combining automatic test generation with coverage feedback, so tests automatically improve based on what parts of the design actually get tested.
