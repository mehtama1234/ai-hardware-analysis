# SQ-DM: Accelerating Diffusion Models with Aggressive Quantization and Temporal Sparsity

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Diffusion models require many inference steps for high-quality generation, limiting practical deployment; aggressive quantization and sparsity are difficult to exploit due to time-variant sparsity patterns that vary across channels and timesteps.

## Motivation
Accelerating diffusion model inference is critical for practical deployment; combining quantization with channel-aware temporal sparsity offers significant speedup potential if hardware can handle dynamic sparsity.

## Method
SQ-DM reduces neural network numbers to 4 bits (instead of standard 32-bit) for both stored weights and intermediate calculations. It exploits sparsity (values that are zero and can be skipped) that varies across data channels and generation timesteps. The team built a custom accelerator with three key features: heterogeneous mixed-precision dense-sparse architecture (hardware that handles both dense and sparse calculations with different bit precisions), channel-last data layout (organizing memory so channel data comes last, for cache efficiency), and timestep-aware sparsity detection (identifying which values can be skipped at each step).

## Key Novelty
Extreme 4-bit quantization combined with dynamic detection of sparsity patterns that vary by data channel and generation timestep, supported by specialized hardware for dense-sparse computation.

## Contributions
- 4-bit quantization technique with superior generation quality compared to existing 4-bit methods
- Identification of channel-specific temporal sparsity patterns across timesteps
- Custom accelerator with heterogeneous mixed-precision dense-sparse dataflow
- 6.91x speedup and 51.5% energy reduction compared to dense accelerators

## Metrics
- Speedup: 6.91x vs dense accelerators
- Energy: 51.5% reduction

## Baselines
- Dense accelerators, Existing 4-bit quantization methods

## Limitations
Evaluation on diffusion models without broader generative model coverage.
