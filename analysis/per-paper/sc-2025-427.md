# RedSan: A Redundant Memory Instruction Sanitizer for GPU Programs

**Paper ID:** sc-2025-427
**Venue:** SC
**Authors:** Yanbo Zhao, Yueming Hao, Zecheng Li 0001, Shuyin Jiao, Xu Liu 0001, Jiajia Li 0001

## Problem

Existing GPU profiling tools focus on hotspot identification but miss opportunities for removing redundant instructions in already-optimized CUDA programs.

## Motivation

Redundant memory operations are common even in production-grade code; identifying and eliminating them could unlock significant performance gains beyond standard profiling.

## Method

Binary instrumentation-based profiler to identify redundant memory instructions. Instruments optimized CUDA programs to detect unnecessary loads/stores without source-code access. Applied to standard benchmarks (PolybenchGPU, Rodinia, PASTA, DARKNET, LULESH).

## Key Novelty

First binary instrumentation tool specifically targeting redundant memory instructions in CUDA; achieves >6× speedup by identifying opportunities missed by existing profilers.

## Contributions

- RedSan binary instrumentation profiler for redundant memory detection
- Actionable optimization guidance beyond hotspot analysis
- 6.27× speedup and 3× memory instruction reduction on benchmarks
- Demonstrated effectiveness on both compute-bound and memory-bound kernels
