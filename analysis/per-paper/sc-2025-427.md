# RedSan: A Redundant Memory Instruction Sanitizer for GPU Programs

**Paper ID:** sc-2025-427
**Venue:** SC
**Authors:** Yanbo Zhao, Yueming Hao, Zecheng Li 0001, Shuyin Jiao, Xu Liu 0001, Jiajia Li 0001

## Problem

Existing GPU profiling tools focus on hotspot identification but miss opportunities for removing redundant instructions in already-optimized CUDA programs.

## Motivation

Redundant memory operations are common even in production-grade code; identifying and eliminating them could unlock significant performance gains beyond standard profiling.

## Method

The tool works by inserting monitoring code into compiled CUDA programs to track every memory operation—both loads (reading data) and stores (writing data)—as the program runs, without requiring access to the original source code. It identifies when the same data is loaded multiple times unnecessarily or when data is stored but never used, marking these as redundant operations. The method was validated on standard performance benchmarks: PolybenchGPU, Rodinia, PASTA, DARKNET, and LULESH.

## Key Novelty

It's the first tool to use binary instrumentation (monitoring how compiled CUDA code actually runs, without source files) to find and eliminate redundant memory operations, achieving over 6× speedup by catching inefficiencies that existing profilers miss.

## Contributions

- RedSan binary instrumentation profiler for redundant memory detection
- Actionable optimization guidance beyond hotspot analysis
- 6.27× speedup and 3× memory instruction reduction on benchmarks
- Demonstrated effectiveness on both compute-bound and memory-bound kernels
