# ASNPC: An Automated Generation Framework for SNN and Neuromorphic Processor Co-Design

**Venue**: DATE  
**Primary Theme**: hardware-algorithm codesign for SNNs via multi-objective optimization  

## Problem
SNN and neuromorphic processor design typically prioritize single optimization criterion; hardware-algorithm codesign space is vast with expensive function evaluations.

## Method
ASNPC uses a prediction model to efficiently search through the vast space of SNN-processor design options without needing expensive hardware simulations. It automatically generates hardware code (RTL, which describes exactly how the processor's circuits work) for the most promising designs and feeds their performance results back into the search. Over multiple iterations, this discovers a set of good designs where each makes different trade-offs between competing goals like speed, energy efficiency, and accuracy.

## Key Novelty
Combining a prediction model for exploring multiple design trade-offs with automatic hardware code generation enables efficient SNN-processor co-design.

## Contributions
- ASNPC hardware-algorithm codesign framework for SNNs
- MOTPE surrogate-based multi-objective optimization
- Automatic RTL code generation from hardware templates
- Better Pareto solutions with lower resource usage and higher throughput vs existing works
