# SparseTransX: Efficient Training of Translation-Based Knowledge Graph Embeddings Using Sparse Matrix Operations

**Problem:** Translational KGE training (TransE, TransR, TransH, TorusE) is bottlenecked by fine-grained scatter/gather embedding operations (up to 40% of CPU training time), causing irregular memory access and high intermediate memory allocation.

**Method:** Instead of using inefficient scattered operations to extract embeddings one-by-one, SparseTransX reformulates training as a single sparse matrix multiplication. It encodes each training fact as a row in a sparse matrix with +1 and -1 markers showing which embeddings to add or subtract, then multiplies this sparse matrix against the dense embedding table to compute all predictions at once for both forward prediction and backward gradient phases. The approach supports four translation-based embedding models (TransE, TransR, TransH, TorusE) and uses optimized sparse libraries: iSpLib with SIMD vectorization for CPUs and DGL's g-SpMM for GPUs, including support for distributed training via PyTorch's DDP and FSDP.

**Key novelty:** First SpMM-based reformulation of scatter-gather in translational KGE; sparse incidence matrix unifying embedding extraction into a single optimized matrix multiply.

**Metrics:**
- Up to 5.3x CPU speedup vs TorchKGE (TransE)
- Up to 4.2x GPU speedup vs TorchKGE (TransE)
- 5.61 vs 13.55 GB GPU memory for TransE (2.4x reduction)
- 0.28 vs 3.1 GB GPU memory for TransH (11x reduction)
- 220 vs 484 billion FLOPs for TransE (2.2x reduction)
