# A Memory-Efficient LLM Accelerator with Q-K Correlation Prediction using Cluster-Based Associative Array for Selective KV Accessing

**ID**: dac-2025-440  
**Venue**: DAC  
**Confidence**: low

## Problem
Autoregressive LLM inference incurs redundant attention computations and high KV cache memory access; full cache retention wastes bandwidth as many key-value pairs contribute minimally to output.

## Motivation
Attention dominates LLM latency and memory bandwidth; reducing cache access without retraining enables immediate deployment.

## Method
During language model inference, the system avoids reading all key-value pairs from cache; instead, it predicts which ones will matter for generating the next output. It uses cluster-based associative arrays (lookup tables organized into related groups for rapid matching) to calculate correlation scores between the current query and each cached pair. A prediction engine filters out low-scoring pairs, keeping only the important cache accesses. A custom ASIC chip accelerates this by exploiting sparsity in attention patterns (the fact that most attention weights are near zero).

## Key Novelty
The key insight is using Q-K correlation prediction—measuring how much each cached key-value pair relates to the current query—to selectively access only important pairs, without requiring model retraining.

## Contributions
- Associative array-based Q-K correlation predictor
- Specialized hardware accelerator for prediction
- Selective KV cache access reducing off-chip memory
- 2.1x-93.8x speedup over prior work and GPUs
