# HyTiS: Hybrid Tile Scheduling for GPU GEMM with Enhanced Wave Utilization and Cache Locality

**Paper ID:** sc-2025-424
**Venue:** SC
**Authors:** Zheng Zhang 0036, Hulin Wang, Hongming Xu, Donglin Yang, Xiaobo Zhou 0002, Dazhao Cheng

## Problem

Wave quantization problem in modern large-core-count GPUs with large tile sizes causes partial wave under-utilization and degraded GEMM performance despite high peak throughput.

## Motivation

GEMM is fundamental to deep learning and scientific computing; modern GPUs scale cores and tile sizes, exacerbating wave quantization; existing solutions are inefficient or introduce synchronization overhead.

## Method

HyTiS uses two-level hybrid tile scheduling: the first level uses standard tile sizes to keep all GPU processing waves (groups of threads running together) fully utilized, while the second level switches to fine-grained adaptive tiles for leftover work that doesn't fill complete waves, reducing partial-wave latency. It pre-profiles different tile combinations offline and stores the most efficient ones as a library. Finally, it selects tile layouts using an analytical model that predicts data movement between main GPU memory and L2 cache, optimizing to minimize this movement.

## Key Novelty

The first framework to jointly address wave quantization and L2 cache efficiency in GPU matrix multiplication by using fine-grained adaptive tiling for partial waves and an analytical model to select tile layouts based on cache behavior.

## Contributions

- Two-level hybrid tile scheduling framework for full and partial waves
- Offline profiling to build efficient runtime search space
- Analytical L2 cache model for tile layout optimization
- 1.95–2.08× speedup over cuBLAS on H100/A100
