# Inferring Likely Counting-related Atomicity Program Properties for Persistent Memory

**Problem:** Developers must ensure atomicity guarantees for counting operations in persistent memory systems, but manually specifying and verifying atomicity properties is error-prone and difficult. The challenge is automatically inferring which memory operations require atomic guarantees to maintain data consistency across crashes.

**Method:** Static analysis infers likely counting-related atomicity properties by examining program data dependencies and memory access patterns. The technique identifies which operations on counters and accumulators need atomic guarantees to preserve consistency in persistent memory contexts.

**Novelty:** Automatic inference of counting-related atomicity program properties in persistent memory rather than requiring explicit programmer specification or manual verification.
