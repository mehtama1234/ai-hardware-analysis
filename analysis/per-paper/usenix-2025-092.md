# Inferring Likely Counting-related Atomicity Program Properties for Persistent Memory

**Problem:** Developers must ensure atomicity guarantees for counting operations in persistent memory systems, but manually specifying and verifying atomicity properties is error-prone and difficult. The challenge is automatically inferring which memory operations require atomic guarantees to maintain data consistency across crashes.

**Method:** The technique analyzes your code without running it, examining how counting operations (like incrementing values) depend on each other and access memory. It automatically determines which operations need to be atomic—completing entirely or not at all—so that your data stays consistent if the system crashes. This matters especially for persistent memory systems, where memory survives crashes and partial updates can corrupt accumulated data.

**Novelty:** The tool automatically infers which counting operations need atomic guarantees in crash-proof memory systems, rather than having programmers manually specify them.
