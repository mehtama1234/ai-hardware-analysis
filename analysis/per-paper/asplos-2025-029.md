# HALO: Loop-aware Bootstrapping Management for Fully Homomorphic Encryption

**ID:** asplos-2025-029  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Loop-aware automatic bootstrapping placement for FHE programs

## Problem
FHE programs using repeated multiplications deplete the ciphertext noise budget (level), requiring bootstrapping to reset it; existing compiler-based bootstrapping placement tools cannot handle loops, severely limiting automated support for practical FHE programs that use iterative constructs.

## Motivation
FHE is the premier approach for privacy-preserving computation on encrypted data, but the high overhead and programming burden of manually placing bootstrapping operations—especially inside loops—prevents adoption of FHE for real-world iterative algorithms.

## Method
HALO is a compiler that extends automatic bootstrapping placement to programs containing loops. It performs loop-aware level analysis to track ciphertext noise levels across loop iterations, determines the minimum set of bootstrapping operations required to prevent level underflow throughout the loop body and across all iterations, and inserts them automatically. The compiler reasons about loop-carried level dependencies to place bootstrapping at loop boundaries or within the loop body only where necessary.

## Key Novelty
First compiler to support automatic bootstrapping placement inside loops for FHE programs, enabling safe and efficient execution of iterative encrypted computations without programmer intervention.

## Contributions
- Loop-aware ciphertext level analysis that tracks noise budget across loop iterations for FHE programs.
- Automatic bootstrapping insertion algorithm that handles loop-carried level dependencies to prevent underflow.
- Reduction of programming burden for FHE developers writing iterative programs.
- Extension of prior bootstrapping placement compilers to a broader class of practical FHE programs.
