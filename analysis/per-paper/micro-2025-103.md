# LLM.265: Video Codecs are Secretly Tensor Codecs

**Venue:** MICRO  
**Confidence:** low (abstract-only analysis)

## Problem
LLM training and inference are increasingly bottlenecked by memory footprint and communication bandwidth for weights, activations, gradients, and KV cache, but existing tensor-compression methods are specialized for only one type of tensor and require custom hardware or software stacks. A unified, bandwidth-efficient compression mechanism applicable across all LLM tensor types is missing.

## Motivation
Video codec hardware (GPU video engines) has been refined for decades and is already present in commodity GPUs; if standard video codecs can exploit the statistical structure of LLM tensors, they offer an immediately deployable compression path with no GPU die-area addition.

## Method
LLM.265 repurposes the video codec hardware built into modern GPUs (H.265/HEVC engines) to compress neural network data. Neural network tensors—weights, activations, gradients, and KV cache (stored attention query/key vectors)—naturally contain redundancy similar to video: smooth regions, gradual changes, and correlated values. The system treats these tensors as video frames and applies the codec's standard compression stages to this structure: intra/inter prediction identifies patterns between neighbors, transform coding reorganizes data to expose structure, scalar quantization rounds values, and context-adaptive arithmetic coding encodes common patterns efficiently. Small hardware extensions to the existing video engine improve throughput without major GPU architectural changes.

## Key Novelty
It unifies compression of all neural network data types (weights, activations, gradients, KV cache) using existing GPU video codec hardware, eliminating the need for specialized compression accelerators.

## Contributions
- Demonstration that standard video codec stages (prediction, transform coding, quantization, entropy coding) effectively compress LLM weights, activations, gradients, and KV cache by exploiting their statistical structure
- LLM.265 system that repurposes existing GPU video engines for tensor compression during LLM inference and distributed training
- Proposed minimal hardware customizations to GPU video engines to improve tensor encode/decode throughput without major architecture changes
- Unified compression approach that works across all LLM tensor types without per-type specialized methods
