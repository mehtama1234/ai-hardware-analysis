# FleetIO: Managing Multi-Tenant Cloud Storage with Multi-Agent Reinforcement Learning

**Venue:** ASPLOS  
**Authors:** Jinghan Sun, Benjamin Reidys, Daixuan Li, Jichuan Chang, Marc Snir, Jian Huang  
**Confidence:** low (abstract only)

## Problem
Cloud virtualized flash storage (SSD) systems must support software-isolated and hardware-isolated tenant instances but face a fundamental tension between performance isolation (preventing noisy neighbors) and resource utilization — strong isolation wastes storage, while weak isolation causes long-tail latency.

## Motivation
Multi-tenant cloud SSD platforms have long struggled to jointly achieve performance isolation and high resource utilization, a problem that worsens as workload diversity increases and SSDs become the primary storage substrate.

## Method
FleetIO assigns each tenant a separate learning agent (using reinforcement learning, where agents improve through trial and error) that learns three coordination tasks: when to process I/O requests, how much storage each tenant gets, and which requests to accept. All agents watch the same system state and coordinate to simultaneously achieve per-tenant performance isolation (preventing noisy neighbors from slowing you down) and efficient overall storage utilization. Since the agents learn automatically rather than relying on hand-tuned policies, the system adapts to changing workloads and jointly optimizes tail latency (the slowest requests) and storage efficiency.

## Key Novelty
FleetIO replaces hand-tuned storage policies with one learning agent per tenant (software that automatically improves through trial-and-error) that balances giving each tenant isolated, predictable performance with overall storage efficiency, by coordinating through shared system observations.

## Contributions
- FleetIO: a multi-agent RL system for managing multi-tenant cloud flash storage
- Joint optimization of performance isolation and resource utilization via MARL
- Support for both software-isolated and hardware-isolated storage instance types
- Demonstration of adaptive storage management under varying multi-tenant workloads
