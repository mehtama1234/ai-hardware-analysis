# FleetIO: Managing Multi-Tenant Cloud Storage with Multi-Agent Reinforcement Learning

**Venue:** ASPLOS  
**Authors:** Jinghan Sun, Benjamin Reidys, Daixuan Li, Jichuan Chang, Marc Snir, Jian Huang  
**Confidence:** low (abstract only)

## Problem
Cloud virtualized flash storage (SSD) systems must support software-isolated and hardware-isolated tenant instances but face a fundamental tension between performance isolation (preventing noisy neighbors) and resource utilization — strong isolation wastes storage, while weak isolation causes long-tail latency.

## Motivation
Multi-tenant cloud SSD platforms have long struggled to jointly achieve performance isolation and high resource utilization, a problem that worsens as workload diversity increases and SSDs become the primary storage substrate.

## Method
FleetIO applies multi-agent reinforcement learning (MARL) to dynamically manage storage resources across multiple tenants. Each tenant is managed by a separate RL agent that learns policies for I/O scheduling, resource allocation, and admission control. The agents coordinate through shared environment observations to balance per-tenant isolation with global storage utilization, enabling adaptive responses to changing workload patterns without hand-tuned policies.

## Key Novelty
Applying multi-agent reinforcement learning to cloud SSD resource management, where per-tenant agents jointly learn to balance isolation and utilization through shared environment feedback.

## Contributions
- FleetIO: a multi-agent RL system for managing multi-tenant cloud flash storage
- Joint optimization of performance isolation and resource utilization via MARL
- Support for both software-isolated and hardware-isolated storage instance types
- Demonstration of adaptive storage management under varying multi-tenant workloads
