# DoCeph: DPU-Offloaded Storage Messaging

## Problem
Ceph messenger layer imposes substantial CPU overhead on host systems, limiting storage performance and datacenter efficiency.

## Approach
Disaggregate Ceph by offloading messenger to NVIDIA BlueField-3 DPU:
- Lightweight RPC for metadata operations
- DMA for data transfer
- Pipelining to overlap transmission with buffer prep

## Results
- **92% reduction** in host CPU usage
- Stable throughput maintained
- Larger benefits for >1 MB object writes

## Architecture
```
Host (Storage Backend) <--DMA--> DPU (Messenger) <--Network--> Clients
```

## Impact
Demonstrates DPU value for I/O-intensive workloads. CPU offload enables host resources to be redirected to storage processing, improving datacenter utilization.
