# 3D-SubG: 3D PIM Accelerator for Subgraph Graph Neural Networks

**Venue:** DAC | **ID:** dac-2025-188

## Summary
3D-SubG stacks logic and DRAM dies via hybrid bonding with SRAM-based PIM macros for subgraph GNN acceleration. Exploits sparsity via bit-level gathering, balances workloads across blocks, and uses distributed pooling to minimize inter-block movement.

## Key Results
- **Performance:** 146.11× vs. RTX 3090Ti
- **Area Efficiency:** 934.18× improvement
- **Energy Efficiency:** 1171.80× improvement
- **Technique:** 3D hybrid bonding + PIM + sparsity exploitation + workload balancing

## Technique
3D stacking of logic die (with SRAM-based PIM macros) atop DRAM die via hybrid bonding; bit-level non-zero gathering for sparsity; workload-balanced subgraph allocation; distributed global pooling minimizes inter-block data movements.
