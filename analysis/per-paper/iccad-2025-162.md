# PipeSDFA - RRAM-based IMC Accelerator for SNN Training via Direct Feedback Alignment

PipeSDFA implements spiking neural network training on RRAM-based in-memory computing accelerators using Direct Feedback Alignment (DFA) as an alternative to backpropagation. By leveraging analog multiply-accumulate operations in RRAM and the reduced computational requirements of DFA, the system achieves 10.5× speedup while maintaining training quality. This work demonstrates the synergy between specialized learning algorithms and analog computing technologies, opening pathways for efficient neuromorphic learning on emerging memory technologies.
