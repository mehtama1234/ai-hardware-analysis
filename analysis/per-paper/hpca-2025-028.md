# hpca-2025-028: Rethinking Dead Block Prediction for Intermittent Computing

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing dead block predictors are ineffective in energy-harvesting intermittent computing because they do not account for power failures that invalidate cache blocks before reuse, causing unnecessary leakage on nominally 'live' but doomed blocks.

## Motivation
Energy-harvesting IoT devices execute intermittently with frequent power failures; minimizing cache leakage is critical for forward execution progress, but conventional dead block predictors misidentify power-failure-doomed blocks as worth retaining.

## Method
EDBP augments existing dead block predictors with a power-failure-aware layer that identifies cache blocks unlikely to be accessed before the next anticipated power failure. These blocks are deactivated to eliminate leakage energy. EDBP is combined with Cache Decay to approach near-theoretical-minimum cache leakage across 20 Mediabench and MiBench applications.

## Key Novelty
Incorporating power failure prediction into dead block identification so that blocks that are conventionally "live" but unreachable due to imminent energy exhaustion are proactively deactivated.

## Contributions
- EDBP framework extending dead block predictors with intermittence-aware deactivation.
- 6.5% total energy reduction and 6.9% performance improvement (EDBP standalone).
- 9.8% energy reduction and 11.9% performance improvement (EDBP + Cache Decay), approaching theoretical minimum.

## Metrics
- energy: 9.8% total energy reduction (EDBP + Cache Decay)
- other: 11.9% performance improvement; evaluated on 20 Mediabench/MiBench applications

## Hardware Target
CPU

## Techniques
cache, power

## Baselines
No dead block predictor baseline; Cache Decay predictor (conventional)

## Limitations
Power-failure prediction relies on empirically estimated energy thresholds that may not generalize across different harvesting environments or supply voltage profiles.
