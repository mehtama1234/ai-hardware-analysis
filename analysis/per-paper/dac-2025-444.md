# Insights from Rights and Wrongs: A Large Language Model for Solving Assertion Failures in RTL Design

**ID**: dac-2025-444  
**Venue**: DAC  
**Confidence**: low

## Problem
SystemVerilog assertion failures in RTL simulation require manual analysis of complex signal timing and logic relationships; no automated tool exists to diagnose and fix failures.

## Motivation
RTL verification is a bottleneck in chip design; automating assertion debugging accelerates design closure.

## Method
AssertSolver trains a large language model on synthetic examples of SystemVerilog assertion failures paired with their fixes. The model learns from these examples and improves when its predictions are wrong (error-driven learning). When given an assertion failure, it generates diagnostic code and proposes design fixes to resolve the issue.

## Key Novelty
AssertSolver is the first large language model trained specifically to fix SystemVerilog assertion failures, using artificially generated failure examples and learning from its own mistakes to improve.
