# Insights from Rights and Wrongs: A Large Language Model for Solving Assertion Failures in RTL Design

**ID**: dac-2025-444  
**Venue**: DAC  
**Confidence**: low

## Problem
SystemVerilog assertion failures in RTL simulation require manual analysis of complex signal timing and logic relationships; no automated tool exists to diagnose and fix failures.

## Motivation
RTL verification is a bottleneck in chip design; automating assertion debugging accelerates design closure.

## Method
AssertSolver is an LLM fine-tuned on synthetic SVA failure-fix pairs and learns from error feedback. Given an assertion failure, the model generates diagnostic code and proposed design fixes.

## Key Novelty
First LLM specifically trained for SVA assertion solving using synthetic data and error-driven learning from challenging cases.

## Contributions
- Open-source LLM for assertion failure debugging
- Synthetic training dataset construction
- Error-driven refinement strategy
