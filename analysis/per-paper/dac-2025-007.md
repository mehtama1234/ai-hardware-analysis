# DARIS: An Oversubscribed Spatio-Temporal Scheduler for Real-Time DNN Inference on GPUs

**Problem:** GPUs underutilized in DNN inference due to coarse-grained scheduling; cannot exploit spatial-temporal concurrency.

**Method:** DARIS is a scheduler that decides what work runs on a GPU when. It combines two techniques: NVIDIA's Multi-Process Service (MPS) lets multiple tasks share different parts of the same GPU at the same time (space-sharing), while CUDA streams run tasks at different times in sequence (time-sharing). The system synchronizes these tasks so work can move between GPU sections instantly without waiting. By analyzing how tasks can run concurrently, it packs more work onto the GPU than conventional approaches allow.

**Key Contribution:** Oversubscription mechanism enables 15% throughput gain over batching without sacrificing deadline guarantees.

**Results:** 11.5% improvement over state-of-the-art; high-priority tasks meet deadlines; <2% miss rate for low-priority.
