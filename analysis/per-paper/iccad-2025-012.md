# 3D DRC: Design Rule Checking for 3D IC with U-Net-based Non-Manhattan Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-012

## Problem
3D IC design rule checking must handle both 2D/3D rules and non-Manhattan geometries, but existing tools require sequential workflows increasing complexity.

## Motivation
Unified 3D DRC enabling single-pass checking improves verification efficiency for advanced packaging technologies.

## Method
U-Net-based deep learning model performs 2D and 3D DRC simultaneously with optimizations for non-Manhattan geometries. Trained on various PDK rule sets for generalization.

## Key Novelty
U-Net-based unified 2D/3D DRC tool with non-Manhattan geometry support, replacing sequential tool workflows.

## Contributions
1. U-Net architecture for 2D/3D DRC rule checking in single pass
2. Optimizations for non-Manhattan geometry handling in 3D IC
3. Generalization across open-source PDK rule sets
4. 22.3x faster than Calibre nmDRC; 13.3x faster than Calibre 3DSTACK

## Hardware Target
ASIC

## Technique Category

## Workloads

## Metrics
- **speedup:** 22.3x vs. Calibre nmDRC (2D); 13.3x vs. Calibre 3DSTACK (3D)
- **accuracy:** 97.5% recall, 97.7% precision
- **other:** unified 2D+3D in single pass

- Calibre 3DSTACK

## Limitations
Deep learning approach may struggle with unseen PDK rules; training data requirements not detailed.
