# 3D DRC: Design Rule Checking for 3D IC with U-Net-based Non-Manhattan Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-012

## Problem
3D IC design rule checking must handle both 2D/3D rules and non-Manhattan geometries, but existing tools require sequential workflows increasing complexity.

## Motivation
Unified 3D DRC enabling single-pass checking improves verification efficiency for advanced packaging technologies.

## Method
A deep learning model called U-Net analyzes the chip design layout (treating it like an image analyzed at multiple detail levels) to simultaneously check design rules across all layers. It handles rules for horizontal layers, vertical connections between layers, and non-Manhattan geometries (diagonal and curved shapes) all in one step, rather than running separate sequential checks. The model is trained on design rule sets from different semiconductor manufacturers, allowing it to work across various production processes.

## Key Novelty
A single U-Net deep learning model performs all design checks simultaneously—for horizontal layers, vertical connections, and diagonal shapes—replacing sequential tool workflows.

## Contributions
1. U-Net architecture for 2D/3D DRC rule checking in single pass
2. Optimizations for non-Manhattan geometry handling in 3D IC
3. Generalization across open-source PDK rule sets
4. 22.3x faster than Calibre nmDRC; 13.3x faster than Calibre 3DSTACK
