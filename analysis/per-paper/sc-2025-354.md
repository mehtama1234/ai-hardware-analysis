# Learning to Schedule: A Supervised Learning Framework for Network-Aware Scheduling of Data-Intensive Workloads

**Paper ID:** sc-2025-354
**Venue:** SC
**Confidence:** low

## Problem Statement
Kubernetes schedulers ignore network conditions, leading to poor job placement and slow data transfers

## Motivation
Network-intensive workloads need placement aware of bandwidth asymmetry and congestion, not just CPU/memory availability

## Method
The system collects real-time data about network conditions between servers (like how fast data travels and how busy the connections are). It uses machine learning (AI trained on this data) to predict how long each job would take to finish on different servers. Then it ranks these predictions and places each job on the server predicted to finish it fastest.

## Key Novelty
It learns from real-time measurements of network performance across multiple data centers to predict which server will finish each job fastest, then places jobs there instead of ignoring network conditions.
