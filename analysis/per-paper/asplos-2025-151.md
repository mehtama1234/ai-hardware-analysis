# asplos-2025-151: Stramash: A Fused-Kernel Operating System For Cache-Coherent, Heterogeneous-ISA Platforms

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Heterogeneous-ISA processors require disjoint OS kernels per ISA with heavy coordination overhead; existing multi-kernel designs use message-passing rather than exploiting cache-coherent shared memory, leaving performance on the table.

## Motivation
Cache-coherent shared memory among heterogeneous-ISA CPUs provides an unexploited substrate for a unified OS design that could eliminate multi-kernel coordination overhead.

## Method
Stramash creates a single operating system kernel that runs on heterogeneous CPUs—ones using different instruction sets like x86 and RISC-V—by treating cache-coherent shared memory (memory that all CPUs can access and modify while staying synchronized) as its primary foundation. Unlike traditional multi-kernel operating systems that coordinate separate kernels through message-passing, Stramash puts its core data structures directly in shared memory and adds new mechanisms for synchronization, memory management, and task scheduling that work transparently regardless of which instruction set a CPU uses. The team built this by adapting Linux (Stramash-Linux) and validated it with a multi-ISA simulator (Stramash-QEMU) that achieves less than 4% average simulation error.

## Key Novelty
The fused-kernel OS unifies CPUs with different instruction sets by running a single operating system kernel built directly on cache-coherent shared memory, rather than coordinating separate kernels per ISA.

## Contributions
- Fused-kernel OS design exploiting cache-coherent shared memory among heterogeneous-ISA CPUs
- New OS mechanisms for ISA-transparent synchronization, scheduling, and memory management
- Stramash-Linux prototype extending monolithic Linux across ISAs
- Stramash-QEMU simulator with <4% error; up to 2.1x speedup over multi-kernel OS on NPB
