# SSDL-ILT: Efficient ILT utilizing a self-supervised deep learning model

## Summary
Self-supervised deep learning for inverse lithography technology enabling fast mask optimization without labeled data.

## Key Results
- **Up to 12,000x speedup** vs SOTA models
- **Good pattern fidelity** improvement
- **Strong generalization** to different patterns via few-shot learning

## Core Innovation
Self-supervised approach eliminates expensive labeled data; automatic SRAF generation with adjustable manufacturability control.

## Technique
Novel loss function guides self-supervised training for pixel-level mask optimization; automatically generates SRAFs; outputs final masks without further iteration.
