# HiPER: Hierarchically-Composed Processing for Efficient Robot Learning-Based Control
**Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Learning-Based Model Predictive Control (LMPC) for robot navigation combines neural network inference with iterative MPC optimization, creating a mixed workload with rapidly varying computational patterns that neither GPUs nor simple CPU-GPU integrations can serve efficiently. The workload alternates between dense ML computation and sparse, irregular MPC solves across time steps.

## Motivation
Robotic autonomy increasingly demands real-time LMPC at the edge, but the unique temporal and spatial variability of LMPC workloads exceeds the adaptability of general-purpose GPU architectures.

## Method
HiPER is a 1024-PE ASIC synthesized in 16nm CMOS (16.37 mm²) built around a fractal interconnect topology that nests local systolic arrays within a hierarchical extension to handle the traffic characteristics of LMPC. A six-level pointer queue hierarchy orchestrates program composition and execution, enabling temporal and spatial mapping of workload phases at runtime. The pointer queues serve as a lightweight control mechanism that composes heterogeneous sub-programs without a complex scheduler, allowing dynamic adaptation to workload changes.

## Key Novelty
Fractal interconnect topology combining local systolic arrays with hierarchical extensions, orchestrated by a multi-level pointer queue hierarchy that enables runtime temporal and spatial remapping for mixed ML+MPC workloads.

## Contributions
- Hierarchically-composed processing array with fractal systolic interconnect supporting both dense ML and irregular MPC computation.
- Six-level pointer queue control hierarchy enabling lightweight runtime workload composition and adaptation.
- 10.75x performance improvement over GTX 1080 GPU and 12.80x energy efficiency improvement over Jetson Orin Nano.
- 11.6x/22.2x performance improvement over RoboX/Plasticine accelerators for LMPC workloads.
