# GraphFI: Graph-Specific Fault Injection on GPGPUs

## Problem
Existing fault injection methods ignore graph-specific execution paradigms (iterations, vertices, error propagation), producing inaccurate system error resilience characterization and blind fault injection trials that are computationally expensive.

## Method
GraphFI avoids testing billions of possible fault scenarios by finding patterns in how graphs execute on GPUs. It selects representative moments in execution when similar vertices are computing (iteration-driven), groups vertices by how similarly they fail when faults occur (topology-driven), and uses fault monotonicity—the principle that worse faults always produce worse outcomes—to predict which failures would be severe without testing all possibilities. Combining these three strategies cuts the test scenarios needed by up to 100x.

## Key Results
- 2.1-15.2x speedup vs SOTA fault injection methods
- Up to 100x reduction in fault site space
- Better reliability assessment accuracy
