# FiDe: Reliable and Fast Crash Failure Detection to Boost Datacenter Coordination

**Problem:** Machine crash detection in datacenters must balance detection speed (critical for maintaining consistency) against false positive rates that trigger incorrect failovers. Current failure detection mechanisms struggle to optimize both dimensions simultaneously.

**Method:** FiDe monitors machines by running multiple independent checks: regular status signals between machines (heartbeats), direct network tests, and requiring agreement from a majority of monitoring nodes (quorum-based verification) before declaring a machine dead. Rather than using a fixed timeout that works poorly under varying network conditions, it adjusts how long to wait before declaring a machine failed based on current network delays. This approach reduces false alarms when networks are congested while maintaining fast detection of genuine crashes.

**Novelty:** FiDe separates the speed-versus-reliability tradeoff into independent tuning dimensions rather than trying to optimize both simultaneously.
