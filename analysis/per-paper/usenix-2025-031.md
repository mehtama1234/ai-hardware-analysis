# DEEPSERVE: Serverless Large Language Model Serving at Scale

**Problem:** Serving large language models at scale in cloud environments faces critical challenges in resource allocation, serving efficiency, and cold start latencies. Traditional approaches cannot rapidly elasticity-scale while maintaining performance.

**Method:** DEEPSERVE organizes work into three nested levels—requests, jobs, and tasks—to simplify management. It uses FLOWSERVE, a lightweight serving engine built around NPUs (specialized AI processing chips), which runs copies of the model in parallel across multiple machines using SPMD (running the same code on different inputs across processors). To handle traffic surges, it keeps containers ready to launch, pre-loads model data into memory, and uses NPU-fork (a technique to quickly duplicate a running model instance) to scale from one machine to 64 machines in just seconds.

**Novelty:** Combining NPU-fork (a fast technique to duplicate running AI models on specialized chips) with automatic serverless scaling enables large language models to start handling requests in under a second on a cluster of separate Ascend NPUs.
