# hpca-2025-110: Predicting DRAM-Caused Risky VMs in Large-Scale Clouds

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
DRAM failures in large-scale clouds are currently mitigated at node granularity, requiring migration of all VMs on a node even when errors affect only a small fraction of the memory address space. This coarse-grained approach consumes excessive resources and causes unnecessary VM disruptions.

## Motivation
At cloud scale (300,000+ nodes), fine-grained DRAM failure prediction at the VM level can dramatically reduce migration costs and VM crash rates compared to node-level approaches, as DRAM errors are spatially clustered in memory.

## Method
Pegasus introduces an Error-VM mapping framework that correlates DRAM ECC error addresses to specific VM memory regions using address space management metadata. A predictor combines ECC correction event features with spatio-temporal clustering features to identify VMs whose working sets overlap with DRAM regions exhibiting uncorrectable error risk. The system operates at VM granularity rather than DIMM/node granularity, enabling selective migration of only at-risk VMs.

## Key Novelty
First VM-level DRAM failure prediction system that maps DRAM error addresses to specific virtual machines, enabling fine-grained proactive migration rather than whole-node migration.

## Contributions
- Novel concept of DRAM-caused risky VMs as prediction target for cloud reliability
- Error-VM mapping framework correlating physical DRAM error addresses to VM address spaces
- Predictor combining ECC and spatio-temporal features achieving prediction performance comparable to node-level approaches
- Deployed at production scale on 300,000+ nodes: >70% cost reduction and >10% fewer VM crashes vs. node-level mitigation
