# MMDFL: Multi-Model-based Decentralized Federated Learning for Resource-Constrained AIoT Systems

**Venue:** DAC
**ID:** dac-2025-378

## Problem
Decentralized federated learning on resource-constrained AIoT devices faces challenges from limited computing/bandwidth, non-IID data, and expensive all-neighbor aggregation.

## Motivation
Centralized FL suffers single-point-of-failure and communication bottlenecks; DFL avoids parameter server but still struggles with resource constraints.

## Method
MMDFL uses multiple traveler models performing local training across devices, with adaptive device selection based on data heterogeneity and resource availability. Knowledge aggregation is decoupled from full neighborhood dependencies.

## Key Novelty
Multi-model traveler architecture enabling adaptive peer exploration in decentralized federated learning with reduced communication.

## Contributions
1. Multi-model-based learning framework using traveler models for distributed knowledge sharing
2. Adaptive device selection strategy accounting for data heterogeneity, resource constraints, and catastrophic forgetting
3. Significant reduction in communication overhead vs state-of-the-art DFL methods
4. Improved classification performance for both IID and non-IID data scenarios
