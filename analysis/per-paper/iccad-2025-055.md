# SOME: Symmetric One-Hot Matching Elector - A Lightweight Microsecond Decoder for Quantum Error Correction

**Venue:** ICCAD | **ID:** iccad-2025-055

## Problem
Conventional QEC decoders trade off between high thresholds (MWPM/UF) with complexity or long decoding times. Need to decode errors in microseconds for practical quantum computers.

## Motivation
Enable practical quantum error correction with microsecond-scale decoding while maintaining high threshold.

## Method
The decoder reformulates quantum error correction as an optimization problem: given sensor measurements (syndromes) revealing where errors occurred, find the errors that most likely caused them. Using One-Hot QUBO—a specific optimization structure—each variable represents a pairing between error locations, and the cost reflects measured error probabilities. The algorithm solves by finding permutation matrices (mathematical structures where each row and column has exactly one 1) that minimize total cost, which directly identifies the most probable errors.

## Key Novelty
The One-Hot QUBO formulation reduces the number of variables by 99.9x and enables quantum error correction to decode errors in microseconds on commodity CPUs.

## Contributions
- Quadratic unconstrained binary optimization formulation as permutation matrix construction
- 99.9x variable count reduction through symmetric one-hot encoding
- Microsecond decoding times on single-threaded commodity CPU
