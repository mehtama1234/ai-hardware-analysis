# Everything Depends on Your Hammer: A Systematic Rowhammer Attack Exploration on SPHINCS+

**Venue:** ICCAD  
**ID:** iccad-2025-000

## Problem
Post-quantum cryptographic implementations are vulnerable to rowhammer-based fault injection attacks on native systems, where remote attackers can forge digital signatures.

## Motivation
As quantum computing advances, securing PQC implementations against practical fault attacks is critical for cloud and multi-user systems.

## Method
Characterize the DRAM fault model on specific platforms (DDR3/DDR4), then devise optimal rowhammer attacks by analyzing fault patterns. Demonstrate a forgery attack on SPHINCS+ using rowhammer on standard liboqs implementation.

## Key Novelty
First rowhammer-based forgery attack on SPHINCS+ (NIST standard), demonstrating practical fault injection threats for hash-based digital signatures in cloud systems.

## Contributions
1. System-specific fault characterization approach for native systems vs. embedded systems
2. Novel rowhammer-based forgery attack on SPHINCS+ with DDR3/DDR4 DRAM
3. Practical demonstration on standard liboqs library implementation
4. Platform-optimized attack methodology exploiting target-specific fault susceptibility
