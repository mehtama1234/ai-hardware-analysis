# Everything Depends on Your Hammer: A Systematic Rowhammer Attack Exploration on SPHINCS+

**Venue:** ICCAD  
**ID:** iccad-2025-000

## Problem
Post-quantum cryptographic implementations are vulnerable to rowhammer-based fault injection attacks on native systems, where remote attackers can forge digital signatures.

## Motivation
As quantum computing advances, securing PQC implementations against practical fault attacks is critical for cloud and multi-user systems.

## Method
The researchers first mapped the pattern of DRAM errors (bit flips caused by rowhammer—repeatedly accessing the same memory row to corrupt adjacent data) on actual hardware platforms (DDR3 and DDR4). They then used this fault pattern information to craft targeted rowhammer attacks designed to flip the specific bits needed to forge digital signatures. Finally, they demonstrated a working forgery attack on SPHINCS+, a post-quantum signature algorithm, using the standard liboqs implementation.

## Key Novelty
This work demonstrates the first practical rowhammer attack (repeated memory access that flips bits in DRAM) capable of forging digital signatures on SPHINCS+, a hash-based algorithm that NIST standardized for post-quantum cryptography, showing this is a real security threat for cryptographic software in cloud systems.

## Contributions
1. System-specific fault characterization approach for native systems vs. embedded systems
2. Novel rowhammer-based forgery attack on SPHINCS+ with DDR3/DDR4 DRAM
3. Practical demonstration on standard liboqs library implementation
4. Platform-optimized attack methodology exploiting target-specific fault susceptibility
