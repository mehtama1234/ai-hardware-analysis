# Boosting System-on-Chip Performance Through AI-Assisted Optimization Using Compositional Neural Networks

**Paper ID:** vlsid-2025-072
**Venue:** VLSID
**Confidence:** low

## Problem
SOC performance verification and pre-silicon optimization involves tuning many parameters (frequency, voltage, routing) to meet targets; manual optimization is time-consuming and error-prone.

## Motivation
Complex parameter interdependencies make manual SOC optimization impractical; need for automated, efficient optimization framework leveraging AI.

## Method
The system trains neural networks at the interfaces between chip components, using real performance data from complete SOC designs to teach them how different design parameters affect performance. Instead of building an expensive full-chip model, it composes these interface-level networks—combining them according to how the components connect—into a single system-level performance predictor. This composed predictor then guides a search algorithm to efficiently find the best parameter configurations.

## Key Novelty
By composing neural networks trained at component interfaces, the method builds a system-level performance predictor that avoids expensive full-chip modeling.

## Contributions
- Compositional neural network framework for SOC optimization
- Interface-level neural models for component performance prediction
- Reduced training time vs full SOC models
- Efficient design parameter search
