# Boosting System-on-Chip Performance Through AI-Assisted Optimization Using Compositional Neural Networks

**Paper ID:** vlsid-2025-072
**Venue:** VLSID
**Confidence:** low

## Problem
SOC performance verification and pre-silicon optimization involves tuning many parameters (frequency, voltage, routing) to meet targets; manual optimization is time-consuming and error-prone.

## Motivation
Complex parameter interdependencies make manual SOC optimization impractical; need for automated, efficient optimization framework leveraging AI.

## Method
Three-stage framework: (1) Train neural models at component/cluster interfaces on SOC dataset to predict performance from design parameters, (2) Neural networks guide search algorithm to find optimal configurations, (3) Compositional neural network at SOC level using interface-level parameters.

## Key Novelty
Application of compositional neural networks to SOC optimization; leverages interface-level models to build system-level predictor without expensive full SOC modeling.

## Contributions
- Compositional neural network framework for SOC optimization
- Interface-level neural models for component performance prediction
- Reduced training time vs full SOC models
- Efficient design parameter search
- Improved SOC validation efficiency
