# A Baseline Framework for the Qualification of LTL Specification Miners

**Venue**: DATE  
**Primary Theme**: Standardized LTL miner evaluation  

## Problem
Evaluating the effectiveness of Linear Temporal Logic specification miners is challenging because predefined ranking metrics often fail to ensure quality when no fixed ground truth exists and specification relevance varies by use case, limiting standardization of the field.

## Method
The framework ensures consistent testing by running each miner in an isolated Docker container—standardized computing environments that prevent installation differences from affecting results. It provides modular evaluation methods that assess both what a specification means (semantic) and how it's structured (syntactic), so different evaluation approaches can be plugged in as needed. Instead of hunting for consensus on real specifications, the framework automatically generates synthetic benchmarks: artificial specifications with known correct answers that miners should discover. This provides an objective measure of whether miners work correctly.

## Key Novelty
The core idea is using automatically generated synthetic specifications as objective ground truth for evaluating miners.

## Contributions
- Comprehensive LTL specification miner evaluation framework standardizing methodology
- Docker containerization enabling easy third-party miner deployment and execution
- Modular evaluation method design supporting extension with new assessment techniques
- Synthetic benchmark generation providing non-subjective ground truth
- Comparative analysis of four well-known LTL miners demonstrating framework utility
