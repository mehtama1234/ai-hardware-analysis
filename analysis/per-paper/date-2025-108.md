# A Baseline Framework for the Qualification of LTL Specification Miners

**Venue**: DATE  
**Primary Theme**: Standardized LTL miner evaluation  

## Problem
Evaluating the effectiveness of Linear Temporal Logic specification miners is challenging because predefined ranking metrics often fail to ensure quality when no fixed ground truth exists and specification relevance varies by use case, limiting standardization of the field.

## Method
Proposes comprehensive evaluation framework with Docker-based containerization for miner installation and configuration, modular design for semantic/syntactic assessment methods, and automatic generation of synthetic benchmarks serving as objective ground truth.

## Key Novelty
Structured framework with automated synthetic benchmark generation for objective LTL miner evaluation.

## Contributions
- Comprehensive LTL specification miner evaluation framework standardizing methodology
- Docker containerization enabling easy third-party miner deployment and execution
- Modular evaluation method design supporting extension with new assessment techniques
- Synthetic benchmark generation providing non-subjective ground truth
- Comparative analysis of four well-known LTL miners demonstrating framework utility
