# isscc-2025-223: Energy-Efficient 3D Flash for AI Applications

## Quick Summary
A 1Tb 3b/cell 3D Flash memory with 29% improved read energy efficiency via small-voltage-swing WL control and 4.8Gb/s high-speed I/Os, designed for area-efficient AI data storage.

## Problem
3D Flash for AI applications requires:
- High-speed I/O (4.8Gb/s+)
- Energy-efficient reads (critical for big data)
- Minimal circuit overhang in CMOS-bonded-array or CMOS-under-array designs
- Compact area to avoid exceeding memory array footprint

## Method
The chip stores 1 terabyte using 3D Flash memory (vertically stacked silicon), with each cell holding 3 bits. It cuts read power consumption by 29% through small-voltage-swing word-line control (applying smaller electrical pulses to activate memory rows instead of large ones, which wastes less energy). Data moves at 4.8 gigabits per second via power-isolated low-tapped-termination I/Os (data connections that keep support circuits tightly bundled), minimizing the extra area needed beyond the memory array.

## Key Novelty
The key innovation is reducing the voltage pulse for memory row activation (small-voltage-swing word-line control), achieving 29% lower read energy while keeping support circuits tightly integrated with the memory in 3D stacking.

## Contributions
- 1Tb capacity, 3b/cell density
- 29% read energy improvement
- 4.8Gb/s I/O bandwidth
- Low-overhang circuit design
- Power-isolated termination
