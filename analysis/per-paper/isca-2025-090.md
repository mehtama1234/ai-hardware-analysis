# Chimera: Communication Fusion for Hybrid Parallelism in Large Language Models

**ID:** isca-2025-090 | **Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Hybrid parallelism for LLMs on multi-NPU systems generates large volumes of diverse blocking collective communications, severely throttling compute utilization. Redundant collective operators produced by combining multiple parallelism dimensions compound the bottleneck.

## Motivation
Communication overhead is the dominant bottleneck in multi-NPU LLM scaling; eliminating redundant collectives via fusion improves throughput without accuracy loss.

## Method
Chimera analyzes communication processes for each parallelism dimension (tensor, pipeline, data, sequence), identifies redundant collectives arising from combining strategies, and eliminates them by fusing adjacent communication operators during parallelism transformation. It reorders operations and generates a single redundancy-free collective that achieves the semantics of the original sequence, injecting it into the LLM computation graph.

## Key Novelty
Cross-parallelism communication operator fusion detecting and eliminating redundant collectives from combined LLM parallelism strategies, replacing them with a single semantically equivalent fused operator.

## Contributions
1. Comprehensive analysis of communication redundancy across all hybrid LLM parallelism patterns
2. Chimera fusion mechanism merging adjacent communication operators during parallelism transformation
3. 1.23–7.06x network bandwidth speedup via redundancy elimination
4. 1.32–1.58x forward pass and 1.16–1.36x backward pass end-to-end speedup on multi-NPU systems

## Metrics
- Forward pass speedup: 1.32–1.58x
- Backward pass speedup: 1.16–1.36x
- Network bandwidth speedup: 1.23–7.06x

## Baselines
Multi-NPU LLM systems without communication fusion

## Limitations
Benefits depend heavily on the specific parallelism configuration used; systems with a single parallelism dimension gain little.
