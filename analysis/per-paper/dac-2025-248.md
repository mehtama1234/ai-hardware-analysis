# dac-2025-248: Late Breaking Results: Breaking Symmetry - Unconventional Placement of Analog Circuits using Multi-Level Multi-Agent Reinforcement Learning

## Summary
First multi-agent RL framework for analog circuit placement that explores asymmetric designs to improve variation performance beyond traditional symmetric layouts, outperforming simulated annealing.

## Key Idea
Use multi-agent Q-learning to break symmetry constraints and discover asymmetric placements that exploit non-linear LDE physics.

## Contributions
- Multi-agent RL for analog placement (first application)
- Better variation performance vs. symmetric techniques
- Objective-driven asymmetric exploration
- Outperforms simulated annealing

## Limitations
Limited to specific analog circuits; generalization across topologies/nodes not shown.
