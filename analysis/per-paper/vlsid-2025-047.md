# Unguided Machine Learning-Based Computation Offloading for Near-Memory Processing

**ID**: vlsid-2025-047 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
Data-intensive applications suffer from memory wall bottlenecks in traditional von Neumann architectures. Existing supervised ML approaches for near-memory processing (NMP) offloading require time-consuming labeled dataset creation, and naive application-wide offloading underutilizes due to NMP core power constraints.

## Motivation
3D-enabled NMP architectures can eliminate expensive off-chip memory transfers by performing computation near storage. However, the deployment burden and suboptimal offloading strategies of existing supervised approaches limit practical adoption.

## Method
- **Approach**: Unguided (unsupervised) clustering-based ML (UCO: Unguided Computation Offloading)
- **Process**: 
  1. Extract application performance characteristics without labels
  2. Cluster regions into CPU-optimal and NMP-optimal groups
  3. Selectively offload only memory-intensive regions to NMP
- **Evaluation**: Standard simulators + data-intensive benchmark applications

## Key Results
**vs. Conventional CPU-only**:
- 1.31x performance improvement
- 16% energy savings
- 78% off-chip data transfer reduction

**vs. State-of-the-art supervised approach**:
- 1.10x performance improvement
- 12% energy savings
- 73% off-chip data transfer reduction

## Novelty & Contributions
1. **First unsupervised ML approach** for NMP offloading, eliminating labeled training data burden
2. **Selective offloading strategy** targeting memory-intensive regions only, avoiding NMP core power limitations
3. **Practical deployment path** reducing time from concept to deployment
4. Strong empirical results on standard benchmarks

## Limitations
- **Benchmark-centric evaluation**: Generalization to novel or irregular workloads unclear
- **Static clustering**: No dynamic re-clustering for phase-changing workloads
- **Simplistic model**: Binary CPU/NMP clusters may not capture complex hierarchical behaviors
- **Limited analysis**: Hyperparameter sensitivity and tuning guidance not provided
- **Simulation-based**: No real hardware implementation or validation
