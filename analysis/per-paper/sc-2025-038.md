# sc-2025-038: An elastic job scheduler for HPC applications on the cloud

## Summary
Presents a Kubernetes-based elastic job scheduler for Charm++ HPC applications on cloud platforms. Enables dynamic rescaling of jobs based on cluster state to optimize resource utilization and minimize costs.

## Problem
- Cloud resources are elastic and charged by usage (pay-as-you-go)
- Traditional HPC programming models (MPI) require fixed resource counts at startup
- Inefficient for cloud where resources availability fluctuates
- Manual scaling is complex and error-prone

## Method
A Kubernetes operator (automated software that manages applications) controls Charm++ parallel programs and automatically adjusts how many computing resources each gets based on what's available in the cluster. The scheduler prioritizes jobs by importance level, giving high-priority work more resources when they're scarce. As resources become available, it expands job allocations; as demand drops, it shrinks them—reducing wasted compute nodes while keeping important jobs on track.

## Key Innovations
1. **Charm++ on Kubernetes**: First operator for this combination
2. **Priority-aware elasticity**: Rescaling considers job importance
3. **Low-overhead**: Minimal performance impact from dynamic rescaling
4. **Automatic rescaling**: Application resizing without manual intervention
