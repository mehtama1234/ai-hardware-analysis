# SC-2025-153: MANS

## Summary
Portable ANS (Asymmetric Numeral Systems) lossless compression framework for multi-byte integer data, with architecture-specific optimizations for CPUs and GPUs (NVIDIA/AMD).

## Problem
- ANS designed for single-byte data; multi-byte extension lacking
- No portable GPU implementations of ANS
- Compression ratio suboptimal for multi-byte integers
- Platform-specific implementations fragment ecosystem

## Key Contribution
**Adaptive Data Mapping (ADM)**: Converts multi-byte integers to single-byte representation based on data characteristics, enabling efficient ANS compression while maintaining portability.

## Performance
- **Compression ratio**: 1.24x improvement average
- **CPU throughput**: 870.27 MB/s
- **GPU speedups**:
  - NVIDIA A100: 288.45x vs CPU
  - AMD MI210: 135.86x vs CPU

## Hardware Support
- CPUs (x86, ARM)
- NVIDIA (A100, others)
- AMD (MI210, others)

## Approach
1. Adaptive Data Mapping for multi-byte → single-byte
2. CPU optimization (SIMD vectorization)
3. GPU optimization (kernel/memory tuning)
4. Unified API across platforms

## Applications
- Scientific data storage/transmission
- Large-scale data analytics
- Distributed computing I/O
