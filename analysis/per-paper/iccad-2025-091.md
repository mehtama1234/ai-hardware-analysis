# A Unified Design Flow for Homogeneous and Heterogeneous 3D Integration with Fine-Pitch Hybrid Bonding

**Venue:** ICCAD  
**ID:** iccad-2025-091

## Problem
Existing EDA tools lack native support for multi-tier 3D IC integration with fine-pitch hybrid bonding, leading to 3D via overflow and design rule violations when using pseudo-3D flows based on conventional 2D tools.

## Motivation
Enable efficient 3D IC design with native support for 3D-specific constraints like via count limitations and pitch overlaps, particularly for heterogeneous integration across different technology nodes.

## Method
The tool creates a single unified design process for multi-layer 3D chips, supporting both identical stacked layers and mixed chip types in one workflow. It starts by compacting the physical footprint while preserving all connections. Then it splits circuits across layers while respecting density limits for the tiny inter-layer connections called 3D vias. Speed-critical circuits are routed to faster layers to improve performance, and finally an algorithm trained by trial and error (reinforcement learning) automatically fixes any resulting connection violations.

## Key Novelty
This is the first unified design framework that natively handles both identical-chip stacks and mixed-type 3D integration.

## Contributions
- Reduces 3D via count by up to 62% with 45-89% via utilization
- Improves WNS by up to 62% and TNS by up to 74% through timing-aware cell assignment
- Eliminates overlapping 3D vias using RL-based post-route legalization
- Supports heterogeneous 3D ICs with different technology nodes
