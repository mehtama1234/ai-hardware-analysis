# isscc-2025-117: PAM-4 Receiver with Adaptive FFE/DFE

**Problem:** Datacenter serial links require >20dB channel loss equalization; ADC-based receivers power-hungry; naive RX FFE increases AFE noise.

**Method:** The receiver uses three tunable signal-processing stages (3-tap RX FFE, which adaptively cancel channel distortion) to create a target pulse pattern (1+0.50: main signal plus a half-strength echo) for a one-tap speculative decision-feedback stage (which predicts bits ahead of time to reduce delay). This recovers from 21.2dB of signal loss without requiring the transmitter to pre-process the signal (no TX FFE). The design separates the cancellation stages from the feedback stage to avoid timing conflicts, eliminates the first intersymbol interference (h1: the strongest echo from prior bits), and maintains power efficiency using mostly-analog circuits.

**Key Novelty:** 3-tap RX FFE generating target pulse response for speculative DFE without requiring TX FFE.

**Main Results:** 106.25Gb/s PAM-4, 2.06pJ/b efficiency, 21.2dB channel loss compensation.

**Confidence:** Low (abstract-only analysis)
