# Generating and Predicting Output Perturbations in Image Segmenters

**Venue**: DATE  
**Primary Theme**: adversarial noise generation and corruption prediction for vision safety  

## Problem
Image segmentation DNN and transformer models used in safety-critical autonomous pipelines are vulnerable to imperceptible sensor noise that causes corrupted segmentation outputs, threatening system safety.

## Method
The approach uses genetic algorithms—iterative search methods similar to natural selection—to generate noise patterns that fool image segmentation systems into producing corrupted outputs. It then trains a machine learning model to predict whether a given image will yield corrupted segmentation when exposed to such noise, achieving over 96% accuracy. The method is evaluated on YOLOv8 and DETR segmentation systems.

## Key Novelty
This is the first machine learning model to predict whether imperceptible noise will corrupt image segmentation with over 96% accuracy, and it shows that noise causing corruption doesn't need to be located in the same image regions where the corruption appears.

## Contributions
- Genetic algorithm-based adversarial noise generation method for image segmentation
- Corruption prediction model achieving >96% accuracy on real segmenters
- Evaluation on state-of-the-art segmenters (YOLOv8, DETR) demonstrating imperceptible yet effective attacks
