# Enabling On-Tiny-Device Model Personalization via Gradient Condensing and Alternant Partial Update

**Venue:** DAC | **ID:** dac-2025-131

## Core Problem
On-device training and personalization on tiny embedded devices (<1 MB SRAM, 2 MB Flash); backpropagation is prohibitively expensive.

## Method
TinyMP framework: Gradient Condensing reduces backprop complexity/memory; Alternant Partial Update selectively updates essential parameters without retraining.

## Key Novelty
Gradient Condensing and Alternant Partial Update for efficient on-tiny-device fine-tuning.

## Contributions
- Gradient Condensing for reduced complexity
- Alternant Partial Update for selective parameter updates
- 2.4x speedup on MobileNetV2/MCUNet
- 80.8% memory saving; 30.3% accuracy improvement
