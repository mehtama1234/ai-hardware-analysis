# Enabling On-Tiny-Device Model Personalization via Gradient Condensing and Alternant Partial Update

**Venue:** DAC | **ID:** dac-2025-131

## Core Problem
On-device training and personalization on tiny embedded devices (<1 MB SRAM, 2 MB Flash); backpropagation is prohibitively expensive.

## Method
TinyMP combines two techniques to train models on tiny devices. Gradient Condensing simplifies the gradient data (the directional information for updating model weights), reducing memory use while keeping model accuracy. Alternant Partial Update alternately selects essential model parameters (the weights that matter most) to update at each step, rather than updating everything, which reduces computation without needing external search processes.

## Key Novelty
By condensing gradient data and updating only essential model parameters, on-device fine-tuning becomes practical on tiny embedded devices with less than 1 MB SRAM and 2 MB Flash.

## Contributions
- Gradient Condensing for reduced complexity
- Alternant Partial Update for selective parameter updates
- 2.4x speedup on MobileNetV2/MCUNet
- 80.8% memory saving; 30.3% accuracy improvement
