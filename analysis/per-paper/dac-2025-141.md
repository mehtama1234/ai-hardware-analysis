# AARC: Automated Decoupled Resource Configuration for Serverless Workflows

## Problem
Traditional serverless resource allocation couples CPU and memory, creating suboptimal provisioning for diverse workloads. Decoupling improves flexibility but introduces a massive configuration space that is difficult to optimize for complex workflows.

## Method
AARC represents the workflow as a graph (showing how tasks depend on each other) and identifies the critical path—the longest sequence of tasks that determines overall execution time. Rather than testing every possible combination of CPU and memory amounts, it uses priority-based scheduling to focus on configuration choices with the biggest impact. This targeted approach maintains performance guarantees (service-level objectives) while dramatically reducing the search time for optimal configurations.

## Key Results
- 85.8-89.6% search time reduction
- 49.6-61.7% cost savings
- Maintains SLO compliance
