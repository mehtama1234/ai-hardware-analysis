# AARC: Automated Decoupled Resource Configuration for Serverless Workflows

## Problem
Traditional serverless resource allocation couples CPU and memory, creating suboptimal provisioning for diverse workloads. Decoupling improves flexibility but introduces a massive configuration space that is difficult to optimize for complex workflows.

## Method
AARC uses a Graph-Centric Scheduler to identify critical paths in workflow DAGs, then applies a Priority Configurator using priority scheduling techniques to optimize CPU-memory allocation. The approach reduces search time by focusing on high-impact configuration decisions and maintaining SLO compliance.

## Key Results
- 85.8-89.6% search time reduction
- 49.6-61.7% cost savings
- Maintains SLO compliance
