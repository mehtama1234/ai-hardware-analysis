# Make Updates Faster: A Fast Multi-Stripe Updates Framework in Erasure-Coded Storage Clusters

**Paper ID:** sc-2025-431
**Venue:** SC
**Authors:** Hai Zhou 0002, Dan Feng 0001

## Problem

Erasure coding introduces high update penalties due to read-modify-write overhead; existing schemes don't fully exploit locality or adapt to heterogeneous network conditions.

## Motivation

Erasure-coded storage reduces redundancy but update costs are high; data center workloads have clustered updates; dynamic network conditions require adaptive scheduling.

## Method

The framework speeds up updates to erasure-coded storage (where data is split across multiple drives with built-in redundancy) by combining three strategies. It groups updates targeting the same stripe—the set of drives holding related data—together to reduce network traffic. It selects an efficient node to collect the updates and designs a routing structure that balances the work across the network, avoiding bottlenecks. It also adjusts routing in real time based on network speeds, favoring faster connections.

## Key Novelty

It jointly optimizes three strategies—data locality, load balancing, and adaptive scheduling—for storage updates in erasure-coded systems for the first time, achieving 16–88% throughput gains.
