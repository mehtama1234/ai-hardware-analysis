# Make Updates Faster: A Fast Multi-Stripe Updates Framework in Erasure-Coded Storage Clusters

**Paper ID:** sc-2025-431
**Venue:** SC
**Authors:** Hai Zhou 0002, Dan Feng 0001

## Problem

Erasure coding introduces high update penalties due to read-modify-write overhead; existing schemes don't fully exploit locality or adapt to heterogeneous network conditions.

## Motivation

Erasure-coded storage reduces redundancy but update costs are high; data center workloads have clustered updates; dynamic network conditions require adaptive scheduling.

## Method

Three-part framework: (1) Locality-aware update merging reduces network traffic by coalescing requests to same stripe, (2) Abstract update schemes into collector selection + tree construction, greedily balance load, (3) Dynamic scheduling adapts to heterogeneous network bandwidth.

## Key Novelty

First framework to jointly optimize locality exploitation, load balancing, and dynamic scheduling for erasure-coded updates; 16–88% throughput gains.

## Contributions

- Locality-aware update request merging
- Greedy load-balanced collector and tree selection
- Dynamic stripe scheduling for bandwidth saturation
- 16.15–88.71% update throughput improvement
