# ISSCC 2025-200: Ultra-Compact 3-Layer Stacked Image Sensor with On-Die ISP

## Core Contribution
400×400 3-layer stacked digital pixel sensor achieving 3.24μm pixel pitch with 117dB single-exposure HDR, on-die ISP/FAU, and sparse transmission for AI/CV tasks in ultra-compact form factors.

## Technical Approach
- **Pixel Readout**: Single-ended comparator + optimized control logic
- **In-Pixel Storage**: 10b SRAM for exposure control and digitization
- **Single-Exposure HDR**: Per-pixel variable exposure time synthesis
- **On-Die ISP**: Frame averaging unit (FAU) for fixed-pattern noise (FPN) correction and image enhancement
- **Sparse Transmission**: Event-driven or region-of-interest transmission for AI/CV workload acceleration
- **3-Layer Stack**: Pixel layer + logic + ISP integration in monolithic 3D

## Performance Metrics
- **Pixel Size**: 3.24μm (extremely compact, suitable for AR/VR modules)
- **Resolution**: 400×400 (160k pixels, VGA-scale)
- **Dynamic Range**: 117dB (equivalent ~19-bit depth via exposure fusion)
- **Die Size**: 2.47×1.85mm^2 (fits AR/VR camera modules)
- **Global Shutter**: Yes (all pixels sampled simultaneously)

## Baselines
- 2-layer stacked DPS (1–2μm pixels, no on-die ISP)
- Conventional Bayer sensors (limited HDR, external ISP)
- Smartphone image sensors (larger form factor)

## Hardware Impact
Enables truly compact AR/VR glasses cameras with computational photography (HDR, denoising) and AI acceleration on-sensor, reducing external processing load and power consumption for metaverse devices.
