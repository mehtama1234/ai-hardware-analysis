# Multiplication-Free DNN Accelerator with Self-Synchronous Pipeline

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

An all-digital MADDNESS-based DNN accelerator using lookup table operations instead of multiplications, with self-synchronous pipeline accumulator for PVT robustness. Achieves 2.5x energy efficiency (174 TOPS/W) and 5x area efficiency (2.01 TOPS/mm²) in 22nm CMOS post-layout simulation.

## Key Contributions

- **LUT-Based Computation**: All-digital MADDNESS replacing multiplications with table lookups
- **Self-Synchronous Design**: Pipeline accumulator eliminating clock distribution complexity
- **Compact Architecture**: 5x area efficiency vs. conventional multiplier-based design
- **High Efficiency**: 174 TOPS/W (2.5x improvement), PVT-invariant operation

## Technical Focus

Exploits MADDNESS approximation technique while addressing implementation challenges through self-synchronous logic for clock distribution and compactness. Digital-only approach enables efficient fabrication at advanced nodes.

## Relevance

**Keywords:** lookup-table, maddness, dnn-accelerator, power-efficiency, self-synchronous
