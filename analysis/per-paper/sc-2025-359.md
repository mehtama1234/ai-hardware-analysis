# Distributed Cross-Channel Hierarchical Aggregation for Foundation Models

**Paper ID:** sc-2025-359
**Venue:** SC
**Confidence:** low

## Problem Statement
Tokenizing and aggregating multi-channel images for foundation models is compute-intensive

## Motivation
Vision-based scientific foundation models need efficient processing of high-channel-count imagery (hyperspectral, weather)

## Method
D-CHAG (Distributed Cross-Channel Hierarchical Aggregation): hierarchical channel aggregation compatible with tensor parallelism/model sharding

## Key Novelty
Distributed hierarchical aggregation for multi-channel vision transformers with 75% memory reduction and 2x throughput improvement

## Contributions
- D-CHAG distributed aggregation method
- 75% memory reduction on 1024 GPUs
- 2x throughput improvement on Frontier
