# dac-2025-403: SSFT: Algorithm and Hardware Co-design for Structured Sparse Fine-Tuning of Large Language Models

**Problem:** Sparse fine-tuning on GPUs underperforms due to irregular sparse memory access patterns that GPUs cannot efficiently handle.

**Method:** Sparse fine-tuning skips some calculations to reduce time and memory, but on regular GPUs the random pattern of which calculations to skip causes inefficient, scattered memory access. SSFT solves this by using regular, predictable patterns for which calculations to skip (structured sparsity), making memory access organized and efficient. A custom hardware accelerator (SSFT-Hw) is co-designed with the algorithm (SSFT-Alg) to efficiently handle these patterns without the memory overhead that generic sparse operations cause on standard GPUs.

**Key Novelty:** Structured sparsity patterns designed for efficient hardware implementation without generic sparse operation overhead.

**Contributions:**
- Predictable sparsity patterns for regularity
- Sparsity-aware accelerator design
- SOTA accuracy on BERT/LLaMA
- 51.0x vs GPU, 1.32x vs SOTA; 19.0x/1.48x energy
