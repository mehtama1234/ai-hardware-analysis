# dac-2025-403: SSFT: Algorithm and Hardware Co-design for Structured Sparse Fine-Tuning of Large Language Models

**Problem:** Sparse fine-tuning on GPUs underperforms due to irregular sparse memory access patterns that GPUs cannot efficiently handle.

**Method:** SSFT-Alg introduces predictable sparsity patterns for regularity; SSFT-Hw accelerator with sparsity-aware design avoids GPU overhead.

**Key Novelty:** Structured sparsity patterns designed for efficient hardware implementation without generic sparse operation overhead.

**Contributions:**
- Predictable sparsity patterns for regularity
- Sparsity-aware accelerator design
- SOTA accuracy on BERT/LLaMA
- 51.0x vs GPU, 1.32x vs SOTA; 19.0x/1.48x energy
