# Adaptive Graph Learning for Efficient Thermal Analysis of Multi-Stacking Chiplet Systems under Interface Variations

**ID:** iccad-2025-241

## Problem
Thermal analysis of 2.5D/3D chiplet systems with multiple stacking layers requires expensive FEM simulations. Interface variations add complexity and computational burden.

## Motivation
Multi-chiplet systems need rapid, accurate thermal prediction to enable efficient power management and design optimization.

## Method
GNN hybrid architecture combined with FEM for thermal prediction. Adaptive graph learning captures varying thermal properties across interface layers. 1000× speedup vs traditional FDM methods with 0.05% MAPE accuracy.

## Key Novelty
GNN-FEM hybrid that adapts to interface variations in multi-chiplet thermal behavior.

## Contributions
- GNN-based thermal modeling for chiplets
- FEM integration for accuracy
- 1000× speedup over FDM
- 0.05% mean absolute percentage error
- Interface variation handling
