# Adaptive Graph Learning for Efficient Thermal Analysis of Multi-Stacking Chiplet Systems under Interface Variations

**ID:** iccad-2025-241

## Problem
Thermal analysis of 2.5D/3D chiplet systems with multiple stacking layers requires expensive FEM simulations. Interface variations add complexity and computational burden.

## Motivation
Multi-chiplet systems need rapid, accurate thermal prediction to enable efficient power management and design optimization.

## Method
The method combines graph neural networks (AI models that map connections between components) with finite element simulation (dividing the chiplet stack into sections to calculate heat flow). A key technique is adaptive graph learning, which adjusts predictions based on the specific thermal properties at each layer's interface. This hybrid approach achieves 1000× faster predictions than traditional finite difference methods, with 0.05% mean absolute percentage error accuracy.

## Key Novelty
The innovation is using graph neural networks combined with finite element simulation to automatically adapt thermal predictions for stacked chiplets based on how each interface conducts heat differently.

## Contributions
