# Weave: Efficient and Expressive Oblivious Analytics at Scale

**Problem:** Oblivious analytics systems incur prohibitive computational and memory bandwidth overhead that prevents them from scaling to production-size datasets. Existing approaches trade expressiveness for performance or vice versa, making practical privacy-preserving analytics infeasible at scale.

**Method:** Weave optimizes privacy-preserving queries by grouping multiple queries together and mixing their execution order (shuffling), which spreads the overhead of hiding data access patterns across more work—making it cheaper per query. It runs computation across multiple computers and uses specialized data structures to reduce how much data must be transferred between storage and processors. It also uses processor-specific optimizations and vectorization (parallel processing of multiple operations) to speed up the core privacy operations.

**Novelty:** Weave achieves both speed and flexibility in privacy-preserving analytics by grouping queries together to distribute the overhead of hiding data access patterns.
