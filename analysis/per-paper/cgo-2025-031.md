# GraalNN: Context-Sensitive Static Profiling with Graph Neural Networks

**Venue:** CGO
**Confidence:** low

## Problem
Static profile prediction (without runtime profiles) is needed for optimal optimization, but existing methods lose precision by not exploiting complex CFG structure or calling context information. Accurate prediction requires better feature engineering.

## Motivation
Dynamic profiles are not always available; static profile prediction enables optimization before first execution. Context-sensitive profiling is critical for inlining and specialization decisions.

## Method
GraalNN uses Graph Neural Networks—a machine learning approach that works on connected graphs—to automatically learn patterns from control-flow graphs (diagrams showing which lines of code execute next) rather than relying on hand-designed patterns. It makes predictions in two stages: first, a basic prediction of how many times each piece of code runs without knowing what calls it, then a refinement using the call graph (the map of which functions call which others) to account for different calling contexts.

## Key Novelty
Rather than using manually-designed patterns, GraalNN automatically learns from code-flow diagrams using machine learning, then refines this by considering which functions call each other.

## Contributions
- GNN-based static profiling framework learning from CFG structure
- Two-stage context-insensitive + context-sensitive prediction
- 10.13% runtime speedup across industry benchmarks, 2.5x better than prior static profiling
- 3.7% throughput improvement on microservices
