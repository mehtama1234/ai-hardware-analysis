# The Munich Microfluidics Toolkit: Design Automation and Simulation Tools for Microfluidic Devices

**Venue:** ICCAD  
**ID:** iccad-2025-224  
**Confidence:** low

## Problem Statement
Microfluidic device design lacks comprehensive open-source design automation and multi-level simulation tools.

## Motivation
Integrated design automation toolkit accelerates microfluidic device development and lowers barriers to entry for researchers.

## Method
The toolkit takes specifications for a microfluidic device and automatically generates designs from them. It validates these designs through simulations at multiple levels—first testing individual components, then testing the complete system. As an open-source tool supporting diverse microfluidic design approaches, it can be used and adapted for different research needs.

## Key Novelty
This toolkit brings together automatic design generation and multi-level simulation validation for microfluidic devices in a single open-source package.

## Contributions

1. Open-source design automation framework
2. Multi-level simulation validation
3. Automatic design generation
4. Support for diverse microfluidic designs
