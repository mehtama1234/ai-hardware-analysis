# DecoRTL: A Run-Time Decoding Framework for RTL Code Generation with LLMs

**Venue:** ICCAD  
**ID:** iccad-2025-003

## Problem
LLM-generated RTL code suffers from hallucinations, repetitions, and syntax errors due to low confidence in structurally complex or semantically ambiguous regions.

## Motivation
Improving RTL generation correctness and diversity enables practical AI-assisted hardware design without manual code review.

## Method
DecoRTL generates multiple versions of code in parallel and compares where they agree. For each token, it adjusts temperature (a parameter controlling the model's conservatism)—setting it low for syntax-critical tokens (rigid rules) and high for design-critical tokens (exploratory choices). Finally, it ranks the candidate codes based on their mutual agreement.

## Key Novelty
The core insight is using contrastive sampling (comparing multiple generated versions) at test time, with different strategies for syntax-critical tokens (conservative) and design-critical tokens (exploratory), and requiring no model retraining.

## Contributions
1. Empirical analysis of token-level entropy during RTL generation identifying confidence issues
2. Self-consistency sampling for promoting correctness with diversity
3. Syntax-aware temperature adaptation mechanism per token role
4. Inference-time solution with no model fine-tuning required
