# CacheGuardian: A Timing Side-Channel Resilient LLC Design

**Venue:** ICCAD  
**ID:** iccad-2025-276

## Problem
The last-level cache (LLC) shared by multiple tenants in cloud computing is frequently exploited through timing side-channel attacks, enabling unauthorized data leakage. Existing defense mechanisms show deficiencies in performance overhead, attack coverage, and detection accuracy.

## Motivation
To provide stronger, broader, and more accurate protection against timing side-channel attacks with low performance overhead in shared LLC environments.

## Method
Hardware-based LLC protection featuring behavior-based, generic attack detector for real-time identification of multiple timing side-channel attacks and cache-set-level access control mechanism that restricts cache usage exclusively to identified attackers instead of influencing all security domains. Implemented and evaluated in gem5 simulator.

## Key Novelty
Behavior-based generic attack detector with cache-set-level access control for granular, low-overhead timing side-channel defense.

## Contributions
- Generic behavior-based attack detector capable of identifying multiple timing side-channel attacks in real time
- Cache-set-level access control restricting cache usage to identified attackers
- Up to 256× reduction in attack success rates including camouflaged variants
- 2.26% average performance improvement for benign workloads with only 2.4% storage overhead
