# asplos-2025-055 — Will We Ever have Truly Secure Operating Systems?

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Operating system kernels remain a dominant attack surface despite decades of security research; formal proofs of OS security have historically been limited to small microkernels and have not scaled to binary-level or general-purpose OS kernels.

## Motivation
Half a century after early OS verification attempts, OS faults continue to enable major security breaches, making mathematically sound OS security proofs a critical unsolved challenge for the systems community.

## Method
The researchers used Isabelle/HOL, an interactive theorem prover (a tool for mathematically proving software correctness), to create a complete chain of formal proofs for seL4. They proved the C source code was correct, then proved the compiled binary faithfully executed it, then proved the binary enforces security properties like confidentiality (data privacy) and integrity (preventing unauthorized changes), and finally gave a mathematically sound guarantee of worst-case execution time (the maximum time any operation takes) across 4 processor instruction sets. The work also included early-stage exploration of extending this methodology to general-purpose operating systems.

## Key Novelty
seL4 achieved the first complete, mathematically verified proof chain from human-written source code through compiled machine instructions all the way to proven security guarantees and maximum execution time limits, across 4 different processor architectures.

## Contributions
- Survey and synthesis of the seL4 formal verification program covering implementation correctness, binary verification, security enforcement, and WCET analysis.
- Coverage of proofs across 4 ISAs, demonstrating portability of the verification methodology.
- Discussion of open research challenges and speculative directions toward a provably secure general-purpose OS.
