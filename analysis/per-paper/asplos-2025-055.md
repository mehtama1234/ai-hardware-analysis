# asplos-2025-055 — Will We Ever have Truly Secure Operating Systems?

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Operating system kernels remain a dominant attack surface despite decades of security research; formal proofs of OS security have historically been limited to small microkernels and have not scaled to binary-level or general-purpose OS kernels.

## Motivation
Half a century after early OS verification attempts, OS faults continue to enable major security breaches, making mathematically sound OS security proofs a critical unsolved challenge for the systems community.

## Method
The paper surveys the seL4 microkernel verification program, which produced a proof chain from C implementation correctness, down to binary-level verification, through to security enforcement proofs (confidentiality, integrity) and sound worst-case execution-time analysis, covering 4 ISAs. The approach uses interactive theorem provers (Isabelle/HOL) to formally connect abstract security policies to compiled binary behavior, then discusses speculative early-stage work on extending this methodology to a provably secure general-purpose OS.

## Key Novelty
First complete proof chain from OS implementation to binary code to security enforcement properties across multiple ISAs, including sound worst-case execution time, for seL4.

## Contributions
- Survey and synthesis of the seL4 formal verification program covering implementation correctness, binary verification, security enforcement, and WCET analysis.
- Coverage of proofs across 4 ISAs, demonstrating portability of the verification methodology.
- Discussion of open research challenges and speculative directions toward a provably secure general-purpose OS.
