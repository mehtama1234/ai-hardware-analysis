# LP-Spec: Leveraging LPDDR PIM for Efficient LLM Mobile Speculative Inference with Architecture-Dataflow Co-Optimization

**Venue:** ICCAD | **ID:** iccad-2025-059

## Problem
Mobile LLM inference constrained by limited memory bandwidth and compute. Speculative inference increases compute-intensive GEMM operations creating new trade-offs for GEMV-accelerated PIM. Redundant draft tokens waste energy.

## Motivation
Enable efficient speculative inference on mobile devices through PIM architecture.

## Method
Architecture-dataflow co-design leveraging hybrid LPDDR5 performance-enhanced PIM: near-data memory controller enabling data reallocation between DRAM and PIM banks; hardware-aware draft token pruner minimizing energy consumption; dynamic workload scheduling maximizing parallel execution.

## Key Novelty
Architecture-dataflow co-design for speculative inference with draft token management on mobile PIM.

## Contributions
- LPDDR5 performance-enhanced PIM architecture for mobile speculative inference
- Hardware-aware draft token pruner reducing energy consumption
- Dynamic workload scheduling and data reallocation between DRAM and PIM

## Hardware Target
PIM

## Technique Category

## Metrics
- **Speedup:** 13.21x vs mobile solutions; 7.56x vs GEMV-accelerated PIM
- **Energy:** 7.56x energy efficiency improvement
- **PPA:** 99.87x energy-delay-product improvement
- **Other:** 12.83x EDP reduction vs AttAcc PIM; 415.31x vs RTX 3090 GPU

## Limitations
Mobile-specific design; scalability to larger models or data center systems unclear.
