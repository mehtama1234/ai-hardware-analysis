# LP-Spec: Leveraging LPDDR PIM for Efficient LLM Mobile Speculative Inference with Architecture-Dataflow Co-Optimization

**Venue:** ICCAD | **ID:** iccad-2025-059

## Problem
Mobile LLM inference constrained by limited memory bandwidth and compute. Speculative inference increases compute-intensive GEMM operations creating new trade-offs for GEMV-accelerated PIM. Redundant draft tokens waste energy.

## Motivation
Enable efficient speculative inference on mobile devices through PIM architecture.

## Method
The system co-designs both hardware architecture and data flow strategy to efficiently handle speculative inference (where the model guesses ahead to speed up token generation), using intelligent memory controllers that dynamically move data between regular memory and processing-in-memory (PIM) banks—special memory that computes directly where the data sits. A hardware component removes wasteful speculative token predictions to save energy. The system then schedules computations dynamically to maximize processor and memory utilization in parallel.

## Key Novelty
Jointly designing hardware architecture and data flow to efficiently handle speculative inference on mobile by filtering wasteful draft tokens.

## Contributions
- LPDDR5 performance-enhanced PIM architecture for mobile speculative inference
- Hardware-aware draft token pruner reducing energy consumption
- Dynamic workload scheduling and data reallocation between DRAM and PIM
