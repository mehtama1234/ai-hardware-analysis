# dac-2025-392: PIMDup: An Optimized Deduplication Design on a Real Processing-in-Memory System

**Problem:** Deduplication chunking causes excessive data movement; PIM systems (UPMEM DPUs) have restricted inter-DPU sharing, no multiplication support, and high CPU-DPU communication overhead.

**Method:** PIMDup tackles deduplication—finding and removing duplicate data—on UPMEM processing-in-memory chips (DPUs), which have processors built directly into memory. It spreads the work across many DPUs in parallel, breaks data into chunks using techniques that don't require multiplication (which these chips can't do efficiently), and minimizes how much data moves between the DPUs and the CPU. The system maintains 100% accuracy in identifying duplicates.

**Key Novelty:** First deduplication co-design for PIM constraints: elimination of multiplication and inter-DPU sharing limits.

**Contributions:**
- DPU-optimized chunking without multiplication
- Efficient parallelization for PIM deduplication
- Reduced DPU-CPU communication
- 1.67x speedup with 100% accuracy

**Confidence:** low (abstract-only)
