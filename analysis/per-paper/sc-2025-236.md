# ILAN: The Interference- and Locality-Aware NUMA Scheduler

**ID:** sc-2025-236
**Venue:** SC
**Confidence:** low

## Problem

OpenMP default scheduler is topology-agnostic; poor data locality and task interference on NUMA systems

## Motivation

Modern HPC uses NUMA; need interference-aware and locality-preserving task scheduling

## Approach

ILAN scheduler: moldability for interference mitigation + hierarchical scheduling for locality

## Key Novelty

Interference detection/mitigation; NUMA-aware hierarchical task scheduling; LLVM OpenMP integration

## Contributions

- Interference-aware task scheduling via moldability
- Hierarchical scheduling for NUMA data locality
- LLVM OpenMP runtime extension
- 13.2% average, 45.8% max speedup on 64-core AMD Zen 4
