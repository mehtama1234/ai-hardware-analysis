# TrackGNN: A Highly Parallelized and Self-Adaptive GNN Accelerator for Track Reconstruction on FPGAs

**Problem:** Real-time track reconstruction in high energy physics experiments requires processing graph neural networks under strict latency constraints that prevent deployment on general-purpose CPU and GPU platforms.

**Method:** TrackGNN employs a dataflow architecture with multiple levels of parallelism to accelerate GNN computations on FPGAs. A self-adaptive renaming mechanism optimizes the processing of graph structures to reduce latency. The design combines data parallelism and adaptive scheduling to improve both performance and resource efficiency.

**Novelty:** Self-adaptive renaming mechanism that reduces end-to-end latency with negligible resource overhead compared to prior FPGA GNN accelerators like FlowGNN.
