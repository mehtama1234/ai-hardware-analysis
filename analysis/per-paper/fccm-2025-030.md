# TrackGNN: A Highly Parallelized and Self-Adaptive GNN Accelerator for Track Reconstruction on FPGAs

**Problem:** Real-time track reconstruction in high energy physics experiments requires processing graph neural networks under strict latency constraints that prevent deployment on general-purpose CPU and GPU platforms.

**Method:** TrackGNN runs on FPGA hardware (a programmable circuit optimized for custom computations) and accelerates graph neural networks—AI models that process interconnected data points—by flowing data through multiple parallel processing stages simultaneously. It includes a self-adaptive renaming system that watches how the graph's nodes are structured and reorganizes their processing on the fly to reduce delays. By combining parallel data processing with flexible scheduling that adapts to each computation's needs, it achieves both speed and efficiency.

**Novelty:** The core innovation is a self-adaptive renaming system that dynamically reorganizes how graph nodes are processed, reducing overall latency with negligible extra hardware cost compared to earlier FPGA-based graph accelerators like FlowGNN.
