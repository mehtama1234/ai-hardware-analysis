# FineRR-ZNS: Fine-Granularity Read Refreshing for Zoned Namespace SSDs

**Venue:** DAC | **ID:** dac-2025-183

## Summary
FineRR-ZNS enables efficient read refreshing in ZNS SSDs via host-controlled block-level metadata remapping, eliminating the severe I/O overhead of zone-level refreshing. Includes zone reconstruction for complete data retrieval and prioritized read-access scheduling.

## Key Results
- **Approach:** Block-level metadata remapping + zone reconstruction + prioritized read access
- **Benefit:** Significant I/O throughput and refreshing efficiency gains vs. ZenFS
- **Target:** Zoned namespace SSD data protection

## Technique
Host manages block-level read refreshing through metadata remapping; zone reconstruction retrieves remapped data efficiently; remapped blocks prioritized for reads until next refresh cycle needed.
