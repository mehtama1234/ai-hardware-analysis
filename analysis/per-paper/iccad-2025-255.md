# PIGen: Accelerating ReRAM Co-Design via Generative Physics-Informed Modeling

**Venue:** ICCAD  
**Paper ID:** iccad-2025-255

## Problem Statement
Optimizing ReRAM device parameters across diverse materials and operating conditions is challenging for data-intensive computing applications.

## Motivation
Efficient ReRAM design requires bridging device physics with system-level performance targets while handling sparse experimental data.

## Method
PIGen uses a Physics-Informed Neural Network (PINN) to model ReRAM switching dynamics with physical constraints, combined with a Conditional Variational Autoencoder (CVAE) to generate optimized design parameters from performance targets (endurance, latency, energy).

## Key Novelty
Integrating physics-informed learning with generative design for automated ReRAM parameter optimization across materials.

## Contributions

1. PINN-based device modeling with sparse training data
2. CVAE-based generative system for parameter synthesis
3. 93× computational speedup over traditional simulations
