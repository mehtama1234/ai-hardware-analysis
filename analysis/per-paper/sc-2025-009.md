# A High Performance GPU CountSketch Implementation and Its Application to Multisketching and Least Squares Problems

**Venue:** SC
**Paper ID:** sc-2025-009
**Confidence:** low

## Problem Statement
CountSketch has not been thoroughly investigated for high-performance GPU implementation despite lower computational complexity than other sketches

## Motivation
Random sketching is useful for dimensionality reduction; multisketching (combining sketches) can reduce tuning cost; efficient GPU CountSketch enables practical deployment

## Method
The paper implements CountSketch—a dimensionality reduction technique that uses randomized hash functions to compress matrix data—to run efficiently on GPUs (graphics processors designed for parallel computation). It demonstrates how multisketching (applying the sketch multiple times and combining results) works with this GPU implementation. The method is applied to solve least squares problems (finding the best-fit solution when there are more equations than variables) and compared against the standard normal equations approach for both speed and numerical accuracy.

## Key Novelty
Implementing CountSketch to run efficiently on GPUs makes multisketching practical, and when applied to least squares it delivers a 77% speedup and better numerical stability than normal equations.
