# DialEgg: Dialect-Agnostic MLIR Optimizer using Equality Saturation with Egglog

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Expressing compiler optimizations in MLIR is tedious; optimization interactions are complex and unpredictable. Equality saturation could solve this but remains absent from production compilers.

## Core Innovation
Achieving dialect-agnostic integration of equality saturation with MLIR, enabling systematic optimization exploration without dialect-specific engineering.

## Method
DialEgg connects Egglog (an equality saturation engine—a tool that systematically generates and tests all mathematically equivalent forms of code to find the fastest version) to MLIR, a compiler optimization framework used across many programming languages. Rather than writing separate optimization rules for each MLIR variant (dialect), DialEgg automatically translates code back and forth between MLIR and Egglog formats. It comes with pre-built definitions for common MLIR operations, types, and attributes, so developers can benefit from equality saturation immediately.

## Key Contributions
- Dialect-agnostic framework (DialEgg) integrating Egglog equality saturation with MLIR
- Modeling of MLIR constructs (operations, types, attributes) in Egglog representation
- Automatic translation between MLIR and Egglog program representations

## Results
Demonstrates potential for combining equality saturation and MLIR through proof-of-concept use-cases.

## Limitations
Use-case evaluation is preliminary; quantitative performance gains not detailed.
