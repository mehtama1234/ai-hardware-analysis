# Pushing the Boundaries of AI Chips: From Monolithic 3D CMOS to Cryogenic Computing

**Venue**: DATE  
**Primary Theme**: 3D monolithic and cryogenic paradigms for AI computing  

## Problem
CMOS scaling approaches fundamental limits while AI and LLM workloads demand unprecedented compute performance and memory bandwidth, creating bottlenecks in current computing architectures.

## Method
Presents two complementary paradigms: (1) 3D monolithic CMOS integration using Complementary FETs (CFETs) with vertically stacked pMOS/nMOS transistors and memory layers integrated atop logic; (2) cryogenic temperature operation of chips where transistors achieve enhanced performance and reduced parasitic resistance.

## Key Novelty
Monolithic 3D CMOS architecture combining vertically stacked CFETs and on-logic memory stacking for unprecedented density and on-chip memory capacity.

## Contributions
- 3D monolithic CMOS integration strategy leveraging CFET vertical stacking for logic density
- Memory-on-logic integration paradigm for expanded on-chip capacity
- Cryogenic computing approach demonstrating performance and power benefits
