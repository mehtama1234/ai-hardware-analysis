# Efficiency, Expressivity, and Extensibility in a Close-to-Metal NPU Programming Interface

**Problem:** NPU programming toolkits present a fundamental tradeoff: low-level toolkits require substantial developer effort while high-level toolkits abstract away critical optimization features. Developers cannot simultaneously achieve ease-of-programming and fine-grained control over accelerator optimizations.

**Method:** The work presents an updated programmer interface to IRON, a close-to-metal NPU toolkit, introducing new and refined programming constructs with extensible mechanisms for placement and data transformation. Evaluation spans three dimensions: efficiency measured via code reduction and Halstead complexity metrics, expressivity demonstrated through support for existing IRON features and patterns, and extensibility illustrated via customizable placement and tiling tools.

**Novelty:** An extensible programmer interface for close-to-metal NPU programming that reduces code verbosity by ~26% while maintaining access to optimization features through modular placement and data transformation abstractions.
