# GridMind: LLMs-Powered Agents for Power System Analysis and Operations

**Venue:** SC

## Problem
Traditional power system analysis workflows are complex and create barriers to efficient decision-making in modern electric grids

## Motivation
Enable conversational scientific computing interfaces for power system analysis while maintaining numerical precision and expert decision support

## Method
The system uses multiple AI agents, where each agent pairs a large language model (AI trained to understand text) with a deterministic engineering solver (a specialized program that calculates exact answers). These agents coordinate two key power-grid tasks: AC Optimal Power Flow—finding the best way to route electricity through the grid—and N-1 contingency analysis, which tests what happens if one component fails. The agents communicate through natural language (human words) combined with function calls (explicit coded instructions), allowing the AI to understand the problem while the solvers calculate precise answers.

## Key Novelty
Smaller language models achieve comparable accuracy to larger models when paired with engineering solvers, while responding faster.

## Contributions
- Multi-agent framework integrating LLMs with deterministic solvers for power system analysis
- Workflow integration and knowledge accessibility via conversational interfaces
- Demonstration of correct solutions across multiple language models with varying computational costs
