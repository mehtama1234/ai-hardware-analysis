# GridMind: LLMs-Powered Agents for Power System Analysis and Operations

**Venue:** SC

## Problem
Traditional power system analysis workflows are complex and create barriers to efficient decision-making in modern electric grids

## Motivation
Enable conversational scientific computing interfaces for power system analysis while maintaining numerical precision and expert decision support

## Method
Multi-agent AI system integrating LLMs with deterministic engineering solvers; specialized agents coordinate AC Optimal Power Flow and N-1 contingency analysis via natural language interfaces with function calls

## Key Novelty
Agentic AI framework for scientific computing combining LLMs with rigorous engineering solvers; demonstrates smaller LLMs can achieve comparable accuracy with reduced latency

## Contributions
- Multi-agent framework integrating LLMs with deterministic solvers for power system analysis
- Workflow integration and knowledge accessibility via conversational interfaces
- Demonstration of correct solutions across multiple language models with varying computational costs
