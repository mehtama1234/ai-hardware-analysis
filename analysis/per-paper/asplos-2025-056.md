# asplos-2025-056 — ShadowLoad: Injecting State into Hardware Prefetchers

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Hardware prefetchers in modern CPUs maintain internal state (stride tables, stream detectors) that persists across security boundaries, and prior work showed this state leaks information across processes, user/kernel space, and TEEs. This paper extends the threat by demonstrating that an attacker can actively inject crafted state into a victim's prefetcher, turning it into a covert channel or interference primitive.

## Motivation
As microarchitectural side-channel attacks grow in sophistication, the ability to actively manipulate—not merely observe—hardware prefetcher state represents a new class of cross-boundary interference that existing mitigations (context-switch prefetcher flushes) do not fully address.

## Method
ShadowLoad crafts memory access sequences that train the hardware prefetcher's internal prediction structures (stride tables, stream buffers) to a desired state from an unprivileged attacker context. When the victim process subsequently executes, the pre-injected prefetcher state causes speculative prefetches that alter the victim's cache state or execution timing, enabling state injection across process, user-kernel, and TEE boundaries. The technique exploits the fact that prefetcher state is not flushed or partitioned at privilege transitions on affected CPUs.

## Key Novelty
Active injection of attacker-controlled state into hardware prefetcher prediction structures to influence victim execution, as opposed to passive observation of prefetcher-induced side channels.

## Contributions
- Demonstration of prefetcher state injection as an active cross-boundary attack primitive on real CPUs.
- Analysis of prefetcher state persistence across process, user-kernel, and TEE security boundaries.
- Concrete attack scenarios using ShadowLoad for covert channels and cross-privilege interference.
- Discussion of mitigation strategies and their limitations.
