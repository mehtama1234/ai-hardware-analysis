# Is RISC-V ready for High Performance Computing? An evaluation of the Sophon SG2044

**Venue:** SC

## Problem Statement
RISC-V adoption is rapid in embedded computing but lags in HPC; unclear if RISC-V can match performance of established HPC architectures

## Motivation
RISC-V offers openness and customization; Sophon SG2044 represents next-gen RISC-V for server workloads; need rigorous HPC performance evaluation
