# From Gates to SDCs: Understanding Fault Propagation Through the Compute Stack

**Venue**: DATE  
**Primary Theme**: fault propagation through compute stack  

## Problem
Understanding how silicon defects in arithmetic units propagate through CPU computation to produce Silent Data Corruption (SDCs). Arithmetic units are typically unprotected, making them primary sources of SDCs and program crashes.

## Method
The method combines two levels of simulation working together: gate-level simulation (modeling individual logic gates) to accurately capture how defects behave in arithmetic units, paired with microarchitecture simulation (simulating CPU instruction execution) which runs faster. In stage one, the researchers inject faults into arithmetic units during instruction execution and watch how those faults change the output values. In stage two, they run complete programs to completion and measure whether each fault results in silent data corruption (wrong answer without crashing), a crash, or gets masked (harmlessly absorbed).

## Key Novelty
By combining fast microarchitecture simulation with accurate gate-level models, the approach can run long programs to completion and catch rare silent data corruption events that couldn't be observed with a single simulation level.

## Contributions
- Quantified fault propagation from gate-level defects to program output
- Fine-grain metrics distinguishing SDCs, crashes, and masking outcomes
- Characterization enabling hardware/software fault detection and tolerance strategies
