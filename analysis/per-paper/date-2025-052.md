# From Gates to SDCs: Understanding Fault Propagation Through the Compute Stack

**Venue**: DATE  
**Primary Theme**: fault propagation through compute stack  

## Problem
Understanding how silicon defects in arithmetic units propagate through CPU computation to produce Silent Data Corruption (SDCs). Arithmetic units are typically unprotected, making them primary sources of SDCs and program crashes.

## Method
Hybrid microarchitecture-level fault injection combined with gate-level designs of arithmetic units. Two-stage analysis: (1) fault propagation through arithmetic unit outputs during instruction execution, (2) end-to-end program outcome impact quantifying SDC vs crash vs masking.

## Key Novelty
Combining microarchitecture simulation speed with gate-level accuracy enables running long programs to completion and observing rare SDC incidents impossible at single abstraction layers.

## Contributions
- Quantified fault propagation from gate-level defects to program output
- Fine-grain metrics distinguishing SDCs, crashes, and masking outcomes
- Characterization enabling hardware/software fault detection and tolerance strategies
