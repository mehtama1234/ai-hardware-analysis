# Late Breaking Results: Automatic Anomaly Detection Method in Physical Unclonable Functions using Data Mining Techniques

**Venue**: DATE  
**Primary Theme**: Data mining-based PUF anomaly detection  

## Problem
PUF-based security systems require distinguishing legitimate PUFs from those that are tampered, defective, or invalid; existing approaches lack systematic methods for detecting anomalies and security violations.

## Method
The approach uses data mining—a technique for finding patterns in data—to extract rules describing how legitimate Physical Unclonable Functions (PUFs: unique, unchangeable hardware identifiers) normally behave. It then compares new or suspicious PUFs against these learned patterns to detect anomalies: significant deviations that indicate tampering, manufacturing defects, or counterfeiting. By systematically identifying when a PUF doesn't match expected behavior, the system catches security compromises automatically.

## Key Novelty
Using data mining to automatically detect when PUFs deviate from patterns of legitimate chips, catching tampering and defects.

## Contributions
- Data mining methodology for characterizing valid PUF behavior patterns
- Rule-based anomaly detection framework for tampering and invalidity detection
- Experimental validation demonstrating tampering identification capability
