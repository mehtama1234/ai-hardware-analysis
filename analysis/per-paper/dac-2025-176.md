# KVO-LLM: Boosting Long-Context Generation Throughput for Batched LLM Inference

**Problem:** KV cache dominates memory traffic in long-context batched inference, under-utilizing accelerator PEs.

**Solution:** Algorithm-architecture co-design: salient-aware quantization + attention-guided pruning + operator fusion + cross-batch interleaving.

**Results:** >91% KV EMA reduction, 7.32x throughput, 5.52-8.38x energy efficiency improvement.

**Theme:** KV cache optimization for efficient long-context LLM inference.
