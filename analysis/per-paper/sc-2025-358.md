# CPU- and GPU-initiated Communication Strategies for Conjugate Gradient Methods on Large GPU Clusters

**Paper ID:** sc-2025-358
**Venue:** SC
**Confidence:** low

## Problem Statement
Conjugate Gradient methods have low computational intensity and high communication sensitivity, limiting scalability

## Motivation
GPU-accelerated solvers need efficient communication strategies for multi-GPU clusters with thousands of GPUs

## Method
They develop iterative solvers (like Conjugate Gradient, which solve equations by successive approximations) that overlap computation with data movement across large GPU clusters. Instead of routing all GPU-to-GPU data through the CPU, they use direct communication libraries (NCCL/RCCL for collective operations, NVSHMEM for direct memory access) that let GPUs exchange data efficiently. They test two variants: one where the CPU initiates data transfers, and one where GPUs initiate them directly.

## Key Novelty
The core idea is letting GPUs directly initiate data transfers using NVSHMEM, removing the CPU bottleneck that had to coordinate all communication in the cluster.
