# CPU- and GPU-initiated Communication Strategies for Conjugate Gradient Methods on Large GPU Clusters

**Paper ID:** sc-2025-358
**Venue:** SC
**Confidence:** low

## Problem Statement
Conjugate Gradient methods have low computational intensity and high communication sensitivity, limiting scalability

## Motivation
GPU-accelerated solvers need efficient communication strategies for multi-GPU clusters with thousands of GPUs

## Method
Scalable CG/pipelined CG solvers using GPU-aware MPI, NCCL/RCCL, NVSHMEM with CPU/GPU-initiated communication variants

## Key Novelty
GPU-initiated CG execution via NVSHMEM eliminating CPU synchronization bottlenecks for large-scale clusters

## Contributions
- Scalable CG and pipelined CG implementations
- GPU-initiated variant eliminating CPU involvement
- 8-14% single-GPU gains, 5-15% improvement at 1000+ GPUs
