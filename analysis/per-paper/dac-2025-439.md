# HybriMoE: Hybrid CPU-GPU Scheduling and Cache Management for Efficient MoE Inference

**ID**: dac-2025-439  
**Venue**: DAC  
**Confidence**: low

## Problem
MoE inference on resource-constrained hybrid CPU-GPU platforms requires offloading experts, but unstable expert activation patterns and complex workload distribution prevent efficient CPU-GPU scheduling and memory utilization.

## Motivation
MoE models offer large capacity gains but create uneven compute and memory demands; hybrid platforms can reduce memory pressure if scheduling is adaptive.

## Method
HybriMoE combines three techniques: (1) dynamic intra-layer scheduling that redistributes workloads between CPU and GPU per layer based on expert activation patterns, (2) impact-driven inter-layer prefetching that predicts required experts, (3) score-based KV/expert caching prioritizing high-value data.

## Key Novelty
Adaptive per-layer CPU-GPU work splitting based on real-time expert activation, replacing fixed mapping strategies.

## Contributions
- Dynamic intra-layer scheduling for workload balancing
- Impact-driven prefetching algorithm
- Score-based cache prioritization
- 1.33x-1.70x speedup over SOTA hybrid MoE inference
