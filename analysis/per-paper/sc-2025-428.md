# Secure In-Storage Execution of VTK Workloads on Modern Parallel NFS Data Servers

**Paper ID:** sc-2025-428
**Venue:** SC
**Authors:** Qing Zheng, Brian Atkinson, Jason Lee 0004, Daoce Wang, Gary Grider

## Problem

Scientific visualization on large datasets is bottlenecked by data movement from storage servers to compute clients; moving terabytes across network for filtering wastes bandwidth and latency.

## Motivation

Data reduction at source (early filtering) dramatically reduces network I/O; pNFS infrastructure already exists in HPC; offloading to data servers is cost-effective and compatible with security models.

## Method

pNFS-based pushdown architecture offloading VTK pipeline stages (read, filter) to data servers. FUSE-based interface for client-server communication. Leverages pNFS client location awareness and Linux enhancements for efficient local storage access. Preserves user credentials and permission checks.

## Key Novelty

First practical in-storage execution system for VTK on pNFS with FUSE interface; demonstrates 6–7× speedup via data filtering at source.

## Contributions

- pNFS pushdown architecture for in-storage VTK execution
- FUSE-based secure client-server interface preserving credentials
- Leverages Linux enhancements for efficient pNFS local access
- 6.1× end-to-end speedup and 7.1× data loading improvement
