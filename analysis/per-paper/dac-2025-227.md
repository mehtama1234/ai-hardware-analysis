# MIRACLE: Multimodal Information Retrieval via a Combined In-Memory Processing and Content Addressable Memory Approach

**Venue:** DAC
**ID:** dac-2025-227

## Problem
Multimodal retrieval via neural feature extraction + similarity search is inefficient; cosine similarity on von Neumann wastes memory bandwidth, and pure hashing sacrifices accuracy due to modal heterogeneity.

## Motivation
Transformer-based feature extraction is well-accelerated, but retrieval remains under-optimized; energy-efficient retrieval is critical for real-time multimodal systems.

## Method
The system makes multimodal retrieval faster using three steps. It starts with in-memory hashing (where the hardware computes hashes right where data lives, avoiding expensive data movement), which quickly ranks candidates. Then content-addressable memory—specialized hardware that searches many items in parallel—filters the list further. Finally, it reranks survivors using cosine similarity to fix accuracy lost during the approximate hashing step.

## Key Novelty
The core idea is combining in-memory hashing (exploiting hardware's native ability to compute without data movement) and content-addressable memory (for parallel search) to eliminate both memory-bandwidth and search-speed bottlenecks.

## Contributions

- PIM-based in-memory random hashing for multimodal features
- CAM-based parallel search space reduction
- Cosine similarity reranking for accuracy restoration
- 9.45x latency and 30.20x energy improvement over CPU baseline
