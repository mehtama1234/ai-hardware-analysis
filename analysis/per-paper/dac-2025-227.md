# MIRACLE: Multimodal Information Retrieval via a Combined In-Memory Processing and Content Addressable Memory Approach

**Venue:** DAC
**ID:** dac-2025-227

## Problem
Multimodal retrieval via neural feature extraction + similarity search is inefficient; cosine similarity on von Neumann wastes memory bandwidth, and pure hashing sacrifices accuracy due to modal heterogeneity.

## Motivation
Transformer-based feature extraction is well-accelerated, but retrieval remains under-optimized; energy-efficient retrieval is critical for real-time multimodal systems.

## Method
Hybrid architecture combining in-memory random hashing (PIM) for fast approximate ranking and content-addressable memory (CAM) for parallel search space reduction, followed by final cosine reranking for accuracy recovery.

## Key Novelty
PIM+CAM hybrid that leverages device-intrinsic hashing properties in memory while using CAM for efficient search reduction.

## Contributions

- PIM-based in-memory random hashing for multimodal features
- CAM-based parallel search space reduction
- Cosine similarity reranking for accuracy restoration
- 9.45x latency and 30.20x energy improvement over CPU baseline
