# asplos-2025-011: Velosiraptor: Code Synthesis for Memory Translation

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
OS code for configuring hardware memory translation and protection mechanisms must be manually adapted for each new hardware design, a repetitive and error-prone process that can introduce security-critical bugs breaking isolation guarantees for untrusted applications.

## Motivation
Hardware designers continuously develop new memory translation and protection mechanisms, and the manual effort required to keep OS code current creates a persistent source of security vulnerabilities in mission-critical memory configuration routines.

## Method
Velosiraptor takes a formal hardware model (a precise specification of the memory hardware's configuration options and how they work) and automatically generates the OS driver code needed to configure it. The system builds this code using a component library of pre-built translation operations and either a constraint solver (automated logic that figures out which settings work together) or template-based code generation (filling in patterns with hardware-specific details). The resulting code is guaranteed correct because it's assembled from verified components, eliminating the manual mistakes that happen when programmers adapt code for each new hardware design.

## Key Novelty
Automatically generating correct OS memory-translation drivers from a formal hardware specification instead of writing them by hand for each hardware design.

## Contributions
- Velosiraptor framework synthesizing OS memory translation configuration code from hardware specification models.
- Formal hardware model language for expressing memory translation and protection mechanisms.
- Demonstration of correctness and reduced development effort across multiple hardware translation schemes.
