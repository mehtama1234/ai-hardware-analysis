# dac-2025-431: Data-Centric ART Acceleration via Operation Coalescing

**Problem:** Adaptive Radix Tree operations suffer redundant traversals and high synchronization costs in concurrent scenarios.

**Motivation:** ART widely deployed but concurrency overhead and traversal redundancy degrade multi-threaded throughput.

**Method:** DCART is a specialized hardware processor that speeds up Adaptive Radix Tree operations by recognizing when the same nodes are accessed repeatedly over time (temporal similarity) or when searches tend to follow predictable sequences (spatial similarity). It combines multiple operations targeting the same tree nodes into single batches, eliminating redundant work. It also automatically adjusts which tree nodes and their search results it keeps in fast-access cache memory, based on which ones are used most frequently.

**Key Novelty:** Data-centric processing model coalescing operations with adaptive result caching.

**Contributions:**
- Operation coalescing on same ART nodes
- Adaptive caching of traversed nodes and results
- 21.1x–44.2x speedup; 71.1x–148.9x energy savings on FPGA

**Hardware Target:** FPGA

**Workloads:** Database

**Confidence:** low (abstract-only)
