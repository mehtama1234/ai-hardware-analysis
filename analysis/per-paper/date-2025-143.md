# EILID: Execution Integrity for Low-end IoT Devices

**Venue**: DATE  
**Primary Theme**: Real-time CFI for low-end IoT  

## Problem
Low-end IoT devices lack runtime execution integrity protection; control-flow attestation enables remote detection of attacks but requires communication with verifiers, preventing real-time mitigation of control-flow attacks targeting safety-critical or time-sensitive tasks.

## Method
EILID builds on a trusted hardware foundation (CASU Root-of-Trust) that keeps the software locked down and prevents it from being secretly modified. It then adds automatic checkpoints throughout the code to catch attacks when function calls or returns try to jump to unexpected places—checking both where functions are called (forward-edge) and where they return (backward-edge). To make this reliable even on devices with very limited memory, it maintains a secure shadow stack (a hidden backup copy of return addresses) that it compares against actual execution to detect attacks.

## Key Novelty
EILID achieves real-time local detection of control-flow attacks on resource-limited IoT devices by layering automatic code checks on top of a trusted hardware foundation, rather than relying on remote verification.

## Contributions
- EILID architecture combining prevention-based RoT with active CFI monitoring
- Semi-automatic code instrumentation technique for CFI integration
- Secure shadow stack implementation enabling backward-edge CFI
- Function-level forward-edge control-flow integrity mechanism
