# EILID: Execution Integrity for Low-end IoT Devices

**Venue**: DATE  
**Primary Theme**: Real-time CFI for low-end IoT  

## Problem
Low-end IoT devices lack runtime execution integrity protection; control-flow attestation enables remote detection of attacks but requires communication with verifiers, preventing real-time mitigation of control-flow attacks targeting safety-critical or time-sensitive tasks.

## Method
Constructs EILID hybrid architecture atop CASU Root-of-Trust ensuring static software immutability; provides fine-grained backward-edge and function-level forward-edge control-flow integrity through semi-automatic code instrumentation and secure shadow stack implementation.

## Key Novelty
Active hybrid RoT providing real-time local control-flow integrity monitoring on resource-limited devices.

## Contributions
- EILID architecture combining prevention-based RoT with active CFI monitoring
- Semi-automatic code instrumentation technique for CFI integration
- Secure shadow stack implementation enabling backward-edge CFI
- Function-level forward-edge control-flow integrity mechanism
