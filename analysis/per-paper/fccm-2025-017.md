# Toward Reconfigurable In-Pixel Computing: A Fault-Tolerant Design Flow for Machine Learning Accelerators: (Invited Paper)

**Problem:** Current HLS-generated hardware designs for in-pixel computing lack flexibility for task adaptation and robustness against single-event upsets (SEUs) in radiation environments. Existing implementations cannot be reconfigured post-deployment or efficiently handle fault tolerance constraints.

**Method:** A fault-tolerant framework performs bit-level vulnerability analysis on neural network weights to identify critical components, then selectively applies Triple Modular Redundancy (TMR) to those components. Custom memory modules are integrated into the HLS workflow to enable post-deployment reconfiguration. A TMR-aware back-end synthesis flow dynamically allocates redundancy according to user-defined area and power constraints.

**Novelty:** Selective bit-level vulnerability-aware TMR allocation that enables simultaneous post-deployment reconfiguration and adaptive fault tolerance within an HLS-integrated design flow.
