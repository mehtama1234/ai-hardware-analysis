# Toward Reconfigurable In-Pixel Computing: A Fault-Tolerant Design Flow for Machine Learning Accelerators: (Invited Paper)

**Problem:** Current HLS-generated hardware designs for in-pixel computing lack flexibility for task adaptation and robustness against single-event upsets (SEUs) in radiation environments. Existing implementations cannot be reconfigured post-deployment or efficiently handle fault tolerance constraints.

**Method:** The approach works by first scanning the neural network's weights (the parameters that control how the AI model makes decisions) to find which ones are most sensitive to radiation damage. It then protects only those critical weights using Triple Modular Redundancy — a fault-tolerance technique where three copies of each critical component are built and compared, so if one copy gets corrupted by radiation, the other two vote it down. The design includes custom memory blocks that can be reconfigured after the hardware is deployed, allowing tasks to be swapped without rebuilding the entire chip. A specialized synthesis tool then decides how much redundancy to add to each part based on area and power budgets you set.

**Novelty:** It uses vulnerability analysis to apply redundancy only where actually needed, rather than everywhere, and keeps the design reconfigurable after deployment.
