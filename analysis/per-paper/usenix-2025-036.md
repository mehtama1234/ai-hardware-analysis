# Z-LFS: A Zoned Namespace-tailored Log-structured File System for Commodity Small-zone ZNS SSDs

**Problem:** Commodity ZNS SSDs with small zones create sequential-write constraints that traditional log-structured file systems cannot efficiently satisfy, causing zone fragmentation, premature resets, and performance degradation.

**Method:** Z-LFS organizes data writes to align with the SSD's zones (limited storage blocks), preventing writes from crossing zone boundaries and triggering expensive resets. The system segments both the temporary write buffer and the file system's address space into zone-sized chunks, so data stays within zone limits by design. When reclaiming space (garbage collection), it prioritizes resetting individual zones rather than the entire drive, reducing the total reset burden. Adaptive zone mapping lets the system adjust zone assignments while maintaining sequential writes (ordered writing), which SSDs require for performance despite small zone boundaries.

**Novelty:** Z-LFS is the first production-ready file system optimized for commodity SSDs with small zones (limited-size storage regions), using a log-structured design that appends all writes sequentially.
