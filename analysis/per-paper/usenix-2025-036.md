# Z-LFS: A Zoned Namespace-tailored Log-structured File System for Commodity Small-zone ZNS SSDs

**Problem:** Commodity ZNS SSDs with small zones create sequential-write constraints that traditional log-structured file systems cannot efficiently satisfy, causing zone fragmentation, premature resets, and performance degradation.

**Method:** Z-LFS implements a zone-aware log-structured design that segments the write buffer and logical address space into zone-aligned units, applies zone-cognizant garbage collection to minimize resets, and uses adaptive zone mapping to tolerate small zone boundaries while maintaining sequential write properties.

**Novelty:** First production-ready log-structured file system optimized specifically for small-zone ZNS SSDs in commodity devices.
