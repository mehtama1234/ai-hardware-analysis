# Late Breaking Results: Practical Electromagnetic Fault Injection on Intel Neural Compute Stick 2

**Venue**: DATE  
**Primary Theme**: physical fault injection vulnerability in edge ML accelerators  

## Problem
Edge ML devices deployed in critical IoT infrastructure lack empirical evaluation of physical fault injection vulnerability; security posture of real edge accelerators undefined.

## Method
Conducts electromagnetic fault injection (EMFI) experiments on Intel Neural Compute Stick 2 using low-cost pulse generator hardware. Systematically varies EMFI fault parameters to induce misclassification at inference output, achieving repeatable results.

## Key Novelty
First practical demonstration of repeatable electromagnetic fault injection attacks causing misclassification on real Intel NCS2 edge ML accelerator.

## Contributions
- Practical EMFI attack methodology on commercial edge ML device (NCS2)
- Low-cost attack setup achieving repeatable misclassifications
- Empirical characterization of fault parameter space for edge ML inference
