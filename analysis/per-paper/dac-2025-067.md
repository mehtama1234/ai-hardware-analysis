# 3D-CIMlet: A Chiplet Co-Design Framework for Heterogeneous In-Memory Acceleration of Edge LLM Inference and Continual Learning

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Edge AI hardware supporting both LLM inference and continual learning remains underexplored; 2D chiplet designs incur thermal and energy inefficiencies when integrating diverse memory technologies (RRAM, eDRAM) for accelerated inference.

## Motivation
Edge LLM inference demands heterogeneous compute-in-memory architectures with superior energy efficiency, requiring 2.5D/3D thermal-aware chiplet designs to combine multiple memory technologies and manage power density.

## Method
3D-CIMlet uses memory-reliability-aware chiplet mapping strategies across 2.5D/3D heterogeneous CIM chiplet architectures combining RRAM, capacitor-less eDRAM, and hybrid chiplets in mixed technology nodes, with thermal modeling to optimize placement for edge LLM tasks.

## Key Novelty
Thermal-aware co-design framework for 2.5D/3D heterogeneous CIM chiplet systems supporting both inference and continual learning.

## Contributions
- First thermal-aware modeling and co-design framework for edge-LLM CIM chiplet systems
- Memory-reliability-aware chiplet mapping strategies for mixed-technology nodes
- Up to 9.3x and 12x energy efficiency improvement in 2.5D and 3D vs 2D baselines
- 90.2% and 92.5% energy-delay product reduction for edge LLM continual learning

## Metrics
- Energy efficiency: 9.3x and 12x improvement in 2.5D/3D vs 2D
- EDP: 90.2% and 92.5% reduction

## Baselines
- 2D chiplet designs, Homogeneous memory architectures

## Limitations
Focus on modeling and simulation without silicon results.
