# MAS-ISP: Proxy-Free Online Hyperparameter Optimization for ISP Hardware

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Real-time ISP adaptation for autonomous driving requires responding to dynamic environmental changes; offline/proxy-based tuning is too slow.

## Key Insight
Distributed DRL-based multi-agent system can optimize ISP hyperparameters in real-time without proxy models; hardware innovations reduce CNN footprint for real-time deployment.

## Method
Master-slave MAS using DRL for online ISP hyperparameter optimization; hardware accelerations: Strip Convolution Kernel, Stride-Aware Dual-Buffer Memory reduce CNN resource use.

## Contributions
- Proxy-free online DRL-based ISP tuning
- Multi-agent cooperative parameter optimization
- Hardware innovations for CNN acceleration
- 1080P@75FPS (FPGA), 1080P@240FPS (ASIC)

## Hardware Target
FPGA, ASIC, CPU

## Workloads
CNN, Vision (Autonomous Driving)

## Theme
Real-time adaptive ISP via distributed DRL for autonomous vision systems.
