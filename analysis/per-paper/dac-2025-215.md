# MAS-ISP: Proxy-Free Online Hyperparameter Optimization for ISP Hardware

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Real-time ISP adaptation for autonomous driving requires responding to dynamic environmental changes; offline/proxy-based tuning is too slow.

## Key Insight
Distributed DRL-based multi-agent system can optimize ISP hyperparameters in real-time without proxy models; hardware innovations reduce CNN footprint for real-time deployment.

## Method
The system uses multiple AI agents trained with reinforcement learning—learning which settings produce good results by trying configurations and receiving reward signals—to adjust Image Signal Processor (ISP) parameters in real-time, without needing a proxy model as an intermediary. A master agent coordinates the others to ensure consistent adjustments across consecutive video frames. Two hardware optimizations, Strip Convolution Kernel and Stride-Aware Dual-Buffer Memory, reduce the neural network computation required for image processing, enabling real-time operation on FPGA or ASIC hardware.

## Contributions
- Proxy-free online DRL-based ISP tuning
- Multi-agent cooperative parameter optimization
- Hardware innovations for CNN acceleration
- 1080P@75FPS (FPGA), 1080P@240FPS (ASIC)
