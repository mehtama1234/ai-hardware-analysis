# hpca-2025-030: NOVA: A Novel Vertex Management Architecture for Scalable Graph Processing

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing graph accelerators require temporal partitioning of large graphs to fit on-chip memory, limiting scalability and causing repeated DRAM sweeps that degrade performance.

## Motivation
Real-world graphs with hundreds of millions of vertices exceed on-chip SRAM capacity; temporal partitioning imposes multiple DRAM passes and limits scaling to large graphs.

## Method
NOVA separates two core operations in graph processing—reduction (combining results from neighbors) and propagation (sending computed values forward)—which allows the entire graph data to stay in off-chip DRAM instead of being split to fit in fast on-chip memory. Rather than storing graph state, the on-chip memory becomes a prefetch buffer that loads data early to mask DRAM access delays. Multiple NOVA chips can be connected to process larger graphs, achieving nearly linear performance scaling as you add more chips. Cycle-accurate simulation with gem5 (architectural modeling software) confirms the design.

## Key Novelty
Separating reduction and propagation operations eliminates the need to partition graph data, enabling it to stay entirely in DRAM with on-chip memory serving only as a prefetch buffer to hide access delays.

## Contributions
- NOVA architecture decoupling reduction and propagation, eliminating temporal partitioning.
- On-chip memory repurposed as DRAM-latency buffer, not graph-state cache.
- Near-perfect weak and strong scaling via spatial multi-node tiling.
- 2.35x over PolyGraph on 134M-vertex / 2.14B-edge graph with a fraction of PolyGraph's on-chip memory.

## Metrics
- speedup: 2.35x over PolyGraph on 134M-vertex 2.14B-edge synthetic graph
