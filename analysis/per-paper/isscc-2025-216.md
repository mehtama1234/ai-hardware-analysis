# isscc-2025-216: Scalable Continuous-Time Sensor Interface

## Quick Summary
A sub-1V, 14-bit sensor interface with frequency-controlled current source achieving 225× power-bandwidth scalability (5.8nW/Hz), enabling adaptive sensor digitization for diverse IoT applications.

## Problem
IoT sensor interfaces must digitize weak signals (tens of mV) from shunt current and biomedical sensors with:
- Low noise (suppress kT/C thermal noise)
- Scalable bandwidth and power for different use cases
- Fixed-power continuous-time front-ends waste power in low-BW scenarios

## Method
The circuit reads analog signals continuously without sampling (avoiding kT/C thermal noise, which is measurement error from discrete sampling), using a frequency-controlled current source whose power and operating speed vary with frequency. Tuning this frequency lets applications choose any point across a 225× range of bandwidth-to-power trade-offs, from power-efficient low-bandwidth operation to fast high-bandwidth modes.

## Key Novelty
A frequency-controlled current source enables continuous-time (non-sampling) sensor interfaces to scale their bandwidth and power consumption together across a 225× range.

## Contributions
- Sub-1V 14-bit interface
- 5.8nW/Hz power efficiency
- 225× scalable range
- kT/C noise suppression
- Bandwidth-power adaptation
