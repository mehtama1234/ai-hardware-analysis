# Simulation-based Parallel Sweeping: A New Perspective on Combinational Equivalence Checking

**Venue:** DAC
**ID:** dac-2025-229

## Problem
Combinational equivalence checking (CEC) is co-NP-complete; SAT-based approaches dominate but timeout on large designs. GPU acceleration for simulation-based checking unexplored.

## Motivation
CEC is critical for verifying design transformations in industrial flows; speedup from modern GPUs can complement SAT approaches for hard instances.

## Method
Exhaustive simulation-based CEC engine using GPU parallelism: distributes simulation across GPU cores to rapidly explore test patterns, achieving 88x speedup vs CPU SAT solver on specific large cases; hybrid with ABC when simulation alone insufficient.

## Key Novelty
Simulation-based CEC perspective using GPU parallelism instead of SAT-based methods.

## Contributions

- GPU-parallel simulation engine for combinational equivalence checking
- 88.11x speedup on large cases over ABC SAT solver
- Hybrid approach combining simulation + SAT for comprehensive coverage
- 4.89x and 4.88x average acceleration over standalone ABC and commercial tools
