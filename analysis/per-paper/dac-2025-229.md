# Simulation-based Parallel Sweeping: A New Perspective on Combinational Equivalence Checking

**Venue:** DAC
**ID:** dac-2025-229

## Problem
Combinational equivalence checking (CEC) is co-NP-complete; SAT-based approaches dominate but timeout on large designs. GPU acceleration for simulation-based checking unexplored.

## Motivation
CEC is critical for verifying design transformations in industrial flows; speedup from modern GPUs can complement SAT approaches for hard instances.

## Method
The method runs many different test patterns simultaneously across a GPU's thousands of cores to check whether two hardware designs always produce identical outputs. Each core runs a different test pattern in parallel, which is much faster than checking patterns one at a time on a CPU. When parallel simulation cannot definitively prove the designs are equivalent, it switches to a SAT-based solver (ABC) to complete the verification. On certain large designs, this GPU-based approach achieves 88x faster results than traditional CPU-based SAT solving.

## Key Novelty
Using parallel GPU simulation instead of SAT-based methods to check if two hardware designs produce equivalent outputs.

## Contributions

- GPU-parallel simulation engine for combinational equivalence checking
- 88.11x speedup on large cases over ABC SAT solver
- Hybrid approach combining simulation + SAT for comprehensive coverage
- 4.89x and 4.88x average acceleration over standalone ABC and commercial tools
