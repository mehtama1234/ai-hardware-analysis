# sc-2025-030: Development of a performance portable distributed FFT interface on top of the Kokkos ecosystem

## Summary
This paper presents a performance-portable distributed FFT implementation built on top of the Kokkos programming ecosystem. The work addresses the challenge of implementing efficient FFT operations across heterogeneous HPC architectures while maintaining code portability.

## Problem
- FFT is fundamental but implementation complexity scales with hardware diversity
- Existing approaches often lock implementations to specific hardware or require extensive manual optimization
- Need for unified abstraction that works across CPU and GPU platforms

## Method
- Leveraged existing Kokkos and kokkos-fft libraries as foundation
- Developed new distributed FFT layer with vendor library bindings
- Implemented batched-distributed FFT capability

## Key Innovations
1. **Batched-distributed FFT**: Novel capability for efficiently processing multiple FFT operations in parallel
2. **Vendor library integration**: Unified interface to vendor-optimized implementations (cuFFT, rocFFT)
3. **Performance portability**: Single codebase achieves good performance on NVIDIA A100, AMD MI250X, and CPUs

## Hardware Targets
- NVIDIA A100 GPUs
- AMD MI250X GPUs  
- CPUs (Intel/AMD multicore)

## Results (from abstract)
- Efficient performance on A100 and MI250X
- Reasonable CPU performance maintained
- Simplified implementation compared to manual distributed FFT coding
