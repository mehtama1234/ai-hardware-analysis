# Optimizing Bandwidth Utilization Through Word Based Compression in Main Memories

**Venue:** VLSID
**Authors:** N. S. Aswathy, Harsh Verma, Hemangee K. Kapoor

## Problem Statement
Memory compression maximizes memory capacity, lowers bandwidth requirements, and reduces energy consumption

## Key Innovation
Novel propose approach

## Method
Cond-FWC compresses memory blocks by analyzing cache lines—the fixed-size chunks of data moved between main memory and CPU—to identify which multi-byte words (values) appear most frequently. It eliminates these redundant words by storing them only once and replacing each occurrence with a short reference, shrinking the data size. This compression reduces the bandwidth required to transfer data between main memory and processor, lowering energy consumption.
