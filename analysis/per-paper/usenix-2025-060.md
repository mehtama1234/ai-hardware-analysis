# Primus: Unified Training System for Large-Scale Deep Learning Recommendation Models

**Problem:** Training large-scale deep learning recommendation models requires handling diverse model architectures, massive datasets, and heterogeneous data dependencies that existing training systems do not support in a unified manner.

**Method:** Primus provides a unified training framework that abstracts over recommendation model heterogeneity through standardized data loading and execution pipelines. It employs optimized scheduling and distributed parallelism strategies tailored to recommendation model memory access and computation patterns, integrating model-agnostic optimization across diverse recommendation architectures.

**Novelty:** A unified training system architecture that standardizes the training pipeline across diverse recommendation model types at production scale.
