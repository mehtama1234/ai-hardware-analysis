# Primus: Unified Training System for Large-Scale Deep Learning Recommendation Models

**Problem:** Training large-scale deep learning recommendation models requires handling diverse model architectures, massive datasets, and heterogeneous data dependencies that existing training systems do not support in a unified manner.

**Method:** Primus is a training system that works with different types of recommendation models (systems that predict what users will like) without requiring separate custom training code for each. It uses standardized processes for loading data and running training, automatically optimizing how work gets scheduled and distributed across computers and GPUs based on how recommendation models use memory and computation. This allows one unified system to efficiently train diverse recommendation models at production scale.

**Novelty:** Primus provides a unified training system that standardizes training across different recommendation models at production scale.
