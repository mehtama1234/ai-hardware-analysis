# isscc-2025-217: SKADI — Complete K-SAT Solver ASIC

## Quick Summary
SKADI is the first complete K-SAT solver ASIC in 28nm, proving both satisfiability and unsatisfiability with bidirectional deduction via dual-path SRAM-based macros and efficient incremental state management.

## Problem
Prior K-SAT ASIC solvers are incomplete (SAT-only):
- Cannot prove unsatisfiability (UNSAT), limiting practical use
- Analog approaches suffer accuracy loss
- Digital methods have poor area and energy efficiency
- Real-world problems require proof of unsatisfiability when no solution exists

## Method
This K-SAT solver is built as a specialized 28nm chip that uses fast memory blocks (SRAM) in two simultaneous paths: one deduces variable values from problem clauses, while the other deduces new clauses from known variables. Rather than recomputing everything when the problem changes, the chip tracks variable assignments incrementally and maintains clauses at multiple levels of detail, ensuring it can correctly handle both satisfiable and unsatisfiable problems without the accuracy loss of analog methods.

## Key Novelty
It's the first K-SAT solver chip that can prove problems unsolvable, using fast memory to simultaneously track both clause-to-variable and variable-to-clause deductions.

## Contributions
- Complete K-SAT solving (SAT + UNSAT proof)
- Dual-path SRAM macro for bidirectional deduction
- Incremental assignment tracking
- Multi-level clause states
- 100% correctness guarantee
