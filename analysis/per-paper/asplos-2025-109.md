# asplos-2025-109: vAttention: Dynamic Memory Management for Serving LLMs without PagedAttention

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** OS-based contiguous virtual memory for LLM KV cache management

## Problem
PagedAttention enables dynamic KV cache allocation during LLM inference by breaking virtual memory contiguity, but this non-contiguous virtual memory layout for KV caches introduces non-trivial programming complexity and performance overheads in attention kernels and memory management logic. The changes to virtual memory layout require rewriting attention kernels and force suboptimal memory access patterns.

## Motivation
LLM serving throughput is critically dependent on maximizing batch size via dynamic KV cache memory allocation, and PagedAttention's current approach imposes unnecessary software complexity and kernel performance penalties that limit throughput.

## Method
vAttention uses operating system memory management primitives—specifically demand paging (where memory is only loaded when actually accessed) and virtual address reservation—to give key-value caches continuous virtual memory addresses while allocating actual physical memory on demand. Unlike PagedAttention, which manually manages fragmented memory locations, vAttention reserves large contiguous virtual address ranges upfront and lets the operating system provide the underlying physical memory as needed. This approach preserves the contiguous virtual memory layout that standard GPU (CUDA) attention kernels expect, so they can run unchanged. It also prevents physical memory fragmentation that would otherwise degrade performance.

## Key Novelty
vAttention achieves dynamic key-value cache allocation with contiguous virtual addresses by using operating system demand paging, eliminating custom non-contiguous memory management.

## Contributions
- Analysis of the programming and performance overheads introduced by PagedAttention's non-contiguous virtual memory layout.
- vAttention design using OS virtual memory reservation and demand paging for dynamic KV cache allocation without breaking virtual memory contiguity.
- Compatibility with unmodified high-performance attention kernels (FlashAttention, etc.) since the KV cache virtual address space remains contiguous.
- Throughput improvements in LLM serving compared to PagedAttention-based systems.
