# Harmonia: A Unified Framework for Heterogeneous FPGA Acceleration in the Cloud

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
The cloud FPGA shell-role architecture does not handle heterogeneous FPGA configurations: each FPGA variant requires laborious provider shell development or ad-hoc user software modifications, with no portable abstraction.

## Motivation
Cloud FPGA heterogeneity is growing as providers deploy diverse FPGA families, but the shell-role split was designed for homogeneous deployments and cannot scale.

## Method
Harmonia introduces a standard interface (called a shell interface specification) that all FPGA types must follow, letting user accelerators be written once and work across different FPGA types without code changes. The framework defines platform-specific logic (the shell) according to this standard for each FPGA type on the hardware side. A software layer on top handles the differences between FPGA types automatically, so applications don't need custom code for each one.

## Key Novelty
A standardized interface specification and software abstraction layer that separate user accelerator code from FPGA-specific logic, allowing accelerators to be written once and deployed across different FPGA types.

## Contributions
- Standardized hardware shell interface for cross-FPGA role portability
- Software abstraction layer hiding FPGA-specific differences
- Harmonia framework reducing both provider and user heterogeneity burden
