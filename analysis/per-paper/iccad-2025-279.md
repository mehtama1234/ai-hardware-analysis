# Equivalent Lumped Element Model for Electromigration Considering Thermal Effects

**Venue:** ICCAD  
**ID:** iccad-2025-279

## Problem
Traditional physics-based electromigration (EM) analysis using partial differential equations (PDEs) is computationally intensive, particularly in multi-physics scenarios with thermal coupling.

## Motivation
To forecast EM-induced stress under coupled electro-thermomechanical effects with significant computational speedup by leveraging lumped element equivalent circuits.

## Method
Self-consistent lumped element modeling framework leveraging equivalence between electrical behavior and stress evolution; embedded controlled sources model thermomechanical interactions driven by temperature gradients; threshold-activated switching dynamically reconfigures circuit topology for void nucleation and post-voiding phases; adaptive non-uniform spatial discretization enhances computational efficiency. Fully compatible with standard SPICE solvers.

## Key Novelty
Lumped element equivalent circuit approach for EM modeling with explicit electro-thermomechanical coupling, enabling SPICE simulation.

## Contributions
- Self-consistent lumped element modeling framework for EM analysis
- Embedded controlled sources for thermomechanical interaction modeling
- Threshold-activated switching for void nucleation and post-voiding transitions
- 50× speedup vs FEM for small interconnects, 3.11× over conventional equivalent circuits
