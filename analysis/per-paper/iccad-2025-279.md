# Equivalent Lumped Element Model for Electromigration Considering Thermal Effects

**Venue:** ICCAD  
**ID:** iccad-2025-279

## Problem
Traditional physics-based electromigration (EM) analysis using partial differential equations (PDEs) is computationally intensive, particularly in multi-physics scenarios with thermal coupling.

## Motivation
To forecast EM-induced stress under coupled electro-thermomechanical effects with significant computational speedup by leveraging lumped element equivalent circuits.

## Method
The approach replaces computationally expensive differential equations with a simplified electrical circuit made of basic elements (resistors, capacitors, controlled sources—devices that adjust voltage or current based on conditions) that represent electromigration physics. It exploits the fact that electrical current flow and mechanical stress evolution (how atoms move under heat and current) follow equivalent patterns, so a single circuit model captures both simultaneously. Temperature effects are built in through controlled sources that respond to heat distribution. During simulation in standard SPICE tools, the circuit automatically reconfigures between void nucleation (void formation onset) and post-void phases, using adaptive mesh refinement (a grid that's finer where needed) to keep computation fast.

## Key Novelty
The core idea is an electrical circuit model for electromigration where electrical, mechanical, and thermal effects are all explicitly linked (electro-thermomechanical coupling), enabling direct simulation in standard SPICE tools instead of solving expensive differential equations.

## Contributions
- Self-consistent lumped element modeling framework for EM analysis
- Embedded controlled sources for thermomechanical interaction modeling
- Threshold-activated switching for void nucleation and post-voiding transitions
- 50× speedup vs FEM for small interconnects, 3.11× over conventional equivalent circuits
