# Achieving Simultaneous Buffering and Steiner Tree Synthesis via Harmonic Based Reinforcement Learning

**Venue:** ICCAD  
**ID:** iccad-2025-020

## Problem
Buffer insertion and Steiner tree construction are traditionally separate tasks, but they are interdependent; joint optimization is computationally complex.

## Motivation
Simultaneous optimization of tree topology and buffer placement can yield superior circuit delay characteristics.

## Method
This approach uses reinforcement learning (a machine learning method where a system learns by trying different actions and receiving feedback) to simultaneously solve two tasks that are usually done separately: constructing Steiner trees (minimum-wire networks connecting multiple circuit points) and inserting buffers (devices that regenerate electrical signals). Rather than first routing connections and then adding buffers, the system learns which combinations of routing and buffer placement decisions work best together by trying many possibilities and improving based on feedback. Harmonic functions (mathematical functions representing optimal balanced solutions) guide the learning process.

## Key Novelty
The core innovation is combining reinforcement learning with harmonic functions to jointly optimize Steiner tree construction and buffer insertion, rather than solving them as separate sequential tasks.

## Contributions
- Novel reinforcement learning framework for joint tree and buffer optimization
- Harmonic function formulation for optimization objective
- Experimental validation of efficiency and effectiveness
- Solution to interdependence problem between topology and buffer placement
