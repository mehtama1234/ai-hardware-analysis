# An Efficient FPGA-Based Hardware Accelerator of Fully Quantized Mamba-2

**Problem:** Mamba-2 inference exhibits element-wise operations that underutilize GPU tensor cores, reducing efficiency. Research on full-quantization strategies for Mamba-2 is lacking.

**Method:** The team built Hfqmamba2 using a reconfigurable FPGA (a chip you can reprogram for specific tasks) instead of a GPU. They employ hybrid-precision quantization, reducing some numbers to fewer bits more aggressively than others to save space and computation. To avoid expensive calculations, they included a segmented lookup table that approximates RMSNorm's inverse square root operation—a normalization step—without computing it fully each time. The design pipelines SSM operations (Mamba-2's state-machine calculations) so different layers run in parallel, all validated on an Alveo U50 FPGA board.

**Novelty:** The core idea is combining a reconfigurable FPGA with lookup-table approximations and selective-precision quantization to efficiently run Mamba-2 where GPUs with tensor cores struggle on element-wise operations.
