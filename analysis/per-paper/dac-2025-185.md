# Routability-Driven Global Placement via Differentiable Congestion and Momentum Inflation

**Venue:** DAC | **ID:** dac-2025-185

## Summary
Advances routability-driven placement via momentum-based cell inflation for local congestion and a differentiable Poisson-derived global congestion function with virtual cell guidance for net movements. Also optimizes pin accessibility via power/ground rail density adjustment.

## Key Results
- **DRV Reduction:** 40% average on ISPD 2015 benchmarks
- **Baseline Comparison:** Comparable wirelength and via count to leading routability-driven placers
- **Technique:** Momentum inflation + Poisson congestion function + density adjustment

## Technique
Momentum-based cell inflation tracks historical ratios; differentiable Poisson-derived congestion function guides net placement; virtual standard cells on two-pin nets abstract congestion; placement density adjusted around power/ground rails per routing congestion.
