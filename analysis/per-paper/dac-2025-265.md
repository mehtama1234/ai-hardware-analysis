# PICK: SRAM-based PIM Accelerator for K-Nearest-Neighbor Search

**Venue:** DAC | **ID:** dac-2025-265

## Problem
kNN search on point clouds is computationally and memory-intensive; off-chip memory access dominates latency and energy in resource-constrained scenarios.

## Key Innovation
Bit-serial PIM (processing-in-memory) architecture with filtering-and-selection strategy achieving approximate constant-time k-selection within on-chip SRAM, eliminating off-chip memory bottleneck.

## Method
PICK puts the k-nearest neighbor search inside SRAM memory itself (processing-in-memory), eliminating trips to slow off-chip storage. It processes distances bit-by-bit to reduce latency, filters out distant points early, and selects the k closest neighbors in constant time regardless of k's value. Two pipelined stages run in parallel—distance calculation and top-k selection—completing the entire search while staying on-chip.

## Results
- **Speedup:** 4.17x vs. state-of-the-art
- **Energy:** 4.42x savings
- **On-chip SRAM:** Eliminates off-chip access
