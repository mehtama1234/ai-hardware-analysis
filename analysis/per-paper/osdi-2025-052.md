# Compass: Encrypted Semantic Search with High Accuracy

**Problem:** Semantic search systems cannot efficiently support similarity queries over encrypted embeddings because standard encryption schemes do not allow direct comparison operations on encrypted data. Existing approaches face a tradeoff between encryption overhead, query latency, and search accuracy degradation.

**Method:** Compass enables encrypted semantic search by using special encryption that allows mathematical operations on encrypted data (homomorphic or functional encryption) combined with approximate nearest-neighbor search—a technique that quickly finds similar vectors without checking all of them. To reduce computational cost, the system compresses vector precision (quantization) and reduces the number of dimensions while maintaining accurate results. Query processing then uses secure comparison protocols to find which encrypted vectors are most similar to the query without decrypting anything.

**Novelty:** Compass achieves high-accuracy encrypted semantic search by optimizing approximate nearest-neighbor search and vector quantization specifically for encrypted operations.
