# Compass: Encrypted Semantic Search with High Accuracy

**Problem:** Semantic search systems cannot efficiently support similarity queries over encrypted embeddings because standard encryption schemes do not allow direct comparison operations on encrypted data. Existing approaches face a tradeoff between encryption overhead, query latency, and search accuracy degradation.

**Method:** Compass combines homomorphic or functional encryption schemes with approximate nearest neighbor search to enable encrypted similarity queries on embedding vectors. The system uses selective quantization and dimensionality reduction to reduce the computational cost of encrypted operations while preserving search accuracy. Query execution leverages secure comparison protocols that maintain semantic similarity relationships without full decryption.

**Novelty:** An encrypted semantic search scheme that achieves high accuracy through encryption-aware approximate search techniques and optimized vector quantization that minimizes the accuracy-privacy-performance tradeoff.
