# isca-2025-033 — Topology-Aware Virtualization over Inter-Core Connected Neural Processing Units

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Inter-core connected NPUs (Graphcore IPU, Tenstorrent) require large hardware resources, leading to poor utilization under imbalanced task mixes. Existing MIG-style monolithic virtualization ignores inter-core NoC topology, delivering suboptimal performance when multiple workloads share the device.

## Motivation
Cloud and edge deployments increasingly rely on inter-core connected NPUs, but imbalanced resource utilization wastes expensive silicon and limits multi-tenancy throughput.

## Method
vNPU virtualizes inter-core connected NPUs using three integrated techniques: (1) routing virtualization redirects instructions and data from virtual core IDs to physical cores across the chip's communication highways (NoC); (2) memory virtualization translates addresses intelligently, accounting for where data lives in each core's fast memory (SRAM) and across the network, to reduce stalls and maintain memory bandwidth; (3) topology mapping tests different virtual-to-physical core mappings and selects the one that best balances hardware utilization against program performance. The design was tested on an FPGA (Chipyard+FireSim) and an NPU simulator (DCRA).

## Key Novelty
vNPU is the first virtualization design for inter-core connected neural processing units (NPUs) that handles routing, memory translation, and topology mapping together to preserve how cores communicate within each virtual partition.

## Contributions
1. NPU route virtualization redirecting data/instruction flow from virtual to physical cores.
2. NoC-aware SRAM memory virtualization minimizing translation stalls.
3. Best-effort topology mapping algorithm selecting optimal virtual-to-physical core assignments.
4. Up to 1.92x speedup (Transformer) and 1.28x (ResNet) vs MIG-based baseline.
