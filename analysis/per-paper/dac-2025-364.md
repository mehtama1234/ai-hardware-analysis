# ACIM-QMM: Efficient Analog Computing-in-Memory Accelerator for QC-MDPC McEliece Cryptosystem

## Summary
Analog CIM accelerator for post-quantum cryptography (McEliece), leveraging analog computation to accelerate matrix operations required for PQC.

## Key Results
- **31.4x to 288.1x speedup** vs SOTA QMM hardware
- **3.12x area efficiency** vs other PQC accelerators
- **20.32x energy efficiency** vs other PQC hardware

## Core Innovation
First analog CIM approach to PQC, using analog circuits instead of digital computing paradigm to perform McEliece key generation and encryption.

## Technique
Analog CIM design with low-error computation for matrix operations; replaces digital MAC operations with analog in-memory computation for cryptographic primitives.
