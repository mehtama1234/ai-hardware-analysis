# isca-2025-063 — Reinforcement Learning-Guided Graph State Generation in Photonic Quantum Computers

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
In photonic quantum computers (PQCs), finding optimal generation sequences for graph states requires jointly minimizing generation time, emitter count, and CZ gate count, but existing frameworks either face exponential search complexity or produce non-optimal results due to non-deterministic properties.

## Motivation
Graph state generation quality directly determines photonic quantum computation fidelity; suboptimal generation sequences waste scarce quantum emitter resources and increase CZ gate count, both of which degrade output fidelity in near-term PQC hardware.

## Method
RLGS (Reinforcement Learning-guided Graph State generation) uses a map-based circuit abstraction that extracts and aligns two-qubit gate dependencies into a structured representation, enabling an RL agent to search over generation sequences that jointly optimize all three fidelity metrics. The framework balances gate serialization depth against crosstalk reduction.

## Key Novelty
RLGS uses a map-based circuit abstraction that converts generation sequence search from exponential dependency graph traversal into an RL-navigable state space, achieving joint optimization of all three fidelity metrics simultaneously.

## Contributions
1. A map-based framework abstracting quantum circuit dependencies for efficient qubit reuse optimization.
2. An RL-guided search strategy jointly minimizing generation time, emitter count, and CZ gate count.
3. Generation time reductions of 31.1%, 49.6%, 57.5% for small/medium/large graph states vs. state-of-the-art.
4. Emitter count reductions of 13.9-17.5%; CZ gate reductions of 37.7-57.8%.
