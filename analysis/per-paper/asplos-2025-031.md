# AnA: An Attentive Autonomous Driving System

**ID:** asplos-2025-031  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Query-driven attentive perception scheduling for autonomous driving

## Problem
Current autonomous driving perception modules execute unconditionally and uniformly regardless of driving context, wasting compute on irrelevant scenes and missing safety-critical events that require focused attention—a mismatch from how humans selectively allocate perception resources.

## Motivation
Compute resources on autonomous vehicles are limited and latency-sensitive; a system that directs perception effort toward driving-relevant objects and events can reduce unnecessary computation while improving safety response time.

## Method
AnA refactors the ADS perception-planning interface with three mechanisms: (1) a query interface that lets the planning module express interest in specific perceptual targets using driving knowledge; (2) a query executor that maps these queries to an optimal subset of active perception tasks; and (3) a monitor that uses driving knowledge to detect and handle anomalous task executions. The system distinguishes between ambient awareness (broad, low-cost perception) and focused attention (targeted, high-fidelity perception on safety-critical elements), dynamically switching modes based on planner queries.

## Key Novelty
A query-driven perception architecture that couples planning knowledge to selective activation of perception tasks, enabling human-like attentive driving that reduces compute by 44% while halving collisions on adversarial benchmarks.

## Contributions
- Query interface enabling the planning module to direct perception with driving-context knowledge.
- Query executor that selects the optimal perception task subset given planner queries.
- Anomaly monitor integrating driving knowledge to handle unexpected perception outcomes.
- Empirical demonstration of 2x collision reduction and 44% compute savings on challenging ADS benchmarks.
