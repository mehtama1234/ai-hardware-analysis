# Network Replay and Consistency Across Testbeds

**Venue:** SC
**ID:** sc-2025-396
**Confidence:** low

## Problem
Shared network testbeds introduce variability (jitter, loss) that degrades experiment fidelity and reproducibility; difficult to quantify testbed quality.

## Motivation
Precise network behavior reproduction is essential for reliable systems research; current testbeds lack tools to measure and compare consistency.

## Method
Choir: 100 Gbps network replay tool running on commodity hardware with novel consistency metric for cross-testbed comparison.

## Key Novelty
First 100 Gbps replay tool for shared infrastructures; quantitative consistency metric enables testbed quality assessment.

## Contributions
1. 100 Gbps network replay engine for commodity hardware
2. Novel consistency metric for testbed comparison
3. Empirical demonstration that shared testbeds (e.g., FABRIC) have significantly higher variability than local bare-metal systems
