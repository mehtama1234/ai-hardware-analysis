# Perturbation-efficient Zeroth-order Optimization for Hardware-friendly On-device Training

**Venue:** ICCAD  
**ID:** iccad-2025-195

## Problem
Zeroth-order optimization for neural network training generates excessive random numbers, making it infeasible for FPGAs and ASICs. Memory and resource constraints prevent efficient hardware implementation.

## Motivation


## Method
PeZO trains neural networks on resource-limited hardware (FPGAs and ASICs) by reusing the same random numbers across multiple training steps rather than generating new ones each time. It also switches from Gaussian-distributed (bell-curve shaped) random numbers to uniform-distributed (evenly spread) ones, which hardware can generate more efficiently. Finally, it uses adaptive scaling that adjusts automatically to each layer, further reducing the total memory and computation demands.

## Key Novelty
This is the first approach to train neural networks on resource-limited hardware using zeroth-order optimization combined with efficient random perturbation generation.

## Contributions
- Identifies hardware-algorithm mismatch in random number generation for ZO optimization
- Proposes perturbation-efficient ZO framework (PeZO)
- Achieves 48.6% LUT and 12.7% FF reduction with up to 86% power savings
