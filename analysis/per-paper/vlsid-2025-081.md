# MAGIC-Based High-Speed Adders for in-Memory Computing Using Memristors

**VLSID 2025** | vlsid-2025-081

## Abstract
Memristor-based in-memory computing using MAGIC logic requires efficient arithmetic. This work proposes optimized RCA designs using serial and semi-serial full adders, both 2x faster than existing MAGIC RCA designs. 32-bit RCA: serial variant (199 steps), semi-serial variant (232 steps). Designs efficiently use memristor crossbar; validated via VTEAM model simulation.

## Problem
- In-memory computing with memristors via MAGIC logic needs fast arithmetic
- Existing MAGIC-based RCA designs have high computational step counts
- Scaling to larger adders requires better optimization strategies

## Key Insight
Exploit parallel processing capabilities across memristor crossbar rows and columns to reduce adder latency; balance between serial and parallel stages optimizes step count.

## Approach
1. Semi-serial full adder design in MAGIC logic
2. Two RCA design variants optimizing different parallelism strategies
3. Exploit row/column parallelism in crossbar array
4. Efficient memristor assignment along crossbar

## Implementations

### 32-Bit RCA Variants
| Design | Full Adder Type | Steps | Improvement |
|--------|-----------------|-------|-------------|
| Serial | Serial FA | 199 | 2x vs. previous |
| Semi-Serial | Semi-serial FA | 232 | 2x vs. previous |

### Full Adder
- **Type**: Semi-serial MAGIC
- **Latency**: 10 computational steps
- **Crossbar**: 3×7 array
