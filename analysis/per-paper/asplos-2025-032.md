# Treelet Accelerated Ray Tracing on GPUs

**ID:** asplos-2025-032  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Treelet-based BVH traversal with ray virtualization for GPU ray tracing

## Problem
GPU ray tracing suffers from poor memory access locality because rays traverse a BVH tree in divergent order, causing excessive DRAM traffic; while treelet-based traversal (grouping BVH subtrees and batching rays per treelet) reduces memory traffic on specialized accelerators, applying it to GPUs is non-trivial and naive implementations are ineffective.

## Motivation
Real-time ray tracing in games and rendering engines is limited by frame-rate penalties from memory bandwidth bottlenecks during BVH traversal, causing users to disable it; GPU-native treelet traversal could close this gap without specialized hardware.

## Method
The solution uses three techniques. First, ray virtualization: after the ray-generation shaders send rays to hardware, they stop and free GPU processor cores (CUDA cores), allowing those cores to generate more rays while hardware traces earlier batches—this multiplies concurrent rays and enables cache reuse within treelet subtrees. Second, a dynamic queue switches between traversal modes (within-treelet vs. across-treelet) at runtime depending on efficiency. Third, warp repacking reorganizes work groups in the ray-tracing hardware unit to optimize parallel execution.

## Key Novelty
Ray virtualization frees GPU processor cores by stopping ray-generation shaders after dispatch, multiplying concurrent rays and enabling cache reuse within treelets, paired with a dynamic queue switching traversal strategies at runtime—achieving 95% average speedup.

## Contributions
- Ray virtualization mechanism that terminates post-trace raygen shaders to increase concurrent in-flight rays and cache reuse.
- Dynamic treelet queue architecture that switches traversal modes to balance intra- and inter-treelet work.
- Warp repacking technique for improving SIMT efficiency in the GPU's hardware RT unit during treelet traversal.
- Average 95% speedup over baseline GPU RT across all scenes in LumiBench with path tracing.
