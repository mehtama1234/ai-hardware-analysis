# Network and Compiler Optimizations for Efficient Linear Algebra Kernels in Private Transformer Inference (Invited Paper)

**Venue:** ICCAD | **ID:** iccad-2025-052

## Problem
Fully Homomorphic Encryption-based private transformer inference is extremely slow. Mapping standard kernels to constrained FHE instruction set is difficult. Memory-bound FHE operations with ~0.1 ops/byte limit scalability.

## Motivation
Enable private inference without compromising latency through algorithm and compiler optimizations.

## Method
Explores linear algebra kernels for FHE transformer inference: benchmarks two methods (packed row vs BSGS), finds BSGS 13.7x faster at scale; applies network-level pruning reducing feed-forward layers 11.46x; extends Orion to support ciphertext-ciphertext GEMM; performs roofline analysis revealing memory-bound bottleneck.

## Key Novelty
Compiler and network-level optimizations for FHE-based transformer inference with roofline characterization.

## Contributions
- BSGS outperforms packed row method by 13.7x for transformer-scale linear transformations
- Network pruning strategies reducing FHE runtimes by 11.46x
- Ciphertext-ciphertext matrix-matrix products and roofline analysis of FHE primitives
