# Network and Compiler Optimizations for Efficient Linear Algebra Kernels in Private Transformer Inference (Invited Paper)

**Venue:** ICCAD | **ID:** iccad-2025-052

## Problem
Fully Homomorphic Encryption-based private transformer inference is extremely slow. Mapping standard kernels to constrained FHE instruction set is difficult. Memory-bound FHE operations with ~0.1 ops/byte limit scalability.

## Motivation
Enable private inference without compromising latency through algorithm and compiler optimizations.

## Method
The team tested different techniques for speeding up matrix math on encrypted data. They compared a basic packed-row method against BSGS (Baby-step Giant-step, a technique that breaks large calculations into smaller, faster chunks), finding BSGS 13.7x faster at scale. They also pruned the network's feed-forward layers down to 11.46x smaller and upgraded the Orion compiler to multiply encrypted matrices directly. Using roofline analysis—a method that measures whether computation or memory access limits performance—they discovered that moving data in and out of memory is the bottleneck, not the speed of arithmetic itself.

## Key Novelty
Optimizing encrypted transformers requires improving both the compiler and the network design, with performance analysis revealing that memory movement—not computation—is the limiting factor.

## Contributions
- BSGS outperforms packed row method by 13.7x for transformer-scale linear transformations
- Network pruning strategies reducing FHE runtimes by 11.46x
- Ciphertext-ciphertext matrix-matrix products and roofline analysis of FHE primitives
