# CGSim: A Simulation Framework for Large Scale Distributed Computing Environment

**ID**: sc-2025-370
**Venue**: SC
**Confidence**: low

## Problem
Limited simulation capabilities for large-scale distributed computing environments

## Motivation
Existing simulators don't scale or support modern ML approaches

## Method
The framework is built on SimGrid, a simulation tool that models how distributed computer systems work. It adds plugin mechanisms—extensible components researchers can customize—to configure simulations of large-scale distributed computing environments. This lets researchers test ideas about these systems without needing access to actual large-scale infrastructure.

## Key Novelty
It is the first simulation framework capable of operating at WLCG scale while automatically generating datasets using machine learning.
