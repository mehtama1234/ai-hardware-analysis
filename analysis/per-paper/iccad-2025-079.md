# MiCo: End-to-End Mixed Precision Neural Network Co-Exploration Framework for Edge AI

**Venue:** ICCAD  
**ID:** iccad-2025-079

## Problem
Layer-wise mixed-precision quantization (MPQ) exploration is limited by inflexible algorithms and lack of end-to-end deployment frameworks. Understanding complex impacts of different MPQ schemes on post-training and quantization-aware training is challenging with existing methods.

## Motivation
Enabling efficient neural network deployment on edge devices requires balancing model accuracy and latency through optimized mixed-precision quantization and direct deployment to bare-metal platforms.

## Method
MiCo automates finding the best mixed-precision quantization scheme (using lower bit counts for some neural network layers and higher for others) by running an optimization algorithm that balances accuracy against speed limits. It predicts how fast each scheme will run on specific hardware targets—like GPUs or edge AI accelerators—without physically building and testing each option. Once the best scheme is found, MiCo directly generates optimized C code from the PyTorch model that runs on bare metal, letting you deploy straight from exploration to edge devices.

## Key Novelty
MiCo combines automated mixed-precision search, hardware-specific latency prediction, and direct C code deployment in a single end-to-end system for edge AI.

## Contributions
- Flexible MPQ exploration algorithm balancing accuracy with latency constraints
- Hardware-aware latency models for fast and accurate exploration across different edge devices
- Direct PyTorch-to-C deployment pipeline enabling minimal accuracy drops with end-to-end speedup
- Comprehensive framework supporting post-training and quantization-aware training
