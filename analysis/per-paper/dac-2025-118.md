# dac-2025-118: PASK – Cold Start Mitigation for GPU Inference

## Quick Summary
PASK is a kernel loading middleware for GPUs that eliminates cold-start overhead in DNN inference (serverless, spot serving) via proactive pipelined loading and selective kernel reuse. Achieves 5.62× average speedup.

## Key Insight
Interleave kernel code loading with GPU computation and reuse kernels across layers to hide cold-start latency, making inference fast even on fresh instances.

## Hardware & Technique
- **Target**: GPU
- **Techniques**: Scheduling, compiler-level optimization
- **Workloads**: LLM inference, CNN

## Results
- 5.62× speedup on popular DNN models
- Addresses cold-start in serverless/spot/edge scenarios
- Baseline: reactive kernel scheduling frameworks
