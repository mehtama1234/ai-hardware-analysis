# HetEC: Architectures for Heterogeneous Quantum Error Correction Codes

**Venue:** ASPLOS  
**Authors:** Samuel A. Stein, Shifan Xu, Andrew W. Cross, Theodore J. Yoder, Ali Javadi-Abhari, Chenxu Liu, Kun Liu, Zeyuan Zhou  
**Confidence:** low (abstract only)

## Problem
Surface codes scale quadratically in physical overhead with correctable errors, making them resource-prohibitive at scale. Quantum LDPC (qLDPC) codes offer superior scaling but lack a clear path to universal logical computation on their own; no architecture jointly exploits both code families.

## Motivation
Future fault-tolerant quantum computers need both resource efficiency and universal gate support, which no single QEC code provides, driving the need for heterogeneous multi-code architectures.

## Method
HetEC designs quantum computer architectures that combine surface codes and qLDPC codes heterogeneously. Surface code regions handle local topological operations and magic state distillation for universal gate sets, while qLDPC code regions provide superior error-correction scaling. The architecture defines interfaces and protocols for logical qubit transfer and gate teleportation between code boundaries.

## Key Novelty
A heterogeneous quantum architecture that systematically combines surface codes and qLDPC codes to achieve universal logical computation while accessing the distinct resource trade-offs of each code family.

## Contributions
- HetEC: a heterogeneous QEC architecture combining surface codes and qLDPC codes
- Architectural design for universal logical computation across heterogeneous code boundaries
- Analysis of resource trade-offs achievable by mixing code families
- A clear path to universal logical quantum computation using qLDPC codes
