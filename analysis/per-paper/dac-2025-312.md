# Libra: Hybrid-Sparse Attention Accelerator with Multi-Level Workload Balance

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

Libra is an attention accelerator exploiting hybrid sparsity (value-level + bit-level) while maintaining load balance across compute units. Uses filtered bit-group sparsification (FBS) for weights, dynamic bit-group quantization (DBQ) for activations, and multi-level task scheduling achieving 1.49-5.89x speedup and 2.65-10.82x energy efficiency vs. SOTA.

## Key Contributions

- **Hybrid Sparsity**: Combined value-level (FBS) and bit-level (DBQ) sparsification maximizing efficiency potential
- **Multi-Level Scheduling**: Task pool enabling workload balance across units despite sparse irregular patterns
- **Adaptive Bit-Width**: Architecture supporting simultaneous computations at different bit-widths
- **Strong Gains**: 1.49-5.89x speedup, 2.65-10.82x energy efficiency vs. SOTA attention accelerators

## Technical Focus

Addresses load imbalance problem that arises when exploiting hybrid sparsity. Multi-level task scheduling and variable bit-width execution ensure compute units stay utilized despite sparse, irregular workloads.

## Relevance

**Keywords:** transformer, hybrid-sparsity, attention-mechanism, quantization, load-balancing
