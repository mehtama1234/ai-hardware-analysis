# HypeReca: Distributed Heterogeneous In-Memory Embedding Database for Training Recommender Models

**Problem:** Training large-scale recommender models requires efficient access to massive embedding tables, but random access patterns and memory bandwidth limitations create significant bottlenecks during distributed training.

**Method:** HypeReca creates a database that lives in memory across multiple computers, designed for embedding tables (lookup tables that map IDs to learned values) that recommender systems need. It arranges data in memory layouts optimized for how embeddings get accessed, making lookups fast, and splits data across machines so work happens in parallel. The system uses custom communication to keep embeddings synchronized when multiple processors work together, and hardware-aware scheduling that runs each task on the device type (GPU, CPU, etc.) best suited for it.

**Novelty:** The core idea is an in-memory database optimized for embedding access patterns that works across different hardware types in distributed recommender training.
