# HypeReca: Distributed Heterogeneous In-Memory Embedding Database for Training Recommender Models

**Problem:** Training large-scale recommender models requires efficient access to massive embedding tables, but random access patterns and memory bandwidth limitations create significant bottlenecks during distributed training.

**Method:** HypeReca implements a distributed in-memory embedding database with heterogeneous hardware support, using data partitioning across multiple nodes and optimized memory layouts for embedding access patterns. The system employs specialized communication protocols for embedding synchronization and hardware-aware scheduling for heterogeneous device execution during training.

**Novelty:** Heterogeneous in-memory database architecture specifically designed for embedding-centric workloads in distributed recommender training.
