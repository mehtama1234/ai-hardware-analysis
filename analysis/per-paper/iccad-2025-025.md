# LsCMM-H: A TCO-Optimized Hybrid CXL Memory Expansion Architecture with Log Structure

**Venue:** ICCAD  
**ID:** iccad-2025-025

## Problem
CXL-SSDs as memory expanders face severe performance and endurance challenges using traditional SSD backends; existing solutions fail to fully address TCO optimization.

## Motivation
CXL memory expansion offers capacity scaling; requires optimized architecture for latency, lifetime, and total cost of ownership.

## Method
The system uses a log-structured approach—data writes are appended sequentially to the end of storage rather than scattered randomly—paired with Zoned Namespace SSDs, which are designed to handle this sequential writing natively. The hardware and software manage the storage together: frequently-accessed data is kept in faster tiers while the system automatically cleans up old copies from slower storage, reducing unnecessary writes that wear out the SSD. The design includes optimizations to speed up reading data even when it's stored on the SSD.

## Key Novelty
The core novelty is aligning log-structured writes with Zoned Namespace SSDs—hardware designed for sequential access—to optimize CXL-based memory expansion by reducing wasteful writes and improving both speed and durability.

## Contributions
- Log-structured memory expansion architecture
- ZNS SSD backend integration for improved latency and lifetime
- Hardware-software co-designed log management
- Data-tiering garbage collection mechanism
- 72.4% TCO savings with 49.9% latency and 280.5% endurance improvement
