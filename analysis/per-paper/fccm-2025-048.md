# N-TORC: Native Tensor Optimizer for Real-Time Constraints

**Problem:** HLS-based compilers achieve lower latency than overlay architectures but have time-consuming compilation and unpredictable area/latency outcomes, making it impractical to simultaneously satisfy latency constraints and minimize area.

**Method:** N-TORC combines data-driven performance and resource models for individual dataflow layers with model hyperparameter optimization and a Mixed Integer Program (MIP)-based solver to rapidly generate latency-constrained hardware architectures that optimize accuracy and resource cost simultaneously.

**Novelty:** Data-driven performance and resource modeling with MIP-based layer-wise optimization enables rapid synthesis of latency-constrained dataflow architectures without expensive end-to-end HLS compilation.
