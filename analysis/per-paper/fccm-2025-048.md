# N-TORC: Native Tensor Optimizer for Real-Time Constraints

**Problem:** HLS-based compilers achieve lower latency than overlay architectures but have time-consuming compilation and unpredictable area/latency outcomes, making it impractical to simultaneously satisfy latency constraints and minimize area.

**Method:** N-TORC learns how each computation layer performs and uses resources by analyzing real data, then tunes these learned patterns to your constraints. A mathematical optimizer (Mixed Integer Program solver) uses these tuned models to rapidly generate hardware designs meeting your latency targets while minimizing area and maintaining model accuracy.

**Novelty:** Instead of slow end-to-end hardware compilation, N-TORC combines data-learned performance and area models for each computation layer with mathematical optimization (Mixed Integer Programming) to rapidly generate hardware designs meeting latency requirements.
