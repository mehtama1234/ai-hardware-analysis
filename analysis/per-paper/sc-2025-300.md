# CASSE: Targeted Threat Modeling for Data Management Libraries

**Venue:** SC 2025  
**Authors:** Keegan Sanchez, Suren Byna, Zhiqiang Lin, David Mattson

## Problem Statement
Data management libraries (HDF5, Zarr, NetCDF) are ubiquitous in scientific computing but their security properties have received minimal attention. Existing threat modeling frameworks like STRIDE are poorly suited to DMLs because they don't account for:
1. File-based data structures and hierarchies
2. Custom data format complexities
3. Domain-specific access patterns and threats

## Technical Approach
**CASSE Framework:**
1. **Problem Identification:**
   - STRIDE attack categorizations often inapplicable to DMLs
   - Lacks context for meaningful interpretation
   - Ignores file structure and data layout complexities

2. **Novel Threat Taxonomy:**
   - Tailored attack categories for DML characteristics
   - Accounts for file format structure and metadata
   - Focuses on data corruption, unauthorized access, format manipulation

3. **File Structure Analysis:**
   - Includes file format diagrams in threat models
   - Analyzes vulnerabilities at data structure level
   - Considers interactions between metadata and data

## Evaluated Libraries
- **HDF5:** Hierarchical data format (most widely used)
- **NetCDF:** Network Common Data Form
- **Zarr:** Modern array storage with cloud-friendly access

## Threat Categories
Examples of DML-specific threats:
- Metadata manipulation (changing array shapes, dimensions)
- Data chunk substitution or corruption
- Unauthorized dataset access via file permissions
- Format version incompatibilities
- Hierarchy traversal attacks

## Key Contributions
- First systematic security analysis of widely-used DMLs
- Demonstrates STRIDE limitations for specialized domains
- Provides foundation for securing scientific data pipelines
- Extensible to other DMLs and binary formats

## Limitations & Future Work
- **Depth:** Abstract presentation; detailed threat analysis not provided
- **Mitigation:** No security solutions or patches proposed
- **Validation:** No feedback from DML maintainers
- **Implementation:** No tools for automated threat detection
- **Scope:** Limited to three DMLs; applicability to others unclear
- **Real Attacks:** No documented vulnerabilities or exploits discussed
