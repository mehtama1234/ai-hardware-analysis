# PuDHammer: Experimental Analysis of Read Disturbance Effects of Processing-using-DRAM in Real DRAM Chips

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Processing-using-DRAM (PuD) operations require multiple-row activation (activating multiple DRAM rows simultaneously or in quick succession), a fundamentally different access pattern from conventional single-row activation. No prior work has characterized whether this multiple-row activation exacerbates DRAM read disturbance (RowHammer-style bitflips) compared to standard single-row activation.

## Motivation
PuD is increasingly proposed as a near-memory compute paradigm to overcome the memory bandwidth wall, but deploying it safely requires understanding its interaction with DRAM read disturbance — a worsening reliability and security vulnerability — before it can be used in real systems.

## Method
The researchers tested 316 real DDR4 DRAM chips from four major manufacturers to see whether activating multiple memory rows at the same time (an access pattern used by processors that compute inside DRAM) triggers more bitflips (read disturbance errors that flip stored data bits) than activating just one row. They varied the test conditions: temperature, data patterns, timing settings, whether rows activate simultaneously or one-after-another, and different locations on the chip. For each test, they measured how many accesses it took to cause the first bitflip—called the hammer count. They compared this to standard RowHammer, which activates only one row.

## Key Novelty
This is the first study measuring on real DDR4 chips whether the multiple-row activation pattern (used in processing-inside-DRAM) triggers bitflips more easily, finding that it can reduce the access threshold by up to 158.58 times compared to standard RowHammer.

## Contributions
- First characterization of PuDHammer read disturbance on 316 real DDR4 DRAM chips from four manufacturers, covering diverse operational conditions.
- Quantification that PuDHammer reduces the minimum hammer count for first bitflip (HC_first) by up to 158.58x compared to conventional RowHammer.
- Analysis showing PuDHammer is affected by temperature, data patterns, timing parameters, and spatial variation within a chip.
- Demonstration that combining RowHammer with PuDHammer is more effective than either attack alone, raising security and reliability implications for PuD deployments.
