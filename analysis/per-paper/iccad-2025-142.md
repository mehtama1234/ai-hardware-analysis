# R2T-Tiny: Runtime-Reconfigurable Throughput-Optimized TinyML for Hybrid Inference Acceleration on FPGA SoCs

**Venue:** ICCAD
**ID:** iccad-2025-142
**Confidence:** low

## Problem
TinyML on FPGAs requires balancing high throughput with tight resource constraints; existing designs choose between high-throughput pipelined or low-throughput systolic approaches, creating resource contention.

## Motivation
Throughput-driven TinyML on resource-constrained FPGAs enables efficient on-device inference for edge applications.

## Method
R2T-Tiny reconfigures the FPGA hardware while running, dynamically switching between two acceleration types per neural network layer: pipelined designs (which process multiple data items in parallel for speed) and systolic designs (which arrange computations in regular grids for efficiency). Each layer also uses tailored approximations—simplified calculations that sacrifice tiny amounts of accuracy for faster processing and smaller hardware footprint. This combination lets the system use exactly the throughput and resources needed per layer.

## Key Novelty
The key innovation is the ability to reconfigure the accelerator while running, allowing the system to switch between pipelined and systolic acceleration strategies at the layer level to optimize throughput on resource-constrained FPGAs.

## Contributions
- Adaptive framework for layer-wise accelerator type selection
- Runtime partial reconfiguration for throughput optimization
- Tailored per-layer approximations
- 1.6x average throughput increase vs. DNNDK with <1% accuracy loss
