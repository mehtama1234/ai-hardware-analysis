# UPP: Universal Predicate Pushdown to Smart Storage
**ID:** isca-2025-051 | **Venue:** ISCA | **Confidence:** low (abstract-only)

## Problem
Existing in-storage processing (ISP) solutions only support simple operators (equality, range comparisons) on fixed-length columns, leaving modern analytical queries that use complex operators and diverse data formats unaccelerated. There is no flexible ISP mechanism that can handle arbitrary filter predicates used in production databases.

## Motivation
As database queries grow in complexity—using date arithmetic, string functions, and compound predicates over variable-length columns—naive ISP offloading cannot match these requirements, leaving bandwidth and compute savings on the table.

## Method
UPP creates a compact instruction set (a language the hardware understands) specifically built for filtering data in storage hardware. The database recognizes what data needs filtering, translates those operations into UPP instructions, and sends them to an FPGA chip inside the storage device (SmartSSD), which executes them directly on the stored data using bitwise comparisons (bit-by-bit checks) and lightweight metadata (bookkeeping about data structure) without reading data into memory or reformatting it. This separation of the instruction set from individual filter operations allows the database to compile and push arbitrary complex filters to storage while keeping data formats unchanged on disk.

## Key Novelty
UPP's core idea is a compact instruction set for storage hardware that enables flexible filter evaluation, so databases can compile any filter operation into executable code instead of relying on hardwired operator support.

## Contributions
- A universal predicate ISA (UPP-ISA) that covers arbitrary filter operators and functions beyond simple comparisons
- A software compilation layer in the database that automatically generates UPP instructions for diverse predicates
- An FPGA-based SmartSSD implementation performing bitwise predicate evaluation with lightweight metadata
- End-to-end evaluation on a 100 GB TPC-H dataset showing 1.2–7.9x Spark query speedup without changing data formats
