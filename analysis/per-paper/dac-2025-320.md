# EDGE: DBMS-Empowered Boolean Decomposition for GIG Synthesis

## Problem
Boolean decomposition-based logic synthesis is high-quality but computationally expensive, preventing scale-up to large industrial circuits.

## Solution
EDGE applies modern DBMS query optimization techniques to accelerate Boolean decomposition candidate enumeration and evaluation in Gate-Inverter Graph (GIG) synthesis.

## Impact
21x runtime speedup; ≥15% node count reduction vs. SOTA logic synthesis methods.
