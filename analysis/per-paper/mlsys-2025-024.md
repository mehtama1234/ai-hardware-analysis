# mlsys-2025-024 — NEO: Saving GPU Memory Crisis with CPU Offloading for Online LLM Inference

**Venue:** MLSYS 2025

**One-line problem:** Increase LLM inference throughput by asymmetrically pipelining GPU and CPU execution to hide CPU attention latency without throughput bubbles.

## Method
NEO splits each inference iteration into two asymmetric sub-batches: Batch-0 (all prefill + most decode) runs a long linear stage on GPU; Batch-1 (minority decode) runs attention on CPU. Both overlap. KV cache is split between HBM and DRAM; layer-wise PCIe swap overlaps with GPU compute. A load-aware scheduler with offline time models assigns requests per iteration. ISPC-compiled SPMD CPU attention kernels (PACPU) use paged attention and Flash Decoding-style multi-core parallelism.

## Key Novelty
Asymmetric sub-batch design integrating prefill into the GPU sub-batch to lengthen GPU-stage duration, eliminating symmetric pipelining bubbles and hiding CPU attention latency.

## Metrics
- Up to 7.5x throughput on T4 vs GPU-only
- 26% gain on A10G, 14% on H100
- Up to 79.3% gain with high-bandwidth CPUs (g5.16xlarge)
