# mlsys-2025-024 — NEO: Saving GPU Memory Crisis with CPU Offloading for Online LLM Inference

**Venue:** MLSYS 2025

**One-line problem:** Increase LLM inference throughput by asymmetrically pipelining GPU and CPU execution to hide CPU attention latency without throughput bubbles.

## Method
NEO overlaps GPU and CPU execution by splitting each inference iteration into two request groups that run simultaneously. The GPU group processes prefill requests and most decode requests through a linear projection stage, while the CPU group handles attention (reviewing previous context tokens) on the same requests using optimized parallel kernels. The key-value cache — data from prior computation — is split across GPU memory (fast) and main memory, with transfers timed to overlap with GPU computation. A scheduler pre-measures operation durations, uses linear interpolation to estimate costs, and greedily assigns requests per iteration to maximize throughput.

## Key Novelty
The innovation is asymmetric sub-batching: combining prefill and most decode on the GPU to lengthen its work phase, allowing the CPU's attention phase to run simultaneously without creating pipeline gaps.

## Metrics
- Up to 7.5x throughput on T4 vs GPU-only
- 26% gain on A10G, 14% on H100
- Up to 79.3% gain with high-bandwidth CPUs (g5.16xlarge)
