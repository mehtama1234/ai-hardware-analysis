# Virtuoso: Enabling Fast and Accurate Virtual Memory Research via an Imitation-based Operating System Simulation Methodology

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Current VM simulation tools either lack OS software accuracy or are too slow for hardware/OS co-design research spanning the hardware/software boundary.

## Motivation
Virtual memory is a major performance bottleneck and the complexity of hardware/OS co-design evaluation impedes research progress as memory demands grow.

## Method
Imitation-based OS simulation: trains on traces of real OS virtual memory decisions (page allocation, eviction, TLB management), then replays those decisions with hardware-accurate timing in a fast simulator, bypassing full OS simulation overhead.

## Key Novelty
Imitation learning used to reproduce OS VM behavior accurately within a fast architectural simulator without requiring full OS simulation.

## Contributions
- Characterization of accuracy and speed limitations in existing VM simulation tools
- Imitation-based OS simulation methodology that captures and replays OS VM decisions
- Fast/accurate simulation framework for hardware/OS co-design exploration
