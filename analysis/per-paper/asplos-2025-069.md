# Virtuoso: Enabling Fast and Accurate Virtual Memory Research via an Imitation-based Operating System Simulation Methodology

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Current VM simulation tools either lack OS software accuracy or are too slow for hardware/OS co-design research spanning the hardware/software boundary.

## Motivation
Virtual memory is a major performance bottleneck and the complexity of hardware/OS co-design evaluation impedes research progress as memory demands grow.

## Method
Virtuoso uses a lightweight simulator that learns from real operating system behavior. It records the decisions an OS makes about managing virtual memory—allocating memory pages, freeing unused ones, and managing the TLB (a hardware cache that stores address translations). The simulator learns to copy these patterns, then replays them with accurate timing measurements when testing new hardware or OS designs. This runs much faster than simulating the entire operating system.

## Key Novelty
A simulator learns from real OS behavior to quickly reproduce virtual memory decisions in new hardware and software designs, avoiding the need for full operating system simulation.

## Contributions
- Characterization of accuracy and speed limitations in existing VM simulation tools
- Imitation-based OS simulation methodology that captures and replays OS VM decisions
- Fast/accurate simulation framework for hardware/OS co-design exploration
