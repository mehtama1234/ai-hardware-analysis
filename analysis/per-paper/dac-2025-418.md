# DCDiff: Enhancing JPEG Compression via Diffusion-based DC Coefficients Estimation

**Problem:** Dropping DC coefficients at camera and reconstructing via statistics introduces errors; these propagate through the image.

**Method:** DCDiff uses an AI diffusion model to reconstruct missing DC coefficients (key numerical values in JPEG compression) instead of using statistical formulas. The model learns from real images to identify and correct reconstruction errors at specific locations. This stops errors from spreading throughout the image, which is a problem with traditional statistical methods. Since it adds only a diffusion step to standard JPEG processing, it works with existing low-cost camera hardware.

**Key Result:** Improved compression performance over baselines; minimal downstream task impact; compatible with low-cost JPEG processors.

**Hardware Target:** CPU  
**Workloads:** vision  
**Confidence:** low (abstract-only)
