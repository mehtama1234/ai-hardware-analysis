# DuRTL - Information Flow Analysis Tool for Register Transfer Level Hardware Designs

**VLSID 2025** | vlsid-2025-079

## Abstract
DuRTL is an open-source C++ hardware information flow analysis tool for Verilog/VHDL designs. It implements Hardware Information Flow Tracking (IFT) via a tagging mechanism: unique tags injected into designs track information propagation during circuit traversal, enabling comprehension of unknown hardware.

## Problem
- Understanding and verifying unknown or legacy hardware designs is difficult and time-consuming
- Manual code inspection unscalable for large designs
- Information flow paths critical for security analysis but hard to visualize

## Key Insight
Systematic tagging of signals enables automated information flow tracking through RTL, revealing data dependencies and potential information leakage paths automatically.

## Approach
1. Inject unique tags into RTL design
2. Each tag associates signal with specific time point
3. Track tag propagation through circuit
4. Identify information flow relationships

## Tool Details
- **Language**: C++
- **Input formats**: Verilog, VHDL
- **Status**: Open-source (available to community)
- **Methodology**: Hardware Information Flow Tracking via tagging

## Contributions
- First open-source hardware IFT tool
- Supports both Verilog and VHDL
- Documented IFT methodology for hardware
- Community resource
