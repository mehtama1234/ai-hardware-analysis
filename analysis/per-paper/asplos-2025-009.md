# asplos-2025-009: Cascade: A Dependency-aware Efficient Training Framework for Temporal Graph Neural Network

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
TGNN training is severely constrained by temporal dependencies between input events: large batches improve parallelism but cause infrequent node memory updates leading to stale information and accuracy degradation, forcing small-batch training with high latency and underutilized hardware.

## Motivation
Temporal GNNs are critical for real-world dynamic graph tasks, but the trade-off between batch size and memory freshness creates a fundamental hardware utilization bottleneck that prevents efficient training on modern accelerators.

## Method
Cascade uses a topology-aware scheduler that packs spatially-independent events into the same batch, then leverages inter-node memory similarity to identify 'stabilized' nodes whose memories have converged sufficiently to safely break temporal dependencies. Similarity-based dependency breaking allows temporally-independent events to be included in larger batches. An adaptive update frequency mechanism based on runtime feedback further reduces redundant memory updates.

## Key Novelty
Similarity-based temporal dependency breaking that identifies stabilized nodes whose memory states can be safely treated as independent, enabling large-batch TGNN training without sacrificing accuracy.

## Contributions
- Topology-aware scheduler that maximizes spatial independence within training batches.
- Node memory similarity analysis to identify stabilized nodes and break temporal dependencies safely.
- Adaptive memory update frequency mechanism guided by runtime feedback.
- 2.3x average (5.1x peak) speedup over prior TGNN training frameworks without accuracy degradation.
