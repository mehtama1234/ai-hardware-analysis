# ALLMod: Exploring Area-Efficiency of LUT-based Large Number Modular Reduction via Hybrid Workloads

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Cryptographic applications require high-bit-width modular reduction (128–8192 bits); LUT-based approaches incur large area overhead.

## Key Insight
Hybrid workload decomposition balances computation across segments to reduce LUT storage while maintaining throughput.

## Method
ALLMod reduces the hardware area required for LUT-based modular reduction by splitting the computation into two balanced workloads, inspired by iterative reduction. A template fairly distributes the work between them. The system explores different timing options for combining results from both workloads to find the optimal approach. By trading computation across the two workloads this way, ALLMod shrinks the total number of lookup tables needed while maintaining throughput.

## Contributions
- Hybrid workload decomposition for LUT modular reduction
- Template-based workload balancing
- DSE for result fusion timing
- 1.65× (128-bit) and 3× (8192-bit) area efficiency improvement

## Hardware Target
FPGA, ASIC

## Workloads
Cryptography (HE, ZKP)

## Theme
Hybrid-workload LUT optimization for area-efficient modular reduction.
