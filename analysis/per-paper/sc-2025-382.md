# cMPI: Using CXL Memory Sharing for MPI One-Sided and Two-Sided Inter-Node Communications

**Venue:** SC
**ID:** sc-2025-382
**Confidence:** low

## Problem

MPI cross-node communication uses complex network protocols (TCP, RoCE) with high latency and verification overhead.

## Motivation

CXL memory sharing offers potential for lower-latency cross-node communication by transforming network communication into memory transactions.

## Method

Normally, computers send data across networks by bundling it into packets using protocols like TCP or RoCE. Instead, cMPI lets computers directly access each other's memory using CXL (Compute Express Link), a new interconnect standard that treats memory as shared between machines. To make this work, the system handles three key challenges: managing where data objects live across machines, keeping copies consistent between different computers' caches (cache coherence), and making sure atomic operations (single indivisible actions) happen correctly without conflicts. The authors proved their approach works on actual CXL hardware.

## Key Novelty

This is the first to implement MPI communication using CXL memory sharing—a paradigm where machines directly access each other's memory instead of exchanging network packets—and demonstrate it on real hardware.

## Contributions

1. CXL-based MPI point-to-point communication implementation
2. Data object management for dax representation
3. Cache coherence and atomic operations support
4. 7.2x-8.1x lower latency vs TCP, 49x-72x improvement for small messages
