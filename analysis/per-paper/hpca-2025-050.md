# hpca-2025-050 — PAISE: PIM-Accelerated Inference Scheduling Engine for Transformer-based LLM

**Venue:** HPCA  
**Confidence:** low (abstract-only)  
**Primary Theme:** PIM-accelerated LLM attention offloading

## Problem
LLM inference on GPUs is memory-bound due to the attention layer's low arithmetic intensity and high memory traffic from frequent KV-cache updates, leading to elevated latency under autoregressive token generation. GPU-only execution under-utilizes available bandwidth for attention operations.

## Motivation
As LLM context lengths and batch sizes grow, the KV-cache bandwidth bottleneck worsens, making GPU-only inference increasingly inefficient and prompting exploration of near-memory execution.

## Method
PAISE offloads memory-intensive attention operations from an AMD MI100 GPU to HBM-PIM devices via a GPU-PIM heterogeneous scheduling framework. A scheduling algorithm determines per-operation offload decisions based on model configuration (layer type, head count) and PIM hardware specifications (bandwidth, FLOPS). An enhanced PIM kernel implements transaction-wise interleave-batched GEMM, restructuring data layout so multiple attention heads' KV reads are interleaved across PIM banks, maximizing memory-level parallelism within the HBM-PIM device.

## Key Novelty
Transaction-wise interleave-batched GEMM on HBM-PIM that reorders KV-cache data layout to exploit bank-level parallelism, combined with a model-aware scheduling algorithm that decides which transformer layers to offload.

## Contributions
1. A scheduling algorithm that selects which operations to offload to PIM based on model and hardware parameters.
2. An enhanced PIM GEMM kernel with interleave-batching and data layout optimization for attention.
3. Implementation and evaluation on GPT-2 and Llama2-7B using AMD MI100 + HBM-PIM.
4. Up to 48.3% reduction in execution time for attention layers vs GPU-only inference.
