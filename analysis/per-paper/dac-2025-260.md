# Efficient and Scalable Architectures for Multi-level Superconducting Qubit Readout

**Venue:** DAC | **ID:** dac-2025-260

## Problem
Superconducting transmons leak into energy levels outside the computational subspace, complicating quantum error correction. Detecting this leakage requires efficient multi-level readout, but current approaches consume excessive FPGA resources and time.

## Key Innovation
Matched filter-based architecture with lightweight neural network for crosstalk correction, achieving 60x FPGA resource reduction and 100x NN size reduction while improving accuracy.

## Method
1. Matched filters detect relaxation and excitation error patterns
2. Modular lightweight neural network corrects crosstalk errors
3. Bit-serial detection for resource efficiency
4. Off-the-shelf FPGA implementation

## Results
- **FPGA:** 60x resource reduction
- **Readout time:** 20% improvement
- **Neural network:** 100x size reduction
- **Accuracy:** 6.6% relative improvement

## Hardware Target
FPGA (for real-time quantum readout)

## Techniques
Circuit design, approximation, neural networks

## Applications
Quantum error correction, fault-tolerant quantum computing

## Limitations
Evaluation on superconducting qubits only; applicability to other modalities unclear.
