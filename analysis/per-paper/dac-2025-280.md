# dac-2025-280: Quantum Layout Synthesis Benchmarking via Optimal-SWAP Costs

**Problem:** QLS tool evaluation uses SWAP-free benchmarks with known depths; SWAP count (real-world requirement) is not evaluated, leaving tool quality assessment incomplete.

**Motivation:** Quantifying SWAP optimality gaps guides QLS algorithm development and tool selection.

**Method:** Creates QUBIKOS, a benchmark test suite with circuit problems where the optimal number of SWAP gates (the minimum hardware rearrangement operations needed to route quantum information between connected qubits) is mathematically proven. Tests four leading QLS tools—LightSabre, ML-QLS, QMAP, and tket—by comparing the SWAP gates each produces against the known-optimal count, revealing substantial performance gaps. Examines specific cases where tools underperformed to extract insights for improving future QLS algorithms.

**Key Novelty:** First benchmark with provable-optimal SWAP counts enabling quantitative optimality gap assessment.

**Contributions:**
- QUBIKOS benchmark with provable-optimal SWAP counts
- Optimality gaps: LightSabre 63x, ML-QLS 117x, QMAP 250x, tket 330x
- Suboptimal case analysis for algorithm guidance
