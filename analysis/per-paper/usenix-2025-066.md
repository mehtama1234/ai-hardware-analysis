# JENGA: Enhancing LLM Long-Context Fine-tuning with Contextual Token Sparsity

**Problem:** Fine-tuning large language models on long contexts requires processing all tokens, incurring substantial computational and memory overhead. JENGA addresses this by selectively sparsifying token processing based on contextual importance during fine-tuning.

**Method:** JENGA identifies which tokens (pieces of text like words or subwords) matter most for learning by looking at where the model's attention goes or which tokens contribute most to fixing errors. It then does full computation on important tokens but skips or speeds up computation on unimportant ones. Fine-tuning requires two passes—forward (making predictions) and backward (updating weights)—so this selective approach cuts computation in both directions, making fine-tuning faster and cheaper without hurting how well the model learns.

**Novelty:** Instead of processing all tokens equally, JENGA does less computational work on tokens that don't matter much for learning during fine-tuning, cutting costs substantially while keeping learning quality.
