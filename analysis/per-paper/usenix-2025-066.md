# JENGA: Enhancing LLM Long-Context Fine-tuning with Contextual Token Sparsity

**Problem:** Fine-tuning large language models on long contexts requires processing all tokens, incurring substantial computational and memory overhead. JENGA addresses this by selectively sparsifying token processing based on contextual importance during fine-tuning.

**Method:** JENGA identifies contextually important tokens and reduces computation for less important ones during fine-tuning. The system scores token importance based on attention patterns or gradient signals, then skips or approximates computation for non-critical tokens. This reduces both forward and backward pass costs through the transformer layers while maintaining learning efficacy.

**Novelty:** Applying dynamic contextual token sparsity specifically during fine-tuning to achieve substantial efficiency gains without sacrificing adaptation quality.
