# GPREEMPT: GPU Preemptive Scheduling Made General and Efficient

**Problem:** GPUs lack efficient, general-purpose preemption mechanisms, limiting multitasking and resource sharing in shared GPU environments. Existing preemption approaches are either architecture-specific or carry high performance overhead.

**Method:** GPREEMPT introduces a general preemption scheduling framework that implements efficient context switching via checkpoint-restore mechanisms and intelligent scheduling policies. The approach abstracts preemption across diverse GPU architectures and workload types to minimize overhead.

**Novelty:** A unified GPU preemption mechanism that achieves both architectural generality and operational efficiency through abstraction-based scheduling.
