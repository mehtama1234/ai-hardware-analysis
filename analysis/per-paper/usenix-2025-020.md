# GPREEMPT: GPU Preemptive Scheduling Made General and Efficient

**Problem:** GPUs lack efficient, general-purpose preemption mechanisms, limiting multitasking and resource sharing in shared GPU environments. Existing preemption approaches are either architecture-specific or carry high performance overhead.

**Method:** GPU preemption means pausing a task running on a graphics processor so you can run a more urgent task instead. GPREEMPT saves the paused task's state (called a checkpoint) so it can resume from that exact point later. The system uses smart scheduling rules to decide when to pause or resume tasks, and it works across different GPU types (NVIDIA, AMD, etc.) by hiding their technical differences behind a common layer of abstraction. This approach keeps the performance cost low.

**Novelty:** A common abstraction layer enables a single preemption system that pauses and resumes GPU tasks efficiently on any hardware.
