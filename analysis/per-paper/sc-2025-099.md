# SC25 Paper Analysis: sc-2025-099

## STELLAR: Storage Tuning Engine Leveraging LLM Autonomous Reasoning for High Performance Parallel File Systems

### Summary
STELLAR is an LLM-powered autonomous tuner for parallel file systems that achieves near-optimal configurations in ~5 attempts—dramatically faster than traditional autotuning methods requiring hundreds of thousands of iterations. It integrates RAG, tool execution, and multiagent reasoning for robust autonomous optimization.

### Key Problem
- **Tuning Complexity**: Parallel file systems have hundreds of tunable parameters
- **Expertise Gap**: Most domain scientists lack knowledge for effective tuning
- **Slow Convergence**: Traditional autotuning requires prohibitive iteration counts
- **Manual Burden**: Current practice requires significant manual expertise and effort

### Technical Approach
1. **LLM-Powered Reasoning**: Autonomous agentic tuning using language models
2. **RAG Integration**: Retrieves tunable parameters from system documentation
3. **Trace Analysis**: Analyzes I/O performance logs to identify bottlenecks
4. **Iterative Refinement**: Reruns applications and adjusts strategies based on feedback
5. **Knowledge Extraction**: Reflects on experiences to build reusable tuning knowledge
6. **Multiagent Design**: Stabilizes LLM reasoning and mitigates hallucinations

### Key Components
- **Parameter Extraction**: Automatic parsing of software manuals
- **I/O Trace Analysis**: Understanding performance bottlenecks
- **Strategy Selection**: Initial and adaptive tuning strategy choices
- **Feedback Loop**: Real system execution with performance measurement
- **Knowledge Base**: Accumulated tuning experiences for future optimizations

### Contributions
1. STELLAR autonomous tuner framework
2. Near-optimal configuration discovery in ~5 attempts
3. Human-like efficiency without excessive iterations
4. RAG-powered parameter extraction from manuals
5. I/O trace analysis capabilities
6. Multiagent design for reasoning stability
7. Reusable knowledge base for future tuning
8. Architectural blueprint for autonomous system optimization

### Hardware & Workloads
- **Target Hardware**: High-performance parallel file systems (storage infrastructure)
- **Workloads**: Data-intensive scientific computing applications

### Performance Results
- **Iteration Efficiency**: ~5 attempts to near-optimal (vs hundreds of thousands)
- **Configuration Quality**: Near-optimal tuning
- **Accessibility**: Enables optimization without deep expertise
