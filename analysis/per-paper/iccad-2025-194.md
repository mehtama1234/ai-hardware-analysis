# ISO 26262-Aligned Functional Safety Verification Framework with Explainable Graph Neural Network

**Venue:** ICCAD  
**ID:** iccad-2025-194

## Problem
Automotive functional safety verification (ISO 26262) requires exhaustive fault injection analysis; traditional simulation-based approaches are slow and lack interpretability for safety certification.

## Motivation
GNN-based functional safety verification accelerates fault analysis and provides explainable predictions, enabling efficient ISO 26262 compliance verification.

## Method
Develop GNN model trained on circuit fault injection data to predict functional safety criticality. Use explainable GNN (e.g., graph attention) to identify fault propagation paths and safe design points. Validate against standard fault injection benchmarks.

## Key Novelty
Explainable GNN framework for ISO 26262 functional safety verification with interpretable fault propagation analysis.

## Contributions
1. GNN-based functional safety prediction model
2. Explainable graph neural network for fault propagation understanding
3. ISO 26262 compliance framework for automotive hardware
4. Demonstrated speedup over traditional fault injection simulation
