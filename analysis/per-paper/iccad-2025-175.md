# The Fellowship of the Leak: Power Analysis of a Masked FrodoKEM Hardware Accelerator

**Authors:** Martin Schmid, Giuseppe Manzoni, Aydin Aysu, Elif Bilge Kavun

**Venue:** ICCAD

## Summary
Demonstrates a first-order side-channel attack on first-order masked FrodoKEM implementations using specially crafted inputs to bypass incomplete masking.

## Key Contributions
- Novel first-order side-channel attack bypassing incomplete masking in FrodoKEM
- Successful recovery of secret matrix rows using correlation power analysis
- Demonstration on Xilinx Artix-7 FPGA with ~10,000 traces
- Identification of masking application gaps in post-quantum crypto hardware
