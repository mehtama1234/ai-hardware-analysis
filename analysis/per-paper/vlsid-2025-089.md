# Advancing Rehabilitation Through Low Weight Hand Assistive System: Design and Impact Analysis

**VLSID 2025** | vlsid-2025-089

## Abstract
Individuals with hand impairments (stroke, spinal cord injury, neuromuscular disorders) require assistive devices providing real-time support and progressive rehabilitation. This work presents a lightweight smart hand assistive system integrating: (1) real-time finger movement detection via sensors, (2) adaptive motor actuation for subtle motion amplification, (3) mobile app with physiotherapy exercises and therapeutic games. Multiple control modes (manual, cyclic training, task-specific). Improves grip strength, dexterity, and overall hand function.

## Problem
- Hand impairments severely limit daily activity and independence
- Conventional assistive devices slow and lack real-time feedback
- Rehabilitation requires sustained engagement and motivation

## Key Insight
Real-time sensor feedback combined with adaptive actuation and interactive mobile engagement enables both functional assistance and progressive therapeutic improvement.

## System Architecture

### Hardware
- **Sensors**: Real-time finger movement detection
- **Actuation**: Adaptive motors for amplification
- **Design**: Lightweight for comfortable wearability
- **Interface**: Seamless body integration

### Software
- **Mobile App**: User-facing control and feedback
- **Physiotherapy module**: Predefined exercise routines
- **Interactive games**: Therapeutic engagement via gamification

## Control Modes
1. **Manual assistance**: User-controlled real-time amplification
2. **Cyclic movement training**: Automated repetitive motion practice
3. **Task-specific routines**: Targeted functional activities

## Evaluation Criteria
- **Grip strength**: Functional improvement metric
- **Dexterity**: Fine motor control assessment
- **Overall hand function**: Comprehensive capability measure

## User Base

- Spinal cord injury rehabilitation
- Neuromuscular disorder management
