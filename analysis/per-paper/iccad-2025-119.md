# GauPRE: A Pattern-based Rendering Engine for Gaussian Splatting on Edge Device

**Venue:** ICCAD  
**Confidence:** low

## Problem
3D Gaussian Splatting rendering on edge devices (~10FPS) fails to achieve real-time (≥30FPS) performance due to computational constraints; Gauss-Tile rasterization bottleneck stems from decoupled nature and computation-accuracy tradeoffs that current hardware cannot effectively address.

## Motivation
3DGS offers excellent visual quality for AR/VR but edge deployment requires real-time performance; rasterization efficiency is critical for mobile 3D rendering.

## Method
The approach combines software and custom hardware to speed up 3D Gaussian rendering on edge devices. A specialized hardware unit (called a pattern-aware rasterization unit) uses flood encoding to compactly represent which screen tiles need rendering, and applies k-means codebook compression (grouping similar patterns to reduce size) to keep the hardware small while maintaining visual accuracy. The GPU then streamlines the process by merging two steps—coverage testing (checking what's visible) and alpha blending (combining colors)—into one continuous pipeline, and processes screen tiles in groups with early depth-sorting (checking closer objects first) to avoid unnecessary work.

## Key Novelty
Pattern-based tile rasterization using flood encoding and k-means codebook compression enables efficient 3D Gaussian rendering on edge devices.

## Contributions
- Pattern-aware rasterization unit (PRU) with efficient tile coverage representation
- 11.6× end-to-end speedup on Jetson Orin Nano vs. baseline
- 0.1% area overhead
- 2.09× higher rasterization throughput vs. SOTA 3DGS accelerator
