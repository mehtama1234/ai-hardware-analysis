# NoiseZO: RRAM Noise-Driven Zeroth-Order Optimization for Efficient Forward-Only Training
**Venue:** DAC

## Problem
RRAM compute-in-memory (CIM) training requires gradient computation overhead; RRAM write noise complicates training convergence.

## Motivation
Energy-efficient DNN training on edge devices via CIM requires eliminating backpropagation and leveraging inherent hardware noise as an optimization primitive.

## Method
NoiseZO trains neural networks using dual RRAM arrays (resistive RAM—a type of memory that stores data using electrical resistance and can perform calculations during storage). Instead of computing gradients, it leverages the random electrical noise that naturally occurs when writing to RRAM as perturbations for zeroth-order optimization (a training method that updates weights using only function outputs, never computing derivatives). The framework provides fine-grained control over noise levels to improve accuracy, and each training update needs just two forward passes through the network.

## Key Novelty
The core innovation is using RRAM's write noise (the random electrical errors inherent to this memory type) as the perturbation source for gradient-free training, eliminating the expensive gradient computation step.

## Contributions
1. Forward-only training eliminates backpropagation on RRAM CIM
2. 21x energy reduction vs. CMOS implementations
3. Perturbation control strategy for high training accuracy
