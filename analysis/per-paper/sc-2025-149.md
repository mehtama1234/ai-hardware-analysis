# GPU Lossy Compression for HPC Can Be Versatile and Ultra-Fast

**Venue:** SC 2025  
**Authors:** Yafan Huang, Sheng Di, Guanpeng Li, Franck Cappello

## Problem
HPC scientific simulations generate data at rates vastly exceeding I/O and storage capacity. Lossy compression mitigates data challenges but existing GPU tools either lack versatility (domain-specific algorithms) or fail to achieve ultra-high throughput needed to match data generation rates.

## Motivation
Data management is critical bottleneck in exascale computing. Modern simulations from diverse domains (climate, materials, combustion) produce massive data volumes. Compression essential for viability, but tool must: (1) support diverse data types, (2) achieve state-of-the-art throughput, (3) provide fine-grained error control.

## Method
VGC (Versatile GPU Compression) framework providing:

1. **Dimension Awareness:** Capture and exploit dimensional structure in scientific data arrays

2. **Multiple Algorithms:** Support three compression algorithms covering diverse HPC domains

3. **Ultra-Fast GPU Kernels:** Optimized kernels delivering state-of-the-art throughput with error control

4. **Memory-Efficient Compression:** Kernel fission design computes compressed size, allocates precisely required GPU memory, eliminates waste

5. **Selective Decompression:** Early stopping mechanism enables direct access to regions of interest without full decompression

## Key Novelty
First GPU compression framework combining versatility across scientific domains with ultra-high throughput via architecture-aware kernel optimization.

## Contributions
1. Support for three compression algorithms across diverse HPC applications
2. Dimension-aware compression exploiting data structure
3. Memory-efficient compression using kernel fission and precise allocation
4. Selective decompression with early stopping for region access
5. State-of-the-art throughput with configurable error control
