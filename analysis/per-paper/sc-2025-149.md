# GPU Lossy Compression for HPC Can Be Versatile and Ultra-Fast

**Venue:** SC 2025  
**Authors:** Yafan Huang, Sheng Di, Guanpeng Li, Franck Cappello

## Problem
HPC scientific simulations generate data at rates vastly exceeding I/O and storage capacity. Lossy compression mitigates data challenges but existing GPU tools either lack versatility (domain-specific algorithms) or fail to achieve ultra-high throughput needed to match data generation rates.

## Motivation
Data management is critical bottleneck in exascale computing. Modern simulations from diverse domains (climate, materials, combustion) produce massive data volumes. Compression essential for viability, but tool must: (1) support diverse data types, (2) achieve state-of-the-art throughput, (3) provide fine-grained error control.

## Method
VGC (Versatile GPU Compression) is a framework that compresses data from scientific simulations using graphics processors (GPUs) and three different compression algorithms. It understands the dimensional structure of the data, which helps it apply compression more effectively, and uses GPU processing routines that are specially optimized to achieve ultra-fast compression speeds while controlling how much accuracy is lost. It works in two operational modes: one optimized for memory efficiency during compression, and another that decompresses only the specific parts of data you need.

## Key Novelty
VGC combines versatility—supporting multiple data types and compression algorithms—with ultra-fast compression speeds by using GPU processing routines that are optimized for the GPU's architecture.

## Contributions
1. Support for three compression algorithms across diverse HPC applications
2. Dimension-aware compression exploiting data structure
3. Memory-efficient compression using kernel fission and precise allocation
4. Selective decompression with early stopping for region access
5. State-of-the-art throughput with configurable error control

## Distinctive Features
- **Memory Efficiency:** Kernel fission eliminates redundant memory allocation
- **Selective Access:** Early stopping enables direct region access without full decompression
- **Versatility:** Multiple algorithms for diverse domain applications
