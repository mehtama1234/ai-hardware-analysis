# Constructing Rectilinear Steiner Minimum Tree with Conditional Generative Adversarial Network

**Paper ID:** vlsid-2025-074
**Venue:** VLSID
**Confidence:** low

## Problem
RSMT (Rectilinear Steiner Minimum Tree) construction for nets is NP-complete and computationally expensive; efficient algorithms are critical for physical design.

## Motivation
RSMT is fundamental backbone of global routers; current heuristics are computationally expensive; need for faster solutions.

## Method
Novel image-to-image translation approach using conditional GAN (cGAN) to generate RSMT. Training dataset: RSMT images with optimal wirelength for randomly generated nets.

## Key Novelty
First application of cGAN for RSMT construction; formulates tree construction as image-to-image translation problem rather than traditional algorithmic approach.

## Contributions
- cGAN-based RSMT generation framework
- Image-to-image translation formulation of RSMT problem
- Wirelength error ≤ 0.348% on average vs optimal
- Support for net degrees up to 50
- First successful ML approach to RSMT
