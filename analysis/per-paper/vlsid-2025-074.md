# Constructing Rectilinear Steiner Minimum Tree with Conditional Generative Adversarial Network

**Paper ID:** vlsid-2025-074
**Venue:** VLSID
**Confidence:** low

## Problem
RSMT (Rectilinear Steiner Minimum Tree) construction for nets is NP-complete and computationally expensive; efficient algorithms are critical for physical design.

## Motivation
RSMT is fundamental backbone of global routers; current heuristics are computationally expensive; need for faster solutions.

## Method
The approach trains a conditional GAN (a machine learning system that transforms images) on pictures of optimally-wired nets. Each training image shows connection points paired with the shortest routing connecting them, teaching the GAN to recognize efficient wiring patterns. Once trained, the system generates new routings by presenting an unrouted net to the GAN, which outputs the predicted optimal wiring pattern.

## Key Novelty
The key idea is treating RSMT construction as an image-to-image translation problem, using conditional GANs instead of traditional routing algorithms.

## Contributions
- cGAN-based RSMT generation framework
- Image-to-image translation formulation of RSMT problem
- Wirelength error ≤ 0.348% on average vs optimal
- Support for net degrees up to 50
- First successful ML approach to RSMT
