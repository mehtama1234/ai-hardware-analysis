# SC-2025-309: TEGRA - Scaling Up Graph Processing with Disaggregated Computing

## Summary
This work presents TEGRA, a composable scale-up architecture for large-scale graph processing that leverages CXL-based disaggregated memory and message-passing communication. By decoupling compute and memory resources, TEGRA enables independent scaling and dynamic provisioning to match varying graph workload intensities.

## Key Contributions
1. **CXL-based disaggregated memory architecture** for graph processing
2. **Message-passing communication model** for accessing remote memory
3. **Dynamic compute provisioning** based on workload arithmetic intensity
4. **Up to 15% improvement** in memory bandwidth utilization vs. coupled accelerators

## Technical Approach
- Disaggregated architecture with compute and memory as independent resources
- CXL interconnect enabling remote memory access with acceptable latency
- Message-passing communication API for workload-memory interaction
- Simulation-based evaluation using gem5 simulator
- Workload-aware compute provisioning algorithms

## Hardware & Systems
- CXL-enabled interconnects (current and emerging)
- Disaggregated memory pools connected via CXL
- Graph processing accelerators (simulated)
- Multi-node distributed systems

## Workloads & Evaluation
- **Primary domain**: Graph processing and analytics
- **Workload spectrum**: Variable compute-to-memory intensity ratios
- **Metrics**: Memory bandwidth utilization, performance scaling, cost efficiency
- **Comparison**: Traditional coupled accelerators, distributed graph systems

## Limitations & Future Work
- Simulation-based results only (no physical hardware prototypes)
- CXL memory access latency overhead not fully characterized
- Real-world congestion and contention behavior not modeled
- Scalability limits to very large disaggregated systems not explored
- Comparison with other disaggregation approaches (e.g., remote NUMA) not detailed
- Applicability to other irregular workloads (sparse linear algebra, etc.) unclear
