# hpca-2025-089 — Enterprise Class Modular Cache Hierarchy

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Enterprise mission-critical workloads demand cache hierarchies that deliver consistent low-latency performance at sustained processor utilization above 90% across diverse and highly virtualized workloads, while remaining extensible across processor generations and new technology insertions.

## Motivation
Traditional monolithic cache designs cannot scale across future technology nodes and platform generations without redesign, creating a growing gap between cache hierarchy rigidity and the evolving demands of enterprise and emerging AI workloads.

## Method
The IBM Telum and Telum II processors introduce a modular, horizontally federated cache hierarchy in which last-level cache slices are distributed across chiplets and interconnected through high-bandwidth on-chip links. An adaptive horizontal cache persistence algorithm dynamically adjusts which cache levels retain hot data across different access patterns and workload phases. The paper details how fetch events flow through this hierarchy and how cache size changes affect system-level performance, culminating in the Telum II design that simultaneously supports traditional enterprise workloads and generative AI inference.

## Key Novelty
An industry-deployed modular and horizontally federated cache hierarchy with adaptive persistence algorithms designed for 90%+ sustained utilization in mission-critical enterprise and generative AI workloads.

## Contributions
- Novel modular, scalable cache hierarchy architecture extendable across IBM Z platform generations
- Adaptive horizontal cache persistence algorithm that dynamically tunes data retention across cache levels
- Performance characterization of cache size sensitivity in enterprise workload contexts
- Integration of generative AI capability into mission-critical IBM Telum II design without compromising enterprise SLAs
