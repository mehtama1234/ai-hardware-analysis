# LeanAttention: Hardware-Aware Scalable Attention for the Decode-Phase of Transformers

**ID:** mlsys-2025-037 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM decode-phase attention has critically low GPU occupancy because FlashAttention-2 only parallelizes over batch and heads (Nq=1 for decode), and FlashDecoding's fixed-split causes imbalanced loads and quantization inefficiencies.

## Method
LeanAttention divides attention work equally across GPU cores using Stream-K, a parallel-processing technique: it breaks the key-value sequence into fixed-size chunks called LeanTiles (each sized optimally for the GPU hardware), distributing them regardless of how attention heads (separate computation paths) are organized. When LeanTiles span head boundaries, their partial results are combined using softmax re-scaling, which is associative—you can compute pieces separately and combine them to get the exact same answer as one complete computation. This keeps GPU cores busy for any sequence length.

## Key Novelty
LeanAttention proves that softmax re-scaling (the normalization step in attention) is associative, meaning you can compute attention work in arbitrary split pieces and combine them perfectly, enabling full GPU utilization for any context length or batch size.

## Metrics
- **Speedup:** Average 1.73x over FlashDecoding on A100 (max 2.18x at 256k ctx); average 1.52x on H100 (max 2.53x)
- **Energy:** More efficient than FlashDecoding at >128k context
