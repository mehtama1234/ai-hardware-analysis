# Can Short Hypervectors Drive Feature-Rich GNNs? Strengthening the Graph Representation of Hyperdimensional Computing for Memory-efficient GNNs
**Venue:** DAC

## Problem
Hyperdimensional computing (HDC) requires ultra-long hypervectors (tens of thousands of bits) to express rich features, creating a memory bottleneck that offsets HDC's computational efficiency.

## Motivation
GNN memory accesses are a key bottleneck in graph processing; reducing hypervector dimension from tens of thousands to hundreds of bits enables massive memory savings for brain-inspired computing.

## Method
CiliaGraph rebuilds HDC operations to overcome three GNN incompatibilities: (1) feature distortion via better encoding, (2) structural bias via weighted aggregation, (3) central-node vacancy via expanded supervision. Uses short hypervectors (hundreds of bits) with error-tolerant neural principles to maintain accuracy.

## Key Novelty
First HDC-based GNN framework that breaks the long-vector consensus by proving hundreds of bits suffice for feature-rich graph learning.

## Contributions
1. 100-1000x reduction in memory access via short hypervectors
2. 100-300x reduction in training latency while maintaining competitive accuracy
3. Three resolved HDC-GNN incompatibilities (feature distortion, structural bias, central-node vacancy)
