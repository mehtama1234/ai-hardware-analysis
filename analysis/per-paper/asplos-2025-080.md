# ByteFS: System Support for (CXL-based) Memory-Semantic Solid-State Drives

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Memory-semantic SSDs expose both byte-addressable (PCIe/CXL) and block interfaces, but existing software systems designed for NVM-on-memory-bus or block-SSDs cannot exploit their dual-interface characteristics and distinct performance profiles.

## Motivation
CXL-attached memory-semantic SSDs offer scalable, affordable byte-addressable capacity, but realizing their potential requires new OS/filesystem abstractions tailored to their asymmetric dual-interface performance.

## Method
ByteFS is a file system built for CXL memory-semantic SSDs—drives that offer both byte-level access (like regular computer memory) and block-level access (like traditional storage) via the CXL protocol. It routes each file operation to whichever interface handles it faster: sending metadata and small random-access requests through the byte-level interface (which has lower latency), and large sequential data transfers through the block interface (which has higher throughput). The file system also redesigns operating system abstractions for space allocation, caching, and I/O operations to leverage both interfaces and account for the SSD's persistent, byte-addressable storage semantics.

## Key Novelty
A file system that intelligently routes operations between byte-level and block-level interfaces of CXL-attached SSDs based on access characteristics, with OS structures designed for NAND flash's persistent byte-addressable nature.

## Contributions
- Characterization of memory-semantic SSD dual-interface performance implications
- ByteFS file system with dual-interface routing
- New OS abstractions for CXL memory-semantic SSDs (allocation, caching, I/O path)
