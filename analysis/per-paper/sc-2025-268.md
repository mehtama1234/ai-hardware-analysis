# Automatic Distributed Fourier Operation Mapping

## Problem
Distributed Fourier libraries force developers to structure code around FFT constraints, missing communication optimization opportunities when FFT is coupled with other operations.

## Approach
Automated mapping generation using SMT solver optimization:
1. Joint optimization of Fourier and linear algebra operations
2. Minimize communication across MPI collectives
3. Automatic grid shape selection
4. Non-linear iterative formulation

## Results
- **2-31x speedup** vs. heFFTe+COSMA coupling
- Eliminates framework constraints
- Enables developer-specified computation flows

## Key Insight
SMT-based joint optimization across kernels outperforms separate library tuning. Holistic view of communication patterns enables significant speedups.

## Applications
- Multi-dimensional FFTs
- Coupled Fourier-linear algebra kernels
- Distributed scientific computing
