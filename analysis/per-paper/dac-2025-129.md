# iTaskSense: Task-Oriented Object Detection in Resource-Constrained Environments

**Venue:** DAC | **ID:** dac-2025-129

## Core Problem
Efficient task-oriented object detection on edge devices; conventional models require extensive data and struggle with generalization.

## Method
The system uses large language models (AI trained on massive amounts of text) to learn from just a few examples by building knowledge graphs that map out task-specific requirements and attributes. It provides two different vision transformers (neural networks for image recognition): one specialized and compressed for particular tasks, achieving 15% higher accuracy on those specific tasks, and another heavily compressed version (quantized—reducing precision to shrink size) that works across multiple different tasks with reasonable performance. A custom hardware acceleration circuit enables these models to run directly on edge devices (resource-constrained hardware like phones or sensors) for real-time processing without sending data to the cloud.

## Key Novelty
The core innovation is using large language models to automatically generate task-specific knowledge graphs that enable object detection from just a few examples, paired with two different vision transformers (one optimized for accuracy on specific tasks, another compressed for flexibility across tasks) and a custom hardware circuit for real-time edge processing.

## Contributions
- LLM-based knowledge graph for few-shot task detection
- Dual-config ViT (distilled task-specific + quantized multi-task)
- Custom edge hardware accelerator
- 3.5x speedup, 40% energy reduction; 15% accuracy gain
