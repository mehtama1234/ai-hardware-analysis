# DevTrace: Lightweight Plug-In Design for PCIe Transaction Tracing in Edge Intelligence Workloads

**Venue:** ICCAD

## Problem
Host-peripheral interactions during high-load tasks create optimization bottlenecks, with existing tracing tools degrading performance by up to 5.39x.

## Motivation
Resource-constrained edge intelligence deployments need low-overhead profiling and analysis of peripheral interactions.

## Method
Low-overhead tracing framework with modular architecture separating data collection from kernel operations, minimal driver modifications, eliminating heavy kernel tracing interrupts.

## Key Novelty
Lightweight plug-in design enabling low-overhead tracing across entire device classes with minimal framework coupling.

## Contributions
- 128x reduction in memory usage vs page-fault solutions
- 10x lower CPU overhead vs page-fault tools
- Negligible performance degradation even under high-load
- Significantly reduced data loss
- Potential eBPF extensions for further decoupling
