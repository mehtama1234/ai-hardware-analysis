# Low-Latency FFT/iFFT RTL Implementation for the FALCON Post-Quantum Signature Algorithm

**Problem:** FALCON, a NIST-standardized post-quantum signature scheme, requires double-precision floating-point FFT for polynomial multiplication, but lacks a full hardware RTL implementation. The unusual floating-point FFT requirement has historically hindered complete RTL design efforts.

**Method:** The work presents a full RTL implementation of double-precision floating-point FFT and inverse FFT on FPGA, tailored specifically for FALCON's cryptographic context. The design employs constant-time execution to prevent side-channel attacks during polynomial multiplication. Hardware optimizations target FALCON's floating-point arithmetic requirements to minimize latency.

**Novelty:** First constant-time RTL implementation of double-precision floating-point FFT/iFFT specifically designed for FALCON on FPGA, achieving state-of-the-art latency.
