# Low-Latency FFT/iFFT RTL Implementation for the FALCON Post-Quantum Signature Algorithm

**Problem:** FALCON, a NIST-standardized post-quantum signature scheme, requires double-precision floating-point FFT for polynomial multiplication, but lacks a full hardware RTL implementation. The unusual floating-point FFT requirement has historically hindered complete RTL design efforts.

**Method:** The work implements the complete hardware logic (RTL) for fast Fourier transforms (FFT) and their inverse on an FPGA—a programmable chip—using double-precision floating-point math, specifically designed for FALCON's cryptographic needs. To prevent attackers from learning the signature key by observing power consumption or timing differences (side-channel attacks), the hardware runs in constant time—taking the same amount of time no matter what values it processes. The design optimizes how the hardware handles floating-point arithmetic to keep latency as low as possible.

**Novelty:** The core idea is the first hardware implementation of FALCON's floating-point FFT and inverse that runs in constant time—taking the same duration for any input—to prevent side-channel attacks while keeping latency low.
