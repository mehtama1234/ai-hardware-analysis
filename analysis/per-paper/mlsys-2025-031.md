# MEADOW: Memory Efficient Adaptable Dataflow for On-Device LLM Workloads

**ID:** mlsys-2025-031 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Running LLM inference on edge FPGAs is severely constrained by limited on-chip SRAM and external DRAM bandwidth at sub-10W power budgets.

## Method
The system fits LLM inference on power-constrained FPGAs by reorganizing attention calculations and compressing weights. It processes attention by handling multiple tokens (input pieces) in parallel while sequencing through heads (sub-units of attention) one at a time, which keeps all needed data in the chip's fast on-board cache instead of repeatedly fetching from slow external memory. For weight tensors, it identifies repeating chunks and compresses them based on frequency—high-frequency chunks stay lightly compressed for speed, low-frequency ones get aggressively compressed to reduce memory traffic to external storage. All numbers are also stored as 8-bit integers (W8A8 quantization) to minimize the overall memory footprint.

## Key Novelty
The core contribution is combining token-parallel head-sequential attention processing with frequency-based weight compression (compressing rarely-used weight patterns more aggressively than frequently-used ones) to enable LLM inference on sub-10W FPGAs, achieving 1.5-2.5x speedup over conventional matrix-multiply approaches.

## Metrics
- **Speedup:** 1.5x decode, 2.5x prefill vs GEMM baseline; >40% vs CTA/FlightLLM
- **Power:** Sub-10W (Xilinx ZCU102)

## Baselines
GEMM baseline, CTA, FlightLLM
