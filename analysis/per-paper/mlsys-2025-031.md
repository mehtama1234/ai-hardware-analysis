# MEADOW: Memory Efficient Adaptable Dataflow for On-Device LLM Workloads

**ID:** mlsys-2025-031 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Running LLM inference on edge FPGAs is severely constrained by limited on-chip SRAM and external DRAM bandwidth at sub-10W power budgets.

## Method
Token-Parallel Head-Sequential (TPHS) dataflow partitions attention across the token dimension in parallel while sequencing over heads to fit within SRAM. Three-level weight packing: unique chunk extraction, packet-specific encoding precision, and frequency-aware reindexing minimizes DRAM traffic. W8A8 quantization applied throughout.

## Key Novelty
Co-designed TPHS dataflow and three-level weight packing targeting sub-10W FPGA inference, achieving 1.5-2.5x latency reduction over GEMM baseline.

## Metrics
- **Speedup:** 1.5x decode, 2.5x prefill vs GEMM baseline; >40% vs CTA/FlightLLM
- **Power:** Sub-10W (Xilinx ZCU102)

## Baselines
GEMM baseline, CTA, FlightLLM
