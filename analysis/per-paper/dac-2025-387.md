# Age-of-Information Minimization for Data Aggregation in Energy-Harvesting IoTs

**Venue:** DAC
**ID:** dac-2025-387

## Problem
Energy-harvesting IoT devices struggle to maintain fresh data under energy constraints; existing AoI minimization methods ignore data aggregation scenarios.

## Motivation
Data freshness is critical; aggregating data from multiple sources while managing energy harvesting introduces new scheduling challenges.

## Method
The approach creates a two-stage transmission schedule for energy-harvesting IoT devices. First, it plans a baseline schedule offline using predictions about how much energy each device will have and when data needs to be fresh. Then it adjusts this plan in real time as actual energy conditions change, shifting which devices transmit to keep the collected data as current as possible within available power.

## Key Novelty
It minimizes data staleness when multiple energy-harvesting devices send sensor readings to a central collector, adapting the transmission schedule in real time to changing energy conditions.

## Contributions
1. First study of AoI minimization for data aggregation in energy-harvesting IoTs
2. Energy-adaptive node scheduling algorithm with offline and online components
3. Demonstrated high performance in AoI minimization and energy efficiency
4. Validated via simulation and testbed experiments
