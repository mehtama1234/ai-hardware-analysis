# Age-of-Information Minimization for Data Aggregation in Energy-Harvesting IoTs

**Venue:** DAC
**ID:** dac-2025-387

## Problem
Energy-harvesting IoT devices struggle to maintain fresh data under energy constraints; existing AoI minimization methods ignore data aggregation scenarios.

## Motivation
Data freshness is critical; aggregating data from multiple sources while managing energy harvesting introduces new scheduling challenges.

## Method
Proposes energy-adaptive node scheduling algorithm combining offline scheduling and online adjustment to minimize AoI for data aggregation tasks.

## Key Novelty
Energy-aware scheduling algorithm for AoI minimization in data aggregation scenarios on energy-harvesting devices.

## Contributions
1. First study of AoI minimization for data aggregation in energy-harvesting IoTs
2. Energy-adaptive node scheduling algorithm with offline and online components
3. Demonstrated high performance in AoI minimization and energy efficiency
4. Validated via simulation and testbed experiments
