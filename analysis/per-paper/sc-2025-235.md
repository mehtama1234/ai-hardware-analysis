# eCounter: Inline Per-IP Network Monitoring at Millisecond Resolution via eBPF

**ID:** sc-2025-235
**Venue:** SC
**Confidence:** low

## Problem

Scientific data acquisition needs sub-millisecond network telemetry; existing tools lack fine-grained observability

## Motivation

Streaming SciDAQ requires real-time monitoring; P4 switches expensive; host-side tools insufficient

## Approach

eBPF-based inline telemetry agent; per-IP per-protocol categorization; millisecond-resolution exports

## Key Novelty

Sub-millisecond telemetry via eBPF; hardware-agnostic per-IP monitoring; low CPU overhead (4%)

## Contributions

- eCounter: eBPF-based telemetry agent
- Per-IP, per-protocol traffic categorization
- Millisecond-resolution export
- Low CPU/bandwidth overhead at 100 Gbps

## Hardware Targets

- 100 Gbps networks
