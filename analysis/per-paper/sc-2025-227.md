# An HPC-Inspired Blueprint for a Technology-Agnostic Quantum Middle Layer

**ID:** sc-2025-227
**Venue:** SC
**Confidence:** low

## Problem

Quantum software must be rewritten for different quantum backends (gate-based, annealing, CV)

## Motivation

Lack of portable quantum middleware; need for hardware-agnostic abstraction similar to HPC libraries

## Approach

Blueprint for quantum middle layer with intent/context separation; POC with Qiskit and D-Wave backends

## Key Novelty

The core innovation is using a backend-neutral middle layer that separates intent from context with a descriptor pattern (borrowed from high-performance computing design), so quantum code only needs to be written once regardless of which quantum hardware it runs on.

## Contributions

- Blueprint for technology-agnostic quantum middleware
- Typed intent + context descriptor separation model
- JSON-based workflow specifications
- Demonstration on two distinct quantum paradigms (gate-model, annealing)
