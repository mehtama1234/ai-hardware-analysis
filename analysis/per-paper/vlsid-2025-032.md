# VLSID 2025-032: ML-Accelerated Design Verification Coverage

## Summary
Applies machine learning to predict which randomly generated verification stimulus will provide incremental coverage, filtering out non-productive simulation runs to accelerate verification closure.

## Problem
Constrained random verification generates many stimulus patterns that do not contribute to code or functional coverage, wasting simulation time. Verification closure becomes the dominant delay in design-to-silicon cycles.

## Method
- ML model to predict incremental coverage contribution
- Stimulus filtering before simulation
- Constrained random verification framework
- Coverage tracking (code + functional)

## Key Results
- Methodology presented but specific quantitative results not provided in abstract
- Claims acceleration of verification closure
- Reduction in non-productive simulation runs

## Applications
- Complex IC design verification
- Module verification for different market segments
- High-complexity SoC verification
- Coverage-driven verification workflows
