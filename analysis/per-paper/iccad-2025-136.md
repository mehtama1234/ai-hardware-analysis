# Wit-HW: Bug Localization in Hardware Design Code via Witness Test Case Generation

**Venue:** ICCAD
**ID:** iccad-2025-136
**Confidence:** low

## Problem
Hardware bug localization remains difficult for large designs and deep bugs because existing techniques rely on single bug-triggering test cases, missing complex interactions in intricate systems.

## Motivation
Automated bug localization can significantly reduce the manual effort required during hardware verification and development.

## Method
Wit-HW generates passing test cases (called witness cases) in addition to analyzing the initial failing test case. It compares which lines of hardware code execute in the passing cases versus the failing case to identify which lines are innocent and cannot contain the bug. To create effective witness cases, it uses mutation-based testing—systematically modifying the code to try different versions—to find passing cases that are especially good at revealing where the actual bug is.

## Key Novelty
Using passing test cases (witness cases) combined with execution comparison between passing and failing runs to pinpoint bugs in hardware designs.

## Contributions
- Test generation framework transforming bug localization into a search problem
- Spectrum-based method for analyzing execution differences to identify buggy statements
- Mutation-based strategy for effective witness test case generation
- 49%/73%/88% bug localization success at Top-1/Top-5/Top-10 ranks on 41 hardware bugs
