# Rex: Closing the language-verifier gap with safe and usable kernel extensions

**Problem:** Kernel extensions require manual verification and are error-prone; there is a significant gap between what high-level programming languages provide and what formal verification tools require, forcing developers to choose between safety and usability.

**Method:** Rex is a specialized programming language and compiler designed for kernel extensions (code that runs at the system's most privileged level). Developers write in this high-level language, and the compiler automatically translates their code into a form that can be mathematically proven correct (formal verification), handling the complex translation that would normally require manual, error-prone work. The language uses type checking (rules about what data types can flow where) to prevent whole categories of safety bugs before verification even begins. This means programmers get an easy-to-use language while still getting mathematical proof that their kernel code won't crash or be exploited.

**Novelty:** A compiler infrastructure that automatically translates high-level, programmer-friendly code into kernel extensions with formal safety guarantees, eliminating the need for manual verification.
