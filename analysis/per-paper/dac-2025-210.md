# LLMShare: Optimizing LLM Inference Serving with Hardware Architecture Exploration

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
LLM serving systems use fixed hardware that doesn't differentiate between prefill (compute-intensive) and decoding (memory-bandwidth-intensive) phases, wasting resources.

## Key Insight
Prefill and decoding phases have opposing computational profiles; a single hardware configuration cannot optimize both simultaneously.

## Method
Simulator-driven design space exploration: models performance/cost across heterogeneous hardware, explores allocations of resources to each phase.

## Contributions
- Performance/cost simulator for heterogeneous LLM serving
- DSE framework for phase-specific hardware allocation
- 4× throughput, 13% cost reduction vs. conventional systems

## Hardware Target
GPU, CPU, ASIC

## Theme
Phase-aware hardware partitioning for efficient LLM inference serving.
