# Scalable Neural Network Training: Distributed Data-Parallel Approaches

**ID**: sc-2025-372
**Venue**: SC
**Confidence**: low

## Problem
Optimizing communication performance in hierarchical multi-GPU systems

## Motivation
Deep learning requires efficient matrix operations on specialized hardware

## Method
This approach treats the training job as independent tasks that each GPU can run on its own portion of data without constant coordination. At the end of each epoch—after each GPU has processed all of its assigned data once—the GPUs synchronize to share results, rather than syncing after every single training step. This drastically reduces communication between GPUs, which is especially critical in hierarchical systems where some GPUs are farther from each other than others.

## Key Novelty
Synchronizing GPUs only at epoch boundaries instead of after every training step reduces training time by 95%.
