# FACAM: Design and Optimization of A Compact Energy Efficient FeFET-Based Analog Content Addressable Memory

**Venue:** ICCAD  
**ID:** iccad-2025-009

## Problem
Existing CAM designs focus on discrete binary/multi-bit values; analog CAMs for continuous value search are rare, limiting density and energy efficiency.

## Motivation
Analog CAMs enable higher density associative search for applications requiring continuous values, with FeFET technology offering compact and efficient implementation.

## Method
FACAM searches for analog values (continuous numbers rather than binary patterns) using a two-phase process. Each memory cell contains two ferroelectric transistors (FeFETs—transistors that use a ferroelectric layer to store and switch between states) and one regular transistor; the FeFETs are programmed to define both the center point and width of the matching range. During the search, the matchline (the signal that reports whether a match occurred) is prepared and checked simultaneously in the cell, improving efficiency. An adaptive scheme can stop the second search phase early if the result is already confident, which saves energy.

## Key Novelty
A compact analog-search cell using ferroelectric transistors, with a two-phase search method that can terminate early to reduce energy use.

## Contributions
1. Single-input 2FeFET-1T ACAM cell with configurable matching range
2. Two-phase search scheme improving energy efficiency
3. Matchline voltage swing reduction via in-cell search integration
4. Adaptive early-termination for further energy optimization
