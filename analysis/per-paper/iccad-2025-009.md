# FACAM: Design and Optimization of A Compact Energy Efficient FeFET-Based Analog Content Addressable Memory

**Venue:** ICCAD  
**ID:** iccad-2025-009

## Problem
Existing CAM designs focus on discrete binary/multi-bit values; analog CAMs for continuous value search are rare, limiting density and energy efficiency.

## Motivation
Analog CAMs enable higher density associative search for applications requiring continuous values, with FeFET technology offering compact and efficient implementation.

## Method
FACAM uses two-phase search with 2FeFET-1T cell: FeFETs set matching range location and width. Matchline precharging integrated into in-cell search. Adaptive scheme early-terminates second phase for energy savings.

## Key Novelty
Compact FeFET-based analog CAM cell with two-phase search mechanism and adaptive early-termination for energy efficiency.

## Contributions
1. Single-input 2FeFET-1T ACAM cell with configurable matching range
2. Two-phase search scheme improving energy efficiency
3. Matchline voltage swing reduction via in-cell search integration
4. Adaptive early-termination for further energy optimization
