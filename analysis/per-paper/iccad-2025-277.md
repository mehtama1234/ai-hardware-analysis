# Open3DFlow: An Open-Source EDA Platform for 3D Chip Design with AI Enhancement

**Venue:** ICCAD  
**ID:** iccad-2025-277

## Problem
The absence of specialized electronic design automation (EDA) tools and standardized design flows for 3D chiplets remains a critical barrier to scalable 3D IC design.

## Motivation
To provide an open-source EDA platform for 3D IC design that integrates multi-physics analysis and enables AI-enhanced design automation.

## Method
The tool runs a seven-step design workflow for 3D chips that simulates the physics of vertically stacked silicon: thermal behavior, signal integrity (electrical signal propagation), and through-silicon vias (the tiny holes connecting layers). Language models automate bonding pad placement and script generation for the design tools, and the platform enables face-to-face layer coupling using a custom bonding approach, as demonstrated on a 3D RISC-V CPU with stacked memory built in the GF180 manufacturing process.

## Key Novelty
The platform is an open-source tool for designing 3D stacked chips that combines language model automation for design decisions with complete physics simulation to verify the design works.

## Contributions
- Comprehensive 7-step 3D IC design workflow with TSV, thermal, and SI modeling
- Implementation demonstrating 3D RISC-V CPU with stacked L2 cache in GF180
- LLM-enabled automation for bonding pad placement and script generation
- Open-source framework enabling AI integration and cross-domain design co-optimization
