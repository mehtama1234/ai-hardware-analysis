# Hummingbird: A Smaller and Faster Large Language Model Accelerator on Embedded FPGA

**Venue:** ICCAD  
**Confidence:** low

## Problem
Deploying LLMs on embedded FPGAs faces severe constraints: limited on-chip/off-chip memory (4GB barrier), high resource consumption, and insufficient prior exploration of embedded FPGA potential for LLM inference compared to cloud-grade FPGA solutions.

## Motivation
Edge deployment of LLMs is critical for privacy, latency, and cost optimization; existing solutions require expensive cloud-grade hardware and support only small models.

## Method
Hummingbird employs memory-offloading strategies to overcome 4GB embedded FPGA memory constraints and scales to 8B-parameter LLMs. The design optimizes DSP/LUT/power utilization through architecture refinement targeting KV260/ZCU104 embedded FPGAs, achieving 93-94% model bandwidth utilization.

## Key Novelty
First practical FPGA accelerator supporting LLaMA3-8B inference on resource-constrained embedded FPGAs through intelligent memory offloading.

## Contributions
- 67% LUT, 39% DSP, 42% power savings vs. existing embedded FPGA LLM accelerators
- 4.8 tokens/s on KV260, 8.6 tokens/s on ZCU104 for LLaMA3-8B
- 93-94% model bandwidth utilization vs. 84% baseline
- Extended context support through memory offloading strategy
