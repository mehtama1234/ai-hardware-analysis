# Utilizing Sparsity in the GPU-accelerated Assembly of Schur Complement Matrices in Domain Decomposition Methods

**Venue:** SC 2025  
**Authors:** Jakub Homola, Ondrej Meca, Lubomír Říha, Tomáš Brzobohatý

## Problem
Domain decomposition methods require explicit Schur complement matrix assembly, which incurs significant overhead in GPU acceleration approaches. While previous work demonstrated GPU assembly reduces this overhead, potential optimizations using matrix sparsity patterns remain unexploited.

## Motivation
Domain decomposition methods scale effectively on supercomputers for large engineering problems. However, explicit dense Schur complement assembly on GPUs adds significant overhead, undermining acceleration benefits. Many application domains produce sparse Schur complements; exploiting this structure could further improve performance.

## Method
The approach assembles Schur complement matrices—matrices that capture how sub-problems interact when a large problem is decomposed into smaller pieces—directly on the GPU to avoid expensive data transfers to the CPU. It systematically exploits sparsity, meaning it only computes and stores the non-zero elements of these matrices, thereby reducing both memory usage and computation time. This strategy is applied to FETI (Finite Element Tearing and Interconnecting), a technique for solving large engineering problems by dividing them into smaller interconnected sub-domains.

## Key Novelty
Systematically exploiting sparsity—the prevalence of zero values—when assembling Schur complement matrices on the GPU delivers significant speedup compared to treating these matrices as entirely dense.

## Contributions
1. Sparsity-aware GPU assembly algorithm for Schur complement matrices
2. 5.1x speedup in GPU computation, 3.3x overall assembly speedup
3. Reduced overhead enabling GPU acceleration to be beneficial from 10+ iterations onward
4. Practical demonstration on FETI with subdomains up to 70,000 unknowns
