# SolFS: An Operation-Log Versioning File System for Hash-free Efficient Mobile Cloud Backup

**Problem:** Cloud backup on resource-limited mobile devices consumes excessive CPU for delta synchronization because identifying modified data ranges requires intensive hash computation across entire files.

**Method:** SolFS records which parts of files get written to—specifically their position and size in data structures called per-file extent trees—instead of computing expensive hash values on entire files. It permanently stores these operation logs and versions them so multiple apps can share the same backup system. To keep overhead minimal, it compresses the logs and adjusts how finely it tracks operations (this dynamic granularity adapts to the situation). On the server, shadow files are quickly reconstructed from these operation records.

**Novelty:** It identifies changed data without computing hashes by recording write operations at the filesystem level.
