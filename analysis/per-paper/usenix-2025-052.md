# SolFS: An Operation-Log Versioning File System for Hash-free Efficient Mobile Cloud Backup

**Problem:** Cloud backup on resource-limited mobile devices consumes excessive CPU for delta synchronization because identifying modified data ranges requires intensive hash computation across entire files.

**Method:** SolFS tracks write operation logs (offset and length) in per-file extent trees to identify changed data without hashing. It implements operation log persistence and versioning for multi-application support, uses compact logs and dynamic granularity for overhead reduction, and deploys server-side shadow files to accelerate file reconstruction.

**Novelty:** Hash-free delta identification by recording write operation metadata at the filesystem level rather than computing file content hashes.
