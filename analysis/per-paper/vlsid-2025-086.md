# Optimal Respiratory Rate Estimation with mmWave Sensing Using PYNQ System-on-Chip Platform

**VLSID 2025** | vlsid-2025-086

## Abstract
Non-invasive respiratory rate monitoring via mmWave on portable embedded systems enables continuous health monitoring for IoT/wearable applications. This work implements optimized range and RR estimation on PYNQ platform. Signal processing: RFFT, phase extraction/unwrapping, FIR filtering, multiple RR estimation methods with optimal weighted combination (quadratic cost function). Results: ~199.2% range accuracy, ~194.5% RR accuracy. Portable embedded deployment ready.

## Problem
- Continuous respiratory monitoring requires non-invasive, portable solutions
- mmWave sensors compact and power-efficient but require embedded signal processing
- Accuracy and real-time performance trade-offs in resource-constrained systems

## Key Insight
Ensemble RR estimation combining multiple algorithms with optimal weighting achieves superior accuracy vs. single-method approaches on embedded platforms.

## Approach
1. mmWave sensor data acquisition on PYNQ
2. Range Fast Fourier Transform (RFFT) for distance estimation
3. Phase extraction and unwrapping for motion detection
4. FIR filtering for noise reduction
5. Multiple RR estimation techniques in parallel
6. Optimal weighted combination via quadratic cost function

## Implementation
- **Platform**: PYNQ (Zynq embedded SoC)
- **Sensor**: mmWave radar
- **Target**: Portable wearable/IoT deployment
