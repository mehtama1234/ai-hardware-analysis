# Building Bridges: Safe Interactions with Foreign Languages through Omniglot

**Problem:** Programming systems need to safely interoperate across multiple programming languages, but current foreign function interfaces (FFI) lack robust safety guarantees and can introduce security vulnerabilities or runtime errors at language boundaries.

**Method:** Omniglot acts as a controlled translator when one programming language calls code written in another. It automatically converts data from one language's format to another's (a process called marshalling) and ensures data types match exactly across the language boundary (type checking). It enforces these checks either at runtime (while the code runs) or through static analysis (checking before the code runs), preventing the security and correctness problems that commonly occur when languages interact at their boundaries.

**Novelty:** Omniglot provides safe cross-language function calls by automatically converting and type-checking data at language boundaries to prevent the common vulnerabilities that occur there.
