# Advancing Neural Network Performance with Probabilistic Computing for ReLU Function

**VLSID 2025** | vlsid-2025-088

## Abstract
Probabilistic computing using p-bits (stochastic bits) enables invertible bidirectional operations for novel neural network training and inference approaches. This work presents framework for designing p-circuits and robust ReLU implementations using Hamiltonian method. Two variants: AND gate-based and non-imply gate-based (fewer p-bits). 10-bit ReLU: 20 p-bits (10 in/10 out). 5-bit ReLU graph density: 0.26 vs. 0.45 best existing (42% improvement). Simulations confirm invertible p-circuit design.

## Problem
- ReLU activation function crucial for deep learning but traditional implementations consume significant energy
- Probabilistic computing offers invertible operations but ReLU design unexplored
- Efficient p-circuit ReLU enables probabilistic neural network acceleration

## Key Insight
Hamiltonian-based p-circuit design enables ReLU implementation with invertible properties; non-imply logic gates reduce p-bit overhead vs. AND-based approaches.

## Approach
1. P-bit framework for circuit design (stochastic bit representations)
2. Hamiltonian method for p-circuit synthesis
3. Two ReLU design approaches:
   - AND gate-based (simpler logic)
   - Non-imply gate-based (fewer p-bits)
4. Supporting circuits: 2×1 multiplexer, AB non-imply gate
5. Graph density and invertibility optimization
