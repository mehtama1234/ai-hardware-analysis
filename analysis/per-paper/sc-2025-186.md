# SC-2025-186: xGFabric

**Venue:** SC 2025  
**Authors:** Liubov Kurafeeva, Alan Subedi, Ryan Hartung, Michael Fay, Avhishek Biswas, Shantenu Jha, Ozgur O. Kilic, Chandra Krintz  
**Confidence:** low (abstract only)

## Summary

End-to-end system (xGFabric) coupling distributed sensor networks with HPC facilities using Private 5G networks for real-time digital agriculture applications with near-real-time feedback loops.

## Hardware Target

- HPC Facilities
- Sensor Networks
- 5G Infrastructure

## Problem & Motivation

Advanced scientific applications require tight coupling between distributed sensor networks and centralized HPC systems. Traditional approaches face mismatch: sensor networks provide low-performance, limited-capacity, unreliable data; HPC offers enormous compute power but through high-latency batch processing. Private 5G networks offer low latency, high throughput, and reliability enabling near-real-time coupling.

## Approach

xGFabric architecture:
1. Remote sensor network instrumentation (environmental monitoring)
2. Private 5G network slicing for low-latency transport
3. HPC facility integration for real-time simulation
4. Closed-loop control for interventions (water application, robotic repairs)

Case study: Citrus Under Protective Screening (CUPS) with CFD simulation.

## Key Contributions

1. Novel xGFabric architecture for edge-to-HPC integration
2. Private 5G network slicing enabling real-time transport
3. End-to-end prototype system demonstration
4. Real-time agricultural intervention capability
5. Near-real-time feedback coupling model

## Limitations

Specific latency/throughput metrics not provided; comparison with batch-processing systems lacking.
