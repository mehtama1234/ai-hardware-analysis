# Tenpura: A General Transient Fault Evaluation and Scope Narrowing Platform for Ultra-fast Reliability Analysis

**Venue:** ICCAD  
**ID:** iccad-2025-029

## Problem
Simulation-based fault injection for reliability analysis is impractically slow (months to years for large designs); most transient faults are harmless, creating inefficiency.

## Motivation
Reliability analysis pre-deployment requires efficient fault evaluation for critical systems.

## Method
FPGA emulation with scan-based activity tracing for transient fault scope narrowing; pre-silicon fault injection targeting only potentially critical faults.

## Key Novelty
Scan-based transient fault scope narrowing method enabling ultra-fast pre-silicon fault injection.

## Contributions
- Transient fault scope narrowing via scan-based activity tracing
- FPGA emulation acceleration for fault injection
- 88.49-96.26% fault reduction across multiple designs
- One month analysis vs months-to-years for simulation-based FI
