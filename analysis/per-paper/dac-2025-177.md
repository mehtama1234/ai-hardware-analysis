# Espresso: Exploiting the Sparsity Property in Event Sensors with Spatiotemporal Ordering

**Problem:** Event camera streams are sparse, but efficient processing without materializing dense representations is challenging.

**Solution:** FPGA architecture using spatiotemporal ordering to maintain sparsity throughout event stream processing.

**Results:** 5000 fps, 5.1x speedup vs. embedded GPU.

**Theme:** Sparse neuromorphic sensing via FPGA acceleration.
