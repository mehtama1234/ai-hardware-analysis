# Mixed-Precision Performance Portability of FFT-Based GPU-Accelerated Algorithms for Block-Triangular Toeplitz Matrices

**ID**: sc-2025-374
**Venue**: SC
**Confidence**: low

## Problem
Performance portability across GPU architectures with mixed-precision requirements

## Motivation
CUDA-only code limits deployment; HIP enables portability

## Method
HIP is a framework that lets the same GPU code run on different hardware vendors (NVIDIA, AMD, etc.) instead of being locked to one brand. The researchers rewrote GPU operations originally optimized for CUDA (NVIDIA's framework) to use HIP instead. They incorporated mixed precision—strategically combining different numeric precision levels (like 32-bit and 16-bit floating point) to balance speed and accuracy. They then tested these operations across different GPU architectures to verify that porting to HIP actually preserves performance.

## Key Novelty
CUDA graph kernels maintain efficient performance across different GPU vendors when ported to HIP with mixed precision.
