# isscc-2025-092: Command-Aware Hybrid LDO for HBM

## Summary
Command-aware LDO achieving sub-10mV voltage droop in 400ps settling time for HBM3E/HBM4 interfaces with minimal on-chip capacitance (20pF) and 150μA quiescent current.

## Key Contributions
- Command-aware hybrid LDO design
- Sub-10mV voltage droop mitigation
- Minimal capacitor footprint (20pF)
- Fast settling (400ps) for WDQS jitter reduction
