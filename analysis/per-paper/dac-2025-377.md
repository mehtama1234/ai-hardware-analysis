# MetaDSE: A Few-shot Meta-learning Framework for Cross-workload CPU Design Space Exploration

**Venue:** DAC
**ID:** dac-2025-377

## Problem
Cross-workload CPU design space exploration suffers from overfitting, data ambiguity, and workload dissimilarity when leveraging transfer learning.

## Motivation
Existing DSE methods require extensive target workload simulation; meta-learning can enable rapid adaptation to new workloads with minimal data.

## Method
MetaDSE reframes cross-workload CPU DSE as a few-shot meta-learning problem using model-agnostic meta-learning (MAML). It introduces a workload-adaptive architectural mask algorithm to uncover inherent architectural properties across diverse workloads.

## Key Novelty
Application of few-shot meta-learning with workload-adaptive architectural masking to enable rapid DSE adaptation across diverse CPU workloads.

## Contributions
1. Reformulation of CPU DSE as few-shot meta-learning problem to overcome overfitting and data ambiguity
2. Workload-adaptive architectural mask algorithm uncovering inherent architecture properties
3. 44.3% reduction in prediction error compared to state-of-the-art transfer learning methods
4. Open-sourced framework enabling efficient cross-workload exploration
