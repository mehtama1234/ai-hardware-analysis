# Hopps: Leveraging Sparsity to Accelerate Automata Processing

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-039  
**Confidence:** low (abstract only)

## Problem
Automata processing (AP) workloads execute many finite state machines (FSMs) in parallel over streaming symbol data, but existing AP accelerators suffer poor utilization because most FSMs are inactive for any given input symbol. The irregular, state-dependent activation pattern makes it hard to exploit spatial parallelism efficiently.

## Motivation
Pattern matching against large rule sets (e.g., network intrusion detection, genomics scanning) demands high-throughput AP, but the inherent sparsity of active FSM transitions wastes memory bandwidth and compute cycles in existing DRAM- and SRAM-based AP engines.

## Method
Hopps exploits cross-FSM sparsity by tracking only active states across all FSMs via a compressed activation bitmap, skipping idle FSMs entirely during each symbol step. Tiled SRAM storage allows burst fetching of state-transition tables for active FSMs only, reducing off-chip memory traffic proportional to the active-FSM fraction.

## Key Novelty
First AP accelerator to exploit cross-FSM input-driven sparsity at runtime using activation bitmaps to skip inactive automata entirely.

## Contributions
- Characterization of sparsity in AP workloads showing low active-FSM fraction per symbol step.
- A sparsity-aware hardware architecture using activation bitmaps to skip inactive FSMs and reduce memory traffic.
- Evaluation showing speedup and energy reduction over prior AP accelerators.
