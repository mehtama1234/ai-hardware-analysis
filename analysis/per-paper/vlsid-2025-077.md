# Precision Clock Generation with Reference Clock Loss Tolerant Dynamic Tuning to Enable Crystal Less SSD

**VLSID 2025** | vlsid-2025-077

## Abstract
SSD controllers require high-speed accurate clocks for PCIe and NAND communication. By eliminating the crystal oscillator (XTAL) via a novel clock multiplexer switching between host-provided and internal relaxation oscillator clocks, PCB cost and complexity reduce. The PLL maintains maximum accuracy during data transfer and gracefully degrades for backend completion.

## Problem
- Crystal oscillators add BOM cost and PCB complexity to SSD controllers
- Host clock may disable before NAND transfer completes
- Need fallback precision clock without external component

## Key Insight
Autonomous dynamic clock selection between host and internal oscillator enables crystal-free operation with seamless transitions and no external control signals.

## Approach
1. Multiplexer selects between host PCIe clock and internal relaxation oscillator
2. Control logic ensures continuous availability
3. Seamless switching without frequency glitch
4. PLL accuracy scales: high during transfer, adequate for backend

## Implementation
- **Technology**: TSMC 7nm
- **Core area**: 0.036 mm²
- **Status**: Validated in lab

## Contributions

- Glitch-free autonomous clock selection
- Practical SSD controller cost reduction
