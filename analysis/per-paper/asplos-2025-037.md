# H-Houdini: Scalable Invariant Learning

**ID:** asplos-2025-037  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Scalable invariant learning for large hardware formal verification

## Problem
Formal hardware verification via invariant learning (e.g., IC3/PDR) does not scale to large hardware designs because the invariant search space grows exponentially with state size, causing state-of-the-art tools to time out on real-world RTL designs.

## Motivation
Hardware bugs discovered post-silicon are extremely costly; formal verification offers correctness guarantees but is limited to small designs, leaving the majority of modern processor and SoC designs unverified by automated techniques.

## Method
H-Houdini speeds up finding invariants—properties that always stay true in a hardware design—by breaking the problem into smaller pieces. Instead of searching for invariants across the entire design at once (which becomes impossible as designs get larger), it breaks the hardware into sub-modules, learns invariants for each piece separately, and reuses those invariants when checking the whole system. This hierarchical approach avoids having to explore every possible state combination, which would grow exponentially with design size.

## Key Novelty
H-Houdini enables formal verification of large hardware designs that previously couldn't be verified due to computational complexity.

## Contributions
- Scalable invariant learning methodology for large-scale RTL hardware designs.
- Advancement of formal verification automation beyond small-design limits.
- Empirical demonstration of scalability to hardware designs that defeat prior tools.
