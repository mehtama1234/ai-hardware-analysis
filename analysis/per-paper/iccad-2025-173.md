# TREX-F: TRustability of Electronics using X-ray based Fingerprinting

**Authors:** Tishya Sarma Sarkar, Shuvodip Maitra, Abhishek Chakraborty 0001, Sarani Bhattacharya, Debdeep Mukhopadhyay

**Venue:** ICCAD

## Summary
TREX-F uses X-ray imaging and computer vision to extract unique physical fingerprints from PCBs for authentication, preventing counterfeit boards in the electronics supply chain.

## Key Contributions
- X-ray imaging-based PCB fingerprint extraction using anomaly detection
- Computer vision-based feature extraction (Canny, contour, PCA, SIFT)
- QR and data-matrix code generation for quick authentication
- ~95% average authentication accuracy with ~0.1% false acceptance rate
