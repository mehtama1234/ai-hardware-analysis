# Implementing Network-level QoS at HPC Datacenters to Enable Distributed Scientific Workflows

**Venue:** SC | **ID:** sc-2025-115

## Summary
DSCP-based Quality of Service implementation on existing HPC datacenter leaf-spine networks, providing end-to-end performance guarantees for mixed real-time and bulk data workloads.

## Problem & Motivation
HPC datacenters face conflicting network demands: real-time scientific workflows need sub-millisecond latency, while bulk data transfers require sustained multi-gigabit throughput. Local network ingress remains best-effort, accumulating latency and jitter that jeopardizes time-sensitive applications. Wide-area networks (ESnet) already enforce QoS, but the local "last-mile" gap creates a blind spot.

## Key Findings
- **Throughput stability:** 60% improvement over best-effort baseline
- **Retransmission rate:** 30% reduction
- **Jitter:** Tightly bounded (deterministic behavior)
- **Deployment:** Non-disruptive installation on operational infrastructure
- **Coverage:** End-to-end from host through leaf-spine to HSN gateway

## Hardware & Systems
- **Network equipment:** Existing leaf-spine Ethernet switches (no upgrades)
- **Deployment:** Local datacenter ingress to HSN gateway
- **Packet marking:** Host-based DSCP per RFC 2474
- **Shaping:** Queuing and rate control on every last-mile hop

## Techniques
- **Differentiated Services Code Point (DSCP):** RFC 2474 traffic classification
- **Per-class queuing:** Separate queues for real-time vs. bulk traffic
- **Last-mile shaping:** Rate limiting on HSN gateway NIC
- **Policy-driven:** Standards-based (no proprietary protocols)

1. **Intra-domain:** Server-to-server flows within datacenter
2. **Inter-domain:** Instrument LAN → WAN → HPC ingress

## Contributions
1. First DSCP-based QoS at HPC datacenter local network edge
2. End-to-end performance guarantees without hardware changes
3. Demonstrated viability for real-time scientific workflows
4. Standards-based deployable on operational systems
5. Bridge between WAN QoS (ESnet) and local datacenter networks

## Limitations
- DSCP compliance not guaranteed across all equipment
- Requires coordination with WAN providers
- Effectiveness dependent on proper traffic classification
- Limited to specific traffic classes (may not suit all workloads)
- Real-world deployment complications not detailed
