# SBQ: Exploiting Significant Bits for Efficient and Accurate Post-Training DNN Quantization

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Achieve accurate 2-4 bit quantization via algorithm-architecture co-design: dynamically extract significant bit terms from high-precision operands and perform error-compensated computation to minimize quantization errors.

## Problem
Conventional 2-4 bit post-training quantization degrades accuracy due to clipping and rounding errors; especially challenging for LLM attention mechanisms.

## Method
SBQ enables extreme low-precision quantization (2-4 bits) without accuracy loss by extracting only significant bits—the most critical bits—from high-precision operands. A product-aware method identifies which bits matter by examining multiplication results. Error-compensated computation mathematically corrects for the discarded bits, and a custom inference engine efficiently implements this on hardware.

## Key Results
- Outperforms prior PTQ methods at 2-4 bit quantization on **CNNs, ViTs, and LLMs**
- **Highest area and energy efficiency** vs TQ and Sibia
