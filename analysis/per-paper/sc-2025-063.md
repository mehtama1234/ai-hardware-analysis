# PEAK: Cost-Adaptive Profiling in a Heartbeat

**ID:** sc-2025-063 | **Venue:** SC

## Problem Statement
Static instrumentation profiling imposes fixed overhead that cannot adapt to dynamic workload characteristics

## Motivation
HPC and cloud applications have dynamic workloads requiring adaptive profiling; static approaches create bottlenecks in monitoring long-running applications

## Method
PEAK uses Dynamic Binary Instrumentation—inserting measurement code into a running program—to profile its performance. Static mode caps overhead at a fixed amount. Heartbeat mode dynamically adjusts how much measuring happens using regular timing pulses, maintaining the user-specified overhead ratio in real-time.

## Key Novelty
The core novelty is heartbeat-based dynamic adjustment that maintains a constant overhead ratio in real-time, enabling better profiling accuracy for changing workloads.

## Contributions
- Two-mode DBI profiler (static/dynamic)
- Heartbeat mechanism for overhead control
- Improved profile accuracy for dynamic workloads
