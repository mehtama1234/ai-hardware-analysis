# dac-2025-424: Circuit-Free Power Side-Channel Attack on ARM-FPGA SoCs

**Problem:** FPGA side-channel attacks require co-resident crafted circuits and shared power networks; impractical in real cloud scenarios.

**Motivation:** FPGA multi-tenancy in cloud exposes shared power delivery; removing attack assumptions is critical for real security assessment.

**Method:** AmpereBleed exploits INA226 current sensors—measurement devices built into ARM-FPGA SoCs (chips combining ARM processors and programmable logic on one die)—in a power side-channel attack (stealing secrets by observing electrical usage patterns). By reading what these sensors measure, attackers can fingerprint (identify by their unique electrical signatures) what encryption and machine-learning programs are executing, then exploit that knowledge to extract their secrets. Unlike earlier power side-channel attacks, this one doesn't require planting malicious circuits on the chip first; it uses only sensors the manufacturer already included.

**Key Novelty:** Circuit-free power side-channel attack using only on-chip current sensors.

**Contributions:**
- AmpereBleed attack with 261x signal variation vs ring oscillators
- 99.7% DNN fingerprinting accuracy on Xilinx DPU
- RSA-1024 key Hamming weight extraction

**Hardware Target:** FPGA, SoC

**Workloads:** DNN, cryptography

**Confidence:** low (abstract-only)
