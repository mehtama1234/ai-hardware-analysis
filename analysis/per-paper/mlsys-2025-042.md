# Self-Data Distillation for Recovering Quality in Pruned Large Language Models

**ID:** mlsys-2025-042 | **Venue:** MLSYS 2025

## Problem
Structured depth pruning of LLMs removes decoder blocks and reduces compute, but post-pruning SFT causes catastrophic forgetting by shifting the data distribution away from the original model's knowledge.

## Method
The method identifies redundant layers by measuring angular cosine distance (how similar the outputs from adjacent layers are in their directional orientation) — the most similar outputs mark the best layers to remove. The original unpruned model regenerates the training dataset by creating high-quality responses that preserve semantic meaning, while selectively keeping original responses for prompts where the pruned model already performs well. The pruned model and the version trained on these regenerated responses are merged using SLERP merging (spherical linear interpolation, which blends model weights along the shortest path), and the pruned model can also function as a draft generator in speculative decoding paired with the full model as verifier.

## Key Novelty
Using the unpruned model to regenerate a semantically-aligned fine-tuning dataset prevents catastrophic forgetting in depth-pruned models, while also enabling SLERP model merging (a method to blend two model versions) and speculative decoding.

## Results
- **91.24%** accuracy retention at block size 6 vs **81.66%** for standard SFT (Llama3.1-8B)
- **+1.70** average accepted token length improvement in speculative decoding at block size 10
- **16.30%** real-world FLOPs reduction (32→26 layers, 8.03B→6.72B parameters)

## Hardware Target
GPU inference (A100-class); edge deployment of pruned models
