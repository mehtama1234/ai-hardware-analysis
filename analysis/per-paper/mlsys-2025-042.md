# Self-Data Distillation for Recovering Quality in Pruned Large Language Models

**ID:** mlsys-2025-042 | **Venue:** MLSYS 2025

## Problem
Structured depth pruning of LLMs removes decoder blocks and reduces compute, but post-pruning SFT causes catastrophic forgetting by shifting the data distribution away from the original model's knowledge.

## Method
Angular cosine distance between adjacent block outputs identifies the most redundant layers for pruning (lowest angular distance = most similar = best to remove). The unpruned model then rewrites the fine-tuning dataset, generating distilled responses that preserve semantic richness. Conditional selection keeps original responses where the pruned model already performs adequately. SLERP merging blends checkpoints. The pruned model also serves as a speculative decoding draft.

## Key Novelty
Using the unpruned model to regenerate a semantically-aligned distillation dataset for post-pruning SFT, preventing catastrophic forgetting while preserving efficiency gains of depth pruning.

## Results
- **91.24%** accuracy retention at block size 6 vs **81.66%** for standard SFT (Llama3.1-8B)
- **+1.70** average accepted token length improvement in speculative decoding at block size 10
- **16.30%** real-world FLOPs reduction (32→26 layers, 8.03B→6.72B parameters)

## Hardware Target
GPU inference (A100-class); edge deployment of pruned models
