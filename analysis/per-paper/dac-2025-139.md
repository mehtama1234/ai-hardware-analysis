# Query-Based Black-Box Stealthy Sensor Attacks on CPS

## Problem
Designing stealthy sensor attacks on cyber-physical systems under black-box conditions (minimal knowledge of target system) requires maintaining attack stealthiness both in output (avoiding detector alerts) and during attack generation (limiting detector queries).

## Method
The method uses active learning (strategically selecting the most informative queries to understand the detector's behavior) to probe a security detector while maintaining stealth through adaptive query budgeting (limiting the total number of queries to avoid triggering alarms). It builds a time series model (a mathematical pattern of how sensor readings normally evolve) from the extracted information, then generates attack sequences from this model that remain hidden within normal-looking sensor behavior.

## Key Results
- Effective on 4 numerical simulations and high-fidelity simulator
- Maintains stealthiness throughout attack generation
- Demonstrates vulnerability of black-box CPS to adversarial sensor attacks
