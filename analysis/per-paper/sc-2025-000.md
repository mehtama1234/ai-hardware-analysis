# A Cache Interaction Graph for Data Locality Optimization

**Venue:** SC
**Paper ID:** sc-2025-000
**Confidence:** low

## Problem Statement
Cache efficiency optimization and root-cause diagnosis of cache inefficiencies in programs is difficult due to complex interactions between data access patterns and cache hierarchy

## Motivation
Performance gap between CPUs and memory systems is critical; existing profiling tools identify bottlenecks but don't diagnose root causes

## Method
Track cache line evictions; measure temporal and spatial locality; classify cache miss types; visualize via Cache Interaction Graph; extend Cachegrind for variable-level analysis

## Key Novelty
Cache Interaction Graph visualization correlating miss patterns with data access interactions to identify root causes and guide optimizations

## Contributions
- Novel Cache Interaction Graph visualization technique
- Variable-level data locality analysis with cache miss classification
- Cachegrind extension for practical deployment
- Effective root-cause diagnosis methodology for cache inefficiencies
