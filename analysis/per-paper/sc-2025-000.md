# A Cache Interaction Graph for Data Locality Optimization

**Venue:** SC
**Paper ID:** sc-2025-000
**Confidence:** low

## Problem Statement
Cache efficiency optimization and root-cause diagnosis of cache inefficiencies in programs is difficult due to complex interactions between data access patterns and cache hierarchy

## Motivation
Performance gap between CPUs and memory systems is critical; existing profiling tools identify bottlenecks but don't diagnose root causes

## Method
The approach works by tracking when data gets evicted (pushed out) from the cache and measuring how often the program reuses the same data (temporal locality) or accesses nearby memory locations together (spatial locality). It categorizes each cache miss—a failed lookup—by its root cause, whether the data was evicted too soon or accessed in a pattern mismatched to the cache structure. It then visualizes these interactions in a Cache Interaction Graph diagram and extends Cachegrind (an existing memory profiler) to analyze this down to individual variables.

## Key Novelty
The Cache Interaction Graph visualizes which pieces of data compete with each other in the cache, revealing the root cause of performance slowdowns.
