# Live Region Mutation Testing for Commercial Cyber-Physical System Development Tool Chain

**Problem:** Simulink compiler bugs cause unexpected behaviors; existing testing methods lack data-flow equivalence preservation and diverse block coverage.

**Method:** LION tests the Simulink compiler using differential testing—running the same model across different Simulink versions and comparing results to find bugs. It inserts 'store-revert' block pairs (blocks that save and immediately restore state) between existing blocks to preserve the model's data flow. It then uses MCMC sampling (a statistical method that explores many possible block combinations) to generate diverse test cases, ensuring comprehensive compiler testing.

**Key Result:** Detected 610 additional bugs vs SOTA; reported 16 valid bugs in stable Simulink version within two months.
