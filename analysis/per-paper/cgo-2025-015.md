# Towards Efficient Compiler Auto-tuning: Leveraging Synergistic Search Spaces

**ID:** cgo-2025-033  
**Venue:** CGO  
**Authors:** Haolin Pan, Yuanyu Wei, Mingjie Xing, Yanjun Wu, Chen Zhao

## Core Problem
Traditional compiler auto-tuning (iterative compilation, ML-based methods) suffers from exponential search spaces and poor generalization to new programs, making per-program optimization prohibitively expensive.

## Key Insight
Compiler optimization passes exhibit **synergistic relationships**—certain pass pairs jointly optimize code in predictable ways. By clustering these patterns into coresets and training an ML model to predict optimal coresets for new programs, the method dramatically reduces search cost.

## Method
1. **Synergy Discovery**: Identify chained pass pairs that jointly optimize a specific metric (IR size, code size) across benchmark programs
2. **Coreset Formation**: Use K-means clustering to group common optimization patterns; form these into reusable coresets
3. **ML Prediction**: Train supervised model to predict best coreset for new programs
4. **Guided Search**: Apply integrated search strategies (e.g., local search) to converge quickly within predicted coreset

## Results
- **7.5% IR instruction reduction** vs. LLVM -Oz baseline across 10 benchmarks (MiBench, CBench, NPB, CHStone)
- **13.9% code size reduction** with simple 5-second search vs. -Oz
- Outperforms existing search-based techniques in initial pass-space exploration

## Hardware & Scope
- CPU-only; compiler-level pass sequencing
- No GPU/accelerator consideration
