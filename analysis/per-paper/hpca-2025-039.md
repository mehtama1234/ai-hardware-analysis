# SparseWeaver: Converting Sparse Operations as Dense Operations on GPUs for Graph Workloads

**Venue:** HPCA 2025  
**Authors:** Shinnung Jeong, Liam Paul Cooper, Ju Min Lee, Heelim Choi, Nicholas Parnenzini, Chihyo Ahn, Yongwoo Lee, Hanjun Kim

## Problem
Real-world graph workloads have sparse and skewed adjacency structures that cause severe warp-level load imbalance on GPUs, where existing software or hardware balancing schemes incur memory overhead or excessive inter- and intra-warp synchronization cost.

## Motivation
GPUs are the dominant platform for large-scale graph analytics, but irregular graph topology makes efficient SIMT utilization nearly impossible without costly runtime rebalancing.

## Method
SparseWeaver is a hardware-software co-design that converts sparse graph operations into balanced dense operations by exploiting graph topology. A lightweight GPU functional unit called Weaver is added to GPU cores; it implements sparse-to-dense conversion directly in the execution pipeline by exploiting memory access locality without additional synchronization overhead. Prototyped on the open-source RISC-V Vortex GPU.

## Key Novelty
Converting sparse graph operations to dense ones at the hardware level via a dedicated Weaver functional unit that exploits topology-driven patterns, eliminating the memory and synchronization overhead of prior software balancing schemes.

## Contributions
- Analysis of common sparse operation patterns enabling dense conversion
- Weaver lightweight functional unit microarchitecture exploiting memory access locality
- SparseWeaver hardware-software co-design framework for balanced graph processing
- 2.36x speedup with only 0.045% area overhead on RISC-V Vortex GPU

## Results
- **Speedup:** 2.36x over state-of-the-art GPU graph processing schemes
- **Area:** 0.045% overhead from added logic registers

## Hardware Target
GPU, RISC-V (Vortex prototype)

## Limitations
Evaluation on the open-source Vortex GPU simulator may not fully reflect commercial GPU microarchitecture behavior.
