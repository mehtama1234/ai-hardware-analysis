# MVQ: Towards Efficient DNN Compression and Acceleration with Masked Vector Quantization

**Venue:** ASPLOS 2025  
**Confidence:** high (full text)

## Problem
Standard vector quantization forces important high-magnitude weights to cluster alongside unimportant (near-zero) weights during k-means, causing large clustering errors on the weights that most affect accuracy. At 20-30x compression ratios this causes unacceptable accuracy loss.

## Motivation
Edge DNN deployment requires extreme compression (20-30x) to fit models on-chip, but standard VQ cannot protect the important weights governing model behavior at these ratios.

## Method
MVQ combines two complementary techniques. At the algorithm level, it removes unimportant weights using N:M structured pruning (eliminating weights in a regular, predictable pattern), then applies masked k-means clustering—which groups only important weights and ignores pruned zeros so they don't distort the cluster centers—converts to 8-bit symmetric quantization of the codebook, and refines accuracy by updating only unpruned weights during finetuning. At the hardware level, a specialized accelerator using Enhanced Weight Stationary dataflow reconstructs sparse weights dynamically from the codebook and N:M mask using a Codebook Register File and LZC-based mask decoder, and employs a systolic array (grid of processing elements) with Q=N/M × d active elements per subvector instead of the full d, reducing multiplier and register file count by 55%. The design was synthesized at 40nm using 0.99V low-threshold transistors with Synopsys Design Compiler.

## Key Novelty
Masked k-means clustering that only includes important, unpruned weights when assigning to clusters and updating their centers, preventing pruned zeros from distorting the averages so the codebook stays close to the weights that matter for accuracy.

## Contributions
- Empirical proof that clustering error on important weights (not total SSE) drives VQ accuracy loss
- Masked k-means algorithm with masked assignment and masked update steps
- Sparsity-aware EWS systolic array with Q active PEs per tile, reducing array by 55%
- Assignment-aware weight-loading controller with CRF and LZC mask decoder

## Hardware Target
ASIC (40nm 0.99V, Synopsys DC synthesis, PULP-based SoC framework)

## Technique Categories
quantization, sparsity, dataflow, circuit-design

## Workloads
CNN, vision (ImageNet classification, COCO detection, VOC segmentation)

## Metrics
- Energy efficiency: 2.3x vs EWS baseline; 1.73x vs prior sparse accelerators; 6.9 TOPS/W ResNet-18 64x64
- Array area: 55% reduction vs EWS baseline at 75% sparsity
- Speedup: 1.2-2.2x vs EWS on 64x64 array
- vs S2TA (normalized 40nm): 73% higher energy efficiency
- Accuracy: ResNet-18 68.8% @ 22x CR (+0.6% vs PQF); ResNet-50 75.2% @ 22x CR (+1.0% vs PQF)
- FLOPs reduced ~70% for large models, ~50% for lightweight models

## Baselines
EWS accelerator, WS accelerator, SparTen (MICRO19), CGNet (MICRO19), SPOTS (TACO22), S2TA (HPCA22), BGD, PQF, PvQ

## Limitations
Depthwise convolution layers do not benefit from MVQ (parameter count too small for weight-loading bottleneck); only pointwise conv results reported for lightweight models.
