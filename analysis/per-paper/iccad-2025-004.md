# SPIMA: Scalable and Cost-Efficient Sparse Matrix Multiplication via Processing in DRAM Array

**Venue:** ICCAD  
**ID:** iccad-2025-004

## Problem
Sparse matrix multiplication faces irregular memory access patterns, bandwidth bottlenecks, and load imbalance on parallel architectures.

## Motivation
Processing-in-memory approaches can mitigate memory bandwidth bottleneck while maintaining scalability across varying sparsity patterns.

## Method
SPIMA leverages DRAM PIM with novel dataflow exploiting bank-level parallelism. Multiple input buffers, output buffer, and vector registers coordinate to enable data reuse even with high sparsity. Architecture co-designed for dataflow optimization.

## Key Novelty
PIM-based SpMM accelerator with dataflow maximizing input/output reuse and bank parallelism for highly sparse matrices.

## Contributions
1. Novel SpMM dataflow exploiting high DRAM bank-level parallelism
2. Architecture with multiple input buffers enabling efficient DRAM access scheduling
3. Robust performance across varying matrix sizes and sparsity patterns
4. Competitive performance vs. ASIC/FPGA accelerators on PIM-based systems
