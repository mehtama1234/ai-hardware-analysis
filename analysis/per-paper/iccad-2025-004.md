# SPIMA: Scalable and Cost-Efficient Sparse Matrix Multiplication via Processing in DRAM Array

**Venue:** ICCAD  
**ID:** iccad-2025-004

## Problem
Sparse matrix multiplication faces irregular memory access patterns, bandwidth bottlenecks, and load imbalance on parallel architectures.

## Motivation
Processing-in-memory approaches can mitigate memory bandwidth bottleneck while maintaining scalability across varying sparsity patterns.

## Method
SPIMA places the matrix multiplication computation directly inside DRAM (the main computer memory) instead of moving data to a separate processor. The DRAM is organized into independent banks that operate in parallel, and the system uses multiple temporary storage areas (buffers and registers) positioned strategically to keep data close to where it's being used. This arrangement lets the same data be reused multiple times, which is especially valuable for sparse matrices (matrices filled mostly with zeros) where traditional approaches waste bandwidth on unused values. The entire architecture is carefully designed to optimize how data flows between these components.

## Key Novelty
SPIMA's core innovation is performing sparse matrix multiplication directly inside DRAM using multiple memory banks working in parallel, which enables efficient data reuse and avoids the bandwidth bottlenecks that normally come from processing matrices filled mostly with zeros.

## Contributions
1. Novel SpMM dataflow exploiting high DRAM bank-level parallelism
2. Architecture with multiple input buffers enabling efficient DRAM access scheduling
3. Robust performance across varying matrix sizes and sparsity patterns
4. Competitive performance vs. ASIC/FPGA accelerators on PIM-based systems
