# date-2025-021: c2c-gem5: Full System Simulation of Cache-Coherent Chip-to-Chip Interconnects

## Problem
High-Performance Computing is transitioning to chiplet-based SoC architectures, but existing simulation tools lack comprehensive support for cache-coherent multi-chip systems needed for design and optimization.

## Method
Extends the gem5 simulator with a new chip-to-chip interconnect model within the Ruby framework. The model is adaptable to various coherence protocols (e.g., Arm CHI) and calibrated with real hardware.

## Contributions
- Extended gem5 simulator with cache-coherent multi-chip support
- Adaptable to various coherence protocols (Arm CHI, etc.)
- Real hardware calibration for accuracy

## Results
Evaluated using PARSEC workloads, demonstrating accuracy in simulating coherent chip-to-chip interactions and effectiveness in capturing key performance metrics early in design flow.
