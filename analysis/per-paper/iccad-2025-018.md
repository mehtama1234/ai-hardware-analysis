# OA-LAMA: An Outlier-Adaptive LLM Inference Accelerator with Memory-Aligned Mixed-Precision Group Quantization

**Venue:** ICCAD  
**ID:** iccad-2025-018

## Problem
Activation outliers in quantized LLMs severely degrade accuracy; existing methods either misalign memory access or sacrifice quantization granularity due to non-uniform tensor distributions.

## Motivation
Efficient LLM inference deployment requires addressing the accuracy-efficiency tradeoff in low-precision quantization.

## Method
The system combines custom hardware with a compression format that keeps memory access aligned while varying precision levels by data type. It reorders activation outliers (values much larger than others) so memory fetches stay aligned, which makes access faster. It compresses different groups of data to different precision levels—finer for outliers to preserve accuracy, coarser for normal values to save space—adjusting group sizes based on how data varies across neural network layers. The hardware includes three accumulation stages designed to efficiently compute with this mixed-precision compressed data.

## Key Novelty
A compression format combining outlier reordering, memory-aligned data access, and different precision levels for different data groups.

## Contributions
- Outlier-adaptive memory-aligned mixed-precision group format with reordering technique
- Distribution-aware group allocation for inter-layer outlier variance
- Hardware architecture with three-level accumulation and timing-balanced PEs
- 1.21-3.09x performance and 1.35-2.47x energy efficiency gains over leading accelerators
