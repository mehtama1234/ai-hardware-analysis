# High-Performance and Power-Efficient Emulation of Matrix Multiplication using INT8 Matrix Engines

**ID**: sc-2025-362
**Venue**: SC
**Confidence**: low

## Problem
Efficient computation of matrix operations on modern architectures with limited precision support

## Motivation
Matrix engines offer performance boosts but lack high-precision support

## Method
Modern GPUs and accelerators have INT8 matrix engines—special-purpose hardware designed to multiply many small numbers very quickly while using minimal power. The approach emulates higher-precision matrix multiplication by breaking it down into smaller operations that these INT8 engines can handle, then combining the results back together. This works because matrix multiplication is mathematically decomposable without losing accuracy. By reusing the fastest, most efficient hardware for this decomposed computation, the approach gains significant speedup and power efficiency compared to general-purpose processors.

## Key Novelty
The core insight is that decomposing higher-precision matrix multiplication into INT8 operations lets you reuse specialized INT8 matrix engines, yielding 2-3x speedup and significant power savings.
