# MaverIQ: Fingerprint-Guided Extrapolation and Fragmentation-Aware Layering for Intent-Based LLM Serving

**Venue:** SC  
**Theme:** LLM Serving and Cost Optimization  
**Confidence:** low

## Problem Statement
Deploying LLMs optimally requires manual exploration of parallelism/compression configurations; existing solutions rely on expensive profiling and suboptimally utilize fragmented cluster resources

## Motivation
LLM serving requires balancing latency, cost, and accuracy across diverse user intents; automating configuration selection could reduce operational cost by orders of magnitude

## Methodology
Fingerprint-based extrapolation: profile small LLM proxy under few configs, analytically extrapolate to full model; fragmentation-aware layering exploits uneven layer distribution for cost optimization

## Key Novelty
First intent-based LLM serving system; combines fingerprinting with analytical extrapolation to eliminate expensive full-model profiling; novel fragmentation-aware deployment

## Contributions
- Fingerprint-based profiling reducing profiling cost 7-15x
- Analytical extrapolation from proxy to full LLM
- Fragmentation-aware layer distribution algorithm
- 3.8-8.3x operational cost reduction for provider
- Consistent user intent satisfaction across LLMs/loads
