# dac-2025-086: WRIM: Weighted Range-Constrained Ising Decoder

**Problem:** Quantum error correction decoders must balance time complexity and error detection threshold; Ising-based decoders have higher complexity than union-find but inferior threshold vs MWPM.

**Method:** The decoder uses a polygon to enclose the locations where errors were detected (called flipped syndromes), guaranteeing coverage of all possible error chains. Within this geometric boundary, it tunes the Ising model's parameters—the coupling strengths (how variables interact) and field coefficients (external biases)—through constraint-based optimization to find settings that preserve error-detection accuracy while keeping calculations manageable.

**Key Novelty:** Range-constrained Ising achieving 97.8x variable reduction, O(n) complexity superior to union-find, 10.71-11.0% threshold exceeding MWPM.
