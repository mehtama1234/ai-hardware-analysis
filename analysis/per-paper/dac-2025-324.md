# Late Breaking Results: Advanced PCB Placement with Irregular Components

## Problem
Automated PCB placement struggles with heterogeneous components having irregular geometries and complex design rules.

## Solution
Three-stage framework: global placement with Separating Axis Theorem for exact collision detection on irregular contours; multi-stage force-directed method for clearance/routability; scanline legalization for spacing.

## Impact
Improved routability over state-of-the-art PCB placement tools on complex industrial designs.
