# PIMoE: Efficient MoE Transformer Deployment on NPU-PIM System

## Summary
Addresses inefficient MoE Transformer inference via heterogeneous NPU-PIM co-design with throttle-aware task offloading and sparse data layout management.

## Key Results
- **4.5x speedup** vs A100
- **13.7x energy efficiency** vs A100
- **1.4x speedup** vs SOTA MoE platform

## Core Innovation
Throttle-aware dynamic task offloading adapts workload distribution based on real-time feedback from heterogeneous compute units, avoiding workload imbalance and data movement overhead.

## Technique
Heterogeneous system combining NPU + PIM with near-memory-controller data condenser for sparse data layout translation; workload balancing via throttle feedback.
