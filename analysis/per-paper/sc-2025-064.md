# Beyond Guess and Check: Quantifying the Fidelity of Proxy Applications

**ID:** sc-2025-064 | **Venue:** SC

## Problem Statement
No consistent method for quantifying proxy application fidelity to parent applications

## Motivation
Proxy apps essential for system design but difficult to validate; no principled way to measure how well proxies capture parent behaviors

## Method
Calder toolkit using similarity algorithms and Laplacian scores with correlation filters to identify important HPC application features

## Key Novelty
Algorithmic toolkit for quantifying proxy fidelity; identifies feature importance for proxy-parent behavior matching

## Contributions
- Calder similarity characterization toolkit
- Feature importance identification using Laplacian scores
- Validation on kernel behavior, network counters, cross-platform performance
- 75% of proxies show highly convergent behavior with parents
