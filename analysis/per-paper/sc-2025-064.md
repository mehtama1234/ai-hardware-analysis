# Beyond Guess and Check: Quantifying the Fidelity of Proxy Applications

**ID:** sc-2025-064 | **Venue:** SC

## Problem Statement
No consistent method for quantifying proxy application fidelity to parent applications

## Motivation
Proxy apps essential for system design but difficult to validate; no principled way to measure how well proxies capture parent behaviors

## Method
The Calder toolkit compares a proxy application to its parent using similarity algorithms (methods that measure behavioral similarity) and Laplacian scores (a technique for ranking feature importance). It uses correlation filters to identify which HPC application features are essential for the proxy to accurately reproduce the parent's behavior.

## Key Novelty
The toolkit enables researchers to quantify how faithfully a proxy application reproduces its parent by identifying which HPC features are essential for matching behavior.

## Contributions
- Calder similarity characterization toolkit
- Feature importance identification using Laplacian scores
- Validation on kernel behavior, network counters, cross-platform performance
- 75% of proxies show highly convergent behavior with parents
