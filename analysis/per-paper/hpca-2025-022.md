# hpca-2025-022 — eDKM: An Efficient and Accurate Train-Time Weight Clustering for Large Language Models

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Differentiable KMeans (DKM) weight clustering achieves state-of-the-art compression accuracy for LLMs but its backward-pass memory complexity makes train-time application to billion-parameter LLMs nearly impossible on standard GPU hardware.

## Motivation
Weight clustering (non-linear quantization) is natively supported on modern smartphones and offers high LLM compression ratios for on-device inference, but DKM's prohibitive training memory overhead has blocked its use at LLM scale.

## Method
Compressing a neural network by clustering weights (grouping similar weights together) requires an algorithm that saves temporary values during backpropagation (the step where weights get updated) to calculate how much each weight should change. eDKM shrinks the memory this requires in two ways: uniquification detects and removes duplicate copies of the same temporary data before offloading it to CPU storage, and sharding splits the remaining large data into smaller pieces that compress better. Together these techniques reduce memory use per decoder layer by 130x, enabling a 7B LLaMA model to be compressed to 3 bits per weight and fine-tuned on a standard GPU.

## Key Novelty
The core insight is removing duplicate copies of temporary data (uniquification) and breaking large data structures called tensors into smaller partitions (sharding) during CPU offload of the backward pass, reducing memory by 130x per decoder layer and making train-time weight clustering practical for 7B-parameter language models.

## Contributions
- Identification of DKM backward-pass tensor redundancy as the key memory barrier to LLM-scale weight clustering.
- Uniquification: deduplication of identical CPU-offloaded DKM tensors.
- Sharding: large tensor partitioning for further footprint reduction.
- 130x memory reduction; LLaMA 7B: 12.6 GB to 2.5 GB at 3b/weight; PIQA 77.7%, Winogrande 66.1%.
