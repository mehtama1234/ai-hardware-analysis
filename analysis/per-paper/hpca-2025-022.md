# hpca-2025-022 — eDKM: An Efficient and Accurate Train-Time Weight Clustering for Large Language Models

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Differentiable KMeans (DKM) weight clustering achieves state-of-the-art compression accuracy for LLMs but its backward-pass memory complexity makes train-time application to billion-parameter LLMs nearly impossible on standard GPU hardware.

## Motivation
Weight clustering (non-linear quantization) is natively supported on modern smartphones and offers high LLM compression ratios for on-device inference, but DKM's prohibitive training memory overhead has blocked its use at LLM scale.

## Method
eDKM reduces DKM backward-pass memory via: (1) uniquification — deduplicating identical tensors before CPU offload to eliminate redundant copies; (2) sharding — splitting large tensors across memory partitions. Applied to intermediate tensors retained on CPU during DKM backward pass. Reduces per-decoder-layer memory 130x; enables LLaMA 7B fine-tuning and compression to 3b/weight.

## Key Novelty
Uniquification-plus-sharding of DKM backward-pass CPU-offloaded tensors, reducing per-decoder-layer memory by 130x and making train-time weight clustering tractable for 7B-parameter LLMs.

## Contributions
- Identification of DKM backward-pass tensor redundancy as the key memory barrier to LLM-scale weight clustering.
- Uniquification: deduplication of identical CPU-offloaded DKM tensors.
- Sharding: large tensor partitioning for further footprint reduction.
- 130x memory reduction; LLaMA 7B: 12.6 GB to 2.5 GB at 3b/weight; PIQA 77.7%, Winogrande 66.1%.

## Hardware Target

## Metrics
- Memory: 130x reduction per decoder layer (train-time)
- Model size: 12.6 GB to 2.5 GB (LLaMA 7B, 3b/weight)
- Accuracy: PIQA 77.7%, Winogrande 66.1%

## Baselines
DKM (Differentiable KMeans Clustering), Standard LLaMA 7B (uncompressed)

## Limitations
Sub-3b compression or larger models (13B, 70B) not evaluated; mobile device inference latency improvements not directly measured.
