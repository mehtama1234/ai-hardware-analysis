# Building n-Dimensional Trees for Resolution-Based Progressive Compression

**ID:** sc-2025-054  
**Venue:** SC  
**Confidence:** high

## Problem
Strict error bounds in floating-point compression yield large files; users may not need full fidelity data

## Motivation
Progressive data access enables users to download initial fidelity then request higher fidelities on-demand

## Method
Resolution-based progressive compression using n-dimensional tree structures; studies fidelity progression tradeoffs

## Key Novelty
Hierarchical tree-based progressive compression enabling quality-resolution tradeoffs

## Contributions
1. Develops n-dimensional tree structures for progressive compression
2. Demonstrates competitive compression ratios vs. traditional methods
3. Analyzes quality impact of resolution progression
