# HiPACK: Efficient Sub-8-Bit Direct Convolution with SIMD and Bitwise Management

**Venue:** MICRO  
**Confidence:** low (abstract only)

## Problem
Sub-8-bit quantized convolutions on ARM SIMD processors suffer from incompatibility because SIMD instructions lack native support for sub-8-bit widths, requiring unpacking operations that conflict with parallel multiplication and negate the memory savings of quantization.

## Motivation
Sub-8-bit quantization dramatically reduces memory footprint and compute cost, but the lack of efficient SIMD execution paths leaves substantial performance on the table on ARM edge processors.

## Method
HiPACK reorganizes numbers compressed below 8 bits into standard 8-bit chunks before multiplication begins, sidestepping the conflict between unpacking and parallel processing. It improves how the fast cache near the processor (L1/L2) serves this packed data and selects how to divide it so that ultra-fast registers don't overflow while still reusing data from cache effectively. The core technique, Dual Interleaved Register (DIR), interleaves two data streams across alternating register slots, enabling a single SIMD (parallel) multiply instruction to handle both streams at full width without resorting to slower single-value fallback operations.

## Key Novelty
The Dual Interleaved Register (DIR) mechanism interleaves two sub-8-bit data streams in registers so a single SIMD multiply instruction processes both at full width without stalls from width mismatch.

## Contributions
1. HiPACK: sub-8-bit direct convolution kernel eliminating SIMD incompatibility via decoupled unpacking and DIR
2. Up to 4.6x speedup over FP baseline; 1.7x over SOTA on BCM2711 ARM Cortex-A72
3. Open-source implementation

## Hardware Target
CPU (ARM Cortex-A72)

## Metrics
- Speedup: up to 4.6x vs. FP; 1.7x vs. SOTA

## Baselines
- FP convolution on BCM2711
- State-of-the-art sub-8-bit ARM libraries

## Limitations
Evaluation on a single ARM Cortex-A72; generalization to other ISAs not discussed.
