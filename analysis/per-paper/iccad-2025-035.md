# LEAF: Lightweight and Efficient Hardware Accelerator for Signature Verification of FALCON

**ID:** iccad-2025-035  
**Venue:** ICCAD

## Problem
FALCON signature verification is computationally complex, and existing hardware accelerators only target high-performance scenarios, leaving resource-constrained applications without efficient implementations.

## Motivation
Post-quantum cryptography (NIST-standardized FALCON) requires efficient hardware acceleration for resource-constrained embedded systems.

## Method
LEAF proposes an efficient design strategy with novel data dependence flow to maximize small-resource utilization, an ultra-lightweight number theoretical transform (NTT) core with novel twiddle factor access pattern, targeting signature verification only.

## Key Novelty
Novel data dependence flow and twiddle factor access pattern enabling resource-efficient FALCON signature verification without sacrificing throughput.

## Contributions
1. Novel data dependence flow maximizing small-resource utilization for all arithmetic procedures
2. Ultra-lightweight NTT core with novel twiddle factor access pattern
3. First lightweight full-hardware FALCON signature verification accelerator
4. 65-66% less aggregate resource usage and 24-14% less area-time product versus state-of-the-art
