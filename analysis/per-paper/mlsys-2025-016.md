# XGrammar: Flexible and Efficient Structured Generation Engine for Large Language Models

**Venue:** MLSys 2025 | **ID:** mlsys-2025-016 | **Confidence:** high

## Problem
CFG-constrained decoding for LLMs is slow because every token step requires recomputing token masks from scratch, dominating inference latency for structured output generation.

## Method
The system groups tokens into two categories: those whose validity depends only on grammar (precomputed offline before inference) and those that depend on where the parser currently is (checked during decoding). For Llama-3.1 generating JSON, only 1,134 out of 128,000 tokens need runtime checking—under 1%. The system tracks parsing progress using a state machine (technically a persistent pushdown automaton, the standard technique for tracking nested structures) and shrinks runtime-checked tokens to about 120 through context expansion (a 90% reduction). Token masks are cached per parser state using just 0.2% extra memory, with remaining runtime checks hidden behind GPU work.

## Novelty
Context-independent/context-dependent token split enabling offline precomputation of >99% of token masks, achieving near-zero constrained decoding overhead.

## Metrics
- Up to 100x per-token speedup
- 80x end-to-end serving throughput vs vLLM+Outlines
- Mask cache: 0.46MB vs 160MB naive (99.7% reduction)
- <1% of tokens context-dependent for Llama-3.1 JSON grammar
