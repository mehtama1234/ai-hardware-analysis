# RIROS: A Parallel RTL Fault SImulation FRamework with TwO-Dimensional Parallelism and Unified Schedule

**Venue:** ICCAD  
**ID:** iccad-2025-197

## Problem
RTL fault simulation for safety-critical applications is time-consuming due to imbalanced task loads from dynamic fault propagation paths, slowing verification cycles.

## Motivation


## Method
Two-dimensional parallel framework combining structural-level and fault-level parallelism with work-stealing and unified computation/synchronization scheduling to minimize execution bubbles.

## Key Novelty
First two-dimensional parallelism approach for RTL fault simulation balancing heterogeneous task loads.

## Contributions
- Two-dimensional parallel architecture (structural and fault-level)
- Work-stealing mechanism for handling numerous low-load tasks
- Unified scheduling approach eliminating synchronization bubbles
- 7.0x and 11.0x speedup over state-of-the-art
