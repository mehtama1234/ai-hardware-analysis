# RIROS: A Parallel RTL Fault SImulation FRamework with TwO-Dimensional Parallelism and Unified Schedule

**Venue:** ICCAD  
**ID:** iccad-2025-197

## Problem
RTL fault simulation for safety-critical applications is time-consuming due to imbalanced task loads from dynamic fault propagation paths, slowing verification cycles.

## Motivation


## Method
The system combines two forms of parallelism: dividing work across both the circuit's structural layout (structural-level parallelism) and across the different faults being tested (fault-level parallelism). When a processor finishes early, it steals remaining work from busier processors through work-stealing, keeping all processors busy. A unified schedule handles both computation tasks and synchronization points between processors in a single plan, eliminating idle gaps where processors would otherwise wait.

## Key Novelty
First RTL fault simulation framework using two-dimensional parallelism (structural-level and fault-level) to balance uneven task loads.

## Contributions
- Two-dimensional parallel architecture (structural and fault-level)
- Work-stealing mechanism for handling numerous low-load tasks
- Unified scheduling approach eliminating synchronization bubbles
- 7.0x and 11.0x speedup over state-of-the-art
