# asplos-2025-154: Fat-Tree QRAM: A High-Bandwidth Shared Quantum Random Access Memory for Parallel Queries

**Venue:** ASPLOS  
**Confidence:** high (full text)

## Problem
BB QRAM cannot process multiple queries in parallel because the binary tree root exclusively occupies all O(N) routers per query, forcing serial execution and O(p*log(N)) total latency for p parallel QPUs. This bottlenecks parallel quantum algorithms that depend on concurrent QRAM access.

## Motivation
Parallel quantum algorithms (distributed Shor's, parallel QSP, Hamiltonian simulation, k-Sum) critically require high-bandwidth QRAM; BB QRAM's sequential nature fundamentally limits quantum computing throughput in shared memory systems.

## Method
Fat-Tree QRAM replaces each BB QRAM router at tree level i with a Fat-Tree node containing (log(N)-i) router copies, doubling total qubit count to 2N-2-log(N). This enables O(log(N)) queries to pipeline simultaneously. Each query alternates 4-layer CSWAP gate steps (address loading) and 1-layer local SWAP steps (two types: SWAP-I and SWAP-II on alternating even/odd router indices) that shift queries through sub-component QRAMs of increasing size using only nearest-neighbor intra-node connectivity. Hardware is realized in both modular form (superconducting chips linked by coaxial cables) and on-chip form (bi-planar two-layer chip with Through-Silicon-Vias for inter-plane connections), both requiring only bi-planar nearest-neighbor connectivity. FIFO query scheduling is proven optimal by greedy exchange argument.

## Key Novelty
O(log(N)) query-level pipelining in O(log(N)) time using O(N) qubits via Fat-Tree node multiplexing, achieving constant QRAM bandwidth independent of memory size N.

## Contributions
- Fat-Tree QRAM: O(log(N)) simultaneous queries in O(log(N)) circuit depth with 2x qubit overhead vs. BB QRAM
- Modular (coaxial) and on-chip (bi-planar TSV) superconducting implementations with bi-planar connectivity sufficiency proof
- FIFO scheduling proven optimal; new QRAM bandwidth, space-time volume, and utilization metrics
- Up to 10x circuit depth reduction for Grover's, k-Sum, Hamiltonian simulation, QSP at N=2^10

## Metrics
- Speedup: up to 10x circuit depth reduction for parallel quantum algorithms vs. BB/Virtual QRAM at N=2^10
- Area: 16N qubits (vs. 8N BB QRAM) — 2x overhead for log(N)-fold parallelism
- Accuracy: same infidelity O(log^2(N)*epsilon) as BB QRAM
- Bandwidth: constant (independent of N) vs. O(1/log(N)) for BB QRAM
- Amortized single-query latency: 8.25 circuit layers (constant) vs. 8*log(N) for BB QRAM

## Baselines
Bucket-Brigade (BB) QRAM, Virtual QRAM, Distributed BB QRAM (D-BB), Distributed Fat-Tree (D-Fat-Tree)

## Limitations
Rapid classical memory swapping at constant intervals is required between queries and may be challenging for large memories in practice.
