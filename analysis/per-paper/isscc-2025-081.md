# isscc-2025-081: BROCA Mobile Social Agent SoC

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
On-device conversational AI requires integrating multimodal perception, RAG, language modeling, emotion generation, and vocoding in power-constrained mobile devices.

## Motivation
Personalized mobile agents need on-device conversational AI for latency/privacy; cloud inference is unsuitable.

## Method
BROCA is a single integrated circuit that runs conversational AI directly on mobile devices. It processes conversation through five stages: perceiving user input (with multimodal encoding for speech and vision), retrieving relevant context, generating a response using a transformer language model, generating emotional tone, and converting to speech via a vocoder. To reduce power consumption, the chip uses adaptive bit-truncation and acoustic-cluster bit grouping—techniques that adjust the numerical precision (number of bits) used in each stage based on what that stage actually needs.

## Key Novelty
The core innovation is using an adaptive bit-truncate unit and acoustic-cluster bit grouping to optimize numerical precision in each stage of the conversational AI pipeline, reducing power consumption.

## Contributions
- 52.4-559.2mW power range
- Adaptive bit-truncation per module
- Acoustic-cluster bit grouping
- Integrated multimodal conversational AI

## Metrics
- Power: 52.4-559.2 mW
- Integration: full conversational pipeline
