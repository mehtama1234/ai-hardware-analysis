# Scalable Parallel Solver for Power Grid Analysis Using Nested Domain Decomposition

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

Proposes a parallel nested domain decomposition solver for efficient analysis of massive power distribution networks at sub-5nm nodes. Introduces intermediate Schur complement to reduce computational complexity, achieving 1.70x speedup in complement computation and 1.30x overall solver improvement.

## Key Contributions

- **Nested Decomposition**: Hierarchical decomposition strategy breaking PDN analysis into manageable stages
- **Intermediate Schur Complement**: Novel formulation reducing final global complement size, the key bottleneck
- **Parallel Implementation**: Enables efficient parallel Schur complement computation across multiple partitions
- **Scalability**: Addresses billion+ node PDNs in advanced technologies with reduced noise margins

## Technical Focus

Solves scalability problem in traditional domain decomposition where dense global Schur complement grows exponentially with partition count. Intermediate complement stages decouple this growth.
