# EarDVFS: Environment-Adaptable RL-based DVFS for Mobile Devices

**Venue:** ICCAD  
**ID:** iccad-2025-098

## Problem
Conventional DVFS methods struggle with mobile device demands including device-specific thermal calibrations, ambient environment impact, and non-processor component thermal effects.

## Motivation
Improve power efficiency across diverse thermal environments while maintaining performance on mobile devices.

## Method
EarDVFS uses machine learning to automatically adjust mobile device processor speed, monitoring not just the processor itself but also ambient air temperature and heat from other components like battery and display. To prevent damage, it slows down the processor proactively before overheating occurs. The system learns the best strategy for each specific device, so the same approach works well across different phones. By tracking all heat sources instead of just processor temperature, it makes smarter throttling decisions.

## Key Novelty
EarDVFS is the first machine learning-based system for mobile processor speed adjustment that adapts to its environment by tracking ambient temperature and heat from device components like battery and display.

## Contributions
- 21.6% average power efficiency improvement (up to 49.6%)
- Maintains performance across varying thermal environments
- Proactive throttling combining strengths of traditional and RL-based methods
- Extensive ablation studies validating each RL component
