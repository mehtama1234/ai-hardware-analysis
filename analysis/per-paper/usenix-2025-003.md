# Katz: Efficient Workflow Serving for Diffusion Models with Many Adapters

**Problem:** Production T2I services struggle to efficiently serve diffusion models augmented with many ControlNet and LoRA adapters, where ControlNets introduce significant compute overhead while LoRAs are bottlenecked by loading latency.

**Method:** KATZ separates ControlNets (specialized networks that guide image generation) from the main model and runs them on dedicated GPUs where results can be cached and reused across requests. For LoRA adapters (lightweight model customizations), it loads them in the background while the base model executes, overlapping up to K steps of computation with loading time without losing image quality. The base model runs faster across multiple GPUs using latent parallelism—processing different parts of the image's compressed representation simultaneously.

**Novelty:** KATZ removes ControlNets (image-guidance networks) from the main computation pipeline by running them on dedicated GPUs as an independent, separately scalable service.
