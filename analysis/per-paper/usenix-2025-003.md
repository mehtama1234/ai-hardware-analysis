# Katz: Efficient Workflow Serving for Diffusion Models with Many Adapters

**Problem:** Production T2I services struggle to efficiently serve diffusion models augmented with many ControlNet and LoRA adapters, where ControlNets introduce significant compute overhead while LoRAs are bottlenecked by loading latency.

**Method:** KATZ decouples ControlNets from the base model and deploys them as an independent, independently-scalable service on dedicated GPUs for caching and sharing. It employs bounded asynchronous loading to overlap LoRA loading with base model execution by a maximum of K steps while maintaining image quality. The system further accelerates base model execution across multiple GPUs using latent parallelism.

**Novelty:** Removing ControlNets from the critical path by deploying them as an independently scalable microservice on dedicated GPUs.
