# isscc-2025-070

**Title:** 20.2 A 67μW/Channel, 0.13nW/Synapse/b Nose-on-a-Chip for Noninvasive Diagnosis of Diseases with On-Chip Incremental Learning

**Venue:** ISSCC

**Problem:** Portable electronic noses for breath-based disease detection struggle with accuracy drift across environments/patients; high power limits portability.

**Key Contribution:** On-chip incremental learning (0.13 nW/synapse/b) enables patient-specific adaptation without external cloud processing.

**Method:** The system uses a low-power electronic nose front-end (67 microwatts per channel) with gas sensors and analog signal conditioning (preparing the raw sensor signals for processing). Instead of sending data to a cloud server for analysis, a lightweight neural network runs directly on the chip and learns from each patient's individual breath signature in real time, using just 0.13 nanowatts per synapse (neural connection) per bit. This on-chip learning allows the sensor to automatically calibrate itself and adapt to each specific patient without needing external connectivity.

**Hardware:** ASIC, SoC

**Metrics:** 67 μW/channel, 0.13 nW/synapse/b

**Techniques:** Circuit design, power, near-data processing

**Primary Theme:** Portable E-nose with on-chip learning for health diagnosis
