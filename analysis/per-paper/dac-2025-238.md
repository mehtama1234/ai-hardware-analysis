# HeteroSVD: Efficient SVD Accelerator on Versal ACAP with Algorithm-Hardware Co-Design

**Venue:** DAC
**ID:** dac-2025-238

## Problem
Singular value decomposition (SVD) has O(n^3) complexity; real-time SVD applications (signal processing, recommendations) require acceleration. GPU and FPGA solutions don't jointly optimize latency, throughput, and power.

## Motivation
SVD is a critical primitive in signal processing and linear algebra; practical systems need low-latency, power-efficient implementations.

## Method
The accelerator combines different processor types on a Xilinx Versal ACAP chip—FPGA logic, CPUs, and specialized AI Engine cores designed for matrix math. The SVD algorithm is reorganized to align with what the AI Engines do best, and an automated tool explores different ways to split work across these components, picking the layout with the fastest speed and lowest power consumption.

## Key Novelty
The core idea is jointly optimizing the SVD algorithm and hardware layout to exploit Versal ACAP's AI Engine processors.

## Contributions

- HeteroSVD system-level SVD decomposition architecture
- Algorithm-hardware co-design for SVD ordering
- AIE-centric dataflow with automatic optimization
- 1.98x latency reduction vs FPGA, 7.22x vs GPU
- 1.77x throughput and 13.18x energy efficiency vs GPU
