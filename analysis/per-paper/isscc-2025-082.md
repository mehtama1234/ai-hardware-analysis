# isscc-2025-082: High-Speed PAM-4 Transmitter with FFE

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
Single-ended PAM-4 reduces signal spacing (1/3 normal), degrading SNR; high-bandwidth FFE and power-efficient encoding are challenging.

## Motivation
AI data centers need fast processor-memory interfaces (32-50Gb/s); PAM-4 boosts bits-per-baud but requires robust equalization and power optimization.

## Method
The transmitter sends data as PAM-4 (four signal levels spaced closely together, making them noise-prone). To keep the signal clean across the channel, it uses a feed-forward equalizer (FFE) that adjusts the signal before sending it, calibrated automatically (ZQ-based) to the actual circuit's electrical properties. To save power, it adds PAM-4 LSB DBI-DC encoding (selective bit-flipping to reduce power-bus activity) built directly into the four signal levels, avoiding extra circuitry.

## Key Novelty
The core innovation is combining a self-adjusting signal recovery circuit (ZQ-based FFE) with power-saving bit-encoding (PAM-4 LSB DBI-DC) in a single PAM-4 transmitter.

## Contributions
- 32-50Gb/s/pin single-ended PAM-4
- ZQ-based FFE
- PAM-4 LSB DBI-DC encoding
- Minimal hardware overhead

## Metrics
- Data rate: 32-50 Gb/s per pin
- Signaling: PAM-4
- Encoding: LSB DBI-DC
