# Characterizing the Performance of Parallel Data-Compression Algorithms across Compilers and GPUs

**ID:** sc-2025-053  
**Venue:** SC  
**Confidence:** high

## Problem
Compiler choice and GPU platform significantly affect data compression performance; unclear which combinations are optimal

## Motivation
Data compression critical for HPC; different compilers produce different performance characteristics requiring systematic study

## Method
Comprehensive empirical evaluation of 107,632 compression algorithms across compilers (NVCC, Clang, HIPCC) and platforms (NVIDIA, AMD)

## Key Novelty
Large-scale empirical characterization showing compiler-hardware interaction effects on compression

## Contributions
1. Evaluates 107,632 compression algorithm variants
2. Identifies compiler-specific performance patterns (Clang slow compression, fast decompression)
3. Provides guidance for compiler selection

## Hardware Targets
NVIDIA GPU, AMD GPU

## Technique Categories

## Workloads
Data compression, Decompression

## Limitations
