# NSGA-RM: NSGA-II Evolved Performance Optimized Non-Homogeneous Recursive Polynomial Multiplier Architectures

**VLSID 2025** | vlsid-2025-084

## Abstract
Polynomial multiplier design for cryptographic SoCs involves large design spaces; heuristic exploration may miss optimal solutions. NSGA-RM applies Non-dominated Sorting Genetic Algorithm II (NSGA-II) to recursive multiplier (RM) configuration space, discovering Pareto-optimal designs. vs. SOTA (MNHKA/MNHOKA/HRM): 24.65% area, 6.71% delay, 29.71% ADP, 40.65% power, 34.32% PPA improvement. GPDK 45nm synthesis; open-source files available.

## Problem
- Polynomial multiplication hardware requires optimization across multiple metrics (area, delay, power)
- Design space for recursive multiplier configurations is large
- Heuristic approaches (HRM) explore space sub-optimally
- Manual exploration infeasible

## Key Insight
NSGA-II evolutionary optimization can systematically explore recursive multiplier design space, discovering better Pareto-optimal architectures than heuristic methods.

## Approach
1. Define RM configuration space (multiplier variants, combinations, parameters)
2. NSGA-II evolutionary search over configurations
3. Synthesis of candidates with Cadence Genus (45nm)
4. Multi-objective optimization across area, delay, power
5. Pareto-front analysis
