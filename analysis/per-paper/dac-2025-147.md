# RL-Driven Window Selection for Detailed Routing

## Problem
Window-based rip-up and reroute in detailed routing is the most runtime-intensive step due to inefficient window selection that targets violations uniformly, wasting effort on low-congestion areas while missing routing hotspots.

## Method
This approach uses reinforcement learning (AI that learns through trial and error) to intelligently choose which sections of the chip to repair and how large each section should be, instead of treating all areas equally. It positions sections based on where design rule violations (places where routing breaks manufacturing rules) occur, focusing effort on high-congestion areas. The AI learns which window placements eliminate the most violations most efficiently, achieving routing without any violations while maintaining competitive wire length and via count.

## Key Results
- DRV-free solution vs TritonRoute
- 0.07% wirelength improvement
- 2.42% via reduction
- Competitive average runtime
