# RL-Driven Window Selection for Detailed Routing

## Problem
Window-based rip-up and reroute in detailed routing is the most runtime-intensive step due to inefficient window selection that targets violations uniformly, wasting effort on low-congestion areas while missing routing hotspots.

## Method
A reinforcement learning approach dynamically generates windows by adjusting size and position based on design rule violation (DRV) distribution, targeting high-congestion areas efficiently. RL learns predictive window placement that minimizes DRVs, achieving high-quality routing results.

## Key Results
- DRV-free solution vs TritonRoute
- 0.07% wirelength improvement
- 2.42% via reduction
- Competitive average runtime
