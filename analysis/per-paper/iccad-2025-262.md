# PAR-CIM: A Precise/Approximate Reconfigurable Digital CIM Macro with 0.35-4b Fractional Mixed-Bitwidth Quantization

**Venue:** ICCAD  
**Paper ID:** iccad-2025-262

## Problem Statement
Digital CIM for DNN acceleration faces overhead from resource usage, energy efficiency, and limited architectural flexibility in balancing precision and approximation.

## Motivation
Existing DCIM solutions handle approximate or reconfigurable paradigms separately; a unified design balancing precision, approximation, and flexibility is needed.

## Method
PAR-CIM reduces chip area to 0.35× using layer/gate-level approximate computation in its adder trees (circuits that add numbers)—letting some calculations use less precision when exact results aren't critical. It combines this with fractional mixed-bitwidth quantization, which assigns each layer the precision it needs based on Taylor sensitivity analysis (identifying which layers are sensitive to precision loss) and DoReFa-Net (a method for determining optimal precision levels), enabling multi-bit reconfigurable computation mode so the chip dynamically chooses between precise and approximate computation for each operation.

## Key Novelty
A reconfigurable CIM (computing-in-memory) macro that combines precise and approximate computation with fractional mixed-bitwidth quantization, dynamically adjusting each layer's precision to balance accuracy and chip efficiency.

## Contributions

1. 3048 TOPS/W at 1b/1b
2. 86.61% compression with <0.74% accuracy loss
3. High flexibility through MBRM
