# Agentic AI vs ML-based Autotuning: A Comparative Study for Loop Reordering Optimization

**Venue:** SC 2025  
**Authors:** Miguel Romero Rosas, Rudolf Eigenmann, Khaled Ibrahim

## Problem Statement
Traditional ML-based autotuning approaches for HPC code optimization suffer from expensive compile-run cycles and poor adaptability. LLM-based Agentic AI systems present a promising alternative, but their practical effectiveness remains unclear.

## Technical Approach
**Agentic AI System (LoopGen-AI):**
- Implements multi-agent reasoning using three LLMs: GPT-4.1, Claude 4.0, Gemini 2.5
- Combines semantic understanding of kernels with dynamic environmental feedback
- Uses Persona + Context Manager prompt engineering patterns

**ML Autotuning Baseline:**
- Statistical exploration of optimization space
- Requires orders of magnitude more program runs for convergence

**Evaluation Domain:**
- Loop reordering optimization for CPU and GPU architectures

## Key Findings
1. **Agentic AI Convergence:** Achieves competitive performance with only few program runs
2. **Decision Quality:** Agent reasoning logs show decisions driven by semantic kernel understanding + dynamic feedback
3. **Prompt Engineering Impact:** Persona + Context Manager patterns significantly improve effectiveness
4. **Comparison:** Agentic AI requires substantially fewer runs than traditional ML autotuners

## Insight
Traditional ML autotuners rely on statistical exploration requiring expensive evaluations. Agentic AI leverages semantic understanding and adaptive reasoning to converge faster, suggesting a complementary (not replacement) paradigm.

## Limitations & Future Work
- Evaluation limited to loop reordering; broader optimization domains untested
- Model-specific results; generalization to other LLMs unclear
- Scalability to very large HPC applications not demonstrated
- Dependency on LLM API providers; sustainability concerns
