# WarmCache: Exploiting STT-RAM Cache for Low-Power Intermittent Systems

**ID:** isca-2025-045 | **Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Energy harvesting systems (EHS) suffer from compulsory cache misses after power failures because volatile SRAM caches lose all data across power outages. Existing non-volatile cache designs impose high write energy and latency overhead.

## Motivation
Intermittent computing on energy-harvested devices is increasingly important for IoT/edge applications, but power-outage-induced compulsory misses impose prohibitive performance penalties with traditional caches.

## Method
WarmCache uses an STT-RAM cache with relaxed thermal stability tuned so cache contents survive typical power outage durations without requiring full non-volatile persistence. The compiler partitions the program into regions and performs region-level error correction: at each region boundary, updated cache lines are scrubbed and any multi-bit retention errors trigger re-execution. A region formation technique via stitching and splitting aligns region boundaries with the STT-RAM scrubbing interval.

## Key Novelty
Using relaxed-retention STT-RAM (not fully non-volatile) to preserve cache warmth across power outages, combined with compiler-driven region-level error correction to handle retention failures without write-back overhead.

## Contributions
1. Insight that STT-RAM retention time need only exceed power outage duration, not persist indefinitely.
2. Region-level error correction scheme: scrubbing at region boundaries and re-executing on detected multi-bit errors.
3. Compiler region formation with stitching and splitting to match region size to scrubbing interval.
4. 1.3-1.4x average performance improvement over state-of-the-art EHS cache designs.
