# Security Opportunities and Challenges for Disaggregated Architectures (Invited)

**Problem:** Disaggregated architectures (separated CPU, memory, storage, networking) introduce novel security risks through expanded attack surfaces and network communication.

**Approach:** Systematic analysis of security in disaggregated systems across enterprise routing, O-RAN, and trusted execution environments.

**Key Points:** Disaggregation offers modularity for patch management and fine-grained policy deployment, but increases data exposure, complicates provenance tracking, and requires TEE redesign.

**Scope:** Position paper addressing isolation, API security, and network fabric risks in disaggregation.

**Tags:** disaggregation, security, o-ran, network-security, tee, architecture
