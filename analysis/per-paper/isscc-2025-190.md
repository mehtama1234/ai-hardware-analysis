# isscc-2025-190: IBM Telum II Enterprise Processor with DPU

**Problem**: Enterprise servers need high single-thread performance, large on-chip cache, and integrated AI acceleration; previous generations limited by memory bandwidth and lack of specialized data/AI processing.

**Solution**: 5nm Telum II with on-die Data Processing Unit (DPU), expanded cache hierarchy (L2: 36MB × 10 per core, L3: 360MB), microarch improvements, and 20% core area reduction enabling more cache while maintaining density.

**Key Results**:
- 5.5GHz frequency, 43B transistors per 600mm² die
- 40% L2 cache expansion (36MB instances)
- 40% L3 growth (360MB total)
- Integrated DPU for AI + data processing
- 32-CP fully coherent drawer scaling (2.88GB L4/drawer)

**Hardware**: CPU (8-core enterprise)  
**Workload**: Database / AI inference / enterprise  
**Confidence**: high (detailed abstract)
