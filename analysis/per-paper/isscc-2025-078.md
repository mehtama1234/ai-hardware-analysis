# isscc-2025-078: SHINSAI Reusable Active TSV Interposer

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
Active TSV interposers are custom-designed for specific chiplet stacks; fixed topologies limit reuse and require redesign for new configurations.

## Motivation
Reducing 3D chiplet design NRE and complexity by enabling platform-level interposer reuse across diverse chip combinations.

## Method
SHINSAI is a programmable physical layer (called an interposer) that connects stacked computer chips together, built in 28nm CMOS with through-silicon vias (tiny wires threaded through the silicon). Inside, it has two routing layers: horizontal 2.5D paths (H-Link) that route connections within the interposer, and vertical 3D paths (V-Link) that connect upward to the stacked chips. It includes 512Mb of on-board SRAM to manage data between chips. Because the routing is programmable rather than hardwired, you can reconfigure how different chips connect without changing the physical hardware, letting the same interposer work with many different chip combinations.

## Key Novelty
The core innovation is making the interposer's routing programmable so it works with different chip combinations instead of being locked into one configuration.

## Contributions
- 586mm² reusable platform
- Dual-layer NoAI with flexible H-Link/V-Link routing
- 512Mb on-interposer SRAM
- Supports CPU and accelerator stacks

## Metrics
- Die size: 586 mm²
- Underdeck memory: 512 Mb SRAM
- Technology: 28nm CMOS/TSV-middle
