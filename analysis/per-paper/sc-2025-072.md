# Reproducibility Report for SC25 Paper ATLAHS: An Application-centric Network Simulator Toolchain for AI, HPC, and Distributed Storage

**ID:** sc-2025-072 | **Venue:** SC

## Problem Statement
Artifact evaluation and reproducibility verification

## Motivation
Ensure reproducibility and artifact quality of SC papers

## Method
We obtained the ATLAHS toolchain (a simulator for modeling how AI, HPC, and storage systems send data across networks) and followed the authors' instructions to build and run it. We then tested whether the code produces the same results the paper claims and verified that other researchers can reliably use it by checking that the code builds without errors, runs successfully, and generates consistent outputs.

## Key Novelty
This report verifies whether the ATLAHS network simulator actually works as described when independent researchers attempt to use it.
