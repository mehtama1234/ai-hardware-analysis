# dac-2025-445: Insights from Rights and Wrongs

**Title:** Insights from Rights and Wrongs: A Large Language Model for Solving Assertion Failures in RTL Design

**Problem:** Assertion failures in SystemVerilog RTL designs require manual analysis of complex logical and timing relationships to identify and fix issues; no automated tool currently exists.

**Motivation:** Automating RTL assertion debugging would accelerate hardware design verification and reduce reliance on manual expertise.

**Method:** AssertSolver is a specialized LLM trained on synthetic data and error-response feedback to diagnose assertion failures and predict bug fixes (88.54% pass@1).

**Key Novelty:** Custom LLM for RTL assertion debugging, outperforming o1-preview by 11.97%.

**Contributions:**
- Specialized LLM for assertion failure diagnosis
- Public testbench & model release
- 88.54% pass@1 accuracy (11.97% over o1-preview)
- LLM viability for hardware verification automation

**Hardware Target:** ASIC

**Technique Category:** Compiler

**Baselines:** OpenAI o1-preview

**Limitations:** Assertion failure solving only; broader RTL verification generalization not discussed.
