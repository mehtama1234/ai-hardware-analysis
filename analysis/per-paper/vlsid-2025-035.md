# VLSID 2025-035: ABMF - Adaptive Bonsai Merkle Forests

## Summary
Forest structure extending Bonsai Merkle Trees for secure persistent memory integrity verification. Reduces tree traversal depth by maintaining intermediate nodes as additional root nodes in secure processor.

## Problem
Secure persistent memories require fast integrity verification via Merkle trees. Traditional BMT designs suffer from expensive tree traversals on every write, creating significant performance overhead.

## Method
Secure memory systems protect data using Merkle trees—hierarchical structures where each node verifies the ones below it, creating a chain of trust from individual memory locations to a single root node. Normally, verifying or updating any data requires traversing this entire chain, from the leaf to the root. This approach identifies intermediate nodes (nodes partway up the tree) as additional roots and stores them in the secure processor alongside the main root. By allowing updates to stop at the nearest intermediate root instead of traversing to the top, the method reduces verification latency while preserving security.
