# An RDMA-First Object Storage System with SmartNIC Offload

**Paper ID:** sc-2025-432
**Venue:** SC
**Authors:** Yu Zhu, Aditya Dhakal, Pedro Bruel, Gourav Rattihalli, Yunming Xiao, Johann Lombardi, Dejan S. Milojicic

## Problem

AI training workloads generate fine-grain I/O that saturates host-mediated TCP paths; kernel involvement and context switches limit storage throughput for GPU-centric pipelines.

## Motivation

LLM training requires high-throughput, low-latency I/O; kernel bypass (RDMA) proven efficient; offloading client logic to Smart-NIC reduces host overhead and enables security services.

## Method

ROS2 architecture: RDMA-first DAOS client offloaded to NVIDIA BlueField-3 DPU. Separates control plane (gRPC, lightweight) from data plane (RDMA/UCX, high-throughput). Keeps server-side DAOS I/O engine unchanged. Supports multi-tenant isolation and inline encryption on SmartNIC.

## Key Novelty

First practical DAOS/SmartNIC integration with RDMA offload achieving host-comparable performance; demonstrates DPU viability for object storage in AI workloads.

## Contributions

- ROS2 RDMA-first object storage design with SmartNIC offload
- BlueField-3 DAOS client offloading achieving comparable host performance
- Control/data plane separation enabling efficient scaling
- Multi-tenant isolation and inline services on DPU
