# An RDMA-First Object Storage System with SmartNIC Offload

**Paper ID:** sc-2025-432
**Venue:** SC
**Authors:** Yu Zhu, Aditya Dhakal, Pedro Bruel, Gourav Rattihalli, Yunming Xiao, Johann Lombardi, Dejan S. Milojicic

## Problem

AI training workloads generate fine-grain I/O that saturates host-mediated TCP paths; kernel involvement and context switches limit storage throughput for GPU-centric pipelines.

## Motivation

LLM training requires high-throughput, low-latency I/O; kernel bypass (RDMA) proven efficient; offloading client logic to Smart-NIC reduces host overhead and enables security services.

## Method

The system moves DAOS client logic from the CPU to a specialized network processor card (NVIDIA BlueField-3 DPU). It splits the work into two paths: control commands use lightweight gRPC messaging, while high-speed data transfers use RDMA and UCX (network techniques that let the network processor directly access memory without burdening the CPU). This way, GPUs can pull data directly without CPU overhead or kernel context switches. The storage server side needs no changes, and the network processor handles encryption and multi-tenant isolation.

## Key Novelty

This is the first practical demonstration that offloading DAOS storage logic to a SmartNIC (specialized network card) using RDMA can achieve host-comparable performance, proving that network processors (DPUs) are viable for object storage in AI training workloads.
