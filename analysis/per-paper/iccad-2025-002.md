# Adaptive Pin Pattern Modification on Standard Cells Towards ECO Routing

**Venue:** ICCAD  
**ID:** iccad-2025-002

## Problem
Pin inaccessibility on standard cells causes routing failures in deep-submicron physical design, with failures increasing as cell sizes shrink.

## Motivation
Resolving pin accessibility failures post-placement enables successful ECO routing without redesign, critical for meeting complex timing closure requirements.

## Method
Adaptive pin-pattern modification (APM) applies three techniques to standard cells: pin-shift-trim (PST), pin-free (PF), and pin-bridge (PB). System selects modifications based on individual cell instance failures and explores routable paths via maze routing.

## Key Novelty
Adaptive cell-level pin pattern modifications enabling ECO routing with no PPA penalty and 116x speedup over concurrent MCF-based methods.

## Contributions
1. Three pin-pattern modification techniques (PST, PF, PB) for routing flexibility
2. Adaptive selection scheme matching modifications to cell instance failures
3. ECO router resolving 17.7% of previously unfixable pin inaccessibility cases
4. Orders-of-magnitude speedup vs. concurrent optimization methods
