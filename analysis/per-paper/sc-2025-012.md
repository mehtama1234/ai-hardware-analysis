# gParaKV: A GPGPU-accelerated Key-Value Separation-based KV Store with Optimized Compaction and Garbage Collection

**Venue:** SC
**Paper ID:** sc-2025-012
**Confidence:** low

## Problem Statement
LSM-tree KV stores suffer from compaction and garbage collection bottlenecks; key-value separation methods don't fully address merge-sorting and expensive GC overhead

## Motivation
LSM-trees widely used in cloud storage; compaction severely impacts performance at scale; GPU parallelism could accelerate these bottleneck operations

## Method
gParaKV is a key-value store using key-value separation (storing keys and values in separate locations to save space) that accelerates its two biggest bottlenecks—compaction and garbage collection—by offloading them to a GPGPU (a graphics processor used for general computing, with many parallel cores). During compaction, the GPU parallelizes merge-sorting (combining multiple sorted data blocks), running hundreds of operations simultaneously instead of sequentially as CPUs do. For garbage collection, it uses a GPU-optimized bitmap (a compact structure tracking which records are still alive) and parallel marking (examining many records simultaneously) to rapidly identify and remove obsolete data.

## Key Novelty
GPU acceleration of compaction merge-sorting and garbage collection using bitmap and parallel marking structures for efficient parallel execution.
