# asplos-2025-004: Mint: Cost-Efficient Tracing with All Requests Collection via Commonality and Variability Analysis

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Distributed tracing systems face a fundamental tension between preserving essential trace information and reducing massive trace volume. The prevailing binary ('1 or 0') sampling strategy either retains a full trace or discards it entirely, failing to exploit structural commonality across requests.

## Motivation
Real-world production traces show that most requests share structural patterns while differing only in a small set of attributes, making full retention wasteful and full discard lossy; a smarter representation can reduce cost without sacrificing observability.

## Method
Mint looks at request traces—the detailed logs of what happens as requests move through a system—and finds the common structure shared by similar requests. It then creates a template from those common parts and stores each request as only its differences from that template, rather than storing complete traces. This dramatically reduces storage while preserving all per-request details needed to understand what each request did.

## Key Novelty
Mint collects all requests but stores only their differences from a shared template, replacing the traditional keep-or-discard trace sampling with full coverage at drastically lower storage cost.

## Contributions
- Empirical study revealing that real-world production traces exhibit strong commonality that binary sampling fails to exploit.
- Mint's commonality-variability decomposition framework achieving all-request collection at reduced cost.
- Evaluation on real-world production trace workloads demonstrating cost-efficiency gains.
