# asplos-2025-090 — Generalizing Reuse Patterns for Efficient DNN on Microcontrollers

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** Generalized computation reuse patterns for DNN inference on microcontrollers

## Problem
DNN inference on microcontrollers is limited by their restricted compute and memory, and existing computation reuse techniques that exploit redundancy in input/activation data are constrained by a narrow definition of reuse patterns, leaving a large portion of potential reuse unexploited.

## Motivation
Microcontrollers are the primary compute substrate for ultra-low-power edge AI, and even small improvements in DNN inference efficiency—through better exploitation of input redundancy—can be decisive for deployability.

## Method
The approach represents neural network data—both inputs and the intermediate outputs from each layer (called activations)—as matrices and explores how rearranging their rows and columns exposes different reuse opportunities. This simple reframing unlocks far more reuse patterns than previous methods could access because they were limited to fixed pattern definitions. To navigate this expanded space efficiently, they build two prediction models: one estimates the accuracy cost of using a reuse pattern (approximate computation—calculating less precisely to save time), and another predicts how fast the pattern will execute on the microcontroller. Together, these models enable automatic search to find the reuse pattern that best trades off accuracy against speed for a given neural network and hardware.

## Key Novelty
Reframing computation reuse as a matrix row/column reordering problem reveals a much larger set of reuse patterns, which dual models can then search to balance accuracy and latency.

## Contributions
- Concept of generalized reuse patterns via matrix row/column reordering of DNN inputs/activations
- Analytical model for predicting accuracy impact of generalized reuse patterns
- Analytical model for predicting inference latency on microcontrollers under a given reuse pattern
- 1.03-2.2x speedup or 1-8% accuracy improvement over conventional reuse on diverse DNNs and MCUs
