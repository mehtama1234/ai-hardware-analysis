# FRESCO: Efficient Subgraph Enumeration for Scalable Clustering in Heterogeneous CGRAs

**ID:** iccad-2025-034  
**Venue:** ICCAD

## Problem
Clustering for heterogeneous CGRAs with complex clusters (100+ primitives, many bypassable) is computationally intractable because it is analogous to CISC instruction selection with orders of magnitude more complex instructions.

## Motivation
FPGA-CGRA hybrid architectures with rich heterogeneous resources require efficient clustering algorithms for design automation tools to remain practical.

## Method
FRESCO uses a two-phase algorithm to organize operations into clusters for heterogeneous CGRAs. In the first phase, it discovers possible cluster configurations using an abstract decision tree strategy—a method that makes systematic yes/no choices to eliminate unpromising options early, avoiding the exponential explosion of checking every combination. In the second phase, it selects the best overall combination of the discovered clusters.

## Key Novelty
The innovation is using abstract decision trees to enumerate potential cluster configurations while efficiently pruning the search space.

## Contributions
1. Architecture-agnostic clustering algorithm scaling to highly complex clusters
2. Abstract decision tree strategy for efficient subgraph match enumeration
3. Effective pruning mechanism reducing search space for complex clusters
4. Superior clustering quality versus CLUMAP state-of-the-art for supported cases
