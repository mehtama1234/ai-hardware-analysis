# STAR: Improving Lifetime and Performance of High-Capacity Modern SSDs Using State-Aware Randomizer

**Venue:** ICCAD  
**ID:** iccad-2025-099

## Problem
Lateral charge spreading (LCS) in high-capacity 3D NAND flash causes retention errors that significantly reduce SSD lifetime, particularly as stack heights increase.

## Motivation
Enable higher-capacity SSDs by mitigating LCS-induced reliability challenges without substantial performance overhead.

## Method
STAR protects high-capacity SSDs by randomizing how data is stored to avoid patterns vulnerable to lateral charge spreading (charge leaking between neighboring cells in stacked memory layers). It detects errors by reading memory cells with opposite electrical polarities (dual-polarity reads), then corrects them using an analytical model that predicts how each cell's threshold voltage—the electrical level determining whether a bit reads as 0 or 1—drifts over time.

## Key Novelty
It is the first data randomizer specifically designed to address the weak data patterns caused by lateral charge spreading in high-capacity 3D NAND SSDs.

## Contributions
- 2.3x SSD lifetime improvement
- 50% average read latency reduction
- Error rates below 10^-13 without significant overhead
- Efficient integration into existing SSD controller I/O datapath
