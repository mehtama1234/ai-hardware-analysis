# STAR: Improving Lifetime and Performance of High-Capacity Modern SSDs Using State-Aware Randomizer

**Venue:** ICCAD  
**ID:** iccad-2025-099

## Problem
Lateral charge spreading (LCS) in high-capacity 3D NAND flash causes retention errors that significantly reduce SSD lifetime, particularly as stack heights increase.

## Motivation
Enable higher-capacity SSDs by mitigating LCS-induced reliability challenges without substantial performance overhead.

## Method
STAR: state-aware data randomizer that proactively eliminates weak data patterns vulnerable to LCS. Uses dual-polarity read for error detection and adaptive error-aware read with analytical Vth drift estimation for correction.

## Key Novelty
First data randomizer specifically targeting LCS-induced weak patterns in high-capacity 3D NAND SSDs.

## Contributions
- 2.3x SSD lifetime improvement
- 50% average read latency reduction
- Error rates below 10^-13 without significant overhead
- Efficient integration into existing SSD controller I/O datapath
