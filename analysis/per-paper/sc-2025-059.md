# To Stream or Not to Stream: Towards A Quantitative Model for Remote HPC Processing Decisions

**ID:** sc-2025-059  
**Venue:** SC  
**Confidence:** high

## Problem
Scientific instruments generate data exceeding local compute; file-based remote HPC processing impractical for time-sensitive analysis

## Motivation
Real-time streaming frameworks promise latency reduction but lack principled feasibility assessment

## Method
Quantitative framework with Streaming Speed Score; incorporates data rate, transfer efficiency, processing power, I/O overhead

## Key Novelty
Formal model (Tpct) identifying operational regimes where streaming beats file-based approaches

## Contributions
1. Develops Streaming Speed Score framework
2. Models total processing completion time (Tpct)
3. Validates on LCLS-II, APS, FRIB, LHC use cases
4. Shows 97% latency reduction under high data rates

## Hardware Targets
HPC facilities, Streaming infrastructure

## Technique Categories
Networking, Data Management, Scientific Computing

## Workloads
Streaming data processing, Real-time analysis

## Metrics
- latency_reduction: up to 97% vs. file-based
- congestion_penalty: order of magnitude increase

## Baselines
- File-based HPC processing

## Limitations
Assumes well-behaved network; tail latency critical but unpredictable
