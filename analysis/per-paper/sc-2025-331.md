# Performance portable batched linear algebra kernels for transport sweeps using Kokkos

**Venue:** SC
**ID:** sc-2025-331
**Confidence:** low

## Problem Statement
Batched linear algebra kernels for neutron transport sweeps on GPUs require high performance across NVIDIA and AMD architectures; existing libraries may not be optimized for transport kernel patterns.

## Motivation
Neutron transport is compute-intensive; batched GESV (small system solvers) can achieve better GPU utilization; need performance-portable solution across architectures.

## Method
Custom batched GESV solver using Kokkos for performance portability. Optimizations: minimize global memory traffic, maximize compile-time computation. Evaluated on H100 (NVIDIA) and MI300A (AMD).

## Key Novelty
Custom batched GESV outperforming state-of-the-art libraries; performance portability across NVIDIA/AMD via Kokkos.

## Contributions
1. Optimized batched GESV solver for transport sweeps
2. Performance competitive with optimized CPU (128-core Genoa)
3. High performance on both H100 and MI300A
4. Memory-efficient design via minimized global traffic
