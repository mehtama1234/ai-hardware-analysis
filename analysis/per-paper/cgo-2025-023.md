# CUrator: An Efficient LLM Execution Engine with Optimized Integration of CUDA Libraries

**Venue:** CGO
**Confidence:** low

## Problem
Modern LLMs require optimal GEMM performance on diverse GPUs; existing CUTLASS and cuBLAS libraries offer tuning but lack systematic exploration of LLM-specific parameters and multi-GPU optimization strategies.

## Motivation
GEMM is the bottleneck in LLM inference; finding optimal CUDA library mapping (CUTLASS vs cuBLAS) and kernels across LLMs and GPU types requires systematic search.

## Method
CUrator generates CUTLASS/cuBLAS-friendly TVM graph IRs for LLMs (BERT, GPT, Llama), performs comprehensive CUTLASS tuning parameter search for each GEMM, introduces Split-K optimizations (reduction key init, batch support), and selects best cuBLAS/CUTLASS path per GEMM.

## Key Novelty
Systematic CUTLASS parameter tuning integrated into TVM with Split-K support for both Batch and regular GEMMs, combined with dual-path selection (cuBLAS vs CUTLASS).

## Contributions
- CUTLASS/cuBLAS mapping to TVM graph IRs for multiple LLMs
- Comprehensive CUTLASS kernel tuning framework
- Split-K optimizations for reduction key initialization and batch GEMMs
- 1.50x and 4.99x inference speedups on A100 GPU in single/half precision
