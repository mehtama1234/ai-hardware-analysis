# CUrator: An Efficient LLM Execution Engine with Optimized Integration of CUDA Libraries

**Venue:** CGO
**Confidence:** low

## Problem
Modern LLMs require optimal GEMM performance on diverse GPUs; existing CUTLASS and cuBLAS libraries offer tuning but lack systematic exploration of LLM-specific parameters and multi-GPU optimization strategies.

## Motivation
GEMM is the bottleneck in LLM inference; finding optimal CUDA library mapping (CUTLASS vs cuBLAS) and kernels across LLMs and GPU types requires systematic search.

## Method
CUrator takes LLM models (BERT, GPT, Llama) and converts them into a form that can be optimized using TVM, a compiler framework. It systematically tests configuration options for CUTLASS (NVIDIA's optimized matrix multiplication library) to find the best settings for each operation. To improve performance, it applies Split-K optimization (a technique for breaking matrix operations into smaller parallel pieces that efficiently combine their results, with special support for batch operations). Finally, it selects the faster option between cuBLAS and CUTLASS for each operation.

## Key Novelty
CUrator systematically tunes CUTLASS within TVM (a compiler framework) and selects the faster library between CUTLASS and cuBLAS for each operation, with extended Split-K support for both batch and regular multiplications.

## Contributions
- CUTLASS/cuBLAS mapping to TVM graph IRs for multiple LLMs
- Comprehensive CUTLASS kernel tuning framework
- Split-K optimizations for reduction key initialization and batch GEMMs
- 1.50x and 4.99x inference speedups on A100 GPU in single/half precision
