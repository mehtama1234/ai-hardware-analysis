# WAGES: Workload-Aware GPU Sharing System for Energy-Efficient Serverless LLM Serving

**Venue:** SC
**ID:** sc-2025-384
**Confidence:** low

## Problem

Serverless LLM serving uses static exclusive GPU allocation causing over-provisioning and low utilization; hardware-controlled clock frequencies waste energy.

## Motivation

Fine-grained GPU multiplexing and dynamic clock scaling can improve SLO attainment and energy efficiency for serverless LLM serving.

## Method

WAGES lets multiple requests share a single GPU using NVIDIA MPS (a technique that allows multiple processes to use one GPU simultaneously). It dynamically adjusts the GPU's streaming multiprocessors (compute cores) and clock speed based on what each request actually needs—allocating more resources and faster speeds for demanding workloads, less for lighter ones. A two-tier scheduling framework manages which requests run together and how resources are distributed.

## Key Novelty

By dynamically partitioning GPU streaming multiprocessors (compute cores) and adjusting clock speeds to match each request's workload needs, WAGES achieves both improved response-time targets and reduced energy consumption for serverless LLM serving.
