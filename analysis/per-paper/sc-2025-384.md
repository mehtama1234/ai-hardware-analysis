# WAGES: Workload-Aware GPU Sharing System for Energy-Efficient Serverless LLM Serving

**Venue:** SC
**ID:** sc-2025-384
**Confidence:** low

## Problem

Serverless LLM serving uses static exclusive GPU allocation causing over-provisioning and low utilization; hardware-controlled clock frequencies waste energy.

## Motivation

Fine-grained GPU multiplexing and dynamic clock scaling can improve SLO attainment and energy efficiency for serverless LLM serving.

## Method

WAGES: workload-aware GPU sharing using NVIDIA MPS; dynamically tunes SM partitions and clock speeds; two-tier scheduling framework.

## Key Novelty

Workload-aware SM partitioning and dynamic clock scaling for serverless LLM; simultaneous SLO improvement and energy reduction.

## Contributions

1. Workload-aware GPU multiplexing system
2. Dynamic SM partitioning and clock scaling
3. Two-tier scheduling framework
4. Model/KV migration overlap
5. 4% SLO improvement + 26% energy reduction
