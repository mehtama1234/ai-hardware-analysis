# Insights from Optimizing HPL Performance on Exascale Systems: A Comparative Analysis of Panel Factorization

**Venue:** SC
**Paper ID:** sc-2025-003
**Confidence:** low

## Problem Statement
HPL performance on exascale systems is sensitive to many interacting parameters; optimizing panel factorization for heterogeneous GPU-CPU systems is non-trivial

## Motivation
Exascale systems like Frontier are architecturally complex; HPL is primary benchmark for evaluating supercomputing performance; parameter tuning guidance is essential

## Method
The researchers tested HPL (a benchmark that measures supercomputer performance using large matrix operations) on Frontier, a supercomputer combining GPUs and CPUs. They built performance models to understand different strategies for panel factorization, which decomposes matrices by breaking them into manageable sections. They developed two approaches: one using dedicated CPU threads to manage work, and another running the factorization directly on GPU hardware using HIP cooperative groups (parallel programming tools that let GPU threads coordinate and share work).

## Key Novelty
Running panel factorization (the matrix decomposition step) directly on GPUs using HIP cooperative groups outperforms running it on CPUs on Frontier.
