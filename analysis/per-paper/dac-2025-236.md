# Versatile Cross-platform Compilation Toolchain for Schrödinger-style Quantum Circuit Simulation

**Venue:** DAC
**ID:** dac-2025-236

## Problem
Quantum circuit simulators are CPU/GPU-bound; existing tools (Qiskit, cuQuantum) lack cross-platform optimization and underutilize hardware for high-qubit simulations (30-32 qubits).

## Motivation
Quantum algorithm development requires efficient classical simulation; speedup unlocks verification of larger circuits before hardware availability.

## Method
The toolchain scans quantum circuits for unused qubits and fuses active gates together while skipping the empty ones—this 'sparsity-aware gate fusion' reduces the amount of computation needed. It then generates optimized code for the target platform: vectorized LLVM code for CPUs (processing multiple values in parallel) or PTX code for Nvidia GPUs. The system automatically selects the best fusion approach and platform for each circuit.

## Key Novelty
The core innovation is combining sparsity-aware gate fusion (skipping unused qubits) with platform-specific compilation (LLVM vectorization for CPUs, PTX generation for Nvidia GPUs).

## Contributions

- CAST cross-platform compilation toolchain for quantum simulation
- Sparsity-aware gate fusion for unused qubits
- LLVM IR vectorization for CPUs, PTX for GPUs
- 8.03x speedup vs Qiskit on 32-qubit CPU benchmarks
- 39.3x speedup vs cuQuantum on 30-qubit GPU benchmarks
