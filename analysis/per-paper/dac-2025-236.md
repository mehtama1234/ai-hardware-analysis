# Versatile Cross-platform Compilation Toolchain for Schrödinger-style Quantum Circuit Simulation

**Venue:** DAC
**ID:** dac-2025-236

## Problem
Quantum circuit simulators are CPU/GPU-bound; existing tools (Qiskit, cuQuantum) lack cross-platform optimization and underutilize hardware for high-qubit simulations (30-32 qubits).

## Motivation
Quantum algorithm development requires efficient classical simulation; speedup unlocks verification of larger circuits before hardware availability.

## Method
Cross-platform compilation toolchain (CAST) with sparsity-aware gate fusion to eliminate redundant qubits, LLVM IR vectorization for CPUs, PTX code generation for Nvidia GPUs. Automatically selects best fusion strategy and backend per platform.

## Key Novelty
Sparsity-aware gate fusion + cross-platform compilation for quantum simulation.

## Contributions

- CAST cross-platform compilation toolchain for quantum simulation
- Sparsity-aware gate fusion for unused qubits
- LLVM IR vectorization for CPUs, PTX for GPUs
- 8.03x speedup vs Qiskit on 32-qubit CPU benchmarks
- 39.3x speedup vs cuQuantum on 30-qubit GPU benchmarks
