# COTIA: Concolic Testing with Intelligent Agent

**Venue:** ICCAD  
**ID:** iccad-2025-196

## Problem
Concolic testing for hardware verification suffers from suboptimal path exploration due to local optima in heuristics, leading to incomplete coverage of corner cases.

## Motivation


## Method
The system uses a large language model to guide an agent exploring hardware through beam search, which maintains multiple candidate paths simultaneously instead of following a single path. The LLM learns from each test execution which paths are more likely to find corner cases and adjusts the exploration strategy in real-time. This dynamic guidance helps the agent escape the dead ends where traditional heuristics typically get stuck.

## Key Novelty
COTIA is the first to use large language models with beam search to dynamically guide path exploration in hardware concolic testing.

## Contributions
- LLM-based intelligent agent framework for path exploration
- Significantly improved branch coverage especially for hard-to-detect branches
- Optimized computational resource usage during verification
