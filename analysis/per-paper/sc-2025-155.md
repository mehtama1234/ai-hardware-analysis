# SC-2025-155: Data Race Detection via Vibe Translation

## Summary
Novel approach to data race detection by translating C/Fortran+OpenMP programs to Go via LLM, then using Go's built-in race detector.

## Problem
- ThreadSanitizer + Archer miss some races in OpenMP programs
- Single-language detection limited by tool design
- Need complementary detection strategies

## Method: Translate-Then-Check
1. Use AI-agent with natural-language prompts (vibe coding) to translate C/Fortran+OpenMP → Go
2. Run Go's dynamic race detector on translated code
3. Compare results against native detectors

## Results (DataRaceBench, C programs)
| Approach | Accuracy | False Negatives |
|----------|----------|-----------------|
| **Translate-then-check** | 92.8% | 9 |
| **Clang TSanitizer + Archer** | 89.9% | 17 |

**Advantage**: 3% accuracy improvement, 47% fewer false negatives.

## Novelty
Leverages LLM translation to expose different race detection paths; Go's semantics catch races missed by C/Fortran tools.

## Limitations
- Quality depends on translation accuracy
- Go detector has own blind spots
- Not all programs translatable to Go
- No false positive rate reported

## Hardware Context
- OpenMP-enabled CPUs (x86, ARM)
- Multi-core shared-memory systems
