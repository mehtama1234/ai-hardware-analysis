# EPICS: Efficient Parallel Pattern Fault Simulation for Sequential Circuits via Strongly Connected Components
**Venue:** DAC

## Problem
Gate-level fault simulation for large sequential circuits is time-consuming; existing parallel-pattern techniques fail for sequential circuits due to timing dependencies within feedback loops (strongly connected components).

## Motivation
Functional safety standards (ISO 26262) mandate high diagnostic fault coverage; accelerating fault simulation reduces chip verification time.

## Method
EPICS speeds up fault simulation by combining loop fusion—compiling simple loops into larger blocks—with event-driven simulation (updating only when signal values actually change). To handle circuits with feedback loops (strongly connected components), it identifies entry points using indegree analysis (counting incoming connections) and selectively compiles larger loops while using lazy propagation (computing internal values only when needed). This hybrid approach—mixing compiled code for speed with event-driven updates for flexibility—enables the parallel execution that traditional methods cannot safely support.

## Key Novelty
EPICS' core innovation is using loop fusion guided by feedback-loop awareness (strongly connected component analysis) to enable safe parallel-pattern fault simulation of sequential circuits.

## Contributions
1. 5.94x speedup over commercial tools while maintaining fault coverage
2. Loop fusion reduces feedback events without excessive redundancy
3. Lazy propagation minimizes false event propagation overhead
