# sc-2025-221: HPC Scheduling for Urgent Workloads

## Overview
Systematic analysis framework for HPC scheduler configurations to handle mixed-urgency workloads, providing practical guidance for production environments.

## Key Problem
HPC centers increasingly face workloads with diverse urgency requirements. Current schedulers optimized for single-urgency scenarios; need strategies balancing urgent rapid execution with overall efficiency.

## Approach
1. Evaluate multiple job scheduling simulators
2. Develop lightweight job-submission emulation framework
3. Create analysis and visualization tools for scheduler metrics
4. Test configurations across urgency scenarios
5. Identify key trade-offs

## Contributions
- Mixed-urgency scheduler evaluation framework
- Practical job-submission emulation methodology
- Scheduling analysis and visualization tools
- Practical Slurm configurations for production
- Trade-off analysis: responsiveness vs fairness vs efficiency

## Key Trade-offs Identified
- **Responsiveness**: Fast execution for urgent jobs
- **Fairness**: Equitable resource access for standard jobs
- **Efficiency**: Overall cluster utilization

## Focus
Tailored for Slurm scheduler (primary production system)

## Confidence
Low (framework-focused, limited specific scheduling recommendations in abstract)
