# SNARY: A High-Performance and Generic SmartNIC-accelerated Retrieval System

**Problem:** Retrieval workloads in data centers create CPU bottlenecks and network latency. Existing systems lack a generic, efficient mechanism to offload diverse retrieval operations to SmartNIC hardware.

**Method:** SNARY offloads retrieval query execution to the SmartNIC data plane using programmable packet processing. It implements efficient in-memory data structures and query logic on SmartNIC hardware while exposing a generic interface supporting diverse retrieval patterns and workload types without custom hardware modification.

**Novelty:** Generic SmartNIC-accelerated architecture that unifies diverse retrieval workloads without requiring custom hardware redesign.
