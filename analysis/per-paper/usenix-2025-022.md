# SNARY: A High-Performance and Generic SmartNIC-accelerated Retrieval System

**Problem:** Retrieval workloads in data centers create CPU bottlenecks and network latency. Existing systems lack a generic, efficient mechanism to offload diverse retrieval operations to SmartNIC hardware.

**Method:** SNARY moves database searches from the CPU to a SmartNIC—a network card with its own processor that can run custom code. It stores lookup tables and search logic directly on this hardware, using programmable packet processing (custom instructions for handling network data) to run searches while data passes through. Because the search happens on the network card itself rather than the CPU, it avoids the bottleneck of shipping data back and forth. The system exposes a simple, flexible interface so many different types of searches can run on the same hardware without needing to redesign it.

**Novelty:** SNARY lets many different types of database searches run on the same SmartNIC hardware without having to build custom versions for each one.
