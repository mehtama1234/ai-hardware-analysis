# Constraint-Driven Auto-Tuning of GEMM-like Operators for MT-3000 Many-core Processor

**Venue:** SC 2025  
**Authors:** Xinxin Qi, Jianbin Fang, Peng Zhang, Yonggang Che, Jie Ren

## Problem & Motivation

The MT-3000 and similar emerging heterogeneous many-core processors present a fundamental challenge: optimizing deep learning operators (especially GEMM) requires navigating enormous search spaces while respecting hardware-specific constraints. Hand-crafted library development is expensive and error-prone, while general-purpose autotuners fail to exploit hardware-specific opportunities, resulting in sub-optimal performance.

## Approach

**DynaChain** introduces a multi-layer optimization strategy:

1. **Computation-Data Movement Decoupling:** Optimizes computation and data movement independently, enabling global data reuse maximization.
2. **Constraint Dependency Chains:** Dynamically eliminates invalid scheduling options during search, reducing exploration overhead.
3. **ILP-Based Decomposition:** Handles irregular matrix dimensions via integer linear programming without resorting to padding.
4. **Hardware-Aware Micro-Kernels:** VLIW+SIMD-optimized micro-kernel design with improved register allocation and instruction pipelining.

## Key Novelty

- **Dynamic Search Space Pruning:** Constraint dependency chains eliminate impossible configurations before exploration.
- **Padding-Free Irregular Handling:** ILP-based decomposition avoids performance penalties from zero-padding.
- **Architecture-Specific Micro-Kernels:** Direct optimization for MT-3000's VLIW+SIMD execution model.

## Contributions

- Operator-level optimization framework specifically designed for MT-3000
- Constraint dependency chain approach reducing search space
- ILP-based method handling irregular dimensions without padding
- Hardware-aware micro-kernel design exploiting VLIW+SIMD parallelism
- Simplified kernel development matching expert-hand-optimized performance

## Hardware Target
