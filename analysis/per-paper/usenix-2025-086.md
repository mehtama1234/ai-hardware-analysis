# Internet Connection Splitting: What's Old is New Again

**Problem:** Systems with multiple network interfaces fail to fully utilize available bandwidth in parallel due to routing decisions that concentrate traffic on single paths. Modern data center topologies support multi-path forwarding but lack transparent splitting mechanisms.

**Method:** The system distributes data across multiple available network paths simultaneously, using classical load-balancing techniques that send entire conversations down one path or spread packets across all paths. It maintains packet ordering and respects network congestion. By applying these techniques transparently—without requiring applications to change—systems fully utilize the multi-path capabilities of modern data centers.

**Novelty:** Transparent, automatic splitting of network connections across multiple paths, extending classical load-balancing to modern multi-path data centers.
