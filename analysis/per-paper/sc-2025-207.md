# Optimizing Data Acquisitions in Multi-Robot Systems

**Venue:** SC  
**Theme:** Robotics and Distributed Systems  
**Confidence:** low

## Problem Statement
Multi-robot systems lack efficient mechanisms for real-time cross-robot data acquisition; traditional file systems fail to exploit robot data temporal locality

## Motivation
Multi-robot coordination requires timely data sharing; improving data freshness and query latency enables collaborative robotics at scale

## Methodology
ROSfs user-level filesystem: labeled sub-file organization with time-indexed queries for active data; integrates with ROS ecosystem; evaluated on physical UAV/UGV platforms

## Key Novelty
First user-level filesystem for multi-robot data management; introduces time-indexed query model for temporal data retrieval

## Contributions
- Novel labeled sub-file data organization for robot data
- Time-indexed architecture enabling efficient query
- ROS ecosystem integration
- 7x reduction in online data query latency
- 271x improvement in data freshness (Age of Information)

## Hardware Targets
Robot platforms, UAV/UGV systems

## Technique Categories
Robotics, Distributed systems, File systems

## Workloads
Multi-robot coordination, Real-time data acquisition

## Performance Metrics
- **query_latency_reduction:** 7x
- **age_of_information_improvement:** 271x
- **network_conditions:** wireless

## Baselines Compared
- Conventional ROS storage
- Traditional file systems

## Limitations & Future Work
Limited to ROS platform; wireless network evaluation only; scalability to large robot swarms not demonstrated
