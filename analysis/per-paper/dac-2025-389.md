# SynGPU: Synergizing CUDA and Bit-Serial Tensor Cores for Vision Transformer Acceleration on GPU

**Venue:** DAC
**ID:** dac-2025-389

## Problem
Vision Transformers suffer from quadratic time/memory complexity in self-attention, leading to inefficiency on GPUs despite token pruning methods overlooking bit-level sparsity.

## Motivation
Vision transformers are memory-bound; exploiting bit-level sparsity can improve compute efficiency beyond token-level sparsity.

## Method
The system uses an Inter-token Bit-sparsity Awareness algorithm to detect patterns of zero-bits within similar tokens, which previous pruning methods missed. It implements this using a Bit-Serial Tensor Core—specialized GPU hardware that performs the core multiplication-accumulation operations (the basic math that powers transformers) in both fixed-point whole numbers and floating-point decimal numbers in parallel. The technique uses novel data mapping to coordinate CUDA and Tensor Core parallelism, allowing both types of processing to run at full speed simultaneously.

## Key Novelty
The core innovation is a Bit-Serial Tensor Core that combines fixed-point and floating-point computation with exponent alignment, enabling efficient processing of sparse-bit vision transformer data.

## Contributions
1. Inter-token Bit-sparsity Awareness (IBA) algorithm exploiting bit-level sparsity across similar tokens
2. Bit-Serial Tensor Core (BSTC) supporting both fixed and floating-point operations
3. Novel data mapping enabling full parallelism of CUDA and Tensor Cores
4. 2.15-3.95x speedup and 2.49-3.81x compute density improvement over A100
