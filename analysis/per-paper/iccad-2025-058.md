# Tasa: Thermal-aware 3D-Stacked Architecture Design with Bandwidth Sharing for LLM Inference

**Venue:** ICCAD | **ID:** iccad-2025-058

## Problem
3D-stacked architecture provides improved memory bandwidth for LLM inference but faces severe thermal issues with higher peak temperature, gradients, and poor scalability compared to 2D. Homogeneous stacking creates imbalanced workload distribution.

## Motivation
Exploit 3D-stacked memory bandwidth while maintaining thermal constraints and scalability for LLM inference.

## Method
The system uses two different types of cores instead of identical ones: a fast, heat-producing core for computation-heavy tasks and an efficient core for memory-intensive operations like attention mechanisms. The fast core handles math work like matrix multiplications, while the efficient core focuses on data access that requires high memory bandwidth. By separating these workloads, the design avoids concentrating heat in one spot. A bandwidth scheduler allocates shared memory access between the cores to prevent waste, and thermal management techniques spread heat evenly across the stacked layers to prevent dangerous hot spots.

## Key Novelty
A 3D-stacked chip design using two different core types—one fast for computing, one efficient for memory access—that combines thermal management with memory bandwidth sharing to accelerate large language model inference.

## Contributions
- Heterogeneous high-performance and high-efficiency core design for LLM operations
- Bandwidth sharing scheduling for heterogeneous architecture
- Cross-stack thermal optimizations improving scalability and temperature balance

## Metrics
- **Speedup:** 2.85x vs GPU baseline (Llama-65B); 2.21x vs GPU (GPT-3 66B)
- **Other:** 5.55-9.37°C peak temperature reduction for 48-72 core configurations

- homogeneous 3D-stacked architecture
- PIM-based LLM accelerators

## Limitations
Evaluation limited to two LLMs; thermal characteristics may vary with different workloads.
