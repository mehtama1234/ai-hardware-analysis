# Faster Chaitin-like Register Allocation via Grammatical Decompositions of Control-Flow Graphs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** parameterized register allocation via CFG treewidth decomposition

## Problem
Register allocation via graph coloring (Chaitin-style) is NP-hard in general, but practical compilers rely on heuristics that do not exploit the sparse, structured nature of real program CFGs, leading to suboptimal allocation or unnecessary spills.

## Motivation
CFGs of structured programs have bounded treewidth/pathwidth, and exploiting this structure enables faster parameterized graph-coloring algorithms that improve allocation quality or speed in practice.

## Method
The method uses treewidth—a measure of how tree-like a program's control-flow graph is—rather than the graph's size to determine algorithm speed. It breaks the control-flow graph (the map of code branches and loops) into tree-shaped pieces through grammatical decomposition (like parsing a sentence). Register allocation (assigning the CPU's limited fast memory slots to variables) is solved using dynamic programming on these pieces. Since real program control-flow graphs naturally have small treewidth, this enables exact or near-exact solutions to be computed fast enough for practical use.

## Key Novelty
The key insight is that program control-flow graphs have tree-like structure (small treewidth), enabling much faster register allocation through tree decomposition.

## Contributions
- Formal characterization of structured program CFGs via treewidth and pathwidth bounds
- Grammatical decomposition framework for CFGs enabling DP-based register allocation
- Faster Chaitin-like algorithm parameterized by CFG treewidth
- Extension of parameterized algorithm techniques to register allocation
