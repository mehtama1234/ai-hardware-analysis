# Ph.D. Project: A Novel Compilation-Based Approach for Generating Sparse Tensor Accelerators

**Problem:** Sparse tensor irregularity challenges GPU/NPU acceleration, and current point-wise manual FPGA design methodologies do not scale efficiently across diverse sparse scenarios.

**Method:** The approach uses a compiler—a tool that translates descriptions into hardware designs—with three components. First, a simple language based on scheduling primitives (basic building blocks for describing how to organize computations) lets you specify what the accelerator should do. Second, a two-step mapping process translates how data flows through computations into actual hardware using sparse meta-operations (reusable patterns for efficient sparse operations). Third, an automated search strategy guided by your actual workload explores different hardware designs and picks the fastest.

**Novelty:** The key idea is automatically generating sparse tensor hardware accelerators using a compiler that translates from a simple scheduling-based description language (combining basic building blocks) to hardware using reusable sparse computation patterns.
