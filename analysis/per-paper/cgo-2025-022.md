# SkipFlow: Improving the Precision of Points-to Analysis using Primitive Values and Predicate Edges

**Venue:** CGO
**Confidence:** low

## Problem
Traditional points-to analysis (Andersen/Steensgaard) loses precision by ignoring branching structure and primitive value flows, leading to unnecessary imprecision when constants flow across method boundaries.

## Motivation
Precise points-to analysis is crucial for closed-world binary generation (e.g., GraalVM Native Image); precision losses directly increase binary size and harm optimization.

## Method
SkipFlow improves points-to analysis—a technique for determining what values variables can hold—by analyzing code in two stages: a quick pass treating each function separately, then refinement using information about which functions call which. Throughout, it tracks both primitive values (numbers, booleans) and objects, using predicate edges (edges representing which branches code takes) to capture control flow, gaining precision without the cost of flow-sensitivity (tracking every possible execution path).

## Key Novelty
Predicate edges (edges representing control-flow branches) combined with primitive value tracking improve points-to analysis precision without needing flow-sensitivity (tracking every possible execution path).

## Contributions
- Lightweight points-to analysis tracking both primitives and objects
- Predicate edges to capture branching structure
- 9% average reduction in reachable methods for microservices without significant analysis time increase
