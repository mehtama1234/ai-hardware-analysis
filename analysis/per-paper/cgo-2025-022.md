# SkipFlow: Improving the Precision of Points-to Analysis using Primitive Values and Predicate Edges

**Venue:** CGO
**Confidence:** low

## Problem
Traditional points-to analysis (Andersen/Steensgaard) loses precision by ignoring branching structure and primitive value flows, leading to unnecessary imprecision when constants flow across method boundaries.

## Motivation
Precise points-to analysis is crucial for closed-world binary generation (e.g., GraalVM Native Image); precision losses directly increase binary size and harm optimization.

## Method
SkipFlow interprocedurally tracks both primitives and objects, capturing branching structure via predicate edges without full flow-sensitivity. Two-stage approach: context-insensitive parsing, then context-sensitive refinement during inlining using call graph information.

## Key Novelty
Predicate edges to explicitly capture control-flow information in points-to analysis, combined with primitive value tracking for improved precision without flow-sensitivity overhead.

## Contributions
- Lightweight points-to analysis tracking both primitives and objects
- Predicate edges to capture branching structure
- 9% average reduction in reachable methods for microservices without significant analysis time increase
