# PyraNet: A Multi-Layered Hierarchical Dataset for Verilog

**Venue:** DAC | **ID:** dac-2025-261

## Problem
LLMs generate poor-quality Verilog due to lack of well-organized, high-quality datasets and specialized fine-tuning methods for hardware description languages.

## Key Innovation
Multi-layered hierarchical dataset structure (PyraNet) specifically designed for Verilog fine-tuning, enabling substantially better code generation quality through improved training data organization.

## Method
PyraNet is an open-source collection of Verilog code (the language engineers use to describe hardware) organized in layers that progress from simple components to complete designs. When fine-tuning (customizing) large language models with this structured data, the layered organization helps the models learn the systematic patterns of correct hardware code. By training on organized examples rather than random data, the LLMs learn to generate Verilog that is both syntactically correct (follows language rules) and functionally correct (actually works as intended).

## Results (VerilogEval)
- 32.6% improvement over CodeLlama-7B baseline
- 16.7% improvement over state-of-the-art models
- Syntactically and functionally correct code generation

## Contributions
- Open-source PyraNet dataset
- Fine-tuning methodology for hierarchical data
- Significant improvements in code correctness

## Limitations
Evaluation only on VerilogEval; scalability to other HDLs (VHDL, Chisel) not addressed.
