# coMtainer: Compilation-assisted HPC Container Images with Enhanced Adaptability

**Venue:** SC
**ID:** sc-2025-122
**Confidence:** low

## Problem
Containers simplify HPC deployment but fail to deliver optimal performance due to separated build/execution workflows, missing system-specific optimizations.

## Motivation
Generic container images cannot leverage system-specific toolchains and libraries, forcing trade-offs between portability and performance.

## Method
coMtainer saves build-time metadata (information about how the code was originally compiled) in the container. When deployed on a remote supercomputing system, that system can recompile the container using its native compilers and apply LTO (Link Time Optimization) and PGO (Profile Guided Optimization, which uses performance data to make code faster). This allows containers to remain portable across systems while still being optimized for each system's specific hardware.

## Key Novelty
coMtainer embeds build-time metadata in containers, enabling remote HPC systems to automatically optimize them for local hardware without losing portability.

## Contributions
1. Build-time metadata embedding in containers
2. Remote specialization via native toolchains
3. Advanced compiler optimizations (LTO/PGO) support
