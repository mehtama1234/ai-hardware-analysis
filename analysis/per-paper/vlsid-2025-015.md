# Low-Power and Superior Performance Design of Ternary Logic Cells Using CNFET and MOSFET Devices for VLSI Applications

**Venue:** VLSID

## Problem
Ternary logic implementation faces challenges in power efficiency and performance

## Motivation
Ternary logic can provide efficiency benefits, but traditional MOSFET implementations have high power dissipation

## Method
The researchers design ternary logic cells (circuits using three operating states instead of the two used in standard transistors) using CNFETs (carbon nanotube transistors) and MOSFETs (standard silicon transistors), testing designs named NTI, PTI, and STI at 45nm technology. They exploit a key difference: CNFETs' threshold voltage—the electrical point where they turn on—can be tuned and adjusted, whereas MOSFETs cannot. This tunable property lets them optimize the ternary cells for both lower power consumption and superior performance.

## Key Novelty
Ternary logic cells built with carbon nanotube transistors (CNFETs) that have tunable threshold voltage achieve better power efficiency than those using standard silicon transistors (MOSFETs).
