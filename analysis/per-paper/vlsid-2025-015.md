# Low-Power and Superior Performance Design of Ternary Logic Cells Using CNFET and MOSFET Devices for VLSI Applications

**Venue:** VLSID

## Problem
Ternary logic implementation faces challenges in power efficiency and performance

## Motivation
Ternary logic can provide efficiency benefits, but traditional MOSFET implementations have high power dissipation

## Method
Compare CNFET and MOSFET ternary logic cells (NTI, PTI, STI) at 45nm; leverage tunable threshold voltage of CNFETs

## Key Novelty
CNFET-based ternary logic cells with controllable threshold voltage for improved power efficiency
