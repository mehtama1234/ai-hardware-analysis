# DIVE: Dynamic Information-Guided Variable Expansion for Deeper Analog Circuit Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-126

## Problem
Transistor sizing has high-dimensional parameter spaces and expensive simulations; Bayesian optimization struggles with the curse of dimensionality when exploring all parameters simultaneously.

## Motivation
Faster analog circuit design with fewer simulations enables rapid iteration and better design exploration.

## Method
DIVE avoids the problem of optimizing all transistor sizes at once, which becomes computationally infeasible when there are many parameters (a problem called curse of dimensionality). Instead, it uses information theory to identify which transistor sizes are most critical by calculating which parameters would provide the most useful information if optimized, while respecting design rules. It tunes only these critical transistors first using a machine learning technique called Gaussian process regression, which learns which parameters matter most and guides the search. As optimization progresses, it progressively adds more parameters to tune, mimicking how experienced circuit designers prioritize the most critical components.

## Key Novelty
Progressive parameter expansion based on information theory, starting with the most critical transistor sizes and adding more as needed, mimicking how experienced circuit designers work.

## Contributions
- Constraint-aware weighted mutual information analysis for parameter importance evaluation
- Adaptive variable inclusion mechanism for dynamic parameter space expansion
- Mutual information-guided kernel learning for improved Gaussian process models
