# DIVE: Dynamic Information-Guided Variable Expansion for Deeper Analog Circuit Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-126

## Problem
Transistor sizing has high-dimensional parameter spaces and expensive simulations; Bayesian optimization struggles with the curse of dimensionality when exploring all parameters simultaneously.

## Motivation
Faster analog circuit design with fewer simulations enables rapid iteration and better design exploration.

## Method
DIVE reformulates parameter optimization as information efficiency maximization problem; progressively includes design variables with highest information content using constraint-aware weighted mutual information analysis, adaptive variable inclusion mechanism, and MI-guided Gaussian process kernel learning.

## Key Novelty
Progressive parameter expansion based on information theory, mimicking experienced designer workflows of focusing on critical parameters first.

## Contributions
- Constraint-aware weighted mutual information analysis for parameter importance evaluation
- Adaptive variable inclusion mechanism for dynamic parameter space expansion
- Mutual information-guided kernel learning for improved Gaussian process models

## Limitations
