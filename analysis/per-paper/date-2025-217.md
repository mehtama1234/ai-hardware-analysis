# CPP-SGS: Cycle-Accurate Power Prediction Framework via SNN and Genetic Signal Selection

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Combine Spiking Neural Networks (SNNs) for temporal power dynamics with Genetic Algorithms (GAs) to select only the most relevant signals as SNN inputs, enabling efficient real-time power prediction.

## Problem
Accurate cycle-level power prediction requires monitoring many signals; traditional approaches scale poorly for runtime power management.

## Method
The method uses Genetic Algorithms (a search technique that mimics evolution) to identify which signals flowing through a chip matter most for power prediction, then feeds only those key signals into Spiking Neural Networks (neural networks modeled on how neurons fire in bursts, which efficiently learn patterns over time). By reducing the number of signals needed, the model becomes smaller and faster to run, enabling real-time power management.

## Key Results
- **NRMSE < 1.6%** on power prediction
- Outperforms state-of-the-art approaches
