# OptiRange: An Efficient ReRAM-Based PIM Accelerator with ADC Resolution Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-075

## Problem
ReRAM-based in-memory computing (IMC) accelerators suffer from high energy consumption in ADCs and throughput limitations when using low-resolution ADCs or shared ADC architectures. Maintaining model accuracy while reducing ADC cost is a key bottleneck.

## Motivation
Mitigating the memory wall for DNN inference through energy-efficient in-memory computing while reducing the area and power overhead of peripheral ADC circuits is critical for practical PIM deployment.

## Method
OptiRange proposes three algorithmic and architectural innovations:
1. **Split-the-Burden (STB) algorithm** that manipulates crossbar cell values to reduce large cell values and shift column-sum distribution toward zero, lowering required ADC resolution
2. **Dynamic ADC Range (DAR) adaptation** that determines optimal ADC operating ranges per column at runtime and skips redundant conversion cycles
3. **ADC range-based grouping (AG) strategy** that leverages dynamic latencies to manage synchronization and boost throughput without sacrificing accuracy

## Key Novelty
Weight-preserving cell manipulation combined with adaptive column-wise ADC range selection enables dynamic ADC workload optimization without changing the original model weights.

## Contributions
- Split-the-Burden algorithm for cell value manipulation that reduces LRS cells and lowers fixed ADC resolution requirements
- Dynamic ADC range adaptation at software level enabling selective skipping of conversion cycles
- ADC range-based grouping strategy for improved synchronization and system throughput
- Experimental validation showing significant energy and performance improvements over conventional ReRAM accelerators
