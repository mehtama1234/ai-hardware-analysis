# BLAZE: Exploiting Hybrid Parallelism and Size-customized Kernels to Accelerate BLASTP on GPUs

**Venue:** SC
**ID:** sc-2025-125
**Confidence:** low

## Problem
BLASTP (sequence alignment) on GPUs remains slower than optimized CPU/multithreaded implementations despite GPU acceleration attempts.

## Motivation
Biological sequence search is ubiquitous; GPU acceleration is needed for high-throughput screening of large databases.

## Method
BLAZE accelerates BLASTP (a tool for comparing DNA or protein sequences) on GPUs by using hybrid parallelism, which means it switches between fine-grained parallelism (many small parallel tasks) and coarse-grained parallelism (fewer large tasks) based on what works best for each piece of data. Instead of using one kernel (a GPU program) for all sequences, BLAZE creates specialized kernel versions tuned for different sequence lengths, since a single kernel wastes GPU resources when sequences don't match its optimized size. The approach also applies additional GPU-specific optimizations. This combination allows BLAZE to outperform hand-optimized CPU implementations.

## Key Novelty
BLAZE combines adaptive parallelism—switching between fine-grained and coarse-grained work distribution—with kernels customized for different sequence lengths to make GPUs faster than CPUs at sequence comparison.
