# BLAZE: Exploiting Hybrid Parallelism and Size-customized Kernels to Accelerate BLASTP on GPUs

**Venue:** SC
**ID:** sc-2025-125
**Confidence:** low

## Problem
BLASTP (sequence alignment) on GPUs remains slower than optimized CPU/multithreaded implementations despite GPU acceleration attempts.

## Motivation
Biological sequence search is ubiquitous; GPU acceleration is needed for high-throughput screening of large databases.

## Method
BLAZE combines hybrid fine/coarse-grained parallelism, sequence-length-customized kernels, and GPU-specific optimizations for BLASTP.

## Key Novelty
Hybrid parallelism + length-customized kernels for efficient GPU BLASTP acceleration

## Contributions
1. Hybrid fine/coarse-grained parallelism
2. Length-customized kernel generation
3. 18.2x vs single-threaded, 4.8x vs previous GPU, 1.9x vs 16-way multithreaded
