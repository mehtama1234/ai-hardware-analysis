# A Peak Performance Model for All-to-all on Hierarchical Systems and Its Applications

**ID**: sc-2025-363
**Venue**: SC
**Confidence**: low

## Problem
Optimizing communication performance in hierarchical multi-GPU systems

## Motivation
Emerging hardware and scale challenge existing approaches

## Method
The method creates a mathematical model that calculates the maximum possible speed for all-to-all communication—where every GPU in a multi-GPU system sends data to every other GPU. The model accounts for the system's hierarchy, recognizing that some communication pathways (like between GPUs on the same computer) are faster than others (like between separate computers). By analyzing these different communication speeds mathematically, it derives what the theoretical performance limit should be, which lets you evaluate whether an actual implementation is performing well.

## Key Novelty
This is the first mathematical model to predict the peak performance specifically for all-to-all communication patterns in hierarchical multi-GPU systems.
