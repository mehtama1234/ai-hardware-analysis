# dac-2025-433: Teacher-Student Bayesian Optimization for RISC-V Design Exploration

**Problem:** RISC-V design space exploration suffers high model errors and lacks constraint handling.

**Motivation:** RISC-V customization requires vast space exploration respecting synthesis constraints; existing methods fail on feasibility.

**Method:** SRBO improves the search for optimal RISC-V processor designs by using a teacher-student model setup within Bayesian optimization—a method that learns from each design test to guide the next search smartly. One model (the teacher) trains a simpler backup model (the student) to predict and correct errors before they mislead the search. Multiple neural networks (deep ensembles) then vote on whether each design meets practical constraints like power consumption and chip size, ensuring only feasible options move forward.

**Key Novelty:** Teacher-student Bayesian optimization for error reduction and constraint feasibility.

**Contributions:**
- Teacher-student BO framework reducing model errors
- Deep ensemble constraint handling
- Outperforms SOTA within time budgets

**Hardware Target:** RISC-V
