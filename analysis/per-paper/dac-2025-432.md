# dac-2025-432: Multi-Agent LLM System for Correct Verilog RTL Generation

**Problem:** Single-LLM RTL generation fails to produce syntactically and functionally correct Verilog.

**Motivation:** Automated RTL from natural language speeds hardware design but requires correctness guarantees.

**Method:** MAGE uses multiple AI agents working together to generate Verilog code. The system generates many diverse candidates by using high-temperature sampling (varying how randomly the AI makes choices to explore more options). It immediately tests each candidate and catches functional errors, providing precise feedback about what broke. Agents then iteratively refine the code based on this feedback until it works correctly.

**Key Novelty:** Verilog-state checkpointing for early functional error detection in multi-agent RTL generation.

**Contributions:**
- High-temperature RTL candidate sampling
- Early functional error detection via Verilog checkpoints
- Multi-agent generation/verification/debugging
- 95.7% correctness; 23.3% improvement over Claude-3.5-sonnet

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
