# Accelerating Gravitational N-Body Simulations Using the RISC-V-Based Tenstorrent Wormhole

## Overview
RISC-V accelerator (Tenstorrent Wormhole n300) validation for scientific computing via astrophysical N-body simulation acceleration.

## Problem & Motivation
- **Challenge**: N-body simulations computationally expensive; traditional CPU throughput limited
- **Opportunity**: RISC-V accelerators designed for AI but potentially suitable for scientific computing
- **Platform**: Tenstorrent Wormhole n300 (RISC-V-based accelerator)

## Architecture & Method
**Implementation**
- Astrophysical N-body code ported to RISC-V Wormhole
- Comparison against highly optimized CPU baseline
- Speedup and energy efficiency measurement

## Key Contributions
1. **>2× speedup** vs highly optimized CPU
2. **~2× energy savings** vs CPU
3. **RISC-V accelerator validation** for scientific computing
4. **N-body benchmark** for emerging accelerator platforms

## Performance & Results
| Metric | Result |
|--------|--------|
| Speedup | >2× vs CPU |
| Energy Efficiency | ~2× savings vs CPU |

## Hardware Insights
- RISC-V accelerators competitive for non-AI scientific workloads
- Tenstorrent Wormhole suitable for embarrassingly parallel algorithms (N-body)
- Energy efficiency comparable to GPU-class performance

## Limitations
- **Single workload**: Only N-body evaluation
- **No GPU comparison**: GPU accelerators clearly relevant (not compared)
- **Scalability unclear**: Large simulation behavior not discussed
- **Energy methodology**: Measurement details sparse
- **Abstract-only**: Limited implementation details

## Relevance to Hardware/AI Systems
**Medium relevance**: Validates alternative accelerator architecture for scientific computing, but single workload limits generalizability. Demonstrates RISC-V viability but lacks comparison with mature GPU alternatives.
