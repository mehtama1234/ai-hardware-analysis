# TickTockStack: In-Datapath Current Imbalance Elimination Using Clocked Differential Logic in a Voltage Stacked Vector Processor

**Venue:** ICCAD | **ID:** iccad-2025-053

## Problem
Voltage stacking mitigates PDN loss but suffers from voltage ripple and power delivery loss due to current imbalance of stacked circuits. CMOS logic activity variations create data-dependent imbalance.

## Motivation
Reduce power delivery loss in high-power-density chips while maintaining frequency and reliability.

## Method
Voltage-stacked vector processor with architecture-circuit co-optimization: datapath implemented using clocked dual-rail domino logic with constant activity factor and differential structure; register file as fully differential latch-based structure with symmetrical multiplexers; single-ended CMOS control logic. Synchronized execution across vector lanes minimizes control-driven variation.

## Key Novelty
In-datapath current imbalance elimination via clocked differential logic with constant activity factor.

## Contributions
- Clocked dual-rail domino datapath design with constant activity factor
- Fully differential register file with symmetrical architecture
- Architecture-circuit co-optimization for voltage-stacked processors
