# TickTockStack: In-Datapath Current Imbalance Elimination Using Clocked Differential Logic in a Voltage Stacked Vector Processor

**Venue:** ICCAD | **ID:** iccad-2025-053

## Problem
Voltage stacking mitigates PDN loss but suffers from voltage ripple and power delivery loss due to current imbalance of stacked circuits. CMOS logic activity variations create data-dependent imbalance.

## Motivation
Reduce power delivery loss in high-power-density chips while maintaining frequency and reliability.

## Method
The design stacks voltage across multiple circuits to save power, but prevents the resulting voltage ripple and power loss by using clocked differential logic (symmetric circuit pairs) in the datapath to maintain constant current consumption every cycle. The register file uses fully differential latches with symmetrical multiplexers to maintain balance in stored data. Control signals remain standard CMOS, and execution across all parallel lanes stays synchronized to prevent variation from accumulating.

## Key Novelty
It solves the current imbalance problem that voltage stacking creates by using differential logic (symmetric circuits that draw constant current each cycle) in the datapath.

## Contributions
- Clocked dual-rail domino datapath design with constant activity factor
- Fully differential register file with symmetrical architecture
- Architecture-circuit co-optimization for voltage-stacked processors
