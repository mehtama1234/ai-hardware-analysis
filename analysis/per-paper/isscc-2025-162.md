# isscc-2025-162: SambaNova SN40L 2.5D Dataflow Accelerator

**Problem:** Trillion-parameter LLM training/inference require extreme bandwidth and capacity; single-memory-tier accelerators bottlenecked; 2.5D chiplets need careful dataflow coordination.

**Motivation:** Cloud AI workloads scale to trillion parameters; infrastructure needs energy-efficient trillion-parameter model training and inference.

**Method:** Reconfigurable Dataflow Unit (RDU) with three-tier memory: on-chip SRAM (bandwidth), on-package HBM (capacity + bandwidth), off-package DRAM (capacity). Dual-die 2.5D CoWoS-S with two 600mm2 dies (5nm). Peer-to-peer fabric for intra-die comms; die-to-die HBM stacking. Each: 102B transistors, 640 BF16 TFLOPs, 520MB SRAM.

**Key Novelty:** Dual-die 2.5D reconfigurable dataflow with three-tier memory supporting trillion-parameter AI.

**Contributions:**
- Trillion-parameter training/inference
- 2.5D dual-die (600mm2 each, 5nm)
- Three-tier memory hierarchy
- 640 BF16 TFLOPs/die, 520MB SRAM

**Hardware Target:** ASIC, accelerator

**Technique Categories:** dataflow, memory-system, packaging, interconnect

**Workloads:** LLM-training, LLM-inference, transformer

**Metrics:** Trillion-param, 640 BF16 TFLOPs, 520MB SRAM, 5nm, 600mm2

**Baselines:** Single-die GPUs, HBM-only designs, prior RDU generations

**Confidence:** low (abstract-only)
