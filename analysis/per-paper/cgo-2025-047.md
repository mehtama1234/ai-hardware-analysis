# VEGA: Automatically Generating Compiler Backends using a Pre-trained Transformer Model

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Developing compiler backends for new hardware targets is time-consuming and expertise-heavy; each target requires substantial manual engineering.

## Core Innovation
Using pre-trained transformer models to auto-generate complete compiler backends from target descriptions, dramatically reducing backend engineering effort.

## Method
VEGA categorizes backend functions into groups with multiple target-specific implementations abstracted as function templates. Uses pre-trained transformer model to distinguish target-independent/target-specific properties via feature vectors. Auto-generates function-template versions for new targets using target-description files alone.

## Key Contributions
- AI-driven system (VEGA) for auto-generating compiler backends using pre-trained transformers
- Function-template abstraction and feature extraction for target customization
- Backend generation in under 1 hour with 62-73% function accuracy on three targets (RISC-V, RI5CY, xCORE)
- Confidence scoring to guide minimal manual intervention

## Results
- RISC-V: 71.5% accuracy
- RI5CY: 73.2% accuracy
- xCORE: 62.2% accuracy
- Generation time: <1 hour
- Improvement vs fork-flow: <8% to 62-73%

## Limitations
30-40% of functions still need manual fixes; generalization to very different ISAs not demonstrated.
