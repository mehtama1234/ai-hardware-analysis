# Double-Side Clock Tree Synthesis with nTSVs

## Problem
Utilizing back-side silicon space via double-side clock trees requires systematic design resource allocation and multi-objective optimization, but existing tools only hack single-side approaches.

## Method
The method builds a clock distribution network by organizing it hierarchically (in levels), placing signal amplifiers and tiny silicon holes (Through-Silicon-Vias, or nTSVs) across both the front and back of the chip. After establishing the routing, it refines the layout on both sides to reduce timing mismatches (skew) between different paths. Throughout this process, it uses a single unified optimization framework to balance four competing goals: signal arrival time (latency), timing uniformity, total wire length, and the count of amplifiers and vias needed.

## Key Results
- Improved latency, skew, and wirelength vs SOTA methods
- Reduced buffer and nTSV count
- Outperforms widely-used open-source tool
