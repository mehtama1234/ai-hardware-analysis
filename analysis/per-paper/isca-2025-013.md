# Folded Banks: 3D-Stacked HBM Design for Fine-Grained Random-Access Bandwidth

**Venue:** ISCA 2025  
**Confidence:** low (abstract-only)

## Problem
HBM sequential (peak) bandwidth has grown 6.4x over two generations, but random/irregular-access bandwidth has been neglected, limiting performance for graph analytics, recommendation, and sparse workloads.

## Motivation
Real-world applications frequently exhibit irregular memory access patterns that cannot benefit from sequential bandwidth improvements, making random-access bandwidth the critical missing dimension in HBM scaling.

## Method
Folded Banks redistributes DRAM bank subarrays vertically across stacked silicon dies and moves the control logic and sense amplifiers to a dedicated logic layer at the base. Signals travel vertically through tiny connections called through-silicon vias (TSVs) and hybrid bonds instead of along long horizontal paths, dramatically reducing power loss from electrical resistance. Self-timed sense amplifiers (which detect when stored charge is ready to read) eliminate the need for dummy test subarrays, adding further power and area savings.

## Key Novelty
Folding bank subarrays vertically across stacked dies with vertical signal routing and a dedicated logic layer eliminates the power and area penalties of long horizontal wiring, enabling fine-grained random memory access.

## Contributions
1. FB-HBM architecture folding bank subarrays across 3D-stacked DRAM dies
2. Dedicated logic base layer for command/control and global sense amplifiers
3. Vertical CSL and MDL routing via thin-pitch TSVs and hybrid bonds
4. Self-timed sense amplifiers replacing power-hungry dummy subarrays

## Hardware Target
PIM / memory architecture (HBM variant)

## Key Metrics
- Baseline gap: 6.4x sequential bandwidth increase over two HBM generations; random-access improvement not quantified in abstract

## Baselines
