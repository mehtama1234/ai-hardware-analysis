# dac-2025-243: Tropical: Enhancing SLO Attainment in Disaggregated LLM Serving via SLO-Aware Multiplexing

## Summary
Hybrid LLM serving system using dynamic SLO-aware multiplexing to balance prefill (TTFT) and decode (TPOT) latencies, achieving 2.09x throughput at 90% SLO attainment and 9x P90 TTFT improvement over disaggregated approaches.

## Key Idea
Dynamically multiplex prefill/decode workloads on hybrid workers to exploit both disaggregated (low interference) and non-disaggregated (low queuing) benefits.

## Contributions
- 2.09x SLO-constrained throughput
- 9x P90 TTFT vs disaggregated (15% TPOT trade-off)
- 2.8x P90 TPOT vs non-disaggregated (same TTFT)
- Adaptive queuing-interference balancing

## Limitations
Cluster scaling and hardware-specific optimizations not addressed.
