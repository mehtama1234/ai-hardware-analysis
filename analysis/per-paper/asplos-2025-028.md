# Concerto: Automatic Communication Optimization and Scheduling for Large-Scale Deep Learning

**ID:** asplos-2025-028  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Automatic computation-communication overlap scheduling for distributed DL training

## Problem
In large-scale distributed DNN training, collective communication (all-reduce, all-gather, etc.) remains a major bottleneck that existing frameworks address only through hand-crafted, framework-specific overlap strategies tightly coupled to particular parallelism schemes. There is no general, automatic mechanism to overlap computation and communication across arbitrary parallelism configurations.

## Motivation
As DL models grow and distributed training scales to thousands of accelerators, communication overhead increasingly dominates training time, yet existing solutions sacrifice programmability and generality by embedding communication optimizations inside specific parallel runtimes.

## Method
Concerto is a compiler framework that decouples communication optimization from the parallelism strategy. It formulates communication scheduling as a resource-constrained project scheduling problem (RCPSP) and applies an off-the-shelf solver to find near-optimal schedules. An auto-decomposition pass splits synchronous (critical-path) communication operations to create overlap opportunities with computation, without requiring manual annotation. The resulting schedule is emitted as a program that any parallelism backend can execute.

## Key Novelty
Automatic decomposition of synchronous collective communications combined with RCPSP-based scheduling to achieve computation-communication overlap generalized across all parallelism strategies without manual tuning.

## Contributions
- A general compiler framework (Concerto) that decouples communication scheduling from parallel execution strategy.
- Formulation of DL communication scheduling as RCPSP and use of a solver for near-optimal overlap schedules.
- Auto-decomposition technique that transforms critical synchronous collectives to enable overlapping with computation.
- Empirical demonstration matching or outperforming Megatron-LM, JAX/XLA, DeepSpeed, and Alpa without hand-crafted optimizations.
