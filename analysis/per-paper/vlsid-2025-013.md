# MERGERS: Multi-Access Edge Resource Governance for Real-Time SaaS Systems

**Venue:** VLSID
**Authors:** Aakashjit Bhattacharya, Arnab Sarkar 0001, Ansuman Banerjee

## Problem Statement
The Multi-access Edge computation (MEC) paradigm is being regarded as a viable alternative for handling data and computation requirements of complex real-time and safety-critical applications in upcoming IoT systems

## Key Innovation
Novel circuit/architecture design

## Method
utilizes a central adaptive orchestrator called Resource Arbiter (RA), to dynamically allocate real-time service requests among heterogeneous MEC servers of a 5G MEC Software-as-a-Service (SaaS) provider
