# MERGERS: Multi-Access Edge Resource Governance for Real-Time SaaS Systems

**Venue:** VLSID
**Authors:** Aakashjit Bhattacharya, Arnab Sarkar 0001, Ansuman Banerjee

## Problem Statement
The Multi-access Edge computation (MEC) paradigm is being regarded as a viable alternative for handling data and computation requirements of complex real-time and safety-critical applications in upcoming IoT systems

## Key Innovation
Novel circuit/architecture design

## Method
A central control system called the Resource Arbiter receives service requests that need fast responses and decides which edge server should handle each one. Since the servers are different types with different capabilities, the system continuously adapts these routing decisions based on real-time conditions to efficiently distribute work across the servers stationed at 5G network nodes.
