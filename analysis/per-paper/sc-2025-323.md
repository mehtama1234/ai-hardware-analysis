# Securing HDF5 Plugins with Digital Signatures

**Venue:** SC
**ID:** sc-2025-323
**Confidence:** low

## Problem Statement
HDF5 plugins can be misused for malicious routing of calls; currently no systematic mechanism to ensure plugin authenticity and integrity.

## Motivation
HDF5 is widely used in scientific computing; extensibility via plugins is powerful but introduces security risk; need to systematically improve plugin security.

## Method
Digital signatures for HDF5 plugins: sign plugins at creation, verify authenticity/integrity before loading; assess implementation scenarios and overhead/accuracy trade-offs.

## Key Novelty
Systematic security hardening of HDF5 via cryptographic plugin verification; first exploration of digital signatures for HDF5 plugin system.

## Contributions
1. Digital signature scheme for HDF5 plugin authentication
2. Implementation scenarios and trade-off analysis
3. Security and performance overhead assessment
