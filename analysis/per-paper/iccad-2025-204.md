# VeriRL: Boosting the LLM-based Verilog Code Generation via Reinforcement Learning

**Venue:** ICCAD  
**ID:** iccad-2025-204

## Problem
LLM-based Verilog generation struggles with concurrency semantics, syntactic rigidity, and sparse/noisy simulation feedback, limiting hardware code quality.

## Motivation


## Method
The system uses reinforcement learning—training through trial and error with feedback—to improve Verilog code generation. When generated code runs in simulation, the system traces through execution to identify which parts caused problems, providing reliable feedback even when simulation results are sparse or noisy. All training examples are weighted equally to prevent the model from forgetting previous lessons while learning new ones. The code-generation strategy and the model that judges code quality learn together, each improving based on what the other learns.

## Key Novelty
Verilog code generation improves when the code generator and reward model (which judges code quality) iteratively improve together from simulation traces.

## Contributions
- Veribench-53K high-quality Verilog dataset with 700K+ problems
- Trace-back based Rescore mechanism for reward robustness
- Sample-balanced weighting strategy preventing overfitting
- State-of-the-art pass rate and functional correctness improvements
