# VeriRL: Boosting the LLM-based Verilog Code Generation via Reinforcement Learning

**Venue:** ICCAD  
**ID:** iccad-2025-204

## Problem
LLM-based Verilog generation struggles with concurrency semantics, syntactic rigidity, and sparse/noisy simulation feedback, limiting hardware code quality.

## Motivation


## Method
Reinforcement learning framework with Trace-back based Rescore mechanism for reward reliability, sample-balanced weighting for catastrophic forgetting mitigation, and co-evolution of policy and reward models.

## Key Novelty
First RL-driven approach for Verilog generation with iterative policy-reward co-evolution and trace-based feedback.

## Contributions
- Veribench-53K high-quality Verilog dataset with 700K+ problems
- Trace-back based Rescore mechanism for reward robustness
- Sample-balanced weighting strategy preventing overfitting
- State-of-the-art pass rate and functional correctness improvements
