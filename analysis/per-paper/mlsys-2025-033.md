# FlexInfer: A Flexible CPU-GPU Collaborative Framework for DNN Inference

**ID:** mlsys-2025-033 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM inference on commodity servers forces weight offloading to CPU via PCIe (96-98% of execution time), but existing offloading systems apply static policies that underutilize GPU or waste PCIe bandwidth.

## Method
Analytical policy estimator selects per-layer execution mode (CPU-only, GPU-offload, or SplitGen) based on current hardware state and phase (prefill vs decode), without profiling overhead.

## Key Novelty
First phase-aware and layer-aware dynamic policy selection between three execution modes (CPU-only/GPU-offload/hybrid) for LLM inference, using an analytical model.

## Metrics
- **Speedup:** 75% (Server1) and 76% (Server2) end-to-end latency reduction vs FlexGen

## Baselines
FlexGen, FlexGen Opt, SplitGen, CPU-only
