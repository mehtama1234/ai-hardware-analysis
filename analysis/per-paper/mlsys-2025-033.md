# FlexInfer: A Flexible CPU-GPU Collaborative Framework for DNN Inference

**ID:** mlsys-2025-033 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM inference on commodity servers forces weight offloading to CPU via PCIe (96-98% of execution time), but existing offloading systems apply static policies that underutilize GPU or waste PCIe bandwidth.

## Method
When large AI models run on limited GPU hardware, each layer must decide where to execute. FlexInfer uses a mathematical model, checking three things in real time (free GPU memory, PCIe bandwidth between CPU and GPU, CPU compute capacity), to pick the best strategy for each layer: CPU-only, GPU-offload, or SplitGen (split computation between CPU and GPU). It makes these decisions while the model runs, not beforehand, which avoids profiling overhead.

## Key Novelty
FlexInfer dynamically selects per-layer execution strategy among CPU-only, GPU-offload, and SplitGen based on real-time hardware state, using a mathematical model rather than static policies or machine learning.

## Metrics
- **Speedup:** 75% (Server1) and 76% (Server2) end-to-end latency reduction vs FlexGen

## Baselines
FlexGen, FlexGen Opt, SplitGen, CPU-only
