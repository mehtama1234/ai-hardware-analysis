# isca-2025-042: LightNobel: Improving Sequence Length Limitation in Protein Structure Prediction Model via Adaptive Activation Quantization

**Venue:** ISCA  
**Confidence:** high (full text)  
**Primary Theme:** hardware-software co-design for protein structure prediction via adaptive activation quantization

## Problem
Protein Structure Prediction Models (PPMs) such as AlphaFold2 and ESMFold use a Pair Representation tensor with dimension (Ns, Ns, Hz) that grows quadratically in memory and cubically in attention score computation with sequence length Ns, causing GPU out-of-memory failures beyond ~2000 amino acids and latency dominated (>91%) by Triangular Attention at long sequences. Existing chunking and low-memory attention workarounds do not reduce the fundamental activation size and degrade performance.

## Motivation
Real-world protein analysis increasingly targets sequences exceeding 1000 amino acids (multimers, CASP16 targets up to 6879 aa), but activation size—not weights—is the dominant memory bottleneck in PPMs, requiring a hardware-software co-design approach tailored to PPM-specific activation statistics.

## Method
LightNobel compresses intermediate values in protein structure prediction models using Token-wise Adaptive Activation Quantization (AAQ), which exploits a pattern unique to these models: values vary much more between different amino acid positions (tokens) than between feature channels, making per-position compression more effective. The system identifies three value ranges with different precision needs—using 8-bit, 4-bit, and 4-bit-only compression while keeping outliers at higher precision—and uses custom hardware (a Reconfigurable Matrix Processing Unit with a 128-lane parallel unit) that processes mixed 4-bit/8-bit/16-bit numbers directly without unpacking each element. To prevent memory overflow, attention is computed one position-pair at a time (like FlashAttention) rather than building the full Ns×Ns×Ns score matrix. The design runs at 1 GHz on 28nm silicon with 80 GB of HBM2E memory.

## Key Novelty
The core innovation is token-wise adaptive quantization that exploits how protein structure models have higher variance between positions than between feature channels, combined with hardware that dynamically handles mixed 4-bit/8-bit/16-bit precision without decompressing individual elements.

## Contributions
1. Discovery and characterization of token-wise distogram patterns in PPM Pair Representation activations enabling token-wise (vs. channel-wise) quantization without accuracy loss
2. AAQ algorithm: three-group adaptive quantization scheme (INT8+outliers, INT4+outliers, INT4-only) matched to activation characteristics, reducing peak activation memory by up to 120.05x
3. RMPU hardware: bit-level reconfigurable PE array with dynamic 4/5-PE-Lane accumulation via Dynamic Accumulation Logic (DAL) supporting multi-precision execution without per-element dequantization
4. LightNobel accelerator achieving up to 8.44x/8.41x speedup and 37.29x/43.35x power efficiency over A100/H100 GPUs with negligible TM-Score accuracy loss

## Hardware Target
ASIC (28nm, 1 GHz, 5x HBM2E 80 GB)

## Techniques
quantization, dataflow, memory-system, circuit-design

## Workloads
transformer (protein structure prediction: AlphaFold2, ESMFold)

## Key Metrics
- Speedup: 8.44x over A100, 8.41x over H100 (Protein Folding Block); 1.74x end-to-end over ESMFold
- Power efficiency: 37.29x over A100, 43.35x over H100
- Memory: peak memory reduced 120.05x; activation footprint 7.90 GB vs 113.49 GB at sequence length 3364
- Accuracy: TM-Score loss <0.001 vs FP16 baseline across CAMEO, CASP14, CASP15

## Baselines
NVIDIA A100 80GB PCIe, NVIDIA H100 80GB PCIe, ESMFold (FP16), AlphaFold2, FastFold, ColabFold, AlphaFold3, MEFold, PTQ4Protein, SmoothQuant, LLM.int8(), Tender

## Limitations
The RMPU is designed specifically for PPM's small hidden dimension (128) and may not generalize efficiently to standard LLM workloads with large hidden dimensions (e.g., 4096).
