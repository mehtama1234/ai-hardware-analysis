# isscc-2025-164: LLM Inference Accelerator with INT-FP-GEMM & Workflow Decoupling

**Problem:** LLM inference faces three bottlenecks: (1) autoregressive generation = 1000x more memory accesses vs. transformers (weight streaming + KV-cache); (2) mixed-precision (INT-FP) GEMM requires expensive dequantization (4.6x power), losing quantization benefits; (3) SFU (softmax/layernorm = 40% ops) creates PE stalls (1/3 time waiting).

**Motivation:** Cloud/edge LLM deployment demands energy efficiency; traditional transformer accelerators fail LLM patterns.

**Method:** The accelerator tackles all three challenges with three core techniques. First, it stores model weights in compressed form (using fewer bits) and performs matrix multiplication directly on these compressed weights combined with normal-precision activations—avoiding the expensive decompression that typically wastes 4.6x extra power. Second, it organizes the compressed weights into aligned data clusters so that data moves efficiently and processing happens in uniform chunks. Third, it decouples the processing timeline so matrix operations and special functions (softmax, trigonometry) run on separate independent paths simultaneously, allowing processors to keep working instead of idling while waiting for non-linear operations to finish.

**Key Novelty:** Cluster-aligned INT-FP-GEMM with bi-dimensional workflow decoupling eliminating PE stalls.

**Contributions:**
- 88.36 TOPS/W efficiency
- Bit-level weight compression
- Cluster-aligned INT-FP-GEMM
- Bi-dimensional SFU–GEMM decoupling
