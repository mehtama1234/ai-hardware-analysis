# Squat: Quant Small Language Models on the Edge

**Venue:** ICCAD  
**ID:** iccad-2025-182

## Problem
Small language models on edge devices are memory- and compute-bound; aggressive quantization enables deployment but risks accuracy loss without careful method design.

## Motivation
Efficient SLM inference on edge devices is critical for privacy-preserving and low-latency AI applications; quantization without quality degradation unlocks resource-constrained deployment.

## Method
Apply quantization techniques (INT8/INT4) optimized for SLM architectures with SIMD-friendly implementations on edge CPUs and microcontrollers. Employ knowledge distillation and activation-aware quantization to maintain accuracy across edge platforms.

## Key Novelty
End-to-end quantization framework for SLMs targeting SIMD edge accelerators with minimal accuracy loss.

## Contributions
1. SLM-optimized quantization methodology for edge devices
2. SIMD kernel optimization for quantized inference
3. Knowledge distillation integration for quality maintenance
4. Deployment framework for resource-constrained platforms
