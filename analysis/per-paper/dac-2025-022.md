# dac-2025-022: PastATPG - Hybrid ATPG with Partial-Assignment SAT

**Title:** PastATPG: A Hybrid ATPG Framework for Better Test Compaction with Partial Assignment SAT

**Venue:** DAC 2025

**Core Issue:** SAT-based ATPG generates complete primary input assignments, inflating test patterns and preventing compaction.

**Key Contribution:** PA-MiniSat SAT solver with partial assignment; hybrid framework integrating structural and SAT methods; improved compaction vs state-of-the-art.

**Hardware Target:** ASIC

**Workload:** Design testing, pattern generation

**Metrics:**
- Pattern compaction: improved vs SAT solvers
- Speed: competitive with commercial ATPG

**Confidence:** Low (abstract-only)
