# ShieldReduce: Fine-Grained Shielded Data Reduction

**Problem:** Shielded execution environments (TEEs) have limited protected memory capacity and security isolation overhead. Reducing data footprint within these secure enclaves while maintaining confidentiality and security properties presents a fundamental challenge.

**Method:** ShieldReduce reduces how much space data takes up inside a trusted execution environment (TEE)—a secure, isolated area of the processor with limited memory. It does this by compressing data, removing duplicate copies, or trimming unnecessary information, while using careful memory management to keep everything encrypted and isolated from outside access.

**Novelty:** ShieldReduce shrinks data size at a detailed, selective level—through compression and deduplication—inside encrypted execution environments while keeping all security intact.
