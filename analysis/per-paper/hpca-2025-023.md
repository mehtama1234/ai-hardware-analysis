# hpca-2025-023 — Bit-slice Architecture for DNN Acceleration with Slice-level Sparsity Enhancement and Exploitation

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing bit-slice DNN accelerators exploit sparsity only at coarse granularity — either input or weight sparsity independently — failing to jointly leverage both at fine bit-slice chunk granularity, leaving large computational savings unrealized.

## Motivation
Bit-slice architectures offer high reconfigurability for mixed-precision DNN inference, but fine-grained joint input+weight sparsity potential is underutilized due to hardware complexity.

## Method
The BADA architecture splits numbers into bit-slices (the individual bit layers within each number) and uses a front-end unit (the first processing stage) to select only non-zero slices before computation. It skips calculations in two ways: when an entire chunk of bits is zero, and when either the input or weight has a zero bit-slice at any position (catching both types of empty space at once). The system represents each bit-slice using 8 bits without needing extra hardware—better than the 6-7 bit limit in earlier designs—and during training it adjusts weight distributions to create more zeros in higher-order bit-slices, amplifying the sparsity gains.

## Key Novelty
The core innovation is using a front-end selection mechanism to exploit both input and weight sparsity simultaneously at the bit-slice level, paired with training that concentrates zeros into higher-order bit-slices.

## Contributions
- BADA architecture: coarse- and fine-grained joint input+weight bit-slice sparsity exploitation.
- Front-end non-zero slice selection enabling skip for any zero-slice operand pair.
- 8-bit data bit-slice representation without additional hardware overhead.
- Training-time weight narrowing; 2.67x throughput, 1.52x area, 2.15x energy efficiency vs. LUTein.
