# DDRoute: a Novel Depth-Driven Approach to the Qubit Routing Problem

**Problem:** Current qubit routing heuristics produce circuits with excessive depth that exceeds NISQ device limits.

**Method:** Qubit routing places quantum bits (qubits) on a quantum computer's physical layout to satisfy interaction constraints, typically by inserting SWAP operations that move qubits to compatible positions. DDRoute solves this routing problem using a depth-driven heuristic: when choosing where to place each SWAP, it selects the position that reduces circuit depth—the total number of sequential operations—the most. This contrasts with existing methods that try to balance multiple competing objectives like minimizing SWAPs while also reducing depth.

**Key Contribution:** Achieves up to 70% circuit depth reduction vs state-of-the-art routing approaches.

**Results:** Enables execution of deeper quantum circuits within near-term hardware constraints.
