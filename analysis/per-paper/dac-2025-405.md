# dac-2025-405: Towards In-Situ Neuromorphic Computing Architecture for Event Stream Super-Resolution

**Problem:** Event-based cameras generate low-resolution event streams; super-resolution requires efficient neuromorphic architecture avoiding inter-layer storage.

**Method:** SNN-based accelerator with hardware-friendly designs (simplified neurons, optimized convolutions, hierarchical arrays). KCTR dataflow with dual-pipeline achieves in-situ computing eliminating inter-layer spike storage.

**Key Novelty:** KCTR dataflow with in-situ computing without intermediate layer storage for neuromorphic event stream processing.

**Contributions:**
- Hardware-friendly SNN with simplified neurons
- KCTR dataflow and dual-pipeline
- Eliminates inter-layer spike storage
- 95.6% speedup vs GPU, 0.546 pJ/synaptic op at 28nm

**Confidence:** low (abstract-only)
