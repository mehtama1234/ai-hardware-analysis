# Leaks beyond Bits: Deep Learning-Assisted Side-Channel Attacks on Hyperdimensional Computing Accelerators

**Authors:** Brojogopal Sapui, Mehdi B. Tahoori

**Venue:** ICCAD

## Summary
Demonstrates CNN-based side-channel attacks on FPGA-implemented HDC accelerators with adaptive Grad-CAM enhancement, achieving 93% bit extraction accuracy. Proposes dynamic masking countermeasure.

## Key Contributions
- CNN-based side-channel analysis specialized for HDC accelerators
- Adaptive Grad-CAM-guided approach improving leakage detection efficiency
- 93% bit extraction accuracy using ~1M power traces
- Dynamic masking countermeasure reducing CNN extraction accuracy to ~18%

## Metrics
- Bit Extraction Accuracy: 93% (adaptive CNN)
- Baseline Accuracy: 47% (non-adaptive)
- Power Traces: 1M
- Accuracy Improvement: 2×
- Masking Overhead: 1.6× LUT, 1.4× latency

## Baselines
- Non-adaptive CNN side-channel analysis

## Limitations
Evaluation limited to Xilinx Artix-7 FPGA; transferability to other platforms not addressed.
