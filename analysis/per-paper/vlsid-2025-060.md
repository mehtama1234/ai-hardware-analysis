# Serialized Control Interface ASIC for Distributed Controllers of Space-Borne RADAR

**Paper ID:** vlsid-2025-060
**Venue:** VLSID
**Confidence:** low

## Problem
SAR (Synthetic Aperture Radar) payloads require distributed control hierarchy with bulky interconnect lines between central and distributed controllers, increasing complexity, size, weight, and harness complexity.

## Motivation
New space arena demands miniaturized, low-weight SAR payloads with reduced subsystems and interconnection infrastructure. Current TRC subsystems are separate large units with significant interconnect overhead.

## Method
Instead of using separate electronics and bulky physical wires to connect distributed controllers, the system puts all control functions into a single integrated circuit (ASIC—a custom-designed chip). Inside this chip, a pattern generator creates the signals that would normally travel through cables: telecommand signals (instructions sent to equipment), telemetry signals (sensor readings), and radar timing signals. By generating signals directly on the chip rather than transmitting them through external cables, the system eliminates the need for bulky differential interconnect lines (high-quality shielded cables that prevent signal distortion between distant control units).

## Key Novelty
The core innovation is consolidating distributed controller functions into a single integrated circuit that uses an internal pattern generator to create control signals on-chip, eliminating the bulky external interconnect harness.
