# Serialized Control Interface ASIC for Distributed Controllers of Space-Borne RADAR

**Paper ID:** vlsid-2025-060
**Venue:** VLSID
**Confidence:** low

## Problem
SAR (Synthetic Aperture Radar) payloads require distributed control hierarchy with bulky interconnect lines between central and distributed controllers, increasing complexity, size, weight, and harness complexity.

## Motivation
New space arena demands miniaturized, low-weight SAR payloads with reduced subsystems and interconnection infrastructure. Current TRC subsystems are separate large units with significant interconnect overhead.

## Method
Integrated SCI ASIC (Serialized Control Interface) housed inside TR Module as a single IC component, replacing separate TRC subsystem. Uses pattern generator concept to generate signals internally, eliminating need for separate differential inter-connect lines for telecommand, telemetry, and radar timing.

## Key Novelty
Integration of TRC functionality into single IC (SCI ASIC), elimination of bulky interconnect harness through on-chip signal generation via pattern generator.

## Contributions
- Novel SCI ASIC architecture for distributed radar controller integration
- Significant reduction in harness complexity and interconnect lines
- Miniaturization of SAR payload by eliminating separate TRC subsystem
- Pattern generator-based signal generation to replace external interconnects
