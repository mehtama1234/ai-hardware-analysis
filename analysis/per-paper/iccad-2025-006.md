# AccelStack: A Cost-Driven Analysis of 3D-Stacked LLM Accelerators

**Venue:** ICCAD  
**ID:** iccad-2025-006

## Problem
LLM accelerators face high bandwidth and latency demands despite HBM and 2.5D packaging; 3D stacking offers new opportunities but cost tradeoffs are unclear.

## Motivation
Understanding cost-performance tradeoffs of 3D-stacked architectures enables practical accelerator designs with optimal PPA for different deployment scenarios.

## Method
AccelStack models memory-on-logic performance and die-stacking costs (DoD, DoW, WoW). Evaluates 3D designs against NVIDIA A100/H100 across LLM workloads.

## Key Novelty
Cost-driven analysis framework for 3D-stacked LLM accelerators comparing different die-stacking modalities.

## Contributions
1. Performance model capturing memory-on-logic behavior in 3D stacks
2. Cost models for die-on-die, die-on-wafer, wafer-on-wafer stacking
3. 7.17x speedup vs. A100 (FP16), 2.09x vs. H100 (FP8) across LLM workloads
4. 38.09% cost reduction via chiplet designs vs. monolithic implementations
