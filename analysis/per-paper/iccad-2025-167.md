# QuickFlow: An Efficient Local Search Method to Map Convolutions on Spatial Architectures

**Authors:** Marco Ronzani, Cristina Silvano

**Venue:** ICCAD

## Summary
QuickFlow addresses the challenge of efficiently mapping convolutions to spatial architectures by using equivalence-based mapping optimization and greedy local search, achieving near-optimal results with minimal computational overhead.

## Key Contributions
- Equivalence-based optimization framework reducing mapping space exploration
- Improved analytical model with exact tile-size formulas for convolutions
- 1-2.1× better energy-delay product compared to state-of-the-art tools
- Up to 182× faster execution than best competing mapping tools
