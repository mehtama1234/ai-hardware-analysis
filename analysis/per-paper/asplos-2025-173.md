# asplos-2025-173: Selectively Uniform Concurrency Testing

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Randomized concurrency testing algorithms fail to uniformly sample thread interleavings, missing bugs that manifest only in rare interleavings. Prior algorithms are biased, yielding poor coverage of the exponentially large interleaving space.

## Motivation
Concurrent bugs appear in only a small fraction of possible thread interleavings, and existing randomized tools systematically under-explore rare cases where bugs lurk.

## Method
Random testing of concurrent programs (where multiple threads execute simultaneously) typically misses bugs because it samples interleavings (the order in which operations from different threads execute) non-uniformly — some orderings get tested far more often than others. SURW (Selectively Uniform Random Walk) is an online testing algorithm that fixes this: it picks a subset of the program's events (points where threads interact or synchronize) and generates all possible orderings with equal probability. The algorithm works as a black-box technique requiring only minimal information about the program, achieving uniform sampling across broad classes of programs and arbitrary event subsets.

## Key Novelty
The method provably achieves uniform sampling of interleavings (the order in which threads' operations execute) without requiring program-specific knowledge, giving each possible sequence equal probability and enabling systematic discovery of bugs hidden in rare orderings.

## Contributions
- Theoretical proof that uniform interleaving-space sampling is achievable with minimal program information
- SURW algorithm achieving interleaving-uniformity for broad program classes and arbitrary event subsets
- More bugs exposed and faster discovery than comparable randomized algorithms on concurrency benchmarks
- Superior interleaving-space and behavior-space exploration uniformity on real-world programs
