# Clay - Open-source ASIP Framework for Microarchitecture-aware Instruction Customization

Clay is an open-source framework for designing application-specific instruction processors (ASIPs) with support for microarchitecture-aware instruction customization and stateful behavior specification. The framework provides end-to-end tools for instruction generation, hardware-software co-simulation, and iterative microarchitecture optimization, enabling rapid prototyping and optimization of specialized processors. By incorporating state management and hardware-software feedback loops, Clay streamlines the ASIP design process traditionally requiring extensive manual specification.
