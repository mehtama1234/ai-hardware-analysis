# Leveraging GPU for Better Detailed Placement Quality

**Venue:** ICCAD  
**ID:** iccad-2025-128

## Problem
Detailed placement has approached practical limits of CPU-based wirelength optimization; leveraging GPU parallelism to further improve placement quality remains underexplored.

## Motivation
Further wirelength and routability improvements in detailed placement enable better overall design optimization.

## Method
Detailed placement—deciding exactly where each component goes on a chip to minimize wiring—normally requires searching through millions of possibilities, which is slow on CPUs. This approach uses a GPU to speed up the search by running SROA (Simultaneous Row and Order Assignment), a two-step process: first, dynamic programming (systematically evaluating options) assigns each component to a row, then heuristics (practical tricks) fine-tune positions within that row. Since GPUs compute many possibilities in parallel, this method explores far more possible arrangements than CPU methods, finding better placements.

## Key Novelty
The core innovation is the SROA algorithm, which combines row assignment and cell positioning so that GPUs can accelerate the search for better chip layouts.

## Contributions
- Simultaneous Row and Order Assignment (SROA) algorithm for detailed placement
- GPU-accelerated exploration of enlarged solution space
- Preserved routability with improved wirelength metrics
