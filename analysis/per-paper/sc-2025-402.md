# Effective Node-Level Anomaly Detection in HPC Systems via Coarse-Grained Clustering and Fine-Grained Model Sharing

**Venue:** SC
**ID:** sc-2025-402
**Confidence:** low

## Problem
Large-scale HPC systems experience performance degradation and failures; anomaly detection at node-level is challenged by massive scales, frequent job transitions, and complex patterns.

## Motivation
Unexpected failures impact scientific research; unsupervised anomaly detection avoids manual labeling overhead and adapts to evolving system behavior.

## Method
NodeSentry detects when individual nodes in a high-performance computer (HPC) system are failing or misbehaving by first grouping similar nodes together (coarse-grained clustering), which reduces the complexity of handling systems with thousands or millions of nodes. Instead of training a separate detection model for each node, it shares models across nodes in the same group (fine-grained model sharing), cutting training time and computational cost. This combination allows the system to monitor each node independently despite the massive scale, frequent job transitions, and complex performance patterns in modern HPC systems.

## Key Novelty
By sharing a single detection model across multiple similar nodes instead of training separate models for each node, the system cuts training overhead by 45.69% while reaching F1-score >0.876—an average 0.560 improvement over baseline approaches.
