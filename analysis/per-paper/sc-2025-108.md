# T2-RELION: Task Parallelism, Tensor Core Accelerated RELION for Cryo-EM 3D Reconstruction

**Venue:** SC | **ID:** sc-2025-108

## Summary
Highly optimized RELION implementation introducing task-level parallelism, GPU memory hierarchy optimization, and Tensor Core acceleration for cryo-EM 3D reconstruction on CPU-GPU platforms.

## Problem & Motivation
RELION is the community standard for cryo-electron microscopy 3D reconstruction, but computational efficiency remains a bottleneck. Original implementation has inefficient parallelization strategies and suboptimal GPU memory management, limiting throughput on GPU-accelerated platforms.

## Key Findings
- **Kernel-level acceleration:** 1.90-23.7× speedup on difference calculation (hot-spot kernel)
- **Application-level speedup:** 3.86× (CNG dataset), 2.68× (Trpv1 dataset) vs. RELION 4.0
- Task parallelism eliminates synchronization bottlenecks
- Memory hierarchy optimization improves GPU utilization

## Hardware & Systems
- **GPU:** NVIDIA A100 (quad configuration)
- **Platform:** CPU-GPU heterogeneous systems
- **Configuration:** Multi-A100 machines for comparison

## Techniques
- **Task parallelism:** Redesigned parallelization reducing dependencies
- **Three-phase GPU memory management:** Optimized data movement between host/device
- **Tensor Core utilization:** Acceleration of linear algebra operations
- **Advanced pipelining:** Latency hiding and thread-block-level data reuse
- **Kernel fusion:** Optimization of difference calculation operations

4. Demonstrated substantial speedups on real cryo-EM datasets

## Limitations
- Limited evaluation to two datasets
- NVIDIA A100 specificity limits portability
- Multi-GPU cluster scalability not thoroughly explored
- No comparison with alternative GPU acceleration approaches
