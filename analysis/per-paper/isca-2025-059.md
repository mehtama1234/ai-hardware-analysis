# LIA: A Single-GPU LLM Inference Acceleration with Cooperative AMX-Enabled CPU-GPU Computation and CXL Offloading

**Venue:** ISCA 2025  
**Authors:** Hyungyo Kim, Nachuan Wang, Qirong Xia, Jinghan Huang, Amir Yazdanbakhsh, Nam Sung Kim  
**Confidence:** low (abstract-only)

## Problem
Single-GPU LLM inference is constrained by GPU memory capacity, forcing either expensive multi-GPU deployments or frequent CPU-GPU transfers over slow PCIe, which bottleneck both latency and throughput.

## Motivation
Modern Intel CPUs with AMX achieve 20-40 TFLOPS matrix throughput—comparable to some GPUs—unlocking substantial computation offloading to CPUs and reducing PCIe data movement.

## Method
LIA runs large language models on a single GPU by offloading heavy math work to matrix units (AMX) built into modern Intel CPUs—specifically 4th-gen Sapphire Rapids and 6th-gen Granite Rapids Xeons. By keeping the model weights in CPU memory instead of shuttling them back and forth over the slow PCIe connection, the system avoids transfer bottlenecks. It also expands memory capacity by combining standard RAM (DDR) with a new high-speed memory protocol (CXL), enabling larger batch inference. The framework automatically distributes each transformer layer's computation between CPU and GPU, optimizing either for low latency (fast answers per question) or high throughput (many answers per second).

## Key Novelty
Single-GPU inference that uses Intel CPUs' matrix units (AMX) as true computational partners to the GPU, with CXL memory taking the place of multi-GPU setups.

## Contributions
1. AMX throughput benchmarking: 20 TFLOPS (Sapphire Rapids), 40 TFLOPS (Granite Rapids).
2. LIA cooperative CPU-GPU framework with latency and throughput optimization.
3. CXL memory offloading policy enabling 1.5x additional throughput and 1.8x larger batch sizes (900-1.6K).
4. Up to 19x lower latency, 5.1x higher throughput vs state-of-the-art single-GPU offloading.

## Metrics
- Speedup: 5.1x latency reduction (Sapphire Rapids), 19x (Granite Rapids) vs SOTA single-GPU offloading
- Throughput: 3.7x-5.1x improvement
- CXL: +1.5x throughput, batch size 900-1.6K (1.8x increase)

## Baselines
- Latest single-GPU LLM offloading framework
- LIA with DDR memory only (CXL comparison)
