# Banked Memories for Soft SIMT Processors

**Problem:** Soft SIMT processors on FPGAs require memory systems delivering high bandwidth (16+ ports) while maintaining high clock speeds (770+ MHz), but the design trade-offs between simpler multi-port and complex banked memory architectures are not well characterized.

**Method:** The authors built and tested 9 memory designs on FPGAs: some with multiple ports (simpler, supporting many simultaneous accesses) and others using banks (splitting memory into independent sections). They ran 51 benchmarks combining matrix transposition and FFT algorithms at different data sizes, measuring each design's speed, clock frequency (targeting 770+ MHz), and FPGA memory usage to see which works best when.

**Novelty:** Simpler multi-port memories perform better on small datasets despite higher memory overhead, while banked memories become more efficient at larger data sizes.
