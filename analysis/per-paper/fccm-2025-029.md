# Banked Memories for Soft SIMT Processors

**Problem:** Soft SIMT processors on FPGAs require memory systems delivering high bandwidth (16+ ports) while maintaining high clock speeds (770+ MHz), but the design trade-offs between simpler multi-port and complex banked memory architectures are not well characterized.

**Method:** The authors design and implement 9 different memory architectures (multi-port and banked variants) on FPGAs, execute 51 benchmarks combining matrix transposition and FFT algorithms across varying data sizes, and measure performance, clock frequency, and memory block consumption to characterize architecture trade-offs.

**Novelty:** Comprehensive empirical comparison showing that simpler multi-port memories achieve higher performance for smaller datasets despite higher memory overhead, while banked memories become more efficient at larger scales.
