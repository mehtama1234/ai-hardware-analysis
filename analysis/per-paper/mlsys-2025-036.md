# Photon: Federated LLM Pre-Training

**ID:** mlsys-2025-036 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM pre-training is constrained to high-bandwidth data centers because standard distributed training requires AllReduce at every step, making cross-region or internet-scale collaboration impractical.

## Method
Photon trains large language models across separate data centers by having each training site perform multiple local gradient steps before sending parameter updates to a central Aggregator server, rather than synchronizing after every step. This works because federated averaging—averaging updates from many sites—is naturally robust to local changes, enabling each site to use smaller batches with higher learning rates; this combination improves learning through noise injection that helps generalization. The system automatically adapts its communication method (centralized parameter server, AllReduce, or Ring-AllReduce) and local parallelization strategy (DDP, FSDP, or sub-federation) based on network connectivity between data centers.

## Key Novelty
Photon successfully trains billion-parameter language models across multiple data centers at the same quality as single-datacenter training by using federated averaging's robustness to combine small batch sizes with high learning rates, reaching 2x faster convergence than DiLoCo.

## Metrics
- **Wall-time:** 35% reduction vs centralized for 7B model (64-512x less communication)
- **Accuracy:** 7B model: 13.8 vs 16.6 perplexity (-16.9% vs centralized)

## Baselines
Centralized training (3D parallelism), DiLoCo
