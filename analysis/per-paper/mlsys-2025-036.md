# Photon: Federated LLM Pre-Training

**ID:** mlsys-2025-036 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
LLM pre-training is constrained to high-bandwidth data centers because standard distributed training requires AllReduce at every step, making cross-region or internet-scale collaboration impractical.

## Method
Cross-silo federated LLM pre-training using LocalSGD with small local batch sizes and high learning rates (exploiting federated averaging's robustness). Aggregator coordinates rounds; LLM Clients train locally; adaptive strategy selection (DDP/FSDP/sub-federation) based on connectivity. Communication via parameter server, AllReduce, or Ring-AllReduce.

## Key Novelty
First complete federated LLM pre-training system at 7B scale that surpasses centralized training quality, using small-batch + high-LR combination enabled by federated averaging robustness for 2x faster convergence vs DiLoCo.

## Metrics
- **Wall-time:** 35% reduction vs centralized for 7B model (64-512x less communication)
- **Accuracy:** 7B model: 13.8 vs 16.6 perplexity (-16.9% vs centralized)

## Baselines
Centralized training (3D parallelism), DiLoCo
