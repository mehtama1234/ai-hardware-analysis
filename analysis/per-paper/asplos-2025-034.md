# COGENT: Adaptable Compiler Toolchain for Tagging RISC-V Binaries

**ID:** asplos-2025-034  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** General-purpose LLVM compiler toolchain for RISC-V binary metadata tagging

## Problem
Adding hardware-enforced metadata tags to RISC-V binaries for security and testing policies currently requires tedious, architecture-specific compiler modifications; there is no flexible, reusable toolchain that can emit variable-width tags at multiple granularities (instruction, basic block, function) from a single compilation pipeline.

## Motivation
Hardware metadata tagging is a powerful approach to runtime security (e.g., control-flow integrity, memory safety) and testing (e.g., fuzzing, adaptive tracing), but the absence of a general-purpose tagging compiler makes deployment impractical for most developers.

## Method
COGENT is an LLVM-based compiler toolchain for RISC-V that generates instruction-level metadata tags. It supports variable-width tags (1–32 bits per instruction) and arbitrary-width tags per function or basic block, at selectable granularities. The toolchain includes a tag-aware disassembler and a tag integrity checker. A control-flow label emission pass marks branch targets and call sites, enabling CFI enforcement downstream. The pipeline is extensible to new tag policies without modifying the core compiler.

## Key Novelty
A single, policy-agnostic LLVM-based tagging toolchain for RISC-V that supports variable-width tags across multiple granularities (instruction/block/function) with integrity checking, rather than requiring bespoke compilers per tagging policy.

## Contributions
- LLVM-based RISC-V compiler that emits variable-width (1–32 bit) tags at instruction, basic block, or function granularity.
- Tag-aware disassembler and tag integrity checker for verifying correctness of generated tags.
- Control-flow label emission enabling downstream CFI enforcement.
- Evaluation of three use cases—CFI, Adaptive Tracing, Hardware-Level Function Tracing—with overhead of 0.94%–5.24% cycle count.
