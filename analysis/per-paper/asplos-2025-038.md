# Earth+: On-Board Satellite Imagery Compression Leveraging Historical Earth Observations

**ID:** asplos-2025-038  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Cross-constellation reference-based on-board satellite imagery compression

## Problem
Satellite downlink capacity is so limited that over 90% of captured earth-observation images are never downloaded; existing on-board compression techniques treat each image independently and cannot exploit the rich temporal and spatial redundancy available across an entire satellite constellation.

## Motivation
Earth-observation satellites generate far more imagery than can be transmitted to ground stations, creating a critical bottleneck that wastes the majority of sensor data; cross-constellation reference images would dramatically improve compression ratios but require a new system architecture.

## Method
Earth+ runs compression software directly on the satellite. Ground stations on Earth upload recent images from other satellites in the same constellation to each satellite, using the uplink signal. The satellite then compares each newly captured image to the most recent matching reference image and sends only the changed pixels (delta encoding—transmitting just the differences rather than the whole image). This works well because it keeps the reference images fresh and stored on-board, so most new images are very similar to the references, creating sparse differences to transmit.

## Key Novelty
Earth+ exploits similarity between images from the same constellation by having ground stations upload reference images from other satellites to each on-board satellite, achieving 3.3x reduction in downlink data compared to previous methods without quality loss.

## Contributions
- Cross-constellation reference image upload architecture that keeps on-board references current using data from sibling satellites.
- Change-detection-based on-board delta compression pipeline operating within satellite compute and storage constraints.
- 3.3x reduction in downlink usage compared to state-of-the-art on-board compression without quality loss.
- First demonstration of constellation-wide imagery sharing to improve per-satellite compression ratios.
