# Lumina: Real-Time Neural Rendering by Exploiting Computational Redundancy

**Venue:** ISCA 2025  
**Confidence:** low (abstract-only)

## Problem
3D Gaussian Splatting (3DGS) neural rendering is too computationally demanding for mobile SoCs, with high rasterization costs and redundant computation across temporally coherent frames blocking real-time performance.

## Motivation
AR/VR on mobile devices increasingly requires neural rendering; the compute gap between 3DGS and mobile SoC capabilities must be closed through co-design.

## Method
Lumina integrates two algorithms: **S2** (Spatial-temporal Skipping) exploits temporal coherence across frames to skip unchanged Gaussian contributions; **RC** (Radiance Caching) caches intermediate color integration values to reduce rasterization frequency. The **LuminCore** hardware accelerator is co-designed to efficiently support these cache lookups and fix fundamental rasterization inefficiencies in the 3DGS pipeline on mobile SoCs.

## Key Novelty
Joint temporal-coherence-based Gaussian skipping and radiance caching, paired with a purpose-built mobile accelerator, targets both compute and memory redundancy in 3DGS.

## Contributions
1. S2 algorithm skipping redundant Gaussian rendering across temporally coherent frames
2. RC mechanism caching color integration to reduce rasterization frequency
3. LuminCore accelerator optimized for 3DGS cache lookup and rasterization on mobile SoCs
4. 4.5x speedup, 5.3x energy reduction vs. mobile Volta GPU, <0.2 dB PSNR loss

## Hardware Target
SoC (mobile)

## Key Metrics
- Speedup: 4.5x over mobile Volta GPU
- Energy: 5.3x reduction over mobile Volta GPU
- Quality: <0.2 dB PSNR loss

## Baselines
Mobile Volta GPU

## Limitations
Restricted to 3DGS; generality to other neural radiance field formats not discussed.
