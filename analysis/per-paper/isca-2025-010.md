# Lumina: Real-Time Neural Rendering by Exploiting Computational Redundancy

**Venue:** ISCA 2025  
**Confidence:** low (abstract-only)

## Problem
3D Gaussian Splatting (3DGS) neural rendering is too computationally demanding for mobile SoCs, with high rasterization costs and redundant computation across temporally coherent frames blocking real-time performance.

## Motivation
AR/VR on mobile devices increasingly requires neural rendering; the compute gap between 3DGS and mobile SoC capabilities must be closed through co-design.

## Method
Lumina renders 3D scenes by blending thousands of Gaussians (fuzzy 3D spheres). Exploiting temporal coherence—the fact that consecutive video frames look almost identical—S2 (Spatial-temporal Skipping) avoids recalculating Gaussian contributions that haven't changed between frames. RC (Radiance Caching) stores intermediate color calculations to skip redundant rasterization work. LuminCore, a purpose-built mobile accelerator, is co-designed to efficiently support these cache lookups and eliminate bottlenecks in standard 3DGS rendering on mobile SoCs.

## Key Novelty
The core insight is that most computation repeats across consecutive video frames, so Lumina combines S2 (Spatial-temporal Skipping to skip unchanged Gaussians) and RC (Radiance Caching to reuse calculated colors), enabled by a custom mobile accelerator (LuminCore).

## Contributions
1. S2 algorithm skipping redundant Gaussian rendering across temporally coherent frames
2. RC mechanism caching color integration to reduce rasterization frequency
3. LuminCore accelerator optimized for 3DGS cache lookup and rasterization on mobile SoCs
4. 4.5x speedup, 5.3x energy reduction vs. mobile Volta GPU, <0.2 dB PSNR loss

## Hardware Target
SoC (mobile)

## Key Metrics
- Speedup: 4.5x over mobile Volta GPU
- Energy: 5.3x reduction over mobile Volta GPU
- Quality: <0.2 dB PSNR loss

## Baselines
Mobile Volta GPU

## Limitations
Restricted to 3DGS; generality to other neural radiance field formats not discussed.
