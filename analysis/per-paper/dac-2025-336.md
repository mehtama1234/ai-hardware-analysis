# Mr.TPL: A Method for Multi-Pin Net Router in Triple Patterning Lithography
**Venue:** DAC

## Problem
Triple patterning lithography (TPL) requires layout decomposition into three masks; multi-pin routing creates excessive color conflicts and stitches, especially for nets with >2 terminals.

## Motivation
Advanced technology nodes require TPL for critical layer patterning; efficient multi-pin routing reduces mask conflicts and enables manufacturable layouts.

## Method
Mr.TPL routes multi-pin nets (connections with multiple terminals) across triple patterning's three mask layers by assigning each segment to a mask color that avoids conflicts with segments on different masks. It reduces stitches (connections between different mask layers) which add manufacturing cost and complexity. By optimizing how the path splits across the three masks, it minimizes both conflicts and inter-layer connections.

## Key Novelty
It enables routing of multi-pin nets in triple patterning lithography.

## Contributions
1. 81.17% reduction in color conflicts for multi-pin nets
2. 76.89% reduction in stitches
3. 5.4x speedup vs. state-of-the-art TPL routing
