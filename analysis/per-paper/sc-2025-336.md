# A Nested Krylov Method Using Half-Precision Arithmetic

**ID:** sc-2025-336  
**Venue:** SC 2025  
**Authors:** Kengo Suzuki, Takeshi Iwashita

## Problem & Motivation

Half-precision (fp16) arithmetic offers **2-4x bandwidth benefits** and **faster computation** on modern hardware, but integrating it into iterative solvers remains challenging. Direct fp16 solvers diverge; existing mixed-precision methods underexploit fp16's potential.

## Solution: Nested Krylov with Progressive Precision Reduction

A deeply nested iterative solver structure combining:
- **Outer solver:** FGMRES (double-precision)
- **Middle levels:** Progressively reduced precision
- **Inner solver:** Richardson method (fp16)

**Key insight:** Limit fp16 iterations to avoid precision degradation, but execute them frequently within the outer solver's convergence framework.

## Performance Results

| Comparison | Speedup |
|------------|---------|
| vs Double-precision FGMRES | 1.65x |
| vs Double-Single mixed | 2.42x |
| vs Mixed-precision CG | 2.47x |
| vs BiCGStab | 2.74x |
| vs Restarted FGMRES | 69.10x |

## Key Properties

- Convergence guaranteed by nested structure
- No precision limit degradation
- Effective bandwidth utilization via fp16
- Significant speedups across multiple solver types

## Implications

Enables practical deployment of half-precision in HPC solvers, critical for bandwidth-limited applications (sparse linear systems, scientific computing).
