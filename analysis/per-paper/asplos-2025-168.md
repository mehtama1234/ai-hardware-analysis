# Hierarchical Prefetching: A Software-Hardware Instruction Prefetcher for Server Applications

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Server-side applications have large instruction working sets causing severe front-end bottlenecks even with FDIP, because record-and-replay prefetchers lose coverage and timeliness when actual control flow diverges from predicted sequences.

## Motivation
Instruction cache misses are a primary bottleneck in server workloads, and existing prefetchers fail when control flow variability causes mismatches between recorded and replayed sequences.

## Method
Hierarchical Prefetching identifies coarse-grained code Bundles—tens to hundreds of kilobytes—through lightweight static software analysis. Hardware uses a compact record-and-replay mechanism (under 2KB on-chip SRAM) that prefetches entire Bundles at bundle entry points rather than individual cache lines. Most Bundle metadata lives in main memory. Bundle formation groups functionally related code regions that tend to co-execute, tolerating control flow variability by prefetching the entire functional region rather than a precise sequence.

## Key Novelty
Defining coarse-grained code Bundles (10s–100s KB) via software analysis and prefetching them wholesale in hardware with under 2KB on-chip storage, achieving high coverage and timeliness despite control flow variability.

## Contributions
- Bundle abstraction: coarse-grained functionality blocks identified via software analysis
- Hierarchical prefetching microarchitecture combining software Bundle formation with hardware record-and-replay under 2KB on-chip storage
- 6.6% average IPC improvement over FDIP across 11 server workloads
- Improved miss coverage and timeliness over prior instruction prefetchers
