# dac-2025-282: SambaNova SN40L—Dataflow-Based Agentic AI Inference

**Problem:** AI inference clouds need efficient token generation (decode-bound) and rapid model switching while hosting diverse model architectures at scale.

**Motivation:** Token efficiency and model hosting costs dominate inference economics.

**Method:** The SambaNova SN40L uses a reconfigurable dataflow unit (a processing block where data flows through computation stages rather than repeatedly fetching instructions from memory) combined with three levels of memory—on-chip SRAM, intermediate-speed HBM (high-bandwidth memory), and DDR. This dataflow design enables aggressive compute-graph fusion (combining multiple computation steps into single super-fast operations), which maximizes performance during token generation (when the AI produces output). The three-tier memory hierarchy reduces the silicon footprint needed to store trillions of parameters.

**Key Novelty:** Dataflow-based reconfigurable unit optimized for token generation and multi-model hosting.

**Contributions:**
- 3x faster token generation vs. DGX H100
- 3x lower energy vs. DGX H100
- 19x lower model hosting costs
