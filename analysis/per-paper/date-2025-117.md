# IR-Fusion: A Fusion Framework for Static IR Drop Analysis Combining Numerical Solution and Machine Learning

**Venue**: DATE  
**Primary Theme**: Hybrid numerical-ML power grid analysis  

## Problem
Static IR drop analysis for on-chip power grids is computationally prohibitive at circuit scale; traditional numerical solvers are accurate but extremely time-consuming while machine learning methods sacrifice interpretability and scalability.

## Method
IR drop is the inevitable voltage sag that occurs in a chip's power distribution network—computing it at full scale is computationally prohibitive. IR-Fusion addresses this by starting with a numerical solver (AMG-PCG, combining algebraic multigrid with conjugate gradient optimization) to quickly generate a rough but accurate foundation. A specialized neural network (Inception Attention U-Net) then refines this foundation by learning power grid patterns across multiple scales—both broad and fine-grained—through hierarchical fusion, which blends the solver's structural information with the network's learned features. The system uses curriculum learning (training progressively on harder design variations) to generalize across different chip designs.

## Key Novelty
The core innovation is a hybrid numerical-machine-learning fusion where a traditional solver generates an accurate foundation that a neural network rapidly refines, combining solver precision with machine learning speed.

## Contributions
- Fusion strategy leveraging AMG-PCG numerical solver with deep learning refinement
- Inception Attention U-Net capturing multi-scale power grid structure and interactions
- Augmented curriculum learning strategy for diverse PG designs
- Significantly improved accuracy versus pure ML methods with fewer solver iterations than pure numerical
