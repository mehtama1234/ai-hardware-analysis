# IR-Fusion: A Fusion Framework for Static IR Drop Analysis Combining Numerical Solution and Machine Learning

**Venue**: DATE  
**Primary Theme**: Hybrid numerical-ML power grid analysis  

## Problem
Static IR drop analysis for on-chip power grids is computationally prohibitive at circuit scale; traditional numerical solvers are accurate but extremely time-consuming while machine learning methods sacrifice interpretability and scalability.

## Method
Combines efficient AMG-PCG numerical solver producing rough solutions with an Inception Attention U-Net for refinement; captures multi-scale power grid features through hierarchical fusion of numerical-structural information and applies augmented curriculum learning to handle design diversity.

## Key Novelty
Hybrid numerical-ML fusion framework combining solver accuracy with ML speed and adaptability.

## Contributions
- Fusion strategy leveraging AMG-PCG numerical solver with deep learning refinement
- Inception Attention U-Net capturing multi-scale power grid structure and interactions
- Augmented curriculum learning strategy for diverse PG designs
- Significantly improved accuracy versus pure ML methods with fewer solver iterations than pure numerical
