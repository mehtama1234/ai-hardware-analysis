# SlimIO: Lightweight I/O Path Design for Write Isolation in FDP-backed In-Memory Databases

**Venue:** SC  
**Theme:** Storage and I/O Optimization  
**Confidence:** low

## Problem Statement
In-Memory Databases (IMDBs) using snapshot-based persistence suffer from syscall overhead, inter-process I/O contention, and SSD garbage collection delays that degrade performance

## Motivation
With growing HPC data management needs, minimizing I/O latency and reducing SSD wear (write amplification) are critical for database performance and hardware longevity in large-scale systems

## Methodology
SlimIO adopts I/O passthru to bypass syscalls, uses Flexible Data Placement (FDP) SSDs for controlled writes, and applies isolation techniques to prevent inter-process interference

## Key Novelty
First system to leverage FDP SSDs for I/O isolation in IMDBs; combines passthru I/O with structured SSD write management to achieve WAF=1.0

## Contributions
- I/O passthru mechanism reducing syscall overhead
- FDP-based write isolation preventing garbage collection interference
- 50% latency reduction (99.9%-ile) and 30% query throughput improvement
- Write amplification factor of 1.00 (zero redundant writes)

## Hardware Targets
