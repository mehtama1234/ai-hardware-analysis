# Robin: RWKV Accelerator using Block Circulant Matrices based on FPGA

**Venue:** ICCAD  
**Confidence:** low

## Problem
Deploying RWKV linear-attention models on FPGAs requires addressing: limited on-chip/off-chip memory for weight storage, lack of hardware-software co-optimization, and computational bottlenecks from linear operations that GPU runtimes handle inefficiently.

## Motivation
RWKV offers efficient sequence processing compared to Transformers, but FPGA deployment lacks integrated software-hardware optimization; enabling efficient edge inference requires closing GPU-FPGA performance gaps.

## Method
Robin compresses model weights using Partial Block Circulant Matrices (PBCM)—a technique that reshapes weights into circular block patterns to reduce memory needs while maintaining accuracy. It implements configurable circulant computing cores (specialized hardware blocks that efficiently perform operations on these circular patterns) that directly map onto DSP48E resources (the FPGA's math units), using a dual DSP packaging strategy to optimize utilization. The entire system is co-designed: software and hardware engineered together so the compressed weights and efficient cores work seamlessly, enabling more efficient inference than GPU-based approaches for this type of linear-attention model.

## Key Novelty
The central idea is using Partial Block Circulant Matrices to compress weights while designing configurable hardware cores that efficiently execute these patterns on the FPGA's DSP units.

## Contributions
- PBCM weight compression technique reducing storage while maintaining accuracy
- Configurable circulant computing core supporting both circulant and standard matrix operations
- 3.09× throughput increase vs. Tesla A100 GPU
- 7.31× energy efficiency improvement vs. A100
