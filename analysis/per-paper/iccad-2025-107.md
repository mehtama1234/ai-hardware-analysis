# Robin: RWKV Accelerator using Block Circulant Matrices based on FPGA

**Venue:** ICCAD  
**Confidence:** low

## Problem
Deploying RWKV linear-attention models on FPGAs requires addressing: limited on-chip/off-chip memory for weight storage, lack of hardware-software co-optimization, and computational bottlenecks from linear operations that GPU runtimes handle inefficiently.

## Motivation
RWKV offers efficient sequence processing compared to Transformers, but FPGA deployment lacks integrated software-hardware optimization; enabling efficient edge inference requires closing GPU-FPGA performance gaps.

## Method
Robin integrates algorithm and hardware optimization: Partial Block Circulant Matrices (PBCM) compress weights while preserving accuracy, configurable circulant computing cores exploit DSP48E resources via dual DSP packaging strategies, and end-to-end software-hardware co-design enables efficient inference.

## Key Novelty
PBCM-based weight compression combined with configurable circulant computing cores tailored to DSP resource efficiency on FPGAs.

## Contributions
- PBCM weight compression technique reducing storage while maintaining accuracy
- Configurable circulant computing core supporting both circulant and standard matrix operations
- 3.09× throughput increase vs. Tesla A100 GPU
- 7.31× energy efficiency improvement vs. A100
