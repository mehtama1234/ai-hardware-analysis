# asplos-2025-107: Skia: Exposing Shadow Branches

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** instruction prefetch via shadow branch exposure

## Problem
Modern processors using Fetch Directed Instruction Prefetching (FDIP) suffer from Branch Target Buffer (BTB) misses for instructions that have been previously decoded and evicted, causing the BPU to fail to recognize branches and either skip prefetching or speculate down wrong paths. These BTB misses stall the front-end and pollute the L1-I cache, a critical bottleneck for complex datacenter applications with large code footprints.

## Motivation
As datacenter applications grow in complexity and code footprint, BTB capacity limitations increasingly prevent FDIP from achieving its full front-end prefetching potential, making front-end stalls a primary performance bottleneck.

## Method
Skia introduces "shadow branches": lightweight metadata structures that expose BTB-evicted branch information to the FDIP engine without restoring full BTB entries. When a branch is decoded and later evicted from the BTB, Skia retains shadow branch records in a separate, higher-capacity structure. The FDIP engine consults these shadow records to continue speculative fetching along correct paths even when a BTB miss would otherwise halt prefetching or cause misdirection.

## Key Novelty
Exposing evicted BTB branch information as lightweight "shadow branch" records that enable FDIP to continue correct speculative prefetching across BTB misses without full BTB entry restoration.

## Contributions
- Characterization of BTB miss patterns in complex datacenter workloads and their impact on FDIP effectiveness.
- Design of the shadow branch structure to retain evicted BTB branch metadata at low cost.
- Integration of shadow branch lookups into the FDIP pipeline to eliminate both missed-prefetch and wrong-path scenarios from BTB misses.
- Evaluation demonstrating front-end stall reduction for large-footprint datacenter applications.
