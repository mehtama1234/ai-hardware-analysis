# asplos-2025-116: Coach: Exploiting Temporal Patterns for All-Resource Oversubscription in Cloud Platforms

**Venue:** ASPLOS  
**Confidence:** high (full text)  
**Primary Theme:** temporal pattern-based holistic cloud VM resource oversubscription

## Problem
Cloud platforms remain significantly underutilized across all resource types (CPU, memory, network, storage) because existing oversubscription approaches target only a single resource (typically CPU), causing the bottleneck to shift to other resources and leaving overall utilization low. Memory oversubscription is especially difficult because memory is non-fungible — physical pages cannot be quickly reassigned between VMs.

## Motivation
Characterization of over 1 million Azure VMs shows that VMs lasting more than one day consume 96% of resource-hours, many exhibit predictable complementary temporal utilization patterns (daily peaks and valleys), and holistic multi-resource oversubscription can enable ~26% more VMs per server with minimal performance degradation.

## Method
Coach introduces CoachVM, a VM type that partitions each resource into a guaranteed portion (always allocated, PA-backed for memory) and an oversubscribed portion (allocated on demand, VA-backed for memory using zNUMA to deprioritize cold pages via the guest's NUMA policy). A random forest regressor predicts per-VM resource utilization in time windows (e.g., 3x8-hour daily windows) using VM configuration, weekday, subscription history, and customer-specific features, computing per-resource oversubscription rates per window. The cluster scheduler colocates VMs with complementary temporal patterns to maximize multiplexing savings. A per-server oversubscription agent monitors utilization and applies reactive (local resource reassignment) or proactive (VM migration) mitigations when contention occurs.

## Key Novelty
Holistic all-resource oversubscription of cloud VMs using temporal utilization pattern prediction to colocate complementary workloads, with a PA/VA memory partition using zNUMA that enables transparent memory oversubscription for unmodified guest VMs.

## Contributions
- Characterization of 1M+ Azure VMs revealing complementary temporal patterns, stranding, and multi-resource bottleneck shifts from CPU-only oversubscription.
- CoachVM abstraction with guaranteed and oversubscribed resource partitions; PA/VA-backed memory split transparent to guest via zNUMA.
- Random forest prediction model for per-VM per-time-window utilization enabling temporal pattern-aware VM scheduling.
- ~26% more VMs hosted per server with minimal performance degradation validated on real Azure traces.

## Hardware Target

## Technique Category

## Workloads
Database, HPC (Azure production VMs including IaaS/PaaS)

## Metrics
- ~26% more VMs hosted per server with minimal performance degradation
- 4x6hr time windows: ~15% memory saved, ~20% CPU saved vs single-lifetime-max allocation
- CPU stranding: 8% without oversub; memory stranding: 18% without oversub

## Baselines
- No oversubscription
- CPU-only oversubscription
- CPU+memory oversubscription (non-temporal)
- Harvest VMs

## Limitations
Memory oversubscription effectiveness depends on complementary temporal patterns which may not exist for all mixes; GPU/NVMe oversubscription requires hardware ATS/PRI support not yet widely available.
