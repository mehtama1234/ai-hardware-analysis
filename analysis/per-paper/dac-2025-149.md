# FedEDA: Privacy-Preserving Federated Learning for EDA

## Problem
EDA ML models require large circuit benchmarks for training, but intellectual property security concerns prevent companies from sharing raw circuit data, creating data scarcity that limits progress in ML-driven EDA.

## Method
FedEDA enables teams to train a shared machine learning model for circuit design without revealing their proprietary designs—instead, they share only trained model weights (numerical patterns the model learned from data). The algorithm uses Rent's Rule, which describes how circuit connections scale with size, to capture the hierarchical structure of circuit data; this lets the system fairly combine everyone's trained weights even when participants have different amounts of training data.

## Key Results
- Outperforms existing federated learning algorithms on EDA tasks
- Effective on routability, parasitic RC, and wirelength prediction
- Addresses IP security concerns by avoiding raw data sharing
