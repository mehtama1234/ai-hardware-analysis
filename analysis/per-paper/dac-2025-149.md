# FedEDA: Privacy-Preserving Federated Learning for EDA

## Problem
EDA ML models require large circuit benchmarks for training, but intellectual property security concerns prevent companies from sharing raw circuit data, creating data scarcity that limits progress in ML-driven EDA.

## Method
FedEDA is a federated learning aggregation algorithm designed for EDA, enabling participants to exchange model weights instead of sharing raw circuit data. The algorithm leverages Rent's Rule and circuit size to capture hierarchical structure, mitigating data imbalance issues among participants and improving weight aggregation quality.

## Key Results
- Outperforms existing federated learning algorithms on EDA tasks
- Effective on routability, parasitic RC, and wirelength prediction
- Addresses IP security concerns by avoiding raw data sharing
