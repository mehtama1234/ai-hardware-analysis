# Identifying System-on-Chip Security Assets with Structure-Based Analysis

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
SoC complexity and supply-chain diversity make manual security asset identification (keys, sensitive data, control logic) time-intensive and error-prone.

## Key Insight
DNN classifiers trained on RTL-derived structural graphs can automatically identify security assets with high accuracy, eliminating manual identification.

## Method
The system converts RTL code (the textual descriptions engineers write for circuits) into graph representations showing how components connect and data flows between them. A deep neural network then examines these graphs and learns to classify each node as either a security asset or regular component based on the structural patterns it observes in training data. The network's learned ability to recognize these patterns lets it automatically identify security assets without human intervention.

## Contributions
- Automated SoC security asset identification framework
- RTL-to-graph structural transformation
- DNN classifier for asset classification
- Up to 99% classification accuracy
- Reduced manual verification requirement
