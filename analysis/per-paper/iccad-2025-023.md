# DANCE: Dual-Side Agile N:M Sparse Compressed Digital CiM Accelerator for Efficient Compound AI

**Venue:** ICCAD  
**ID:** iccad-2025-023

## Problem
Existing CiM accelerators have rigid array structures unable to support fine-grained pruning for expert models and outlier-aware quantization for LLM router models needed in compound AI systems.

## Motivation
Compound AI combining LLMs with expert models requires flexible model compression support for efficient deployment.

## Method
The accelerator performs computation directly within memory, exploiting sparsity—areas of zero or near-zero values—in both the weights (model parameters) and activations (data flowing through the network) to skip unnecessary work. Instead of using rigid array structures, it employs set-associative circuits (flexible mapping logic that resembles how cache memory stores data, allowing dynamic routing of sparse values to available compute units). This flexibility enables it to simultaneously support fine-grained pruning (removing unimportant weights identified during training) and outlier-aware quantization (compressing values to lower precision while preserving unusually large numbers that significantly affect results).

## Key Novelty
The key innovation is a customized set-associative circuit that extracts N:M sparsity patterns (keeping only N non-zero values per M consecutive positions) from both weights and activations simultaneously, creating a unified compression approach.

## Contributions
- Set-associative selection circuit supporting N:M pattern extraction
- Unified framework for fine-grained pruning and outlier-aware quantization
- Cross-layer co-optimizations for compound AI workloads
- 4.36x energy efficiency for ResNet-18, 2.59x for Llama-7B
