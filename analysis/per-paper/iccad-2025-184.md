# BMCFuzz: Hybrid Verification of Processors by Synergistic Integration of Bound Model Checking and Fuzzing

**Venue:** ICCAD  
**ID:** iccad-2025-184

## Problem
RISC-V processor verification requires exhaustive checking of instruction semantics and corner cases, which is computationally expensive using pure formal methods or fuzzing alone.

## Motivation
Hybrid verification combining bounded model checking (BMC) with fuzzing can achieve deeper coverage more efficiently, reducing design bugs and accelerating processor bring-up.

## Method
Integrate bounded model checking with fuzzing: use BMC to verify instruction behavior formally within bounded execution depth, guide fuzzing with BMC-discovered constraints to find edge cases beyond formal bounds. Synergistic feedback loop between both techniques for RISC-V ISA compliance.

## Key Novelty
Synergistic integration of BMC and fuzzing for efficient RISC-V processor verification with improved corner-case detection.

## Contributions
1. Hybrid BMC-fuzzing framework for processor verification
2. Constraint-guided fuzzing based on BMC findings
3. RISC-V ISA-specific verification strategies
4. Demonstration of improved coverage and bug detection vs. standalone approaches
