# BMCFuzz: Hybrid Verification of Processors by Synergistic Integration of Bound Model Checking and Fuzzing

**Venue:** ICCAD  
**ID:** iccad-2025-184

## Problem
RISC-V processor verification requires exhaustive checking of instruction semantics and corner cases, which is computationally expensive using pure formal methods or fuzzing alone.

## Motivation
Hybrid verification combining bounded model checking (BMC) with fuzzing can achieve deeper coverage more efficiently, reducing design bugs and accelerating processor bring-up.

## Method
Bounded model checking (formal verification of all possible execution paths up to a fixed depth) identifies the constraints—the rules and limits—that RISC-V instructions must follow. Fuzzing (automated random testing) then uses these constraints to focus on corner cases that the formal method couldn't explore deeply. This creates a feedback loop: formal verification narrows the search space by identifying what matters, and fuzzing scales testing across that narrowed space to catch bugs that either technique alone would miss.

## Key Novelty
Combining formal verification and fuzzing (automated random testing) with constraints from verification guiding fuzzing's search toward corner cases in RISC-V processors.

## Contributions
1. Hybrid BMC-fuzzing framework for processor verification
2. Constraint-guided fuzzing based on BMC findings
3. RISC-V ISA-specific verification strategies
4. Demonstration of improved coverage and bug detection vs. standalone approaches
