# Efficient Weight Mapping and Resource Scheduling on Crossbar-based Multi-core CIM Systems

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Multi-core CIM systems suffer from high inter-core communication latency and suboptimal resource utilization when running CNNs.

## Key Insight
Stream-based data processing can reduce communication latency; optimized weight mapping maximizes crossbar utilization.

## Method
The approach organizes convolutional neural network computations into data streams that flow through multiple processor cores sequentially, which reduces expensive communication within and between cores. It strategically assigns the neural network's weights (the learned parameters) across the crossbar arrays (the hardware grids where calculations happen) to maximize their utilization. By minimizing handoffs between cores, the system reduces latency.

## Contributions
- Stream-based resource scheduling
- Weight mapping for crossbar utilization
- 76% latency reduction
- 30% resource utilization improvement
- 94.7% crossbar array usage
