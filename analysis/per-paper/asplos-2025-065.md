# asplos-2025-065 — Accelerating Number Theoretic Transform with Multi-GPU Systems for Efficient Zero Knowledge Proof

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Number Theoretic Transform (NTT), a key bottleneck in zero-knowledge proof generation, has not been efficiently parallelized across multiple GPUs because its butterfly permutation access pattern generates high inter-GPU communication overhead that offsets the compute gains from additional GPUs.

## Motivation
ZK proof generation is becoming critical for verifiable outsourcing and blockchain applications, and NTT—unlike Multi-Scalar Multiplication (MSM) which has been multi-GPU accelerated—remains the unaddressed bottleneck preventing proof generation from scaling to practical speeds.

## Method
The paper redesigns the NTT algorithm for multi-GPU execution by restructuring the butterfly computation stages to localize data access within GPU memory and minimize the frequency and volume of inter-GPU data transfers. The approach introduces a GPU-topology-aware permutation schedule that maps NTT stages to GPU assignments so that communication-intensive permutation steps are batched and overlap-optimized with computation. NVLink or PCIe interconnect topology is leveraged to select inter-GPU transfer paths that maximize aggregate bandwidth.

## Key Novelty
GPU-topology-aware NTT stage mapping that restructures butterfly permutations to minimize inter-GPU communication overhead and enable scalable multi-GPU NTT for ZK proof generation.

## Contributions
- Analysis of inter-GPU communication as the key barrier to multi-GPU NTT scalability.
- Topology-aware NTT algorithm that localizes data access per GPU and batches cross-GPU permutations.
- Multi-GPU NTT system implementation enabling scalable ZK proof acceleration.
- Demonstrated speedup on ZK proof generation benchmarks exceeding single-GPU NTT performance.
