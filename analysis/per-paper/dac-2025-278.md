# dac-2025-278: Simulation-Based Autotuning via ML Prediction

**Problem:** Autotuning ML workloads requires target hardware; limited availability constrains parallel exploration.

**Motivation:** ML optimization spaces are exponentially large; simulation-based exploration accelerates autotuning.

**Method:** Instruction-accurate simulators execute autotuning workloads; ML predictors trained on simulation statistics forecast target hardware performance (x86, ARM, RISC-V).

**Key Novelty:** ML-based performance prediction from simulator statistics to replace target hardware execution.

**Contributions:**
- Simulation-based autotuning framework
- Top-3% accuracy in identifying best implementations
- Outperforms native execution for embedded with 3+ parallel simulations

**Confidence:** low (abstract-only)
