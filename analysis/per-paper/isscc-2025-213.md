# isscc-2025-213: Ultra-Fast Burst-Mode Clock and Data Recovery

## Quick Summary
A 60Gb/s burst-mode CDR with cross-injection-locking and flash phase detector achieving 0.13ns reconfiguration time, enabling 50% throughput increase in rapidly reconfigurable photonic switch networks.

## Problem
Photonic switches operating at ns timescales demand BM-CDR with sub-ns reconfiguration. Prior injection-locking approaches suffer from poor recovered-clock jitter at higher data rates, limiting throughput.

## Method
A 60-gigabit-per-second burst-mode clock-and-data recovery circuit recovers timing from arriving data bursts using cross-injection-locking—a technique where oscillators stabilize each other to reduce jitter (unwanted timing variations). It combines this with a flash phase detector (a fast circuit using parallel comparators that measures timing offset between data and clock within 2 bit periods). Implemented in 28nm CMOS, it achieves 0.13 nanosecond reconfiguration time.

## Key Novelty
The key idea is using cross-injection-locking—where oscillators mutually stabilize each other's frequency—to suppress jitter (unwanted timing variations) in burst-mode clock and data recovery.

## Contributions
- 60Gb/s NRZ burst-mode CDR
- 0.13ns reconfiguration time (50× improvement)
- Jitter suppression via cross-injection-locking
- Flash phase detector for rapid acquisition
