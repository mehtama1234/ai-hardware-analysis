# TRANSPOSE: Circuit Transformations for Power Side-Channel Security at Register Transfer Level

**VLSID 2025** | vlsid-2025-078

## Abstract
Power side-channel attacks passively probe device power consumption to leak cryptographic secrets. TRANSPOSE automates RTL-level circuit transformations—register duplication, register pushing/balancing, clock gating—to randomize power consumption and reduce dynamic power. TVLA validation on PRESENT and AES S-boxes shows significant increase in univariate PSCA attack resistance.

## Problem
- Cryptographic hardware vulnerable to passive power analysis attacks
- Power consumption correlates with secret data being processed
- Attackers can recover keys from power traces without internal access

## Key Insight
Automated RTL-level transformations can systematically break power-data correlation by randomizing and balancing power consumption across sensitive operations.

## Approach
1. Identify sensitive registers in RTL
2. Duplicate sub-circuits influencing sensitive outputs
3. Apply register pushing and balancing
4. Integrate clock gating for obfuscation
5. Validate via TVLA

## Evaluated On
- PRESENT cipher
- AES S-boxes
- Custom test benches

## Validation
- Test Vector Leakage Assessment (TVLA) analysis
- Univariate PSCA attack resistance quantified
- Power consumption randomization demonstrated
