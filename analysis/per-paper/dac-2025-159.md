# GraphAccel: An In-Storage Accelerator for Efficient Graph-Based Vector Similarity Search

**Authors:** Yoonyoung Kwon, Yunjong Boo, Hyungmin Cho  
**Venue:** DAC 2025

## Summary
GraphAccel is an in-storage SSD accelerator for graph-based approximate vector similarity search, essential for retrieval-augmented generation. It uses page packing to reduce SSD page accesses and speculative search to maximize idle channel utilization, outperforming DiskANN and DiskANN++.

## Key Contributions
- In-storage accelerator integrated into SSD storage hierarchy
- Page packing reducing per-query SSD page accesses
- Speculative search exploiting idle SSD channels
- Performance gains over DiskANN and DiskANN++

## Technical Approach
The accelerator uses two key optimizations: (1) page packing co-locates related graph nodes on SSD pages to reduce page fetch count per query, and (2) speculative search prefetches and processes multiple search paths in parallel, utilizing SSD chips and channels that would otherwise remain idle during sequential traversal.
