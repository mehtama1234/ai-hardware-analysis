# FREEDOM: FPGA-Based Hardware Redaction Emulator

**Problem:** Hardware redaction systems protect IP by storing critical portions off-chip, but evaluating attacks requires prohibitively long simulation times. Traditional logic locking exposes locking mechanisms to untrusted foundries, enabling potential tampering or key extraction.

**Method:** The framework automatically partitions ASIC and FPGA components, maps the design to a low-cost FPGA board (Terasic DE10-SoC), and provides software APIs running on the embedded processor to launch attacks. The unprogrammed redacted design goes to the foundry while the bitstream acts as the security key, preventing reverse engineering without the key.

**Novelty:** Open-source FPGA-based emulation platform that accelerates attacks on hardware redaction systems by orders of magnitude compared to simulation, enabling faster security evaluation.
