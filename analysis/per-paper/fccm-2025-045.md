# FREEDOM: FPGA-Based Hardware Redaction Emulator

**Problem:** Hardware redaction systems protect IP by storing critical portions off-chip, but evaluating attacks requires prohibitively long simulation times. Traditional logic locking exposes locking mechanisms to untrusted foundries, enabling potential tampering or key extraction.

**Method:** The framework automatically divides the hardware design into two parts: an ASIC portion that's redacted (security-critical logic removed) and sent to the foundry, and an FPGA portion that stays in-house on a low-cost board (Terasic DE10-SoC). On the FPGA's embedded processor, software APIs let researchers launch and test attacks on the redacted design—simulating threats without actually fabricating chips. The design stays secure because the FPGA's bitstream (the configuration code that makes the FPGA work) is the key; without it, the incomplete redacted ASIC sent to the foundry cannot be completed or reverse-engineered.

**Novelty:** The core idea is an open-source FPGA-based emulation platform that tests attacks on hardware redaction systems orders of magnitude faster than simulation.
