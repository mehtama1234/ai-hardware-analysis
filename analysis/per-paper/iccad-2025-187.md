# DeepCell: Self-Supervised Multiview Fusion for Circuit Representation Learning

**Venue:** ICCAD  
**ID:** iccad-2025-187

## Problem
Circuit design automation lacks effective representation learning from heterogeneous circuit data (AIGs, netlists); learning transferable features is challenging without labeled datasets.

## Motivation
Self-supervised circuit representations enable downstream tasks (placement, routing, power prediction) with minimal labeling; multiview learning combines complementary structural and logical circuit views.

## Method
The system learns circuit representations without human-labeled examples using contrastive learning—comparing different descriptions of the same circuits to learn what makes them similar or different. It uses two complementary descriptions: AND-inverter graphs (logic gates showing how computation flows) and netlists (component connections showing physical layout). The learning process encourages the system to recognize when these two different views describe the same circuit, while distinguishing it from different circuits. This creates a unified understanding that captures both logical behavior and physical structure, making it robust even when the two views don't perfectly align.

## Key Novelty
The core contribution is learning unified circuit representations by combining two views—logical structure (AND-inverter graphs) and physical connections (netlists)—through self-supervised contrastive learning.

## Contributions
1. Self-supervised learning framework for circuit representations
2. Dual-view fusion of AIG and netlist information
3. Contrastive learning objective for circuit understanding
4. Demonstrated transfer to downstream EDA tasks
