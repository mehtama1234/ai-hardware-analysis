# DeepCell: Self-Supervised Multiview Fusion for Circuit Representation Learning

**Venue:** ICCAD  
**ID:** iccad-2025-187

## Problem
Circuit design automation lacks effective representation learning from heterogeneous circuit data (AIGs, netlists); learning transferable features is challenging without labeled datasets.

## Motivation
Self-supervised circuit representations enable downstream tasks (placement, routing, power prediction) with minimal labeling; multiview learning combines complementary structural and logical circuit views.

## Method
Apply self-supervised contrastive learning on dual circuit representations: AND-inverter graphs (AIG) for logic structure and netlist for physical connectivity. Fuse both views via contrastive objective to learn unified circuit embeddings robust to view misalignment.

## Key Novelty
Self-supervised multiview contrastive learning for circuit representation combining AIG and netlist information.

## Contributions
1. Self-supervised learning framework for circuit representations
2. Dual-view fusion of AIG and netlist information
3. Contrastive learning objective for circuit understanding
4. Demonstrated transfer to downstream EDA tasks
