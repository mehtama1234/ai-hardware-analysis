# isscc-2025-036: Small-Object Detection CNN Accelerator

**Title:** A 16nm 5.7TOPS CNN Processor Supporting Bi-Directional FPN for Small-Object Detection on High-Resolution Videos

**Venue:** ISSCC

## Core Contribution
16nm CNN accelerator achieving 5.7TOPS for high-resolution (896x896) small-object detection via bi-FPN and bandwidth-optimized scheduling.

## Key Metrics
- **Throughput:** 5.7TOPS
- **Technology:** 16nm
- **Input Resolution:** 896x896
- **Network:** 77-layer EfficientDet-D3

## Problem
Deep backbones with multi-scale feature extraction suffer from high memory bandwidth and external-memory access, limiting mobile/edge deployment.

## Method
OICP bi-FPN models to reduce feature-map memory; RARC backbone scheduling to minimize external access; RTE supporting diverse operations.

## Confidence
Low (abstract-only analysis).
