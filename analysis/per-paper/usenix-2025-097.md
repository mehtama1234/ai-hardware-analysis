# SAVE: Software-Implemented Fault Tolerance for Model Inference against GPU Memory Bit Flips

**Problem:** GPU memory bit flips can silently corrupt model weights and activations during inference, causing incorrect predictions. Software-based protection mechanisms are needed that don't require hardware ECC or full model replication.

**Method:** SAVE detects bit flips in GPU memory during model inference by checking for corruption in the data being used (applying error detection codes—mathematical checksums that reveal when bits have flipped). When corruption is found, it recovers either by re-running the affected computation or using backup data, all through software running on the GPU or CPU. This protects against bit flips without requiring special error-correcting hardware or keeping duplicate copies of the entire model in memory.

**Novelty:** Software-only protection against GPU memory bit flips during model inference, without special error-correcting hardware or data duplication.
