# BlockPIM: Memory Management Optimization for Long-Context LLM Inference on PIM

**Venue:** DAC | **ID:** dac-2025-192

## Summary
BlockPIM optimizes memory layout and access patterns in PIM architectures for long-context LLM inference. Proposes cross-channel block layout strategy maximizing utilization and eliminates context length constraints via distributed attention computation.

## Key Results
- **Throughput:** 62% average improvement vs. state-of-the-art PIM solutions
- **Approach:** Cross-channel block memory layout + distributed attention computation
- **Benefit:** Scalable long-context LLM inference without length constraints

## Technique
Cross-channel block memory layout consolidates fragmented data and maximizes utilization; cross-channel attention computation distributes operations across channels efficiently.
