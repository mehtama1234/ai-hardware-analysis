# StreamCSD: SSD-Autonomous Stream Management via In-Storage Content Learning

**Problem:** Write amplification from GC degrades SSD performance; host-aware stream management requires OS modifications.

**Solution:** Autonomous compression-based stream clustering using K-means on compressor feedback from computational storage drives.

**Results:** Reduces write amplification from 1.7 to 1.06; matches host-aware methods without host changes.

**Theme:** Autonomous storage optimization via in-device learning.
