# asplos-2025-108: Tackling ML-based Dynamic Mispredictions using Statically Computed Invariants for Attack Surface Reduction

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** static invariants to bound ML-based security prediction errors

## Problem
ML-based runtime predictors used for code debloating and dynamic control flow monitoring lack guarantees that distinguish mispredictions from actual security attacks, making them unsuitable for safety-critical security contexts. Without this distinction, the system either blocks legitimate executions (false positives from mispredictions) or fails to stop real attacks.

## Motivation
The increasing adoption of ML for runtime control flow and security decisions creates a correctness-security gap: ML predictions are accurate but not guaranteed, yet security enforcement requires distinguishing false positives (ML error) from true positives (adversarial attack).

## Method
The paper computes static program invariants at compile/analysis time to reduce the attack surface that ML-based dynamic predictors must cover. Statically proven safe behaviors are removed from the ML decision space, so the ML model only makes predictions over a reduced, ambiguous region. When the ML predictor fires on the reduced set, the probability that it is a misprediction versus an actual attack is much lower, enabling more reliable enforcement in security settings such as control flow integrity and debloating.

## Key Novelty
Using statically computed program invariants to reduce the attack surface exposed to ML-based runtime predictors, making it feasible to distinguish mispredictions from genuine security violations.

## Contributions
- Formulation of the misprediction-vs-attack disambiguation problem for ML-based runtime security monitors.
- Static invariant computation approach to shrink the set of behaviors that the ML predictor must adjudicate.
- Integration with debloating and control flow monitoring use cases to demonstrate attack surface reduction.
- Evaluation showing improved precision of ML-based security decisions after invariant-guided reduction.
