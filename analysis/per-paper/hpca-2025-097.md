# hpca-2025-097 — A Hardware-Software Design Framework for SpMV Acceleration with Flexible Access Pattern Portfolio

**Venue:** HPCA  
**Authors:** Zhenyu Wu, Maolin Wang, Hayden Kwok-Hay So  
**Confidence:** low (abstract only)

## Problem
Sparse matrix-vector multiplication (SpMV) is difficult to accelerate due to highly irregular data access patterns that vary by input matrix structure. Static accelerators optimized at compile time cannot handle the dynamic matrix structures encountered in large practical SpMV workloads.

## Motivation
SpMV is a critical kernel in scientific computing and graph analytics, and large matrices that cannot fit in on-chip memory expose the fundamental tension between flexibility and performance in existing accelerators.

## Method
SPASM is a hardware-software co-design framework that analyzes input matrices to understand their data access patterns (how they retrieve values from memory) and creates specialized templates for different matrix types. The system uses reconfigurable hardware (processing units programmed to switch between strategies) to apply the best pattern for each matrix at runtime, rather than being locked into one fixed approach. A global analysis of the input matrix determines how to configure the hardware and distribute computational work across multiple processing units, preventing any unit from being overloaded. This approach optimizes for expected matrices while gracefully handling unexpected structures.

## Key Novelty
The key novelty is flexible data-access pattern templates combined with adaptable hardware, allowing both optimization for expected matrices and support for unexpected patterns at runtime.

## Contributions
- Hardware-software framework (SPASM) encoding sparse matrix access patterns as a portfolio of run-time-selectable templates
- Reconfigurable hardware structure supporting vectorized computation and flexible per-tile template switching
- Global composition-based workload scheduling to improve load balance
- 2.81x average speedup over state-of-the-art SpMV accelerators with low customization overhead
