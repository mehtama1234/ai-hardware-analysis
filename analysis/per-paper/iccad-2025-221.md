# When Semi-Supervised LVM Meets Frequency-Based Critical Layout Pattern Selection

**Venue:** ICCAD  
**ID:** iccad-2025-221  
**Confidence:** low

## Problem Statement
Identifying critical lithography patterns for process optimization requires manual annotation, which is time-consuming and subjective.

## Motivation
Automated pattern criticality detection reduces manual effort and improves consistency in lithography pattern selection.

## Method
Semi-supervised learning with Vision Transformers (ViT) for pattern classification. Frequency domain analysis for criticality assessment. Combines image and frequency-based features.

## Key Novelty
First semi-supervised approach combining ViT and frequency analysis for lithography pattern criticality detection.

## Contributions

1. Semi-supervised ViT-based pattern classifier
2. Frequency-based criticality analysis
3. Eliminates manual pattern annotation
4. Replaces manual process
