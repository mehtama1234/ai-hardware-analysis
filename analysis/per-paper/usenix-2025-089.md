# DRack: A CXL-Disaggregated Rack Architecture to Boost Inter-Rack Communication

**Problem:** Inter-rack communication in data centers faces bandwidth and latency bottlenecks due to traditional hierarchical network architectures. Modern disaggregated computing requires efficient resource sharing across racks, but conventional network stacks add latency overhead.

**Method:** DRack uses CXL (a high-speed hardware protocol for direct machine-to-machine connections, bypassing software routing layers) to let one rack access another rack's memory and processing power directly. Instead of sending requests through multiple network software layers—which adds latency—DRack redesigns the physical connections so that one rack can treat another's resources almost as if they were local. This eliminates the software routing overhead that normally slows down inter-rack access.

**Novelty:** DRack's core insight is using CXL (a direct hardware connection protocol) at the rack level to skip the traditional network software layers when one rack accesses another's memory or processing power.
