# DRack: A CXL-Disaggregated Rack Architecture to Boost Inter-Rack Communication

**Problem:** Inter-rack communication in data centers faces bandwidth and latency bottlenecks due to traditional hierarchical network architectures. Modern disaggregated computing requires efficient resource sharing across racks, but conventional network stacks add latency overhead.

**Method:** DRack uses CXL (Compute Express Link) to create a disaggregated rack architecture that exposes memory and compute resources directly to remote racks. The system redesigns rack topology to enable low-latency CXL-based access to resources without traversing traditional network stacks.

**Novelty:** Applying CXL protocol to disaggregate resources at the rack level, eliminating traditional network indirection for inter-rack communication.
