# Balanced and Elastic End-to-end Training of Dynamic LLMs

**Venue:** SC
**ID:** sc-2025-378
**Confidence:** low

## Problem

Dynamic LLM techniques (MoE, pruning, layer freezing, sparse attention, early exit, MoD) reduce computation but introduce severe workload imbalance across workers, making them impractical for large-scale distributed training.

## Motivation

Need autonomous dynamic load balancing for distributed LLM training to maximize efficiency gains from dynamic computation techniques.

## Method

DynMo: autonomous dynamic load balancing achieving maximum reduction in workload imbalance; adaptively equalizes compute loads across pipeline-parallel training; consolidates computation onto fewer workers; supports multi-GPU and multi-node clusters.

## Key Novelty

Provable maximum reduction in workload imbalance; dynamic worker consolidation without sacrificing throughput.

## Contributions

1. Autonomous dynamic load balancing algorithm with provable guarantees
2. Worker consolidation mechanism for releasing idle workers
3. Support for multi-GPU and multi-node cluster deployment
4. Speedup for dynamic GPT: 1.23x (MoE), 3.18x (pruning), 2.23x (layer freeze), 4.02x (sparse), 4.52x (early exit), 1.17x (MoD)
