# A Scalable and Robust Compilation Framework for Emitter-Photonic Graph State

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Deterministic emitter-photonic quantum graph state generation is more scalable than probabilistic schemes, but compilation lacks scalability and ignores hardware constraints, causing impractical high-overhead designs.

## Core Method
Hierarchical framework partitioning target graphs into subgraphs, compiling individually, then recombining with local complementation transforms and emitter-resource-aware scheduling to maximize utilization.

## Key Contribution
Graph partitioning + local complementation transforms enabling scalable hardware-aware emitter-photonic compilation.

## Results
- 52% CNOT gate reduction
- 56% circuit duration reduction
- 1.9× photon loss suppression
