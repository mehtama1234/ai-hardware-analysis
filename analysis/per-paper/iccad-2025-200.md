# VeriSAT: the Hardware Design of Modern SAT Solver

**Venue:** ICCAD  
**ID:** iccad-2025-200

## Problem
Traditional SAT solvers execute in software; hardware-accelerated approaches lack optimization for concurrent operations and efficient data structures.

## Motivation


## Method
This implements a SAT solver—a tool that checks if logical formulas can be satisfied—as synthesizable hardware (SystemVerilog code compiled into circuits) instead of software. It uses three hardware-optimized operations: linked-list literal-watching for tracking which variables need checking, concurrent constraint propagation in a tree structure, and pipelined clause learning where learning stages execute in parallel instead of sequentially.

## Key Novelty
Building a SAT solver—a tool that checks if logical formulas can be satisfied—as synthesizable hardware with data structures and processes designed to exploit parallel circuit execution.

## Contributions
- Hardware-optimized linked-list literal-watching with cached literals
- Concurrent propagation tree for faster conflict detection
- Pipelined clause learning for high throughput
- 1044x speedup over SAT-Hard, 18x over SAT-Accel, 30x over MiniSat
