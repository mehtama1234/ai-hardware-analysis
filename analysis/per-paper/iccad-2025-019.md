# Versatile Rewiring and Concurrent Resynthesis for High-Quality Customized Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-019

## Problem
Traditional logic synthesis algorithms reach saturation; need for substantial circuit structural improvements beyond standard methods.

## Motivation
High-quality circuit optimization requires exploring beyond conventional synthesis techniques.

## Method
The method divides a circuit into smaller pieces, each affecting only certain signals (support-limited subcircuits). For each piece, it builds a truth table—a map showing what output it should produce for every possible input combination. Using this truth table, it finds better ways to rearrange the piece's wiring to use fewer or faster logic connections. All pieces are simultaneously rebuilt together, so improvements in one piece improve the others.

## Key Novelty
The core contribution is dividing circuits into pieces, rewiring each using its truth table, and rebuilding them all simultaneously so improvements spread through the entire circuit.

## Contributions
- Novel truth-table-based rewiring method for circuit restructuring
- Concurrent resynthesis framework with support-limited subcircuit partitioning
- Synergistic deployment of multiple synthesis algorithms
- Substantial improvements over strong baselines in node, transistor, and area metrics
