# Dual-Issue Execution of Mixed Integer and Floating-Point Workloads on Energy-Efficient In-Order RISC-V Cores

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Single-issue in-order cores lack IPC; dual-issue adds overhead; mixed integer-FP workloads common but underserved.

## Key Idea
COPIFT methodology + RISC-V ISA extensions enable lean dual-issue execution coupling integer and floating-point units.

## Method
Develops the COPIFT methodology and RISC-V ISA extensions (instruction set additions) to enable low-cost dual-issue execution—processing two instructions per cycle—for mixed integer and floating-point workloads. The approach couples the integer and floating-point functional units (execution hardware) together, which reduces the extra chip area and complexity needed for dual-issue while maintaining timing performance. By issuing different instruction types in parallel each cycle, it achieves instruction-level parallelism (multiple computations at once) without the full hardware cost of a traditional dual-issue system.

## Contributions
1. COPIFT dual-issue mixed-workload methodology
2. RISC-V ISA extensions
3. 1.47x speedup, 1.75 peak IPC, 1.37x energy vs. RV32G

## Hardware Target
RISC-V (in-order cores)
