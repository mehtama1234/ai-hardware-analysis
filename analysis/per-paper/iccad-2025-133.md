# LLM-Augmented Multi-Modal Fusion for SoC Design Space Exploration

**Venue:** ICCAD  
**ID:** iccad-2025-133

## Problem
Complex SoC designs have vast design spaces; current approaches reduce microarchitectures to simple parameter vectors, losing rich information embedded in functional behaviors and implementation details.

## Motivation
More effective feature extraction from microarchitectures enables better design space exploration and optimization.

## Method
The approach gathers information about a chip design from two sources: an LLM (language model trained on domain knowledge) reads the written design descriptions, while a graph neural network analyzes the actual circuit structure (Chisel-compiled RTL). A multilayer neural network combines these two perspectives to predict performance, using Monte Carlo dropout—running the prediction multiple times with random variations—to measure prediction confidence. The entire system trains together using Bayesian optimization, which automatically searches for the best settings.

## Key Novelty
It combines semantic understanding from written descriptions (LLM) with structural understanding from circuit code (graph neural network) to capture richer information about chip designs for design space exploration.

## Contributions
- LLM-based semantic feature extraction from design descriptors
- GNN-based structural feature extraction from RTL
- Multi-modal fusion with Monte Carlo dropout for uncertainty
