# LLM-Augmented Multi-Modal Fusion for SoC Design Space Exploration

**Venue:** ICCAD  
**ID:** iccad-2025-133

## Problem
Complex SoC designs have vast design spaces; current approaches reduce microarchitectures to simple parameter vectors, losing rich information embedded in functional behaviors and implementation details.

## Motivation
More effective feature extraction from microarchitectures enables better design space exploration and optimization.

## Method
LLM-augmented multi-modal fusion combining domain-knowledge-enhanced LLM for semantic features (from natural language design descriptors) and graph neural network for structural features (from Chisel-compiled RTL); MLP with Monte Carlo dropout for uncertainty quantification; end-to-end training via Bayesian optimization.

## Key Novelty
Combining LLM semantic extraction with GNN structural analysis for richer microarchitecture representation in DSE.

## Contributions
- LLM-based semantic feature extraction from design descriptors
- GNN-based structural feature extraction from RTL
- Multi-modal fusion with Monte Carlo dropout for uncertainty

## Hardware Target
- RISC-V

## Technique Categories
- EDA
- compiler

## Metrics
- **Result:** Improved exploration efficiency and prediction quality under data limitations

## Baselines
- Standard methods

## Limitations
Evaluated only on Gemmini-based RISC-V; generalization to other SoC designs unclear.
