# BLAST: Bisection-Free Statistical Timing Characterization

## Problem
Statistical timing characterization of standard cells requires laborious bisection analysis to extract setup/hold constraints for sequential cells, creating computational bottlenecks in timing closure workflows.

## Method
BLAST extracts delay measurements from data and clock paths in sequential cells (memory-holding logic elements) and feeds these into a machine learning model called multi-gate mixture-of-experts (MMoE). The model learns to predict setup and hold constraints—the timing windows that specify when data must be stable relative to clock transitions—by understanding how these constraints depend on each other through multi-task learning. To make training more efficient, BLAST uses active learning to identify and focus on the most informative examples.

## Key Results
- 76.9% runtime reduction vs commercial tools
- 2.21% relative RMSE on constraint prediction
- 0.82ps worst-case absolute error
- Tested on 135 PVT corners with TSMC 12nm process
