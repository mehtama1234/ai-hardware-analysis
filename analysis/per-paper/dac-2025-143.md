# BLAST: Bisection-Free Statistical Timing Characterization

## Problem
Statistical timing characterization of standard cells requires laborious bisection analysis to extract setup/hold constraints for sequential cells, creating computational bottlenecks in timing closure workflows.

## Method
BLAST extracts inherent delay for data and clock paths in sequential cells as features, then applies multi-task learning with a multi-gate mixture-of-experts (MMoE) model to exploit interdependencies between setup and hold constraints. Active learning strategy improves training efficiency by focusing on high-value samples.

## Key Results
- 76.9% runtime reduction vs commercial tools
- 2.21% relative RMSE on constraint prediction
- 0.82ps worst-case absolute error
- Tested on 135 PVT corners with TSMC 12nm process
