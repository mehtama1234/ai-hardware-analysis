# An Efficient RISC-V Vector Coprocessor for Heart Rate Variability Detection on Edge

**Paper ID:** vlsid-2025-061
**Venue:** VLSID
**Confidence:** low

## Problem
Continuous HRV (Heart Rate Variability) monitoring on edge/wearable devices is challenging due to lack of power and area-efficient processing optimized for this specific task.

## Motivation
Modern wearables need efficient, low-power continuous health monitoring. General-purpose processors are not optimized for HRV detection in terms of power and area efficiency.

## Method
Design of vector coprocessor based on open-source RISC-V ISA that offloads vector operations from main processor. Implements vector-aware HRV algorithm optimized for edge computing with chunked data processing for limited memory constraints.

## Key Novelty
Vector coprocessor design for RISC-V targeting HRV workload; vector-aware algorithm optimization for edge memory constraints.

## Contributions
- RISC-V vector coprocessor for efficient HRV detection
- Vector-aware HRV algorithm optimized for edge computing
- Memory-efficient chunked data processing for limited edge device resources
- 80% power density improvement vs Ibex processor
