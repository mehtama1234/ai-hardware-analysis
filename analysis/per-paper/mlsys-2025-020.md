# mlsys-2025-020 — Interference-Aware Edge Runtime Prediction with Conformal Matrix Completion (Pitot)

**Venue:** MLSYS 2025

**One-line problem:** Predict workload runtime on diverse edge platforms under multi-tenant interference from sparse observations.

## Method
Pitot uses a pair of neural networks that together apply matrix factorization—a technique for estimating missing values by decomposing data—to predict runtime. The networks take two types of information as input: features describing the workload's instructions (opcode counts) and specifications of the hardware platform. The system adds a low-rank bilinear interference term (a compact mathematical component modeling how multiple simultaneous workloads slow each other by competing for resources) directly into the learned representation. It's trained by minimizing log-scale prediction errors and provides confidence intervals via conformalized quantile regression with optimal quantile selection, calibrated separately for each platform type.

## Key Novelty
Pitot integrates the interference model—the mathematical component capturing how concurrent workloads slow each other—directly into the matrix factorization embedding space via a low-rank bilinear term, enabling joint estimation of missing runtime values and interference effects from sparse observations.

## Metrics
- 5.2% MAPE on held-out platform/workload pairs
- Up to 48% lower prediction error vs next-best baseline
- Up to 44% tighter prediction intervals
- 2x improvement over naive matrix factorization
