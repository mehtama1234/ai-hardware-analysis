# mlsys-2025-020 — Interference-Aware Edge Runtime Prediction with Conformal Matrix Completion (Pitot)

**Venue:** MLSYS 2025

**One-line problem:** Predict workload runtime on diverse edge platforms under multi-tenant interference from sparse observations.

## Method
Pitot uses two-tower MLP matrix factorization with opcode-count and hardware-spec side information. A low-rank bilinear interference term in the embedding space captures multi-tenancy contention. Uncertainty bounds are produced via conformalized quantile regression (CQR) with optimal quantile selection and per-platform calibration pools.

## Key Novelty
First system to embed interference modeling directly in the matrix factorization latent space via a low-rank bilinear term, enabling joint sparse-data matrix completion and interference estimation.

## Metrics
- 5.2% MAPE on held-out platform/workload pairs
- Up to 48% lower prediction error vs next-best baseline
- Up to 44% tighter prediction intervals
- 2x improvement over naive matrix factorization
