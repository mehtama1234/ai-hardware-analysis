# dac-2025-076: ReSMiPS: A ReRAM-based Sparse Mixed-precision Solver

**Problem:** Sparse matrix solvers on digital platforms suffer from memory bandwidth bottlenecks; ReRAM CIM struggles to maintain precision and efficiency.

**Method:** Combines Fast Sparse Matrix Reordering (FSMR) and In-memory float64 (IF64) in analog ReRAM arrays with hybrid-domain solver framework.

**Key Novelty:** In-memory float64 analog computation enabling BiCGSTAB-level precision in ReRAM at 100× speed/energy.

**Hardware Target:** CIM, ASIC  
**Technique Category:** near-data-processing, memory-system, circuit-design  
**Workloads:** HPC, scientific-computing  

**Metrics:**
- Speedup: >100x
- Energy: >100x
- Accuracy: error < 10^-15

**Baselines:** CPU BiCGSTAB, GPU BiCGSTAB
