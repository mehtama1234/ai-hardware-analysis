# ReaLM: Reliable and Efficient LLM Inference with Statistical Algorithm-Based Fault Tolerance

## Summary
Algorithm-circuit co-design for fault-tolerant LLM inference leveraging inherent LLM robustness to minimize recovery overhead.

## Key Results
- **35.83% energy efficiency** improvement vs existing methods
- **Perplexity degradation** reduced from 18.54 to 0.29
- **1.42% circuit area + 1.79% power overhead**

## Core Innovation
First systematic characterization of LLM error tolerance via large-scale injection; statistical ABFT adapts recovery strategy based on learned robustness.

## Technique
Large-scale error injection study, statistical ABFT with adaptive recovery, customized error detection circuits for efficient online statistics collection.
