# SCALES: Boost Binary Neural Network for Image Super-Resolution with Efficient Scalings

**Venue**: DATE  
**Primary Theme**: multi-granularity binarization for SR networks  

## Problem
Binary neural networks for image super-resolution suffer large performance gap versus floating-point networks due to unhandled pixel-wise, channel-wise, layer-wise and image-wise activation distribution variations.

## Method
SCALES applies scaling factors (adjustable multipliers) at multiple levels to handle how activation values vary across the network. It scales at three granularities: across network layers (layer-wise), across pixels in an image (pixel-wise), and across information channels (channel-wise). Each scaling factor adjusts based on the specific input image, so it adapts to whatever activation distributions (the ranges and patterns of intermediate values) appear. This multi-level scaling captures how activation distributions differ across the network's depth and across spatial regions of the image.

## Key Novelty
Using input-dependent scaling factors at multiple levels (layers, pixels, and channels) allows binary neural networks to accurately capture the varying activation distributions needed for image super-resolution.

## Contributions
- Layer-wise, spatial, and channel-wise scaling factor design
- 0.2 dB PSNR improvement over prior art for CNN-based SR
- First accurate binary Transformer-based SR network
- 1+ dB PSNR improvement for binary Transformer variant
