# asplos-2025-054 — PAPI: Exploiting Dynamic Parallelism in Large Language Model Decoding with a Processing-In-Memory-Enabled Computing System

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
LLM decoding kernels dynamically shift between memory-bound and compute-bound behavior as request parameters (batch size, sequence length, sampling strategy) change at runtime, making static assignment of kernels to either PIM units or GPU-like compute accelerators suboptimal. Furthermore, existing PIM units are designed with a one-size-fits-all approach that fails to exploit the heterogeneity within memory-bound LLM kernels.

## Motivation
LLM inference is increasingly deployed at scale and throughput/latency are bottlenecked by the need to move billions of model parameters across the memory bus every decoding step, yet the dynamic workload character invalidates static hardware partitioning strategies.

## Method
PAPI introduces a heterogeneous computing system combining PIM units embedded in DRAM with compute-centric accelerators (GPU-like), and a runtime that dynamically profiles kernel characteristics and remaps each kernel to the most suitable processing element at runtime. The PIM units are co-designed with awareness of intra-PIM heterogeneity to efficiently handle diverse memory-bound kernel patterns. A dynamic parallelism scheduler dispatches work to PIM or compute units based on real-time parameter changes driven by user or system demands.

## Key Novelty
Runtime dynamic kernel-to-hardware mapping that responds to changing LLM decoding workload characteristics, combined with heterogeneity-aware PIM unit design to exploit intra-PIM variance in memory-bound kernels.

## Contributions
- Characterization of dynamic compute/memory-bound transitions in LLM decoding kernels under varying runtime parameters.
- Heterogeneity-aware PIM unit architecture tailored to the diversity within memory-bound LLM kernels.
- Dynamic scheduling framework (PAPI) that remaps kernels to PIM or compute accelerators at runtime.
- Demonstration that dynamic mapping outperforms static heterogeneous mapping for LLM decoding throughput.
