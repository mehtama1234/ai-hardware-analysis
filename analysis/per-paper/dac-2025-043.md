# Alchemy: Source-Aware Adaptive Cache Management for CXL

**Problem:** CXL disaggregated memory with multiple hosts exhibits dynamic access patterns that conventional cache policies cannot track per-host, limiting efficiency.

**Key Idea:** Use online reinforcement learning to adaptively manage cache replacement and bypassing, tracking per-host access behavior and optimizing for individual host performance.

**Approach:** RL agent jointly optimizes replacement and bypassing; rewards derived from sampling-based action effectiveness and per-host macro metrics.

**Results:** 8.71%-14.56% latency reduction vs. LRU, 44× faster than ICGMM with comparable overhead.

**Theme:** Adaptive RL-based cache management for multi-host disaggregated memory systems.
