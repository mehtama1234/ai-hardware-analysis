# EOD: Enabling Low Latency GNN Inference via Near-Memory Concatenate Aggregation

**Venue:** ISCA 2025  
**Authors:** Taehwan Kim, Yunki Han, Seohye Ha, Jiwan Kim, Lee-Sup Kim  
**Confidence:** low (abstract-only)

## Problem
Real-time GNN inference for online services requires an inductive setup where the system must first prepare the computational graph and node features before executing inference, with this preparation step dominating end-to-end latency. The neighborhood explosion problem causes exponential growth in memory access and computation as the number of GNN layers increases.

## Motivation
Graph-database-backed online services increasingly require low-latency per-request GNN inference, but the heavy host-memory access and data I/O in the preparation step, combined with neighborhood explosion, make sub-millisecond targets unachievable on conventional systems.

## Method
EOD co-designs algorithm and hardware: (1) a precomputation method converting exponential neighborhood aggregation to linear complexity, (2) a concatenated ZVC compression scheme for compacted hidden features, and (3) an NMP architecture that aggregates directly on ZVC-compressed data without decompressing to host memory, eliminating the PCIe/host-memory bottleneck.

## Key Novelty
A concatenated ZVC compression format co-designed with a dedicated NMP aggregation engine that operates natively on compressed GNN features.

## Contributions
- Precomputation algorithm reducing GNN neighborhood aggregation from exponential to linear complexity.
- Concatenated ZVC compression minimizing storage overhead for precomputed hidden features.
- NMP architecture performing efficient aggregation directly on compressed data in host memory.
- 17.9x geomean (up to 74.3x) end-to-end latency speedup over GPU baseline; 981x geomean aggregation speedup.
