# PathWeaver: A High-Throughput Multi-GPU System for Graph-Based Approximate Nearest Neighbor Search

**Problem:** Existing multi-GPU ANNS solutions overlook scalability and use naive dataset partitioning that treats additional GPUs merely as memory extensions. Independent searching on each GPU partition results in redundant search iterations and poor multi-GPU utilization.

**Method:** PathWeaver uses three coordinated techniques on multiple GPUs: pipelining-based path extension (connecting GPUs to share search progress and eliminate duplicate work), ghost staging (using representative datasets to find optimal starting points), and direction-guided selection (filtering irrelevant points to reduce calculations and memory transfers). These techniques make GPUs collaborate on searches instead of working independently.

**Novelty:** Pipelining-based path extension using GPU-to-GPU communication (connecting GPUs to share search progress) to eliminate redundant search iterations in multi-GPU systems.
