# PathWeaver: A High-Throughput Multi-GPU System for Graph-Based Approximate Nearest Neighbor Search

**Problem:** Existing multi-GPU ANNS solutions overlook scalability and use naive dataset partitioning that treats additional GPUs merely as memory extensions. Independent searching on each GPU partition results in redundant search iterations and poor multi-GPU utilization.

**Method:** PathWeaver introduces three coordinated techniques: (1) pipelining-based path extension that leverages GPU-to-GPU communication to reduce redundant search iterations, (2) ghost staging that identifies optimal query starting points using representative datasets, and (3) direction-guided selection that filters irrelevant points early to minimize memory accesses and distance computations.

**Novelty:** Pipelining-based path extension mechanism that leverages GPU-to-GPU communication to eliminate redundant search iterations in multi-GPU ANNS systems.
