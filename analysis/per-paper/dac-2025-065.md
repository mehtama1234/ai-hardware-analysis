# DeepPUFSCA: Deep learning for Physical Unclonable Function attack based on Side Channel Analysis support

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Physical Unclonable Functions are vulnerable to combined challenge-response and side-channel attacks, but existing machine learning attack methods do not simultaneously leverage both information sources, missing attack opportunities.

## Motivation
PUF security verification requires understanding the combined threat of side-channel and challenge-response attacks to validate nonlinearity claims and physical uniqueness guarantees.

## Method
The method trains a deep learning model using two types of data from a PUF (a unique hardware identifier built into FPGAs): the test inputs sent to it and the electrical power it consumes while responding. By learning from both information types simultaneously, rather than separately, the model discovers patterns that more effectively break the PUF's security. This combination approach demonstrates its effectiveness on arbiter-style PUFs, a common design, showing that fusing both data sources produces much stronger attacks than using either alone.

## Key Novelty
The innovation is combining test-input data and power-consumption measurements in a single deep learning model to attack PUFs, rather than analyzing them separately.

## Contributions
- DeepPUFSCA deep learning model combining challenge and side-channel features for PUF attacks
- Outperforms other machine learning methods including ensemble algorithms in attack accuracy
- Demonstrates that side-channel information substantially boosts PUF attack performance
- FPGA implementation of arbiter PUF for realistic security validation

## Metrics
- Accuracy: Outperforms other ML and ensemble methods in attack accuracy

## Baselines
- Other machine learning methods, Ensemble algorithms, Challenge-response only attacks

## Limitations
Evaluation limited to arbiter PUF architecture without exploring other PUF types.
