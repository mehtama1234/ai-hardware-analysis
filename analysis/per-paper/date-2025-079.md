# MPFS: A Scalable User-Space Persistent Memory File System for Multiple Processes

**Venue**: DATE  
**Primary Theme**: scalable persistent memory systems  

## Problem
Multi-process performance degradation in user-space persistent memory file systems due to repeated page faults and cross-process synchronization overhead. Duplicate paging structures per process create large memory footprint.

## Method
Normally, each process maintains its own page table—a bookkeeping structure that tracks where its data lives in memory. MPFS instead creates one shared page table that all processes use together, eliminating the duplicate memory overhead. To make this sharing efficient, they organize the page table in 512GB-aligned blocks (called PGD alignment), which lets hardware handle address translations faster. A protection mechanism keyed to these alignment boundaries ensures one process's data stays isolated from another's.

## Key Novelty
Multiple processes share a single page table structure aligned to 512GB chunks instead of each maintaining their own, reducing memory waste while keeping their data protected from interference.

## Contributions
- Shareable page table eliminating duplicate paging structures
- PGD-aligned mapping accelerating page table sharing
- Cross-process protection with negligible overhead
- 15-60% speedup in multi-process scenarios
