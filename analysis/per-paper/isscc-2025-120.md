# isscc-2025-120: 8K-60fps Space-Time Resolution-Enhancement Neural-Network Processor

**Problem:** Rendering 8K-UHD 60fps videos on edge devices requires balancing model depth for quality against resource constraints, and managing on-chip memory overhead from deformable convolution with modulation (DCM) across multiple temporal alignment layers.

**Motivation:** Ultra-high-definition (UHD) displays demand efficient on-device video enhancement as 8K stream scarcity and transmission bandwidth costs necessitate real-time super-resolution on terminal displays.

**Method:** The processor improves low-quality video in both spatial detail (pixels) and temporal smoothness (between frames) using space-time video super-resolution. To run on edge devices, it combines multiple processing operations using layer-fusion, which drastically cuts the temporary data stored on the chip. It uses deformable convolution — filters that adapt their shape to follow motion between frames — to align frames precisely across time. Custom processing-element hardware is built specifically for 8K resolution at 60 frames per second with minimal power draw.

**Key Novelty:** Layer-fusion workflow that reduces on-chip memory overhead from deformable convolution modulation by fusing operations across multiple temporal alignment layers.

**Contributions:**
- 8K-60fps space-time video super-resolution processor for edge devices
- Layer-fusion technique to reduce feature map memory storage in DCM-based temporal alignment
- Architecture balancing PE array throughput with power efficiency constraints
