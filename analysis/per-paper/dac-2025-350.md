# Ares: High Performance Near-Storage Accelerator for FHE-based Private Set Intersection

**Venue:** DAC  
**ID:** dac-2025-350

## Problem
General-purpose FHE accelerators inadequately address PSI requirements, leading to suboptimal data handling and hardware underutilization for PSI acceleration.

## Motivation
Privacy-preserving PSI based on FHE is widely deployed in federated learning and password verification, but inefficient FHE processing limits practical adoption.

## Key Innovation
Lazy Relinearization optimization eliminating redundant FHE operations in PSI without protocol changes, combined with hardware architecture specialized for PSI compute patterns.

## Method
Proposes Lazy Relinearization to optimize redundant PSI calculations, analyzes/decouples PSI compute patterns, and designs hardware architecture fully utilizing bandwidth and compute resources.

## Contributions
- Lazy Relinearization algorithm reducing PSI computational complexity
- Analysis and decoupling of PSI computing patterns
- Hardware-software co-designed FPGA accelerator
- 47.99x speedup vs CPU; 1.79x-1.93x vs SOTA (Poseidon, FAB)

## Results
47.99x speedup vs CPU, 1.79x-1.93x vs SOTA FPGA; 7.96x-10.95x energy efficiency improvement.
