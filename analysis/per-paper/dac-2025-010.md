# Comparison-Free Bit-Stream Generation for Cost-Efficient Unary Computing

**Problem:** Comparator-based binary-to-unary converters have high area and power cost, scaling poorly with precision.

**Method:** Binary numbers are converted to unary representation—expressing a value N as N ones in a sequence—traditionally using comparison circuits (comparators) that check if one number is larger than another. These circuits consume significant power and chip space, especially as input size increases. This design eliminates comparators entirely and instead uses alternative conversion logic to accomplish the same transformation. It provides three implementations: a serial approach that processes one value at a time (simpler, slower), and two parallel approaches (faster) that either compute the exact result or approximate it to reduce costs further.

**Key Contribution:** Eliminates comparator overhead in unary conversion while maintaining conversion accuracy.

**Results:** Reduced area, power, and area-delay product vs state-of-the-art across four use cases.
