# PatternPaint: Practical Layout Pattern Generation Using Diffusion-Based Inpainting

**ID**: dac-2025-446  
**Venue**: DAC  
**Confidence**: low

## Problem
VLSI layout pattern generation requires large, design-rule-compliant training datasets; new technology nodes lack such data, making existing training-based methods impractical.

## Motivation
Design rules evolve with each new node; agile pattern generation enables rapid technology development.

## Method
PatternPaint uses diffusion-based inpainting with few-shot fine-tuning on pretrained image models; template-based denoising simplifies generation into inpainting tasks. Fine-tuning requires only 20 design-rule-compliant samples.

## Key Novelty
Few-shot transfer learning via diffusion inpainting for layout pattern generation, eliminating need for large training corpora.

## Contributions
- Diffusion-based inpainting framework for layout patterns
- Template-based denoising for complex routing
- Few-shot fine-tuning (20 samples) on pretrained models
- Only framework generating legal patterns for Intel 18A (sub-3nm)
