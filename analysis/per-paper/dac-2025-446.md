# PatternPaint: Practical Layout Pattern Generation Using Diffusion-Based Inpainting

**ID**: dac-2025-446  
**Venue**: DAC  
**Confidence**: low

## Problem
VLSI layout pattern generation requires large, design-rule-compliant training datasets; new technology nodes lack such data, making existing training-based methods impractical.

## Motivation
Design rules evolve with each new node; agile pattern generation enables rapid technology development.

## Method
PatternPaint fine-tunes a pretrained image model for chip layout generation using diffusion-based inpainting, a technique that fills in masked (hidden) parts of images by gradually removing noise. The method treats layout generation as an inpainting problem, handled through template-based denoising. Fine-tuning requires only 20 design-rule-compliant sample layouts, enabling it to work with new technology nodes that lack large training datasets.

## Key Novelty
PatternPaint adapts image-generation techniques (diffusion inpainting) to chip layout design, requiring only 20 example patterns instead of the thousands needed by existing methods.

## Contributions
- Diffusion-based inpainting framework for layout patterns
- Template-based denoising for complex routing
- Few-shot fine-tuning (20 samples) on pretrained models
- Only framework generating legal patterns for Intel 18A (sub-3nm)
