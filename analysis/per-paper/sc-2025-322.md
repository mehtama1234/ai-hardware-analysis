# Architecting Tensor Core-Based Reductions for Irregular Molecular Docking Kernels

**Venue:** SC
**ID:** sc-2025-322
**Confidence:** low

## Problem Statement
Tensor Cores are optimized for dense matrix operations but molecular docking has irregular computation patterns; their adoption in such HPC applications remains limited.

## Motivation
Tensor Cores offer high compute density; molecular docking is compute-intensive but irregular; TC-based accelerations could significantly improve performance if accuracy is preserved.

## Method
Tensor Cores are specialized GPU accelerators optimized for fast matrix multiplication. The authors speed up sum reduction operations—a computational bottleneck in molecular docking where you repeatedly add up numbers—by using Tensor Cores on NVIDIA GPUs (A100, H100, B200). Since Tensor Cores prioritize speed over precision, the team applies numerical error correction techniques to detect and fix small inaccuracies, keeping results accurate despite the acceleration.

## Key Novelty
This work accelerates irregular molecular docking by offloading its sum reduction bottleneck to Tensor Cores on NVIDIA GPUs (A100, H100, B200), then using numerical error correction to maintain accuracy.

## Contributions
1. TC-based reduction acceleration for AutoDock-GPU
2. Numerical error correction preserving algorithmic accuracy
3. Consistent performance gains on A100, H100, B200
