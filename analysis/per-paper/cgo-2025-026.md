# Calibro: Compilation-Assisted Linking-Time Binary Code Outlining for Code Size Reduction in Android Applications

**Venue:** CGO
**Confidence:** low

## Problem
Pre-compiled Android OAT files exhibit up to 25% code redundancy; reducing binary size is critical for constrained mobile storage and memory. Traditional link-time optimization misses redundancy.

## Motivation
Mobile devices have limited storage and memory; Android's pre-compilation creates large OAT binaries. Redundancy elimination directly reduces app footprint and improves launch performance.

## Method
Calibro reduces binary size by extracting duplicate code into single locations, using a two-stage process. During compilation, it identifies code regions that likely repeat. During linking (when all code is assembled into the final binary), it uses a parallel suffix tree—a fast data structure for detecting repeated patterns—to find actual duplicates and extract them. To avoid slowing the app, it only extracts code from infrequently-called functions.

## Key Novelty
It finds and removes duplicate code using compilation-stage hints to guide a fast link-time search, optimizing only infrequently-called functions to preserve performance.

## Contributions
- Compilation-time + linking-time binary code outlining approach
- Parallel suffix tree method for fast redundancy detection
- Hot function filtering to prevent performance degradation
- 15.19% average code size reduction with negligible runtime overhead
