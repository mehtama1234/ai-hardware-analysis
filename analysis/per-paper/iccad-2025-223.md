# No Redundancy, No Stall: Lightweight Streaming 3D Gaussian Splatting for Real-time Rendering

**Venue:** ICCAD  
**ID:** iccad-2025-223  
**Confidence:** low

## Problem Statement
3D Gaussian Splatting rendering incurs redundant computations and memory stalls affecting real-time performance.

## Motivation
Efficient 3D Gaussian Splatting acceleration enables practical real-time rendering in resource-constrained environments.

## Method
Algorithm-hardware co-design reducing computational redundancy through viewpoint transformation. Workload-aware accelerator design. Streaming architecture eliminating memory stalls.

## Key Novelty
First algorithm-hardware co-optimized approach for 3D Gaussian Splatting with redundancy elimination and stall prevention.

## Contributions

1. Viewpoint transformation for redundancy reduction
2. Workload-aware accelerator design
3. Streaming architecture eliminating stalls
4. 5.41-17.3x speedup
