# No Redundancy, No Stall: Lightweight Streaming 3D Gaussian Splatting for Real-time Rendering

**Venue:** ICCAD  
**ID:** iccad-2025-223  
**Confidence:** low

## Problem Statement
3D Gaussian Splatting rendering incurs redundant computations and memory stalls affecting real-time performance.

## Motivation
Efficient 3D Gaussian Splatting acceleration enables practical real-time rendering in resource-constrained environments.

## Method
The method co-designs the algorithm and custom hardware for 3D Gaussian Splatting. It uses the camera position to identify and eliminate redundant calculations, and builds the hardware to process only what's needed for each frame. By streaming data through the system continuously rather than loading everything into memory, it prevents the processor from stalling while waiting for data.

## Key Novelty
The core advance is co-designing the algorithm and hardware for 3D Gaussian Splatting rendering specifically to eliminate redundant work and prevent memory delays.

## Contributions

1. Viewpoint transformation for redundancy reduction
2. Workload-aware accelerator design
3. Streaming architecture eliminating stalls
4. 5.41-17.3x speedup
