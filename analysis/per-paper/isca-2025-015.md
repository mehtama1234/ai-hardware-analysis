# Caravan: A Hardware/Software Co-Design for Efficient SIMD Neighbor Search on Point Clouds

**Venue:** ISCA 2025  
**Confidence:** low (abstract-only)

## Problem
3D point cloud neighbor search via k-d trees underutilizes SIMD (VPU) lanes because consecutive queries follow similar tree paths but diverge at deeper levels, causing lane sparsity that standard SIMD cannot handle.

## Motivation
Neighbor search is the core bottleneck in 3D computer vision point cloud processing; accelerating it on commodity CPUs with minimal hardware changes offers broader applicability than custom ASICs.

## Method
**Caravan-SW** batches consecutive queries with similar k-d tree traversal paths for parallel SIMD (AVX512) execution. At divergent deeper tree levels, **Caravan-HW** introduces two new ISA instructions that (1) re-index valid (non-empty) SIMD lanes and (2) shuffle operands for dense SIMD execution, eliminating the sparsity penalty at leaf processing. The hardware extension costs only 0.032 mm2.

## Key Novelty
Two new ISA instructions re-index and compact active SIMD lanes at k-d tree divergence points, enabling dense SIMD execution without a dedicated accelerator.

## Contributions
1. Caravan-SW: query batching based on k-d tree traversal similarity for parallel SIMD neighbor search
2. Caravan-HW: two new CPU ISA instructions for lane re-indexing and operand shuffling at leaf levels
3. 5.19x neighbor search speedup (1.97x end-to-end) with HW; 4.05x (1.85x) SW-only
4. Only 0.032 mm2 area overhead for hardware extension

## Hardware Target
CPU (AVX512)

## Key Metrics
- Speedup: 5.19x neighbor search, 1.97x end-to-end (with Caravan-HW); 4.05x / 1.85x (SW only)
- Area: 0.032 mm2 additional

## Baselines
Commodity CPU baseline; custom accelerators (end-to-end comparison)

## Limitations
End-to-end speedup (1.97x) is substantially lower than kernel speedup (5.19x), indicating pipeline bottlenecks beyond neighbor search.
