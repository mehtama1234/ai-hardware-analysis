# Hydra: Harnessing Expert Popularity for Efficient Mixture-of-Expert Inference on Chiplet System

**Venue:** DAC 2025  
**Confidence:** low (abstract-only)

## Problem
Mixture-of-Expert (MoE) LLM inference on chiplet systems suffers from excessive all-to-all communication (routing tokens to replicas) and redundant computation in softmax gating for unpopular experts. These create bottlenecks in distributed architectures.

## Key Insight
Expert gating exhibits popularity bias (skewed usage distribution). Exploiting this via popularity-aware mapping and hardware permutation elimination dramatically reduces interchiplet traffic and wasted computation.

## Hardware-Software Co-Design
### Software
- **Popularity-aware expert mapping:** Route tokens considering expected gating distribution, minimizing all-to-all volume
- Reduces inefficient cross-chiplet permutation traffic

### Hardware (Chiplet-based ASIC)
- **Content Addressable Memory (CAM):** Eliminates explicit token unscrambling; replaces expensive sparse matrix multiplication
- **Redundant-calculation-skipping softmax:** Avoids exponential/division for low-probability expert paths

## Results (22 nm Technology)
- **Latency:** 14.2× vs. GPU, 3.5× vs. state-of-the-art MoE accelerator
- **Power:** 169.1× reduction vs. GPU, 18.9× vs. MoE accelerator
- Scalable solution for distributed MoE deployment
