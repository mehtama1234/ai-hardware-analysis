# isscc-2025-032: Multi-Site Biochemical Processor

**Title:** A 384-Site Chip Platform for Biochemical Applications with Individual Site Precision Temperature Control

**Venue:** ISSCC

## Core Contribution
384-site silicon chip platform enabling independent temperature control per site for parallel PCR, gene assembly, and biochemical workflows.

## Key Metrics
- **Sites:** 384 independent sites
- **Capability:** Precision per-site temperature control
- **Application:** PCR, gene assembly, biochemical reactions

## Problem
Silicon's high thermal conductivity prevents efficient thermal isolation between sites, preventing independent temperature control in multi-site biochemical processors.

## Method
The chip has 384 reaction sites, each with its own heating element and temperature sensor. Heat spreads between neighboring sites through the silicon substrate (which conducts heat easily), making independent temperature control nearly impossible. To fix this, they engineered the substrate with thermal barriers—physical structures that block heat spread—giving each site the thermal isolation needed to maintain its target temperature independently.
