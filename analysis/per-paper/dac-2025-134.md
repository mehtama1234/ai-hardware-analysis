# Megabits Down to Kilobits: Memory-Efficient Time-Aware Shaping for TSN

**Venue:** DAC | **ID:** dac-2025-134

## Core Problem
Memory-efficient Time-Aware Shaper for TSN; traditional per-frame gate control tables require tens of megabits, exceeding switch capacity.

## Method
Instead of storing control rules for every single frame, METAS keeps just one persistent rule per flow and generates specific frame-level rules on-demand. This approach trades memory for computation: less upfront storage but slightly more work when each frame arrives. An FPGA implementation demonstrates the payoff: memory usage drops from 14.34 megabits to 288 kilobits for 1,024 flows (a 98% reduction), using only 1.56% of FPGA logic resources while maintaining microsecond-level latency and nanosecond-level jitter guarantees.

## Key Novelty
Store a single rule per traffic flow and generate per-frame rules on-demand instead of storing them all, slashing memory by 98% while maintaining strict timing guarantees.

## Contributions
- Per-flow approach with dynamic frame rules
- 14.34 Mbits → 288 Kbits (98% reduction) for 1,024 flows
- Microsecond/nanosecond latency/jitter preservation
- FPGA prototype using 1.56% logic resources
