# dac-2025-453: Quantum Solver for Portfolio Optimization

## Summary
SAPO is a quantum algorithm and circuit design framework for portfolio optimization that improves both scalability and accuracy by embedding financial domain knowledge into the HHL algorithm.

## Key Results
- 36.94% complexity reduction vs basic HHL
- 1.46× accuracy gain vs hybrid HHL
- Evaluated on market data

## Technical Approach
- **Core Algorithm**: Extended HHL with mean-variance financial theory
- **Optimization**: Min-max eigenvalue calibration using historical market characteristics
- **Benefit**: Trades off computational complexity with high precision for financial workloads

## Contribution
Demonstrates that quantum algorithm design for domain-specific problems (finance) benefits from explicit integration of domain theory and empirical calibration, enabling better scalability-accuracy trade-offs than generic quantum linear solvers.
