# H3Match: Hybrid Heterogeneous Hypergraph Matching for Subcircuit Identification

**Venue:** DAC | **ID:** dac-2025-180

## Summary
H3Match addresses subcircuit matching in logic synthesis and verification by modeling circuits as heterogeneous hypergraphs and using directed GNN-based approximate matching followed by MINLP exact verification. The approach eliminates false negatives that plagued prior GNN methods and achieves 7.08× end-to-end speedup with improved accuracy.

## Key Results
- **Speedup:** 7.08× overall; 4.16× on exact verification alone
- **Accuracy:** 4.31% improvement over SOTA; virtually zero false negatives
- **Method:** Hypergraph representation + DAG-reformulated GNN matching + MINLP exact verification with warm-start

## Technique
Heterogeneous hyperedge features capture circuit topology; directed GNN identifies candidates with near-zero false negatives; MINLP exact verification accelerated by extracting initial solutions from GNN results.
