# Synthesis of Sorting Kernels

**Venue:** CGO | **Confidence:** low (abstract-only)

## Problem
Optimal small-array sorting kernels are difficult to synthesize; AlphaDev required massive resources and solved only lengths 3-5 partially.

## Core Innovation
Using A* search with specialized heuristics and pruning to efficiently enumerate optimal sorting kernels without TPU clusters, establishing tight lower bounds.

## Method
The algorithm uses A* search—a technique that systematically tries different solutions while using heuristics to steer toward the best answers. To stay efficient, it employs two types of shortcuts: some guarantee it never skips the optimal solution, while others speed things up by pruning unpromising branches (even if they might contain an answer). For arrays of length 3, it exhaustively tries all correct sorting kernels; for larger arrays, it intelligently samples the best candidates. This approach runs about 100 times faster than prior work (AlphaDev) without requiring specialized hardware like TPU clusters.

## Key Contributions
- A* search with optimality-preserving heuristics and pruning cuts
- Complete enumeration of all correct length-3 sorting kernels with optimal selection
- Discovery of near-optimal kernels for larger lengths; tight lower bound for length 4

## Results
- Synthesis speedup vs AlphaDev: 100x
- Improved lower bound tightness for length 4

## Limitations
Scalability to practical array sizes and computational cost for lengths >5 not analyzed.
