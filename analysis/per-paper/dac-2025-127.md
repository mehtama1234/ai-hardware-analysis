# PIMPAL: Accelerating LLM Inference on Edge Devices via In-DRAM Arithmetic Lookup

**Venue:** DAC | **ID:** dac-2025-127

## Core Problem
Accelerating GEMV for LLM inference on edge devices; GEMV is memory-intensive and existing PIM architectures have high area overhead or restricted precision.

## Method
PIMPAL replaces arithmetic with parallel in-DRAM LUT lookups: (1) DRAM subarrays divided into compute blocks; (2) Locality-aware Compute Mapping maximizes LUT access locality; (3) LUT Aggregation enables multi-precision.

## Key Novelty
Cost-effective PIM using LUT-based operations for GEMV, reducing area while maintaining edge performance.

## Contributions
- Parallel in-DRAM LUT-based GEMV acceleration
- Locality-aware Compute Mapping minimizing row activations
- LUT Aggregation for multi-precision
- 17.8x vs. LUT-PIM; 40% area vs. processing unit-PIM
