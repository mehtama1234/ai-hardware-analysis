# PIMPAL: Accelerating LLM Inference on Edge Devices via In-DRAM Arithmetic Lookup

**Venue:** DAC | **ID:** dac-2025-127

## Core Problem
Accelerating GEMV for LLM inference on edge devices; GEMV is memory-intensive and existing PIM architectures have high area overhead or restricted precision.

## Method
Instead of doing arithmetic in a processor, PIMPAL pre-computes and stores the results of calculations as lookup tables inside DRAM memory, then looks up these values in parallel across multiple sections of DRAM banks. This avoids the energy cost of moving data back and forth between memory and a processor. The system uses smart data placement to minimize DRAM row activations (the expensive operation of reading different parts of memory), and combines results from multiple small lookup tables to support multiple precision levels.

## Key Novelty
PIMPAL uses lookup tables stored in DRAM memory instead of traditional arithmetic operations to accelerate matrix-vector multiplication with low chip area overhead while supporting multiple precision levels on edge devices.

## Contributions
- Parallel in-DRAM LUT-based GEMV acceleration
- Locality-aware Compute Mapping minimizing row activations
- LUT Aggregation for multi-precision
- 17.8x vs. LUT-PIM; 40% area vs. processing unit-PIM
