# isscc-2025-008: Per-Pixel OLED Display Compensation

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
LTPS-TFT OLED displays exhibit pixel-to-pixel TFT parameter variation (Kp, Vth) and channel voltage offset (Vos), causing luminance non-uniformity. Internal compensation via extra TFTs reduces aperture ratio and efficiency.

## Approach
Source-driver IC with external real-time pixel compensation:
1. **Dual-slope error detection:** measures individual DTFT characteristics
2. **Multi-channel time-multiplexed compensator:** dynamically adjusts Vdata per pixel
3. Preserves high aperture ratio vs. internal approaches

## Key Contribution
External per-pixel luminance correction via dual-slope detection and time-multiplexed compensation—no aperture sacrifice.

## Performance
- Application: Mobile OLED with LTPS-TFTs
- Scope: Per-pixel real-time compensation
- Method: External source-driver compensation
