# AMALI: An Analytical Model for Accurately Modeling LLM Inference on Modern GPUs

**Venue:** ISCA  
**Confidence:** low (abstract-only analysis)

## Problem
Existing GPU analytical models cannot accurately predict LLM inference performance because they mismodel tensor core throughput, ignore constant and instruction cache effects, and abstract away warp-level execution details critical to LLM kernels.

## Motivation
Architects rely on analytical models to quickly identify bottlenecks and explore design spaces; errors exceeding 100% MAPE in current models make them unreliable for LLM inference workloads on modern GPUs such as A100.

## Method
AMALI introduces three modeling innovations: (1) an instruction-modifier and throughput-based tensor core model that captures math-pipe throttle stalls; (2) micro-benchmark-derived analytical models for constant cache and instruction cache measuring CUDA kernel launching latencies; (3) a multi-warp model using warp instruction number distributions to reflect LLM inference kernel characteristics. All three are validated against real A100 measurements.

## Key Novelty
Explicit modeling of instruction-cache and constant-cache latencies via micro-benchmarks, combined with a throttle-stall-aware tensor core model, reduces LLM inference MAPE from 127.56% to 23% on A100.

## Contributions
1. Instruction-modifier and throughput-based tensor core model capturing math-pipe throttle stalls
2. Analytical constant-cache and instruction-cache models derived from CUDA micro-benchmarks
3. Multi-warp execution model using warp instruction number distribution for LLM inference characteristics
4. Validation on A100 GPU reducing MAPE from 127.56% to 23%
