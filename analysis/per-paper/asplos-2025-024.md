# MoE-Lightning: High-Throughput MoE Inference on Memory-constrained GPUs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** CPU-GPU-IO pipeline for high-throughput MoE inference on memory-constrained GPUs

## Problem
Sparse MoE LLMs have very large total parameter counts exceeding commodity GPU VRAM, forcing weight offloading to CPU memory, which creates severe I/O bottlenecks and low GPU utilization during batch inference.

## Motivation
MoE models offer high capacity at low per-token compute cost, but their large memory footprint makes them inaccessible to users with low-end GPUs without efficient offloading strategies.

## Method
CGOPipe (CPU-GPU-I/O Pipelining) pipelines expert weight streaming between CPU memory and GPU memory using paged weight management, overlapping expert computation with prefetching of next expert weights. A Hierarchical Roofline Model (HRM) guides offloading policy selection by predicting throughput as a function of batch size, GPU memory, CPU memory, and I/O bandwidth. Supports multi-GPU (2-4 T4s) for larger models like Mixtral 8x22B and DBRX.

## Key Novelty
CGOPipe: a CPU-GPU-I/O pipeline with paged expert weights, guided by a Hierarchical Roofline Model, achieving near-peak offloading throughput with significantly less CPU memory than prior work.

## Contributions
- CGOPipe: CPU-GPU-I/O pipeline with paged weight management for high-throughput MoE inference
- HRM: a performance model for identifying high-throughput offloading policies
- 10.3x throughput over state-of-the-art offloading for Mixtral 8x7B on single T4 GPU (16GB)
- 2-3x CPU memory reduction at throughput upper bound; support for Mixtral 8x22B and DBRX on 2-4 T4s
