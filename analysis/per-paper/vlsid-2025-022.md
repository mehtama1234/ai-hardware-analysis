# Symmetry-Based Synthesis for Interpretable Boolean Evaluation

**Venue:** VLSID

## Problem
Boolean function synthesis for >6 inputs intractable; state-of-the-art requires hyper-parameter tuning; poor interpretability

## Motivation
Boolean circuits fundamental to hardware; efficient synthesis essential for circuit design; interpretability aids optimization

## Method
The approach exploits symmetries—patterns where certain inputs behave the same way—to make Boolean function synthesis practical. Inspired by Edward's theory, it recursively breaks large problems into smaller subproblems with the same structure, synthesizing solutions for each piece. By reusing solutions across symmetrical parts, the method can handle Boolean functions with up to 20 inputs, whereas earlier approaches got stuck at 6.

## Key Novelty
By exploiting symmetries in Boolean functions and breaking them into recursive, interpretable structures, this method scales synthesis from 6 to 20 inputs.
