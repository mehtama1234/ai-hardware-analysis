# SC-2025-301: Overcoming Dynamic I/O Boundaries: a Double-Sided Streaming Methodology with dispel4py and CAPIO

## Summary
This work proposes a novel double-sided streaming methodology that combines control-plane streaming (via dispel4py) with data-plane streaming (via CAPIO) to eliminate artificial I/O boundaries in scientific workflow orchestration. The approach introduces a new commit rule in CAPIO that enables streaming over dynamically generated file sets, supporting hybrid in-memory and file-based dataflows without modifying existing workflow logic.

## Key Contributions
1. **Double-sided streaming architecture** combining control-plane and data-plane streaming for end-to-end workflow processing
2. **CAPIO extension** with dynamic file-set commit rule enabling seamless streaming across phase boundaries
3. **23-40% performance improvement** on seismic cross-correlation workflows through eliminated synchronization barriers
4. **Transparent integration** that preserves existing workflow logic and programmer interfaces

## Technical Approach
- Integration of dispel4py (control-plane) and CAPIO (data-plane) streaming systems
- Extension to CAPIO's commit rules to support dynamically generated file sets
- Hybrid execution model supporting both in-memory dataflows and file-based communication
- Elimination of phase-boundary barriers that typically enforce strict ordering

## Hardware & Systems
- Multi-core distributed systems with shared storage
- Applicable to various HPC architectures with file I/O subsystems

## Workloads & Evaluation
- **Primary workload**: Seismic cross-correlation workflow
- **Performance metrics**: 23-40% throughput improvement
- **Key benefit**: Streaming across entire workflow including phase boundaries

## Limitations & Future Work
- Limited evaluation scope (single seismic application)
- Scalability on very large distributed systems not thoroughly explored
- Extension to other multi-stage applications needs empirical validation
