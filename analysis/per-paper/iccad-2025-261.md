# HRAMTran: A Hybrid-RAM Transformer Accelerator With Dynamic Sparsity Floating-Point CIM and Written-Back Transpose Array

**Venue:** ICCAD  
**Paper ID:** iccad-2025-261

## Problem Statement
Transformer attention mechanism computation is energy and latency intensive; existing accelerators lack efficient floating-point CIM support with dynamic sparsity.

## Motivation
Attention computation is a bottleneck in transformer models; hybrid-RAM CIM architecture can enable efficient dynamic sparsity-based matrix multiplication.

## Method
HRAMTran uses SOT-MRAM and SRAM based CIM for weight storage and dynamic MM, implements dynamic sparsity by ignoring low-impact elements, adds data-reuse MAC scheme for mantissa operations, and uses written-back transpose SRAM array for efficient KT computation.

## Key Novelty
Hybrid SOT-MRAM/SRAM CIM with dynamic floating-point sparsity and specialized written-back transpose architecture for transformer attention.

## Contributions

1. 3.6 µJ/Token energy efficiency
2. 68.77 TFLOPS/W
3. 4.33× performance improvement
4. 2.39× energy efficiency vs SOTA
