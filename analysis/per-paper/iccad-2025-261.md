# HRAMTran: A Hybrid-RAM Transformer Accelerator With Dynamic Sparsity Floating-Point CIM and Written-Back Transpose Array

**Venue:** ICCAD  
**Paper ID:** iccad-2025-261

## Problem Statement
Transformer attention mechanism computation is energy and latency intensive; existing accelerators lack efficient floating-point CIM support with dynamic sparsity.

## Motivation
Attention computation is a bottleneck in transformer models; hybrid-RAM CIM architecture can enable efficient dynamic sparsity-based matrix multiplication.

## Method
The accelerator stores weights in SOT-MRAM and SRAM memory and performs calculations directly in that memory instead of moving data to a separate processor, which saves time. It automatically skips operations involving numbers with low impact on the result, and reuses data efficiently across repeated calculation steps on floating-point values (decimal numbers). A specialized transpose array then quickly flips the arrangement of weights to efficiently compute the attention mechanism.

## Key Novelty
The core innovation pairs magnetic RAM (SOT-MRAM) with standard RAM (SRAM) to perform calculations directly in memory, automatically skip low-impact operations, and use a specialized transpose array for efficient transformer attention.
