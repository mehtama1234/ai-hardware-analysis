# FastFlip: Compositional SDC Resiliency Analysis

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Silent Data Corruption (SDC) resiliency analyses are expensive and must rerun entirely after code changes, making them impractical for standard development workflows like regression testing.

## Technical Approach
Combines empirical error injection with symbolic SDC propagation to enable incremental re-analysis. Only modified program sections are reanalyzed instead of entire programs, with compositional analysis guiding selective compiler-level SDC detection mechanisms.

## Key Novelty
FastFlip is the first to enable compositional (modular, reusable) and incremental error injection analysis, reanalyzing only changed program sections instead of running fresh analyses each time.

## Key Results
- 3.2× geomean speedup on incremental modifications; up to 17.2×
- Selective protection minimizes runtime overhead while meeting SDC coverage targets

## Hardware & Techniques
- **Target:** CPU
- **Techniques:** Compiler-level reliability analysis, compositional error injection
