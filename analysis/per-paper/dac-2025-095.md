# EnQode: Fast Amplitude Embedding for Quantum Machine Learning

## Problem
Conventional amplitude embedding (AE) for QML requires deep variable-length circuits, causing cumulative gate error and inconsistent noise levels across samples, degrading model accuracy.

## Method
Instead of building a unique circuit for each data sample, EnQode groups similar samples and creates a single circuit template—an ansatz—that represents each group's average state. This ansatz is designed to be shallow (short) and tailored to the specific quantum hardware, minimizing the number of quantum gates. Since all samples in a group share the same circuit, noise from quantum hardware imperfections stays consistent rather than varying unpredictably per sample. This consistency, combined with reduced gates, ensures reliable learning on noisy quantum computers.

## Key Innovation
Symbolic clustering-based AE that standardizes circuit depth and minimizes gates, ensuring noise consistency on NISQ devices.

## Contributions
- Symbolic representation-based amplitude embedding
- Sample clustering for cluster mean state derivation
- Low-depth, machine-specific ansatz
- Standardized circuit depth reducing noise variance
- 94%+ fidelity in data mapping

## Motivation
NISQ devices require efficient, low-depth data encoding to minimize cumulative gate error and achieve model robustness.
