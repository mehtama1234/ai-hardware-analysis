# VoLUT: Efficient Volumetric streaming enhanced by LUT-based super-resolution

**ID:** mlsys-2025-044 | **Venue:** MLSYS 2025

## Problem
3D volumetric video streaming requires high bandwidth; downsampling before transmission and 3D super-resolution at the receiver is needed, but neural 3D SR methods are too slow for real-time use on commodity mobile devices.

## Method
VoLUT uses a two-stage SR pipeline:
1. **Dilated kNN interpolation**: broader spatial context via dilated k-nearest neighbors; octree parallelism for speed; neighbor relationship reuse across steps.
2. **LUT refinement**: normalize point coordinates, quantize to b=128 bins per axis, look up precomputed high-resolution offsets in a 3D LUT (RF=4, bin=128 → 1.6GB LUT built offline from a trained NN).

An MPC-based adaptive bitrate (ABR) algorithm dynamically selects downsampling rate based on network conditions.

## Key Novelty
First system enabling high-quality 3D point cloud super-resolution at line-rate on commodity mobile devices via offline NN-to-LUT conversion with position encoding quantization.

## Results
- **8.4x** SR speedup vs YuZu
- **70%** bandwidth reduction
- **36.7%** QoE improvement for volumetric video streaming
- Baselines: GradPU, YuZu, Vivo

## Hardware Target
Commodity mobile devices (receiver); server-side encoding
