# VoLUT: Efficient Volumetric streaming enhanced by LUT-based super-resolution

**ID:** mlsys-2025-044 | **Venue:** MLSYS 2025

## Problem
3D volumetric video streaming requires high bandwidth; downsampling before transmission and 3D super-resolution at the receiver is needed, but neural 3D SR methods are too slow for real-time use on commodity mobile devices.

## Method
VoLUT uses a two-stage super-resolution process for 3D point clouds. Stage 1 uses dilated k-nearest neighbor search (finding nearby points using a wider search pattern to provide context), accelerated via octree parallelism (organizing 3D space into a tree structure for parallel processing), with neighbor relationships reused across steps. Stage 2 normalizes coordinates to [0,1], quantizes them into 128 bins per axis, and looks them up in a precomputed 3D table (built from a neural network, 1.6GB, with a 4-pixel receptive field) that provides position offsets; an adaptive bitrate algorithm (Model Predictive Control) dynamically adjusts downsampling based on network conditions.

## Key Novelty
VoLUT achieves real-time 3D point cloud super-resolution on mobile devices by converting trained neural networks to a precomputed 3D lookup table (1.6GB, 128 bins per axis) for position refinement, combined with dilated k-nearest neighbor interpolation and adaptive bitrate streaming.

## Results
- **8.4x** SR speedup vs YuZu
- **70%** bandwidth reduction
- **36.7%** QoE improvement for volumetric video streaming
- Baselines: GradPU, YuZu, Vivo

## Hardware Target
Commodity mobile devices (receiver); server-side encoding
