# Chronbench: An Incremental HDL Benchmark Suite

**Problem:** FPGA CAD tools compile entire designs from scratch, causing slow development iterations and limiting designer productivity. There is a lack of benchmarks encapsulating realistic HDL development histories, preventing research into sophisticated incremental compilation flows.

**Method:** Chronbench records real hardware design work by capturing ordered snapshots (called 'commits') in git repositories, where each snapshot is a complete, compilable design. The researchers built a tool that transforms public code repositories into benchmark test suites. They analyzed these benchmarks by compiling all 170 snapshots through the three main stages—synthesis (converting designs to basic logic gates), placement (arranging components on the chip), and routing (connecting them with wires)—to study how designs evolve, which parts change between versions, and how much work could be reused.

**Novelty:** Turning ordered, compilable snapshots of real hardware development from git repositories into standard benchmarks enables researchers to study how to rebuild only the parts that changed, instead of recompiling entire designs from scratch.
