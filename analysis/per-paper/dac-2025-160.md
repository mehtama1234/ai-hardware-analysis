# Real-Time Dynamic IR-drop Prediction for IR ECO

**Authors:** Yu-Che Lee, Yu-Hsuan Chen, Yu-Chen Cheng, Yong-Fong Chang, Jia-Wei Lin, Hsun-Wei Pao, Yung-Chih Chen, Yi-Ting Li  
**Venue:** DAC 2025

## Summary
This work proposes an XGBoost-based ML model for real-time IR-drop prediction during Engineering Change Order (ECO) stages in chip design. It predicts voltage integrity changes without simulation, achieving 88x speedup over Voltus and enabling concurrent evaluation of multiple ECO candidates.

## Key Contributions
- XGBoost model for dynamic IR-drop prediction with global cell-context awareness
- Real-time estimation (minutes) replacing hour-long simulations
- 88x speedup over Voltus commercial tool
- 64x speedup over traditional ML predictors
- 93% detection accuracy for fixed cells, 8.75 mV average error

## Technical Approach
The XGBoost model captures IR-drop variations after cell movement by learning from surrounding cell context and global chip state. After ECO modifications, it provides immediate predictions without needing to run expensive SPICE simulations or Voltus analysis, enabling designers to evaluate and compare multiple ECO candidates in parallel within a single iteration.

## Hardware Target
ASIC design and optimization (3nm technology demonstrated)

## Technique Category
Compilation and design automation

## Metrics
- Speedup vs Voltus: 88x
- Speedup vs traditional ML: 64x
- Detection accuracy: 93% of fixed cells
- Mean absolute error: 8.75 mV

## Limitations
Evaluated on single industrial 3nm design; generalization to other designs and technologies unclear.
