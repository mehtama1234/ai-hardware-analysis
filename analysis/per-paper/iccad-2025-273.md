# EI-TR: A Versatile Exponential Integrator Framework for Transient Analysis of Generic Nonlinear Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-273

## Problem
Application of exponential integrator (EI) methods to generic nonlinear circuits faces numerical instability and difficulty in combining with Newton iterations.

## Motivation
To provide a more efficient and stable alternative to backward differentiation formulas (BDF) for transient circuit simulation.

## Method
Novel nonlinear EI framework with implicit regularization using smart eigenvalue modification to avoid system partition that induces numerical instability; truncated rational (TR) approximation for nonlinear function treatment. Decouples linear and nonlinear system solutions and reduces three-layer nested iteration in EI-NK to single Newton loop similar to conventional BDF.

## Key Novelty
Implicit regularization scheme with TR approximation enabling stable exponential integration for generic nonlinear circuits.

## Contributions
- Novel EI-TR framework for generic nonlinear circuit transient analysis
- Implicit regularization scheme avoiding system partition instability
- 3× reduction in Newton iterations compared to EI-NK
- 6.5× larger time steps compared to traditional trapezoidal methods
