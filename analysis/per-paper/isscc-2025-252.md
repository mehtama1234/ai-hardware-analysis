# PVT-Robust Interleaved GRO-Based ADC

**Venue:** ISSCC  
**ID:** isscc-2025-252

## Problem
Ring-oscillator (RO)-based ADCs offer scaling advantages but face challenges: VC-RO requires nonlinear calibration and individual ROs per channel; gated-RO shares poorly due to long integer-counting; cyclic coupled ROs have phase errors from prior art.

## Solution
2×64-channel time-interleaved two-step ADC uses gated cyclic coupled ring-oscillator (G-CCRO) quantizer shared across channels and steps. G-CCRO operates independently of input amplitude with inherent phase interpolation; ramp generator reallocated to reference path for constant input impedance.

## Key Innovation
Shared G-CCRO quantizer enabling efficient channel/step interleaving with inherent phase interpolation.

## Results
- **Sampling rate:** 2.2 GS/s
- **ENOB @ 4.5GHz:** 7b
- **Energy:** 19.7 fJ/conv-step Walden FoM
- **Area:** 0.004 mm²

## Hardware Target
ASIC

Circuit design, signal processing, parallelism
