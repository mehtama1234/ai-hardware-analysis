# A Streaming Collectives Interface Targeting Dataflow Acceleration and HPC Workloads

**ID:** sc-2025-074 | **Venue:** SC

## Problem Statement
Dataflow accelerators lack scalable collective communication support; no framework for accelerator-initiated MPI

## Motivation
Dataflow accelerators offer energy efficiency but limited by communication capabilities; HLS interface needed for HPC adoption

## Method
They built a streaming interface—continuous data pipelines created through hardware synthesis tools—that enables communication between a host computer and a dataflow accelerator (a processor optimized for routing data through operations). The interface uses MPI (the standard multi-computer communication protocol) and allows the accelerator itself to initiate collective operations, which are coordinated data exchanges involving multiple processors. They validated the design using an enhanced version of the HPL benchmark from the HPCC_FPGA suite.

## Key Novelty
A collective communication interface using data streaming for dataflow accelerators that reduces hardware resource consumption.
