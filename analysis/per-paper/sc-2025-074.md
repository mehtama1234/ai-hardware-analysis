# A Streaming Collectives Interface Targeting Dataflow Acceleration and HPC Workloads

**ID:** sc-2025-074 | **Venue:** SC

## Problem Statement
Dataflow accelerators lack scalable collective communication support; no framework for accelerator-initiated MPI

## Motivation
Dataflow accelerators offer energy efficiency but limited by communication capabilities; HLS interface needed for HPC adoption

## Method
HLS-based streaming interface for fine-grained host-accelerator data transfer via MPI; enhanced HPL benchmark from HPCC_FPGA

## Key Novelty
Streaming collective communication interface for dataflow accelerators; resource-efficient via stream-based transfers

## Contributions
- HLS streaming interface for collectives
- Software-hardware co-design approach
- 18% throughput improvement on enhanced HPL
- 36% latency reduction in kernel execution
- Superlinear speedup in strong scaling stencil benchmark
