# Bridging FPGA and GPU over PCIe: A Low-Latency Communication Path using AVX-512

**ID:** sc-2025-228
**Venue:** SC
**Confidence:** low

## Problem

Inter-accelerator communication bottlenecks; high latency and complexity in GPU-FPGA bridging

## Motivation

Need low-latency FPGA-GPU communication for hybrid accelerator systems; DMA overhead limits performance

## Approach

Programmed I/O using AVX-512 instructions for PCIe communication; GPU peer-to-peer memory mapping

## Key Novelty

Ultra-low sub-2-microsecond latency between GPUs and FPGAs is achieved using AVX-512-driven direct PCIe I/O and peer-to-peer GPU memory mapping, eliminating traditional DMA controllers.

## Contributions

- Programmed I/O mechanism for FPGA-GPU communication
- AVX-512-based descriptor/payload injection
- GPU peer-to-peer memory remapping technique
- Outperforms RDMA for small packets
