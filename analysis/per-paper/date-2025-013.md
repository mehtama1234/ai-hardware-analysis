# date-2025-013: Assessing Soft Error Reliability in Vectorized Kernels

## Problem
Vector extensions (Arm SVE, RISC-V RVV) on high-performance processors increase soft error vulnerability. The relationship between register cross-section, vector operations, and error criticality needs characterization.

## Method
Uniform random fault injection techniques assess soft error vulnerability in vectorized kernels across Arm and RISC-V ISAs. The study correlates soft error criticality to register cross-section and vectorized benchmark characteristics.

## Contributions
- Quantified soft error criticality correlation to register cross-section
- Performance and reliability trade-off analysis for vector extensions
- Fault injection methodology applicable to vectorized kernels

## Results
Results show soft error criticality correlation to registers' cross-section and vectorized benchmarks, emphasizing the need for performance and reliability balance in emerging devices with vector capabilities.
