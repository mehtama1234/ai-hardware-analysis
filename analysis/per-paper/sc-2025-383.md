# LLM4FP: LLM-Based Program Generation for Triggering Floating-Point Inconsistencies Across Compilers

**Venue:** SC
**ID:** sc-2025-383
**Confidence:** low

## Problem

Floating-point inconsistencies across compilers undermine numerical software reliability; existing detection tools (Varity) miss many inconsistencies.

## Motivation

LLM-guided program generation can improve detection of floating-point inconsistencies across different compilers and optimization levels.

## Method

LLM4FP: combines Grammar-Based Generation and Feedback-Based Mutation to generate diverse floating-point programs triggering compiler inconsistencies.

## Key Novelty

First framework using LLMs for targeted floating-point inconsistency detection; uncovers real-valued differences beyond extreme values.

## Contributions

1. LLM-based floating-point program generation framework
2. Grammar-based and feedback-based mutation strategies
3. 2x more inconsistencies detected vs Varity
4. Broader optimization level coverage
5. Host-device compiler mismatch detection
