# LLM4FP: LLM-Based Program Generation for Triggering Floating-Point Inconsistencies Across Compilers

**Venue:** SC
**ID:** sc-2025-383
**Confidence:** low

## Problem

Floating-point inconsistencies across compilers undermine numerical software reliability; existing detection tools (Varity) miss many inconsistencies.

## Motivation

LLM-guided program generation can improve detection of floating-point inconsistencies across different compilers and optimization levels.

## Method

LLM4FP uses language models to generate test programs that expose how different compilers handle floating-point arithmetic (decimal math) differently. It works in two stages: Grammar-Based Generation creates syntactically correct programs, then Feedback-Based Mutation observes which ones trigger compiler differences and modifies them to find more inconsistencies. By combining systematic generation with learning from prior results, the approach discovers compiler mismatches that traditional testing tools miss.

## Key Novelty

It's the first framework to use language models to hunt for floating-point inconsistencies across compilers, uncovering numerical differences that occur in normal calculations rather than only at extreme values.

## Contributions

1. LLM-based floating-point program generation framework
2. Grammar-based and feedback-based mutation strategies
3. 2x more inconsistencies detected vs Varity
4. Broader optimization level coverage
5. Host-device compiler mismatch detection
