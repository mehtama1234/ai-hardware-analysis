# SC-2025-182: Drona Workflow Engine

**Venue:** SC 2025  
**Authors:** Andrii Kryvenko, Duy Pham, Marinus Pennings, Honggao Liu  
**Confidence:** low (abstract only)

## Summary

Drona is a GUI-based HPC workflow engine that assists novice researchers in running scientific workflows by generating HPC scripts automatically while maintaining full transparency and editability.

## Hardware Target

- HPC Systems (general-purpose)

## Problem & Motivation

HPC resources are becoming increasingly complex, but adoption is growing among novice researchers across domains. Most lack HPC skills, leading to steep learning curve, frustration, and inefficient resource utilization. Drona addresses this by abstracting HPC complexity while retaining user control.

## Approach

1. Intuitive GUI for researchers to specify workflow requirements
2. Automatic generation of all required HPC scripts
3. Fully editable preview window for script inspection and adjustment
4. Flexible framework for importing, creating, adapting, and sharing custom workflows

## Key Contributions

1. User-friendly GUI-based workflow assistance
2. Automatic HPC script generation and customization
3. Framework for workflow portability and sharing
4. Significant productivity enhancement through HPC abstraction

## Limitations

No quantitative performance or usability metrics in abstract; productivity gains not quantified.
