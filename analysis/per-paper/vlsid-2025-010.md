# Effective Memory Management and Sparse Aware Cache for Row-Wise Sparse CNNs

**Venue:** VLSID
**Authors:** MC Balasubramaniam, Basava Naga Girish Koneru, Nitin Chandrachoodan

## Problem Statement
Convolutional Neural Networks (CNNs) are used in several image processing tasks like image recognition and object localization

## Key Innovation
Novel propose approach

## Method
Convolutional neural networks for image processing often have many zero values; this approach exploits that sparsity by skipping zeros during computation instead of processing them. It organizes non-zero values in row-wise patterns that match how the processor's cache (fast memory attached to the processor) works, keeping related data together so the processor doesn't have to fetch from slower main memory as often. On resource-constrained hardware with limited cache, this reduces the bandwidth and power needed, making the network run faster.
