# FeKAN: Efficient Kolmogorov-Arnold Networks Accelerator

**Problem:** KANs require dynamic B-spline interpolation operations, but existing MLP-optimized accelerators use vector-matrix multiplication, wasting hardware on this specialized workload.

**Method:** FeKAN uses a software-hardware co-design approach that pre-computes the B-spline basis functions KAN needs and stores them in specialized FeFET-based memory structures (lookup tables and content-addressable memory that quickly find stored values), converting expensive dynamic calculations into simple static lookups. The system compresses the stored basis functions using sparse-data encoding, groups operations together to reduce memory traffic and power use, and optimizes the processing pipeline to prevent bottlenecks.

**Key Result:** 150.68K-fold speedup over CPU, 4664x over A6000 GPU; 11196x energy efficiency gain.

**Hardware Target:** ASIC, CIM  
**Workloads:** LLM-inference, transformer  
**Confidence:** low (abstract-only)
