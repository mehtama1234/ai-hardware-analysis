# Protecting Cyber-Physical Systems via Vendor-Constrained Security Auditing with Reinforcement Learning

**Venue**: DATE  
**Primary Theme**: RL-based CPS security auditing with vendor constraints  

## Problem
CPS security requires vendor diversity for mutual auditing against hardware Trojans, but multi-vendor integration creates cost and maintenance challenges with insufficient vendor availability.

## Method
The system audits devices to detect when hardware Trojans (malicious circuits hidden in chips) from different vendors coordinate, then removes infected devices from operation. It employs multi-agent reinforcement learning (multiple AI agents learning through trial and error) to automatically decide which vendor should supply each device, optimizing to keep the maximum number of devices running.

## Key Novelty
Using multi-agent reinforcement learning to assign devices to vendors protects cyber-physical systems from hardware Trojans even when only a few vendors are available.

## Contributions
- Vendor-constrained auditing framework for CPS with untrustworthy devices
- Side auditing mechanism for Trojan collusion detection
- Multi-agent RL-based vendor assignment optimization
- 40.95% reduction in vendor requirements with 0.39% infected node increment
