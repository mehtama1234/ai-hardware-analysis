# Oaken: Fast and Efficient LLM Serving with Online-Offline Hybrid KV Cache Quantization

**Venue:** ISCA 2025  
**Confidence:** high (full text)

## Problem
LLM serving with large batch sizes is dual-bottlenecked: HBM provides bandwidth but limited capacity, while high-capacity LPDDR lacks bandwidth. Existing KV cache quantization methods either pay excessive online overhead (O(n log n) topK sorting) or sacrifice accuracy with coarse-grained grouping.

## Motivation
KV cache size scales linearly with both batch size and context length, increasingly dominating device memory, making efficient quantization with minimal runtime overhead essential for throughput and cost-effectiveness.

## Method
Oaken has two stages: offline, it runs about 100 inferences to find data-agnostic breakpoints (thresholds that depend only on the layer, not the input data) in values for each layer. Online during inference, these thresholds partition each token's KV data into three groups: large outliers, small outliers, and normal values. For each group, group-shift quantization subtracts the threshold to narrow the value range, then encodes each value with 4 or 5 bits. Outliers are fused into unused slots of the dense 4-bit matrix using 8 bits total per outlier, and a custom hardware engine with DMA and page-based memory management handles bandwidth-efficient burst access from HBM or LPDDR memory; the system is built on an LPU architecture synthesized in TSMC 28nm.

## Key Novelty
By pre-computing per-layer value thresholds offline, Oaken avoids expensive online sorting and can pack outliers directly into unused slots of the dense 4-bit matrix, reducing storage from 23 to 8 bits per outlier.

## Contributions
1. Online-offline hybrid KV quantization avoiding O(n log n) sort via offline-profiled thresholds
2. Group-shift algorithm narrowing outlier value ranges for low-bitwidth uniform quantization
3. Fused dense-and-sparse encoding embedding outlier bits in zeroed dense matrix slots
4. DMA-integrated quantization engines + page-based MMU with 8.21% area overhead and 1.58x throughput over A100

## Hardware Target
ASIC (LPU-based, TSMC 28nm); NPU-compatible modules

## Key Metrics
- Throughput: 1.79x over vLLM (FP16 GPU), 1.58x over QServe at batch size 256
- Accuracy loss: 0.54% average vs. SOTA KV quantization baselines
- Bitwidth reduction: up to 70% on KV cache
- Area overhead: 8.21% for Oaken modules

## Baselines
NVIDIA A100 GPU (vLLM), QServe, KVQuant, KIVI, Tender, Atom, LPU

## Limitations
Offline profiling must be repeated per model; fixed group ratios (4%/90%/6%) may be suboptimal for atypical KV distributions.
