# VLSID 2025-042: Programmable Voltage Regulator for Cryo-Cooler Electronics

## Summary
Programmable voltage regulator in 0.18μm HV-CMOS for cryo-cooler electronics. Supports 10-60V input, 5-55V programmable output with 550mA sink current, 0.42mV peak variation, 0.09mm² area.

## Problem
Cryogenic cooling systems (quantum computing, low-temperature physics) require robust voltage regulators across extreme input ranges with high current capability and tight voltage regulation.

## Method
- Novel programmable voltage regulator topology
- HV-CMOS implementation (0.18μm)
- Low-side supply for HV gate driver circuits
- Monte Carlo analysis for robustness validation

## Key Results
- **Input range: 10V to 60V**
- **Output range: 5V to 55V (programmable)**
- **Sink current: 550mA**
- **Peak voltage variation: 0.42mV during current pulses**
- **Quiescent current: 124.7μA**
- **Line regulation: 0.45mV/V**
- **Load regulation: 1.52mV/mA**
- **Die area: 0.09mm²**
- **Monte Carlo validated** across process/temperature

## Applications
- Quantum computing control electronics
- Cryo-cooler systems
- HV gate driver supplies
- Extreme-environment electronics
- Scientific instrumentation

## Limitations
- Specific to cryo-cooler application; general-purpose applicability unclear
- Pre- and post-layout simulations only (no silicon results)
- Single design point validated
- Comparison with other HV regulators not provided
- Temperature range not specified

## Hardware Targets

- Quantum processor support electronics
- Specialized scientific systems
