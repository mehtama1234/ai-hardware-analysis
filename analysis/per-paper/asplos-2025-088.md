# asplos-2025-088 — ReSBM: Region-based Scale and Minimal-Level Bootstrapping Management for FHE via Min-Cut

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** Min-cut-based bootstrapping minimization for FHE encrypted inference

## Problem
In RNS-CKKS fully homomorphic encryption, repeated homomorphic multiplications escalate ciphertext scale and consume multiplicative levels, requiring expensive bootstrapping to restore capacity; existing compile-time approaches do not efficiently minimize the number and placement of bootstrapping operations, leading to excess overhead in encrypted ML inference.

## Motivation
FHE-based privacy-preserving ML is bottlenecked by bootstrapping cost, which dominates latency; minimizing bootstrapping insertions at compile time is essential for practical encrypted inference.

## Method
The approach uses a min-cut algorithm—a graph technique for finding the minimum number of 'cuts' needed to divide a network into parts—to determine where bootstrapping (the expensive recovery step for encrypted data) needs to be placed in a computation. It divides the computation into regions, each kept within multiplicative level limits (the maximum number of times encrypted values can be multiplied together). At compile time, the min-cut method mathematically proves it has found the smallest possible number of bootstrapping operations, while assigning scales (sizes) to the encrypted values within each region to prevent overflow.

## Key Novelty
The core innovation is to formulate where to place bootstrap operations as a min-cut optimization problem on the computation graph, which mathematically guarantees finding the minimal set needed at compile time.

## Contributions
- Region-based scale management that tracks and bounds multiplicative level consumption across computation regions
- Min-cut-based algorithm for finding minimal bootstrapping insertion points in FHE computation graphs
- Compile-time framework (ReSBM) for rapid encrypted inference with reduced bootstrapping overhead
- Demonstrated improvements in FHE-based ML inference latency
