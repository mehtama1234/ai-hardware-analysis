# MAHL: Multi-Agent LLM-Guided Hierarchical Chiplet Design with Adaptive Debugging

**Venue:** ICCAD  
**ID:** iccad-2025-198

## Problem
LLM-driven chiplet design faces high dimensionality (cores, arrays, memory hierarchies), flattened designs, expensive validation, and imprecise parameter optimization.

## Motivation


## Method
Multi-agent hierarchical LLM framework with six specialized agents for hierarchical description, retrieval-augmented code generation, diverse validation, and multi-granularity design space exploration.

## Key Novelty
First hierarchical LLM-based framework with multi-agent collaboration for 2.5D chiplet design generation.

## Contributions
- Multi-agent collaborative chiplet design generation framework
- Hierarchical HDL generation and validation
- Design space exploration for PPA optimization
- Pass@5 accuracy improved from 0 to 0.72 on real chiplet designs
