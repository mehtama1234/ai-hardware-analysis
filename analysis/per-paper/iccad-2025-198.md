# MAHL: Multi-Agent LLM-Guided Hierarchical Chiplet Design with Adaptive Debugging

**Venue:** ICCAD  
**ID:** iccad-2025-198

## Problem
LLM-driven chiplet design faces high dimensionality (cores, arrays, memory hierarchies), flattened designs, expensive validation, and imprecise parameter optimization.

## Motivation


## Method
The system coordinates six specialized AI agents in a hierarchy—higher-level agents guide lower-level ones. They split the work: some describe designs at multiple detail levels, others generate code by learning from working examples (retrieval-augmented generation), others validate whether designs would actually function, and others explore different possible configurations to find better solutions.

## Key Novelty
This is the first system using multiple AI agents organized hierarchically to automatically generate 2.5D chiplet designs (architectures where smaller chips are arranged horizontally on a shared layer).

## Contributions
- Multi-agent collaborative chiplet design generation framework
- Hierarchical HDL generation and validation
- Design space exploration for PPA optimization
- Pass@5 accuracy improved from 0 to 0.72 on real chiplet designs
