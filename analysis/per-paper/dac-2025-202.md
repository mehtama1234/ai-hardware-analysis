# All-in-Memory Stochastic Computing using ReRAM

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
Stochastic computing bit-stream generators consume 80% of system power and area; data movement between memory and processor is the dominant bottleneck.

## Method
Moves entire SC flow into **ReRAM**: (1) in-place random bit-stream generation using ReRAM variability, (2) SC operations in ReRAM crossbar, (3) in-place binary conversion. Leverages ReRAM's fault tolerance to complement SC robustness.

## Key Novelty
In-place stochastic computing entirely within ReRAM eliminates external data movement and uses ReRAM variability as randomness source.

## Results
- **1.39-2.16× throughput improvement** vs CMOS/ReRAM SC
- **1.15-2.8× energy reduction** vs alternatives
- **5% average image quality drop**
