# Diff-DiT: Temporal Differential Accelerator for Low-bit Diffusion Transformers on FPGA

**Venue:** ICCAD  
**ID:** iccad-2025-199

## Problem
Diffusion Transformer inference has high computational cost and requires substantial memory for attention layers, limiting deployment on edge platforms like FPGAs.

## Motivation


## Method
The accelerator runs on an FPGA (a reprogrammable circuit chip) and uses approximated differential attention: instead of fully recomputing attention for each diffusion step, it computes only what's changed. The system ranks which computations matter most using significance scoring, then routes data through the hardware with optimized access patterns to prevent bottlenecks. By splitting the computation workflow based on partial conditioning information, it can use low-bit quantization (representing numbers with fewer bits, like 8-bit integers instead of 32-bit floats).

## Key Novelty
This is the first FPGA accelerator that applies temporal differential computation—where each diffusion step only computes what's changed from the previous step—to enable low-bit Diffusion Transformer inference.

## Contributions
- Approximated differential attention method for low-bit execution
- Optimal cross-cast data accessing pattern with flexible reuse
- Half-condition splitting and fine-grained pipelining
- 1.39x throughput and 5.60x energy efficiency vs V100 GPU
