# CIMWise: An IREE-based End-To-End AI Compiler with Auto-Tuning for CIM Processors

**Venue:** ICCAD
**ID:** iccad-2025-139
**Confidence:** low

## Problem
Existing CIM compilers focus on hardware parameters while neglecting diverse dataflow patterns across different CIM architectures, limiting optimization for specific workloads.

## Motivation
An architecture-aware compiler for computing-in-memory processors can better exploit hardware capabilities and improve DNN inference efficiency.

## Method
CIMWise is an AI compiler built on IREE that automatically finds the best way to run AI models on CIM (computing-in-memory) processors. It improves on existing CIM compilers by tuning both hardware settings (like memory and timing) and dataflow patterns (how data moves through the computation), because a workload's performance depends on how these factors interact. The compiler searches this space systematically using a two-stage simulated annealing algorithm—a technique that gradually explores and refines possibilities—with an adaptable on-chip memory model and operator-level optimizations to fine-tune each part of the model.

## Key Novelty
CIMWise auto-tunes both hardware parameters and dataflow characteristics to find optimal scheduling strategies for CIM processors.

## Contributions
- General IREE-based compiler for diverse CIM processor architectures
- Auto-tuning framework with comprehensive search space and analytical cost model
- Two-stage simulated annealing search for optimal scheduling
- 58% energy reduction and 19% latency decrease vs. prior CIM compilers
