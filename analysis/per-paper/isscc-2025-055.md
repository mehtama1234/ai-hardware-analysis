# isscc-2025-055: MEGA.mini Heterogeneous Generative AI NPU

**Title:** MEGA.mini: A Universal Generative AI Processor with a New Big/Little Core Architecture for NPU

**Venue:** ISSCC

**Core Problem:**
Generative AI workloads span non-diffusion models (NDMs: VAEs, GANs, transformers) and diffusion models (DMs requiring 25–100x more iterations); single-architecture NPUs cannot efficiently handle both.

**Method:**
Big/little heterogeneous core architecture: big cores optimize for compute-dense NDM inference, little cores accelerate diffusion iterative steps.

**Key Innovation:**
Heterogeneous big/little NPU architecture addressing computational asymmetry between NDMs and diffusion models.

**Metrics:**
- **Unified Coverage:** NDMs (VAEs, GANs, transformers) + diffusion models
- **Workload Diversity:** Handles 25–100x operation variance

**Architecture:** Heterogeneous big/little NPU cores

**Techniques:** Dataflow, heterogeneous computing, scheduling

**Confidence:** Low (abstract-only)
