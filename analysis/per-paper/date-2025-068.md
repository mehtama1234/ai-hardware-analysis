# ${MC}{3}$: Memory Contention-Based Covert Channel Communication on Shared DRAM System-on-Chips

**Venue**: DATE  
**Primary Theme**: memory contention covert channels  

## Problem
Exploiting memory contention in shared DRAM SoCs without last-level cache for high-throughput covert communication. Prior attacks required LLC or privileged/physical access; mobile SoCs lack LLC, creating unexploited vulnerability.

## Method
The MC³ attack sends hidden messages by creating contention in shared DRAM—one program deliberately slows down memory access for another program's memory requests. The attacker varies (modulates) the stress intensity to encode signals, and the receiving program decodes them by measuring how much slower its memory access becomes. This approach works on mobile system-on-chips (SoCs) without a last-level cache (LLC), where previous covert attacks couldn't operate. The technique trades speed of communication against risk of detection—more intense patterns are faster but easier for security monitoring to catch.

## Key Novelty
Fast secret communication through shared memory strain (DRAM contention) alone, without the last-level cache, special system access, or irradiation that previous attacks needed.

## Contributions
- Novel memory-contention-based covert channel on shared DRAM
- Achieved 6.4 Kbps transmission rate with <1% error on NVIDIA Orin platforms
- Demonstrated feasibility without LLC or elevated system privileges
