# asplos-2025-176: Controlled Preemption: Amplifying Side-Channel Attacks from Userspace

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Many microarchitectural side-channel attacks are hampered by low temporal resolution measurements, which preclude or complicate sensitive information extraction. Userspace attackers lack a mechanism to synchronize observations with victim activity at fine-grained time resolution.

## Motivation
Microarchitectural side channels remain a persistent threat, but attack effectiveness is fundamentally limited by coarse measurement granularity caused by unpredictable OS scheduling.

## Method
The attacker uses an unprivileged mechanism to control exactly when the operating system pauses their program and runs the victim program (called preemption). By timing these pauses precisely, the attacker can measure the victim's CPU behavior—specifically patterns in cache access and memory use. This synchronized, finely-timed measurement greatly amplifies side-channel attacks (techniques that steal secrets by observing CPU timing and resource patterns) without requiring special privileges or custom hardware.

## Key Novelty
A mechanism allowing unprivileged users to control precisely when the operating system pauses programs, which amplifies attacks that steal secrets through observing CPU behavior patterns.

## Contributions
- Controlled preemption technique enabling userspace synchronization of side-channel measurements with victim execution
- Demonstration that low-temporal-resolution attacks can be significantly amplified using this technique
- Analysis of security implications of OS scheduling mechanisms exploitable from userspace
