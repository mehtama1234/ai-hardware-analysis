# SC-2025-244: SENSE - Intent-Based Networking for Exascale Workflows

**Transforming the Network into a First-Class Schedulable Resource**

## Summary
SENSE (Software-Defined Network for End-to-end Networked Science at the Exascale) is an intent-based networking framework enabling deterministic, priority-aware network services for scientific workflows spanning multiple administrative domains. This paper demonstrates SENSE in practice on a comprehensive multi-domain testbed including production LHC infrastructure.

## Problem
Modern scientific workflows increasingly require coordinated execution across multiple institutions and administrative domains. Current challenges:
1. **Best-Effort Limitations**: Traditional networks provide only best-effort delivery, leading to unpredictable data movement performance
2. **Priority Blindness**: No distinction between critical and less-urgent data transfers
3. **Multi-Domain Complexity**: Orchestrating resources across institutional boundaries requires manual coordination
4. **Data Movement Inefficiency**: Lack of deterministic guarantees forces over-provisioning or acceptance of performance uncertainty

## Approach
SENSE implements intent-based networking through:

### 1. Intent Translation
- Users express high-level requirements (e.g., "move 100 TB dataset with 10Gbps guarantee")
- Intent-based orchestration translates to concrete network configurations
- Automatic provisioning across multiple SDN domains

### 2. Multi-Domain Orchestration
- Coordinates network resources across GNA-G AutoGOLE, NRP, FABRIC, and production CMS
- Manages cross-domain bandwidth reservations
- Ensures end-to-end performance contracts

### 3. Priority-Aware Scheduling
- Allocates bandwidth proportionally to workflow priority
- Higher-priority scientific data flows receive preferential treatment
- Dramatically faster completion times vs best-effort

## Key Contributions
1. **First Practical Multi-Domain Evaluation**: Demonstrates intent-based bandwidth reservation at scale
2. **Quantified Provisioning Performance**:
   - Simple services: 183 seconds provisioning
   - Complex multi-domain workflows: 290 seconds
3. **Bandwidth Guarantee Validation**: SENSE maintains committed bandwidth allocations throughout workflow
4. **Dramatic Performance Delta**: Priority flows complete "significantly faster" than best-effort equivalents (specific metrics in full paper)
5. **Network-as-a-Resource**: Establishes network as first-class schedulable resource (alongside compute, storage)

## Scientific Impact
SENSE addresses a critical bottleneck in exascale science: **data movement**. By enabling:
1. **Deterministic Performance**: Scientific workflows can be planned with guaranteed network performance
2. **Priority-aware Execution**: Critical experiments get network priority over routine analysis
3. **Multi-institutional Collaboration**: Seamless resource sharing across traditional administrative boundaries
4. **Predictable Science**: Results depend less on network congestion luck

## Implementation Considerations

## Broader Implications
This work challenges the assumption that networks are best-effort services. For exascale science, the network becomes:
- An optimization target (like computational algorithms)
- A schedulable resource (managed by workflow orchestrators)
- A predictor of scientific outcome (data movement delays affect results)
