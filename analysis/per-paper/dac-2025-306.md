# Property-driven Parallel Symbolic Model Checking of LTL

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

Proposes first parallel symbolic model checking approach for full LTL (including fairness constraints) by partitioning nested fixpoint calculations across product automata. Achieves 2.81-17.19x speedup on 32-core machine and 33.1% average improvement over SOTA BDD-based methods.

## Key Contributions

- **Fair State Labeling**: Novel partitioning function for nested fixpoint across model-property automaton product
- **Full LTL Support**: Handles liveness properties and fairness, not just safety/reachability
- **Significant Speedups**: 2.81-17.19x scaling on 32 cores, 33.1% average vs. SOTA, up to 134% improvement
- **Parallel Fixpoint**: First practical parallelization of nested fixpoint calculations in symbolic model checking

## Technical Focus

Addresses parallelization of nested fixpoint iterations inherent to LTL model checking. Uses fairness-aware state labeling to partition the state space across processors without loss of correctness.

## Relevance

**Keywords:** model-checking, ltl-verification, parallel-algorithms, symbolic-methods, fairness
