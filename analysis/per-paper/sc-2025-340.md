# IzhiRISC-V: RISC-V Processor with Custom ISA for Spiking Neural Networks

**ID:** sc-2025-340  
**Venue:** SC 2025  
**Authors:** Wiktor Jan Szczerek, Artur Podobas

## Problem & Motivation

**Spiking Neural Networks (SNNs)** promise energy efficiency from sparse spike events, but when run on general-purpose hardware (including RISC-V), this advantage is **nullified by inefficient instruction sequences** for neuron state updates.

Each neuron update requires multiple basic arithmetic instructions, eliminating the energy gains from sparsity.

## Solution: IzhiRISC-V

A RISC-V-compliant processor with:
- **Custom neuromorphic ISA extension** featuring dedicated instructions for Izhikevich neuron updates
- **Hardware expansion** to existing ALU (not a separate co-processor)
- **Seamless integration** with standard RISC-V instruction set

## Izhikevich Model

The Izhikevich neuron is a reduced-complexity spiking model:
- Captures spike dynamics with minimal computation
- Fewer operations than Hodgkin-Huxley models
- Ideal for hardware acceleration

## Architecture

- Standard RISC-V pipeline with custom neuromorphic instructions
- Bespoke ALU extensions for neuron state computation
- First-step toward large-scale SNN systems (future: multi-processor systems)

## Implications

Enables practical deployment of energy-efficient spiking neural networks via specialized instruction support, without requiring radical processor redesigns.
