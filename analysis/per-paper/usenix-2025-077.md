# Voltrix: Sparse Matrix-Matrix Multiplication on Tensor Cores with Asynchronous and Balanced Kernel Optimization

**Problem:** Sparse matrix-matrix multiplication is inefficient on Tensor Cores because they are optimized for dense operations, resulting in load imbalance and irregular memory access patterns that severely underutilize the hardware. Exploiting Tensor Cores for sparse workloads requires novel kernel designs to handle sparsity-induced irregularity.

**Method:** Voltrix lets different processing tasks run independently without waiting for each other, eliminating the delay that normally happens when all tasks must pause together. To handle the irregular patterns in sparse matrices—where some parts have many zeros and others have fewer—it automatically rebalances work across processing elements to keep all of them busy. The whole system is designed around how Tensor Cores specifically access memory and perform calculations.

**Novelty:** The core idea is using independent, non-blocking task execution paired with dynamic workload rebalancing so that Tensor Cores can efficiently handle sparse matrix multiplication even though the irregular sparsity patterns would normally underutilize them.
