# Voltrix: Sparse Matrix-Matrix Multiplication on Tensor Cores with Asynchronous and Balanced Kernel Optimization

**Problem:** Sparse matrix-matrix multiplication is inefficient on Tensor Cores because they are optimized for dense operations, resulting in load imbalance and irregular memory access patterns that severely underutilize the hardware. Exploiting Tensor Cores for sparse workloads requires novel kernel designs to handle sparsity-induced irregularity.

**Method:** Voltrix employs asynchronous kernel execution to enable independent, non-blocking processing of sparse tiles with varying sparsity patterns, eliminating global synchronization overhead. A dynamic load balancing strategy distributes irregular workloads across processing elements to maximize hardware utilization. The approach is specifically optimized for Tensor Core architecture constraints and memory access characteristics.

**Novelty:** Combining asynchronous kernel execution with dynamic load balancing to efficiently map irregular sparse workloads onto Tensor Cores.
