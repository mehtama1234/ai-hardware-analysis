# MeshSlice: Efficient 2D Tensor Parallelism for Distributed DNN Training
**Venue:** ISCA | **Confidence:** low (abstract-only)

## Problem
One-dimensional tensor parallelism (1D TP) for large DNN training scales poorly because all-reduce communication cost grows linearly with the number of devices. Existing 2D TP algorithms for general matrix multiplication (GeMM) have fundamental inefficiencies: Cannon's algorithm generates high traffic, SUMMA suffers from synchronization overhead, and 2D GeMM with standard collective communication operations cannot overlap communication with computation.

## Motivation
Training frontier LLMs requires hundreds to thousands of accelerators, and tensor parallelism communication overhead at scale is a dominant bottleneck — 2D tensor parallelism can reduce collective communication traffic quadratically versus 1D, but existing 2D GeMM algorithms waste this opportunity through avoidable synchronization and communication-compute serialization.

## Method
MeshSlice introduces a new 2D GeMM algorithm that decomposes collective communication operations into multiple smaller partial collectives, each of which can be issued and overlapped with ongoing matrix-multiply computation on the local shard. The algorithm maps the 2D device mesh such that partial all-reduces along one mesh dimension are issued while the other dimension is computing, hiding most communication latency behind arithmetic. An analytical autotuner searches over 2D mesh shape (rows x columns), GeMM dataflow configuration, and communication granularity (number of slices) to find the Pareto-optimal configuration for each LLM layer and cluster size, targeting TPUv4 hardware with its torus interconnect.

## Key Novelty
Slicing collective communications into multiple partial collectives that are interleaved with computation, enabling near-complete hiding of 2D tensor parallelism communication latency in distributed LLM training.

## Contributions
- MeshSlice 2D GeMM algorithm that decomposes collectives into partial operations to overlap communication with computation
- Analytical LLM autotuner that automatically finds optimal mesh shape, dataflow, and communication granularity for each model and cluster configuration
- Demonstration of good 2D TP efficiency up to at least 256-way parallelism on TPUv4 clusters
- 12.0% faster GPT-3 training and 23.4% faster Megatron-NLG training on 256 TPUs versus state-of-the-art 2D TP algorithms

## Hardware Target
TPU

## Metrics
- Speedup: 12.0% faster than SOTA for GPT-3 on 256 TPUs; 23.4% faster for Megatron-NLG on 256 TPUs

## Baselines
- State-of-the-art 2D TP algorithms (Cannon, SUMMA, collective-based 2D GeMM)

## Limitations
Evaluation is simulation-based on TPUv4 clusters; real hardware measurements and cross-platform (GPU cluster) validation are not reported.
