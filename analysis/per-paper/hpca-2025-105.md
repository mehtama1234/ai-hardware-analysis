# hpca-2025-105 — Hydra: Scale-out FHE Accelerator Architecture for Secure Deep Learning on FPGA

**Venue:** HPCA  
**Authors:** Yinghao Yang, Xicheng Xu, Haibin Zhang, Jie Song, Xin Tang, Hang Lu, Xiaowei Li  
**Confidence:** low (abstract only)

## Problem
Existing FHE accelerators for deep learning focus on single-node throughput via stacked compute clusters, cannot exploit application-level model parallelism, and are not scalable beyond a single card for large models.

## Motivation
Privacy-preserving DL inference under FHE is computationally intensive (ciphertext convolution, matmul, bootstrapping), and single-node FPGA designs hit a performance ceiling that multi-node scale-out can overcome.

## Method
Hydra partitions CNN and LLM layers across multiple FPGA-based server nodes, each handling a portion of the model, governed by a central host scheduler. The architecture supports theoretically arbitrary numbers of compute nodes, enabling pipeline parallelism at the model level alongside intra-node parallelism, with the host managing data routing and synchronization.

## Key Novelty
A scale-out multi-FPGA architecture for FHE-based DL inference exploiting application-level model parallelism rather than simply stacking parallelized single-card designs.

## Contributions
- Scale-out FHE acceleration supporting arbitrary numbers of FPGA nodes with central scheduling
- 74x and 160x speedup over single-card SOTA (Poseidon, FAB)
- 12-21x speedup over 8-card FAB-2 for FHE CNNs and LLMs
- 8.1x and 2.5x speedup over ASIC accelerators CraterLake and SHARP for LLM OPT-6.7B

## Metrics
- **Speedup:** 74x/160x over Poseidon/FAB; 12-21x over 8-card FAB-2; 8.1x/2.5x over CraterLake/SHARP
- **Energy:** comparable or superior to ASIC accelerators at same chip technology
