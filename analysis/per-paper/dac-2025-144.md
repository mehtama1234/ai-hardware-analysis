# GS-TG: 3D Gaussian Splatting Accelerator with Tile Grouping

## Problem
3D Gaussian Splatting rendering faces a fundamental trade-off: large tile sizes reduce redundant sorting but increase unnecessary rasterization computations, limiting real-time performance in novel view synthesis.

## Method
GS-TG groups small rectangular image tiles together during sorting—the phase that arranges which pixels to compute—to reduce redundant work, then uses binary flags during rendering (converting the scene to pixels) to identify which tiles actually need processing. This hybrid approach combines the efficiency of handling large regions together during sorting with the efficiency of computing only necessary regions during rendering, without requiring model retraining.

## Key Results
- 1.54x speedup over SOTA 3D-GS accelerators
- Lossless method (no retraining or fine-tuning required)
- Compatible with previous 3D-GS optimization techniques
