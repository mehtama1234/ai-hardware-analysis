# isscc-2025-057: 38GHz RF-Sampling ADC for mm-Wave Satellite Comms

**Title:** A 12.8GS/s Sub-Sampling ADC Front-End With 38GHz Input Bandwidth and >39dB SNDR for 1 to 32GHz in 22nm FDSOI

**Venue:** ISSCC

**Core Problem:**
RF-sampling for mm-wave Earth-to-Satellite (27–31GHz) requires wide RF bandwidth, high fidelity, and multi-channel flexibility; single-rate Nyquist sampling is data-rate inefficient.

**Method:**
12.8GS/s sub-sampling ADC front-end with optimized aperture and anti-aliasing filtering achieves 38GHz input bandwidth, 6.4GHz Nyquist bandwidth for multi-channel selection, maintains >39dB SNDR via FDSOI advantages.

**Key Innovation:**
38GHz input bandwidth sub-sampling front-end with flexible multi-channel Nyquist reception.

**Metrics:**
- **Sampling Rate:** 12.8 GS/s
- **Input Bandwidth:** 38 GHz
- **Nyquist Bandwidth:** 6.4 GHz (flexible channel selection)
- **SNDR:** >39 dB (1–32 GHz)
- **Process:** 22 nm FDSOI

**Architecture:** Sub-sampling ADC front-end with wide RF input stage

**Techniques:** RF circuit design, analog design

**Confidence:** Low (abstract-only)
