# Investigating Impact of Bit-flip Errors in Control Electronics on Quantum Computation

**Venue:** VLSID

## Problem
Bit-flip errors in FPGA control electronics (quantum pulse memory) degrade quantum gate fidelity

## Motivation
FPGA controls quantum systems; environmental stresses cause bit flips; need robust representation for quantum gates

## Method
The researchers tested how quantum pulses—the electromagnetic signals that control quantum gates—resist bit-flip errors (random bit changes in memory) when represented using two different number formats. They compared floating-point representation, which uses scientific notation, against fixed-point representation, where the decimal point is always in the same position. Using IBM quantum simulators, they measured which format better preserved the accuracy of the control signals when bit-flips occurred in the FPGA memory.

## Key Novelty
Fixed-point representation—where the decimal point is always in the same place—resists bit-flip errors (random bit changes in memory) better than floating-point representation (scientific notation) when storing quantum control signals.
