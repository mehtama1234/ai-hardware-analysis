# A 14-nm Energy-Efficient and Reconfigurable Analog Current-Domain In-Memory Compute SRAM Accelerator

**Venue:** VLSID
**Authors:** Aya G. Amer, Maitreyi Ashok, Xin Zhang 0025, John Cohn, Anantha P. Chandrakasan

## Problem Statement
This work presents a low-power reconfigurable 12T-SRAM current-domain analog in-memory computing (IMC) SRAM macro design to address non-linearities, process variations, and limited throughput

## Method
The accelerator performs computations directly inside SRAM memory cells using analog electrical currents rather than digital signals. Instead of using voltage levels to encode data, it uses time-domain encoding—information is represented by how long or short electrical pulses last—allowing transistors to operate in the subthreshold regime (at voltages below where they would normally switch on, which dramatically reduces power consumption). Each computation cycle executes a multiply-and-accumulate operation (multiplying values and adding results to a running sum) by controlling these analog currents. The outcome is determined using differential current sensing, which compares currents flowing in opposite directions to produce the final result.
