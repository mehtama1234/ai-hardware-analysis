# CXLfork: Fast Remote Fork over CXL Fabrics

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** CXL-enabled zero-copy remote process cloning for serverless scale-out

## Problem
Remote process cloning across cluster nodes incurs high serialization and copying overhead, creating large cold-start latency for serverless functions and other scale-out workloads. Traditional fork() semantics do not map efficiently to distributed shared memory environments like CXL-attached memory.

## Motivation
CXL interconnects enable globally-shared memory pools across nodes, and exploiting this for process cloning can eliminate cold-start bottlenecks in serverless computing without the overhead of network-based state transfer.

## Method
CXLfork implements a remote fork interface (a way to copy a running process to a different computer in a cluster) using CXL-attached shared memory—specialized memory physically connected to multiple machines that can all access it directly. Instead of copying the process's pages and metadata over the network, it stores everything in this globally-shared CXL memory, so if multiple processes need the same data, it only exists once instead of being duplicated. The system smartly splits storage between fast local DRAM and the slower shared CXL memory: pages that are frequently used stay in local DRAM for speed, while pages that are rarely used or shared across processes live in CXL memory. CXL-porter builds on this to efficiently scale serverless functions (small on-demand tasks) by spawning multiple copies of a function across cluster nodes without the network copying overhead.

## Key Novelty
Using CXL-attached globally-shared memory for cluster-wide deduplication of process state, so remote process cloning runs nearly as fast as local cloning.

## Contributions
- CXLfork: a remote fork interface achieving close to zero-serialization, zero-copy process cloning over CXL fabrics
- Cluster-wide process-state deduplication using CXL shared memory
- Fine-grained state tiering between local DRAM and CXL memory
- CXL-porter: an efficient horizontal autoscaler for serverless functions built on CXLfork
