# dac-2025-244: FF-INT8: Efficient Forward-Forward DNN Training on Edge Devices with INT8 Precision

## Summary
Combines INT8 quantization with Forward-Forward algorithm for efficient edge training, achieving 4.6% speedup, 8.3% energy savings, and 27% memory reduction on Jetson Orin Nano while maintaining competitive accuracy via look-ahead refinement.

## Key Idea
Exploit FF's layer-by-layer structure to stabilize INT8 gradient quantization for practical edge device training.

## Contributions
- 4.6% faster training (Jetson Orin Nano)
- 8.3% energy savings
- 27% memory reduction
- Look-ahead scheme for accuracy recovery

## Limitations
Limited to Jetson Orin Nano; other edge accelerators not tested.
