# Postiz: Extending Post-increment Addressing for Loop Optimization and Code Size Reduction

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Memory auto-addressing modes in ISAs are underutilized by compilers. Existing methods focus narrowly on code size or neglect post-increment instructions and outer loops. ML workloads benefit from post-increment optimization.

## Technical Approach
Extends post-increment optimization to inner loops, cross-loop regions, and nested structures. Profitability analysis judiciously applies optimizations, balancing architectural benefits. Implemented in LLVM for multiple ISA targets.

## Key Novelty
First systematic approach to exploit post-increment instructions across full loop hierarchies.

## Key Results
- 98.04% optimization coverage on MobileNet and BERT
- 4× more post-increment instructions than default LLVM
- 9.45% average code size reduction across platforms

- **Techniques:** Compiler optimization, loop scheduling, code size reduction
