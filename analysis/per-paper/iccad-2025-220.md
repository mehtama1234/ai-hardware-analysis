# SCArmor: Layer-Bit Joint Hardening with a Fast Genetic Optimization for Cost-Efficient and High-Reliable SC-DCNN Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-220  
**Confidence:** low

## Problem Statement
Stochastic Computing-based Deep CNNs face radiation-induced errors affecting reliability in harsh environments.

## Motivation
Cost-efficient radiation hardening for SC-DCNN circuits enables deployment in reliability-critical applications.

## Method
Stochastic computing represents numbers using random bit streams, which is naturally resistant to radiation but vulnerable to bit errors. SCArmor uses a genetic algorithm (an optimization technique that tests many candidate solutions mimicking natural selection) to jointly determine which neural network layers to protect from errors and what bit-width (number of bits per value) to assign to each layer. This combined optimization reduces the circuit's total area, power consumption, and processing time by hardening only the layers that matter most.

## Key Novelty
This is the first genetic algorithm-based approach to jointly choose which layers of a stochastic-computing neural network to harden against radiation and what bit-width to use in each layer.

## Contributions

1. Genetic algorithm for layer-bit selection
2. Joint hardening optimization for SC-DNN
3. 22-43% reduction in area/power/latency
