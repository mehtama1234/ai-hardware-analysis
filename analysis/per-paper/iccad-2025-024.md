# CLASS: A Controller-Centric Layout Synthesizer for Dynamic Quantum Circuits

**Venue:** ICCAD  
**ID:** iccad-2025-024

## Problem
Traditional quantum layout synthesis focuses on circuit depth optimization; ignores classical controller communication time, critical for Dynamic Quantum Circuits with runtime measurements and conditional operations.

## Motivation
Dynamic quantum circuits require controller-to-controller communication optimization beyond traditional device-centric depth minimization.

## Method
The method models the quantum control system as a hypergraph—a graph where edges can connect multiple nodes at once—representing both the quantum circuit and the controllers issuing commands to it. It uses a heuristic algorithm (a practical, rule-of-thumb approach) to partition this graph into groups, placing controllers that command the same circuit parts nearby to minimize the distance signals must travel between them. This reduces communication latency—the delay between when one controller sends a signal and another receives it—cutting the time overhead from controller coordination.

## Key Novelty
It's the first layout synthesizer to prioritize reducing communication delays between multiple controllers in a distributed quantum system, rather than focusing only on circuit execution depth.

## Contributions
- Controller-centric design methodology for DQC layout
- Hypergraph-based modeling of distributed control systems
- Heuristic-based graph partitioning algorithm
- Up to 100% communication latency reduction with only 2.10% avg operation increase
