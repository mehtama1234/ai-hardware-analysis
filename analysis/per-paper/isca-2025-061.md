# isca-2025-061 — AiF: Accelerating On-Device LLM Inference Using In-Flash Processing

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
On-device LLM inference with SSD offloading is severely bottlenecked by the limited external read bandwidth of flash storage (NAND-to-host path), making inference latency unacceptably high even though LLM weight matrices fit in flash capacity. Existing SSD offloading engines are bound by PCIe/interface bandwidth rather than the high internal NAND bandwidth.

## Motivation
Edge and personal devices lack sufficient DRAM to hold large LLM weights, and SSD offloading is the only capacity solution, but NAND internal bandwidth (hundreds of GB/s aggregate across planes) vastly exceeds the external interface bandwidth (~7 GB/s), creating a large exploitable gap if computation can be pushed inside the flash chip.

## Method
AiF solves the data bottleneck in on-device AI inference by putting matrix multiplication compute hardware directly inside flash chips, so calculations happen where the data lives instead of shuttling data through the slow external PCIe connection. It introduces specialized flash read techniques designed for how LLM weights are arranged in memory and streamlines the error-correction process (which normally slows reads) to achieve 4x faster internal data movement with minimal overhead. This allows in-flash matrix operations to run at nearly full speed on the flash chip's internal pathways.

## Key Novelty
AiF embeds matrix multiplication compute directly inside flash chips using flash-read techniques optimized for how LLM weights are stored, achieving a 4x boost to internal data movement speed through a streamlined error-correction scheme.

## Contributions
1. An in-flash processing architecture (AiF) that offloads GEMV operations into flash chips, bypassing external bandwidth limitations.
2. Two novel flash-read techniques optimized for reading LLM weight parameters stored in NAND flash.
3. A streamlined ECC mechanism achieving 4x internal read bandwidth improvement.
4. 14.6x throughput over SSD offloading baseline; 1.4x over in-memory inference across eight real-world LLMs.
