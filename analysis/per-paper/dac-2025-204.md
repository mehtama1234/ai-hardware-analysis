# SSpMV: A Sparsity-aware SpMV Framework Empowered by Multimodal Machine Learning

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
SpMV performance varies widely across sparse matrices and hardware; fixed algorithms in standard libraries fail to adapt to matrix patterns and architecture characteristics.

## Method
SSpMV combines expert-designed matrix measurements with a machine learning model called MM-Adapter that analyzes multiple characteristics of a sparse matrix (its sparsity patterns, density, and structure) to predict the fastest-running algorithm. Rather than using the same algorithm for every matrix, it learns which matrix features correspond to which algorithms, then selects the best algorithm and settings for each specific matrix.

## Key Novelty
It uses machine learning that examines multiple types of information about matrices—expert measurements and patterns learned from data—to automatically pick the best algorithm instead of using one fixed algorithm for all cases.

## Results
- **81.05% prediction accuracy**
- Consistent performance improvements over state-of-the-art sparse libraries
