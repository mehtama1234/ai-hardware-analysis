# CirSTAG: Circuit Stability Analysis on Graph-based Manifolds

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Circuit stability analysis requires expensive simulations to estimate parameter sensitivity. Scalability is a bottleneck for large modern integrated circuits.

## Key Idea
Use GNNs with spectral manifold analysis to compute local Lipschitz constants for circuit elements, detecting mapping distortions that indicate critical sensitivity without simulation.

## Method
CirSTAG uses graph neural networks (AI systems that understand connections between circuit components) to measure circuit stability without running many simulations. It calculates a stability score—the local Lipschitz constant, which measures how much the circuit responds to small input changes—for each component and connection, considering both the network structure and how changing component values affects behavior. When nearby components on the input map to distant components on the output (mapping distortion), this reveals poor stability and identifies the most critical circuit elements.

## Contributions
1. Spectral manifold-based GNN stability analysis framework
2. Scalable robustness assessment without extensive simulation
3. Validated on timing prediction tasks
