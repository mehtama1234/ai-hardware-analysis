# Fast Interpreter-Based Instruction Set Simulation for Virtual Prototypes

**Venue**: DATE  
**Primary Theme**: High-performance instruction set simulator for RISC-V  

## Problem
Interpreter-based instruction set simulators for virtual prototypes have poor performance; optimizations often sacrifice comprehensibility and adaptability.

## Method
The approach uses caching to speed up software simulation of RISC-V processors. When the processor executes the same instruction sequence multiple times (called a basic block), the simulator caches the results so it doesn't have to re-simulate them—it just looks them up instead. Similarly, it caches memory read and write operations, which are normally slow to simulate. These two optimizations are built into a SystemC-based virtual prototype, achieving high performance while keeping the code understandable and modifiable.

## Key Novelty
The core idea is combining instruction-sequence caching (basic blocks) with memory-operation caching to achieve high performance without sacrificing code clarity.

## Contributions
- Dynamic Basic Block Cache for instruction processing acceleration
- Load/Store Cache for memory operation optimization
- Peak performance of 406.97 MIPS
- 8.98× speedup over original VP, 1.65× over Spike simulator
- RISC-V Zfh half-precision extension support
- Open-source release
