# Fast Interpreter-Based Instruction Set Simulation for Virtual Prototypes

**Venue**: DATE  
**Primary Theme**: High-performance instruction set simulator for RISC-V  

## Problem
Interpreter-based instruction set simulators for virtual prototypes have poor performance; optimizations often sacrifice comprehensibility and adaptability.

## Method
Proposes Dynamic Basic Block Cache (DBBCache) to accelerate instruction processing and Load/Store Cache (LSCache) to speed up memory operations in interpreter-based RISC-V ISS; implemented on SystemC-based VP.

## Key Novelty
Combined DBBCache and LSCache optimization achieving high performance while maintaining interpreter comprehensibility and adaptability.

## Contributions
- Dynamic Basic Block Cache for instruction processing acceleration
- Load/Store Cache for memory operation optimization
- Peak performance of 406.97 MIPS
- 8.98× speedup over original VP, 1.65× over Spike simulator
- RISC-V Zfh half-precision extension support
- Open-source release
