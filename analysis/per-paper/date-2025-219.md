# GTN-Cell: Efficient Standard Cell Characterization Using Graph Transformer Network

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Use Graph Transformer Networks (GTN) to learn circuit topology and predict accurate Current Source Model (CSM) waveforms directly, replacing expensive SPICE transistor-level simulations.

## Problem
Advanced nodes require CSM for accurate static timing analysis, but generating CSM libraries demands extensive SPICE simulations—major EDA bottleneck.

## Method
- **Graph representation:** Transistor-level cell structures as graphs
- **Transformer encoder:** Path-related positional encodings capture global node relationships
- **Direct prediction:** GTN outputs CSM waveforms for all timing arcs
- Reduces SPICE simulation count by 70%

## Key Results
- **2.27% average error** on voltage waveforms across cells and arcs
- **70% reduction** in required SPICE simulations
- Library-compatible LUT-based CSM prediction

## Hardware Targets
ASIC

## Technique Category
compiler, circuit-design

## Limitations
Single cell library evaluated; generalization to other process nodes and extreme corners not addressed.
