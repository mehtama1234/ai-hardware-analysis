# micro-2025-072: LEGOSim: A Unified Parallel Simulation Framework for Multi-chiplet Heterogeneous Integration

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Existing simulators (gem5, GPGPU-Sim) cannot efficiently simulate heterogeneous multi-chiplet systems because they lack modular composition of diverse chiplet models and suffer from prohibitive synchronization overhead — per-cycle global synchronization wastes up to 99.9% of simulation time on barriers.

## Motivation
The industry shift to chiplet-based heterogeneous integration (SIMBA, CXL memory, CIM accelerators on interposers) requires accurate and fast performance simulation, but no unified framework supports plugging together diverse chiplet simulators with acceptable speed and accuracy.

## Method
LEGOSim wraps each chiplet simulator as an independent parallel process (simlet) that runs on its own schedule rather than waiting at every cycle. Synchronization is on-demand: each simlet advances through adaptable time windows (time quanta) and only stops to exchange messages when one chiplet actually needs to communicate with another, eliminating expensive global synchronization barriers. A separate simulator handles the network connecting the chiplets, tracking message latency, bandwidth, and routing. Testing on SIMBA (a multi-chiplet neural network accelerator) and a CiM-based accelerator showed simulation errors of 3.79% and 3.94% respectively.

## Key Novelty
The core idea is using on-demand synchronization with adaptive time windows: chiplet simulators advance independently and only pause to exchange messages when cross-chiplet communication actually occurs, eliminating the global synchronization barriers that were consuming up to 99.9% of simulation time.

## Contributions
- LEGOSim framework integrating heterogeneous chiplet simulators as independent parallel simlets with minimal code modification
- On-demand synchronization protocol with adaptive time quanta and non-global fencing
- Integrated Network-on-Interposer (NoI) simulator for accurate inter-chiplet communication modeling
- <4% average simulation error vs. real hardware (SIMBA: 3.79%, CiM accelerator: 3.94%); sync overhead reduced 99.9% vs. per-cycle and 66.1% vs. fixed-quantum
