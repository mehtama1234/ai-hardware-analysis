# SpecMPK: Efficient In-Process Isolation with Speculative and Secure Permission Update Instruction
**Venue:** HPCA 2025 | **ID:** hpca-2025-009 | **Confidence:** low (abstract only)

## Problem
Memory Protection Keys (MPK) enable user-space in-process isolation, but the permission update instruction (WRPKRU) is serialized, imposing significant performance overhead when applications require frequent domain switches.

## Motivation
In-process isolation protects against memory safety vulnerabilities and speculative execution attacks, but serialized MPK permission updates make it impractical for high-frequency domain-switching workloads.

## Method
SpecMPK executes the memory permission update instruction (WRPKRU) speculatively—out-of-order, without waiting for earlier instructions to finish. The processor monitors all memory accesses that follow: if any try to access memory whose permissions were temporarily loosened by the speculative update, the processor blocks them from taking effect. These blocked accesses are allowed to proceed only once the permission update itself is guaranteed to happen (past the point where it could be undone). This prevents attackers from reading protected data through speculative execution while the processor gains speed by overlapping the permission update with useful work.

## Key Novelty
SpecMPK allows the memory permission update instruction (WRPKRU) to execute out-of-order speculatively while preventing speculative access to memory regions whose permissions were temporarily loosened, by blocking such accesses until the update is guaranteed to happen.

## Contributions
1. Analysis identifying WRPKRU serialization as the dominant MPK performance bottleneck
2. Speculative WRPKRU execution with transient-access blocking tied to non-squashable commit point
3. 12.21% average performance improvement for frequent-domain-switch SPEC workloads
4. Security argument preventing speculative execution exploitation of transient permission upgrades

## Metrics
- **Speedup:** 12.21% average performance improvement vs serialized WRPKRU
