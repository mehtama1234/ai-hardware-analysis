# Micro-MAMA: Multi-Agent Reinforcement Learning for Multicore Prefetching

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Independent RL-based prefetchers on each core of a multicore system compete for shared memory bandwidth without coordination, causing each agent to greedily claim excessive bandwidth and converging to sub-optimal system-wide policies. This problem is an instance of the multi-agent credit assignment and non-stationarity challenge in MARL.

## Motivation
As core counts grow and memory bandwidth becomes increasingly shared, bandwidth-unaware per-core prefetchers degrade system throughput and fairness, motivating a coordinated multi-agent approach.

## Method
MAMA divides control into two layers. Each processor core runs a simple decision agent (a multi-armed bandit—it tries different options and learns which works best) to choose how aggressively to prefetch memory into the cache. A central supervisor watches overall bandwidth and sends feedback to each local agent about global load, encouraging them to back off when the system is congested. The supervisor then coordinates these local choices to maximize system-wide speed or fair sharing—avoiding the exponential explosion that would occur if the center had to individually control every core.

## Key Novelty
A central supervisor shows each core's prefetcher how much memory bandwidth the entire system is using, enabling them to coordinate their prefetching instead of each core competing blindly for resources.

## Contributions
- Identification of bandwidth competition as the core MARL failure mode for multicore RL prefetching
- MAMA hierarchical architecture combining distributed local bandit agents with a global supervisor
- 2.1% average throughput improvement and 10.4% fairness improvement over independently operating agents on an 8-core system
- Demonstration that gains increase further in bandwidth-constrained configurations
