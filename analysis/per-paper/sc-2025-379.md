# KAMI: Communication-Avoiding General Matrix Multiplication within a Single GPU

**Venue:** SC
**ID:** sc-2025-379
**Confidence:** low

## Problem

Large-scale GEMM near peak GPU performance, but substantial optimization opportunities remain in small and batched GEMM operations.

## Motivation

Communication-avoiding techniques can improve small/batched GEMM through better memory hierarchy utilization within GPU.

## Method

KAMI reduces data movement during matrix multiplication on GPUs using three communication-avoiding approaches (1D, 2D, and 3D thread block configurations). For each approach, it stores intermediate results in different memory levels—thread registers (ultra-fast, one per core) and shared memory (fast, shared across a block)—and uses specialized tensor cores (hardware built into GPUs for fast matrix math). The framework also supports sparse variants called SpMM and SpGEMM for matrices with many zeros.

## Key Novelty

KAMI is the first to analyze communication-avoiding matrix multiplication at the GPU clock cycle level (counting individual GPU processing steps), providing a unified framework for dense, sparse, batched, and low-rank matrices.

## Contributions

1. Communication-avoiding GEMM algorithms (1D, 2D, 3D variants) for single GPU
2. Clock cycle-level performance analysis for GPUs
3. SpMM and SpGEMM implementations
4. Support across NVIDIA, AMD, Intel GPUs
