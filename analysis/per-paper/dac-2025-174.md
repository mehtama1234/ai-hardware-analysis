# STREAM: Spatiotemporal Similarity-based Efficient Approximate Median with Tunable Granularity

**Problem:** Exact median computation is slow; existing approximate methods don't exploit data characteristics or offer accuracy trade-offs.

**Solution:** Bucket reuse via spatiotemporal similarity with tunable-grain bucketing for application-specific accuracy-latency trade-offs.

**Results:** 47x vs. DDSketch, 71.2x vs. KLL (10.1x average for both); maintains accuracy.

**Theme:** Efficient streaming statistics via data similarity reuse.
