# Lichen: Leveraging Coupled Heterogeneity

**Venue:** VLSID

## Problem
Heterogeneous-ISA CMPs use coarse-grained uniform program phases, missing optimization across multiple heterogeneity dimensions

## Motivation
Heterogeneous architectures promising for energy; ISA heterogeneity emerging; need fine-grained phase scheduling

## Method
Lichen: dynamic morphing between ISA cores and execution modes (in-order/out-of-order); CART ML algorithm predicts optimal phase

## Key Novelty
Fine-grained heterogeneous-ISA scheduling via dynamic morphing with 85.44%/91.35% prediction accuracy

## Contributions
- 15.36% energy savings
- 9.63% EDP reduction
- CART algorithm 85.44%/91.35% accuracy
- Minimal overhead
