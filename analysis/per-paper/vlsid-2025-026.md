# Lichen: Leveraging Coupled Heterogeneity

**Venue:** VLSID

## Problem
Heterogeneous-ISA CMPs use coarse-grained uniform program phases, missing optimization across multiple heterogeneity dimensions

## Motivation
Heterogeneous architectures promising for energy; ISA heterogeneity emerging; need fine-grained phase scheduling

## Method
Lichen watches a program as it runs and dynamically morphs (switches) between different processor cores, each supporting a different instruction set (the language a processor understands), and different execution modes—in-order (executing instructions strictly in sequence) versus out-of-order (reordering instructions for efficiency). Before each switch, a machine learning algorithm called CART predicts which combination will run the next code section fastest based on the program's current behavior. This continuous fine-grained optimization across cores and execution modes replaces older systems that could only switch at coarse program phases, missing many opportunities for improvement.

## Key Novelty
Instead of switching at coarse program phases, Lichen continuously morphs between heterogeneous processor cores and execution modes based on machine learning predictions, achieving 85.44%/91.35% accuracy.
