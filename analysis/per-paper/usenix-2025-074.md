# Turbocharge ANNS on Real Processing-in-Memory by Enabling Fine-Grained Per-PIM-Core Scheduling

**Problem:** Approximate Nearest Neighbor Search (ANNS) workloads suffer from inefficient resource utilization on Processing-in-Memory (PIM) architectures due to coarse-grained scheduling that does not optimize for per-core heterogeneity and memory bandwidth contention.

**Method:** The paper introduces a fine-grained per-PIM-core scheduling mechanism that dynamically distributes ANNS operations across individual PIM cores based on local memory bandwidth availability, computation capacity, and data access patterns. The scheduler adapts to ANNS algorithm characteristics and memory behavior to minimize contention and maximize core utilization.

**Novelty:** Fine-grained per-core scheduling that dynamically optimizes ANNS workload distribution based on individual PIM core capabilities and memory access patterns.
