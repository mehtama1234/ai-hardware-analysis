# Turbocharge ANNS on Real Processing-in-Memory by Enabling Fine-Grained Per-PIM-Core Scheduling

**Problem:** Approximate Nearest Neighbor Search (ANNS) workloads suffer from inefficient resource utilization on Processing-in-Memory (PIM) architectures due to coarse-grained scheduling that does not optimize for per-core heterogeneity and memory bandwidth contention.

**Method:** Instead of assigning work to groups of cores, the scheduler gives tasks to individual PIM cores based on each one's available memory bandwidth (how fast data flows in and out) and computing capacity. It dynamically adjusts which cores get which tasks to prevent multiple cores from competing for memory access at the same time. This keeps cores from sitting idle and ensures efficient use of the available computing power.

**Novelty:** It brings ANNS scheduling down to individual PIM cores, dynamically matching each core's workload to its actual memory bandwidth and computing capacity.
