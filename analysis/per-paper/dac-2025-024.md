# dac-2025-024: CLI-HD - Topology-Aware Hotspot Detection

**Title:** Delving into Topology Representation for Layout Pattern: A Novel Contrastive Learning Framework for Hotspot Detection

**Key Contribution:** CLI-HD contrastive learning with Layout2Seq polygon encoding and absolute position embedding; 0.82%-4.77% accuracy gain; 4.9%-23.18% FAR reduction.
