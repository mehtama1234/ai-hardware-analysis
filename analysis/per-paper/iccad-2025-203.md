# Unveiling the Mask: Trusted Semiconductor Manufacturing through Wafer-Level Mask-Set Attestation

**Venue:** ICCAD  
**ID:** iccad-2025-203

## Problem
Semiconductor supply chain security requires detecting wafers fabricated with untrusted mask-sets; traditional methods cannot leverage wafer metrology data for attestation.

## Motivation


## Method
A machine learning system learns to detect wafers made with untrusted mask-sets (the photomasks that control which patterns get printed onto semiconductor chips) by analyzing inline measurements from manufacturing and electrical tests of finished chips. Trained on 8000 wafers, it learns to recognize how changes to the mask-set causally alter both the physical structures and electrical performance of the resulting chips.

## Key Novelty
Machine learning authenticates semiconductor mask-sets by detecting process variation signatures—distinctive patterns in how manufacturing variations differ between wafers made with authentic versus untrusted masks.

## Contributions
- ML-based mask-set attestation methodology
- Systematic analysis of process variation correlation with mask changes
- Validation on 8000 wafers in GlobalFoundries 12LP FinFET
- Detection of trusted vs untrusted mask-sets via metrology
