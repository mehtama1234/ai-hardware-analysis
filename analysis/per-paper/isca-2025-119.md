# DiTile-DGNN: An Efficient Accelerator for Distributed Dynamic Graph Neural Network Inference

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Dynamic Graph Neural Networks (DGNNs) combine GNN and RNN computations over evolving graph snapshots, creating combinatorial challenges of heterogeneous operator types, intra- and inter-snapshot data dependencies, redundant data across snapshots, and load imbalance that prevent efficient parallel scaling.

## Motivation
DGNNs are critical for temporal relational learning but their hybrid GNN+RNN structure and evolving graph topology create severe data redundancy and synchronization overheads that existing GNN or RNN accelerators cannot address.

## Method
DiTile-DGNN uses a redundancy-free parallelism framework that analytically identifies snapshot-level data overlap and eliminates redundant computation while minimizing inter-node communication complexity. A workload-balance optimizer removes synchronization barriers between snapshots. A reconfigurable accelerator architecture with flexible interconnect dynamically adapts to support multiple DGNN dataflows (GNN aggregation, RNN recurrence, and their combination) without hardware redesign.

## Key Novelty
A redundancy-free parallelism strategy that jointly eliminates inter-snapshot data redundancy and minimizes communication complexity in distributed DGNN execution.

## Contributions
1. Redundancy-free parallelism framework for DGNN that eliminates inter-snapshot data redundancy
2. Workload balance optimization across snapshots to remove synchronization overhead
3. Reconfigurable accelerator with flexible interconnect supporting multiple DGNN dataflows
4. Demonstrated 23-56% latency reduction and 71-84% energy efficiency gain vs. state-of-the-art
