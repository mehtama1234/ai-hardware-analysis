# Mamba-X: An End-to-End Vision Mamba Accelerator for Edge Computing Devices

**ID:** iccad-2025-247

## Problem
Vision Mamba models (state-space based architectures) are computationally demanding and poorly suited for edge devices. Existing accelerators lack support for this emerging model class.

## Motivation
Vision Mamba offers better efficiency than transformers for certain workloads; specialized hardware support is needed to deploy these models on edge devices.

## Method
The accelerator is a specialized chip designed specifically for Vision Mamba, a neural network that processes images by sequentially updating internal state. It uses a systolic scan array—a hardware pattern with repeating cells optimized for sequential state calculations—to run these updates efficiently. To fit on edge devices, it applies quantization (reducing number precision from 32-bit to 8-bit values, for example) to compress the model. All components—hardware, compression, and software—integrate into one coordinated system for efficient edge deployment.

## Key Novelty
This is the first hardware accelerator built specifically for Vision Mamba, using a systolic scan array (repeating hardware cells optimized for sequential state calculations) to efficiently run these image models on edge devices.
