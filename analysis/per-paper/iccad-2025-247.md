# Mamba-X: An End-to-End Vision Mamba Accelerator for Edge Computing Devices

**ID:** iccad-2025-247

## Problem
Vision Mamba models (state-space based architectures) are computationally demanding and poorly suited for edge devices. Existing accelerators lack support for this emerging model class.

## Motivation
Vision Mamba offers better efficiency than transformers for certain workloads; specialized hardware support is needed to deploy these models on edge devices.

## Method
Dedicated hardware accelerator with systolic scan array architecture optimized for Vision Mamba's state-space operations. Hardware-friendly quantization schemes for model compression. End-to-end optimized design for edge deployment.

## Key Novelty
First end-to-end hardware accelerator for Vision Mamba with systolic scan array for state-space model inference.
