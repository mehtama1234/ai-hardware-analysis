# sc-2025-039: On the integration of lightweight tasks with MPI using the C++26 std::execution 'Senders' API

## Summary
Explores integration of asynchronous MPI messaging with tasking runtimes using C++26 Senders API. Implements Senders in pika tasking runtime and demonstrates MPI as first-class execution nodes.

## Problem
- Integrating MPI (message-passing) with tasking runtimes is complex
- Requires careful handling of:
  - Asynchronous message requests
  - Polling and progress
  - Completion handling and dispatching
- Existing approaches lack clean abstractions

## Method
The team implemented the C++26 Senders API—a standard way to describe sequences of computations—in the pika parallel tasking runtime (software that schedules work across processor cores). They represented asynchronous MPI messaging calls (which send data across networked computers) as individual nodes in a computation graph, treating network I/O the same way the runtime treats regular computation. Then they tested different strategies for polling (checking when messages arrive) and dispatching (routing completed messages to the right task).

## Key Innovations
1. **Senders API for HPC**: First implementation in HPC tasking runtime
2. **Explicit semantics**: Senders make execution transfer explicit (crucial for high performance)
3. **MPI as first-class nodes**: Enables compiler/runtime reasoning about messaging
4. **Flexible scheduling**: Experimental framework for evaluating scheduling strategies
