# DyREM: Dynamically Mitigating Quantum Readout Error with Embedded Accelerator

**ID**: dac-2025-447  
**Venue**: DAC  
**Confidence**: low

## Problem
Quantum readout error mitigation requires on-the-fly computation of large mitigation matrices, incurring high latency and memory overhead that limits practical quantum computing scale.

## Motivation
Quantum systems suffer from measurement errors; efficient mitigation is essential for near-term quantum computing viability.

## Method
Quantum computers introduce errors during readout measurements. DyREM improves this by exploiting sparsity—the fact that quantum probability distributions contain many zero or near-zero values. Rather than processing large error-correction matrices, DyREM dynamically creates smaller versions. An embedded hardware accelerator performs the required calculations (tensor products), using gating—conditional logic gates—to skip computing certain quantum state values, reducing latency and memory overhead.

## Key Novelty
DyREM's core idea is that quantum probability distributions are sparse (full of zeros), enabling dynamic shrinking of error-correction matrices through gated computation that skips unnecessary calculations.
