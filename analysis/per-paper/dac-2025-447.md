# DyREM: Dynamically Mitigating Quantum Readout Error with Embedded Accelerator

**ID**: dac-2025-447  
**Venue**: DAC  
**Confidence**: low

## Problem
Quantum readout error mitigation requires on-the-fly computation of large mitigation matrices, incurring high latency and memory overhead that limits practical quantum computing scale.

## Motivation
Quantum systems suffer from measurement errors; efficient mitigation is essential for near-term quantum computing viability.

## Method
DyREM leverages sparsity in quantum state probability distributions to dynamically downsample mitigation matrices. An embedded accelerator computes tensor products using gating to skip nonzero quantum state computations.

## Key Novelty
Sparsity-aware dynamic matrix downsampling and gated computation for quantum readout error mitigation.

## Contributions
- Sparsity-driven mitigation matrix downsampling
- Embedded accelerator architecture with computational gating
- 9.6x-2000x speedup vs SOTA
