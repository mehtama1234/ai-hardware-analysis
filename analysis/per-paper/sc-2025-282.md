# Dori: User Centered HPC for Data Intensive Computing

**Venue:** SC 2025  
**Author:** Georg Rath (Joint Genome Institute)

## Problem & Motivation

Managing a mixed production/research HPC cluster serving data-intensive workloads (genomics, bioinformatics) presents unique challenges: diverse user requirements, complex governance needs, software infrastructure demands, and the sheer scale of data processing. Traditional HPC cluster management models, designed for simulation-heavy compute, struggle with data-intensive genomic workflows.

## Approach

Dori, the Joint Genome Institute's primary HPC cluster since 2022, exemplifies a user-centered design philosophy:

1. **Governance Model:** Established processes for addressing mixed production/research stakeholder needs.
2. **Communications Strategy:** Mechanisms for understanding and responding to diverse user requirements.
3. **Software Tools:** Specialized infrastructure for genomic data processing and analysis.
4. **Operational Practices:** Lessons from processing petabytes of genomic data at scale.

## Key Novelty

- **User-Centered Focus:** Cluster design and operations centered on user needs rather than generic resource optimization.
- **Integrated Approach:** Unified governance, communications, and tooling strategy for data-intensive environments.
