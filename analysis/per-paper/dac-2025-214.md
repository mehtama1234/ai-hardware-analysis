# Swift or Exact? Boosting Efficient Microarchitecture DSE via Multi-fidelity Partial Order Prediction

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Microarchitecture DSE bottlenecks on slow synthesis/simulation; early-stage PPA estimates are pessimistic, preventing rapid design iteration.

## Key Insight
Multi-fidelity data (fast/inaccurate + slow/accurate) can be intelligently fused to approximate Pareto fronts faster by reusing low-fidelity info with selective high-fidelity refinement.

## Method
The system combines quick-rough estimates with slow-accurate simulations using a Gaussian process, which is a statistical model that predicts outcomes and estimates its own uncertainty. It learns which rough estimates are reliable by comparing them to accurate results, then runs expensive accurate simulations only when it needs confirmation of uncertain designs. This avoids both the cost of always running slow simulations and the inaccuracy of relying only on rough estimates.

## Contributions
- Gaussian process for multi-fidelity fusion
- Reliability assessment of low-fidelity via logical regression + partial orders
- Faster Pareto front approximation
- Reduced high-fidelity simulation cost
