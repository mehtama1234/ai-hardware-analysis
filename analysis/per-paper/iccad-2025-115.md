# Ultrafast Density Gradient Accumulation in 3D Analytical Placement with Divergence Theorem

**Venue:** ICCAD  
**Confidence:** low

## Problem
Density gradient accumulation is a critical bottleneck in 3D analytical placement, especially for mixed-size designs with large macros; 3D placement requires larger grids than 2D, exacerbating the computational burden.

## Motivation
3D placement for advanced packaging is increasingly important; reducing this bottleneck directly improves design automation tool efficiency and enables faster design iteration.

## Method
Algorithm inspired by divergence theorem reduces density gradient accumulation time complexity. Implementations provided for both CPU and GPU to leverage diverse hardware capabilities efficiently.

## Key Novelty
Divergence theorem-based algorithm reducing time complexity of density gradient accumulation in 3D placement.

## Contributions

- 3× end-to-end runtime speedup on CPU
- 3× end-to-end runtime speedup on GPU
- Significantly faster 3D analytical placement
