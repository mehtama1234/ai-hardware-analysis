# Efficient Lossless Compression of Scientific Floating-Point Data on CPUs and GPUs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** high-throughput lossless floating-point compression for CPUs and GPUs

## Problem
Scientific datasets are growing faster than storage and interconnect bandwidth, making data compression essential, but existing lossless compressors for floating-point data are either fast or achieve good compression ratios—rarely both on both CPUs and GPUs.

## Motivation
As GPU-accelerated scientific computing produces ever-larger floating-point datasets, a compressor that is cross-platform (CPU/GPU compatible), high-throughput, and high-ratio eliminates a key I/O bottleneck without becoming a new processing bottleneck.

## Method
The paper introduces four lossless compression algorithms built specifically for floating-point numbers (the standard way computers represent decimals, with an exponent that sets the scale and a mantissa holding the significant digits). The algorithms work identically on both CPUs and GPUs, producing the same compressed format so data can move between them without re-encoding. The compression works by identifying and removing redundancy in the patterns of exponent and mantissa bits. Both implementations are tuned for CPU vector units and GPU streaming multiprocessors—parallel processing systems that handle many data items simultaneously—to maximize compression and decompression speed.

## Key Novelty
The core innovation is four lossless floating-point compression algorithms that work identically on both CPUs and GPUs, producing the same compressed data on either platform while achieving over 500 GB/s throughput on an RTX 4090 GPU without sacrificing compression quality.

## Contributions
- Four new lossless compression algorithms for single- and double-precision scientific floating-point data
- Full CPU-GPU bitstream compatibility enabling cross-platform interoperability
- Compression and decompression throughput exceeding 500 GB/s on RTX 4090
- Comprehensive evaluation against 18 compressors on SDRBench
