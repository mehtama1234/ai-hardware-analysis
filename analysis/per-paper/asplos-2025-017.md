# Efficient Lossless Compression of Scientific Floating-Point Data on CPUs and GPUs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** high-throughput lossless floating-point compression for CPUs and GPUs

## Problem
Scientific datasets are growing faster than storage and interconnect bandwidth, making data compression essential, but existing lossless compressors for floating-point data are either fast or achieve good compression ratios—rarely both on both CPUs and GPUs.

## Motivation
As GPU-accelerated scientific computing produces ever-larger floating-point datasets, a compressor that is cross-platform (CPU/GPU compatible), high-throughput, and high-ratio eliminates a key I/O bottleneck without becoming a new processing bottleneck.

## Method
Four new lossless compression algorithms for single- and double-precision IEEE 754 floating-point data, fully compatible between CPUs and GPUs (same bitstream). Algorithms exploit bit-level patterns in floating-point exponent/mantissa fields and are tuned for SIMD/SIMT parallelism. Evaluated against 18 compressors on SDRBench scientific datasets on two CPUs and two GPUs.

## Key Novelty
Four floating-point-specific lossless compression algorithms that are simultaneously CPU/GPU bitstream-compatible and achieve best-in-class throughput (>500 GB/s on RTX 4090) without sacrificing compression ratio.

## Contributions
- Four new lossless compression algorithms for single- and double-precision scientific floating-point data
- Full CPU-GPU bitstream compatibility enabling cross-platform interoperability
- Compression and decompression throughput exceeding 500 GB/s on RTX 4090
- Comprehensive evaluation against 18 compressors on SDRBench
