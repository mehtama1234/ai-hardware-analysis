# ITERA-LLM: Boosting Sub-8-Bit Large Language Model Inference via Iterative Tensor Decomposition

**Problem:** Deploying LLMs on resource-constrained platforms with sub-8-bit quantization causes significant accuracy degradation. Standard quantization-only methods cannot maintain model accuracy when precision falls below 8 bits.

**Method:** The method uses sub-8-bit quantization—cutting the precision of weights to a few bits, which shrinks the model and speeds up inference but normally destroys accuracy. To recover that accuracy, it applies an iterative tensor decomposition technique (using SVD to break large operations into simpler, lower-rank parts) that reduces computational cost while compensating for the precision loss. It then runs a hardware-aware search (Design Space Exploration) that tries different precision levels and decomposition depths to find the best balance between accuracy, inference speed, and memory use for the target hardware and language model.

**Novelty:** The innovation is a hardware-aware integration of sub-8-bit quantization and iterative tensor decomposition to achieve high model compression without accuracy loss.
