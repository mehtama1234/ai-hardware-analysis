# asplos-2025-149: Performance Prediction of On-NIC Network Functions with Multi-Resource Contention and Traffic Awareness

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Co-located NFs on SmartNICs suffer performance interference from multi-resource contention, but existing prediction models lack SmartNIC-specific knowledge and traffic awareness, yielding poor accuracy for SLA management.

## Motivation
NF offloading to SmartNICs is widely adopted; co-location creates resource contention that must be quantified for SLA-driven data center resource management.

## Method
A performance prediction framework profiles SmartNIC-specific multi-resource contention (CPU, memory, DMA, queues) between co-located NFs and incorporates traffic-arrival awareness to predict per-NF throughput and latency under contention.

## Key Novelty
SmartNIC-aware, traffic-sensitive performance prediction model jointly capturing multi-resource contention among co-located on-NIC network functions.

## Contributions
- Performance prediction framework for SmartNIC multi-resource contention
- Traffic-awareness component accounting for arrival patterns
- Accurate NF performance prediction enabling SLA-driven resource management
