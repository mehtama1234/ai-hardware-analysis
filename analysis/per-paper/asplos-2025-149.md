# asplos-2025-149: Performance Prediction of On-NIC Network Functions with Multi-Resource Contention and Traffic Awareness

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Co-located NFs on SmartNICs suffer performance interference from multi-resource contention, but existing prediction models lack SmartNIC-specific knowledge and traffic awareness, yielding poor accuracy for SLA management.

## Motivation
NF offloading to SmartNICs is widely adopted; co-location creates resource contention that must be quantified for SLA-driven data center resource management.

## Method
The framework predicts how fast network functions (programs that process network traffic) will run when multiple are co-located on a SmartNIC (a specialized network processor card), by measuring how they interfere when competing for shared resources: CPU cores, memory bandwidth, data transfer engines, and packet queues. It accounts for how incoming traffic patterns affect queuing delays, using machine learning to predict each function's latency (how long operations take) and throughput (how much data it processes), given its resource allocation and traffic conditions.

## Key Novelty
It predicts network function performance on SmartNICs by jointly modeling how co-located functions compete for multiple resources (CPU, memory, data transfer engines, queues), with competition patterns that depend on incoming traffic.

## Contributions
- Performance prediction framework for SmartNIC multi-resource contention
- Traffic-awareness component accounting for arrival patterns
- Accurate NF performance prediction enabling SLA-driven resource management
