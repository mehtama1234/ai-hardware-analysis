# SC-2025-313: Moment: Co-optimizing Physical Communication Topology and Data Placement for Multi-GPU Out-of-core GNN Training

## Summary
This work presents Moment, a framework for co-optimizing physical GPU communication topology and data placement in multi-GPU Graph Neural Network (GNN) training. By formulating communication scheduling as a max-flow problem and using data-distribution-aware placement algorithms, Moment achieves high throughput on a single machine at significantly lower cost than distributed approaches.

## Key Contributions
1. **Co-optimization of communication topology and data placement** for multi-GPU GNN training
2. **Max-flow formulation** for communication scheduling and contention resolution
3. **Data-distribution-aware knapsack algorithm** for optimal placement
4. **6.51x speedup** over out-of-core approaches
5. **3.02x speedup** over distributed systems with 50% cost reduction

## Technical Approach
- Physical topology modeling as capacity-constrained directed graphs
- Communication scheduling via maximum flow optimization
- Data placement optimization using distribution-aware knapsack formulation
- GPU load balancing algorithms
- Integration with PyTorch for GNN training

## Hardware & Systems
- Multi-GPU systems (8+ GPUs on single machine)
- NVLink for high-speed GPU-to-GPU communication
- PCIe Gen4/5 for CPU-GPU communication
- UMA (unified memory address space) systems

## Workloads & Evaluation
- **Primary**: Large-scale graph neural networks
- **Applications**: Recommendation systems, social network analysis
- **Baseline comparison**:
  - Single-machine out-of-core GNN training
  - Distributed multi-machine approaches
- **Performance metrics**: Throughput, memory efficiency, total cost of ownership

## Limitations & Future Work
- Evaluation limited to specific GNN architectures (GCN, GraphSAGE variants implied)
- Scalability to systems with 32+ GPUs not explored
- Applicability to other graph algorithms (sparse linear algebra, traversal) unclear
- Heterogeneous GPU types and cloud environments not addressed
- Communication overhead analysis during data transfers not detailed
- Comparison with other out-of-core systems (cuGraph, DGL) not provided
