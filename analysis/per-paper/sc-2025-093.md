# SC25 Paper Analysis: sc-2025-093

## Simulating Hybrid Analog + RISC-V Systems for HPC Applications

### Summary
This work explores hybrid analog-digital RISC-V architectures where analog accelerators serve as coprocessors. Using SST simulation, the authors evaluate iterative linear solvers and reveal that digital operations remain bottlenecks even in analog-dominated workloads, providing guidance for future hybrid system design.

### Key Problem
- **Analog Integration Gap**: Analog computing offers efficiency but supports only limited kernels
- **Full Application Challenge**: Complex HPC workloads cannot be purely analog-accelerated
- **Hybrid Architecture Unknown**: Integration patterns for analog accelerators in general-purpose systems are unexplored

### Technical Approach
1. **Hybrid Architecture**: Analog accelerators as tightly integrated coprocessors within cores
2. **RISC-V Foundation**: Mature software stack for digital components
3. **SST Simulation**: Structural Simulation Toolkit for architectural evaluation
4. **Workload Analysis**: Iterative linear solver evaluation on hybrid systems

### Contributions
1. Hybrid analog-digital RISC-V architecture design
2. Analog coprocessor integration strategy
3. Simulation methodology for evaluating hybrid systems
4. Performance analysis of iterative algorithms on hybrid architectures
5. Identification of digital bottlenecks in analog workloads

### Hardware & Workloads
- **Target Hardware**: RISC-V with analog coprocessors
- **Workloads**: Iterative linear solvers (representative HPC kernels)

### Key Findings
- Digital operations remain bottlenecks even in analog-dominated applications
- Importance of software-hardware co-design for hybrid systems
- Need for further research on balancing analog and digital operations

### Applications
- High-performance computing
- Numerically intensive applications
- Energy-efficient processing

Emerging Computing Paradigms and Alternative Technologies
