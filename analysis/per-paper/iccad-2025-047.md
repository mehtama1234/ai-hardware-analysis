# Prompt, Fab, Flex: Agentic LLMs for Flexible Electronics Design

**Venue:** ICCAD | **ID:** iccad-2025-047

## Problem
Flexible electronics EDA workflows are complex, time-intensive, and inaccessible to non-experts. Existing LLM-driven design automation targets only conventional silicon, not flexible electronics with unique constraints.

## Motivation
Lower barriers to adoption and accelerate development of personalized, application-specific flexible electronics for extreme edge applications.

## Method
The framework uses a large language model—an AI trained on text—to automatically design circuits for flexible electronics, which bend and flex unlike rigid silicon. It automates the design workflow: writing hardware descriptions (RTL), converting them to working circuits (logic synthesis), and exploring different design options to optimize power consumption, speed, and chip size for machine learning classifier applications while respecting flexible materials' physical constraints. The system handles these trade-offs end-to-end without human intervention at each design step.

## Key Novelty
It's the first system using large language models to automate circuit design specifically for flexible electronics, which have different constraints than rigid silicon.

## Contributions
- LLM-driven RTL generation for flexible electronics ML classifiers
- Cross-layer PPA design space exploration for FE-based systems
- Reduced barriers to adoption through automated hardware design methodology
