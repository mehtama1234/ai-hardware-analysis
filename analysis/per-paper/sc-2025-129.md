# Experiences Integrating Database Support into the OLCF Test Harness

**Venue:** SC
**ID:** sc-2025-129
**Confidence:** low

## Problem
HPC system testing frameworks lack database integration for real-time monitoring and advanced analysis on leadership-class supercomputers.

## Motivation
Frontier and other leadership systems require comprehensive testing of 9000+ nodes with efficient monitoring and root-cause analysis.

## Method
OLCF Test Harness (OTH) v3.0/3.1 integrates InfluxDB, Apache Kafka, Apache Druid, and Grafana for database-backed testing.

## Key Novelty
First explicit database-backed testing framework for leadership-class HPC systems

## Contributions
1. InfluxDB support in OTH v3.0
2. Kafka/Druid support in OTH v3.1
3. Grafana integration for real-time monitoring
