# Experiences Integrating Database Support into the OLCF Test Harness

**Venue:** SC
**ID:** sc-2025-129
**Confidence:** low

## Problem
HPC system testing frameworks lack database integration for real-time monitoring and advanced analysis on leadership-class supercomputers.

## Motivation
Frontier and other leadership systems require comprehensive testing of 9000+ nodes with efficient monitoring and root-cause analysis.

## Method
The OLCF Test Harness (testing framework for Oak Ridge's leadership-class supercomputers) connects four specialized database tools to work together. Apache Kafka shuttles test data between systems quickly, InfluxDB stores timestamped measurements (like temperature or performance readings), Apache Druid analyzes large datasets efficiently, and Grafana creates interactive dashboards. This setup lets engineers watch tests run in real time and dig through historical results afterward.

## Key Novelty
It uses integrated database systems instead of flat files to collect, store, and analyze testing data from leadership-class supercomputers.

## Contributions
1. InfluxDB support in OTH v3.0
2. Kafka/Druid support in OTH v3.1
3. Grafana integration for real-time monitoring
