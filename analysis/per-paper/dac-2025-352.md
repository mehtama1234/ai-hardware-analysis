# Monolithic 3D FPGA Design and Synthesis with Back-End-of-Line Configuration Memories

**Venue:** DAC  
**ID:** dac-2025-352

## Problem
Conventional FPGAs use bulky Si SRAM for configuration, occupying area and increasing reconfigurable circuit overhead; this limits routing efficiency and increases latency.

## Motivation
Post-Moore era demands area-efficient FPGA designs; monolithic 3D integration with novel materials achieves better AT² trade-offs by reducing configuration memory footprint.

## Key Innovation
BEOL-compatible AOS transistor-based configuration memory replacing Si SRAM in monolithic 3D FPGA, enabling denser routing matrices and reduced interconnect latency.

## Method
The design stacks special transistors—amorphous oxide semiconductors (AOS) made from materials like W-doped indium oxide and tin oxide—in the back-end-of-line (BEOL) layers above the main logic blocks (CLBs). These AOS transistors store configuration data with less power leakage than conventional silicon SRAM, shrinking the space needed. By placing the FPGA's switch and connection blocks directly above the logic blocks using AOS pass gates (transistors that act as controllable switches), routing distances shrink, reducing interconnect latency.

## Contributions
- AOS transistor-based configuration memory for BEOL integration
- Monolithic 3D FPGA architecture leveraging BEOL transistors
- Physics-based TCAD modeling of AOS devices
- 3.4x lower AT², 27% lower latency, 26% lower routing power

## Results
3.4x lower AT² product, 27% lower critical path latency, 26% lower routing block power.
