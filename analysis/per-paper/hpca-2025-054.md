# Uni-Render: A Unified Accelerator for Real-Time Rendering Across Diverse Neural Renderers

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Existing neural rendering accelerators are designed for a single specific rendering pipeline, making them unable to efficiently support the diverse and evolving landscape of neural rendering algorithms (NeRF, 3DGS, hybrid methods) required for different application scenarios.

## Motivation
Immersive 3D applications demand real-time rendering (>30 FPS) across multiple distinct neural rendering pipelines, but dedicated pipeline-specific accelerators are economically and practically infeasible for edge deployment.

## Method
Uni-Render is a reconfigurable ASIC accelerator that identifies common operators shared across diverse neural rendering pipelines (ray marching, Gaussian rasterization, MLP inference, volume compositing) and implements a configurable dataflow engine that dynamically adjusts dataflow and operator mapping to match each rendering algorithm. The hardware supports both typical and hybrid rendering pipelines through runtime reconfiguration of processing elements and memory hierarchy.

## Key Novelty
A single reconfigurable accelerator architecture that covers the full breadth of representative neural rendering pipelines by exploiting their shared computational operators while dynamically adapting dataflow for each pipeline's specific requirements.

## Contributions
1. Systematic identification of common computational operators across diverse neural rendering pipelines
2. Reconfigurable hardware architecture with dynamically adjustable dataflow supporting multiple neural rendering algorithms
3. First unified accelerator achieving real-time neural rendering (>30 FPS) across varied pipelines at ~5W edge power
4. Up to 119x speedup over state-of-the-art neural rendering hardware
