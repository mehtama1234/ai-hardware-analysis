# Emulating Space Computing Networks with RHONE

**Problem:** Space Computing Networks (SCNs) research requires high-fidelity modeling of satellite and constellation behavior (power, thermal, network, computation states), but real satellite experimentation is prohibitively expensive.

**Method:** RHONE uses a two-stage process. First, it builds models of satellite behavior—power consumption, heat, orbits, networking, and computation—by combining real satellite data with real chip code running in a simulator. Then it runs containerized applications (self-contained software packages) through these integrated models to simulate how entire satellite networks would function.

**Novelty:** The core innovation is using real satellite data together with real chip code in a simulator to accurately model how satellites and constellations operate while remaining practical to use.
