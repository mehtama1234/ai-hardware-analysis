# Self-Attention to Operator Learning-based 3D-IC Thermal Simulation

**Venue:** DAC | **ID:** dac-2025-125

## Core Problem
Efficient thermal simulation for 3D ICs with high power densities; PDE solvers are accurate but slow for iterative design.

## Method
The approach uses a neural network called SAU-FNO (Self-Attention UNet Fourier Neural Operator) that learns to predict how heat flows through 3D chips. It combines three complementary techniques: self-attention (which lets the network track how temperature changes in one part of the chip affect distant regions), U-Net architecture (which processes thermal features at multiple scales simultaneously), and Fourier Neural Operators (which efficiently model both fine-grained temperature details and broader heat patterns). To train this network efficiently, the method uses transfer learning: it starts with low-fidelity simulations (fast but less precise) and fine-tunes on high-fidelity data (slow but accurate), which reduces the need for expensive high-fidelity training data.

## Key Novelty
The hybrid architecture combines self-attention (which captures thermal interactions across the chip), U-Net (which preserves fine temperature details), and Fourier Neural Operators (which model heat patterns) to capture both high-frequency temperature information and long-range thermal dependencies, trained efficiently via transfer learning using low-fidelity simulation data.

## Contributions
- SAU-FNO architecture (self-attention + U-Net + FNO)
- Transfer learning enabling low-fidelity training
- State-of-the-art thermal prediction
- 842x speedup over FEM
