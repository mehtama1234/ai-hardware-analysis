# Extended User Interrupts (xUI): Fast and Flexible Notification without Polling

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** hardware extensions for fast user-space interrupt notification without polling

## Problem
Intel's existing User Interrupt (UIPI) mechanism for fast user-space notification has correctness and performance limitations that prevent it from matching shared-memory polling latency while maintaining the efficiency of asynchronous notification. Current designs lack support for preemption in user-level runtimes, kernel-bypass timers, and efficient interrupt forwarding to accelerators.

## Motivation
High-performance systems (user-level runtimes, networking stacks, streaming accelerators) need notification mechanisms that avoid expensive kernel transitions but also avoid burning CPU cycles on polling; existing user-interrupt designs leave a performance gap.

## Method
xUI extends Intel's UIPI with four hardware capabilities: (1) tracked interrupts that confirm when notifications arrive, (2) hardware safepoints—points where the processor safely pauses thread execution—enabling thread management without kernel help, (3) a user-space timer for deadline-driven scheduling without kernel overhead, and (4) interrupt forwarding (based on Intel's DSA) routing notifications directly to accelerators. Together, these solve key limitations: delivery confirmation, kernel-free preemption, deadline-driven scheduling, and accelerator communication. The design is evaluated through gem5, a full-system computer simulator, measuring latency for three distinct use cases.

## Key Novelty
The core innovation is extending Intel's user-interrupt model with hardware safepoints that enable thread pausing without the kernel, combined with interrupt forwarding that routes notifications directly to accelerators.

## Contributions
- Detailed analysis and timing model of Intel UIPI's limitations
- Four hardware extensions: tracked interrupts, hardware safepoints, kernel-bypass timer, interrupt forwarding
- gem5-based evaluation across three use cases
- Demonstrated performance matching polling with efficiency of async notification
