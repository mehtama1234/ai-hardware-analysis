# isscc-2025-179: Hybrid-Shutter Switchable Image Sensor

**Title:** 6.1 A 3-Stacked Hybrid-Shutter CMOS Image Sensor with Switchable 1.2µm-Pitch 50Mpixel Rolling Shutter and 2.4µm-Pitch 12.5Mpixel Global Shutter Modes for Mobile Applications

**Problem:** Mobile imaging must choose between high-resolution rolling shutter (with flicker/motion blur) or lower-noise global shutter.

**Approach:** 3-layer stacked hybrid-shutter sensor supporting both modes switchably: 1.2µm 50Mp rolling-shutter and 2.4µm 12.5Mp global-shutter.

**Key Result:** On-demand flexible imaging without noise/resolution tradeoff, eliminates flicker/flash-banding/motion-distortion.

**Hardware:** ASIC (image sensor).

**Tags:** image-sensor, hybrid-shutter, pixel-array, rolling-shutter, global-shutter, mobile
