# dac-2025-242: Optimizing windowed arithmetic for quantum attacks against RSA-2048

## Summary
Optimizes windowed arithmetic uncomputation in quantum factoring circuits, achieving ~50% reduction in memory lookup costs and 1.5-3.4% overall gate reduction for RSA-2048 attacks, with optional 16% speedup at 12% qubit cost.

## Key Idea
Reduce uncomputation overhead in windowed memory lookups for quantum modular exponentiation via specialized optimization techniques.

## Contributions
- 50% uncomputation cost reduction for memory lookups
- 1.5-3.4% factoring gate count improvement
- Runtime/qubit trade-off: 16% faster with 12% more qubits
- Generalizable to windowed quantum algorithms

## Limitations
RSA-2048 only; post-quantum cryptography attacks not addressed.
