# FlexNeRFer: A Multi-Dataflow, Adaptive Sparsity-Aware Accelerator for On-Device NeRF Rendering

**ID:** isca-2025-085 | **Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
GPUs fail to meet the PPA demands for on-device NeRF rendering, and existing NeRF-specific accelerators target a single algorithm, yielding poor efficiency across diverse NeRF models. No versatile hardware exists to serve the growing variety of NeRF frameworks used in on-device 3D reconstruction.

## Motivation
On-device AR/VR and robotics are rapidly adopting multiple NeRF model families, demanding a single accelerator that handles diverse dataflows and sparsity patterns without re-design per algorithm.

## Method
FlexNeRFer is a specialized chip where an internal communication network (called a Network-on-Chip or NoC) reconfigures itself to handle different ways data flows through the computation, allowing the same hardware to adapt to different algorithm styles. Its multiply-accumulate units (the computational cores) can adjust their precision—operating at different bit-widths like 8-bit or 16-bit—based on accuracy needs, and the chip automatically detects sparse data (matrices with lots of zeros) and selects the most efficient storage format at runtime to avoid wasting computation on zero values. Built in 28 nanometer CMOS technology, this combination of flexible routing, adjustable precision, and automatic sparse-data handling enables one chip to efficiently run many different NeRF algorithms.

## Key Novelty
FlexNeRFer uses a flexible internal network that adapts its data routing and compute precision on-the-fly, automatically selecting the right format for sparse data, so a single accelerator chip can efficiently run different NeRF algorithms that would otherwise each require algorithm-specific hardware.

## Contributions
1. FlexNeRFer ASIC supporting multi-dataflow and adaptive sparsity on a precision-scalable MAC array
2. Flexible NoC that reconfigures per dataflow requirement of each NeRF model
3. Runtime sparsity format selection based on observed sparsity ratio and precision mode
4. 28 nm layout with 8.22–43.3x speedup and 24.15–20.3x energy efficiency over RTX 2080 Ti

## Metrics
- Speedup: 8.22–43.3x over RTX 2080 Ti; 4.28–6.9x over NeuRex
- Energy efficiency: 24.15–20.3x over RTX 2080 Ti; 2.34–7.5x over NeuRex
- Technology: 28 nm CMOS

## Baselines
NVIDIA RTX 2080 Ti, NeuRex

## Limitations
Generalization to all emerging NeRF architectures beyond the evaluated variants is not fully demonstrated.
