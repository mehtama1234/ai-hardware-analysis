# Quantum Analysis of LESCA

**Venue:** VLSID

## Problem
Stream cipher security under quantum attacks unclear; quantum implementation cost of LESCA unknown

## Motivation
NIST quantum security levels require formal assessment; need to understand LESCA resilience to quantum threats

## Method
The researchers built LESCA—a stream cipher (a type of encryption)—to run on quantum computers. They then tested how it would fare against Grover's search algorithm, a quantum attack that tries encryption keys much faster than traditional computers could. They verified that LESCA still meets the security standards set by NIST even under this quantum attack.

## Key Novelty
This is the first quantum implementation of LESCA, including analysis of how it resists Grover's search algorithm and compliance with NIST security standards.
