# SparseInfer: Training-free Prediction of Activation Sparsity for Fast LLM Inference

**Venue**: DATE  
**Primary Theme**: Training-free activation sparsity prediction for LLM inference  

## Problem
Modern LLMs using SiLU activation show minimal sparsity; ReLU replacement induces sparsity but prior methods required training a separate predictor to estimate it.

## Method
SparseInfer predicts which computations in language models can be skipped when using ReLU activation (where negative outputs become zero) without any training. It checks only whether each input and weight value is positive or negative—not the actual numbers—to decide if an activation will be zero and safe to skip. You can tune the predictor to be more or less aggressive, trading off how many operations you actually skip against the risk of incorrectly identifying which ones can be skipped.

## Key Novelty
It predicts which computations can be skipped in ReLU language models using only sign comparison of inputs and weights, without training a separate predictor.

## Contributions
- Training-free sparsity prediction mechanism
- Approximately 21% faster inference over state-of-the-art
- Negligible accuracy loss within 1 percentage point
- Adaptive conservativeness tuning for inference optimization
