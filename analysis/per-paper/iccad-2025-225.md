# 3D CoSim: Coupled Operator Learning-Based Co-Simulator for Transferable 3D-IC Analysis

**Paper ID:** iccad-2025-225  
**Venue:** ICCAD

## Problem

Multi-physics analysis in 3D integrated circuits requires complex PDE simulations coupling electromagnetic and thermal fields, which are time-consuming and difficult to adapt to diverse design configurations. Existing neural network field solvers lack compatibility with complex, arbitrary 3D IC configurations.

## Motivation

Accelerating multi-physics simulations for 3D ICs while maintaining compatibility across different design configurations is essential for modern chip design optimization.

## Method

It trains a neural network called DeepONet on physics equations (specifically the heat equation and Maxwell's equations, which describe how electricity and heat behave) to learn the mapping between a 3D chip's geometry, materials, and the resulting electromagnetic and thermal fields. Rather than solving these equations from scratch for each new design—which takes hours in traditional simulation software—the trained network produces predictions instantly. The network learns transfer functions that generalize across different chip configurations with different boundary conditions, so it works on designs it hasn't encountered during training.

## Key Novelty

It's the first neural-network simulator that combines electromagnetic and thermal field analysis for arbitrary 3D chip configurations, delivering 844–7600× speedup compared to commercial software (COMSOL) while maintaining 97% accuracy on electromagnetic predictions and 99.8% on thermal predictions.

## Contributions

- Physics-informed neural network architecture leveraging DeepONet for transferable multi-physics field solving
- Support for multiple PDE configurations (heat, Maxwell) with diverse boundary conditions in unified framework
- Achieves orders-of-magnitude speedup (844-7600×) over COMSOL while preserving accuracy
