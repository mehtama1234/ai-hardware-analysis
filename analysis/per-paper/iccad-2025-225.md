# 3D CoSim: Coupled Operator Learning-Based Co-Simulator for Transferable 3D-IC Analysis

**Paper ID:** iccad-2025-225  
**Venue:** ICCAD

## Problem

Multi-physics analysis in 3D integrated circuits requires complex PDE simulations coupling electromagnetic and thermal fields, which are time-consuming and difficult to adapt to diverse design configurations. Existing neural network field solvers lack compatibility with complex, arbitrary 3D IC configurations.

## Motivation

Accelerating multi-physics simulations for 3D ICs while maintaining compatibility across different design configurations is essential for modern chip design optimization.

## Method

Proposes 3D CoSim, a Physics-Informed Neural Network (PINN) based simulator using a Multi-input DeepONet architecture to learn nonlinear mappings from geometrical and physical setups to multiphysics fields. The framework integrates heat equation, Maxwell's equations, and diverse boundary conditions to enable unified solutions for both electromagnetic and thermal fields. DeepONet learns transfer functions that generalize across different configurations.

## Key Novelty

First PINN-based multi-physics simulator for arbitrary 3D IC configurations that achieves 844-7600× speedup over traditional COMSOL while maintaining 97% accuracy on EM and 99.8% on thermal simulations.

## Contributions

- Physics-informed neural network architecture leveraging DeepONet for transferable multi-physics field solving
- Support for multiple PDE configurations (heat, Maxwell) with diverse boundary conditions in unified framework
- Achieves orders-of-magnitude speedup (844-7600×) over COMSOL while preserving accuracy
