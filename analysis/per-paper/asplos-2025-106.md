# asplos-2025-106: Pave: Information Flow Control for Privacy-preserving Online Data Processing Services

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
When users submit personal data to remote online services for processing, they have no technical guarantee that the service will not leak their data, because the processing logic runs in an untrusted server environment entirely outside the user's control.

## Motivation
The proliferation of data-processing web services has made it routine to hand over sensitive personal data to third-party servers; users need strong, formally verifiable privacy guarantees without trusting the service operator's software.

## Method
Pave creates a locked processing box (PaveBox) on a remote server using Intel SGX—a hardware feature that runs code in a private, tamper-proof zone. A monitor inside watches all data entering and leaving, applying information flow control rules (policies that block dangerous data movements while allowing safe ones). Allowed flows work normally to keep programs functional; blocked flows prevent user data from being exposed. The system's security is mathematically proven, and users can verify its trustworthiness through remote attestation.

## Key Novelty
A remote data-processing service that runs programs in a hardware-protected box (Intel SGX) with a monitor enforcing information flow control (rules that prevent data leaks), mathematically proven secure and verifiable through remote attestation.

## Contributions
- PaveBox: a runtime IFC monitor inside an Intel SGX enclave enforcing data-flow policies for arbitrary processing programs.
- A formal security model for Pave with proofs of privacy and functionality preservation.
- Remote attestation integration enabling users to verify PaveBox integrity before trusting the service.
- Quantitative prototype evaluation of performance overhead.
