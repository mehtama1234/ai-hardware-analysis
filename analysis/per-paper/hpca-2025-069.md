# EDA: Energy-Efficient Inter-Layer Model Compilation for Edge DNN Inference Acceleration

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Inter-layer operator scheduling on edge NPUs can reduce DRAM traffic by reusing layer outputs in on-chip SRAM, but naive deep traversal of DNN operator graphs greatly increases off-chip memory transactions when on-chip SRAM is small, negating energy savings.

## Motivation
Edge NPUs have strict price and energy budgets where DRAM accesses dominate energy; optimizing the traversal depth of inter-layer scheduling to match available on-chip memory is critical for energy-efficient deployment of DNNs.

## Method
EDA is a compiler that prepares neural networks for efficient execution on edge processors with limited on-chip memory. It breaks down the network into smaller parts and uses a cost model—a calculator estimating memory efficiency—to decide how many layers each part should process together, balancing the benefit of keeping intermediate data in fast on-chip memory against the cost of accessing slower main memory. It allocates on-chip memory carefully to prevent overflow and groups computation operations to improve how well the processor's compute units and memory are utilized. The result avoids both excessive main-memory traffic from processing too many layers together and computational waste from processing too few.

## Key Novelty
The innovation is a cost model—a mathematical calculator—that determines, for each section of a neural network, how many layers should be processed together, balancing how much intermediate data stays in fast on-chip memory against trips to slower main memory, optimized for edge processors with limited on-chip storage.

## Contributions
- EDA compilation framework with tensor-splitting and subgraph decomposition
- Inter-layer cost model for fast traversal-depth determination per subgraph
- On-chip shared memory management to prevent SRAM overflow during inter-layer scheduling
- Operator grouping method improving MAC and SRAM utilization; 2.08x energy efficiency and 2.39x performance geomean over NPU with designated memory buffers
