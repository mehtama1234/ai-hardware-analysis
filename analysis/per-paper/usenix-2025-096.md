# MARC: Motion-Aware Rate Control for Mobile E-commerce Cloud Rendering

**Problem:** Cloud rendering systems for mobile e-commerce must balance video quality, bandwidth, and latency. Static bitrate control fails to adapt to varying motion levels in video streams, wasting bandwidth on low-motion scenes or degrading quality during high-motion content.

**Method:** MARC detects motion in each video frame using optical flow (which tracks how pixels shift between frames) or frame differencing (which compares consecutive frames). Based on the detected motion, it dynamically adjusts how much data the cloud encoder sends (bitrate and resolution)—more for high-motion scenes and less for low-motion ones. The encoder uses this motion information to prioritize bandwidth for complex, fast-moving parts instead of wasting it on static scenes.

**Novelty:** The system continuously detects motion in video frames and automatically adjusts how much data (bitrate) gets sent based on that—allocating more bandwidth to motion-heavy scenes and less to static ones.
