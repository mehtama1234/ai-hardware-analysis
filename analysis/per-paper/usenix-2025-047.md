# DSA-2LM: A CPU-Free Tiered Memory Architecture with Intel DSA

**Problem:** Memory bandwidth and CPU overhead limit performance when managing data movement between multiple memory tiers. CPU-based memory management creates bottlenecks in tiered memory hierarchies requiring frequent prefetching and data placement decisions.

**Method:** DSA-2LM uses Intel's Data Streaming Accelerator (DSA)—a specialized hardware chip designed to move data—to automatically manage data across a two-level memory hierarchy without the main CPU being involved. The system uses DSA to make three key decisions: where to place each piece of data (in faster or slower memory), when to prefetch it (bringing data into faster memory before it's needed), and how to keep all copies of data matching each other across the two memory tiers. By offloading these management tasks to DSA, the CPU is freed from the overhead of constantly deciding how to move data around.

**Novelty:** DSA-2LM is the first system to use Intel's Data Streaming Accelerator to handle all tiered-memory management—data placement, prefetching, and coherence management (keeping all copies of data matching each other)—without CPU involvement.
