# DSA-2LM: A CPU-Free Tiered Memory Architecture with Intel DSA

**Problem:** Memory bandwidth and CPU overhead limit performance when managing data movement between multiple memory tiers. CPU-based memory management creates bottlenecks in tiered memory hierarchies requiring frequent prefetching and data placement decisions.

**Method:** DSA-2LM uses Intel's Data Streaming Accelerator (DSA) to autonomously manage data movement and prefetching between memory tiers without CPU involvement. The system employs DSA for intelligent data placement decisions, coherence management, and prefetch scheduling in a two-level memory hierarchy.

**Novelty:** First system to leverage Intel DSA hardware accelerator to offload all tiered memory management decisions, eliminating CPU participation in data movement and prefetch operations.
