# sc-2025-036: Umpire: Portable Memory Management for High-Performance Computing Applications

## Summary
Umpire is an open-source library providing unified memory management abstraction for HPC platforms with complex memory hierarchies. Enables portable performance across CPUs, GPUs, and emerging memory technologies.

## Problem
- Modern HPC systems have diverse memory types (DRAM, NUMA, GPU memory, HBM)
- Each memory type has different:
  - Access patterns and latency characteristics
  - Capacity constraints
  - Performance profiles
- Manual memory management across these tiers is error-prone and non-portable

## Method
Umpire provides a single, unified interface for managing memory across different types in HPC systems—whether it's CPU memory, GPU memory, or high-bandwidth memory. Instead of allocating and freeing memory piece-by-piece, Umpire uses memory pools, which pre-allocate memory in large blocks and reuse them efficiently, avoiding the overhead of constant allocation. It integrates with RAJA, a portability framework, so the same code can run across different architectures without rewriting memory management.

## Key Innovations
1. **Portable memory management**: Single API works across diverse hardware
2. **Memory pools**: Achieve significant speedups (15x+) over malloc
3. **Ecosystem integration**: Part of RAJA portability ecosystem
4. **Production-proven**: Used in real LLNL codes

## Hardware Targets
