# sc-2025-217: LangChain-Parsl - LLM Agents meet HPC

## Overview
Integration framework connecting LLM agents (LangChain) to HPC schedulers (Parsl), enabling agents to invoke large-scale scientific simulations.

## Key Problem
LLM agents can invoke external tools but lack integration with HPC job schedulers. Scientific applications need coordinated execution across distributed HPC resources.

## Approach
Two implementation strategies:
1. **Direct mapping**: Modify LangChain tool calls to Parsl functions, queue to Parsl workers
2. **Ensemble approach**: Design Parsl ensemble function as LLM tool

Test on local GPU workstations and ALCF's Polaris HPC system with molecular dynamics workflows.

## Contributions
- LangChain-Parsl middleware layer
- Two implementation patterns for tool-to-HPC integration
- Demonstration of parallel scientific tool execution
- Cross-platform validation (local GPU + HPC clusters)

## Applications
- Molecular dynamics simulations with varying parameters and conditions
- Multi-step scientific workflows

## Hardware Target
- Local GPU workstations (NVIDIA)
- HPC clusters (ALCF Polaris)
- Job-scheduled distributed systems
