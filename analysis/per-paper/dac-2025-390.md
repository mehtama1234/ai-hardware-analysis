# Rank-based Multi-objective Approximate Logic Synthesis via Monte Carlo Tree Search

**Venue:** DAC
**ID:** dac-2025-390

## Problem
Approximate logic synthesis focuses on single objectives (delay or area), leading to local optima in multi-objective optimization under error constraints.

## Motivation
Error-tolerant applications benefit from Pareto-optimal circuits; multi-objective exploration requires systematic search beyond single-objective heuristics.

## Method
The system uses Monte Carlo Tree Search (randomly sampling different options to learn which design improvements are most valuable) guided by circuit rankings that preserve options excelling at different tradeoffs rather than discarding all but one. A machine learning model predicts which local circuit modifications (small changes to improve speed or size) are most promising to try next. This enables systematic exploration of approximate circuits that balance speed, area, and acceptable error without getting stuck at a local optimum.

## Key Novelty
The core innovation is using a ranking approach that preserves competitive designs (not just one 'best' circuit) combined with Monte Carlo Tree Search to systematically explore approximate circuits optimizing for speed, area, and error constraints.

## Contributions
1. Multi-objective approximate logic synthesis framework using MCTS
2. Non-dominated circuit ranking guiding exploration of local approximate changes
3. Rank-Transformer model for path-domain rank prediction and LAC quality assessment
4. Faster and more efficient optimization in delay and area simultaneously vs SOTA methods
