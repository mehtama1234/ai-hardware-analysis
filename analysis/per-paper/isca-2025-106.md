# SWIPER: Minimizing Fault-Tolerant Quantum Program Latency via Speculative Window Decoding
**Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Parallel window decoding for fault-tolerant quantum error correction requires some decoding tasks to be delayed until preceding windows complete, creating head-of-line blocking that inflates program runtime, especially during T gate teleportation where decoding latency directly extends logical circuit depth.

## Motivation
Future fault-tolerant quantum computers require real-time decoders that meet throughput demands, but existing parallel window decoders introduce sequential data dependencies that unnecessarily lengthen program runtimes.

## Method
SWIPER predicts data dependencies between quantum error correction decoding windows (similar to branch prediction in classical CPUs) and launches multiple layers of decoding work in parallel based on these predictions, rather than waiting for earlier windows to complete. If a prediction is wrong, the system rolls back and redecodes with correct information. The system is optimized to maximize prediction opportunities, and performance is measured with a cycle-accurate simulator.

## Key Novelty
SWIPER applies speculative execution—making educated guesses about data dependencies between quantum error correction decoding windows before those dependencies are resolved—to eliminate processing delays at window boundaries.

## Contributions
- SWIPER speculative window decoder that predicts inter-window data dependencies to enable simultaneous multi-layer decoding.
- 40% average reduction in application runtime compared to prior parallel window decoders.
- Integration with a state-of-the-art fault-tolerant compilation pipeline to maximize speculation benefit.
- Detailed open-source simulator for evaluating speculative decoding strategies.
