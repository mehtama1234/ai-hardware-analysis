# CognitiveArm: Enabling Real-Time EEG-Controlled Prosthetic Arm Using Embodied Machine Learning

**Problem:** Real-time EEG processing for prosthetic control requires efficient on-device inference balancing latency, accuracy, and resource constraints.

**Method:** Integrates BrainFlow EEG library with Pareto-optimal deep learning models found via evolutionary search. Applies pruning and quantization for embedded deployment; supports voice-command mode switching.

**Key Contribution:** Embodied ML approach achieving 90% classification accuracy with real-time latency on edge hardware.

**Results:** 90% accuracy on three-class action detection; prototype with OpenBCI headset enables multi-action control.

**Tags:** eeg, brain-computer-interface, prosthetic-control, edge-ai, model-compression, embodied-ml
