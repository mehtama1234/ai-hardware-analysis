# CognitiveArm: Enabling Real-Time EEG-Controlled Prosthetic Arm Using Embodied Machine Learning

**Problem:** Real-time EEG processing for prosthetic control requires efficient on-device inference balancing latency, accuracy, and resource constraints.

**Method:** The system reads brain signals using the BrainFlow library and trains deep learning models to interpret them for prosthetic control. It searches through different combinations of settings—such as network size, learning algorithms, data window sizes, and whether to combine multiple models—using evolutionary search (testing random variations and keeping what works best) to find configurations that maintain accuracy while running on resource-limited hardware. To make these models small enough for the prosthetic device, it removes unnecessary connections from the networks (pruning) and converts numbers to lower precision (quantization). Users can switch between different control modes with voice commands.

**Key Contribution:** Embodied ML approach achieving 90% classification accuracy with real-time latency on edge hardware.

**Results:** 90% accuracy on three-class action detection; prototype with OpenBCI headset enables multi-action control.
