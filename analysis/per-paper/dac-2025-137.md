# NDFT: LR-TDDFT Acceleration via Near-Data Computing

## Problem
Linear-response time-dependent DFT (LR-TDDFT) is memory-bound with constant data movement between host and heterogeneous accelerators (GPU, FPGA, Sunway), creating substantial data movement overhead that dominates compute-optimized kernels.

## Method
NDFT reduces data-movement bottlenecks by using near-data processing—executing calculations on processing units built into the memory system instead of shipping data to distant accelerators. It splits the quantum chemistry calculation into stages and assigns each to whichever processor (CPU or on-chip unit) is most efficient for that task. The hardware and software are then co-designed: the chip's architecture and the algorithms are redesigned together, rather than separately, to further squeeze out data movement and reduce delays.

## Key Results
- 5.2x speedup over CPU baseline
- 2.5x speedup over GPU baseline
- Effective for large physical systems with reduced data movement overhead

## Technique
