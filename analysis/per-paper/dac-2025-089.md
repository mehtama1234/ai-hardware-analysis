# dac-2025-089: LightRIM: Lightweight Kernel Integrity Monitoring

**Problem:** Kernel security modules consume excessive resources unsuitable for embedded systems.

**Method:** LightRIM protects the Linux kernel (the core of the operating system) by hashing its components in two stages to create a fingerprint for detecting tampering. Instead of checking constantly and wasting CPU power, it only measures when something security-relevant changes. To stay within strict CPU budgets, it randomizes when checks happen, making it harder for attackers to time their modifications between checks and actual use (called TOCTOU vulnerabilities).

**Key Novelty:** Event-triggered measurement with CPU-constrained TOCTOU mitigation via interval randomization.

**Hardware Target:** CPU  
**Technique Category:** security  
**Workloads:** embedded-systems, security  

**Metrics:**
- Performance overhead: <0.7%

**Confidence:** low (abstract only)
