# isscc-2025-080: Diffusion Model Accelerator with Bandwidth-Aware CIM

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
CIM accelerators for diffusion models face: high OpI variance (dynamic bandwidth needs), 10x larger storage, system-level efficiency degradation despite good macro efficiency, 59% power on data access, 31% ops on multi-view/temporal attention.

## Motivation
Diffusion models enable high-quality content generation (images/3D/video) but A100 inference takes ~270s; hardware acceleration essential for practical deployment.

## Method
The 22nm accelerator performs calculations directly in memory (compute-in-memory or CIM) instead of moving data back and forth, saving power. It splits memory into sections that match each layer's actual data needs (bandwidth-aware partitioning) and divides memory access paths using bit-line segmentation, keeping data local and reducing movement. These optimizations especially help tasks requiring multi-view or temporal attention—comparing multiple camera angles or frames over time—which are common in 3D and video generation.

## Key Novelty
It solves the problem of varying data needs across layers by using bandwidth-aware memory partitioning and bit-line segmentation in compute-in-memory, which cuts data-access power without sacrificing computational efficiency.

## Contributions
- 60.81 TFLOPS/W energy efficiency
- Bandwidth-aware partitioning matching layer OpI
- BL-segmented CIM macros
- Multi-view/temporal attention operators
