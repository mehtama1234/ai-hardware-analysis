# SegTransformer: Enhancing Softmax Performance Through Segmentation with a ReRAM-Based PIM Accelerator

**Venue**: DATE  
**Primary Theme**: ReRAM PIM accelerator with segmented softmax  

## Problem
ReRAM-based PIM Transformer accelerators shift performance bottleneck from matrix multiplication to softmax computation; data sharding prevents global softmax normalization.

## Method
Segmentation techniques applied within ReRAM-based PIM architecture improve softmax computation accuracy and throughput while maintaining precision.

## Key Novelty
Segmentation-based softmax optimization specifically designed for ReRAM PIM accelerator constraints.

## Contributions
- SegTransformer ReRAM-based PIM accelerator design
- Segmentation technique for softmax enhancement
- High-accuracy softmax computation in PIM architecture
- Outperforms SOTA Transformer accelerators
