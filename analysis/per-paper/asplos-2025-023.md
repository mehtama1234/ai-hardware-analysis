# SmoothE: Differentiable E-Graph Extraction

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** differentiable e-graph extraction for scalable compiler optimization

## Problem
E-graph extraction suffers from an unfavorable scalability-quality trade-off: exact methods are slow, fast heuristics are suboptimal, and current methods only support simple linear cost functions—limiting use for realistic optimization objectives.

## Motivation
E-graphs are increasingly used in compilers and program synthesis; extraction quality directly determines the quality of the optimized output, and existing extractors bottleneck the usefulness of equality saturation for complex real-world cost models.

## Method
SmoothE formulates e-graph extraction as a continuous differentiable optimization by relaxing the discrete node-selection problem to a smooth objective over real-valued weights. Gradient-based optimization is applied to find the optimal extraction, enabling arbitrary differentiable cost functions including learned neural cost models. The relaxation is designed so the continuous optimum closely corresponds to a valid discrete extraction.

## Key Novelty
Reformulating e-graph extraction as a differentiable continuous optimization problem, enabling gradient-based search and support for arbitrary differentiable cost functions beyond simple linear models.

## Contributions
- SmoothE: a differentiable relaxation of the e-graph extraction problem
- Support for non-linear and learned (neural) cost models in e-graph extraction
- Improved scalability-quality trade-off vs. existing exact and heuristic extractors
- Applicability to compiler optimization, program synthesis, and theorem proving
