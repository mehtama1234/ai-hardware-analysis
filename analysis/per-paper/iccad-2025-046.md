# Augmented Co-Simulation for Fast Functional and System-Level Verification of HLS Accelerators

**Venue:** ICCAD | **ID:** iccad-2025-046

## Problem
Manual co-simulation for HLS accelerators is error-prone, requires low-level testbenches, and involves slow RTL simulation. Cannot capture host-accelerator interaction. Hinders design space exploration.

## Motivation
Speed up and simplify verification of HLS-generated accelerators to enable practical early design exploration.

## Method
Proposes two augmented co-simulation components: (1) fast functional simulation calculating clock cycles on annotated HLS IR avoiding RTL simulation bottleneck, (2) system-level co-simulation coupling RTL simulation with host software via direct programming interfaces and inter-process communication. Both enable quick kernel extraction, performance prediction, and full system correctness validation.

## Key Novelty
Augmented HLS co-simulation combining fast functional-level simulation with full system-level simulation through IPC.

## Contributions
- Fast functional simulation methodology on annotated HLS IR with high accuracy
- System-level co-simulation framework coupling RTL with host application execution
- Integrated augmented verification within HLS tools enabling automatic correctness validation
