# Augmented Co-Simulation for Fast Functional and System-Level Verification of HLS Accelerators

**Venue:** ICCAD | **ID:** iccad-2025-046

## Problem
Manual co-simulation for HLS accelerators is error-prone, requires low-level testbenches, and involves slow RTL simulation. Cannot capture host-accelerator interaction. Hinders design space exploration.

## Motivation
Speed up and simplify verification of HLS-generated accelerators to enable practical early design exploration.

## Method
It uses two simulation techniques working together. First, it calculates how many clock cycles the accelerator code will take by analyzing the high-level code directly—this skips the slow step of simulating every hardware detail gate-by-gate. Second, it runs the actual hardware simulation connected to the real host software that will use it, using inter-process communication (direct connections between programs) to pass data between them. This combination lets engineers quickly test accelerator functions, predict their speed accurately, and verify the entire system works correctly without rebuilding hardware repeatedly.

## Key Novelty
The core idea is combining fast performance prediction from high-level code analysis with complete hardware-software system simulation through inter-process communication.

## Contributions
- Fast functional simulation methodology on annotated HLS IR with high accuracy
- System-level co-simulation framework coupling RTL with host application execution
- Integrated augmented verification within HLS tools enabling automatic correctness validation
