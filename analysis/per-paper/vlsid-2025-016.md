# LO-SC: Local-Only Split Computing for Accurate Deep Learning on Edge Devices

**Venue:** VLSID

## Problem
DNNs on edge devices sacrifice accuracy or require unreliable server communication

## Motivation
Cloud offloading incurs latency/cost; on-device solutions degrade accuracy; need accuracy-preserving local execution

## Method
Formalize DNN splitting as MILP; solve via multi-constrained ordered knapsack algorithm for local-only execution

## Key Novelty
Local-Only Split Computing (LO-SC) preserves accuracy while executing entirely on-device without server dependency

## Contributions
- LO-SC framework as MILP formulation
- Knapsack-based solver
- On-device accuracy maintenance
