# LO-SC: Local-Only Split Computing for Accurate Deep Learning on Edge Devices

**Venue:** VLSID

## Problem
DNNs on edge devices sacrifice accuracy or require unreliable server communication

## Motivation
Cloud offloading incurs latency/cost; on-device solutions degrade accuracy; need accuracy-preserving local execution

## Method
The approach models splitting a neural network between device and server as a mathematical optimization problem (Mixed Integer Linear Programming, or MILP). To solve this, they use an algorithm based on the knapsack problem—the classic technique for fitting different-sized items into a limited container—adapted to handle multiple constraints (like memory and computation speed limits) while respecting which network components must execute in order. This finds a way to keep the entire neural network running on just the edge device.

## Key Novelty
Local-Only Split Computing (LO-SC) runs the complete neural network on the edge device, preserving accuracy without any need for server communication.
