# GenEDA: Towards Generative Netlist Functional Reasoning via Cross-Modal Circuit Encoder-Decoder Alignment

**ID:** iccad-2025-044  
**Venue:** ICCAD

## Problem
Existing circuit foundation models are limited to standalone encoders or decoders, operating on different circuit modalities and separate latent spaces, preventing complementary capability development.

## Motivation
Foundation models tailored for IC design can accelerate automation if they unify multiple modalities and reasoning capabilities.

## Method
GenEDA presents first framework cross-modally aligning circuit encoders with decoders in shared latent space, bridging graph-based circuit representation learning and text-based LLMs. Provides two paradigms supporting both trainable and frozen commercial LLMs.

## Key Novelty
Cross-modal encoder-decoder alignment enabling LLMs to directly reason over low-level bit-blasted netlists and generate high-level specifications.

## Contributions
1. First cross-modal encoder-decoder alignment framework for circuits
2. Shared latent space bridging graph and text modalities
3. Support for both trainable and frozen commercial LLMs
4. First generative foundation model for netlists enabling netlist-to-spec generation
5. Significant performance boost on LLMs (GPT, DeepSeek) for functional reasoning tasks
