# SC-2025-417: MetoHash - Memory-Efficient Indexing for Hybrid PMem-DRAM

## Summary
MetoHash optimizes hashing indexes for hybrid persistent memory (PMem) and DRAM systems through staged insertion and traffic-aware fingerprinting, achieving 86-257% throughput improvement.

## Problem
Existing PMem-aware hashing indexes suffer from traffic amplification between memory tiers and inefficient memory utilization, negating the benefits of persistent memory's high capacity.

## Method
- **Three-layer index structure**:
  - Layer 1: CPU caches for fast inserts
  - Layer 2: DRAM for arrangement
  - Layer 3: PMem for persistence
- **Staged insertion**: Aggregates inserts in caches, flushes to DRAM/PMem in batches
- **Fingerprinting**: Reduces unnecessary probing into PMem
- **Duplicate elimination**: Removes duplicates during bucket relocations

## Key Results
- 86.1-257.6% throughput improvement over state-of-the-art PMem indexes
- Across various workloads
- Effective traffic reduction between memory tiers
