# Piccolo: Large-Scale Graph Processing with Fine-Grained in-Memory Scatter-Gather

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Graph processing requires irregular fine-grained random memory accesses incompatible with DDR memory access granularity, leading to massive bandwidth waste and cache capacity waste; existing approaches using graph tiling (maximizing on-chip reuse) or PIM (placing arithmetic near memory) each have limitations when implemented with DDR standards, and combining them is difficult.

## Motivation
Graph processing is extremely memory-bound due to random access patterns at sub-cache-line granularity, and neither tiling nor PIM alone adequately addresses both the bandwidth waste from DDR granularity mismatch and the flexibility needed for diverse graph operations.

## Method
Piccolo implements non-arithmetic function-in-memory focused specifically on fine-grained random scatter-gather operations in off-chip memory, avoiding expensive arithmetic units inside DRAM. The accelerator's cache and miss-handling architecture (MHA) are redesigned to work compatibly with in-memory scatter-gather, enabling both graph tiling (on-chip data reuse) and in-memory operations simultaneously. The scatter-gather function-in-memory reduces off-chip traffic without requiring the expensive multi-operation support that makes traditional PIM impractical.

## Key Novelty
Placing only non-arithmetic scatter-gather function-in-memory rather than full arithmetic units, enabling cost-effective fine-grained random access reduction while preserving compatibility with graph tiling through a redesigned cache and MHA.

## Contributions
1. Piccolo: graph processing accelerator with fine-grained in-memory scatter-gather (non-arithmetic function-in-memory)
2. Redesigned cache and miss-handling architecture enabling simultaneous tiling and in-memory scatter-gather benefits
3. Avoidance of expensive arithmetic-in-memory while still reducing off-chip traffic from DDR granularity mismatch
4. Up to 3.28x speedup (1.62x geomean) and up to 59.7% energy reduction across graph processing benchmarks
