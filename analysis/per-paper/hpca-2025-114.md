# hpca-2025-114: RpcNIC: Enabling Efficient Datacenter RPC Offloading on PCIe-attached SmartNICs

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
RPC processing has become a dominant datacenter tax in microservice/serverless environments, but existing RPC accelerators either integrate logic into the CPU or use specialized low-latency interconnects unavailable in commodity servers, preventing broad deployment.

## Motivation
As networking speeds rise and software stacks grow more complex, RPC serialization/deserialization overhead consumes an ever-larger fraction of CPU cycles, creating a compelling case for PCIe-attached SmartNIC offload if its inherent PCIe bandwidth and latency challenges can be overcome.

## Method
RpcNIC combines hardware and software on a Xilinx U280 FPGA (a reprogrammable smart network interface) to speed up RPC messaging by reducing PCIe bottlenecks. It uses three techniques: batching writes to the FPGA's fast memory with compact data structures to cut PCIe transfers, collaborating between the CPU and network interface to keep data on the CPU side instead of copying over PCIe, and automatically reconfiguring RPC message encoding when applications change so unchanged fields avoid crossing PCIe.

## Key Novelty
Three PCIe-aware optimization strategies enable commodity PCIe-attached SmartNICs to match the performance of specialized RPC accelerators with custom interconnects for datacenter workloads.

## Contributions
- Target-aware deserializer with compacted SRAM data structures for batched cross-PCIe writes
- Memory-affinity collaborative serializer trading host copies for slow PCIe transfers
- Automatic field update technique for reconfigurable RPC kernel schema with minimal PCIe overhead
- 2.3x lower RPC processing time and 2.6x throughput over comparable RPC accelerator on HyperProtoBench
