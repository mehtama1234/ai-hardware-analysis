# M-ANT: Efficient Low-bit Group Quantization for LLMs via Mathematically Adaptive Numerical Type

**Venue:** HPCA 2025  
**Authors:** Weiming Hu, Haoyan Zhang, Cong Guo, Yu Feng, Renyang Guan, Zhendong Hua, Zihan Liu, Yue Guan

## Problem
Existing adaptive data types for LLM group quantization provide adaptivity at the tensor level, but small quantization groups within the same tensor exhibit markedly different distributions that tensor-level formats cannot accommodate. Additionally, dynamically generated KV caches require efficient real-time quantization that existing approaches do not support well.

## Motivation
Group-wise quantization has become the standard for LLM deployment, but the group-level distribution diversity demands a new level of per-group adaptivity to minimize accuracy loss at ultra-low bit widths.

## Method
MANT defines a mathematically adaptive numeric type with a flexible encoding paradigm covering a wider range of data distributions than prior adaptive types. A hardware framework assigns the appropriate MANT variant to each quantization group dynamically. A dedicated PE fuses decoding and computation, and a real-time quantization unit handles dynamic KV cache quantization. These PEs are integrated into a systolic array, unifying weight and KV cache quantization in a single datapath.

## Key Novelty
A per-group adaptive numeric type with a decoding-computation fusion mechanism that simultaneously handles both weight quantization and real-time KV cache quantization in a systolic array accelerator.

## Contributions
- MANT adaptive numeric type with flexible encoding and wider distribution coverage than prior adaptive types
- Group-level adaptive assignment framework that selects the appropriate data type per quantization group
- Real-time quantization unit for dynamic KV cache quantization
- Systolic-array PE design with decoding-computation fusion achieving 2.99x average speedup and 2.81x energy reduction

## Results
- **Speedup:** 2.99x average (up to 4.46x) over state-of-the-art LLM accelerator
- **Energy:** 2.81x average (up to 4.10x) energy reduction

## Hardware Target
ASIC (systolic array)
