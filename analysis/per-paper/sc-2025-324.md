# Connected-Component Labeling Using HLS for High-Energy Particle Physics Instruments

**Venue:** SC
**ID:** sc-2025-324
**Confidence:** low

## Problem Statement
High-level synthesis (HLS) can reduce FPGA development time, but effectiveness for complex signal processing kernels (like island detection) is unclear.

## Motivation
Particle physics instruments use FPGAs for front-end processing; HLS promises productivity gains but must validate performance and resource efficiency on realistic kernels.

## Method
HLS implementation of island detection with 1D/2D configurations and 4-way/8-way connected-component labeling; report resource usage, throughput, and required optimizations.

## Key Novelty
Empirical evaluation of HLS effectiveness for particle physics signal processing, identifying optimizations needed for high-throughput implementations.

## Contributions
1. HLS island detection implementation for gamma-ray telescopes
2. 4-way CCL at 15k 43x43-pixel images/second
3. Resource usage and optimization requirements
