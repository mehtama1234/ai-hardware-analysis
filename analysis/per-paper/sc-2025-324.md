# Connected-Component Labeling Using HLS for High-Energy Particle Physics Instruments

**Venue:** SC
**ID:** sc-2025-324
**Confidence:** low

## Problem Statement
High-level synthesis (HLS) can reduce FPGA development time, but effectiveness for complex signal processing kernels (like island detection) is unclear.

## Motivation
Particle physics instruments use FPGAs for front-end processing; HLS promises productivity gains but must validate performance and resource efficiency on realistic kernels.

## Method
They implemented island detection—an algorithm that groups neighboring particle signals together—using high-level synthesis (HLS), a tool that converts high-level code into FPGA hardware. They tested different data layouts (1D and 2D) and neighbor-detection rules (4-way or 8-way connectivity, where 8-way includes diagonal neighbors). They then measured resource usage, throughput, and identified which code optimizations were necessary for high-speed operation.

## Key Novelty
This work shows whether high-level synthesis is actually practical for the complex, high-speed signal processing required in particle physics experiments, and identifies which code optimizations are essential.

## Contributions
1. HLS island detection implementation for gamma-ray telescopes
2. 4-way CCL at 15k 43x43-pixel images/second
3. Resource usage and optimization requirements
