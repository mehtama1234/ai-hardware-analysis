# ZRAID: Leveraging Zone Random Write Area (ZRWA) for Alleviating Partial Parity Tax in ZNS RAID

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
ZNS RAID partial parity for incomplete stripes is logged in reserved zones, creating throughput bottlenecks and write amplification that reduce device lifetime.

## Motivation
ZNS SSDs reduce conventional block-interface overhead, but RAID construction introduces a "partial parity tax" negating key efficiency benefits.

## Method
ZRAID uses the Zone Random Write Area (ZRWA) — a small in-device random-write buffer in ZNS SSDs — as a transient parity staging area. Partial parity is buffered in ZRWA until a full stripe is complete, then committed sequentially to zones, eliminating reserved-zone logging and its associated write amplification.

## Key Novelty
Using ZNS ZRWA buffers for in-device transient partial parity staging, eliminating reserved-zone bottlenecks in ZNS RAID.

## Contributions
- Characterization of the partial parity tax problem in ZNS RAID
- ZRAID design exploiting ZRWA for partial parity staging
- Elimination of reserved-zone throughput bottleneck and write amplification
