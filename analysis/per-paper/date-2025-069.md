# Efficient Approximate Logic Synthesis with Dual-Phase Iterative Framework

**Venue**: DATE  
**Primary Theme**: accelerated approximate synthesis  

## Problem
Accelerating approximate logic synthesis for error-tolerant applications while maintaining circuit quality. ALS runtime grows rapidly as circuit size increases, offsetting energy efficiency benefits of approximation.

## Method
Dual-phase iterative framework: Phase 1 performs comprehensive circuit analysis including error characterization. Phase 2 employs minimal incremental computation leveraging Phase 1 information.

## Key Novelty
Separating comprehensive analysis from incremental computation enables rapid re-optimization with minimal computational overhead.

## Contributions
- 21.8x acceleration vs state-of-the-art without quality loss
- Dual-phase framework reducing incremental computation per iteration
- Scalable synthesis for large approximate circuits
