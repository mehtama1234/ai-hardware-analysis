# A Partitioning-Based CAD Flow for Interposer-Based Multi-Die FPGAs

**Problem:** Multi-die interposer-based FPGA architectures face limited inter-die connectivity resources and increased interposer delays compared to intra-die routing, which directly impact routability, routed wirelength, and maximum clock frequency.

**Method:** FPGAPart divides circuit netlists (descriptions of how components connect) into smaller chunks while minimizing signal propagation delay—the core goal of timing-driven optimization. Built for FPGAs and integrated with VTR 7.0, it starts with grouping hints from VTR, then applies the FP-Growth algorithm to find repeating patterns across timing-critical paths, improving component clustering. To speed up the mathematical solver (ILP—a method for finding optimal solutions), it adds 'neighborhood influences-based cutting planes'—constraints linking nearby sections to narrow the search space.

**Novelty:** FPGAPart is the first open-source timing-driven netlist partitioner for FPGAs, using 'neighborhood influences-based cutting planes' (constraints linking nearby circuit sections) to achieve 38× faster optimization with less than 1% quality loss.
