# Rhea: a Framework for Fast Design and Validation of RTL Cache-Coherent Memory Subsystems

**Venue:** ICCAD  
**ID:** iccad-2025-280

## Problem
Designing and validating efficient cache-coherent memory subsystems is complex; there is a gap between high-level simulation fidelity and the reality of RTL hardware implementations.

## Motivation
To enable fast design iteration and system-level validation by bridging the gap between gem5 full-system simulation and actual RTL hardware with realistic workloads.

## Method
Unified framework generating synthesizable, highly configurable RTL supporting various architectural parameters; integrates Verilator's cycle-accurate RTL simulation with gem5's full-system simulation enabling realistic workloads and operating systems to run alongside actual RTL under test. Hybrid co-simulation approach for improved fidelity over pure simulation.

## Key Novelty
Gem5-Verilator co-simulation flow enabling realistic workload validation on RTL cache-coherent memory subsystems.

## Contributions
- RTL generation framework for configurable cache-coherent memory subsystems
- Gem5-Verilator hybrid co-simulation infrastructure
- Demonstration with MSI-based RTL systems up to 16 cores
- Validation with 22 applications from SPEC 2017 and state-of-the-art benchmark suites

## Limitations
The simulation overhead scales with system size; scalability to larger systems and more complex coherence protocols remains to be demonstrated.
