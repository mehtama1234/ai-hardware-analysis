# Rhea: a Framework for Fast Design and Validation of RTL Cache-Coherent Memory Subsystems

**Venue:** ICCAD  
**ID:** iccad-2025-280

## Problem
Designing and validating efficient cache-coherent memory subsystems is complex; there is a gap between high-level simulation fidelity and the reality of RTL hardware implementations.

## Motivation
To enable fast design iteration and system-level validation by bridging the gap between gem5 full-system simulation and actual RTL hardware with realistic workloads.

## Method
The framework generates synthesizable hardware designs (RTL) that support various architectural configurations. It connects two simulators—Verilator, which simulates the hardware design cycle-by-cycle as it would run, and gem5, which can run realistic software workloads and operating systems. Running both simulators together (called co-simulation) gives you better accuracy than using either alone, because you're testing the actual hardware design against realistic workloads instead of simplified scenarios.

## Key Novelty
The core innovation is connecting a realistic-workload simulator (gem5) to a cycle-accurate hardware simulator (Verilator) so you can validate memory system designs by testing actual hardware descriptions against realistic software before building chips.

## Contributions
- RTL generation framework for configurable cache-coherent memory subsystems
- Gem5-Verilator hybrid co-simulation infrastructure
- Demonstration with MSI-based RTL systems up to 16 cores
- Validation with 22 applications from SPEC 2017 and state-of-the-art benchmark suites
