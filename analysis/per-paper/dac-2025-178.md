# MARIO: A Superadditive Multi-Algorithm Interworking Optimization Framework for Analog Circuit Sizing

**Problem:** Analog circuit sizing has diverse optimization landscapes; single algorithms sub-optimal across circuit families.

**Solution:** Multi-algorithm portfolio with dynamic adaptation via Gaussian process regression and resource reallocation.

**Results:** Superadditive optimization performance; outperforms state-of-the-art algorithm-combining tools.

**Theme:** Adaptive multi-algorithm optimization for analog design.
