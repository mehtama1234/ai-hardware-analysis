# GeneralSparse: Bridging the Gap in SpMM for Pruned Large Language Model Inference on GPUs

**Problem:** Sparse Matrix-Matrix Multiplication (SpMM) kernels for GPU inference struggle to efficiently handle the irregular sparsity patterns produced by pruning in Large Language Models. Existing sparse libraries either target fixed sparsity structures or revert to dense computation, failing to bridge pruning efficiency with practical GPU performance.

**Method:** GeneralSparse builds an efficient sparse matrix multiplication (SpMM) system that handles pruned neural networks, where weights are zeroed to compress the model. Rather than assuming all networks have the same sparsity pattern, it analyzes the specific pattern during inference and automatically selects the fastest computation method, arranges data efficiently in GPU memory, and compiles the calculation on-the-fly to maintain speed across varying sparsity densities and granularities.

**Novelty:** A sparse multiplication engine that adapts to any irregular pattern from pruning without requiring fixed structure types or reverting to dense computation.
