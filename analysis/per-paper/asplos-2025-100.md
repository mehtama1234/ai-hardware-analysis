# asplos-2025-100: Vela: A Virtualized LLM Training System with GPU Direct RoCE

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
LLM training at scale typically requires dedicated bare-metal GPU clusters with specialized interconnects, but deploying training on cloud-native virtualized infrastructure using commodity hardware and standard Ethernet-based RDMA (RoCE) introduces performance challenges from virtualization overhead and suboptimal network stack interactions.

## Motivation
Making LLM training infrastructure accessible on commodity cloud hardware (RDMA over Converged Ethernet, KVM virtualization) broadens access and reduces cost, but achieving acceptable efficiency requires careful co-design of the virtualization and network layers.

## Method
Vela uses Linux KVM-based virtualization with SRIOV-based network interfaces to enable GPU-to-GPU peer-to-peer DMA (GPU Direct) across VMs without passing through the host CPU. VMs are connected via a virtualized RoCE network built from off-the-shelf NICs. The system was deployed on NVIDIA A100 GPUs in IBM Cloud, using model parallelism for a 50B-parameter decoder model at ~1500 GPU scale, and insights from 2.5 years of production operation guide architectural recommendations.

## Key Novelty
Demonstrating that GPU Direct RoCE with KVM virtualization and SRIOV can achieve approximately 80% of ideal LLM training throughput at 1500-GPU scale using entirely commodity, off-the-shelf hardware.

## Contributions
- A production-scale cloud-native LLM training system architecture using KVM virtualization, SRIOV NICs, and GPU Direct RoCE.
- ~80% of ideal throughput training a 50B-parameter model at ~1500 GPU scale; ~70% per-GPU FLOPS vs. single-VM HPL.
- 2.5 years of operational insights on designing, building, and operating virtualized AI infrastructure.
- Identification of bottlenecks and improvement opportunities for future virtualized AI systems.
