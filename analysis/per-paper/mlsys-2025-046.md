# AI Metropolis: Scaling Large Language Model-based Multi-Agent Simulation with Out-of-order Execution

**ID:** mlsys-2025-046 | **Venue:** MLSYS 2025

## Problem
LLM-powered multi-agent simulations use global step-wise synchronization that creates false dependencies between spatially distant agents with no real interaction, limiting concurrency to ~1.94 avg concurrent queries out of 25 agents (95% of time is LLM inference).

## Method
AI Metropolis introduces out-of-order execution for multi-agent simulation. A spatiotemporal dependency graph tracks real read-after-write dependencies based on agents' perception radius and movement speed; agents are coupled only when spatially close. A controller process dispatches ready clusters (groups of coupled agents) via priority queues sorted by simulation step, allowing fast agents to advance ahead. Workers update the dependency graph in Redis with transactional updates. The controller critical path is implemented in C++.

## Key Novelty
Out-of-order execution scheduling for LLM multi-agent simulation based on spatial-temporal dependency tracking, eliminating false dependencies while preserving temporal causality.

## Results
- **1.3x-4.15x** speedup over parallel-sync global synchronization baseline
- Approaches oracle performance at 500 agents (97% of oracle on 8 GPUs)
- Evaluated: Llama-3 8B (L4 GPUs), Llama-3 70B (A100 GPUs), Mixtral 8x7B
- Baselines: single-thread, parallel-sync, oracle

## Hardware Target
NVIDIA L4 GPUs, NVIDIA A100 GPUs; LLM inference via SGLang
