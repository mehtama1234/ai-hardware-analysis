# VLSID 2025-044: SGX Static vs Dynamic Memory Optimization

## Summary
Profile-guided optimizer (Harmony) for Intel SGX applications analyzing static vs dynamic memory allocation impact. Achieves 68% latency improvement over purely dynamic and 29% over purely static allocation.

## Problem
Intel SGX enclaves must balance static memory (allocated at creation) and dynamic memory (allocated at runtime). Inappropriate allocation strategy causes severe performance degradation due to expensive page swapping in enclave.

## Method
- Profile-guided optimization framework (Harmony)
- Measures dynamic memory management performance impact
- Suggests near-optimal static/dynamic distribution
- Analysis of memory allocation strategies
- Enclave memory management instrumentation

## Key Results
- **68% latency improvement** vs purely dynamic allocation
- **29% latency improvement** vs purely static allocation
- Near-optimal memory distribution recommendations
- Applicability to SGX applications

## Applications
- SGX-based cloud applications
- Security-sensitive software
- Confidential computing systems
- Privacy-preserving applications

## Limitations
- Limited to Intel SGX (not ARM TrustZone, AMD SEV, etc.)
- Profiling overhead not discussed
- Generalization to other TEEs unclear
- Single platform evaluation (Intel CPUs)
- Application diversity of test cases not specified

## Hardware Targets
- Intel SGX-enabled CPUs
- Cloud computing platforms
- Confidential computing systems

## Analysis Notes
**Confidence: LOW** (abstract only)

Practical contribution addressing real SGX performance challenge. The 68% latency improvement over naive dynamic allocation is substantial and directly applicable to production SGX applications. The insight that static allocation needs careful tuning is valuable for developers. However, the paper is specific to SGX—generalization to other TEE implementations (increasingly important) would strengthen impact.
