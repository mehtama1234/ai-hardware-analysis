# sc-2025-037: Experience Deploying Containerized GenAI Services at an HPC Center

## Summary
Experience report on deploying containerized GenAI services (specifically Llama LLM with vLLM inference server) at an HPC center. Describes converged architecture bridging traditional HPC and cloud (Kubernetes) practices.

## Problem
- GenAI applications require specialized components: inference servers, databases, APIs
- These components are cloud-native (containerized, Kubernetes-based)
- HPC centers traditionally run batch scientific workloads
- Integrating cloud/GenAI patterns with HPC infrastructure requires new approaches

## Method
1. **Architecture**: Converged HPC-Kubernetes platform
2. **Case study**: Deploy Llama LLM using vLLM inference server
3. **Evaluation**: Test across:
   - Kubernetes platform
   - HPC platform
   - Multiple container runtimes
4. **Assessment**: Reproducibility, integration, operational aspects

## Key Innovations
1. **Converged architecture**: Unified platform for HPC + cloud workloads
2. **Multi-runtime evaluation**: Assess container runtime compatibility
3. **Practical deployment**: Real-world integration experience

## Hardware Targets
- HPC GPU clusters (NVIDIA)
- Kubernetes clusters (containerized)
- GPU inference servers

## Results (from abstract)
- Successful deployment of Llama LLM via vLLM on both platforms
- Multiple container runtimes work
- Reproducibility benefits from containerization
