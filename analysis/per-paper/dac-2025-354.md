# SpecASR: Accelerating LLM-based Automatic Speech Recognition via Speculative Decoding

**Venue:** DAC  
**ID:** dac-2025-354

## Problem
LLM-based ASR suffers from high decoding latency due to autoregressive generation; existing speculative decoding ignores ASR-specific characteristics.

## Motivation
LLM-based ASR offers high accuracy but decoding latency is critical bottleneck for real-time speech recognition.

## Key Innovation
Audio-conditioned draft generation exploiting alignment between small/large ASR models, with adaptive sequence length and recycling to minimize draft model overhead.

## Method
Leverages audio-conditioned generation with high output alignment between models; features adaptive draft generation, draft recycling, and two-pass sparse token tree generation to balance latencies.

## Contributions
- Observation of high output alignment in audio-conditioned ASR
- Adaptive draft sequence generation with dynamic length tuning
- Draft sequence recycling strategy
- Two-pass sparse token tree generation for latency balancing
- 3.04x-3.79x speedup vs baseline, 1.25x-1.84x vs SOTA

## Results
3.04x-3.79x speedup over autoregressive decoding, 1.25x-1.84x over SOTA speculative decoding, with no accuracy loss.
