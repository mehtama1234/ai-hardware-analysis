# DBC: Drift-aware Binary Code for Drift-tolerant Deep Neural Networks

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
PCM conductance drift degrades DNN accuracy over time when weights are stored in multi-level PCM cells.

## Key Idea
Novel binary code (DBC) maps smaller values to low-error PCM levels and shifts values downward on drift, leveraging DNN tolerance of weight decrease over increase.

## Method
Drift-aware Binary Code (DBC) is a binary encoding scheme that makes neural networks resistant to phase change memory's conductance drift—the gradual degradation of memory cell performance over time. It maps smaller decimal values to the most stable levels in the memory cells, so when drift occurs, stored values naturally decrease rather than increase. This works because neural networks tolerate weight reductions much better than weight increases, so storing the most important network weights at the most stable levels keeps accuracy consistent over years of use. The approach requires no additional hardware and works seamlessly with existing error correction codes.

## Contributions
1. Drift-aware binary code specifically for PCM reliability
2. Magnitude-based encoding strategy
3. 55.18x drift-tolerance improvement vs. conventional code
