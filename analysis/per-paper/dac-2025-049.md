# DBC: Drift-aware Binary Code for Drift-tolerant Deep Neural Networks

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
PCM conductance drift degrades DNN accuracy over time when weights are stored in multi-level PCM cells.

## Key Idea
Novel binary code (DBC) maps smaller values to low-error PCM levels and shifts values downward on drift, leveraging DNN tolerance of weight decrease over increase.

## Method
- Magnitude-aware value-to-level mapping
- Smaller decimals → less error-prone PCM levels
- Encoding ensures drift causes value decrease, not increase
- Zero hardware overhead; compatible with ECC

## Contributions
1. Drift-aware binary code specifically for PCM reliability
2. Magnitude-based encoding strategy
3. 55.18x drift-tolerance improvement vs. conventional code
