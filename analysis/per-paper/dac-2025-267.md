# Image-Graph Heterogeneous Fusion for IR Drop Prediction

**Venue:** DAC | **ID:** dac-2025-267

## Problem
IR drop analysis is computationally expensive at ultra-deep-submicron scales. Current CNN-based methods neglect PDN global spatial features and cell-instance topology.

## Key Innovation
Dual-branch CNN-GNN architecture (IGHF) integrating spatial power features with topological PDN information for superior IR drop prediction accuracy.

## Method
The framework uses two neural networks working in parallel. The first (CNN—a network that processes information like images) analyzes power distribution as spatial patterns at multiple scales, blending fine details with broad system-wide effects through modules called LLE and HACG in Power ScaleFusion UNet; the second (GNN—a network designed for graphs and connections) captures how voltage propagates through the power network's topology by gathering information from connected neighbors via a CVA module. Transfer learning enables the model to quickly adapt to new circuits using only a few examples.

## Results
- **24.6% error reduction** vs. MAUNet
- **55.0% error reduction** vs. IREDGe
- Higher structural fidelity in prediction maps
- Transfer learning improves real circuit accuracy
