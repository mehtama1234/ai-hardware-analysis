# Image-Graph Heterogeneous Fusion for IR Drop Prediction

**Venue:** DAC | **ID:** dac-2025-267

## Problem
IR drop analysis is computationally expensive at ultra-deep-submicron scales. Current CNN-based methods neglect PDN global spatial features and cell-instance topology.

## Key Innovation
Dual-branch CNN-GNN architecture (IGHF) integrating spatial power features with topological PDN information for superior IR drop prediction accuracy.

## Method
**CNN Branch (Power ScaleFusion UNet):**
- Long-range Local-detail Encoder (LLE): multi-scale spatial power extraction
- Hierarchical Adjacent Compensation Group (HACG): adaptive high-to-low feature fusion

**GNN Branch:**
- Cell Voltage Aware (CVA) module: aggregates PDN topological features from heterogeneous neighbors

**Transfer Learning:** Few-shot real circuit adaptation

## Results
- **24.6% error reduction** vs. MAUNet
- **55.0% error reduction** vs. IREDGe
- Higher structural fidelity in prediction maps
- Transfer learning improves real circuit accuracy

## Techniques
Dataflow optimization, circuit design, machine learning (CNN+GNN)

## Limitations
Evaluation on specific datasets; generalization to diverse technologies/design styles not fully explored.
