# SC-2025-306: Reduction-Aware Directive-Based Programming via Multi-Dimensional Homomorphisms

## Summary
This work introduces a novel directive-based programming model grounded in Multi-Dimensional Homomorphisms (MDH) formalism, specifically designed for reduction-heavy tensor computations. The approach provides portable performance across CPUs and GPUs while maintaining programmer productivity through Python integration and high-level abstractions.

## Key Contributions
1. **MDH-based directive specification** for data-parallel tensor expressions
2. **Portable performance** across Intel CPUs (MKL/oneMKL) and NVIDIA GPUs (cuBLAS/cuDNN)
3. **Performance results**: 5x speedups on CPUs, 2x on GPUs vs. vendor libraries
4. **Python host language** enabling enhanced programmer productivity

## Technical Approach
- Multi-Dimensional Homomorphisms formalism for expressing reductions
- Directive-based abstraction layer over tensor operations
- Portable collective communication via OMPCCL
- Compiler backend targeting both CPU and GPU architectures

## Hardware & Systems
- Multi-core CPUs (Intel Xeon with MKL support)
- NVIDIA GPUs (with cuBLAS/cuDNN support)
- Heterogeneous CPU-GPU systems

## Workloads & Evaluation
- **Applications**: Linear algebra, stencil computations, data mining, quantum chemistry, deep learning
- **Comparison**: Against OpenMP, OpenACC, Intel MKL/oneMKL, NVIDIA cuBLAS/cuDNN
- **Performance metrics**: 5x CPU speedup, 2x GPU speedup

## Limitations & Future Work
- Speedup claims require validation against latest vendor library versions
- Specific GPU models and generations not detailed in abstract
- Generalization to non-reduction tensor operations not addressed
- Memory efficiency and scalability to distributed systems not discussed
- Overhead of MDH abstraction layer vs. direct library calls not quantified
