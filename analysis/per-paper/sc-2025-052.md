**ID:** sc-2025-052

## Problem

## Motivation
Support SC25 Reproducibility Initiative; validate numerical method artifact

## Method
The team ran the Implicitly Restarted Arnoldi Method—an algorithm that finds eigenvalues of large matrices—using four alternative numeric formats (OFP8, Bfloat16, Posit, and Takum, which are different systems for how computers store decimal numbers). They executed the same computations described in the original paper and verified whether the reported numerical results could be reproduced. This checks whether the code actually works and produces the claimed performance.

## Key Novelty
The work validates whether the Implicitly Restarted Arnoldi Method's numerical results can be independently reproduced across alternative numeric formats (OFP8, Bfloat16, Posit, and Takum).
