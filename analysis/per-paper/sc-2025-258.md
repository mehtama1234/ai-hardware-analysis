# ASCRIBE-XR: VR + HPC Scientific Visualization

## Problem
Immersive exploration of 3D scientific data is challenging; traditional tools lack HPC integration and multi-user collaboration.

## Approach
Godot-based VR application with three integration layers:
1. Local VR rendering for immersive exploration
2. HPC backend for remote large-scale data processing + streaming
3. WebRTC+MQTT multi-user real-time collaboration

## Key Features
- AI-driven object modeling for feature detection
- Real-time multi-user visualization
- HPC offload for large-scale processing
- No external API dependencies

## Applications
- 3D dense array exploration
- Mesh visualization and manipulation
- Collaborative research across distributed teams
