# SiGNoR: Similarity-based Graph Partitioning and Node Reuse for Memory Efficient GNN Acceleration

**Venue:** ICCAD

## Problem
GNNs require large memory, and graph partitioning for on-chip memory creates halo nodes that lead to frequent redundant external DRAM access.

## Motivation
Edge and mobile applications demand memory-efficient GNN deployment but memory constraints limit scalability.

## Method
Hardware-friendly graph partitioning with similarity-based node reuse replacing halo nodes with local nodes, multiphase partitioning for boundary refinement, and partition-wise block floating-point for energy efficiency.

## Key Novelty
Similarity-based node replacement strategy reducing redundant halo node DRAM access by leveraging local partition nodes.

## Contributions
- 44.5% DRAM traffic reduction
- 2.6x energy efficiency improvement
- Negligible accuracy degradation
- Partition-wise block floating-point technique
- Hardware-efficient GNN accelerator design
