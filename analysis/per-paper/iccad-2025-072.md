# SiGNoR: Similarity-based Graph Partitioning and Node Reuse for Memory Efficient GNN Acceleration

**Venue:** ICCAD

## Problem
GNNs require large memory, and graph partitioning for on-chip memory creates halo nodes that lead to frequent redundant external DRAM access.

## Motivation
Edge and mobile applications demand memory-efficient GNN deployment but memory constraints limit scalability.

## Method
The approach splits a graph into sections small enough to fit on a chip's fast local memory. For boundary nodes (called halo nodes) that would normally require repeated fetches from slow external DRAM, the system uses similar nodes already stored locally instead. Over multiple refinement phases, the partition boundaries improve, and data uses block floating-point format (grouping similarly-sized numbers to save storage and energy).

## Key Novelty
The key innovation replaces halo nodes (boundary nodes normally fetched from external DRAM) with similar nodes already in the partition's local memory.

## Contributions
- 44.5% DRAM traffic reduction
- 2.6x energy efficiency improvement
- Negligible accuracy degradation
- Partition-wise block floating-point technique
- Hardware-efficient GNN accelerator design
