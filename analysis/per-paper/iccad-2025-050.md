# NeuroPDE: A Neuromorphic PDE Solver Based on Spintronic and Ferroelectric Devices

**Venue:** ICCAD | **ID:** iccad-2025-050

## Problem
Conventional von Neumann architecture lacks hardware-intrinsic randomness needed for efficient Monte Carlo random walk-based PDE solvers. Performance severely limited by software-based randomness generation.

## Motivation
Accelerate partial differential equation solving with inherent probabilistic computation capability.

## Method
The system builds a neuromorphic processor (brain-inspired chip) from spintronic devices (circuits based on magnetic spin) and ferroelectric materials (substances that permanently store electrical charge). Spintronic neurons naturally produce the random behavior needed for random-walk methods in solving PDEs; ferroelectric synapses persistently store the numerical weights for computation. This approach generates randomness directly in hardware, bypassing the software randomness generation that typically creates a major performance bottleneck.

## Key Novelty
Spintronic devices that naturally generate randomness for random-walk PDE solvers, eliminating software randomness generation.

## Contributions
- Spin neuron design with probabilistic transmission for random walk emulation
- Ferroelectric synapse integration for non-volatile continuous weight storage
- Complete neuromorphic PDE solver leveraging physical device stochasticity
