# isca-2025-067 — HYTE: Flexible Tiling for Sparse Accelerators via Hybrid Static-Dynamic Approaches

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Tiling very large sparse tensors on hardware accelerators is challenged by the inability of purely static schemes (simple heuristics) and purely dynamic schemes (high design complexity) to jointly find near-optimal tile size/shape, iteration order, buffer allocation, and metadata management under highly variable local sparsity patterns.

## Motivation
Sparse tensor operations dominate many ML and scientific workloads; as tensor sizes exceed on-chip buffer capacity, tiling becomes mandatory, but high sparsity variability makes a single static tiling scheme leave significant performance on the table, while fully dynamic schemes add unacceptable hardware complexity.

## Method
HYTE combines upfront planning with runtime adjustment to tile sparse tensors (breaking multi-dimensional arrays containing mostly zeros into chunks) on specialized hardware accelerators. Before execution, it samples the sparse data to estimate good tile sizes, shapes, and processing order without examining the full dataset. At runtime, it adjusts tile shapes on-the-fly as the actual sparsity (where zeros are located) varies across the data. It also efficiently manages metadata (the structural information about how data is organized) in both main memory and fast on-chip storage, solving an overhead problem that earlier approaches overlooked.

## Key Novelty
HYTE combines simple upfront sampling of the data with runtime adjustment to jointly optimize tile size, shape, iteration order, and memory allocation while adapting to how sparsity varies.

## Contributions
1. A static offline scheduler using lightweight sampling to identify near-optimal tiling configurations.
2. A dynamic runtime tile-shape tuner that maintains high buffer utilization under variable local sparsity.
3. Efficient on-chip and off-chip metadata management for sparse accelerator tiling.
4. 3.3x to 6.2x geomean speedup over state-of-the-art sparse tiling strategies.
