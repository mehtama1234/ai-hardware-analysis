# Klotski: Efficient Mixture-of-Expert Inference via Expert-Aware Multi-Batch Pipeline

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-045  
**Confidence:** low (abstract only)

## Problem
MoE LLMs with trillion-scale parameters require CPU/disk offloading when GPU VRAM is insufficient, but per-expert compute time is shorter than I/O load time, creating pipeline bubbles that negate the benefit of I/O-compute overlap.

## Motivation
MoE models enable parameter scaling without proportional compute cost, but their sparse activation makes the offloading compute-to-I/O ratio unfavorable, bottlenecking inference throughput on commodity hardware.

## Method
Klotski processes multiple requests in parallel instead of one at a time. When different requests' computations need the same expert module (a specialized part of the trillion-parameter model), Klotski groups those token computations together, making the total work on that module long enough to keep the GPU busy while loading it from disk into fast memory—eliminating idle processor gaps. The system predicts which expert modules upcoming requests will use and pre-loads them, while also deciding which computations to run next, balancing the load across the memory bus and GPU processors so both operate at full capacity.

## Key Novelty
Klotski groups token computations from multiple concurrent requests that target the same expert module, making the computation work long enough to fully hide the time spent loading that module.

## Contributions
- Analysis of the compute-I/O imbalance and pipeline bubble problem in offloaded MoE inference.
- Klotski multi-batch pipeline co-scheduling I/O prefetch and compute across concurrent batches.
- Significant throughput improvement for trillion-parameter MoE inference on memory-constrained hardware.
