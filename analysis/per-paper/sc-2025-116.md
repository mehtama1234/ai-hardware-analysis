# Qonductor: A Cloud Orchestrator for Quantum Computing

**Venue:** SC | **ID:** sc-2025-116

## Summary
Qonductor: cloud orchestrator for hybrid quantum-classical applications with hardware-agnostic API, resource estimation, and intelligent scheduling optimizing QoS and resource utilization.

## Problem & Motivation
Hybrid quantum-classical computing requires managing heterogeneous resources and balancing classical-quantum workload distribution. Hardware noise, resource contention, and scheduling complexity prevent practical deployment of quantum applications at scale. No unified orchestration platform exists for hybrid workflows.

## Key Findings
- **Performance:** 54% reduction in job completion times vs. baseline
- **Quality trade-off:** 3% quality reduction for JCT improvement (acceptable)
- **Resource utilization:** 66% increase in quantum processor (QPU) utilization
- **Scalability:** Demonstrated with 7000+ real IBM quantum cloud runs
- **Adaptability:** Intelligent scheduling across heterogeneous resources

## Hardware & Systems
- **Quantum platform:** IBM quantum cloud
- **Architecture:** Hybrid quantum-classical infrastructure
- **Deployment:** Cloud-based orchestration
- **Integration:** Hardware-agnostic API abstraction

## Techniques
- **Hardware-agnostic API:** Unified programming interface for hybrid apps
- **Resource estimator:** Quantum-classical workload balancing
- **Noise mitigation:** Strategic resource allocation accounting for hardware effects
- **Hybrid scheduler:** QoS optimization with load balancing across QPUs
- **Job management:** Automated scheduling and resource allocation
