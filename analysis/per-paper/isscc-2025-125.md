# isscc-2025-125: Ultra-Low-Power Voice-Activity Detection with Neuromorphic Features

**Problem:** Always-on voice-activity detection (VAD) dominates power consumption in voice processing systems; achieving ultra-low power consumption (<200nW) while maintaining noise robustness (0-5dB SNR) and high accuracy (>90%) without excessive spike generation from feature encoding is challenging.

**Motivation:** Always-on VAD is critical for reducing total VPS power consumption and extending battery life in AIoT devices; existing bio-inspired spike-based methods suffer from excessive spike generation in high-frequency voice signals.

**Method:** The 161nW VAD engine combines information-aware data compression for efficient feature encoding with neuromorphic spatial-temporal feature extraction using spiking neural networks (SNNs) that reduce spike generation compared to level-crossing coding methods.

**Key Novelty:** Information-aware data compression combined with neuromorphic spatial-temporal feature extraction achieving ultra-low power VAD with maintained noise robustness.

**Contributions:**
- 0.22mm2 161nW always-on voice-activity detection engine
- Information-aware data compression for efficient feature encoding
- Neuromorphic spatial-temporal feature extraction with reduced spike generation
- >90% accuracy across 0-5dB SNR with improved noise robustness
