# FPGA-CC: Confidential Containers for Virtualized FPGAs

**Paper ID:** iccad-2025-229  
**Venue:** ICCAD

## Problem

Virtualized FPGA cloud services lack security mechanisms to protect user data and computation, as current trusted execution environment (TEE) approaches do not support FPGA acceleration in cloud environments.

## Motivation

Growing adoption of FPGAs in cloud computing for performance-critical workloads creates security vulnerabilities; TEE-based confidential computing lacks FPGA support, requiring new security architecture.

## Method

FPGA-CC creates a secure channel connecting virtualized FPGAs (specialized computing hardware running on shared cloud servers) to a trusted execution environment or TEE (a secure CPU that encrypts code and data from other users). This isolated data path protects information as it flows between the FPGA and the secure CPU, keeping everything confidential from other users on the same cloud. The framework achieves this while maintaining acceptable performance for real applications.

## Key Novelty

FPGA-CC is the first to make virtualized FPGAs secure for cloud users by connecting them through an encrypted channel to trusted CPU environments that protect the data traveling between them.

## Contributions

- End-to-end confidential container architecture for virtualized FPGAs
- Secure communication path between TEE-enabled CPU and virtualized FPGA resources
- Demonstrates practical security implementation with acceptable performance overhead
