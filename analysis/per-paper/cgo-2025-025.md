# ANT-ACE: An FHE Compiler Framework for Automating Neural Network Inference

**Venue:** CGO
**Confidence:** low

## Problem
Fully Homomorphic Encryption (FHE) enables privacy-preserving NN inference but requires extensive cryptographic expertise to implement correctly, securely, and efficiently. Manual FHE programming is complex and error-prone.

## Motivation
Privacy regulations (healthcare, finance) demand encrypted computation; automating FHE-based NN inference lowers barrier to adoption and reduces implementation errors.

## Method
ANT-ACE takes neural network models in standard ONNX format (a common way to describe machine learning models) and automatically generates C/C++ code that performs inference—makes predictions—on encrypted data using a custom 44,000-line cryptography library. The compiler uses a multi-level intermediate representation (a format that sits between the original model and the final executable code) that can adapt to different model types and different encryption schemes. The current implementation uses the RNS-CKKS encryption scheme to run these encrypted computations on CPUs.

## Key Novelty
The core innovation is a multi-level intermediate representation that abstracts different encryption schemes and input formats, enabling automatic conversion of standard neural network models into efficient encrypted code.

## Contributions
- Production-quality open-source FHE compiler for ONNX models
- Custom multi-level IR supporting multiple FHE schemes
- ResNet encrypted inference speedups over manual implementations
