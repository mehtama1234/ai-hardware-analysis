# ANT-ACE: An FHE Compiler Framework for Automating Neural Network Inference

**Venue:** CGO
**Confidence:** low

## Problem
Fully Homomorphic Encryption (FHE) enables privacy-preserving NN inference but requires extensive cryptographic expertise to implement correctly, securely, and efficiently. Manual FHE programming is complex and error-prone.

## Motivation
Privacy regulations (healthcare, finance) demand encrypted computation; automating FHE-based NN inference lowers barrier to adoption and reduces implementation errors.

## Method
ANT-ACE compiler accepts ONNX models and generates C/C++ programs using custom FHE library (44k LOC). Custom IR with multiple abstraction levels supports diverse input formats and FHE schemes. Current implementation leverages RNS-CKKS scheme for encrypted inference on CPUs.

## Key Novelty
Multi-level intermediate representation enabling support for diverse FHE schemes and input formats; automated ONNX-to-FHE compilation with scheme abstraction.

## Contributions
- Production-quality open-source FHE compiler for ONNX models
- Custom multi-level IR supporting multiple FHE schemes
- ResNet encrypted inference speedups over manual implementations
