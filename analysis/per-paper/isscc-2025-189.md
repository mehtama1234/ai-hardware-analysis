# isscc-2025-189: Scalable 2.5D Chiplet System for AI Inference

**Problem**: Large AI inference workloads face memory bandwidth/capacity bottlenecks; monolithic designs cannot adapt post-fabrication to workload diversity or support multi-stream concurrent inference.

**Solution**: 2.5D chiplet system (20 chiplets) with 300MB distributed SRAM and 20Tb/s scalable interconnect enabling workload-dependent assembly-time reconfiguration and heterogeneous foundry integration.

**Key Results**:
- 300MB distributed SRAM
- 20Tb/s scalable bandwidth
- Workload-customized resource allocation (compute/memory)
- Simultaneous multi-stream inference
- Heterogeneous multi-foundry support

**Hardware**: Chiplet / SoC  
**Workload**: LLM / CNN / transformer inference  
**Confidence**: low (abstract only)
