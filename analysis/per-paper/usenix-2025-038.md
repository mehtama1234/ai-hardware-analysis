# Para-ksm: Parallelized Memory Deduplication with Data Streaming Accelerator

**Problem:** Traditional kernel samepage merging (KSM) sequentially scans and compares memory pages to identify duplicates, creating CPU bottlenecks that limit deduplication throughput and adoption. The sequential nature of page hashing and comparison prevents efficient utilization of modern hardware parallelism.

**Method:** Para-ksm introduces a hardware data streaming accelerator that parallelizes memory page scanning, hashing, and comparison operations. The accelerator streams memory pages through specialized hardware that performs parallel page hash computations and duplicate detection. This offloads deduplication work from the CPU, reducing overhead while increasing deduplication throughput.

**Novelty:** Using a dedicated data streaming accelerator to parallelize memory deduplication scanning, eliminating the CPU-bound sequential bottleneck inherent in traditional KSM.
