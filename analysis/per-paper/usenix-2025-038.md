# Para-ksm: Parallelized Memory Deduplication with Data Streaming Accelerator

**Problem:** Traditional kernel samepage merging (KSM) sequentially scans and compares memory pages to identify duplicates, creating CPU bottlenecks that limit deduplication throughput and adoption. The sequential nature of page hashing and comparison prevents efficient utilization of modern hardware parallelism.

**Method:** Para-ksm moves memory deduplication work from the CPU to a specialized hardware accelerator (a data streaming accelerator) that processes many pages simultaneously. The accelerator computes a unique identifier (hash) for each page and identifies duplicates by comparing these identifiers in parallel. This offloads the repetitive work from the CPU, reducing overhead and dramatically increasing the speed of finding duplicate pages.

**Novelty:** Using a specialized hardware accelerator (a data streaming accelerator) to parallelize memory page deduplication, eliminating the CPU bottleneck of processing pages one at a time.
