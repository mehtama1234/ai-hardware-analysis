# isca-2025-036 — Magellan: A High-Performance Loop-Guided Prefetcher for Indirect Memory Access

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Graph analytics and sparse linear algebra applications rely heavily on indirect memory access (IMA), where pointer-chasing through irregular data structures causes frequent high-latency DRAM accesses due to poor temporal and spatial locality. Existing hardware and software prefetchers for IMA target narrow access patterns and struggle with complex nested-loop IMA patterns in sparse workloads.

## Motivation
Sparse applications dominate scientific and graph-analytics workloads, and their irregular memory access patterns stall processors waiting for DRAM at rates that hardware prefetchers cannot address due to limited look-ahead through pointer indirections.

## Method
Magellan is a compiler-based software prefetcher that constructs dependence graphs across loop levels to detect complex multi-level IMA patterns. It captures inner-outer loop semantics to schedule prefetches for both current and future loop iterations, inserting prefetch instructions ahead of the load chain. The compiler analysis extracts the indirection chains (e.g., A[B[i]]) across nested loop boundaries and emits prefetch instructions with appropriate software distances derived from loop trip counts and memory latency estimates.

## Key Novelty
Magellan is the first software prefetcher to model cross-loop-level dependence graphs and leverage inner-outer loop semantics to prefetch across nested IMA patterns, enabling coverage of access patterns that prior single-level approaches miss.

## Contributions
1. Dependence graph extraction across loop levels to detect complex multi-level indirect memory access patterns
2. Inner-outer loop semantic analysis to schedule prefetches for both current and future loop iterations
3. 25% reduction in cache misses and 14% reduction in dynamic instruction count vs. best prior IMA software prefetcher
4. 1.14x average speedup (up to 1.41x) across 14 memory-intensive benchmarks on real-world social network and web graph datasets
