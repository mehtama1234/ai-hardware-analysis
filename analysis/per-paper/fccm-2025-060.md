# Ph.D. Project: Floorplan Quality Prediction for HLS Design Exploration on Multi-Die FPGA

**Problem:** Cross multi-die boundary delays and local congestion in HLS designs on multi-die FPGAs require iterative parameter tuning through Vitis to achieve better frequency performance, consuming significant time overhead.

**Method:** A graph neural network predictor is trained to evaluate floorplan configurations for each FPGA slot by predicting high-level congestion and critical resource metrics. The GNN enables rapid design space exploration at millisecond latency by eliminating expensive iterative implementation runs in Vitis.

**Novelty:** Using graph neural networks to directly predict floorplan quality metrics without requiring expensive iterative Vitis implementations.
