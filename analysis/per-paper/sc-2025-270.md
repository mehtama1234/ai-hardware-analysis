# Application-Aware Source Routing via Traffic Classes

## Problem
Path-aware source routing (PolKA) lacks application awareness. Datacenters need smarter allocation decisions that understand workload characteristics and QoS requirements.

## Approach
Extend source routing with edge traffic classification:
1. Classify flows based on application requirements at network edge
2. Develop traffic class patterns for QoS tiers
3. Implement fair queuing across classes
4. Leverage P4 programmable switches for decisions

## Key Features
- In-band Network Telemetry (INT) for visibility
- P4 programmable forwarding
- Self-engineering network capability
- Fair allocation across traffic classes

## Results
- Optimized network utilization
- All traffic classes' QoS satisfied
- Finer-grained control than traditional TE

## Applications
- Mixed-workload datacenters
- Latency-sensitive (e.g., interactive) + throughput-intensive (e.g., analytics) coexistence
- Dynamic traffic engineering
