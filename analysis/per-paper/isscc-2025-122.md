# isscc-2025-122: 30.4 GOPS/mW MK-CKKS Processor for Secure Multi-Party Computation

**Problem:** Multi-key fully homomorphic encryption (MK-FHE) processors for secure multi-party computation face challenges in integrating flexible configuration of task-, ciphertext-, and polynomial-level operations into a single area-efficient hardware architecture that scales to an unlimited number of parties.

**Motivation:** MK-FHE enables privacy-preserving computation across multiple parties with non-interactive communication; MK-CKKS is robust for fixed-point data but CPU throughput is limited by irregular access patterns in homomorphic operations.

**Method:** The processor implements a flexible, scalable architecture for MK-CKKS that supports variable task-level configurations (linear/nonlinear transformations) composed from ciphertext-level operations (multiplication, key-switching, rescaling) and polynomial-level operations (NTT, base conversion, permutations) optimized for area efficiency.

**Key Novelty:** First hardware processor supporting MK-CKKS for unlimited-party multi-party computation with flexible integration of hierarchical operation combinations.

**Contributions:**
- First MK-CKKS processor supporting unlimited parties for multi-party computation
- Flexible architecture integrating task-, ciphertext-, and polynomial-level operations
- Area-efficient design for diverse MPC application scenarios
- 30.4 GOPS/mW efficiency metric
