# SC-2025-192: Reproducibility Report for CI in HPC

**Venue:** SC 2025  
**Authors:** Ruben Laso  
**Confidence:** low (abstract only)

## Summary

Reproducibility report providing artifact evaluation for SC25 paper "Addressing Reproducibility Challenges in HPC with Continuous Integration" by Hayot-Sasson et al.

## Problem & Motivation

Reproducibility challenges widespread in HPC research; continuous integration offers systematic approach to validation. Formal evaluation documents effectiveness.

## Approach

Systematic artifact evaluation following:
1. SC25 Artifact Description and Evaluation appendix guidelines
2. Reproducibility Initiative assessment methodology
3. Continuous integration workflow validation
4. HPC-specific reproducibility criteria

## Contributions

1. Artifact evaluation for continuous integration HPC work
2. Reproducibility assessment of CI-based validation
3. Documentation of HPC best practices
4. Evaluation support for reproducibility methods

## Limitations

Reproducibility reports focus on evaluation rather than novel methods. Abstract provides minimal technical depth.
