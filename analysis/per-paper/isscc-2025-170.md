# isscc-2025-170: Cryo-CMOS Spin Qubit Readout with QAM Multiplexing

**Title:** 13.5 An 18.5µW/qubit Cryo-CMOS Charge-Readout IC Demonstrating QAM Multiplexing for Spin Qubits

**Problem:** Scaling spin qubits to thousands requires simultaneous readout with minimal power and footprint, but existing schemes suffer bulky inductors or poor array scaling.

**Approach:** Capacitive-feedback transimpedance amplifier using QAM multiplexing to read multiple qubits per carrier frequency, eliminating inductors.

**Key Result:** 18.5µW/qubit within thermal constraints, multiple qubits per carrier (vs OOK's one-qubit-per-carrier).

**Hardware:** ASIC/CMOS (cryo-readout circuit).

**Tags:** quantum-computing, spin-qubit, cryo-cmos, charge-readout, qam-multiplexing, low-power
