# SC-2025-163: EMLIO - Energy-Aware I/O for AI Training

## Summary
EMLIO service for jointly minimizing I/O latency and energy consumption in large-scale deep learning. Maintains consistent performance across local disk, LAN, and WAN using adaptive data loading and prefetching.

## Problem
- Large datasets exceed local GPU storage → network I/O required
- Current optimizations focus on latency only
- **Energy consumption overlooked** despite being critical at scale
- Network variability (30ms WAN vs 0.05ms LAN) requires adaptive strategies

## Solution: Service-Based Architecture
**Storage daemon**:
- Serialize and batch raw samples
- TCP streaming with out-of-order prefetch
- Adaptive to network conditions

**Client integration**:
- NVIDIA DALI preprocessing on GPU
- Transparent API
- Constant throughput guarantee

## Performance
| Metric | Improvement |
|--------|-------------|
| **Latency** | 8.6x faster |
| **Energy** | 10.9x lower |
| **Consistency** | Network-distance invariant |

## Evaluation Environments
- **Local disk**: Baseline
- **LAN**: 0.05ms RTT (intra-datacenter)
- **LAN**: 10ms RTT (regional)
- **WAN**: 30ms RTT (cross-datacenter)

## Key Innovation
**Constant profile guarantee**: Same performance/energy regardless of network distance via adaptive prefetch and batching.

## Architecture
Scalable service design:
- Storage-side daemon (minimal overhead)
- Client-side integration (seamless)
- Network protocol (TCP, standard)

## Applications
- Multi-node GPU training clusters
- Cloud-based AI platforms
- Distributed data centers
