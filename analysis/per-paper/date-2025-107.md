# CAS-PUF: Current-Mode Array-Type Strong PUF for Secure Computing in Area Constrained SoCs

**Venue**: DATE  
**Primary Theme**: Area-efficient strong PUF for IoT  

## Problem
Strong PUFs are essential for secure SoCs but traditional designs consume excessive area, preventing deployment in area-constrained IoT and mobile applications requiring hardware-based cryptographic key generation and device authentication.

## Method
The design creates a strong PUF (a hardware security device that generates unique fingerprints from manufacturing variations) using only six minimum-size transistors per unit, arranged in an array. It operates using electrical current rather than voltage, which makes it naturally stable when the power supply varies. Despite this minimal design, it can efficiently generate many different challenge-response pairs (where you ask it a security question and it gives a unique answer based on its physical properties) without consuming much chip space.

## Key Novelty
The core innovation is that using minimal transistors in a current-mode design enables a strong PUF to produce many unique challenge-response pairs while taking up almost no additional chip area.

## Contributions
- Six-transistor current-source PUF design reducing area by 20-72% versus prior strong PUFs
- Power supply variation tolerance with 96.45% reliability at ±10% fluctuation
- 19-53 orders of magnitude higher CRP capacity for equivalent area
- 97.69% reliability under temperature variation (0–80°C) with 50.01% uniqueness and 49.54% uniformity
