# dac-2025-085: VersaSlot: FPGA Sharing with Big.Little Architecture

**Problem:** FPGA sharing via DPR suffers from reconfiguration contention and task execution blocking.

**Method:** VersaSlot divides each FPGA into variable-sized slots—some large, some small—so different-length tasks can run at the same time instead of queuing while the FPGA reconfigures (reprograms itself). It uses smart allocation to match each task to the right-size slot and live migration (moving a running task between FPGAs) to spread workload across a cluster. On Xilinx UltraScale+ FPGAs, this eliminates the performance bottleneck where reconfiguration delays become the limiting factor, the primary source of slowdown in shared FPGA environments.

**Key Novelty:** Heterogeneous slot architecture resolving DPR contention with seamless live migration across FPGA clusters.

**Hardware Target:** FPGA  
**Technique Category:** virtualization, scheduling  
**Workloads:** datacenter, accelerator-sharing
