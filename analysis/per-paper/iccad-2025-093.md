# AI-Driven Multi-Die Architecture Exploration

**Venue:** ICCAD  
**ID:** iccad-2025-093

## Problem
Multi-die chip design requires comprehensive design space exploration considering power, performance, and interconnect constraints.

## Motivation
Data-driven methodology and tools accelerate multi-die architecture specification and help meet power/performance goals.

## Method
The approach uses computer simulations to test different ways of designing a multi-die chip—a chip made of multiple separate pieces that work together. AI automatically searches through thousands of possible configurations, evaluating each one by simulating how data moves between the pieces, how real software runs on it, and measuring factors like power consumption and speed.

## Key Novelty
Using AI to automatically explore and evaluate the vast space of possible multi-die chip designs instead of relying on manual design choices.

## Contributions
- Data-driven design space exploration methodology for multi-die systems
- Virtual prototyping framework for interconnect and workload simulation
- Accelerated design time through AI-assisted analysis
