# isca-2025-108 — Process Only Where You Look

**Venue:** ISCA  
**Confidence:** low (abstract-only)

## Problem
Image rendering in VR head-mounted displays (HMDs) is computationally expensive, particularly for real-time applications where low latency is mandatory. Existing gaze-tracking and foveated rendering approaches impose high algorithmic and hardware costs that compound the overall rendering budget.

## Motivation
VR HMDs must render high-quality, immersive visuals at low latency on power-constrained embedded SoCs, and leveraging the human visual system's foveal concentration can eliminate unnecessary computation in peripheral regions if gaze can be tracked efficiently.

## Method
The paper proposes POLONet, an efficient multitask deep learning framework for real-time eye-movement tracking, co-designed with a dedicated POLO accelerator integrated as a plug-in for VR HMD SoCs. The system exploits the observation that human gaze is concentrated in a small foveal region, so full-resolution rendering is performed only where the eye is looking while peripheral regions are rendered at reduced quality. The hardware-algorithm co-optimization jointly minimizes gaze-tracking latency and rendering compute cost through a tightly coupled accelerator-SoC interface.

## Key Novelty
A hardware-algorithm co-design that unifies multitask gaze tracking (POLONet) with a dedicated SoC accelerator (POLO) to achieve end-to-end foveated rendering with minimal latency overhead.

## Contributions
- POLONet: a multitask deep learning framework for low-latency eye tracking on VR HMDs.
- POLO accelerator: a plug-in hardware block for VR HMD SoCs that accelerates gaze-informed foveated rendering.
- Algorithm-hardware co-optimization that reduces end-to-end latency by up to 3.9x compared to state-of-the-art gaze tracking methods.
- Demonstration of the POLO system integrated into a complete VR rendering pipeline targeting real-time performance.
