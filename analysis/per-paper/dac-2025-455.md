# dac-2025-455: OutlierCIM - Outlier-Aware LLM Accelerator

## Summary
OutlierCIM is a hardware-algorithm codesign framework targeting compute-in-memory (CIM) accelerators that optimizes LLM inference under activation outliers through outlier-aware tiling, hybrid quantization, and unified FP-INT computation.

## Key Results
- 4.54× energy efficiency vs outlier-aware accelerators
- 3.91× speedup vs state-of-the-art
- Chip area: 2.25 mm² (28 nm CMOS)

## Technical Approach
- **Outlier-Clustered Tiling**: Groups outliers to improve memory access patterns and reduce wasted computation
- **Hybrid-Strategy Quantization**: Reconfigurable double-bit CIM macros adapt to outlier intensity
- **Unified FP-INT Path**: Dedicated quantizer handles mixed-precision operations
- **Target**: Low-bit-width CIM arrays for transformer inference

## Contribution
Demonstrates that explicit algorithm-hardware codesign for outlier handling in CIM yields significant efficiency gains over generic quantization, making CIM viable for outlier-heavy LLM workloads.
