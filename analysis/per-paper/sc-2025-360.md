# In-Transit Data Transport Strategies for Coupled AI-Simulation Workflow Patterns

**Paper ID:** sc-2025-360
**Venue:** SC
**Confidence:** low

## Problem Statement
Coupled AI-Simulation workflows lack tools for performance analysis and prototyping of in-situ data transport

## Motivation
HPC facilities need benchmarking tools for coupled workflows to identify data transport bottlenecks

## Method
SimAI-Bench: benchmarking tool for one-to-one (colocated) and many-to-one (ensemble) coupled workflows on Aurora

## Key Novelty
SimAI-Bench tool and analysis of data transport for hybrid AI-simulation workflows showing DragonHPC advantage

## Contributions
- SimAI-Bench benchmarking tool
- Analysis of one-to-one pattern: node-local and DragonHPC superior
- Many-to-one: data transport bottleneck identified
