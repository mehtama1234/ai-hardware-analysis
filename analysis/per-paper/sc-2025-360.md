# In-Transit Data Transport Strategies for Coupled AI-Simulation Workflow Patterns

**Paper ID:** sc-2025-360
**Venue:** SC
**Confidence:** low

## Problem Statement
Coupled AI-Simulation workflows lack tools for performance analysis and prototyping of in-situ data transport

## Motivation
HPC facilities need benchmarking tools for coupled workflows to identify data transport bottlenecks

## Method
SimAI-Bench is a benchmarking tool that tests data movement between AI systems and simulations running together, addressing a gap in tools for analyzing performance in these coupled workflows. It evaluates two patterns: one-to-one setups where an AI system and simulation share the same hardware (colocated), and many-to-one (ensemble) setups where multiple simulations send data to a single AI system. By measuring how efficiently data transports between these components on the Aurora supercomputer, the tool helps researchers identify and prototype solutions for performance bottlenecks.

## Key Novelty
SimAI-Bench enables performance testing of data transport in coupled AI-simulation workflows and demonstrates the performance advantage of DragonHPC for this purpose.

## Contributions
- SimAI-Bench benchmarking tool
- Analysis of one-to-one pattern: node-local and DragonHPC superior
- Many-to-one: data transport bottleneck identified
