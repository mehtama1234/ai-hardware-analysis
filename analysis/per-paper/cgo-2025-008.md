# Tensorize: Fast Synthesis of Tensor Programs from Legacy Code

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Tensor DSLs offer substantial performance through high-level optimization and hardware acceleration, but manual rewriting is prohibitive. Prior automatic translation approaches lack scalability for real-world code.

## Technical Approach
MLIR-based synthesis lifts legacy code to tensor DSLs using symbolic trace as specification. Automatically selects sketches from target DSLs and uses algebraic solver for rapid simplification. Guarantees correctness by construction.

## Key Novelty
Algebraic solver-driven synthesis using symbolic traces for fast, correct-by-construction tensor DSL translation.

## Key Results
- Lifts more code than prior approaches
- Order of magnitude faster synthesis
- Correctness guaranteed by construction

## Hardware & Techniques
- **Target:** GPU, ASIC, TPU
- **Techniques:** Compiler, program synthesis, parallelism, algebraic solving
