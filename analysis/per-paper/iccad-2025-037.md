# LCTMwalk: GPU-Accelerated Transient Thermal Simulation for Liquid-Cooled 2.5D/3D ICs

**ID:** iccad-2025-037  
**Venue:** ICCAD

## Problem
Existing matrix-solving acceleration methods for compact thermal models (CTMs) are inadequate for high-speed iterative transient thermal analysis of large-scale liquid-cooled 2.5D/3D ICs, and random walk methods were not applicable to liquid-cooled CTM circuits.

## Motivation
Thermal management is critical in 2.5D/3D IC design; liquid cooling requires fast thermal simulation during iterative design optimization.

## Method
LCTMwalk proposes a novel GPU-accelerated random walk method by: (1) replacing voltage-controlled current source with diode model to enable random walks on liquid-cooled CTM circuits, (2) improving transient analysis with time-backward random walk and time-domain path reuse for local node solutions.

## Key Novelty
Adaptation of random walk method to liquid-cooled CTM circuits via diode model replacement, enabling GPU acceleration for large-scale transient thermal analysis.

## Contributions
1. Diode model replacement enabling random walks on liquid-cooled CTM-derived circuit networks
2. Time-backward random walk with time-domain path reuse for transient analysis
3. GPU acceleration scaling to million-scale thermal problems
4. 14-22× speedup versus ADI method with high accuracy (<1 K error)
