# LCTMwalk: GPU-Accelerated Transient Thermal Simulation for Liquid-Cooled 2.5D/3D ICs

**ID:** iccad-2025-037  
**Venue:** ICCAD

## Problem
Existing matrix-solving acceleration methods for compact thermal models (CTMs) are inadequate for high-speed iterative transient thermal analysis of large-scale liquid-cooled 2.5D/3D ICs, and random walk methods were not applicable to liquid-cooled CTM circuits.

## Motivation
Thermal management is critical in 2.5D/3D IC design; liquid cooling requires fast thermal simulation during iterative design optimization.

## Method
The method simulates how heat spreads over time through liquid-cooled stacked chips using random walks on circuit thermal models—imagining heat flow as particles taking random paths through the network, then averaging many paths to find temperature distribution. To make random walks work with liquid cooling, it replaces a problematic circuit element (voltage-controlled current source) with a diode model that's compatible with the random walk algorithm. GPU acceleration and time-domain path reuse (reusing results across time steps) make this fast enough for large systems.

## Key Novelty
Replacing a circuit element with a diode model adapts random walks to liquid-cooled systems, enabling GPU-accelerated thermal simulation.

## Contributions
1. Diode model replacement enabling random walks on liquid-cooled CTM-derived circuit networks
2. Time-backward random walk with time-domain path reuse for transient analysis
3. GPU acceleration scaling to million-scale thermal problems
4. 14-22× speedup versus ADI method with high accuracy (<1 K error)
