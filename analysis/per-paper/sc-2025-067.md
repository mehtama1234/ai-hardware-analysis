# MoE-Inference-Bench: Performance Evaluation of Mixture of Expert Large Language and Vision Models

**ID:** sc-2025-067 | **Venue:** SC

## Problem Statement
MoE models have load imbalance and routing overhead at inference; lacks systematic hardware acceleration evaluation

## Motivation
MoE enables scaling LLMs/VLMs efficiently, but inference presents deployment challenges requiring optimization guidance

## Method
They created a benchmark that measures how Mixture of Experts models—systems that automatically route data to different expert subnetworks—perform on H100 GPUs under different configurations. They varied parameters like batch size (how many examples at once), sequence length (how long the input is), number of experts, and feed-forward network size. The benchmark tests optimization techniques including pruning (removing unused experts), fused operations (combining multiple computational steps into one), speculative decoding (predicting outputs early), quantization (using lower precision), and parallelization (distributing work across processors).

## Key Novelty
By testing Mixture of Experts models from different sources (Mixtral, DeepSeek, OLMoE, Qwen) under various configurations, they showed that the best way to run these models depends on factors like batch size and sequence length.
