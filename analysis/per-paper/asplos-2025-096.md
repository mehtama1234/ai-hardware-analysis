# asplos-2025-096: Saving Energy with Per-Variable Bitwidth Speculation

**Venue:** ASPLOS  
**Confidence:** low (abstract only)

## Problem
Compilers for tiny embedded devices directly translate source-level variable bitwidths (e.g., 32-bit integers) to binary without exploiting the fact that most variables use far fewer bits than declared at runtime. This wastes energy in computations and memory traffic on highly optimized, energy-constrained devices where further traditional optimizations are difficult.

## Motivation
Tiny IoT devices operate under tight energy budgets but cannot afford to sacrifice performance, and their hardware is already heavily optimized, making bitwidth reduction a rare remaining source of energy savings.

## Method
BitSpec has the compiler (which translates source code to machine instructions) and hardware work together. The compiler guesses how many bits each variable needs (fewer than its declared size) and writes instructions using those smaller sizes. The hardware watches the actual values flowing through these variables; if a value needs more bits than predicted and overflows (doesn't fit), the hardware detects this mismatch and signals software to re-run that calculation using the original, safe bitwidth. By doing the right-sized computation most of the time but falling back when needed, BitSpec saves energy without ever producing wrong results.

## Key Novelty
BitSpec lets compilers automatically narrow how many bits each variable uses by guessing what values will actually appear, with hardware detecting when those guesses are wrong—all without programmers having to annotate code or run test cases to guide the optimization.

## Contributions
- BitSpec: a compiler pass that speculatively narrows per-variable bitwidths to their expected runtime needs.
- A lightweight hardware monitor that detects bitwidth misspeculation (overflow) and triggers software re-execution at full bitwidth.
- Energy reduction of 9.9% on average and up to 28.2% on tiny-device workloads, with correctness guaranteed by the speculation-recovery mechanism.
