# Breaking New Ground: Division Directly in Memory

**Problem:** Implementing complex arithmetic operations such as division directly within memory has remained an elusive challenge in in-memory computing systems. Performing division outside memory requires costly data movement that negates the efficiency benefits of IMC architectures.

**Method:** The approach leverages stochastic computing principles through specialized circuits integrated into the memory substrate to perform division. The technique uses probabilistic computation to trade numerical precision for reduced circuit complexity and lightweight implementation suitable for memory integration.

**Novelty:** First successful implementation of division operations directly within in-memory computing frameworks using stochastic computing-based circuits.
