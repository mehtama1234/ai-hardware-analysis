# Breaking New Ground: Division Directly in Memory

**Problem:** Implementing complex arithmetic operations such as division directly within memory has remained an elusive challenge in in-memory computing systems. Performing division outside memory requires costly data movement that negates the efficiency benefits of IMC architectures.

**Method:** The circuit performs division using stochastic computing—a technique where calculations work with probabilistic signals instead of exact binary numbers—integrated directly into the memory hardware. By using approximate, probabilistic calculations rather than precise arithmetic, the circuit becomes simpler and uses far fewer transistors than a traditional division unit. This trades numerical precision (results are approximate) for a lightweight, low-power design that can fit inside the memory substrate.

**Novelty:** For the first time, division operations can run directly inside memory hardware using stochastic computing (mathematical operations based on probabilistic signals instead of exact binary values).
