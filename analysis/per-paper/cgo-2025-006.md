# Speeding up the Local C++ Development Cycle with Header Substitution

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
C++ header inclusion severely increases compilation time. Forward declaration rules are complex and prevent optimization of methods and lambda-parameter functions. Compilation time is a critical bottleneck in development.

## Technical Approach
Automatically detects forward declaration opportunities to replace includes via Yalla tool (LLVM-based). For methods and lambda-taking functions, introduces function wrappers. Guided by profitability analysis.

## Key Novelty
Automated forward declaration detection with wrapper-based solutions for previously unhandleable cases.

## Key Results
- 24.5× speedup in C++ file compilation
- 4.68× speedup in development cycle
- Tested on various C++ projects

## Hardware & Techniques
- **Target:** CPU
- **Techniques:** Compiler optimization, build system, profiling
