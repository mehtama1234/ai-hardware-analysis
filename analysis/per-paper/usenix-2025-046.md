# Towards Optimal Rack-scale μs-level CPU Scheduling through In-Network Workload Shaping

**Problem:** Prior rack-scale CPU scheduling systems suffer from inaccurate network load balancing and complex sub-optimal scheduling because they lack application awareness. This results in poor tail latency and throughput for microsecond-level services.

**Method:** Pallas performs application-aware in-network workload shaping to partition requests into shards with homogeneous CPU demands. This enables simple yet near-optimal inter-server load balancing, where requests are routed based on CPU affinity. Intra-server scheduling then operates with knowledge of workload characteristics to make near-optimal scheduling decisions.

**Novelty:** In-network workload shaping to partition workloads by CPU demand homogeneity, enabling application-aware rack-scale scheduling.
