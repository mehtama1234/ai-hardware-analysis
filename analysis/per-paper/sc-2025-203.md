# HP-MDR: High-performance and Portable Data Refactoring and Progressive Retrieval with Advanced GPUs

**Venue:** SC  
**Theme:** Data Compression and I/O  
**Confidence:** low

## Problem Statement
Scientific data management lacks GPU-accelerated progressive compression; existing methods are CPU-based and leave GPU performance potential untapped for heterogeneous systems

## Motivation
Scientific simulations produce vast data; GPU-accelerated progressive methods enabling on-demand retrieval could dramatically reduce data movement cost and I/O latency

## Methodology
HP-MDR optimizes bitplane and lossless encoding on GPUs; incorporates pipeline optimization with progressive retrieval; enables QoI-driven error-controlled retrieval

## Key Novelty
First high-performance GPU-accelerated progressive compression framework; combines optimized encoding with QoI-guided retrieval

## Contributions
- GPU-optimized bitplane and lossless encoding stages
- Pipeline optimization for large-scale data processing
- QoI-driven error control for data retrieval
- 13.68x throughput improvement in data refactoring, 6.31x in retrieval vs SOTA

## Hardware Targets
NVIDIA GPUs, Modern GPU clusters

## Technique Categories
Data compression, Progressive retrieval, GPU optimization

## Workloads
Scientific simulations, Climate data, Astrophysics simulations

## Performance Metrics
- **data_refactoring_throughput:** 13.68x vs SOTA
- **progressive_retrieval_throughput:** 6.31x vs SOTA
- **qoi_retrieval_throughput:** 11.22x
- **end_to_end_retrieval:** 6.04x

## Baselines Compared
- State-of-the-art compression methods
- CPU-based progressive methods

## Limitations & Future Work
GPU memory constraints for very large datasets; QoI error model specificity not detailed; evaluation on specific GPU types
