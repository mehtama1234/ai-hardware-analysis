# ABC-FHE: A Resource-Efficient Accelerator for Client-Side Fully Homomorphic Encryption

**Problem:** Client-side FHE operations require 10,000x more computation than plaintext; bootstrappable parameters with large encoding/decryption operations create a computational bottleneck.

**Method:** Streaming ASIC with reconfigurable dual-mode Fourier engine (NTT/FFT), on-chip PRNG, and unified on-the-fly twiddle generation to reduce off-chip memory and latency.

**Key Result:** 1112x speedup (encoding/encryption) vs CPU, 214x vs SOTA; 963x (decoding/decryption) vs CPU, 82x vs SOTA. 28.638 mm² @ 28nm, 5.654W.

**Hardware Target:** ASIC  
**Workloads:** cryptography  
**Confidence:** low (abstract-only)
