# FPGA-TrustZone: Security Extension of TrustZone to FPGA for SoC-FPGA Heterogeneous Architecture
**Venue:** DAC

## Problem
FPGAs in heterogeneous SoC platforms lack trusted execution environment (TEE) support; existing ARM TrustZone works only on CPUs and cannot protect FPGA workloads.

## Motivation
As heterogeneous computing (CPU+FPGA) becomes mainstream, security gaps in FPGA acceleration create vulnerabilities for sensitive data in mobile and edge devices.

## Method
FPGA-TrustZone creates a protected execution space on FPGAs (programmable logic chips) by replicating ARM TrustZone's security approach—the same feature that protects sensitive CPU code. It does this by inserting security checkpoints at two levels: where the FPGA connects to the rest of the chip (the SoC interconnect), and within the FPGA's programmable logic itself (the fabric). These checkpoints block untrusted code from accessing data and logic marked as trusted, creating the same kind of isolation that TrustZone provides on CPUs.

## Key Novelty
This is the first system to fully extend ARM TrustZone's security model to FPGAs, covering both the SoC interconnect and FPGA fabric layers in chips with both CPUs and FPGAs.

## Contributions
1. Extension of TrustZone architecture to support FPGA accelerators with minimal overhead
2. Access control and isolation mechanisms for heterogeneous FPGA-CPU execution
3. Validated on real SoC-FPGA development boards with low performance overhead
