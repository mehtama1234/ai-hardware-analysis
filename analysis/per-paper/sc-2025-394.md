# Testing and Benchmarking Emerging Supercomputers via the MFC Flow Solver

**Venue:** SC
**ID:** sc-2025-394
**Confidence:** low

## Problem
New supercomputers require systematic testing and evaluation; lack of portable, user-friendly benchmarking tools limits adoption validation.

## Motivation
CFD codes serve as valuable proxies for supercomputer evaluation; MFC provides a standardized testbed across generations of GPU and CPU architectures.

## Method
Multicomponent Flow Code (MFC) is a simulation tool for complex fluids, paired with an automated system that performs three tasks: compiling the code for different supercomputers, checking that results stay consistent when the code or compilers change (regression testing), and measuring how fast the code runs. By automating these steps across diverse hardware, researchers can verify whether newly built supercomputers work correctly and efficiently without setting up tests manually for each machine.

## Key Novelty
A portable testing framework that automatically detects compiler bugs and performance regressions (when code runs slower than it should) when running fluid-dynamics simulations on emerging supercomputers.

## Contributions
1. Automated MFC benchmarking toolchain across 50+ compute devices and 5 flagship supercomputers
2. Comparative evaluation across NVIDIA (5 gen), AMD (3 gen) GPUs and multiple CPU architectures
3. Discovery of compiler bugs and regressions on Frontier and El Capitan
