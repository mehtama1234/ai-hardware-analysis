# Testing and Benchmarking Emerging Supercomputers via the MFC Flow Solver

**Venue:** SC
**ID:** sc-2025-394
**Confidence:** low

## Problem
New supercomputers require systematic testing and evaluation; lack of portable, user-friendly benchmarking tools limits adoption validation.

## Motivation
CFD codes serve as valuable proxies for supercomputer evaluation; MFC provides a standardized testbed across generations of GPU and CPU architectures.

## Method
Multicomponent Flow Code (MFC) with automated toolchain for compilation, regression testing, and benchmarking across diverse hardware.

## Key Novelty
Portable CFD benchmarking framework that automatically identifies compiler bugs and performance regressions on emerging supercomputers.

## Contributions
1. Automated MFC benchmarking toolchain across 50+ compute devices and 5 flagship supercomputers
2. Comparative evaluation across NVIDIA (5 gen), AMD (3 gen) GPUs and multiple CPU architectures
3. Discovery of compiler bugs and regressions on Frontier and El Capitan
