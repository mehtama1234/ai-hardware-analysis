# Rewire: CGRA Mapping via Consolidated Multi-Node Routing

**Venue:** DAC | **ID:** dac-2025-186

## Summary
Rewire advances CGRA compilation by mapping multiple dataflow graph nodes jointly rather than individually, leveraging shared routing information and data dependencies as placement constraints. Achieves 2.1× performance improvement and 13.5× compilation time speedup vs. prior mappers.

## Key Results
- **Performance:** 2.1× improvement vs. prior mappers
- **Compilation Time:** 13.5× reduction (vs. first mapper); 4.7× speedup on second mapper
- **Approach:** Shareable routing propagation + dependency-constrained joint placement

## Technique
Generates shareable routing information across nodes via propagation; intersects routing sets to form placement candidates; uses data dependencies as constraints to jointly place multiple nodes simultaneously rather than individually.
