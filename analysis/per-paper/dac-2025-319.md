# HIVE: A High-Priority Victim Cache for Accelerating GPU Memory Accesses

## Problem
GPU memory hierarchies suffer when victim caches are accessed as secondary L1D miss handlers, causing high latency.

## Solution
HIVE inverts the victim cache hierarchy: handles memory requests at the victim cache level before L1D access, reducing critical path latency for memory-intensive workloads.

## Impact
77.1% performance improvement over baseline GPU; 21.7% over state-of-the-art cache design.
