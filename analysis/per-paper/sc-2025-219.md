# sc-2025-219: Compression Error Sensitivity in MoE Model Inference

## Overview
Analyzes how lossy compression of non-activated MoE experts affects inference accuracy across network layers.

## Key Problem
GPU memory constraints require offloading non-activated MoE experts to main memory. Data transfer becomes bottleneck; compression needed but error impact varies by layer.

## Approach
Apply error-bounded lossy compression algorithms (SZ3, CuSZp) to non-activated experts during inference. Analyze layer-dependent sensitivity to compression errors across various benchmarks.

## Key Findings
- **Shallow-layer experts**: Minimal accuracy degradation with bounded errors (safe to compress heavily)
- **Middle-layer experts**: Significant accuracy loss with bounded errors (critical to preserve)
- **Deep-layer experts**: Bounded errors sometimes improve accuracy (redundancy in instruction following)

## Contributions
- Systematic compression error sensitivity analysis across MoE layers
- Practical selective compression strategy
- Integration of error-bounded lossy compression into MoE inference
- Layer-specific compression guidance

## Compression Algorithms
- SZ3
- CuSZp

## Hardware Target
GPU clusters with limited GPU memory (multi-GPU systems)
