# FastNN: FPGA Accelerator for 3D Point Cloud KNN Search

**Venue:** DAC | **ID:** dac-2025-184 | **Type:** Late Breaking Results

## Summary
FastNN accelerates K-nearest neighbor search in point clouds via locality-sensitive E2LSH partitioning combined with a precomparator module, reducing candidate set by 58.57%-86.17% vs. octree and achieving 10.04× throughput improvement on FPGA.

## Key Results
- **Candidate Reduction:** 58.57%-86.17% vs. octree-based methods
- **Throughput:** 10.04× acceleration vs. BitNN comparator subsystem
- **Target:** FPGA-based 3D point cloud processing

## Technique
E2LSH partitioning pre-filters candidates; precomparator module further reduces search space; optimized Euclidean distance computation minimizes expensive calculations while maintaining precision.
