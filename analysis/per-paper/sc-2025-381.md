# Rethinking Back Transformation in 2-stage Eigenvalue Decomposition on Heterogeneous Architectures

**Venue:** SC
**ID:** sc-2025-381
**Confidence:** low

## Problem

2-stage EVD method loses performance advantage over 1-stage when computing eigenvectors via back transformation on GPUs.

## Motivation

Back transformation bottleneck limits applicability of efficient 2-stage EVD; need optimization for obtaining eigenvectors.

## Method

During bulge-chasing (the phase where computation shifts along the matrix diagonal), replace BLAS3 operations—which work on entire matrix blocks—with BLAS2 operations, which work on single vectors. Reorganize the workflow from a fixed backward sequence to a pattern that maximizes GPU parallelism, which hides the latency introduced by the divide-and-conquer decomposition.

## Key Novelty

The core insight is switching to BLAS2 operations and reorganizing the workflow for GPU parallelism during back transformation (computing the eigenvectors from the decomposition).

## Contributions

1. BLAS3-to-BLAS2 operation replacement
2. Parallelism-driven back transformation workflow
3. 3.58x speedup vs MAGMA
4. 2.62x vs MAGMA and 2.21x vs cuSOLVER for complete FP64 EVD
