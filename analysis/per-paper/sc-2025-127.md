# A Workflow for Error Analysis for Drug Response Prediction via Statistical Standardization and Distribution Analysis

**Venue:** SC
**ID:** sc-2025-127
**Confidence:** low

## Problem
Drug response prediction for cancer therapy requires high-throughput screening but faces severe class imbalance (rare promising drugs).

## Motivation
Personalized medicine demands accurate drug predictions; identifying promising candidates is critical for clinical deployment.

## Method
The workflow standardizes drug response measurements to a consistent scale, then analyzes how prediction errors are distributed across different drug types to identify which errors matter most in an imbalanced dataset. It was tested on the Aurora exascale supercomputer.

## Key Novelty
The core contribution is a step-by-step workflow that uses data standardization and error distribution analysis together to understand failures in drug response prediction when promising drugs are rare.

## Contributions
1. Statistical standardization for imbalanced drug problems
2. Distribution analysis methodology
3. Aurora supercomputer evaluation
