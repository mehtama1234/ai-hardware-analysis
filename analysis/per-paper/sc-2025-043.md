# sc-2025-043: Uno: A One-Stop Solution for Inter- and Intra-Data Center Congestion Control and Reliable Connectivity

## Summary
Uno is a unified network system for congestion control and load balancing in hybrid intra/inter-datacenter environments. Combines adaptive rate control, erasure coding, and adaptive routing to fairly handle traffic with different RTT characteristics.

## Problem
- Datacenters host both local and remote traffic simultaneously
- Intra-DC networks have fast RTT (~100µs)
- Inter-DC networks have slow RTT (milliseconds)
- Different RTTs require different control loop timescales
- Separate control loops cause unfairness and inefficiency

## Method
Uno treats all network traffic—whether within a data center or between distant ones—with a single unified system. It uses a transport protocol that quickly detects congestion and fairly adjusts each application's send rate to avoid starvation. It also spreads traffic across multiple paths using erasure coding (splitting data into redundant pieces so you can recover the original from fewer than all pieces) and adaptive routing that continuously selects the best path based on real-time network conditions.

## Key Innovations
1. **Unified control**: Single mechanism handles heterogeneous traffic types
2. **Fair rate control**: Accounts for RTT disparity in fairness model
3. **Erasure coding**: Improves reliability of inter-DC transfers
4. **Adaptive routing**: Dynamic balancing of traffic
