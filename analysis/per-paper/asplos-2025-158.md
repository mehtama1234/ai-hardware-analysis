# Fast On-device LLM Inference with NPUs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
On-device LLM inference on mobile NPUs incurs unacceptably high latency, particularly during the prefill stage, because existing NPU programming models are not designed to efficiently map the irregular, attention-heavy computation patterns of LLMs. Even mobile-sized models (e.g., Gemma-2B) run too slowly for interactive tasks such as screen UI understanding.

## Motivation
Growing privacy concerns and the availability of smaller open models are driving demand for fully on-device LLM inference, but mobile NPUs—which dominate edge SoCs—lack the software infrastructure to execute prefill efficiently.

## Method
The system first identifies where the mobile NPU (a specialized hardware chip for AI) becomes the bottleneck in LLM inference, then redesigns the inference pipeline to exploit how the NPU actually works. It merges multiple operations into single steps (operator fusion) and breaks computation into chunks that fit the NPU's memory layout. The approach specifically speeds up the prefill stage (where the model processes your initial prompt) by bundling token processing so the cost of invoking the NPU is shared across more work, and restructuring the attention computation (where the model decides which input parts matter) to fit the NPU's built-in hardware units.

## Key Novelty
The innovation is restructuring how language models focus on input (their attention mechanism) specifically for mobile AI chips, and combining operations to reduce the number of times the chip must be called.

## Contributions
- Characterization of prefill-stage bottlenecks on mobile NPUs for LLMs such as Gemma-2B
- NPU-optimized operator fusion and tiling strategy for attention and feed-forward layers
- Prefill pipeline that overlaps CPU and NPU execution to hide latency
- Demonstrated significant prefill speedup enabling practical on-device LLM inference
