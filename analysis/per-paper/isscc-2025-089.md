# isscc-2025-089: Multi-Mode Microscaling CIM Macro

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
CIM macros face INT/FP tradeoff (efficiency vs. accuracy); emerging microscaling formats need multi-mode support with: system-to-CIM transfer overhead, expensive adder trees, and inflexible data flows.

## Motivation
Optimal AI data format is workload-dependent; edge AI requires flexible CIM supporting MX-INT-FP without excessive overhead.

## Method
The design combines a 16-nanometer chip with 216 kilobytes of gain-cell memory that supports three formats: microscaling (a compact format), integer, and floating-point. It converts floating-point data to microscaling format inside the computation rather than beforehand, using a specialized unit that tracks signal variance to maintain accuracy. The adder tree—which sums partial results—is optimized for high-probability operations, reducing wasted work in common cases. The chip dynamically reconfigures how it accumulates results based on the precision needed at each step.

## Key Novelty
The core contribution is enabling a single CIM chip to support microscaling, integer, and floating-point formats by performing format conversion inside the computation and using a pattern-aware adder tree optimized for high-probability operations.

## Contributions
- 188.4 TOPS/W MX-MAC efficiency (MXINT8)
- 133.5 TFLOPS/W FP-MAC efficiency (BF16)
- In-CIM format conversion
- Pattern/accumulation-aware dataflow

## Metrics
- MX-MAC: 188.4 TOPS/W
- FP-MAC: 133.5 TFLOPS/W
- Technology: 16nm
- Macro: 216 kb
