# Defense in the Reverse Fragment: RL-Based Partial Netlist Hardware Trojan Detection

**Venue:** ICCAD  
**ID:** iccad-2025-104

## Problem
Hardware Trojan detection methods assume complete netlists, but practical reverse engineering yields incomplete/partial information, reducing detection accuracy and stability.

## Motivation
Enable practical hardware Trojan detection from partial netlist information obtained through reverse engineering of real circuits.

## Method
RE-PNRL: Reinforcement Learning-based framework for reconstructing partial netlists using node-level transition probabilities. Clustering-based hardware Trojan detection using complete netlist reconstruction.

## Key Novelty
First hardware Trojan detection framework addressing practical partial-netlist scenarios from reverse engineering.

## Contributions
- 66.39% TPR and 73.72% TNR on partial-netlist HT detection
- 96.80% TPR and 94.80% TNR on clustering-based complete-netlist detection
- RL-based netlist reconstruction from partial information
- Effective across different levels of netlist missingness
- Validated on Trojan benchmarks
