# PS-GS: Group-Wise Parallel Rendering with Stage-Wise Complexity Reductions for Real-Time 3D Gaussian Splatting

**Venue**: DATE  
**Primary Theme**: Parallel 3D Gaussian Splatting  

## Problem
3D Gaussian Splatting rendering is computationally expensive; deploying real-time 3D-GS on mobile and edge devices is challenging despite its superior speed and quality advantage over NeRF.

## Method
PS-GS divides the rendering scene into groups of Gaussians (the 3D blob-like primitives used in Gaussian Splatting), adapting each group's composition to the camera viewpoint so that each stage handles simpler work. Preprocessing clusters the data and sorts by depth (distance from camera), and these stages flow through a hardware pipeline where different stages can process different groups simultaneously—while one group renders, the next is being prepared. This parallel processing of groups through multiple stages, combined with reduced complexity at each stage, enables real-time rendering on resource-constrained devices.

## Key Novelty
The core idea is to use approximate Gaussian ordering (fast but not perfect) to divide work into groups that can flow through multiple pipeline stages at the same time.

## Contributions
- Observation that 3D-GS rendering parallelism requires pre-known approximate Gaussian ordering
- Cluster-based preprocessing for efficient Gaussian grouping
- Low-complexity depth-based sorting and grouping techniques
- PS-GS hardware architecture achieving 1.20x average speedup with negligible PSNR degradation
