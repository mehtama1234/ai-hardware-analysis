# PISA: Efficient Precision-Slice Framework for LLMs with Adaptive Numerical Type

**Venue:** DAC
**ID:** dac-2025-385

## Problem
LLM quantization is ineffective due to outliers; mixed-precision approaches suffer from value-wise granularity and complex encoding/decoding hardware.

## Motivation
On-device LLM deployment requires extreme efficiency; outliers in weight distributions prevent aggressive quantization.

## Method
PISA splits 16-bit values into 4-bit/12-bit format, exploiting sparsity in higher-order bits. An early bird mechanism uses high-order 4-bit computation to predict result importance, enabling efficient computational skips. Integrates with systolic arrays.

## Key Novelty
Precision-slice splitting with early bird prediction mechanism enabling computational skipping based on high-order bits.

## Contributions
1. Precision-slice 16-bit to 4-bit/12-bit splitting exploiting higher-order bit sparsity
2. Early bird mechanism predicting computation importance from 4-bit results for efficient skipping
3. Integration with existing accelerators (systolic arrays) without complex encoding/decoding
4. 1.3-4.3x performance boost, 14.3-66.7% energy efficiency improvement, minimal accuracy loss
