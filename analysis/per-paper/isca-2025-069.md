# isca-2025-069 — Profile-Guided Temporal Prefetching

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Temporal prefetching for irregular memory access patterns requires on-chip metadata to record and replay past access sequences; existing on-chip metadata storage is capacity-limited, and prior software-guided approaches fail to optimize metadata management effectively (achieving only 0.1% performance gain), leaving hardware temporal prefetchers significantly underperforming their potential.

## Motivation
Irregular memory access patterns in server and data-intensive workloads cause temporal prefetchers to thrash their limited on-chip metadata stores; profile-guided hints can steer metadata management far more efficiently than dynamic-only policies, but prior software approaches lacked adaptive per-input tuning.

## Method
Prophet is a hardware-software co-designed framework that profiles programs using lightweight hardware counters (not full access traces), injects binary hints to guide the hardware temporal prefetcher's metadata storage management at runtime, and dynamically tunes those hints to adapt to different program inputs. Prophet coexists with existing hardware temporal prefetchers: it applies optimized metadata management for frequently executed hot paths while the original hardware scheme handles less frequent paths.

## Key Novelty
Prophet uses counter-based profiling combined with binary-injected hints and dynamic runtime tuning to guide on-chip metadata storage management for temporal prefetchers, enabling input-adaptive optimization without re-profiling.

## Contributions
1. A counter-based profiling methodology generating metadata storage hints with negligible overhead.
2. A binary annotation mechanism injecting runtime hints to steer temporal prefetcher metadata management.
3. Dynamic in-binary hint tuning adapting to varying program inputs without re-profiling.
4. 14.23% improvement over Triangel (state-of-the-art temporal prefetcher), vs. 0.1% for prior profile-guided methods.
