# Scalio: Scaling up DPU-based JBOF Key-value Store with NVMe-oF Target Offload

**Problem:** Scaling distributed key-value stores in JBOF architectures faces CPU bottlenecks from NVMe-oF target-side processing. Current designs waste CPU cycles on storage protocol operations, limiting throughput and scalability.

**Method:** Scalio uses specialized processor chips called DPUs (Data Processing Units) instead of the main CPU to handle storage network operations. When a key-value store reads or writes data across multiple storage boxes, the DPU manages the storage protocol work (NVMe-oF, which sends storage data over a network), data movement, and storage-specific tasks. This frees the main CPU to focus entirely on running the key-value store application. By using hardware built specifically for I/O-intensive work, Scalio reduces CPU overhead that normally limits throughput in large-scale JBOF systems.

**Novelty:** Scalio eliminates CPU bottlenecks by moving storage network processing (NVMe-oF target operations) from the main CPU to specialized DPU chips.
