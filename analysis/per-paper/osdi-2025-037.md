# Scalio: Scaling up DPU-based JBOF Key-value Store with NVMe-oF Target Offload

**Problem:** Scaling distributed key-value stores in JBOF architectures faces CPU bottlenecks from NVMe-oF target-side processing. Current designs waste CPU cycles on storage protocol operations, limiting throughput and scalability.

**Method:** Scalio offloads NVMe-oF target processing to Data Processing Units (DPUs) instead of CPUs. The DPU handles storage protocol operations, data movement, and target-side NVMe-oF logic, liberating CPU resources for application workloads. This architecture reduces CPU overhead through hardware specialization for I/O-intensive operations across JBOF nodes.

**Novelty:** Offloading NVMe-oF target functionality to DPUs to eliminate CPU bottlenecks in JBOF-based key-value store scaling.
