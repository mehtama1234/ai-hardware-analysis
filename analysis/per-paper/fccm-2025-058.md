# Microscaling Vision Transformers on FPGAs

**Problem:** Vision Transformer models contain complex arithmetic operations (Softmax, LayerNorm) sensitive to quantization that cannot be mapped to efficient low-precision hardware. Existing methods only accelerate matrix multiplication on hardware while offloading complex operations to CPU, causing communication overhead and suboptimal performance.

**Method:** The team built an FPGA accelerator (a specialized reconfigurable chip) using a compact number format called Microscaling Integer (MXInt) that can handle all Vision Transformer operations while maintaining accuracy, including complex operations like Softmax and LayerNorm. They developed custom hardware circuits that run these complex operations using mathematical approximations designed specifically for the MXInt format. Previous accelerators could only efficiently run multiplication on the FPGA and had to send complex operations to the CPU, creating communication delays; keeping everything on the FPGA eliminates this bottleneck.

**Novelty:** This is the first Vision Transformer accelerator to perform all operations—including the complex arithmetic functions normally offloaded to the CPU—directly on an FPGA using Microscaling Integer format.
