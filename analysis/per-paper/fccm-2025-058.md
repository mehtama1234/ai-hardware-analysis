# Microscaling Vision Transformers on FPGAs

**Problem:** Vision Transformer models contain complex arithmetic operations (Softmax, LayerNorm) sensitive to quantization that cannot be mapped to efficient low-precision hardware. Existing methods only accelerate matrix multiplication on hardware while offloading complex operations to CPU, causing communication overhead and suboptimal performance.

**Method:** The authors propose an FPGA accelerator using the Microscaling Integer (MXInt) arithmetic format to quantize all ViT operations. They develop MXInt-specific approximation methods that map complex arithmetic operations (Softmax, LayerNorm) into custom hardware circuits, eliminating CPU involvement and reducing communication overhead.

**Novelty:** First ViT accelerator to map all operations including complex arithmetic functions onto FPGAs using MXInt format instead of offloading to CPU.
