# Bin2Wrong: a Unified Fuzzing Framework for Uncovering Semantic Errors in Binary-to-C Decompilers

**Problem:** Binary-to-C decompilers produce semantic errors where decompiled C code has different runtime behavior than the original binary. Existing decompilers lack systematic testing to identify correctness issues.

**Method:** Bin2Wrong generates random test binaries and passes them to target decompilers to produce C code versions. It then compares the original binary and decompiled C code to see if they behave identically when executed. To find where they diverge, it analyzes the control flow (the sequence and branching of operations) and data dependencies (which values depend on which other values) in both versions to spot semantic errors—cases where the decompiled C runs differently than the original.

**Novelty:** An automated framework that generates test binaries to systematically find semantic errors—cases where decompiled C code behaves differently than the original—across multiple decompilers.
