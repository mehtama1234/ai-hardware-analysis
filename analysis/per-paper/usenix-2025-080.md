# Bin2Wrong: a Unified Fuzzing Framework for Uncovering Semantic Errors in Binary-to-C Decompilers

**Problem:** Binary-to-C decompilers produce semantic errors where decompiled C code has different runtime behavior than the original binary. Existing decompilers lack systematic testing to identify correctness issues.

**Method:** Bin2Wrong implements a unified fuzzing framework that systematically generates test binaries, decompiles them using target decompilers, and compares semantic equivalence between original and decompiled code. The framework extracts control flow and data dependencies to identify cases where decompiled C exhibits different behavior than the original binary.

**Novelty:** A unified automated fuzzing framework specifically designed to systematically discover semantic errors across multiple binary-to-C decompilers.
