# A Precision-Steerable Electromigration Solver with Physics-Informed Adaptive Graph Partitioning

**Venue:** ICCAD  
**ID:** iccad-2025-123

## Problem
Solving Korhonen's equation for multi-segment interconnect line models becomes increasingly challenging as technology scales; traditional FEM-based methods are computationally expensive.

## Motivation
Electromigration reliability is increasingly critical as circuit density rises; faster and more scalable EM analysis is essential for modern VLSI design.

## Method
Physics-Informed Message Passing Neural network (PIMNEM) architecture for solving coupled multi-domain Korhonen equations; AdaptEM incorporates hierarchical graph partitioning with unsupervised training on subgraphs and fine-tuning with boundary constraints.

## Key Novelty
Physics-informed graph neural networks with hierarchical adaptive partitioning for scalable multi-scale EM analysis.

## Contributions
- Physics-Informed Message Passing (PIMNEM) architecture for coupled Korhonen equations
- AdaptEM with adaptive graph partitioning and hierarchical training strategy
- Hierarchical unsupervised learning framework for generalization
