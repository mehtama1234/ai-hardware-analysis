# A Precision-Steerable Electromigration Solver with Physics-Informed Adaptive Graph Partitioning

**Venue:** ICCAD  
**ID:** iccad-2025-123

## Problem
Solving Korhonen's equation for multi-segment interconnect line models becomes increasingly challenging as technology scales; traditional FEM-based methods are computationally expensive.

## Motivation
Electromigration reliability is increasingly critical as circuit density rises; faster and more scalable EM analysis is essential for modern VLSI design.

## Method
The approach uses a Physics-Informed Message Passing Neural Network (PIMNEM)—a neural network that bakes in the physics of Korhonen's equation, which models how electromigration damages interconnects. To handle large, complex interconnect patterns, it uses hierarchical graph partitioning (recursively dividing the interconnect network into smaller subgraphs). Each piece is trained on its own without labeled data, then the full system is fine-tuned using boundary constraints that enforce correct predictions where the pieces meet.

## Key Novelty
Combining physics-informed graph neural networks with hierarchical adaptive partitioning makes it possible to solve multi-scale electromigration equations on large interconnect networks efficiently.

## Contributions
- Physics-Informed Message Passing (PIMNEM) architecture for coupled Korhonen equations
- AdaptEM with adaptive graph partitioning and hierarchical training strategy
- Hierarchical unsupervised learning framework for generalization
