# TAPAS: Thermal- and Power-Aware Scheduling for LLM Inference in Cloud Platforms

**Venue:** ASPLOS  
**Authors:** Jovan Stojkovic, Chaojie Zhang, Inigo Goiri, Esha Choukse, Haoran Qiu, Rodrigo Fonseca, Josep Torrellas, Ricardo Bianchini  
**Confidence:** low (abstract only)

## Problem
LLM inference workloads exhibit fine-grained millisecond-scale phase transitions (prefill vs. decode) with distinct thermal and power profiles, which traditional cloud thermal and power management techniques are too coarse-grained to handle. Cloud co-location of SaaS and IaaS workloads with differing visibility further complicates scheduling.

## Motivation
Rising demand for generative LLM inference in cloud datacenters creates unprecedented thermal and power management challenges because inference phases switch faster than conventional thermal control loops can respond, risking throttling, SLA violations, and hardware damage.

## Method
TAPAS is a thermal- and power-aware scheduler for LLM inference that models per-phase (prefill/decode) thermal and power profiles at millisecond granularity. It leverages LLM configuration parameters (model parallelism, model size, quantization level) as scheduling knobs to trade off performance, temperature, power, and output quality. The scheduler handles co-located SaaS and IaaS workloads with different control strategies depending on visibility and flexibility.

## Key Novelty
A scheduler that explicitly models millisecond-scale thermal and power phase transitions of LLM inference and uses quantization, parallelism, and model size as scheduling knobs to jointly optimize thermal, power, and performance objectives in a multi-tenant cloud.

## Contributions
- Characterization of fine-grained thermal and power profiles across LLM inference phases at millisecond granularity
- TAPAS: a thermal- and power-aware LLM inference scheduler using model configuration parameters as control knobs
- Multi-tenant scheduling strategy handling SaaS and IaaS workloads with different visibility levels
- Trade-off analysis between performance, temperature, power, and output quality in LLM inference
