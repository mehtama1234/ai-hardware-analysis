# REMU: Memory-aware Radiation Emulation via Dual Addressing for In-orbit Deep Learning System

## Summary
Memory-aware radiation emulator for space-deployed GPUs that precisely links DRAM-level radiation faults to runtime DNN behavior.

## Key Results
- Evaluated on **10 DNN models**
- Tested on **2 in-orbit computing tasks**

## Core Innovation
First dual-addressing mechanism mapping radiation errors across virtual-physical-DRAM boundaries to capture fault effects on DNN inference.

## Technique
Dual addressing across memory hierarchy (virtual, physical, DRAM) to inject radiation-induced errors and observe DNN runtime behavior changes.
