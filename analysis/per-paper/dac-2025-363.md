# Exploiting Power Side-Channel Vulnerabilities in XGBoost Accelerator

## Summary
Demonstrates power side-channel attacks on FPGA-accelerated XGBoost that leak sensitive model data through power consumption monitoring.

## Key Results
- **367k tests** sufficient to leak sensitive values
- **95.6% accuracy** in fingerprinting operations

## Core Innovation
First hardware-level power side-channel attack on accelerated XGBoost showing how power variations reveal decision tree structure and node features.

## Technique
Reverse-engineer RDMA NIC and XGBoost accelerator behavior via microbenchmarks; construct covert channels by monitoring power consumption to infer model structure.
