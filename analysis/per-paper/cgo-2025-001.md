# Cage: Hardware-Accelerated Safe WebAssembly

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
WASM applications in unsafe languages lack memory safety despite WASM's sandboxing, and sandboxing itself incurs overhead. Need efficient memory safety for ubiquitous WASM deployment.

## Technical Approach
Leverages Arm Memory Tagging Extension (MTE) for spatial/temporal memory safety on heap and stack, and Arm Pointer Authentication (PAC) to prevent pointer reuse. LLVM compiler toolchain applies function wrappers and instrumentation to unmodified WASM.

## Key Novelty
First system to leverage Arm MTE and PAC to provide both memory safety and improve WASM sandboxing performance.

## Key Results
- 5.1% speedup of WASM sandboxing
- <5.8% runtime overhead, <3.7% memory overhead
- Spatial and temporal safety for heap and stack

## Hardware & Techniques
- **Target:** CPU (Arm MTE/PAC)
- **Techniques:** Memory tagging, pointer authentication, security
