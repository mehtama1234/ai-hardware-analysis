# TraceFlow: Efficient Trace Analysis for Large-Scale Parallel Applications via Interaction Pattern-Aware Trace Distribution

**Venue:** SC
**Paper ID:** sc-2025-006
**Confidence:** low

## Problem Statement
Large-scale trace analysis must handle vast datasets; current parallel trace analysis introduces inter-process communications to fetch non-local event data, causing bottlenecks

## Motivation
Understanding parallel application interaction behaviors (synchronization, async overlaps) is critical for optimization; trace size explodes with scale; communication overhead limits analysis speed

## Method
TraceFlow performs static program analysis on the source code beforehand to identify interaction patterns—which parts of the program communicate with each other. Based on this understanding, it partitions trace events so that events from interacting parts are assigned to the same analysis process. This strategy eliminates the inter-process communication that normally bottlenecks large-scale trace analysis.

## Key Novelty
Static program analysis enables communication-free trace analysis by directing related trace events to the same process based on code interaction patterns.
