# TraceFlow: Efficient Trace Analysis for Large-Scale Parallel Applications via Interaction Pattern-Aware Trace Distribution

**Venue:** SC
**Paper ID:** sc-2025-006
**Confidence:** low

## Problem Statement
Large-scale trace analysis must handle vast datasets; current parallel trace analysis introduces inter-process communications to fetch non-local event data, causing bottlenecks

## Motivation
Understanding parallel application interaction behaviors (synchronization, async overlaps) is critical for optimization; trace size explodes with scale; communication overhead limits analysis speed

## Method
Interaction pattern-aware trace distribution (TraceFlow); leverage static program structures and interaction patterns for global perspective; distribute correlated events to same processes to minimize inter-process communication

## Key Novelty
Communication-free trace analysis via interaction-aware event distribution; static program analysis to guide trace partitioning

## Contributions
- Interaction pattern-aware trace distribution strategy

- Static program structure analysis for partitioning
