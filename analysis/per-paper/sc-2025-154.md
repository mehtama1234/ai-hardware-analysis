# SC-2025-154: Code Coverage for MPI Correctness Testing

## Summary
Uses code coverage analysis to identify gaps in MPI-BugBench (MBB), an MPI correctness testing framework. Adds 34 new tests to improve feature coverage.

## Problem
- MBB relies on pruning real-world usage patterns; misses edge cases
- Coverage of MPI tools (MUST, PARCOACH, clang-tidy) incomplete
- Missing features: varying-count collectives, loops, array handles
- Limited code structure diversity

## Key Finding
Single varying-count collectives test adds **770 covered lines** in MUST—demonstrating significant gaps in existing test suite.

## Contributions
1. Code coverage analysis of MBB against 3 MPI correctness tools
2. Identification of missing MPI features
3. 34 new targeted test cases
4. Quantification of coverage improvements

## Tested Tools
- **MUST**: MPI runtime correctness checking
- **PARCOACH**: Static analysis for MPI programs
- **clang-tidy**: C++ static analysis (MPI support)

## Limitations
- No data on false positive/negative rates
- Coverage analysis limited to 3 tools
- Full extent of missing features not characterized

## Implications
- MPI correctness verification tools need more comprehensive testing
- Feature gap testing critical for parallel application debugging
- Coverage-driven test generation effective for finding tool blind spots
