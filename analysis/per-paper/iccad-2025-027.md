# SO3-Cell: Standard Cell Layout Automation Framework for Simultaneous Optimization of Topology, Placement, and Routing

**Venue:** ICCAD  
**ID:** iccad-2025-027

## Problem
Standard cell layout design lacks automated simultaneous optimization of circuit topology, transistor placement, and internal routing; traditional sequential approaches are suboptimal.

## Motivation
Custom cell layouts with optimized area, power, and timing require integrated design space exploration.

## Method
The framework uses Mixed-Integer Linear Programming—a mathematical technique for finding the best solution among many options while respecting design constraints—to optimize three things simultaneously: how transistors are connected together (topology), where they're physically positioned (placement), and how the wires between them are routed. To keep computation manageable, the approach uses design space pruning, which eliminates obviously suboptimal combinations before solving, so the optimizer focuses on the most promising possibilities.

## Key Novelty
This is the first automatic framework to optimize circuit topology, transistor placement, and wiring routes all at the same time using Mixed-Integer Linear Programming.

## Contributions
- MILP formulation for simultaneous topology, placement, and routing
- Design space pruning techniques for scalability
- Scalability to 44-transistor 2-bit flip-flop
- 35% power reduction, 2.2% frequency improvement, 31.1% area reduction
