# SO3-Cell: Standard Cell Layout Automation Framework for Simultaneous Optimization of Topology, Placement, and Routing

**Venue:** ICCAD  
**ID:** iccad-2025-027

## Problem
Standard cell layout design lacks automated simultaneous optimization of circuit topology, transistor placement, and internal routing; traditional sequential approaches are suboptimal.

## Motivation
Custom cell layouts with optimized area, power, and timing require integrated design space exploration.

## Method
Mixed-Integer Linear Programming (MILP) formulation for simultaneous topology, placement, and routing optimization; design space pruning techniques for scalability.

## Key Novelty
First automatic standard cell layout framework using MILP for simultaneous T+P+R optimization.

## Contributions
- MILP formulation for simultaneous topology, placement, and routing
- Design space pruning techniques for scalability
- Scalability to 44-transistor 2-bit flip-flop
- 35% power reduction, 2.2% frequency improvement, 31.1% area reduction
