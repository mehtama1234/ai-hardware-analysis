# Defending Side-Channel Attacks in Convolutional Neural Networks with Channel-Level Parallelization

**Problem:** Side-channel attacks exploit power and timing information leakage to compromise neural networks deployed on hardware platforms, particularly in untrusted cloud FPGA environments where attackers can extract sensitive information.

**Method:** The technique processes multiple input channels of a neural network layer at the same time, rather than one after another. When channels run in parallel, the pattern of electrical activity in the chip (which attackers can measure through power consumption or timing) no longer matches what the network is actually computing—instead of a clear signal for each computation step, attackers see a jumbled mix. This works because attackers rely on spotting predictable power spikes or timing delays to figure out what the network is doing. The parallel design can be adjusted to either use minimal extra hardware resources or achieve faster execution.

**Novelty:** Processing multiple input channels in parallel simultaneously makes side-channel attacks harder while letting designers choose whether to prioritize using less hardware or running faster.
