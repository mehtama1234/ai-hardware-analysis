# DRSA: Accelerating Macro Placement on Commercial FPGAs

**Problem:** FPGA macro-component placement in DynaRapid creates a bottleneck where the existing greedy placement strategy causes significant frequency degradation, limiting the practical benefits of macro-based fast compilation.

**Method:** DRSA replaces a greedy approach (choosing the best position for each circuit block one at a time without considering future steps) with simulated annealing, an optimization algorithm that explores many different overall arrangements to find ones that work well together. It iteratively adjusts where the macro components (large circuit blocks) are positioned on the FPGA to minimize the drop in operating frequency, discovering combinations that greedy placement would overlook. This keeps DynaRapid's advantage of fast compilation while fixing the frequency loss that was the main bottleneck.

**Novelty:** Using simulated annealing instead of greedy placement for macro components in DynaRapid solves the operating-frequency loss without sacrificing compilation speed.
