# Parallel Rank-Adaptive Tensor Decomposition

## Problem
Tucker decomposition requires fixed rank selection, potentially suboptimal for variable compressibility. Fixed-rank methods like STHOSVD may miss better compression opportunities.

## Approach
Rank-adaptive HOOI (Higher Order Orthogonal Iteration):
1. Determine ranks adaptively to meet error targets
2. Optimize per-iteration cost
3. Parallel scaling to thousands of cores

## Results
- **82x faster** than STHOSVD on 3D fluid-flow
- **50% better** compression ratio on same data
- Scales efficiently on large clusters

## Key Insight
Adaptive rank selection outperforms fixed-rank methods in high-compression regimes. HOOI's iteration strategy is competitive when ranks are chosen optimally.

## Applications
- Large-scale scientific simulation data
- Tensor compression
- Memory-limited HPC systems
