# HILP: Accounting for Workload-Level Parallelism in System-on-Chip Design Space Exploration

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Early-stage heterogeneous SoC design space exploration tools (MultiAmdahl, Gables) only model minimum and maximum workload-level parallelism (WLP) extremes; they cannot model realistic mixed-application workloads where multiple independent multi-phase applications share an SoC's heterogeneous cores and accelerators.

## Motivation
Modern SoCs are designed for workloads—sets of concurrent applications—not single applications, so failing to account for realistic WLP during early design space exploration causes later-stage analysis to focus on suboptimal design points, wasting expensive engineering effort.

## Method
HILP schedules multiple independent applications—each with phases that must run in sequence—across a shared set of heterogeneous cores and accelerators, minimizing total execution time while respecting power and memory bandwidth constraints. To do this, it formulates the scheduling problem as a job-shop scheduling problem (where different types of work must be assigned to different types of machines) and solves it using integer linear programming, a mathematical technique that converts all constraints into equations and finds the best solution. This approach captures the full spectrum of how applications can run in parallel, not just the minimum and maximum extremes, making it suitable for exploring many different hardware configurations during early design.

## Key Novelty
By formulating heterogeneous SoC workload scheduling as a job-shop scheduling problem (where different applications are assigned to different processor types) solved with integer linear programming, this work enables early exploration of the full spectrum of realistic parallelism instead of just the extreme cases.

## Contributions
1. HILP: first early-stage DSE approach for heterogeneous SoCs that fully models workload-level parallelism
2. Job-shop scheduling ILP formulation capturing phase-level dependencies across concurrent multi-phase applications
3. Validation showing HILP recovers Amdahl's law, memory wall, and dark silicon effects
4. Demonstration that modeling WLP is necessary to identify optimal design points in large heterogeneous SoC design spaces

## Limitations
