# Weaver: Efficient Multi-LLM Serving with Attention Offloading

**Problem:** Serving multiple LLMs concurrently requires substantial GPU memory and compute for attention operations, which become a critical bottleneck when scheduling multiple models and inference requests together.

**Method:** When serving multiple large language models simultaneously, GPUs hit a bottleneck: attention operations (the computational step where the model decides what to focus on) consume massive amounts of GPU memory and processing power. Weaver fixes this by moving these attention calculations to the CPU or auxiliary memory instead, freeing up GPU resources. By scheduling attention operations separately and managing data movement between the GPU and these alternative resources, the system can serve more models concurrently.

**Novelty:** The key insight is treating attention operations (the memory-intensive step where the model decides what words to focus on) as a separate offloading problem—instead of serving the entire model together—so more language models can run on the same GPU.
