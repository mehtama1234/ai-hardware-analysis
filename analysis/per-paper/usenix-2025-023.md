# Weaver: Efficient Multi-LLM Serving with Attention Offloading

**Problem:** Serving multiple LLMs concurrently requires substantial GPU memory and compute for attention operations, which become a critical bottleneck when scheduling multiple models and inference requests together.

**Method:** Weaver offloads attention computation from GPUs to alternative compute resources (CPU or auxiliary memory hierarchy), reducing GPU memory pressure and enabling concurrent serving of more models. The system schedules attention operations separately and manages data movement between execution units.

**Novelty:** Selective offloading of attention operations as a distinct serving optimization to decouple memory-intensive attention from other model layers.
