# VIRTUAL: Vector-based Dynamic Power Estimation via Decoupled Multi-Modality Learning

**Venue:** ICCAD  
**ID:** iccad-2025-131

## Problem
Dynamic power analysis requires gate-level synthesis and simulation, creating critical bottleneck in iterative design flows; estimating power directly from RTL is challenging without manual feature engineering.

## Motivation
Faster power estimation enables rapid design iteration and optimization.

## Method
The approach uses two separate analysis paths: a transformer neural network finds timing patterns in the voltage/current waveforms at chip inputs, while a graph neural network analyzes the structural relationships in the hardware design code (RTL). These separate analyses are then aligned through self-supervised contrastive learning (training by comparing different versions of the data) and combined using a lightweight fusion module. Finally, a power prediction layer estimates the power consumption for one clock cycle.

## Key Novelty
The key insight is processing waveform timing patterns and circuit structure through separate analytical pathways before combining them to predict power consumption.

## Contributions
- Transformer-based encoder for waveform temporal pattern extraction
- Graph neural network for RTL structural dependency modeling
- Self-supervised contrastive learning across sequential and graph modalities
