# VIRTUAL: Vector-based Dynamic Power Estimation via Decoupled Multi-Modality Learning

**Venue:** ICCAD  
**ID:** iccad-2025-131

## Problem
Dynamic power analysis requires gate-level synthesis and simulation, creating critical bottleneck in iterative design flows; estimating power directly from RTL is challenging without manual feature engineering.

## Motivation
Faster power estimation enables rapid design iteration and optimization.

## Method
Multi-modality learning framework with decoupled feature extraction: transformer encoder extracts temporal patterns from input port waveforms, GNN captures structural dependencies from RTL; self-supervised contrastive learning across modalities, lightweight fusion module for embeddings, power prediction head for fixed clock period estimation.

## Key Novelty
Decoupled multi-modality learning combining waveform temporal patterns and RTL structural features for power estimation.

## Contributions
- Transformer-based encoder for waveform temporal pattern extraction
- Graph neural network for RTL structural dependency modeling
- Self-supervised contrastive learning across sequential and graph modalities
