# AASD: Accelerate Inference by Aligning Speculative Decoding in Multimodal Large Language Models

**Venue:** DAC
**ID:** dac-2025-379

## Problem
Multimodal LLM inference is slow due to auto-regressive decoding with long token sequences; traditional acceleration methods compromise quality or multimodal integration.

## Motivation
Speculative decoding can accelerate inference; alignment between draft and target models in multimodal settings is challenging due to complex token dependencies.

## Method
AASD accelerates language model inference through speculative decoding—a technique where multiple tokens are predicted quickly and then verified by the full model. It reuses the cached key-value pairs (reusable intermediate calculations from processing earlier tokens) from the full model to quickly generate draft predictions. A compression layer (KV Projector) reduces the size of this cache while preserving accuracy-critical information. A special attention mechanism (Target-Draft Attention) then aligns the draft predictions with the full model's output, efficiently accepting or rejecting each draft without compromising quality or multimodal understanding.

## Key Novelty
The key novelty is the Target-Draft Attention mechanism, which aligns predictions between fast draft and full target models during speculative decoding (predicting tokens quickly then verifying them) for multimodal language models.

## Contributions
1. Speculative decoding framework using target model KV pairs for efficient draft token generation
2. KV Projector for lossless KV cache compression maintaining representational fidelity
3. Target-Draft Attention mechanism optimizing draft-target alignment
4. Up to 2x inference speedup without accuracy loss across mainstream MLLMs
