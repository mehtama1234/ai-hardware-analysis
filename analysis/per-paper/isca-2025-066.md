# isca-2025-066 — ANSMET: Approximate Nearest Neighbor Search with Near-Memory Processing and Hybrid Early Termination

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
ANNS over large high-dimensional vector databases is both highly memory-bound and computationally wasteful: many fetched vectors and their distance computations are ultimately discarded because they are far from the query, resulting in excess memory traffic and low data utilization.

## Motivation
Vector databases are growing rapidly for LLM retrieval-augmented generation and recommendation systems; ANNS at scale requires processing billions of high-dimensional vectors with tight latency budgets, making bandwidth waste and unnecessary computation a critical bottleneck.

## Method
ANSMET puts a small processor inside each memory rank (a unit of physical memory) that calculates distances right where data lives, rather than sending all vectors to the main CPU. For each candidate vector, the system quickly estimates the distance using partial data (a subset of dimensions or bits); this estimate is guaranteed to be at most the true distance, so if it already exceeds the target threshold, the fetch stops immediately. Memory is laid out to support these early-stop decisions, and a simple protocol between the host CPU and memory processors handles index traversal and result sorting.

## Key Novelty
ANSMET uses conservative estimates from partial data (partial dimensions and bits) to stop fetching vectors early, with this early-termination logic embedded in memory-rank processors to eliminate wasted bandwidth for far-away candidates.

## Contributions
1. A rank-level NDP architecture offloading ANNS distance calculation, eliminating off-chip data movement for rejected vectors.
2. A hybrid early termination strategy combining partial-dimension and partial-bit lower-bound estimation.
3. Co-optimized data layout within and across memory ranks for early termination granularity.
4. 5.26x average speedup from NDP; additional 1.52x from hybrid early termination.
