# Fast ACS: Low-Latency File-Based Ordered Message Delivery at Scale

**Problem:** Delivering messages with ordering and at-least-once delivery guarantees across clusters to thousands of consumers while maintaining low latency and enabling consumer-controlled pacing.

**Method:** Fast ACS minimizes message delivery time by choosing different communication strategies based on whether the destination is nearby or far away. For machines within the same cluster, it uses RMA (one-sided communication: the sender directly writes to the receiver's memory without waiting for permission), which is fast. For distant machines across different clusters, it uses RPC (request-response messaging: the sender asks and waits for a reply), which is slower but more reliable over long distances. The system stores all messages in files to guarantee they arrive in the correct order.

**Novelty:** The system uses fast direct-memory delivery for nearby machines and slower request-response delivery for distant clusters, automatically choosing which method to use based on message distance.
