# Optimizing Input Minimization in Kernel Fuzzing

**Problem:** Input minimization in kernel fuzzing is computationally expensive, requiring repeated kernel executions to identify minimal crash-triggering inputs, creating a bottleneck in fuzzing campaigns.

**Method:** The approach breaks the input into sections and uses binary search to identify which ones are necessary to trigger the crash (a technique called delta-debugging). Rather than running the kernel repeatedly from scratch, it predicts which input changes won't affect the crash by reusing information from previous runs, skipping unnecessary kernel executions. It also parallelizes multiple minimization attempts to speed up the overall process.

**Novelty:** It skips redundant kernel executions during minimization by predicting which parts of the input are unnecessary for the crash, based on observations from previous runs.
