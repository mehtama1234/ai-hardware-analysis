# FeNOMS - In-storage Processing on 3D FeNAND for MS Spectral Search

FeNOMS implements hyperdimensional computing directly within 3D FeNAND memory to accelerate mass spectrometry spectral search without moving data to external processors. By processing queries at the storage layer, the system eliminates data movement bottlenecks and achieves 43× speedup over traditional architectures. This work demonstrates the viability of near-data processing for scientific applications and highlights how specialized algorithms like hyperdimensional computing can be effectively embedded in emerging storage technologies.
