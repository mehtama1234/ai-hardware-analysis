# Pin Efficient Tri-Level Based Inductive Coupling Transceiver for 3D ICs

**Venue:** VLSID
**Authors:** Soumojit Bakshi, V. K. Surya, Nijwm Wary

## Problem Statement
This paper presents a tri-level coded differential signaling scheme for data transmission across 3D stacked ICs using inductive coupling links

## Key Innovation
Novel propose approach

## Method
The transmitter sends data through inductive coupling links (electromagnetic connections between stacked chip layers) using differential signaling, which transmits both a signal and its inverse to cancel electrical noise. Instead of using two voltage levels like conventional systems, this design encodes information with three levels, fitting more data into each transmission cycle. The tri-level differential approach achieves a 5× improvement in signal-to-noise ratio while maintaining the same number of pins per unit area, making each connection point more efficient for densely stacked 3D circuits.
