# Pin Efficient Tri-Level Based Inductive Coupling Transceiver for 3D ICs

**Venue:** VLSID
**Authors:** Soumojit Bakshi, V. K. Surya, Nijwm Wary

## Problem Statement
This paper presents a tri-level coded differential signaling scheme for data transmission across 3D stacked ICs using inductive coupling links
