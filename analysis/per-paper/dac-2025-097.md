# SCONE: Logic Locking via SMT Solver and Circuit Encoding

## Problem
Stripped-Functionality Logic Locking (SFLL) with Distance-2 Protected Input Patterns (D2PIPs) suffers from poor scalability, limited flexibility, and vulnerabilities to advanced structural attacks.

## Method
SCONE combines SMT (Satisfiability Modulo Theories) solver for constraint satisfaction with a novel secure circuit encoding scheme. SMT enables scalable PIP generation; encoding provides structural attack resilience.

## Key Innovation
SMT solver with circuit encoding achieves 350x scalability while resisting both I/O and structural attacks.

## Contributions
- SMT solver-based PIP generation
- Novel secure circuit encoding scheme
- 350x scalability improvement on IBEX processor (16K gates)
- Resilience against five categories of attacks

## Motivation
IC supply chain security requires robust, scalable logic locking resistant to I/O and structural attacks.
