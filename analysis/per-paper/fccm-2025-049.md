# HBMex: An Attachment for Nonbursting Accelerators to Enhance HBM Performance

**Problem:** Applications with irregular, nonbursting memory access patterns (SpMV, graph analytics) cannot effectively utilize HBM's high bandwidth, and the HBM interconnect may stall requests under certain conditions.

**Method:** HBMex is a configurable module positioned between the accelerator and HBM that distributes memory requests across multiple HBM interfaces to improve parallelism. It mitigates interconnect stalls by intelligently routing requests to balance load and exploit available bandwidth across interfaces.

**Novelty:** A specialized attached module that addresses HBM interconnect bottlenecks by distributing irregular memory requests across multiple interfaces.
