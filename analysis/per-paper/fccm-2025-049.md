# HBMex: An Attachment for Nonbursting Accelerators to Enhance HBM Performance

**Problem:** Applications with irregular, nonbursting memory access patterns (SpMV, graph analytics) cannot effectively utilize HBM's high bandwidth, and the HBM interconnect may stall requests under certain conditions.

**Method:** HBMex is a configurable module placed between an accelerator and its HBM memory. It takes incoming memory requests from the accelerator and distributes them across multiple HBM interfaces so they're processed in parallel instead of backing up in a queue. For workloads with irregular access patterns (like sparse matrix operations or graph analytics), this prevents the interconnect from stalling and allows the accelerator to use the full available bandwidth.

**Novelty:** A module that distributes irregular memory requests across multiple HBM interfaces to prevent interconnect stalls.
