# Mitigating Resource Usage Dependency in Sorting-based KV Stores on Hybrid Storage Devices via Operation Decoupling

**Problem:** Sorting-based key-value stores (LSM-tree based) on hybrid storage experience tight coupling where concurrent operations—background compaction, foreground writes, and reads—compete for the same DRAM cache and I/O bandwidth, creating resource dependencies that limit throughput and predictability.

**Method:** The approach decouples operations by isolating their resource usage: compaction, writes, and reads are scheduled and serviced independently with separate memory pools and distinct I/O scheduling policies. This allows each operation type to optimize its resource utilization without interfering with others.

**Novelty:** Decoupling operations in LSM-tree based KV stores to eliminate resource usage dependencies between background compaction and foreground operations on hybrid storage tiers.
