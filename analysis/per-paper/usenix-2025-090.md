# Mitigating Resource Usage Dependency in Sorting-based KV Stores on Hybrid Storage Devices via Operation Decoupling

**Problem:** Sorting-based key-value stores (LSM-tree based) on hybrid storage experience tight coupling where concurrent operations—background compaction, foreground writes, and reads—compete for the same DRAM cache and I/O bandwidth, creating resource dependencies that limit throughput and predictability.

**Method:** The system decouples operations by giving compaction (the background process that reorganizes data in LSM-tree structures), writes, and reads their own separate memory pools so they don't fight over DRAM cache. It also assigns each operation type distinct I/O scheduling rules—separate policies controlling which operation gets to transfer data between memory and hybrid storage (the mix of different-speed storage devices) at any moment. This works because when operations aren't competing for the same resources, each can run efficiently without being blocked or slowed down by the others.

**Novelty:** The core innovation is isolating background data reorganization (compaction) from foreground reads and writes by giving each operation type its own memory pool and I/O scheduling in LSM-tree key-value stores on hybrid storage.
