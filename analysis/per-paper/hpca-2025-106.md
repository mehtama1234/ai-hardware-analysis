# hpca-2025-106 — Buffalo: Enabling Large-Scale GNN Training via Memory-Efficient Bucketization

**Venue:** HPCA  
**Authors:** Shuangyan Yang, Minjia Zhang, Dong Li  
**Confidence:** low (abstract only)

## Problem
Training GNNs on large graphs using partitioning causes a memory explosion from the long-tail degree distribution of nodes, along with expensive partitioning, difficult per-partition memory estimation, and slow block generation.

## Motivation
GNNs achieve SOTA results on graph tasks but are memory-limited at billion-node scale; existing partitioning strategies fail to handle high degree variance causing unpredictable memory spikes.

## Method
Buffalo solves a memory overload problem by organizing nodes based on their degree (how many connections each has) and spreading high-degree nodes across different chunks (partitions) of the graph so no single chunk gets overloaded. Instead of dividing the graph using expensive algorithms, it uses simple bucketing rules based on degree. Before loading data, it uses a lightweight mathematical model to predict how much memory each chunk will need, preventing overload before it happens. It also uses sampling to select a subset of data during block generation, speeding up the data preparation step.

## Key Novelty
Buffalo uses degree-based node bucketization—a strategy that spreads high-degree nodes across different partitions—to eliminate the memory explosion caused by the long-tail distribution of connections in real-world graphs.

## Contributions
- Node bucketization system preventing memory explosion from skewed degree distributions
- Fast bucketing-based graph partitioning without global partitioning overhead
- Lightweight analytical per-partition memory estimation
- 70.9% average training time reduction vs. DGL, PyG, Betty; enables billion-scale training

## Metrics
- **Speedup:** 70.9% end-to-end training time reduction vs. DGL, PyG, Betty
- **Other:** enables training on billion-scale graphs exceeding GPU memory capacity
