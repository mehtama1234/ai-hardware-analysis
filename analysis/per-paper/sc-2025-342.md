# InferA: A Smart Assistant for Cosmological Ensemble Data

**ID:** sc-2025-342  
**Venue:** SC 2025  
**Authors:** Justin Z. Tam, Pascal Grosset, Divya Banesh, Nesar Ramachandra, Terece L. Turton, James P. Ahrens

## Problem & Motivation

Analyzing **terabyte-scale scientific datasets** presents formidable challenges:
1. **Volume:** Too large for typical in-memory analysis
2. **Complexity:** Multidimensional, hierarchical structure
3. **Expertise gap:** Requires domain knowledge + technical skill

Existing tools like **PandasAI** require full data ingestion, making them impractical for terabyte datasets.

## Solution: InferA (LLM-Based Multi-Agent System)

A **supervisor-agent architecture** orchestrating specialized agents:

### Architecture
- **Supervisor agent:** Orchestrates workflow phases
- **Specialized agents:** Handle distinct data retrieval and analysis tasks
- **Interactive engagement:** Clarifies user intent through dialogue
- **Lazy loading:** Retrieves only necessary data subsets

### Workflow
1. User queries dataset in natural language
2. Supervisor interprets intent
3. Specialized agents execute targeted data retrieval
4. Results aggregated and presented to user

## Key Features

- **Scalability:** Handles terabyte datasets via structured querying
- **No full ingestion:** Only required data is loaded
- **Context-aware:** Understands data structure and domain
- **Interactive refinement:** Engages users for clarification

## Demonstration

Evaluated on **HACC (Hardware/Hybrid Accelerated Cosmology Code)** ensemble runs:
- Multiple terabyte-scale simulation outputs
- Cosmology domain-specific queries
- Proof-of-concept for scientific data agents

## Implications

LLM-based multi-agent orchestration enables **democratized access to large-scale scientific data**, removing technical barriers for domain scientists.
