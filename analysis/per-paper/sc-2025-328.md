# Experiences of Porting Structured and Unstructured Stencil Applications to FPGA using SYCL

**Venue:** SC
**ID:** sc-2025-328
**Confidence:** low

## Problem Statement
Porting stencil applications to FPGAs using single-source languages (SYCL) may sacrifice productivity or performance; unclear if FPGAs are viable for low-arithmetic-intensity stencils.

## Motivation
SYCL promises portable GPU/CPU/FPGA code; but FPGAs have different memory hierarchies and resource constraints; need empirical evaluation on realistic stencil kernels.

## Method
The researchers implemented stencil algorithms (patterns where the same computation applies repeatedly across a grid of data points) in SYCL, a language designed to work across different hardware types. They created optimized versions for both AMD CPUs and Intel Stratix 10 FPGAs—specialized hardware accelerators—and ran the same algorithms on both systems, measuring execution time and how much of the FPGA's hardware resources they consumed.

## Key Novelty
The paper tests whether SYCL can practically move code from CPUs to FPGAs, and finds that algorithms with low arithmetic intensity (few calculations relative to memory accessed) hit fundamental performance limits on FPGAs.

## Contributions
1. SYCL stencil implementations for CPU and FPGA
2. Structured and unstructured grid variants
3. Evidence of FPGA performance gaps for low-intensity kernels
