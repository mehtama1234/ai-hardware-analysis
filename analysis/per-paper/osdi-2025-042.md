# ZEN: Empowering Distributed Training with Sparsity-driven Data Synchronization

**Problem:** Distributed training systems face significant communication bottlenecks when synchronizing gradients across multiple nodes, with bandwidth and latency limitations preventing efficient scaling. Traditional approaches transmit complete gradient updates, wasting communication bandwidth on non-critical values.

**Method:** ZEN notices that gradient updates—the adjustments computers share during distributed training—mostly contain tiny or zero values that don't actually help the model. Instead of sending every gradient value, ZEN only transmits the large, important ones. It adapts how aggressive this filtering is based on observed patterns, ensuring the model still trains to a good solution while cutting the data sent between computers.

**Novelty:** ZEN reduces inter-computer communication during distributed training by only sending gradients that are large enough to matter, exploiting the sparsity (the fact that most gradient values are small or zero) in the updates.
