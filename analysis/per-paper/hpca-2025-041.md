# EIGEN: Enabling Efficient 3DIC Interconnect with Heterogeneous Dual-Layer Network-on-Active-Interposer

**Venue:** HPCA 2025  
**Authors:** Siyao Jia, Bo Jiao, Haozhe Zhu, Chixiao Chen, Qi Liu, Ming Liu

## Problem
Chiplet-based 3DIC systems using active interposers struggle with heterogeneous and high-load inter-chiplet network traffic because interconnects are tightly coupled to top-die designs, preventing flexible topology adaptation and causing high latency and congestion.

## Motivation
As AI accelerators, CPUs, and GPUs are integrated via chiplets on active interposers for HPC, rigid monolithic NoC designs cannot handle heterogeneous traffic demands of mixed compute fabrics at scale.

## Method
EIGEN places two layers on the active interposer (the chip connecting other chips). The first layer (AspLayer) sets up an optimized connection pattern based on the application's typical needs; the second layer (DynLayer) adapts in real time, rerouting data around bottlenecks as they form. A machine-learning system (reinforcement learning) learns the best routing paths by trial and error, rewarded for low message delays and high link usage—considering network structure, current traffic, and memory access patterns. The layers work together to move data between chips with fewer relay hops and less congestion.

## Key Novelty
A two-layer active-interposer design that separates setting up optimized connection patterns from real-time traffic routing, both guided by machine learning trained to balance message speed and link efficiency.

## Contributions
- EIGEN dual-layer Network-on-Active-Interposer architecture (AspLayer + DynLayer)
- RL-based path routing framework for dual-layer inter-chiplet communication
- Up to 67.16% latency and 53.89% hop reduction vs SOTA chiplet interconnects
- Demonstrated scalability from 4x4 to 32x32 chiplet configurations

## Results
- **Latency:** Up to 67.16% reduction vs SOTA
- **Hops:** Up to 53.89% reduction
- **Runtime:** Up to 11.21% reduction
- **Scalability:** 20.96% to 52.77% latency reduction scaling from 4x4 to 32x32

## Hardware Target
Chiplet (active interposer)

## Limitations
RL routing framework training convergence and generalization to unseen workload mixes at larger scales are not fully discussed.
