# ISSCC-2025-141: T-REX — Memory-Optimized Transformer Accelerator

**Problem:**  
Transformer accelerators suffer from external memory access (EMA) dominating energy (up to 81%) and low hardware utilization (as low as 9%), limiting overall efficiency despite optimized on-chip computation.

**Solution:**  
T-REX architecture reduces EMA via data reuse and memory hierarchy optimization; enhances hardware utilization through improved scheduling and dataflow.

**Key Results:**  
- 0.41–3.95 µJ/token energy efficiency
- 68–567 µs/token latency
- Up to 81% EMA reduction vs prior designs

**Key Innovation:**  
First transformer accelerator making external memory access the primary optimization goal, proving memory subsystem efficiency can dominate gains over compute-only optimization.

**Technique:** Memory System, Dataflow, Scheduling
