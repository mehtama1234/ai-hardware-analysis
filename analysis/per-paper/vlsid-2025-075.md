# Physical Synthesis Optimization Prediction Using Machine Learning

**VLSID 2025** | vlsid-2025-075

## Abstract
Early availability of estimated Power-Performance-Area (PPA) parameters—known only after EDA tool completion—can accelerate design convergence in complex SOCs. This work demonstrates supervised ML for predicting timing slack, critical path depth, leakage power, and area with 6-10% accuracy on sub-10nm designs at 1 GHz.

## Problem
- Long EDA tool runtimes bottleneck design turn-around-time and engineering productivity
- Critical PPA metrics unavailable until full tool completion
- Iterative design refinement requires multiple expensive tool runs

## Key Insight
ML models trained on rich SOC implementation datasets can predict post-synthesis PPA metrics early or in parallel with tool execution.

## Approach
1. Supervised ML model on sub-10nm SOC design datasets
2. Predicts: timing slack, critical path depth, leakage power, area
3. 6-10% typical accuracy vs. actual tool results

## Contributions
- ML framework for physical synthesis PPA prediction
- Demonstration on industry SOC designs
- Fast prediction enabling parallel exploration

## Hardware Target
- Sub-10nm SOCs
- Clock speed: 1 GHz nominal
