# XShift: FPGA-efficient Binarized LLM with Joint Quantization and Sparsification

**ID**: dac-2025-449  
**Venue**: DAC  
**Confidence**: low

## Problem
LLM binarization severely degrades activation precision and fails to eliminate multipliers from self-attention; LLMs show stage-specific (prefill vs decode) computational imbalance requiring specialized handling.

## Motivation
Edge deployment of LLMs demands extreme resource efficiency; binarization offers maximum compression but accuracy challenges limit adoption.

## Method
XShift enables efficient binarized LLMs (where weights and activations are 1-bit values) by replacing expensive multiplications with XNOR operations and bit shifts. It adapts to the structure of each neural network layer by detecting outlier values and sparse activations across channels, then exploits these patterns using a systolic array (a grid of simple processing units optimized for matrix math). A specialized XNOR-Shift Systolic Array and base-2 SoftMax converter (using only powers of 2 for the probability conversion) keep computation efficient throughout.

## Key Novelty
XShift maintains precision in binarized LLMs by using XNOR and shift operations instead of multiplications, with adaptive handling of outlier values.

## Contributions
- XNOR-Shift Encoding for lossless binarization
- Hardware Adaptive Outlier and Sparsity techniques
- Dedicated XSSA + BSMC accelerator
- 10-15x DSP reduction, 4.17-4.76x speedup, 14.29-6.95x energy gain
