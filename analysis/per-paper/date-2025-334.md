# Accurate and Extensible Symbolic Execution of Binary Code Based on Formal ISA Semantics

**Venue**: DATE  
**Primary Theme**: formal ISA semantics for accurate binary symbolic execution  

## Problem
Symbolic execution of binary code requires semantic translation to architecture-independent IR, introducing errors and complexity from manual ISA specification implementation.

## Method
Instead of manually translating processor instruction specifications into intermediate code (a step prone to errors), this tool uses formal, machine-readable specifications directly for symbolic execution—a technique that tests code by systematically exploring all possible execution paths. The formal specifications precisely define how each instruction in the processor works, and the tool reads them directly rather than requiring researchers to hand-translate them. The approach was prototyped on RISC-V and shown to extend to other processor architectures.

## Key Novelty
Using machine-readable formal specifications directly avoids the error-prone manual translation step that traditional symbolic execution requires.

## Contributions
- Formal ISA semantics-based approach to binary symbolic execution
- RISC-V prototype implementation
- Discovery of five previously unknown bugs in angr ISA implementation
- Demonstrated extensibility to additional instructions
