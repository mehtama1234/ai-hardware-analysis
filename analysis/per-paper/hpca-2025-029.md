# hpca-2025-029: Anda: Unlocking Efficient LLM Inference with a Variable-Length Grouped Activation Data Format

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Weight-only quantized LLMs retain FP activations for accuracy, shifting the bottleneck to costly FP memory accesses and FP-INT GEMM computation; existing accelerators optimize computation without jointly redesigning the FP activation data format.

## Motivation
FP-INT GEMM dominates LLM inference cost, and FP activations are simultaneously memory-bandwidth-hungry and compute-inefficient; a co-designed adaptive format can cut both without accuracy loss.

## Method
Anda compresses floating-point activation data by grouping values with a shared scale (exponent) per group but variable precision (bits) per value, letting different network layers use different precision without retraining. It automatically searches for the best precision per layer by testing accuracy and efficiency after training. The hardware organizes data by individual bits, processes them sequentially in specialized units, and compresses on-the-fly as the model runs. Together, these co-designed software and hardware changes reduce data storage and the floating-point-to-integer calculations that currently bottleneck large language model inference.

## Key Novelty
Anda uses a grouped data format with a shared scale per group but variable precision per value, automatically tuning precision per layer to simultaneously reduce data storage, bandwidth, and the floating-point-to-integer math that bottlenecks large language model inference.

## Contributions
- Anda adaptive data format with group-shared exponent and dynamic mantissa allocation.
- Iterative post-training precision search for per-module bit-width optimization without retraining.
- Hardware: bit-plane organization, bit-serial PEs, runtime bit-plane compressor.
- 2.4x speedup, 4.0x area efficiency, 3.1x energy efficiency over GPU-like FP-FP baseline on OPT/LLaMA/LLaMA-2.

## Metrics
- speedup: 2.4x over GPU-like FP-FP baseline (FP-INT GEMM)
- energy: 3.1x energy efficiency improvement
- area: 4.0x area efficiency improvement
