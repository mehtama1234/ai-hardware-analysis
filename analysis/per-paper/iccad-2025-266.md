# QUARK: Quantization-Enabled Circuit Sharing for Transformer Acceleration by Exploiting Common Patterns in Nonlinear Operations

**Venue:** ICCAD  
**Paper ID:** iccad-2025-266

## Problem Statement
Nonlinear operations in transformers significantly contribute to inference latency and hardware resource overhead in FPGA acceleration.

## Motivation
Common patterns in nonlinear activation functions offer circuit sharing opportunities; quantization enables efficient approximation.

## Method
QUARK exploits the fact that transformers use similar patterns in their mathematical processing operations (called nonlinear operations). It applies quantization—using fewer bits to represent numbers—which makes approximations accurate enough for one hardware circuit to perform multiple different operations instead of needing separate circuits for each. This approach on an FPGA reduces the total hardware needed.

## Key Novelty
Using quantization to enable a single hardware circuit to handle multiple different nonlinear operations in transformers.

## Contributions

1. 1.96× end-to-end speedup over GPU
2. >50% nonlinear module overhead reduction
3. Accuracy preservation under ultra-low-bit quantization
