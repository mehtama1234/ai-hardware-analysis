# Learning-Enhanced High-Throughput Pattern Matching Based on Programmable Data Plane

**Problem:** Pattern matching at line rate in programmable network switches requires efficient algorithms that maintain high throughput while accurately identifying patterns in packet streams. Traditional sequential matching approaches create bottlenecks under terabit-scale traffic.

**Method:** The approach embeds machine learning models into programmable network switches and SmartNICs (specialized network cards) to speed up pattern matching. The ML model learns which patterns are most likely to appear in traffic, allowing the hardware to prioritize checking those patterns first or skip comparisons that won't match. This prioritization maintains accuracy while handling terabit-scale traffic volumes by exploiting the parallel processing power built into switches and SmartNICs.

**Novelty:** Machine learning is applied for the first time to speed up pattern matching in programmable network switches and SmartNICs.
