# CIMTester - Template-based BIST Compiler for Digital Compute-in-memory

CIMTester is a template-based compiler that automatically generates built-in self-test (BIST) circuits for digital compute-in-memory systems, achieving 99.48% fault coverage. The framework encodes domain knowledge about CIM-specific faults and test strategies in reusable templates, enabling synthesis of efficient test circuits tailored to diverse CIM array architectures. This work demonstrates the value of domain-specific test generation for emerging memory-compute technologies and provides a practical methodology for achieving comprehensive fault coverage in CIM systems.
