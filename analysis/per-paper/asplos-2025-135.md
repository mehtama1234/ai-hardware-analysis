# asplos-2025-135: Towards End-to-End Optimization of LLM-based Applications with Ayo

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
LLM-based applications mix LLM and non-LLM components whose combined end-to-end latency is not jointly optimized; existing frameworks use coarse-grained task-module orchestration that confines optimizations within individual modules, yielding suboptimal scheduling.

## Motivation
As LLM pipelines grow in complexity with multi-step retrieval, compute, and generation stages, per-module optimization leaves significant cross-module scheduling inefficiency that compounds into high end-to-end latency.

## Method
Ayo breaks application pipelines into smaller pieces than existing systems do, letting it coordinate decisions across different components instead of optimizing each separately. It creates a complete map of how all parts depend on each other (called a DAG or dependency graph), then jointly optimizes when the language model runs and when the other computation happens, making the entire pipeline faster.

## Key Novelty
Ayo schedules the entire pipeline by optimizing language model and non-LLM parts together, rather than treating each as a separate piece to optimize independently.
