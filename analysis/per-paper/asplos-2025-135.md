# asplos-2025-135: Towards End-to-End Optimization of LLM-based Applications with Ayo

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
LLM-based applications mix LLM and non-LLM components whose combined end-to-end latency is not jointly optimized; existing frameworks use coarse-grained task-module orchestration that confines optimizations within individual modules, yielding suboptimal scheduling.

## Motivation
As LLM pipelines grow in complexity with multi-step retrieval, compute, and generation stages, per-module optimization leaves significant cross-module scheduling inefficiency that compounds into high end-to-end latency.

## Method
Ayo introduces a fine-grained, end-to-end workflow optimizer that breaks down application pipelines below the task-module boundary, enabling cross-module scheduling of both LLM inference and non-LLM compute stages to minimize overall pipeline latency.

## Key Novelty
Cross-module, end-to-end scheduling that jointly optimizes LLM and non-LLM pipeline stages rather than treating them as isolated task modules.

GPU
