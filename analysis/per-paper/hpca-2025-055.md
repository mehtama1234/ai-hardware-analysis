# LUT-DLA: Lookup Table as Efficient Extreme Low-Bit Deep Learning Accelerator

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Scalar quantization cannot reduce DNN bit-width below 1-bit, capping compression gains; existing accelerators lack hardware support for vector-quantization-based LUT approaches that could push beyond this limit.

## Motivation
Growing DNN model sizes demand ever-lower inference costs, but the numerical floor of scalar quantization (1-bit) prevents further compression, necessitating vector quantization via lookup tables as a path to extreme low-bit inference.

## Method
LUT-DLA converts DNN weight tensors into lookup tables via vector quantization, replacing multiply-accumulate operations with LUT index lookups and accumulations. The LUTBoost algorithm trains DNNs through a multistage process to learn LUT-compatible vector codebooks. A co-design space exploration framework evaluates trade-offs between LUT table size, codebook dimensionality, model accuracy, and hardware cost. The ASIC accelerator implements LUT fetch-and-accumulate dataflow units that directly consume quantized indices.

## Key Novelty
Replacing conventional scalar MAC units with vector-quantization LUT fetch-and-accumulate hardware, achieving extreme sub-1-bit-equivalent compression through hardware-algorithm co-design including the LUTBoost multistage training algorithm.

## Contributions
1. LUT-DLA accelerator framework enabling extreme low-bit DNN inference via vector quantization LUTs
2. LUTBoost multistage training algorithm to convert diverse DNN models into LUT-based representations
3. Co-design space exploration methodology linking model and hardware parameters
4. 1.4-7.0x power efficiency and 1.5-146.1x area efficiency improvements with modest accuracy drops

## Hardware Target
ASIC

## Technique Categories
quantization, approximation, dataflow, circuit-design

## Workloads
CNN, transformer, LLM-inference

## Metrics
- Power efficiency: 1.4-7.0x improvement
- Area efficiency: 1.5-146.1x improvement
- Accuracy drop: 0.1-3.8% on CNNs; 1.4-3.0% on transformers

## Baselines
- Conventional scalar quantization accelerators
- Prior low-bit DNN accelerators

## Limitations
Accuracy degradation of up to 3.8% on CNNs and 3.0% on transformers may be unacceptable for precision-sensitive tasks, and LUTBoost multistage training adds training complexity.
