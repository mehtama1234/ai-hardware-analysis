# KVCache Cache in the Wild: Characterizing and Optimizing KVCache Cache at a Large Cloud Provider

**Problem:** Real-world LLM serving systems lack understanding of actual KVCache access patterns, and cache eviction policies are not optimized for production workloads where design decisions are highly workload-dependent.

**Method:** The researchers analyzed real-world data from a major AI company to understand how KVCache (data stored from language model computations) actually gets reused in practice. They examined which cached data gets accessed again and how often, comparing short single-turn requests with long multi-turn conversations, and found these patterns are predictable within each category. They built a cache eviction policy (the rule for deciding what to delete when storage fills up) that automatically adjusts itself based on what type of requests are happening.

**Novelty:** First study of real production data showing that cache reuse patterns are heavily skewed and that short single-turn requests need as much attention as long multi-turn conversations—contradicting what prior work assumed from artificial test workloads.
