# How Do Errors Impact NN Accuracy on Non-Ideal Analog PIM? Fast Evaluation via an Error-Injected Robustness Metric

**Venue:** ICCAD | **ID:** iccad-2025-056

## Problem
Existing analog PIM simulators use bit-and-crossbar slicing paradigm evaluating MVM operations bit-by-bit and crossbar-by-crossbar, extremely time-consuming for large models like LLMs. Doesn't capture coupling effects among various error sources.

## Motivation
Enable fast accuracy evaluation for analog PIM designs supporting large-scale models.

## Method
Proposes error-injected robustness metric unifying various errors into weight dimension enabling joint error analysis. Develops Non-Ideal PIM Accuracy (NIPA) evaluation model considering coupling effects using NN prior information. Proposes non-slicing absolute accuracy evaluation eliminating bit-and-crossbar slicing overhead.

## Key Novelty
Non-slicing accuracy evaluation method achieving 105.8x speedup over traditional slicing approach.

## Contributions
- Error-injected robustness metric unifying software and hardware errors
- NIPA evaluation model considering error coupling effects with NN prior
- Non-slicing absolute accuracy evaluation method eliminating slicing overhead

## Metrics
- **Speedup:** 105.8x speedup vs bit-and-crossbar slicing
- **Accuracy:** 0.91 correlation with absolute accuracy; 0.29% average evaluation error

- bit-and-crossbar slicing methods

## Limitations
Approach specific to analog PIM; applicability to digital PIM or heterogeneous systems unclear.
