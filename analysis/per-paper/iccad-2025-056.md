# How Do Errors Impact NN Accuracy on Non-Ideal Analog PIM? Fast Evaluation via an Error-Injected Robustness Metric

**Venue:** ICCAD | **ID:** iccad-2025-056

## Problem
Existing analog PIM simulators use bit-and-crossbar slicing paradigm evaluating MVM operations bit-by-bit and crossbar-by-crossbar, extremely time-consuming for large models like LLMs. Doesn't capture coupling effects among various error sources.

## Motivation
Enable fast accuracy evaluation for analog PIM designs supporting large-scale models.

## Method
The method models how analog hardware errors affect neural network accuracy by representing different types of errors as variations in the network weights, allowing them to be analyzed together. It develops NIPA (Non-Ideal PIM Accuracy), a model that accounts for how these errors interact with each other using information about how neural networks typically respond to weight changes. Rather than the traditional approach of simulating each bit and crossbar individually, it evaluates the model's accuracy all at once, eliminating the expensive granular simulation.

## Key Novelty
By evaluating how all errors affect the model at once instead of simulating individual bits and crossbars, it achieves 105.8x speedup.

## Contributions
- Error-injected robustness metric unifying software and hardware errors
- NIPA evaluation model considering error coupling effects with NN prior
- Non-slicing absolute accuracy evaluation method eliminating slicing overhead
