# Guiding Application Users via Resource Estimation for Massively Parallel Chemistry Computations

**ID:** sc-2025-341  
**Venue:** SC 2025  
**Authors:** Tanzila Tabassum, Omer Subasi, Ajay Panyala, Epiya Ebiapia, Gerald Baumgartner, Erdal Mutlu, P. Sadayappan, Karol Kowalski

## Problem & Motivation

Chemistry simulations on supercomputers (e.g., **CCSD - Coupled Cluster with Singles and Doubles**) have complex parameter spaces:
- Number of nodes
- Tile sizes
- Problem sizes

Users face two critical questions:
1. **Shortest time:** Which parameters minimize execution time?
2. **Cheapest run:** Which parameters minimize node-hours (cost)?

Without guidance, users make poor allocation decisions, wasting expensive supercomputer time.

## Solution: ML-Based Resource Predictor

Two complementary approaches:

### 1. Gradient Boosting (GB)
Excellent prediction accuracy with sufficient training data:
- **Aurora:** MAPE = 0.023 (2.3% error)
- **Frontier:** MAPE = 0.073 (7.3% error)

### 2. Active Learning (AL)
When experimental data is limited:
- **MAPE ~ 0.2** (20% error)
- Requires only ~450 experiments
- Adaptively selects most informative parameter points

## Optimization Modes

Users can query the model to find:
- **Fastest execution:** optimal (nodes, tile_size) for given problem
- **Lowest cost:** configuration minimizing total node-hours

## Results

Successfully deployed on **Frontier** and **Aurora**, enabling users to pre-compute optimal configurations before submission.

## Implications

ML-based resource guidance improves allocation efficiency, reduces wasted compute, and democratizes expert-level optimization knowledge for general users.
