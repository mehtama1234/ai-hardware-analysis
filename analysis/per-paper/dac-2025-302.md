# Enhancing Test Quality by Targeting Timing Marginalities Due to Process Variations

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

An invited paper proposing variation-aware IC testing methodology that targets timing failures from random process variations in threshold voltages, moving beyond single-defect stuck-at models to address real failures in advanced technology nodes.

## Key Contributions

- **Variation-Aware Framework**: Methodology prioritizing performance-sensitive device parameters in test generation
- **Multi-Device Variation Targeting**: Tests designed for correlated threshold voltage variations affecting multiple devices
- **Timing Failure Detection**: Addresses gap where conventional test methods miss variation-induced failures
- **Advanced Node Relevance**: Particularly critical for sub-7nm nodes with significant random process variations

## Technical Focus

Challenges the assumption that single passive defects dominate IC failures. Proposes testing strategies that explicitly target nonlinear circuit behavior under specific operating conditions caused by random multi-device variations.

## Relevance

**Keywords:** process-variation, test-methodology, timing-failures, advanced-nodes, reliability
