# isscc-2025-049: Calibration-Free Pipelined-SAR ADC with Cross-Stage Error Shaping

**Title:** 18.3: A 93.3dB SNDR, 180.4dB FoMs Calibration-Free Noise-Shaping Pipelined-SAR ADC with Cross-Stage Gain-Mismatch-Error-Shaping Technique and Negative-R-Assisted Residue Integrator

**Venue:** ISSCC

**Core Problem:**
Multi-stage pipelined-SAR ADCs require error correction for mismatch and gain errors; prior GES schemes use multi-bit feedback with additional noise sources needing calibration.

**Method:**
Cross-stage gain-mismatch-error-shaping (GMES) technique using single-bit feedback combines GES and MES without auxiliary mismatch contributors; negative-R-assisted residue integrator enables efficient integration.

**Key Innovation:**
Single-bit feedback cross-stage error shaping combining gain and mismatch correction without calibration.

**Metrics:**
- **SNDR:** 93.3 dB
- **FoM_S:** 180.4 dB
- **Calibration:** None required

**Architecture:** Calibration-free pipelined-SAR with unified error shaping

**Techniques:** Circuit design, error shaping, ADC design

**Confidence:** Low (abstract-only)
