# Late Breaking Results: Improving Deep SNNs with Gradient Clipping and Noise Exploitation in Neuromorphic Devices

**Venue**: DATE  
**Primary Theme**: Noise-aware SNN training for neuromorphic hardware  

## Problem
Deep SNNs trained with soft resets are computationally expensive and unsuitable for neuromorphic hardware; hard reset-based SNNs suffer performance degradation without gradient clipping.

## Method
The approach trains hard reset spiking neural networks (neural networks that compute using discrete pulses, built into neuromorphic hardware devices) by using gradient clipping—capping the size of weight adjustments during training to keep the learning process stable. Rather than treating device noise (random variations in the physical hardware) as interference to eliminate, the method exploits it to enhance learning performance. The technique is validated across multiple datasets and neural network architectures.

## Key Novelty
Device noise in neuromorphic hardware can improve learning in hard reset spiking neural networks, contrary to the standard practice of treating it purely as interference.

## Contributions
- Gradient clipping technique improving training performance in hard reset SNNs
- Demonstration that device noise enhances rather than degrades learning
- Bridges algorithmic-hardware gap for practical neuromorphic computing
