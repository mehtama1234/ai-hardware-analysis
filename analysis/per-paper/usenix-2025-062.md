# CLONE: Customizing LLMs for Efficient Latency-Aware Inference at the Edge

**Problem:** Deploying large language models on edge devices is constrained by limited storage, weight, and power budgets, requiring careful balance between latency requirements, energy consumption, and model accuracy. Current approaches fail to achieve efficient inference while maintaining generation quality on off-the-shelf edge platforms.

**Method:** CLONE takes a paired approach: it designs both the AI model and the hardware accelerator together rather than treating them as separate components to optimize independently. The hardware uses 28nm technology and dynamically adjusts power consumption during inference using real-time energy monitoring. The language model itself is customized—compressed and optimized—to run efficiently on this specialized hardware. Together, these changes ensure the system meets strict latency (response time) targets while minimizing power usage, whether on always-on devices or intermediate edge systems.

**Novelty:** CLONE jointly designs the language model and specialized hardware accelerator as a single system to meet latency and power requirements together, rather than optimizing them independently.
