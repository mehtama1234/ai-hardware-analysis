# CLONE: Customizing LLMs for Efficient Latency-Aware Inference at the Edge

**Problem:** Deploying large language models on edge devices is constrained by limited storage, weight, and power budgets, requiring careful balance between latency requirements, energy consumption, and model accuracy. Current approaches fail to achieve efficient inference while maintaining generation quality on off-the-shelf edge platforms.

**Method:** CLONE performs algorithm-hardware co-design at both model and system levels to optimize for energy consumption while meeting latency requirements. The approach specializes a 28nm scalable hardware accelerator system and integrates real-time energy optimization with model customization for always-on and intermediate edge computing settings.

**Novelty:** Joint algorithm-hardware co-design framework that simultaneously customizes the LLM model and specialized hardware accelerator to achieve latency-aware, energy-efficient inference on edge devices.
