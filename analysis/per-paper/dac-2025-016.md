# dac-2025-016: Bit-level CAN Bus Reverse Engineering

**Title:** On Bit-level Reverse Engineering of Vehicular CAN Bus

**Venue:** DAC 2025

**Core Issue:** CAN bus signal-to-action mapping at bit resolution needed for vehicle security but hampered by massive search space.

**Key Contribution:** Systematic framework achieving bit-level precision; identified 43 control actions on Tesla Model 3; runs on Raspberry Pi.

**Hardware Target:** Embedded systems (Raspberry Pi), vehicular ECUs

**Workload:** Automotive security analysis

**Metrics:**
- 43 actions identified (Tesla Model 3)
- Platforms tested: Tesla Model 3, Leapmotor C10/C11

**Confidence:** Low (abstract-only)
