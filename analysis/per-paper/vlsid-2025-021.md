# Bidirectional Spiking Neuron Based Dual-Mode Signal Acquisition Front-End System

**Venue:** VLSID

## Problem
Signal acquisition for spiking neural networks requires dual-mode operation for power/precision trade-off

## Motivation
SNNs emerging for low-power AI; need flexible front-end supporting both surveillance (low-power) and precision modes

## Method
The system uses bidirectional spiking neurons—artificial neurons that communicate through discrete electrical pulses and can send and receive signals simultaneously—to sense incoming signals. The design includes two switchable modes: surveillance mode for ultra-low-power operation, and precision modes for high-quality measurement. It is built using 65-nanometer TSMC technology, a commercial manufacturing process.

## Key Novelty
A signal sensor using bidirectional spiking neurons that switches between ultra-low-power surveillance mode (under 250 nanoWatts) and precision modes with signal-to-noise-and-distortion performance of 38, 49, and 53.6 decibels.
