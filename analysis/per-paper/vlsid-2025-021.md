# Bidirectional Spiking Neuron Based Dual-Mode Signal Acquisition Front-End System

**Venue:** VLSID

## Problem
Signal acquisition for spiking neural networks requires dual-mode operation for power/precision trade-off

## Motivation
SNNs emerging for low-power AI; need flexible front-end supporting both surveillance (low-power) and precision modes

## Method
Bidirectional Spiking Neuron (BSN) front-end with switchable surveillance/precision modes in 65nm TSMC

## Key Novelty
Dual-mode BSN-based acquisition with 38/49/53.6dB SNDR across modes and <250nW surveillance power

## Contributions
- BSN front-end design
- Surveillance mode <250nW
- Precision mode 49dB SNDR
- 0.0034mm2 silicon
