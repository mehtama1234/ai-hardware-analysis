# SparStencil: Retargeting Sparse Tensor Cores to Scientific Stencil Computations via Structured Sparsity Transformation

**Venue:** SC  
**Theme:** Sparse Tensor Acceleration  
**Confidence:** low

## Problem Statement
Sparse Tensor Cores (structured 2:4 sparsity) excel at AI but underutilized for scientific stencil computations with irregular sparsity; no existing system bridges this gap

## Motivation
Stencil computations dominate scientific applications; enabling sparse tensor core acceleration could unlock significant performance gains for core HPC workloads

## Methodology
SparStencil transforms irregular stencil patterns into structured sparse matrices via: (1) Adaptive Layout Morphing (flatten-crush pipeline), (2) Structured Sparsity Conversion (graph matching), (3) Automatic Kernel Generation (layout search + memory mapping)

## Key Novelty
First system retargeting sparse tensor cores for scientific stencil computations; introduces adaptive layout morphing to enforce 2:4 sparsity structure on irregular patterns

## Contributions
- Adaptive Layout Morphing restructuring stencils into staircase-aligned sparse matrices
- Graph matching-based sparsity transformation ensuring 2:4 compatibility
- Automatic sparse MMA kernel generation with layout search
- 7.1x max speedup (3.1x average) on 79 diverse stencil kernels

## Hardware Targets
NVIDIA GPUs with Sparse Tensor Cores, Hopper architecture

## Technique Categories
Sparse tensor acceleration, Code generation, Stencil optimization

## Workloads
Scientific stencil computations, PDE solvers, Scientific simulations
