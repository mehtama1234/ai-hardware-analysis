# Seeking Cost-Optimal Infrastructure Size for Distributed Filesystems: A Ceph Case Study

**Paper ID:** sc-2025-356
**Venue:** SC
**Confidence:** low

## Problem Statement
Predicting distributed filesystem I/O performance based solely on hardware configuration is not straightforward

## Motivation
Cost-effective DFS design requires understanding how hardware choices (cores, RAM, bandwidth) affect actual performance

## Method
Empirical evaluation of Ceph DFS varying CPU cores, RAM, and disk bandwidth using Linux hotplug and Cgroups

## Key Novelty
Empirical characterization showing non-linear relationship between hardware resources and DFS I/O performance

## Contributions
- Method for assessing hardware configuration impact on DFS
- Evidence that resource reduction doesn't yield proportional performance loss
- Cost-effective Ceph design guidelines
