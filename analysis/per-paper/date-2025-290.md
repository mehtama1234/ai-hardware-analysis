# One More Motivation to Use Evaluation Tools This Time for Hardware Multiplicative Masking of AES

**Venue**: DATE  
**Primary Theme**: Side-channel secure multiplicative masking for AES  

## Problem
Prior hardware implementations of multiplicative masking for AES contain critical vulnerabilities in the Kronecker delta function that leak information under side-channel analysis.

## Method
Evaluates prior multiplicative masking design (De Meyer et al. CHES 2018) using PROLEAD evaluation tool under glitch-and-transition-extended probing model; identifies leakage in first-order Kronecker delta; proposes improved randomness optimization.

## Key Novelty
Identifies critical vulnerability in prior SOTA multiplicative masking design and demonstrates effective fix via improved randomness optimization.

## Contributions
- Discovered leakage in prior Kronecker delta implementation under formal evaluation
- Proposed alternative randomness optimization addressing the vulnerability
- Demonstrated effectiveness of fix using PROLEAD evaluation tool
