# Target Circuit Matching in Large-Scale Netlists Using GNN-Based Region Prediction

**Authors:** Sangwoo Seo, Jimin Seo, Yoonho Lee 0002, Donghyeon Kim, Hyejin Shin, Banghyun Sung, Chanyoung Park 0001

**Venue:** ICCAD

## Summary
Proposes GNN-based region prediction for efficient subgraph matching in large-scale circuits, avoiding expensive per-candidate computation by directly extracting global subgraph embeddings.

## Key Contributions
- GNN-based target region prediction eliminating per-candidate subgraph matching
- Negative sample construction for accurate circuit detection
- Direct subgraph embedding extraction capturing global circuit information
- Significantly outperforms existing methods in time efficiency and prediction accuracy
