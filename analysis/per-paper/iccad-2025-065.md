# PLAIN: Leveraging High Internal Bandwidth in PIM for Accelerating Large Language Model Inference via Mixed-Precision Quantization

**Venue:** ICCAD

## Problem
DRAM-PIM systems have limited computational capabilities supporting only element-wise and GEMV operations, making them insufficient for LLM workloads which are compute-heavy in FC layers.

## Motivation
DRAM-based PIM offers commercial viability but lacks adequate compute for LLM acceleration without powerful host processors.

## Method
The approach splits computation between GPU and PIM hardware: the GPU handles attention operations (which need flexible full-precision computation) using its high-bandwidth memory, while PIM accelerates fully-connected layers by operating on data in simplified number formats. Rather than choosing one precision level for everything, they use mixed-precision quantization—assigning different precision (fewer or more bits per number) to different layers based on both what each layer's math requires to stay accurate and what PIM's internal bandwidth can handle efficiently. A dataflow scheduler coordinates this split, routing each operation to the processor that can execute it best.

## Key Novelty
Mixed-precision quantization that chooses each layer's precision by balancing the algorithm's accuracy needs against the hardware's bandwidth capabilities.

## Contributions
- 5.03x performance boost over GPU with same memory parameters
- 1.69x improvement over state-of-the-art PIM accelerator
- Negligible model quality loss
- Workload-aware dataflow scheduler for mixed-precision tensors
