# EqMap: FPGA LUT Remapping using E-Graphs

**Venue:** ICCAD

## Problem
FPGA technology mapping creates a gap between SAT-based exact synthesis and heuristic cut enumeration, resulting in suboptimal LUT counts and circuit depths.

## Motivation
Decades of research on technology mapping still leaves substantial room for improvement despite understanding the computational complexity.

## Method
E-graphs are data structures that represent all mathematically equivalent ways to partition a circuit into LUTs (the logic blocks used in FPGAs). The system systematically explores different partitioning strategies by combining exact SAT-based methods—which find provably optimal arrangements—with faster heuristics that guide the search, producing circuits with fewer LUTs and shorter signal paths.

## Key Novelty
The core contribution is using e-graphs to systematically explore all equivalent FPGA circuit configurations, combining exact optimization methods with practical heuristics to improve LUT mapping.

## Contributions
- 12% average LUT reduction over vendor tools
- Never increases circuit depth
- Practical runtime for large designs
- Reusable compiler infrastructure for RTL equivalence checking and QoR auditing
