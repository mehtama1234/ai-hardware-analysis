# Exploring and Mitigating Failure Behavior of Large Language Model Training Workloads in HPC Systems

**Venue:** SC
**Paper ID:** sc-2025-011
**Confidence:** low

## Problem Statement
LLM training on HPC systems faces reliability challenges from transient faults; failure patterns are more complex than DNN inference due to massive parameter scale and iterative updates

## Motivation
Exponential growth in LLM training demand; transient faults increasingly common; understanding failure modes and enabling recovery is critical for large-scale training

## Method
They created LLMFI, a tool that injects simulated hardware faults into LLM training to observe resulting failures. Running over 300,000 of these experiments across 5,000+ GPU hours revealed distinct failure patterns. They then developed LLMFT, an ML-based framework that continuously monitors for these failures (using extracted system features and a fault detector) and automatically applies recovery strategies to resume training.

## Key Novelty
They identified six distinct failure modes in LLM training on HPC systems and built an ML-based closed-loop control system (continuous monitoring with automatic targeted recovery) to handle each one.
