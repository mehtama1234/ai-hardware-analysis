# Evaluating Trusted Execution Environment Performance for Genome Sequence Alignment: An AMD SEV Case Study

**Venue:** SC

## Problem
HPC systems processing sensitive genomic data need security guarantees in multi-tenant environments; TEE overhead impact on real workloads unclear

## Motivation
Characterize performance of AMD SEV/SME trusted execution for sensitive genomic data processing on HPC systems

## Method
Evaluation of AMD SEV and SME on BWA-MEM2 genome alignment workload; comparison across SMP, SEV+SME, and SME-only configurations with varying thread counts

## Key Novelty
First characterization of AMD SEV/SME for genomic workloads; quantifies 50% memory bandwidth reduction and 10.4-20.9% runtime overhead

## Contributions
- Performance evaluation of AMD SEV/SME for genome alignment
- Characterization of memory bandwidth impact (50% reduction)
- Analysis of thread scaling degradation under TEE encryption
