# Evaluating Trusted Execution Environment Performance for Genome Sequence Alignment: An AMD SEV Case Study

**Venue:** SC

## Problem
HPC systems processing sensitive genomic data need security guarantees in multi-tenant environments; TEE overhead impact on real workloads unclear

## Motivation
Characterize performance of AMD SEV/SME trusted execution for sensitive genomic data processing on HPC systems

## Method
The researchers tested a genome alignment tool (BWA-MEM2) on AMD processors under three security configurations: no security features (SMP), memory encryption alone (SME), and both memory encryption plus virtualization-layer encryption (SEV+SME). They tested each setup with different numbers of processor threads and measured how runtime and memory bandwidth changed. This quantified the performance overhead that security features add to real genomic data processing.

## Key Novelty
This is the first measurement of how AMD's security features—memory encryption (SME) and virtualization-layer encryption (SEV)—affect real genome alignment, showing a 50% reduction in memory bandwidth and 10.4-20.9% increase in runtime.

## Contributions
- Performance evaluation of AMD SEV/SME for genome alignment
- Characterization of memory bandwidth impact (50% reduction)
- Analysis of thread scaling degradation under TEE encryption
