# asplos-2025-133: CoServe: Efficient Collaboration-of-Experts (CoE) Model Inference with Limited Memory

**Venue:** ASPLOS  
**Confidence:** high (full text)

## Problem
CoE inference on memory-constrained edge devices (RTX 3080Ti, 12 GB GPU) requires serving 300+ expert models (60 GB total) that cannot fit in GPU memory. Expert swapping from SSD accounts for over 90% of inference latency; existing MoE-style LRU/FCFS management is inefficient for CoE's deterministic routing.

## Motivation
CoE achieves 99.9% accuracy (vs. 92% for a single model) for circuit board inspection and must run at the edge for privacy, but memory constraints make expert-switching the dominant cost.

## Method
CoServe takes advantage of a key property of Collaboration-of-Experts systems: they pre-determine which experts each request needs before execution, making expert requirements predictable—unlike Mixture-of-Experts systems where routing is decided at runtime. It uses three strategies to leverage this predictability: grouping requests that use the same expert to keep it loaded in GPU memory longer, removing experts that won't be needed for upcoming requests when GPU memory fills up (starting with the largest ones to free space quickly, then removing rarely-used ones), and using hardware benchmarks beforehand to find the optimal GPU memory allocation and CPU-GPU computation split.

## Key Novelty
CoServe's core idea is exploiting the fact that Collaboration-of-Experts systems determine expert requirements before execution, enabling intelligent request scheduling and expert eviction strategies that Mixture-of-Experts systems cannot achieve since their routing is only determined at runtime.

## Metrics
- 4.5x to 12x throughput over Samba-CoE (NUMA and UMA devices)
- Expert switching reduced by up to 93.87% (1060 to 65 switches in Task B2/NUMA)

## Hardware Target
GPU, CPU (heterogeneous NUMA and UMA edge devices)

## Baselines
Samba-CoE (LRU+FCFS), Samba-CoE FIFO, Samba-CoE Parallel

## Limitations
Evaluation uses only ResNet101/YOLOv5 circuit board inspection workloads; generalization to language-model CoE or dynamic routing distributions is not demonstrated.
