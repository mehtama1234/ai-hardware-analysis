# A Parallel Analytical Legalization Algorithm via Alternating Direction Method of Multipliers

**Venue:** ICCAD

## Problem
Legalization with cell overlap resolution typically relies on suboptimal heuristic cell-by-cell search, while analytical methods suffer from runtime overhead and discrete problem complexity.

## Motivation
Large-scale design legalization requires better solution quality without excessive runtime overhead.

## Method
Parallel analytical legalization using Alternating Direction Method of Multipliers (ADMM) with heterogeneous CPU-GPU parallelism to handle the discrete nature of placement legalization.

## Key Novelty
Parallel analytical formulation of legalization problem via ADMM with CPU-GPU heterogeneous acceleration.

## Contributions
- Significantly improved solution quality vs existing legalizers
- Analytical approach overcoming heuristic limitations
- CPU-GPU parallel acceleration
- Applicable to large-scale designs
