# A Parallel Analytical Legalization Algorithm via Alternating Direction Method of Multipliers

**Venue:** ICCAD

## Problem
Legalization with cell overlap resolution typically relies on suboptimal heuristic cell-by-cell search, while analytical methods suffer from runtime overhead and discrete problem complexity.

## Motivation
Large-scale design legalization requires better solution quality without excessive runtime overhead.

## Method
The method uses Alternating Direction Method of Multipliers (ADMM), an iterative algorithm that breaks the legalization problem into smaller pieces that can be solved in stages. CPUs and GPUs divide the work: the GPU performs parallel optimization on the continuous math problem, while the CPU handles the discrete constraints that force cells to snap to valid grid positions. This parallel analytical approach avoids the runtime slowdown of pure analytical methods while achieving better results than traditional heuristic cell-by-cell search.

## Key Novelty
Legalization is solved analytically using ADMM with CPUs and GPUs working in parallel to jointly handle continuous optimization and discrete cell positioning.
