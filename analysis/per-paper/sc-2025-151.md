# SC-2025-151: Workload Intelligence

## Summary
Proposes a bidirectional communication framework (Workload Intelligence) between cloud workloads and platforms to improve resource efficiency by enabling workloads to declare characteristics and respond to platform events.

## Problem
- Cloud platforms receive minimal workload information beyond VM type/decoration
- Workloads have limited platform visibility (only telemetry + occasional signals like pre-eviction)
- Narrow interface creates three problems:
  1. VM type/decoration proliferation complicates customer selection
  2. Unspecified workload characteristics prevent platform customization
  3. Workloads lack sufficient information for timely optimization

## Key Contribution
Workload Intelligence (WI) framework enabling bidirectional communication:
- Workloads declare characteristics (availability requirements, resource preferences)
- Platform exposes optimization hints and events
- Dynamic adaptation without static VM type constraints

## Novelty
First comprehensive framework for workload-platform communication in IaaS; addresses the abstraction gap that traditional VM models create.

## Hardware/Systems
- Cloud infrastructure
- Virtual machine environments
- Multi-tenant data centers
