# dac-2025-426: Voltage Side-Channel Attack via DSP Blocks in FPGAs

**Problem:** Multi-tenant FPGA clouds expose shared power networks; DSP blocks remain unexploited as malicious voltage sensors.

**Motivation:** Cloud multi-tenancy requires covert-channel-resistant isolation; DSP block abuse enables practical voltage-based attacks.

**Method:** Reconfigures DSP blocks to sense fine-grained voltage fluctuations; detects colocated circuit activity and extracts secrets.

**Key Novelty:** First voltage-sensing side-channel attack using only DSP blocks.

**Contributions:**
- DSP configuration as high-sensitivity voltage sensor with placement robustness
- AES key extraction from 25k–78k traces
- Covert channel at 247.94 bit/s
