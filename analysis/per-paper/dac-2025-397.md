# dac-2025-397: SimPhony: A Device-Circuit-Architecture Cross-Layer Modeling and Simulation Framework for Heterogeneous Electronic-Photonic AI System

**Problem:** EPICs lack unified simulation framework for exploring hardware innovations and evaluating on common benchmarks across device-circuit-architecture layers.

**Method:** SimPhony simulates electronic-photonic AI chips across all design levels—from individual devices to complete system architecture—using dataflow models specific to optical components that capture multiple forms of parallelism. It calculates power consumption based on actual data patterns and component behavior, estimates chip area and optical signal quality, and adjusts memory bandwidth to match throughput requirements. It integrates with machine learning frameworks so researchers can test new designs without building physical prototypes.

**Key Novelty:** First unified framework for electronic-photonic systems with optics-specific dataflow modeling beyond spatial/temporal dimensions.

**Contributions:**
- Generic hardware topology for heterogeneous EPIC architectures
- Optics-specific multi-dimensional dataflow
- Data-aware energy modeling with layout awareness
- Hardware/software co-simulation integration
