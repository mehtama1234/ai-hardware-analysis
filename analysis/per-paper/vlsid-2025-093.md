# PAF-Enc: Position Affine Encoding to Reduce Bit-Flips in Non-Volatile Main Memories

**Venue:** VLSID 2025  
**Authors:** Swati Upadhyay, Hemangee K. Kapoor

## Problem Statement
Emerging non-volatile memories (NVMs) are proposed as replacements for DRAM to address scalability challenges in data-intensive workloads. However, NVM lifetime and performance are severely limited by high write operation counts. The disparity between stored data and incoming cache-block data creates unnecessary bit-flip operations, accelerating wear and reducing system lifespan.

## Key Contributions
1. **Position-Affine Encoding Scheme**: Two-stage encoding technique that reduces bit-write operations by pre-processing incoming data to match existing memory patterns
2. **Pattern-Aware Data Transformation**: Lightweight XOR-based encoding that generates masks from memory data patterns
3. **Reduced Write Operations**: Significant reduction in bit-flip count during cache-to-memory writes
4. **Improved Lifetime**: Direct correlation between reduced writes and increased NVM endurance
5. **Performance Enhancement**: Reduced write latency and power consumption through decreased write operations

## Technical Approach
- **Stage 1 - Pattern Analysis**: Analyze memory data patterns to generate affine masks representing typical stored values
- **Stage 2 - Encoding**: Apply XOR-based encoding to incoming cache blocks using masks to transform data closer to memory patterns before write
- **Implementation**: Lightweight, requiring only XOR operations and mask storage
- **Scope**: Applied at cache-memory interface

## Hardware Target
