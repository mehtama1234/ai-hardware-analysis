# RISC-V Based Secure Processor Architecture for Return Address Protection

**VLSID 2025** | vlsid-2025-083

## Abstract
RISC-V embedded systems face memory-based attacks, particularly buffer overflows targeting control flow. This work proposes hardware-based return address protection using the existing Return Address Stack (RAS), aligned with RISC-V zicfiss/zicfiip standards. Implementation on Rocket-Core SoC: <0.1% memory overhead, 2% worst-case timing overhead; validated with RIPE benchmark and custom tests.

## Problem
- RISC-V systems vulnerable to stack-based buffer overflow attacks
- Control flow hijacking common attack vector
- Software-only mitigations insufficient and costly

## Key Insight
Leverage existing RAS hardware for low-overhead backward edge control flow integrity (CFI), protecting return addresses with minimal architectural changes.

## Approach
1. Hardware enforcement of return address integrity via RAS
2. Minimal changes to existing microarchitecture
3. Low software overhead integration
4. Alignment with RISC-V zicfiss/zicfiip standards

## Protection Mechanisms
- **Backward edge CFI**: Return address validation
- **Forward edge CFI**: Call target validation (via zicfiip)
- **Spectre RAS mitigation**: Reduces RAS-based Spectre variants
