# SC-2025-415: RingX - Scalable Parallel Attention for Long-Context Learning on HPC

## Summary
RingX optimizes ring attention for HPC architectures through improved workload partitioning and communication patterns, achieving 3.4x speedup on Frontier and 38% MFU for Llama3 8B training with 1M-token sequences on 4096 GPUs.

## Problem
Ring attention achieves parallelism but uses point-to-point communication that fails to exploit HPC network topologies, resulting in poor scalability and underutilization on supercomputers.

## Method
RingX improves ring attention (splitting attention across GPUs by chaining data through them) by redesigning workload distribution and communication patterns. Ring attention's point-to-point communication (GPU-to-GPU in a chain) doesn't match modern supercomputer network topologies, causing inefficiencies. RingX optimizes the communication pattern to match how supercomputers like Frontier are actually wired, reducing bottlenecks and balancing the workload. It supports both bi-directional and causal attention mechanisms.

## Key Results
- 3.4x speedup over ring attention on Frontier (AMD MI250X GPUs)
- 1.5x end-to-end speedup for Vision Transformer and Llama3 8B
- 38% model FLOPs utilization on 4096 GPUs (1M-token sequences)
- Represents one of highest reported efficiencies for long-context training on HPC
