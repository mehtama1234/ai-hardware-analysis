# Row-Column Hybrid Grouping for Fault-Resilient Multi-Bit Weight Representation on IMC Arrays

**Venue:** ICCAD  
**ID:** iccad-2025-076

## Problem
Analog IMC systems suffer from stuck-at faults (SAFs) that reduce computational reliability and existing fault-mitigation algorithms (e.g., Fault-Free) impose high compilation overhead. Fault-resilient design of IMC arrays remains computationally expensive and challenging to scale.

## Motivation
Enabling fault-tolerant in-memory computing is essential for deploying reliable neural accelerators, particularly as IMC arrays scale to larger sizes where faults become more prevalent.

## Method
The paper proposes row-column hybrid grouping that generalizes column grouping by introducing redundancy across both rows and columns in weight representation. A compiler pipeline reformulates fault-aware weight decomposition as an Integer Linear Programming (ILP) task solved by off-the-shelf solvers. Theoretical insights identify fault patterns with trivial solutions, significantly reducing computation time while maintaining fault tolerance.

## Key Novelty
2D redundancy structure (row-column hybrid grouping) combined with ILP-based compilation for fast, scalable fault-aware weight decomposition in IMC arrays.

## Contributions
- Row-column hybrid grouping technique extending conventional column grouping with 2D redundancy structure
- ILP-formulated compiler pipeline for fast fault-aware weight decomposition with theoretical optimization
- Demonstration of up to 8%p accuracy improvement and 2× energy efficiency gain on CNNs and small LLMs
- 150× faster compilation compared to existing Fault-Free baselines
