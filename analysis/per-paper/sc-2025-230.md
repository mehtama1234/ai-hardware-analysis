# MLP-Offload: Multi-Level, Multi-Path Offloading for LLM Pre-training to Break the GPU Memory Wall

**ID:** sc-2025-230
**Venue:** SC
**Confidence:** low

## Problem

LLM training blocked by GPU memory limits; existing offloading has high I/O overhead in training critical path

## Motivation

LLMs exceed GPU memory; I/O during update phase dominates iteration time; multi-tier storage unused

## Approach

Multi-level, multi-path offloading engine; optimizer state across tiers; cache-efficient, contention-aware design

## Key Novelty

Multi-tier offloading with concurrency control; I/O optimization for backward/update phases; 2.5x speedup

## Contributions

- Multi-level optimizer state offloading strategy
- Cache-efficient tier-aware placement
- Contention mitigation for concurrent offloading
- 2.5x faster training iterations vs SOTA
