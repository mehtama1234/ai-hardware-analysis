# MambaOPU: An FPGA Overlay Processor for State-space-duality-based Mamba Models

**Venue:** DAC
**ID:** dac-2025-237

## Problem
Mamba2 state-space models are memory-bound due to irregular broadcast element-wise multiplications and structured sparse computations; neither CPU nor standard GPU achieve good compute efficiency.

## Motivation
Mamba2 models are emerging as transformer alternatives with linear complexity; efficient hardware support is critical for adoption.

## Method
The system builds a specialized processor on an FPGA that addresses three performance bottlenecks in Mamba models. First, it combines (fuses) multiplication and addition operations into single steps, using backward shifting to embed multiplication into subsequent operations and reduce intermediate data storage. Second, it skips computation on sparse data—mostly-empty tensors—by reorganizing data into groups and using a specialized fetcher that only retrieves non-zero values. Third, it uses a reconfigurable systolic array—a flexible grid of connected processing elements—to perform linear calculations while improving data reuse by keeping values in faster local memory.

## Key Novelty
A specialized FPGA processor combining operator fusion (merging operations), sparse skipping (computing only non-zero values), and a reconfigurable processing grid to speed up state-space models like Mamba by reducing data movement bottlenecks.

## Contributions

- MambaOPU FPGA overlay for state-space-duality models
- Software-hardware co-optimized operator fusion
- Sparse computation skipping algorithm
- 1812x throughput vs CPU, 880.79x vs A100 GPU
- 12908x energy efficiency vs CPU, 24.27x vs GPU
