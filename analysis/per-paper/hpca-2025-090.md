# hpca-2025-090 — CogSys: Efficient and Scalable Neurosymbolic Cognition System via Algorithm-Hardware Co-Design

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Neurosymbolic AI workloads—combining neural network inference with symbolic reasoning (e.g., probabilistic logic, abduction)—exhibit high memory intensity, compute heterogeneity, and irregular access patterns that cause severe underutilization on commodity CPU/GPU/TPU hardware.

## Motivation
Neurosymbolic AI offers superior data efficiency and interpretability for edge deployments, but lacks dedicated hardware support, preventing its adoption in real-time cognitive applications that require reasoning within human-level latency constraints.

## Method
CogSys uses three coordinated techniques. The algorithm reduces memory and compute demands through tensor factorization (breaking symbolic reasoning calculations into smaller pieces that take less space and processing). The hardware is a custom chip (ASIC) with reconfigurable processing tiles (nsPEs) that switch between neural and symbolic work; a bubble streaming dataflow architecture (using spatial-temporal mapping to spread computation across space and time) lets them execute tasks in parallel without blocking. An adaptive scheduler assigns work to tiles based on demand, keeping all tiles busy and fully utilized, implemented on TSMC 28nm.

## Key Novelty
Reconfigurable processing tiles (nsPEs) with bubble streaming dataflow enable a single spatial chip design that unifies neural and symbolic reasoning with adaptive kernel scheduling, making real-time abductive reasoning (inferring likely causes from observations) possible.

## Contributions
- First characterization of neurosymbolic workload bottlenecks on existing hardware (CPU/GPU/TPU)
- Efficient factorization algorithm reducing neurosymbolic compute and memory overhead
- CogSys ASIC architecture with reconfigurable nsPEs and bubble streaming dataflow
- Adaptive workload-aware scheduler enabling real-time abduction reasoning at 0.3s per task in 4mm^2, 1.48W

## Hardware Targets

## Metrics
- >75x speedup over TPU-like systolic array; 4x-96x over desktop/edge GPUs
- Area: 4mm^2 at TSMC 28nm
- Power: 1.48W; <5% area overhead vs systolic array baseline

## Baselines
- TPU-like systolic array, desktop GPU, edge GPU

## Limitations
Evaluation is limited to TSMC 28nm synthesis; real-time performance on production silicon for larger neurosymbolic models is not validated.
