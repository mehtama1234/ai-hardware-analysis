# hpca-2025-021 — Gaze into the Pattern: Characterizing Spatial Patterns with Internal Temporal Correlations for Hardware Prefetching

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Spatial-region hardware prefetchers rely on system-level context (trigger PC, data address) that fails to capture intrinsic spatial access pattern structure, resulting in suboptimal accuracy and flexibility across diverse workloads.

## Motivation
Widening memory latency gaps demand better hardware prefetching; conventional spatial prefetchers over-rely on external context rather than intra-footprint access structure, limiting adaptability.

## Method
Gaze works by analyzing the order and timing of memory accesses within a spatial region to predict what the program will access next. Instead of relying on external signals like the program location (trigger PC) or memory address patterns, it uses these internal ordering patterns, which are more consistent across different workloads. For programs with very dense memory access patterns within a region, Gaze uses a two-stage approach: it first identifies these high-density patterns, then makes targeted decisions about which data to fetch in advance, so it doesn't fetch data that won't be used.

## Key Novelty
The key idea is using the order of memory accesses within a region (footprint-internal temporal correlation) as the signal for prediction, rather than relying on external context like the program location (trigger PC) or memory address patterns.

## Contributions
- Identification of intra-footprint temporal correlation as more effective than external context for spatial prefetching.
- Gaze hardware prefetcher using temporal correlations within spatial footprints.
- Two-stage approach mitigating over-prefetching in high-density streaming.
- 5.7%/5.4% single-core and 11.4%/8.8% eight-core IPC improvement vs. PMP and vBerti.

## Limitations
