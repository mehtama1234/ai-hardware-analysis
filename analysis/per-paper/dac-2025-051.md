# ZXNet: ZX Calculus-Driven Graph Neural Network Framework for Quantum Circuit Equivalence Checking

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
Quantum circuit transpilation requires equivalence verification; existing methods have poor scalability and high computational overhead.

## Key Idea
Combine ZX calculus graph abstractions with GNNs to capture local/global circuit features for efficient equivalence checking.

## Method
ZXNet converts quantum circuits into simplified diagram representations using ZX calculus, a mathematical notation that expresses quantum operations as connected shapes. Machine learning models called graph neural networks then learn patterns in these diagrams to determine if two circuits are equivalent. This approach dramatically reduces the computational work needed to verify whether different circuit implementations perform the same function.

## Contributions
1. ZXNet framework: ZX calculus + GNN integration
2. 99.4% validation accuracy with 62x speedup
3. 45.83% scalability, 42.22% per-qubit time, 5.94% accuracy improvements
