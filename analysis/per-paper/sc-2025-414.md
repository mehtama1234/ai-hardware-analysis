# SC-2025-414: Do Large Language Models Speak Scientific Workflows?

## Summary
An experimental study evaluating LLM capabilities for scientific workflow tasks (configuration, annotation, translation), revealing that LLMs lack sufficient training data for workflows and showing performance variations across systems.

## Problem
Scientific workflows are essential for HPC but complex to author and maintain. It's unclear whether LLMs can effectively configure, annotate, or translate workflows—potentially due to limited training data.

## Methodology
- **Three workflow-specific experiments**: Evaluated real-world workflow scenarios
- **Open and closed-source LLMs**: Tested both commercial and academic models
- **State-of-the-art workflow systems**: Used current production workflow tools

## Key Findings
- LLMs struggle with scientific workflows due to limited training data
- Performance varies significantly across different workflow systems
- Capability gaps exist in workflow configuration and translation
- Opportunities for targeted improvements identified

## Hardware/System Target
- HPC systems with workflow management
- Scientific computing platforms
- Federated and distributed workflow systems

## Technique Categories
- Large language model evaluation
- Workflow automation and domain adaptation
- Training data analysis
- LLM capability assessment

## Research Impact
- Identifies specific gaps in LLM training for scientific computing domains
- Motivates future work on workflow-specific model training or fine-tuning
- Informs workflow tool designers about LLM integration feasibility

## Limitations
- Analysis based on abstract only
- Specific performance metrics not disclosed
- Which workflow systems tested not detailed
- Details on tested LLM models not provided

## Implications
Results suggest that effective LLM-based workflow automation requires either (a) large-scale collection of workflow training data, (b) fine-tuning existing models on domain-specific data, or (c) hybrid approaches combining traditional parsers with LLM assistance.
