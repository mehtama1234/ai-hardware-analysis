# Solving the Cold-Start Problem for the Edge: Clustering and Adaptive Deep Learning for Emotion Detection

**Venue**: DATE  
**Primary Theme**: clustering-based personalization for edge emotion detection  

## Problem
Personalized edge ML systems face cold-start problem when new users lack labeled data, and deployment constraints limit model complexity for resource-constrained edge devices.

## Method
CLEAR groups existing users based on their emotion-recognition patterns, finding natural clusters without needing labels (unsupervised clustering). When a new user arrives with minimal labeled data, the system assigns them to the most similar cluster and fine-tunes that cluster's model using just a few of their labeled examples, adapting it to their individual style. The entire system runs on resource-constrained edge devices: Coral Edge TPU and Movidius Neural Compute Stick 2.

## Key Novelty
The key idea is using unsupervised clustering to group users, allowing new users to personalize a cluster's model with just a few labeled examples instead of needing either a generic model or full individual labeling.

## Contributions
- Clustering-based cold-start solution requiring no initial labeled data
- Accuracy improvement from 75% to 81.9% via clustering
- Fine-tuning achieving 86.34% accuracy on fear detection task
- Efficient deployment on Coral Edge TPU and Movidius platforms
