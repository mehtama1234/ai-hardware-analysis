# Solving the Cold-Start Problem for the Edge: Clustering and Adaptive Deep Learning for Emotion Detection

**Venue**: DATE  
**Primary Theme**: clustering-based personalization for edge emotion detection  

## Problem
Personalized edge ML systems face cold-start problem when new users lack labeled data, and deployment constraints limit model complexity for resource-constrained edge devices.

## Method
CLEAR (Clustering and Learning for Emotion Adaptive Recognition) combines unsupervised clustering for user grouping with fine-tuning on minimal labeled data, deployed on Coral Edge TPU and Movidius Neural Compute Stick 2.

## Key Novelty
Data-driven clustering enables cold-start personalization without labeled data for new users, bridging population-wide and fully personalized models.

## Contributions
- Clustering-based cold-start solution requiring no initial labeled data
- Accuracy improvement from 75% to 81.9% via clustering
- Fine-tuning achieving 86.34% accuracy on fear detection task
- Efficient deployment on Coral Edge TPU and Movidius platforms
