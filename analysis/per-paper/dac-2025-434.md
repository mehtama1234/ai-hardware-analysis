# dac-2025-434: Diffusion Model with HGNN for Initial Floorplan Generation

**Problem:** Classical floorplanners sensitive to initial solutions; learning-based methods are computationally inefficient.

**Motivation:** Better initial solutions significantly improve analytical optimizer results.

**Method:** The approach uses a diffusion model—a generative technique starting from noise and iteratively refining toward realistic solutions—to produce high-quality initial floorplans (arrangements of circuit blocks). It employs a heterogeneous graph neural network that learns how different entity types (blocks and pins/connection points) should relate and position relative to each other. A guidance function steers this generation process by optimizing for minimal wirelength (total connecting wire length) and zero block overlaps.

**Key Novelty:** Diffusion-based initial floorplan generation with HGNN feature extraction.

**Contributions:**
- Customized diffusion model for high-quality initial solutions
- HGNN explicitly modeling block-to-block and pin-to-block relationships
- Guidance sampling reducing steps while optimizing objectives
- 4.8% runtime; 3.0% HPWL reduction vs original floorplanner

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
