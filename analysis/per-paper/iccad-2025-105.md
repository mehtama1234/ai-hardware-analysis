# SLTarch: Towards Scalable Point-Based Neural Rendering by Taming Workload Imbalance and Memory Irregularity

**Venue:** ICCAD  
**Confidence:** low

## Problem
Point-based neural rendering suffers from inefficiency on mobile GPUs due to two bottlenecks: LoD (level-of-detail) search with workload imbalance and irregular memory access, and splatting with severe warp divergence from inherent sparsity.

## Motivation
Real-time, high-quality 3D rendering is critical for AR/VR, autonomous driving, and 3D modeling applications on mobile platforms.

## Method
SLTarch speeds up neural rendering on mobile GPUs by pairing algorithm changes with custom hardware accelerators. It adds a specialized data structure called SLTree and a hardware accelerator called LTcore to make level-of-detail search faster—the search for how much geometric detail to show in each pixel, which normally creates workload imbalance where some GPU cores get far more work than others. For the splatting step (blending neural network outputs into the final image), it uses an algorithm and hardware component called SPcore that prevents warp divergence—where GPU cores take different computation paths and waste cycles—and efficiently handles irregular memory access patterns.

## Key Novelty
The core innovation is co-designing specialized hardware accelerators (LTcore and SPcore) with custom algorithms to directly eliminate the two bottlenecks of point-based neural rendering: workload imbalance in level-of-detail search and warp divergence in splatting.

## Contributions
- SLTree subtree-based data structure with LTcore hardware for efficient LoD search
- Divergence-free splatting algorithm with SPcore co-processor
- 3.9× speedup and 98% energy savings vs. mobile GPU baseline
- 1.8× speedup and 54% energy savings vs. existing accelerator designs
