# isscc-2025-088: Tomahawk5 AI/ML Network Switch

**Venue:** ISSCC  
**Confidence:** low (abstract-only)

## Problem
Next-generation AI/ML data centers demand 51.2Tb/s switching (2x previous); monolithic integration at scale with diverse connectivity options is challenging.

## Motivation
Explosive AI/ML growth drives need for high-capacity, flexible data center switching infrastructure.

## Method
Tomahawk5 is a monolithic chip—meaning all the network switching logic fits on one 5-nanometer piece of silicon—achieving 51.2 trillion bits per second switching capacity in a single integrated design. The chip uses Peregrine SerDes cores, which are high-speed circuits that translate signals between the chip's internal architecture and external cables, enabling it to work with multiple physical connection formats. These cores support direct copper cables, front-panel optics, pluggable optical modules, and fiber optics built directly into the chip's package, allowing data centers to use whichever connection method they already have deployed.

## Key Novelty
Embedding Peregrine SerDes cores into the monolithic switch enables a single 51.2Tb/s chip to natively support multiple connection types—copper and various optical formats—without needing separate interface cards.

## Contributions
- 51.2Tb/s switching (2x predecessor)
- Integrated Peregrine SerDes
- Multi-protocol optical/copper support (DAC/FPO/LPO/CPO)
- 5nm monolithic integration

## Metrics
- Switching: 51.2 Tb/s
- Technology: 5nm
- Improvement: 2x vs. Tomahawk4
