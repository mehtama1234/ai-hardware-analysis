# Stratum: System-Hardware Co-Design with Tiered Monolithic 3D-Stackable DRAM for Efficient MoE Serving

**Venue:** MICRO  
**Confidence:** high (full text)

## Problem
MoE LLM inference is bottlenecked by the massive expert parameter volume (>95% of model size in Mixtral 8x7B), overwhelming GPU HBM bandwidth and capacity. HBM-based NMP is further limited by coarse-pitch TSVs (~10 µm) that cap internal bandwidth.

## Motivation
Monolithic 3D-Stackable DRAM (Mono3D DRAM) achieves Cu-Cu hybrid bonding at 1 µm pitch (5x finer than HBM TSVs), delivering higher internal bandwidth, but its aggressive vertical scaling introduces layer-dependent access latency heterogeneity that naive designs waste.

## Method
Stratum integrates specialized DRAM (Mono3D) with a processor chip via copper-to-copper bonding, connecting both to a GPU through a 2.5D silicon interposer. Expert weights are stored in two DRAM tiers: fast (faster access time) and slow—before processing each batch, a topic classifier predicts which experts will be used and remaps hot experts to fast tiers via a row-swap buffer, avoiding expensive off-chip data transfers. The processor contains tensor cores (matrix multiplication hardware) positioned near the DRAM, connected by a ring network, plus engines for Softmax/SiLU computation; the GPU handles prefill (first token), while Stratum handles decoding (remaining tokens).

## Key Novelty
The core innovation is exploiting Mono3D DRAM's inherent speed differences between its layers, combined with predicting which experts each batch will use, to keep hot expert weights in fast tiers without off-chip data movement.

## Contributions
1. First MoE serving co-design using Mono3D DRAM with 3D hybrid bonding + 2.5D silicon interposer
2. In-memory tiering with tiering tables and row-swap buffers exploiting layer-latency heterogeneity
3. Ring-network NMP processor with near-bank tensor cores and SIMD special-function engine
4. Up to 8.29x decoding throughput and 7.66x energy efficiency vs. GPU baselines

## Hardware Target
GPU, PIM, chiplet

## Metrics
- Speedup: up to 8.29x decoding throughput vs. GPU baseline
- Energy: up to 7.66x better energy efficiency vs. GPU baseline
- Internal bandwidth: ~5x higher vertical interconnect density than HBM (1 µm vs 10 µm)

## Baselines
- NVIDIA H100 GPU-HBM, NVIDIA RTX A6000, AttAcc, Neupims, Duplex

## Limitations
Mono3D DRAM is not yet in volume production; evaluation is simulation-based with projected device parameters.
