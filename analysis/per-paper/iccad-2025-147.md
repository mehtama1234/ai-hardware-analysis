# M3: Mamba-assisted Multi-Circuit Optimization via Model-based RL with Effective Scheduling

**Venue:** ICCAD
**ID:** iccad-2025-147
**Confidence:** low

## Problem
Analog circuit design traditionally uses task-specific optimization models that don't generalize across different circuit topologies, limiting automation and scalability.

## Motivation
Unified RL models for multi-circuit optimization can accelerate analog design space exploration and enable automated circuit optimization.

## Method
M3 uses a machine-learning system called Mamba combined with model-based reinforcement learning (learning through trial-and-error guided by predictions) to design multiple circuits with different topologies (physical layouts) simultaneously. The system includes a dynamic scheduling mechanism that adjusts the balance between exploring new design possibilities and refining promising ones. Because it learns to handle different circuit topologies directly, it works without needing manual adjustments for each circuit type.

## Key Novelty
A single learning system that optimizes multiple circuits with different physical layouts at once, without needing manual reconfiguration for each circuit type.

## Contributions
- Mamba architecture for unified circuit optimization model
- Model-based RL with dynamic scheduling for exploration-exploitation balance
- Multi-topology circuit optimization without task-specific adjustments
- Successful optimization of multiple circuits to target specifications
