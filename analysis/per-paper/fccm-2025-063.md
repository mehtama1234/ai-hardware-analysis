# LLM4DV: Using Large Language Models for Hardware Test Stimuli Generation

**Problem:** Hardware design verification requires manual generation of complex test stimuli to validate functional equivalence against specifications. This test generation process is labor-intensive and specific to each hardware design.

**Method:** LLM4DV automates the creation of test inputs for hardware verification by having multiple large language models (AI systems trained on text) work together using refined prompting techniques—different ways of asking the models to generate tests. Rather than manually creating tests for each chip design, the framework tests six different models and six different prompting strategies across eight hardware designs to discover which combinations work best.

**Novelty:** Using coordinated large language models (multiple AI systems working together) with refined prompting to automatically generate hardware test inputs.
