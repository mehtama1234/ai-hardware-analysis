# LLM4DV: Using Large Language Models for Hardware Test Stimuli Generation

**Problem:** Hardware design verification requires manual generation of complex test stimuli to validate functional equivalence against specifications. This test generation process is labor-intensive and specific to each hardware design.

**Method:** LLM4DV orchestrates multiple LLMs with systematic prompting strategies for automated test stimuli generation. The framework evaluates six different LLMs with six prompting improvements across eight hardware designs to identify effective approaches for leveraging LLMs in the verification workflow.

**Novelty:** First systematic framework for applying orchestrated LLMs with prompting optimization to automated hardware test stimuli generation.
