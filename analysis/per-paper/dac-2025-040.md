# PatLabor: Pareto Optimization of Timing-Driven Routing Trees

**Problem:** Conventional timing-driven routing uses parameter tuning to trade wirelength vs. delay, but cannot compute full Pareto frontiers or provide theoretical guarantees.

**Key Idea:** Directly optimize the Pareto set for routing trees; for small nets (≤9 pins), compute all Pareto-optimal solutions with provable time complexity bounds.

**Approach:** Algorithm avoids parameter tuning by explicitly exploring the delay-wirelength trade-off space; provides approximation bounds and complexity proofs.

**Results:** 58.5% more Pareto solutions vs. prior methods on degree-9 nets; tighter Pareto curves on ICCAD-15.

**Theme:** Theoretically-grounded Pareto optimization for timing-aware routing design.
