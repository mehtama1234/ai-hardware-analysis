# Söze: One Network Telemetry Is All You Need for Per-flow Weighted Bandwidth Allocation at Scale

**Problem:** Achieving agile and precise weighted bandwidth allocation for large-scale cloud networks is fundamentally challenging.

**Method:** Söze collects simple traffic information from standard network switches—the equipment routing data in cloud networks. Each data flow is assigned a weight indicating its bandwidth priority; the system uses only these switch-level metrics and weights to calculate how much bandwidth each flow should get, without needing to know the network's full topology, which servers are involved, or which paths the data takes. These calculations happen in a decentralized way (no central controller needed), and the allocations are then enforced throughout the network.

**Novelty:** Weighted bandwidth allocation can be achieved using only simple traffic information from standard switches, without needing to track individual flows, know the network's layout, or understand routing paths.
