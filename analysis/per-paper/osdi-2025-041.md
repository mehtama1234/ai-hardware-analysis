# Söze: One Network Telemetry Is All You Need for Per-flow Weighted Bandwidth Allocation at Scale

**Problem:** Achieving agile and precise weighted bandwidth allocation for large-scale cloud networks is fundamentally challenging.

**Method:** Söze is a lightweight decentralized system that leverages network telemetry features from commodity Ethernet switches. Given flow weights, it computes and enforces weighted bandwidth allocations using only telemetry information, without requiring per-flow, topology, or routing knowledge. The system uses decentralized computation to determine per-flow allocations based on switch-level metrics.

**Novelty:** Using simple network telemetry from commodity switches to perform decentralized weighted bandwidth allocation without per-flow, topology, or routing knowledge.
