# ODOS-MPI: HPC-Friendly SmartNIC Offloading of Computation/Communication Kernels

**ID**: sc-2025-364
**Venue**: SC
**Confidence**: low

## Problem
Optimizing communication performance in hierarchical multi-GPU systems

## Motivation
Domain scientists need higher-level abstractions for GPU acceleration

## Method
The approach extends OpenMP with new pragmas—compiler directives that programmers add to their code—to automatically offload MPI operations (Message Passing Interface, how connected computers exchange data in HPC systems) to SmartNICs (specialized network processor cards). This keeps the main CPU free for computation while the SmartNIC handles communication in multi-GPU clusters, reducing performance bottlenecks in hierarchical systems.

## Key Novelty
The first OpenMP pragmas designed to enable offloading of Message Passing Interface communication to SmartNICs.
