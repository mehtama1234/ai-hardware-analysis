# InterA-ECC: Interconnect-Aware Error Correction in STT-MRAM

**Venue**: DATE  
**Primary Theme**: Interconnect-aware memory error correction  

## Problem
STT-MRAM reliability is compromised by stochastic switching, process variation, and manufacturing defects; interconnect parasitic resistive-capacitive effects disproportionately impact cells distant from write drivers, creating reliability gradients across the memory subarray.

## Method
In STT-MRAM, cells far from write drivers become less reliable because connecting wires act as resistors and capacitors, degrading the electrical signals needed for writing data. Instead of using uniform error correction coding (a technique that detects and fixes data corruption) across all cells, this method applies stronger error protection to vulnerable rows and weaker protection to reliable rows nearer the drivers. This zone-based strategy concentrates the overhead of error correction exactly where errors are most likely to occur.

## Key Novelty
The innovation is applying variable-strength error correction that matches each location's vulnerability to interconnect effects instead of protecting uniformly.

## Contributions
- Identification and characterization of interconnect parasitic effects on STT-MRAM reliability
- Zone-aware ECC architecture providing non-uniform protection
- Reduction in ECC parity bits while maintaining bit error rate resilience in critical zones
- Improved manufacturing yield through targeted protection strategy
