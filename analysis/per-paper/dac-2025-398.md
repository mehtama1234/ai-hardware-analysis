# dac-2025-398: TAXI: Traveling Salesman Problem Accelerator with X-bar-based Ising Macros Powered by SOT-MRAMs and Hierarchical Clustering

**Problem:** Ising solvers degrade solution quality at scale; hardware-agnostic approaches miss hardware co-design opportunities.

**Method:** TAXI solves Traveling Salesman Problems by breaking them into smaller subproblems with hierarchical clustering, then solving each subproblem in parallel using Ising macros—specialized circuits built from crossbars (grid-like arrangements of switches). The crucial design choice is that each macro works entirely independently without sharing data with other macros, enabling true parallelism. The random numbers used during annealing (gradually cooling down to lock in good solutions) come from SOT-MRAM devices (Spin-Orbit-Torque magnetic memory chips), which produce randomness rapidly while consuming very little power.

**Key Novelty:** Hardware-algorithm co-design pairing Ising solver macros with SOT-MRAM annealing and hierarchical clustering for massive parallelism without data movement.

**Contributions:**
- Crossbar Ising macro architecture
- SOT-MRAM random number generators
- Hardware-algorithm co-design to 85,900-city TSPs
- 8x speedup; 20-22% from optimal
