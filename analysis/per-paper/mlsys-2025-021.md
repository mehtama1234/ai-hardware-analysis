# mlsys-2025-021 — MiLo: Efficient Quantized MoE Inference with Mixture of Low-Rank Compensators

**Venue:** MLSYS 2025

**One-line problem:** Enable accurate, fast INT3-quantized inference for MoE LLMs without calibration data and with real throughput gains at batch size > 1.

## Method
Calibration-free HQQ-based INT3 quantization with a mixture of adaptive low-rank compensators (SVD-based residual reconstruction). Compensator rank is chosen per-layer using weight kurtosis and expert activation frequency. A custom W3A16 Tensor Core kernel uses zero-bit-waste INT3 packing, binary manipulation I2F dequantization, and async global weight loading to achieve batch size > 1 speedups. Compensators are also INT3-quantized.

## Key Novelty
First W3A16 Tensor Core kernel to demonstrate measured throughput speedups at batch size > 1 for MoE models, paired with calibration-free adaptive low-rank compensation.

## Metrics
- 1.2x speedup over MARLIN backend for Mixtral-8x7B (A100)
- 3x faster quantization time vs GPTQ
- Recovers 87%+ accuracy at 22% compression ratio
- MiLo-s2 surpasses GPTQ by 17% on Wikitext2 PPL
