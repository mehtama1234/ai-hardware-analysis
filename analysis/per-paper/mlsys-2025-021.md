# mlsys-2025-021 — MiLo: Efficient Quantized MoE Inference with Mixture of Low-Rank Compensators

**Venue:** MLSYS 2025

**One-line problem:** Enable accurate, fast INT3-quantized inference for MoE LLMs without calibration data and with real throughput gains at batch size > 1.

## Method
The approach combines HQQ-based INT3 quantization (storing weights as 3-bit integers without calibration data) with adaptive low-rank compensators that use SVD (a matrix decomposition) to recover lost accuracy. For each layer, the compensator's complexity is chosen based on three factors: dense vs sparse layer type, weight distribution (kurtosis), and expert activation frequency. Both the quantized weights and compensators are jointly optimized and packed into INT3 format. The method includes a custom GPU kernel (W3A16 Tensor Core GeMM) that efficiently runs these 3-bit weights with multiple inputs at once through zero-bit-waste INT3 packing, fast binary-manipulation integer-to-float conversion, and asynchronous weight loading.

## Key Novelty
It provides the first GPU kernel proven to speed up mixture-of-experts models when processing multiple inputs at once using 3-bit weights, while recovering accuracy through calibration-free adaptive weight correction.

## Metrics
- 1.2x speedup over MARLIN backend for Mixtral-8x7B (A100)
- 3x faster quantization time vs GPTQ
- Recovers 87%+ accuracy at 22% compression ratio
- MiLo-s2 surpasses GPTQ by 17% on Wikitext2 PPL
