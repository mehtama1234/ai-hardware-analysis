# Automatic Tracing in Task-Based Runtime Systems

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
In task-based parallel runtime systems, dependence analysis becomes a performance bottleneck at fine task granularity, and existing tracing techniques that memoize this analysis require brittle manual annotations that are difficult to apply to programs composed from independent library components.

## Motivation
Task-based programming models are widely used for HPC applications, but manual trace annotation limits adoption and does not scale to complex, multi-library programs where the component author cannot anticipate composition.

## Method
Apophenia watches the stream of parallel tasks an application creates and automatically finds repeating patterns in them. When it spots a repeating pattern, it saves the task-dependency analysis for that pattern, so the system doesn't have to recompute it each time. The system integrates with existing parallel runtime systems by intercepting the task-creation API, and unlike previous approaches, needs no manual annotations from programmers.

## Key Novelty
The core innovation is automatically detecting repeating patterns in the task stream (using sequence-analysis techniques like finding repeated sequences in text) to achieve near-manual-trace performance without any programmer annotations.

## Contributions
- Apophenia: automatic trace identification in task-based runtimes without programmer annotation
- Dynamic string analysis algorithms for detecting repeated program fragments in task streams
- 0.92x–1.03x performance parity with manually traced programs
- 0.91x–2.82x speedup over untraced programs on Perlmutter and Eos supercomputers

## Limitations
Relies on task stream periodicity; may not generalize to highly irregular or data-dependent task graphs where no repeated pattern exists.
