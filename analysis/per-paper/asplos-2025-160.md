# Automatic Tracing in Task-Based Runtime Systems

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
In task-based parallel runtime systems, dependence analysis becomes a performance bottleneck at fine task granularity, and existing tracing techniques that memoize this analysis require brittle manual annotations that are difficult to apply to programs composed from independent library components.

## Motivation
Task-based programming models are widely used for HPC applications, but manual trace annotation limits adoption and does not scale to complex, multi-library programs where the component author cannot anticipate composition.

## Method
Apophenia automatically discovers traces through dynamic string analyses applied to the stream of tasks issued by the application. It identifies repeated program fragments online by treating the task stream as a string and detecting periodicity, then memoizes the dependence analysis for those fragments. The system requires no programmer annotation and integrates with existing runtimes by intercepting the task issue API.

## Key Novelty
Automatic trace discovery via dynamic string periodicity analysis of the task stream, eliminating manual annotation while achieving near-manual-trace performance.

## Contributions
- Apophenia: automatic trace identification in task-based runtimes without programmer annotation
- Dynamic string analysis algorithms for detecting repeated program fragments in task streams
- 0.92x–1.03x performance parity with manually traced programs
- 0.91x–2.82x speedup over untraced programs on Perlmutter and Eos supercomputers

## Limitations
