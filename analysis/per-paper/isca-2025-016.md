# Avalanche: Optimizing Cache Utilization via Matrix Reordering for Sparse Matrix Multiplication Accelerator

**Venue:** ISCA  
**Confidence:** low (abstract-only analysis)

## Problem
Sparse Matrix Multiplication (SpMM) accelerators suffer from poor on-chip memory utilization due to irregular memory access patterns; existing designs fail to cache both input matrices efficiently, leading to redundant DRAM accesses and low throughput.

## Motivation
SpMM is ubiquitous in scientific computing and graph workloads, and as models grow sparser, on-chip memory utilization becomes the primary performance limiter rather than raw compute throughput.

## Method
Avalanche applies three complementary techniques: (1) **Mat-Reorder** reorders columns of matrix B to maximize data locality and enable early completion of row computations in matrix A; (2) **DP-Evict** (Dead-Product Early Eviction) immediately evicts fully-computed intermediate products from on-chip SRAM to reclaim capacity; (3) **RM-Caching** (Reuse Distance-Aware Matrix Caching) prioritizes retention of matrix B elements with short reuse distances in the on-chip cache. Together these techniques keep both operand matrices resident in a 6.15 mm2 chip with minimal spill-to-DRAM.

## Key Novelty
Column reordering of the sparse input matrix (Mat-Reorder) to align non-zero access patterns with on-chip cache capacity, enabling simultaneous caching of both operand matrices.

## Contributions
1. Mat-Reorder algorithm that reorders matrix columns to improve data locality and allow early row-computation completion
2. Dead-Product Early Eviction (DP-Evict) policy that reclaims on-chip memory as soon as partial products are finalized
3. Reuse Distance-Aware Matrix Caching (RM-Caching) that prioritizes high-reuse elements for on-chip retention
4. End-to-end SpMM accelerator (6.15 mm2) achieving 1.97x average speedup over state-of-the-art SpMM accelerators
