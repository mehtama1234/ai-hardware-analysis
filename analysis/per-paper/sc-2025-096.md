# SC25 Paper Analysis: sc-2025-096

## A Query Engine for Scientific Data Exploration using Theory, Simulation, and Artificial Intelligence Models

### Summary
IDS (Intelligent Data Search) is a unified query engine that integrates data retrieval, simulations, and AI model inference. It demonstrates how to compose complex scientific workflows (e.g., AlphaFold + AutoDock Vina + Smith-Waterman) in a single query with 5-15x performance improvements through intelligent caching.

### Key Problem
- **Workflow Fragmentation**: Scientists must manually coordinate simulations, databases, and AI models
- **Latency Challenge**: Interactive scientific discovery requires low-latency integrated queries
- **Interface Gap**: Existing systems lack unified query language spanning data and models

### Technical Approach
1. **Unified Query Engine**: Keyword, set-theoretic, and linear-algebraic operators
2. **Multi-Modal Datastore**: Feature store, vector store, and knowledge graph
3. **Model Repository**: Pre-trained AI models and custom UDFs
4. **Distributed Multi-Tier Cache**: Global caching of intermediate results and model outputs
5. **Cray Graph Engine Integration**: Scalable data substrate

### Key Components
- **In-Memory Datastore**: Scalable storage for multi-modal scientific data
- **Query Operators**: Keywords (text search), sets (Venn diagrams), linear algebra (ML-style)
- **Model Execution**: AlphaFold, AutoDock Vina, custom Python UDFs
- **Caching Strategy**: Distributed, multi-tier for performance

### Contributions
1. Unified query-model framework for integrated scientific discovery
2. Scalable distributed datastore for scientific data
3. Query language spanning multiple paradigms
4. Demonstration on real life-sciences workflow
5. 5-15x performance improvement from caching
6. Low-latency execution at scale

### Hardware & Workloads
- **Target Hardware**: HPC systems with distributed storage
- **Workloads**: Life-sciences workflows, protein structure prediction, molecular docking, sequence analysis

### Performance Results
- **Query Latency**: Tens of seconds for millions of similarity searches + thousands of inferences
- **Speedup**: 5-15x from distributed caching
- **Throughput**: Millions of similarity searches + thousands of model inferences per query

### Applications
- Drug discovery pipelines
- Protein structure analysis
- Genomics and bioinformatics
- Materials discovery

### Theme
Scientific Data Integration and Model-Driven Discovery
