# DAWN: Accelerating Point Cloud Object Detection via Object-Aware Partitioning and 3D Similarity-Based Filtering

## Problem
Point cloud object detection in autonomous driving/robotics has high computational cost due to complex point processing operations.

## Solution
DAWN exploits inter-frame redundancy via object-aware partitioning (based on prior detection results) and 3D similarity-based point filtering. Axis-sorted point selection handles non-uniform distributions. Configurable filtering ratios enable latency-accuracy tradeoffs.

## Impact
1.59x average speedup (1.70x peak) by filtering 50%+ of points with negligible accuracy loss.
