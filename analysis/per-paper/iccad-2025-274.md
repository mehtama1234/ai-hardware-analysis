# SetupKit: Efficient Multi-Corner Setup/Hold Time Characterization Using Bias-Enhanced Interpolation and Active Learning

**Venue:** ICCAD  
**ID:** iccad-2025-274

## Problem
Accurate setup/hold time characterization relies on potentially millions of SPICE simulations across diverse process-voltage-temperature (PVT) corners, creating a major bottleneck lasting weeks or months. Existing methods suffer from slow search convergence and inefficient exploration in multi-corner settings.

## Motivation
To drastically reduce characterization time using statistical intelligence and active learning to intelligently guide expensive SPICE simulations to the most informative corners.

## Method
SetupKit integrates three key innovations: BEIRA (bias-enhanced interpolation search) from statistical error modeling to accelerate convergence; initial search interval estimation by circuit analysis; active learning strategy using Gaussian Process to learn PVT-timing correlations and guide simulations to informative corners, minimizing redundancy in multi-corner characterization.

## Key Novelty
Active learning approach using Gaussian Process to intelligently minimize multi-corner characterization by focusing on the most informative PVT corners.

## Contributions
- BEIRA (bias-enhanced interpolation) method for accelerated search convergence
- Active learning framework learning PVT-timing correlations
- Gaussian Process-based corner selection strategy
- 2.4× overall CPU time reduction (720→290 days on single core) for 16 PVT corners
