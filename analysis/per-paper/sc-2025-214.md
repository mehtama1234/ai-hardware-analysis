# sc-2025-214: DHAP - Efficient OLAP in Disaggregated Heterogeneous Systems

## Overview
End-to-end framework for OLAP query processing in disaggregated datacenters with heterogeneous CPU/GPU nodes through specialized compilation and runtime.

## Key Problem
Existing data systems handle either disaggregated systems with homogeneous CPUs OR heterogeneous accelerators in monolithic servers, but not both simultaneously. This limits adoption of emerging disaggregated heterogeneous architectures.

## Approach
Co-designed query compiler and runtime system:
- **Compiler**: Planning module generates efficient execution plans for heterogeneous backends
- **Runtime**: Manages inter-stage pipelined execution, minimizes communication, respects local memory constraints

## Contributions
- Query compiler with planning for disaggregated heterogeneous systems
- Specialized runtime for CPU/GPU coordination
- Communication and memory-aware optimizations
- Achieves near-optimal solutions

## Performance Results
- **SSB/TPC benchmarks**: up to 16.3x latency speedup
- **vs. Disaggregated baseline**: 2.8x speedup
- **vs. GPU-accelerated framework**: 13.9x speedup

## Hardware Target
Disaggregated datacenters with heterogeneous CPUs and GPUs
