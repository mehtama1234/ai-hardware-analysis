# LLM4Verilog: Building Large-Scale, High-Quality Data Infrastructure for Verilog Code Generation via Community Efforts

**ID:** iccad-2025-250

## Problem
High-quality training datasets for Verilog code generation are limited. Existing datasets lack scale and diversity for robust LLM fine-tuning.

## Motivation
Large-scale, high-quality Verilog datasets enable LLM-based hardware design automation, reducing design cycle time and improving design quality.

## Method
The approach collects Verilog code examples—the language for describing chip hardware designs—from community contributors and uses them to fine-tune language models. Fine-tuning trains the models further on this specialized data to learn patterns of correct Verilog code. Success is measured by testing whether generated code works correctly (pass@1 metric: whether a single generated output passes validation), and fine-tuning improves this by 6.6-13.2% across different models.

## Key Novelty
Community-sourced Verilog datasets enable language models to generate working hardware-design code, improving generation success rates by 6.6-13.2%.
