# LLM4Verilog: Building Large-Scale, High-Quality Data Infrastructure for Verilog Code Generation via Community Efforts

**ID:** iccad-2025-250

## Problem
High-quality training datasets for Verilog code generation are limited. Existing datasets lack scale and diversity for robust LLM fine-tuning.

## Motivation
Large-scale, high-quality Verilog datasets enable LLM-based hardware design automation, reducing design cycle time and improving design quality.

## Method
Community-driven dataset collection and curation infrastructure for Verilog code generation. LLM fine-tuning on the dataset with pass@1 evaluation. Achieves 6.6-13.2% improvements in pass@1 metrics via fine-tuning.

## Key Novelty
Large-scale community-driven Verilog dataset infrastructure for LLM training with demonstrated pass@1 improvements.
