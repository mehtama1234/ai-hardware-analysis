# asplos-2025-136: Tela: A Temporal Load-Aware Cloud Virtual Disk Placement Scheme

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Cloud Virtual Disk (CVD) placement algorithms do not account for temporal I/O load fluctuations, leading to imbalanced storage warehouse loads, low resource utilization, and frequent overloads under dynamic workloads.

## Motivation
Cloud storage loads are inherently time-varying; static placement creates hotspots that degrade I/O performance and waste physical storage capacity.

## Method
Tela predicts how I/O load patterns (the read/write traffic over time) will vary for each storage warehouse, rather than just looking at current conditions. It then places cloud virtual disks (CVD—chunks of data storage that live on physical hardware) onto warehouses in a way that spreads the workload both now and into the future, avoiding placements that would later overload a warehouse.

## Key Novelty
The key idea is using predictions of how load will change over time when deciding where to place virtual disks, so storage warehouses stay balanced over time rather than just at one moment.
