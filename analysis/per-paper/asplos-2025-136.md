# asplos-2025-136: Tela: A Temporal Load-Aware Cloud Virtual Disk Placement Scheme

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Cloud Virtual Disk (CVD) placement algorithms do not account for temporal I/O load fluctuations, leading to imbalanced storage warehouse loads, low resource utilization, and frequent overloads under dynamic workloads.

## Motivation
Cloud storage loads are inherently time-varying; static placement creates hotspots that degrade I/O performance and waste physical storage capacity.

## Method
Tela models and predicts time-varying I/O load trajectories for each physical storage warehouse, then uses these temporal predictions to place CVDs in a way that balances load both at placement time and over future intervals.

## Key Novelty
Incorporating temporal load prediction into CVD placement decisions to balance storage warehouse loads across time, not just instantaneously.
