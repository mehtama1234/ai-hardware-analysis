# TurboFNO: High-Performance Fourier Neural Operator with Fused FFT-GEMM-iFFT on GPU

**Venue:** SC
**ID:** sc-2025-399
**Confidence:** low

## Problem
Fourier Neural Operators execute FFT, filtering, GEMM, and iFFT as separate stages, incurring multiple kernel launches and high memory traffic; lacks architecture-aware optimization.

## Motivation
FNO is widely used for PDE solvers but performance is sub-optimal; fusing kernels can reduce memory overhead and improve throughput.

## Method
Normally, Fourier Neural Operators split computation into four separate GPU operations (FFT, filtering, matrix multiplication, and inverse-FFT), with each launch moving data between fast and slow memory. TurboFNO fuses all four into a single continuous kernel that keeps data in fast GPU memory throughout. The implementation uses custom-written FFT and matrix multiplication code, strategically arranges data in memory (called "memory swizzling") to avoid slowdowns, and removes unnecessary zero-padding during computation.

## Key Novelty
This is the first implementation to fully fuse the three core operations (FFT, matrix multiplication, inverse-FFT) into a single GPU kernel, achieving 100% utilization of the GPU's shared memory and matching or exceeding NVIDIA's hand-optimized libraries cuBLAS and cuFFT.

## Contributions
1. Custom FFT kernel competitive with cuFFT with built-in optimizations
2. Custom GEMM kernel competitive with cuBLAS
3. Fused FFT-GEMM-iFFT kernel with 100% memory bank utilization
4. Up to 150% speedup vs. PyTorch, cuBLAS, cuFFT on A100
