# TurboFNO: High-Performance Fourier Neural Operator with Fused FFT-GEMM-iFFT on GPU

**Venue:** SC
**ID:** sc-2025-399
**Confidence:** low

## Problem
Fourier Neural Operators execute FFT, filtering, GEMM, and iFFT as separate stages, incurring multiple kernel launches and high memory traffic; lacks architecture-aware optimization.

## Motivation
FNO is widely used for PDE solvers but performance is sub-optimal; fusing kernels can reduce memory overhead and improve throughput.

## Method
Custom FFT and GEMM kernels from scratch; fused FFT-GEMM-iFFT with shared memory swizzling and zero-padding/pruning built-in.

## Key Novelty
First fully fused FFT-GEMM-iFFT kernel; matches/exceeds closed-source cuBLAS and cuFFT; 100% shared memory bank utilization.

## Contributions
1. Custom FFT kernel competitive with cuFFT with built-in optimizations
2. Custom GEMM kernel competitive with cuBLAS
3. Fused FFT-GEMM-iFFT kernel with 100% memory bank utilization
4. Up to 150% speedup vs. PyTorch, cuBLAS, cuFFT on A100

## Hardware Targets
- NVIDIA A100 GPU

## Technique Categories
- GPU Kernel Fusion, FFT Optimization, Memory Hierarchy Optimization

## Workloads
- Fourier Neural Operators for PDE solving

## Metrics
- **speedup**: 150% vs. PyTorch/cuBLAS/cuFFT

## Baselines
- PyTorch native FNO, cuBLAS, cuFFT

## Limitations
A100-specific; large engineering effort; may not generalize to other GPU architectures; narrow workload (FNO only).
