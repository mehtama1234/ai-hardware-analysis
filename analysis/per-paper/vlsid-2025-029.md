# TimeFloats: Train-in-Memory with Time-Domain Floating-Point Scalar Products

**Venue:** VLSID

## Problem
Compute-in-memory (CIM) lacks floating-point training capability; conventional ADC/DAC costly in advanced nodes

## Motivation
DNN training in memory attractive for efficiency; floating-point precision needed; ADC/DAC power/complexity limiting

## Method
TimeFloats performs floating-point arithmetic directly within memory, where data is stored, bypassing expensive analog-to-digital converters that translate continuous signals to numbers. It represents floating-point values using timing—the duration of electrical pulses—instead of voltage levels. The system uses purely digital logic, built using 15nm CMOS technology (a modern chip manufacturing process), to compute scalar products (multiplying pairs of numbers and summing them up).

## Key Novelty
The core innovation is encoding floating-point numbers through pulse timing rather than voltage level representation, enabling compute-in-memory training without requiring expensive analog-to-digital converters and achieving 22.1 TOPS/W.
