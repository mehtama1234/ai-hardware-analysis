# FlexTEE: Dynamically Enhancing Metadata Locality Through Affine Address Transformation for Heterogeneous & Secure AI Platforms

**Venue:** ICCAD  
**ID:** iccad-2025-181

## Problem
DNN accelerators in heterogeneous secure AI platforms suffer from poor metadata locality when managing Merkle tree integrity structures, causing performance bottlenecks and security vulnerabilities.

## Motivation
Secure AI accelerators require efficient metadata management without sacrificing security guarantees; improving metadata locality reduces memory bandwidth and latency while maintaining cryptographic integrity.

## Method
Apply affine address transformations to dynamically optimize Merkle tree metadata layout in accelerator memory hierarchies. Adaptively reorganize tree structures to improve cache/scratchpad locality based on runtime access patterns in heterogeneous CPU-GPU systems.

## Key Novelty
Dynamic metadata locality optimization via affine address transformation for Merkle tree integrity in secure heterogeneous AI accelerators.

## Contributions
1. Affine address transformation methodology for metadata locality enhancement
2. Adaptive Merkle tree layout optimization for heterogeneous AI platforms
3. Integration with secure enclave memory management
4. Demonstrated performance improvements in CPU-GPU heterogeneous systems
