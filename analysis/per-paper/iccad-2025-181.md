# FlexTEE: Dynamically Enhancing Metadata Locality Through Affine Address Transformation for Heterogeneous & Secure AI Platforms

**Venue:** ICCAD  
**ID:** iccad-2025-181

## Problem
DNN accelerators in heterogeneous secure AI platforms suffer from poor metadata locality when managing Merkle tree integrity structures, causing performance bottlenecks and security vulnerabilities.

## Motivation
Secure AI accelerators require efficient metadata management without sacrificing security guarantees; improving metadata locality reduces memory bandwidth and latency while maintaining cryptographic integrity.

## Method
Merkle trees (tree structures that verify data integrity by detecting any changes) used in DNN accelerators suffer from poor memory locality because fixed storage layouts force distant branches that are accessed together to be far apart in memory. The system uses affine address transformations (mathematical formulas that remap where data sits in memory) to dynamically reorganize the tree layout, keeping frequently-accessed branches closer together in cache and scratchpad storage. By monitoring actual access patterns at runtime in heterogeneous systems with both CPUs and GPUs, it continuously adapts the tree organization to reduce memory latency.

## Key Novelty
Dynamic affine address transformation of Merkle tree layout based on runtime access patterns in heterogeneous DNN accelerators.

## Contributions
1. Affine address transformation methodology for metadata locality enhancement
2. Adaptive Merkle tree layout optimization for heterogeneous AI platforms
3. Integration with secure enclave memory management
4. Demonstrated performance improvements in CPU-GPU heterogeneous systems
