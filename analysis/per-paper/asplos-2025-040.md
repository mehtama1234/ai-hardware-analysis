# ARC: Warp-level Adaptive Atomic Reduction in GPUs to Accelerate Differentiable Rendering

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-040  
**Confidence:** low (abstract only)

## Problem
During the backward pass of rasterization-based differentiable rendering (e.g., 3D Gaussian Splatting), gradient computation requires a large volume of atomic add operations that overwhelm the atomic units in the GPU L2 cache, causing long stalls that dominate training time.

## Motivation
3D Gaussian Splatting training is critical for novel-view synthesis but backward-pass atomic contention blocks interactive use on modern GPU hardware.

## Method
ARC introduces warp-level adaptive atomic reduction: intra-warp threads targeting the same memory address are reduced using warp-level shuffle instructions before issuing a single atomic to the L2 cache. An adaptive gate detects contention and bypasses the mechanism when atomics are already sparse, avoiding overhead.

## Key Novelty
Warp-level coalescing of atomic reductions before they reach the L2 cache, adaptively gated by contention detection, targeting the gradient accumulation bottleneck in differentiable rendering.

## Contributions
- Characterization of atomic contention as the dominant bottleneck in 3D Gaussian Splatting backward pass.
- ARC: a warp-level adaptive atomic reduction mechanism coalescing intra-warp atomics before L2.
- Significant training speedup for differentiable rendering without quality loss.
