# ARC: Warp-level Adaptive Atomic Reduction in GPUs to Accelerate Differentiable Rendering

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-040  
**Confidence:** low (abstract only)

## Problem
During the backward pass of rasterization-based differentiable rendering (e.g., 3D Gaussian Splatting), gradient computation requires a large volume of atomic add operations that overwhelm the atomic units in the GPU L2 cache, causing long stalls that dominate training time.

## Motivation
3D Gaussian Splatting training is critical for novel-view synthesis but backward-pass atomic contention blocks interactive use on modern GPU hardware.

## Method
In 3D rendering models that compute gradients for learning, many GPU threads simultaneously try to add their values to the same shared locations, creating contention (competition for the same resource). These requests pile up at the atomic units in the GPU's L2 cache (the hardware coordinating simultaneous updates), creating stalls that slow training. ARC intercepts these requests at the warp level—a group of 32 threads that communicate quickly with each other—before they reach that bottleneck. Threads updating the same memory location first combine their updates into one using fast warp communication, then send that single combined update instead of many separate ones, with automatic detection to apply this combining only when contention is detected.

## Key Novelty
ARC combines atomic operations at the warp level before they reach the GPU's bottleneck, with automatic detection to enable this combining only when many operations are trying to happen simultaneously.

## Contributions
- Characterization of atomic contention as the dominant bottleneck in 3D Gaussian Splatting backward pass.
- ARC: a warp-level adaptive atomic reduction mechanism coalescing intra-warp atomics before L2.
- Significant training speedup for differentiable rendering without quality loss.
