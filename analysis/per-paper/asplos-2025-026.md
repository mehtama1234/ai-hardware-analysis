# asplos-2025-026 — OctoCache: Caching Voxels for Accelerating 3D Occupancy Mapping in Autonomous Systems

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
OctoMap, a widely used octree-based 3D mapping framework for autonomous robots, suffers from slow update performance due to costly and irregular memory accesses into the octree structure. The lack of cache-friendly access patterns and parallelism limits real-time deployment on autonomous platforms such as UAVs.

## Motivation
3D occupancy mapping is latency-critical for robot navigation and AR/VR; as map resolution and environment complexity grow, the compute and memory bottlenecks of octree traversal become a hard barrier to real-time operation.

## Method
OctoCache is a software-level acceleration system with three techniques: (1) optimized cache memory access patterns that restructure octree node traversal to improve spatial locality, (2) refined voxel ordering that reorders ray-casting updates to maximize cache reuse, and (3) workflow parallelization that concurrently executes independent map-update tasks. No custom hardware is introduced; the system targets general-purpose CPUs.

## Key Novelty
Cache-aware voxel ordering combined with parallelized workflow scheduling to transform the inherently irregular OctoMap access pattern into a cache-friendly, concurrent workload without modifying the octree data structure.

## Contributions
- OctoCache software system with three orthogonal acceleration techniques for OctoMap.
- 45.63–88.01% speedup in 3D environment construction versus baseline OctoMap.
- Up to 3.02x end-to-end speedup and 28% reduction in UAV mission completion time in real navigation scenarios.
