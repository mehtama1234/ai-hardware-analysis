# (Invited) Generalized GPU-Accelerated Dynamic Programming with Application to Mixed-Cell-Height Detailed Placement

**Venue:** ICCAD

## Problem
Dynamic programming algorithms with quadratic or higher time complexities face scalability challenges in large-scale physical design applications like placement.

## Motivation
DP methods are fundamental to many optimization algorithms in physical design but their computational complexity limits practical applicability.

## Method
The approach speeds up dynamic programming problems by using graphics processors (GPUs), which can perform many calculations simultaneously instead of one at a time. It works by breaking the expensive cost calculations into independent pieces that run in parallel across the GPU's cores, then efficiently combines these results back together. This is demonstrated on the practical problem of optimally arranging electronic components of different sizes on a computer chip.

## Key Novelty
The main contribution is a general GPU acceleration framework for any dynamic programming algorithm in chip design.

## Contributions
- Average 96.6% runtime reduction on placement tasks
- Peak speedups exceeding 1600x
- Optimal placement solutions maintained
- General technique applicable to other physical design algorithms
