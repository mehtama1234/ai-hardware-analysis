# SIGMo: High-Throughput Batched Subgraph Isomorphism on GPUs for Molecular Matching

**ID:** sc-2025-057  
**Venue:** SC  
**Confidence:** high

## Problem
Subgraph isomorphism is NP-complete and computationally expensive; state-of-the-art frameworks insufficient for large-scale molecular matching

## Motivation
Drug discovery requires fast molecular matching via subgraph isomorphism; batch processing enables high throughput

## Method
The framework uses SYCL (a programming language for GPUs) to write code that runs on AMD, Intel, and NVIDIA hardware. It narrows down candidate matches through multiple filtering stages using neighborhood signatures—fingerprints encoding the local graph structure around each node—which eliminates most non-matches before expensive computation. Once filtered, it runs a depth-first search on the GPU to find actual matching subgraphs, using parallel processing to explore candidate paths efficiently.

## Key Novelty
It combines multi-level signature-based filtering with GPU-accelerated depth-first search for subgraph matching, all in portable SYCL that works on AMD, Intel, and NVIDIA GPUs.

## Contributions
1. Develops high-throughput batch subgraph isomorphism
2. Introduces neighborhood signature encoding filtering
3. Achieves 7.7B matches/sec on 256-GPU cluster
4. Portable SYCL implementation
