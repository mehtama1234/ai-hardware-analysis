# SAFF: Scalable Acceleration of GNN-based Machine Learning Force Fields using Tensor-Aware Hardware for Molecular Simulation

**Venue:** ICCAD | **ID:** iccad-2025-057

## Problem
GNN-based machine learning force fields for molecular dynamics have high tensor product computational workload. High-dimensional tensors cause memory bottlenecks limiting GPU resource utilization. Current performance inadequate for practical semiconductor process simulations.

## Motivation
Accelerate molecular dynamics simulations to enable practical use in semiconductor process simulation.

## Method
Tensor-based function fusion technique improving data continuity and on-chip reuse reducing off-chip memory accesses. Restructured computation flow removing redundant operations enhancing performance. Designed dedicated tensor product hardware architecture optimized for GNN-based MLFF computations.

## Key Novelty
Tensor-aware hardware architecture specialized for GNN-based MLFF tensor operations.

## Contributions
- Tensor-based function fusion increasing data continuity and on-chip reuse
- Dedicated tensor product hardware architecture for GNN-based MLFF
- Computation flow restructuring eliminating redundant operations

## Limitations
