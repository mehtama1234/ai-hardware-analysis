# Me-MPK: Accelerating Krylov Subspace Solvers via Memory-efficient Matrix-Power Kernel

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Matrix-Power Kernels in Krylov solvers require repeated SpMVs with same matrix, causing data dependency conflicts that block cache reuse and parallelization on multi-core CPUs.

## Core Method
Unified dependency graph capturing cache reuse and symmetry conflicts; architecture-aware recursive partitioning creating independent subgraphs; ordered parallel execution maximizing cache reuse while eliminating synchronization.

## Key Contribution
Unified dependency-driven partitioning enabling simultaneous exploitation of matrix reuse and symmetry, eliminating conflicts.

## Results
- 2.0× speedup on MPK (X86), 1.86× (ARM)
- 1.65× overall solver speedup (X86), 1.58× (ARM)
