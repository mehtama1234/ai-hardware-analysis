# Logic Optimization Meets SAT: A Novel Framework for Circuit-SAT Solving

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Circuit Satisfiability (CSAT) is critical for IC verification but CNF-optimized solvers lose circuit structure information, creating unnecessary inefficiency in design closure.

## Core Method
Preprocessing framework integrating logic synthesis + reinforcement learning. Cost-customized Look-Up Table (LUT) mapping transforms circuits into SAT-solver-friendly forms. RL agent adapts mapping strategy per instance, learning which transformations yield fastest solutions.

## Key Contribution
RL-driven cost-customized LUT mapping preprocessing CSAT into efficient SAT formulations.

## Results
- 63% runtime reduction on industrial-scale CSAT benchmarks
- Seamless integration with SOTA SAT solvers
