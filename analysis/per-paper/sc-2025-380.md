# STZ: A High Quality and High Speed Streaming Lossy Compression Framework for Scientific Data

**Venue:** SC
**ID:** sc-2025-380
**Confidence:** low

## Problem

Error-bounded lossy compression degrades compression quality and speed when supporting both progressive and random-access decompression.

## Motivation

Scientific data volume reduction requires compression framework supporting both progressive and random-access decompression without sacrificing quality or speed.

## Method

The STZ framework divides scientific data into hierarchical levels of partitions, and at each level uses prediction to reduce storage by forecasting what data comes next. This enables progressive decompression—reading from start to finish—and random-access decompression—jumping to any chunk without reading everything. The hierarchical structure allows both access modes to work efficiently from the same compressed data.

## Key Novelty

This is the first compression framework that simultaneously supports both progressive decompression (streaming from start to finish) and random-access decompression (jumping to any chunk), using hierarchical partitioning to overcome the quality and speed degradation that normally occurs when supporting both modes.

## Contributions

1. First framework enabling both progressive and random-access decompression
2. Hierarchical partitioning strategy
3. Hierarchical prediction mechanism
4. 6.7x faster than SZ3 with comparable quality
