# G-Contour: GPU Accelerated Contour Tracing For Large-Scale Layouts

**ID:** iccad-2025-246

## Problem
Contour tracing for VLSI layout processing and lithography simulation is computationally expensive on CPUs. Large layouts require significant processing time.

## Motivation
Accelerating contour tracing speeds up physical design and lithography simulation workflows, reducing design turnaround time.

## Method
Contour tracing identifies the edges of shapes in VLSI chip layouts (patterns in semiconductor designs). The algorithm runs on a GPU (graphics processor with thousands of cores) instead of a CPU (traditional single processor), splitting the work so each GPU core traces contours in a different layout region simultaneously. Results combine to form the complete edge map. This parallelization achieves 90× speedup versus CPU processing.

## Key Novelty
The core idea is moving contour tracing to GPUs so thousands of cores can process different layout regions in parallel instead of one processor doing it sequentially.
