# CoP&R: Co-Optimizing Place-and-Route for Standard Cell Layout via MCTS and AllSAT

**Venue:** ICCAD  
**ID:** iccad-2025-192

## Problem
Standard cell placement and routing are typically solved sequentially; coupled optimization is NP-hard and requires sophisticated algorithms to avoid local optima.

## Motivation
Co-optimized placement and routing reduces total area, wirelength, and critical path; joint optimization with advanced search methods (MCTS, SAT) provides better global solutions.

## Method
Use Monte Carlo Tree Search (MCTS) to explore placement configurations while predicting routing feasibility via incremental SAT solvers (AllSAT). Iteratively refine place-route decisions with feedback from routing analysis.

## Key Novelty
Co-optimization of placement and routing via MCTS-guided search with AllSAT routing feasibility checking.

## Contributions
1. MCTS framework for coupled placement-routing optimization
2. Incremental SAT-based routing feasibility prediction
3. Co-objective optimization (area, wirelength, timing)
4. Demonstrated improvements on standard benchmark circuits
