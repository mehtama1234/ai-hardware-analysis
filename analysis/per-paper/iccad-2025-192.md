# CoP&R: Co-Optimizing Place-and-Route for Standard Cell Layout via MCTS and AllSAT

**Venue:** ICCAD  
**ID:** iccad-2025-192

## Problem
Standard cell placement and routing are typically solved sequentially; coupled optimization is NP-hard and requires sophisticated algorithms to avoid local optima.

## Motivation
Co-optimized placement and routing reduces total area, wirelength, and critical path; joint optimization with advanced search methods (MCTS, SAT) provides better global solutions.

## Method
Rather than placing chip components and routing wires as separate sequential steps, this approach optimizes both together. It uses Monte Carlo Tree Search (a technique that explores many candidate solutions by sampling promising paths and learning which work best) to try different component arrangements. For each arrangement, it predicts whether connections can physically fit using incremental SAT solvers (tools that verify if routing constraints can be satisfied, updated as new constraints arrive). The algorithm then uses routing feasibility results to guide which placements to try next.

## Key Novelty
The key innovation is jointly optimizing chip placement and routing using Monte Carlo search guided by SAT solver feasibility checks, rather than solving these as separate steps.

## Contributions
1. MCTS framework for coupled placement-routing optimization
2. Incremental SAT-based routing feasibility prediction
3. Co-objective optimization (area, wirelength, timing)
4. Demonstrated improvements on standard benchmark circuits
