# ThermoPhoton: Fast 3D Thermal Simulation of Photonic Integrated Circuits via Operator Learning

**Venue:** ICCAD | **ID:** iccad-2025-054

## Problem
Silicon photonic integrated circuits face severe thermal crosstalk at high density. Traditional numerical solvers prohibitively slow for large-scale 3D simulation. Existing ML surrogates lack generalization to distributed heaters and layered PIC structures.

## Motivation
Enable fast, accurate thermal-aware design of next-generation high-density photonic chips.

## Method
The system uses a neural network trained to predict how heat spreads through photonic circuits from heater positions (operator learning). It represents heat sources in a pseudo-3D way that accounts for the circuit's layered structure, and trains using a physics-informed loss function that directly enforces heat-diffusion rules. The network includes attention mechanisms to focus on areas with sharp temperature changes and heat crosstalk effects, and uses zero coordinate shift encoding to make predictions work regardless of circuit position, improving generalization.

## Key Novelty
A neural network combining operator learning with physics-based training and position-independent representations to quickly predict thermal behavior in stacked photonic circuits.

## Contributions
- Pseudo-3D source representation exploiting device stratification
- Zero coordinate shift encoding for improved physics-informed loss
- Attention-based operator learning capturing thermal gradients and crosstalk
