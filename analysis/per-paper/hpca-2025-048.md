# LSQCA: Resource-Efficient Load/Store Architecture for Limited-Scale Fault-Tolerant Quantum Computing

**Venue:** HPCA 2025  
**Authors:** Takumi Kobori, Yasunari Suzuki, Yosuke Ueno, Teruo Tanimoto, Synge Todo, Yuuki Tokunaga

## Problem
Current FTQC floorplan strategies devote 50% of qubit memory space to routing infrastructure required for unit-time random access to all logical qubits, leaving only half the qubit count for data storage when qubits are scarce.

## Motivation
The primary obstacle to practical quantum computing is limited qubit count; existing FTQC architectures waste half of available qubits on access infrastructure rather than computation, directly halving the effective problem size addressable.

## Method
LSQCA (Load/Store Quantum Computer Architecture) separates quantum memory into Computational Registers (CR), small regions that are very fast to access, and Scan-Access Memory (SAM), much larger regions that are slower with variable access times. The system defines an instruction set for these regions, with two concrete implementations called point-SAM and line-SAM architectures. To hide SAM's access delays without slowing down computation, the design overlaps memory operations with other computation and reorders accesses based on which qubits the program tends to use near each other, identified through static analysis of when each qubit is referenced.

## Key Novelty
LSQCA achieves nearly double the quantum memory density (from 50% to 100%) by splitting memory into fast Computational Registers and slower Scan-Access Memory, then hiding access delays through instruction scheduling guided by static analysis of memory access patterns.

## Contributions
- LSQCA floorplan with CR and SAM regions achieving nearly 100% memory density
- Point-SAM and line-SAM concrete architecture designs
- Instruction set and optimization techniques exploiting access locality in memory reference timestamps
- ~90% memory density with only 5% execution time overhead vs 50%-density conventional floorplans

## Results
- **Memory density:** ~90% vs ~50% for conventional unit-time-access FTQC floorplans
- **Execution overhead:** ~5% increase in execution time

## Hardware Target
ASIC (FTQC quantum computer substrate)

## Baselines
Conventional FTQC floorplan with unit-time random access achieving 50% memory density

## Limitations
Results are numerical simulations of abstract qubit architectures; physical qubit connectivity and gate error rate constraints may affect real performance.

**Confidence:** low (abstract-only)
