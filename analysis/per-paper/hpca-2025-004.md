# Efficient Memory Side-Channel Protection for Embedding Generation in Machine Learning
**Venue:** HPCA 2025 | **ID:** hpca-2025-004 | **Confidence:** low (abstract only)

## Problem
Embedding table lookups in ML models (DLRMs, LLMs) leak sensitive input features through memory access patterns, making them vulnerable to side-channel attacks; protecting these accesses with conventional ORAM incurs prohibitive overhead due to the massive size of embedding tables.

## Motivation
Privacy-preserving ML inference requires hiding memory access patterns to embedding tables, but embedding tables can be hundreds of gigabytes, making ORAM's O(log N) overhead per access impractical.

## Method
Three protection strategies are compared: (1) linear scan; (2) ORAM; and (3) Deep Hash Embedding (DHE), which replaces the table lookup with a hash-based neural network computation on the embedding index, eliminating the memory access pattern entirely through compute. A hybrid DHE+linear-scan scheme selects per-table based on profiled break-even points.

## Key Novelty
Using DHE to replace embedding table memory accesses with computation, eliminating the side-channel rather than obfuscating it, yielding 4x speedup over optimized ORAM with up to 1116x memory footprint reduction.

## Contributions
1. Systematic comparison of linear scan, ORAM, and DHE for embedding side-channel protection
2. Demonstration that DHE eliminates memory access patterns and reduces memory footprint by up to 1116x
3. Hybrid DHE+linear-scan scheme: 4x speedup over ORAM (DLRM), 3.08x end-to-end speedup
4. Extension to LLMs: 1.32x prefill and 1.07x decoding speedup over ORAM for GPT-2

## Metrics
- **Speedup:** 4x large DLRM tables vs ORAM; 3.08x end-to-end vs optimized ORAM; 1.32x GPT-2 prefill, 1.07x decoding
- **Memory:** up to 1116x footprint reduction
