# Interconnect Optimization for Timing and Power [IOTAP]

**VLSID 2025** | vlsid-2025-076

## Abstract
Complex SOC CAD tools leave sub-optimality in routed interconnect. IOTAP detects and corrects under-optimized signal nets via multi-variate cost analysis, alternate track assignment, and incremental re-routing. Testing on 15+ designs across 3 tech nodes shows 4-10% timing and 0.53% power gains with 60%+ success rate.

## Problem
- Standard CAD multi-objective optimization (timing, power, area) leaves residual sub-optimality
- Tool-dependent limitations and heuristic design space exploration miss optimizations
- Manual post-implementation tuning impractical at scale

## Key Insight
Systematic sub-optimality characterization of routed interconnect enables automated detection and correction via guided re-routing, independent of original tool.

## Approach
1. Multi-variate cost function analysis of signal interconnect
2. Automated identification of sub-optimal nets
3. Best-fit track assignment guidance
4. Incremental, scalable re-routing flow

## Results
- **Timing**: 4-10% improvement
- **Power**: 0.53% reduction
- **Success rate**: 60%+ trials positive
- **Validation**: 15+ designs, 3 technology nodes

## Contributions
- Automated sub-optimality detection framework
- Guided re-routing algorithm
- Scalable post-synthesis optimization
