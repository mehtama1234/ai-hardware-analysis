# mlsys-2025-025 — TurboAttention: Efficient Attention Approximation for High Throughput LLMs

**Venue:** MLSYS 2025

**One-line problem:** Eliminate FP32/FP16 bottlenecks in attention by enabling fully quantized execution (MatMul + softmax) on GPU Tensor Cores.

## Method
TurboAttention shrinks memory and computation by using smaller numbers instead of full-precision floats. FlashQ quantizes the query/key/value matrices to 8-bit integers for matrix multiplication, then compresses the key/value cache down to 2-4 bits—assigning 2-bit precision to the least important attention heads and 4-bit to the rest based on variability metrics—compressing every 64 steps. SAS (Sparse Activated Softmax) approximates the expensive exponential calculation using a lookup table for the integer part and a degree-3 polynomial for the decimal part. This runs on Tensor Cores in half-precision and treats near-zero attention scores as exactly zero, so the entire attention operation can stay in 8-bit integers and half-precision.

## Key Novelty
TurboAttention is the first to combine FlashAttention's efficient tiling method with low-precision quantization, letting both the matrix multiplication and softmax of attention run entirely on GPU Tensor Cores in 8-bit and half-precision, avoiding slow full-precision computation.

## Metrics
- Up to 1.8x prefill speedup, 1.7x decode speedup vs FlashAttention FP16 (A100)
- Up to 2.37x maximum throughput
- KV cache reduced >4.4x; supports 32k context where FP16 OOMs at 4k
- Near-lossless accuracy: 60.27% vs 61.89% baseline on reasoning tasks
