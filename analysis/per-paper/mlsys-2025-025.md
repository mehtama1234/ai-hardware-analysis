# mlsys-2025-025 — TurboAttention: Efficient Attention Approximation for High Throughput LLMs

**Venue:** MLSYS 2025

**One-line problem:** Eliminate FP32/FP16 bottlenecks in attention by enabling fully quantized execution (MatMul + softmax) on GPU Tensor Cores.

## Method
TurboAttention combines FlashQ and SAS. FlashQ applies blockwise progressive quantization (BPQ) to Q/K/V — INT8 symmetric for MatMul compatibility with FlashAttention tiling, then channel-wise INT4/INT2 for KV cache storage. Headwise mixed precision uses a gap×std priority metric to assign 2-bit quantization to lowest-priority heads. An enhanced KV buffer batches progressive compression every 64 steps. SAS (Sparse Activated Softmax) replaces FP32 exponentiation with a LUT (integer part) + degree-3 polynomial (decimal part) running on Tensor Cores in FP16, with sparsification of near-zero scores. Implemented in Triton with fused QKV projection+quantization kernels.

## Key Novelty
First approach bridging FlashAttention's tiled dataflow with quantization, enabling fully INT8 MatMul + Tensor Core softmax without any FP32 CUDA core operations in attention.

## Metrics
- Up to 1.8x prefill speedup, 1.7x decode speedup vs FlashAttention FP16 (A100)
- Up to 2.37x maximum throughput
- KV cache reduced >4.4x; supports 32k context where FP16 OOMs at 4k
- Near-lossless accuracy: 60.27% vs 61.89% baseline on reasoning tasks
