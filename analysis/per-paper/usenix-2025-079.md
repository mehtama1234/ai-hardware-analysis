# Roaming Free in the VR World with MP2

**Problem:** VR users face latency and coordination constraints when roaming freely across large virtual environments. MP2 addresses the technical challenge of enabling seamless, low-latency user movement in distributed VR systems.

**Method:** MP2 tracks the user's movements in real-time and predicts where they will be a moment later, sending this prediction across the network to all the servers managing different parts of the VR world. Because network signals and rendering both take time, sending a prediction ahead compensates for this delay and keeps the lag low. The system also synchronizes all the distributed computers to render at the exact same moment through an optimized network protocol, so the user sees seamless motion without seeing inconsistencies between what different systems are displaying.

**Novelty:** MP2 enables unconstrained roaming in distributed VR by predicting user motion ahead of time and synchronizing rendering across multiple networked computers.
