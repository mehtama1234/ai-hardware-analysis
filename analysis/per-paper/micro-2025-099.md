# MUSS-TI: Multi-level Shuttle Scheduling for Large-Scale Entanglement Module Linked Trapped-Ion

**Venue:** MICRO  
**Confidence:** high (full-text analysis)

## Problem
Compiling quantum circuits for Entanglement Module Linked Quantum Charge-Coupled Device (EML-QCCD) trapped-ion architectures is inefficient because existing compilers do not account for the distinct functional zones (storage, operation, optical/entanglement) within each QCCD module, leading to excessive ion shuttle operations and reduced circuit fidelity. Cross-module nonlocal gates via photonic fiber links further complicate qubit routing.

## Motivation
Trapped-ion quantum computers scale via modular EML-QCCD architectures using photonic interconnects, but without zone-aware shuttle scheduling, qubit movement overhead grows super-linearly with circuit size, making large-scale quantum algorithms impractical.

## Method
The system represents the quantum circuit as a dependency graph and uses a memory-management strategy to schedule qubit operations: storage zones act like slow disk, operation zones like fast memory, and optical zones like the CPU. It prioritizes gates that are immediately ready to execute, assigns each qubit to the nearest available zone, and when zones fill up, evicts the least-recently-used qubit to a lower zone—the same page-replacement strategy classical computers use. To reduce qubit movements across hardware modules, it looks eight circuit layers ahead and strategically inserts SWAP operations (which exchange two qubits' positions) to move qubits closer together. A bidirectional initial placement algorithm inspired by the standard SABRE method further reduces shuffling overhead.

## Key Novelty
It adapts classical computer cache management (specifically LRU replacement, which keeps frequently-used data fast and evicts rarely-used data to slower storage) to trapped-ion quantum systems by treating the three functional zones as a multi-level memory hierarchy.

## Contributions
- Multi-level shuttle scheduling framework (MUSS-TI) that maps EML-QCCD zones to memory hierarchy levels for efficient qubit routing
- Zone-aware SWAP insertion algorithm using an 8-layer look-ahead weight table to reduce inter-QCCD shuttle operations
- SABRE-based bidirectional initial qubit mapping adapted for EML-QCCD enhanced connectivity
- Shuttle reduction of 41.74% (30-32 qubits), 73.38% (117-128 qubits), and 59.82% (256-299 qubits) vs. prior QCCD compilers, with 58.9% shorter execution time on small-scale benchmarks

## Limitations
The evaluation uses simulation with a fidelity model rather than real hardware; the approach is specific to EML-QCCD and does not generalize to other modular quantum architectures such as superconducting or photonic chips.
