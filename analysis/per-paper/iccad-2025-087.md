# TOGGLE: Temporal Logic-Guided Large Language Model Compression for Edge

**Venue:** ICCAD  
**ID:** iccad-2025-087

## Problem
Existing LLM compression techniques like quantization and pruning often degrade critical linguistic properties and lack formal guarantees for preserving model behavior during compression, limiting reliable deployment on edge devices.

## Motivation
Deploying LLMs on resource-constrained edge devices requires compression techniques that preserve linguistic correctness and behavior, not just numerical accuracy.

## Method
TOGGLE uses Signal Temporal Logic—a mathematical notation for formally specifying language properties—to define what linguistic behaviors must survive compression. It searches through layer-wise configurations for making the model smaller, including quantization (reducing weight precision) and pruning (removing unimportant connections), using Bayesian optimization (a guided search method favoring configurations that satisfy the constraints). The result is a compressed model mathematically proven to preserve the specified linguistic properties without retraining.

## Key Novelty
First to add formal verification (Signal Temporal Logic—a mathematical method for specifying and checking what systems do) to large language model compression, mathematically proving that compressed models preserve specified language properties.

## Contributions
- STL-based formal specification framework for linguistic properties in LLM compression
- Robustness-guided Bayesian optimization for exploring compression configurations
- Compression without retraining or fine-tuning while satisfying formal constraints
- Up to 3.3× FLOPs reduction and 68.8% model size reduction on GPT-2, DeepSeek-V2, LLaMA 3, Mistral
