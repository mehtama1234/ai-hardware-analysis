# PATHE: A Privacy-Preserving Database Pattern Search Platform with Homomorphic Encryption

**Venue:** ICCAD  
**ID:** iccad-2025-222  
**Confidence:** low

## Problem Statement
Database pattern search requires sensitive data handling, raising privacy concerns in centralized query systems.

## Motivation
Homomorphic encryption enables privacy-preserving database operations without exposing query data to the database server.

## Method
The system searches encrypted databases for patterns without decrypting them, using Fully Homomorphic Encryption (computation directly on encrypted data) combined with Hyperdimensional Computing (representing patterns as high-dimensional vectors for efficient matching). To make this practical, they built a hardware accelerator connected via CXL (a high-speed standard for connecting processors to accelerators) that performs both the encryption and pattern-matching calculations. They demonstrated it on protein spectra databases.

## Key Novelty
They created a hardware accelerator combining Fully Homomorphic Encryption (computation on encrypted data) and Hyperdimensional Computing (high-dimensional pattern matching) for private database searches.

## Contributions

1. FHE+HDC combined approach for encrypted search
2. CXL-based hardware accelerator
3. 2.1x speedup on protein spectra database
4. Privacy-preserving pattern search platform
