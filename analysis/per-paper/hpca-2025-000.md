# BitMoD: Bit-serial Mixture-of-Datatype LLM Acceleration
**Venue:** HPCA 2025 | **ID:** hpca-2025-000 | **Confidence:** low (abstract only)

## Problem
LLM deployment is constrained by large weight memory footprints; existing low-precision quantization schemes either sacrifice too much accuracy or lack hardware support for multiple heterogeneous data types simultaneously. Current accelerators cannot efficiently process mixed numerical formats within a single design.

## Motivation
Memory bandwidth and capacity are the primary bottleneck for LLM inference, and sub-4-bit quantization is necessary to fit large models on edge/server hardware without unacceptable accuracy degradation.

## Method
BitMoD is an algorithm-hardware co-design that introduces fine-grained per-group (128-weight) data-type adaptation, selecting from a set of carefully designed numerical types to minimize quantization error per group. On the hardware side, a bit-serial processing element natively handles multiple precisions by decomposing weights into bit-planes; a unified representation maps all data types to a common internal format, and a dedicated bit-serial dequantization unit rescales per-group partial sums with minimal overhead.

## Key Novelty
Fine-grained per-group mixture-of-datatype assignment with a matched bit-serial hardware that processes all types through a unified representation, eliminating the need for separate datapaths per format.

## Contributions
1. Fine-grained data-type adaptation assigning a distinct numerical type to each 128-weight group to preserve accuracy at 3-4 bit precision
2. Bit-serial PE with a unified internal representation supporting heterogeneous weight types without datapath duplication
3. Bit-serial dequantization unit that rescales per-group partial sums with minimal area overhead
4. 1.69x and 1.48x speedup over ANT and OliVe with <0.5% accuracy loss at 4-bit and better perplexity at 3-bit

## Metrics
- **Speedup:** 1.69x over ANT, 1.48x over OliVe
- **Accuracy:** <0.5% loss at 4-bit (discriminative); better perplexity than prior at 3-bit (generative)
