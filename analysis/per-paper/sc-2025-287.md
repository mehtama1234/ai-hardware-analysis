# An MLIR Pipeline for Offloading Fortran to FPGAs via OpenMP

**Venue:** SC 2025  
**Authors:** Gabriel Rodriguez-Canal, David Katz, Nick Brown

## Problem Statement
Fortran-based HPC applications lack practical, portable pathways for offloading computation to FPGAs. Existing OpenMP FPGA compilers require custom infrastructure, limiting adoption and hindering interoperability with the broader HPC compiler ecosystem.

## Technical Approach
**MLIR-Based Compilation Pipeline:**
1. **Frontend:** Flang (LLVM Fortran compiler) parses Fortran source
2. **IR Transformation:** MLIR OpenMP dialect represents OpenMP parallelism
3. **Backend:** HLS (High-Level Synthesis) dialect targets FPGA synthesis
4. **Composition:** Leverages existing MLIR building blocks for portability

**Key Features:**
- OpenMP target directives for selective kernel offloading
- Manual optimization through standard OpenMP pragmas
- Supports any MLIR-compatible frontend (not Fortran-specific)

## Architecture Highlights
- **Portable:** Works with MLIR ecosystem rather than custom compilers
- **Composable:** Reuses existing MLIR dialects and passes
- **Extensible:** Framework for future heterogeneous targets

## Hardware Target
FPGAs (evaluated conceptually; specific FPGA vendor not mentioned)
