# High-throughput Point-Cloud Accelerator with Sparsity-aware Hierarchical Neighbor Voxel Search

**Problem:** Irregular voxel sparsity in 3D sparse convolution networks reduces hardware utilization and throughput.

**Method:** The approach combines algorithm and hardware design to handle sparse point clouds efficiently. The algorithm skips empty voxels (tiny 3D boxes that partition the point cloud) based on a threshold. The hardware uses a 3-stage hierarchical search engine that progressively narrows which voxels contain data, adapting to the irregular sparsity patterns of each point cloud. This eliminates wasted computation by processing only the voxels with actual data.

**Key Result:** 77.7% delay reduction vs baseline; 1.34x energy efficiency, 2.22x throughput vs SOTA (65nm).

**Hardware Target:** ASIC, GPU  
**Workloads:** vision, GNN, graph-analytics
