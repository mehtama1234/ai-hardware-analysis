# HachiFI: A Lightweight SoC Architecture-Independent Fault-Injection Framework for SEU Impact Evaluation

**Venue**: DATE  
**Primary Theme**: SEU reliability evaluation framework  

## Problem
Evaluating reliability of electronic devices under Single-Event Upsets (SEUs) triggered by energetic particles in safety-critical applications. Traditional irradiation experiments are costly; prior fault injection lacks full coverage and accuracy.

## Method
The framework automatically injects faults (simulated particle impacts) throughout a system by accessing memory and scan chains—built-in testing pathways—to cover 100% of potential failure points. It simulates particle-induced bit flips based on measured cross-sections, the probability of impact at different particle energies, and supports both system-wide and component-level testing. The approach works across any processor architecture and adds only about 2% computational overhead.

## Key Novelty
Complete fault injection coverage (100% of all possible bit flips) is achieved through direct hardware access with minimal performance overhead (<2%) while matching real particle irradiation with 98.4% correlation.

## Contributions
- 100% coverage fault injection framework independent of SoC architecture
- Sub-2% hardware overhead for complete SEU simulation
- Validated on 22nm edge-AI chip showing 0.984 R² match to irradiation
