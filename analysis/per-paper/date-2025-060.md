# HachiFI: A Lightweight SoC Architecture-Independent Fault-Injection Framework for SEU Impact Evaluation

**Venue**: DATE  
**Primary Theme**: SEU reliability evaluation framework  

## Problem
Evaluating reliability of electronic devices under Single-Event Upsets (SEUs) triggered by energetic particles in safety-critical applications. Traditional irradiation experiments are costly; prior fault injection lacks full coverage and accuracy.

## Method
Lightweight architecture-independent framework automating fault injection with 100% coverage via memory and scan-chain accesses. Simulates SEU behavior based on specific cross-sections with configurable patterns for system/module-level analysis.

## Key Novelty
100% fault injection coverage via hardware access mechanisms with only <2% overhead and high correlation (R²=0.984) to irradiation experiments.

## Contributions
- 100% coverage fault injection framework independent of SoC architecture
- Sub-2% hardware overhead for complete SEU simulation
- Validated on 22nm edge-AI chip showing 0.984 R² match to irradiation
