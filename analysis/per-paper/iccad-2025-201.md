# VeriOpt: PPA-Aware High-Quality Verilog Generation via Multi-Role LLMs

**Venue:** ICCAD  
**ID:** iccad-2025-201

## Problem
LLM-generated Verilog prioritizes functional correctness while ignoring Power-Performance-Area (PPA) metrics critical for industrial designs.

## Motivation


## Method
Role-based multi-LLM framework with specialized roles (Planner, Programmer, Reviewer, Evaluator) integrated with PPA-aware prompting and multi-modal feedback from synthesis reports.

## Key Novelty
First PPA-aware LLM framework using role-based prompting and synthesis feedback for high-quality RTL generation.

## Contributions
- Role-based multi-agent prompting emulating human design workflows
- PPA-aware constraints in prompting pipeline
- Multi-modal feedback integration from synthesis tools
- 88% power, 76% area, 73% timing improvement over baseline LLM
