# VeriOpt: PPA-Aware High-Quality Verilog Generation via Multi-Role LLMs

**Venue:** ICCAD  
**ID:** iccad-2025-201

## Problem
LLM-generated Verilog prioritizes functional correctness while ignoring Power-Performance-Area (PPA) metrics critical for industrial designs.

## Motivation


## Method
The system coordinates four specialized AI models—a Planner, Programmer, Reviewer, and Evaluator—that collaborate to write hardware descriptions (Verilog code). Each model receives prompts that explicitly ask it to minimize Power, Performance, and Area (PPA) costs—essentially the electricity usage, speed, and physical chip size. The system feeds actual performance data from hardware synthesis reports back into the models, letting them learn how to write code that performs well when manufactured into real hardware.

## Key Novelty
This is the first system to combine multiple AI models with specialized roles, all trained to optimize power-performance-area trade-offs using real hardware performance feedback.

## Contributions
- Role-based multi-agent prompting emulating human design workflows
- PPA-aware constraints in prompting pipeline
- Multi-modal feedback integration from synthesis tools
- 88% power, 76% area, 73% timing improvement over baseline LLM
