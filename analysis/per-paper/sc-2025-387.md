# An Optimized Generalized Multi-Color Point Implicit Solver for Intel GPUs using OneAPI ESIMD

**Venue:** SC
**ID:** sc-2025-387
**Confidence:** low

## Problem

Memory bandwidth-bound linear solvers with variable matrix row lengths and indirect access patterns; inefficient 512-bit vector register utilization on Intel GPUs.

## Motivation

Optimize FUN3D CFD linear solver for Aurora exascale machine (Intel 1550 GPUs) through efficient vectorization and memory access patterns.

## Method

The approach uses ESIMD (Intel's tool for writing code that directly harnesses the GPU's 512-bit wide registers) to restructure the solver into block-sparse vector operations—calculations on chunks of the matrix of varying sizes that skip zeros efficiently. This efficient packing reaches memory speeds within 10% of the theoretical maximum, overcoming the bandwidth bottleneck despite variable row lengths and irregular memory access patterns.

## Key Novelty

Using ESIMD vectorization, Intel GPUs can match NVIDIA GPU performance on unstructured-grid solvers.
