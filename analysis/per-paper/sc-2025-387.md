# An Optimized Generalized Multi-Color Point Implicit Solver for Intel GPUs using OneAPI ESIMD

**Venue:** SC
**ID:** sc-2025-387
**Confidence:** low

## Problem

Memory bandwidth-bound linear solvers with variable matrix row lengths and indirect access patterns; inefficient 512-bit vector register utilization on Intel GPUs.

## Motivation

Optimize FUN3D CFD linear solver for Aurora exascale machine (Intel 1550 GPUs) through efficient vectorization and memory access patterns.

## Method

ESIMD-based optimization using efficient vectorization for block-sparse vector computations; optimized for variable block sizes; performance within 10% of bandwidth benchmark peak.

## Key Novelty

ESIMD vectorization approach for unstructured-grid solvers; demonstrates parity with NVIDIA GPU performance.

## Contributions

1. Efficient ESIMD implementation for block-sparse kernels
2. Vectorized memory load optimization
3. Performance near bandwidth benchmark peak
4. NVIDIA/Intel GPU performance comparison
