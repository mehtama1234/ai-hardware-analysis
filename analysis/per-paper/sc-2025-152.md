# SC-2025-152: HStencil

## Summary
Framework for accelerating stencil computations by jointly leveraging matrix and vector units through interleaved execution, fine-grained instruction scheduling, and spatial prefetch strategies.

## Problem
- Stencil computations underutilize specialized matrix units (MLA/outer-product)
- Limited instruction-level parallelism from sequential kernel structure
- Poor cache hit rates when working sets exceed cache capacity
- Auto-vectorization insufficient for modern CPUs

## Key Contributions
1. **Microkernel Design**: Joint matrix-vector execution patterns
2. **Instruction Scheduling**: Interleaved execution to expose ILP
3. **Cache Strategy**: Spatial prefetch for large working sets

## Performance
- **Speedup**: 1.81x - 5.76x vs auto-vectorization
- **vs SOTA**: 31% - 91% better than prior methods
- Evaluated on representative benchmarks (details in full paper)

## Hardware Targets
- CPUs with matrix units (Intel, ARM)
- Multi-core processors with vector+matrix capabilities

## Novelty
First framework to systematically exploit both matrix and vector execution units for stencils through interleaved computation.

## Workloads
- 2D/3D stencil kernels
- HPC finite-difference applications
- Intelligent computing kernels
