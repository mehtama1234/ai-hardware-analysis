# GauRast: Enhancing GPU Triangle Rasterizers to Accelerate 3D Gaussian Splatting

**Problem:** 3D Gaussian splatting requires high compute; dedicated accelerators are costly; GPU acceleration needed.

**Solution:** Enhance existing GPU rasterizer hardware to support 3DGS primitives and blending by exploiting graphics pipeline similarities.

**Results:** 23x speedup, 24x energy reduction, only 0.2% area overhead (24-46 FPS end-to-end).

**Theme:** Efficient 3D rendering via graphics pipeline reuse.
