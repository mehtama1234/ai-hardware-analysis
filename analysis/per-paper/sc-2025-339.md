# Reproducibility Report: HP-MDR (Data Refactoring with GPUs)

**ID:** sc-2025-339  
**Venue:** SC 2025  
**Author:** Philippe Swartvagher (SC25 Reproducibility Committee)

## Purpose

Artifact evaluation and reproducibility assessment of SC25 paper **"HP-MDR: High-performance and Portable Data Refactoring and Progressive Retrieval with Advanced GPUs"** by Podhorszki et al.

## Scope

This is a **meta-paper** documenting:
- Artifact setup and validation for GPU-accelerated data processing
- Reproducibility of data refactoring and progressive retrieval results
- Evaluation methodology used by SC25 Reproducibility Initiative

## Key Focus Areas

- **Data refactoring:** Transformation of scientific data structures
- **Progressive retrieval:** Staged access to dataset subsets
- **GPU acceleration:** Portability and performance on diverse GPU architectures

## Contribution

Provides independent verification of data refactoring performance and portability results, validating GPU optimization effectiveness.

## Implications

Reproducibility evaluation confirms the practical viability of GPU-accelerated data refactoring for scientific workflows, important for I/O-bound applications.
