# StreamTensor: Make Tensors Stream in Dataflow Accelerators for LLMs

**Venue:** MICRO  
**Confidence:** high (full-text analysis)

## Problem
Dataflow accelerators for LLMs (e.g., AMD Versal, SambaNova SN40L, IBM AIU) require manual effort to wire together kernels via on-chip FIFOs, manage external DMA access patterns, size FIFOs to prevent deadlock, and fuse kernels with compatible stream layouts — problems that compound across inter-kernel, multi-DMA, and large context-length LLM workloads, preventing end-to-end optimization.

## Motivation
The LLM decode phase is heavily memory-bound and benefits from dataflow streaming between kernels, but the current manual programming paradigm does not scale; an automated compiler that handles stream layout, FIFO sizing, and kernel fusion end-to-end would unlock substantial latency and energy efficiency gains on FPGA-class dataflow accelerators.

## Method
StreamTensor is an MLIR-based compiler that represents tensor data flow through kernels using iterative tensor types (itensors), which encode element shape, iteration space, and data-access order—capturing exactly how each kernel reads and writes data. It converts high-level tensor operations into a dataflow graph via Linalg tiling, automatically fuses kernels with matching itensor types directly via FIFOs, and inserts minimal data-format converters (ping-pong buffers) where types mismatch; it then merges adjacent buffers and aligns FIFO bandwidth with kernel parallelism through vectorization. The compiler analytically sizes buffers from itensor patterns and solves a scheduling problem via linear programming to prevent deadlocks while minimizing depth. Finally, it searches across kernel tiling, fusion, and resource-allocation choices using blackbox optimization (Optuna), intensity-aware unrolling, and permutation heuristics.

## Key Novelty
StreamTensor's iterative tensor (itensor) type system captures each kernel's streaming data-access order, enabling a compiler to automatically fuse kernels via FIFOs, generate minimal data converters, and mathematically size buffers to prevent deadlocks on dataflow accelerators.

## Contributions
- First PyTorch-to-device dataflow compiler (StreamTensor) that automatically generates stream-based dataflow accelerators and runtime systems from high-level models
- Iterative tensor (itensor) type system encoding stream layout for automated kernel fusion, buffer sizing, and correctness verification
- Three hierarchical design space exploration algorithms: intensity-aware Linalg tiling, heuristic kernel fusion with memory constraints, and LP-based FIFO sizing
- Up to 0.76x lower latency vs. state-of-the-art FPGA LLM accelerators, 0.64x vs. GPUs, and 1.99x higher energy efficiency vs. GPUs on LLM benchmarks
