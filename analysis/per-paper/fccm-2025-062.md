# RV-ESMC: Efficient Sparse Matrix Convolution Processor based on RISC-V Custom instructions for Edge Platforms

**Problem:** Deploying compute-intensive deep neural networks on resource-constrained edge platforms remains challenging. Efficient sparse convolution acceleration is critical to enable practical DNN inference within strict power and area budgets.

**Method:** The system adds custom instructions to the RISC-V processor vocabulary—the set of operations a CPU understands—optimized specifically for sparse convolution (multiplying matrices where most values are zero, common in neural networks). Programs can call these custom instructions directly from C code using inline assembly (raw processor commands embedded in C), making sparse math operations fast without rewriting entire programs. The researchers prototyped this on an FPGA (programmable hardware) and predicted its power consumption and chip area using a 55nm CMOS process (a standard manufacturing specification that estimates real-world performance).

**Novelty:** The core idea is adding custom processor instructions specifically optimized for sparse convolution—multiplying large matrices where most values are zero—to enable neural networks to run faster on power-limited edge devices.
