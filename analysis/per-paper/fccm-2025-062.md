# RV-ESMC: Efficient Sparse Matrix Convolution Processor based on RISC-V Custom instructions for Edge Platforms

**Problem:** Deploying compute-intensive deep neural networks on resource-constrained edge platforms remains challenging. Efficient sparse convolution acceleration is critical to enable practical DNN inference within strict power and area budgets.

**Method:** RV-ESMC extends the RISC-V ISA with custom instructions optimized for sparse matrix convolution operations. The processor supports inline assembly calls in C to leverage custom instructions. The design is validated on FPGA and evaluated via 55nm CMOS process technology node for power and area characteristics.

**Novelty:** Custom RISC-V instruction extensions specifically designed to accelerate sparse convolution patterns on edge platforms.
