# isca-2025-071 — LightML: A Photonic Accelerator for Efficient General Purpose Machine Learning

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
General-purpose ML workloads demand massive throughput that strains conventional electronic infrastructure. Existing photonic ML proposals lack a complete system-level design — particularly the memory and buffer architecture — needed to fully exploit the photonic crossbar.

## Motivation
Photonic crossbars perform matrix-vector multiplications at the speed of light with near-zero switching energy, but prior proposals left the memory interface and functional-unit support gaps unaddressed, preventing real system deployment.

## Method
LightML is the first complete system-level photonic crossbar architecture for ML. It pairs a photonic crossbar core with a co-designed memory and buffer architecture that sustains >80% crossbar utilization. Dedicated units handle large-scale MMM, element-wise operations, non-linear activations, and convolutional layers. The system delivers 325 TOP/s at 3 W.

## Key Novelty
First system-level photonic crossbar design with a purpose-built memory/buffer architecture enabling sustained high utilization (>80%) across diverse ML operations.

## Contributions
1. First complete system-level photonic crossbar architecture for ML with >80% utilization
2. Memory and buffer architecture co-designed to match photonic crossbar throughput
3. Hardware support for MMM, element-wise ops, non-linear functions, and convolutional layers
4. 325 TOP/s at 3 W — suitable for edge and dense data-center deployments
