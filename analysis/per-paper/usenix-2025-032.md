# SwCC: Software-Programmable and Per-Packet Congestion Control in RDMA Engine

**Problem:** RDMA networks suffer from congestion that degrades throughput and latency, but existing congestion control mechanisms are hardcoded in hardware and lack the flexibility to adapt policies dynamically or apply fine-grained per-packet control decisions. Current approaches operate at flow granularity, limiting optimization potential.

**Method:** SwCC adds a programmable layer inside RDMA engines (specialized network hardware for fast data transfers) that lets you upload custom congestion control algorithms at runtime. These algorithms inspect each packet individually and dynamically decide whether to forward, slow it down, or mark it—rather than making one decision per data flow. The key advantage is that this control logic is separate from the hardware, so you never need to modify the underlying chips.

**Novelty:** SwCC moves programmable congestion control into the RDMA engine itself, making decisions per-packet instead of per-flow, rather than relying on hardcoded hardware rules or host-based software.
