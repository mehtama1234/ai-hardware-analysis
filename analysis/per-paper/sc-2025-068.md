# Scaling Hybrid Quantum-HPC Applications with the Quantum Framework

**ID:** sc-2025-068 | **Venue:** SC

## Problem Statement
Hybrid Q-HPC workflows must select best simulator for each circuit type; no single simulator optimal for all

## Motivation
NISQ devices require flexible execution across diverse simulators; backend selection critical for performance but circuit-dependent

## Method
Extended Quantum Framework (QFw) integrating Qiskit Aer, NWQ-Sim, QTensor, TN-QVM (local) and IonQ (cloud) under unified interface

## Key Novelty
Backend-agnostic orchestration for Q-HPC; demonstrates simulator-specific advantages enabling informed platform selection

## Contributions
- Unified interface for diverse quantum backends
- HPC-aware orchestration layer
- Workload-specific backend performance analysis
- Demonstration of backend-specific advantages
