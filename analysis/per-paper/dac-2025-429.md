# dac-2025-429: Token-Stationary CIM with 3D Memory for LLM Speculative Decoding

**Problem:** LLM decoding bandwidth bottleneck from logic die; 2D memory cannot overcome limited memory-to-logic bandwidth.

**Motivation:** Speculative decoding requires higher bandwidth; vertical stacking enables tight memory-compute coupling.

**Method:** 3D memory stacked on logic die with token-stationary CIM; novel dataflow minimizes intra-die data movement, reducing power and balancing throughput.

**Key Novelty:** Token-stationary CIM dataflow for 3D-stacked speculative decoding.

**Contributions:**
- Token-stationary CIM reducing intra-die data movement
- 3D memory stacking for improved bandwidth
- 15.1x throughput; 324x energy efficiency vs RTX 3090 on Llama2-7B

**Hardware Target:** CIM, PIM, chiplet

**Workloads:** LLM-inference

**Confidence:** low (abstract-only)
