# isscc-2025-212: Dynamic Guard-Band Optimization in IBM zNext

## Quick Summary
IBM zNext system dynamically optimizes voltage guard bands by combining robust error recovery and power-supply droop mitigation, achieving significant power savings with minimal area overhead.

## Problem
Current systems use fixed voltage guard bands at each frequency to cover worst-case variation sources:
- Power-supply droops from sudden workload changes
- Temperature excursions
- Device aging

Fixed margins waste power when worst-case conditions do not occur simultaneously.

## Method
Integrated system using on-chip sensors and firmware that:
1. Monitors real-time system state and variations
2. Applies robust droop mitigation (power delivery management)
3. Applies robust error recovery (correction/timeout mechanisms)
4. Dynamically adjusts voltage margins to minimum safe levels

## Key Novelty
Simultaneous integration of droop mitigation and error recovery for dynamic guard-band reduction.

## Contributions
- Dynamic guard-band optimization system
- Firmware-controlled margin adjustment
- On-chip sensor integration
- Power savings with small area cost

## Hardware Target
CPU (IBM zSeries)

## Technique
Power management, reliability
