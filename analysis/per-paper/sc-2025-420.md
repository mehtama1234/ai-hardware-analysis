# SC-2025-420: InferCT - Efficient 3D Deep Learning for CT Inference

## Summary
InferCT enables efficient 3D deep learning inference on large CT volumes by partitioning into GPU-memory-fit sub-volumes with lock-free synchronization and pipelined execution, achieving 1.97-2.32x speedup.

## Problem
3D deep learning models outperform 2D methods for CT analysis but are impractical at inference due to high memory requirements. Existing approaches lack generalization across dataset sizes and imaging tasks.

## Method
- **Volume partitioning**: Divides CT volumes into cubic sub-volumes that fit GPU memory
- **Multi-GPU distribution**: Distributes sub-volumes across multiple GPUs
- **Lock-free shared memory**: Reduces synchronization overhead
- **Pipelined execution**: Overlaps data prefetching and post-processing with computation
- **Parallel data loader**: Improves I/O efficiency

## Key Results
- 1.97x speedup for 1024³ voxel datasets
- 2.32x speedup for 4096³ voxel datasets
- Reduced energy consumption
- Excellent strong scaling: 89.25% (single-node), 75.75% (multi-node)
