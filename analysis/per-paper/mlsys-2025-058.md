# Youmu: Efficient Columnar Data Pipeline for LLM Training

**Venue:** MLSYS 2025

## One-line Problem
LLM datasets stored in Parquet columnar format cause 100x I/O efficiency drops when used directly for training due to granularity mismatch between columnar chunk I/O (100s MB) and fine-grained random access for shuffling.

## Method
YOUMU uses **page-level (KB-to-MB) direct access** to Parquet data. A **global page index** built at initialization maps random page IDs to physical file/chunk/page locations via layered binary search. The data plane reads compressed pages directly from SSD and decodes them. **Aggressive buffer shuffle** continuously replaces consumed pages with new random pages, providing superior shuffle quality. Implemented in ~500 lines of Rust with PyO3 Python bindings.

## Novelty
First practical system enabling direct fine-grained columnar data access for LLM training, eliminating format conversion while achieving shuffle quality comparable to fully random shuffle.

## Key Metrics
- Memory footprint: **~80% less** than distributed memory solutions (30-47 GB vs 100-150 GB per node)
- Batch latency: **3ms** (page shuffle) — well below GPU waiting threshold
- Perplexity vs streaming: **0.3-0.7 lower** (better accuracy)
- Shuffle degradation: **10.6%** of no-shuffle baseline vs **53.3%** for streaming
