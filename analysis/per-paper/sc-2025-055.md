# Dynamic Factor Graphs for Attack Preemption

**ID:** sc-2025-055  
**Venue:** SC  
**Confidence:** high

## Problem
Supercomputing systems face sophisticated attacks; noisy alerts and unreliable signals mask real attacks leading to data breaches

## Motivation
National-scale HPC systems at NCSA require proactive security to prevent system compromise and data loss

## Method
Live-traffic security testbed using factor-graph-based dynamic models for attack preemption; visualization tools for attack analysis

## Key Novelty
Factor-graph-based detection system deployed in petascale production HPC environment

## Contributions

2. Develops attack visualization tool for operators
3. Successfully detects real ransomware family; improves production Zeek policies
