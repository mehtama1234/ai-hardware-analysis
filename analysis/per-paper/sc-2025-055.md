# Dynamic Factor Graphs for Attack Preemption

**ID:** sc-2025-055  
**Venue:** SC  
**Confidence:** high

## Problem
Supercomputing systems face sophisticated attacks; noisy alerts and unreliable signals mask real attacks leading to data breaches

## Motivation
National-scale HPC systems at NCSA require proactive security to prevent system compromise and data loss

## Method
The system monitors real network traffic on the supercomputer using factor graphs—mathematical models that show how different security signals relate to each other and might indicate an attack. When alerts come in, the system uses these dynamic models to distinguish real attacks from false alarms, letting it identify threats before they cause damage. Visualization tools help security teams understand what attacks are being detected and respond accordingly.

## Key Novelty
The system uses factor graphs to detect attacks in petascale production supercomputers—systems operating at the scale of millions of trillions of calculations per second.
