# Hermes: Algorithm-System Co-design for Efficient Retrieval-Augmented Generation At-Scale

**Venue:** ISCA 2025
**Confidence:** low (abstract-only)

## Problem
As RAG datastores expand into the trillions of tokens, retrieval phase dominates end-to-end latency and energy. Existing RAG systems have no mechanism for efficiently routing queries to relevant subsets of a massive distributed datastore.

## Motivation
RAG avoids expensive LLM retraining by anchoring generation to external knowledge, but trillion-token datastores make retrieval the dominant bottleneck at datacenter scale.

## Method
Hermes partitions the RAG datastore across multiple nodes and applies a hierarchical search strategy. A coarse-grained index tier rapidly identifies high-relevance partitions; only those partitions undergo full dense retrieval (exact k-NN or ANN). This co-design eliminates unnecessary retrieval computation on irrelevant partitions while maintaining recall quality.

## Key Novelty
Hierarchical query routing combined with datastore partitioning that dynamically adapts retrieval effort to query-to-partition relevance.

## Contributions
1. Algorithm-systems co-design framework characterizing large-scale RAG retrieval bottlenecks
2. Hierarchical search strategy with dynamic query routing to relevant datastore subsets
3. Distributed datastore partitioning across nodes for parallel retrieval
4. 9.33x latency and 2.10x energy improvement on open-source RAG benchmarks without quality loss
