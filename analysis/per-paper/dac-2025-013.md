# Fast End-to-End Simulation and Exploration of Many-RISCV-Core Baseband Transceivers for Software-Defined Radio-Access Networks

**Problem:** RTL simulation of many-core SDR processors is prohibitively slow, hindering design-space exploration for 5G baseband processing.

**Method:** The framework runs compiled code directly (rather than simulating each step, which is slow) with a fast but approximate model of how long operations take on 1024 RISC-V cores working together. It connects to wireless channel models to test 5G signal detection functions in realistic conditions. Single-threaded, it simulates each symbol in 9.5 seconds to 3 minutes—about 1000 times faster than traditional RTL simulation—and can split the work across 128 threads for an additional 73–121× speedup.

**Key Contribution:** 3 orders of magnitude speedup over RTL; enables rapid end-to-end performance analysis.

**Results:** Single-threaded: 9.5s-3min per OFDM symbol; 73-121x speedup with 128-thread parallelization.
