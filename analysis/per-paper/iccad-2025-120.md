# Differentiable Timing-Driven FPGA Placement with Smooth Optimization and ML-Based Delay Calibration

**Venue:** ICCAD  
**ID:** iccad-2025-120

## Problem
FPGA placement must simultaneously minimize wirelength and optimize timing metrics (TNS/WNS), but traditional placement algorithms struggle with multi-objective optimization and accurate timing estimation.

## Motivation
Placement is critical for timing closure in FPGA design; faster convergence enables more efficient design iterations.

## Method
The approach uses differentiable optimization (calculus-based search for better placements) with timing preconditioning that smooths out the optimization landscape, making solutions easier to find. It gradually adjusts the balance between wirelength and timing constraints using a multiplier scheduling scheme. To improve timing prediction accuracy, an XGBoost machine learning model learns to predict net delays from data, replacing manual timing estimates with learned predictions.

## Key Novelty
It combines smooth calculus-based optimization with machine-learned delay prediction to better optimize both wirelength and timing in FPGA placement.

## Contributions
- Novel timing preconditioning method that smooths the timing objective landscape
- General multiplier scheduling scheme for multi-objective optimization
- XGBoost-based net delay prediction model for improved timing estimation
