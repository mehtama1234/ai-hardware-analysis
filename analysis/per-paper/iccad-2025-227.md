# Parallel Non-Integer Multiple-Cell-Height Node Remapping

**Paper ID:** iccad-2025-227  
**Venue:** ICCAD

## Problem

Timing-aware node remapping for VLSI circuits with non-integer multiple-cell-height (NIMCH) standard cells suffers from computational overhead due to exhaustive enumeration of all node-to-gate mapping combinations, limiting scalability for large designs.

## Motivation

Growing circuit complexity with NIMCH cells makes rapid timing closure essential for physical design; existing sequential approaches are too slow for large-scale applications.

## Method

The approach uses two parallel schemes (both running on multiple processors or GPUs simultaneously) to speed up node remapping (reassigning circuit nodes to physical gates). The first scheme prioritizes timing-critical nodes by starting with the longest data path, while the second scheme prioritizes paths with the least slack (remaining timing margin before a path becomes too slow). Both schemes greatly reduce the search space by focusing on critical paths rather than exhaustively checking every possible node-to-gate assignment.

## Key Novelty

This is the first parallel node remapping approach for NIMCH circuits (building blocks with non-integer height multiples), achieving 5.58× speedup while preserving placement quality by prioritizing timing-critical paths.

## Contributions

- Parallel longest-path-first scheme enabling concurrent remapping execution
- Iterative minimum-slack-first optimization scheme
- 5.58× average runtime speedup over state-of-the-art while maintaining placement quality
