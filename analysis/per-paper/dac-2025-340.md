# Leopard: Hardware Pass-Through Remote Storage Access with Queue Concurrency for Edge Intelligent Workstations
**Venue:** DAC

## Problem
Edge workstations access remote cloud storage via complex software stacks and limited CPUs, causing 75% performance degradation by failing to saturate NVMe queue concurrency.

## Motivation
Edge AI workloads require high-throughput remote storage access; eliminating CPU-mediated I/O overhead enables near-local-storage performance for cloud-backed systems.

## Method
Leopard uses a programmable chip on a network card (SmartNIC FPGA) that emulates an NVMe storage device. When the operating system sends storage commands, the FPGA intercepts them and processes each using parallel hardware circuits, communicating directly with remote cloud storage. This completely bypasses the CPU and its software stack. The hardware preserves queue concurrency—the ability to run multiple storage requests in parallel—which the software layers had been unable to maintain.

## Key Novelty
A programmable chip on a network card (SmartNIC FPGA) acts as a direct hardware pass-through for NVMe storage requests to remote cloud storage, preserving queue concurrency by eliminating the CPU-based software stack.

## Contributions
1. 1.09-6.04x lower remote storage access latency
2. Direct hardware queue concurrency management via FPGA
3. Eliminates complex remote storage software stacks
