# Edge Vision Transformer Accelerator with Hybrid CIM-RRAM and Decoupled Chunk Attention

**Venue:** DAC | **ID:** dac-2025-189

## Summary
Co-optimized edge ViT accelerator combining algorithm-level decoupled chunk attention (DCA) with hybrid SRAM-CIM and RRAM storage. Features bit/element-reconfigurable CIM macros and fusion scheduling for workload balancing, enabling efficient dense predictions.

## Key Results
- **Speedup:** 18.5×-217.1× on dense predictions (object detection, segmentation, depth)
- **Memory Access:** 1.7×-7.4× reduction
- **Energy Efficiency:** 1.8× improvement with <1% performance degradation
- **Patch Length Support:** Up to 16,384 patches

## Technique
Decoupled chunk attention pipelines off-chip memory reduction; hybrid SRAM-CIM and RRAM eliminate extensive memory access; bit/element two-way reconfigurable macros adapt to pyramid ViT block sizes; fusion scheduling balances workloads.
