# EPIC: Error PredIction and Correction for Power-Efficient Voltage Underscaling Multiply-Accumulate Unit

**Venue:** DAC  
**ID:** dac-2025-357

## Problem
Voltage underscaling enables power savings in MAC units but induces timing errors potentially causing catastrophic accuracy loss; error correction without high overhead is challenging.

## Motivation
Matrix multiplication dominates power in DNNs; voltage underscaling offers significant power savings but requires robust error handling.

## Key Innovation
Error prediction with delay-tunable clock correction achieving 100% accuracy under voltage underscaling (0.74x nominal) with only 8% area and 1% power overhead.

## Method
Predicts timing errors in underscaled MACs using prediction bits searching algorithm maximizing accuracy with low overhead, then samples correct output via delay-tunable clock to correct errors before use.

## Contributions
- Error prediction framework for voltage-underscaled MAC units
- Delay-tunable clock correction mechanism
- Prediction bits searching algorithm
- 52% power savings with 100% accuracy; 60%-88% less area vs SOTA

## Results
Up to 52% power savings at 0.74x nominal voltage with 100% accuracy preservation; 60%-88% less area than SOTA error-resilient designs.
