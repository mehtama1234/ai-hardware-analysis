# A FeFET-Based Compute-in-Memory Architecture on FPGA for Neural Network Inference

**Problem:** Traditional BRAM-based compute-in-memory designs suffer from low parallelism due to single-word-line activation and require additional adder trees for partial sum accumulation, which limits efficiency. The von Neumann bottleneck restricts memory-bound neural network inference on FPGAs.

**Method:** Instead of using traditional block RAM—which can only read one row at a time—they replace it with compute-in-memory cells built from a 2T1C structure: two transistors paired with one capacitor per cell. These cells compute using charge redistribution, where electrical charge moves between capacitors to perform calculations. To save space, they reuse the same capacitors that normally convert signals from analog to digital. Because each memory cell now does computation itself, multiple operations can happen in parallel, speeding up neural network inference.

**Novelty:** The core innovation is combining ferroelectric transistors (FeFETs), 2T1C cells, charge redistribution computation, and reused analog-to-digital conversion capacitors to replace block RAM and enable parallel processing on FPGAs.
