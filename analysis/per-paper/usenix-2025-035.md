# mTuner: Accelerating Parameter-Efficient Fine-Tuning on Multi-GPU Servers with Elastic Tensor

**Problem:** Parameter-efficient fine-tuning (PEFT) methods like LoRA reduce trainable parameters but face memory fragmentation and inefficient resource utilization when distributed across multiple GPUs. Coordinating computation and data movement across multi-GPU servers introduces communication bottlenecks and load imbalance.

**Method:** mTuner introduces Elastic Tensor, a dynamic tensor allocation mechanism that adapts tensor shapes and placements to GPU memory hierarchy and communication topology. The system coordinates parameter-efficient training layers with elastic tensor packing to reduce fragmentation, overlaps communication with computation, and uses workload-aware scheduling to balance gradients and updates across GPUs.

**Novelty:** Elastic Tensor abstraction that dynamically resizes and reorganizes trainable tensors during PEFT to optimize multi-GPU memory utilization and reduce communication overhead.
