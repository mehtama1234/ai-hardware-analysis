# mTuner: Accelerating Parameter-Efficient Fine-Tuning on Multi-GPU Servers with Elastic Tensor

**Problem:** Parameter-efficient fine-tuning (PEFT) methods like LoRA reduce trainable parameters but face memory fragmentation and inefficient resource utilization when distributed across multiple GPUs. Coordinating computation and data movement across multi-GPU servers introduces communication bottlenecks and load imbalance.

**Method:** mTuner introduces Elastic Tensor, a technique that dynamically reshapes and repositions training data (tensors) based on each GPU's memory structure and how the GPUs are connected to each other. It packs these tensors efficiently to reduce wasted memory space (fragmentation). The system overlaps communication—sending data between GPUs—with computation on each GPU, so processors don't sit idle waiting for data. A workload-aware scheduler balances gradient calculations and weight updates across all GPUs to prevent any single GPU from becoming a bottleneck.

**Novelty:** Elastic Tensor dynamically resizes and reorganizes trainable tensors during parameter-efficient fine-tuning to optimize how they fit in GPU memory and reduce communication overhead between GPUs.
