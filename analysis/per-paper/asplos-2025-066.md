# asplos-2025-066 — BQSim: GPU-accelerated Batch Quantum Circuit Simulation using Decision Diagram

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Existing quantum circuit simulators process one input state at a time, but applications such as quantum testing and verification require simulating a circuit under multiple input states (batch simulation). No GPU-accelerated batch quantum circuit simulator exists that exploits shared structure across inputs.

## Motivation
Testing and verification of quantum algorithms requires reasoning over many input scenarios simultaneously, and current CPU-based or single-input simulators are far too slow to support this at scale, blocking quantum software development workflows.

## Method
BQSim uses decision diagrams (DDs) to compactly represent quantum gate matrices and identify shared structure across batch inputs, then converts the DD representation into a GPU-efficient data structure for parallel evaluation. A task-graph-based execution engine minimizes repetitive GPU kernel launch overhead by grouping related computations into batched kernel calls and overlapping kernel execution with data movement between host and device. The DD optimization step reduces the total computation needed for batch simulation by collapsing redundant operations shared across inputs.

## Key Novelty
Combining decision-diagram-based circuit optimization for shared-structure exploitation with a GPU-efficient data structure and task-graph execution engine to achieve the first GPU-accelerated batch quantum circuit simulator.

## Contributions
- BQSim system: first GPU-accelerated batch quantum circuit simulator.
- GPU-efficient data structure derived from decision diagrams to enable parallel batch simulation.
- Task-graph execution strategy minimizing repetitive kernel call overhead and overlapping computation with data transfer.
- 3.25x speedup over cuQuantum, 159x over Qiskit Aer, 311x over FlatDD on average.
