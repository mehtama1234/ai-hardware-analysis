# NeuraLUT-Assemble: Hardware-Aware Assembling of Sub-Neural Networks for Efficient LUT Inference

**Problem:** Existing LUT-based neural network designs suffer from accuracy degradation because the fan-in required by neurons is limited by the exponential scaling of LUT resources with input width, forcing reliance on extremely sparse models that limit connectivity.

**Method:** NeuraLUT-Assemble overcomes the fan-in limitation—the constraint that lookup tables can't efficiently handle many inputs—by combining multiple smaller lookup tables into each neuron. It uses mixed-precision quantization, representing some values with fewer bits than others, to keep the total hardware resources manageable while increasing connectivity. Skip-connections allow gradient signals to flow backward across the network during training, which improves learning. The result is competitive accuracy with traditional dense neural networks while fitting within hardware constraints.

**Novelty:** Assembling neurons from smaller lookup tables with mixed-precision quantization (representing different values with different bit-widths) to overcome the fan-in limit—the maximum number of inputs a lookup table can handle.
