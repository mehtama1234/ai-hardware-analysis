# Converos: Practical Model Checking for Verifying Rust OS Kernel Concurrency

**Problem:** Verifying concurrent code in OS kernels is extremely difficult; traditional testing cannot guarantee the absence of race conditions, deadlocks, and other concurrency bugs in Rust OS kernel implementations.

**Method:** Converos automatically tests all possible orderings of thread operations in concurrent kernel code to find bugs. To prevent this from taking forever, it uses abstraction (simplifying the code to just the essential parts) and reduction techniques (eliminating redundant checks) to cut down the number of execution paths that need checking. This makes automatic verification practical for real Rust OS kernels.

**Novelty:** Using targeted simplification to manage the explosion of possible execution paths makes automatic verification practical for real Rust OS kernels.
