# Converos: Practical Model Checking for Verifying Rust OS Kernel Concurrency

**Problem:** Verifying concurrent code in OS kernels is extremely difficult; traditional testing cannot guarantee the absence of race conditions, deadlocks, and other concurrency bugs in Rust OS kernel implementations.

**Method:** Converos uses formal model checking to exhaustively explore the state space of concurrent kernel code, employing abstraction and state-space reduction techniques to make verification practical for real OS kernel implementations without exhaustive exploration becoming intractable.

**Novelty:** Making model checking practical and scalable for real Rust OS kernel concurrency by effectively managing state-space explosion through targeted reduction strategies.
