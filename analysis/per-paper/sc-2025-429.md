# Minimizing Power Waste in Heterogenous Computing via Adaptive Uncore Scaling

**Paper ID:** sc-2025-429
**Venue:** SC
**Authors:** Zhong Zheng, Seyfal Sultanov, Michael E. Papka, Zhiling Lan

## Problem

In GPU-dominant heterogeneous systems, uncore (memory, cache, interconnect) frequencies remain at maximum because scaling only occurs when CPU power nears TDP—a rare event in GPU workloads, wasting power.

## Motivation

Uncore power is significant in HPC systems; GPU-dominant workloads don't stress CPUs, so traditional frequency scaling policies don't apply; dynamic phase-aware scaling could reclaim power without hurting performance.

## Method

MAGUS monitors memory access patterns to predict memory bandwidth demand (memory intensity) and identifies execution phases in GPU workloads. It automatically scales down the uncore components—memory, cache, and interconnect hardware—when those phases don't need full speed, handling transitions between phases smoothly. The system integrates with vendor power management (NVIDIA DCGM, Intel RAS) and runs transparently without code changes.

## Key Novelty

MAGUS is the first uncore scaling system to adapt to GPU-dominant workload phases, delivering 27% energy savings while maintaining less than 5% performance loss.
