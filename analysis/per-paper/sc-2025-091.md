# SC25 Paper Analysis: sc-2025-091

## Zero-Value Code Specialization via Profile-Guided Control Data Flow Analysis

### Summary
ZeroSpec is an automated profile-guided code optimizer that detects and specializes code paths for zero-value propagation patterns. It combines static control data flow analysis with runtime profiling to identify redundant operations caused by zero-values, achieving up to 1.31x speedup.

### Key Problem
- **Runtime Zero-Values**: Zero-values are generated dynamically, making static detection insufficient
- **Redundant Computation**: These zero-values cause cascading redundant operations
- **Optimization Gap**: Existing static analyzers miss zero-value-dependent optimization opportunities

### Technical Approach
1. **Control Data Flow Analysis**: Static algorithm identifying zero-value propagation patterns
2. **Profile-Guided Selection**: Runtime profiling determines which optimizations are worthwhile
3. **Cost Model**: Fine-grained evaluation of optimization potential per instruction
4. **Fast Path Specialization**: Code specialization for identified zero-value patterns

### Contributions
1. Novel static control data flow analysis for zero-value detection
2. Automated ZeroSpec framework for profile-guided optimization
3. Fine-grained cost model for optimization selection
4. Evaluation on standard benchmarks (SPEC CPU2017, NPB)

### Hardware & Workloads
- **Target Hardware**: General-purpose CPUs
- **Workloads**: SPEC CPU2017, NAS Parallel Benchmarks, real-world applications

### Performance Results
- **Maximum speedup**: 1.31x
- **Benchmark coverage**: SPEC CPU2017, NPB, real-world applications
