# True-PolyTronik: Securing Circuits Against Laser Logic State Imaging Attack Using RFET

**ID**: vlsid-2025-059 | **Venue**: VLSID | **Confidence**: low (abstract only)

## Problem Statement
Laser Logic State Imaging (LLSI) attacks using optical probing can extract secret data from SRAM, combinational circuits, and sequential logic via modulated power supply at low frequency and amplitude. Existing defenses suffer from high power consumption, require large supply amplitude, or demand costly on-chip laser sensors, impeding practical deployment.

## Motivation
LLSI poses practical security threat to high-value chips (cryptographic accelerators, secure processors, payment systems). Existing mitigations lack practical deployment path due to overhead. A low-cost, CMOS-compatible, effective defense is needed.

## Method
Uses reconfigurable transistors (RFETs—transistors that can be switched between positive-channel and negative-channel types) embedded in logic cells designed to sense small ripples in the power supply. Upon detecting an LLSI attack, the RFETs automatically corrupt the circuit's internal state by applying a biased voltage to their control pins, scrambling the data an attacker is trying to read via optical imaging. A biasing circuit holds these control pins at a steady voltage during the attack to ensure reliable state destruction. The approach was tested on combinational logic and D-latch cells.

## Key Results
- RFET logic cells successfully detect small power modulation
- State corruption effective during LLSI attack
- CMOS-compatible implementation path
- Practical defense without external sensors or large supply modulation

## Novelty & Contributions
1. **First RFET-based LLSI defense** exploiting runtime reconfiguration for state corruption
2. **Seamless CMOS integration** avoiding costly process modifications
3. **Eliminates need for laser sensors** or large supply perturbation
4. **Practical threat model** addressing real optical probing capabilities
