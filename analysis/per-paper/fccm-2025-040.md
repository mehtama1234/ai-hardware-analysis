# SmartNIC-Based Distributed Shared Memory

**Problem:** Maintaining memory coherence and enabling efficient data sharing across heterogeneous computing systems that mix x86 and ARM processors with SmartNICs and other smart I/O devices. Current architectures lack a unified mechanism for distributed shared memory in these ISA-heterogeneous environments.

**Method:** Leverages SmartNICs embedded with full-featured SoCs to implement a distributed shared memory layer that bridges heterogeneous ISA endpoints. Uses the SmartNIC's processing capabilities to manage memory coherence protocol enforcement and remote memory access requests across the heterogeneous fabric, eliminating the need for centralized coherence management.

**Novelty:** Using SmartNICs as coherence controllers to enable distributed shared memory abstractions in ISA-heterogeneous computing environments.
