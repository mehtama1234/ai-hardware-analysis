# SmartNIC-Based Distributed Shared Memory

**Problem:** Maintaining memory coherence and enabling efficient data sharing across heterogeneous computing systems that mix x86 and ARM processors with SmartNICs and other smart I/O devices. Current architectures lack a unified mechanism for distributed shared memory in these ISA-heterogeneous environments.

**Method:** SmartNICs (specialized network cards with their own processors) sit between different computer types—x86 and ARM processors—to enable memory sharing. When any processor reads or writes data, the SmartNIC intercepts the request and applies coherence rules (the protocol that ensures all processors see the same data). The SmartNIC also routes requests to access remote memory across the network, eliminating the need for a separate central system to manage coherence.

**Novelty:** The core idea is using SmartNICs—which already connect heterogeneous computer systems—as distributed coherence controllers, rather than building separate centralized coherence hardware.
