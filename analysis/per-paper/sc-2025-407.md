# SC-2025-407: Fast on-demand Memory Mapping for Shared Memory and Disaggregated Systems

## Summary
This work addresses memory mapping synchronization overhead in disaggregated systems by optimizing the XPMEM-inspired shared-memory driver. Three key optimizations—parallel batched pinning, cache-policy lookup bypass, and dynamic re-registration—reduce cold-start memory copy by up to 13.22x over XPMEM.

## Problem
Efficient memory mapping between processes is increasingly costly as systems become disaggregated and heterogeneous. Fault-driven mapping models require expensive page table walks and updates, creating a bottleneck for shared memory export.

## Method
The system implements a shared-memory driver inspired by XPMEM. It batches and parallelizes pinning operations (locking memory pages in place) instead of handling them one at a time, reducing synchronization overhead. When mapping to physical frame numbers—the actual memory addresses—it skips unnecessary cache-policy lookups. Through dynamic re-registration, it can expand the registered memory region without resetting existing mappings.

## Key Results
- 13.22x speedup in cold-start memory copy over XPMEM for multi-process workloads
- Particularly effective for collective communication patterns
- Benefits demonstrated for rapidly resizing buffers
