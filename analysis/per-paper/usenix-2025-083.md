# PageFlex: Flexible and Efficient User-space Delegation of Linux Paging Policies with eBPF

**Problem:** Linux kernel paging policies are rigid and cannot be customized per-application without kernel modifications. Different workloads have varying memory access patterns and page replacement requirements that would benefit from tailored eviction strategies.

**Method:** PageFlex lets applications customize how the operating system frees up memory without modifying the OS itself. It uses eBPF (a secure way to run custom code inside the OS kernel) to intercept the moment when the OS needs to free up memory. When this happens, programs running outside the kernel can step in and decide which data to delete based on how the application uses memory. The OS automatically verifies this application-written code to make sure it won't crash the system.

**Novelty:** PageFlex uses eBPF to safely delegate paging policy decisions to user-space, allowing applications to customize memory management at runtime for their specific workloads without modifying the OS.
