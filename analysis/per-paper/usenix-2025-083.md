# PageFlex: Flexible and Efficient User-space Delegation of Linux Paging Policies with eBPF

**Problem:** Linux kernel paging policies are rigid and cannot be customized per-application without kernel modifications. Different workloads have varying memory access patterns and page replacement requirements that would benefit from tailored eviction strategies.

**Method:** PageFlex uses eBPF programs deployed in user-space to intercept kernel paging decisions and apply custom page selection and eviction logic. The framework hooks into kernel memory reclamation events, allowing user-space handlers to override or influence page victim selection based on application-defined criteria while maintaining kernel safety via eBPF verification.

**Novelty:** Leveraging eBPF to safely delegate Linux kernel paging policy decisions to user-space applications, enabling runtime customization and per-workload memory management optimization without kernel modifications.
