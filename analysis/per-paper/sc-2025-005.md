# LLM Agents for Interactive Workflow Provenance: Reference Architecture and Evaluation Methodology

**Venue:** SC
**Paper ID:** sc-2025-005
**Confidence:** low

## Problem Statement
Large-scale workflow provenance data becomes complex and difficult to analyze at scale; existing query approaches (custom scripts, structured queries, dashboards) limit interactivity

## Motivation
Scientific discovery workflows span Edge/Cloud/HPC; comprehensive data analysis essential for reproducibility and hypothesis validation; natural language querying could improve accessibility

## Method
The approach uses AI agents powered by large language models to accept natural language questions and convert them into structured queries for workflow provenance data—records showing what processes executed and what data they created. It uses a metadata-driven design where the system understands the structure of the provenance data, combined with retrieval-augmented generation (RAG—giving the LLM access to relevant metadata records to ground its answers in real data). The prompts feeding the system are tuned for accuracy, and the approach was tested on LLaMA, GPT, Gemini, and Claude models across diverse query types.

## Key Novelty
The innovation is using large language model agents with retrieval-augmented generation to enable natural language queries of workflow provenance data.
