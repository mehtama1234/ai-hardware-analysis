# Register-Based Addressing for In-DRAM PIM

## Problem
In-DRAM Processing-in-Memory architectures incur two critical overheads: PIM code offloading to memory and data transfers between CPU and memory, limiting speedup potential for DNN inference.

## Method
The solution adds two new ways to specify memory addresses in processor-memory instructions: indexed addressing (combining a base address with a register value) and base-offset addressing (combining a base address with a constant offset). These methods reduce the size and complexity of each instruction because they avoid repeating full addresses. By making instructions more efficient, the system reduces the amount of data transferred between the processor and memory, and decreases the code overhead for memory operations.

## Key Results
- 1.94x speedup vs baseline in-DRAM PIM
- 4.65% area overhead
- 8.61% power overhead
- Significant reduction in control and data transfer overhead
