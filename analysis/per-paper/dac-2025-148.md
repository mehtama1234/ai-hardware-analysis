# Register-Based Addressing for In-DRAM PIM

## Problem
In-DRAM Processing-in-Memory architectures incur two critical overheads: PIM code offloading to memory and data transfers between CPU and memory, limiting speedup potential for DNN inference.

## Method
Two register-based addressing modes—indexed and base-offset—are added to DMA descriptor-based in-DRAM PIM ISAs. These modes reduce CPU-memory transfer overhead and PIM code offloading cost by enabling efficient descriptor composition and reducing descriptor complexity.

## Key Results
- 1.94x speedup vs baseline in-DRAM PIM
- 4.65% area overhead
- 8.61% power overhead
- Significant reduction in control and data transfer overhead
