# dac-2025-395: BoolE: Exact Symbolic Reasoning via Boolean Equality Saturation

**Problem:** Boolean symbolic reasoning on gate-level netlists fails to identify multi-I/O structures (full adders); conventional hashing is sensitive to structural modifications.

**Method:** BoolE explores all equivalent ways to arrange a circuit's basic building blocks (gate-level netlists) using Boolean transformation rules, storing the equivalent forms in a data structure called an e-graph. It then uses an extraction algorithm to recognize when groups of gates form familiar structures like full adders or datapath blocks—even after the circuit has been optimized—making it easier to reason about what the circuit does and improve it.

**Key Novelty:** E-graph extraction algorithm for structure identification independent of technology mapping and logic optimization changes.

**Contributions:**
- Equality saturation with domain-specific Boolean rules
- Novel multi-I/O structure extraction
- 3.53-3.01x more full adders vs ABC
- 4+ order magnitude speedup in formal verification

**Confidence:** low (abstract-only)
