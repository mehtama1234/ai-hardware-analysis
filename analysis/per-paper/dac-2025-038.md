# GPart: GNN-Enabled Multilevel Graph Partitioner

**Problem:** Conventional multilevel partitioners like METIS use static heuristics; learning-based optimization can improve cut quality while maintaining memory efficiency.

**Key Idea:** Integrate GNN embeddings into the multilevel graph partitioning framework to guide coarsening and refinement with learned graph structure insights.

**Approach:** Multilevel architecture with GNN-enhanced partition decisions; optimized hidden layer sizes reduce memory vs. prior GNN-based methods; hierarchical refinement improves cut quality.

**Results:** 34-43% cut reduction vs. METIS, 24.6× better memory than GAP.

**Theme:** Learning-augmented multilevel graph partitioning for efficient distributed processing.
