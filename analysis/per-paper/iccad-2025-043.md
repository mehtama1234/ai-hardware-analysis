# Designing with Deception: ML- and Covert Gate-Enhanced Camouflaging to Thwart IC Reverse Engineering

**ID:** iccad-2025-043  
**Venue:** ICCAD

## Problem
Integrated circuits face significant security risks from physical reverse engineering attacks; existing IC camouflaging focuses on localized gate modifications without comprehensive deception strategies.

## Motivation
IC intellectual property protection requires robust defenses against reverse engineering to maintain security and market advantage.

## Method
The system uses machine learning (a neural network called an autoencoder) to create two types of camouflage that fool reverse engineers. It modifies the logic gates (basic components that process electrical signals) while keeping the circuit's outputs the same—so an attacker sees fake logic that doesn't explain the outputs. It also inserts fake gates (fake inverters, fake buffers, and universal transmitters) that serve no purpose. Together, these two approaches hide what the circuit really does while keeping it functionally correct.

## Key Novelty
The innovation is using machine learning to combine two types of deception simultaneously: changing how the circuit works internally while keeping the same results, and adding fake gates that don't do anything.

## Contributions
1. AIG-VAE architecture for circuit representation learning
2. Dual-layered camouflage strategy: functional preservation and appearance mimicry
3. Novel covert gate variants: Fake Inverters, Fake Buffers, Universal Transmitters
4. Robust protection against SAT-based and AI-based reverse engineering attacks with low overhead
