# SC-2025-189: RISC-V Multi-word Arithmetic Extension

**Venue:** SC 2025  
**Authors:** Yunhao Lan, Larry Tang, Naifeng Zhang, Youngjin Eum, James C. Hoe, Franz Franchetti  
**Confidence:** low (abstract only)

## Summary

Proposes model-based RISC-V Vector Extension for efficient multi-word arithmetic, addressing carry-propagation bottlenecks in cryptographic workloads and post-quantum cryptography applications.

## Hardware Target

- RISC-V architecture
- RISC-V Vector Extension (RVV)

## Problem & Motivation

Multi-word arithmetic (>native word size operands) critical for HPC:
- Cryptographic kernels rely on multi-word operations
- Carry-propagation bottlenecks limit performance
- GPU approaches less energy-efficient
- Specialized accelerators incur high design costs
- RISC-V potential not yet explored for this domain

## Approach

1. General modeling-based multi-word arithmetic extension on RVV ISA
2. Comprehensive performance models across diverse microarchitectures
3. Carry-propagation support enhancement
4. Validation on cryptographic workloads

Applications:
- Number theoretic transform (NTT)
- Post-quantum cryptography (log2(q)-bit arithmetic)
- Mod-q polynomial multiplication

## Key Contributions

1. General multi-word arithmetic extension framework for RVV
2. Cross-microarchitecture performance modeling
3. Pipeline saturation enhancement via carry-propagation support
4. Demonstrates RISC-V viability for cryptographic HPC
5. Architectural guidance for targeted extensions

## Limitations

Specific performance improvements over GPUs/DSAs not in abstract; energy efficiency comparison missing; practical deployment challenges not addressed.
