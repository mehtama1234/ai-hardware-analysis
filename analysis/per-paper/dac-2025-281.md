# dac-2025-281: INSIGHT—Transformer-Based Analog Circuit Neural Simulator

**Problem:** SPICE simulation is compute-expensive; neural surrogates often lack data efficiency or cross-technology generalization.

**Motivation:** Accelerating analog design automation requires fast, accurate performance prediction.

**Method:** INSIGHT predicts analog circuit performance by building predictions step-by-step using transformers, neural networks that learn how information flows through sequences. Rather than retraining for each new chip manufacturing technology, it uses LoRA (Low-Rank Adaptation), a technique that updates only a small part of the model to adapt its knowledge. This approach requires 60% less training data for new technologies, while reducing memory usage by 42% and training time by 25%.

**Key Novelty:** Autoregressive transformer neural simulator with efficient cross-technology transfer via LoRA.

**Contributions:**
- R^2 >= 0.95 prediction accuracy
- Cross-technology transfer with 60% data reduction
- 100-1000x faster RL-based sizing
