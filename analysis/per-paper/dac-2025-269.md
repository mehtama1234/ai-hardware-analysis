# Constraint Graph-based PCB Legalization

**Venue:** DAC | **ID:** dac-2025-269

## Problem
Modern high-density PCB designs with dense, heterogeneous, irregular-shaped, and any-oriented components challenge automatic placement legalization, especially on double-sided boards.

## Key Innovation
First constraint graph-based legalization approach with accurate slicing-based component modeling and MILP formulation for complex heterogeneous components.

## Method
The approach builds a constraint graph—a network showing how components relate spatially on the circuit board—to arrange them without overlaps or violations. Instead of using simple bounding boxes, it models irregular shapes more accurately by breaking them into rectangles using a slicing technique. It then applies Mixed Integer Linear Programming (MILP)—a mathematical method for solving optimization problems that mix continuous and discrete choices—to find valid placements that satisfy all constraints. This works even when components have different shapes, rotations, and densities packed together.

## Advantages
- Accurate component representation
- Handles complex constraints
- Expanded solution space via MILP
- Support for any-oriented components
