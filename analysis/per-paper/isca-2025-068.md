# isca-2025-068 — H2-LLM: Hardware-Dataflow Co-Exploration for Heterogeneous Hybrid-Bonding-based Low-Batch LLM Inference

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Edge-side low-batch LLM inference is bottlenecked by DRAM bandwidth; existing in-die NMP designs have limited compute capacity, creating an imbalance for both compute-bound prefill and bandwidth-bound decoding stages. Hybrid-bonding technology enables higher compute density near memory but requires simultaneous architecture and dataflow co-optimization.

## Motivation
Low-batch LLM inference at the edge is memory-bandwidth-bound during decoding; hybrid bonding (face-to-face die stacking) offers far more compute logic near memory than in-die NMP, but maximizing efficiency requires joint hardware architecture and dataflow exploration.

## Method
H2-LLM stacks compute chips directly against memory chips using hybrid bonding—a technology that connects them with thousands of tiny data pathways (through-silicon vias) that move data far faster than traditional side-by-side layouts. Instead of uniform compute, it mixes specialized processors optimized for different tasks: some for math-heavy operations, others for memory-heavy ones. The system assigns each LLM operation—attention heads, feed-forward layers, memory lookups—to whichever compute resource sits closest to where its data lives, whether during prefill (when the model processes your input) or decoding (when it generates output one token at a time). Finally, an automated search finds the best combination of compute count and memory allocation that balances speed and efficiency.

## Key Novelty
H2-LLM jointly explores hardware architecture and dataflow design together—instead of separately—for hybrid-bonded LLM accelerators, so compute placement and data flow can reinforce each other.

## Contributions
1. A hybrid-bonding-based heterogeneous accelerator architecture with explicit design space characterization.
2. A data-centric dataflow abstraction mapping prefill and decoding LLM operations onto heterogeneous resources.
3. An automated DSE framework for joint architecture-dataflow optimization.
4. 2.72x geomean speedup and 1.48x geomean energy efficiency improvement over in-die NMP accelerators.
