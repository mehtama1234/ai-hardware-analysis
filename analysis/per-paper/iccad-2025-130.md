# MoE-OPU: An FPGA Overlay Processor Leveraging Expert Parallelism for MoE-based Large Language Models

**Venue:** ICCAD  
**ID:** iccad-2025-130

## Problem
MoE-based LLM inference on edge devices faces severe token allocation imbalances among experts, causing storage and computational burdens; lack of integration between expert-aware pruning and parallel scheduling leads to suboptimal resource utilization.

## Motivation
Enable scalable MoE-LLM inference on resource-constrained FPGA devices for edge deployment.

## Method
The processor speeds up MoE inference on an FPGA using three coordinated techniques. First, it removes unimportant weights from experts based on how often each expert gets used (keeping 25–75% depending on the usage pattern, expressed as ratios like 1:4 to 8:8), and stores numbers in space-saving formats (16-bit, 8-bit, or 4-bit precision). Second, it predicts which experts the next layer will need with an 83.4% success rate, so the hardware can load them in advance. Third, it uses a reconfigurable grid of processing cores (a systolic array) that can efficiently compute with both sparse weights and mixed-precision numbers in parallel.

## Key Novelty
It predicts which experts to use next and removes weights from rarely-used experts, both strategies guided by expert activation patterns, so prediction and pruning work as one system.

## Contributions
- Activation-frequency-guided N:M sparsity and mixed-precision quantization
- Lightweight prediction network for proactive expert scheduling
- Reconfigurable systolic array architecture for efficient MoE computation

## Metrics
- **Speedup vs NVIDIA A100:** 6.78×
- **Speedup vs RTX 4090:** 13.37×
- **Speedup vs Xilinx U200 FPGA:** 7.85×
- **Parameter Size Reduction:** 2.76×
- **Expert Prediction Hit Rate:** 83.4%
- **Accuracy Drop (after fine-tuning):** 1.53% average

## Limitations
Specific to MoE architectures; may not generalize to other sparse model types.
