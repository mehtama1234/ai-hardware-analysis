# Adaptive Learning Approach for Clock Tree Hub Node Selection

**Venue:** DAC 2025  
**Confidence:** abstract-only

## Summary

Proposes reinforcement learning-based methodology with adaptive learning strategy for selecting optimal hub nodes in clock trees, balancing wire-length cost against skew in large-scale designs.

## Key Contributions

- **RL Formulation**: Reinforcement learning approach to hub node selection for cost-skew tradeoff
- **Adaptive Strategy**: Learning strategy enabling efficient exploration of design space
- **Scalability**: Handles both small and large-scale routing instances effectively
- **EDA Integration**: Practical approach suitable for industrial clock tree synthesis tools

## Technical Focus

Addresses combinatorial optimization of hub node selection where greedy or heuristic methods may be suboptimal. RL agent learns cost-skew tradeoff landscape and adapts selection strategy dynamically.

## Relevance

**Keywords:** clock-tree, routing, reinforcement-learning, cost-skew-optimization, eda
