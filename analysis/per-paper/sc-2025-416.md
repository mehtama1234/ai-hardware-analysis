# SC-2025-416: TaGNN - FPGA Accelerator for Dynamic Graph Neural Networks

## Summary
TaGNN accelerates dynamic GNNs on FPGA (Xilinx Alveo U280) through topology-aware concurrent execution, achieving 535.2x speedup over CPUs and 84.3x over GPUs with 742.6x energy savings.

## Problem
Dynamic GNNs process evolving graphs using snapshot-by-snapshot execution with strict temporal dependencies, resulting in low parallelism, high memory contention from irregular vertex accesses, and poor utilization.

## Method
TaGNN speeds up dynamic graph neural networks by running multiple computations at the same time based on the graph's structure. Instead of recalculating everything each time step, it updates only the vertices (nodes) that actually change, while loading the unchanged ones just once per layer. The data is organized by the graph's topology and timestamps so the computer's fast memory cache works efficiently. When the RNN (recurrent neural network, which processes sequences) outputs are nearly identical between steps, it skips those redundant calculations.

## Key Results
- 535.2x speedup over Intel Xeon CPUs
- 84.3x speedup over NVIDIA A100 GPUs
- 742.6x energy savings vs CPU
- 104.9x energy savings vs GPU
- 13.5-6.5x speedup vs other DGNN accelerators (DGNN-Booster, E-DGCN, Cambricon-DG)
