# HPIM-NoC: A Priori-Knowledge-Based Optimization Framework for Heterogeneous PIM-Based NoCs

**Problem:** Existing NoC simulators and search frameworks are designed for homogeneous architectures and don't explore the heterogeneous PIM configuration space.

**Method:** HPIM-NoC combines simulation and search to optimize systems where different types of processing cores are connected by a network-on-chip (a grid of communication channels on the chip). It accurately models how long data takes to travel through the network by simulating transmission delays. The system searches for good designs in three stages using a customized simulated annealing algorithm (a method that gradually refines solutions by testing variations), guided by prior knowledge about architecture. To accelerate the search, it pre-calculates performance metrics for each core type, reduces simulation frequency for the network, and applies a customized layout algorithm.

**Key Result:** 2.12-2.96x search time reduction; FoM improvements up to 37.41% for heterogeneous vs homogeneous (ResNet-18).

**Hardware Target:** ASIC, SoC  
**Workloads:** LLM-inference, CNN, transformer, vision
