# HPIM-NoC: A Priori-Knowledge-Based Optimization Framework for Heterogeneous PIM-Based NoCs

**Problem:** Existing NoC simulators and search frameworks are designed for homogeneous architectures and don't explore the heterogeneous PIM configuration space.

**Method:** Joint simulation + search framework with three-stage heterogeneous PIM search guided by priori knowledge, customized simulated annealing, and optimized layout algorithm.

**Key Result:** 2.12-2.96x search time reduction; FoM improvements up to 37.41% for heterogeneous vs homogeneous (ResNet-18).

**Hardware Target:** ASIC, SoC  
**Workloads:** LLM-inference, CNN, transformer, vision  
**Confidence:** low (abstract-only)
