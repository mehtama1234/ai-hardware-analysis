# Anchor: Stationary-Data-Aware GNN Processing on PIM

**Problem:** GNNs on multi-bank PIM see only 35.6% stationary data; irregular graph topology forces cross-bank communication that scales poorly with PIM density.

**Key Idea:** Maximize stationary data through locality-preserving graph partitioning (Mastav), and minimize non-stationary data movement via single-pass access and optimized critical-path communication.

**Approach:** Hardware-software co-design: Mastav partitioning allocates vertices/edges to preserve locality; customized dataflow ensures one-pass access; critical-path analysis reduces redundant transfers.

**Results:** Significant latency and data movement reduction vs. representative PIM schemes.

**Theme:** Locality-aware PIM architecture for scalable graph neural network acceleration.
