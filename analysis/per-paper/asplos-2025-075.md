# Relax: Composable Abstractions for End-to-End Dynamic Machine Learning

**Venue:** ASPLOS 2025  
**Confidence:** low (abstract-only)

## Problem
Dynamic shape ML workloads (especially LLMs) cannot be efficiently compiled by frameworks that treat computation graphs, loop-level tensor programs, and library calls as separate non-interoperable abstractions, blocking cross-level optimization and multi-backend deployment.

## Motivation
LLM universal deployment across GPUs, mobile, embedded, and browsers demands dynamic-shape-aware end-to-end compilation that existing compilers cannot provide.

## Method
Relax builds a single unified representation (called a compiler IR, or intermediate representation) that describes three normally separate aspects of ML programs: high-level computational graphs, low-level loop-based tensor operations (called TIR), and calls to external libraries—all in one language. Instead of treating shape sizes (how big tensors are) as information that gets lost between these levels, Relax marks them as first-class values that flow through the entire program, enabling the compiler to optimize based on shape information at every stage. The compiler then uses this unified view to fuse multiple operations into single kernels (combining operations for speed), specialize operators for their actual inputs, and finally generate deployment code for GPUs, mobile phones (Android/iOS), embedded microcontrollers, and web-based targets (WebAssembly and WebGPU).

## Key Novelty
Relax unifies three separate aspects of ML programs (computational graphs, low-level tensor loop operations, and external library calls) with first-class symbolic shapes that flow throughout the program, enabling shape-aware optimizations that work across all these different levels.

## Contributions
- Cross-level IR unifying computation graphs, loop programs, and library calls
- First-class symbolic shape annotations for global dynamic-shape propagation
- End-to-end compilation competitive with SOTA GPUs while targeting mobile/embedded/browser
- Open-source Apache TVM integration
