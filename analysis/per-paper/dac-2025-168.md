# PipeLink: A Pipelined Resource Sharing System for Dataflow High-Level Synthesis

**Problem:** Dataflow HLS lacks centralized control, making it hard to pipeline access to shared functions in general software programs.

**Solution:** Two-stage synthesis (compilation + linking) in asynchronous dataflow circuits enabling full pipelining of shared resources.

**Results:** 20x energy reduction, 1.56x throughput improvement.

**Theme:** Pipelined resource sharing in asynchronous HLS.
