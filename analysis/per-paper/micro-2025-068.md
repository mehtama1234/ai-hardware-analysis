# micro-2025-068: SeaCache: Efficient and Adaptive Caching for Sparse Accelerators

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Sparse tensor accelerators suffer from poor on-chip SRAM utilization because variable-length sparse fibers do not map cleanly into fixed-size cache blocks, wasting capacity. Theoretically optimal replacement policies (Belady OPT) require expensive on-chip metadata.

## Motivation
Sparse workloads (GNNs, sparse transformers, recommendation models) are highly memory-bound; effective on-chip data reuse is critical to performance, yet existing cache designs leave substantial capacity unused due to fragmentation from variable-length sparse data.

## Method
SeaCache uses three techniques to make sparse caches more efficient. First, it reorganizes variable-length sparse data (rows or columns of nonzero values) by splitting long fibers across multiple cache blocks and grouping short fibers together, reducing wasted space. Second, instead of using an expensive way to decide which data to keep when the cache is full, it uses a practical approximation that exploits access patterns in sparse computations. Third, it dynamically adjusts how much cache space is reserved for data versus the metadata needed for these decisions, measuring the optimal split at runtime.

## Key Novelty
The core idea is a two-phase process that dynamically adjusts how the on-chip SRAM is split between sparse data and the metadata used to decide which data to keep, tuning their ratio at runtime to maximize space for variable-length fibers.

## Contributions
- Fiber packing/splitting for variable-length sparse data in fixed-size cache blocks
- Practical replacement policy approximating OPT at low implementation cost
- Two-phase adaptive cache-space partitioning between data and metadata
- 2.8x average speedup over state-of-the-art sparse cache designs
