# SC-2025-418: X-MoE - Scalable MoE Training on HPC Platforms

## Summary
X-MoE enables scalable training of emerging Mixture-of-Experts models on HPC systems through cross-platform kernels and redundancy-bypassing dispatch, achieving 10x larger models (545B parameters) on Frontier compared to existing methods.

## Problem
Emerging MoE architectures (DeepSeek-style) deliver better model quality but suffer from high activation memory overhead and expensive all-to-all communication. Current implementations are NVIDIA-GPU-optimized, performing poorly on other HPC platforms.

## Method
X-MoE scales mixture-of-experts training (a neural network approach where different experts activate based on input) through three optimizations: memory-efficient code that runs on different hardware platforms, direct expert routing that eliminates redundant data copying, and hybrid parallelization that splits both the data and model across machines. Together, these reduce memory overhead and communication bottlenecks that normally limit the size of models you can train.

## Key Results
- Trains 545 billion parameter models on 1024 Frontier GPUs
- 10x larger models than existing methods under same hardware budget
- High training throughput maintained
- Cross-platform compatibility demonstrated
