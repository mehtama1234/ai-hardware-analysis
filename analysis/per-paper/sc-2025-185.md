# SC-2025-185: TT-LoRA MoE

**Venue:** SC 2025  
**Authors:** Pradip Kunwar, Minh N. Vu, Maanak Gupta, Mahmoud Abdelsalam, Manish Bhattarai  
**Confidence:** low (abstract only)

## Summary

Novel framework combining Parameter-Efficient Fine-Tuning (PEFT) with sparse Mixture-of-Experts (MoE) for scalable multi-task LLM inference. Uses tensor-train decomposition for expert parameters and separate router training.

## Hardware Target

- GPUs
- Multi-GPU distributed systems

## Problem & Motivation

Large model deployments require efficient scaling; traditional MoE approaches incur significant computational overhead as expert counts grow. Multi-task learning faces catastrophic forgetting when fine-tuning shared parameters.

## Approach

Two-stage training pipeline:

1. **Expert Stage:** Train lightweight tensor-trained low-rank (TT-LoRA) adapters independently for each task
2. **Router Stage:** Train sparse MoE router separately using frozen base model representations to select exactly one adapter per input

Key insight: Structured decoupling eliminates inter-task interference.

## Key Contributions

1. Tensor-train decomposition for compact expert representation
2. Separate router training eliminating catastrophic forgetting
3. Extreme parameter efficiency:
   - 2% of standard LoRA parameters
   - 0.3% of Adapters
   - 0.03% of AdapterFusion
4. 4% average improvement over AdapterFusion on multi-task benchmarks
5. Practical scalable multi-task inference
