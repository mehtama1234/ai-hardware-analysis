# SampleAttention: Near-Lossless Acceleration of Long Context LLM Inference with Adaptive Structured Sparse Attention

**ID:** mlsys-2025-060  
**Venue:** MLSYS 2025  
**Confidence:** high (full text analyzed)

## Problem
Long-context LLM prefill latency scales quadratically with sequence length; existing sparse attention methods use static patterns or fixed sparsity budgets that cannot adapt to per-head, per-input, and per-model variability in sparsity ratio and structured pattern.

## Method
Two-stage query-guided key-value filtering driven by Cumulative Residual Attention (CRA), a runtime accuracy proxy equal to the minimum fraction of attention probability retained per query after sparsification.  
- **Stage 1 (Chunked Sampling):** Queries partitioned into chunkn equal segments; full attention computed for a small query block at each chunk's tail; token-level scores block-reduced (block=128) along column and slash axes.  
- **Stage 2 (Block Filtering):** Separate CRA thresholds (αc, αs) used to find the minimum number of column-strip and slash-strip KV blocks via cumulative-sum top-k; blocks extended to cover the full head, merged into a binary block-sparse mask, then executed via a modified FlashAttention2 sparse kernel.  
- Sampling pipeline (bmm, mask_fill, softmax, reduction) is kernel-fused; hyperparameters tuned offline per model and sequence-length range on a small RULER subset.

## Key Novelty
CRA metric enables fully adaptive, per-head, per-input sparsity ratio and pattern selection at runtime without retraining, tightly predicting downstream task accuracy across models.

## Metrics
| Metric | Value |
|--------|-------|
| TTFT speedup vs. FlashAttention2 | 5.29x at 1M tokens; 1.15x–3.94x at 32K–512K |
| Accuracy retention | >99% of full attention (MLPerf near-lossless) on RULER, LongBench, InfiniteBench |
| Sampling overhead share | 21.6%–39.1% of total attention time at 32K–128K; shrinks with length |

## Baselines
FlashAttention2, MInference, BigBird, StreamingLLM, HyperAttention, Hash-Sparse

## Limitations
Prefill-only; no KV-cache compression for decoding; negligible gains at sequences shorter than ~32K; offline per-model, per-length-range hyperparameter tuning required.
