# PUFiM: A Robust and Efficient FeFET-Based Security Solution Merging Physical Unclonable Function with Compute-in-Memory for Edge AI

**Problem:** CiM architectures expose plaintext weights; PUF key generation/delivery frameworks lack comprehensive implementation.

**Solution:** Unified FeFET-based PUF+CiM array using MLC FeFETs for hybrid PUF/weight storage without separate ciphertext overhead.

**Results:** 9.7x density, 1.2x energy efficiency; resists 10M-sample modeling attacks.

**Theme:** Integrated on-chip security for edge AI via PUF-CiM fusion.
