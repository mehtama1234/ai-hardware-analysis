# LABMATE: Language Model Based Multi-Agent System to Accelerate Catalysis Experiments

## Overview
Multi-agent LLM system for coordinating materials science and catalysis research workflows, balancing automation with human expert validation.

## Problem & Motivation
- **Challenge**: LLMs unreliable for decision-making (hallucination); unable to execute complex simulations essential to materials science
- **Opportunity**: Coordinating simulation runs, particle tracking, data analysis, literature review, and hypothesis generation in a single framework can substantially accelerate research
- **Key Insight**: Domain-specific agent decomposition + human validation prevents hallucination while maintaining automation benefits

## Architecture & Method
- Multi-agent framework: agents specialize in distinct tasks (simulation, analysis, literature, hypothesis)
- Human experts retain control through validation checkpoints
- Domain-specific prompting and tool integration
- System benchmarked on Chemistry and Materials Science corpus

## Key Contributions
1. **Modular agent design** separating research concerns across specialized LLM agents
2. **Human-in-the-loop** validation preventing unreliable autonomous decisions
3. **Domain-agnostic** framework architecture enabling cross-domain adaptation
4. **Comparable benchmark performance** to frontier LLMs on domain-specific evaluations

## Performance & Results
- Achieves performance on par with frontier LLMs for Chemistry and Materials Science segments
- Enables research process acceleration through integrated workflow coordination
- Maintains scientific rigor via human expert checkpoints

## Limitations
- Not fully autonomous—requires human experts for validation
- Limited to domains where research tasks can be decomposed into distinct agent modules
- Abstract-only availability limits detailed performance metrics assessment

## Relevance to Hardware/AI Systems
Low direct relevance—focuses on LLM agent orchestration for scientific applications rather than hardware acceleration, distributed system optimization, or ML infrastructure concerns.
