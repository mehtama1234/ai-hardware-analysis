# ASaP: Automatic Software Prefetching for Sparse Tensor Computations in MLIR

**Venue:** SC
**ID:** sc-2025-325
**Confidence:** low

## Problem Statement
Sparse tensor computations have irregular memory access patterns that degrade cache performance; existing compiler approaches lack semantic insight for effective prefetching.

## Motivation
Sparse tensor operations are critical for ML and scientific computing; software prefetching can mitigate cache misses if intelligently placed; MLIR's sparsification provides semantic context.

## Method
ASaP is an automatic software prefetching system in MLIR (a compiler framework) that works with sparse tensors—arrays stored in specialized compressed formats where most values are zero. It analyzes the tensor storage format and the loop structure that accesses the data, then calculates which memory regions need to be prefetched. It automatically inserts prefetch instructions—software requests to load data into the cache in advance—in both inner and outer loops, so memory is ready at multiple nesting levels.

## Key Novelty
The breakthrough is semantic-aware prefetching—intelligently using MLIR's understanding of sparse tensor structure to inject prefetches in both outer and inner loops, rather than the single-loop prefetching of earlier systems.

## Contributions
1. ASaP prefetching framework for sparse tensors in MLIR
2. 1.38x speedup (SpMV vs Ainsworth & Jones)
3. 1.28x speedup (SpMM with outer-loop prefetching)
