# mlsys-2025-023 — ThunderServe: High-performance and Cost-efficient LLM Serving in Cloud Environments

**Venue:** MLSYS 2025

**One-line problem:** Serve LLMs efficiently on heterogeneous cloud GPU clusters with limited PCIe/Ethernet interconnects.

## Method
Two-level hierarchical scheduling: tabu search partitions GPUs into prefill-phase vs decode-phase groups, then LP optimizes tensor/pipeline parallelism and request routing per group. Prefill goes to high-FLOPS GPUs (A40), decode to high-HBM-bandwidth GPUs (3090Ti). 4-bit KV cache quantization reduces inter-phase transfer cost. Lightweight rescheduling (phase re-designation only, no model reload) reacts to load changes in ~13s.

## Key Novelty
First system combining prefill-decode phase splitting with heterogeneous GPU assignment in low-bandwidth cloud environments, coordinated via tabu search + linear programming.

## Metrics
- Up to 2.1x (avg 1.7x) throughput improvement vs SOTA
- Up to 2.5x (avg 1.5x) latency reduction
- Lightweight rescheduling: ~13s vs ~157s for full reschedule
