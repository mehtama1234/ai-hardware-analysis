# mlsys-2025-023 — ThunderServe: High-performance and Cost-efficient LLM Serving in Cloud Environments

**Venue:** MLSYS 2025

**One-line problem:** Serve LLMs efficiently on heterogeneous cloud GPU clusters with limited PCIe/Ethernet interconnects.

## Method
ThunderServe uses two optimization levels to split LLM serving across heterogeneous GPUs: tabu search (an algorithm that explores solutions while avoiding previous dead-ends) partitions the GPU pool and assigns groups to prefill-phase (processing input) or decode-phase (generating output), while linear programming determines how to split the model within each group and route requests. Compute-heavy prefill work goes to fast GPUs like A40s, while decode work needing fast memory access goes to high-bandwidth GPUs like 3090Tis. The system compresses intermediate data to 4 bits during inter-phase transfer to reduce network congestion and adjusts assignments dynamically when traffic changes.

## Key Novelty
It's the first system to split LLM serving between prefill and decode phases and assign each phase to different GPU types optimized for that phase in cloud environments with low-bandwidth interconnects between GPUs.

## Metrics
- Up to 2.1x (avg 1.7x) throughput improvement vs SOTA
- Up to 2.5x (avg 1.5x) latency reduction
- Lightweight rescheduling: ~13s vs ~157s for full reschedule
