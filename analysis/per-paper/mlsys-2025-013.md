# AIOpsLab: A Holistic Framework to Evaluate AI Agents for Enabling Autonomous Clouds

**Venue:** MLSys 2025 | **ID:** mlsys-2025-013 | **Confidence:** high

## Problem
No standardized evaluation framework exists for AI agents performing cloud operations (fault detection, localization, RCA, mitigation), preventing rigorous progress measurement.

## Method
AIOpsLab sets up a standard way for AI agents to interact with a realistic cloud system: it uses DeathStarBench, a microservice testbed that deliberately breaks services using ChaosMesh, measures what happens through Prometheus (a metrics collector), and tracks requests across services with Jaeger (distributed tracing). The system tests agents on 100 problems organized into four levels: detecting that a fault occurred, pinpointing where it happened, analyzing why it happened (root-cause analysis), and applying a fix. Faults come in two types—symptomatic ones where you can observe the problem but don't know its source, and functional ones where the root cause is specified. The best-performing agent, FLASH, achieves 59.32% accuracy on these tasks.

## Novelty
First holistic AIOps benchmark combining a standardized Agent-Cloud Interface, realistic fault injection, and a hierarchical 4-level task taxonomy covering the full incident lifecycle.

## Metrics
- FLASH: 59.32% task accuracy (best agent)
- GPT-4-W-Shell: 49.15% task accuracy
- 100-problem benchmark
