# AIOpsLab: A Holistic Framework to Evaluate AI Agents for Enabling Autonomous Clouds

**Venue:** MLSys 2025 | **ID:** mlsys-2025-013 | **Confidence:** high

## Problem
No standardized evaluation framework exists for AI agents performing cloud operations (fault detection, localization, RCA, mitigation), preventing rigorous progress measurement.

## Method
Agent-Cloud Interface (ACI) connects agents to a live DeathStarBench microservice testbed with ChaosMesh fault injection, Prometheus metrics, and Jaeger tracing. 100-problem benchmark across a 4-level task taxonomy (detect/localize/RCA/mitigate) with symptomatic and functional fault categories. Best agent: FLASH at 59.32% accuracy.

## Novelty
First holistic AIOps benchmark combining a standardized Agent-Cloud Interface, realistic fault injection, and a hierarchical 4-level task taxonomy covering the full incident lifecycle.

## Metrics
- FLASH: 59.32% task accuracy (best agent)
- GPT-4-W-Shell: 49.15% task accuracy
- 100-problem benchmark
