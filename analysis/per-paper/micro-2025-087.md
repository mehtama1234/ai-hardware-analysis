# micro-2025-087: Flexing RISC-V Instruction Subset Processors to Extreme Edge

**Venue:** MICRO 2025  
**Authors:** Alireza Raisiardali, Konstantinos Iordanou, Jedrzej Kufel, Kowshik Gudimetla, Kris Myny, Emre Ozer  
**Confidence:** high (full text)

## Problem
Extreme edge applications (smart labels, wearable healthcare, smart textiles) need ultra-low-area, ultra-low-power, conformable, programmable processors that conventional silicon RISC-V designs cannot provide. Flexible integrated circuits (FlexICs) on IGZO/polyimide substrates offer conformability and low cost but have very limited transistor budgets.

## Motivation
The extreme edge application space demands kHz-range processors manufacturable on flexible substrates with dramatically lower carbon footprint; even the world's smallest RISC-V processor (Serv) is too power-hungry for these applications due to its bit-serial, flip-flop-heavy design.

## Method
The approach analyzes an application to identify which instructions from the full RISC-V instruction set (RV32E) it needs—typically 24-86% of the total—then assembles pre-built, formally verified hardware blocks for those instructions from a library into a Modular Execution Unit (ModularEX) using a switch statement. The combined hardware is synthesized (converted to a physical chip layout) with commercial tools (Synopsys ICC2 or Cadence Innovus) on Pragmatic Semiconductor's 0.6-micron IGZO FlexIC process (a technology for making low-area, flexible chips), and the synthesis automatically eliminates unused logic gates. A single-cycle, non-pipelined microarchitecture (where each instruction completes in one clock step, rather than overlapping multiple instructions) suffices for the kilohertz performance requirements of extreme-edge devices. For applications that need firmware updates later, an AI tool rewrites any instructions outside the chosen subset using equivalent instructions from within it.

## Key Novelty
The core idea is using a library of formally pre-verified instruction-sized hardware blocks that can be automatically assembled into minimal-area processors on the FlexIC process, eliminating per-application design and verification cycles.

## Contributions
1. Pre-verified full ISA hardware library with each RISC-V instruction as a discrete, formally verified RTL block
2. Physical FlexIC implementation of three extreme edge RISSPs: up to 42% area and 21% power reduction over full RISC-V
3. ~40x energy-efficiency advantage over Serv per instruction (Serv's bit-serial CPI=32 dominates its energy)
4. Generative AI assembly retargeting tool for firmware updates in long-lasting applications

## Hardware Target
RISC-V, ASIC (IGZO FlexIC on polyimide substrate)

## Techniques
circuit-design, power, compiler

## Workloads
Extreme edge inference (armpit malodour classification, atrial fibrillation detection, XGBoost decision trees); embedded benchmarks (Embench)

## Key Metrics
- Area: 8-43% reduction vs. full RISSP-RV32E (synthesis); up to 42% in FlexIC physical impl.
- Power: 3-30% reduction (synthesis); up to 21% in FlexIC physical impl.
- Energy: ~40x more energy-efficient per instruction than Serv
- Frequency: 1500-1850 kHz max on 0.6-um IGZO process (300 kHz physical impl.)
- ISA utilization: applications use 24-86% of RV32E ISA (average 19 of ~40 instructions)

## Baselines
RISSP-RV32E (full RV32E processor by same methodology), Serv (world's smallest 32-bit RISC-V, bit-serial)

## Limitations
RISSPs require applications to use only supported instructions; generative AI retargeting adds toolchain complexity for long-lasting applications, and single-cycle non-pipelined design limits frequency on conventional silicon.
