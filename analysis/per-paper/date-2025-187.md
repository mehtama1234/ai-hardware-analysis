# Buddy ECC: Making Cache Mostly Clean in CXL-Based Memory Systems for Enhanced Error Correction at Low Cost

**Venue:** DATE  
**Confidence:** low (abstract-only)

## Core Idea
Optimize CXL Memory Module (CMM) systems by leveraging full-duplex architecture to minimize dirty cache lines and differentiate ECC protection based on line cleanliness.

## Problem
CXL-based memory systems have different characteristics than traditional DRAMs; existing ECC optimizations don't translate well to CMMs.

## Method
- **Proactively Write-back:** Dead block prediction identifies cache lines unlikely to be rewritten and proactively writes them back, reducing dirty lines and improving bandwidth efficiency
- **Utilization-aware Policy:** Monitors CMM internal bandwidth; issues write-back only during low-load periods to avoid performance degradation
- **Buddy ECC:** Separates weak EDC for clean cache lines and stronger ECC for dirty lines, reducing parity area overhead

## Key Results
- **46% bandwidth utilization improvement**
- **0.33% performance degradation**
- **<1% energy overhead**
