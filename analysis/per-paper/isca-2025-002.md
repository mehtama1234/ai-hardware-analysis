# Leveraging control-flow similarity to reduce branch predictor cold effects in microservices

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Microservices suffer from severe branch mispredictions due to cold branch predictor state when cores are shared across interleaved service invocations or power-gated between requests. This cold-start effect degrades tail latency under strict SLA constraints.

## Motivation
Microservice architectures dominate modern datacenters, and their fine-grained execution with frequent core switching causes predictor state eviction, making branch mispredictions a primary performance bottleneck that existing warm-predictor-focused designs cannot address.

## Method
The authors propose Similarity-based Branch Prediction (SBP), a hybrid predictor augmenting conventional history-based and static-hint predictors with a similarity component (CHESS). CHESS encodes control flow of prior request executions into a compact reference execution trace, identifies branches hard to predict via conventional means, and redirects them to the similarity predictor. The similarity predictor replays past execution paths for matching current requests via dynamic control-flow reconvergence analysis, requiring only 18.1 KB additional storage.

## Key Novelty
CHESS exploits inter-request control-flow similarity in microservices—encoding prior execution traces as reference paths—to warm-start branch prediction for cold-predictor scenarios without requiring actual predictor state persistence.

## Contributions
- Quantitative analysis confirming high control-flow similarity across microservice requests
- SBP hybrid predictor combining history-based, static-hint, and similarity-based prediction
- CHESS achieving 94% branch MPKI reduction over cold fetch predictor; 78% over state-of-the-art
- Performance within 95% of warm baseline using 18.1 KB additional storage
