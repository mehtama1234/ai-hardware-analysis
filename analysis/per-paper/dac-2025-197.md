# Less Sense Makes More Sense: In-Sensor Compressive Learning for Efficient Machine Vision

**Venue:** DAC  
**Confidence:** low (abstract-only analysis)

## Problem
High-resolution image acquisition generates excessive data with high quantization and transmission overhead for deep learning tasks.

## Method
A **1-bit in-sensor encoder** integrated within the image sensor is jointly optimized with downstream vision tasks to extract task-specific features in low-dimensional compressed form.

## Key Novelty
Joint optimization of encoder and downstream task enables 10× compression with minimal accuracy loss at the sensor interface.

## Results
- **10× data compression**
- **3.93× sensor-end energy savings**
- **1.6% maximum accuracy loss**
