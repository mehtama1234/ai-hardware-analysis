# Graphago: Accelerating SSD-based Graph Processing via Activity-Aware Graph Preprocessing

**Venue:** SC
**ID:** sc-2025-405
**Confidence:** low

## Problem
SSD-based graph processing suffers from read amplification due to mismatch between large SSD access granularity (4KB) and small vertex data size; existing solutions are inefficient.

## Motivation
Out-of-core graph processing on SSDs is cost-effective but I/O bound; activity-aware optimization can improve throughput and reduce overhead.

## Method
Graphago: dual-centrality activity prediction, activity-neighborhood ordering, and active-data-balanced partitioning to optimize graph storage and access patterns.

## Key Novelty
Activity-aware preprocessing achieves 4.8x speedup with reduced read amplification and I/O imbalance; reasonable preprocessing overhead.

## Contributions
1. Dual-centrality activity prediction model (local connectivity + global importance)
2. Activity-neighborhood graph ordering to minimize read amplification
3. Active-data-balanced partitioning for I/O load distribution
4. 4.8x speedup vs. SOTA SSD-based systems with improved I/O efficiency

## Limitations
SSD-specific; activity prediction accuracy depends on workload; preprocessing overhead not negligible for small graphs; limited to graph traversal.
