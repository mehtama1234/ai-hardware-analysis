# State Machine Orchestration of an HPC Workflow in Cloud

**Venue:** SC
**ID:** sc-2025-319
**Confidence:** low

## Problem Statement
Porting HPC workflows between cloud and on-premises environments is non-trivial; existing designs may not efficiently leverage cloud-native orchestration frameworks.

## Motivation
Uncertain HPC resource availability drives need for portable workflows; Kubernetes offers advanced orchestration but HPC workflows weren't designed around cloud-native patterns.

## Method
They took MuMMI, an ensemble workflow (a coordinated set of computational tasks), and redesigned it to run on Kubernetes, a cloud platform for managing containerized software. The redesign transformed it from traditional HPC (where tasks run tightly coupled on a supercomputer) to a cloud-native architecture where components can be independently deployed and scaled. They tested two coordination methods: service-based orchestration that uses shared filesystems to pass data between tasks, and event-driven orchestration where each completed task sends a message to trigger the next step.

## Key Novelty
Event-driven orchestration—where completed tasks automatically trigger the next step via messages—achieves better performance and lower cloud costs for HPC workflows compared to service-based coordination.

## Contributions
