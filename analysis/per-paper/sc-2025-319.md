# State Machine Orchestration of an HPC Workflow in Cloud

**Venue:** SC
**ID:** sc-2025-319
**Confidence:** low

## Problem Statement
Porting HPC workflows between cloud and on-premises environments is non-trivial; existing designs may not efficiently leverage cloud-native orchestration frameworks.

## Motivation
Uncertain HPC resource availability drives need for portable workflows; Kubernetes offers advanced orchestration but HPC workflows weren't designed around cloud-native patterns.

## Method
Redesign MuMMI ensemble workflow for Kubernetes: progression from traditional HPC to fully portable cloud variant; compare service/filesystem-based vs event-driven orchestration.

## Key Novelty
Systematic redesign of HPC workflow using event-driven cloud-native patterns; quantified performance and cost improvements from orchestration approach.

## Contributions
1. Event-driven orchestration design for MuMMI on Kubernetes
2. 62.24% faster CPU workflow; 40.29% faster GPU workflow completion
3. 45.0% CPU cost reduction; 38.3% GPU cost reduction
