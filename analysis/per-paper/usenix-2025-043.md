# IRHash: Efficient Multi-Language Compiler Caching by IR-Level Hashing

**Problem:** Compilation time is a bottleneck in multi-language software development, and existing compiler caches cannot effectively share compilation results across different programming languages and compiler frontends. Developers face repeated recompilation of semantically equivalent code across polyglot projects.

**Method:** IRHash compares code at the intermediate representation level—the standardized form that all compilers use between source code and machine code—rather than comparing the original source. It normalizes this intermediate form and computes a stable checksum (hash) for it. When the same checksum appears (whether from Python, Java, or another language), the cache retrieves and reuses the previously compiled result. This works because semantically equivalent code in different languages produces identical intermediate representations.

**Novelty:** Instead of matching source code, it matches the intermediate representation that all compilers use, so different languages can share compilation results.
