# Agentic HPC Tutor System

## Problem
HPC education lacks scalable, personalized instruction. Traditional methods require manual resource development and external APIs.

## Approach
Multi-agent tutoring with specialized LLM roles:
- Lesson planner: curriculum design
- Explainer: concept clarification
- Code scaffolder: guided programming
- Executor: run and validate code

Key features:
- Structured prompt composition (not traditional code)
- Per-agent history summarization
- Self-correcting generation
- On-premises deployment

## Deployment
- Runs on leadership-class supercomputers
- Scales from single-user to classroom
- No external APIs or subscriptions

## Impact
Demonstrates prompt-driven multi-agent design for domain education. Enables HPC centers to provide personalized tutoring at scale as a service.
