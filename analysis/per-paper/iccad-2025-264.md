# H3D: Heterogeneous Resources Aware Global Router for Face-to-Face Bonded 3D ICs

**Venue:** ICCAD  
**Paper ID:** iccad-2025-264

## Problem Statement
3D IC routing is challenging; existing pseudo-3D approaches separate intra-die and inter-die routing, degrading solution quality by not considering hybrid bonding terminal (HBT) resources jointly.

## Motivation
Face-to-face bonded 3D ICs introduce new routing resources and constraints; native 3D routing aware of HBT placement can improve quality.

## Method
H3D creates routing grids—maps of where wires can go and where hybrid bonding terminals (HBTs, the connection points between 3D chip layers) can be placed—then jointly optimizes routing and HBT placement rather than solving them separately. It applies dynamic programming (an algorithm breaking problems into reusable subproblems) with reverse depth-first and breadth-first search to find optimal wire paths and connection placement that form Steiner trees (minimal-cost structures connecting specified points in 3D space).

## Key Novelty
H3D is the first global router that jointly optimizes wire routing and hybrid bonding terminal placement—the connection points between 3D layers—in face-to-face bonded 3D circuits.

## Contributions

1. 12% wirelength reduction
2. 25% fewer HBTs
3. 1.9× speedup
