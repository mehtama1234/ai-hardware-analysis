# isscc-2025-069

**Title:** 19.3 A Fractional-N PLL with 34fsrms Jitter and -255.5dB FoM Based on a Multipath Feedback Technique

**Venue:** ISSCC

**Problem:** Advanced wireless (4K-QAM) demands sub-100 fs jitter PLLs; prior designs use expensive high-reference frequencies (150–500 MHz), impractical for mass deployment.

**Key Contribution:** Multipath feedback technique in analog PLL achieves 34 fs RMS jitter at practical 80 MHz reference frequency (7.5x lower than prior work).

**Method:** The design uses multipath feedback—routing the output signal back through multiple parallel paths instead of a single path—in an analog phase-locked loop (a circuit that synchronizes an output signal to an input reference clock). The parallel paths reduce the dead-zone (where the charge pump circuit stops responding) and reference spurs (unwanted frequency spikes from the reference clock), improving loop stability. This yields very low jitter—timing noise in the output signal—while using just an 80 MHz reference frequency, 7.5 times lower than previous low-jitter designs. The circuit produces output from 7.3 to 9.5 GHz.

**Hardware:** ASIC

**Metrics:** 34 fs RMS jitter, -255.5 dB FoM, 7.3–9.5 GHz output

**Techniques:** Circuit design

**Primary Theme:** Low-reference-freq PLL for cost-effective wireless
