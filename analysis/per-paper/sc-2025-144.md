# Compile-Time QoS Scheme for Deep Learning Inferences

**Venue:** SC 2025  
**Authors:** Sungin Hong, Hyunjun Kim, Hwansoo Han

## Problem
Accelerator sharing for multiple concurrent deep learning inference services requires maintaining Quality of Service (QoS) guarantees with strict target latency requirements. Inference requests consist of sequences of short-duration kernels, making online scheduling difficult and adding significant runtime overhead.

## Motivation
Inference services deployed in production require strict latency Service Level Agreements (SLAs). Online schedulers struggle with fine-grained kernel sequences and introduce overhead. Compile-time approaches could eliminate runtime scheduling burden by pre-computing resource partitioning strategies.

## Method
QoSlicer compile-time QoS management framework:

1. **Kernel Slicing:** Decompose inference kernels into slices with predetermined scheduling plans

2. **Plan Generation:** Compile-time heuristic search identifies multiple optimal slicing plans for different scenarios

3. **Performance Estimation:** Robust models validate plans meet target latency requirements

4. **Lightweight Runtime:** Online scheduler selects appropriate pre-computed plan without complex decision-making

5. **Multi-Workload Support:** Support diverse inference workloads and latency targets

## Key Novelty
Shifts QoS scheduling burden from runtime to compile-time through pre-computed kernel slicing plans, enabling lightweight, efficient online scheduling.

## Contributions
1. Compile-time kernel slicing framework for QoS guarantees
2. Heuristic search algorithm identifying optimal slicing plans
3. Robust performance estimation models validating latency requirements
4. 20.2% average throughput improvement across 75 diverse workload combinations
