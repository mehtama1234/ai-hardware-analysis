# Zebra: Efficient Redundant Array of Zoned Namespace SSDs Enabled by Zone Random Write Area (ZRWA)

**Venue:** HPCA 2025  
**Authors:** Tianyang Jiang, Guangyan Zhang, Xiaojian Liao, Yuqi Zhou

## Problem
Integrating ZNS SSDs into RAID configurations requires handling partial parity updates (PPUs) caused by ZNS's append-only write semantics; existing metadata-zone-based solutions become performance bottlenecks under high PPU workloads.

## Motivation
ZNS SSDs reduce device-level garbage collection overhead and provide predictable storage performance, but RAID configurations are severely limited by the latency of dedicated metadata zones required for PPU management.

## Method
Zebra exploits the Zone Random Write Area (ZRWA), the SSD's internal write buffer in front of each zone, to handle PPUs in-place. By ensuring parity chunks fit within the ZRWA window, Zebra performs partial parity overrides within the buffer rather than writing to separate metadata zones. Complementary reliability techniques maintain correctness across large-zone and small-zone ZNS SSD models.

## Key Novelty
Using the ZRWA (SSD's native write buffer) as in-place storage for parity partial updates in ZNS RAID, matching the repeated sequential overwrite I/O pattern of PPUs to the ZRWA's random-write capability.

## Contributions
- Zebra architecture mapping ZNS RAID PPUs to the ZRWA write buffer
- Analysis identifying repeated sequential overwrite as the dominant PPU I/O pattern
- Reliability techniques ensuring correctness under diverse ZNS RAID workloads
- 1.1x to 4.2x throughput improvement over RAIZN

## Results
- **Throughput:** 1.1x to 4.2x improvement vs RAIZN on micro and application benchmarks

## Hardware Target
Storage (ZNS SSD RAID)

## Limitations
Evaluation covers only two ZNS SSD models; ZRWA window size constraints may limit applicability with large parity chunks.
