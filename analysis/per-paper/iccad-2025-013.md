# WROXIM: A Network-Level Simulation Platform for Wavelength-Routed Optical Networks-on-Chip

**Venue:** ICCAD  
**ID:** iccad-2025-013

## Problem
Wavelength-routed optical NoCs (WRONoCs) lack network-level simulation tools for evaluating end-to-end communication despite having device/circuit-level simulators.

## Motivation
Network-level WRONoC simulation enables system-level design exploration and optimization for practical deployment.

## Method
WROXIM extends open-source Noxim with cycle-accurate optical component modeling (waveguides, serializers, deserializers, buffers) while maintaining electrical NoC compatibility.

## Key Novelty
First network-level WRONoC simulator combining optical and electrical component modeling with task-driven workloads.

## Contributions
1. Network-level simulation platform for WRONoCs adapted from Noxim
2. Cycle-accurate optical component modeling (waveguides, buffers, PEs)
3. Full electrical-optical integration for end-to-end data movement
4. Task-driven workload support with latency, throughput, energy metrics

## Limitations
Simulation platform only; no real silicon results; photonic component model fidelity not validated against silicon.
