# MAS-Attention: Memory-Aware Stream Processing for Attention Acceleration on Edge Devices

**ID:** mlsys-2025-038 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
On resource-constrained edge neural accelerators, attention acceleration methods (FLAT, oneDNN) execute MatMul and softmax sequentially on MAC and VEC units, leaving one unit idle at all times.

## Method
The approach breaks attention computation into small tiles and runs two separate processing streams in parallel: matrix multiplication (MatMul) on the multiply-accumulate (MAC) units and softmax (the normalization step) on the vector (VEC) units. Instead of running one after the other—which leaves one unit idle—these streams run overlapped in a semi-synchronized pipeline to keep both compute units busy simultaneously. The tile sizes (sub-matrices for MatMul and row-level chunks for softmax) are optimized offline using MCTS (Monte-Carlo Tree Search) and Genetic Algorithm to find the best configuration for the device. To prevent running out of on-chip memory during processing, the system proactively overwrites and reloads intermediate matrices (the K and V tiles) as needed, prioritizing softmax completion to avoid stalling the pipeline.

## Key Novelty
It's the first attention acceleration method to exploit edge devices' separate compute units (MAC and VEC) by running matrix multiplication and softmax in parallel semi-synchronized pipelines, combined with a proactive strategy that overwrites intermediate data to prevent cache overflow without stalling either stream.

## Metrics
- **Speedup:** Up to 2.75x over FLAT (simulated, geomean 1.70x); up to 1.76x on real Huawei DaVinci NPU (geomean 1.42x)
- **Energy:** 54% reduction vs FLAT (simulated, geomean 18.55%)
