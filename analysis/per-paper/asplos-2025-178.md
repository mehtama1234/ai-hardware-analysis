# asplos-2025-178: Gigaflow: Pipeline-Aware Sub-Traversal Caching for Modern SmartNICs

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
vSwitch offloading to SmartNICs suffers from high cache miss rates and poor scalability as the flow rule space grows. Existing solutions cannot efficiently store or traverse large, complex flow rule tables required by modern cloud tenants, bottlenecking packet processing throughput.

## Motivation
Modern public and edge clouds rely on high-performance end-host network stacks for diverse tenant workloads (distributed training, fast inference), making vSwitch SmartNIC offloading a key scalability lever, undermined by inability to handle growing flow rule spaces.

## Method
Gigaflow introduces pipeline-aware sub-traversal caching, decomposing multi-stage vSwitch pipelines into sub-traversals and caching intermediate traversal results rather than only complete flow lookups. By being aware of pipeline structure, Gigaflow identifies which sub-traversal results can be safely reused across multiple packets, reducing redundant flow rule table traversals and improving NIC cache hit rates even for large flow tables.

## Key Novelty
Pipeline-aware sub-traversal caching that caches intermediate pipeline stages rather than only full flow lookups, enabling scalable flow rule matching on SmartNICs with large flow tables.

## Contributions
- Pipeline-aware decomposition of vSwitch processing into cacheable sub-traversal units
- Sub-traversal caching mechanism improving hit rates for large flow rule spaces on SmartNICs
- Scalable flow rule matching for growing flow tables in modern multi-tenant clouds
- Improved throughput and reduced miss rates compared to existing SmartNIC offload solutions
