# asplos-2025-086 — MDPeek: Breaking Balanced Branches in SGX with Memory Disambiguation Unit Side Channels

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** Memory Disambiguation Unit side-channel attack on SGX

## Problem
Intel SGX enclaves are believed to be protected against control-flow side-channel attacks when software defenses balance branch execution paths; this paper discovers that the Memory Disambiguation Unit (MDU) inside modern Intel CPUs leaks information even through these balanced branches, creating a previously unknown side channel.

## Motivation
SGX is widely deployed for confidential computing, and a growing body of software defenses attempt to eliminate control-flow leakage by balancing branch paths, but undiscovered microarchitectural side channels in the MDU can silently defeat these defenses.

## Method
MDPeek exploits the Memory Disambiguation Unit (the CPU component that predicts whether memory operations will conflict, enabling parallel execution). By crafting memory access patterns dependent on secret values, the attacker makes the MDU predict differently for each secret, leaving observable timing traces. A spy process running on the same CPU measures these timing differences, leaking the secret despite defenses that balance both branches to take equal time.

## Key Novelty
MDPeek discovers that the Memory Disambiguation Unit (which predicts memory conflicts in the CPU) leaks secret-dependent timing variations, breaking SGX protections that balance branch execution time.

## Contributions
- Discovery and characterization of the Memory Disambiguation Unit (MDU) as a new SGX side-channel
- MDPeek attack that breaks balanced-branch software defenses for SGX enclaves
- Reverse engineering of MDU behavior on Intel CPUs to enable the attack
- End-to-end demonstration of information leakage from protected enclaves
