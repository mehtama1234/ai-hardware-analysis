# dac-2025-427: LLM-Based RTL Generation with RL-Guided PPA Optimization

**Problem:** RTL design requires early PPA commitment; mismatches discovered only after synthesis require costly redesign.

**Motivation:** LLMs enable hardware generation but lack goal-driven PPA optimization; flexible automation is essential.

**Method:** The tool uses an AI language model trained with reinforcement learning—where the model learns from reward signals—to generate hardware designs (RTL). After each generated design is converted to a circuit (synthesis), the tool measures the actual power consumption, speed, and chip area (PPA metrics) and feeds these measurements back as rewards to guide the model. This teaches the model to generate designs that hit specific optimization targets instead of discovering mismatches only after costly synthesis runs.

**Key Novelty:** RL integration with LLM-based RTL generation for PPA-aware automation.

**Contributions:**
- RL framework coupling LLMs with post-synthesis PPA rewards
- Single and multi-objective PPA optimization support
- Applicable across various application scenarios

**Hardware Target:** ASIC

**Confidence:** low (abstract-only)
