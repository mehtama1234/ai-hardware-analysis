# isscc-2025-160: Interface-Decoupled 380mV Ultra-Low-Voltage SRAM

**Problem:** Ultra-low-voltage SoC operation requires SRAM to accept logic supply (V_DD) lower than bitcell array minimum (V_DDA). Conventional level-shifters add large area/power overhead, preventing SRAM from achieving lowest SoC V_DD.

**Motivation:** Energy-critical systems maximize SoC savings at lowest logic voltage; SRAM should not constrain this optimization.

**Method:** Interface Dual-Rail (IDR) architecture decouples SRAM interface voltage (V_DD) from internal bitcell supply (V_DDA). Extended-range level shifter (ERLS) with integrated latches enables 380mV interface operation. Clock buffer bypass reduces level-shift overhead. V_DD tracks logic voltage independently.

**Key Novelty:** Interface dual-rail with extended-range level-shifter enabling SRAM voltage decoupling and 380mV interface operation.

**Contributions:**
- 380mV interface voltage (lowest reported)
- 38Mb/mm2 density (highest for 1-port)
- 1.3Mb capacity compiler
- Minimal ERLS area overhead

**Hardware Target:** ASIC

**Technique Categories:** memory-system, circuit-design, low-power

**Metrics:** 38Mb/mm2, 380mV, 1.3Mb, 3nm

**Baselines:** Conventional dual-rail SRAM, prior low-voltage designs

**Confidence:** low (abstract-only)
