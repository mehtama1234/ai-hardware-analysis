# hpca-2025-104 — GoPIM: GCN-Oriented Pipeline Optimization for PIM Accelerators

**Venue:** HPCA  
**Authors:** Siling Yang, Shuibing He, Wenjiong Wang, Yanlong Yin, Tong Wu, Weijian Chen, Xuechen Zhang, Xian-He Sun  
**Confidence:** low (abstract only)

## Problem
ReRAM-based PIM accelerators for GCN training suffer from pipeline underutilization due to skewed execution times across GCN stages and skewed vertex degree distributions causing crossbar resource imbalance.

## Motivation
GCNs require frequent memory access; ReRAM PIM offers in-situ computing to address the memory bottleneck, but naive pipelining fails to exploit full potential due to stage and vertex heterogeneity.

## Method
GoPIM uses machine learning to watch which pipeline stages are lagging and dynamically shifts ReRAM crossbar resources (physical computing elements) to the stage that needs them most at any moment. It also uses interleaved vertex mapping to spread graph nodes across multiple crossbars so that nodes with more connections don't all end up on the same resource. Together, these reduce execution time while maintaining accuracy.

## Key Novelty
The innovation is a machine-learning policy that dynamically shifts ReRAM crossbar resources to pipeline stages based on real-time bottlenecks, combined with interleaved vertex mapping to distribute graph nodes despite their skewed degree distributions (many nodes have far more connections than others).

## Contributions
- ML-based dynamic crossbar resource allocation to bottleneck GCN pipeline stages
- Selective vertex updating with interleaved crossbar mapping for skewed vertex degrees
- Practical GoPIM architecture design
- Up to 191x speedup and 16.1x energy saving vs. state-of-the-art
