# Exploring Dendritic Computation in Bio-Inspired Architectures for Dynamic Programming

**Venue**: DATE  
**Primary Theme**: neuromorphic graph algorithms  

## Problem
Finding shortest paths in graphs using bio-inspired neuromorphic architectures rather than conventional sequential algorithms. Neuromorphic systems offer alternative computational paradigm with different efficiency/latency tradeoffs.

## Method
Each graph node is represented by an artificial neuron with delay mechanisms (dendritic delay lines) that encode the cost of traveling along edges. When a signal originates from a starting node, it propagates through the network with delays proportional to edge costs; a backward-tracing method breaks the problem into sub-problems that are solved iteratively. The shortest path is identified by whichever neuron fires (sends its signal) earliest—since delays accumulate along paths, the first neuron to fire must be closest to the start. The system uses countdown counters to manage signal timing and eligibility traces to track and encode the edge costs into the delay values.

## Key Novelty
Using when neurons fire (spike timing) as the direct solution to shortest-path dynamic programming problems.

## Contributions
- Novel mapping of dynamic programming to dendritic spiking neural systems
- Demonstrated scalability on real-world graph instances
- FPGA prototyping on Virtex UltraScale validating approach
