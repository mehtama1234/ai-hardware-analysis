# Compute-In-Memory on FPGAs for Deep Learning: A Review

**Problem:** Deep learning acceleration on FPGAs suffers from a data movement bottleneck between memory blocks and compute units. FPGAs lack built-in compute-in-memory capabilities to mitigate this von Neumann bottleneck.

**Method:** This review provides a comprehensive overview of CIM and FPGA architectures, detailing how CIM can be implemented on FPGAs through modifications to memory blocks. It categorizes existing FPGA CIM proposals, explains architectural nuances for CIM block design, and synthesizes implementation approaches and current challenges.

**Novelty:** Comprehensive categorization and analysis of compute-in-memory implementations specifically optimized for FPGA memory block modifications and architectural constraints.
