# Compute-In-Memory on FPGAs for Deep Learning: A Review

**Problem:** Deep learning acceleration on FPGAs suffers from a data movement bottleneck between memory blocks and compute units. FPGAs lack built-in compute-in-memory capabilities to mitigate this von Neumann bottleneck.

**Method:** Compute-in-memory puts processing logic right inside memory blocks rather than having separate memory and processors that swap data back and forth. On FPGAs (reconfigurable chips), engineers modify the memory blocks already built into the chip to also perform calculations. Because computation happens where data lives, it eliminates the slow, energy-expensive data movement that creates a bottleneck in traditional computer designs.

**Novelty:** Using existing FPGA memory blocks as the foundation for compute-in-memory, adding computation capability to what's already there instead of requiring entirely new custom hardware.
