# ArtMem: Adaptive Migration in Reinforcement Learning-Enabled Tiered Memory

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Tiered memory systems struggle with three key inefficiencies: existing migration policies perform inconsistently across workloads, fail to adapt when the fast-tier access rate is low, and miss opportunities to tune migration scope dynamically based on workload patterns, causing unnecessary page migrations.

## Motivation
As DRAM capacity growth stalls and emerging applications demand more memory, tiered memory systems (mixing HBM/DRAM with NVM/CXL) become essential for data centers, but static or rule-based migration policies leave significant performance on the table.

## Method
ArtMem uses a learning algorithm (reinforcement learning) that watches how often the fast memory tier gets accessed and how data access patterns change during execution. Based on what it observes, the algorithm decides which data to keep in fast memory and which to move to slower tiers, how many pages to migrate at once, and when to stop migrating entirely if the fast tier isn't being heavily used. Instead of using fixed rules set beforehand, it learns what works best for each workload by trial and feedback, adapting its decisions as workload behavior evolves.

## Key Novelty
The innovation is using a learning agent that controls three interconnected decisions about memory migration—which strategy to use, how many pages to move, and whether to pause migrations—adapting them together in real time based on changing workload behavior.

## Contributions
1. Identification of three structural limitations in existing tiered memory migration solutions
2. RL-driven framework (ArtMem) that dynamically adapts migration strategy to workload evolution
3. Adaptive migration scope tuning based on fast-tier access rate feedback
4. 35-172% performance improvement over state-of-the-art tiering systems across diverse workloads
