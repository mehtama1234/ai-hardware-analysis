# Speculative Decoding for Verilog: Speed and Quality, All in One

## Summary
Syntax-aware tokenization and speculative decoding for LLM-based Verilog generation, improving both inference speed and code quality.

## Key Results
- **5.05x speedup** in Verilog code generation
- **17.19% pass@10 accuracy** improvement on RTLLM

## Core Innovation
First syntax-aware tokenization for LLMs that aligns decoding stops with Verilog syntactic boundaries, enabling speculative decoding to improve speed and quality simultaneously.

## Technique
Speculative decoding with tokens aligned to Verilog syntactic significance rather than subword boundaries; enables better pattern capture and faster generation.
