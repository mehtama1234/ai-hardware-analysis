# Hybrid SLC-MLC RRAM Mixed-Signal Processing-in-Memory Architecture for Transformer Acceleration via Gradient Redistribution

**Venue:** ISCA 2025
**Confidence:** high (full text read)

## Problem
Analog RRAM PIM with multi-level cells (MLC) offers 2x storage density and higher throughput than single-level cells (SLC), but MLC non-linearity causes catastrophic accuracy loss (up to 40%) in Transformer models. Brute-force hybrid SLC/MLC mapping fails because the error-tolerant fraction of weights is too small to yield meaningful efficiency gains.

## Motivation
Transformers are memory-bandwidth-limited; analog RRAM PIM can eliminate data movement and exploit massive bitcell-level parallelism, but accuracy sensitivity to MLC noise has prevented analog PIM from covering the dominant weight fraction.

## Method
HyFlexPIM implements a three-tier mixed-signal architecture: (1) digital SLC RRAM PIM handles Q·K^T and ×V attention operations that require high precision and frequent writes to real-time Q/K/V vectors, using NOR-based bit-serial operations; (2) analog SLC RRAM PIM stores the most critical static weight rows; (3) analog 2-bit MLC RRAM PIM handles the error-tolerant weight majority, using bitline current accumulation for GEMV with a flexible 6-b/7-b SAR-ADC that bypasses the MSB comparison capacitor in SLC mode (less than 1% area/energy overhead). The gradient redistribution algorithm applies SVD to each static weight matrix, truncates to a hard-threshold rank (preserving iso-computational cost), fine-tunes for 1-3 epochs with AdamW; fine-tuning naturally concentrates loss sensitivity into the top 5-10% of singular values, making SLC vs. MLC assignment unambiguous. All 24 processing units operate in pipelined fashion, one layer per PU, communicating via a 1000 GB/s on-chip interconnect and PCIe-6.0.

## Key Novelty
Gradient redistribution via SVD truncation followed by fine-tuning actively reshapes gradient distributions so that 90-95% of Transformer weights become MLC-compatible, enabling near-full MLC utilization with less than 1% accuracy loss.

## Contributions
1. Reconfigurable analog RRAM PIM module supporting SLC/MLC via a shared flexible 6-b/7-b SAR-ADC (ADC bypass for SLC, <1% area/energy overhead)
2. Three-tier mixed-signal architecture (digital RRAM for attention, analog SLC for critical weights, analog MLC for error-tolerant majority)
3. SVD-based gradient redistribution that concentrates weight importance into 5-10% of parameters through post-truncation fine-tuning
4. Max 1.86x throughput and 1.45x energy efficiency vs. ASADI (SOTA analog-digital hybrid PIM) with <1% accuracy loss on BERT/ViT and <10% loss increase on GPT-2/Llama3

## Hardware Target

## Technique Category

## Workloads
LLM-inference, transformer, attention, vision

## Key Metrics
- Speedup: 1.86x max throughput over ASADI
- Energy: 1.45x efficiency improvement over ASADI
- Area: 65nm node; <1% overhead for SLC/MLC reconfigurability
- Accuracy: <1% degradation (encoders, ViT); <10% loss increase (GPT-2, Llama3)
- SLC protection rate: 5-10% for encoders; 5-20% for decoders

## Baselines
- ASADI (FP32, SLC-only analog-digital hybrid PIM)
- ASADI† (INT8 variant of ASADI)
- SPRINT (digital processor + analog PIM for attention MSBs only)
- TransPIM (NMP with FIMDRAM + HBM)
- Non-PIM INT8 digital baseline

## Limitations
Optimized for inference only; SVD fine-tuning is a one-time preprocessing cost excluded from inference latency measurements; 65nm process node may not reflect current RRAM process feasibility.
