# AcclMT: A Highly Resource-Efficient and Flexible Poseidon Hash-Based Merkle Tree Architecture

**Venue:** DAC
**ID:** dac-2025-233

## Problem
Zero-knowledge proof systems (zkSTARK) rely on Poseidon hash-based Merkle trees; hashing dominates runtime. GPU/CPU-based hashing is inefficient; FPGA acceleration exists but underutilizes modular multiplication units.

## Motivation
ZKP protocols are computationally intensive; efficient Merkle tree construction is critical for practical proof generation and verification.

## Method
The solution runs the Poseidon hash algorithm on an FPGA (a chip that can be rewired to solve different problems), with hardware and software designed together to move data smoothly through the pipeline. Instead of building many separate multipliers for modular math (which wastes chip space), the design reuses one multiplier repeatedly, accomplishing the same work in less area. Intermediate results are stored in hierarchical caches on the chip (like layers of faster memory), so frequent lookups stay fast. The system schedules work to keep every stage of the pipeline busy, letting it build large Merkle trees efficiently with flexible parameters.

## Key Novelty
The key innovation is to accelerate Merkle tree construction by reusing the modular multiplier within each Poseidon hash and caching intermediate results on the chip.

## Contributions

- 14.3x faster Poseidon hash engine than latest FPGA work
- 14.8% area reduction through improved resource utilization
- 1665x speedup over software implementations
- 95.9% and 99.2% hardware utilization on dual hash engines
