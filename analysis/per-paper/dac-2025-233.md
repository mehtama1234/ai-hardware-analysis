# AcclMT: A Highly Resource-Efficient and Flexible Poseidon Hash-Based Merkle Tree Architecture

**Venue:** DAC
**ID:** dac-2025-233

## Problem
Zero-knowledge proof systems (zkSTARK) rely on Poseidon hash-based Merkle trees; hashing dominates runtime. GPU/CPU-based hashing is inefficient; FPGA acceleration exists but underutilizes modular multiplication units.

## Motivation
ZKP protocols are computationally intensive; efficient Merkle tree construction is critical for practical proof generation and verification.

## Method
FPGA-based hardware acceleration combining hardware-software co-design for optimized dataflow, area-efficient Poseidon hash engine with improved modular multiplier reuse, hierarchical on-chip caching, and optimized task scheduling for building large trees with flexible parameter support.

## Key Novelty
Hardware-optimized Poseidon hash engine exploiting modular multiplier reuse and hierarchical caching for efficient Merkle tree construction.

## Contributions

- 14.3x faster Poseidon hash engine than latest FPGA work
- 14.8% area reduction through improved resource utilization
- 1665x speedup over software implementations
- 95.9% and 99.2% hardware utilization on dual hash engines
