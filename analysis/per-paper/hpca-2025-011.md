# Efficient Caching with A Tag-enhanced DRAM
**Venue:** HPCA 2025 | **ID:** hpca-2025-011 | **Confidence:** low (abstract only)

## Problem
DRAM-based caches (HBM3-as-cache) suffer from high miss penalties due to two-step tag-then-data access, wasted data movement on misses (data fetched then discarded), and data bus turnaround delays from dirty eviction before new data fetch. Existing DRAM cache designs cannot perform in-DRAM tag comparison or conditional data response.

## Motivation
SRAM caches are hitting a scaling wall, driving DRAM-based caches for large-footprint workloads, but DRAM cache performance is limited by the fundamental mismatch between DRAM architecture and cache semantics (tag checks, conditional data return, dirty management).

## Method
TDRAM adds small low-latency tag/metadata mats to the HBM3 die alongside data mats, enabling lockstep tag-and-data access, in-DRAM tag comparison, and conditional data response (data transferred only on hit). Opportunistic early tag probing starts tag lookups before the full DRAM row is available, reducing hit and miss latency. An in-DRAM flush buffer stores conflicting dirty data on write misses, eliminating data bus turnaround delays.

## Key Novelty
Adding on-die low-latency tag mats to HBM3 enabling in-DRAM tag comparison and conditional data response, replicating SRAM cache semantics (no wasted bandwidth on miss) in a DRAM-based cache.

## Contributions
1. TDRAM microarchitecture: on-die tag mats for in-DRAM tag comparison and conditional data response
2. Opportunistic early tag probing reducing hit and miss latencies
3. In-DRAM flush buffer eliminating data bus turnaround delays on write misses
4. 2.65x faster tag checks, 1.23x speedup, 21% energy reduction vs state-of-the-art DRAM caches

## Metrics
- **Speedup:** 1.23x vs state-of-the-art commercial and research DRAM cache designs
- **Energy:** 21% less energy
- **Other:** 2.65x faster tag checks
