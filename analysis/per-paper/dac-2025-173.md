# ATLAS: A Self-Supervised and Cross-Stage Netlist Power Model for Fine-Grained Time-Based Layout Power Analysis

**Problem:** Accurate power prediction requires slow back-end simulation; delays design optimization.

**Solution:** Self-supervised deep learning model predicting layout-stage power from gate-level netlist without layout information.

**Results:** <1% total power MAPE (0.58% clock tree, 0.45% register, 5.12% combinational); much faster than commercial tools.

**Theme:** Fast multi-stage power modeling via machine learning.
