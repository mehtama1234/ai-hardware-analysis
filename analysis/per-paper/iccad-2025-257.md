# (Invited) FENIX: Flexible and Efficient Hybrid HE/MPC Acceleration with Near-Memory Processing

**Venue:** ICCAD  
**Paper ID:** iccad-2025-257

## Problem Statement
Hybrid homomorphic encryption (HE) and multi-party computation (MPC) for private transformer inference suffers from high computation cost due to suboptimal protocol integration and hardware inefficiencies.

## Motivation
Private inference requires combining HE for linear operations and oblivious transfer (OT) for nonlinear operations, creating complex scheduling and memory access patterns.

## Method
FENIX employs protocol-hardware co-design: fine-grained OT partitioning to overlap HE and OT operations, flexible batch encoding for computation-storage tradeoffs, and near-memory processing (NMP) to offload memory-bound HE/OT computations.

## Key Novelty
Protocol-hardware co-design combining fine-grained operation scheduling with near-memory acceleration for hybrid HE/MPC inference.

## Contributions

1. Fine-grained OT partitioning
2. Flexible batch encoding
3. Near-memory processing offload
