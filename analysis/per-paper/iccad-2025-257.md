# (Invited) FENIX: Flexible and Efficient Hybrid HE/MPC Acceleration with Near-Memory Processing

**Venue:** ICCAD  
**Paper ID:** iccad-2025-257

## Problem Statement
Hybrid homomorphic encryption (HE) and multi-party computation (MPC) for private transformer inference suffers from high computation cost due to suboptimal protocol integration and hardware inefficiencies.

## Motivation
Private inference requires combining HE for linear operations and oblivious transfer (OT) for nonlinear operations, creating complex scheduling and memory access patterns.

## Method
FENIX co-designs the encryption algorithm with specialized hardware. It breaks oblivious transfer (a secure communication protocol) into small pieces that overlap with homomorphic encryption (computation on encrypted data), and uses flexible batch encoding to balance storage and computation speed. Specialized processors placed near memory accelerate the memory-intensive encryption operations.

## Key Novelty
The core idea is co-designing the encryption algorithm with specialized hardware positioned near memory, enabling fine-grained operation scheduling that overlaps encrypted operations for greater efficiency.

## Contributions

2. Flexible batch encoding
3. Near-memory processing offload
