# Hypnos: Memory Efficient Homomorphic Processing Unit

**Venue:** DAC  
**ID:** dac-2025-349

## Problem
FHE accelerators using Host+ACC topology neglect PCIe bus inefficiency and irregular memory access patterns, leading to data-movement bottleneck rather than computation-bound performance.

## Motivation
FHE's computational intensity and large encrypted data volumes create critical memory-movement bottleneck in current accelerator designs.

## Key Innovation
Paged memory management system tailored to FHE's irregular data access patterns, abstracting operations into memory-efficient commands that minimize off-chip communication.

## Method
Hypnos simplifies fully homomorphic encryption operations (computation on encrypted data) into memory-efficient commands. It pairs these with a paged memory management system—like how computers use virtual memory—that intelligently stages encrypted data between main memory and on-chip caches based on homomorphic encryption's irregular data access patterns. This approach eliminates the constant data movement and waiting time that slows down older accelerators, which assume all encrypted data must stay on-chip.

## Contributions
- FHE operator abstraction into memory-efficient command streams
- Paged memory management system for FHE-specific access patterns
- Architecture optimizing cache and memory hierarchy
- 2.58x speedup vs ASIC, 4.43x vs FPGA; 3.78x communication reduction

## Results
2.58x speedup vs CraterLake ASIC, 4.43x vs Poseidon FPGA; 27.6x-19.06x energy efficiency gain.
