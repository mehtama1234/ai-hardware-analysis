# "OOPS!": Out-Of-Band Remote Power Side-Channel Attacks on Intel SGX and TDX

**Venue:** DAC | **ID:** dac-2025-257

## Problem
Intel's MSR filtering defense prevents in-band power attacks on confidential computing (SGX/TDX), but out-of-band (OOB) management interfaces expose energy readings outside this protection, enabling new attack vectors.

## Key Innovation
First exploitation of OOB management interfaces to bypass in-band power-side-channel defenses by accessing Package Configuration Space (PCS) energy readings for cryptographic key extraction.

## Attack Method
1. Reverse-engineer OOB communication protocol
2. Access PCS energy readings outside MSR filtering scope
3. Synchronize in-band execution with OOB measurements via deliberately-disabled MSRs
4. Extract cryptographic keys via power analysis

## Results
- RSA-2048 key recovery from SGX MbedTLS (with single-step assumption)
- AESNI key extraction from TDX (no single-step assumption needed)
- Demonstrates necessity of evaluating combined in-band + out-of-band threat model

## Hardware Target
CPU (Intel Sapphire Rapids)

## Techniques
Security, side-channel analysis

## Limitations
Requires access to out-of-band management interface; not applicable to systems without OOB exposure.
