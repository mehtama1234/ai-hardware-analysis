# Hybrid Token Selector based Accelerator for ViTs

**Venue:** DATE | **ID:** date-2025-376

## Problem
Vision Transformers have quadratic token complexity; token selection reduces computation but early-layer pruning causes accuracy loss while late-layer pruning limits savings.

## Motivation
ViTs face quadratic complexity bottleneck; efficient token pruning with accuracy preservation is essential for practical deployment.

## Approach
Hybrid Token Selection combining Keypoint-based Token Selection (KTS) in early layers + Attention-based Token Selection (ATS) in later layers + custom hardware acceleration modules.

## Key Innovation
Multi-layer hybrid token selection integrating content-aware and attention-aware pruning with co-designed hardware.

## Results
- 35.85% execution time reduction
- 6.05% GFLOP savings
- +0.39% accuracy improvement

## Target Hardware
ASIC (custom accelerator)

## Techniques
Sparsity (token pruning), kernel-fusion (hardware acceleration)

## Workload
Vision Transformers (image classification)

**Low** (abstract-only analysis)
