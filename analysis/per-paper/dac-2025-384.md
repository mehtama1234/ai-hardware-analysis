# NSFlow: An End-to-End FPGA Framework with Scalable Dataflow Architecture for Neuro-Symbolic AI

**Venue:** DAC
**ID:** dac-2025-384

## Problem
Neuro-Symbolic AI workloads exhibit heterogeneous kernels and unique memory access patterns unsuitable for general-purpose ML accelerators (CPU/GPU/TPU).

## Motivation
NSAI systems integrate neural networks and symbolic reasoning; their distinctive computation and memory patterns require specialized acceleration.

## Method
NSFlow analyzes how data flows through a Neuro-Symbolic AI workload and creates an optimized dataflow (the most efficient path for data to travel through computations). It reconfigures an FPGA array (a reprogrammable hardware chip) to execute that dataflow, adjusting which computing units are active, how memory is organized, and numerical precision (bits per number) to match the workload.

## Key Novelty
NSFlow automatically generates optimized FPGA hardware by analyzing the data flow patterns (what computations depend on what data) in Neuro-Symbolic AI workloads, enabling end-to-end system acceleration.

## Contributions
1. Design architecture generator identifying workload dependencies and creating optimized dataflow architectures
2. Reconfigurable FPGA array with flexible compute units, memory reorganization, and mixed-precision
3. 31x speedup over Jetson TX2, >2x over GPU, 8x over TPU-like systolic array, >3x over Xilinx DPU
4. Enhanced scalability: only 4x runtime increase when symbolic workloads scale by 150x
