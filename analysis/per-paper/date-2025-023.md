# date-2025-023: Efficient SAT-Based Bounded Model Checking of Evolving Systems

## Problem
Current SAT-based verification tools reverify systems from scratch after each design modification, even when changes are small. This wastes computation since prior verification results could inform later verification rounds.

## Method
Verification of hardware designs like RISC-V cores uses bounded model checking—testing whether bugs can occur within a limited number of steps—via a SAT solver, a tool that systematically searches for failure scenarios. When a design is modified, PrediCore doesn't restart this search from scratch; instead it saves the logical impossibilities and constraints the SAT solver learned from the previous design and feeds them to the solver for the next version of the SystemVerilog code. This lets the solver skip redundant work and accelerates verification.

## Contributions
- PrediCore tool for incremental bounded model checking
- Significantly improved verification time on later system versions
- Public benchmark set based on real edit history for open-source RISC-V cores

## Results
PrediCore significantly improves verification time required for properties on later versions of RISC-V cores compared to verify-from-scratch approach.
