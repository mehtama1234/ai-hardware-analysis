# Streaming X-ray Detector Data to Remote Facilities Using EJFAT

**ID**: sc-2025-375
**Venue**: SC
**Confidence**: low

## Problem
Real-time transfer and analysis of high-throughput scientific data to remote facilities

## Motivation
Emerging hardware and scale challenge existing approaches

## Method
The system uses an FPGA (specialized hardware that can be quickly customized to handle specific tasks) to rapidly move X-ray detector data across the network. It integrates this transport layer with EPICS, a widely-used framework that controls and monitors scientific experiments. The FPGA accelerates the data transfer, while EPICS coordinates everything and ensures detector data flows continuously in real time to remote facilities, letting scientists analyze results as soon as they arrive.

## Key Novelty
This is the first integration of EJFAT (a detector data transport system) with EPICS (the standard experiment control framework) for real-time streaming of X-ray detector data to remote facilities.
