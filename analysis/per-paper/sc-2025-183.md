# SC-2025-183: Teaching Task-Based Parallel Programming

**Venue:** SC 2025  
**Authors:** Vivek Kumar  
**Confidence:** low (abstract only)

## Summary

Educational paper describing the Parallel Runtimes for Modern Processors (PRMP) course at IIIT Delhi, teaching task-based parallel programming through implementation of runtime systems.

## Hardware Target

- Multicore Processors

## Problem & Motivation

Explicit multithreading on multicore processors imposes significant complexity in work organization and load balancing. Task-based models abstract this complexity, but teaching such models effectively requires understanding the underlying runtime systems.

## Approach

Course structure combining:
1. Introduction to async-finish task-based programming model
2. Student implementation of general-purpose dynamic load-balancing runtime
3. Iterative improvements to address modern processor architecture challenges
4. Progression from basic to advanced concepts

## Key Contributions

1. Structured curriculum for task-based parallel programming education
2. Implementation-focused learning approach
3. Runtime systems design and optimization experience
4. Course evaluation showing improved student understanding
5. Demonstrated scalability and performance gains

## Limitations

Primarily educational focus; no novel algorithmic contributions. Quantitative metrics limited in abstract.
