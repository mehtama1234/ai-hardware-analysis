# Distributed-HISQ: A Distributed Quantum Control Architecture

**Venue:** MICRO  
**Confidence:** high (full text)

## Problem
Distributed quantum control architectures for superconducting qubits face two blockers: lock-step synchronization schemes incur large execution overheads, and existing quantum ISAs are either too high-level or too hardware-specific to support diverse qubit technologies on a single microarchitecture.

## Motivation
Fault-tolerant quantum computing requires thousands to millions of qubits, making distributed control inevitable, yet nondeterministic feedback loop latencies demand cycle-accurate cross-controller synchronization that current schemes cannot provide efficiently.

## Method
Distributed-HISQ combines two mechanisms. HISQ is a hardware instruction set extending RISC-V 32I that represents quantum operations as timed commands: 'send codeword X to port Y at time T'—this separation lets the same instructions work across different quantum hardware and electronics implementations. BISP (Booking-based Instruction Synchronization Protocol) eliminates synchronization overhead by letting controllers reserve their sync points in advance instead of requesting sync on demand; since quantum gates run for a fixed, known duration, the system can send synchronization messages during this execution time, achieving zero-cycle overhead when the preceding operations are long enough to hide communication delays. The system connects controllers using a hybrid tree-and-mesh network topology: a balanced tree handles region-level synchronization, while mesh-like links mirroring the physical qubit layout handle nearest-neighbor synchronization, with only 13 LUTs per SyncU hardware cost on an FPGA.

## Key Novelty
BISP (Booking-based Instruction Synchronization Protocol) lets controllers pre-announce their synchronization points in advance, hiding the communication delay under the fixed-duration execution of preceding quantum gates and enabling zero-cycle synchronization overhead in the common case.

## Contributions
1. HISQ: hardware-agnostic quantum ISA extension to RISC-V decoupling control from quantum semantics
2. BISP: booking-based sync protocol with potentially zero-cycle overhead, implemented in only 13 LUTs
3. Validation on commercial 66-qubit superconducting quantum control system (DQCtrl)
4. 22.8% average program execution time reduction and ~5x infidelity reduction vs. lock-step baseline

## Hardware Target
FPGA

## Metrics
- Speedup: 22.8% execution time reduction vs. lock-step baseline
- Fidelity: ~5x infidelity reduction for long-range CNOT circuits
- Area: BISP SyncU = 13 LUTs; full HISQ control board = 4155 LUTs, 6392 FFs, 2.46 Mb BRAM

## Baselines
- IBM-style lock-step synchronization (central controller broadcast)

## Limitations
Region-level synchronization not achievable in physical prototype due to limited LVDS connectivity; baseline analysis assumes idealized constant communication latency.
