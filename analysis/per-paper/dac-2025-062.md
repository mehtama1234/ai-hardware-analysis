# FastPath: A Hybrid Approach for Efficient Hardware Security Verification

**Venue:** DAC | **Confidence:** Low (abstract-only)

## Problem
Microarchitectural information leakage verification methods suffer individual weaknesses: formal methods lack scalability, simulation lacks exhaustiveness, and existing approaches have limited flexibility for changing security requirements.

## Motivation
Verification methods for detecting information leakage in hardware designs must be simultaneously scalable, exhaustive, and flexible to meet diverse and evolving security requirements.

## Method
FastPath combines simulation efficiency with formal verification exhaustiveness via a hybrid methodology that employs structural analysis to automate the verification process, enabling practical deployment in existing verification flows.

## Key Novelty
Hybrid simulation-plus-formal verification framework with structural automation for microarchitectural security verification.

## Contributions
- Hybrid verification methodology combining simulation efficiency and formal exhaustiveness
- Structural analysis framework to automate security verification
- Significant reduction in manual effort while maintaining exhaustive confidence
- Discovery and fix of previously unknown operand leak in cv32e40s RISC-V processor

## Metrics
- Significant reduction in manual verification effort with same exhaustiveness level

## Baselines
- State-of-the-art formal verification approaches, Simulation-based methods

## Limitations
Evaluation focused on security verification workflow integration without detailed scalability metrics.
