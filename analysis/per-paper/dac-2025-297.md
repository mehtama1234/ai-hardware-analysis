# VSpGEMM: Exploiting Versal ACAP for High-Performance SpGEMM Acceleration

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
Sparse matrix-matrix multiplication (SpGEMM) in DNN/HPC has irregular access patterns creating communication and computation bottlenecks; storage overhead and intermediate product merging are critical pain points.

## Core Method
Hardware accelerator on Xilinx Versal ACAP using AI Engines (AIEs) + programmable logic (PL). Introduces BCSX block-wise storage enabling fixed-pattern memory access. Multi-level tiling decomposes SpGEMM into AIE-friendly granularities. Hybrid AIE/PL orchestration handles intermediate product merging.

## Key Contribution
BCSX block-wise storage + multi-level tiling + hybrid AIE/PL orchestration for efficient SpGEMM on heterogeneous ACAP.

## Results
- 2.65× speedup over SOTA GEMM on Versal
- 33.62× energy efficiency vs cuSPARSE on RTX 4090
