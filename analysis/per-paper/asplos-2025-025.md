# Instruction-Aware Cooperative TLB and Cache Replacement Policies

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** cooperative instruction-aware TLB and cache replacement for server workloads

## Problem
Modern server and data center applications have large instruction footprints causing frequent instruction-side TLB and cache misses. Instruction TLB misses are particularly harmful because they cause pipeline stalls, and existing replacement policies treat instruction and data streams equivalently.

## Motivation
As server applications grow in code size, instruction working sets no longer fit in iTLBs and iCaches, making instruction-side misses a dominant performance bottleneck in production workloads.

## Method
Instruction-aware cooperative replacement policies that distinguish instruction from data accesses in both TLB and cache. The cooperative approach coordinates eviction decisions between iTLB and iCache, so evicting a page from one structure informs or triggers corresponding decisions in the other, reducing redundant refills. Replacement is guided by instruction-access frequency and recency.

## Key Novelty
Cooperative replacement policies that jointly manage iTLB and iCache evictions using instruction-access awareness, preventing the two structures from independently evicting and refilling the same instruction working set.

## Contributions
- Analysis quantifying instruction TLB and cache misses as a dominant server/data center bottleneck
- Instruction-aware replacement policy distinguishing instruction vs. data access patterns
- Cooperative iTLB-iCache replacement framework coordinating eviction decisions across both structures
- Performance evaluation on server workloads showing reduced instruction miss rates
