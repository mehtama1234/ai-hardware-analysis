# iG-kway: Incremental k-way Graph Partitioning on GPU

**Authors:** Wan-Luan Lee, Shui Jiang, Dian-Lun Lin, Che Chang, Boyang Zhang, Yi-Hua Chung, Ulf Schlichtmann, Tsung-Yi Ho  
**Venue:** DAC 2025

## Summary
iG-kway is the first GPU-based incremental k-way graph partitioner designed for iterative CAD applications. It uses incrementality-aware data structures and refinement kernels to efficiently update only affected vertices, achieving 84x speedup over G-kway with comparable partitioning quality.

## Key Contributions
- First GPU-accelerated incremental k-way partitioner
- Incrementality-aware data structures for efficient updates
- Specialized refinement kernel preserving partitioning quality
- 84x speedup over G-kway

## Technical Approach
Unlike full-graph partitioning, iG-kway maintains an incrementality-aware data structure that efficiently tracks which vertices and edges are affected by graph modifications. The refinement kernel operates only on these affected regions, achieving massive speedups while maintaining comparable partition quality to full re-partitioning.
