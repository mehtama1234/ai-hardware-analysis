# dac-2025-284: CIMFlow—Framework for Digital CIM Design and Evaluation

**Problem:** Digital CIM architectures lack comprehensive design and evaluation frameworks; capacity constraints make CIM adoption and optimization difficult.

**Motivation:** CIM addresses memory wall for energy-efficient DNN acceleration; unified framework reduces design complexity.

**Method:** CIMFlow provides a complete workflow for designing neural network accelerators using compute-in-memory (CIM)—a technique that calculates data where it's stored, eliminating slow memory access. It works by connecting two usually separate steps: converting neural network code into hardware instructions, and simulating those instructions on hardware. This connection is made through a flexible instruction set—the customizable set of operations the hardware can perform—so designers can quickly test different design options. To handle compute-in-memory's main limitation (limited storage space), the framework automatically splits neural network calculations into smaller pieces and runs them in parallel, ensuring everything fits in available memory.

**Key Novelty:** Unified framework with partitioning strategies specifically addressing digital CIM capacity constraints.

**Contributions:**
- End-to-end CIMFlow workflow for DNN implementation
- Flexible ISA design connecting compilation and simulation
- Advanced partitioning for CIM capacity handling
