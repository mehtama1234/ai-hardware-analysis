# FATE: Boosting the Performance of Hyper-Dimensional Computing Intelligence with Flexible Numerical DAta TypE

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
HDC requires high-precision representations for cosine similarity calculations, making multiplication-heavy computation expensive on resource-constrained edge FPGAs. Binary HDC reduces cost but degrades accuracy significantly.

## Motivation
HDC is attractive for edge ML due to its light-weight, parallel nature and robustness, but the precision-efficiency tension has not been resolved—existing approaches apply uniform quantization across all dimensions.

## Method
FATE assigns different numerical precision (how many bits are used to represent each number) to different dimensions of hypervectors, using lower precision for less-important dimensions and higher precision for important ones. It also skips computations on near-zero values (a technique called sparsity) to reduce the overall computational work. Designed for embedded FPGAs, this approach achieves high accuracy while using fewer bits on average than standard systems that apply the same precision uniformly across all dimensions.

## Key Novelty
FATE breaks from the standard practice of uniform numerical precision by assigning different precision levels to different dimensions of hypervectors, exploiting the fact that some dimensions contribute more than others to enable sparse computation and faster FPGA performance.

## Contributions
- Per-dimension flexible numerical data type assignment for HDC
- Integration of sparsity with mixed-precision quantization for FPGA cost reduction
- Demonstrated accuracy-efficiency balance on embedded FPGA
