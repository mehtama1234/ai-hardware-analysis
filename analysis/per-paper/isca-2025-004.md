# FATE: Boosting the Performance of Hyper-Dimensional Computing Intelligence with Flexible Numerical DAta TypE

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
HDC requires high-precision representations for cosine similarity calculations, making multiplication-heavy computation expensive on resource-constrained edge FPGAs. Binary HDC reduces cost but degrades accuracy significantly.

## Motivation
HDC is attractive for edge ML due to its light-weight, parallel nature and robustness, but the precision-efficiency tension has not been resolved—existing approaches apply uniform quantization across all dimensions.

## Method
FATE introduces per-dimension mixed numerical data types for HDC, assigning different quantization bitwidths to different hypervector dimensions based on their importance. Combined with sparsity, this targets embedded FPGA deployment and exploits the observation that not all HDC dimensions contribute equally, enabling high-accuracy inference at lower average precision than uniform quantization.

## Key Novelty
FATE applies different numerical data types to different HDC hypervector dimensions, breaking from the uniform-quantization paradigm to jointly exploit dimension-level importance heterogeneity and sparsity.

## Contributions
- Per-dimension flexible numerical data type assignment for HDC
- Integration of sparsity with mixed-precision quantization for FPGA cost reduction
- Demonstrated accuracy-efficiency balance on embedded FPGA
