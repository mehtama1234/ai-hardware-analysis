# Optimizing Deep Learning Inference Efficiency through Block Dependency Analysis

**ID:** asplos-2025-036  
**Venue:** ASPLOS  
**Confidence:** low (abstract-only)  
**Primary Theme:** Block-granularity dependency analysis for inter-operator DNN compiler optimization

## Problem
ML compilers perform data dependency analysis at element or operator granularity, which creates overly complex inter-operator dependencies that block efficient fusion and overlap, and obscures parallelizable computation opportunities, leaving significant GPU utilization on the table.

## Motivation
Suboptimal inter-operator optimization in production DNN compilers like TensorRT and MIGraphX leads to underutilized GPU resources and excess memory traffic during inference, with no existing framework reasoning at an intermediate block granularity to bridge operator-level and element-level analysis.

## Method
BlockDepend is an ML compiler tool that analyzes how computations depend on each other at the block level—a middle ground between tracking individual data elements and whole operations. It groups computation into blocks, identifies which blocks need data from which others, and simplifies the dependency graph. This reveals opportunities to fuse operations that produce and consume each other's data, to reuse data in shared GPU memory, and to run independent work in parallel. The compiler uses these insights to reduce data movement and schedule parallel work across different GPU compute units.

## Key Novelty
BlockDepend simplifies how ML compilers track which operations depend on which others by analyzing blocks of computation instead of individual elements or operations, which reveals hidden opportunities for parallel work and data reuse, achieving up to 2.88x speedup over production compilers.

## Contributions
- Block-level dependency analysis framework integrated into the ML compiler lower-level compilation phases.
- Simplification of complex inter-operator dependency graphs by reasoning at tile granularity.
- Discovery of previously hidden parallelizable computation opportunities across operator boundaries.
- Demonstrated speedups of 1.71x over NVIDIA TensorRT and 2.88x over AMD MIGraphX across various workloads.
