# ILP-Driven FPGA Multiplier Synthesis: A Scalable Framework for Area-Latency Co-Optimization

**ID:** iccad-2025-242

## Problem
Multiplier design in Xilinx FPGAs requires manual tuning for area-latency trade-offs. Existing approaches lack systematic optimization frameworks.

## Motivation
Multipliers are critical components in DSP designs; automated co-optimization improves design quality and reduces engineering time.

## Method
The approach uses integer linear programming—a mathematical technique for finding optimal solutions to problems with whole-number constraints—to automatically design multipliers (arithmetic circuits) for Xilinx FPGAs. Rather than manual tuning, it systematically explores the complete range of efficient speed-versus-size combinations (the Pareto frontier, where you cannot improve both dimensions at once). The resulting designs achieve 27.8% faster operation and use 21.4% fewer lookup tables (LUTs—the basic configurable building blocks in FPGAs) compared to hand-designed baselines.

## Key Novelty
The core idea is using mathematical optimization (integer linear programming) to automatically find the best multiplier designs for FPGAs by balancing speed and chip area.
