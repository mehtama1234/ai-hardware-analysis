# ILP-Driven FPGA Multiplier Synthesis: A Scalable Framework for Area-Latency Co-Optimization

**ID:** iccad-2025-242

## Problem
Multiplier design in Xilinx FPGAs requires manual tuning for area-latency trade-offs. Existing approaches lack systematic optimization frameworks.

## Motivation
Multipliers are critical components in DSP designs; automated co-optimization improves design quality and reduces engineering time.

## Method
Integer Linear Programming (ILP) formulation for FPGA multiplier synthesis targeting Xilinx architectures. Automatically searches area-latency Pareto frontier. Achieves 27.8% delay reduction and 21.4% LUT savings over baseline designs.

## Key Novelty
ILP-based automated multiplier synthesis with systematic area-latency co-optimization for FPGAs.
