# Architecting Value Prediction around In-Order Execution

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
In-order processors suffer from stalls when long-latency instructions block younger independent instructions from issuing, and the compiler cannot always find sufficient independent work to fill the pipeline. Conventional branch prediction techniques fail to resolve hard-to-predict (delinquent) branches quickly enough to prevent pipeline bubbles.

## Motivation
In-order pipelines offer area/power advantages over out-of-order designs, but their performance falls short because the simplicity that makes them efficient also makes them vulnerable to cache misses and branch mispredictions—value prediction can bridge this gap without requiring full OOO machinery.

## Method
The paper integrates both address-based value prediction and direct value prediction into an in-order pipeline (based on a scaled-up CVA6 RISC-V core), exploiting the property that in-order execution allows aggressive value speculation without recovery penalties. A reworked cache hierarchy adds a fast first-level cache that can be written speculatively. A 32-entry scoreboard 4-issue in-order pipeline is augmented without full register renaming or out-of-order memory hazard handling.

## Key Novelty
Demonstrating that in-order execution's deterministic instruction ordering enables penalty-free aggressive value speculation, achieving near-OOO performance without register renaming or out-of-order memory hazard resolution.

## Contributions
1. First study of both address-based and direct value prediction integrated into an in-order pipeline
2. Analysis showing that in-order execution properties enable speculation without recovery penalty
3. Reworked speculative-write fast L1 cache hierarchy for in-order processors
4. 38.4% geomean IPC improvement over baseline in-order CVA6, reaching 86.7%/46.3% of the gains from comparable 32/16-entry and 64/32-entry ROB OOO processors
