# MemSens: Significantly Reducing Memory Overhead in Adjoint Sensitivity Analysis Using Novel Error-Bounded Lossy Compression

**Problem:** Adjoint sensitivity analysis requires storing all state at each time step, causing prohibitive memory costs for large systems.

**Solution:** Error-bounded lossy compression exploiting spatiotemporal data characteristics while maintaining adjoint accuracy.

**Results:** 100x memory overhead reduction with preserved solution accuracy.

**Theme:** Memory-efficient simulation via controlled lossy compression.
