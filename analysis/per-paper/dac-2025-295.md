# Approximate SMT Counting Beyond Discrete Domains

**Venue:** DAC | **Confidence:** low (abstract-only)

## Problem & Motivation
SMT solvers handle hybrid (discrete + continuous) formulas but model counting—especially discrete projections in hybrid formulas—is missing. Bit-blasting cannot handle continuous variables.

## Core Method
pact: hashing-based approximate SMT model counter with theoretical error guarantees; makes logarithmic SMT solver calls relative to projection variables using optimized hash functions for solution space partitioning.

## Key Contribution
Hashing-based approximate SMT model counting with logarithmic solver query complexity for hybrid formulas.

## Results
- 603 instances solved vs 13 for baseline (46× improvement)
- Logarithmic solver complexity in projection variable count
