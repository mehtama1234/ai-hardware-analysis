# HEC: Equivalence Verification Checking for Code Transformation via Equality Saturation

**Problem:** Current tools cannot provide holistic verification of source-to-source code transformations (control flow and datapath transformations) used in compiler optimization and High-Level Synthesis, leaving the correctness of these transformations unvalidated.

**Method:** HEC leverages e-graphs integrated with MLIR to verify functional equivalence of code transformations. It uses dynamic and static e-graph rewriting to comprehensively check loop unrolling, tiling, and fusion transformations on PolyBenchC benchmarks, processing over 100,000 lines of MLIR code in 40 minutes.

**Novelty:** Integration of MLIR into the e-graph framework with combined dynamic and static rewriting for comprehensive equivalence verification of code transformations.
