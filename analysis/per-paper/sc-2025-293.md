# FZModules: A Heterogeneous Computing Framework for Customizable Scientific Data Compression Pipelines

**Venue:** SC 2025  
**Authors:** Skyler Ruiter, Jiannan Tian, Fengguang Song

## Problem Statement
Scientific simulations and instruments generate massive data volumes that exceed storage and network capacity. Existing compression solutions are suboptimal:
- **GPU compressors:** High throughput, hard-coded fused kernels, poor rate-distortion trade-offs
- **CPU compressors:** Better quality, insufficient throughput
- **Hybrid approaches:** No systematic framework for rapid pipeline design and optimization

Researchers need flexible tools to assemble domain-tailored compression pipelines without deep expertise.

## Technical Approach
**FZModules Framework:**
1. **Modular Design:** High-performance compression modules (CPU, GPU) with clean interfaces
2. **Extensibility:** Easy to add custom compression algorithms or stages
3. **Asynchronous Execution:**
   - Task-backed execution library
   - Automatic data dependency inference
   - Memory movement optimization across devices
   - Branch and stage-level concurrency exposure

**Pipeline Assembly:**
- Users specify compression pipeline as directed acyclic graph (DAG)
- Framework handles orchestration, data movement, synchronization

## Evaluation Results
**Three Custom Pipelines:**
- Competitive end-to-end speedup vs. fused-kernel GPU compressors
- Superior rate-distortion compared to GPU-only approaches
- Maintains quality of CPU compressors with GPU throughput

**Tested Datasets:**
- Four representative scientific datasets from different domains

## Key Benefits
- **Rapid Prototyping:** Quickly experiment with pipeline variants
- **Domain-Tailored:** Optimize for specific data characteristics and objectives
- **Performance-Quality Balance:** Trade-offs between throughput and accuracy
- **Extensibility:** Add new compression algorithms without rewriting framework

## Limitations & Future Work
- Evaluation on only 4 datasets; broader scientific domain coverage needed
- Scalability to complex multi-stage pipelines (10+ stages) not evaluated
- Overhead of dynamic dependency inference not quantified
- Interaction with other I/O optimizations (buffering, scheduling) unclear
