# AnchorNet: Bridging Live and Collaborative Streaming with a Unified Architecture

**Problem:** Live and collaborative streaming applications traditionally require separate optimization strategies and system architectures, resulting in inefficient resource allocation and complex deployments when supporting both paradigms simultaneously.

**Method:** AnchorNet proposes a single architectural framework that abstracts common streaming requirements for both live broadcast and collaborative use cases. The system employs coordinated scheduling, buffer management, and resource allocation to efficiently handle concurrent data flows across broadcast and peer-to-peer delivery models.

**Novelty:** A unified architecture that seamlessly bridges live and collaborative streaming without requiring separate specialized subsystems or optimization paths.
