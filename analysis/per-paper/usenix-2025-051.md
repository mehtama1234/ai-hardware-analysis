# AnchorNet: Bridging Live and Collaborative Streaming with a Unified Architecture

**Problem:** Live and collaborative streaming applications traditionally require separate optimization strategies and system architectures, resulting in inefficient resource allocation and complex deployments when supporting both paradigms simultaneously.

**Method:** AnchorNet is a single system that handles both live broadcasting (one source streaming to many viewers) and collaborative streaming (multiple people streaming to each other in real-time). It works by identifying what both types need—when to send data, how much to temporarily store in buffers, and where to direct computing resources—and uses these same solutions for both broadcast and peer-to-peer delivery. This shared approach lets the system efficiently manage data flows whether they're one-to-many or many-to-many.

**Novelty:** A single unified architecture that handles both live broadcast and collaborative peer-to-peer streaming together, eliminating the need for separate specialized systems.
