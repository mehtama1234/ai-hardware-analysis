# Towards Accurate Characterization of In-Memory Computing Non-Idealities: A Physics & Data Co-Driven Generative Framework

**Venue:** ICCAD  
**ID:** iccad-2025-095

## Problem
Analog in-memory computing non-idealities severely degrade inference accuracy in fabricated chips, but existing physical models fail to capture complex behaviors and black-box neural networks lack interpretability and generalization.

## Motivation
Enable accurate pre-silicon prediction of post-silicon IMC behavior to improve hardware-aware neural network optimization for analog accelerators.

## Method
PDGM-IMC merges physics-based understanding with real measurement data to model imperfections in analog in-memory computing systems. It uses normalizing flows—a machine learning technique that transforms simple probability distributions into complex, realistic ones—customized with transformations based on device physics. The framework captures three interconnected problems: the statistical distribution of errors across the chip, how errors correlate in different regions, and natural manufacturing variations between individual chips.

## Key Novelty
It's the first generative framework combining physics-based principles with machine learning to model imperfections in analog in-memory computing while preserving both interpretability and generalization.
