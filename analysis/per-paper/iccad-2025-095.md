# Towards Accurate Characterization of In-Memory Computing Non-Idealities: A Physics & Data Co-Driven Generative Framework

**Venue:** ICCAD  
**ID:** iccad-2025-095

## Problem
Analog in-memory computing non-idealities severely degrade inference accuracy in fabricated chips, but existing physical models fail to capture complex behaviors and black-box neural networks lack interpretability and generalization.

## Motivation
Enable accurate pre-silicon prediction of post-silicon IMC behavior to improve hardware-aware neural network optimization for analog accelerators.

## Method
PDGM-IMC: physics and data co-driven generative framework using normalizing flows with custom transformations derived from device physics principles to model complex probability distributions, spatial correlations, and die-to-die variations.

## Key Novelty
First physics and data co-driven generative framework for accurate IMC non-ideality characterization combining interpretability and generalization.

## Contributions
- 4.6x accuracy improvement for input circuit and IMC array modeling
- 2.0x accuracy improvement for output circuit
- Enables pre-silicon prediction of post-silicon behavior
- Publicly available code and pre-trained models
