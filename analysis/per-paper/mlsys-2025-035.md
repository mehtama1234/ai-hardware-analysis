# GSplit: Scaling Graph Neural Network Training on Large Graphs via Probabilistic Splitting

**ID:** mlsys-2025-035 | **Venue:** MLSYS 2025 | **Confidence:** high

## Problem
Data-parallel GNN mini-batch training causes massive redundant feature loading (up to 2.5x) and computation because the same graph vertices appear in multiple GPU micro-batches.

## Method
Split parallelism: each mini-batch is sampled once and non-overlappingly partitioned among GPUs on-the-fly using a probabilistic algorithm. Offline pre-sampling weights vertices/edges by sampling frequency; METIS computes global partition. Online splitting maps each vertex to its pre-assigned GPU in constant time with provable expected communication minimization.

## Key Novelty
Online probabilistic splitting reduces NP-hard per-mini-batch partitioning to a constant-time lookup by leveraging an offline pre-sampled weighted graph partition with provable guarantees.

## Metrics
- **Speedup:** Up to 4.4x over DGL (2.5x avg), 4.1x over P3 (2.4x avg), 1.9x over Quiver (1.4x avg)
- **Hardware:** AWS EC2 p3.8xlarge, 4x NVIDIA V100

## Baselines
DGL, Quiver, P3 (push-pull parallelism), Edge (naive split)
