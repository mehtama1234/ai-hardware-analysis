# asplos-2025-091 — BatchZK: A Fully Pipelined GPU-Accelerated System for Batch Generation of Zero-Knowledge Proofs

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** Pipelined GPU batch zero-knowledge proof generation

## Problem
GPU-accelerated zero-knowledge proof (ZKP) systems optimize for low single-proof latency but do not support high-throughput batch proof generation, creating a bottleneck for applications like blockchain and verifiable ML that require generating many proofs concurrently.

## Motivation
The explosive growth of ZKP applications in blockchain and verifiable ML demands high-throughput batch proof generation, which existing single-proof-optimized GPU systems cannot efficiently provide.

## Method
BatchZK generates multiple zero-knowledge proofs simultaneously on a GPU by running them through different computational stages in parallel—while one proof handles polynomial commitment, another handles multi-scalar multiplication, and a third handles the number-theoretic transform (a fast algorithm for multiplying polynomials). This pipeline keeps the GPU constantly busy and amortizes (spreads) the expensive overhead of data transfer and computation launches across many proofs instead of paying those costs once per proof. The system works with standard blockchain proof schemes like Groth16 and PLONK-family.

## Key Novelty
BatchZK is the first system to use full pipeline parallelism for zero-knowledge proof generation on GPU, allowing multiple proofs to move through different computational stages simultaneously instead of completing one proof entirely before starting the next.

## Contributions
- Fully pipelined GPU execution framework for batch ZKP generation
- Overlap of polynomial commitment, MSM, and NTT stages across concurrent proofs via GPU streams
- Throughput-optimized batch scheduling that amortizes GPU overhead across proofs
- Demonstrated high-throughput batch proof generation for blockchain/verifiable ML applications
