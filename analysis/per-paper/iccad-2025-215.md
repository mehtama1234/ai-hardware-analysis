# LEAP: LLM Inference on Scalable PIM-NoC Architecture with Balanced Dataflow and Fine-Grained Parallelism

**Venue:** ICCAD  
**ID:** iccad-2025-215  
**Confidence:** low

## Problem Statement
LLM inference requires massive memory bandwidth and communication overhead that exceeds GPU capabilities in latency and energy.

## Motivation
Processing-In-Memory architectures combined with optimized NoC can overcome memory bottlenecks in LLM inference.

## Method
LEAP designs a chip that puts processing elements directly at memory (called processing-in-memory) and connects them with an on-chip network, built from scratch for language models. This avoids the common problem where data travels far from memory to a distant processor, wasting time and energy. The system spreads work evenly across many processors so nothing waits for data, and adjusts automatically whether you run a small or large model.

## Key Novelty
The core innovation is putting processing right at memory with an on-chip network, both designed together specifically for language models, so work distributes evenly and prevents bottlenecks.

## Contributions

1. PIM-NoC co-design for LLM inference
2. Balanced dataflow and fine-grained parallelism
3. 2.55x throughput vs A100
4. 71.94x energy efficiency vs A100
