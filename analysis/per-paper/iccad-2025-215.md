# LEAP: LLM Inference on Scalable PIM-NoC Architecture with Balanced Dataflow and Fine-Grained Parallelism

**Venue:** ICCAD  
**ID:** iccad-2025-215  
**Confidence:** low

## Problem Statement
LLM inference requires massive memory bandwidth and communication overhead that exceeds GPU capabilities in latency and energy.

## Motivation
Processing-In-Memory architectures combined with optimized NoC can overcome memory bottlenecks in LLM inference.

## Method
Co-designed PIM-NoC architecture optimizing computation, memory, and communication. Balanced dataflow distribution. Fine-grained parallelism exploiting PIM processing elements. Scalable design handling variable model sizes.

## Key Novelty
First PIM-NoC architecture specifically co-designed for LLM inference with balanced dataflow optimization.

## Contributions

1. PIM-NoC co-design for LLM inference
2. Balanced dataflow and fine-grained parallelism
3. 2.55x throughput vs A100
4. 71.94x energy efficiency vs A100
