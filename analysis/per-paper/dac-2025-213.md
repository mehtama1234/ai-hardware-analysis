# CXL-ECC: Efficient LRC-based ECC for CXL Memory Expanders

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
CXL Memory Expanders boost capacity/bandwidth but RAID/replica fault tolerance incurs prohibitive CXL fabric bandwidth overhead, degrading performance.

## Key Insight
Offloading ECC computation to the expander controller avoids redundant CXL fabric traffic, achieving reliability without bandwidth amplification.

## Method
On-CXL-Memory-Expander-Controller (CXL-MXC) ECC using Locally Recoverable Codes (LRC) as inter-channel ECC; computation offloaded to expander.

## Contributions
- LRC-based inter-channel ECC for CXL Expanders
- On-expander computation eliminates fabric redundancy
- 10^9× reliability improvement
- Bandwidth overhead: 63.5%→3.4%, 12% perf gain

## Hardware Target
CPU, SoC (CXL-enabled)

## Workloads
HPC, Database

## Theme
On-expander ECC for CXL memory reliability and bandwidth efficiency.
