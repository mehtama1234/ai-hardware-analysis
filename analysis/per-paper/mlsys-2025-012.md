# Distributed Submodular Subset Selection at Billion Scale

**Venue:** MLSys 2025 | **ID:** mlsys-2025-012 | **Confidence:** high

## Problem
Submodular subset selection for dataset pruning requires centralizing all data in one machine's memory, infeasible at billion-point scale.

## Method
The algorithm distributes the dataset across many computers (workers). Each worker independently estimates how valuable each remaining data point would be to add to the selection (called marginal gains), using upper and lower bound estimates that tighten through grow and shrink steps based on each point's minimum and maximum potential value—without workers needing to send data to each other. Over multiple rounds, the algorithm redistributes data across workers and combines their selections into a global result, running on Apache Beam for large-scale distributed execution.

## Novelty
Bounding algorithm that avoids centralizing data by computing provably tight distributed bounds on submodular marginal gains.

## Metrics
- 98% of centralized greedy quality at 32 communication rounds
- Scales to 13 billion data points
