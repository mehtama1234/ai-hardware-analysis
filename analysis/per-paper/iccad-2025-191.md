# LLM-Barber: Block-Aware Rebuilder for Sparsity Mask in One-Shot for Large Language Models

**Venue:** ICCAD  
**ID:** iccad-2025-191

## Problem
LLM pruning generates irregular sparsity patterns that are difficult to exploit efficiently on hardware; post-hoc sparsity mask restructuring is needed to enable block-sparse execution.

## Motivation
Structured sparsity (block-wise pruning) enables efficient accelerator implementation; one-shot mask rebuilding eliminates fine-tuning overhead and maintains accuracy.

## Method
After pruning an LLM, zeros scatter randomly through the weight matrix, but hardware accelerators run fastest when zeros are grouped into blocks. LLM-Barber identifies the most important remaining weights by their magnitude, then restructures the pruning pattern to create contiguous blocks of zeros matching the accelerator's block size. It does this in one pass without retraining, reorganizing which weights get removed to optimize the sparsity mask for hardware execution.

## Key Novelty
Restructuring a pruned LLM's sparsity pattern into blocks—grouped zeros that hardware can execute efficiently—in one pass without retraining.

## Contributions
