# LLM-Barber: Block-Aware Rebuilder for Sparsity Mask in One-Shot for Large Language Models

**Venue:** ICCAD  
**ID:** iccad-2025-191

## Problem
LLM pruning generates irregular sparsity patterns that are difficult to exploit efficiently on hardware; post-hoc sparsity mask restructuring is needed to enable block-sparse execution.

## Motivation
Structured sparsity (block-wise pruning) enables efficient accelerator implementation; one-shot mask rebuilding eliminates fine-tuning overhead and maintains accuracy.

## Method
Analyze weight importance scores in pruned LLMs and rebuild sparsity masks to achieve block-structured patterns. Use one-shot restructuring based on magnitude importance within blocks; optimize for target accelerator block sizes.

## Key Novelty
One-shot block-aware sparsity mask rebuilding for LLMs enabling efficient hardware execution without retraining.

## Contributions
1. Block-structured sparsity mask rebuilding algorithm
2. One-shot reconstruction methodology without fine-tuning
3. Weight importance analysis for structured pruning
4. Demonstrated efficiency gains on accelerator hardware
