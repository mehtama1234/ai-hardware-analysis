# dac-2025-275: Fine-Tuning LLMs for Test Stimuli Generation

**Problem:** LLM-based test stimulus generation lacks domain-specific optimization; prompt engineering and feedback methods are insufficient.

**Motivation:** Automated test generation with high coverage and correctness reduces hardware verification time.

**Method:** Two-stage fine-tuning: (1) generate table-shaped test dataset for consistent outputs, (2) apply RL feedback on generated outputs for correctness and coverage.

**Key Novelty:** Domain-specific fine-tuning via table-shaped dataset generation + RL feedback for test generation.

**Contributions:**
- Table-shaped dataset generation strategy
- Two-stage fine-tuning with RL feedback
- Improved syntax correctness and coverage vs. commercial models
