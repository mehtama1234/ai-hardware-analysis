# Machine Learning-Driven STL Generation for Enhancing Functional Safety of E/E Systems

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
ATPG and BIST are intrusive, disrupting operations; unsuitable for in-field functional safety testing in mission-critical systems.

## Key Idea
Reinforcement learning generates design-specific test patterns (STL) enabling non-intrusive in-field testing during idle periods.

## Method
- Reinforcement learning for test pattern generation
- Design-specific STL creation
- In-field testing during idle periods
- Non-intrusive approach avoiding operation disruption

## Contributions
1. RL-driven automated STL generation
2. Design-specific pattern generation
3. 57.57% fault coverage improvement; 85% efficiency vs. pattern-based testing

## Hardware Target
ASIC (mission-critical systems)

## Techniques
Reliability, test generation
