# Machine Learning-Driven STL Generation for Enhancing Functional Safety of E/E Systems

**Venue:** DAC  
**Confidence:** low (abstract-only)

## Problem
ATPG and BIST are intrusive, disrupting operations; unsuitable for in-field functional safety testing in mission-critical systems.

## Key Idea
Reinforcement learning generates design-specific test patterns (STL) enabling non-intrusive in-field testing during idle periods.

## Method
The system uses reinforcement learning (machine learning that learns through trial-and-error) to automatically create a Self-Test Library—a customized set of test patterns for each hardware design. These patterns run during idle periods when the system isn't performing its normal job, allowing the hardware to test itself for defects without disrupting operations. The learning algorithm discovers which test patterns work best, maximizing the range of hardware faults detected while keeping the system available.

## Contributions
1. RL-driven automated STL generation
2. Design-specific pattern generation
3. 57.57% fault coverage improvement; 85% efficiency vs. pattern-based testing
