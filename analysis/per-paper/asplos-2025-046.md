# StreamGrid: Streaming Point Cloud Analytics via Compulsory Splitting and Deterministic Termination

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-046  
**Confidence:** low (abstract only)

## Problem
Point cloud accelerators generate frequent off-chip memory traffic because conventional line-buffer streaming techniques cannot be applied to point clouds: irregular, non-grid computation patterns cause unpredictable data access boundaries and non-deterministic termination conditions.

## Motivation
Point clouds are critical for autonomous driving and robotics, but off-chip DRAM traffic energy cost limits deployability on edge devices.

## Method
StreamGrid introduces compulsory splitting (fixed spatial grid cells bounding on-chip working sets despite irregular neighborhoods) and deterministic termination (static analysis determining when each streaming unit finishes its partition, enabling on-chip buffering without deadlock). An automated optimizer then right-sizes SRAM buffers under accuracy constraints.

## Key Novelty
Compulsory spatial splitting paired with deterministic termination that together enable fully-streaming point cloud processing with conventional line-buffer discipline despite irregular access patterns.

## Contributions
- Compulsory splitting: bounds on-chip working sets for irregular point cloud computations.
- Deterministic termination: eliminates unpredictable stalls in streaming accelerators.
- StreamGrid with automated SRAM buffer sizing.
- 10x speedup, 3.9x energy efficiency; 61.3% on-chip memory reduction, 40.5% energy reduction.
