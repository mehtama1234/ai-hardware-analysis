# StreamGrid: Streaming Point Cloud Analytics via Compulsory Splitting and Deterministic Termination

**Venue:** ASPLOS 2025  
**ID:** asplos-2025-046  
**Confidence:** low (abstract only)

## Problem
Point cloud accelerators generate frequent off-chip memory traffic because conventional line-buffer streaming techniques cannot be applied to point clouds: irregular, non-grid computation patterns cause unpredictable data access boundaries and non-deterministic termination conditions.

## Motivation
Point clouds are critical for autonomous driving and robotics, but off-chip DRAM traffic energy cost limits deployability on edge devices.

## Method
StreamGrid solves a memory bottleneck in point cloud processors: point clouds have irregular, unpredictable data access patterns that break conventional streaming buffers—systems that efficiently prefetch data by assuming regular access patterns like those in images. The solution uses two techniques: compulsory splitting, which divides the point cloud into fixed-size grid cells to make data access predictable and keep it all in on-chip memory; and deterministic termination, which precomputes when each processor finishes so the system avoids stalling while waiting for memory. Together, these enable point cloud processors to use the same efficient streaming approach that already works for images. An automated optimizer then minimizes the on-chip memory (SRAM) needed to maintain accuracy.

## Key Novelty
By partitioning point clouds into fixed-size regions and precomputing when processing finishes, StreamGrid enables point cloud processors to use conventional streaming buffers—systems designed for regular, predictable data access.

## Contributions
- Compulsory splitting: bounds on-chip working sets for irregular point cloud computations.
- Deterministic termination: eliminates unpredictable stalls in streaming accelerators.
- StreamGrid with automated SRAM buffer sizing.
- 10x speedup, 3.9x energy efficiency; 61.3% on-chip memory reduction, 40.5% energy reduction.
