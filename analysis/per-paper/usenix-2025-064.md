# Minos : A Lightweight and Dynamic Defense against Traffic Analysis in Programmable Data Planes

**Problem:** Attackers can infer sensitive information from network traffic patterns and packet characteristics in programmable data planes. Existing traffic analysis defenses introduce significant computational overhead and performance penalties.

**Method:** Minos implements lightweight dynamic defenses within programmable data planes to obfuscate traffic patterns at line rate. The mechanism adapts to network conditions and threat models without requiring expensive cryptographic overhead or significant performance impact.

**Novelty:** Efficient, dynamically-adaptive traffic obfuscation mechanisms specifically designed for programmable data plane execution constraints.
