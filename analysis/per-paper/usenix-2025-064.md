# Minos : A Lightweight and Dynamic Defense against Traffic Analysis in Programmable Data Planes

**Problem:** Attackers can infer sensitive information from network traffic patterns and packet characteristics in programmable data planes. Existing traffic analysis defenses introduce significant computational overhead and performance penalties.

**Method:** Minos hides network traffic patterns (the timing and size of packets that reveal who is communicating) by using simple scrambling techniques in programmable network switches—special hardware devices that can be reconfigured to process packets in custom ways. Rather than relying on heavy cryptographic protection that would slow the network down, it adapts these obfuscation techniques to match current threat levels and network conditions. All of this happens at line rate, meaning the network operates at full speed without any performance penalty.

**Novelty:** The core idea is implementing traffic pattern obfuscation as lightweight, self-adapting logic within programmable network switches, rather than using computationally expensive defenses elsewhere.
