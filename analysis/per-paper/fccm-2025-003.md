# SoftCUDA: Running CUDA on Softcore GPU

**Problem:** Softcore GPU designs on FPGAs lack comprehensive software stack support, making it challenging to translate CUDA code to alternative programming models while maintaining feature parity, limiting adoption across diverse parallel workloads.

**Method:** SoftCUDA is a framework that compiles and runs CUDA programs (code written for NVIDIA GPUs) on a Vortex softcore GPU implemented on FPGAs (reconfigurable hardware you can program). The framework automatically translates CUDA instructions into commands that the Vortex architecture understands, so programmers don't need to rewrite their code. This approach works because FPGAs can be customized to support different GPU designs.

**Novelty:** SoftCUDA enables unmodified CUDA applications to run on softcore GPU designs built on FPGAs without requiring translation to a different programming model.
