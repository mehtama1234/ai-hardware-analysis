# SoftCUDA: Running CUDA on Softcore GPU

**Problem:** Softcore GPU designs on FPGAs lack comprehensive software stack support, making it challenging to translate CUDA code to alternative programming models while maintaining feature parity, limiting adoption across diverse parallel workloads.

**Method:** SoftCUDA provides a comprehensive framework that compiles and executes unmodified CUDA applications on the Vortex softcore GPU implemented on FPGAs. The framework leverages FPGA reconfigurability while maintaining a user-friendly CUDA interface for transparent integration with existing CUDA ecosystems.

**Novelty:** End-to-end CUDA support on softcore GPU architectures, enabling unmodified CUDA applications to run directly on FPGA platforms without translation to alternative programming models.
