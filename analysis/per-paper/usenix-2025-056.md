# Burst Computing: Quick, Sudden, Massively Parallel Processing on Serverless Resources

**Problem:** Serverless platforms lack mechanisms to efficiently handle sudden bursts of massively parallel workloads, causing high latency and poor resource utilization for bursty parallel applications.

**Method:** When a sudden burst of parallel work arrives, the system starts many serverless functions in parallel. It coordinates these functions so each waits for its dependencies to finish, and schedules the work to maximize parallel execution while minimizing idle time.

**Novelty:** Coordinating serverless functions when massively parallel workloads arrive in bursts, instead of invoking each function independently.
