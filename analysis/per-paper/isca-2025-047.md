# Dadu-Corki: Algorithm-Architecture Co-Design for Embodied AI-powered Robotic Manipulation

**ID:** isca-2025-047 | **Venue:** ISCA | **Confidence:** high (full text)

## Problem
Embodied AI robotic manipulation systems run LLM inference on a frame-by-frame basis, creating cumulative sequential latencies (LLM inference + robot control + data communication) that reach 249 ms per frame and prevent real-time operation at >=30 Hz. LLM inference alone consumes 72.7% of latency and 95.8% of energy per frame.

## Motivation
LLM-controlled robots require real-time control (>=30 Hz, preferably 100 Hz), but existing vision-centric frame-by-frame pipelines violate the frequency-decoupled front-end/back-end principle standard in robotics.

## Method
Corki replaces per-frame discrete action decisions with trajectory prediction (smooth cubic paths calculated over multiple steps), reducing how often the LLM needs to run by up to 5.1x. A custom dataflow ASIC accelerator runs task-space computed torque control (a method that calculates joint forces and torques), using pipelined stages (breaking the calculation into parallel steps connected by FIFOs and line buffers) and an approximate computing unit that skips matrix recalculation when robot joints move below a threshold (saving >51% of matrix updates). Communication latency is hidden by overlapping image capture and transmission with trajectory execution.

## Key Novelty
Replacing frame-by-frame action prediction with cubic trajectory planning decouples the LLM inference rate from the control rate, enabling an FPGA hardware accelerator with task-space computed torque control and approximate computing to achieve 29x control speedup.

## Contributions
1. Corki algorithm: predict cubic polynomial robot trajectory for multiple future steps instead of per-frame discrete actions, reducing LLM inference frequency by up to 5.1x.
2. Adaptive trajectory length selection via curvature-based waypoint identification for runtime latency-accuracy trade-off.
3. Custom TS-CTC dataflow accelerator with pipelined PEs, intermediate data reuse (54% latency reduction), and pipeline design (additional 69.6% latency reduction), implemented on Xilinx Zynq-7000 FPGA.
4. Application-specific approximate computing: reuse previously computed matrices when joint movement is small, eliminating >51% of matrix updates.
5. End-to-end pipeline that parallelizes image communication with trajectory execution; 5.9x speedup, 13.9% success rate improvement over RoboFlamingo.

## Hardware Target
FPGA (prototype), ASIC (design), GPU (LLM inference server)

## Techniques
dataflow, approximation, scheduling, parallelism

## Workloads
LLM-inference, vision

## Metrics
- **Speedup:** 5.9x end-to-end; 29x control acceleration on FPGA; LLM inference frequency reduced 5.1x
- **Energy:** 9.2x energy reduction (Corki-9 variant)
- **Area:** 13.6% DSP, 7.8% FF, 16.9% LUT, 6.6% BRAM on Xilinx Zynq-7000 ZC706
- **Accuracy:** Success rate improvement up to 13.9%; average job length improvement up to 17.3% on seen tasks

## Baselines
RoboFlamingo on Nvidia V100 GPU with Intel Core i7-6770HQ CPU for robot control

## Limitations
Currently limited to robotic arms with <=9 DoF; requires retraining the LLM policy head and may not generalize directly to higher-DoF humanoid robots.
