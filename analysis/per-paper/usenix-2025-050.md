# LITESHIELD: Secure Containers via Lightweight, Composable Userspace μKernel Services

**Problem:** Traditional container security mechanisms suffer from high overhead and complex kernel interactions. Existing approaches either provide insufficient isolation guarantees or impose significant performance penalties on containerized workloads.

**Method:** LITESHIELD protects containers by running security functions as small, isolated programs in user space (where applications normally run, rather than in the kernel—the core of the operating system). Each security function handles one job, like controlling file access or network permissions, and they work together through a coordinator. Because these functions run outside the kernel, they add less overhead to container performance. You can also pick which security functions to use based on what your specific container needs, rather than being locked into an all-or-nothing approach.

**Novelty:** Instead of building container security into the kernel, LITESHIELD lets each security function run as a separate, swappable program in user space, so you only pay for the protections you actually need.
