# APR-OIS: A Near-Sensor Point Cloud Pre-Processing Accelerator on FPGA

**Problem:** Raw point clouds from 3D sensors (LiDAR, RGB-D cameras) contain enormous numbers of points and require expensive down-sampling to reduce data while preserving spatial structure before use in point cloud applications.

**Method:** The paper proposes APR-OIS (Approximate Octree-Indexed Sampling), an approximation method that accelerates Octree-based down-sampling by exploiting spatial proximity properties of Octree nodes. The method is implemented as an FPGA-based accelerator functioning as a near-sensor processor on raw 3D sensor data.

**Novelty:** An approximation method (APR-OIS) that achieves significant acceleration in Octree-based point cloud down-sampling with minimal accuracy loss.
