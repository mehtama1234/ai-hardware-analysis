# APR-OIS: A Near-Sensor Point Cloud Pre-Processing Accelerator on FPGA

**Problem:** Raw point clouds from 3D sensors (LiDAR, RGB-D cameras) contain enormous numbers of points and require expensive down-sampling to reduce data while preserving spatial structure before use in point cloud applications.

**Method:** The approach organizes 3D points using an Octree—a tree structure that divides space into nested boxes—grouping nearby points together. Since points in the same region behave similarly, it approximates them with fewer representative points while preserving the overall structure. This filtering logic runs on an FPGA (a hardware chip designed for specific tasks), processing raw sensor data before it's transmitted or stored.

**Novelty:** Approximating point cloud reduction using Octree spatial groupings is fast enough to run in custom hardware (FPGA) right at the 3D sensor, filtering data before transmission.
