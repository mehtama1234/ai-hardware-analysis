# SpecEE: Accelerating Large Language Model Inference with Speculative Early Exiting

**Venue:** ISCA  
**Confidence:** low (abstract only)

## Problem
Early exiting for LLM inference is bottlenecked by the predictor, which must search over a vocabulary of ~30,000 tokens per layer and incurs up to 20% overall inference latency overhead. Existing predictors also fail to integrate with speculative decoding token trees without exponential mapping complexity.

## Motivation
Early exiting can skip expensive upper Transformer layers for easy tokens, but the vocabulary-scale predictor overhead and poor interaction with speculative decoding prevent its practical deployment at scale.

## Method
SpecEE reduces the early-exit predictor's bottleneck by using a small draft model to filter the vocabulary search—instead of checking all ~30,000 possible tokens per layer, the predictor only evaluates likely candidates, cutting the up-to-20% latency overhead. The predictor is redesigned to run in parallel on GPUs and exploit natural data variation to reduce complexity. It profiles which layers are most uncertain and concentrates effort there rather than uniformly. Finally, it adds tree-aware mapping so speculative decoding (generating multiple tokens at once) works efficiently with early exiting, avoiding the exponential complexity that would normally arise.

## Key Novelty
A small draft model shrinks the early-exit predictor's search space, enabling efficient composition of early exiting and speculative decoding.

## Contributions
1. Identification of vocabulary size as the dominant source of early-exit predictor overhead (up to 20% latency)
2. Speculative-model-based predictor that reduces vocabulary search space and improves GPU parallelization
3. Layer-wise non-uniform predictor deployment guided by per-layer activation frequency statistics
4. Tree-aware early-exit mapping compatible with speculative decoding token trees at linear rather than exponential complexity
