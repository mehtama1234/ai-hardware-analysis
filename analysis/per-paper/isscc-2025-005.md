# isscc-2025-005: Calibration-Free Wideband D-Band Phase Shifter

**Venue:** ISSCC  
**Confidence:** Low (abstract-only)

## Problem
D-band (110-170GHz) phased arrays require compact bidirectional phase shifters with 360° range, fine resolution, low phase/gain error, frequency-independent codes, and low power. Existing designs trade off accuracy or bandwidth.

## Approach
**Frequency/switching-staggering** technique enables:
- Frequency-invariant phase codes over 24% bandwidth (no calibration needed)
- Bidirectional TX/RX sharing for compact element spacing
- <2.38° RMS phase error, <0.63dB RMS gain error
- 360° range with ~6b resolution

## Key Contribution
Frequency/switching-staggering produces calibration-free, frequency-invariant phase codes—eliminating runtime tuning in wideband D-band systems.

## Performance
- Frequency: 110-170 GHz
- Bandwidth: 24%
- Phase error: <2.38° RMS
- Gain error: <0.63 dB RMS
- Element spacing: ~1mm×1mm (λ/2)
