# hpca-2025-108 — Gaussian Blending Unit: An Edge GPU Plug-in for Real-Time Gaussian-Based Rendering in AR/VR

**Venue:** HPCA  
**Authors:** Zhifan Ye, Yonggan Fu, Jingqun Zhang, Leshu Li, Yongan Zhang, Sixu Li, Cheng Wan, Chenxi Wan  
**Confidence:** low (abstract only)

## Problem
3D Gaussian Splatting on edge GPUs (Jetson Orin NX) achieves only 7-17 FPS for AR/VR rendering (target: 60+ FPS), because the Gaussian Blending Stage—computing each Gaussian's contribution at every pixel—dominates compute time and is poorly suited to conventional GPU pipelines.

## Motivation
AR/VR demands real-time photorealistic rendering on resource-constrained edge devices; 3D Gaussian Splatting leads in rendering quality/efficiency but its pixel-blending stage is the primary bottleneck on edge hardware.

## Method
GBU is a hardware module for edge GPUs that accelerates the Gaussian Blending Stage—the calculation of each Gaussian blob's contribution to every pixel. It processes pixels row by row, left to right, using a two-step coordinate transformation that reuses calculation values between adjacent pixels (cutting work by up to 5.5×) and skips Gaussians that contribute minimally (saving up to 93% per pixel). A Gaussian Reuse Cache reduces memory accesses by 44.9%, and a dedicated rendering engine balances workload across Gaussians.

## Key Novelty
Intra-row sequential shading (IRSS) processes each row left to right, where a two-step coordinate transformation exploits adjacent pixels' similarity to simultaneously reuse intermediate calculations and skip Gaussians that contribute minimally—both optimizations in one unified pass.

## Contributions
- Bottleneck analysis identifying the Gaussian Blending Stage as the primary limiter for 3DGS on edge GPUs
- IRSS dataflow with 5.5x intermediate value sharing and 93% per-pixel computation reduction via early culling
- Dedicated rendering engine balancing workload across rows
- Gaussian Reuse Cache reducing off-chip memory by 44.9%; achieves real-time 60+ FPS vs. 7-17 FPS baseline

## Metrics
- **Speedup:** 1.72x GPU-only (IRSS); real-time (60+ FPS) with full GBU on Jetson Orin NX vs. 7-17 FPS
- **Accuracy:** SOTA rendering quality maintained
- **Other:** off-chip memory reduction 44.9%; per-pixel computation reduction up to 93%
