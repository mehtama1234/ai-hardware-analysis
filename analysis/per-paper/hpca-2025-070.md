# FHENDI: A Near-DRAM Accelerator for Compiler-Generated Fully Homomorphic Encryption Applications

**Venue:** HPCA  
**Confidence:** low (abstract-only)

## Problem
Fully Homomorphic Encryption (FHE) workloads are both compute- and memory-intensive, and even dedicated FHE ASICs are bottlenecked by expensive memory transfers due to large ciphertext operands and limited bank-to-bank communication, die-to-die bandwidth, and memory access latency within near-DRAM processing.

## Motivation
FHE enables privacy-preserving cloud computation on encrypted data, but the extreme memory bandwidth requirements of NTT, polynomial multiplication, and bootstrapping make purely compute-centric acceleration insufficient.

## Method
FHENDI places computation inside memory (near-DRAM) to avoid expensive data movement of large encrypted values. It exploits parallelism at four scales—individual elements, data chunks (limbs), frequency components (coefficients), and whole ciphertexts—assigning each to different hardware hierarchy levels. Within individual memory banks, a conflict-free localized permutation network (a specialized reordering method) enables element-wise and butterfly operations without data conflicts or inter-bank movement. The HElayers compiler pipelines parallel bootstrapping (re-encryption) operations, while dual banking and subarray-level parallelism hide memory latency.

## Key Novelty
The core innovation is a conflict-free localized permutation network (a data-reordering technique contained within each memory bank) that enables efficient element-wise and butterfly NTT operations on encrypted data without requiring inter-bank communication.

## Contributions
- FHENDI hierarchical NDP design exploiting four parallelism levels in FHE workloads
- Conflict-free bank-local permutation network for element-wise and butterfly operations
- Pipelined bootstrapping to address die-to-die bandwidth limits using HElayers compiler output
- Mean speedups of 2145.8x over server CPU, 118.29x over GPU, 2.45x over FHE ASIC
