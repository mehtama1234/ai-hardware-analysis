# Ensembler: Protect Collaborative Inference Privacy from Model Inversion Attack via Selective Ensemble

**Venue:** DAC
**ID:** dac-2025-228

## Problem
Collaborative inference allows cloud providers to reconstruct sensitive client inputs via model inversion attacks; existing defenses either sacrifice privacy or add prohibitive overhead.

## Motivation
Privacy in collaborative DNN inference is essential for healthcare, finance; current split-learning exposes gradient information enabling inversion.

## Method
Uses selective ensemble on server-side: multiple model branches ensemble predictions to obfuscate gradient signals, making input reconstruction harder while maintaining inference accuracy with <5% overhead.

## Key Novelty
Selective ensemble-based privacy defense that exploits model diversity to hide input signatures in collaborative inference.

## Contributions

- Ensembler framework for privacy-preserving collaborative inference
- Selective model ensemble to obfuscate input reconstruction
- 43.5% structural similarity improvement over baselines
- 4.8% inference time overhead for privacy guarantee
