# Enabling Efficient GPU Communication over Multiple NICs with FuseLink

**Problem:** Existing ML cluster systems with multiple NICs per server fail to fully utilize all NICs due to static GPU-NIC bindings, creating bottlenecks at hot-spot NICs when handling imbalanced communication patterns across LLM serving instances, expert-parallel training, and recommendation model training.

**Method:** FuseLink extends the inter-server network by integrating high-speed intra-server connections and leverages GPUs as relay points to dynamically route traffic to idle NICs. It integrates into NCCL to enable seamless adoption by ML applications without code modifications.

**Novelty:** Using GPUs as dynamic relay points to overcome static GPU-NIC bindings and redistribute traffic to underutilized NICs.
