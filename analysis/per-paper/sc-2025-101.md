# SC25 Paper Analysis: sc-2025-101

## From Soil to Software: Experience from a STEM Workshop on Smart Plant Care and Teachable Machines

### Summary
This paper presents a three-day STEM workshop integrating IoT sensors, visual programming (MakeCode), and machine learning (Teachable Machine) for high school students. Students built a smart plant care assistant and trained ML classifiers, demonstrating effective hands-on engagement with computing concepts.

### Key Problem
- **STEM Engagement**: Traditional computing education lacks real-world, hands-on applications
- **Abstraction Gap**: Students struggle to connect abstract concepts to tangible outcomes
- **Accessibility**: ML and AI tools are often inaccessible to high school students

### Educational Approach
1. **Custom IoT Device**: Sensor system for environmental data collection
2. **Visual Programming**: MakeCode for accessible sensor programming
3. **Machine Learning**: Teachable Machine for training classifiers
4. **Real-World Application**: Smart plant care assistant as motivating project

### Workshop Components
- **Data Acquisition**: IoT sensors collecting environmental measurements
- **Programming**: MakeCode visual programming for sensor integration
- **ML Training**: Teachable Machine classifier training with student data
- **System Integration**: End-to-end smart plant monitoring system

### Contributions
1. Custom IoT sensor device for STEM education
2. Integration of data acquisition, visual programming, and ML
3. Hands-on workshop model for computing education
4. Smart plant care assistant as student project
5. Teachable Machine integration for accessible ML
6. Engagement model for foundational computing concepts
7. Future directions: parallel computing, real-time visualization

### Hardware & Workloads
- **Target Hardware**: IoT sensors, microcontrollers, laptops
- **Workloads**: Environmental data collection, ML classifier training

### Applications
- High school STEM education
- Computer science outreach
- ML literacy for students
- IoT system design learning

### Key Insights
- Real-world applications improve student engagement
- Accessible tools enable hands-on ML learning
- Integration of multiple computing concepts enhances understanding

### Theme
STEM Education and AI Literacy
