# asplos-2025-140: CTXNL: A Software-Hardware Co-designed Solution for Efficient CXL-Based Transaction Processing

**Venue:** ASPLOS  
**Confidence:** low (abstract-only)

## Problem
Directly using CXL for multi-node transaction processing incurs high performance overhead because standard CXL cache coherence primitives enforce fine-grained coherence uniformly, while transactional data is inherently loosely coherent and does not require full coherence at every access.

## Motivation
CXL enables low-latency cache-coherent shared memory across nodes, making it attractive for distributed OLTP, but naive adoption wastes bandwidth and latency on unnecessary coherence traffic.

## Method
CTXNL introduces a hybrid coherence primitive co-designed in software and hardware that allows transaction developers to selectively achieve data coherence on a per-item basis, bypassing full CXL coherence overhead for loosely coherent data during normal execution while enforcing coherence at commit or conflict points. Hardware extensions to CXL memory controllers implement the selective coherence primitive efficiently.

## Key Novelty
A hybrid CXL coherence primitive giving transaction developers selective, per-item coherence control, avoiding unnecessary coherence overhead for loosely coherent transactional data.

## Metrics
- Up to 2.08x throughput over vanilla CXL memory sharing on OLTP workloads
- Outperforms network-based (RDMA) distributed transaction systems

## Hardware Target
CPU, SoC

## Baselines
Vanilla CXL memory sharing, network-based (RDMA) distributed transaction systems
