# Qtenon: Towards Low-Latency Architecture Integration for Accelerating Hybrid Quantum-Classical Computing
**Venue:** ISCA | **Confidence:** low (abstract only)

## Problem
Hybrid quantum-classical algorithms are bottlenecked by the decoupled architecture of current quantum hardware systems, which lacks low-latency communication channels and fine-grained software control for tightly coordinating quantum and classical computation. The high round-trip latency between host processor and quantum accelerator prevents real-time feedback loops required by variational algorithms.

## Motivation
Hybrid quantum-classical algorithms (e.g., VQE, QAOA) are among the most promising near-term quantum applications, but their practical speedup is nullified by host-accelerator communication overhead in loosely coupled designs.

## Method
Qtenon is a RISC-V extended chip implemented in Chisel that tightly couples classical and quantum processing via three hardware components: a unified memory hierarchy serving as a shared communication buffer between the host and quantum accelerators, an efficient quantum controller with dedicated data paths, and a multi-stage processing pipeline that exploits instruction-level parallelism across quantum-classical interaction phases. A custom ISA extension provides instructions for data communication, computation, fine-grained synchronization, and efficient scheduling of quantum-host interaction.

## Key Novelty
Unified memory hierarchy bridging host and quantum accelerator combined with a custom RISC-V ISA extension enabling fine-grained synchronization and scheduling for hybrid quantum-classical algorithms in a tightly coupled chip.

## Contributions
- Unified memory hierarchy acting as a low-latency communication buffer between host and quantum accelerators.
- Custom quantum controller with dedicated data paths and interfaces for tight coupling.
- Multi-stage processing pipeline exploiting parallelism across quantum-classical computation phases.
- RISC-V ISA extensions for quantum data communication, synchronization, and scheduling, achieving up to 14.9x end-to-end speedup.
