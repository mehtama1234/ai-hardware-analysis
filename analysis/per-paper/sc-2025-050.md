## Method
MLP-Offload moves computations and intermediate data values from GPU memory to CPU or storage during language model training. It uses multi-level offloading to choose the granularity at which to move data and multi-path offloading to direct data to the most appropriate destination based on memory and speed constraints. This combination reduces peak GPU memory requirements, allowing training of models larger than GPU memory alone would support.

## Key Novelty
Multi-level, multi-path offloading—moving computations and intermediate values from GPU at variable granularities to multiple possible storage locations—reduces GPU memory requirements during large language model training.
