# SC-2025-162: SIREN - HPC Software Identification

## Summary
Process-level monitoring framework (SIREN) for identifying and recognizing software in HPC systems using fuzzy hashing of executables, preserving privacy while enabling workload analytics.

## Problem
- Job/file names unreliable for software identification (user-provided)
- Lack application-specific insights for system optimization
- Cannot track repeated executions across runs
- Security/compliance requires software inventory

## Solution: Fuzzy Hashing
**Key insight**: Hash executable content for version-resilient identification
- Same application, different versions/compilation → similar hashes
- Different applications → dissimilar hashes
- Privacy-preserving (hash doesn't expose code)

## SIREN Framework
**Data collection at process level**:
1. Process metadata (PID, command)
2. Environment information
3. Executable fuzzy hash
4. Runtime metrics

**Analysis capabilities**:
- Identify unknown software (via similarity)
- Recognize repeated executions
- Understand software usage patterns
- Track application prevalence

## Deployment
**Real-world validation**: Opt-in campaign on LUMI supercomputer
- Real HPC workloads tested
- Practicality demonstrated at scale

## Benefits
- Workload characterization without intrusion
- Software inventory for compliance
- Performance attribution per application
- Security monitoring capability

## Limitations
- Abstract only; no accuracy/false-positive data
- Fuzzy hash collisions not discussed
- Limited to executable binaries (scripts, containers?)

## Applications
- HPC performance analysis
- Workload classification
- Security/compliance auditing
- System optimization
