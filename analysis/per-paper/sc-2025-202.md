# Diff-MoE: Efficient Batched MoE Inference with Priority-Driven Differential Expert Caching

**Venue:** SC  
**Theme:** MoE Inference Optimization  
**Confidence:** low

## Problem Statement
MoE models require massive expert parameter storage; existing GPU memory management solutions use sophisticated prefetching but suffer communication bottlenecks at large batch sizes

## Motivation
MoE inference is bandwidth-limited on GPUs; enabling efficient multi-batch inference could unlock higher throughput for LLM serving with resource constraints

## Methodology
Differential cache hierarchy: globally-hot experts in high-priority per-layer caches, locally-hot in medium-priority caches under LRU with predictive prefetch, cold experts cached on-demand

## Key Novelty
First to exploit both global and temporal locality in MoE expert activation; introduces priority-driven differential cache hierarchy

## Contributions
- Identification of global and temporal locality in expert activation patterns
- Differential cache hierarchy (high/medium/cold priority)
- Lightweight predictor for prefetching next-layer experts
- 2.74x throughput improvement vs DeepSpeed, 2.22x vs Pre-gated MoE, 1.55x vs MoE-Infinity
