# Push Multicast: A Speculative and Coherent Interconnect for Mitigating Manycore CPU Communication Bottleneck
**Venue:** HPCA 2025 | **ID:** hpca-2025-001 | **Confidence:** low (abstract only)

## Problem
In manycore processors running parallel workloads, multiple cores repeatedly fetch the same shared cacheline at different times, consuming redundant LLC and NoC bandwidth through independent demand requests. The reactive cache hierarchy does not exploit temporal redundancy in same-data accesses across cores.

## Motivation
As CPU core counts scale, NoC bandwidth becomes the performance bottleneck because the reactive hierarchy wastes bandwidth serving identical data to many cores sequentially.

## Method
Push Multicast transforms the LLC into a proactive agent: when it services a demand request, it simultaneously pushes the data to predicted sharers via multicast. A coherent in-network filter is installed in routers to prune outstanding demand requests that match an in-flight push. A dynamic pause/resume mechanism adaptively disables pushing when contention is detected.

## Key Novelty
Converting the LLC from a reactive responder to a proactive multicast pusher, coupled with a coherent in-network filter that prunes redundant in-flight requests along the push delivery path.

## Contributions
1. Speculative LLC-to-sharer push mechanism that multicasts data upon demand-request reply
2. Coherent in-network request filter in routers that prunes outstanding requests for cachelines already being pushed
3. Dynamic pause/resume control for pushing to avoid interference under varying traffic loads
4. 33%/43% NoC BW savings in 16/64-core systems; up to 1.56x/2.08x speedup

## Metrics
- **Speedup:** geomean 1.02x (max 1.56x) 16-core; geomean 1.11x (max 2.08x) 64-core
- **BW saving:** 33% avg (16-core), 43% avg (64-core)
