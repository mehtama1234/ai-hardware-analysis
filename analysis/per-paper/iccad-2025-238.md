# Uranus: Ultra-efficient Acceleration Architecture for the Privacy Inference of Graph Neural Networks

**Paper ID:** iccad-2025-238  
**Venue:** ICCAD

## Problem

Fully Homomorphic Encryption enables secure GNN inference on encrypted data, but high computational costs make it impractical without dedicated accelerators. Existing CKKS-based GNN approaches require large encryption parameters; PPGNN combines CKKS with TFHE for memory efficiency but TFHE's SISD computing causes severe computational overhead.

## Motivation

Privacy-preserving GNN deployment on cloud platforms requires efficient FHE-based inference; existing approaches have prohibitive computational or memory costs.

## Method

Uranus uses a split encryption strategy: CKKS (a compression-friendly encryption scheme) for linear layers where approximate arithmetic works, and BFV (a scheme preserving exact integer values) for nonlinear activation functions that need precision, both with reduced encryption parameters sized for hardware. The hardware accelerator is highly reconfigurable to handle this mixed workload and maximize utilization by strategically balancing computation speed, memory use, and accuracy.

## Key Novelty

Uranus is the first accelerator that combines software and hardware design for encrypted graph neural networks (fully homomorphic encryption), achieving 92× speedup versus CKKS-only methods and 3.3–4.2× speedup versus PPGNN, with 119× better energy efficiency.

## Contributions

- Hybrid FHE framework (CKKS+BFV) enabling SIMD-based efficient nonlinear computations
- Reduced encryption parameter requirements improving hardware feasibility
- Reconfigurable hardware accelerator maximizing computation throughput
- 92× speedup vs. CKKS, 3.3-4.2× vs. PPGNN, 119× energy vs. PPGNN
