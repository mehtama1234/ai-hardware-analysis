# Scaling the memory wall using mixed-precision - HPG-MxP on an exascale machine

**Venue:** SC

## Problem
Most scientific simulations are memory bandwidth-limited; applicability of mixed-precision to sparse matrix workloads remains unclear

## Motivation
Quantify mixed-precision benefits for bandwidth-limited sparse matrix applications on exascale systems

## Method
Optimized HPG-MxP benchmark implementation on exascale systems with algorithm enhancements for mixed-precision computation

## Key Novelty
1.6x speedup from double/single-precision mixing on modern GPU supercomputers; first large-scale exascale validation of mixed-precision for sparse matrices

## Contributions
- Optimized HPG-MxP benchmark implementation for exascale
- Algorithm enhancements for mixed-precision sparse matrix operations
- Demonstration of 1.6x speedup on modern GPU-based supercomputers
