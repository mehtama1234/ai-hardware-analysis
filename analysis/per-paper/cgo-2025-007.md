# Improving Native-Image Startup Performance

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Serverless/FaaS startup time directly impacts SLA. Despite AOT heap pre-initialization in GraalVM Native Image, startup is suboptimal due to excessive page faults from poor binary layout.

## Technical Approach
Profile-guided binary reordering minimizes page faults by reordering code and heap objects. Execution-order profiling captures method and object access sequences. Three object ordering strategies applied. Matches profiled objects to built objects despite identity/persistence changes.

## Key Novelty
First profile-guided approach to reorder heap snapshots in AOT-compiled Native Image to reduce startup page faults.

## Key Results
- 1.59× average execution speedup
- 1.61× average page fault reduction

## Hardware & Techniques
- **Target:** CPU
- **Techniques:** Compiler optimization, memory system, binary layout, profiling
