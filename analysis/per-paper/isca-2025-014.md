# HPVM-HDC: A Heterogeneous Programming System for Accelerating Hyperdimensional Computing

**Venue:** ISCA 2025  
**Confidence:** high (full text)

## Problem
HDC programs are manually written in target-specific languages (CUDA, C++, Python) that cannot be retargeted to HDC-specific accelerators (digital ASICs, ReRAM devices). No previous system enables productive development and efficient code generation across CPUs, GPUs, and HDC accelerators from a single codebase.

## Motivation
Custom HDC accelerators achieve orders-of-magnitude power efficiency gains but require adoption of practical, retargetable programming abstractions to avoid reimplementing each application per hardware target.

## Method
Two components: **HDC++**, a C++-based DSL (built on Hetero-C++) exposing 24 target-agnostic HDC primitives — hypervector/hypermatrix operations (Hamming distance, cosine similarity, matmul), and high-level stage constructs (encoding_loop, training_loop, inference_loop); and **HPVM-HDC**, a compiler extending LLVM/HPVM IR with HDC-specific intrinsics that generates code for CPUs (HPVM CPU backend), GPUs (CUDA/cuBLAS/Thrust), a 40nm digital HDC ASIC (pipelined Hamming distance, 0.78 TOPS/W), and a ReRAM HDC accelerator simulator. Two error-resilience-exploiting optimizations are implemented: **automatic binarization propagation** (taint analysis reducing element bitwidth to 1-bit using bitvector ops) and **reduction perforation** (strided or segmented loop iteration over hypervector dimensions for Hamming/cosine/matmul).

## Key Novelty
HDC++ stage-level primitives (encoding_loop etc.) allow the same source to lower to coarse-grain accelerator calls on ASIC/ReRAM and to fine-grain CUDA/HPVM IR on CPUs/GPUs, enabling the first complete HDC application execution on a taped-out 40nm digital ASIC and a ReRAM accelerator.

## Contributions
1. HDC++: first HDC-specific high-level language with 24 target-agnostic primitives including coarse-grain stage constructs for accelerator targeting
2. HPVM-HDC: first retargetable HDC compiler generating code for CPUs, GPUs, 40nm digital ASIC, and ReRAM accelerator simulator from one source
3. Automatic binarization and reduction perforation optimizations — up to 3.4x GPU speedup with marginal accuracy loss
4. 1.17x geomean GPU speedup over optimized CUDA; 1.6x LOC reduction across 5 applications

## Hardware Target
ASIC (40nm digital HDC), CIM/ReRAM, GPU (RTX 2080 Ti, Jetson Orin), CPU (Xeon)

## Key Metrics
- Speedup: 1.17x geomean over optimized CUDA on GPU; up to 3.4x with approximation optimizations
- Code reduction: 1.6x total LOC vs. separate CPU+GPU baselines
- First execution of HD-Classification and HD-Clustering on digital ASIC and ReRAM accelerator

## Baselines
Hand-written CUDA (GPU), Python/NumPy (CPU), NVIDIA Jetson AGX Orin (edge GPU comparison for accelerators)

## Limitations
Automatic selection of optimal approximation configurations (binarization, reduction perforation parameters) is not implemented; programmer must specify them manually.
