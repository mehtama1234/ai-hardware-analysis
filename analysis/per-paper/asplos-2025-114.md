# asplos-2025-114: TaOPT: Tool-Agnostic Optimization of Parallelized Automated Mobile UI Testing

**Venue:** ASPLOS  
**Confidence:** low (abstract only)  
**Primary Theme:** tool-agnostic parallel UI test optimization via subspace partitioning

## Problem
Parallelizing automated mobile UI testing across multiple test devices is inefficient because existing tools explore overlapping UI subspaces on different devices, wasting resources by redundantly testing similar app states. No existing approach optimizes the parallelization of arbitrary automated UI testing tools without modifying their internal workflow.

## Motivation
Modern testing clouds with many real devices and emulators enable parallel testing, but the rapid iteration cycles of mobile development require extracting maximum code coverage and crash detection from available testing resources and time budgets.

## Method
TaOPT performs online UI subspace inference by analyzing the App Under Test (AUT) to identify loosely coupled UI subspaces — regions of the app's state graph that can be explored independently. TaOPT then coordinates access to these subspaces across different testing devices, guiding each device's testing tool toward distinct, unexplored subspaces without modifying the tool's internal search logic (tool-agnostic). This subspace partitioning and assignment is updated dynamically as testing progresses, using observations of which subspaces each device has covered to avoid redundancy.

## Key Novelty
Online inference of loosely coupled UI subspaces and tool-agnostic cross-device subspace assignment that prevents redundant exploration without requiring modifications to the underlying testing tool.

## Contributions
- Formulation and algorithm for online inference of loosely coupled UI subspaces from the AUT's state graph.
- Tool-agnostic subspace assignment mechanism that coordinates multiple testing devices without accessing tool internals.
- Evaluation on 18 popular mobile apps with 3 state-of-the-art Android testing tools: 60% less testing duration, 62% less machine time for comparable coverage.
- 1.2x to 2.1x more unique crashes detected under the same resource budget vs. uncoordinated parallel testing.
