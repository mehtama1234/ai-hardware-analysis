# Modeling the SL-LET Paradigm in AUTOSAR Adaptive

**Venue**: DATE  
**Primary Theme**: deterministic execution for automotive middleware  

## Problem
AUTOSAR Adaptive standard does not address non-functional requirements like determinism, which is critical for automotive functional safety guarantees in service-oriented C++ middleware running on POSIX systems.

## Method
The authors extend AUTOSAR Adaptive (an automotive software standard) with System-Level Logical Execution Time (SL-LET), a timing mechanism that ensures tasks execute predictably and deterministically—a requirement for automotive safety systems. They build a prototype of this extension and validate it on realistic automotive applications using the official AUTOSAR Adaptive Platform Demonstrator.

## Key Novelty
This is the first extension of SL-LET (a model ensuring deterministic, predictable task execution) from AUTOSAR Classic to AUTOSAR Adaptive's more flexible, service-based architecture.

## Contributions
- Modeling extension integrating SL-LET semantics into AUTOSAR Adaptive specification
- Prototype implementation of SL-LET enforcement in AUTOSAR Adaptive middleware
- Experimental validation on realistic automotive application via APD
