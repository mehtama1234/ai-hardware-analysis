# Multicore Environment State Representation for Agent-Directed Test Generation

**Venue:** DAC | **ID:** dac-2025-256

## Problem
Multicore system verification requires effective test program generation, but extracting actionable state information from raw environment observations for learning-based test optimization remains challenging.

## Key Innovation
A reinforcement learning framework that learns to extract structured state representations from raw multicore environment observations, enabling directed test generation for coherence and interaction verification.

## Method
An AI agent trained with reinforcement learning generates test programs and runs them in a simulator of a multicore processor—specifically a 16 or 32-core ARM system where multiple cores share memory using the MOESI coherence protocol. After each test, the agent observes what happens and learns to pull out meaningful patterns from those raw observations. Using this learned understanding, the agent gradually improves its test programs to better verify how the multiple cores interact with each other.

## Hardware Target
CPU (multicore systems)

## Techniques
Scheduling, reinforcement learning

## Evaluation
16 and 32-core ARMv8 MOESI coherence protocol
