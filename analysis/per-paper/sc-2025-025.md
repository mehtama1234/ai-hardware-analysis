# ROSE: RADICAL Orchestrator for Surrogate Exploration

## Overview
Portable orchestration framework for end-to-end surrogate modeling lifecycle, integrating active learning with asynchronous execution across heterogeneous HPC resources.

## Problem & Motivation
- **Challenge**: Surrogate modeling at scale requires managing expensive simulations, dynamic data generation, and tight coupling of simulation → inference → training. Existing systems inadequate for active learning.
- **Opportunity**: Asynchronous orchestration decoupling workflow stages, enabling efficient resource utilization and rapid iteration
- **Scale**: Multi-facility (Polaris, Perlmutter, Delta) with diverse resource constraints

## Architecture & Method
**Orchestration Framework**
- Asynchronous execution primitives (non-blocking across pipeline stages)
- Pilot-based execution enabling parallel task batching
- Support for heterogeneous resource types and constraints

**Workflow Support**
- **In-situ vs ex-situ**: Data generated within simulations or exported
- **Online vs offline**: Concurrent or sequential training
- **Dynamic adaptive sampling**: Surrogate guides next data acquisition
- **Refinement loops**: Iterative surrogate improvement

**Active Learning**
- Surrogate predictions drive data acquisition strategy
- Reduce high-fidelity simulation count (expensive)
- Prioritize uncertain regions of design space

**Multi-facility Deployment**
- Abstracts resource differences (job schedulers, storage, compute)
- Minimal user orchestration burden

## Key Contributions
1. **ROSE framework**: End-to-end surrogate modeling management
2. **Active learning integration**: Surrogate-guided data acquisition
3. **Asynchronous execution**: Non-blocking parallel workflows
4. **Multi-facility portability**: Polaris, Perlmutter, Delta support
5. **4-8× end-to-end speedups** (across use cases)
6. **1.5-3× speedup** from asynchronous vs synchronous execution

## Performance & Results
| Use Case | Speedup | Notes |
|----------|---------|-------|
| Electrolyte structure | 4-8× | Asynchronous pilot-based |
| Neutron diffraction | 4-8× | Structure recovery |
| Colloid phase | 4-8× | Classification workflow |
| Orchestration overhead | Low | Scales with pilot execution |

## Workflow Insights
- Asynchronous orchestration (1.5-3× speedup) critical for efficiency
- Pilot-based execution enables task batching across heterogeneous systems
- Active learning amortizes expensive simulations

## Limitations
- Evaluation limited to 3 use cases (generalizability unclear)
- Comparison with existing workflow systems (Parsl, Swift/T, etc.) absent
- Large-scale (1000s of nodes) behavior unexplored
- Active learning algorithm choices not discussed
- Portability beyond 3 HPC systems unclear

## Relevance to Hardware/AI Systems
**High relevance**: Demonstrates workflow orchestration innovations important for scientific computing at scale, active learning deployment patterns, and asynchronous execution efficiency.
