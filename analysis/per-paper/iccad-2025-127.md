# Advanced Packaging Warpage Modeling with DeepONet-Based Operator Learning

**Venue:** ICCAD  
**ID:** iccad-2025-127

## Problem
Warpage caused by manufacturing thermal processes significantly impacts advanced packaging yield; FEM-based numerical simulations are time-consuming due to mesh generation and large matrix-solving requirements.

## Motivation
Faster warpage analysis accelerates packaging optimization and improves time-to-market for advanced packages.

## Method
The approach trains a neural network operator called DeepONet to learn how manufacturing conditions like temperature patterns create warpage—physical bending—in semiconductor chips. Physics laws are incorporated as constraints during training so the network's predictions respect the actual rules of how materials deform under heat. Once trained, the network instantly predicts warpage for new manufacturing scenarios, replacing expensive finite element method (FEM) simulations that normally require mesh generation and solving enormous systems of equations.

## Key Novelty
Using a physics-informed neural network operator (DeepONet) to replace expensive computer simulations for predicting semiconductor chip warpage during manufacturing.

## Contributions
- Physics-informed operator learning framework for warpage prediction
- Training methodology for DeepONet-based surrogate models
- Rapid warpage analysis tool reducing simulation time
