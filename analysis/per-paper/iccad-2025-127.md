# Advanced Packaging Warpage Modeling with DeepONet-Based Operator Learning

**Venue:** ICCAD  
**ID:** iccad-2025-127

## Problem
Warpage caused by manufacturing thermal processes significantly impacts advanced packaging yield; FEM-based numerical simulations are time-consuming due to mesh generation and large matrix-solving requirements.

## Motivation
Faster warpage analysis accelerates packaging optimization and improves time-to-market for advanced packages.

## Method
Physics-informed operator learning framework using DeepONets for warpage surrogate model; enables rapid prediction of warpage effects without expensive FEM simulations.

## Key Novelty
DeepONet-based physics-informed operator learning for automated warpage surrogate model generation.

## Contributions
- Physics-informed operator learning framework for warpage prediction
- Training methodology for DeepONet-based surrogate models
- Rapid warpage analysis tool reducing simulation time
