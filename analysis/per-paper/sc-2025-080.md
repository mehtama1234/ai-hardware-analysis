# LLM-based Optimization Algorithm Selection for High-Performance Networks Orchestration

**Venue:** SC 2025  
**Authors:** Dalgkitsis, Hsu, Papagianni, Grosso, de Laat

## Problem
High-performance networks supporting AI/LLM growth face:
- Rapid infrastructure growth cannot keep pace with demand
- Suboptimal resource utilization in complex multi-domain environments
- Manual optimization is slow, error-prone, inflexible
- No single optimization algorithm works universally across scenarios

## Approach
**LLM-based algorithm selection framework:**

1. **Algorithm Pool** – Multiple optimization algorithms available (not specified in abstract)
2. **LLM Embeddings** – Generate descriptive embeddings for:
   - Algorithm characteristics and behavior
   - Current network state (logs, metrics)
   - Service request specifications
3. **Intelligent Triage** – LLM analyzes scenario and selects best algorithm
4. **Dynamic Selection** – Adapts without code changes as network evolves

## Key Innovation
**Meta-optimization via LLM:**
- Rather than optimizing network directly, use LLM to optimize **algorithm selection**
- Embeddings enable abstract scenario matching to algorithm suitability
- Removes need for hardcoded decision trees or manual tuning rules
