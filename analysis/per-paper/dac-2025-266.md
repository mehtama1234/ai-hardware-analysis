# ReChisel: LLM-Based Chisel Code Generation with Reflection

**Venue:** DAC | **ID:** dac-2025-266

## Problem
Chisel's high-level abstractions enable superior hardware design compared to Verilog, but LLM-based code generation for Chisel remains unexplored, limiting automation opportunities.

## Key Innovation
First LLM-based agentic system for Chisel code generation with reflection mechanism that iteratively refines code using compilation and simulation feedback.

## Method
ReChisel starts by having an AI write code in Chisel, a programming language designed specifically for describing hardware circuits. The generated code is then tested using a compiler and simulator (tools that check if the code works), and any errors or failures are reported back to the AI. The AI takes this feedback and rewrites the code to fix what went wrong, then the cycle repeats—test the new code, get feedback, improve the code. The system keeps doing this until the code works correctly, and it includes a mechanism to escape if it gets stuck repeating the same failed attempts.

## Design
- **Agentic system:** Multi-round refinement
- **Feedback loop:** Compilation and simulation results
- **Escape mechanism:** Avoids infinite loops

## Results
- Success rate comparable to state-of-the-art Verilog LLM systems
- Iterative refinement effective for HDL generation
- First successful Chisel code generation pipeline

HDL/Design automation
