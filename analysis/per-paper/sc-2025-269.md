# ML-Driven Causal Discovery for Datacenter Reliability

## Problem
Datacenters with hundreds of megawatts and complex subsystem interdependencies suffer cascading failures. Threshold/correlation-based monitoring cannot isolate root causes in high-dimensional telemetry.

## Approach
PACE (Pattern and Causal Exploration):
1. Unsupervised correlation clustering for subsystem identification
2. Lag-aware Granger causality for directed relationships
3. Produces interpretable causal graphs and heatmaps
4. Aligns with physical processes and control logic

## Integration
- Digital twin embedding for what-if reasoning
- Actionable insights for operations teams
- Proactive failure prevention

## Significance
Demonstrates ML's value in understanding complex distributed systems. Causal discovery bridges pattern detection and actionable reliability insights.

## Applications
- Cooling system interdependencies
- Power distribution cascades
- Network failure propagation
- Predictive maintenance
