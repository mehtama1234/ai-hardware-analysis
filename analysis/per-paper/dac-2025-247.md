# dac-2025-247: POLARIS: Explainable Artificial Intelligence for Mitigating Power Side-Channel Leakage

## Summary
XAI-guided masking framework for power side-channel mitigation using unsupervised dataset generation and automated model training. Outperforms VALIANT in leakage reduction, execution time, and area overhead.

## Key Idea
Use explainable AI to identify and target high-impact power leakage patterns for automated, interpretable masking.

## Contributions
- XAI-guided automated mitigation
- Unsupervised threat-model dataset generation
- Better leakage reduction than VALIANT
- Lower execution/area overhead

## Limitations
Power side-channels only; timing/EM attacks and adaptive adversaries not addressed.

## Confidence
**low** (abstract-only)
