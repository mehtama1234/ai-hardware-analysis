# Honey Potion: An eBPF Backend for Elixir

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
eBPF programs limited to C/Rust/Python bindings. Extending to functional languages enables broader developer accessibility and leverages functional programming benefits for kernel systems programming.

## Technical Approach
Translates Elixir to eBPF binaries while satisfying verifier constraints. Creatively leverages verifier's termination requirement to enable optimizations: constant propagation, type specialization, partial evaluation. Ensures semantics preservation and verifier acceptance.

## Key Novelty
First functional language compiler to eBPF, leveraging termination constraints for optimization.

## Key Results
- Publicly available; used in production for packet routers, process monitors, event loggers
- Functional programming paradigm enabled for kernel-space applications

## Hardware & Techniques
- **Target:** CPU (eBPF VM)
- **Techniques:** Compiler, functional language translation, verifier constraints
