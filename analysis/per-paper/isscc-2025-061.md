# isscc-2025-061

**Title:** 20.3 An RFID-Inspired One-Step Packaged Multimode Bio-Analyzer with Vacuum Microfluidics for Point-of-Care Diagnostics

**Venue:** ISSCC

**Problem:** Point-of-care diagnostics struggle between accuracy (bulky centralized labs) and speed (low-accuracy paper assays); microfluidic-CMOS integration faces packaging complexity.

**Key Contribution:** RFID-inspired single-package integration of CMOS + vacuum microfluidics eliminates external pumps and bonding complexity.

**Method:** The system integrates a millimeter-scale CMOS chip (computer circuit) with vacuum-based microfluidics (channels that transport fluid using suction pressure) in a single compact package, eliminating the need for external syringe pumps. It detects biomarkers (disease indicators in blood or saliva) using multimode sensing—measuring electrical current (electrochemical), light signals (optical), or electrical resistance (impedance)—tailored to each target molecule. Vacuum microfluidics passively moves samples through the channels by creating pressure differences, requiring no external mechanical actuation.

**Hardware:** ASIC, SoC

**Techniques:** Circuit design, packaging, near-data processing

**Primary Theme:** Integrated CMOS-microfluidics for portable diagnostics
