# CrossBit: Bitwise Computing in NAND Flash Memory with Inter-Bitline Data Communication

**Venue:** MICRO  
**Confidence:** low (abstract-only)

## Problem
Existing in-flash processing (IFP) architectures can only perform bitwise operations on data sensed within the same bitline, preventing computation involving data from different bitlines. This restriction makes prior IFP designs unable to implement error correction codes (ECC) or efficiently process database query operations that require inter-bitline data interactions.

## Motivation
NAND flash memory's high capacity and low cost make it attractive for near-data processing of data-intensive workloads, but the limited intra-bitline-only operation support severely restricts the computational scope and forces continued use of less dense SLC cells without reliable in-flash ECC.

## Method
CrossBit extends commodity NAND flash memory with minimal additional circuitry to support both intra-bitline and inter-bitline bulk bitwise operations. It introduces inter-bitline communication pathways that allow data sensed from different bitlines to interact during in-flash compute. This enables in-flash ECC (IF-ECC) operations directly on MLC flash cells. The same inter-bitline capability accelerates fundamental database selection and join queries that previously required data movement across bitlines.

## Key Novelty
CrossBit is the first IFP architecture to support inter-bitline data communication during in-flash computation, enabling reliable MLC-based IFP through in-flash ECC and substantially expanding the class of operations executable within NAND flash memory.

## Contributions
1. An IFP architecture (CrossBit) supporting both intra-bitline and inter-bitline bulk bitwise operations with minimal additional circuitry
2. In-flash ECC (IF-ECC) enabling reliable MLC IFP — 1.8x bit density improvement over prior SLC-only IFP
3. 2.1x speedup and 2.5x energy efficiency over SOTA IFP for fundamental database queries
4. End-to-end evaluation on Star Schema Benchmark showing 1.7x speedup over prior IFP
