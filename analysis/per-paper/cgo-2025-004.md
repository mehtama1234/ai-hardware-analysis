# Janitizer: Rethinking Binary Tools for Practical and Comprehensive Security

**Venue:** CGO 2025 | **Confidence:** Low (abstract-only)

## Problem & Motivation
Binary rewriting techniques trade off coverage vs. soundness vs. overhead. Source unavailability makes compiler-level protection infeasible. Comprehensive security requires protecting all code including libraries.

## Technical Approach
Hybrid static-dynamic mechanism combines dynamic technique soundness and coverage with static technique performance. Implements hybrid binary rewriting for memory sanitization and control flow integrity (CFI).

## Key Novelty
First hybrid static-dynamic framework achieving sound, comprehensive coverage with practical performance.

## Key Results
- Sound memory sanitizer with full code coverage
- Sound CFI with full code coverage
- Performance competitive with low-overhead static approaches

## Hardware & Techniques
- **Target:** CPU
- **Techniques:** Binary rewriting, security (CFI, sanitization), hybrid analysis
