# HELM: Characterizing Unified Memory Accesses to Improve GPU Performance under Memory Oversubscription

**Venue:** SC

## Problem
Unified Memory default migration policies severely degrade performance under memory oversubscription; existing solutions fail to generalize across applications

## Motivation
Characterize and predict UM access patterns to enable dynamic policy selection for improved performance under oversubscription

## Method
HELM collects data from the Unified Memory driver—the GPU's automatic memory-management system—to understand how programs access memory. By analyzing these access patterns, it determines which data should stay on the GPU and which can be moved back to main memory. HELM then uses this analysis to automatically select the data-migration policy that works best for each program, rather than applying a one-size-fits-all default.

## Key Novelty
HELM introduces metrics that reveal what programs actually do with GPU memory, enabling automatic optimization of data-migration policies and achieving an average 3.5x speedup.
