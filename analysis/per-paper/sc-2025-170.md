# HELM: Characterizing Unified Memory Accesses to Improve GPU Performance under Memory Oversubscription

**Venue:** SC

## Problem
Unified Memory default migration policies severely degrade performance under memory oversubscription; existing solutions fail to generalize across applications

## Motivation
Characterize and predict UM access patterns to enable dynamic policy selection for improved performance under oversubscription

## Method
HELM metrics derived from UM driver telemetry to characterize access patterns; metrics guide selection of optimal UM migration policies

## Key Novelty
HELM: semantically meaningful, interpretable metrics for UM access characterization; enables policy-driven optimization achieving 3.5x average improvement

## Contributions
- Novel HELM metrics for UM access pattern characterization
- Metrics derived from accessible UM driver telemetry for broad applicability
- Methodology for policy selection under memory oversubscription
