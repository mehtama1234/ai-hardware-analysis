# Software-Style Hardware Debugging: A Hardware Generation, Simulation and Debugging Framework

**Venue:** ICCAD  
**ID:** iccad-2025-121

## Problem
Hardware verification still relies on traditional RTL workflows, creating a bottleneck in design-verification iteration efficiency and limiting the use of modern debugging techniques.

## Motivation
Hardware design iteration cycles are slow compared to software; bringing software debugging paradigms to hardware can significantly accelerate development.

## Method
ComoPy framework enables host language native simulation with fine-grained tracing and breakpoints on HDL source lines, software-style hot-reloading for incremental debug-fix cycles, and dynamic switching between fast low-level RTL simulation and high-level HDL execution.

## Key Novelty
Applying software debugging paradigms (breakpoints, tracing, hot-reloading) directly to hardware verification through host language integration.

## Contributions
- Host language native simulation enabling breakpoints and tracing on HDL source lines
- Software-style hot-reloading for incremental debug-fix iterations
- Dynamic switching between RTL and HDL execution levels
