# dac-2025-272: PoP-ECC—Hierarchical Error Correction for MBU Protection

**Problem:** Process scaling increases memory error severity (MBUs); traditional ECC insufficient for DNN accelerator safety.

**Motivation:** Safety-critical systems (autonomous vehicles) require robust protection against multi-bit upsets.

**Method:** Two-tier hierarchical ECC: Virtual Parities (first level) feed into Parities of Parities (second level). Dynamic correction tailored to error patterns.

**Key Novelty:** Two-tier hierarchical structure (VP→PP) enables flexible MBU protection with tunable levels.

**Contributions:**
- PoP-ECC two-tier architecture
- Higher MBU tolerance vs. state-of-the-art
- Negligible overhead

**Confidence:** low (abstract-only)

**Tags:** ecc, error-correction, mbu, reliability, dnn-accelerator
