# DiffCCD: Differentiable Concurrent Clock and Data Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-077

## Problem
Post-CTS timing optimization must address clock skew and data path delays while respecting physical implementation constraints. Traditional methods handle these optimizations separately, limiting effectiveness in timing closure for advanced nodes.

## Motivation
Achieving timing closure on modern VLSI designs requires joint optimization of clock skew and data delays with physical constraints, as clock skew significantly impacts circuit timing performance.

## Method
DiffCCD formulates concurrent clock and data optimization as a GPU-accelerated differentiable optimization problem. The approach includes:
1. **Smooth differentiable formulation** for CCD optimization with gradient calibration mechanism
2. **ADMM-based problem decomposition** into manageable subproblems
3. **Implementation** as buffer sizing in clock network and placement refinement, balancing timing optimization with physical constraints

## Key Novelty
First differentiable framework to jointly optimize clock skew and data path delays during post-CTS timing closure with physical constraint awareness.

## Contributions
- Differentiable formulation of concurrent clock and data optimization with calibrated gradient computation
- ADMM-based decomposition strategy balancing timing optimization with physical implementation constraints
- GPU-accelerated implementation demonstrating 22.4% average WNS improvement and 45.0% TNS improvement
- 9.434× runtime speedup on industrial open-source benchmarks
