# DiffCCD: Differentiable Concurrent Clock and Data Optimization

**Venue:** ICCAD  
**ID:** iccad-2025-077

## Problem
Post-CTS timing optimization must address clock skew and data path delays while respecting physical implementation constraints. Traditional methods handle these optimizations separately, limiting effectiveness in timing closure for advanced nodes.

## Motivation
Achieving timing closure on modern VLSI designs requires joint optimization of clock skew and data delays with physical constraints, as clock skew significantly impacts circuit timing performance.

## Method
DiffCCD solves the problem of adjusting clock and data timing as a mathematical optimization on a GPU, using gradients—mathematical slopes that indicate which way to adjust parameters to improve timing results. The approach has three components: first, it converts the timing problem into smooth mathematical equations with a calibration step to ensure the gradients stay accurate; second, it breaks the large problem into smaller subproblems that are solved in alternating rounds using a technique called ADMM; third, it implements the solution through buffer sizing (adding delays in the clock network) and repositioning components on the chip, while keeping everything within physical design limits.

## Key Novelty
DiffCCD is the first approach using gradient-based optimization to jointly handle clock skew and data path timing delays during post-CTS timing closure while maintaining physical design constraints.

## Contributions
- Differentiable formulation of concurrent clock and data optimization with calibrated gradient computation
- ADMM-based decomposition strategy balancing timing optimization with physical implementation constraints
- GPU-accelerated implementation demonstrating 22.4% average WNS improvement and 45.0% TNS improvement
- 9.434× runtime speedup on industrial open-source benchmarks
