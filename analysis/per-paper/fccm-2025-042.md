# Unlocking the AMD Neural Processing Unit for ML Training on the Client Using Bare-Metal-Programming Tools

**Problem:** Efficiently utilizing AMD's Neural Processing Unit for GPT-2 training on client devices while maximizing throughput and power-efficiency requires low-level hardware-software co-design.

**Method:** The authors develop an optimized GPT-2 training implementation using a low-level programming framework that enables direct hardware mapping of application logic to AMD NPU capabilities, leveraging bare-metal programming techniques for performance optimization.

**Novelty:** Using bare-metal programming tools to directly map GPT-2 training kernels to AMD NPU hardware for improved efficiency through tight hardware-software co-design.
