# Unlocking the AMD Neural Processing Unit for ML Training on the Client Using Bare-Metal-Programming Tools

**Problem:** Efficiently utilizing AMD's Neural Processing Unit for GPT-2 training on client devices while maximizing throughput and power-efficiency requires low-level hardware-software co-design.

**Method:** They write GPT-2 training code using bare-metal programming (code that speaks directly to the hardware without an operating system layer). By carefully mapping each training operation to what the AMD NPU can do natively, they eliminate unnecessary overhead. This tight hardware-software alignment improves both training speed and power efficiency on client devices.

**Novelty:** The key idea is using bare-metal programming to map GPT-2 training directly onto AMD NPU hardware, eliminating the operating system layer for maximum efficiency.
