# Reconfigurable Retina-Inspired Looming Detection

**Problem:** Detecting rapidly approaching objects and potential threats requires efficient real-time detection. Current systems lack specialized hardware optimized for retinal looming detection computation.

**Method:** The approach builds looming-detection computation directly into the image sensor using reconfigurable transistor circuits (CMOS, the switching technology in all modern chips), which mimics how the retina detects approaching objects. The sensor computes results as light arrives rather than collecting raw pixel data for processing later, using only 0.36 picojoules of energy per detection event on a 5×5 pixel area. The circuit was built using GlobalFoundries' 22nm FD-SOI technology and validated against real laboratory footage and hardware-behavior simulations.

**Novelty:** The core idea is building looming detection directly into the image sensor using a reconfigurable circuit, so the computation happens as light arrives rather than in separate processing hardware.
