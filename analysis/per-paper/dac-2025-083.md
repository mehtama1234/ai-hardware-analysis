# dac-2025-083: ParGNN: Scalable Full-Batch GNN Training on Multi-GPUs

**Problem:** Full-batch GNN training suffers from load imbalance and high communication overhead due to irregular graph structure.

**Method:** ParGNN measures how much computation each GPU receives (profiling), then breaks the graph into extra pieces and redistributes them to make the work more even (graph over-partitioning and adaptive load balancing). It arranges the work in a pipeline where each GPU processes multiple graph pieces in sequence, timed so that while one GPU is computing, another is simultaneously receiving or sending data (computation-communication overlap). This keeps data flowing and GPUs busy at the same time, eliminating the idle waiting that happens when data arrives late.

**Key Novelty:** Adaptive load balancing combined with computation-communication overlap for scalable GNN training accuracy preservation.

**Hardware Target:** GPU  
**Technique Category:** parallelism, memory-system, dataflow  
**Workloads:** GNN, graph-analytics  

**Metrics:**
- Speedup vs PipeGCN: 2.7x
- Speedup vs DGL: 21.8x

**Baselines:** PipeGCN, DGL
