# GenomeDPU: A Cost-Effective In-Memory Data Processing Unit for GPU-based Genome Analysis

**Venue:** ICCAD  
**Paper ID:** iccad-2025-256

## Problem Statement
GPU-based genomics analysis suffers from memory bottlenecks, with memory accesses accounting for >60% of pipeline stalls despite massive parallel processing power.

## Motivation
Genomics data volume is growing exponentially, requiring efficient acceleration while overcoming memory bandwidth limitations in GPU systems.

## Method
GenomeDPU adds simple processing logic directly to the DRAM interface, the point where data moves between the GPU and main memory. Rather than sending genome sequences to the GPU for alignment processing and then back to storage, the processor handles part of the alignment work right at the interface. This keeps data local to memory and eliminates the expensive back-and-forth transfers that were the main source of slowdowns.

## Key Novelty
GenomeDPU achieves in-memory processing for GPU-accelerated genome analysis by adding simple logic to the DRAM interface instead of embedding costly processors into memory chips.

2. 55% energy reduction
3. Minimal overhead compared to other PIM techniques
