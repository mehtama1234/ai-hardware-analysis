# NoH: NoC Compilation in High-Level Synthesis

**Problem:** High-level synthesis tools lack accessible abstractions for leveraging hardened networks-on-chip (NoCs) in multi-die FPGAs, requiring manual placement knowledge and only supporting memory access offloading. Automatically offloading communication to NoCs requires solving three interconnected challenges: balancing hard NoC and programmable logic resource utilization, allocating limited NoC resources between communications, and aligning NoC placement without knowing programmable logic placement beforehand.

**Method:** NoH uses mathematical optimization called integer linear programming (a technique for finding the best arrangement given many constraints) to automatically place communications on a hardened network-on-chip (a pre-built communications system in an FPGA). The algorithm decides which communications use the NoC versus the programmable logic (the flexible parts), handling both time-critical memory access and flexible communication between chip modules. It predicts where the programmable logic will be placed, then positions the NoC connection points based on that prediction, removing the need for manual placement expertise.

**Novelty:** NoH is an HLS compiler that automatically handles hard network-on-chip offloading through mathematical optimization, eliminating manual placement expertise requirements.
