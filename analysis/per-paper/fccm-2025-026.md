# NoH: NoC Compilation in High-Level Synthesis

**Problem:** High-level synthesis tools lack accessible abstractions for leveraging hardened networks-on-chip (NoCs) in multi-die FPGAs, requiring manual placement knowledge and only supporting memory access offloading. Automatically offloading communication to NoCs requires solving three interconnected challenges: balancing hard NoC and programmable logic resource utilization, allocating limited NoC resources between communications, and aligning NoC placement without knowing programmable logic placement beforehand.

**Method:** NoH develops a formal NoC-aware placement algorithm using integer linear programming (ILP) that jointly optimizes resource allocation and trade-offs for external memory accesses and latency-insensitive inter-module communication. A port-affinity model arranges NoC ports synergistically with programmable logic modules by approximating future PL placement. The algorithm is integrated into an end-to-end HLS flow that automatically generates specifications for place-and-route without manual intervention.

**Novelty:** First HLS compiler flow that fully automates hard NoC offloading through formal NoC-aware placement with integer linear programming, eliminating manual placement knowledge requirements.
