# dac-2025-084: MemSeer: Memory Failure Prediction in Heterogeneous Clusters

**Problem:** DRAM failures in heterogeneous x86/ARM clusters require architecture-specific prediction accounting for platform-dependent failure patterns.

**Method:** MemSeer predicts memory chip failures in data-center clusters using both x86 and ARM processors (two different chip architectures), by recognizing that each fails in different ways. It monitors warning signs at multiple time scales (from hours to weeks ahead) and feeds predictions to automated systems that can replace failing chips before outages occur. This improves prediction accuracy by 17.3% and catches 27% more failures.

**Key Novelty:** Architecture-aware multi-grained prediction exploiting x86/ARM failure distinctions for heterogeneous reliability.

**Hardware Target:** CPU  
**Technique Category:** reliability  
**Workloads:** datacenter, cloud-systems  

**Metrics:**
- F1-score: 17.3% improvement
- Recall: 27% improvement
- VM interruption reduction: 42.7%

**Confidence:** low (abstract only)
