# BBS: Bi-Directional Bit-Level Sparsity for Deep Learning Acceleration

**Problem:** Existing accelerators exploit sparsity at coarse granularities (structured, vector-level) and typically in only one dimension (weights or activations), missing fine-grained optimization opportunities. Bit-level sparsity remains largely unexploited, especially in bidirectional fashion.

**Method:** BBS scans both weights and activations for sparsity—zero bits scattered throughout the data—at individual bit precision, finer than existing approaches. Hardware circuits mask and skip computations on those zero bits, routing processing only where bits are nonzero. By working at bit level in both data streams simultaneously, it exposes optimization opportunities that coarser methods miss while keeping hardware overhead low.

**Novelty:** First to find and skip zero bits in both weights and activations at the same time using custom hardware.
