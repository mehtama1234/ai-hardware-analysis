# CloudEval-YAML: A Practical Benchmark for Cloud Configuration Generation

**Problem:** Automatically generating valid cloud configuration files in YAML format requires evaluation against comprehensive benchmarks, but no standardized evaluation framework exists for this task.

**Method:** CloudEval-YAML is a testing toolkit for systems that automatically generate cloud configuration files in YAML format (a structured text format used to describe cloud settings). The toolkit provides example configurations showing correct outputs, test cases covering different cloud setup scenarios, and metrics to evaluate whether generated files are actually valid. It also includes baseline implementations—simple reference systems—so researchers can measure how their new systems improve over known baseline performance.

**Novelty:** A standardized test suite for evaluating systems that automatically generate YAML cloud configuration files.
