# Distributed Matrix-Based Sampling for Graph Neural Network Training

**Problem:** GNN training on large graphs requires sampling subgraphs or nodes to manage memory and computation, but coordinating sampling across distributed nodes introduces synchronization overhead and communication bottlenecks.

**Method:** The approach formulates node/edge sampling for GNN training as matrix operations, enabling efficient computation of sampling probabilities in distributed settings. It coordinates sampling decisions across multiple devices using matrix-based representations to reduce per-step communication and leverage GPU/CPU matrix multiplication capabilities.

**Novelty:** Using matrix-based formulations to unify and optimize sampling operations in distributed GNN training.
