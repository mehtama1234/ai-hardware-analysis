# Prompt Cache: Modular Attention Reuse for Low-Latency Inference

**Problem:** LLM inference exhibits high latency due to redundant attention computation when processing repeated or overlapping prompt prefixes. This inefficiency becomes severe in interactive applications where similar prompts frequently recur.

**Method:** When an LLM processes a prompt, it calculates how each word should pay attention to other words—an expensive step called attention. The system saves these precomputed calculations by breaking them into modular (reusable) pieces indexed by the prompt content. Whenever a new request arrives with an identical or overlapping prompt prefix, it retrieves and reuses these saved pieces instead of recalculating them.

**Novelty:** Reusing precomputed attention work across similar prompts by organizing it into modular, reusable pieces.
