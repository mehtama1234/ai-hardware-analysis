# NeoMem: Hardware/Software Co-Design for CXL-Native Memory Tiering

**Problem:** Existing memory systems do not efficiently leverage CXL's cache-coherent capabilities for automatic data tiering across local and remote memory tiers. Current approaches incur excessive coherence overhead and inefficient data placement policies when managing heterogeneous memory hierarchies through CXL.

**Method:** NeoMem combines custom hardware and software to automatically tier data across local and remote memory connected by CXL. The hardware implements coherence protocols—rules that keep data consistent—specifically optimized for tiering, and includes fast pathways to move data between tiers. Software monitors which data is accessed frequently and guides the hardware to promote hot data to faster memory and demote cold data to slower memory. This design reduces the overhead of keeping data consistent compared to systems that weren't designed with tiering in mind.

**Novelty:** The key idea is designing tiering policies that work with CXL's built-in ability to keep data consistent across memory tiers, rather than treating CXL like any other remote memory system.
