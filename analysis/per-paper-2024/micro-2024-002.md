# NeoMem: Hardware/Software Co-Design for CXL-Native Memory Tiering

**Problem:** Existing memory systems do not efficiently leverage CXL's cache-coherent capabilities for automatic data tiering across local and remote memory tiers. Current approaches incur excessive coherence overhead and inefficient data placement policies when managing heterogeneous memory hierarchies through CXL.

**Method:** NeoMem proposes a hardware/software co-design that includes CXL-aware coherence protocols optimized for tiering semantics, hardware support for efficient memory promotion/demotion between tiers, and adaptive software policies that monitor access patterns to guide data placement. The system leverages CXL's cache-coherent fabric to reduce coherence traffic compared to traditional remote memory systems while maintaining correctness across tier boundaries.

**Novelty:** The key insight is co-designing coherence protocols and tiering policies specifically for CXL's capabilities rather than applying generic tiering to CXL, enabling efficient automatic memory tiering without excessive coherence overhead.
