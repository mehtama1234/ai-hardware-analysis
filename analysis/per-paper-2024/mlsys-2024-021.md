# Disaggregated Multi-Tower: Topology-aware Modeling Technique for Efficient Large Scale Recommendation

**Problem:** Large-scale recommendation systems using multi-tower architectures face efficiency challenges when deployed across heterogeneous hardware topologies. Traditional tower designs do not account for hardware topology constraints, resulting in suboptimal resource utilization and excessive communication overhead.

**Method:** The system breaks a recommendation model into many small pieces and assigns each piece to run on a specific processor, using an algorithm that considers the hardware topology (how computers are physically connected), network bandwidth, communication latency, and compute capabilities. It then schedules the work so that pieces that exchange data run close together, which reduces how much data needs to travel between different parts of the hardware.

**Novelty:** The core innovation is using hardware topology information (how processors are connected and how fast they can communicate) to guide where each piece of the recommendation model gets placed, which reduces unnecessary data moving between machines.
