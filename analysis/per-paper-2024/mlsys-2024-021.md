# Disaggregated Multi-Tower: Topology-aware Modeling Technique for Efficient Large Scale Recommendation

**Problem:** Large-scale recommendation systems using multi-tower architectures face efficiency challenges when deployed across heterogeneous hardware topologies. Traditional tower designs do not account for hardware topology constraints, resulting in suboptimal resource utilization and excessive communication overhead.

**Method:** The approach disaggregates multi-tower recommendation models by decomposing individual towers into fine-grained compute units and distributing them according to the underlying hardware topology. A topology-aware placement algorithm maps tower components to processors considering network bandwidth, communication latency, and compute capabilities. The system uses dynamic scheduling to co-locate dependent components and minimize cross-topology communication.

**Novelty:** Integration of topology-aware hardware mapping into multi-tower model disaggregation to optimize component placement and reduce inter-device communication.
