# Reliable Hardware Design for Approximate Computing in Deep Learning

**Problem:** Approximate computing circuits trade off accuracy for energy efficiency in deep learning accelerators, but computation errors can exceed acceptable bounds. Existing designs lack adaptive mechanisms to control errors while maintaining reliability constraints.

**Method:** The circuit speeds up calculations by using less precision, which saves power but creates errors. The system watches these errors as the circuit runs; when errors grow too large, it automatically increases the power settings (voltage and frequency) to restore accuracy, and when errors stay small, it reduces these settings to save more energy. This creates a continuous feedback loop where the circuit adjusts itself to keep errors within acceptable limits while minimizing power waste.

**Novelty:** It automatically adjusts the circuit's power settings (voltage and frequency) based on error measurements taken in real time, rather than using fixed settings, to keep errors within safe bounds.

**Theme:** Adaptive reliability management for approximate computing
