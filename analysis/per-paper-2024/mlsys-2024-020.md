# HeteroSwitch: Characterizing and Taming System-Induced Data Heterogeneity in Federated Learning

**Problem:** Federated learning systems experience data heterogeneity induced by system-level factors such as device heterogeneity, network variability, and distributed resource availability. This system-induced heterogeneity degrades convergence speed and model accuracy across heterogeneous clients.

**Method:** HeteroSwitch measures how physical system factors—different device capabilities, variable network speeds, and uneven resource availability—create uneven data distributions in a federated learning system (where models train across many distributed devices). When it detects these patterns, it automatically switches the strategies for combining the data and training to adapt to what it finds. This adaptive approach helps the system converge faster and more reliably despite heterogeneous devices and network conditions.

**Novelty:** HeteroSwitch treats system-induced data unevenness—caused by device differences and network variability—as a distinct problem from natural data skew, and addresses only the system-induced part.
