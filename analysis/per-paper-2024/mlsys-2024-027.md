# FLASH: Fast Model Adaptation in ML-Centric Cloud Platforms

**Problem:** Model adaptation and fine-tuning of pre-trained machine learning models in cloud platforms incurs high latency and consumes substantial computational resources. Efficient model customization for new tasks remains a bottleneck in ML serving infrastructure.

**Method:** FLASH speeds up model adaptation by strategically choosing which layers (stages of computation) of a pre-trained model to update rather than retraining the entire model. It organizes how data moves through cloud resources—GPUs for fast computation, CPUs for general processing, and storage systems—to minimize wasted transfer time. The system also schedules multiple adaptation jobs to run without idle gaps, keeping compute resources constantly in use.

**Novelty:** FLASH's core innovation is making adaptation faster by customizing the fine-tuning strategy to match the specific hardware capabilities and how data flows through the cloud platform being used.
