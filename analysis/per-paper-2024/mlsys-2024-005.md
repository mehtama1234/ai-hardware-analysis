# Q-Hitter: A Better Token Oracle for Efficient LLM Inference via Sparse-Quantized KV Cache

**Problem:** LLM inference requires maintaining key-value caches that grow linearly with sequence length, consuming substantial GPU memory and limiting inference throughput. Existing KV cache management strategies fail to distinguish between critical and less important tokens.

**Method:** Q-Hitter employs a token oracle to predict which tokens are most important for attention computation. The system combines this token prediction with quantization to create a sparse-quantized KV cache that selectively retains high-importance tokens while quantizing embeddings to lower precision, reducing overall memory consumption.

**Novelty:** Integration of a token oracle mechanism to guide sparse selection of KV cache entries paired with quantization for memory-efficient LLM inference.
