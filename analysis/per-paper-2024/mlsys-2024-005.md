# Q-Hitter: A Better Token Oracle for Efficient LLM Inference via Sparse-Quantized KV Cache

**Problem:** LLM inference requires maintaining key-value caches that grow linearly with sequence length, consuming substantial GPU memory and limiting inference throughput. Existing KV cache management strategies fail to distinguish between critical and less important tokens.

**Method:** Q-Hitter works by predicting which tokens (words) the model truly needs to remember—this prediction happens during attention computation, which is when the model decides which past words are relevant for what comes next. Based on this prediction, it stores important tokens at high precision while compressing less important ones to lower precision in the key-value cache (the storage that holds information about every past word). By keeping important tokens at full detail and shrinking the rest, it reduces GPU memory consumption while maintaining the model's ability to compute attention correctly.

**Novelty:** Q-Hitter combines a token oracle (a mechanism that predicts which tokens matter) with quantization (precision reduction) to selectively compress the key-value cache, reducing GPU memory use for LLM inference.
