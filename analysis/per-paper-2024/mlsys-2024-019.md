# Lancet: Accelerating Mixture-of-Experts Training via Whole Graph Computation-Communication Overlapping

**Problem:** Mixture-of-Experts training incurs frequent communication between experts and parameter servers, creating synchronization bottlenecks where computation and communication happen sequentially. This sequential execution limits training throughput and scalability.

**Method:** Lancet overlaps computation and communication in Mixture-of-Experts training by using pipelining (breaking work into stages) and scheduling to identify which computations don't depend on each other. These independent tasks can run while data moves between distributed experts (different processors) and parameter servers (where shared model parameters are stored). By coordinating this overlap across the entire computation graph rather than piece-by-piece at individual layers, Lancet hides communication delays behind productive work.

**Novelty:** Lancet's core idea is overlapping computation and communication at the whole-graph level for Mixture-of-Experts training, instead of doing it piece-by-piece at individual layers.
