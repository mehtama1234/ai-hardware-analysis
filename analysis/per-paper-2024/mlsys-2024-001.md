# Does Compressing Activations Help Model Parallel Training?

**Problem:** Model parallel training requires substantial activation communication between partitioned devices, creating a communication bottleneck. The core question is whether activation compression can reduce this overhead while maintaining training convergence.

**Method:** The paper tests compression techniques on intermediate training data (activations) that must be communicated between devices in model parallel training, where large models are split across multiple GPUs. It applies compression methods like quantization (representing data with fewer bits) and sparsity (removing unimportant values), then measures how much communication volume shrinks, whether training speed stays acceptable, and if models still converge correctly. Testing spans different model parallelism strategies to understand the tradeoff between communication savings and the overhead of compression itself.

**Novelty:** The paper empirically tests whether compressing intermediate training data reduces communication overhead in multi-device model training while maintaining training convergence.
