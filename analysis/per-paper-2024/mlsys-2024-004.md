# SLoRA: Scalable Serving of Thousands of LoRA Adapters

**Problem:** Serving thousands of different LoRA adapters concurrently requires prohibitive memory and compute resources, as naive approaches load each adapter independently. Existing systems only scale to dozens of adapters.

**Method:** SLoRA uses intelligent scheduling and memory virtualization to enable thousands of concurrent adapters on limited GPU resources. The system employs dynamic adapter loading/unloading, request batching across adapters, memory pooling, and prefix caching to reduce per-adapter overhead and maximize resource utilization.

**Novelty:** First system to demonstrate serving thousands of LoRA adapters through efficient scheduling and memory virtualization on commodity GPUs.
