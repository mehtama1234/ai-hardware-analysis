# SLoRA: Scalable Serving of Thousands of LoRA Adapters

**Problem:** Serving thousands of different LoRA adapters concurrently requires prohibitive memory and compute resources, as naive approaches load each adapter independently. Existing systems only scale to dozens of adapters.

**Method:** SLoRA serves thousands of different LoRA adapters (small model customizations) from a single GPU by swapping adapters in and out of memory as requests arrive, rather than keeping them all loaded. The system batches together requests for different adapters so the GPU processes them in parallel, uses shared memory pools instead of giving each adapter its own space, and reuses computation across requests (prefix caching). These techniques let thousands of specialized models run on a single commodity GPU without exhausting memory or compute resources.

**Novelty:** SLoRA is the first system to serve thousands of LoRA adapters on a single commodity GPU by scheduling which adapters to load when and dynamically sharing GPU memory between them.
