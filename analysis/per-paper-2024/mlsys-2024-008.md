# On Latency Predictors for Neural Architecture Search

**Problem:** Neural Architecture Search requires evaluating numerous candidate architectures, which is computationally expensive. Accurately predicting hardware latency without executing each candidate would significantly reduce the search cost.

**Method:** Develops a machine learning model trained on architecture-latency pairs to predict execution latency for unseen candidates. The predictor learns relationships between architecture features and measured latency, enabling quick evaluation without actual execution.

**Novelty:** A latency prediction model that replaces expensive architecture evaluation in the NAS feedback loop.
