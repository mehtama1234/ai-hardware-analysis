# On Latency Predictors for Neural Architecture Search

**Problem:** Neural Architecture Search requires evaluating numerous candidate architectures, which is computationally expensive. Accurately predicting hardware latency without executing each candidate would significantly reduce the search cost.

**Method:** The approach trains a machine learning model on examples of past neural architectures and how fast they actually executed. This model learns patterns about which design choices (like the number of layers or connection patterns) affect execution speed. Instead of building and running each candidate architecture to measure its speed, the search process now just uses the trained model to instantly predict speed for new candidates. This replaces slow physical execution with fast predictions, dramatically reducing the time needed to search for good architectures.

**Novelty:** Instead of running each architecture candidate to measure speed, use a trained model to predict speed from design features.
