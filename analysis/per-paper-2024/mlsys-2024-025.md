# LIFL: A Lightweight, Event-driven Serverless Platform for Federated Learning

**Problem:** Federated learning systems require stateful coordination of distributed participants across network communication, which conflicts with the stateless, short-lived execution model of serverless platforms. Deploying FL on serverless infrastructure incurs high orchestration overhead and coordination latency.

**Method:** LIFL models FL orchestration as event-driven workflows where serverless functions handle participant registration, parameter aggregation, and model updates triggered by completion events rather than polling or persistent connections. Lightweight event handlers coordinate training rounds asynchronously, reducing long-running stateful processes and leveraging serverless platform elasticity.

**Novelty:** Event-driven serverless architecture that decouples FL orchestration from stateful coordination, eliminating overhead of traditional centralized parameter servers.
