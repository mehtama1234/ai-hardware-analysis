# LIFL: A Lightweight, Event-driven Serverless Platform for Federated Learning

**Problem:** Federated learning systems require stateful coordination of distributed participants across network communication, which conflicts with the stateless, short-lived execution model of serverless platforms. Deploying FL on serverless infrastructure incurs high orchestration overhead and coordination latency.

**Method:** LIFL breaks federated learning into serverless functions (cloud programs that run on-demand without managing servers) that activate only when something finishes—like when a participant completes training—instead of constantly checking for updates. These functions handle participant registration, collect and average model parameters across sites, and send out updated models through event-driven triggers. This approach eliminates the overhead of long-running coordination processes, letting the system automatically scale based on demand.

**Novelty:** Instead of always-on central servers, LIFL uses serverless functions triggered by events, so coordination only runs when participants finish work—cutting the overhead of continuously maintaining state.
