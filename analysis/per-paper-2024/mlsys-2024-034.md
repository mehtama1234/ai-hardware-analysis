# HeteGen: Efficient Heterogeneous Parallel Inference for Large Language Models on Resource-Constrained Devices

**Problem:** Large language models require substantial computational and memory resources, making inference on resource-constrained edge devices (mobile, IoT, embedded systems) infeasible with single hardware accelerators. Existing inference systems cannot efficiently leverage multiple heterogeneous hardware resources simultaneously on such devices.

**Method:** HeteGen distributes LLM inference computation across heterogeneous hardware accelerators available on resource-constrained devices through dynamic workload partitioning. The system assigns different layers or operations to the most suitable hardware (CPU, GPU, NPU) based on their computational characteristics and hardware capabilities. A scheduling layer coordinates execution and communication across heterogeneous components to minimize idle time and synchronization overhead.

**Novelty:** A heterogeneous parallel inference framework that dynamically partitions and schedules LLM workloads across multiple hardware resources on edge devices to maximize hardware utilization and minimize inference latency.
