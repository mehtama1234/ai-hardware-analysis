# HeteGen: Efficient Heterogeneous Parallel Inference for Large Language Models on Resource-Constrained Devices

**Problem:** Large language models require substantial computational and memory resources, making inference on resource-constrained edge devices (mobile, IoT, embedded systems) infeasible with single hardware accelerators. Existing inference systems cannot efficiently leverage multiple heterogeneous hardware resources simultaneously on such devices.

**Method:** HeteGen runs large language models on resource-constrained devices like phones by splitting the computational work across available hardware accelerators—CPUs, GPUs, and NPUs. Rather than sending all the work to one chip, it dynamically decides at runtime which operations go to which hardware based on what each chip handles fastest. A scheduling layer coordinates execution and communication between the chips, keeping them all working in parallel to avoid idle time and delays.

**Novelty:** HeteGen speeds up large language model predictions on phones and other resource-limited devices by dynamically splitting work across different hardware accelerators (CPU, GPU, NPU) so they all run in parallel.
