# VQPy: An Object-Oriented Approach to Modern Video Analytics

**Problem:** Video analytics systems struggle with modularity and composability when building complex processing pipelines. Imperative approaches lack abstraction mechanisms for reusable, optimizable video operations.

**Method:** VQPy provides an object-oriented abstraction layer enabling modular composition of video processing operations. The framework uses declarative query patterns to specify analytics tasks. A compiler optimizes query execution through operation fusion, scheduling, and mapping to hardware accelerators like GPUs.

**Novelty:** Object-oriented abstraction paradigm for expressing video analytics queries with emphasis on composability and automated optimization.
