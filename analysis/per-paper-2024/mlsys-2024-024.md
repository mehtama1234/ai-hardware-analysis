# Torch2Chip: An End-to-end Customizable Deep Neural Network Compression and Deployment Toolkit for Prototype Hardware Accelerator Design

**Problem:** Deploying neural networks to custom hardware accelerators requires integrated optimization, compression, and compilation steps that are not unified. Practitioners lack end-to-end tooling for compressing models and mapping them to prototype accelerator specifications.

**Method:** Torch2Chip takes PyTorch neural network models and automatically makes them smaller through compression techniques: quantization (using fewer bits to represent numbers) and sparsity optimization (removing unnecessary connections). It then converts these compressed models into hardware-specific code that maps each operation in the network to the right resources on the target accelerator.

**Novelty:** Torch2Chip integrates neural network compression, compilation, and hardware mapping into a single customizable toolkit for deploying PyTorch models to custom accelerators.
