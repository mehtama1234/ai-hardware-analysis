# Accurate Low-Degree Polynomial Approximation of Non-Polynomial Operators for Fast Private Inference in Homomorphic Encryption

**Problem:** Non-polynomial operators such as activation functions cannot be directly computed in homomorphic encryption schemes, forcing private inference to rely on expensive polynomial approximations that degrade both speed and accuracy.

**Method:** To run neural networks on encrypted data using homomorphic encryption (a method to compute on encrypted data without decrypting it), the paper replaces activation functions like ReLU and sigmoid—which can't be directly computed—with low-degree polynomials (simplified mathematical expressions). The technique carefully balances the number of polynomial terms to achieve accurate approximations while keeping computation fast, avoiding the expensive high-degree polynomials typically needed for private neural network inference.

**Novelty:** The core method is using low-degree polynomials (simplified mathematical expressions) to replace activation functions like ReLU and sigmoid in encrypted neural networks, making it possible to run them efficiently without expensive high-degree polynomial approximations.
