# Neural Network Accelerator with Dataflow-Optimized Memory Hierarchy

**Problem:** Conventional memory hierarchies in neural network accelerators do not adapt to dataflow patterns, resulting in performance and energy inefficiencies for CNN inference. The static bandwidth allocation of traditional designs fails to match the dynamic memory access patterns of dataflow-driven computation.

**Method:** The accelerator has two levels of fast on-chip memory, and it watches how data actually flows during CNN inference. When one memory level gets overloaded while another sits idle, the system adjusts bandwidth allocation—how much data can move between levels—to rebalance the flow. This avoids bottlenecks and moves data faster than traditional accelerators that use the same bandwidth allocation regardless of what the network is doing.

**Novelty:** The memory hierarchy adjusts how much data can flow between levels based on the actual dataflow of the neural network computation, rather than using a fixed design for all cases.
