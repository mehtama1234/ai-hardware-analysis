# Neural Network Accelerator with Dataflow-Optimized Memory Hierarchy

**Problem:** Conventional memory hierarchies in neural network accelerators do not adapt to dataflow patterns, resulting in performance and energy inefficiencies for CNN inference. The static bandwidth allocation of traditional designs fails to match the dynamic memory access patterns of dataflow-driven computation.

**Method:** The design implements a two-level on-chip memory system with dynamic bandwidth allocation that matches dataflow patterns. The memory hierarchy monitors computation flow during CNN inference and adjusts bandwidth allocation across levels to reduce bottlenecks and optimize data movement.

**Novelty:** Dynamic bandwidth allocation in the memory hierarchy that adapts to dataflow patterns rather than using fixed conventional architectures.

**Theme:** Dataflow-optimized memory hierarchy for CNN acceleration
