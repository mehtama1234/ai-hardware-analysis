# JIT-Q: Just-in-time Quantization with Processing-In-Memory for Efficient ML Training

**Problem:** ML training incurs substantial memory bandwidth overhead and compute inefficiency. Applying quantization during training requires efficient mechanisms to reduce precision without sacrificing model accuracy or requiring excessive data movement.

**Method:** JIT-Q addresses training's memory bandwidth problem by reducing numerical precision (quantizing) on-the-fly rather than storing full-precision numbers. It uses processing-in-memory (PIM)—specialized hardware that performs calculations directly inside the memory system where data lives. By co-locating quantization with PIM, the system computes using lower-precision numbers in-place within memory, avoiding the data movement that would otherwise bottleneck training performance.

**Novelty:** Combining on-the-fly quantization with processing-in-memory enables training computations to happen in-place within memory using reduced precision, eliminating data-movement overhead.
