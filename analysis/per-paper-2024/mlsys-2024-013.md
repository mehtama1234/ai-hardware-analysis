# ACROBAT: Optimizing Auto-batching of Dynamic Deep Learning at Compile Time

**Problem:** Dynamic deep learning workloads have unpredictable batch sizes and tensor shapes at runtime, making it difficult to optimize batching strategies in advance. Compile-time systems struggle to generate efficient batching code without knowing the actual dynamic characteristics.

**Method:** ACROBAT predicts how data shapes and sizes will vary at runtime, then uses those predictions at compile time to determine the best batching strategy (grouping data into batches of similar size for efficient processing). It generates specialized code that handles multiple different data sizes efficiently without needing to make slow decisions during actual execution.

**Novelty:** ACROBAT optimizes batching strategies at compile time, even though the actual data sizes won't be known until the program runs.
