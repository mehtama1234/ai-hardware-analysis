# DiffusionPipe: Training Large Diffusion Models with Efficient Pipelines

**Problem:** Training large-scale diffusion models incurs prohibitive memory and computational costs due to sequential denoising across many timesteps and the need to maintain large intermediate activations. Pipeline parallelism becomes inefficient for diffusion models because of their strong sequential dependencies and dynamic timestep-based computation patterns.

**Method:** DiffusionPipe applies pipeline parallelism—splitting the model across multiple GPUs like an assembly line—but tailors it to how diffusion models work. The key insight is that diffusion's sequential denoising steps create different computational patterns than other models, so DiffusionPipe arranges pipeline stages to match these dependencies and schedules GPU execution to minimize idle waiting time. It also overlaps data transfer between GPUs with computation, hiding the communication cost.

**Novelty:** DiffusionPipe's core contribution is pipeline parallelism (splitting model work across GPUs) built specifically to handle diffusion models' sequential denoising steps, rather than using generic parallelism strategies from other model types.
