# Keyformer: KV Cache reduction through key tokens selection for Efficient Generative Inference

**Problem:** KV cache grows linearly with sequence length during LLM inference, creating severe memory bandwidth and storage bottlenecks that limit throughput and increase latency. This overhead becomes critical for long-context generation and resource-constrained deployments.

**Method:** During text generation, an LLM keeps cached attention data (the stored key-value pairs for every token seen so far) to help predict the next words. Keyformer identifies which of these tokens will actually matter for future predictions—using attention pattern analysis or scoring each token's predicted usefulness—then discards the cached data for less-important tokens. By keeping only essential cached data, it reduces memory bandwidth (the amount of data the GPU fetches per generation step) and storage overhead, while maintaining generation accuracy.

**Novelty:** Keyformer prunes the KV cache to only the most-important tokens based on predicted usefulness, rather than always retaining the complete cache.
