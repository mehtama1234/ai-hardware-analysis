# Keyformer: KV Cache reduction through key tokens selection for Efficient Generative Inference

**Problem:** KV cache grows linearly with sequence length during LLM inference, creating severe memory bandwidth and storage bottlenecks that limit throughput and increase latency. This overhead becomes critical for long-context generation and resource-constrained deployments.

**Method:** Keyformer selects a subset of tokens (key tokens) deemed most important for future attention computations, pruning less critical key-value pairs from the cache. The selection mechanism likely employs attention pattern analysis or importance scoring to identify which tokens remain essential during generation. This sparse cache representation reduces memory bandwidth requirements and storage overhead while maintaining inference accuracy.

**Novelty:** Using token-level importance-based selection to prune KV cache dynamically rather than materializing the full cache, achieving significant inference efficiency gains.
