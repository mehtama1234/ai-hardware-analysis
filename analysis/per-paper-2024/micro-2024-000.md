# Duplex: A Device for Large Language Models with Mixture of Experts, Grouped Query Attention, and Continuous Batching

**Problem:** LLM inference requires managing sparse computation through mixture of experts, reducing key-value cache memory overhead via grouped query attention, and maximizing hardware utilization through dynamic request batching. Existing systems do not co-optimize these three mechanisms in hardware.

**Method:** Duplex implements a specialized hardware device with native support for mixture of experts routing logic, grouped query attention that shares key-value heads across query heads to reduce memory bandwidth, and continuous batching that dynamically schedules inference requests to maintain high utilization.

**Novelty:** Co-designed hardware accelerator that integrates MoE routing, GQA, and continuous batching as first-class primitives rather than software-simulated techniques.
