# Duplex: A Device for Large Language Models with Mixture of Experts, Grouped Query Attention, and Continuous Batching

**Problem:** LLM inference requires managing sparse computation through mixture of experts, reducing key-value cache memory overhead via grouped query attention, and maximizing hardware utilization through dynamic request batching. Existing systems do not co-optimize these three mechanisms in hardware.

**Method:** Duplex is specialized hardware designed to run large language models by addressing three performance bottlenecks at once. It implements mixture of experts routing (directing each input through only the relevant neural network modules rather than all of them), grouped query attention (having multiple query heads share the same cached key-value information instead of storing separate copies), and continuous batching (processing multiple requests concurrently and adding new ones as old ones finish). These three mechanisms are built directly into the hardware circuit rather than simulated by software, eliminating the performance cost and complexity of trying to implement them in software.

**Novelty:** Duplex co-optimizes mixture of experts routing, grouped query attention, and continuous batching directly in hardware instead of implementing them separately in software.
