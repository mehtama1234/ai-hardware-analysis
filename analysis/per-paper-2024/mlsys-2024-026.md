# UniDM: A Unified Framework for Data Manipulation with Large Language Models

**Problem:** Data manipulation tasks like cleaning, transformation, and integration are typically handled by separate specialized tools and systems. A unified framework that can handle diverse data manipulation operations is needed.

**Method:** UniDM uses a single large language model (an AI trained on vast amounts of text) to understand what data represents and handle multiple data tasks—cleaning errors, converting formats, and merging different sources—through one unified interface. The model's reasoning capabilities let it figure out what steps are needed for each task, rather than requiring separate specialized tools for cleaning, transformation, and integration.

**Novelty:** Using a single large language model to handle all data manipulation tasks instead of relying on separate specialized tools for each type of work.
