# Reconfigurable Computing Platform for Dynamic Neural Architecture Search

**Problem:** Neural architecture search (NAS) requires exploring numerous network designs, which is computationally expensive when done in software. Current software-only NAS approaches are slow for iterative design exploration and limit the scope of searchable architectures.

**Method:** The system uses an FPGA (field-programmable gate array—hardware that can be electronically reconfigured to change how it processes information) to physically adapt itself for each different neural network design being tested. Rather than running calculations one at a time through software, the reconfigured hardware performs many calculations simultaneously in parallel and efficiently coordinates the flow of data between them. Compared to testing all designs entirely in software, this approach achieves a 10x speedup.

**Novelty:** Instead of using fixed software or fixed hardware to test all network designs, this approach dynamically reconfigures an FPGA's internal circuits for each different architecture being tested.

**Theme:** FPGA-accelerated neural architecture search
