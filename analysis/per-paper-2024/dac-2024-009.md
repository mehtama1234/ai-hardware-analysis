# Reconfigurable Computing Platform for Dynamic Neural Architecture Search

**Problem:** Neural architecture search (NAS) requires exploring numerous network designs, which is computationally expensive when done in software. Current software-only NAS approaches are slow for iterative design exploration and limit the scope of searchable architectures.

**Method:** The platform uses a reconfigurable FPGA to dynamically adapt hardware configurations for different neural network architectures. It accelerates candidate design evaluation through hardware-level parallelism and efficient dataflow orchestration, achieving 10x speedup compared to software-only NAS approaches.

**Novelty:** Reconfigurable FPGA-based acceleration of neural architecture search with dynamic hardware adaptation to different network designs.

**Theme:** FPGA-accelerated neural architecture search
