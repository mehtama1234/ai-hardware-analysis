# Genie Cache: Non-Blocking Miss Handling and Replacement in Page-Table-Based DRAM Cache

**Problem:** DRAM caches suffer from blocking cache misses that serialize subsequent memory operations, reducing throughput. Existing cache replacement policies in page-table-based DRAM caches lack non-blocking mechanisms.

**Method:** Genie Cache repurposes the page-table structures (hardware tables that normally map virtual addresses to physical memory) to track which data is currently cached. Instead of making the CPU wait when a data request misses the cache, requests are queued and processed in parallel, letting other operations continue. The system decides which cached data to remove when space is needed using rules built into the page-table mechanism, managing capacity efficiently without slowing concurrent requests.

**Novelty:** It enables non-blocking handling of cache misses by using page-table structures to track cache state, allowing multiple misses to be resolved at the same time instead of one after another.
