# Genie Cache: Non-Blocking Miss Handling and Replacement in Page-Table-Based DRAM Cache

**Problem:** DRAM caches suffer from blocking cache misses that serialize subsequent memory operations, reducing throughput. Existing cache replacement policies in page-table-based DRAM caches lack non-blocking mechanisms.

**Method:** Genie Cache uses page-table entries to track cache state and decouple miss handling from the critical path. Misses are processed in parallel via a queue without blocking subsequent operations. The replacement policy is integrated with page-table mechanisms to manage cache capacity efficiently while supporting concurrent miss resolution.

**Novelty:** Non-blocking miss handling using page-table-based state tracking to enable parallel resolution of DRAM cache misses without serialization.
