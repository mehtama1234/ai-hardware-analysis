# COMET: Neural Cost Model Explanation Framework

**Problem:** Neural cost models predict hardware metrics like latency, power, and area but operate as black boxes, preventing designers from understanding which architectural features most influence predictions. This opacity limits trust in ML-based hardware design automation and makes it difficult to optimize designs based on cost model insights.

**Method:** COMET applies explanation techniques from explainable AI to reveal why neural cost models make their predictions. It likely uses methods such as feature attribution (identifying which architectural parameters matter most), attention visualization (showing which parts the model focuses on), or gradient-based analysis (tracking how input changes propagate). The framework translates these internal mechanisms into human-readable explanations connected to actual hardware design choices.

**Novelty:** First framework to systematically explain neural cost model predictions, showing which hardware design choices actually cause changes in predicted latency, power, and area.
