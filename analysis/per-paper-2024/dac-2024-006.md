# Thermal-Aware Scheduling for Heterogeneous CPU-GPU Systems

**Problem:** Efficiently scheduling tasks across heterogeneous CPU-GPU systems while managing thermal constraints that can limit performance and reliability. Traditional schedulers fail to account for thermal dynamics when mapping workloads across different core types.

**Method:** The algorithm continuously monitors the temperature of each CPU and GPU core, then assigns tasks to cores based on what each task needs and which cores still have capacity before overheating. When a core gets too hot, the system moves its tasks to cooler cores. By treating heat management as equally important as performance in its scheduling decisions, the system keeps all cores productive while staying within a fixed power budget (the total electrical power available).

**Novelty:** The system makes keeping cores cool a primary scheduling goal—treated with the same importance as performance—and actively balances the two by moving tasks between CPU and GPU cores in real time.
