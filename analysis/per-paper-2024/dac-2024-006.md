# Thermal-Aware Scheduling for Heterogeneous CPU-GPU Systems

**Problem:** Efficiently scheduling tasks across heterogeneous CPU-GPU systems while managing thermal constraints that can limit performance and reliability. Traditional schedulers fail to account for thermal dynamics when mapping workloads across different core types.

**Method:** The algorithm dynamically maps tasks to CPU and GPU cores based on real-time thermal state and task characteristics. It continuously monitors core temperatures and adjusts task allocation to prevent thermal violations. The approach integrates thermal feedback as a first-class constraint in scheduling decisions, optimizing performance within a fixed power envelope.

**Novelty:** Dynamic task scheduling that integrates real-time thermal monitoring and constraints as a primary optimization target alongside performance in heterogeneous CPU-GPU systems.

**Theme:** thermal-aware heterogeneous scheduling
