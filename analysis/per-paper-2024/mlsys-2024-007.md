# VIDUR: A Large-Scale Simulation Framework for LLM Inference

**Problem:** Optimizing large-scale LLM inference systems requires expensive hardware experimentation and prototyping. Existing simulation tools lack the fidelity to accurately model modern LLM serving with diverse hardware backends and dynamic workloads at scale.

**Method:** VIDUR is a simulation tool that predicts how large AI language models will perform when running on computer systems. You input hardware specifications (the processors, memory systems, and network connections between machines), actual user request patterns, and the tool simulates the full execution to estimate system performance. It can model multiple machines working together and handle setups that mix different types of hardware.

**Novelty:** A simulation tool purpose-built to predict AI language model inference performance by accurately modeling both how the language models compute and how real-world systems serve them.
