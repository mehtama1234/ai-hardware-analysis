# VIDUR: A Large-Scale Simulation Framework for LLM Inference

**Problem:** Optimizing large-scale LLM inference systems requires expensive hardware experimentation and prototyping. Existing simulation tools lack the fidelity to accurately model modern LLM serving with diverse hardware backends and dynamic workloads at scale.

**Method:** VIDUR provides a configurable simulation framework that models compute units, memory hierarchy, and network interconnects. It accepts hardware specifications and LLM workload traces, then simulates end-to-end execution to predict performance metrics. The framework supports multi-device simulations and heterogeneous hardware configurations.

**Novelty:** A large-scale simulation framework specifically optimized for LLM inference that captures transformer characteristics and modern serving system dynamics.
