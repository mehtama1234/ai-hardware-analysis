# Supply-Chain Security in Hardware Design for AI Systems

**Problem:** Supply-chain attacks can introduce unauthorized hardware modifications to AI accelerators that evade detection, compromising system integrity and security at manufacturing or design stages.

**Method:** The framework combines formal verification to mathematically prove hardware design correctness against threat models with runtime hardware security monitoring to detect deviations. Verification establishes design-time guarantees while monitoring catches runtime unauthorized modifications, maintaining security with minimal performance overhead through selective instrumentation.

**Novelty:** Integration of formal verification with lightweight hardware security monitoring to systematically detect supply-chain attacks in AI hardware while preserving performance efficiency.

**Theme:** supply-chain security in AI hardware
