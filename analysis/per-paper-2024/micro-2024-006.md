# Stream-Based Data Placement for Near-Data Processing with Extended Memory

**Problem:** Data placement decisions in heterogeneous memory hierarchies with near-data processing capabilities must balance locality and throughput as data streams traverse different memory tiers. Efficiently mapping streaming data to extended memory regions near processing elements remains unresolved.

**Method:** This approach treats data movement as streams—patterns of how data flows through the processor. It analyzes which data chunks are used together repeatedly and how much data traffic they create, then places those chunks in the fastest memory closest to the processor. As the program runs, it continuously moves data between different memory layers, keeping frequently-needed data close and moving rarely-used data further away, based on the actual streaming patterns it observes.

**Novelty:** It places data based on how it actually streams through the system, rather than using pre-determined storage decisions.
