# Stream-Based Data Placement for Near-Data Processing with Extended Memory

**Problem:** Data placement decisions in heterogeneous memory hierarchies with near-data processing capabilities must balance locality and throughput as data streams traverse different memory tiers. Efficiently mapping streaming data to extended memory regions near processing elements remains unresolved.

**Method:** Stream-based data placement characterizes data access patterns as streams and uses this information to guide allocation across extended memory regions. The approach likely profiles streaming characteristics of kernels and dynamically places data blocks in memory tiers closest to processing elements based on reuse patterns and bandwidth requirements.

**Novelty:** Stream-centric data placement policy specifically designed for near-data processing architectures with heterogeneous extended memory.
