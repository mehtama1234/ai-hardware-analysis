# Multi-Issue Butterfly Architecture for Sparse Convex Quadratic Programming

**Problem:** General-purpose architectures suffer from poor hardware utilization when performing sparse matrix operations such as factorization and multiplication in convex quadratic programming solvers. Achieving optimal performance is challenged by the sparse nature of objective and constraint matrices.

**Method:** Multi-Issue Butterfly (MIB) is a processor with parallel stages arranged in a butterfly network (a specific data-routing topology), where each stage can dynamically switch what operation it performs. For sparse matrix factorization, it reorders instructions using an elimination tree (a structure derived from the matrix) to prevent data hazards (conflicts where one instruction waits for another's result). For matrix-vector multiplication, it prefetches data (loads values early) to avoid register file stalls (delays when fast memory can't supply intermediate values quickly enough). Multiple instructions execute simultaneously whenever there are no such hazards, maximizing throughput.

**Novelty:** A butterfly-network processor that adapts instruction scheduling to sparse matrix structures, eliminating data and memory conflicts that would otherwise slow parallel execution.
