# Multi-Issue Butterfly Architecture for Sparse Convex Quadratic Programming

**Problem:** General-purpose architectures suffer from poor hardware utilization when performing sparse matrix operations such as factorization and multiplication in convex quadratic programming solvers. Achieving optimal performance is challenged by the sparse nature of objective and constraint matrices.

**Method:** Multi-Issue Butterfly (MIB) proposes a pipelined spatial architecture with a butterfly computational network where each node has runtime-controlled working modes. For factorization, an elimination tree guides instruction reordering to avoid data hazards from dependencies. For matrix-vector multiplication, data prefetching resolves structural hazards in register file access. Multi-issue execution enables simultaneous instruction issue when hazards are absent to maximize pipeline throughput.

**Novelty:** A pipelined spatial butterfly architecture that adapts to sparse matrix structures through sparsity-aware scheduling and specialized hazard avoidance mechanisms.
