# Efficient Post-training Quantization with FP8 Formats

**Problem:** Post-training quantization of neural networks requires balancing model accuracy with computational efficiency when reducing precision. FP8 formats offer a narrow 8-bit floating-point representation that must preserve model behavior without retraining.

**Method:** Converts the weights and activations (the numerical parameters that determine how a neural network makes predictions) from full precision down to an 8-bit floating-point format—a compact representation that uses much less memory and computes faster. The technique uses calibration (systematically testing different ways to map the original numbers into the 8-bit range) and smart rounding strategies to keep accuracy loss minimal during the conversion. Because no retraining occurs, the method must find the right mapping purely by analyzing the original numbers, without teaching the network anything new.

**Novelty:** An 8-bit floating-point format (FP8) enables you to shrink fully-trained neural networks without retraining them.
