# Efficient Post-training Quantization with FP8 Formats

**Problem:** Post-training quantization of neural networks requires balancing model accuracy with computational efficiency when reducing precision. FP8 formats offer a narrow 8-bit floating-point representation that must preserve model behavior without retraining.

**Method:** Applies FP8 floating-point quantization to pre-trained models using format conversion and calibration techniques. Maps full-precision weights and activations to 8-bit floating-point representation while minimizing accuracy loss through careful range selection and rounding strategies.

**Novelty:** Efficient use of FP8 format specifically for post-training quantization without requiring model retraining.
