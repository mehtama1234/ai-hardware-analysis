# FlashDecoding++: Faster Large Language Model Inference with Asynchronization, Flat GEMM Optimization, and Heuristics

**Problem:** LLM inference is bottlenecked by synchronization overhead between kernel operations and inefficient GEMM (general matrix multiplication) memory access patterns. Current decoding implementations use suboptimal scheduling that leaves hardware resources underutilized.

**Method:** The system eliminates synchronization barriers through asynchronous kernel execution that enables operations to proceed without waiting for completion. Flat GEMM optimization transforms strided memory layouts into contiguous layouts to improve cache efficiency and throughput. Heuristics adaptively choose scheduling strategies and batch sizes based on hardware characteristics and current workload properties.

**Novelty:** Combining asynchronization with flat GEMM layouts to reduce synchronization stalls and improve memory efficiency simultaneously in token generation workloads.
