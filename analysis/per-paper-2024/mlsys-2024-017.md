# FlashDecoding++: Faster Large Language Model Inference with Asynchronization, Flat GEMM Optimization, and Heuristics

**Problem:** LLM inference is bottlenecked by synchronization overhead between kernel operations and inefficient GEMM (general matrix multiplication) memory access patterns. Current decoding implementations use suboptimal scheduling that leaves hardware resources underutilized.

**Method:** The system avoids synchronization overhead by running operations asynchronously—letting them proceed without waiting for each other to complete. It optimizes matrix multiplication (GEMM) by improving the memory layout: instead of accessing memory in a scattered way that skips around (strided pattern), data is arranged to be read sequentially (contiguous layout), which improves cache efficiency and throughput. Heuristics then adaptively adjust the scheduling strategy and batch sizes based on the hardware and workload, preventing underutilization.

**Novelty:** Combining asynchronous kernel execution with flat GEMM optimization to simultaneously reduce synchronization stalls and improve memory efficiency in token generation.
