# Heterogeneous Chiplet Integration for Flexible AI Workload Execution

**Problem:** Monolithic AI accelerator designs cannot efficiently adapt to varying compute requirements of diverse AI workloads, resulting in suboptimal resource utilization and inefficient performance per watt. Different AI applications require different ratios of GPU, NPU, and CPU compute resources.

**Method:** The architecture integrates multiple compute chiplets (GPU, NPU, CPU) connected via a flexible interconnect fabric that dynamically routes data and adapts resource allocation based on workload requirements. The flexible interconnect enables efficient communication between different compute elements to execute diverse AI workloads.

**Novelty:** Dynamic chiplet-based heterogeneous architecture with flexible interconnect that adapts compute resource allocation to varying AI workload requirements.

**Theme:** heterogeneous chiplet architecture for adaptive AI execution
