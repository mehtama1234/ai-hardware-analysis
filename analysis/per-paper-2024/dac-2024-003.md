# Heterogeneous Chiplet Integration for Flexible AI Workload Execution

**Problem:** Monolithic AI accelerator designs cannot efficiently adapt to varying compute requirements of diverse AI workloads, resulting in suboptimal resource utilization and inefficient performance per watt. Different AI applications require different ratios of GPU, NPU, and CPU compute resources.

**Method:** The system combines multiple specialized chips (a GPU for graphics-heavy tasks, an NPU for AI-specific operations, and a CPU for general computing) connected through a flexible network. This network dynamically watches what the AI workload is doing and routes computation to the right chip for each part of the job. It also adjusts how much computing power each chip is using, ensuring resources match the workload's requirements moment-to-moment.

**Novelty:** A system with multiple different specialized chips (GPU, NPU, CPU) that automatically adjusts which chip does what work based on the AI workload's requirements.

**Theme:** heterogeneous chiplet architecture for adaptive AI execution
