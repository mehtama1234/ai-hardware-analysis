# Proteus: Preserving Model Confidentiality during Graph Optimizations

**Problem:** ML models undergoing compiler optimizations (fusion, scheduling, quantization) risk exposing proprietary model architecture and parameters through intermediate graph representations. Existing ML compilers do not protect model confidentiality during transformation passes.

**Method:** Proteus protects a machine learning model during compiler optimization by keeping its computation graph (the blueprint of operations and data flows) encrypted or scrambled. Even while locked this way, the system can apply standard speedup techniques: kernel fusion (merging small operations together), memory scheduling (deciding when and where to move data), and layout transformations (reorganizing how data is stored). The model remains encrypted throughout, so its architecture and parameters never get exposed.

**Novelty:** Enables full compiler optimizations—kernel fusion, memory scheduling, and data reorganization—on encrypted machine learning models without decrypting the model's architecture or parameters.
