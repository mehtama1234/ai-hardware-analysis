# Proteus: Preserving Model Confidentiality during Graph Optimizations

**Problem:** ML models undergoing compiler optimizations (fusion, scheduling, quantization) risk exposing proprietary model architecture and parameters through intermediate graph representations. Existing ML compilers do not protect model confidentiality during transformation passes.

**Method:** Proteus encrypts or obfuscates computation graphs during optimization while applying standard compiler transformations. The system likely uses cryptographic techniques or homomorphic properties to perform optimizations (kernel fusion, memory scheduling, layout transformations) without decrypting intermediate representations. Graph structure and parameters remain protected throughout the compilation pipeline.

**Novelty:** Enabling full graph-level optimizations (fusion, scheduling, memory management) while maintaining cryptographic confidentiality of model architecture throughout compilation.
