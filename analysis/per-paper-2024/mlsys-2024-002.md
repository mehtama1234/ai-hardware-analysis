# AWQ: Activation-aware Weight Quantization for On-Device LLM Compression and Acceleration

**Problem:** Large language models are too large and compute-intensive for efficient on-device inference. Existing quantization methods do not account for activation patterns, leading to suboptimal compression-accuracy tradeoffs.

**Method:** AWQ compresses neural network weights (reducing bits per weight to save memory and speed up inference) by watching which parts of the network handle the largest values during actual use. Weights connected to channels with high-magnitude activations (the numerical data flowing through those channels) stay at higher precision, while weights in low-activation channels use lower precision, enabling sub-bit quantization while preserving accuracy. This per-channel adaptation is guided by observing real activation patterns rather than applying uniform compression everywhere.

**Novelty:** AWQ uses real activation patterns (the actual data flowing through the network) to decide how much each weight should be compressed, instead of using the weights' own statistics or applying uniform compression.
