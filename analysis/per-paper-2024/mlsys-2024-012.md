# SiDA: Sparsity-Inspired Data-Aware Serving for Efficient and Scalable Large Mixture-of-Experts Models

**Problem:** Serving large Mixture-of-Experts models at scale requires efficient routing and scheduling to handle high throughput while respecting latency constraints. Current systems do not adequately exploit the natural sparsity in MoE models where each token activates only a subset of experts.

**Method:** SiDA uses data-aware analysis of input characteristics to inform sparsity-inspired serving decisions. The system employs adaptive routing and batching strategies that exploit expert activation sparsity patterns, combining intelligent token-to-expert routing with memory-efficient scheduling to reduce end-to-end inference latency.

**Novelty:** Integrating data-aware serving with sparsity-inspired routing to dynamically adapt MoE inference strategies based on input data characteristics and activation patterns.
