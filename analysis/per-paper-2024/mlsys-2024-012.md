# SiDA: Sparsity-Inspired Data-Aware Serving for Efficient and Scalable Large Mixture-of-Experts Models

**Problem:** Serving large Mixture-of-Experts models at scale requires efficient routing and scheduling to handle high throughput while respecting latency constraints. Current systems do not adequately exploit the natural sparsity in MoE models where each token activates only a subset of experts.

**Method:** SiDA analyzes the characteristics of input data to guide its routing and batching decisions. For each token (a piece of text being processed), it routes only to the experts (specialized model components) needed for that token, rather than activating all experts. It also groups requests together in memory-efficient ways that fit hardware constraints. This approach exploits the natural sparsity in Mixture-of-Experts models—where each token typically uses only a subset of experts—to reduce the total processing time.

**Novelty:** SiDA uses the characteristics of input data to guide routing decisions that exploit the sparsity of Mixture-of-Experts models, activating only the experts each token needs.
