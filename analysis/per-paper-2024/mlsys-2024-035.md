# Atom: Low-Bit Quantization for Efficient and Accurate LLM Serving

**Problem:** Large language models require significant computational and memory resources for inference. Low-bit quantization can reduce these requirements but risks degrading model accuracy.

**Method:** The approach compresses language models using low-bit quantization (storing numbers with fewer bits of precision). Instead of applying quantization uniformly across all model parts, it tailors the compression specifically for the characteristics of language-model serving. This targeting preserves accuracy while cutting computation and memory requirements. The system then efficiently executes these compressed models on hardware.

**Novelty:** Tailoring low-bit quantization to the specific requirements of language-model serving makes it possible to have both efficiency and accuracy, rather than trading one for the other.
