# ICED: An Integrated CGRA Framework Enabling DVFS-Aware Acceleration

**Problem:** Existing coarse-grained reconfigurable architectures (CGRAs) lack integrated support for dynamic voltage and frequency scaling (DVFS), missing critical power-efficiency opportunities. Traditional DVFS mechanisms designed for general-purpose processors do not effectively map to reconfigurable dataflow accelerators.

**Method:** ICED integrates DVFS awareness at the CGRA microarchitecture level with voltage/frequency-aware resource management and dataflow scheduling. The framework includes compiler techniques to generate code optimized for different voltage-frequency operating points and runtime mechanisms to dynamically adapt DVFS based on workload demands and power constraints.

**Novelty:** First integrated CGRA design that natively incorporates DVFS support throughout the architecture, compiler, and runtime for power-efficient acceleration.
