# ICED: An Integrated CGRA Framework Enabling DVFS-Aware Acceleration

**Problem:** Existing coarse-grained reconfigurable architectures (CGRAs) lack integrated support for dynamic voltage and frequency scaling (DVFS), missing critical power-efficiency opportunities. Traditional DVFS mechanisms designed for general-purpose processors do not effectively map to reconfigurable dataflow accelerators.

**Method:** ICED embeds power-efficiency decisions throughout the system: the hardware design, the compiler (which generates optimized code for different power-speed tradeoffs), and the runtime (the system while code is running). The compiler pre-optimizes code for different voltage-frequency operating points. At runtime, the system monitors the workload and power budget, then automatically switches between optimized versions to reduce power when full performance isn't needed.

**Novelty:** ICED is the first reconfigurable-hardware design that builds voltage and frequency adjustment into the hardware, compiler, and runtime as an integrated system.
