# vMCU: Coordinated Memory Management and Kernel Optimization for DNN Inference on MCUs

**Problem:** Microcontroller units (MCUs) have severe memory constraints (typically kilobytes to tens of kilobytes) and limited processing power, making it extremely difficult to run deep neural network inference workloads. Existing systems treat memory management and kernel optimization independently, resulting in inefficient resource utilization.

**Method:** Instead of treating memory management and kernel optimization as separate problems, the system jointly schedules both together. It reduces memory usage through smart tensor allocation (placing data efficiently to minimize peak memory demand), in-place operations (modifying data without creating copies, reducing fragmentation), and operator fusion (combining operations to eliminate intermediate storage). The kernels themselves are optimized for MCU constraints using quantization-aware computation (processing lower-precision numbers that use less memory) and tiled execution (processing large tensors in smaller chunks that fit in available memory).

**Novelty:** The core idea is to jointly optimize memory management and kernel execution as a single scheduling problem, rather than treating them as separate optimization targets.
