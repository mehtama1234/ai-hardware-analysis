# Low-Power Inference Engine with Quantization-Aware Circuit Design

**Problem:** Power consumption limits inference deployment on edge devices. Standard neural networks require high-precision arithmetic, increasing circuit power overhead and silicon area.

**Method:** The approach trains ResNet-50 (a type of neural network) to work with reduced-precision numbers (fewer bits) rather than standard high-precision calculations—a process called quantization-aware training that lets the model learn to compensate for this constraint. Instead of building a general-purpose circuit, the hardware uses specialized arithmetic units designed specifically for these reduced-precision operations, which consume far less power. The dataflow (path data takes through the circuit) is optimized for these reduced-precision operations to avoid wasted computation.

**Novelty:** The key insight is building the circuit hardware and training the neural network together, rather than separately, so the network learns to work with the simplified arithmetic operations the circuit is designed for.

**Theme:** Low-power inference through quantization-aware circuit co-design
