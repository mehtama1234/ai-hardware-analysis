# Schrodinger's FP Training Neural Networks with Dynamic Floating-Point Containers

**Problem:** Neural network training requires substantial computational resources and memory due to fixed high-precision floating-point requirements throughout training. Training efficiency is bottlenecked by the cost of maintaining uniform precision across all operations.

**Method:** The system uses dynamic containers—wrappers that adjust the floating-point precision (how many bits represent each number) during training. Based on each training phase's needs, containers use lower precision (fewer bits, faster, more memory-efficient) when rounding error is tolerable, and higher precision (more bits, more accurate) when accuracy is critical. By adjusting precision on-the-fly rather than fixing it for the entire training run, the system trades computational efficiency against accuracy in a way that's optimized for each phase.

**Novelty:** Dynamic floating-point containers that automatically adjust precision during training based on what each training phase requires.
