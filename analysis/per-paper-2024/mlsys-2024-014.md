# QMoE: Sub-1-Bit Compression of Trillion Parameter Models

**Problem:** Trillion-parameter models require prohibitive storage and memory bandwidth for inference. Achieving sub-1-bit quantization while maintaining accuracy is challenging, especially for Mixture of Experts architectures.

**Method:** The approach compresses the model's trillion parameters to less than 1 bit each—a dramatic reduction in storage and memory needs. It exploits the Mixture of Experts architecture, where multiple specialized sub-networks exist but only some activate for each input (this sparsity is key). By applying different compression settings to each expert module based on its weight patterns, the technique achieves extreme compression while preserving accuracy.

**Novelty:** The key insight is that Mixture of Experts' sparsity—where only some expert modules activate per input—allows different experts to use tailored compression levels, enabling sub-1-bit compression of trillion-parameter models.
