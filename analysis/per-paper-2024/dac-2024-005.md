# In-Memory Computing Architecture Using Phase-Change Memory for Machine Learning

**Problem:** Conventional machine learning systems suffer from significant data movement bottlenecks between memory and compute units during matrix operations. This data transfer consumes disproportionate energy and limits performance scalability.

**Method:** The architecture uses phase-change memory (PCM) to enable computation directly within the memory hierarchy. Matrix operations are performed in-memory using PCM cells, eliminating the need to transfer data between separate DRAM and compute units, thereby reducing data movement overhead.

**Novelty:** Using phase-change memory for in-memory computing to eliminate data movement bottlenecks in machine learning matrix operations.

**Theme:** in-memory computing with phase-change memory
