# Accelerating ReLU for MPC-Based Private Inference with a Communication-Efficient Sign Estimation

**Problem:** ReLU activation functions are expensive to compute in Multi-Party Computation (MPC) based private inference systems due to their non-linear nature and high communication overhead between parties. Standard MPC protocols for ReLU require many rounds of secure computation.

**Method:** ReLU activation functions—which output the input number if positive or zero if negative—are costly to compute securely when multiple parties jointly perform the computation without revealing their data (a technique called Multi-Party Computation or MPC), normally requiring many rounds of back-and-forth messages between parties. This work accelerates ReLU by using a more efficient approach to calculate the sign (whether a number is positive or negative), which is the key decision ReLU needs to make, thereby reducing the number of communication rounds.

**Novelty:** A faster way to compute the sign function (positive or negative) in ReLU for systems where multiple parties jointly perform calculations without revealing their data, reducing the messages they must exchange.
