# Characterizing the Performance of Parallel Data-Compression Algorithms across Compilers and GPUs

**Venue:** SC · **Subtheme:** Performance Modeling

## What It Does

Comprehensive empirical evaluation of 107,632 compression algorithms across compilers (NVCC, Clang, HIPCC) and platforms (NVIDIA, AMD)

Large-scale empirical characterization showing compiler-hardware interaction effects on compression

## The Key Result

- **Algorithms Evaluated:** 107632

## Why This Approach

Evaluates 107,632 compression algorithm variants. Identifies compiler-specific performance patterns (Clang slow compression, fast decompression). Provides guidance for compiler selection

This work addresses the fundamental problem: Compiler choice and GPU platform significantly affect data compression performance; unclear which combinations are optimal

## What It Leaves Open

- Empirical characterization; lacks root-cause analysis of performance differences.
