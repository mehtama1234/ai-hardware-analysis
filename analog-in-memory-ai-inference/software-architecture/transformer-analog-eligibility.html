chapter 02 · analog boundary

Decide what analog is allowed to do

Analog eligibility is not a marketing category. It is a constrained decision combining fixed-weight structure, model sensitivity, converter cost, physical range, calibration, movement, and fallback.

The hidden object: an error budget attached to an operator

An analog array does not return an exact mathematical product. It returns a physical measurement shaped by conductance variation, voltage range, current summation, parasitics, noise, conversion, and calibration. The relevant question is whether the resulting error remains acceptable after the transformer’s subsequent operations.

analog operator → physical signal → converter code → calibrated value → accumulation/nonlinear context → model output → task decision

The model’s sensitivity determines how much physical error can be tolerated. The same residual may be harmless in one projection and catastrophic near a logit tie or control boundary.

Eligibility test

GateQuestionReject condition

Analog error is a stack

Distinguish static programming error, dynamic noise and settling, conversion error, calibration residual, drift, mapping/bit-slice error, and system error from timeout or fallback. Each requires a distribution or bound, not only a nominal residual.

A nominal simulator replay can establish local software evidence. It cannot close the physical converter gate. The converter, model sensitivity, and movement budget must be evaluated together.

Placement policy

fixed-weight matrix + supported precision + sensitivity pass + positive movement benefit + physical pass + fresh calibration → analog

otherwise → digital fallback + first failed gate as reason

The first failed gate must be retained. Fallback is a system behavior with latency, energy, and reliability consequences.

Immediate work

  1. Run sensitivity sweeps per transformer operator.
  2. Identify output-sensitive locations near logits and attention decisions.
  3. Attach movement and conversion costs to every candidate.
  4. Use physical converter evidence to reject illegal ranges.
  5. Generate a placement table with analog, digital, fallback, and reason fields.
  6. Run the same model with all candidates digital to establish the baseline.

Allowed claim

This chapter can claim a conservative operator-level policy for selecting fixed-weight analog candidates under explicit sensitivity, movement, physical, and runtime gates.

Refused claim

It cannot claim that every matrix multiplication should be analog, that Softmax or KV-cache work is automatically suitable, or that a nominal simulator residual proves hardware accuracy.
