Kimi K3, from first principles · Session 03 of 07

Don't pile on. Overwrite.

Linear attention's board blurs because every fact is just added. DeltaNet's fix is almost obvious once you see it: before writing a fact, first read what's already stored there and subtract it, so a new value replaces the old one instead of stacking beside it. That one change turns a fixed board from a smear into an editable memory.

▶ We ran it · overwrite the same key twice

Write value v1 at a key, later write v2 at the same key, then ask for it. DeltaNet returns the new value cleanly (cos +0.78 to v2, +0.00 to the stale v1). Softmax can't update — it kept both copies and averaged them (+0.68 / +0.70, near-equal). Editing in place is the whole point.

In plain words · the problem, then the idea

Erase before you write

The last rung kept a single fixed-size board and blended every new fact smoothly into it. But blending had a cost: if the same label came up twice with different answers, the board just averaged them. It could not fix a fact or change its mind.

The problem. Picture a whiteboard where the marker never fully wipes off. You write 'the capital is Berlin', later learn it should be 'Vienna', and all you can do is write over the first — what's left is a smudge of both, pulled toward the middle. Ask the board later and it mumbles. In the run below, when a fact has been rewritten, the blend-only board hands back a 0.68 match to the new answer and a nearly identical 0.70 to the old one: it has forgotten nothing, and so remembers everything at once, as mush.

The idea. Instead of just adding each new fact, look first. Before writing a value under a label, check what already sits under that label, remove it, and write the new value in its place. That's not blending — it's replacement: one fact per label, and when the fact changes, the label changes with it. The board stays clear because the old entry comes off before the new one goes down.

The name, translated. Researchers call this the delta rule — 'delta' means the difference, the change from old to new. It writes only the gap between what's stored and what's arriving. Models built around it are called DeltaNet.

What it still can't do

That cleanliness costs speed. To erase correctly you must look up the old value, work out the difference, then write — and you can't shortcut that the way you can with plain addition. So every single word needs the same careful three-step dance, which makes training slow. The board is accurate now; the price is paid in time.

The rule · read, subtract, write

A finite board needs an eviction policy

Once memory is a fixed board, you can't keep adding forever — at some point new facts have to take the place of old ones. DeltaNet makes that explicit. For each token it treats the key as an address, reads what's there, and writes only the difference:

# plain linear attention — blind addition S = S + kᵀ v # DeltaNet — read the address first, write only the delta v_old = k · S # what the board already says at key k u = β ( v − v_old ) # the correction: only what's new (β = write strength) S = S + kᵀ u # same outer-product write, but of the delta

If you write the same key again, v_old is the value you stored last time — so the subtraction cancels it and you're left holding just the new value. Old information is removed and new information is written in its place. β (a learned, per-token write strength) controls how forcefully; β=1 is a full replace.

We ran it · update vs accumulate

Only DeltaNet actually updates a fact

The same overwrite experiment, all three mechanisms side by side. Blue = how much the recalled value resembles the new v2; red = how much it still resembles the stale v1. You want tall blue, no red:

DeltaNet
new v2+0.78
old v1+0.00
Softmax
new v2+0.68
old v1+0.70
Linear
new v2+0.17
old v1+0.23

DeltaNet returns the NEW value (high cos to v2, ~0 to v1) — the second write erased the first. Softmax keeps both copies on file, so it AVERAGES them (similar cos to v1 and v2 — it can't update, only accumulate). Plain linear blurs both into noise. This is what 'edit in place' buys: an association can be corrected, not just re-added.

We ran it · does it also fix the blur?

Recall holds up far longer — but a single board still saturates

Back to Session 02's needle test (store N pairs, query one by its exact key), now with DeltaNet added. Subtracting-before-writing keeps correlated writes from stacking into a blur, so DeltaNet recalls much better than plain linear while the board isn't overfull:

x = number of stored tokens N. softmax keeps every note (flat ~1.0); deltanet holds high then falls as the fixed board saturates; linear fades from the start.

The honest catch — and why the next rungs exist

DeltaNet delays the blur but doesn't abolish it: one D×D board has finite capacity, so past ~d writes even DeltaNet's recall collapses (with a hard β=1 it can even churn the needle out entirely). It can replace a fact it has an address for, but it can't fade the board generally for a new topic. Those two gaps — needing to forget broadly, and needing finer control — are precisely what gating (Session 05) and per-channel decay (Session 06) add, and why K3 keeps a few full-attention layers on the side.

The one-line aha

A memory you can rewrite is far more useful than one that can only pile up — being able to forget the old answer is worth the extra care it takes.
