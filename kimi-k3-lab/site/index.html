Hands-on companion

Kimi K3, from first principles.

The path from GPT-2 (2019) to Kimi K3 (2026) is a 22,580× jump in parameters — but the worklog's claim is that scale isn't the story. Each architectural rung changes what the model stores, how it updates that state, or how it retrieves what a fixed-size state can't hold. This lab rebuilds the ladder and runs every rung for real — the claims become measured numbers.

00🗺️Start here · the big picture

No jargon: the one problem the whole GPT-2→K3 lineage solves — how to remember cheaply and smartly — and every rung as an answer to it. Read this first.
01🧱The softmax baseline

GPT-2 attention and the KV-cache wall — the fact every later rung reacts to. Real weights, real cache-growth, no-cache O(N²) vs cache O(N).
02➗Linear attention

ELU+1 folds K,V into a fixed D×D board — the cache stops growing. Real runs: exact re-association, flat decode cost, and the needle-recall fade (0.65→0.08) that prices the tradeoff.
03✏️DeltaNet

The delta rule: read-old → subtract → write-new. Real runs: overwrite the same key twice (DeltaNet replaces cleanly, softmax only averages) + needle recall that holds far longer than linear.
04🧩Chunked DeltaNet

Chunk-wise reparameterization → parallel prefill. Real runs: sequential vs chunked identical to 7e-7 across all C, sequential depth cut 32× (L→L/C), 3–22× faster, and the state/score FLOP split.
05🎚️Gated DeltaNet

Mamba-2 decay meets the delta rule. Real runs: a decay dial that forgets stale context (recall 0.46→0.02) while keeping fresh recall sharp, and the α^Δ survival law verified to 4 decimals.
06🧬KDA / Kimi Linear

Per-channel decay + MLA hybrid. Real runs: per-channel keeps AND forgets (goal 0.86 vs best scalar 0.16), and the 3 KDA:1 MLA interleave reproduces the paper's −75% KV cache.
07🌐Kimi K3soon

23×(3 KDA + 1 MLA) macrocycles, latent MoE, SiTU, Gated MLA, AttnRes. Capacity with a job.
