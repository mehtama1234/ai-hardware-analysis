Kimi K3, from first principles · Session 06 of 07

A separate forget dial for every slot.

Our model can now fade its memory to make room — but it fades everything at the same rate, which is clumsy: a person's name gets forgotten just as fast as a passing detail. This rung gives it a finer touch, letting each kind of information fade at its own speed, so it can hold onto what matters while clearing away the clutter. This is the step where this cheap kind of memory first started matching the expensive keep-everything kind.

▶ We ran it · fine beats blunt

On a task that needs to hold onto some things and drop others at the same time, giving each slot its own fade-dial scores 0.86 — the best a single shared dial manages is 0.16, because one dial has to keep everything or forget everything. And mixing one full keep-everything layer in for every three cheap ones shrinks the memory bill by a flat 75% at any length — matching the real system's reported number.

In plain words · the problem, then the idea

Each kind of thing remembers at its own speed

We had a single forget-dial that dims a fixed-size board evenly — everything fades together. That keeps the cost flat however long the text, but it's blunt: the board treats a person's name the same as a throwaway detail, so it drops what matters just to make room.

The problem. Imagine listening to a mystery with one master volume knob. Turn it down to clear the background chatter and you also mute the detective's key clue; leave it up to keep the clue and you drown in noise. One dial forces all-or-nothing. In a real passage a name or a plot twist should stick for the whole stretch, while what someone had for lunch can go almost immediately — but a single dial fades them at the same rate. The board can't hold some things steady while clearing others in the same step.

The idea. Give every separate slot on the board its own forget-dial. Now, as each word arrives, some slots fade slowly — holding names and key facts — while others fade fast, clearing small talk. The slot tracking 'who is speaking' turns its dial down gently so that identity lives for dozens of words; a slot tracking something that resets constantly turns its dial down hard. Same fixed-size board, but now it can be selective: keep what serves the thread, drop what clutters it, all at once.

The name, translated. Researchers call this per-slot (fine-grained) gating; in Moonshot's Kimi Linear model it's the core idea, named Kimi Delta Attention. Each slot simply gets its own fade-speed.

What it still can't do

Even with per-slot fading, a fixed board still can't recall everything that ever happened. So the model keeps a few full keep-everything layers on the side for the moments that truly need exact recall — mixing one full layer in for every three cheap ones, which is what cuts the memory bill by about 75% in the real design.

The move · one fade dial per slot

A separate fade for every slot

Everything else stays the same; the one change is that the fade is no longer a single number for the whole page — it's one number per slot, each learned on its own:

# before — one fade for the whole page page = fade × page + change # a single number # now — a fade per slot: each slot keeps or forgets at its own rate page = (fade-per-slot) × page + change # slot 1 might be 0.99, slot 2 might be 0.70

Now a "keep" slot can sit at 0.99 (barely fades) while a "forget" slot right next to it runs at 0.70 (fades fast) — at the same time. In the report this is the "finer-grained" forgetting that makes better use of a small fixed memory, and it is the heart of the system called Kimi Linear.

The task needs two things at once: hold the 'keep' slots and clear the 'forget' slots. Giving each slot its own dial does both (keep stays high, forget drops to near zero) for a goal score far above any single dial. One shared dial is forced to choose: set it to 0.99 and it keeps everything (never clears the clutter); set it to 0.70 and it forgets everything (loses what mattered). Per-slot control is simply more capable — the exact gain that lets this cheap memory match the keep-everything kind.

We ran it · the hybrid, and the −75%

Mostly the cheap page, a little full memory

The cheap fixed page still can't recall everything perfectly (Sessions 03–05). So the real system mixes two kinds of layer: mostly the cheap kind, with one full keep-everything layer every fourth. Only those full layers hold a store that grows with the text — so the memory bill drops by exactly the fraction of layers that are cheap:

The cheap layers keep a fixed-size page, so only the 1-in-4 full layers hold a store that grows with the text. That's a flat 75% cut in memory at every length — exactly the up-to-75% smaller memory the Kimi Linear report gives, and the same structure behind its up-to-6× faster generation on very long text. The full layers are the 'keep a little perfect memory' hedge; the cheap ones carry the rest.

One more twist · even the full layers are cheap

Those full keep-everything layers aren't the expensive original kind either. Before a note is stored, it's squeezed into a small shared summary — like keeping a photo instead of the whole video — so the kept notes take far less room than storing everything in full. Even the "expensive" layers come cheap. Researchers call this compressed keep-everything memory Multi-head Latent Attention (MLA); "latent" just means that squeezed-down form.

The one-line takeaway

The moment each kind of information is allowed to fade at its own speed, cheap fixed-size memory starts to rival the expensive keep-everything kind — because matching the shape of the problem beats brute force.
