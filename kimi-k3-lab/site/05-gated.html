Kimi K3, from first principles · Session 05 of 07

Add a dial for forgetting.

DeltaNet can correct a fact it recognizes — but it has no way to let go of old context when the subject changes. Gated DeltaNet adds one number, borrowed from Mamba: a decay α that gently fades the whole board every step before writing. Now the memory can forget on purpose, and old clutter stops crowding out new information.

▶ We ran it · forgetting on a dial

Write an old topic, then a new one, then recall. Ungated (α=1) leaves the stale topic fully present (recall 0.46). Turn the dial to α=0.9 and the stale topic fades to 0.02 — forgotten — while the fresh topic stays sharp (0.92). And a memory left for Δ steps comes back scaled by exactly α^Δ (measured = predicted to 4 decimals).

The rule · decay, then write

One number that fades the whole board

The delta rule only touches the key it's writing. Mamba's contribution is the opposite reflex — shrink everything a little each step, so the board naturally makes room. Gated DeltaNet does both: decay first, then the delta write:

# DeltaNet: correct one address, never fade S = S + kᵀ u # Gated DeltaNet: fade the whole board by α, then write the delta S = α · S + kᵀ u # α=1 → pure DeltaNet · α=0 → wipe the board

Because α multiplies the entire state each step, a value written at time t and read Δ steps later has been multiplied by α a total of Δ times → α^Δ. Recent writes are loud; distant ones fade geometrically unless refreshed. That's a general "forget" the delta rule couldn't express.

We ran it · forget the old, keep the new

Turning α down clears stale context

We write an early "topic-A" needle, fill in with a later "topic-B" batch, then recall each. Watch what the decay dial does as we turn it from 1.0 (never forget) down toward 0.80 (forget fast): the stale A memory fades away, while fresh B stays sharp — until decay gets so aggressive it starts eating the present too.

α=1 is ungated DeltaNet: the stale early needle (A) is still fully on the board, cluttering the fresh late needle (B). As α drops, the old topic FADES (stale_A_recall falls — that's the board forgetting) and the recent topic comes back CLEANER (fresh_B_recall rises) because the early clutter has decayed away. Push α too low and even B starts to fade — decay is a dial, and its best setting is data-dependent, which is exactly what the model learns.

We ran it · the α^Δ law

A memory's strength is a running discount

To isolate the decay, we write one value, then take Δ steps that only fade (no new writes), and measure how much of it survives. It comes back scaled by exactly the running product of the decays — a constant α here, so α^Δ:

A value written then left untouched for Δ steps comes back scaled by the running product of the decays — here a constant α, so exactly α^Δ. Measured matches predicted to a few thousandths. This multiplicative discount is the 'cumulative decay' (γ) term: a token's influence shrinks geometrically with how long ago it was written, unless it keeps getting refreshed.

See it · the fade dial

Old writes dim; new writes stay bright

The same board, now with a decay applied every step. Early cells (the old topic) dim toward black as time passes; the newest writes stay bright. That's what "forget generally" looks like — no address needed, the whole board just relaxes toward empty:

—

Each step multiplies every cell by α (<1). A refreshed cell jumps back to full; an untouched one keeps fading. The dial α is learned and data-dependent — the model decides when to hold on and when to let go.

The one-line aha

One decay dial turns a memory that could only be overwritten into one that can also forget — fading the whole board a little each step so a new topic isn't buried under an old one. But α fades every feature by the same amount, and not all memories deserve the same fate.
