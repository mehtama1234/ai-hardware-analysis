Kimi K3, from first principles · Words, translated

The plain words, and their real names.

The lab explains everything in plain language on purpose — "keep every note", "a forget dial", "reach back across depth". But those ideas all have real technical names in the papers. This page is the bridge: every plain phrase we used, next to the term you'll meet if you go read the source. Plain on the left, real on the right.

The memory mechanisms · one per rung
"keep every note" · "re-read everything"→(softmax) attention · "full attention"Score every earlier word, blend them. The GPT-2 baseline. · Session 01
"the growing pile of notes"→the KV cacheThe stored keys & values full attention must keep for every past word. · Session 01
"re-read everything, cheaply"→FlashAttentionSame answer, computed in tiles without ever building the whole comparison grid. · Session 01
"one running summary" · "a fixed page/board"→linear attentionFold all past keys & values into one fixed-size state; flat cost. · Session 02
"erase-first page" · "erase, then write"→the delta rule · DeltaNetRead a key's old value and subtract it before writing the new one. · Session 03
"work in blocks" · "a summary between blocks"→chunk-wise (parallel) formReal attention inside a chunk, a carried state across chunks — same answer, parallel. · Session 04
"a forget dial" · "fade the page"→gating · a decay gate (from Mamba)Multiply the whole state by a factor each step so old context fades. · Session 05
"a dial per slot" · "each thing fades at its own speed"→Kimi Delta Attention (KDA) · fine-grained gatingA separate decay rate per channel — the core of Kimi Linear. · Session 06
The assembly · Kimi K3
"full memory, but compressed"→Multi-head Latent Attention (MLA)Keep-everything recall, but each note squeezed to a small latent summary first. · Session 06–07
"a crowd of specialists" · "the chooser"→Mixture-of-Experts (MoE) · the routerHundreds of expert sub-networks; a router wakes a few per word. · Session 07
"the squash" · "a squash that levels off"→activation function · SiLU → SiTUThe step that reshapes numbers; K3's version is bounded so it can't run away. · Session 07
"reach back across depth"→Attention Residuals (AttnRes)A later layer scores earlier layers and pulls the one it needs, instead of an equal blend. · Session 07
"a repeating group of four layers"→a macrocycle (3 KDA + 1 MLA)The backbone repeats this group 23 times = 92 layers. · Session 07
Training · how it learns
"grow the reading length gradually"→progressive / curriculum context extensionStart on short text, lengthen it as training goes. · Bonus
"trial-and-error practice"→reinforcement learning (RL)Learning from reward on its own attempts. · Bonus
"merge nine specialists into one"→Multi-Teacher On-Policy Distillation (MOPD)One model learns to imitate nine separately-trained specialists. · Bonus
"design the model and machines together"→algorithm–system co-designArchitecture and hardware shaped hand-in-hand. · Bonus
Everyday shorthands
"word"→tokenThe chunk of text a model actually processes (often a word or word-piece).
"internal settings" · "size"→parametersThe learned numbers; K3 has 2.8 trillion, ~104B active per word.
"slot" · "channel"→a dimension of the stateOne coordinate of the memory vector.
"the must-wait chain"→sequential dependency (depth)Steps that must run one after another because each needs the last.
"work" · "operations"→FLOPsFloating-point operations — a count of raw arithmetic.
