Kimi K3, from first principles · Session 06 of 07

One decay rate per channel.

Gated DeltaNet fades the whole board by a single number — too blunt, because different kinds of memory deserve different fates. Kimi Delta Attention (KDA) gives every channel its own decay rate. The board can hold some dimensions steady while clearing others in the very same step. That fine-grained control is Kimi Linear's headline move — the first linear attention to beat full attention under fair comparison.

▶ We ran it · fine beats blunt

On a task that needs "keep these channels and forget those," per-channel KDA scores 0.86 — the best any single scalar can manage is 0.16, because one number must either keep everything or forget everything. And interleaving 3 KDA layers per MLA layer cuts the KV cache by a flat −75% at every context length — the paper's number, from first principles.

The move · a vector, not a scalar

Decay becomes per-channel

Everything else about the gated delta rule stays; the one change is that the decay α is no longer a single number multiplying the whole board — it's a vector, one rate per channel:

# Gated DeltaNet — one α fades everything equally S = α · S + kᵀ u # α is a scalar # KDA — each channel c fades at its own learned rate S = diag(α) · S + kᵀ u # α is a vector: α_c per channel

Now a "keep" channel can sit at α≈0.99 while a "forget" channel next to it runs at α≈0.7 — simultaneously. In the paper this is the "finer-grained gating mechanism ... enabling more effective use of limited finite-state memory," implemented with a hardware-efficient Diagonal-Plus-Low-Rank (DPLR) chunkwise kernel.

We ran it · keep AND forget, at once

A single scalar can't do both

The task needs two things at once: hold the 'keep' channels and clear the 'forget' channels. Per-channel KDA does both (keep≈high, forget≈0) for a goal score far above any scalar. A single α is forced to choose: α=0.99 keeps everything (never forgets the clutter), α=0.70 forgets everything (loses what mattered). Fine-grained gating is strictly more expressive — the exact capacity gain that lets Kimi Linear beat full attention.

We ran it · the hybrid, and the −75%

Mostly KDA, a little full attention

KDA is cheap but a fixed board still can't recall everything perfectly (Sessions 03–05). So Kimi Linear interleaves layers: mostly KDA, with a full-attention (MLA) layer every fourth. Only those MLA layers keep a KV cache that grows with context — so the memory bill drops by exactly the fraction of layers that are cheap:

KDA layers keep a fixed-size board, so only the 1-in-4 MLA layers hold a cache that grows with context. That's a flat 75% KV-cache reduction at every context length — exactly the up-to-−75% Kimi Linear reports, and the same structure behind its up-to-6× decode throughput at 1M tokens. The MLA layers are the 'keep a little perfect memory' hedge; KDA carries the rest cheaply.

See it · channels on their own clocks

Some columns hold; others fade

The board's columns, each decaying at its own rate. The left columns (α≈1) barely dim — they keep their memory; the right columns (small α) fade fast. One board, many different retention times — impossible with a single dial:

—

Each column has its own α, shown above it. Every step multiplies each column by its own rate; occasional writes flash a cell back to full. The decay profile across channels is learned per token.

The one-line aha

Turning the single decay dial into one-dial-per-channel lets a fixed board keep and forget at the same time — the small expressiveness gain that finally makes linear attention competitive with full attention, while a few interleaved full-attention layers cover what a fixed board still can't.
