GPU kernels and LLM serving lab - Session 10

The KV cache behaves like a memory allocator.

PagedAttention-style serving is easier to understand once tokens become blocks. This session simulates block allocation, capacity pressure, and prefix reuse.

Simulation assumptions

16 tokens per block

Capacity is 4096 blocks. This is a block allocator model, not vLLM internals.

Boundary

This proves the memory-accounting shape of block-based KV allocation and prefix reuse. It does not claim to reproduce vLLM's exact scheduler or eviction policy.
