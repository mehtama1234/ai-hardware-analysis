Worked walkthroughs for the core GPU labs.

How To Use These

Read the claim, inspect the named files, predict the result, run the command, change one variable, and explain the measured change.

Walkthroughs

CUDA Memory Access

Adjacent threads should read adjacent addresses when the goal is high bandwidth.

Triton Fused Softmax

Softmax can avoid extra memory traffic by keeping row state inside one fused program.

JAX Roofline Model

A workload is compute-limited only when it has enough arithmetic work for each byte moved.

KV Cache Blocks

Serving long prompts becomes memory work unless cached key and value blocks are reused and accounted for.

Speculative Decoding

A draft model helps only when accepted tokens save more target-model work than rejected tokens waste.

Quantization Format Choice

Fewer bits reduce storage, but the result is useful only if error and dequantization cost stay inside the workload limit.

Distributed Collectives

A training step can wait on communication even when each GPU has enough compute.

GPU Evidence Gate

A project should not claim real accelerator proof unless the measurement came from a real accelerator host and passed the metric contract.
