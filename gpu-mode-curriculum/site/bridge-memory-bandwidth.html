Steps

  1. Read JAX Scaling Book - All About Rooflines and write down the claimed bottleneck model.
  2. Open GPUMODE lesson #115: Lecture 4 Compute and Memory Basics and extract the kernel/runtime concept that should be measurable.
  3. Run gpu-kernels-serving-lab/23-gpumode-shared-memory-gemm and preserve the generated JSON artifact.
  4. Compare 23-gpumode-shared-memory-gemm/out_gpumode_shared_memory_gemm.json against the source model and the GPUMODE lesson concept.
  5. Use Hybe: GPU-NPU Hybrid System for Efficient LLM Inference with Million-Token Context Window as the research cross-check for whether this bottleneck appears in current AI systems work.

Success Checks

  • Correctness status is passed or the artifact records an explicit environment-gated skip.
  • The generated tutorial page names the same bottleneck class as the workbench profile.
  • The measurement summary explains what changed or why real GPU execution was unavailable.
  • At least one GPUMODE lesson, external tutorial source, and corpus paper can be traversed from the profile page.
