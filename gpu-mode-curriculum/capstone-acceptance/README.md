# Capstone Acceptance

This layer grades the whole GPUMODE curriculum stack as a portfolio artifact.
It reads the generated reports and scores the result across lesson coverage,
programming projects, comprehensive labs, kernel source, custom ops, autotune,
model integration, serving, regression, GPU promotion, runtime gates, site, and
audit evidence.

## Run

```bash
python3 scripts/build_capstone_acceptance.py
python3 scripts/verify_capstone_acceptance.py
```
